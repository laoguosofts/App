## ✨ MyBoy 是什么

MyBoy 是一款专为 Android 平台打造的 Game Boy Advance（GBA）模拟器，它让你在手机上就能运行原版 GBA 游戏 ROM——无论是宝可梦系列、马里奥赛车、瓦里奥制作还是那些年沉迷过的像素神作，统统可以揣进兜里随时开玩。

相比同类模拟器，MyBoy 的核心优势在于联机和外设支持做得特别扎实：用蓝牙就能仿真 GBA 联机线卡，两台手机之间交换存档、对战或合作；完整版还支持几乎所有能被 Android 识别的蓝牙/USB 手柄，映射完按键之后的手感跟原版掌机几乎没有区别。另外它还能把手机本身的硬件传感器（陀螺仪、环境光传感器、振动马达）映射到 GBA 特殊卡带的仿真上——比如宝可梦金/银的太阳能卡带、瓦里奥小游戏的倾斜感应、路易吉洋馆的振动反馈，这些原版卡带里才有的硬件特性，MyBoy 都用手机自身能力给复刻出来了。

适合谁用？如果你是 GBA 老玩家，想把存档从旧掌机迁移到手机上继续玩；或者是从没接触过 GBA 的新玩家，想体验一下二十年前的那些像素神作，MyBoy 都是一个成熟稳定的选择。免费版已经能覆盖大部分单机场景，完整版解锁联机服务器、完整手柄映射和传感器仿真的全部功能。

## 🔧 安装步骤

### Android 平台安装

MyBoy 目前仅支持 Android，iOS 上暂无官方版本。安装流程和大多数第三方 APK 一样：

1. 从上面的下载入口获取 APK 文件
2. 如果是首次安装未知来源应用，需要在系统设置里授权：**设置 → 安全 → 允许未知来源安装**（不同厂商 ROM 的路径略有差异，小米、华为、OPPO 等都需要手动开启这个开关）
3. 点击下载好的 APK 文件，按提示一路下一步即可

> [!WARNING]
> 安装完成后建议立即在应用内核对版本号——打开 MyBoy 进入「设置 → 关于」，确认版本号与下载页标注的一致，避免安装到被二次打包的修改版。

## 📖 使用入门

### 加载第一个游戏

打开 MyBoy 之后，它会自动扫描手机存储里的 .gba 文件。如果扫描不到，手动进入「MENU → 加载游戏」浏览到你的 ROM 存放目录选中即可。

> [!TIP]
> ROM 文件的来源请确保合法合规，推荐从自己拥有的实体卡带通过合法手段导出备份。

### 屏幕布局与虚拟按键

首次进入游戏时，屏幕上会覆盖 GBA 的按键布局——方向键、A、B、L、R、START、SELECT 全部触控可点。长按任意按键可以进入「屏幕布局编辑器」，在这里你可以：

- 调整每个按键的位置和大小（拖动即可）
- 改变按键的透明度（手指长时间操作时透明度调低更不挡画面）
- 添加额外的快捷按钮，比如直接保存/加载状态

### 连接蓝牙手柄彻底解放手指

配了手柄的体验和纯屏幕触控完全是两个档次。完整版支持几乎所有能被 Android 系统识别的蓝牙或 USB 手柄，包括 Xbox、PS、Switch Pro、MOGA、飞智、iPega 等品牌的主流型号。

配对流程分两种：

**蓝牙手柄：**

1. 打开手柄的蓝牙配对模式（通常按住配对键几秒，指示灯闪烁即表示已进入配对）
2. 进入 Android 系统设置 → 蓝牙 → 扫描设备，等手柄出现在列表里后点击配对
3. 回到 MyBoy，进入「设置 → 按键映射」，此时手柄的按键会自动出现在映射列表里

**USB OTG 手柄：**

1. 确认手机支持 USB OTG（大多数中高端机型都支持，不确定的话可以插个 U 盘试试能不能读出来）
2. 用一根 OTG 转接线把手机和手柄连起来
3. MyBoy 会自动识别，直接进按键映射检查就行

配对成功后逐个编辑 GBA 按键的映射目标——每编辑一个，直接按一下手柄上想分配的那个物理按钮，MyBoy 会自动记录下来。有些手柄还带额外的功能键，也可以映射到 MyBoy 的快捷按钮（比如直接保存状态或加载状态）。

**最后一步别忘了回屏幕布局编辑器把全部虚拟按键的透明度调到 0**，画面瞬间干净，再也不会出现手指挡住战斗画面的尴尬情况。

### 传感器仿真——把手机硬件当卡带用

GBA 有一些特殊游戏卡带内置了额外硬件，原版不可能物理复刻，但 MyBoy 用手机自带的传感器一一对应仿真：

- **陀螺仪 / 加速度计**：仿真卡带的倾斜传感器，玩需要旋转设备的游戏时真实转动手机就行
- **环境光传感器**：仿真宝可梦金/银的太阳能卡带——白天把手机放窗边就能捕获那些只在光线下出现的特殊宝可梦
- **振动马达**：仿真卡带内置的振动电机，路易吉洋馆里碰到幽灵时机身会同步震一下

进入「设置 → 卡带功能」可以看到三个开关：启用传感器作为输入、传感器灵敏度滑杆（0~100% 可调）、以及振动开关。

> [!NOTE]
> 如果发现太阳能仿真不太明显，把灵敏度调到 70% 以上，手机直接对着强光（太阳光或台灯），别放在兜里。极个别 Android 设备传感器兼容性不好的，MyBoy 里还有「强制高/低光照」选项可以绕过传感器直接手动设定。

### 联机对战——蓝牙仿真联机线卡

原版 GBA 侧面有个联机端口，插上一条线卡就能把两台掌机连在一起交换存档、对战或合作。MyBoy 直接用蓝牙/USB/WiFi 来代替那根实体线，在手机上就能实现同样的联机效果。

**基础前提：**

- 双方都安装 MyBoy，且至少一方为完整版（完整版才能当服务器）
- 两边的 ROM 文件必须是**同一个版本**——不同语言、不同汉化版本之间线卡协议有细微差异，大概率连不上
- 双方都打开了游戏内的联机功能（通常在游戏的「联机」或「对战」菜单）

**操作流程（蓝牙为例）：**

1. 一方打开 MyBoy 加载游戏，进入「MENU → 联机 → 联机设置 → 勾选「作为服务器」，通信方式选「蓝牙」，停留在联机等待画面**不要退出**
2. 另一方打开同一个游戏，进入「MENU → 联机 → 扫描设备」
3. MyBoy 弹出蓝牙扫描列表，找到对方手机并点击配对
4. 配对成功后客户端自动连上服务器，两边同时进入游戏内联机菜单即可开始

**WiFi 联机**的流程类似，区别是服务器端会显示一个 IP 和端口号（默认 12345），客户端手动输入这个地址就行。同设备联机则是打开两个 MyBoy 实例——一个当服务器一个当客户端，适合不方便拿两台手机的时候自己跟自己交换存档。

### 联机连不上？按这个顺序排查

| 现象 | 排查方向 |
|---|---|
| 扫描不到对方设备 | Android 12+ 手动开启「对附近设备可见」；双方蓝牙都要打开 |
| 配对成功但连不上 | 距离控制在 10 米内，远离微波炉、路由器等干扰源 |
| 连上后游戏没反应 | 两边 ROM 版本必须严格一致，不同语言/汉化版基本连不上 |
| WiFi 下连接超时 | 路由器是否开了「AP 隔离」（客户端隔离），关掉即可；公共 WiFi 几乎全开 AP 隔离，换蓝牙 |
| 打开第二个实例后第一个被杀 | 手机后台清理了——开发者选项里关掉「不保留活动」，或给 MyBoy 锁后台 |

如果以上都不行，对调一下服务器/客户端角色再试一次，或者用「同设备联机」做基准测试——同设备能连上说明问题在蓝牙/WiFi 通道，同设备也连不上可能是 MyBoy 或 ROM 版本的问题。
