## ✨ FPA 是什么：免 Root 跑 Xposed 模块的新选择

FPA 是一款面向 Android 的应用补丁工具，它的核心定位只有一句话——让你在**不 Root 手机**的前提下，把 Xposed 模块注入到单个应用里。

传统的 Xposed 框架需要先给手机 Root，然后在系统层面注入 Hook 机制，全局拦截所有应用进程。这条路在安卓 12 之后开始出现兼容问题，安卓 15 以上基本跑不动了。FPA 走的是另一条路：它不碰系统，而是把 Hook 框架**打进目标应用的安装包里**，一个应用一份补丁——改坏了只影响被 patch 的那个应用，卸掉重装原版就恢复，系统本体毫发无损。

这种设计决定了 FPA 的作用边界：它只能作用于被 patch 的那个应用，碰不到系统进程。所以那些作用域包含系统框架的模块（比如改状态栏、改系统动画的）在 FPA 上注定用不了，但只针对单个应用的模块（比如改汽水音乐的播放体验、改某个工具的界面）完全没问题。

FPA 目前社区口径持续更新至 v3.8，主打安卓 12/15 以上机型，正好填补了高版本安卓用户从 LSPosed 转过来后的空档。

## 🔧 安装步骤：装上就能用的免 Root 方案

FPA 的安装过程比传统 Root + LSPosed 简单得多，全程不需要解锁 Bootloader、不需要刷 Magisk。但有几个注意点不能跳过。

### 安装前的准备

- 确认手机系统版本在安卓 12 及以上（低于 12 的机型 FPA 没有优势）
- 腾出至少 500MB 存储空间（打包过程会临时占用较多空间）
- 目标应用先从应用商店装好原版（后面 patch 会覆盖）

### 安装流程

1. **安装 FPA 本身**：从下载页拿到 APK 后直接安装，第一次打开需要授予存储权限等必要授权。

2. **开启未知来源安装**：FPA 打包后的应用安装时，系统可能提示「未知来源」，到设置里给 FPA 授权安装应用即可。

3. **确认 FPA 不能卸载**：这一点非常关键——过签后的应用会检测 FPA 包名，FPA 卸了，patch 过的应用直接打不开。把 FPA 当作系统级工具留在手机里就好。

> [!WARNING]
> FPA 不能卸载！过签后的应用会校验 FPA 是否存在，卸载 FPA 会导致所有 patch 过的目标应用直接闪退。

## 📖 使用入门：从 Patch 到模块生效

FPA 的日常使用可以归纳为一个循环：**选应用 → 执行 Patch → 装模块 → 勾选 → 重开应用**。以社区实测最多的汽水音乐为例，完整流程走一遍就能掌握。

### 基础操作：给应用打补丁

1. 打开 FPA 主界面，点右下角**加号**按钮
2. 在应用列表里选中你要 patch 的目标应用（比如汽水音乐）
3. 点击**执行 Patch**，等待打包完成——这个过程可能需要几分钟，取决于应用体积和手机性能
4. 打包完成后 FPA 会提示安装，此时系统可能报「签名冲突」——**先卸载原版应用**，再回到 FPA 点安装
5. 装好 patch 版之后，先正常登录一次，确认基础功能正常

### 给 patched 应用挂模块

应用成功 patch 并安装后，就可以挂 Xposed 模块了：

1. 把你想用的模块（APK 格式）装到手机上
2. 重新打开 FPA，在应用列表里找到刚才 patch 过的应用
3. 点进去，勾选你装好的模块
4. **把目标应用从后台完全退掉，重新打开**——模块才会生效

> [!NOTE]
> 为什么必须重开应用？因为 FPA 是在应用启动时注入 Hook 框架，应用已经在运行时再勾模块，当前进程不会加载。杀后台重开是关键一步，跳过了就会误以为模块没用。

社区实测显示，汽水音乐的 18.9.0、19.8.0、20.6.0、20.8.0、21.1.0 五个版本全部能在 FPA 3.8 上成功过签，配合 MoonHook、WinHook 等模块实现播放体验优化。这个结果的前提是**版本匹配**——旧版 FPA 可能失败，3.8 版本恰好调整了过签方案。

### 模块加载失败的排查思路

模块勾了不生效、导入报错、列表里不出现——这三类情况大多数可以按下面的顺序排查，比凭感觉重装快得多：

| 排查方向 | 说明 |
| --- | --- |
| 版本匹配 | 模块版本与 FPA 版本凑不上是最常见原因，两边都换到最新版再试 |
| 文件完整 | 模块 APK 下载不完整会导致导入报错，重新下载一份 |
| 权限缺失 | FPA 或目标应用的必要权限没给，特别是 Shizuku 相关授权 |
| 重启应用 | 部分模块需要重开应用甚至重启手机才生效 |
| 作用域不对 | 模块本身作用域含系统框架（FPA 上注定无效），或没勾给当前应用 |
| 加载冲突 | 多模块混挂可能互相干扰，先只留一个模块验证 |

> [!TIP]
> 排查无果时先升级 FPA 到最新版——同一目标应用，旧版 FPA 失败、新版成功的情况在社区里屡见不鲜。

### 社区与更新渠道

FPA 的作者在应用内置了 Telegram 频道入口，打开 FPA 主界面底部就能看到。新版本发布、问题说明、过签方案调整都从这个渠道出。社区讨论则散布在安卓玩机论坛，搜「FPA + 目标应用名」大概率能找到真人实测的排雷记录。

关于「最后一版」的传闻：2026 年 10 月社区有用户认为 3.8 可能是最后一个版本，但截至目前作者没有正式宣布停更。无论如何，社区对免 Root 框架的维护成本有共识——对用户来说，把好用的「应用 + 模块 + FPA 版本」组合各组件安装包留底，是面向长期的稳妥策略。
