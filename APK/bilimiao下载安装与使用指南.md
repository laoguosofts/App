## ✨ 哔哩喵是什么

哔哩喵（bilimiao）是一款面向 B 站生态的第三方客户端，核心定位是「时光机」——让用户能够回看 B 站历史时间段的热门视频，而不仅仅依赖首页推荐。它在官方客户端的基础上扩展了分区筛选、区域代理、弹幕三模式独立配置等实用功能，覆盖手机、平板、手表等多种设备形态。

与 B 站官方客户端相比，哔哩喵的差异化主要体现在两个方面：一是时光机功能，通过时间维度 + 分区维度的交叉筛选，帮助用户挖掘被时间遗忘的优质内容；二是播放器层面的精细化控制，包括弹幕密度的场景化独立设置、代理服务器配置等。适合经常追番、喜欢考古旧视频、或者对播放器有个性化需求的 B 站重度用户。

## 🔧 怎么安装

哔哩喵的常规版是一个约 30MB 的 APK 文件，安装流程与绝大多数 Android 应用一致，但有几个注意点值得提前了解。

### Android 安装步骤

1. **允许未知来源**：如果是首次从应用商店之外安装应用，需要先在系统设置中打开「允许安装未知来源应用」开关。路径因品牌而异，常见位置是「设置 → 安全 → 应用安装权限」。
2. **下载 APK**：从下载页获取最新版本的安装包，建议核对文件大小（约 30MB）和版本号后再安装。
3. **安装确认**：点击 APK 文件后系统会弹出安装界面，点击「安装」即可。首次安装可能需要授权存储、网络等基本权限。
4. **版本核对**：安装完成后进入应用「设置 → 关于」，确认版本号与下载时一致。

> [!TIP]
> 安装过程中如果系统弹出杀毒软件拦截提示，属于 Android 第三方应用安装的正常现象，选择「允许本次安装」即可。如果反复出现，可以先临时关闭杀毒软件的实时防护。

### 版本形态选择

哔哩喵提供三种版本形态，根据你的使用场景来选：

| 你的需求 | 推荐版本 |
| --- | --- |
| 普通手机用户、追最新功能 | 常规版（夸克/GitHub） |
| 重视隐私、偏好纯开源 | F-Droid FOSS 版 |
| 安卓手表设备 | 手表版 |
| 车机/平板 | 常规版（横屏已优化） |

常规版功能最全，包含所有组件；FOSS 版移除了闭源依赖库，代码更干净但更新节奏略滞后；手表版单独打包，界面做了大幅简化，只保留核心浏览和播放功能。

### 版本号解读

版本号形如 **v2.4.8.1**，其中第一位大版本（2）代表完整客户端时代，第二第三位（4.8）是功能迭代，最后一位（.1）是小修复补丁。安装时注意选择最新稳定版。

## 📖 从追番到时光机：核心功能上手

哔哩喵的功能模块可以分为三个层次：基础浏览与播放、时光机核心、播放器进阶。下面按使用频率和学习曲线逐步展开。

### 基础浏览

首次打开应用会进入首页推荐流，与官方客户端类似但弹幕默认关闭（避免竖屏小窗口被弹幕盖满）。你可以通过顶部分类入口快速跳转到动画、游戏、鬼畜、音乐等分区，也可以使用内置搜索功能查找特定的 UP 主或视频。

### 时光机：回看历史热门

这是哔哩喵最核心的功能。时光机让你设定一个时间范围（具体日期、月份跨度或自定义区间），然后展示该时间段内 B 站各分区的热门视频列表。

设置时间范围后，配合分区筛选可以进一步缩小范围。分区筛选是时光机的纵轴维度——与时间横轴交叉后，你可以精确定位到「2023 年 3 月动画分区的热门」或「2022 年春节期间游戏分区的热门」。

B 站主要分区覆盖动画（国创番剧、日番、短片）、游戏（攻略、实况、测评）、鬼畜（音 MAD、鬼畜调教）、音乐（UP 主原创、翻唱、演奏）、科技（数码评测、AI、编程）、生活（日常、搞笑、美食）、影视（影评、剪辑、解说）、知识（科普、历史、教育）八大类。

在时光机热门列表中可以切换三种排序方式：**播放量**（该时间段内累计播放最多）、**弹幕量**（弹幕互动最密集）、**评论数**（讨论最热烈）。不同排序适合不同的考古目的——想找最火的看播放量，想看社区讨论度看弹幕和评论。

### 弹幕三模式独立设置

官方 B 站客户端的弹幕设置是全局一套：你在全屏播放时觉得密度刚好，切到首页推荐的竖屏小窗口，弹幕可能把画面整个盖住。哔哩喵把这个问题彻底解决了——它将弹幕场景拆成三个独立配置：

| 模式 | 适用场景 | 典型设置 |
| --- | --- | --- |
| 首页推荐 | 竖屏小窗口快速浏览 | 关闭或极低密度 |
| 视频详情页 | 中等窗口预览 | 中等密度 |
| 全屏播放 | 沉浸观看 | 最大密度 + 所有类型 |

每种模式下的参数独立保存、互不影响，包括是否开启、字体大小、透明度、弹幕速度、显示类型（滚动/固定从右/从左/底部/顶部/彩色）、行数上限（同屏最多显示多少行）。

进入设置路径：视频播放时点击屏幕中央调出控件 → 点击弹幕开关旁的设置图标 → 切换到对应模式标签页配置。设置即时生效，退出菜单时自动保存。

> [!NOTE]
> 弹幕行数上限是防止画面被盖满的关键参数，推荐首页模式设为 0 行（直接关闭），详情页设 3~5 行，全屏播放设 10 行以上。

### 区域代理：访问港澳台番剧

B 站部分分区（港澳台番剧、海外纪录片）因版权原因不对大陆地区开放。哔哩喵内置了代理设置功能，可以通过配置代理服务器访问这些受限内容。

配置路径：**设置 → 网络 → 区域代理**。从 v2.3.1 版本起支持设置请求参数和请求头，比简单 HTTP 代理更灵活。代理类型分为三类：

| 类型 | 适用场景 | 配置难度 |
| --- | --- | --- |
| HTTP 代理 | 基础代理转发 | 简单 |
| HTTPS 代理 | 加密代理通信 | 简单 |
| 请求头注入 | 修改 API 请求头绕过检测 | 中等 |

> [!WARNING]
> 代理服务器需要自行准备，哔哩喵不提供内置节点。使用代理绕过区域限制可能违反 B 站服务条款，请自行评估合规风险。代理设置仅影响哔哩喵本身，不会修改系统全局网络配置。

### 横屏优化与多设备支持

对于平板、车机等大屏设备，哔哩喵的常规版已经做了横屏布局优化，播放器会自动检测屏幕方向并切换到适合的界面。如果你有 Android Wear 手表设备，可以单独安装手表版，界面做了大幅简化，只保留核心浏览和播放功能。
