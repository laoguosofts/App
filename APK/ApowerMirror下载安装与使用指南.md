## ✨ ApowerMirror 是什么

ApowerMirror 是一款跨平台屏幕镜像与操控工具，能把手机画面实时投射到电脑或另一台移动设备上，同时支持用电脑反向操控安卓手机。桌面端覆盖 Windows 和 macOS，移动端提供安卓和 iOS 两个版本，无线连接依赖同一局域网，也支持 USB 数据线兜底。

核心功能集中在三件事：**手机投电脑**（最常用的场景，演示、录屏、玩手游都走这条）、**电脑控安卓**（用键鼠点手机界面，打字比触屏快得多）、**移动设备互投**（两台手机或平板之间直接镜像，不用电脑中转）。免费版单次镜像有分钟级时长限制，付费版解除限制并解锁录屏、截图等附加工具。

它适合三类用户：需要把手机内容搬到大屏的演示党、想在电脑上用键鼠操作安卓的重度用户、以及手头没有投屏设备时用来应急分享画面的人。如果你经常需要把手机屏幕展示给同事或家人，又不想凑到小屏幕前，这款工具能省不少事。

## 🔧 安装步骤与常见坑

桌面端和移动端的安装门槛差异不小，分别说。

**移动端**是最省心的一环——应用商店搜名字直接装，iOS 没什么门槛，安卓首次打开时需要在系统设置里给应用授予"显示在其他应用上方"和"麦克风"权限，否则投屏后画面正常但没声音。装完建议立刻打开一次确认弹窗授权，别等到投屏时才手忙脚乱。

**Windows 桌面端**是故障高发区，主要集中在两类问题：

**安装路径与运行库**

安装时如果弹出路径错误提示，十有八九是路径里含了特殊字符——中文全角括号、表情符号、过深的嵌套目录都算。最稳的做法是直接用默认路径（`C:\Program Files\` 下），或者手动选一个纯英文、不含任何特殊符号的目录。

如果报的是 .NET Framework 4.0 相关错误，说明系统缺少运行库。解决顺序是：先装 4.0，再补装 4.7.2 和 4.8 两个版本（都是微软官方可下载的独立安装包），三个都到位后再运行安装程序。这步别跳过，少了哪个版本都可能导致程序装完闪退。

> [!WARNING]
> 三个运行库必须全部安装——只装 4.0 而缺 4.7.2 或 4.8，程序能启动但部分功能会报静默错误。

**启动崩溃的救急方案**

程序能装上但一开就闪退的情况，官方提供了一个改配置文件的小技巧：打开"此电脑"，在地址栏输入 `%appdata%\Apowersoft\ApowerMirror\Config.ini` 后回车，用记事本打开这个文件，找到 `[Main]` 段，在下面加一行 `ShowNewerToutrial=False`，保存关闭后重新启动。这个配置项能屏蔽一个已知的试用期弹窗冲突，对 Win10/11 上的闪退有奇效。

| 平台 | 安装方式 | 常见故障 |
|---|---|---|
| 安卓 | Google Play / 官网 APK | 权限未授予导致投屏无声 |
| iOS | App Store | 无，系统自动处理 |
| Windows | 官网 EXE | 路径含特殊字符、.NET 缺失、启动闪退 |
| macOS | 官网 DMG | Gatekeeper 首次打开需手动允许 |

## 📖 无线投屏与日常使用

装完之后真正的大头在连接环节。ApowerMirror 提供了无线和有线两条路，**无线是日常最顺手的方案**——不用插线，手机电脑在同一网络里就能互相发现。但无线也是坑最多的地方，把它摸透了基本就搞定了 80% 的场景。

### 安卓手机投电脑（WiFi 四步走）

连接前确认两件事：手机和电脑连的是**同一个 WiFi 名字**（家里双频路由器经常把 2.4G 和 5G 拆成两个 SSID，手机连了一个、电脑连了另一个，互相就看不见），电脑上桌面端已经打开并保持运行。

1. 电脑上打开桌面程序，保持窗口别最小化；
2. 手机上打开 App；
3. 点按界面中间偏下的**投屏**按钮，等待它扫描局域网设备；
4. 设备列表里找到以 **Apowersoft** 开头的电脑名称，点选它，弹窗里点"立即开始"，手机画面就出现在电脑上了。

> [!TIP]
> 每次投屏都会弹"开始捕获"的确认框，勾选"不再显示"后后续连接直接进入镜像，省一次点击。

### 电脑反向操控安卓

投屏成功后电脑端会出现手机画面，此时用鼠标点击画面上的按钮等效于手指触控，键盘输入会直接打进手机当前的输入框——打字比触屏快得多，适合聊微信、输验证码、编辑文档这类场景。首次启用反向控制时手机会弹授权提示，确认后即可用。

### 搜不到电脑怎么办

无线投屏连不上时，嫌疑按顺序排查：

**第一层：网络互通确认。** ping 通了、同一 WiFi 名字也确认了，手机就是搜不到电脑——这时候要把焦点转到电脑本机的"守门员"上。

**第二层：Windows 防火墙放行。** 打开"控制面板 > 系统和安全 > Windows 防火墙 > 允许应用或功能通过 Windows 防火墙"，在列表里找到本软件，把**"专用"和"公用"两个框都勾上**。列表里没有它就点"允许其他应用"手动添加桌面程序的主程序。

**第三层：杀毒软件。** McAfee 是官方点名的惯犯，会拦截通信，造成连不上或频繁掉线两种症状。处理方式是先退出杀毒软件试一次，确认是它的话把投屏程序加进白名单，或者至少关掉它的网络防护功能。其他带"网络防护"的安全软件同理处理。

**第四层：Bonjour 服务。** iOS 的 AirPlay 设备发现依赖 **Bonjour Service**，它通常随 iTunes 一起装上。打开任务管理器切到"服务"标签，找 Bonjour Service 这一行——正在运行就右键"重新启动"，已停止就"启动"，不存在就得先装 iTunes 或单独的 Bonjour 安装包。

| 症状 | 最可能的原因 |
|---|---|
| 手机能看到电脑但连不上，或连上秒断 | Windows 防火墙未放行、杀毒拦截 |
| iPhone 控制中心里压根没有 Apowersoft 条目 | Bonjour Service 未运行或缺失 |
| 完全搜不到设备，ping 也不通 | 不在同一网段，或公司/校园网开启了设备隔离 |

### 移动设备之间直接互投

两台手机或平板之间也能直接互投，不需要电脑中转。典型场景：把新手机上的照片演示给旁边的人看、用 iPad 当第二块屏幕监视另一台设备。

发送端系统不同，步骤略有差别：

**iPhone/iPad 投另一台移动设备**：两台都装好 App 并连同一 WiFi → 发送端点"投屏"搜索目标设备 → 选择"投屏手机"类型 → iOS 弹出广播选择时选本软件并"开始直播"。

**安卓投另一台移动设备**：两台都装好 App 并连同一 WiFi → 发送端点"投屏"搜索选择目标 → 点"投屏手机"确认"立即开始"。

互投是单向的——发送端画面显示在接收端上，接收端想反向控制发送端需要额外的授权流程。投出后点画面可以调出旋转按钮，横竖屏随手切。

> [!NOTE]
> 免费版在移动端互投同样受单次时长限制，和手机投电脑的限制口径一致。

### 有线兜底

实在连不上无线的时候，USB 数据线是最稳的兜底方案。安卓用 USB 线连上电脑后在手机上开启 USB 调试模式，桌面端会自动识别并建立连接；iOS 插上 Lightning 线后在手机上点"信任此电脑"即可。有线的优势是不依赖网络，画质和延迟都更稳定，缺点是束缚了移动性。
