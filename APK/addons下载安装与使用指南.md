## ✨ MCPE Addons 是什么

MCPE Addons 是一款专为 Minecraft 基岩版（Bedrock Edition）打造的模组管理工具。它把散落在各处的 McPack（资源包/行为包）和 McWorld（完整存档）集中到一个地方，让玩家不用再手动找文件、解压、搬目录，点一下 INSTALL 就能把模组装进游戏。

对于手机版 Minecraft 玩家来说，这款工具的价值非常直接——基岩版不像 Java 版有成熟的 Forge/Fabric 生态，长期以来装模组都是一件折腾人的事。MCPE Addons 填补了这个空白，把模组发现、下载、导入、激活整个流程打包成了一个干净的 App。

它的内容库里既有免费的社区作品，也有部分付费的精品模组，涵盖了跑酷地图、生物改造、家具装饰、小游戏、 Lucky Block 等几乎所有常见的模组类型。金锭评分系统让玩家能快速判断一个包的质量高低，评论区则提供了真实的安装反馈。

## 🔧 安装步骤

MCPE Addons 目前主要面向 Android 平台，安装流程和普通 APK 类似，但有几个 Minecraft 玩家专属的注意事项。

### Android 安装流程

1. **允许未知来源安装**：如果是从官网下载的 APK，需要先在手机设置里开启「允许安装未知来源应用」。不同品牌手机的设置入口略有差异，一般在「安全」或「应用权限」相关的菜单下。
2. **下载并安装**：从下载页获取最新版本的 APK 文件，点击安装。
3. **授予存储权限**：首次打开 App 时，系统会请求存储权限——这个权限是必要的，因为 MCPE Addons 需要往 Minecraft 的目录里写入解压后的模组文件。拒绝授权会导致安装流程无法完成。

> [!TIP]
> **务必核对版本号**：下载页会列出当前最新版本，安装前花 5 秒看一下和你手机上已装的版本号是否一致。旧版本可能存在兼容性问题，尤其是 Minecraft 基岩版更新之后。

### 空间与版本需求

| 项目 | 要求 |
|---|---|
| Minecraft 版本 | 基岩版 1.19 及以上 |
| 存储空间 | App 本体约 50MB，每个模组按需额外占用 |
| 系统 | Android 8.0+ |

> [!WARNING]
> **杀毒软件误报**：部分手机管家可能会把第三方来源的 APK 标记为风险。安装前先确认 APK 来自官方渠道，忽略非致命告警即可。如果安装后 App 被自动清理，在手机管家里把它加入信任名单。

### 装完怎么核对

打开 App 后能正常浏览首页的模组卡片列表，就说明安装成功了。如果首页加载不出来或一直转圈，先检查网络连接，再确认存储权限是否真的授予成功。

## 📖 使用入门

MCPE Addons 的核心玩法可以拆成四个阶段：**发现模组 → 判断要不要装 → 一键导入 → 在游戏里激活**。下面按实际使用顺序展开。

### 第一步：发现模组——搜索 vs 分类浏览

进入 App 之后，你有两条路可以走。

**已经知道自己要什么**——比如就想找一个幸运方块模组，直接用搜索。搜索框通常在首页顶部或点右上角搜索图标后弹出。它支持英文关键词、中文关键词（切中文界面后自动映射英文标签）、模糊匹配，不区分大小写。搜 `block` 能匹配到 `lucky block` 相关的包，搜 `funny mob` 能找到改生物外观的模组。

**完全没想法、随便逛逛**——首页的分类热榜更合适。MCPE Addons 会按热度排序展示模组，金锭评分和下载量直接显示在每张卡片上。

| 场景 | 用搜索 | 用分类 |
|---|---|---|
| 想找特定类型（幸运方块、家具） | ✓ | |
| 随便逛逛看有什么好玩的 | | ✓ |
| 想找某个具体名字的包 | ✓ | |
| 不确定要什么，按热度发现 | | ✓ |

### 第二步：看懂卡片——快速过滤不踩坑

首页和搜索结果里的每张模组卡片，都包含一组固定的信息元素：预览图、标题、金锭评分、下载量。别小看这些信息，熟练之后几秒钟就能筛选掉明显不行的包。

**预览图是第一眼**。好的地图或模组，预览图往往就是最出彩的那个场景——跑酷地图会给最高难度关的截图，生物模组会给生物的特写。如果预览图模糊、和标题不搭、或者看起来就是随便截的一张，这个包大概率也不认真。

**标题看什么**。McPack 类的标题通常会告诉你这包是干什么的，常带 "Mod"、"Addon"、"Pack" 字样，有些还会带版本号或作者名。McWorld 类的标题有时带类型标签（Parkour、Adventure 之类），有时纯标题党——标题模糊的（比如只叫 "My World"）最好点进详情页看介绍再决定。

**金锭评分 + 下载量要联动看**：

- 5 锭 + 高下载 = 闭着眼进
- 4 锭 + 中等下载 = 大概率不错
- 5 锭 + 低下载 = 冷门精品，进去看看介绍
- 3 锭以下 + 任何下载量 = 谨慎，看评论区有没有实锤问题

### 第三步：看评论区——装之前最后的情报站

卡片信息帮你快速过滤，评论区才是真正决定要不要下载的最后关口。金锭评分是一个数字，评论区是真人反馈。在点 INSTALL 之前花 30 秒扫一眼，可以避开很多坑。

**真的有问题的包会被骂成筛子**。如果评论区前几条全是"装不上"、"导入成功但没反应"、"和 XX 包冲突"、"太卡/耗电"，直接关掉换一个同类包——MCPE Addons 里同类替代品多的是。

**正面评论要看是不是具体**。好的正面评论不是"太棒了！"而是"跑酷地图设计得真精细，尤其是第 12 关"、"生物模组改的苦力怕特别可爱，还有对话"、"家具模组的沙发真好看，和现代风建筑完美搭"。越具体说明越真实，泛泛的好评可能是作者自己刷的。

**"导入成功但游戏里没反应"是最常见的评论**。如果评论区反复出现这句话，不要直接判定包有问题——先自己看看有没有在游戏里正确激活（进入编辑世界 → 行为包/资源库 → 手动启用）。这是新手最容易踩的坑。

### 第四步：一键导入——McPack 和 McWorld 是两条完全不同的路

点 INSTALL 之后，MCPE Addons 会自动下载、解压、把文件搬到正确位置。但 McPack 和 McWorld 的导入行为完全不一样，搞混了会浪费时间。

**McPack（资源包/行为包）** 导入后会进入 Minecraft 的资源库，停在主界面。你需要手动进入一个世界的编辑界面，在行为包或资源库 tab 里找到刚导入的包，点启用才能生效。McPack 是"给你的现有世界贴一层东西"。

**McWorld（完整存档）** 导入后 Minecraft 会直接启动游戏并加载地图——跳过所有中间步骤，你一抬头就在这个地图里了。玩完退出到 Play → Worlds 列表，这个新地图已经在里面，以后可以反复进入。McWorld 是"拿来一个现成的世界"，不能给自己的存档加内容。

| | McWorld | McPack |
|---|---|---|
| 本质 | 完整存档文件 | 资源包/行为包 |
| 点 INSTALL 后 | Minecraft 直接加载地图 | 包进资源库，停主界面 |
| 需要手动激活 | 不需要 | 需要去编辑世界激活 |
| 作用对象 | 创建一个新的世界存档 | 给已有世界加新元素 |

> [!NOTE]
> **McWorld 不会覆盖你的现有存档**——它会在 `games/com.mojang/minecraftWorlds/` 目录下新建一个独立的文件夹。想删掉 McWorld：在 Minecraft 里点这个世界旁边的铅笔图标 → Delete。

有些 McWorld 本身带了行为包/资源包（作者在世界里预配置好了），这种情况下 Minecraft 会自动应用，你不用手动激活。但如果你想额外给这个 McWorld 再加新的 McPack，还是要去编辑世界手动启用。
