## ✨ Olib 是什么 — 一款简洁的 Z-Library 客户端

Olib 是一款开源的 Z-Library 客户端，支持 Windows 桌面端和 Android 移动端。它不做资源聚合、不搞账号代注册，定位非常明确——直接对接 Z-Library 官方 API，让用户用自己的账号在本地客户端里完成搜索和下载。

核心功能就三件事：**搜书、下载、管理下载历史**。界面走的是简洁路线，没有花哨的推荐算法或社交模块，打开就是搜索框和账号状态。多账号轮换是它的一个实用特性——免费账号每日限额用完时，可以一键切到另一个已保存的账号继续下，不用重新走登录流程。

适合谁用？日常需要从 Z-Library 找书、嫌网页端广告多、又不想折腾复杂脚本的用户。开发者拾壹0x7f 在 B 站和 GitHub 上持续更新，两个平台的源码都公开，遇到问题可以直接看 Issue 或提交反馈。

## 🔧 安装前准备与平台差异

Olib 不帮你注册 Z-Library 账号，也没有游客模式。安装前需要确认两件事：**你已经有 Z-Library 的账号**（免费的就行），以及**你知道自己的网络环境能访问 Z-Library** 哪个可用线路。

### Windows 端安装

Windows 端有两种分发方式：绿色免安装包和安装程序。绿色包直接解压到任意目录即可，推荐放到非系统盘（比如 `D:\Olib\`），避免权限问题。

> [!WARNING]
> 路径里尽量不要放中文或特殊字符。实测发现某些 Win10 版本上，路径包含中文时 Olib 会出现双击没反应、闪退等启动异常。

安装过程中需要注意：

1. 下载后先核对文件大小是否与发布说明一致
2. 首次运行建议**右键以管理员身份运行**，权限不够是 Win10 上最常见的启动失败原因
3. 如果杀毒软件弹窗拦截，参考后文的误报处理章节

### Android 端安装

Android 端以 APK 形式分发，不是从应用商店上架的版本。安装步骤：

1. 允许**安装未知来源应用**（不同品牌手机路径略有差异，通常在设置 → 安全中心里）
2. 如果系统弹出风险提示，确认来源可靠后点击继续安装
3. 部分手机安全软件会在安装后拦截自启动——建议把 Olib 加入「允许自启动」和「不清理」白名单

| 平台 | 分发形式 | 是否需要特殊权限设置 | 常见问题 |
| --- | --- | --- | --- |
| Windows | 绿色包 / 安装程序 | 建议管理员权限启动 | 杀毒误报、路径含中文、Win10 特定版本兼容 |
| Android | APK | 允许未知来源安装 | 系统拦截自启动、安装后被清理 |

## 📖 使用入门 — 从登录到下载完成

### 登录：用自己的 Z-Library 账号

打开 Olib 后第一步是登录。填入你在 Z-Library 注册的**邮箱和密码**，然后选择一条可用线路连接 API。Olib 会在本地加密保存你的账号凭证，不会上传到开发者的服务器。

登录成功后，界面会显示当前登录的邮箱和**今日剩余下载次数**。免费账号大约每天 10 本，对日常阅读来说基本够用。如果不够用，可以在设置里保存多个账号，今日额度用完时一键切换。

### 切换账号：额度用完怎么办

当你看到「今日剩余下载次数」变成 0 时，就该切账号了。操作非常简单：

**Windows 端**：打开账号管理（设置或侧边栏）→ 在已保存的账号列表里点击目标账号 → Olib 自动验证 → 切换完成。

**Android 端**：设置页面 → 账号管理入口 → 点击要切换的账号 → 确认。

切换本质上是用凭证重新验证 Z-Library，所以不需要重新走登录流程——几秒钟就能完成。切换后的变化见下表：

| 项目 | 切换后的行为 |
| --- | --- |
| 剩余下载次数 | 显示新账号的额度 |
| 当前邮箱 | 变成新账号的邮箱 |
| 搜索历史 | 保留（搜索不区分账号） |
| 下载历史 | 同步新账号的云端记录 |
| 已保存账号 | 不变，随时能切回去 |

> [!TIP]
> 建议提前保存 3~5 个免费账号。单个账号日下载 10 本，多账号轮换后总额度相当可观，而且免费账号本身零成本。

### 搜索与下载

登录后直接在搜索框里输入书名、作者或 ISBN，Olib 会从 Z-Library 拉取匹配结果。点击结果进入详情页，可以选择格式（PDF、EPUB、MOBI 等）和下载位置。

下载过程中，Olib 会优先测试当前线路的连通性，如果目标线路不通会自动切换到备用线路重试，这也是它比单纯网页端更省心的地方之一。

### 常见问题处理

**应用打不开 / 双击没反应**

这是 Win10 上反馈最多的问题。按以下顺序排查：

1. 右键 → 以管理员身份运行
2. 检查 Windows Defender 是否隔离了 Olib（安全中心 → 保护历史记录 → 还原）
3. 把 Olib 文件夹加入 Defender 排除项
4. 把 exe 放到 `D:\Olib\` 这种简单路径下（排除中文路径问题）
5. 右键 → 属性 → 兼容性 → 勾选兼容模式（Windows 7 或 8）

**启动后闪退**

重点检查三件事：是否装在 C 盘（绿色版权限不够）、杀毒软件日志里有没有拦截行为、是不是旧版本（下载最新版试试）。

**杀毒软件提示报毒**

Olib 是 Python 打包的桌面应用，这类程序经常被杀毒软件误报。原因也很直接：个人开发者没有数字签名，pyinstaller 打包的 exe 容易触发启发式规则，加上 Olib 需要访问外部域名。

> [!NOTE]
> 开发者明确表示过：360、电脑管家等软件的报毒为误报，加入白名单即可。如果你是从开发者 B 站视频简介或 GitHub Releases 下载的安装包，来源是可靠的。

Windows Defender 处理方法：安全中心 → 病毒和威胁防护 → 管理设置 → 滚到底部「排除项」→ 添加文件夹 → 选中 Olib 所在文件夹。360 和电脑管家的操作类似，在「信任区」或「白名单」里添加整个文件夹即可。

**缺少 DLL**

如果弹出「缺少 DLL」类错误对话框，通常是系统缺少 Visual C++ 运行库，安装最新版 Visual C++ Redistributable 就能解决。
