## ✨ Aseprite 是什么——专为像素画而生的专业编辑器

Aseprite 是一款专门为**像素画（Pixel Art）和逐帧动画**设计的桌面级绘图软件，诞生于 2001 年，至今仍是独立游戏开发者、像素艺术家、表情包创作者圈内最主流的生产工具之一。它不像 Photoshop 那样面面俱到，也不像 Piskel 那样轻量简单——Aseprite 把像素画这件事做到了极致：从画布尺寸约束、调色板管理、逐帧时间轴、动态网格，到专为像素画打磨的抖动过渡、洋葱皮（Onion Skin）、瓦片图层等功能，全都是为"每一格像素都要有意义"这个核心目标服务的。

核心能力可以用四个维度概括：

- **像素精确控制**：每一格像素就是一个独立单元，默认的铅笔工具只生成纯实色方块，不会出现普通绘图软件里的抗锯齿模糊——这是像素画"清晰感"的根源
- **逐帧动画**：内置完整的时间轴面板，支持帧分组、循环标记、洋葱皮参照，画完直接导出 GIF、PNG 序列或 sprite sheet，不需要额外工具
- **调色板驱动**：可以把整张画限制在最多 256 色的索引模式下，改调色板就能一键替换全图配色——这是复刻老游戏、做风格统一的像素美术的关键能力
- **Lua 脚本扩展**：社区已经积累了上千个现成脚本，覆盖批量导出、自动切片、调色板转换等场景，也可以自己写几行脚本让重复工作自动化

适合谁用？独立游戏开发者（做角色、瓦片、UI）、像素风格插画师、表情包和贴纸创作者、对像素艺术感兴趣的入门玩家——只要你的创作目标是"小尺寸、高清晰度、每格都要讲究"，Aseprite 就是最合适的选择。

## 🔧 Aseprite 安装步骤

### Windows 平台

1. 从下载入口获取最新版本的 `.exe` 安装包，文件大小通常在 20~30MB 左右
2. 双击运行安装程序，按向导选择安装路径（默认 `C:\Program Files\Aseprite`）
3. 安装过程中如果 Windows Defender 或第三方杀毒软件弹出"未知来源"提醒，选择"允许运行"即可——Aseprite 是开源软件，签名完整
4. 安装完成后桌面会生成快捷方式，双击启动

> [!TIP]
> 建议在桌面版安装完成后，首次启动时花 5 分钟熟悉界面布局——左侧工具栏、顶部菜单栏、右侧调色板、底部时间轴面板是你每天都要打交道的四个区域。

### macOS 平台

1. 下载 `.dmg` 安装镜像，双击挂载
2. 将 Aseprite 图标拖入 `Applications` 文件夹
3. 首次启动时 macOS 可能提示"无法打开来自未知开发者的应用"，前往"系统设置 → 隐私与安全性"点击"仍要打开"
4. 之后从启动台或访达中正常双击启动即可

### 安装后核对

打开软件后进入 **Help → About**（macOS 下是 Aseprite → About Aseprite），确认版本号与下载时看到的一致。桌面版首次启动会进入欢迎页，可以选择新建画布、打开最近文件或浏览示例项目。

## 📖 上手 Aseprite：从第一张画布到逐帧动画

### 第一次新建画布

打开后按 `Ctrl+N`（macOS 是 `Cmd+N`）弹出新建 Sprite 对话框——这是你配置画布的唯一机会，之后改尺寸会导致像素失真，尽量一次选对。三个关键参数：

**画布尺寸**：像素画的"大"和"小"跟普通插画完全不同，几十像素就算大画布了。新手推荐从 **32×32** 开始——足够放下一个小角色，又不会太费时间。常见规格参考：

| 用途 | 常见尺寸 | 说明 |
| --- | --- | --- |
| 微型图标、道具 | 8×8 / 16×16 | 每一格都要有意义，练"取舍"的最佳尺寸 |
| 头像、小图标 | 16×16 / 32×32 | 改错成本低，最适合练手 |
| 表情包 | 64×64 / 100×100 | 导出后仍清晰 |
| 游戏角色 | 32×32 / 48×48 | 独立游戏常用规格 |
| 场景背景 | 128×128 以上 | 工作量大，先画小图找感觉 |

**颜色模式**：不确定就选 RGBA（每个像素任取颜色、支持半透明）。想严格控色可以切到 Indexed 模式——全图最多 256 色，改调色板就是改全图配色。Grayscale 只有黑白深浅，适合练习明暗关系。

**透明背景**：默认就是透明的，Aseprite 用棋盘格表示透明区域。画完后导出时再决定背景是保留透明还是填成白色/黑色。保持透明通常是游戏素材的正确选择——引擎里好融合到场景。

画布建好后，先做三件事：**放大到每格像素清晰可见**（`Ctrl++`）、**打开网格显示**、选铅笔工具开始画第一笔。画几笔就缩回到正常尺寸看一眼整体比例——只在放大状态下画很容易比例全歪。

### 自定义画笔——像素画纹理和抖动的核心

默认的铅笔只生成纯实色方块。**自定义画笔（Custom Brush）** 让你可以把任意像素区域定义成画笔头，以后在画布上拖就会按定义的图案重复铺开。典型场景：定义一个 4×4 的棋盘格做画笔头，在两个颜色交界处来回扫几次就能做出柔和的抖动过渡——比渐变工具更可控。

**创建方式**：用选框工具（`M` 键）选中画布上你想做成画笔的区域，右键选区 → Brush → Create Brush from Selection，起个名字保存即可。自定义画笔是全局的，存在 Aseprite 设置里，新建项目也能用。

Aseprite 自带几种预设画笔：硬边铅笔（默认）、软边画笔（边缘半透明）、抖动画笔（多种棋盘格图案）、纹理画笔（模拟砖墙、草地、金属等材质）。画笔快捷键速查：

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Shift+拖拽 | 调整当前画笔大小 |
| Space+D / H / V | 对角 / 水平 / 垂直翻转画笔 |
| Space+R | 旋转画笔 |

翻转和旋转画笔在画**对称纹理**时特别有用——比如左边用了一种抖动图案，右边镜像过去只需要 Space+H，不用重新定义画笔。

### 洋葱皮——逐帧动画能不能画顺的分水岭

洋葱皮（Onion Skin）会把**前后相邻的帧以半透明影子叠在当前画面上**。不开洋葱皮画动画，等同于蒙着眼开车。桌面版开启方式：按 **F3** 或 **;**（分号键），或在时间轴工具栏点那个"几层叠起来的方块"图标。

Aseprite 的洋葱皮有三种显示模式，按需切换：

| 模式 | 特点 | 适合场景 |
| --- | --- | --- |
| 红蓝描边（默认） | 前帧红色描边、后帧蓝色描边、当前帧正常 | 画人物动作时最推荐，轮廓清晰、前后来源一眼区分 |
| 灰度模式 | 所有前后帧都显示为灰色半透明 | 画形状渐变、颜色替换等不需要看具体轮廓的场景 |
| 融合模式 | 前后帧以正常颜色显示（更淡），不区分先后 | 多图层、颜色丰富的复杂动画 |

显示帧数量可以在 Edit → Preferences → Editor → Onion Skin 里调整：小动作（呼吸、眨眼）用前后各 1 帧，常规动作（走路、跑步）用默认的各 2 帧，大动作（跳跃、挥剑）用到前后各 3~4 帧。

> [!NOTE]
> 使用纪律：开洋葱皮对位 → 关掉洋葱皮画细节 → 再开洋葱皮检查整体动幅——这是正确节奏。洋葱皮的半透明度建议设为 30~50%，太高会导致前后帧和当前帧混淆。另外可以设置**哪些图层参与洋葱皮**——静态背景图层每帧都一样，没必要让它出现在洋葱皮里干扰视线。

### Lua 脚本——让重复工作自动化

Aseprite 内置完整的 Lua 脚本运行环境，社区已经积累了**上千个现成脚本**，覆盖批量导出、自动切片、调色板转换、瓦片地图导出等场景。三个主要资源入口：Aseprite Community 的 Scripts & Extensions 板块、GitHub 搜索 "aseprite script"、mintlify 上的官方级 API 参考文档。

**安装脚本有三种方式**：一是把 `.lua` 文件丢进脚本文件夹（Windows 默认 `C:\Users\<你>\AppData\Roaming\Aseprite\scripts`），重启后自动出现在 File → Scripts 菜单；二是 File → Scripts → Open Script 直接运行；三是命令行模式 `aseprite -b --script 脚本.lua target.ase`，适合批量处理。

几个高频实用脚本：

- **Export By Group**：把每个图层组分别导出成独立 PNG（自动创建文件夹结构），角色设计时想把身体、头部、武器分别导出做配件系统特别好用
- **Palette Swap**：输入新调色板文件（`.gpl` / `.aseprite_palette` / `.png`），自动把当前画布的颜色替换成新调色板——一套角色想用 10 种配色风格，导入 10 个调色板跑 10 次脚本就行
- **Tilemap JSON Export**：把 Aseprite 的瓦片图层导出成 Godot / Tiled 可用的 JSON 格式（含瓦片 ID、位置、碰撞数据），画完直接对接游戏引擎
- **RotSprite Tool**：像素完美旋转算法，旋转小尺寸 sprite 时比内置工具更能保持像素边界清晰、减少锯齿
- **Auto Slice**：根据颜色差异自动把 sprite 切成多个部分，做可定制角色（衣服、头盔、武器单独换）时自动分离不同颜色区域

自己写脚本也很简单——在 Run Command（`Ctrl+Space`）窗口里输入直接就能跑。入门脚本示例（弹窗显示当前画布的尺寸、图层数、帧数）：

```lua
local sprite = app.activeSprite
if sprite then
  app.alert("当前画布: " .. sprite.width .. "x" .. sprite.height .. "px\n" ..
           "图层数: " .. #sprite.layers .. "\n" ..
           "帧数: " .. #sprite.frames)
else
  app.alert("没有打开的画布")
end
```

写脚本的纪律：先在界面里测试正确再丢进 `-b` 命令行模式，关键节点加 `app.alert("xx: " .. 值)` 方便调试，别忘了检查 `app.activeSprite` 可能为 nil 的情况（没有打开任何文件时），Lua 里不等于用 `~=` 不是 `!=`。
