## ✨ LinkAI 是什么

LinkAI 是一款把 AI 模型接入到日常工作与生活渠道的应用平台。它提供超级 AI 助理、内容创作 Studio、业务流程 Builder、模型服务 MaaS 等产品线，核心思路是让大模型能力落地到具体场景——无论是让助理 7×24 在线处理定时任务，还是一句话完成从文案到视频的创作流水线，LinkAI 都试图扮演"AI 连接器"的角色。

对普通用户来说，超级助理可以通过云端托管或桌面客户端两种方式运行：云端助理跑在 LinkAI 云电脑上，适合需要常驻在线、定时执行的任务；桌面助理直接操作本机的文件、终端和浏览器，适合数据不出本机、本地开发调试的场景。两种方式共享同一个账号和积分体系，可以同时开启、各司其职。

积分是 LinkAI 平台的统一计量单位，采用版本订阅 + 积分按量消耗的混合计费模式。模型调用、插件执行、知识库嵌入、声音复刻等不同资源消耗积分的规则各不相同，积分用完按需充值即可继续使用。

LinkAI Studio 则是面向内容生产团队的无限画布创作空间，内置内容创作 Agent，用户只需用一句话描述创意，Agent 会自动判断需要生成什么类型的内容、调用合适的多模态模型、先生成预览卡片确认后再执行，最终把文案、图片、视频、配音等所有成果落到画布上，支持自由拖拽连线、框选运行、批量下载等操作，大幅提升内容生产效率。

## 🔧 安装步骤

桌面客户端支持 Windows 和 macOS 两大平台，安装过程简单直接，登录 LinkAI 账号后即可开始使用。

### Windows 平台

1. 从官方下载页面获取 .exe 安装包
2. 双击安装包，按向导选择安装路径，点击"下一步"完成安装
3. 安装完成后启动客户端，输入 LinkAI 账号密码登录
4. 登录成功后客户端会自动在你的用户目录下创建一个独立的工作空间目录，Agent 在这个目录内可以自主操作文件和执行终端命令

### macOS 平台

1. 从官方下载页面获取 .dmg 安装包
2. 双击 .dmg 文件，将 LinkAI 图标拖入 Applications 文件夹
3. 首次启动时系统可能会提示安全性警告，进入"系统设置 → 隐私与安全性"点击"仍要打开"
4. 启动客户端并登录账号，工作空间目录会在用户目录下自动创建

> [!NOTE] 工作空间安全机制
> Agent 在自己的工作空间目录内可以自主读写文件、执行 Bash/PowerShell 命令、操作浏览器；涉及工作空间之外的文件变更（比如 Documents 目录下的文档），会弹出确认对话框让你手动批准——可以选择"允许"（本次执行）、"总是允许"（记住该目录权限）或"拒绝"。

### 安装完成验证

- 客户端界面能正常打开，账号登录状态显示正常
- 工作空间目录已在用户目录下生成（路径可在客户端设置里查看）
- 尝试一次简单对话，确认 Agent 能正常响应

## 📖 使用入门

### 超级助理的两种运行方式

LinkAI 超级助理提供云端托管和桌面客户端两种运行方式，核心差异在于 Agent 运行在哪里，分别适合不同的使用场景：

| 对比项 | 云端托管 | 桌面客户端 |
|---|---|---|
| **运行位置** | LinkAI 云电脑 | 本机 macOS / Windows |
| **在线时长** | 7×24 小时不中断 | 跟随本机开关机 |
| **可操作资源** | 云电脑内的文件、终端、浏览器 | 本机文件、终端、浏览器 |
| **成本结构** | 需持续消耗云端资源配额 | 本机算力，无额外云端运行费 |
| **数据沉淀** | 云端独立工作空间 | 本机工作空间目录 |
| **适合场景** | 定时任务、常驻在线服务、云端资源处理 | 本地文件处理、开发调试、数据不出本机 |

云端助理的优势是 7×24 不中断——每天早上自动拉取财报生成报告、晚上定时发送消息到飞书群这类任务，只有云端托管能稳定执行。桌面助理的优势是直接操作本机资源：读写本地文件、执行终端命令、控制浏览器，处理本地数据不需要先上传云端，工作空间和记忆也全部存放在本机，数据安全更有保障。两种方式可以同时开启，同一个账号、同一套积分体系，云端助理负责常驻在线任务，桌面助理负责本机文件和开发，互不干扰。

### 积分控制与成本优化

LinkAI 的积分消耗主要集中在模型调用上，不同类型的模型计费方式不同：文本类按 token 计（和 OpenAI token 计算口径一致，总 token = 请求 token + 响应 token），文生图按次计费（不同模型价格差异较大），视频模型按次计费，语音类按时长或文本长度计。插件调用也消耗积分，搜索类 5~10 积分/次、文生图类 150~200 积分/次、视频生成类 700~1000 积分/次，计算器、当前时间、网页速读等实用插件免费。

> [!TIP] 降低积分消耗的四个策略
> 1. **模型选型**：简单问答用豆包 Lite / DeepSeek V3 足够，成本比 GPT-4o 级别模型低 10~20 倍
> 2. **控制上下文**：应用设定（提示词）不要写太长，对话记忆轮次不要设太多——提示词和历史消息都占 token
> 3. **知识库优化**：召回数量（Top N）设合理值，文档拆分粒度适中，过细会导致召回片段数量增加
> 4. **插件策略**：知识库优先策略比"知识库 + 插件同时执行"更省 token，不用的插件关掉

积分单价根据充值套餐不同在 1 积分 = 0.0016~0.0019 元之间，买得多单价越低。获取积分的途径也比较丰富：版本订阅自带一定量积分、基础版用户每日签到可领取少量积分、按需购买充值、把自己的应用发布到应用广场后别人使用时还能获得创作者收益。

### Studio 无限画布创作

Studio 是 LinkAI 面向内容生产团队的产品，核心是无限画布加内置的内容创作 Agent。用户不需要手动搭建任何节点，只需要在对话框里用一句话描述创意——比如"帮我写一条给 Z 世代消费者看的运动鞋新品发布视频，文案口语化有梗，画面风格活力动感，最后配一段节奏轻快的配音"，创作 Agent 会自动完成整个流程：

1. 判断需要生成什么类型的内容（文案脚本 → 分镜图片 → 视频 → 配音）
2. 调用合适的创作技能和多模态模型
3. **先生成预览卡片**——用户可以修改提示词、切换模型、调整参数，确认后才执行
4. 确认后自动把所有成果落到画布上，按流程自动连线

"先确认再生成"这个交互设计特别重要——AI 生成内容有成本，确认后再执行能大幅减少无效消耗。画布支持多种节点类型（文本、图片、视频、音频、文件），所有节点可以自由拖拽位置、连线表示上下游关系、框选一组节点作为整体运行。音频节点接入了 186 款预置音色，还支持用自己复刻的专属音色，方括号可以标注语气（比如 `[惊喜地] 这款运动鞋的设计太绝了`），长文本会自动分段合成拼接，不需要手动处理。批量下载图片、单个或批量导出视频都能一键完成。

### 桌面端常见问题与排查

桌面客户端的安全模型理解起来有一个关键点：Agent 只在自己的工作空间目录内可自主操作，工作空间之外的文件变更需要用户手动确认。这个机制能解释大部分"桌面端好像卡了 / 没反应"的现象。

渠道接入（微信、飞书、钉钉）没响应时，**最常见的原因是电脑关机或休眠了**。桌面客户端的渠道接入依赖客户端在本机运行——关机或休眠时 Agent 无法响应渠道消息、定时任务无法执行、手机端远程指挥处理本机任务的功能也不可用。需要 24/7 响应的场景应该切换到云端托管模式。

数据沉淀全部在本机：工作空间文件、核心记忆与天级记忆（memory 子目录）、本地知识库（knowledge 子目录）、对话历史（sessions 子目录）、配置文件都存放在标准文件系统里，客户端关闭后可以直接用系统自带的方式拷贝到备份位置。

> [!WARNING] 对话内容与模型推理
> 虽然文件操作在本机执行，但对话内容和 Agent 执行任务时读取的必要上下文仍然会发送给大模型进行推理——这是所有需要大模型能力的 Agent 产品的共同点。如果对这一点敏感，可以用自定义模型接入本地部署的模型，但本地模型的能力上限取决于硬件资源。
