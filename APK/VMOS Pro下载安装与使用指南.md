## ✨ VMOS Pro 是什么

VMOS Pro 是一款在安卓真机上运行独立安卓虚拟机的应用。它能在你的手机里再跑一套完整的安卓系统——拥有自己的系统空间、应用目录和 ROOT 权限，和真机系统完全隔离。

核心能力可以概括为三点：**多开隔离**（同一应用多账号互不干扰）、**安全 ROOT**（虚拟机内 ROOT 不影响真机保修和银行 App）、**玩机环境**（Xposed、ROOT、系统定制全套玩机能力在隔离容器里安全运行）。

适合哪些人用？日常需要管理多个社交账号的人、想体验玩机但不敢碰真机 ROOT 的新手、需要沙盒测试 App 的开发者、以及手游多开挂机的玩家。VMOS Pro 把这些原本需要云手机或专门刷机才能做的事，搬到了一个轻量的虚拟容器里。

## 🔧 安装 VMOS Pro

VMOS Pro 是安卓应用，安装流程和普通 APK 基本一致，但有几个需要注意的点。

### 安装前准备

1. **确认真机安卓版本**：VMOS Pro 要求真机安卓 5.0 及以上，推荐 7.0 及以上以获得更好的兼容性
2. **预留存储空间**：安装包本身约 100-200 MB，每个虚拟机初始化还需要下载 ROM（通常 500-800 MB），建议至少预留 3 GB 以上的存储空间
3. **允许"未知来源"安装**：如果是首次从非应用商店安装 APK，需要在真机设置 → 安全中开启允许未知来源

### 安装步骤

1. 从下载页或应用商店下载 VMOS Pro 安装包
2. 点击 APK 文件，按提示完成安装
3. 首次启动时授予存储权限——这是必须的，虚拟机的 ROM 和解压数据都需要写入存储
4. 选择要创建的虚拟机镜像（见下文"镜像版本怎么选"），等待下载和初始化完成
5. 初始化完成后虚拟机自动启动，进入 VMOS Pro 桌面

### 镜像版本怎么选

VMOS Pro 提供多个预编译的安卓版本镜像，各有侧重：

| 镜像类型 | 安卓版本 | ROOT | Xposed | 适合场景 |
| --- | --- | --- | --- | --- |
| 官方版 | 7.1 / 5.1 | ✅ | 手动装 | 通用场景，需要自己配置 Xposed |
| 精简版 | 7.1 / 5.1 | ✅ | 手动装 | 存储空间紧张的设备，系统精简无预装 |
| Geek ROM | 7.1 | ✅ 预装 | ✅ 预装 | 玩机玩家首选，开箱即用 ROOT + Xposed 全套 |
| 谷歌版 | 7.1 | ⚠️ 受限 | 不支持 | 需要完整 Google 服务框架的场景 |

> [!TIP]
> 如果你是第一次接触 VMOS Pro，推荐直接选 **精简版 7.1**。系统干净、启动快、ROOT 直接开，后续要玩 Xposed 再手动装就行。Geek ROM 适合已经熟悉玩机的用户。

### 安装后的验证

虚拟机首次启动后，做三件事确认安装正常：

1. 打开虚拟机内的「设置 → 关于手机」，确认安卓版本和你选择的镜像一致
2. 进入「设置 → 超级用户」，确认 ROOT 开关能正常打开并生效
3. 真机侧打开 VMOS Pro，确认虚拟机列表能看到刚才创建的实例

## 📖 使用入门

### 基础操作

VMOS Pro 的核心使用逻辑很简单：**真机装一个壳（VMOS Pro 主程序），壳里跑虚拟机（一台或多台），每个虚拟机里是独立的安卓系统**。

真机 VMOS Pro 主界面是虚拟机列表。点击卡片进入虚拟机内部，长按卡片或点三点菜单可以进行设置、克隆、删除等操作。

### 多开与虚拟机克隆

多开最常用的技巧是**克隆虚拟机**。当你把一台虚拟机配置好——装完所有应用、调好用机习惯、ROOT 和 Xposed 都配好——就可以克隆出一模一样的副本，秒级完成多开环境的搭建。

**克隆的操作流程**：

1. 回到 VMOS Pro 主界面（虚拟机列表页）
2. 找到要克隆的源虚拟机卡片，点击右上角三点 → 选择「克隆」（部分版本是长按卡片弹出菜单）
3. 给新虚拟机起个名字，确认
4. 等待 10-60 秒完成复制（耗时取决于虚拟机内数据多少）

克隆出来的虚拟机和源虚拟机**完全独立**——后续可以各自运行、各自修改、互不影响。但有一个关键细节：**克隆会把 App 登录态也复制过去**。如果你克隆的是一台已登录微信的虚拟机，新虚拟机里的微信也是登录状态，但两个同账号实例容易被微信服务器检测异常下线。

> [!WARNING]
> 要做账号多开，要么克隆一个只装 App 不登录的"干净模板"虚拟机，要么克隆后手动退出源登录态再登新号。不要让两个克隆体用同一个账号同时在线。

克隆和重新创建虚拟机的效率对比一目了然：重新创建需要下载 ROM + 初始化，耗时 1-5 分钟还要重新装应用；克隆 10 秒出结果，应用、设置、文件全部原封不动继承。多开场景下克隆是唯一高效的路径。

### 在虚拟机内开启 ROOT

虚拟机内的 ROOT 是 VMOS Pro 最安全的玩机方式。真机 ROOT 的代价越来越大——触发 Knox 熔断失去保修、银行 App 检测拒绝运行、系统更新变麻烦。而虚拟机内的 ROOT **完全隔离**，只在容器内生效，真机系统碰不到，银行 App 也不受影响。

**开启 ROOT 的步骤**：

1. 进入虚拟机内部
2. 打开「设置」应用，找到「超级用户」（部分版本藏在开发者选项里——先连点「关于手机 → 版本号」打开开发者选项）
3. 打开 ROOT 权限开关，等待 1-2 秒生效

所有 VMOS Pro 官方镜像（非 Google Play 版）的 7.1 / 5.1 / 4.4 版本都支持 ROOT，Geek ROM 版本已经预装了 ROOT 管理工具，开箱即用。Google Play 版本受商店政策限制，ROOT 功能被移除。

开启后，虚拟机内需要 ROOT 的应用（如 Root Explorer、Tasker 的 ROOT 模式）就能正常请求和获得权限。但安全使用 ROOT 也要注意：陌生 App 请求 ROOT 一律拒绝，不要把虚拟机内的危险操作当真机操作——虚拟机搞崩了大不了重建，真机系统不能碰。

### 虚拟机内存怎么分配

虚拟机运行时的内存完全来自真机的空闲 RAM，VMOS Pro 从真机"借出"一块连续内存用于虚拟机进程。不能指定一个固定值让虚拟机独占，而是通过虚拟机设置中的「RAM 大小」选项调整目标值，VMOS Pro 会在真机内存允许的范围内分配。

**推荐分配值**可以按真机总 RAM 来参考：

| 真机总 RAM | 建议虚拟机分配 | 同时运行数量 |
| --- | --- | --- |
| 3 GB | 1.2-1.5 GB | 1 |
| 4 GB | 1.5-2 GB | 1 |
| 6 GB | 2-2.5 GB | 1-2 |
| 8 GB | 2.5-4 GB | 2-3 |
| 12 GB+ | 4-6 GB | 3+ |

核心原则：**虚拟机分配的 RAM + 真机自身系统占用 ≤ 真机总 RAM 的 80%**。留 20% 给真机系统做内存缓冲，避免系统级杀进程。

如果真机内存不够会发生什么？虚拟机内的 App 会被 OOM Kill 自动杀进程（游戏突然闪退），严重时真机直接把整个虚拟机进程杀掉，里面所有 App 一起挂掉。低内存真机（3-4 GB）想用好 VMOS Pro，建议把虚拟机分辨率降到 720P、虚拟机里只装必要的 App、关闭自启项、真机侧也少装后台常驻的应用。

### Magisk vs Xposed：玩机框架怎么选

很多玩家会问：VMOS Pro 里能不能装 Magisk（面具）？

短期结论是**官方不完整支持**。VMOS Pro 的 ROOT 方案基于传统的 su 二进制（daemonsu / SuperSU），和 Magisk 的 systemless 注入机制架构层面不兼容。直接装 Magisk Manager 会提示设备不支持，即使强行移植部分组件，核心功能（模块安装、Zygisk、Hide）也无法正常工作。

这不是操作问题，是产品层面还没适配——官方 FAQ 也明确提到 Magisk 适配需要较长时间。

那想实现 Magisk 模块的功能怎么办？用 **Xposed 框架**替代。下面是一些常见需求的替代方案：

| 需求 | Magisk 模块 | Xposed 替代 |
| --- | --- | --- |
| 状态栏定制 | Iconify | GravityBox / Xposed Edge |
| 隐藏 ROOT 状态 | Magisk Hide | RootBeer Cloaker |
| 指纹模拟 | MagiskFrida | Device Emulator Pro |
| 字体替换 | Magisk 字体模块 | PerApp Settings |

对玩机玩家来说，VMOS Pro 提供的 **ROOT（SuperSU）+ Xposed SDK25** 组合已经覆盖了绝大多数玩机需求。想要改系统行为用 Xposed 模块，想要 ROOT 权限给 App 用虚拟机自带 ROOT，想要修改 build.prop 等系统文件用 Root Explorer 直接改。这套传统方案经过多年社区打磨，稳定性和兼容性反而是最好的。

> [!NOTE]
> 如果你一定要使用 Magisk 生态，建议等待 VMOS 官方后续版本的正式适配，不要强行自己移植——架构层面的差异不是简单 APK 安装能解决的。
