## ✨ TouchScale 是什么

TouchScale 是一款把 iPhone 变成便携式电子秤的轻量工具。它的核心思路很简单：利用 iPhone 屏幕下的 3D Touch 压力传感器，读取用户按压时的真实压力值，再换算成克重显示出来。对那些需要临时称一点小物件（比如咖啡豆、珠宝、调料包）又不想随身揣个小电子秤的人来说，TouchScale 算是把闲置硬件派上了用场。

目前 TouchScale 有两种形态并存：**网页版**直接在 Safari 里打开就能用，零安装、零账号，靠的是 iPhone 自带的硬件传感器读数；**App Store 正式版**由开发者 Sheng Yong Loh 维护，除了传统的 3D Touch 称重，还加了 AI 相机拍照估重——对没有 3D Touch 硬件的新 iPhone（XR 及以后机型），拍照估重是唯一能用的路径。两个版本共享同一套称重原理，但在设备兼容性和功能覆盖上各有边界。

> [!NOTE]
> TouchScale 的精度上限受物理硬件限制。3D Touch 传感器的量程大约在 0~400 克力之间，超过这个范围的重物会触发过载保护；AI 拍照估重的精度取决于物体形状（规则物体好估算，不规则物体误差大）。它适合日常粗略称量，不适合精密实验或商业交易场景。

## 🔧 安装步骤

根据你打算用 TouchScale 的哪种形态，安装方式完全不同：网页版不需要任何安装动作，App Store 版则是常规的 iOS 应用安装流程。

### 网页版：30 秒直达

网页版是一串纯静态文件，没有服务端、没有账号系统、没有安装包。操作只有一步：在 Safari 地址栏输入可用的镜像网址，回车即可。社区爱好者维护了多个镜像源，任何一个都能正常工作，内容完全相同。

> [!TIP]
> 首次打开网页版时，如果界面上直接显示红色的「NOT SUPPORTED」提示，不用继续折腾——你的 iPhone 大概率是 XR 或更晚的机型，没有实体 3D Touch 传感器。这不是你操作错了，是硬件先天不支持，直接跳去 App Store 装正式版用 AI 拍照估重即可。

如果你确定想长期用网页版，Safari 打开后点底部的分享按钮，选「添加到主屏幕」，下次桌面点图标就能直接进入，体验和 App 几乎一样。

### App Store 版：正规安装

正式版 App 的安装就是标准 iOS 应用流程：

1. **确认系统版本**：TouchScale 正式版要求 iOS 17.6 或更高。到「设置 → 通用 → 关于本机 → 软件版本」核对，不够就先跑系统更新。
2. **去 App Store 搜索**：搜「TouchScale」，认准开发者是 Sheng Yong Loh 的那个条目，别下错同名 App。
3. **下载安装**：23.1MB 大小，Wi-Fi 下几十秒就能装完。

安装完成后，第一次打开 App 会请求相机权限（AI 拍照估重用），允许即可。如果相机权限被临时禁用或自己不小心关掉了，可以到「设置 → 隐私与安全性 → 相机 → TouchScale」手动开启。

## 📖 使用入门

TouchScale 上手不难，但要获得靠谱的读数，几个关键细节决定了精度上限。以下内容综合了网页版和 App Store 版的共用要点与各自特性。

### 设备门槛先搞清楚

网页版和 App Store 版的硬件兼容性差异很大，先自查一遍自己的 iPhone 属于哪一类，再决定用哪种形态：

| 机型 | 3D Touch 硬件 | 网页版可用 | App Store 3D Touch 称重 | App Store AI 拍照估重 |
|---|---|---|---|---|
| iPhone 6s / 6s Plus | ✓ 实体传感器 | ✓ | ✓ | ✓ |
| iPhone 7 / 7 Plus | ✓ 实体传感器 | ✓ | ✓ | ✓ |
| iPhone 8 / 8 Plus | ✓ 实体传感器 | ✓ | ✓ | ✓ |
| iPhone X | ✓ 实体传感器 | ✓ | ✓ | ✓ |
| iPhone XS / XS Max | ✓ 实体传感器 | ✓ | ✓ | ✓ |
| iPhone XR 及以后 | ✗ 只有 Haptic Touch | ✗ NOT SUPPORTED | ✗ | ✓ |
| iPhone SE（全系列） | ✗ | ✗ | ✗ | ✓ |
| 所有 iPad | ✗ | ✗ | ✗ | 部分可用 |
| 所有安卓手机 | ✗ 无统一标准 | ✗ | ✗ | 不支持 |

> [!WARNING]
> Haptic Touch 和 3D Touch 不是一回事。Haptic Touch 只有「你长按了屏幕」这个二值信号，没有压力数据；3D Touch 则有屏幕下的压力传感矩阵，能读取连续的压力值。从 iPhone XR 开始，苹果全面转向 Haptic Touch，所有新型号硬件上就不支持网页版了，网页版打开一定报 NOT SUPPORTED。

自查方法：打开「设置 → 辅助功能 → 触控」，如果看到「三维触控」开关就是 3D Touch 机型；如果只有「触感触控」就是 Haptic Touch 机型，网页版不用试。不同 iOS 版本的路径可能略有差异，有的版本直接在辅助功能里叫「3D Touch」。

### 手机放置：决定精度的第一因素

TouchScale 用户反馈里，读数不准、数字乱跳的情况超过四成是因为手机没放对。正确放法只有一种，错误放法各有各的问题：

**三种常见错误放法别踩**：

- ❌ **膝盖或腿上**：腿是软的、会随心跳微振动，哪怕你觉得坐得很稳，传感器读数也会在 ±5g 范围内飘。
- ❌ **鼠标垫、笔记本等软垫上**：3D Touch 传感器需要均匀直接的压力传递，软垫会缓冲掉 5~15% 的压力，读数系统性偏小。
- ❌ **倾斜放置**：传感器只检测垂直于屏幕表面的压力，倾斜时重力有一部分变成滑动摩擦力，没被捕捉到。

**正确放法必须同时满足**：

1. **完全水平**：用手机自带的水平仪 App 或放一杯水确认，屏幕不能歪。
2. **坚硬表面**：大理石、玻璃、花岗岩、实心木桌是最佳选择；空纸箱、软布、笔记本一律排除。
3. **无振动环境**：远离走路通道、空调外机、马路边等振动源。

### 物品放置：中央区域精度最高

3D Touch 传感器在屏幕上的精度分布不是均匀的，中央 30% 区域是精度最好的区域，往边缘走精度会明显衰减：

| 屏幕位置 | 精度相对中央 |
|---|---|
| 中央 30% 区域 | 100% 最佳 |
| 中周 30% 区域 | ~90% 轻微衰减 |
| 边缘 40% 区域 | ~70~80% 明显衰减 |

网页版界面中央那个虚线框就是用来标记最佳放置区域的。物品放框里读数最准，放框外精度直接打折。

放物品的标准动作：从屏幕正上方 5~10cm 轻轻松开，不要扔不要拍；放好后双手完全离开屏幕（手掌余光离屏幕太近也会干扰电容传感器）；等 2~3 秒让压力传感器稳定下来再读数。

### AI 拍照估重的实用技巧

没有 3D Touch 硬件的新 iPhone 用户只能用 App Store 版的 AI 拍照估重功能。它的精度取决于几个关键因素：

- **物体形状**：规则物体（立方体、圆柱体）估重准，不规则物体误差大；透明物体或反光物体识别容易出错。
- **光线条件**：光线充足时识别效果好，暗光或逆光会让物体边缘模糊，影响估算。
- **参考物清晰**：App 需要一个已知尺寸的参考物（比如一枚硬币、一张名片）来做比例尺，参考物拍得越清晰、摆放位置越靠近待估物体，精度越高。
- **避免手抖**：拍照时用双手稳住手机，或靠在支撑物上，模糊的照片直接影响识别结果。

### 常见故障速查

虽然 TouchScale 整体稳定性不错，但偶尔会出现启动白屏、长时间转圈、传感器没反应等情况。以下是几个高频问题的排查思路：

**启动白屏或卡死**：多半是 iOS 版本不够（最低 17.6）、设备内存不足（iPhone 8 或更老机型可能在加载 AI 模型时内存吃紧），或者 App 缓存损坏。解决路径：删 App → 确认系统版本 → App Store 重装。

**AI 拍照后长时间转圈**：先检查相机权限有没有被临时收回（「设置 → 隐私与安全性 → 相机 → TouchScale」开关是否打开）；然后让手机降温——Neural Engine 跑 AI 模型时手机过热会自动降速或暂停，关掉其他大功耗 App（游戏、视频、导航），阴凉处放 2~3 分钟再试。

**3D Touch 称重一直显示 0.00g**：先查系统级开关（「设置 → 辅助功能 → 触控 → 三维触控」是否打开、灵敏度调到「中」或「强」），再查 App 内灵敏度设置；如果都对还是没反应，重启手机能解决大多数传感器临时失灵。

**历史记录丢失**：极罕见，通常出现在 iOS 大版本更新时数据迁移出问题，或 App 历史版本（1.1.x）的 bug。正式版没有云同步，误删无法恢复，重要记录建议截图保存。

> [!TIP]
> 常规维护建议：保持 App 和 iOS 都是最新版本（TouchScale 针对 17.6+ 优化，更新系统能获得更好的性能表现）；每 1~2 个月清理一次不需要的历史记录释放沙盒空间；避免在极端温度（< 0℃ 或 > 40℃）环境下使用。
