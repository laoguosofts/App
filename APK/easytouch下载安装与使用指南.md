## ✨ EasyTouch 是什么

EasyTouch 是一款专为 Android 手机设计的悬浮球辅助工具。它在屏幕边缘提供一个常驻的圆形悬浮入口，通过单击、双击、长按、滑动等多种手势，可以快速触发 Home 键、返回键、截屏、清理后台、音量调节等常见操作，省得每次都去按实体键或在屏幕上做大范围滑动。

对于大屏手机用户来说，单手操作时拇指够不到屏幕上半部和角落，EasyTouch 把这些够不到的操作转移到悬浮球手势上——点一下悬浮球就能完成通知栏下拉、音量调节、最近任务切换等动作，显著降低了单手持机时的操作难度。除了悬浮球核心功能，EasyTouch 还集成了垃圾文件清理模块，可以扫描应用缓存、卸载残留、空文件夹并一键释放存储空间，作为一个多合一的轻量工具，适合日常使用、通勤族、以及追求单手效率的用户群体。

## 🔧 安装与权限配置

EasyTouch 的安装流程与普通 Android 应用一致，但安装完成后需要开启几项关键权限才能让悬浮球正常工作。

### 安装步骤

1. 打开下载好的安装包（APK 文件），系统会弹出安装提示
2. 如果提示「未知来源安装被禁止」，需要先在系统设置里允许安装未知来源应用：
   > 设置 → 安全（或隐私） → 未知来源安装 → 找到浏览器/文件管理器 → 打开允许
3. 确认应用权限列表，点击「安装」等待完成
4. 安装完成后先别急着关闭安装页面，点「打开」直接进入应用

### 首次启动的必要权限

首次打开 EasyTouch 时，应用会引导你开启以下权限，按提示一步步操作即可：

> [!TIP]
> 辅助功能权限（Accessibility）是 EasyTouch 最核心的权限，没有它悬浮球无法响应手势、截屏等功能也无法工作。部分品牌手机在设置路径上会把辅助功能藏得比较深，参考下表快速定位。

| 权限名称 | 作用 | 开启路径 |
|----------|------|----------|
| 辅助功能（无障碍） | 悬浮球手势响应、截屏、模拟按键 | 设置 → 无障碍（或辅助功能） → 已下载的服务 → EasyTouch → 开启 |
| 显示在其他应用上层 | 悬浮球能覆盖在所有 App 之上 | 设置 → 应用 → EasyTouch → 权限 → 显示在其他应用上层 → 允许 |
| 自启动 | 开机后自动运行，悬浮球常驻 | 各品牌路径不同，见下文各品牌开启路径 |

### 各品牌自启动权限开启路径

不同品牌的 Android 系统对自启动的叫法和入口位置都不一样，按你的手机品牌对照找到即可：

| 品牌 | 开启路径 |
|------|----------|
| 小米 / Redmi | 设置 → 应用设置 → 自启动 → 找到 EasyTouch → 打开 |
| 华为 / 荣耀 | 设置 → 应用和服务 → 应用启动管理 → 找到 EasyTouch → 允许自动启动 + 关联启动 + 后台活动 |
| OPPO / 一加 | 设置 → 应用管理 → 自启动管理 → 找到 EasyTouch → 允许 |
| vivo | 设置 → 应用与权限 → 权限管理 → 自启动 → 找到 EasyTouch → 允许 |
| 三星 | 设置 → 应用 → EasyTouch → 电池 → 无限制 |

> [!WARNING]
> 华为和荣耀用户需要把「允许自动启动」「允许关联启动」「允许后台活动」三个开关全部打开，少一个都可能导致悬浮球被系统杀掉。

### 验证是否生效

权限都开完之后，建议重启一次手机，确认悬浮球能自动出现在屏幕边缘：

1. 重启手机
2. 解锁后直接看屏幕边缘，不需要手动打开 EasyTouch
3. 如果悬浮球没出现，回头检查自启动和后台活动权限是否都已开启

## 📖 功能与操作指南

### 悬浮球位置与手势基础

默认情况下，EasyTouch 的悬浮球会放在屏幕右下边缘并开启边缘吸附——也就是贴在屏幕边上，不会挡住应用内容，需要时点一下它就展开。你可以在设置里调整位置、大小、透明度，以及绑定手势对应的功能。

### 单手操作场景配置

大屏手机单手使用时，拇指的自然覆盖范围主要集中在屏幕下方三分之一的右下区域。EasyTouch 的核心优势就是把拇指够不到的上半部和角落操作，全部转换成悬浮球手势。以下是一个右手持机的推荐手势分配方案：

| 手势 | 绑定功能 | 替代的原操作 |
|------|----------|-------------|
| 单击 | 回桌面（Home） | 按屏幕底部 Home 键 |
| 双击 | 最近任务 | 从屏幕底部上滑 |
| 长按 | 音量调节弹窗 | 按实体音量键 |
| 左滑 | 展开通知栏 | 从屏幕顶部下拉 |
| 右滑 | 截屏 | 电源键 + 音量键组合 |
| 上滑 | 返回键 | 部分全面屏手势下在屏幕左边缘操作 |
| 下滑 | 清理后台 | 从屏幕底部上滑后逐个划掉 |

面板里建议只留 3-5 个最高频的功能图标，塞太多反而难找。一个精简的典型配置是：

```
Home | 返回 | 音量 | 清理后台 | 常用 App 快捷入口
```

屏幕顶部的时间、电量、通知图标对单手操作来说是重灾区，把以下操作转移到悬浮球上能大幅减少抬手次数：

- 拉通知栏 → 手势绑定「展开通知栏」
- 调节亮度 → 面板里放亮度滑块
- 开关 WiFi / 蓝牙 → 面板快捷开关

### 一键截屏配置

把截屏绑定到悬浮球手势（比如右滑）之后，任何界面下——包括全屏游戏、视频播放器内——一滑就能立刻触发截屏，比按电源键 + 音量键组合好按得多。具体设置：

1. 进入 EasyTouch 手势设置
2. 选择「向右滑动」或「向下滑动」手势
3. 在功能列表里选择「截屏」（Screenshot）
4. 保存设置

截屏后的图片默认保存在「手机内部存储 / Pictures / EasyTouch /」目录，相册 App 的「EasyTouch」分相册里可以直接找到。文件名一般带时间戳，方便区分。

> [!NOTE]
> EasyTouch 截屏依赖辅助功能权限。部分银行 App 或版权视频 App 有应用层面的反截屏保护，任何截屏工具都无法绕过这个限制，包括系统自带截屏。

### 垃圾文件清理

除了悬浮球核心功能，EasyTouch 还内置了清理模块，可以扫描并清除应用缓存、卸载残留、空文件夹、无用安装包等垃圾文件：

| 垃圾类型 | 可否安全删除 | 说明 |
|----------|-------------|------|
| 应用缓存 | ✅ 可删 | 应用临时下载的图片、配置，删掉后会自动重建 |
| 卸载残留 | ✅ 可删 | 已卸载应用遗留的安装包和临时文件 |
| 空文件夹 | ✅ 可删 | 应用卸载后留下的空目录 |
| 缩略图缓存 | ✅ 可删 | 相册自动重建 |
| 日志文件 | ✅ 可删 | 应用运行时的记录 |
| 用户数据 | ❌ 别删 | 游戏存档、微信聊天记录等 |

清理的操作流程很简单：打开 EasyTouch 主界面 → 进入清理模块 → 点「扫描」→ 等几秒扫描结果出来 → 确认后点「清理」。存储空间清理的收益比内存清理更直观，清理完在手机存储设置里就能看到可用空间增加。

### 自启动与后台保活

系统的省电策略和后台清理是悬浮球消失的最常见原因。除了之前提到的自启动权限，还需要检查「后台活动」权限是否也开了——它控制的是应用能不能在后台保持运行而不被系统强制休眠。

> [!NOTE]
> EasyTouch 不会清理用户数据（游戏存档、离线地图、聊天记录等），它的扫描范围只覆盖缓存、临时文件和卸载残留。但扫描结果里如果出现缓存视频、缓存音乐等离线媒体文件，建议仔细看一眼再决定要不要清理。
