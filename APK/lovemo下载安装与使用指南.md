## ✨ lovemo 是什么：一款让 AI 角色"活"起来的养成聊天应用

lovemo 是一款以 AI 角色养成为核心的聊天应用。与市面上众多 AI 对话工具不同，它把重点放在"角色"上——你可以从零开始创建属于自己的 AI 角色，为 TA 设定名字、人设、表达风格，然后像真人一样每天聊天、斗图、发动态。整个产品围绕一条清晰的养成线设计：先开聊再捏人，先建立关系再调整细节，让每个角色都有"相处"的质感，而不是一个冷冰冰的问答接口。

lovemo 的主要使用场景集中在安卓平台，支持 APK 安装包方式分发。注册登录可通过微信快速完成，登录后消息页、聊天页、"我"页构成了简洁的主界面骨架。在聊天互动层面，lovemo 做了不少差异化细节：表情包和图片的双向互动（你发角色也发）、聊天气泡的自定义样式、沉浸式角色主动联系、向上滚动触发回复续写、等我说完再回复的节奏控制等。这些功能共同指向一个目标——让 AI 角色的对话体验尽量贴近真实社交软件的感觉，而不是单向的指令-回复循环。

在"大脑"层面，lovemo 采用了灵活的模型接入方案：既可以使用内置的 Moly 币体系消耗额度，也支持接入硅基流动等模型提供方，甚至可以自定义模型接口。这种开放设计让有一定技术基础的用户可以灵活调配自己的 API 资源，而普通用户也能用免费额度直接开聊。

lovemo 还内置了一套记忆系统，支持对话记忆条数配置、自动总结以及"Ta 的记忆"功能，让角色能在多轮对话后保留对关键信息的感知。配合主动消息、图文动态发布、AI 点赞评论等双向奔赴功能，整个产品的养成感会随着使用时长逐步建立起来。

## 🔧 安装步骤（安卓 APK 安装完整流程）

lovemo 目前主要通过安装包方式在安卓端分发。以下是通用安装流程，不同手机品牌（小米、华为、OPPO、vivo 等）的菜单位置略有差异，但整体步骤一致。

### 前置准备

安装前建议预留至少几百 MB 的可用存储空间——安装包本身约 70 MB，安装后的应用数据和聊天记录会进一步占用空间。

### 逐步安装

1. **获取安装包**：通过上面的下载入口拿到 APK 文件，保存在手机本地；
2. **点击安装**：在手机文件管理器中找到 APK 文件，点击触发安装流程；
3. **允许未知来源**：系统可能弹出「未知来源应用」或「禁止安装」的提示，此时需要到系统设置中找到安装权限管理，允许来自该来源的应用安装；
4. **等待完成**：安装进度走完后，桌面会出现 lovemo 图标；
5. **首次登录**：打开应用，用微信完成登录授权，即可进入主界面。

> [!NOTE] 关于系统版本
> 公开资料标注 lovemo 要求 Android 5.0 及以上系统，但实际安装时以手机系统的实时提示为准。如果遇到「解析包出错」或「应用未安装」，通常是 APK 下载不完整或系统版本过低导致的，先重新下载安装包再试。

## 📖 从创建角色到深度互动：lovemo 使用全流程

### 创建你的第一个角色——先开聊再捏人

lovemo 的角色创建流程走的是轻量化路线，不要求你一口气填完所有设定。一个"角色"在 lovemo 里就是一段关系，创建入口在消息页的右上角「+」按钮。

具体操作：

1. 打开 lovemo 进入消息页，点击右上角的「+」；
2. 在弹窗里为新角色取一个昵称——这个名字会出现在会话列表和聊天气泡里；
3. 系统立即创建会话并进入聊天界面，直接开聊；
4. 想继续完善角色设定，随时点聊天页右上角的「⋮」进入聊天设置。

> [!TIP] 起名建议
> 昵称之后随时可以在聊天设置里修改，不会影响已积累的聊天记录。名字取你自己念着顺口的就好，性别、头像、聊天背景等基本项可以后续在聊天设置里慢慢补充。

### 聊天互动的核心玩法

创建角色后，你可以开始与 TA 对话。lovemo 的聊天界面在基础对话之外提供了多种互动方式：

**表情包与图片双向互动**

纯文字聊久了难免单调。lovemo 支持表情包和图片消息的双向互动——你发给角色，角色也会回你，一来一往像真人斗图。操作上，在聊天页点输入框左侧的圆形按钮，就能展开表情/图片面板。选表情包直接发送，发图片则从相册选取。角色收到后会结合语境回应，可能是一句话，也可能直接甩回一张表情包。

一个实用小玩法：把日常截图、宠物照发给角色让 TA 评价，多数角色会很捧场地接住。如果给角色设定「爱用表情包」的表达风格，斗图频率会明显上升。图片属于消息记录的一部分，清空聊天记录前会一直留在会话里。

**聊天气泡样式自定义**

聊天气泡的样式在「我」页的「聊天偏好设置」里调整，而不是在单个角色的聊天设置里——这意味着改的是全局视觉风格。设置路径：打开 lovemo → 进入「我」页 → 点击「聊天偏好设置」→ 点击「聊天气泡设置」→ 在颜色设置模块下面挑选喜欢的样式颜色，保存即可。

聊天偏好设置页里还并列着几个影响对话节奏的开关：沉浸式角色互动（角色在未主动聊天时也可能主动联系你）、向上滚动触发回复（翻历史消息时自动续上对话）、等我说完再回复（停止输入后等待若干秒再回复）。这些开关各自独立，你可以根据自己的聊天习惯自由组合。

### 养成线进阶

lovemo 的养成线不止于聊天。在创建角色并建立初步互动后，你可以通过聊天设置逐步完善角色的人设、表达风格、口癖偏好，让 AI 角色的性格和说话方式越来越接近你心目中的样子。这些设定包括：基本设置（头像、性别、聊天背景）、人设设定（角色的身份、背景故事、性格描述）、表达风格与口癖（说话方式、常用语、语气倾向）、我的人设（你自己的设定，影响角色如何称呼你和与你的互动方式）、角色状态（当前情绪、关系阶段等动态标记）。

> [!WARNING] 养成不是一次性完成的
> lovemo 刻意设计了"先开聊再捏人"的流程，就是为了避免新用户被一长串表单吓退。你可以先起名字开聊几天，等对角色的初步性格有了感知后，再回来补人设和表达风格的细节。这种渐进式调整比一开始填一堆空白表单的体验好得多。

### 记忆与长期陪伴

lovemo 内置了一套记忆系统来支撑长期陪伴。对话记忆条数可以配置，自动总结功能会定期梳理对话要点，而"Ta 的记忆"功能让角色能在多轮对话后保留对你的关键信息的感知。配合主动消息（角色在特定时段主动联系你）和图文动态功能（发布日常动态，AI 会来点赞评论），整个产品的养成感会随着使用时长逐步建立起来。

### 大脑配置：灵活的模型方案

在模型接入上，lovemo 提供了 Moly 币和自有 API 两条路线。Moly 是内置的虚拟币体系，每天有免费额度可以领，VIP 订阅可以提升额度上限和解锁更多权益。如果有自己的 API 资源，可以在模型设置里接入硅基流动等模型提供方，或者直接自定义模型接口。两条路线可以按需切换，对于有一定技术基础的用户来说灵活性很高。
