## 🔧 安装步骤 —— 一路默认即可，留意杀毒误报

Revo Uninstaller 是典型的 Windows 桌面软件，安装过程不复杂。下面按免费版和 Pro 版分别说。

### 下载与校验

1. 打开下载页，选择对应的安装包（32 位 / 64 位系统自动匹配，现在基本都是 64 位）
2. 文件大小通常在几 MB 量级，下载完成后建议核对一下文件大小是否与下载页标注一致，避免拿到损坏或中途截断的包
3. 如果浏览器提示文件有风险，这是 Windows SmartScreen 的常见误报——正规渠道下载的安装包可以信任

### 安装过程

1. 双击安装包，Windows 弹出 UAC 提权窗口时点"是"
2. 选择安装路径。默认是 `C:\Program Files\VS Revo Group\Revo Uninstaller\`，如果 C 盘空间紧张可以改到其他盘，但大多数情况默认就行
3. 安装过程会创建开始菜单项、桌面快捷方式，这些都可以按需勾选
4. 点完"安装"后等几十秒就能装好

> [!WARNING] 杀毒软件误报
> 部分杀毒软件（尤其是国产的几款）可能会把 Revo 的安装器当成潜在风险软件标记。原因是 Revo 的核心能力就是扫描和删除注册表键值，这种行为特征跟病毒类似。只要你是从官方渠道下载的，就可以放心添加信任或暂时关闭杀毒后再装。装完记得重新开启。

### 装完怎么确认是正版

- 免费版打开后界面顶部有"Revo Uninstaller Free"字样
- Pro 版会显示授权状态（"Licensed to: xxx"）
- 在菜单 → 帮助 → 关于里能看到版本号、构建号、授权信息

## 📖 使用入门 —— 四大核心能力逐个说

Revo Uninstaller 不是一个只会"点卸载"的简单工具，它能做的事情远不止清理残留。下面挑最常用、最有价值的几个能力来讲。

### 扫描级别怎么选：Safe / Moderate / Advanced

Revo 在标准卸载完成之后会做深度扫描，扫描深度分三档，理解这个是用好 Revo 的前提：

| 扫描级别 | 扫描范围 | 速度 | 适合场景 |
|---|---|---|---|
| Safe | 仅标准卸载器标记过的残留 | 最快 | 卸载官方软件、没装第三方工具、追求稳妥 |
| Moderate | Safe + 常见残留目录和注册表项 | 中等 | 日常清理，大多数时候选这个就好 |
| Advanced | Moderate + 全盘深度扫描 | 慢 | 软件卸不干净、怀疑有顽固残留、追踪安装后的精准清理 |

> [!TIP] 扫描能大胆选 Advanced 的底气
> 为什么敢选最狠的 Advanced？因为 Revo 在每次扫描和删除之前，**已经自动备份了要动到的注册表键值**。备份位置在 `%AppData%\VS Revo Group\Revo Uninstaller Pro\Backups\`，Revo 自有格式 + 标准 .reg 文件两份都存。万一删错了，用 regedit 导入那个 .reg 文件就能一键还原。

### 注册表自动备份：敢深度扫描的根本保障

Revo 的多级扫描机制背后，是一套被低估的备份系统。它在任何卸载操作（标准卸载 / Quick Uninstall / Forced Uninstall / 猎手模式卸载 / 追踪卸载）**开始之前**，就已经分析出了本次操作可能涉及的所有注册表条目，并先做快照备份再开始扫描。备份文件体积通常只有几百 KB 到几 MB，几乎不占空间，但关键时刻能救命。

这个备份跟 Windows 系统还原点是两套东西。系统还原点覆盖整个系统状态（注册表 + 系统文件 + 安装的程序），Revo 的注册表备份只覆盖本次卸载涉及的键——恢复更快、更精准，不会导致你还原到某个时间点之后新装的软件消失。Revo 甚至在卸载前会**同时创建两者**：注册表备份用于精细恢复，还原点用于极端情况下的系统回退。备份默认开启，建议保持不要关闭。

### 四种卸载模式：有日志跟没日志是两条路

Revo Pro 提供了四种追踪卸载模式，什么时候用哪个，简单记一条：

| 模式 | 场景 | 扫描方式 | 用户确认 |
|---|---|---|---|
| Uninstall（Traced Programs） | 绝大多数日常卸载 | 自动用日志，不额外扫 | 全自动 |
| Advanced Uninstall | 日志里有不确定的条目想过一遍 | 自动用日志 | 需要手动勾选确认 |
| Custom Uninstall | 想先修改日志条目、再加一层扫描 | 自由选扫描级别 | 完全手动 |
| Forced Uninstall | 没有日志、卸载器缺失或损坏 | 三档扫描任选 | 标准流程 |

核心分界线：**有日志**还是**没日志**。用了 Revo 的"追踪安装"功能装的软件，卸载时 Revo 手里有一份完整的注册表和文件变更日志，这时候直接用 Uninstall 或 Advanced Uninstall 就行——日志比任何扫描都精准。没日志但知道软件在哪，就用 Forced Uninstall 指定一个路径让它从零开始扫。

Custom Uninstall 是给"想全程手动控制"的进阶用户准备的——可以先编辑日志（删掉里面混入的无关条目），再选 Safe/Moderate/Advanced 任意一档追加扫描，注册表窗口和文件窗口都要手动勾选才删。适合对自动删除不放心、或者日志被污染过的情况。

### 猎手模式：所见即所得的快速处理

猎手模式（Alt+H）是 Revo 里最有特色的功能之一——启动后屏幕上会出现一个准星，拖到任何**正在运行的窗口、任务栏按钮、托盘图标**上松开，Revo 就反查出这个程序的进程、安装路径、自启动位置，然后给你一组操作选项。

它不只是用来卸载窗口里的程序，**管理自启动**才是猎手模式最惊艳的用法：

1. 按 Alt+H 启动猎手模式
2. 准星拖到烦人的托盘图标上松开
3. 选"停止并禁用自启动"——Revo 先 kill 掉当前进程，再找到它的自启动注册位置（注册表 Run 键 / 启动文件夹 / 计划任务）禁用

整个过程 3 秒搞定，比去 Autorun Manager 的几百条列表里翻快得多。禁用不是删除，注册项还在 Autorun Manager 里灰着，想恢复时勾回去就行。如果确定永远不再需要，在 Autorun Manager 里点 Remove 才是真正删掉。

### 程序分组：让 All Programs 不再是一锅粥

Revo 默认把已安装程序按"新程序（7 天内装的）"和"其他程序"来分组显示，程序多了之后还是一锅粥。Groups Manager 允许你按自己的逻辑把程序归类：

- 所有浏览器放一组，所有游戏放一组（将来批量清理过期游戏方便）
- 所有免费试用版放一组，定期检查哪些到期该续或该删
- 按工作场景分组：开发工具 / 设计工具 / 日常办公 / 影音娱乐

操作很直接：在 All Programs 里右键任意程序 → Add to Group → Add new group → 输入分组名，完事。也可以从菜单 → 选项 → 分组管理里集中管理。一个程序只能在一个分组里（新程序 / 其他程序 / 自定义分组三选一），内置的四个默认分组（Internet / Games / Multimedia / Utilities）不能删也不能改名。

> [!NOTE] 缓存重建会清分组
> 在 All Programs 里执行"Rebuild cache file"会**清除所有自定义分组、图标、注释**。如果缓存确实需要重建（比如程序列表显示异常），重建前记得先把分组里的程序位置记一下，或者考虑有没有必要重建。

### 残留文件：Revo 会列出但不会"一刀切"

Revo 扫描完成后，会把找到的注册表残留和文件残留分别列在两个窗口里。注册表部分通常可以全选删除——这是 Revo 扫描的强项，误判概率很低。文件部分需要过一眼：有时候 Revo 会把软件共享的运行库也标成残留，这时候**只删那些明确是本软件独有的文件夹**，共享 DLL 之类先别碰。
