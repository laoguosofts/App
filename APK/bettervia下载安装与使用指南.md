## ✨ BetterVia 是什么

BetterVia 是 Via 浏览器的增强扩展模块，通过 Xposed/LSPosed 框架注入运行，为原版 Via 补齐了大量缺失的实用功能。从解除浏览器脚本白名单、到截屏防护、隐私锁、启动执行自动化——每一项都是日常高频使用中会真正感知到的改进。

原版 Via 虽然以轻量著称，但在一些细节上做了精简或限制：腾讯视频被单独列入脚本白名单导致油猴脚本无法生效、没有系统级截屏保护、浏览历史和书签缺少独立的上锁入口、启动流程也无法自定义。BetterVia 就是针对这些点位逐一开刀，让 Via 在保持轻量的同时变得更可控、更安全。

它适用于已经是 Via 重度用户、又愿意花几分钟折腾增强模块的 Android 玩家。不需要 root（LSPatch 免 root 方案可行），也不依赖 Magisk——只要设备能装 Xposed/LSPosed，就能跑。

## 🔧 安装与激活

BetterVia 有两种安装路径，取决于你的设备是否 root：

### LSPosed 模块方式（推荐，需 root）

1. **安装 LSPosed 框架**：设备已 root 后，通过 Magisk 安装 LSPosed 模块并重启
2. **安装 BetterVia APK**：正常安装下载到的 APK 文件
3. **在 LSPosed 管理器中启用模块**：打开 LSPosed → 模块列表 → 勾选 BetterVia → 作用域选择 Via 浏览器
4. **强制停止 Via 后重新打开**：模块注入生效需要 Via 进程重启

### LSPatch 免 root 方式

没有 root 的设备可以用 LSPatch 对 Via APK 进行补丁：

1. 安装 LSPatch 和 BetterVia APK
2. 在 LSPatch 中选择 Via APK → 注入 BetterVia 模块
3. 生成补丁版 Via APK 并安装（需要先卸载原版 Via）

> [!WARNING]
> LSPatch 方式每次 Via 升级后都需要重新打补丁，维护成本较高。如果有 root 权限，优先走 LSPosed 模块方式。

### 安装后验证

打开 Via，检查状态栏或侧边栏是否出现 BetterVia 的入口；或者进入 Via 设置，看是否多出了 BetterVia 相关的设置分组。如果都没有，说明模块没有正确注入，回到 LSPosed/LSPatch 管理器检查作用域选择。

## 📖 使用入门

BetterVia 的功能不少，但上手不需要全部搞定——挑几个最刚需的先用起来就好。下面按日常使用频率从高到低介绍核心能力。

### 解除浏览器脚本白名单

Via 从某个旧版本开始内置了一个奇怪的脚本白名单，只包含 v.qq.com 和 film.qq.com 两个腾讯视频域名。这意味着在其他任何视频网站（优酷、爱奇艺、B 站、喜马拉雅）上你本来就能装油猴脚本，但唯独腾讯视频不行——UI 层面直接把脚本入口藏起来了，手动导入的脚本也不会执行。

BetterVia 通过 hook Via 内部的脚本启用判断方法，强制让这两个域名"退出"白名单。生效后：

- Via 设置 → 浏览器脚本里可以正常导入针对腾讯视频的脚本
- 访问腾讯视频页面时已启用的脚本自动注入
- 脚本的执行时机和权限与其他站点完全一致

常见的配套脚本包括：精简页面（去推广 Banner 和会员推荐）、弹幕净化（过滤广告弹幕）、播放增强（自定义倍速、自动跳过片尾）。脚本本身需要自己找，BetterVia 不提供脚本编辑器。

### 隐私锁——五个场景按需上锁

BetterVia 的隐私锁不只是一个开关，而是针对 Via 的不同敏感区域提供了五种独立的上锁粒度：

| 受保护页面 | 触发时机 | 适用场景 |
|:---|:---|:---|
| Via 启动页 | 每次打开 Via | 整个 App 都不想被碰 |
| 历史单页面 | 打开历史记录列表 | 日常浏览不打扰，但有几条历史不想被翻 |
| 书签单页面 | 打开书签列表 | 书签里有私人链接 |
| 离线网页页面 | 打开离线网页列表 | 离线保存的敏感帖子或邮件快照 |
| 混合页面 | 有历史/书签常驻 UI 时，超时自动锁 | Via 某些主题把书签常驻侧边栏，离开时自动隐藏 |

验证方式支持数字密码、图案或指纹，连续 3 次失败会临时锁定 60 秒。推荐的组合方案：如果只是不想让历史被翻，开历史单页锁就行；如果担心锁屏后有人捡到手机翻看，启动页锁 + 混合页面超时锁的双重保险更靠谱。

### 截屏防护——配合隐私锁的第二道防线

Android 系统允许 App 通过 FLAG_SECURE flag 阻止截屏和录屏，Via 本身不内置这个功能。BetterVia 的截屏防护就是在 Via 进程内动态设置这个 flag，让系统对 Via 的渲染区域开启保护。

开启后，系统截屏会提示"由于安全策略禁止截屏"，录屏则录到黑屏或空白区域。部分版本支持精细控制：全局保护（所有页面）、仅特定页面保护（只对隐私锁涵盖的页面生效）、智能判断（URL 匹配自定义关键词如 mail、account 时自动开启）。

> [!TIP]
> 推荐使用「仅特定页面保护」——日常浏览的普通页面没必要禁止截屏，某些网站（如银行 App 的登录回调页）反而需要截屏功能。

需要注意的边界：root 设备上的截屏工具可以通过直接读取帧缓冲绕过 FLAG_SECURE，物理拍摄屏幕更是任何软件都阻止不了。截屏防护和隐私锁是互补关系——隐私锁防止别人打开敏感页面，截屏防护防止打开后截屏保存，两者组合才是完整方案。

### 启动执行——让 Via 每天按你的流程自动启动

每天打开 Via 后你可能都按固定流程操作：先去知乎热榜看一眼、再打开 B 站、切到深色模式、启用某个常用脚本。BetterVia 的启动执行功能就是把这些重复动作自动化。

可以编排的动作分为三类：

- **导航类**：自动打开指定 URL（支持多个，新标签页分别打开）、跳转到某个书签文件夹、打开历史记录列表
- **配置切换类**：切换主题、开启/关闭超级隐身、启用指定脚本、设置临时视频倍速
- **工具类**：自动清理 Cookie、执行某个开机脚本、截取启动后屏幕快照

动作间有 200ms 左右的间隔时间，避免 Via 还没准备好就执行下一步。执行时机也可以灵活选择：每次启动、仅每天首次启动、仅特定时间段内、或者手动触发。进阶选项还支持条件触发——比如系统深色模式时才切暗色主题、连接到家庭 WiFi 时才执行某个动作。

一个实际可用的配置组合（上班族通勤场景）：

1. 执行时机：每天首次启动
2. 动作 1：切换到 Material You 主题
3. 动作 2：自动打开知乎热榜 + B 站推荐页
4. 动作 3：启用夜间护眼模式

> [!NOTE]
> 启动执行会增加 Via 启动时间——打开的网页越多、初始化的脚本越多，延迟越长。升级 Via 后建议验证一下，内部类名和方法签名的变化可能导致部分 hook 失效。
