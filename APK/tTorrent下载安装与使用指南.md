## ✨ tTorrent 是什么

tTorrent 是一款面向 Android 设备的 BT（BitTorrent）协议下载客户端，主打轻量、专注和无广告的使用体验。与系统自带下载器或其他重型 BT 客户端不同，tTorrent 把核心功能集中在一个界面清晰的 App 里：种子导入、队列管理、速度限制、RSS 自动订阅——做 BT 下载该做的事，不做多余的事。

它适合在手机或平板上需要偶尔或高频下载 BT 资源的用户：追剧党想自动跟进新番更新、资料收藏者想批量拉取文献包、或者只是需要一个靠谱的 .torrent 导入器。Android 上 BT 客户端的选择不算少，但 tTorrent 在 Google Play 上的长期口碑和更新频率让它在同类工具里保持了稳定的用户基础。

## 🔧 安装步骤

tTorrent 仅支持 Android 平台，不需要 PC 端配合，安装过程相对简单。

### 从应用商店安装

1. 打开 Google Play，搜索 **tTorrent**
2. 点击安装按钮，等待下载完成
3. 安装完成后直接打开首次启动向导，确认必要权限即可

### 手动安装 APK（Google Play 不可用的地区）

1. 从下载入口获取最新版 APK 文件
2. 将 APK 传输到手机存储（或直接在手机浏览器下载）
3. 在文件管理器中点击 APK 文件，系统会弹出安装确认
4. 如果首次安装未知来源应用，系统会提示开启「未知来源安装」权限——按提示跳转设置打开 tTorrent 的安装权限，再回头点击安装

> [!WARNING]
> 手动安装前**核对 APK 大小和版本号**。有些渠道分发的 APK 可能被二次打包植入广告组件，建议只从下载入口推荐的页面获取安装包。

### 首次启动的权限配置

第一次打开 tTorrent 时，App 会请求两类权限：

- **存储读取与写入**：这是最关键的权限——没有它 tTorrent 无法在设备上保存下载的文件
- **网络访问**：基础联网权限，正常情况下默认授予即可

> [!NOTE]
> 安卓 11+ 采用分区存储机制，tTorrent 会引导你选择一个具体目录作为默认保存路径。建议选一个空间充足的位置（比如下载目录或自建的 BT 文件夹），避免后续下载时遇到权限问题。

## 📖 使用入门

### 导入种子：.torrent 文件与磁力链接

BT 种子有两种常见载体：.torrent 文件和磁力链接。tTorrent 两者都支持。

**.torrent 文件**本质是一个很小的元数据文件（通常几 KB 到几十 KB），里面记录了要下载的文件名列表、每个文件的大小、分片校验值和 tracker 地址。它不包含实际内容，只是一个"下载地图"。导入方式有两种：

- **从文件管理器直接打开**：在文件管理器里点 .torrent 文件，系统弹出 App 选择器，选 tTorrent 即可
- **在 tTorrent 内部导入**：打开 App，点新增按钮，选「从文件导入」，浏览到目标文件位置选中

磁力链接则是一串以 `magnet:?xt=urn:` 开头的文本，通过复制粘贴或浏览器点击触发导入。

| 特性 | .torrent 文件 | 磁力链接 |
| --- | --- | --- |
| 依赖 | tracker 服务器在线 | DHT 分布式网络 |
| 是否会失效 | tracker 挂了可能失效 | DHT 网络上的热种子基本不会失效 |
| 体积 | 几 KB ~ 几十 KB | 一条字符串 |
| 获取方式 | 下载文件 | 复制粘贴 |

导入完成后 tTorrent 会展示种子详情页——文件名列表、总大小、可选的选择性下载、保存路径确认。确认无误后点「开始」进入下载队列。

### 选择性下载：只下需要的部分

有些种子包含几十上百个文件：一部电影附带多个语言字幕、一个资源包有不同分辨率的版本、一个软件合集包含多个平台的安装包。全下既浪费流量又占空间，这时选择性下载非常有用。

导入种子进入详情页后，切换到 **Files（文件）** 标签，可以看到完整的文件树。每个文件或文件夹前面都有勾选框——取消勾选不需要的，只保留你想要的。

文件列表里还显示一个数字，这是该文件的**下载优先级**：

| 数字 | 含义 |
| --- | --- |
| 0 | 不下载（等同取消勾选）|
| 1 | 低优先级 |
| 2 | 默认优先级 |
| 3 | 高优先级（更早完成）|

如果你想先看某一集电视剧，给它设 3、其他集设 0 或 1，tTorrent 会优先请求高优先级文件的分片。下载进行中也可以随时回详情页改勾选和优先级——取消勾选的文件会停止下载（已下载的部分保留不会丢），新勾选的会立即开始。

### RSS 订阅：自动化追新下载

RSS（Really Simple Syndication）是网页内容更新通知协议。很多种子站提供 RSS feed 链接，tTorrent 可以订阅这些频道，**自动拉取新发布的种子并开始下载**，不需要你每次手动去种子站找。

配置步骤：

1. 打开 tTorrent，进入 **Settings → RSS feeds**
2. 新增一个 feed，填写 **Feed URL**（种子站提供的 RSS 地址），可选地填一个 **Label** 给这个 feed 下的种子自动打标签
3. 勾选 **Automatically download** 开启自动下载新条目
4. 设置检查频率（比如每 15 分钟检查一次）
5. 保存后 tTorrent 会按周期轮询，有新种子就自动触发下载

> [!TIP]
> RSS feed 一次推送几十上百个种子时，可以配置**关键词过滤**来缩小范围。Include 填逗号分隔的关键词，只下载标题里包含这些词的种子；Exclude 填要排除的关键词。比如一个动漫频道 RSS，Include 填 `1080p`、Exclude 填 `480p,720p`，就只下载 1080p 画质的资源。

tTorrent 会记录每个 feed 已处理过的条目 ID，避免同一集被重复下载。自动下载的种子也会使用配置好的 Label 打上标签，主界面可以按标签筛选管理。

### 常见故障：Free space 0 B

打开 tTorrent 后顶部状态栏显示 **Free space: 0 B**，任何下载任务加进来都报存储不足或直接不动——这是 Android 上比较常见的一个问题。

根因通常是**保存路径的存储权限丢失了**。触发场景包括：Android 系统大版本更新后重置了所有 App 的存储权限、手动清理了 App 数据或缓存、SD 卡被拔出过。tTorrent 启动时检查默认保存路径的可写性，权限丢了就拿不到剩余空间数，只能显示 0 B。

修复步骤很简单，不用卸载重装也不用清缓存：

1. 进入 **Settings → Directories**
2. 找到当前配置的 Default save path
3. 点进去**重新选一遍同一个目录**——不用换路径，重新确认即可
4. 回到主界面，顶部状态栏应该就恢复正常的剩余空间显示了

> [!NOTE]
> 如果重新选路径还是不行，继续排查这几个点：存储是否真的满了（去 Android 设置里确认）、换一个保存路径试试（从 SD 卡切回内置存储）、用 SD 卡的话检查 External storage access 是否重新授权、Android 设置里 App 的「所有文件访问」权限是否打开。
