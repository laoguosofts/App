## ✨ javdb 是什么

javdb 是一款面向安卓平台的在线视频资源聚合应用，提供视频浏览、搜索、在线播放和离线缓存等功能。其核心价值在于将分散的视频资源以统一的界面形式呈现，用户可以通过关键词搜索、分类浏览快速定位到想看的内容，并支持将喜爱的视频缓存到本地离线观看。

从公开渠道可见的版本信息来看，这款应用体量较轻，安装包仅约 12.63MB，对设备性能要求不高，安卓 5.2 及以上版本的手机和电视盒子均可运行。应用采用侧载分发模式，不在官方应用商店上架，需要通过下载页获取 APK 文件手动安装。

功能层面，javdb 主打三件事：**视频浏览与搜索**（首页内容列表 + 关键词检索）、**在线播放**（适配不同网络环境自动选源）、**离线缓存**（下载管理 + 本地存储）。界面底部导航以三个标签页组织全部功能，结构清晰，上手门槛低。

## 🔧 安装步骤

### 安装前的核对清单

在开始安装之前，先确认三件事，避免走到一半卡壳：

1. **安装包完整性**：文件大小应接近 12.63MB，若只有几 MB 或明显偏小，说明下载不完整，需要重下；
2. **设备兼容性**：javdb 仅支持安卓系统，iPhone 和 PC 无法直接安装；电视盒子可以装，见下文；
3. **存储空间**：至少腾出几百 MB 的剩余空间——安装包本身不大，但应用运行后会产生缓存和离线文件。

> [!TIP]
> 下载完成后，如果对文件完整性有疑虑，可以计算 MD5 校验值与官方记录比对。已知版本的 MD5 为 `811492776C42105AA3451B7CD2091439`，一致则说明包没损坏。

### 手机安装流程

1. 用文件管理器点开下载好的 `javdb_v2.1.apk`，系统会弹出「**禁止安装来自此来源的应用**」——这是安卓对侧载应用的标准安全拦截，不代表文件有问题；
2. 按弹窗提示跳转到设置页面，为**当前这个来源**（浏览器或文件管理器）开启「允许安装未知应用」权限。安卓 8.0 及以上版本按来源逐个授权，无需全局放开；
3. 返回安装界面，点击「安装」，等待进度条走完；
4. 点击「打开」启动应用，首次启动需同意用户协议与隐私政策后才能进入首页；
5. 首页内容列表需要联网加载，第一次建议在 Wi-Fi 环境下打开。

安装过程中如果弹出 Play Protect 扫描提示，属于侧载包的常规扫描，确认来源可信后选择「仍然安装」即可继续。

### 电视盒子安装流程

与手机逻辑相同，入口不同：

1. 将 APK 文件拷贝到 U 盘，插入电视盒子的 USB 接口；
2. 用盒子自带的文件管理器（或第三方工具的「本地安装」功能）打开 APK；
3. 同样会遇到来源授权提示，用遥控器确认允许安装；
4. 装完后在应用列表中找到 javdb 启动，通过遥控器进行操作。

### 装完必做的版本核对

安装完成后，务必到 **设置 → 应用 → 应用信息** 页面核对版本号与包名。已知包名为 `com.aiyouxiba.wzzc`，确认无误后再正常使用。如果包名对不上，说明装的不是预期版本，建议卸载后重新获取。

## 📖 使用入门

### 界面初览

javdb 的界面结构很简单——底部三个标签页涵盖了全部核心功能：**首页/发现**（内容列表与分类浏览）、**搜索**（关键词检索）、**收藏/历史**（本地记录与离线缓存）。首次进入首页会自动加载推荐内容，网络不通时会白屏或加载失败。

### 闪退与白屏的五步排查法

使用过程中遇到应用打不开、闪退、白屏是常见问题，按以下顺序逐一排查，**走到哪步好了就停**，不要跳过：

| 步骤 | 操作 | 适用场景 |
| --- | --- | --- |
| ① 重启应用 | 上滑关掉进程重新打开 | 一次性进程卡死，大多数闪退到这就解决 |
| ② 清缓存 | 设置 → 应用 → javdb → 存储占用 → 只清缓存 | 缓存数据损坏导致的崩溃，清缓存不丢记录 |
| ③ 确认网络 | 首页内容需要联网，Wi-Fi 与移动数据互切试一次 | 网络异常导致白屏、加载失败 |
| ④ 检查存储与内存 | 清后台应用、删除不用的文件腾出空间 | 剩余空间不足或后台太多时，应用容易起不来 |
| ⑤ 卸载重装 | 以上都不行才走这步 | 终极手段，卸载会清掉本机观看记录和收藏 |

> [!WARNING]
> 卸载重装会清除**本机的观看记录、收藏和离线缓存**——javdb 没有账号云同步，卸载前如果追更到一半，建议先记一下进度。

### 安装失败的分型处理

如果在安装阶段就报错，根据具体文案对号入座：

| 报错文案 | 常见原因 | 处理办法 |
| --- | --- | --- |
| 解析包时出现问题 | 包不完整或与设备架构不匹配 | 删除残件后换网络重下，核对大小和 MD5 |
| 禁止安装来自此来源的应用 | 安卓标准安全拦截 | 为当前来源开启「允许安装未知应用」 |
| 应用未安装 | 空间不足或与旧版本冲突 | 清出几百 MB 空间；装过旧版先卸载 |
| Play Protect 拦截 | 侧载包的常规扫描 | 确认来源后选「仍然安装」 |
| 系统版本过低 | 安卓版本太旧 | javdb 要求 5.2 以上，过旧设备装不了 |
| 与已装应用冲突 | 同包名应用已存在且签名不同 | 先卸载已有的同名应用 |

> [!NOTE]
> 如果反复出现「解析包出问题」，重下载不是简单再点一次：先删掉本地 APK 和 `.part` 残件，换一个网络（Wi-Fi ↔ 流量）重下，下完核对文件大小和 MD5。两轮都校验不过，问题在分享端或传输链路，不是你的设备。

### 权限申请解读

安装和首次使用时，javdb 会申请以下权限，了解每项权限的用途有助于判断是否合理：

| 权限 | 用途 | 合理性 |
| --- | --- | --- |
| 完全的网络访问权限 | 在线播放、搜索、首页内容加载 | 必需 |
| 查看 / 连接 WLAN 状态 | 识别 Wi-Fi 环境，判断是否允许缓存 | 合理 |
| 读取 / 写入外部存储 | 离线缓存写入、下载管理、读取本地媒体 | 必需 |
| 挂载 / 反挂载外部文件系统 | 存储访问的旧式声明 | 常见于此类应用 |
| 允许请求安装文件包 | 应用内自更新 | 需留意（见下方） |

> [!TIP]
> 有两类信号需要特别留意：一是如果你的版本索要**通讯录、短信、通话记录、精确定位**等与功能无关的权限，属于异常信号；二是「允许请求安装文件包」意味着应用可能在内部推送新包——升级时建议回到下载页拿确认过的包，不要直接同意应用内推送的未知来源。

权限可以在 **设置 → 应用 → javdb → 权限管理** 页面逐项查看和关闭。关掉某项权限后，对应的功能会失效（比如关掉存储读写就无法离线缓存），这也能反推权限与功能的真实对应关系。

### 两类典型闪退场景

**新装就闪退**：先过安装核对——确认包名是 `com.aiyouxiba.wzzc`、大小接近 12.63MB、MD5 校验通过。校验无误还闪退，大概率是包与设备系统不兼容，记录标注要求安卓 5.2 以上，过旧的设备装不稳。

**系统刚升级后开始闪退**：安卓大版本更新后应用一时不适应是常见现象。先清缓存重进；如果持续闪退，回下载页看看有没有新版本覆盖安装——覆盖装不会丢记录。
