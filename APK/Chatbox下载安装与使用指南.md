## ✨ Chatbox 是什么

Chatbox 是一款本地优先的 AI 对话客户端——和网页端不同，它把聊天记录、配置、自定义搭档全存在你自己的设备上，不依赖任何云端账号，换模型也不用迁移数据。它的定位很明确：给那些同时接了好几个模型 API（OpenAI、Anthropic、国内各家）、又嫌各自的官网网页端体验割裂的用户，一个统一的工作台。

核心能力可以归为三层：最底层是多模型接入——不管是主流的大模型还是本地跑的开源模型，只要有 API Key 就能挂进来；中间层是日常对话——多轮上下文、文件夹上传、导出 Markdown，和网页端能用的基本都有；最上面一层是工作模式（Agent）——给 AI 一块本地目录，让它自己读写文件、跑命令、改代码，像坐在你旁边的同事。

适合谁？经常跟 AI 打交道的独立开发者、内容创作者、研究员——他们手上不止一个 API Key，又不想每次都开浏览器切换标签；还有在意数据隐私的用户，聊天内容不落服务器、自定义搭档和 Soul 人设只存在本地目录。

> [!NOTE]
> "本地优先"是这款产品的设计底线，不是一个卖点标签。意味着它**没有自动云同步**，也没有厂商侧备份——数据安全完全在你自己手里。后面备份章节会展开说。

Chatbox 本身不绑定任何模型，也不强制订阅。下载安装是免费的，各模型的 API 费用由你自己的供应商收取。

## 🔧 安装步骤

### 桌面端（Windows / macOS / Linux）

桌面端是主流使用场景，工作模式和工作目录等高级功能主要在这里发挥：

1. 到下载页选择对应平台的安装包——Windows 是 `.exe` 安装程序，macOS 是 `.dmg` 镜像，Linux 提供 AppImage 和 DEB/RPM 包
2. Windows 用户双击 `.exe`，建议选择自定义安装路径到非系统盘，避免后续权限问题；部分杀毒软件可能对 Electron 应用有拦截提示，属正常现象，添加信任即可
3. macOS 用户把 `.dmg` 里的 App 拖进「应用程序」文件夹；首次打开如果遇到 Gatekeeper 提示，到「系统设置 → 隐私与安全性」里点「仍要打开」
4. Linux 用户推荐 AppImage，无需安装，赋执行权限后直接运行；想用包管理器装的选 DEB 或 RPM

> [!TIP]
> 装完先核对版本号：应用内「设置 → 关于」里能看到完整版本号。不要从第三方网盘或论坛找"绿色版"——安装包完整性无法保证，且本地优先的设计意味着任何被篡改的客户端都可能读取你的 API Key。

### 移动端（Android / iOS）

移动端主打轻量对话和随身查看历史：

1. Android 用户注意：部分版本不在 Google Play 上架，需允许"未知来源"安装（系统设置里授予当前浏览器的安装权限）
2. iOS 用户直接 App Store 搜索即可，无需额外配置
3. 移动端同样支持多模型切换和搭档系统，但工作模式、工作目录等需要文件系统访问的功能暂不完整

## 📖 使用入门

### 多模型配置

首次打开应用，第一件事是接入你的模型。左侧栏「设置 → 模型管理」里可以添加多个供应商，每个供应商下挂一个或多个 API Key。添加完之后，对话界面顶部会出现模型切换下拉框，随时切换不用重新开对话。

> [!WARNING]
> API Key 只存在本地配置文件里，不会上传到任何服务器。但这也意味着设备丢失或被盗时 Key 有泄漏风险——不要把装有配置文件的电脑随意借人。

### 我的搭档：预置 AI 助手库

「我的搭档」是一批调好系统提示的 AI 助手。每个搭档本质是一份专业人设（角色定位 + 输出格式 + 行事规矩），点一下就能用，省去自己写提示词的功夫。

入口在左侧栏，助手按场景分类：写作、办公、学习、编程、翻译、生活等。常用的有会议纪要生成器、周报助手、翻译润色、正则表达式生成器、代码审查、简历优化等——官方库里覆盖挺广，具体清单以应用内实际展示为准。

启用一个搭档很简单：点开需要的助手 → 查看它的提示词内容 → 点「使用这个搭档」→ 自动进入对话界面直接输入任务。想微调人设？对话输入框上方点搭档名称就能编辑它的提示词，改完这场对话按新设定走。

搭档和普通对话的区别本质在输出可控：

| 对比 | 普通对话 | 搭档对话 |
|---|---|---|
| 系统提示 | 空白或自己填 | 预置专业人设 |
| 上手成本 | 要自己描述要求 | 直接派活 |
| 输出格式 | 看模型发挥 | 通常有固定结构 |

搭档的价值就是把提示词工程的成果固化成了模板——你不必每次都重新描述要求和期望的输出格式，直接用就行。

### Soul：给智能体定性格

Soul 是工作模式里 AI 的一份全局人格说明——性格、语气、行事原则和底线。它回答的问题是：这个动手干活的 Agent，应该以什么姿态为你工作。

Soul 和搭档提示词的作用域完全不同：搭档管"这件事怎么做"（任务流程和输出格式），Soul 管"这个人是什么样"（性格、原则、边界）。两者不冲突——工作模式里也可以挂搭档与知识库，Soul 则是更底层的行为准则。

编辑位置在「设置 → 智能体（Agent）→ Soul」，提供编辑器与模板。一个实用的 Soul 不用长，四个要素就够：性格与语气、原则、边界、交付要求。

> [!NOTE]
> Soul 修改后，**正在运行的工作模式会话继续用开始时的那份**，只有新会话才加载新 Soul。这是故意的设计——中途换性格不会把跑了一半的任务带跑偏。想立刻用新人设，开个新工作模式对话即可。

调校 Soul 的建议是从痛点写起：被 AI 哪种行为烦到过（废话多、自作主张、谎报进度），就写哪条。边界要具体——"先问我"比"小心行事"可执行得多，写明哪些动作必须先请示。别写任务细节，具体任务的规矩放搭档提示词或当轮指令里，Soul 保持稳定。

### 工作目录：授权 AI 直接读写本地文件夹

工作目录是一项关键能力——它把授权范围从单次文件上传升级为整块文件夹。指定一个本地目录后，AI 在这个目录里读写文件不用逐次审批，像一位坐在你旁边、能直接碰你项目的同事。

没有工作目录时，AI 每次读写都要你上传或批准单个文件，多步骤任务会变成"点同意"马拉松。设定工作目录后，AI 可以浏览目录结构、按需读取文件，改代码改文档直接落盘，配合代码执行还能"找到问题 → 修改 → 运行验证"一条龙。

设定方法：悬停输入框上的机器人图标打开控制面板 → 在扩展区找到「工作目录」→ 选择一个本地文件夹授权。新版本里输入框上方会显示当前工作目录标签，点一下即可更换。

> [!WARNING]
> 授权范围怎么定很重要。建议**按项目给**——一次只授权当前在做的项目目录，别授权整个用户目录或磁盘根。证件扫描件、账本、隐私文档不要放进工作目录。工作目录内的操作免逐次审批，等于自动放行这一片区域，所以它天然应该与"批准"级别（而不是完全访问）搭配，多一层文件修改确认。用完收权：项目结束换任务时，记得换掉或清空工作目录。

平台支持方面，桌面端可用，但 Windows 对部分工作目录能力暂不完整，具体以当前版本说明为准；Linux、macOS 支持更完整。

### 备份与恢复

数据只存本地，意味着**备份是你自己的责任**——应用方没有服务器副本可帮你找回。聊天记录、自定义搭档、API 配置全在本地目录，卸载应用、设备重置、应用数据被系统清理都会让数据清零。

桌面端与移动端的备份路径一致：「设置 → 数据管理 → 导出数据」，选择保存位置后导出为 JSON 文件，转移到安全位置（网盘、移动硬盘）。恢复时在新设备（或重装后）选「导入数据」，导入之前的 JSON 即可。

客户端目前没有自动云同步，各设备数据独立。想把 A 设备的数据带到 B 设备，流程就是 A 导出 → 传文件 → B 导入。注意：导入是合并还是覆盖取决于版本实现，**先在 B 设备上也导出一份当前数据**再导入，任何情况下都有退路。

建议的备份节奏：重要对话随时导，全量备份按月一次。每季度演练一次"导出 → 导入"闭环，确认备份真的可用——备份文件本身含全部聊天内容与配置，存放位置的访问权限也要管好。
