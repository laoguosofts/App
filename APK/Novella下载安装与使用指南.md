## ✨ Novella 是什么

Novella 是一款专为轻小说和网络小说爱好者打造的开源 Android 阅读器。它的核心理念很简单：给读者一个干净、舒适、功能完整的阅读工具，不做内容聚合、不内置书城，专注在「阅读体验」本身。

在阅读体验上，Novella 提供了六种翻页模式，从模拟纸书的左右滑动到连续卷轴式的上下滚动，再到音量键翻页和自动逐行滚动，几乎覆盖了所有主流的阅读习惯。文本渲染方面支持自定义字体、字号、行间距、段落间距等细节参数，暗光环境下的深色模式和护眼模式也一应俱全。

更受欢迎的是它的翻译能力。Novella 内置了谷歌翻译和 Gemini 翻译两个引擎，让你可以直接阅读外文原著（比如日文轻小说、英文网络小说），边读边译，不用等中文翻译版滞后几个月甚至永远等不到。翻译界面支持原文译文并排对比、逐段手动翻译、切换隐藏等灵活操作。

账号体系上，Novella 走 GitHub OAuth 授权——登录后可以通过 GitHub Gist 同步书架数据、阅读进度和配置设置，换设备或重装应用都能快速恢复。这种设计省去了自建用户数据库的麻烦，也让整个账号体系更加透明可控。

总体来说，Novella 适合两类用户：一类是有大量本地轻小说/网文资源的读者，想要一个功能完整的阅读器来管理和阅读；另一类是想直接啃外文原著的读者，依赖它的翻译功能实时获取中文内容。开源、无广告、不追踪，是它在同类阅读器中最核心的竞争力。

> [!TIP] 开源阅读器选型建议
> 如果你还在纠结用哪个开源阅读器，不妨这样判断：需要翻译功能选 Novella，主打本地文本管理选其他成熟项目。Novella 的翻译接入做得最深入，这是它最突出的差异化优势。

## 🔧 安装步骤

Novella 是 Android 平台的 APK 应用，安装过程和大多数第三方应用类似，但有几个细节值得注意。

### 第一步：允许未知来源安装

Android 系统默认禁止安装来自应用商店以外的 APK 文件。在安装 Novella 之前，你需要先开启「未知来源」授权：

1. 打开手机 **设置 → 安全（或隐私保护）→ 安装未知应用**
2. 找到你用来下载 APK 的应用（比如浏览器或文件管理器）
3. 将「允许安装未知应用」开关打开

> [!WARNING] 安全提醒
> 只对你信任的下载来源开启此权限。Novella 官方渠道包括它的下载页、GitHub Releases 页和 Google Play，第三方镜像站请自行甄别。

### 第二步：下载并核对 APK

从下载页获取最新版 APK 后，建议核对一下文件版本号和文件大小是否与页面标注一致。Novella 的安装包体积通常在 20~30MB 区间，如果下载到的文件明显偏小或偏大，大概率是下载不完整或被篡改，应该重新下载。

### 第三步：安装与首次启动

点击下载好的 APK 文件，系统会弹出安装界面。安装完成后首次打开应用，Novella 会请求存储权限（用于扫描本地小说文件）和可选的联网权限（用于翻译功能和云同步）。权限授予完毕后即可进入主界面，开始导入本地书架或配置翻译引擎。

### 版本更新

Novella 不会自动检查更新，需要你手动到下载页或 GitHub Releases 页查看是否有新版本。更新时直接安装新版 APK 覆盖旧版即可，已导入的书架数据和配置设置会自动保留，不需要提前备份。

## 📖 使用入门

Novella 的功能围绕「导入—阅读—同步」三条主线展开，下面结合实际使用场景逐一说明。

### 导入本地小说

首次启动后进入书架，点击右上角的「添加」按钮，可以选择从本地文件夹扫描 txt/epub/pdf 等常见格式文件。扫描到的书籍会自动出现在书架卡片上，长按卡片可以进行删除、移动、重命名等管理操作。

### 翻页模式选择

进入具体一本书的阅读界面后，呼出工具栏找到「翻页模式」设置，Novella 提供六种模式：

**左右滑动翻页**是最经典的纸书仿真模式，每滑一下翻一页，带翻页动画。适合喜欢「读完一页翻一页」明确感的读者。

**上下滚动**像网页一样连续往下滚，没有页码概念，内容无缝衔接——这也是最推荐的网文连载阅读方式，和大多数人在网页上追更的习惯一致。

**点击区域翻页**把屏幕分成三个区域：左半区上一页、右半区下一页、中间呼出工具栏。不喜欢滑动手势的读者可以考虑。

**音量键翻页**让音量加键 = 上一页、音量减键 = 下一页，躺着阅读不想抬手滑屏幕时特别实用。

**自动翻页**开启后屏幕内容自动缓慢往下滚动，可以在任意位置暂停，速度在每秒 0.5 行到每秒 5 行之间可调，默认 1.5 行/秒适合大多数人。章节切换处会自动暂停几秒等新内容加载好。

值得一提的是，Novella 允许同时启用多种翻页方式——比如默认用上下滚动，但同时开启音量键翻页作为备用，随时可以在不同场景下灵活切换。

### 翻译功能配置与使用

翻译是 Novella 最有特色的功能点。设置里可以选择谷歌翻译或 Gemini 翻译作为默认引擎，也可以让应用根据章节语言自动选择。

两个引擎各有侧重：

| 维度 | 谷歌翻译 | Gemini 翻译 |
| --- | --- | --- |
| 长文本理解 | 逐句翻译，上下文易断 | 能识别前后文指代关系 |
| 专有名词一致性 | 可能前后翻译不一致 | 长篇连载中更稳定 |
| 文风处理 | 中等偏上，口语化表达容易失真 | 轻小说语气、双关语处理更好 |
| 是否需要 API Key | 免费接口无 Key 也能用 | 必须配置 Google AI Studio Key |
| 费用 | 免费接口有小时级限速（约 2000 次/小时） | 免费层每分钟 60 次、每天 60 次；超出按 Token 计费 |

**谷歌翻译**的配置最简单：网络能直连谷歌服务的话，设置里直接选「谷歌翻译」保存就能用免费接口。如果直连有问题，可以在手机系统层面开启代理让 Novella 自动走同一通道，或者申请 Google Cloud 项目的 Cloud Translation API Key 填入（每月 50 万字符免费）。

**Gemini 翻译**需要额外申请 Google AI Studio API Key：打开 Google AI Studio 网站，用 Google 账号登录后进入 API Key 管理页，创建一个新 Key 复制下来，回到 Novella 设置里粘贴即可。Gemini 在长篇连载场景下优势最明显——它能记住之前翻译过的人名、地名，保持全文专有名词一致。

翻译界面的交互也很灵活：每段外文内容下方会自动出现对应译文，可以切换对比模式（原文译文并排）、纯译文模式或纯原文模式；不想自动全译时，长按某段文字可以手动触发单段翻译。

> [!NOTE] 翻译不缓存
> Novella 的翻译结果每次打开都实时向引擎请求，不会本地缓存。好处是翻译质量随引擎升级自动变好，代价是需要联网且消耗 API 配额。不过看一本书大概只需要几百次调用，免费接口完全够用。

### GitHub 账号登录与云同步

Novella 选择 GitHub 作为唯一的云同步通道，登录走标准 OAuth 2.0 授权码模式，应用不会拿到你的 GitHub 密码。

登录步骤：进入 **设置 → 账号**，点击「登录 GitHub」，应用会调用系统浏览器跳转到 GitHub 授权页面，确认授权范围后点击「授权」，浏览器自动跳回 Novella，设置页会显示你的 GitHub 用户名。

Novella 请求的 GitHub 权限只有两项：**user:read**（读取公开资料，仅用于显示身份）和 **gist**（读写 Gist 代码片段，这是云同步的核心——Novella 把同步数据序列化后写入私有 Gist）。不会请求仓库读写、组织管理等敏感权限。

> [!WARNING] 授权可以随时撤回
> 如果你以后不想用云同步了，打开 GitHub 设置 → Applications → Authorized OAuth Apps，找到 Novella 对应的条目点击「撤销」即可。撤销后 Novella 立即失去 Gist 访问权，但本地书架数据不受影响。

### 一些实用小技巧

- **同时启用多种翻页方式**：默认上下滚动 + 音量键备用 + 自动翻页随时开，各方式之间不冲突。
- **翻译引擎即时切换**：设置里选的是默认引擎，但在具体阅读某章时可以呼出工具栏 → 翻译面板，直接点选另一个引擎重新翻译整章。
- **自动翻页速度调优**：默认 1.5 行/秒，觉得快或慢可以在阅读设置里微调。也可以切换到「每行停留时间」模式让光标在一行上停几秒再往下移。
