## ✨ DuckStation：一款开箱即用的 PlayStation 1 模拟器

DuckStation 是索尼 PlayStation 1 主机的模拟器，由开发者 stenzek 主导开发。它的定位可以用三个词概括：可玩性、速度、长期可维护性——目标是尽可能精确还原，同时保证低配置设备也能流畅运行。

与依赖插件体系的老一辈模拟器不同，DuckStation 不需要任何插件。装完导入 BIOS 和游戏镜像就能玩，把过去散落在第三方插件里的画面放大、几何修正、贴图过滤等增强能力，全部收进了统一的设置面板，这也是它能在一部手机上"开箱即用"的关键。

桌面版内置 Qt 主界面和 Big Picture 全屏界面两套界面，后者基于 Dear ImGui 专为电视和手柄操作设计；安卓版则是为触屏优化的单页应用，主屏是游戏列表，滑动抽屉进入设置，游戏内通过返回手势呼出暂停菜单。

项目遵循 CC BY-NC-ND 4.0 许可协议，可以原样转发但不能修改后再分发，也不能商用。BIOS 镜像因法律原因不随软件附带，需要从自己的主机上转储；游戏镜像同理，应来自合法持有的光盘。

## 🔧 安装前的准备与流程

安装 DuckStation 之前，有两个文件是必须提前准备好的：BIOS 镜像和游戏镜像。BIOS 镜像因法律原因不随软件附带，需要从自己的 PlayStation 1 主机上转储；游戏镜像则应来自你合法持有的光盘。没有这两样，装完模拟器也无法运行任何游戏。

### 平台安装差异

| 平台 | 安装方式 | 注意事项 |
|------|----------|----------|
| Windows | 运行安装包，选择路径 | 杀毒软件可能误报模拟器行为，添加信任即可 |
| macOS | DMG 镜像拖入应用程序 | 首次打开需在系统偏好设置中允许未知来源 |
| Android | APK 安装或 Google Play | 开启「允许未知来源」或「安装未知应用」权限 |

### 安装后的首次配置

1. **导入 BIOS**：启动模拟器后，在设置中找到 BIOS 路径，指向你转储的 BIOS 镜像文件。
2. **添加游戏目录**：在游戏列表中添加存放镜像文件的文件夹，支持 ISO、BIN/CUE、CHD 等常见格式。
3. **核对版本号**：安装完成后建议确认一下当前版本，确保是较新的稳定版，旧版本可能缺少某些兼容性修复。

> [!TIP] 杀毒软件误报是模拟器圈的常见问题，这并不代表软件本身有问题。建议将模拟器安装目录加入杀毒软件的信任列表。

## 📖 画面增强、超频与存档进阶玩法

DuckStation 默认配置就能运行绝大多数可玩的游戏，各种增强选项默认关闭，需要时手动打开。它把画面增强、性能调优、存档管理、成就追踪等能力全部内置，不需要借助任何外部工具或插件。

### 画面增强：让老游戏焕发新生

PS1 原生分辨率只有 320×240，在现代显示器上满是像素块。DuckStation 提供了一套完整的画面增强方案：

- **内部分辨率缩放**：最高可以拉到 8 倍或更高，画面精度直接翻倍。
- **几何修正（Widescreen Hack）**：强制把 4:3 画面拉伸到 16:9，适合现代宽屏显示器，部分游戏可能出现画面变形。
- **贴图过滤与锐化**：平滑放大后的像素块，或使用锐化滤镜保留像素感。
- **各向异性过滤**：改善斜向纹理的清晰度，降低画面发糊的问题。

> [!NOTE] 画面增强选项对硬件性能有要求，安卓中低端设备建议把内部分辨率控制在 2~3 倍以内，否则会掉帧。

### CPU 超频：读盘更快、帧率更稳

PS1 的 CPU 标称 33.8688MHz，部分游戏没跑满这个预算，反而出现了"主机性能不够、游戏本身就慢"的场景。DuckStation 允许在 System / Console 设置里找到 **Clock Speed Control**，以百分比调节模拟 CPU 的时钟频率，默认 100%。

超频能解决几个典型痛点：

- **帧率不稳**：部分游戏的掉帧源于 CPU 瓶颈，超频后帧时间显著改善。
- **读盘加载慢**：配合快速读盘选项，存读档等待明显缩短。第三方教程里甚至有把超频拉到 1000% 专门秒过加载的玩法。
- **帧率解锁补丁前置**：一些 60 帧补丁要求更大的 CPU 预算，超频后才能正常运行。

但超频也有边界。游戏内部计时逻辑可能受影响，个别游戏超频后会出现物理、计时的微妙异常，需要逐游戏验证。而且超频只影响模拟的 CPU，与模拟器自身性能无关——模拟器本身卡顿请检查画面增强选项或硬件负载，超频只会加重负担。对于 8MB 内存（Dev Console 选项）这类"主机改装"项，也建议默认值最稳，只在特定游戏需要时调整。

### 存储卡编辑器：存档的可视化管理

存储卡编辑器把虚拟存储卡当成可视文件来管理：每张卡里的存档块逐条列出，带游戏图标、名称、占用块数与大小。它支持三种核心操作：

- **查看**：确认哪款游戏的档占了哪几块，避免误删。
- **复制 / 移动 / 删除**：跨存储卡搬运存档，清理损坏块，相当于当年的"卡对卡拷贝"。
- **导入**：直接读取多种格式的外部存档文件，包括 gme、mcr、mc、mcd 等社区通行格式。从别的模拟器或老存档合集迁移进度，靠的就是这项。

常见的使用场景包括：从旧模拟器搬家、卡空间告急时分卡存放、存档保险复制一份到备用卡再动主线防覆盖。桌面版从 Tools 菜单进入，安卓版在 App Settings - Memory Cards 页里，游戏内暂停菜单也有入口。

> [!WARNING] 对存档做删除或覆盖操作不可撤销，动手前先把整张卡文件复制备份。

### RetroAchievements 成就系统

RetroAchievements 是复古游戏圈的成就平台，社区为几千款老游戏手工制作了成就集。DuckStation 原生集成了这套系统，安卓与桌面端都能用。接入流程很简单：

1. 先在 RetroAchievements 平台注册一个账号（第三方平台，与模拟器账号体系无关）。
2. 在模拟器的 Achievements 设置页填入用户名与密码登录。
3. 打开 Enable Achievements 总开关，启动支持的游戏即可。

成就玩法有个核心概念叫 **硬核模式（Hardcore Mode）**：开启后即时存档、倒带、金手指、补丁全部禁用，只能像当年一样用游戏内存档通关。硬核模式解锁的成就积分计入排行榜，普通模式解锁的积分减半。如果只是想休闲游玩，直接关掉硬核模式或整局不开成就即可。离线期间成就进度暂存，恢复联网后会自动同步。
