## ✨ Ampere 是什么 —— 你的电池电量显微镜

Ampere 是一款专为 Android 设备打造的电池监测工具，它能实时显示手机电池的充放电电流（单位 mA）、电压、温度、电量百分比等关键参数。和系统自带的电池统计不同，Ampere 直接从手机内置的电池管理系统（BMS）读取原始传感器数据，让你看到充电时电流到底有多大、放电时耗电到底有多快。

这类工具的核心价值不在于"看个数字"，而在于**对比和诊断**：同一台手机、同一电量下换不同充电器，用 Ampere 一看就知道谁在"虚标"功率；换不同数据线，能立刻发现哪根线在默默衰减；甚至屏幕亮度、后台负载这些变量对功耗的影响，都能通过电流读数量化出来。

> [!TIP]
> Ampere 本身没有硬件电路，它是纯软件工具——数据全部来自手机自带的 BMS 传感器。所以读数精度取决于手机厂商固件，不同机型之间可能存在差异。但在"同一台手机、固定条件"下做横向对比，它的参考价值非常高。

适合哪些人用？如果你在意充电效率、喜欢折腾数码配件、或者想搞清楚手机为什么"突然变费电"，Ampere 是一款值得装起来的小工具。它不占资源、广告不多，免费版覆盖了绝大多数日常使用场景。

## 🔧 安装步骤 —— Android 平台完整指南

Ampere 是 Android 独占应用，不支持 iOS 和桌面系统。安装过程和普通 APK 应用一致，但有几个细节值得注意。

### 安装前的准备

1. **确认设备兼容性**：Ampere 需要 Android 6.0（Marshmallow）及以上版本。如果你的手机系统版本太旧，部分电池 API 可能不开放，读数会受限。
2. **开启未知来源安装**：从官方渠道下载 APK 后，需要在系统设置中允许浏览器或文件管理器安装未知来源应用。不同品牌手机的入口略有差异：
   - 原生 Android：设置 → 安全 → 安装未知应用 → 选择你的下载工具
   - 小米 MIUI：设置 → 隐私保护 → 特殊权限设置 → 安装未知应用
   - 华为 HarmonyOS：设置 → 安全 → 更多安全设置 → 未知来源应用下载

### 安装过程

1. 打开下载好的 APK 文件，系统会弹出安装确认窗口
2. 点击「安装」，等待进度条走完（通常 5-10 秒）
3. 安装完成后点击「打开」首次启动

### 首次启动与权限

首次打开 Ampere 时，系统会请求以下权限：

| 权限 | 是否必须 | 作用 |
|---|---|---|
| 电池使用情况 | ✅ 必须 | 读取 BMS 电流传感器数据的前提 |
| 通知访问 | 可选 | Pro 版用于通知栏显示电池状态 |
| 忽略电池优化 | 可选 | 防止系统在后台杀掉 App 进程 |

> [!WARNING]
> 如果拒绝了「电池使用情况」权限，Ampere 将无法获取任何电流数据，界面会一直显示零值。遇到这种情况请在系统设置 → 应用 → Ampere → 权限管理中手动开启。

### 安装后的核对

装好之后建议做一个简单的验证：插上充电器，打开 Ampere，等待 10 秒左右的"正在检测"采样过程，主界面应该能看到一个非零的电流读数（充电状态下通常是绿色或蓝色）。如果读数一直是 0 或显示"不支持"，说明你的手机固件没有开放电池 API，Ampere 在这台设备上无法正常工作。

## 📖 使用入门 —— 从读懂读数到对比测试

Ampere 的功能不算复杂，但要真正用好、读懂读数背后的含义，需要对几个核心机制有基本了解。

### 主界面读数怎么看

打开 App 后第一眼就是 mA 电流读数，配合颜色编码快速判断电池状态：

| 颜色 | 含义 |
|---|---|
| 🟠 橙色系 | 放电中（手机正在消耗电量） |
| 🟢 绿色系 | 充电中（电流流入电池） |
| 🔵 蓝色系 | 已充满（充电器还在连着但电流很小） |
| 🔴 红色系 | 电压异常（可能是充电器故障或电池老化） |

这个"四色四状态"的识别逻辑是 Ampere 的固定行为，无论你切换哪套主题都不会变。

> [!NOTE]
> App 刚启动时会显示约 10 秒的"正在检测"状态——这不是传感器在预热，而是 Ampere 在做采样统计：连续读取 50 次电流值，去掉最高的 10 个和最低的 10 个，用剩下的中间值取平均。这个设计是为了过滤掉插拔充电器瞬间的电流尖峰。

### 主题切换 —— 找到最适合你的数据视图

Ampere 内置了多套主题，每套主题有不同的配色和信息布局，但颜色编码规则保持一致。切换主题有两种方式：

- **快速滑动**：在主界面上左右滑动，每滑一次切换一套
- **精确选择**：进入设置页面，在主题配置项中挑选

滑到满意的主题后，点界面右下角出现的 ⭐ 图标可以把它固定为默认，下次打开直接进入。主题是免费功能，Pro 版不在这里做区分。

三套常用主题各有侧重：
- **横版大字主题**：电流值铺满屏幕中央，最适合对比测试时盯紧 mA 读数
- **列表主题**：电量、温度、电压、型号等多项参数同时列出，适合日常浏览核对
- **图标主题**：每项参数配图标，视觉上更丰富

### 充电三阶段 —— 为什么电流会"越充越小"

这是 Ampere 新手最容易困惑的问题之一：明明用的是 65W 快充头，30% 电量时电流 3000 mA，到了 60% 怎么只剩 1500 mA？是不是充电器坏了？

不是充电器的问题，是锂电池在主动保护自己。LiPo 电池充电分三个阶段：

**阶段一：预充（0-10%）** — 电池极低电量时内部电压不稳定，充电管理芯片用小电流（通常 < 500 mA）预充，等电压回升到安全区间再加大电流。这个阶段 Ampere 读数会偏低，不要据此判断充电器能力。

**阶段二：恒流（10-70%）** ⭐ — 充电电流最大、最稳定的阶段。充电器维持固定大电流给电池充电，电流大小由充电器能力、手机快充协议、线材三者共同决定。**对比测试应该在这个阶段做**——电流不会因为电量变化而大幅下降。

**阶段三：恒压（70-100%）** — 接近满电时电池内部电压已接近标称上限（LiPo 通常 4.2V），继续大电流会过充损坏。充电芯片逐步降低电流、维持电压不变，直到电流降到非常小的截止值（通常 < 50 mA）才算充满。

一个典型的电流衰减曲线：

```
10% 电量 → 2800 mA（恒流阶段，峰值）
30% 电量 → 2800 mA（恒流阶段，稳定）
50% 电量 → 2600 mA（接近恒压起点，略降）
70% 电量 → 1800 mA（恒压阶段，明显下降）
85% 电量 → 800 mA（恒压阶段，快速下降）
95% 电量 → 200 mA（接近满电，涓流充电）
```

所以如果你在 80% 电量对比两个充电器，两个读数都会很低且接近——不是充电器没差距，是电池已经进入恒压阶段，充电器功率再大也给不上去了。**固定在 20-60% 电量区间做对比**才是靠谱的做法。

### 屏幕亮度 —— 最被低估的功耗变量

屏幕是手机最大的耗电组件，亮度直接决定了整机功耗：

| 亮度档位 | 屏幕功耗占比 | 对充电电流的影响 |
|---|---|---|
| 最低亮度（夜间） | 15-25% | 充电电流几乎不受屏幕影响 |
| 中亮度（室内） | 35-50% | 屏幕吃掉约 300-500 mA |
| 最高亮度（阳光） | 60-75% | 屏幕可能吃掉 800-1200 mA |

这意味着充电器输出能力没变（比如 3000 mA），但屏幕功耗吃掉了不同份额，电池实际充电电流此消彼长。亮屏 + 刷视频的情况下，电池实际充电电流可能只剩 1000 mA 左右——不是充电器不行，是屏幕太能吃。

> [!TIP]
> 做对比测试时，要么**关掉屏幕**（黑屏状态下手机功耗最低），要么手动固定一个明确的亮度档位。绝对不要在测 A 充电器时自动亮度调到 80%、测 B 时调到 20%——读数差异主要来自屏幕，和充电器关系不大。

日常充电也建议注意：快充时尽量别玩游戏或看视频，夜间充电开屏幕保持关闭或用黑色壁纸，这些小习惯能显著缩短充电时间。

### 读数不准怎么办 —— 理解它的局限性

Ampere 自己也承认：**不要把读数当作绝对科学数据**。因为 Android 电池 API 的设计初衷是估算电量百分比，不是做精确电流测量。读数精度受几个因素影响：

- **手机厂商固件**：部分三星等厂商的固件直接返回额定最大值，不是实际测量值
- **Android 版本**：早期版本 API 不完善，不同厂商实现差异大
- **省电模式**：某些省电策略下 BMS 传感器会降频甚至关闭
- **充电方式**：无线充电、部分快充协议的电流路径和有线不同，传感器可能捕捉不准

但这些局限**只影响绝对值，不影响相对值**。在"同一台手机、固定条件、对比不同"这个场景里——换充电器、换数据线、换亮度——Ampere 的参考价值依然很高。

### Pro 版值不值得买

Ampere 免费版已经覆盖了实时读数、主题切换、基础统计等核心功能。Pro 版解锁的是桌面小组件、通知栏常驻、电池警报、详细历史日志等进阶功能。如果你只是偶尔看看充电电流、做一做充电器对比测试，免费版完全够用；如果你想长期监测电池健康、需要在通知栏实时看状态，可以考虑升级。
