## ✨ Girigiri 是什么：一款专注追番体验的移动应用

Girigiri 是一款面向番剧爱好者的移动应用，核心定位是帮助用户高效追踪、浏览和管理自己的追番列表。它提供了时间表视图让用户一眼看清一周内每天有哪些番更新、今日更了什么，配合分类标签和排行榜，无论是日常追更还是发现新番都很顺手。

对于追番党来说，Girigiri 解决了几个常见痛点：每天打开就能看到当天更新的番剧、缓存文件集中管理不怕占空间、观看历史登录后云端同步换设备也不丢记录。应用本身免费提供基础功能，离线缓存、多设备同步等体验上的加分项让它在同类产品中口碑不错。

从参考资料来看，Girigiri 的设计思路很务实——不搞花里胡哨的界面，把追番这件事需要的核心功能做扎实：时间表、分类浏览、缓存管理、云端同步，每一块都瞄准日常使用场景。

## 🔧 安装步骤：Android 设备安装与注意事项

Girigiri 主要面向移动端，以下以 Android 为例说明安装流程。如果你的设备是通过官方下载页获取的 APK 安装包，需要注意「未知来源授权」这个常见关卡。

### 安装流程

1. **获取安装包**：从上方下载入口下载最新版 APK，记下文件大小（通常几十 MB 到一百多 MB）；
2. **允许未知来源安装**：Android 系统默认禁止安装应用商店以外来源的 APK。进入「设置 → 安全 → 安装未知应用」，找到你用文件管理器打开 APK 的那个应用（比如系统自带的文件管理器或浏览器），授权它「允许安装未知应用」；

> [!WARNING]
> 某些手机厂商（小米、华为、OPPO 等）对未知来源安装有额外的安全提示弹窗——这是系统正常防护机制，选「仍要安装」即可继续，不是 APK 有问题。

3. **打开 APK 文件**：用文件管理器找到下载好的 APK，点击打开安装；
4. **等待安装完成**：首次安装可能需要几秒钟，看到「应用已安装」提示后，桌面图标就会出现。

### 安装后核对

打开应用，检查以下几点确认安装正常：

- 首页能正常加载出番剧列表，不是空白；
- 时间表 tab 能切换，能看到一周的排片；
- 如果弹出更新提示，建议更到最新版再使用。

## 📖 使用入门：追番、缓存与多设备同步全流程

Girigiri 的功能模块围绕「追番」这个核心需求展开。参考使用经验，以下几个高频场景值得熟悉。

### 每日追更：时间表 tab 自动定位当天

打开应用时如果直接跳到时间表 tab，页面会根据当前日期自动高亮「今天是周几」那一列，当天更新的番剧卡片直接出现在顶部区域。比如今天是周四，进去首先看到的就是周四的更新列表，往下才是周五、周六、周日的排片。

日常用法很简单：每天打开时间表，扫一眼当天的卡片，有想追的番直接点进去播放。如果时间表里当天那一列是空的，说明今天没有番剧更新，不是应用坏了，可以去首页逛分类标签或补看之前收藏的番。

### 发现新番：分类标签 + 排行榜双入口

首页顶栏有一排分类标签：首页、日番、美番、剧场版、真人番剧、国漫。点哪个就切到哪个分类下的番剧列表。分类标签适合两种场景：榜单和搜索都没覆盖到的小众需求（比如想看真人番剧但不知道有哪些），以及题材方向明确但不知道具体番名（想补国漫但不想在日番堆里翻）。

分类标签和排行榜是互补关系——排行榜告诉你「现在大家都在追什么」，分类标签告诉你「这个题材下有哪些番」。两个入口都刷一遍，基本不会漏掉想追的。

### 离线缓存：看完就删，别让缓存吃存储

缓存的番剧会永久占用手机存储，如果数字已经上 GB 了说明缓存了不少内容。查看和清理的路径：

- **查看缓存占用**：应用内「我的 → 离线缓存」可以看到每部番占用的具体大小；手机系统设置「存储 → 应用数据」也能看到 girigiri 的总占用；
- **清理方法**：看完的番别留着占空间，长按或点管理模式一次性勾选多个一起删。删掉的只是离线副本——番剧还在片库里，想再看的时候在线播放或重新缓存都行；

> [!TIP]
> 缓存文件存在应用内部目录，普通文件管理器看不到（或者需要 root 权限）。**不要手动去文件管理器删 girigiri 的目录**——容易删到应用运行必需的文件导致应用损坏。从应用内的离线缓存区删最安全。

如果手机长期提示存储不足，可以考虑把缓存统一用标清档，或者把老照片视频传云盘后删本地，卸载不常用的老应用腾空间。

### 多设备续看：登录账号开启云端同步

观看历史有两个状态：游客状态下观看历史只存在本地，清缓存、卸载应用、换手机全没了；登录后每看完一集，当前观看位置自动同步到云端——换手机登录同一个账号，直接续上。

查看观看历史的路径是底部导航「我的 → 观看历史」，里面列着最近看过的番剧，每条目显示看到的那一集，点进去直接回到上次的播放位置。

常见的多设备续看场景：手机看了一半想在平板上接着看（平板登同一个账号）、换了新手机（旧账号登过去追番记录和观看历史都在）、给朋友试看（用完记得退出登录保护隐私）。

> [!NOTE]
> 追番记录和观看历史是两个独立的列表——追番记录是你标记要追的番（不管有没有看），观看历史是你实际看过的番（看到第几集），各自独立管理不要混淆。

如果想清空观看历史，走「我的 → 观看历史 → 管理 → 全选 → 删除」路径，删了云端也同步清空且不可恢复，操作前确认一下。
