## ✨ Toolkit 工具箱是什么

Toolkit 是一款面向安卓玩机用户的全能工具箱应用，把刷机资源、系统体验、Minecraft 资源和日常小工具集中到一个界面里。从主界面看，一半是信息栏（版本动态、社区入口），一半是功能板块——结构清晰，v1.0.6 Beta 到 v1.0.9 Beta 期间布局保持稳定。

四个功能板块的定位分得比较清楚：刷机资源面向想刷 ROM、装模块的玩家，DSU Sideloader 给想试 GSI 但不想真刷机的用户，Minecraft 专区服务方块玩家，实用功能则覆盖所有人——翻译、Ping、二维码等日常小工具随手可用。对玩机用户来说，这四个板块其实是一条路线：先找素材，不确定效果就低风险试系统，Minecraft 是兴趣延伸，小工具则是随时补位。

Toolkit 是个人开发者维护的应用，没有会员墙，功能以免费形式开放。但接口与模型随时可能调整，版本迭代快，遇到功能变化属于正常现象，以最新版为准。

## 🔧 安装步骤

Toolkit 是安卓平台的应用，安装过程与常规 APK 一致。下面是完整的操作流程和注意点，照着走基本不会出问题。

1. **允许未知来源安装**：进入手机「设置 → 安全 → 安装未知应用」，找到你使用的文件管理器或浏览器，打开「允许安装应用」开关。这一步每个厂商的叫法略有不同，有的在「隐私保护」或「应用权限」分类下，找不到的话直接在设置里搜「未知来源」。
2. **下载 APK 文件**：从上面的下载入口拿到安装包，核对一下文件大小和版本号——Toolkit 不同版本的体积会有差异，但如果你拿到的文件明显偏小或名称对不上，建议换源重下。
3. **执行安装**：用文件管理器找到 APK，点击后系统会弹出安装界面，一路「下一步」即可。部分机型在安装时可能弹出「杀毒提示」，属于安全软件的正常提醒，确认来源可信就选「继续安装」。
4. **首次启动**：安装完成后点「打开」进入应用，会看到主页顶部的公告栏和下方四大功能板块入口。

> [!TIP] 版本核对
> 进入应用后，可以在设置或关于页里确认当前版本号（如 1.0.9 Beta），与下载时看到的版本是否一致。如果不一致，说明下载过程中可能被替换或缓存了旧包。

> [!WARNING] 权限说明
> 应用首次启动会请求存储、网络等基础权限，建议全部允许。刷机资源板块和 DSU Sideloader 涉及更深层的系统操作，后续可能还会请求 ADB 或 root 相关权限，按需授权即可。

## 📖 四大板块使用入门

Toolkit 的功能集中在四个板块，每个板块面向不同人群，这里按「新手从哪开始、老手怎么深入」的逻辑梳理一遍。

### 刷机资源：找 ROM 和模块的一站式入口

刷机资源板块是玩机玩家的主战场，里面集成了小米 ROM、Magisk、LSPosed 三个在线仓库。Magisk 是安卓玩机圈最常用的 root 方案，它的「systemless」思路可以在不改动系统分区的前提下实现各种增强功能，围绕它形成了庞大的模块生态。

在 Toolkit 里，你可以直接浏览 Magisk 仓库和 LSPosed 仓库的模块列表，省去在多个站点之间切换的麻烦。但刷模块之前有几个基础检查不能省：

| 检查项 | 说明 |
| --- | --- |
| Magisk 安装状态 | 模块管理依赖 Magisk 环境，root 状态异常时先修环境 |
| 模块说明 | 每个模块的系统版本要求、冲突项都写在说明里，安装前务必看清 |
| 一次只装一个 | 出问题时才能定位是哪个模块引起的 |
| 救急手段 | 进不去系统时，安全模式或移除模块文件是常见自救路径 |

> [!NOTE] 刷机风险
> 刷机翻车、数据丢失属于操作风险，协议页已声明第三方下载（含 ROM 与 GSI）导致的问题与应用团队无关。操作前务必备份数据。

### DSU Sideloader：免刷入试 GSI

如果你想体验不同的安卓系统但又不想真刷入、怕搞坏分区，DSU Sideloader 就是为你准备的。它提供「访客系统」方案——GSI（Generic System Image）通过动态分区临时加载，体验完直接卸载，不会改动原有系统。这是四大板块里面向人群最广的功能，甚至不需要 root。

### Minecraft 专区

方块玩家的专属入口，集中了 MC 相关资源和服务器信息。与玩机功能相对独立，如果你不玩 Minecraft 可以直接跳过这个板块。

### 实用功能：六个日常小工具

实用功能板块是所有人都能用上的补充工具集，目前包含六个小工具：翻译、Ping、二维码相关、ChatGpt AI 等。其中 ChatGpt AI 值得单独说一下——

ChatGpt AI 是 Toolkit 内置的 AI 对话功能，和翻译、Ping 这些本地小工具不同，它依赖在线服务。使用前需要了解三件事：

1. **必须联网**：AI 对话走在线服务，网络不通时不可用
2. **服务会变**：个人开发者维护的在线服务，接口与模型随时可能调整，以应用内实际为准
3. **别输入敏感信息**：对话内容会经过服务端，隐私信息不要往里贴

产品线在 AI 功能上持续投入，主页公告里出现过「玩机百宝箱 4.0.0 即将发布，已接入 Deepseek」的预告——这是同团队的另一个产品，后续 Toolkit 内的 AI 工具如何演进，可以留意应用内的公告栏动态。

### 反馈问题的正确姿势

个人开发者的应用没有客服体系，反馈问题的姿势直接决定解决速度。Toolkit 的反馈渠道全部在应用内可见，优先级如下：

1. **QQ 群（1026114809）**：第一渠道，开发者本人通常在群里，报 Bug、问用法都最快
2. **微信公众号（rootes_apps）**：留言适合不紧急的事项
3. **社区论坛（bbs.rootes.top）**：适合写长帖子，图文并茂描述问题
4. **酷安 / 哔哩哔哩**：关于页里的个人主页，评论能到但刷得慢

> [!TIP] 进群前核对群号
> 进群前先在应用内公告栏核对一遍群号，网上搜到的群号有仿冒风险。

反馈时记得准备好：设备机型与安卓版本、是否已 root 或解锁 BL、应用版本号、操作路径（按顺序列出来）、实际现象与期望效果、是否可复现（每次都出现还是偶发）。
