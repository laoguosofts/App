## ✨ Guitar Pro 是什么

Guitar Pro 是一款面向吉他手、贝斯手、尤克里里手等弹拨乐器演奏者的**多轨制谱与播放软件**，核心定位是"让你听到自己写的谱子"。它内置了多种乐器的虚拟音色引擎，可以把五线谱和六线谱（tab）实时播放出来——这是它和纯 tab 编辑器最大的区别：你扒完一段 riff，立刻能听到虚拟吉他按你写的音高、节奏、技巧弹出来，对不对耳朵说了算。

经历过 7 个版本迭代后，Guitar Pro 8 引入了两个重量级功能：**外部音频轨**和 **Focus 音轨隔离**，把制谱、扒带、练琴三件事真正打通到了同一条时间轴上。再加上历代版本积累下来的歌词输入、文本标注、音箱模拟、效果器链等工具，它已经不只是一个 tab 编辑器，而是一套完整的弹拨乐器创作辅助工作台。

适合谁用？

- **想扒带的人**：听到一首歌想扒谱，导入原曲音频轨，配合波形图对齐，边听边写，扒完立刻能听到虚拟乐器演奏来验证对错。
- **写原创的人**：在多轨里分别写节奏吉他、主音、贝斯、鼓组，用内置效果器链和音箱模拟调出自己满意的音色，再导出 PDF 乐谱或音频。
- **练琴的人**：用 Focus 模式只突出自己要练的那条轨，其他轨降音量但保留节奏框架，跟着"半原曲半虚拟"的伴奏弹，比完全 Mute 其他轨更有代入感。
- **教琴或做教材的人**：完整的歌词系统、分节标记、力度提示、技巧说明都能在导出 PDF 时保留，一份专业级的乐谱直接交付给学生或读者。

## 🔧 安装步骤

### 下载前核对

> [!NOTE] 版本核对提醒
> Guitar Pro 8 是当前最新版本，支持 Windows 10/11 和 macOS 10.15 及以上系统。下载时务必核对系统版本和软件版本号，避免装错。

从下载页获取安装包后，建议把安装包文件大小和下载页标注的大小做一下比对——文件过小说明下载不完整，解包或安装时会报错。

### Windows 安装

1. **双击安装程序**：Windows 可能弹出 SmartScreen 保护提示，点击"仍要运行"即可继续。
2. **选择安装路径**：默认装在 C 盘 Program Files 下，想换位置直接点"浏览"选其他目录。建议不要装在包含中文或特殊字符的路径里。
3. **杀毒误报处理**：少数安全软件会把 Guitar Pro 的虚拟音频驱动误判为可疑组件。如果安装过程中被拦截，先把安装程序和安装目录加到杀毒软件的白名单再重试。
4. **完成后首次启动**：桌面上会创建快捷方式，双击启动。首次启动可能需要加载音色库，等待进度条跑完即可。

### macOS 安装

1. 打开 `.dmg` 镜像文件，把 Guitar Pro 图标拖入"应用程序"文件夹。
2. 第一次启动如果提示"无法打开，因为来自身份不明的开发者"，在"系统设置 → 隐私与安全性"里点"仍要打开"，或在 Finder 里右键应用程序 → "打开"。
3. 音色库会在首次启动时自动下载到 `~/Library/Application Support/Guitar Pro/` 目录，确保磁盘空间充足（音色库约 1~2 GB）。

### 安装后核对

安装完成后打开软件，可以做三件事确认安装没问题：

1. **打开一个示例文件**：Guitar Pro 自带几首示例曲，比如 `Smoke On The Water.gp`，如果能正常加载、播放、看到六线谱和五线谱同时显示，说明主程序和音色库都 OK。
2. **检查音频输出**：点播放按钮后耳机或音箱应该能听到虚拟吉他的声音。如果没声音，去"编辑 → 首选项 → 音频"里检查输出设备是否选对了。
3. **创建新文件**：`Ctrl/Cmd + N` 新建项目，试着在吉他轨上点几个音符，看看能不能正常输入和播放。

## 📖 核心功能与使用入门

这一节不做"从哪点到哪"的说明书式罗列，而是从实际工作流出发——扒带、写谱、练琴、出文档——每个环节里最常用、最有价值的功能点拆解开来。

### 多轨制谱：不只是吉他

新建一个 Guitar Pro 文件后，默认会给你一条吉他六线谱轨。但一个完整的项目可以包含**任意多条轨道**，每条轨道可以是不同乐器、不同调弦、不同显示模式（只显示六线、只显示五线、两者同时）。

每个轨道都有独立的**效果器链**和**音量/声像**控制——这意味着你可以给节奏吉他挂一个 Marshall JCM800 + 过载，给主音吉他挂一个 Mesa Boogie + 延迟，给贝斯挂一个 Ampeg SVT 箱头，混在一起就是一首完整的虚拟 Demo。

### 导入音频轨：扒带工作流的分水岭

Guitar Pro 8 最能改变工作方式的功能就是**外部音频轨**。在这之前，你扒完一段只能靠脑子记住"原曲是那样的"，现在直接把 MP3/WAV/FLAC 文件拖进编辑区，它会和你的乐谱**在同一条时间轴上同步播放**。

具体的扒带工作流可以这样走：

1. **导入原曲音频**：直接从资源管理器拖到编辑区，底部面板会出现波形图。波形的高低直观对应音频的振幅变化——底鼓重拍在波形上有明显的尖峰，人声高潮是持续的高幅区域，间奏空白则是一条直线。
2. **对齐时间轴**：第一次导入默认从第一小节第一拍对齐。如果音频开头有空白或前奏是从某个中间位置开始的，需要手动调整音频轨的起始位置，让波形上的底鼓重拍正好对齐到乐谱里的底鼓音符。
3. **边听边扒**：波形图和上方乐谱时间轴完全对齐，播放头同时穿过两者。你可以一边盯着波形确认节奏位置，一边在六线谱上输入音符。
4. **验证扒谱**：扒完一段后，播放时同时开音频轨和虚拟乐器轨——对比着听原曲和自己扒的谱子，哪里对不上立刻能发现。

> [!TIP] 音频轨内存占用提醒
> 音频文件全部加载到内存，建议单文件控制在 10 分钟以内、44.1kHz/16-bit WAV 格式足够，长段落可以先用 Audacity 剪出来再导入。

### Focus：比 Solo 更聪明的音轨隔离

扒带或练琴时，传统的 Solo（只听一轨）和 Mute（静音某轨）不够灵活——Solo 太极端，完全听不到伴奏；Mute 又把想排除的轨整个砍掉。Guitar Pro 8 新增的 **Focus** 模式在中间找到了一个很好的平衡：

| 功能 | 被选中的轨 | 其他轨 | 适用场景 |
| --- | --- | --- | --- |
| **Solo** | 正常播放 | 全部静音 | 只听一轨，检查扒的对不对 |
| **Mute** | 静音 | 正常播放 | 排除某个轨的干扰 |
| **Focus** | 正常播放（可自动略增音量） | 自动降低音量但不完全静音 | 突出一轨，同时保留其他轨的配合感 |

Focus 的图标在左侧轨道面板每个轨的第三个位置（目标图标），选中轨道后按 `F` 键也能快速切换。它的核心价值在于**练琴时的"半陪伴"状态**：

- 练主音吉他 Solo 时，Focus 主音轨让虚拟主音听起来清楚，其他轨（贝斯、鼓、节奏吉他、原曲音频）降音量但还能听到——你既不会被淹没，又有节奏框架保持同步。
- 扒贝斯时，Focus 贝斯轨让自己扒的贝斯变清晰，同时原曲音频轨不降音量——可以一边听原曲贝斯的真实音色，一边对比自己扒的音高和节奏。

衰减程度可以在偏好设置里调（默认 -12 dB，范围 -6 dB 到 -24 dB），衰减越小其他轨越清晰，越大越像背景音。

### 音箱模拟：音色塑形的第一步

Guitar Pro 的音箱模拟器内置了全球最著名的吉他箱头模型——从 Fender Twin Reverb 的温暖清音到 Mesa Boogie Rectifier 的重型高增益，选择正确的箱头是音色塑形的起点。

| 品牌 | 典型型号 | 音色特点 | 适用风格 |
| --- | --- | --- | --- |
| **Fender** | Twin Reverb / Deluxe Reverb | 温暖干净，带弹簧混响 | 布鲁斯、乡村、Jazz、经典摇滚 |
| **Marshall** | JCM800 / Plexi / JVM | 经典失真，中频突出 | Hard Rock、80s Metal、Classic Rock |
| **Vox** | AC30 / AC15 | 中频甜，英伦音色 | The Beatles 式摇滚、英伦 Pop |
| **Mesa Boogie** | Rectifier | 高增益重型，低频硬 | Metal、Djent |
| **Ampeg** | SVT（贝斯） | 管箱温暖，低音扎实 | 通用贝斯 |

每个箱头都有 Gain/Drive（失真量）、Bass/Middle/Treble（三段 EQ）、Presence（高频空气感）、Reverb（内置混响）等参数可以调。一个实用的搭配思路是：

**吉他调弦越低，选越厚重的箱头**——Standard E 调弦配 Fender Twin Reverb 就是清音布鲁斯，Drop D 配 Marshall JCM800 就是硬摇滚，Drop F# 配 Mesa Boogie Rectifier 就是现代 Metal/Djent。

音箱总是在效果器链的**最末端**（吉他 → 效果器 → 音箱），因为效果器处理的是原始信号，音箱负责把处理后的信号放大并加上自己的音色染色。某些高级箱头还支持选择搭配的箱体规格（2×12 / 4×12）和麦克风模拟，进一步细化音色。

### 歌词与文本标注：让谱子不只是音高

很多人觉得"做吉他谱"就是画六线谱上的音——其实一份能直接交给乐手排练的专业乐谱，还需要完整的歌词、和弦行、分节标记、力度提示、技巧说明、版权信息。Guitar Pro 的文本标注系统把这些全收纳了进来。

**歌词输入**有两种方式：按 `F5` 在项目信息里粘贴整段歌词，Guitar Pro 会自动对齐到音符位置；或者直接在人声轨/指定轨上按 `Ctrl/Cmd + L` 打开歌词光标，逐字对应音符输入。一个字对多个音时用连字符分隔，空音时按空格跳过。

文本标注的类型相当丰富：

| 类别 | 具体项目 | 示例 |
| --- | --- | --- |
| 标题分节 | 曲名、艺术家、章节标记、速度文字 | "Intro"、"Verse 1"、"Moderately" |
| 演奏提示 | 技巧说明、调音提示、力度标记、反复记号 | "Gently palm mute"、"Drop D Tuning"、"mp" |
| 版权信息 | 版权声明、转录者、备注 | "Copyright © 1976 Asylum Records" |

添加标注的方法也灵活——**双击乐谱空白区域**直接创建文本框、或在右侧检查器面板选择标注类型、或右键菜单添加。所有标注都可以用鼠标拖拽调整位置（小节上方最常见，力度标记在下方，技巧说明在音符上方），也可以在样式表里统一设置字体、字号、颜色，改一次全局生效。

> [!WARNING] 导出 PDF 时的完整性
> 所有文本标注在导出 PDF 或打印时会完整保留——这是 Guitar Pro 比纯 tab 软件专业的地方。如果导出的 PDF 里发现歌词或标注缺失，检查一下标注的位置是否在可打印区域内。
