## ✨ Baka 是什么

Baka 是一款面向动漫爱好者的多源聚合播放器，核心特点是把分散在不同站点的番剧源统一收拢到一个界面里，用户不需要在各平台之间来回切换搜索。它内置了 mpv 作为播放内核，配合 Anime4K 画质增强引擎，主打"一个应用搞定追番全流程"——从搜索、播放到下载，都在同一个界面内完成。

Baka 采用了脚本化的源适配方案，社区可以维护各自的源解析脚本，源站改版时只需更新脚本而不必等官方发版。这种开放架构让它的源库更新速度非常快，热门番剧源基本都能跟上。播放器层面，它支持硬解码、弹幕叠加、字幕轨切换等常见功能，桌面端还提供完整的键盘快捷键映射，重度用户可以实现纯键盘操作。

这款应用特别适合两类人：一是追番量比较大、习惯多平台切换找资源的用户；二是对画质有追求、希望在低分辨率源上也能获得不错观感的观众。对于只想偶尔看一两部热门番剧的轻度用户来说，它的多源聚合优势可能感受不那么明显，但 Anime4K 的画质增强依然值得一试。

## 🔧 安装前准备与安装步骤

### Android 平台安装

Android 版 Baka 通常以 APK 形式分发，安装前需要做两件事：

1. **允许未知来源安装**：进入系统设置 → 安全与隐私 → 安装未知应用，找到你用来下载 APK 的浏览器或文件管理器，勾选"允许安装未知来源应用"。不同厂商 ROM 的路径可能略有差异，有的在"应用管理"下面。

2. **核对文件信息**：下载完成后检查 APK 文件大小和版本号，避免下载到不完整的安装包或旧版本。部分下载页会附带 MD5 或 SHA 校验值，可以用文件哈希工具比对一下。

> [!WARNING]
> 如果安装时弹出"解析包错误"或"签名不一致"，大概率是下载过程中文件损坏了，重新下载一次即可。如果是从非官方渠道获取的 APK，建议在安装前先用杀毒软件扫一遍。

安装过程很直接：点击 APK 文件 → 确认安装权限 → 等待进度条走完 → 点击"完成"或"打开"。首次启动时应用会请求存储权限（用于缓存视频和存放下载内容）和网络权限，全部允许即可。

### PC 平台安装

桌面端支持 Windows 和 macOS，Windows 用户下载 `.exe` 安装包后双击运行，默认安装路径在 `C:\Program Files\Baka`，可以自定义到其他盘符。安装过程中如果被 Windows Defender 拦截，选择"更多信息 → 仍要运行"即可——这是因为安装包没有 Microsoft 签名，属于常见的安全误报。

macOS 用户下载 `.dmg` 文件后双击打开，将 Baka 图标拖拽到 Applications 文件夹。首次打开时需要在"系统设置 → 隐私与安全性"中点击"仍要打开"。

### 安装后验证

安装完成后打开应用，先确认三件事：

- **版本号**：在设置 → 关于中查看，确认是下载页标注的最新版本
- **源列表**：首次启动会自动加载内置的番剧源，打开源管理界面看是否正常显示
- **基础功能**：随便搜一部热门番剧（比如"鬼灭之刃"），点一集播放试试画面和声音

如果这三项都正常，说明安装没问题，可以开始正常使用了。

## 📖 使用入门

### 搜索与播放

打开应用后直接进入主界面，顶部是搜索栏，下方是源列表和分类入口。在搜索栏输入番剧名或关键词，结果会自动从所有已启用的源中聚合展示。点开某一集后进入播放界面，Baka 默认优先选择响应最快的源，如果这个源加载慢或播放失败，可以在播放界面点击源切换按钮（通常在播放器右上角或播放菜单里）选择其他源。

多源聚合最大的好处就是容错——一个源挂了换另一个，基本不会出现"整部番剧看不了"的情况。搜索结果里同名番剧如果有多个源可用，播放时会自动回退到下一个源，不需要手动干预。

### 画质增强（Anime4K）

Baka 内置了 Anime4K 超分辨率引擎，这是它最突出的功能之一。引擎提供三种增强模式：

| 模式 | 适用场景 | 快捷键 |
|------|----------|--------|
| 模式 A | 720p 高码率源，现代番剧 | Ctrl + 1 |
| 模式 B | 720p/1080p 源，老番修复 | Ctrl + 2 |
| 模式 C | 480p 及以下，压缩严重的视频 | Ctrl + 3 |
| 关闭 | 1080p 以上原生源 | Ctrl + 0 |

选模式的判断逻辑很简单：如果源本身就是 1080p 甚至 4K，直接关闭增强就行——超分辨率不能凭空增加真实细节，反而会增加延迟。720p 源根据质量选 A 或 B，480p 及以下直接上 B 或 C。

> [!TIP]
> 刚开始用可以先开模式 A 试几集，觉得效果不够再升 B。模式 C 效果最激进，但处理时间最长，设备性能一般的话可能卡帧。

### 多线程下载

Baka 的下载不是简单的单线程 HTTP 请求，而是一个独立的多线程下载引擎。它把视频文件切成多块并行下载，总速度是各线程之和，在优质源上 1080p 一集约 1~2 分钟就能下完。下载过程中支持断点续传，线程失败会自动重试，网络断开后恢复连接会继续下载。

最实用的是"边下边播"功能——下载开始后引擎先缓冲一小段数据（约 10~30 秒），然后播放器可以同步开始播放，不用等全集下载完再看。如果觉得不好看可以随时停止下载，不浪费空间。

### 故障排查

使用过程中最常见的问题就是源加载失败，表现为搜索无结果、点击打不开视频、播放几秒后退出等。排查时按这个顺序来：

1. **先判断范围**：搜一部热门番剧，如果所有源都没结果 → 网络问题；如果只有个别源失败 → 源本身挂了
2. **检查网络**：打开浏览器确认手机能上网，VPN/代理是否开着，DNS 是否需要切换
3. **测试源状态**：在源管理界面每个源旁边有"测试连接"按钮，绿色=正常，黄色=慢，红色=不可用
4. **切换或更新脚本**：源站改版是常态，HTML 结构变了或接口改了都会导致解析失败，禁用问题源后检查有没有脚本更新
5. **最后手段**：清理缓存 → 重启应用 → 重装（注意提前导出收藏夹）

### 快捷键（桌面端）

桌面端用户用键盘操作会高效很多，以下是最常用的快捷键：

| 功能 | 快捷键 |
|------|--------|
| 播放/暂停 | Space / K |
| 快进/快退 5 秒 | ← / → |
| 上一集/下一集 | Page Up / Page Down |
| 音量加减 | [ / ] |
| 全屏切换 | F11 / f |
| 弹幕显示/隐藏 | F |
| 字幕切换 | J / Shift + J |
| Anime4K 模式 | Ctrl + 1/2/3/0 |
| 退出播放 | q / Esc |

这些快捷键基于 mpv 的默认配置，部分版本支持自定义映射，可以在设置中调整。
