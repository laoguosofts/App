## ✨ Susan 是什么——一款开源的影视解析播放器

Susan 是一款面向安卓用户的开源影视播放器，核心能力是**粘贴视频平台播放页链接即可解析播放**，同时内置了影视库信息流和站内搜片作为两条备用路径。它不托管任何视频资源，走的是社区维护的开源解析接口，所以平台偶尔改版会暂时影响解析，但社区跟进修复的速度通常较快。

适合谁用：手机里装了腾讯视频、爱奇艺、优酷、芒果 TV、哔哩哔哩等多个视频 App，但不想来回切换、想在一个应用里统一播放的人；或者不想开会员、只想偶尔看点内容的轻度观众。它不提供独家内容，价值在于把多个平台的播放体验整合到一个界面里。

## 🔧 安装步骤——安卓平台的未知来源授权

Susan 以 APK 形式分发，安装流程和大多数第三方安卓应用一样，核心卡在「允许安装未知来源应用」这一步。

1. 从下载页拿到最新版 APK 文件，确认文件大小和版本号与下载页标注一致
2. 在手机上打开 APK，系统会弹出「未知来源」提示
3. 点击「设置」进入权限管理，找到你的文件管理器或浏览器，开启「允许安装未知应用」
4. 返回安装界面，点击「安装」，等待完成

> [!WARNING]
> 安卓 8.0 之后，未知来源权限是**按应用分配**的——你从哪个文件管理器打开 APK，就给那个文件管理器授权。换了另一个管理器打开，还得单独授权一次。

装完之后建议打开应用检查一下版本号，和下载页标注的是否一致。如果系统弹出杀毒误报（开源项目偶尔会碰到签名或行为特征误判），确认文件来源是官方渠道即可放行。

## 📖 使用入门——两条路径覆盖不同场景

Susan 的界面逻辑很清晰：主界面上方是链接输入框，下方是影视库信息流。实际使用时，你会在两条路径之间来回切换——不知道看什么就刷信息流，有明确想看的目标就搜片名或粘链接。

### 路径一：粘贴链接解析

这是 Susan 最核心的功能。从视频 App 的播放页走「分享 → 复制链接」拿到地址，粘进输入框就能解析。当前版本明确支持腾讯视频、爱奇艺、优酷、芒果 TV、哔哩哔哩这几个主流平台，它们的链接格式分别带 `vid`、`play`、`episode`、`video` 或 `bv` 等字段。

> [!TIP]
> 不是所有链接都能解析。必须是**播放页地址**（带视频标识字段的那种），聊天转发的口令文本、App 首页、搜索结果页、剧集详情页这些都不行。拿不准是不是播放页？看 URL 里有没有 vid/play/episode/video/bv 这类字段就行。

其他平台没在官方列表里不代表一定不能用——只要它的分享逻辑也是生成一条带视频标识的 http 地址，就值得试一下。能解析就是能用，解析不了再换站内搜片那条路。

### 路径二：站内搜片和信息流

不想搜、不想粘链接？主界面下方的影视库信息流就是为这种场景设计的——一排热播剧集封面，点封面直接进选集列表，连搜索框都不用碰。信息流里的内容会随应用版本更新而变化，覆盖国产剧、美剧、动漫、综艺等常见品类。

| | 信息流点封面 | 手动搜片名 |
| --- | --- | --- |
| 适合场景 | 漫无目的随便看点什么 | 有明确想看的目标 |
| 操作步骤 | 1 步点封面 | 点放大镜 → 输入 → 搜索 |
| 内容来源 | 应用固定推荐 | 内置资源库全文搜索 |
| 能不能看冷门剧 | 基本不能 | 大概率可以试试 |

### 播放器界面和深色模式

进入播放器之后就是标准的视频播放体验。有一点值得提：Susan 的界面颜色**跟随系统深色开关**，不需要在 App 内单独设置主题。系统开深色它就变深，系统关闭它就恢复浅色，切换是秒级的，不用重启 App。这个深色模式覆盖的是主界面、设置、选集列表这些外层界面，播放器里的视频画面本身不受影响。

### 链接解析突然失效怎么办

原来能用的链接突然解析不出来，按这个顺序排查：

1. **这条链接本身是不是变了**——视频平台有时会调整某一集的播放页地址规则，换一个同平台完全不同的剧集链接试一下，如果能解析说明只是原来那条挂了
2. **重新复制一条播放页链接**——回到原视频 App 的播放页，重新走一遍「分享 → 复制链接」，新复制的地址应该能用
3. **换网络试一次**——关掉 WiFi 用流量，或者反过来
4. **切站内搜片救急**——如果同一个平台的所有链接都解析不出来，大概率是平台接口改版了，站内搜片走的是完全不同的资源源，不受影响
5. **等应用更新**——Susan 的解析接口由社区维护，平台改版后通常几天内就能跟进修复，更新应用即可恢复
