## ✨ Simpler 是什么

Simpler 是一款面向英语零基础和初中级学习者的自学应用，由 Goodvyzn 团队开发，在 iOS 和 Android 双端都有发行。它的核心理念很朴素——不搞直播课、不堆录播视频，用一套"词块拼句 + 间隔复习 + 每日节奏"的轻量组合，让用户每天花十几分钟就能推进学习进度。

课程内容从 Level 1 的动词原形、名词复数起步，一路覆盖到 Level 3 的比较度、反身代词，免费版就能解锁相当完整的语法主题。每个语法点不是先给规则再做题，而是先展示正确的词块组合，让你用拖拽或点击的方式把句子拼对——拼对了就有即时反馈，拼错了它会提示哪里不对、为什么不对。这种"词块积木"的交互方式是 Simpler 最有辨识度的地方，比纯刷题更能帮你建立"为什么要这么搭配"的语感。

应用在 6.4.0 / 6.5.0 版本引入了桌面小组件功能，把连胜天数、今日目标完成度、最近一次学习时间直接推到手机主屏幕上。开发者说这是"让坚持变得可见、让纠错变得及时"——心理学上叫"提示性习惯"，你不需要刻意记住"今天要学英语"，每次解锁手机的那个动作就是提示。

适合的人群主要有两类：零基础自学但以前半途而废过的人，以及能看懂日常对话但组句子总不确定语法对不对的初中级学习者。如果你已经能无字幕看英文电影、和外国朋友自由聊天，或者正在准备四六级、雅思这类应试目标，Simpler 的内容会显得偏简单，不太对路。

## 🔧 安装步骤

### iOS（iPhone / iPad）

1. 打开 App Store，搜索 "Simpler"
2. 确认开发者名称为 Goodvyzn，避免下载同名其他应用
3. 点击"获取"或价格按钮，等待下载安装完成
4. 首次启动时，应用会引导你完成等级测试——选几个简单句子评估起点，或者直接手动指定级别

> [!NOTE]
> App Store 中国区和海外区的 Premium 订阅价格可能不同，部分地区提供"三天免费试用 + 年订阅"模式，具体以应用内显示为准。

### Android

1. 打开 Google Play，搜索 "Simpler"
2. 找到 Goodvyzn 开发者发布的版本，点击"安装"
3. 如果你的设备没有自动从应用商店获取，也可以从上面的官方下载页获取安装包——首次安装外部来源的 APK 时，系统会弹出"允许未知来源"的授权请求，需要在设置中确认

> [!WARNING]
> Android 安装外部 APK 时务必核对文件大小和版本号，避免下载到被篡改的二次打包版本。建议优先使用 Google Play 渠道。

### 安装后核对

安装完成后打开应用，检查以下几点确认是正版：

- 等级测试界面能正常进入
- 设置页面底部能看到 Goodvyzn 的开发者信息
- 课程内容与官方介绍一致（从第三课起单词和规则练习完全免费）

## 📖 使用入门

### 每日学习的基本节奏

Simpler 的课程按级别组织，每个级别下有若干语法主题，每个主题又分成几个小单元。每个单元的学习流程大致是：

1. **规则讲解卡片**：用简体中文讲这条语法，不出现"现在进行时""主谓一致"这类术语，直接说"表示正在发生的动作"这种直白表述
2. **词块拼句**：给你一堆词块碎片，拼出正确的句子——拼错会提示哪里有问题
3. **Trener 综合练习**：混入上一课的内容，帮你巩固不遗忘
4. **星星奖励**：拼对就给星星，攒星星可以解锁进阶剧情或侦探故事

整个流程每节课大概 10-15 分钟，和开发者宣称的"每天十几分钟"节奏吻合。

### 桌面小组件的使用

小组件在 Simpler 6.4.0 / 6.5.0 及以上版本中可用，免费版和 Premium 都支持。它显示的核心信息有：

- **连胜天数**：大字居中显示，每次中断会归零
- **今日目标完成度**：进度条或具体数字，比如"今天目标 15 分钟，已学 8 分钟"
- **最近一次学习**：小图标指示上次打开应用是什么时候
- **快速入口**：点击小组件直接跳转到应用

添加方式：iOS 用户在主屏幕空白处长按 → 点左上角"+"号 → 搜索 Simpler → 选择尺寸（小/中/大）→ 拖到主屏幕合适位置。Android 用户也是类似的长按空白 → 选小组件 → 找 Simpler → 拖拽，不同品牌系统的菜单名称略有差异。

数据同步是实时的——今天学了 10 分钟，小组件进度条立刻更新；连胜变成 11 天，数字跟着变。偶尔有用户反馈小组件显示的还是昨天的进度，重启应用或等几分钟就能同步过来。

### 免费版到底能用到什么程度

Simpler 的免费版范围比很多人预期的要宽。开发者在商店问答区明确说过："从第三课起，单词和规则练习在所有课程与级别完全免费。" 这意味着免费版里你能用上的核心功能包括：

| 功能 | 免费版 | Premium |
|---|---|---|
| 基础语法主题（Level 1-3） | ✅ 完整 | ✅ 完整 |
| 词块拼句练习 | ✅ | ✅ |
| Trener 综合练习 | ✅ | ✅ |
| 单词插图卡 + 间隔复习 | ✅ | ✅ |
| 每日单词宝箱 | ✅ | ✅ |
| 等级测试 + 主线进度追踪 | ✅ | ✅ |
| 桌面小组件 | ✅ | ✅ |
| 星星奖励系统 | ✅ | ✅ |
| 进阶课程（条件句、虚拟语气等） | ❌ 需攒星星解锁 | ✅ 直接访问 |
| 更多对话场景 | ❌ | ✅ |
| 无限制离线下载 | ❌ 有数量上限 | ✅ |
| 侦探故事剧情 | 部分解锁 | 完整 |

如果你是零基础或初中级、每天学 10-15 分钟，免费版可能很久都够用不上 Premium。进度很快想一口气推完所有级别，或者已经有基础想补特定语法点，可以考虑 Premium 跳过解锁等待。

### 重置学习进度

如果学了一半想重新开始，或者等级测试选错了级别想重测，Simpler 提供重置功能。重置会清除所有已学课程进度、星星数量、连胜记录、收藏单词列表、复习队列和已领取的证书，但**不会**清除下载到本地的课程文件、Premium 订阅状态和应用设置偏好。如果开了云同步，重置之后云端数据也会同步清空。

操作入口：设置（齿轮图标或底部导航最后一个）→ 找到"重置学习进度"或"重新开始"选项 → 确认 → 输入密码或二次确认 → 完成。不同版本里这个入口可能在"隐私"分类下，也可能在"关于"里，找不到可以直接在应用内搜 "reset" 或"重置"。

> [!WARNING]
> 重置后如果之前没开云同步，本地数据**无法恢复**。以下几种情况不建议重置：某节课卡住了（可以跳过或关掉应用下次继续）、想换级别但不想丢已有的（某些版本允许同时追踪多个级别）、换设备但保留进度（直接用原账号登录，云同步会把进度带过去）。

重置之后应用会回到等级测试界面，就像第一次安装时那样，可以重新做测试或手动选级别。

### 设备支持与离线学习

Simpler 原生支持 iOS 和 Android 双端，手机和平板都可以用。交互以触屏操作为主，平板体验略好一些，但手机端也完全够用。课程支持提前下载到本地，下载后可以完全离线学习——地铁、长途飞行或者网络不好的地方都不影响进度。下载功能在免费版有数量上限，Premium 解锁无限制下载。
