## ✨ ePSxe 是什么

ePSxe 是目前兼容性最广的 PS1（PlayStation 1）模拟器之一，核心特色在于**插件架构**——视频、音频、光驱、BIOS 各自独立成插件，用户可以根据不同游戏的 bug 灵活切换，而不是被单文件模拟器的固化逻辑锁死。从 Windows XP 到 Windows 11，从单核老笔记本到多核新台式机，它都能跑，低端机用内置软件渲染器不依赖独立显卡，高端机则可以拉满内部分辨率和纹理过滤榨取画面。

和 DuckStation、RetroArch 这些后来者相比，ePSXe 的重编译器经过 20 年打磨，对 PS1 各类冷门 CPU 指令的覆盖最完整——一些在其他模拟器里花屏或直接崩溃的小众游戏（日本文字冒险、教育软件），在 ePSXe 里往往能直接跑通。2.0.5 版本起更是独有的本地局域网联机功能（NETCORE 插件），两台电脑加载同一款游戏、同一个 BIOS 就能对战，其他 PS1 模拟器要么没有，要么需要额外中间件。

适合谁用：想把压箱底的 PS1 老游戏翻出来重温的怀旧党、追求最高兼容性的折腾党、需要同局域网联机对战的格斗/竞速玩家。如果只是想"双击 exe → 选 BIOS → 选游戏直接跑"，嫌插件切换麻烦，可以试试 DuckStation——但遇到冷门游戏跑不起来时，ePSXe 仍然是最后的保险。

## 🔧 安装步骤

ePSXe 分 Windows、Android、Linux、Mac 四个平台，安装方式略有差异。以下以 Windows 版为例，其他平台的逻辑类似。

### 安装前准备：BIOS 文件

> [!WARNING]
> ePSXe 不内置 PS1 BIOS——你需要自行准备一个合法获取的 BIOS 镜像（常见文件名 `SCPH1001.BIN` 或 `SCPH7003.BIN`）。没有 BIOS 模拟器无法启动任何游戏。

1. **下载安装包**：从下载入口获取对应平台的最新版本（Windows 版通常是 ZIP 压缩包或 exe 安装器）。
2. **解压 / 运行安装器**：ZIP 包解压到任意目录即可，不需要安装路径白名单限制；exe 安装器按向导选择目录。路径尽量避免中文和特殊字符。
3. **放入 BIOS**：把 `.BIN` 或 `.ZIP` 格式的 BIOS 文件复制到 ePSXe 安装目录下的 `bios/` 文件夹（没有就手动新建）。
4. **首次启动配置 BIOS**：打开 ePSXe → Config → BIOS → 勾选正确的 BIOS 文件 → OK。

### 验证安装是否正确

- 启动 ePSXe 不报错、BIOS 能被正确识别
- Config → Video → Configure 能正常打开视频插件配置面板
- 加载任意一个已知可运行的游戏镜像（.bin/.cue 或 .chd）能启动到游戏画面

如果杀毒软件误报，把 ePSXe.exe 和插件目录加入白名单即可——ePSXe 本身是开源合法软件，误报通常来自插件签名问题。

## 📖 用 ePSXe 重温 PS1 老游戏

装好只是第一步，想让游戏跑得顺、音效对、画面好，还需要理解几个核心概念。

### 先给你的游戏选对模拟器

| 模拟器 | 特点 | 适合场景 |
|--------|------|----------|
| **ePSXe** | 插件架构 + 最高兼容性 + 本地 netplay | 冷门游戏 + 联机对战 + 深度调优 |
| DuckStation | 单文件 + 现代化 UI + 内置画面增强 | 新手 + 新硬件 + 怕折腾 |
| RetroArch (PSX Core) | 前端式全家桶 + 灵活 shader 系统 | 多平台玩家 + 画面党 |
| Mednafen | 命令行驱动 + 精准模拟 | 硬核爱好者 + 模拟器开发者 |

一个简单的决策逻辑：你的游戏在 DuckStation 里能跑吗？能跑就用 DuckStation 省得折腾；跑不起来、花屏、崩溃，再装 ePSXe 试试。需要局域网联机的话——直接装 ePSXe，其他模拟器目前做不到。

### 镜像格式决定了你能不能听到音乐

很多新手跑起来游戏后发现"只有画面没有背景音乐"，90% 的原因是镜像格式选错了或者 CDDA 开关没开。PS1 游戏里有两种音频存储方式：

| 格式 | 存储位置 | 说明 |
|------|---------|------|
| **CD-DA** | 光盘额外音轨（Track 1 之后） | 高音质背景音乐、OP/ED 主题曲，类似音乐 CD |
| **XA** | 数据轨内部的压缩流式音频 | 过场语音、BGM 循环、音效 |

关键差异在镜像格式对 CDDA 的保留：

- `.bin/.cue + .sub`：三个文件齐全才能完整保留 CD-DA 轨，选游戏时**要选中 .cue 文件**（不是 .bin）
- `.chd`：CHD 格式把所有轨打包进一个文件，CD-DA 完整保留，推荐首选
- `.iso`：**绝大多数 .iso 只含第一条数据轨，没有 CD-DA 轨**——用 .iso 的游戏大概率只有音效没有背景音乐
- `.pbp`：PSP 格式，CD-DA 会被转成 OGG 内嵌，ePSXe 能正确解码

> [!TIP]
> 遇到"只有音效没背景音乐"的情况：先看镜像是不是 .iso，如果是就换 .bin/.cue 或 .chd；如果镜像没问题，检查 Config → Sound 里的 **Enable CDDA Audio** 勾上没有。同理"有背景音乐过场语音听不到"要勾 **Enable XA Audio**。

### 音效调优：混响和插值

ePSXe 的 SPU 模拟支持硬件混响——Enable Reverb 开启后会为音效增加反射延迟，模拟声音在墙壁间弹跳的空间感。RPG/冒险游戏有大量人声和环境探索场景，混响必开；射击/格斗游戏核心在打击感，混响反而可能让音效变糊，建议关掉。

插值（Interpolation）是解决 XA 流式音频（37800Hz）和 PC 声卡（44100Hz）采样率不匹配的开关——开了转换更平滑无失真，关了性能更好但可能有"咔哒"声或音高偏移。以下情况考虑关插值：特定游戏 BGM 断断续续、过场语音卡顿、CPU 是老 Pentium 4 级别。

同时关掉混响和插值能让音效处理 CPU 开销降低约 30%，适合低端笔记本或游戏帧率一直偏低的场景。代价是声音会干巴巴的，部分游戏（比如《寂静岭》）的恐怖氛围依赖混响，关了效果大打折扣。

### 进阶：本地局域网联机对战

2.0.5 版本起独有的 NETCORE 插件支持两台电脑同局域网联机，格斗、竞速、体育游戏的双人对战不再需要两台主机。设置步骤：

1. **确认两台电脑环境一致**：都用 ePSXe 2.0.5+、同一个 BIOS 文件、完全相同的游戏镜像（核对 .cue 文件 MD5 哈希）
2. **查 IP**：两台电脑分别查局域网 IP（不是公网 IP），比如主机 192.168.1.100、客户端 192.168.1.200
3. **主机端配置**：Config → Netplay → 下拉选 NETCORE 插件 → Server Type 选 Host → Port 保持 18282 → Start
4. **客户端配置**：下拉选 NETCORE → Host IP 填主机 IP → Port 18282 → Server Type 选 Client → Connect
5. **同步开始**：两边都加载游戏 → 进入主菜单 → 找到双人模式 → 同时按下开始游戏

联机期间有几条纪律不能碰，否则直接 desync（两边画面不同步）：

| 禁止行为 | 原因 |
|---------|------|
| 按 F1/F2 即时存档/读档 | 直接导致状态不同步 |
| 使用金手指 | 修改内存后两边状态分叉 |
| 一边切换视频插件 | 渲染管线变化导致 desync |
| 中途退出模拟器 | 游戏状态丢失，两边都崩溃 |

可以做的：ESC 回主菜单调整视频参数（不影响联机状态）、按 Start 暂停游戏。NETCORE 插件跨平台支持，Windows ↔ Linux ↔ Android 可以直接联机。
