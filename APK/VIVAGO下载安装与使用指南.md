## ✨ VIVAGO 是什么

VIVAGO 是 HiDream 智象未来推出的 AI 视频聚合创作平台，把模型聚合器、模板墙和 Agent 高阶创作三大能力揉成一个统一界面，让用户在单个账户下就能完成从灵感草图到成片的全流程。平台一站式接入了 Sora 2、Veo 3.1、Kling 等十多款顶级视频与图像模型，内置 300+ 一键出片模板，并提供 HiDreamClaw 云端智能体和 vivago R1 对话式短片创作两种高阶形态。

与同类产品相比，VIVAGO 的差异化在于：聚合外部顶级模型的同时保持多模型自由切换，模板生态定期更新且模板即入口，高阶能力层面有云端部署的 Agent 可以自动编排任务，而入门门槛极低——模板模式下零提示词即可开始创作。三个核心产品形态共用同一账户体系，积分与订阅在所有形态间互通。

这款平台适合短视频与自媒体创作者快速攒素材、自媒体运营批量产出社媒内容、独立开发者搭建 AI 工作流自动化流水线，学生和个人项目创作者也能靠每日免费积分覆盖课程项目的视觉需求。如果你日常需要在多款 AI 视频模型之间来回切换找最合适的出片效果，或者想探索对话式创作完整短片的可能性，VIVAGO 是一个值得深入的工具。

## 🔧 注册与快速上手

VIVAGO 是一款 SaaS 平台产品，不需要传统意义上的本地安装流程，注册账号后直接在浏览器中使用即可。以下是快速上手的完整步骤。

### 第一步：注册账号

访问平台主站，通过邮箱或第三方账号登录。注册后系统会自动赠送初始积分，之后每日登录还能领取 100 credits 用于日常试验。

> [!NOTE]
> 首次注册时注意选择正确的区域与语言设置，平台支持多区域部署，不同区域的模型可用性和响应速度会有所差异。

### 第二步：熟悉界面布局

注册完成后进入主界面，左侧导航栏主要包含三个板块：

- **模型聚合区**：可以直接选择 Sora 2、Veo 3.1、Kling、vivago 2.0 等十多款模型进行文生视频或图生视频创作
- **模板墙**：300+ 热门模板按类别分组，宠物舞、老照片恢复、产品演示等场景都能找到对应的一键模板
- **Agent 区**：HiDreamClaw 云端智能体和 vivago R1 对话式短片创作入口

### 第三步：检查积分与订阅状态

在账户设置页面可以查看当前积分余额和订阅状态。基础版用户每日登录领 100 credits，积分消耗按模型不同有所差异。vivago 2.0 自研模型的积分消耗最低，适合批量模板套用场景；Sora、Veo 等外部顶级模型消耗较高，但出片质量也更高。

> [!TIP]
> 日常批量产出优先使用 vivago 2.0 模型省钱，高质量单篇作品再切换到 Sora 2 或 Veo 3.1。模板墙里的模板已经帮你选好了合适的模型，直接套用就行。

### 第四步：完成首次出片

最简单的首次出片路径：进入模板墙，选择一个感兴趣的模板类别（比如萌宠类），点击套用后按提示上传素材或填写参数，平台会自动调用对应模型完成生成。整个过程不需要写任何提示词，1~3 分钟就能拿到第一成片。

## 📖 使用入门

完成注册后，VIVAGO 的创作能力大致可以分为四个层次：模型切换与基础生成、模板墙批量套用、参考图控制角色一致性、Agent 高阶创作。下面逐层展开。

### 模型切换与基础生成

VIVAGO 的核心优势之一就是多模型聚合。文生视频和图生视频界面都会显示模型选择下拉菜单，你可以按创意方向自由切换。大致的模型选择参考：

| 模型 | 积分消耗 | 适合场景 |
|---|---|---|
| vivago 2.0 | 低 | 批量模板套用、日常社媒素材 |
| Kling 系列 | 中 | 老照片翻新动效、风格化视频 |
| Sora 2 / Veo 3.1 | 高 | 高质量单篇作品、剧情短片 |

模型之间的输出风格差异明显——Sora 2 的画面流畅度和光影层次更优，Kling 在风格化和动效方面有独特表现，vivago 2.0 在通用场景下性价比最高。建议对同一提示词用两三款模型各跑一遍，对比后挑选最契合当前需求的版本。

### 模板墙的正确用法

300+ 模板墙是 VIVAGO 降低入门门槛的关键设计。模板不是简单的"预设参数包"，每一个模板背后都绑定了经过筛选的模型、推荐的参数范围和典型素材示例。使用时有几个实用技巧：

- **模板即入口**：如果你对某个创作方向没概念，直接从模板墙切入是最快的方式——先套用模板跑一遍，再根据出片效果微调参数或改写提示词
- **定期刷新**：模板墙会不定期新增模板，保持浏览习惯能第一时间发现新出的风格化模板
- **模板组合**：多个模板的参数可以手动拆解后重新组合，比如用宠物舞模板的节奏参数搭配老照片恢复模板的模型选择

> [!WARNING]
> 模板墙的模板虽然方便，但并非所有模板都适合所有场景。比如某些老照片恢复类模板依赖 Kling O1 模型，如果你的积分余额不足或当前区域 Kling 不可用，模板就会提示失败。遇到这种情况换同类别下依赖其他模型的模板即可。

### 参考图与角色一致性控制

纯文生视频每次生成的角色外观可能不一致——同一提示词"穿风衣的女人"，第一次可能是金发，第二次可能是黑发，做系列内容就会很麻烦。VIVAGO 的参考图功能专门解决这个问题，核心有两种用法：

**角色一致性控制**：上传人物正脸照（最好加一张全身照），平台会提取面部特征、发型、服装等关键信息，在后续生成中保持统一。适合系列短片里的同一主角、同一品牌形象的不同场景展示、虚拟角色设定图的后续迭代。

**风格迁移**：上传一张"风格参考图"（比如某张水彩画或动漫截图），让平台把目标内容生成成参考图的整体风格。

平台使用特征匹配算法提取参考图的特征点，覆盖面部五官比例、肤色、发型轮廓、服装款式颜色纹理以及整体构图色调。参考图支持 JPG 和 PNG 两种格式。

最佳实践方面，参考图质量是第一要素——清晰、光线均匀的照片效果最好，模糊或过度滤镜的图会干扰特征提取。即使有参考图，提示词里也应该写清楚想要的"变化方向"，比如"在咖啡馆里"或"穿着红色风衣"，这样模型的发挥空间会更精准。可以同时上传正脸照、侧脸照和全身照三张参考图，角色还原度会明显提高。最后要注意的是，参考图是"引导"而非"复制"，模型在不同风格和场景下会保持一定自由度，过度依赖单一参考图反而可能限制创意发挥。

### HiDreamClaw 云端智能体

HiDreamClaw 是 VIVAGO 基础版用户也能用的云端 AI 智能体，定位是日常创作的自动化助手。与 vivago R1 的完整短片智能体不同，HiDreamClaw 偏向任务型执行，在平台上一键点击就能完成云端部署，不需要本地算力资源和复杂配置。部署后智能体 7×24 在线，可以随时通过聊天界面给它下达任务。

HiDreamClaw 自带 Skill 库，覆盖了常见创作场景的自动化能力——自动生成某个风格的视频、批量套用模板、给一组图片批量添加动效等。你用自然语言告诉它"帮我生成 10 个竖屏宠物短视频"，它会自动拆解成具体的执行步骤并依次完成。平台还支持接入多个聊天工具，在你常用的聊天入口里直接给 HiDreamClaw 下指令。

此外平台提到了一个叫 "OpenClaw" 的能力形态——它有独特的人格和长期记忆，与纯任务型的 HiDreamClaw 互为补充。HiDreamClaw 可以把 OpenClaw 一键部署到云端，适合需要长期陪伴和记忆型交互的使用场景。

### vivago R1 对话式短片创作

如果说 HiDreamClaw 面向日常批量创作，vivago R1 则面向单次完整作品交付。它支持对话式创作 5 分钟级完整短片，核心能力是 SkillHub 能力库的自动编排——你只需描述想要什么样的短片，R1 会自动拆解为分镜、配乐、字幕等环节并串联完成。R1 还开放了命令行接口，独立开发者可以通过命令行调用其完整能力，配合 HiDreamClaw 搭建自动化内容流水线。

### 适合谁用的几个典型场景

| 场景 | 推荐路径 |
|---|---|
| 宠物日常短视频 | 模板墙 → 宠物舞 / 萌宠类模板 |
| 老照片翻新动效 | 模板墙 → 老照片恢复类模板 → 选 Kling O1 |
| 5 分钟完整剧情短片 | vivago R1 → 对话式创作 → SkillHub 自动编排 |
| 产品演示视频 | 文生视频 → 选 vivago 2.0 → 竖屏 9:16 1080p |
| AI Podcast 口播视频 | Lip Sync 功能 → 头像照 + 录音 → 自动口型同步 |

最后提一个使用建议：如果你只需要某单一模型（比如只用 Kling），直接去该模型官方页面可能更直接。VIVAGO 的核心价值在于多模型聚合与 Agent 高阶编排，只用一个模型时它的优势体验不出来。
