## ✨ Mineradio 是什么：一款带粒子视觉的多音源播放器

Mineradio 是一款主打「私人视觉电台」概念的音乐播放器，核心特色在于把粒子星河视觉系统与传统音乐播放结合在一起——不放歌时界面是一片柔和流动的粒子银河，播放时又有歌词舞台、动态壁纸等视觉效果随之联动。播放器本身不托管音源，而是接入网易云音乐、QQ 音乐、酷狗、汽水等多个平台的账号，把你已有的歌单、收藏、播客内容统一收进一个界面里播放，强调「视觉」与「音源多接」两条主线并行。

支持的平台覆盖 Android、Windows 桌面和网页版三端，其中 Windows 桌面端功能最完整，是唯一能跑全量粒子视觉的一端——银河壁纸、动态壁纸、歌词舞台、桌面歌词全开也不卡顿。播放器的账号体系只负责接入音源平台（网易云、QQ 等），所有配置和缓存数据都存在本地设备上，没有自有云端账号，这一点在隐私敏感用户群体里口碑不错。

适用人群大致有三类：想把不同平台的歌单集中到一个播放器里的多平台用户、喜欢把播放器当成桌面装饰品的视觉党、以及对隐私存储有明确要求的开源爱好者。如果你只在单一平台听歌、对视觉效果不感兴趣，Mineradio 的核心价值可能发挥不出来；但如果你同时开着网易云和 QQ 的会员、又想给桌面加点动态效果，它就是现成的组合拳。

## 🔧 安装步骤与注意事项

Mineradio 的安装包分发渠道因平台而异，主流安装流程分为 Android 和 Windows 两端，安装前有几个要点值得提前确认。

**下载前核对**：官方下载页会同时挂出多个版本（稳定版、移植版、预发布版等），建议优先选稳定版；移植版通常来自社区贡献，会标注「仅供免费使用、不可收费售卖」的边界声明。安装包体积不大，但下载完成后最好核对一下文件大小与官方标注是否一致，避免在第三方渠道下到被篡改的版本。

**Android 端安装**：如果从官方渠道下载 APK，需要在系统设置里开启「未知来源应用安装」权限（不同厂商 ROM 里这个开关位置不同，通常在安全或隐私设置下）。打开下载好的 APK 文件，按提示点确认即可。首次安装完成后建议立即更新到应用内检测到的最新版本——软件内置了 GitHub Releases 更新检测，新版本会自动弹窗提醒。

**Windows 桌面端安装**：Windows 端提供的是压缩包形式，解压后直接运行主程序即可，不需要传统的安装向导。部分杀毒软件可能会对无签名的 exe 文件误报，这种情况下把解压目录加入杀毒软件的信任列表就能解决，不需要关闭实时防护。Windows 端解压路径建议选在非系统盘（比如 D 盘），方便后续直接更新覆盖。

> [!WARNING] 权限按需授予
> Mineradio 安装完成后首次启动会申请多项系统权限，但不是所有权限都必需。如果你不用天气电台功能，就不需要给位置权限；介意摄像头的话就用鼠标操作，网页版的摄像头权限只用于手势控制，不开启完全不影响核心播放功能。关闭对应权限只影响对应功能，不会导致播放器无法启动。

## 📖 使用入门：从首次启动到日常工作流

装好之后第一次打开，界面体验和传统播放器不太一样——值得花一两分钟把首屏和核心功能过一遍，后续使用会顺手很多。

### 首次启动与账号登录

**启动页与首屏导览**：点击应用图标后，先看到一块暗色底上有彩色光带流动的启动画面，中间是品牌标识和「PRIVATE VISUAL RADIO」字样，点击进入主界面。首屏默认是银河星河壁纸铺满整个界面，不放歌时是一片干净柔和的粒子星河，这是 Mineradio 区别于普通播放器的第一眼感受。顶部横排着搜索框和分享、主页、登录等入口按钮，中部是各功能入口卡片，底部固定播放控制条。首次启动通常会弹出公告弹窗，内容包括当前版本号和使用声明，看完确认即可。

**音源账号登录**：登录音源平台是解锁 Mineradio 核心能力的第一步——没登录也能播本地文件，但歌单同步、每日推荐、个性化内容都要账号才生效。网易云音乐是接入最完整的音源，推荐先从网易云扫码登录开始：打开播放器后点右上角的头像或登录按钮，在音源选择里选「网易云」，弹出扫码窗口后用网易云 App 扫码或在手机上确认登录。登录成功后会自动开始同步云端数据，包括收藏歌单、关注的播客、红心单曲。QQ 音乐、酷狗、汽水等其他音源也在同一登录弹窗里，接入范围各有不同。

> [!TIP] 核对同步结果
> 网易云登录后回到首页，「我的歌单」入口里应该能看到所有已导入的列表，「每日推荐」也会按你的账号开始生成。如果几秒内歌单没有加载出来，先检查网络，再退出重新扫码。会员歌曲能否播放取决于你账号本身的会员状态，播放器不做破解。

### Windows 桌面端的专属玩法

Windows 桌面版是功能最全的一端，把 Mineradio 融进日常桌面工作流是很多桌面用户选择它的主要原因。

**窗口控制与后台挂机**：标题栏提供完整的窗口控制按钮，可以最小化到任务栏或系统托盘，音乐不会中断。长时间后台播放的稳定性不错，挂一整天工作 BGM 是常规用法。需要临时遮挡时直接最小化到托盘图标，不占桌面空间。

**桌面歌词与右键歌单架**：写文档或写代码时可以开启桌面歌词功能，歌词窗口会置顶显示，全屏应用下也在屏幕边缘持续展示。右键托盘图标或播放窗口可以直接唤起 3D 歌单架，不用进菜单就能浏览和调整当前播放队列，切歌和改排序都很顺手。

**视觉全开的配置建议**：Windows 端是唯一能跑全量粒子视觉的桌面端，银河壁纸、动态壁纸、歌词舞台、桌面歌词全开也不重。但如果同时跑着大型开发环境或视频剪辑软件，建议把粒子的运动速度和光源强度调低一些，给 GPU 留余地；或者临时把壁纸从动态银河换成静态图片，视觉效果降一点但不影响播放。

**内置更新检测**：软件自带 GitHub Releases 更新检测，有新版本时会自动弹出提醒并提供一键下载入口，不需要手动去找最新版本号。

### 隐私与数据安全

Mineradio 在隐私设计上有几个值得单独说明的点，也是它在开源社区里口碑不错的原因：

**数据本地存储**：官方仓库的说明里明确写了「所有数据本地存储，不收集用户信息」。歌单缓存、视觉配置、音源平台的登录态都只存在你的设备本地，没有 Mineradio 自己的云端账号体系。播放器里的「账号」指的是网易云、QQ 音乐等音源平台的账号，数据归属还是对应平台。

**权限清单与用途透明**：软件申请的每一项权限都有明确用途对应——位置权限只用于天气电台获取所在城市的实时天气，存储权限用于扫描本地音频文件（MP3、FLAC 等），网络权限用于访问音源平台接口和天气服务，通知权限用于后台播放时显示媒体控制通知，摄像头权限仅在网页版开启手势控制时才调用。这些权限都可以在系统设置里逐项关闭，关闭只影响对应功能。

**开源可审计**：源代码托管在 GitHub 上（GPL-3.0 协议），第三方安全扫描渠道也对安装包做过 clamav、APKiD、Quark-Engine 等多引擎扫描，未报威胁。对隐私敏感的用户来说，开源意味着任何人都可以审查代码里的数据处理逻辑——这是闭源软件给不了的透明度。

### 一个完整的桌面工作流示例

早起到工位打开 Mineradio，用天气电台按今日天气起一个播放队列，然后最小化到托盘挂后台，同时开着桌面歌词挂屏幕边缘。午休时切到每日推荐挖掘新歌，晚上睡前切到关注的播客节目，设一个睡眠定时自动停止。一整天只在开头点一次启动，后面完全不需要碰播放器界面——后台播放稳定性和桌面歌词的常驻效果让它真的能融进日常工作流。
