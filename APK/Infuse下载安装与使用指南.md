## ✨ Infuse 是什么

Infuse 是由 Firecore 工作室开发的跨平台视频播放器，运行在 Apple TV、iPhone、iPad 和 Mac 上。它的定位很明确——把一堆乱七八糟命名的 MKV、蓝光原盘、ISO 文件，变成像 Netflix 一样漂亮的海报墙，点开就能看、字幕自动匹配、播放历史自动同步。

跟 VLC、nPlayer 这类"功能优先"的播放器不同，Infuse 走的是**体验优先**的路线。支持的编码和格式够全是底线，真正拉开差距的是自动海报墙、Trakt 看片记录同步、跨设备续看、以及 Plex/Emby/Jellyfin 直连这些生态级功能。如果你家里有 NAS、或者已经在用 Plex 搭了媒体服务器，Infuse 是最省心的客户端选择。

它适合什么人？有 Apple TV 想把 NAS 里的电影海报化的、多设备追剧需要同步进度的、手里攒了一堆蓝光原盘想原盘播放的、或者只是嫌 VLC 界面太丑想要一个好看又好用的播放器。免费版就已经覆盖了绝大多数日常使用场景，Pro 订阅则解锁杜比全景声、DTS-HD MA 无损音频、4K HDR 原盘播放这些发烧级功能。

## 🔧 安装步骤

Infuse 的安装在苹果生态里算是最省心的那一类，全程走 App Store 分发，没有证书信任、没有 IPA 侧载那一套麻烦事。

**iPhone / iPad / Apple TV 端**：

1. 打开 App Store，搜索 "Infuse"
2. 确认开发者是 Firecore，点击获取
3. Apple TV 上第一次打开时，系统会弹一个权限请求问要不要用 iCloud 同步，选允许就行（不同步也能正常用）

**Mac 端**：

同样走 Mac App Store 下载。Mac 上 Infuse 多了一个菜单栏入口，可以快速打开最近播放、切换媒体库。

> [!TIP]
> 安装完成后先别急着订阅 Pro。免费版已经支持基础视频解码、AAC/AC3/MP3 音频、SRT 字幕和自动海报墙，把最常用的场景先跑通再决定要不要升级。Pro 的核心价值在 4K HDR + 杜比全景声原盘播放和 Trakt 完整同步，如果你目前只看 1080p 在线转码资源，免费版完全够用。

**版本核对**：Infuse 设置 → 关于，可以看到当前版本号。建议在更新大型版本（比如 7.x → 8.x）前先等社区反馈，Firecore 偶尔会在大版本更新里引入一些需要重启或重新授权的变更。

## 📖 使用入门

Infuse 的使用体验可以分成三块：**媒体库与海报墙**、**同步与跨设备**、**进阶配置**。下面基于实际使用中最常遇到的场景逐一展开。

### 媒体库：让一堆文件变成海报墙

Infuse 打开后的首页就是海报墙，但前提是你得先让它看到你的视频文件。支持的来源包括本地相册、SMB/NAS 共享、Plex/Emby/Jellyfin 直连，以及 URL 直播流。对于大多数家庭用户，SMB 连 NAS 是最常见的起点——进入设置 → 文件来源 → 添加 SMB 共享，填好 NAS 的 IP、用户名密码就能扫描。

文件加进来之后，Infuse 会自动从 TMDB（一个全球社区维护的影视数据库）拉取元数据。这个过程大致四步：解析文件名提取标题和年份 → 在 TMDB 搜索最匹配的条目 → 下载海报、剧情、演员、评分 → 缓存到本地。匹配成功的话，几十秒之内海报墙就会从一堆文件名变成整整齐齐的 Netflix 风格卡片。

**匹配失败是新手最常遇到的问题**。TMDB 匹配靠文件名里的信息，如果你有一堆叫 "电影1.mkv"、"xxx.mp4" 的文件，Infuse 无能为力。解决办法有两个：改文件名为规范格式（比如 `盗梦空间 (2010) Inception.mkv`），或者手动编辑元数据——长按视频图标 → 编辑，直接输入标题、上传自己的海报图。

> [!NOTE]
> TMDB 默认跟随系统语言请求中文条目，但中文覆盖不全时 Infuse 会自动回退到英文。可以在设置 → 库 → 语言里手动指定，不过实际上保持"跟随系统"体验最好。

### 海报不对或没有？自己覆盖

TMDB 不是万能的。国产片刚上映时 TMDB 还没中文条目、老电影的英文海报被抓成中文条目、或者你想放自己收藏的粉丝海报——这些情况都需要手动覆盖。

最简单的方式是**文件夹放本地文件**。把你的海报图命名为 `poster.jpg` 放在视频文件同目录，Infuse 扫描时会优先使用本地文件。如果想更精细控制剧情、评分、演员这些字段，可以写一个 `movie.nfo`（标准 XML 格式）放在同目录。Infuse 还支持 `fanart.jpg`（详情页背景图）和 `landscape.jpg`（横版横幅），海报墙效果会更完整。

如果你不想动文件夹结构，也可以在 Infuse 界面里直接编辑：iPhone/iPad 长按 → 编辑元数据；Apple TV 长按点击板 → 编辑；Mac 右键 → 编辑元数据。可以改标题、年份、类型标签、评分、剧情简介、演员列表，也可以从相册直接选图片当海报。

### Trakt：跨设备看片记录自动同步

Trakt 是一个影视观看记录社区，Infuse 原生集成了它。多设备用户最需要这个功能——iPhone 上看了一半，切 Apple TV 打开同一集自动续上，两边的观看历史、评分、看过标记还会自动汇总到 Trakt 账户里。

**连接步骤**在三端都是统一的：设置 → 同步 → Trakt → 连接 → 登录 Trakt 账号授权。Infuse 用的是标准 OAuth 流程，不会存你的 Trakt 密码，只存一个 Token。Trakt 账号本身免费注册，免费版就能用完整的同步功能，Pro 订阅不额外加东西。

同步的内容覆盖了播放历史、看过标记、评分、播放进度和在看列表。但有一个容易踩的坑：如果你用直连模式连接 Plex/Emby/Jellyfin，观看历史的同步链会变成 `Infuse → 媒体服务器 → Trakt`，而 Trakt → Infuse 这一路不会反写观看历史标记。所以想标记看过请在 Infuse 里操作，这样服务器和 Trakt 两边都能同步。直接在 Trakt 网页上标记看过，不会回到 Infuse 的本地库。

> [!WARNING]
> Trakt 免费账号有 API 调用限额。如果家里同时很多设备在同步，可能会触发限流，表现为某些历史提交失败。限流是小时级别的，等几个小时自动恢复，或者升级 Trakt VIP（$10/年）提高限额。

### 格式支持：哪些能播、哪些需要 Pro

Infuse 号称"全格式播放器"，实际表现也对得起这个说法。视频容器覆盖 MP4/MOV/M4V、MKV/AVI/WEBM、蓝光原盘 BDMV、DVD 原盘 VIDEO_TS、ISO/IMG、直播流 TS/M2TS 等；编码覆盖 H.264/H.265/H.266、VP8/VP9/AV1、DIVX/VC-1、MPEG-1/2/4 等。音频侧支持最多 7.1 声道、24 位、48kHz 无损输出，包括杜比全景声、Dolby TrueHD、DTS-HD MA、FLAC 多声道等。字幕格式同样是全覆盖——SRT/VTT/SUB 这类文本字幕支持 AirPlay 和 Google Cast，PGS/VOBSUB 这类图形字幕也能正常渲染。

免费版和 Pro 版的差异集中在音频解码深度：

| 功能 | 免费版 | Pro 版 |
|------|--------|--------|
| 基础视频解码 | ✅ | ✅ |
| AAC/AC3/MP3 | ✅ | ✅ |
| SRT 字幕 | ✅ | ✅ |
| DTS-HD MA 无损 | ❌ | ✅ |
| 杜比全景声 | ❌ | ✅ |
| 空间音频 | ❌ | ✅ |
| 4K HDR 原盘播放 | 有限制 | ✅ 完整支持 |

如果你日常播放 4K HDR + 杜比全景声的蓝光原盘，Pro 才能发挥全部音质；如果只是看 1080p 在线转码或普通 MP4，免费版完全够用。

### 文件来源：直连媒体服务器 vs SMB

Infuse 连媒体服务器有两种模式：**直连模式**和**SMB 文件浏览模式**。选哪种取决于你想不想让媒体服务器帮你管元数据。

直连模式下，Infuse 直接使用 Plex/Emby/Jellyfin 的元数据、海报和播放历史，不走自己的 TMDB 抓取，也不读本地 NFO 文件。好处是你只需要在服务器端维护一份元数据，所有客户端保持一致；坏处是 TMDB 匹配失败时，想自定义海报或剧情就得去服务器上操作。

SMB 模式下，Infuse 自己扫描文件、自己从 TMDB 拉元数据、自己缓存。好处是独立灵活，可以在 Infuse 界面里直接改任何视频的元数据；坏处是如果你同时用 Plex 客户端，两边元数据可能不一致。

家庭用户的推荐路径：如果已经搭了 Plex/Emby/Jellyfin 并在用，优先直连模式，减少重复维护；如果只是想简单看 NAS 上的电影，SMB 模式就够了，海报墙自动生成也很方便。
