## ✨ httpCanary 是什么

httpCanary 是 Android 平台上一款原生的网络抓包与分析工具，它的工作原理是在手机本地建立 VPN 隧道，以中间人代理的方式捕获设备上所有应用的 HTTP、HTTPS、WebSocket、TCP、UDP 流量，并提供查看、过滤、修改、重放等完整的调试能力。和电脑端的 Charles、Fiddler 以及 iOS 上需要额外配置的抓包工具不同，httpCanary 完全在手机端原生运行，界面为触屏操作深度优化，绝大多数功能开箱即用，**不需要 Root 权限**。

这款工具在开发者和测试工程师圈子里应用最广——Android 开发者用它调试 Rest API、定位网络编程 bug、分析接口性能；测试工程师编辑响应数据模拟各种边界条件（比如把库存字段改成 0、把状态码改成 500），验证客户端对异常情况的处理是否健壮；网络安全工程师用它检测 App 是否传输敏感数据、验证 API 通信是否安全。它的价值在于把原本需要电脑配合才能完成的抓包调试，压缩到了手机这一台设备上，而且不需要任何 Root 权限就能跑起来。

> [!NOTE]
> httpCanary 的开发团队后来推出了跨平台的 Reqable，定位是 Fiddler + Charles + Postman 的合体，覆盖 Windows、macOS、iOS、Android 四大平台。httpCanary 目前仍在独立维护更新，最新版本 v4.6.8 发布于 2026 年 3 月。如果你只需要 Android 抓包功能，httpCanary 完全够用；如果需要跨平台调试和 API 测试一体化，可以考虑迁移到 Reqable。

httpCanary 的设计哲学是「手机端原生体验」——数据以手机本地存储为主，不需要服务器、不需要电脑端配合，长按即快捷菜单、悬浮窗随时唤起。不过它也有局限：部分使用 SSL Pinning 的应用会检测到证书异常并拒绝连接，这种情况下需要额外的绕过手段。

## 🔧 安装步骤

httpCanary 是 Android 独占应用，安装过程和普通 APK 没有本质区别，但有几个关键节点需要注意。

### 1. 允许未知来源安装

如果是从官方下载页获取的 APK 文件而非 Google Play，需要先让手机允许安装未知来源的应用：

1. 进入手机「设置 → 安全」或「设置 → 隐私」（不同品牌路径略有差异）
2. 找到「安装未知应用」或「允许未知来源」选项
3. 对你使用的文件管理器或浏览器开启权限

> [!WARNING]
> 网络上流传着各种「破解版」「蓝鸟版」「汉化版」，这些都不是官方发布，可能植入恶意代码。建议只从官方下载页或 Google Play 获取安装包。

### 2. 安装 APK

1. 打开文件管理器，找到下载好的 httpCanary APK 文件
2. 点击文件，系统会弹出安装确认窗口
3. 确认应用权限列表（主要是网络访问和 VPN 相关权限），点击安装
4. 等待安装完成

### 3. 核对版本号

首次启动应用后，进入「设置 → 关于」页面，确认版本号与下载页标注的最新版一致。如果发现版本号落后，建议重新下载最新的安装包。

### 4. 免费版与高级版

httpCanary 有两个版本，高级版包名带 premium 后缀（`com.guoshi.httpcanary.premium`），Google Play 上有单独的付费页面。功能对比如下：

| 功能 | 免费版 | 高级版 |
| --- | --- | --- |
| HTTP/HTTPS 抓包 | ✅ | ✅ |
| WebSocket / TCP / UDP | ✅ | ✅ |
| CA 证书解密 | ✅ | ✅ |
| 基础数据查看（Raw/Text/Header） | ✅ | ✅ |
| JSON 预览 | ✅ | ✅ |
| **静态注入** | ❌ | ✅ |
| **动态注入** | ❌ | ✅ |
| **断点调试** | ❌ | ✅ |
| **请求重放 / 编辑重发 / 批量重发** | ❌ | ✅ |
| **cURL 转换** | ❌ | ✅ |
| **全部插件** | 部分 | 全部 |
| 请求收藏与备注 | ✅ | ✅ |
| 搜索和过滤 | ✅ | ✅ |
| 主题切换 | ✅ | ✅ |
| 广告 | 有 | 无 |

免费版已经覆盖了绝大多数场景的基础需求——查看 HTTP 和 HTTPS 请求的完整内容、按应用或 Host 筛选请求、查看 JSON/图片/音频/视频等多种数据格式、收藏重要请求。对于「我只想看看某个接口传了什么参数、返回了什么数据」这类场景，免费版完全够用。如果是专业开发者、测试工程师或安全研究人员，高级版的静态注入、动态注入、断点调试、请求重放等能力会大幅提升工作效率。

## 📖 使用入门

### 启动抓包与 VPN 授权

打开 httpCanary 后，主界面是一张纸飞机图标的大按钮——这就是启动抓包的入口。点击纸飞机，Android 系统会弹出 VPN 连接授权提示：「httpCanary 请求建立 VPN 连接以监控所有网络流量」。这是整个工具最核心的机制，**必须确认授权**，否则无法捕获任何流量。

授权后，屏幕顶部状态栏会出现 VPN 小钥匙图标，表示抓包正在运行。此时手机上所有应用的网络请求都会经过 httpCanary 的本地隧道，被实时捕获并记录。再次点击纸飞机按钮即可停止本轮抓包。

### HTTPS 解密与 CA 证书

HTTP 请求可以直接看到明文内容，但 HTTPS 需要额外的解密步骤。httpCanary 安装时会引导你将自签名 CA 证书安装到系统的「用户证书」目录，之后它就能以中间人代理的方式对 HTTPS 流量进行解密和重新加密，让你看到明文的请求体和响应体。

> [!TIP]
> Android 7.0+ 默认不信任用户级 CA 证书，部分应用会检测证书异常。如果遇到 HTTPS 请求显示「解密失败」或「证书不被信任」，这是应用使用了 SSL Pinning 机制，需要额外的绕过处理（通常需要 Root 后将证书安装到系统证书目录）。

### 会话管理

每次点击纸飞机启动抓包，httpCanary 都会自动创建一个新的会话——可以理解为「从启动到停止这一段时间内所有抓到的请求」。主界面左上角的「三」菜单按钮可以打开侧边栏，找到会话管理入口，在这里能看到所有历史会话的列表，每个会话显示：会话名称（默认自动生成，可自定义）、抓包的时间范围、包含的请求总数、是否有新的未查看请求。

为了方便回忆每次抓包的目的，建议在重要会话结束后给它起一个有意义的名字——比如「首页加载性能测试」「登录接口调通」「支付流程模拟」等。默认情况下所有会话数据都会一直保存在本地存储中，时间长了会占用不少空间，在设置中可以配置自动清理策略（会话保留天数、单条会话请求数量上限、本地存储总大小上限），超过上限的最旧会话会被自动清理。

重要的抓包数据可以导出分享：在会话列表或请求详情页找到导出选项，选择 `.hcy` 格式（httpCanary 专属格式），导出文件会保存在 `HttpCanary/download/` 目录下。对方用 httpCanary 打开后可以看到完整的抓包数据。

### 请求查看与 Header 分析

点击某个会话后进入请求列表，按时间倒序展示所有捕获到的请求。每个请求卡片显示请求方法（GET/POST 等）、目标域名、路径、响应状态码、请求体/响应体大小。点击任意一条请求进入详情页，可以看到几个标签区域：

- **Header 区域**：包含请求头和响应头，支持表格视图和原始视图两种展示方式
- **Body 区域**：请求体和响应体，JSON 数据自动格式化高亮
- **Preview 区域**：图片、音频、视频等富媒体的直接预览

HTTP Header 承载了比请求体更多的元信息，很多调试场景中问题的根源就在 Header 里。请求头需要重点关注的字段：`Authorization` 和 `Cookie`——这两个字段决定了请求能不能通过身份验证，如果你抓的某个接口一直返回 401 或 403，先检查这两个字段。响应头需要重点关注的字段：`Set-Cookie`（登录后服务端通过这个字段下发 session）、`Content-Type`（决定了响应体格式和编码）、`Cache-Control`（缓存策略设置）。

### 用 Header 解决实际问题

- **接口返回 302 重定向但客户端没有跳转**：检查响应头里的 `Location` 字段——可能是一个内网地址或已经失效的 URL。同时检查请求头里的 `User-Agent`——有些服务端会根据 UA 返回不同的重定向目标。
- **请求参数正确但服务端返回「请先登录」**：看请求头里的 `Cookie` 或 `Authorization` 字段——要么根本没带上（客户端漏发了），要么值已经过期了。
- **服务端返回的 JSON 客户端解析失败**：先看响应头的 `Content-Type`——是不是正确的 `application/json`。如果是 `text/html`，说明服务端返回的其实是一个 HTML 错误页面。
- **客户端总是拿到缓存数据**：检查响应头的 `Cache-Control`——如果有 `max-age=xxx` 或者 `no-cache` 标记，客户端可能在走本地缓存而不是发真实请求。

### 过滤与搜索

当抓包量特别大的时候，直接在请求列表里找目标请求会很痛苦。httpCanary 提供了多层过滤：按应用筛选（只看某个 App 产生的请求）、按 Host 域名筛选、按请求方法筛选、按状态码筛选，还可以用关键词在 URL 和请求体里全文搜索。组合使用这些过滤条件，可以从成百上千条请求中快速定位到你关心的那几条。

### 高级功能概览（高级版）

免费版已经足够覆盖日常调试需求，高级版解锁的核心能力集中在「修改」和「效率」两个维度：

- **静态注入**：预设规则自动修改响应，测试客户端对各种数据的处理
- **动态注入**：实时拦截手动改包，精确调试单个请求
- **断点调试**：暂停在特定请求处，像调试器一样逐步观察
- **请求重放**：把历史请求重新发送，不需要重新走一遍操作流程
- **cURL 转换**：请求一键转成 cURL 命令，方便在电脑端复现

如果你是专业开发者或测试工程师，这些功能会让调试效率上一个台阶。但如果你只是偶尔看看接口传了什么参数，免费版完全够用。
