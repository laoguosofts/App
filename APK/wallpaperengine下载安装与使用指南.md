## ✨ Wallpaper Engine 是什么

Wallpaper Engine 是一款让 Windows 桌面"活起来"的动态壁纸引擎。它不像传统静态壁纸那样只是一张图，而是能播放视频、3D 场景、Web 动画、交互脚本等多种形式的实时渲染内容。简单来说，它在桌面后台跑一个轻量渲染器，把壁纸从"画布"升级成了"窗口"。

引擎本身不直接存放壁纸资源，壁纸的来源主要有两个途径：一是 Steam Workshop 社区订阅，全球用户在上面分享制作的壁纸作品；二是用户自己的本地媒体文件——MP4 视频、WebM 动画、GIF、乃至网页都能一键导入并自动适配成壁纸。引擎还自带一个壁纸编辑器，支持在现有素材基础上做二次创作，比如叠加粒子效果、调整参数驱动的动态响应。

从硬件消耗来看，Wallpaper Engine 的设计目标就是"不碍事"。视频壁纸走 GPU 硬解码，场景壁纸用显卡加速渲染，空闲时会自动暂停或降帧。只要不是特别夸张的 4K HEVC + 多屏组合，日常办公时几乎感知不到它的存在。这也正是它能长期驻留后台而不被用户吐槽的核心原因。

除了 PC 端，引擎还配套了一个 Android 伴侣应用——可以在 PC 和手机之间通过局域网无线传输壁纸，把电脑上订阅或自制的动态壁纸直接推送到手机桌面。一条完整的工作流大致是：在 PC 端浏览和挑选壁纸 → 无线传给手机 → 手机端应用到桌面。

适合哪些人？如果你厌倦了看腻的静态桌面图、想让桌面有点仪式感但又不想装重量级美化套件，或者正在寻找能替代 RainWallpaper、PUSH Wallpaper 等同类方案的更稳定选择，Wallpaper Engine 值得尝试。

## 🔧 安装步骤

Wallpaper Engine 的主程序是通过 Steam 分发的，所以安装流程的第一步是确保 Steam 客户端已经就绪。

### PC 端安装

1. 打开 Steam 客户端，登录你的账号
2. 在商店搜索框输入 **Wallpaper Engine**，定位到开发者为 Wallpaper Engine 的那一项
3. 购买后点击安装，Steam 会自动下载并解压文件（体积约 1~2GB，取决于下载的壁纸资源量）
4. 安装完成后，首次启动会弹出简短的引导——选择语言、确认视频编解码器支持情况

> [!TIP]
> Windows 10 / 11 默认不内置 H.265 (HEVC) 硬解码。如果你的显卡支持 HEVC 硬解（GTX 10 系及以上、AMD RX 5000 系及以上、Intel 核显 11 代及以上），建议提前在 Microsoft Store 搜索安装「HEVC 视频扩展」，否则后续播放 HEVC 编码的视频壁纸时会出现黑屏或只有声音没画面。

### Android 伴侣应用安装

1. 在 Google Play 搜索 **Wallpaper Engine**（开发者同样是 Wallpaper Engine）
2. 点击安装，约 50MB
3. 首次启动时授予存储和后台运行权限，否则无线传输后的壁纸可能无法正确应用

### 安装后的核对

- 启动主程序，主界面能正常加载预览缩略图 → 引擎正常
- 点击右上角设置 → 视频标签 → 选择一段 HEVC 壁纸测试播放 → 能流畅解码说明编解码器就绪
- 右下角 Steam 状态栏显示在线 → 后续订阅 Workshop 壁纸才能正常同步

## 📖 使用入门

### 浏览与订阅壁纸

Wallpaper Engine 的壁纸生态高度依赖 Steam Workshop。打开主程序后，左侧边栏有「已订阅」「收藏」「本地」三个分类，点击底部的「浏览」按钮会跳转到 Workshop 页面，支持按分类、评分、热度、时间排序。找到喜欢的壁纸后点击「订阅」，Steam 会在后台自动下载，回到主程序稍等几秒就能在「已订阅」列表里看到新壁纸出现。

> [!NOTE]
> 订阅数量过多会拖慢启动速度——几百款订阅在引擎启动时需要逐一校验元数据和缩略图。建议保持在二十到五十款之间，定期清理不再使用的订阅。

### 视频壁纸卡顿排查

视频壁纸理论上走 GPU 硬解码，消耗应该很低，但实际使用中卡顿时有发生。排查可以按"五步走"的顺序来：

**第一步，先区分是壁纸的问题还是系统的问题**。用系统自带的「电影和电视」或 VLC 播放器直接打开该视频文件——如果播放器也卡，说明视频本身码率太高或编码不支持；如果播放器流畅但 Wallpaper Engine 里卡，问题在引擎配置或显卡驱动。

**第二步，切换视频解码框架**。Wallpaper Engine 支持 Media Foundation（Windows 默认，兼容性好）、DirectShow（旧式框架，某些机器更稳定）、FFmpeg（开源解码器，格式支持最全）三种框架。在设置中切换后重启引擎测试，经常能解决某类特定编码的卡顿。

**第三步，更新显卡驱动**。视频解码依赖显卡硬件加速，驱动版本过旧是隐形卡顿元凶。Nvidia 用户可以用 GeForce Experience 自动更新，AMD 用户用 Adrenalin 软件，Intel 核显用 Intel Driver and Support Assistant。更新时建议勾选「清洁安装」（Clean Install），清除旧驱动残留的配置错误。

**第四步，降低视频壁纸参数**。如果源视频是 4K / HEVC / 高码率，可以用 HandBrake 压缩到 1080p / H.264，码率控制在 5~15 Mbps，帧率锁定 30fps。压缩后的视频体积更小、解码更快，动态壁纸场景下画质损失几乎察觉不到。

**第五步，检查 VSync**。如果壁纸画面出现上下半部分错位的撕裂感，说明显卡垂直同步没开启。在 Wallpaper Engine 设置中开启 VSync，或到显卡控制面板强制开启即可。

### 视频编解码器问题

另一个高频问题是视频壁纸只有声音没画面，或颜色错乱。这本质上也是编解码器缺失或不匹配导致的。

先看症状区分：黑屏有声音 → 视频轨编解码器不支持；有画面但颜色错乱 → 色空间或位深问题；视频完全无法识别 → 文件格式不被引擎底层支持。

Wallpaper Engine 底层使用 Media Foundation + FFmpeg 解码，主流格式支持情况如下：

| 容器格式 | 推荐视频编码 | 备注 |
| --- | --- | --- |
| .mp4 | H.264 (AVC) | 最兼容，首选 |
| .mp4 | H.265 (HEVC) | 画质好但硬解码需硬件支持 |
| .mkv | H.264 / H.265 | 需装 Media Foundation 扩展 |
| .webm | VP8 / VP9 | 原生支持 |

最常见的缺失是 H.265 硬解码。解决方案有两种：一是 Microsoft Store 里的「HEVC 视频扩展」，按机器配置自动判断条件免费或付费；二是 K-Lite Mega Codec Pack，免费开源，安装时勾选 Windows Media Foundation codecs。

如果某款视频格式实在奇葩、找遍编解码器都不行，还有一个兜底方案：用 HandBrake 转码成 H.264 / MP4，再用新文件重新创建视频壁纸。

> [!WARNING]
> 有些用户以为下载的是视频壁纸，实际是 Web 壁纸（嵌入式浏览器渲染）。Web 壁纸的性能消耗远高于视频壁纸，在壁纸缩略图下方确认类型标签再决定要不要用。

### PC 到 Android 无线传输

Android 伴侣应用的核心玩法就是无线传输壁纸。前提条件很简单：PC 和手机在同一局域网、PC 端引擎保持运行、手机上伴侣应用打开。

操作分三步：

1. **手机上开启接收**：打开伴侣应用 → 点击底部「传输」标签 → 屏幕上显示一个 6 位 PIN 码，保持该页面打开
2. **PC 端发起传输**：在主界面底部找到传输按钮（手机图标） → 客户端自动扫描局域网设备 → 找到手机后输入 PIN 码 → 配对成功，选中要传输的壁纸点击发送
3. **传输后自动应用**：第一张收到的壁纸会自动设为手机桌面背景，后续传输的进入手机壁纸库等待手动选择

传输速度取决于局域网带宽，一张 10MB 左右的视频壁纸约 5~10 秒。可以一次选多张壁纸批量传。

传输失败时可以对照下表排查：

| 现象 | 可能原因 | 解决方法 |
| --- | --- | --- |
| PC 扫描不到手机 | 不在同一 Wi-Fi / Wi-Fi 隔离 | 确认两台设备连同一个 SSID，关闭路由器的 AP 隔离 |
| PIN 码无效 | 网络延迟导致码过期 | 关闭传输页重新打开，生成新码 |
| 传输中断 | Wi-Fi 信号不好 | 靠近路由器或切换到 5GHz 频段 |
| 传输后壁纸打不开 | 手机版本太旧 | 检查 Android 系统版本是否 ≥ 8.0 |

目前只支持 PC → Android 单向传输，反向还不支持。

### 启动崩溃与闪退

如果引擎双击后瞬间消失或卡死不加载，也有一套分层排查方法。

**启动时闪退**的常见原因：
- Steam 文件损坏：Steam 中右键 Wallpaper Engine → 属性 → 已安装文件 → 验证完整性
- 缓存文件夹有问题：关闭引擎后删除 `%APPDATA%\WallpaperEngine\Caches\` 下所有内容
- 插件或多屏配置冲突：按住 Shift 同时双击启动，进入安全模式跳过所有第三方插件和上次的多屏配置。安全模式能启动 → 问题在插件或配置，逐个排查

**启动后卡死不加载**的常见原因：
- Steam 同步卡住：断开网络后启动，能启动就说明是 Workshop 同步问题，可以在设置里禁用自动更新
- 订阅数量过多：几百款订阅导致启动扫描时间过长，清理不需要的订阅
- 某款壁纸文件损坏：安全模式启动后不选任何壁纸直接运行，不卡了就是某张壁纸的问题

如果启动时弹出带错误代码的对话框：

| 代码含义 | 触发原因 | 解决方法 |
| --- | --- | --- |
| DirectX 初始化失败 | 显卡驱动 / DirectX 版本问题 | 更新驱动 + 运行 DirectX Repair 工具 |
| Steam API 连接失败 | Steam 客户端没登录 / 离线 | 确保 Steam 在线登录状态 |
| 磁盘空间不足 | 没足够空间解压缩 | 清理磁盘，留出 2GB+ |

终极方案是完全重装：Steam 中卸载（订阅列表保留在云端）→ 手动删除 `%APPDATA%\WallpaperEngine\` 和 `%LOCALAPPDATA%\WallpaperEngine\` → 重启电脑 → 重新安装 → 首次从安全模式进入。完全重装不会丢失订阅（云端），但会丢失本地壁纸文件和自定义设置。
