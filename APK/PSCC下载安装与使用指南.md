## ✨ Photoshop CC 是什么

Photoshop CC（简称 PSCC）是 Adobe 公司开发的专业级图像处理软件，自 1990 年发布以来已经成为设计行业的标准工具。它提供了图层系统、非破坏性编辑、智能对象、生成式填充等一整套从基础修图到高级合成的工作流能力，覆盖从摄影师后期修片、UI 设计师出图标、插画师数位绘画到电商运营做 Banner 等几乎所有视觉创作场景。

CC 版本的核心优势在于云端同步和 Adobe Creative Cloud 生态联动——在多设备间保持设置同步、与 Illustrator / After Effects / Lightroom 无缝协作、字体和素材库随时调用。2024 版本进一步集成了 AI 驱动的生成式填充功能，可以用自然语言描述快速替换画面中的元素。

PSCC 主要面向 Windows 和 macOS 桌面平台，专业级功能完整，学习曲线较陡，但熟练后效率极高。业余爱好者也能用它完成日常的图片裁剪、调色和简单合成，只是需要先适应它的非破坏性图层工作方式。

## 🔧 安装步骤与注意事项

### 系统前置检查

在下载安装之前，先确认电脑是否跑得动 PSCC。Adobe 官方给出的最低要求是 Windows 10 64 位或 macOS 11 Big Sur 以上，处理器至少 Intel i3 级别或 Apple M1，内存 8GB 起，推荐 16GB 及以上。显卡驱动必须是最新稳定版，特别是 NVIDIA 显卡，建议安装 Studio Driver 而非 Game Ready 驱动，对创作者场景做了专门优化。

> [!TIP]
> 正式下载前先核对两个细节：安装包大小是否与官网声明一致（PSCC 安装包通常在 2GB 以上），下载渠道是否是官方推荐的 Creative Cloud 或可信的镜像源，避免误下带捆绑的第三方修改版。

### Windows 安装流程

1. 下载完成后双击安装包中的 `Set-up.exe`，安装器会弹出语言选择窗口，默认跟随系统语言
2. 选择安装路径，建议放在 SSD 且系统盘之外的盘符（例如 `D:\Adobe\Photoshop`），留出至少 10GB 空余空间
3. 安装器会自动检测并安装 Creative Cloud 桌面端，如果之前已经装过会跳过这一步
4. 等待进度条走完，最后点击"完成"即可启动

安装完成后首次启动会弹出登录界面，使用 Adobe ID 登录后才能使用。如果系统自带杀毒软件对安装路径做了实时防护，可能会导致安装卡顿，可以临时关闭杀毒再装。

### macOs 安装流程

Mac 用户下载的是 `.dmg` 镜像文件，双击打开后把 Photoshop 图标拖进 Applications 文件夹即可。首次启动时 macOS 可能弹出安全提示，到"系统设置 > 隐私与安全性"里点"仍要打开"放行。Apple Silicon（M1/M2/M3）芯片的 Mac 原生支持 PSCC，无需 Rosetta 转译，性能比 Intel Mac 更优。

### 安装后的快速验证

启动 PSCC 后新建一个 1000×1000 像素的文档，用画笔工具画几笔，再用 `Ctrl+Shift+Alt+E`（Mac: `Cmd+Shift+Option+E`）合并可见图层。如果这些操作都正常响应，说明安装没问题。再打开"帮助 > 诊断 GPU"，确认显卡加速已启用。

## 📖 上手使用与进阶技巧

### 图层系统：PSCC 的灵魂

图层是 PSCC 区别于传统修图软件的核心设计。每一张 PSD 文件都像一叠透明的胶片，每张胶片可以独立编辑而不影响其他层。常见的图层类型有：

- **背景层**：最底部的锁图层，代表原图。双击可以解锁变成普通图层
- **像素图层**：最基础的类型，画笔、填充、滤镜都作用在像素上
- **调整图层**：非破坏性调色工具，曲线、色阶、色相饱和度都以调整图层形式叠加，删掉或隐藏就能还原
- **智能对象**：把多个图层或外部文件打包成一个单元，等比缩放不失真，双击可以进入内部编辑
- **文字图层**：输入文字自动生成，支持字体、大小、颜色、样式调整

> [!NOTE]
> 保持图层整洁是高效工作的基础。养成习惯：每做一组相关操作就放进一个图层组，命名用中文加序号（例如"01-人物主体"），长期积累下来几百层的大文件也能快速找到目标。

### 混合模式：让图层叠加出不同效果

混合模式决定了当前图层的像素如何与下方图层计算合成。默认是"正常"，完全覆盖下方。改变模式后画面会呈现截然不同的质感。

常用模式可以按效果分组：

| 分组 | 代表模式 | 适用场景 |
| --- | --- | --- |
| 变暗组 | 正片叠底、颜色加深 | 阴影叠加、给浅色区域加深色 |
| 变亮组 | 滤色、颜色减淡 | 光效叠加、火光光斑提亮 |
| 对比组 | 叠加、柔光、差值 | 提升画面对比度、营造反色风格 |
| 色彩组 | 颜色、饱和度、明度 | 给黑白照片上色、单独调整色调 |

实战中不用记公式——在图层面板顶部的混合模式下拉菜单里滚动就能实时预览效果。配合不透明度一起调比 100% 更可控，比如"正片叠底 + 50% 不透明度"是最常用的阴影叠加组合。按住 `Shift + + / -` 可以在当前模式组内快速循环切换。

### 暂存盘已满：四种清理方法 + 永久预防

PSCC 用暂存盘（Scratch Disk）来存放历史记录、剪贴板内容和临时文件，默认占用 C 盘空间。当 C 盘快满或历史记录堆积过多时就会弹出"暂存盘已满"警告，轻则卡顿重则无法保存。

紧急情况下四步立即可用：

1. **清空剪贴板**：编辑 > 清除 > 剪贴板，大图复制过之后这一步效果最明显
2. **清空历史记录**：历史记录面板右上角菜单 → 清除历史记录，默认 50 步每一步都占内存
3. **关闭不用的文档**：每个打开的 PSD 都在消耗暂存盘
4. **重启 PSCC**：最直接有效，所有临时数据会被清空

长期预防方案：首选项 > 性能 > 暂存盘，勾选一个至少有 50GB 空余的 SSD 盘符作为第二暂存盘，PSCC 会自动并行使用多个暂存盘。同时把历史记录状态从默认 50 降到 20~30，日常工作中很少会撤销到 40 步之前。

> [!WARNING]
> C 盘空间不足是暂存盘问题的最常见根因。定期清理回收站、运行 `%temp%` 清空临时文件、把大软件和素材移到其他盘，比加内存还立竿见影。效率指示器长期低于 100% 说明 PSCC 一直在用暂存盘，该优化了。

### 闪退排查五步法

PSCC 闪退（Crash）的原因集中在五个方向，按出现概率从高到低依次排查：

**第一步：GPU 驱动**（最常见）。打开"帮助 > 诊断 GPU"检查驱动状态，过时或损坏的驱动会让画笔拖拽、生成式填充等 GPU 加速功能触发崩溃。临时绕过方法：首选项 > 性能 > 取消"使用图形处理器加速计算"，如果不闪了就是驱动问题，去显卡厂商渠道下载最新 Studio Driver 升级。

**第二步：字体损坏**。损坏或重复的字体会在显示字体预览时触发闪退。启动时按住 `Shift` 进入安全模式，如果安全模式正常，说明是字体或插件问题。Windows 下到设置 > 个性化 > 字体里清理重复字体，Mac 用字体簿验证完整性。

**第三步：插件冲突**。第三方滤镜、扩展面板可能与当前版本不兼容。同样按住 `Shift` 进安全模式逐个禁用排查，也可以到编辑 > 首选项 > 增效工具里暂时取消全部启用。

**第四步：用户配置损坏**。快捷键、首选项、工作区设置文件损坏会导致启动即闪退。启动时**同时按住** `Ctrl + Shift + Alt`（Mac: `Cmd + Shift + Option`），弹出对话框确认删除设置文件，PSCC 会恢复默认启动。注意这会清空所有自定义设置。

**第五步：安装文件损坏**。前面四步都排除后，打开 Creative Cloud 桌面端，在 PSCC 旁边点 `...` 菜单选"修复"。还不行就卸载重装——记得先到编辑 > 首选项 > 导出备份自定义设置。

### Windows 贴靠布局：多窗口高效协作

在大尺寸显示器上工作时，Windows 11 的 Snap Layouts 功能可以把 PSCC 窗口快速排列成预设布局，不用手动拖来拖去。操作有三种方式：

1. **拖拽到屏幕顶部**，Windows 自动弹出布局预览网格，滑过想要的布局松开即可
2. **键盘快捷键** `Win + Z` 打开预览，方向键选择、回车确认
3. **最大化按钮 hover**，鼠标悬停在窗口右上角最大化按钮上弹出布局预览

在 PSCC 中具体能做什么：原图和修图版左右并排对照、同时打开 PSD 源文件和导出的 PNG 预览、一边编辑一边拖入参考图窗口、把图层面板单独拖到另一个 Snap 区域专注查看。

macOS 用户有类似的 Mission Control 可以用，把窗口拖到屏幕边缘自动贴靠，或者用全屏模式多桌面切换。
