## ✨ PingID 是什么

PingID 是 Ping Identity 推出的企业级多因素认证（MFA）解决方案，主打"低摩擦 + 高安全"的平衡。它覆盖推送通知、OTP 动态密码、生物识别（指纹/面容）、FIDO2 安全密钥等多种认证方式，广泛部署在金融、医疗、政府、科技等行业的企业 SSO 和 VPN 场景中。

对终端用户来说，PingID 的核心体验就是：在电脑上输完公司账号密码，手机 App 弹出一条推送，点开确认一下，登录就完成了。不用记验证码，不用等短信，一次按键解决二次验证。企业 IT 侧则可以根据风险自适应策略，决定每次登录是否强制 MFA、触发哪种方式，在安全和便利之间做精细调配。

PingID 支持 Android、iOS、Windows、macOS 多平台，App 本身免费，由企业统一采购授权后为员工开通。如果你所在的公司启用了 PingID，你需要做的就是把 App 装到手机上，完成一次设备配对，之后日常使用基本无感。

## 🔧 安装与首次配对

安装 PingID App 本身很简单，但配对是决定后续能不能正常认证的关键一步。

### 下载安装

按你的手机平台选择对应渠道：

1. **Android**：打开 Google Play，搜索 PingID，认准开发者为 Ping Identity 的官方应用，点击安装。如果你的设备没有 Google Play（比如部分国内 Android 手机或企业管控设备），可以从公司 IT 提供的内部渠道获取 APK 安装包，安装时可能需要在系统设置里临时允许"未知来源"应用安装。
2. **iOS**：打开 App Store，搜索 PingID，直接安装即可。
3. **桌面端（可选）**：部分企业会要求在 Windows 或 macOS 上安装 PingID 桌面组件，用于支持 FIDO2 安全密钥或更无缝的 SSO 体验——具体按公司 IT 指引来。

安装完成后**先别急着打开**——你需要先拿到公司 IT 给的配对凭证。

### 拿到配对凭证

IT 一般会通过以下两种方式之一给你配对信息：

- **二维码**：最常见，IT 发一张二维码图片或在身份门户页面展示
- **配对码（Pairing Key）**：一串字母数字组合，可能有破折号分隔，比如 `ABC123-DEF456-GHI789`

> [!TIP]
> 二维码和配对码**功能完全等价**，任选其一即可，不要试图两个都用。配对凭证通常有有效期（10~30 分钟），过期了直接找 IT 重新生成，反复输入同一个过期码没用。

### 完成配对

**扫码方式**：

1. 打开 PingID App，主界面点击「扫描二维码」
2. 允许相机权限后对着 IT 给的二维码扫一下
3. App 显示公司名称和你的账号信息，确认无误后点「完成」

**配对码方式**：

1. 打开 PingID App，主界面点击「输入配对码」或类似入口
2. 把 IT 给的配对码**复制粘贴**进去（别手敲，容易把 O 和 0、I 和 1 搞混）
3. 忽略配对码中的破折号或空格，App 会自动过滤
4. 确认账号信息后点「完成」

配对成功后 App 主界面会出现公司账号的图标，状态显示已激活。

> [!NOTE]
> 配对过程中如果 App 提示 "Invalid Key" 或扫描没反应，先检查是不是凭证过期了、有没有复制多余的空格，还是不行就找 IT 重发一份——自己排查半天不如一张新的二维码来得快。

## 📖 使用入门

PingID 配好之后日常用起来很轻，但不同认证方式的体验差异不小，了解清楚才能在关键时刻不慌。

### 推送通知（最常用的方式）

这是 PingID 默认也最主流的认证方式。完整流程：

1. 在电脑上登录公司系统，输完密码后屏幕显示"正在等待 PingID 验证..."
2. 几秒钟后手机顶部或锁屏弹出 PingID 通知，可能伴随震动或提示音
3. 解锁手机、点开通知，App 会显示请求来源（比如"从 Chrome 浏览器登录公司 VPN"）
4. **确认是你自己发起的**——如果来源不对、IP 地址陌生，不要点批准，直接拒绝并联系 IT
5. 点绿色的「批准」按钮，电脑端自动跳转完成登录

正常情况下整条链路不超过 10 秒。如果等了十几秒还没推送，先检查手机网络和通知权限，再手动打开 PingID App 看主界面有没有"待处理请求"卡片——有时候 Android 的后台清理会把推送链路掐断。

### 生物识别（指纹 / 面容）

PingID 支持把生物识别作为推送的二次确认层，也支持直接用生物识别完成认证。开启后每次推送弹出时，App 会先要求你用指纹或面容过一遍，再加一层保险。

Android 用户需要注意一个官方文档明确记录的坑：如果你在系统里**同时录了 Face 和 Iris** 两种面部识别，PingID App 可能无法在两者之间切换，导致面容验证直接弹出 "Canceled" 或秒退。解决办法是进手机设置 → 生物识别与安全，**删掉其中一种**（多数人保留 Face），再重启 App 就好了。

Android 上还有一个系统级限制：某些手机的 PingID 界面**不会让你选择用面容还是指纹**，它直接调用系统默认的生物识别面板，由系统决定弹出哪种。这不是 PingID 的问题，要么在系统设置里暂时关掉不用的那种，要么升级系统版本碰碰运气。

iOS 上 Face ID 与 PingID 的配合比 Android 稳定得多，常见问题反而是 App 设置里的 Face ID 开关被系统重置成"需要密码"——进 App 设置重新开一下就行。如果生物识别彻底罢工，终极解法是**卸载 App → 重启手机 → 重装 → 重新配对**，能清掉全部本地状态，很多奇怪的缓存问题都能通过这招解决。

### FIDO2 安全密钥（最高安全等级）

PingID 支持所有 FIDO2 / WebAuthn 合规的硬件安全密钥，包括 YubiKey、Feitian、Thetis、Google Titan 等品牌。这是目前最安全的认证方式：密钥内置密码学芯片，在设备本地生成密钥对，完全不依赖网络、不存密码、抗钓鱼。

| 对比项 | 推送 | OTP | 生物识别 | 安全密钥 |
|---|---|---|---|---|
| 抗钓鱼 | ❌ | ❌ | 系统级 ✅ | ✅ |
| 离线可用 | ❌ | ✅ | 系统级 ✅ | ✅ |
| 需要手机 | ✅ | ✅ | App 内需要 | ❌ |
| 成本 | 无 | 无 | 无 | 数百元 |
| PingID 支持 | ✅ | ✅ | ✅ | ✅ |

安全密钥的配对需要 IT 发起绑定流程，通过浏览器访问绑定页面，按提示插入密钥、按键确认即可。日常使用时，电脑端输完密码弹出安全密钥提示，把密钥插进 USB（或手机 NFC 靠近），按一下上面的按钮，LED 闪一下就完成了——3 秒以内，比推送还要直接。

> [!WARNING]
> 安全密钥丢了**立刻联系 IT 解绑旧密钥**，不要等。一个 YubiKey 可以绑定多个账号多个域名，但丢了就是物理控制权旁落，必须第一时间作废。

### 推送迟迟不到怎么办

这是 PingID 用户最常遇到的问题。排查顺序：

1. **手机网络**：Wi-Fi 或移动数据是否正常，能不能打开其他网页
2. **通知权限**：手机设置里 PingID 的通知有没有被禁用
3. **后台清理**：Android 手机的省电策略或一键加速会不会把 PingID 的后台进程杀掉——把 PingID 加到电池优化白名单里
4. **手动打开 App**：主界面有没有"待处理请求"卡片，点进去直接批准
5. **终极方案**：卸载 App → 重启手机 → 重装 → 重新配对

大多数情况下前两三条就能解决，真正需要重装的反而是少数。

### 什么时候会触发 PingID

这完全取决于你公司 IT 的策略，常见三种模式：

- **每次登录强制**：不管什么设备什么 IP，每次都要走 PingID
- **风险自适应**：常用设备和 IP 只输密码，异地或新设备才弹 PingID
- **用户自选**：IT 放开权限，你可以在推送、OTP、生物识别之间挑

如果发现自己某天突然不用 PingID 就能登录，不一定是系统坏了，可能是 IT 调整了策略或者你登录的场景被判定为低风险。反过来，如果某次在酒店或咖啡馆登录被强制触发，也属于正常的风控行为。
