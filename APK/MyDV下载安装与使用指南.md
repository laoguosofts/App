## ✨ MyDV 是什么——电视盒子上的抖音开源客户端

MyDV 是一款运行在 Android TV 设备上的抖音第三方客户端，核心定位就是把手机上刷的抖音内容搬到大屏上来。它开源免费，不走官方 API，靠自己维护的接口层拉取短视频和直播流。如果你有一台电视盒子、Android 智能电视或者其他能跑 APK 的大屏设备，MyDV 能让你躺在沙发上用遥控器刷抖音。

跟手机版抖音最大的差别在**遥控器交互**——所有操作靠方向键和 OK 键完成，没有触屏，所以界面是专门为 TV 场景重新设计的。导航栏、视频播放页、设置界面，每个元素都要能被遥控器光标准确选中。这意味着 MyDV 不是简单的 APK 套壳，而是从底层适配了 Android TV 的交互范式。

MyDV 支持的主要功能：短视频流刷取、直播观看、画质与播放控制（弹幕开关、画中画、熄屏续播）、Cookie 登录同步收藏与稍后再看、视频详情面板、按作者主页浏览。功能更新比较勤快，社区反馈的高频问题修得也快，版本号已经迭代到 v2.0.x 系列。

适合谁用？家里有 Android TV 盒子、又想在大屏上刷抖音的用户；或者想在电视上看抖音直播但不想装那些弹窗广告满天飞的魔改 APK 的人。不适合需要点赞评论互动的重度抖音用户——写接口受限于抖音，第三方客户端做不了。

## 🔧 MyDV 安装手把手——电视盒子装 APK 的正确姿势

MyDV 是 Android TV APK，安装思路和普通安卓应用不同——电视盒子一般没有浏览器，得先把 APK 文件投进去。下面按最常见的三种场景说。

### 场景一：有文件管理器的盒子（最省心）

1. 把下载好的 APK 放到 U 盘根目录
2. 把 U 盘插盒子的 USB 口
3. 盒子里打开文件管理器（ES 文件浏览器、Solid Explorer 都行）
4. 找到 U 盘里的 MyDV APK，点 OK 确认安装

> [!TIP]
> 安装过程中如果弹窗提示"未知来源未开启"，先回到盒子设置里找到"安全与限制"，把"允许安装未知来源应用"打开，再回来装。不同品牌盒子的设置入口位置不一样，小米、当贝、创维各自叫法略有差异。

### 场景二：没文件管理器的盒子

用电脑通过局域网推送：

1. 盒子和电脑连同一个 Wi-Fi
2. 电脑上装 ADB（Android Debug Bridge）工具
3. 盒子设置里开启"USB 调试"和"网络调试"，记下盒子 IP
4. 电脑命令行执行 `adb connect <盒子IP>`，连接成功后 `adb install MyDV.apk`

### 场景三：Android 手机/平板

直接在手机上装就行，和普通 APP 没区别。不过注意 MyDV 的界面是为 TV 遥控器优化的，触屏能用但体验不如手机版抖音，更多是临时应急用。

### 安装后核对版本号

装完第一次启动，在设置里找"关于"或"版本信息"，确认版本号和下载页标的一致。目前最新迭代在 v2.0.x，如果你拿到的还是 v1.x 的包，建议换成新版——v1.5 之后修复了不少弹幕渲染、接口兼容性的问题。

## 📖 遥控器全键位 + 核心功能吃透 MyDV

装完启动，你会看到一个 TV 风格的导航栏界面——左侧是分类入口（推荐、关注、直播、收藏、稍后再看），右侧是内容预览。上手的关键是搞清楚遥控器每颗键在不同页面的行为差异，MyDV 对短按和长按做了区分。

### 短按 OK vs 长按 OK——同一个键干两件事

这是用 MyDV 最容易混淆的点：

| 操作 | 在播放页的行为 |
|---|---|
| **短按 OK** | 暂停/继续播放 + 弹出视频详情面板 |
| **长按 OK** | 直接跳转到发布者主页 |

暂停时浮现的详情面板不挡画面核心区域，包含视频标题、作者昵称、互动数据（点赞数/评论数/收藏数/分享数），v1.5.x 之后还加了**实时网速显示**——在网络不好的时候能帮你判断到底是视频源卡还是自己家带宽卡。继续播放后面板会自动淡出消失，不会一直糊在画面上。

### 左键呼出推荐面板——主动挑着看 vs 被动往下刷

按 ← 键会在画面右侧弹出一个"相关视频推荐面板"，列出当前视频作者的其他作品或系统推荐的相似内容。和上下键的区别是：

- **上下键** 按推荐流的时间/热度顺序往下刷，节奏是被动接收——刷到什么看什么
- **左键面板** 自己挑想看的，节奏是主动选择——适合刷到一个感兴趣的作者、不想重新翻前面找他视频的场景

面板里用方向键移动焦点、OK 确认打开。如果按左键没反应，先确认是不是 v1.2.16 之后的版本——早期版本左键行为是调进度条的，后来改了。退出播放页回导航栏重进，或者重启应用一般都能恢复。

### 弹幕控制——直播默认开、短视频默认关

弹幕在短视频和直播场景下的默认行为不一样：

| 场景 | 默认状态 | 建议 |
|---|---|---|
| 直播 | **开启** | 想看人气互动就开，嫌画面乱就关 |
| 短视频 | **关闭** | 弹幕会遮挡视频主体，大部分场景关了干净；想看互动感可以开，但短视频弹幕量通常不多 |

开关方式：**长按菜单键**弹出功能面板，找到"弹幕"选项选开或关，OK 确认即时生效。如果你遇到弹幕显示异常（全方块字、只显示一部分），更新到最新版试试——v2.0.33 修复过 overlay 层渲染的性能问题。

### 稍后再看——Cookie 登录后手机加标记电视继续

登录抖音账号后（通过 Cookie 方式，不用输密码），MyDV 会同步你手机上标记的"稍后再看"列表。导航栏里有"稍后再看"入口，进去就是在手机上点过"以后再看"的视频。

跨设备同步有几个细节要注意：

- **手机加标记 → 电视可见**，通常有几分钟延迟，不是即时同步
- **电视播放完的状态**不会自动回写到手机端的稍后再看列表——要清理还得回手机上操作
- 抖音没有开放写接口给第三方客户端，所以 MyDV 只能"读"你的稍后再看，不能"写"新标记或删旧标记

如果导航栏里没找到稍后再看入口，先确认是不是 v1.5.27 之后的版本——较早版本没有完整实现这个功能，或者入口藏得比较深。

### 已知限制——开源客户端绕不开的边界

点赞、评论、收藏这些需要写接口的互动操作，目前 MyDV 都做不了。能看到别人点了多少赞、写了多少评论，但自己无法操作。这不是 bug，是抖音压根没开放写接口给第三方客户端。喜欢一个视频只能记下来，或者换回手机版抖音互动。
