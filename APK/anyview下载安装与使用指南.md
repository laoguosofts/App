## ✨ AnyViewer 是什么

AnyViewer 是一款跨平台远程控制工具，主打手机控电脑的低门槛场景——把装着 Windows 或 macOS 的电脑留在家里/公司，掏出安卓或 iOS 手机就能直接看到桌面、操作鼠标键盘，像坐在电脑前一样。它的核心逻辑简单：两端登录同一个账号，被控端保持在线，控制端随时发起连接，整个过程不需要两端处于同一局域网，走的是官方服务器中继。

和同类型工具相比，AnyViewer 的定位偏向「家庭远程 + 轻量办公」：免费档就能满足日常的远程查看、文件传输、无人值守唤醒，付费档则解锁更高画质、更快的文件传输速度和隐私模式。界面克制，没有广告弹窗，电脑端常驻后台也不抢资源。

典型的使用场景包括：远程查看家里的电脑桌面、外出时临时取回办公文件、帮朋友远程排查电脑问题、把手机当遥控器操作挂机的电脑游戏或下载任务。

## 🔧 Windows 电脑端安装步骤

AnyViewer 的 Windows 客户端安装过程和普通软件一样，但远程控制类软件有几个安装后的检查点不能省。

### 获取渠道

优先从官方下载页获取安装程序，32 位和 64 位版本分开提供，根据系统位数选择。微软商店等第三方应用商店也能下载，但版本更新节奏可能略慢于官方。

> [!WARNING] 安全提醒
> 远程控制软件一旦被植入后门，等于把整台电脑的控制权拱手让人。务必从官方渠道获取，不要从来路不明的镜像站下载所谓的「修改版」「精简版」。

### 安装流程

1. **双击安装程序**，选择安装路径（默认路径即可，不需要额外调整）。
2. 等待安装完成，客户端会自动在桌面创建快捷方式并常驻后台。
3. **首次启动必须注册或登录账号**——账号是两端配对的唯一凭证，控制端和被控端必须登录同一个账号才能建立连接。注册免费，只需要一个邮箱地址。

### 装完立刻检查两件事

- **开机自启与后台驻留**：进入客户端设置，确认「随系统启动」选项已开启。无人值守的核心前提就是电脑开机后客户端能自动运行、自动登录账号，不需要人手动点开。
- **网络可达性**：公司或学校的电脑如果有严格防火墙策略，需要允许 AnyViewer 联网。远程连接依赖与官方服务器的通信，不要求两端在同一局域网。

### 与手机端的对应关系

电脑端装好后，记住客户端显示的**设备名**（类似 DESKTOP-XXXX 的格式）和设备 ID。手机端登录同一个账号后，设备列表里会自动出现这台电脑，点一下就能发起连接。

## 📖 上手使用：从第一次连接到日常操作

电脑端和手机端都装好、登录了同一个账号之后，远程控制的大门就打开了。下面从界面认识、操控模式、常见问题三个维度带你走通整个流程。

### 电脑端界面速览

打开 Windows 客户端，左侧是一列图标导航，中间是主工作区。没登录时主区展示注册入口和其他平台的下载按钮；登录后主区会变成账号卡片和设备面板：

- **账号卡片**：显示头像、邮箱和当前套餐（免费版显示 Free edition）。
- **登录设备计数**：比如 1/3，表示免费档最多允许 3 台设备同时登录这个账号，超过后新设备会顶掉旧设备。
- **最近连接列表**：记录最近 10 台连接过的设备，方便快速回连。
- **升级提示区**：列出付费档解锁的功能——高清画质、高速文件传输、隐私模式等，免费用户可以暂时忽略。

左侧四个图标的职责分别是：连接相关功能、账号与登录状态、设备与连接管理、系统设置（安全码、无人值守、语言切换都在设置里）。把这一屏的布局记清楚，后面的所有操作都从这里发散。

### 手机端的两种操控模式

手机屏幕是触控的，电脑桌面是指针驱动的——AnyViewer 在远程会话里给你两套把「触」翻译成「点」的方案，工具栏底部随时切换：

| 你要做的事 | 推荐模式 | 原因 |
| --- | --- | --- |
| 点大按钮、滑动浏览网页 | 触控模式 | 手指点哪光标落哪，直觉式操作 |
| 精准点小图标、小菜单 | 鼠标模式 | 把定位和点击拆成两个动作，误差收敛 |
| 悬停预览（任务栏缩略图、网页 hover 菜单） | 鼠标模式 | 触控没有悬停态，只有指针能触发 |
| 拖拽选中文本、框选文件 | 鼠标模式 | 虚拟指针的可控性远高于手指直接触摸 |
| 快速翻页滚动 | 触控模式 | 手指直接滑，和手机浏览一致 |

实际使用建议以触控模式为主、鼠标模式为辅：日常浏览和翻页用触控，遇到精准操作需求时切鼠标模式，做完切回来即可。

### 远程黑屏的三种情况与处理

远程会话里看到黑屏，不要慌——先判断属于哪种「黑」，处理方式完全不同：

**锁屏界面（有时间和头像）**：说明 Windows 本身锁定了。两条路：一是如果电脑端之前保存过 Windows 登录密码，手机端设备详情页点「解锁密码」按钮就能一键解锁；二是直接在远程会话里用手机键盘输入 Windows 密码。解锁不了的多半是没在电脑端配置过解锁密码。

**纯黑屏但会话还活着**：先想是不是上次结束会话时忘了关隐私模式——工具栏里关掉隐私模式就能恢复显示。如果不是隐私模式，可能是电脑显示器进入休眠了，在会话里发送一个鼠标移动或按键就能唤醒。

**会话整个断开**：大概率是电脑睡眠或者网络掉线了。远程控制的天敌就是睡眠——建议在电脑电源设置里关闭自动睡眠（关闭显示器可以保留，省电又不影响远程），配合客户端的开机自启和解锁密码，形成「重启后自动上线 → 锁屏后一键解锁」的闭环。

> [!NOTE] 安全边界
> 解锁密码功能让「输 Windows 密码」变成一键操作，但也意味着手机丢了等于电脑裸奔。务必给手机设锁屏密码，账号开启双因素认证。
