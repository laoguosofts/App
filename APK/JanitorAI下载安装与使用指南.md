## ✨ JanitorAI 是什么：角色扮演社区 + 模型自选的 AI 对话平台

JanitorAI 是一个把模型选择权完全交给用户的 AI 角色对话社区，官方标语是「Be anyone, Build anything」——扮演任何人，构建任何东西。平台本身可以理解成三层结构：角色卡由社区用户编写，决定角色是谁；对话界面负责聊天、改写、记忆管理；模型接口则决定由哪个「大脑」来生成回复。前两层免费且全站共用，第三层可以选择官方自研模型，也可以把自己申请的第三方接口接进来。

平台的核心差异化在于三个方向：网站功能全免费（聊天、建卡、搜索不收钱，官方模型也不收费）；模型完全自选（觉得官方模型文风不合口味，可以接入自己的 DeepSeek、OpenAI 等接口，费用直接付给服务商）；内容分级开放（以 Limited 与 Limitless 两档标签区分内容尺度，对成年用户放开创作边界，但设有零容忍清单）。

官方公布的规模是 1500 万以上用户，热门角色的累计消息量以百万计，角色卡上会直接标注消息数与 token 体积。主要使用人群是 18 岁以上的角色扮演、互动小说与文字冒险爱好者，另一大群体是想做角色卡的创作者——平台上大部分高质量角色都来自社区创作。

使用方式也很简单：浏览器直接访问官网即可使用，桌面与手机浏览器均已适配；官方 iOS 与 Android 应用也已上架应用商店。没有官方桌面客户端，网页即全部。

## 🔧 安装步骤：浏览器免装 + 移动端应用安装

### 浏览器端（最推荐）

JanitorAI 的网页版是核心体验，无需任何安装：

1. 打开浏览器（Chrome、Edge、Safari 等主流浏览器均可），输入官网地址；
2. 页面加载完成后，点击右上角注册——支持 Google、Discord 等第三方账号快捷登录，也可以邮箱直接注册；
3. 登录成功后即可直接进入首页的角色库，选一个感兴趣的角色点开就能聊天。

> [!TIP]
> 浏览器端没有任何安装门槛，且功能最完整。移动端应用本质上是网页的壳包装，功能与网页版完全一致。

### 移动端应用安装

**iOS（iPhone / iPad）：**

1. 打开 App Store，搜索「JanitorAI」；
2. 找到开发者为官方账号的应用（注意甄别同名仿冒应用），点击获取；
3. 首次打开时可能需要验证年龄与同意服务条款，按提示操作即可。

**Android：**

1. 打开 Google Play，搜索「JanitorAI」；
2. 同样注意识别官方开发者，点击安装；
3. 如果所在地区 Google Play 无法访问，可通过下载页获取 APK 安装包，安装前需要在系统设置中允许「未知来源」应用安装。

> [!WARNING]
> Android 用户如果下载 APK 安装包，请务必核对文件来源的可信度，并检查安装包的哈希值或数字签名，避免第三方篡改带来的安全风险。

## 📖 使用入门：从第一次对话到自建角色卡

### 快速上手：聊一次试试

注册登录后，首页就是热门角色推荐。角色卡片上会显示累计消息数和 token 体积——消息数越高说明这个角色被越多用户反复使用，质量通常也越好。点开一个角色，直接在底部输入框发第一条消息，就能开始对话了。对话界面支持多行输入、发送图片，还可以随时中断生成、重新生成上一条回复。

### 配置代理模型：十五分钟跑通 OpenRouter 免费档

官方免费模型够用，但很多用户喜欢自己接外部模型以获得更好的文风或更低的成本。OpenRouter 是官方帮助中心首推的入门方案——它聚合各家模型，其中 DeepSeek 的免费档每天送 50 条消息，无需绑卡。

**拿到密钥：**

1. 打开 OpenRouter 官网，右上角注册（可用 Google 快捷登录）；
2. 登录后点头像，进入 Keys（密钥）页面；
3. 点创建密钥，名字随意（比如填 JanitorAI），其他字段留空；
4. **立刻复制生成的密钥**——以 `sk-or-v1-` 开头，这是唯一一次完整显示，存进备忘录。

**填进 JanitorAI：**

1. 回到 JanitorAI，打开任意一个角色的聊天界面；
2. 聊天窗口右上角打开 API Settings，选择 Proxy，点添加配置；
3. 五个字段按下面的表格填写：

| 字段 | 填写内容 |
| --- | --- |
| Config Name | 自定义名称，如「我的免费 DeepSeek」 |
| Model Name | `deepseek/deepseek-chat-v3-0324:free` |
| Proxy URL | `https://openrouter.ai/api/v1/chat/completions` |
| API Key | 刚才复制的密钥，首尾不能带空格 |
| Custom Prompt | 留空 |

4. 点添加 → 点 Save Settings → **刷新页面**；
5. 发一条测试消息，有正常回复就说明配置成功。

### 额度管理：429 报错的两种解法

使用过程中最常见的报错是 429，但它有两种完全不同的成因，需要先看清是哪一种：

**第一种：Rate limit exceeded: free-models-per-day**

这是 OpenRouter 免费档的每日额度用完了。三条关键规则：

- 免费用户每天 50 条，按世界协调时零点重置；
- **报错的请求也计入额度**——配置有错时反复点测试，额度烧得飞快；
- 给 OpenRouter 账户一次性充值 10 美元，免费模型日额度永久升到 1000 条，这笔钱本身可以不用花掉。

解法：等零点重置；或充值升级额度；或改用平台自带的官方免费模型（不走 OpenRouter 额度）。

**第二种：[model] is temporarily rate-limited upstream**

这不是你的额度问题，是这个模型当前上游过载，全平台用户都在挤。热门免费模型高峰期经常这样。解法很简单——换一个模型立刻见效，或原模型稍后再试。建议把两三个型号都存进配置随时切换，体验更流畅。

> [!NOTE]
> 界面弹出 `Unknown response: [object Object]` 这类含糊提示时，多半也是额度触顶的变体表现，先按第一种情况处理——等零点重置再试。

### 自建角色卡：从私有到公开的三个开关

平台对创作者的支持也很完整。点创建按钮就能从零开始写一张角色卡，包括人格设定、场景背景、示例对话、世界书等模块。刚创建时新角色**默认私密**——只有你能看到、能聊。想把它变成公共资产，有三个开关需要理解：

| 开关 | 打开后 | 保持关闭 |
| --- | --- | --- |
| Public | 全平台用户可以搜到并使用你的角色 | 只有自己可见，随时继续改稿 |
| Show Definition | 任何人能查看角色的完整定义（人格、场景、示例对话） | 定义对外隐藏 |
| Allow Proxies | 接外部模型的用户也能正常使用这只角色 | 只有官方模型的用户能聊 |

这里有一条官方的联动规则：**打开了 Show Definition 的角色会自动允许代理**——定义都公开了，锁定官方模型用户也就没了意义。想让角色保持「仅官方模型可用」，就把定义视图关着、代理开关也关着。

发布前建议走一遍自测清单：用自己的账号完整聊一轮确认人设不崩、检查标签分级没选错（这关系到过审）、含世界书的角色多触发几条验证、确认头像与简介符合图像与内容规范。发布不是终点——公开后仍可继续编辑，改动即时生效。
