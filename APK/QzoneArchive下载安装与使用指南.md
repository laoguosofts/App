## ✨ QzoneArchive 是什么

QQ 空间走过了十几年的岁月，很多人发在说说、日志、留言板里的内容，承载着青春的印记。但把这些内容**完整、结构化地搬到本地**，一直是个麻烦事——腾讯没有提供官方导出工具，第三方方案要么只抓文字漏图片，要么只抓单条动态漏评论链。QzoneArchive 就是为解决这个痛点而生的开源归档工具，它走非侵入式登录路线（Tauri 壳 + 内置 WebView），从 QQ 空间接口**温柔地、有频率保护地**拉取动态、日志、留言、相册和好友列表，原样存入本地 SQLite 数据库，同时缓存所有媒体文件到硬盘。

它的核心特性有三条：第一，**完整度优先**。归档范围覆盖自己的动态、好友动态、留言板、私密日志、相册和说说的图片视频，连每条动态下的评论链、点赞人列表都会一并抓下来，还原出原始的互动关系。第二，**频率保护兜底**。内置请求节流和限流检测，不会因为抓太快触发腾讯的风控，归档一次可能需要几小时，但稳定、不中断。第三，**离线可用 + 可二次导出**。归档完成后可以在应用里离线浏览所有内容，还能按分类、按时间导出为独立 HTML 文件夹——双击 index.html 就能在任何浏览器里看，不依赖 QzoneArchive 本身，十年后也不怕格式过时。

适合它的人大致分四类：网龄十年以上、想把非主流说说和火星文签名留在硬盘上的怀旧派；准备弃用 QQ 空间或担心平台状况的迁移派；早年写过图文日志、想把旧内容素材化再利用的创作者；以及帮不会操作工具的父母备份数字记忆的家庭用户。当然它也有边界——仅限本人账号或已获授权的账号，商用批量抓取和未授权的他人内容都不在范围内。

## 🔧 安装步骤

### Windows 安装

1. 从下载页选 **MSI 安装包**（推荐自动配置 PATH）或 **ZIP 绿色版**（解压即用）
2. MSI 安装时一路下一步即可，默认装到 `C:\Program Files\QzoneArchive\`；ZIP 版解压到你习惯的工具目录（比如 `D:\Tools\QzoneArchive\`），**不要解压到系统盘 C 盘根目录**——归档运行时会在 `%APPDATA%/qzonearchive/` 写大量媒体缓存
3. 首次启动如果被 SmartScreen 拦截，点「更多信息 → 仍要运行」即可（Tauri 应用首次签名未积累信誉时常见）

### macOS / Linux 安装

- macOS：DMG 双击后把 QzoneArchive 拖进 `/Applications/`；首次启动如果被 Gatekeeper 拦截，在「系统设置 → 隐私与安全性」底部点「仍要打开」
- Linux AppImage：下载后 `chmod +x QzoneArchive-*.AppImage`，直接双击运行；deb 包 `sudo dpkg -i` 安装

> [!TIP]
> **版本核对**：归档前建议在应用「设置 → 关于」里确认版本号和下载页一致。不同版本的接口适配、频率保护参数、数据库 schema 可能有差异，混跑容易导致归档不完整。

### 磁盘空间提前留足

归档结果包括 SQLite 数据库 + 媒体缓存（图片、视频），一个有几千条动态、大量配图视频的账号，归档后的媒体文件可能超过 10GB。**建议预留至少 20GB 的可用空间**，不够的话归档中途会因写入失败而中断。部分版本允许在归档时把媒体缓存的存储位置选到外接硬盘——如果你的主力盘空间紧张，可以考虑这个方案。

## 📖 使用入门

### 登录与授权

打开应用后会进入内嵌 WebView 的登录页面，扫码或用账号密码登录后，QQ 空间的登录凭证会被安全保存在本地。**归档期间不要在手机 QQ 或电脑 QQ 上切换账号**——README 特别提醒：同一账号在多个终端切换可能导致当前登录凭证失效甚至触发账号风险。归档跑着就让它跑着，别在另一个终端切号。

### 开始归档：四步流程

登录成功后，归档任务的标准流程是四步：

1. **打开「归档任务」页面** —— 应用主界面一般有明显入口，进入后会显示当前登录状态和之前的归档进度（如果是首次使用则为空）
2. **确认前置条件** —— 网络连接稳定（Wi-Fi 优先，移动网络可能不稳定且耗费流量）、磁盘空间充足、当前账号没有在其他终端被使用
3. **点击「开始归档」** —— 应用开始向 QQ 空间接口发起请求，按配置好的节流节奏抓取数据入库
4. **等待完成** —— 首次归档时长取决于账号内容量和接口限流，普通账号几十分钟到几小时，活跃账号（上万条动态、大量视频）可能需要一整天。进度页会显示已完成数量、进度百分比和限流倒计时

> [!NOTE]
> **慢是正常的**。项目内置频率保护，请求节奏被严格控制，所以归档看起来不会特别快——这是"温柔地抓"，牺牲速度换稳定性和账号安全。强行加速或绕过限流反而容易触发风控，导致登录失效。

归档跑着的时候你可以最小化窗口让它后台跑，也可以切换到其他页面查看**已经归档完成**的内容。中途可以中断后稍后恢复，应用会记住进度继续抓——但正常跑完是最干净的，能不中断就别中断。

### 归档过程中会抓到什么

QzoneArchive 的抓取范围比很多人想象的要宽：

| 类型 | 具体内容 |
|---|---|
| 自己的动态 | 说说正文、配图、视频、位置标签、发布时间 |
| 好友动态 | 好友发的说说和互动（需要你在权限范围内能看到） |
| 评论链 | 每条动态下的完整评论楼，包括回复关系 |
| 点赞/浏览 | 点赞人列表、浏览次数（接口能拿到的部分） |
| 日志 | 长文日志正文、插图、分类标签 |
| 留言板 | 访客留言和回复 |
| 相册 | 相册列表和照片原文件 |
| 好友列表 | 好友分组和备注 |

### 归档完成后做什么

归档跑完只是第一步——**立即做这两件事**：

**第一，检查存储位置**。归档数据默认存在跨平台 Tauri 应用的标准目录里：

| 操作系统 | 默认路径 |
|---|---|
| Windows | `%APPDATA%/qzonearchive/` 或 `%LOCALAPPDATA%/qzonearchive/` |
| macOS | `~/Library/Application Support/qzonearchive/` |
| Linux | `~/.local/share/qzonearchive/` |

这个目录里有 SQLite 数据库文件、媒体缓存目录和应用配置（不含登录凭证）。

**第二，导出 HTML**。归档完成后，数据已经存在本地 SQLite 里了，但额外导出一份 HTML 非常值得——原因有三：一是 SQLite 需要用 QzoneArchive 或专用查看器打开，HTML 任何浏览器都能看；二是十年后 SQLite 还在不在、QzoneArchive 还维护不维护很难说，但 HTML 格式不会消失；三是导出的 HTML 可以作为第二份备份，和原始数据库分别存在不同位置（一份在硬盘，一份在 U 盘或云盘）。

导出选项通常有四种：

| 选项 | 说明 |
|---|---|
| 全量导出 | 导出所有已归档内容（首次归档完成后**建议立即导出一份全量**） |
| 按分类导出 | 只导出本人动态 / 好友动态 / 留言板 |
| 按时间导出 | 只导出特定年份或时间段 |
| 按选中导出 | 手动勾选要导出的动态 |

导出结果是一个目录，里面每条动态一个 HTML 文件（或按分类聚合），图片和视频保存在关联文件夹里，样式内联不依赖外部 CSS/JS。双击 `index.html` 就能在任何浏览器里打开，像浏览一个简化版的静态网站。

### 手动备份的正确姿势

定期备份归档数据时，按这个流程来：

1. **先关闭 QzoneArchive** —— 确保数据库不被写入，否则 SQLite 在写入时复制可能导致数据库损坏
2. 复制整个存储目录（数据库 + 媒体缓存）到目标位置
3. 同时备份一份导出的 HTML 文件

> [!WARNING]
> 以下三件事**绝对不要做**：① 归档运行中直接复制数据库文件（会损坏）；② 用 SQLite 查看器直接编辑数据库文件（会破坏数据完整性）；③ 手动清理媒体缓存目录（数据库里还存着引用，删了就找不到对应的图片视频了）。归档的意义就是冗余——别让备份本身成为单点。
