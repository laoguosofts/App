## ✨ GameBooster 是什么

GameBooster 由 G19 Mobile 开发，是一款面向安卓玩家的游戏赛前检查工具，目前全球下载量已超过 5000 万次。它的设计思路很朴素——多数玩家遇到的"越打越卡"并不是玄学，而是三件叠加在一起的小事：后台进程挤占了运行内存、手机存储余量见底、机身高温触发处理器降频。GameBooster 把这三件事的检查和处理收进了同一块仪表盘，进游戏前花 90 秒过一遍，开团时就少一份意外。

它的核心功能可以概括为四件事：**ULTRA BOOST 一键清后台**，结束无关进程把运行内存让给游戏；**DASHBOARD 仪表盘**，一屏显示存储环形读数、PING 网络延迟和 AI 评估入口，开打前扫一眼状态；**GFX TOOL 画质工具**，把分辨率、帧率、阴影、抗锯齿等常用图形参数集中到一处调整；**HUD 悬浮监视器**，游戏中实时显示帧率和运行状态，不必切出去看。

有一件事必须说清楚——GameBooster **不改变硬件的性能上限**。处理器算力、GPU 渲染能力、机身温度阈值，这些都是硬件决定的，任何软件都无法越过。GameBooster 做的是资源调度（把被后台 App 挤占的内存收回来，让游戏独占更多资源；帮你在温度告警前意识到异常），以及画质换流畅（通过 GFX TOOL 调整游戏本地图形设置项，和手动进游戏设置里调是同一类操作，用较低的画质换更稳的帧率）。把它当成一款赛前检查工具，预期摆正，它就是一款趁手的辅助。

## 🔧 安装步骤

GameBooster 以 APK 包形式分发，安装方式和大多数第三方安卓应用相同。

1. **允许未知来源安装**：进入手机「设置 → 安全 → 安装未知应用」，找到浏览器或文件管理器，开启允许安装。不同品牌手机的路径略有差异，部分机型需要在「设置 → 应用管理 → 特殊访问权限」中找到对应开关。
2. **下载并打开 APK**：从下载页获取安装包后，用文件管理器定位到下载目录，点击 APK 文件触发安装。
3. **确认覆盖安装（更新时）**：如果手机上已有旧版本，系统会提示"将应用升级到新版本"，确认后完成更新——因为包名相同（com.g19mobile.gamebooster），**覆盖安装会保留原有设置和游戏列表**，不需要重新配置。

> [!TIP]
> 安装前建议核对文件大小和版本号，只从可信渠道获取，避免第三方修改版。更新后进入游戏前，留意一下权限是否被系统意外撤销——极少数情况下更新会触发权限重置。

安装完成后，桌面上会出现 GameBooster 图标。首次启动时，应用会请求一系列必要权限（存储访问、无障碍服务等），按提示逐一授权即可。

## 📖 使用入门

GameBooster 的日常使用围绕 DASHBOARD 仪表盘展开——每次开游戏前花 90 秒过一遍，就是它全部的工作节奏。以下从实际使用流程出发，拆解几个高频场景。

### ULTRA BOOST：赛前一键清场

点击 DASHBOARD 首页的 ULTRA BOOST 按钮，GameBooster 会扫描并结束后台运行的无关进程，把运行内存腾出来让给游戏。这一步没有参数可调，就是点一下等几秒，适合所有重度游戏前必做。如果时间紧，**至少点一下 ULTRA BOOST 再进游戏**，效果立竿见影。

> [!NOTE]
> GameBooster 的优化在退出游戏后就结束了。下次打开游戏前重新走一遍 DASHBOARD 流程是正确的使用节奏——因为后台状态、存储余量、网络信号每次都不一样，切出去刷了会微信、游戏运行时偷偷下了更新包、Wi-Fi 断连重连过，这些都会让上一次的优化失效。

### DASHBOARD 仪表盘：一屏扫状态

DASHBOARD 主界面集成了存储环形读数、PING 网络延迟和 AI 评估入口，开打前扫一眼就能知道当前手机状态。如果存储余量低于某个阈值，环形读数会变红提示；如果网络 PING 值波动明显，会建议切换 Wi-Fi 或蜂窝。这些都是不需要进设置菜单就能快速看到的信息。

### GFX TOOL 画质工具：分辨率、帧率、阴影一把调

GFX TOOL 是 GameBooster 最具实用价值的模块，它把游戏里常见的图形设置项集中到一处，不用每次进游戏设置菜单一个个翻。核心参数包括**分辨率**、**帧率上限**、**阴影品质**、**抗锯齿**等，每个参数都有多个档位可选。

帧率上限有三档可选，选择时的核心原则是——**锁稳一档比飙高更重要**。

| 帧率档位 | 适用场景 | 硬件要求 |
|---------|---------|---------|
| 30 fps  | 休闲类 / 单机游戏 | 低 |
| 60 fps  | 竞技类游戏（大多数玩家首选） | 中 |
| 90 fps  | 旗舰机玩竞技游戏 | 高，发热明显 |

很多玩家追求把帧率拉到最高，但实际体验中**稳定的 60fps 比忽上忽下的 90fps 更好**。帧率频繁波动本身就是一种卡顿感——屏幕可能出现撕裂，操作响应也不均匀。如果你发现游戏中帧率偶尔暴跌（比如从 90 掉到 40 再弹回），说明硬件扛不住当前档位，降到 60fps 锁稳它，整体体验反而提升。

> [!WARNING]
> 帧率上限不要单独调——它应该和分辨率、阴影等参数配合。如果一定要高帧率（比如 90fps），那分辨率和阴影就要让步一些，否则 GPU 负载过载，反而会出现更严重的掉帧。

### HUD 悬浮监视器：游戏中实时看状态

开启 HUD 后，游戏画面上会叠加一个小窗口，实时显示当前帧率和温度状态。不用切出去看 GameBooster 主界面，在团战间隙瞄一眼就知道手机是否扛得住。

### 省事技巧：让常用配置固定下来

如果嫌每次都手动点参数太麻烦，有几个简化方法：一是**添加游戏后从 DASHBOARD 直接启动**——点下方游戏卡片会自动应用当前 DASHBOARD 状态，一步到位；二是**GFX TOOL 参数设好一次能用很久**，不需要每次都重新调，除非换了新游戏或者换了新手机；三是**至少用 ULTRA BOOST 保底**——时间紧的时候，点一下清后台再进游戏，这一步就足够把内存环境拉到合理水平。

### 版本更新：不走应用商店，手动覆盖

GameBooster 不走 Google Play 或国内应用商店分发，系统不会自动推送更新通知。获取新版本的方式很简单：从你获取当前版本的**同一可信渠道**拿到最新 APK，直接覆盖安装即可——包名相同，系统会识别为升级，原有设置和游戏列表全部保留。更新前可以截一张 DASHBOARD 配置图以防万一，更新后在 GameBooster 设置页面底部核对一下版本号是否正确。

> [!TIP]
> 更新后如果出现权限异常，检查一下「设置 → 安全 → 安装未知应用」的授权状态，部分机型在系统更新或应用更新后会自动重置部分权限开关。
