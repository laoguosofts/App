## ✨ Bilby 是什么——订阅党的 B 站专属入口

Bilby 是一款面向 B 站用户的第三方轻量客户端，APK 体积仅 7.45M，主打「订阅优先、零骚扰」的极简设计。它最核心的设计决策只有一条：**首页只展示你已经关注了的 UP 主的最新更新**，没有算法推荐、没有开屏广告、没有商城入口、没有信息流，甚至连一个「猜你喜欢」的板块都没有。

对于那些已经建立了自己的关注清单、不想再被算法牵着走的用户来说，这种纯粹恰恰是 Bilby 的价值所在。B 站官方客户端随着功能迭代，首页逐渐被算法推荐、活动推送、商业化入口占据，真正想看的关注动态反而被挤到了二级页面。Bilby 把这个顺序彻底颠倒了过来——订阅的人在最上面，推荐流不存在。

> [!NOTE]
> Bilby 不试图成为「另一个官方客户端」，它是订阅党的专属入口。如果你习惯在推荐流里发现新内容，那 Bilby 可能会让你觉得「空」；但对于只想安静追更的人来说，这种极简反而是一种久违的专注感。

和官方客户端的直观对比：

| 对比项 | Bilby 首页 | 官方客户端首页 |
|---|---|---|
| 内容来源 | 仅已关注 UP 主 | 算法推荐 + 关注 + 热门 + 活动 |
| 广告 | 无 | 开屏 + 信息流 |
| 商城入口 | 无 | 有独立板块 |
| 启动速度 | 7.45M 轻量 APK，快 | 功能多，冷启动相对慢 |
| 内存占用 | 低，中低端机可流畅运行 | 较高，老机型可能卡顿 |

## 🔧 安装步骤

### 前置准备

- Android 设备（Bilby 目前仅提供 Android 平台 APK）
- 系统设置中开启「允许安装未知来源应用」

### 安装流程

1. 从下载入口获取最新版 APK 文件
2. 在手机文件管理器中找到下载好的 APK，点击开始安装
3. 如果系统弹出安全提示，选择「允许本次安装」或「始终允许」（取决于你的系统版本）
4. 等待安装完成，桌面上会出现 Bilby 的图标

> [!TIP]
> APK 体积仅约 7.45M，下载和安装过程都很快，建议安装完成后核对一下版本号是否为下载页标注的最新版，避免用到过期版本。

### 装完怎么核对

打开应用，第一屏就是登录二维码界面（详见下一节）。如果能正常显示二维码，说明安装没问题，可以继续登录使用。如果应用启动后闪退或白屏，通常是系统版本过低，检查一下 Android 版本是否满足最低要求。

## 📖 首次登录与日常使用

### 扫码登录——唯一的登录方式

Bilby 不提供手机号验证码、账号密码、快捷登录等多种途径，**扫码登录是唯一的登录方式**。这既是简化操作的选择，也有安全方面的考虑——全程不涉及密码输入和存储。

#### 完整操作链路

1. 打开 Bilby，第一屏就是登录二维码
2. 切到哔哩哔哩官方客户端
3. 点右上角头像区域或设置里找「扫一扫」入口
4. 摄像头对准 Bilby 界面上的二维码
5. 官方客户端弹出确认对话框，点确认
6. 切回 Bilby，自动跳转到首页

> [!WARNING]
> 二维码有有效期（几秒到一分钟不等）。如果扫的时候提示过期，点 Bilby 界面上的刷新按钮换一个新的就行，不需要重新打开应用。

#### 登录后会同步什么

扫码登录使用 B 站官方 API，登录完成后：

- **会同步**：收藏夹、稍后再看、关注列表、历史记录（部分）
- **不会同步**：本地设置（播放速度、清晰度偏好、后台保活开关）、本地缓存

这意味着你在 Bilby 里加入稍后再看的视频，切到官方客户端后也能看到；但你在 Bilby 里设置的「后台保活」，官方客户端不会继承。

#### 登录后首页是空的？别急

如果你扫码成功登录后首页什么都没有，**这不是登录失败**。登录成功但你还没有关注任何 UP 主，首页就会是空的。用底部放大镜搜几个常看的 UP 主，进他们主页点关注，动态马上就会出现。

### 搜索并关注新的 UP 主

Bilby 的首页只显示你已经关注的人的更新——它不会主动「推荐」任何人给你。这意味着找到想要关注的 UP 主是你自己的事。好消息是，搜索能力是 Bilby 做得比较完整的功能之一，支持模糊关键词识别，能区分合集与单视频，结果支持多种排序。

#### 操作步骤

1. 点底部导航栏的**放大镜图标**进入搜索页
2. 在输入框里输入你想找的 UP 主名字——搜索支持模糊匹配，不需要一字不差地输入全名，输入部分关键词也能搜到（比如输入「罗翔」能搜到「罗翔说刑法」）
3. 从搜索结果里挑人——结果页会把视频和 UP 主都列出来，UP 主的结果里会显示头像、名字、粉丝数、认证信息等辅助判断的元素，点击进入对方的个人空间
4. 在个人空间里找到**关注按钮**点一下就完成了，按钮状态会从「关注」变成「已关注」
5. 返回订阅首页，下拉刷新一下，从这个 UP 主关注时刻起发布的新动态，之后都会出现在你的首页流里

> [!TIP]
> 如果你之前在 B 站官方客户端里已经有关注列表，扫码登录时会**自动同步过来**，不需要在 Bilby 里重新一个个搜。第一次登录后首页应该已经有内容了。

### 下拉刷新与位置保持

在订阅页顶部**按住往下拉**，拉到一定距离后松手即可触发刷新。刷新完成后新的动态会追加到列表顶部。

刷新会不会把你推到列表最顶部——这取决于你使用的版本：

- **v0.11.1 及之后**：刷新会在当前位置追加新内容，不会把你推到列表最顶部，也不会丢失你已经翻阅到的位置。这是该版本明确标记修复的第一个问题。
- **v0.11.1 之前**：刷新会把列表重置回第一页，之前翻到的内容和「上次看到这里」的位置会一并丢失。如果你遇到了这种情况，直接升级到 v0.11.1 就能解决。

对于订阅列表来说，位置保持是一个很实际的细节——比如你在地铁上翻到了列表中部，突然来了个电话，挂了电话拉一下刷新，结果列表跳回第一页，之前看到哪里全忘了。v0.11.1 之前的版本确实存在这个体验缺陷，但已经修复，升级后不需要任何额外配置。

### 快速回到顶部

除了下拉刷新，点击底部导航栏的「订阅」Tab 本身，可以快速回到列表最顶部。这比用手指往回滑动效率高很多。

### 为什么 Bilby 不做算法推荐

Bilby 不做「猜你喜欢」的原因是它的产品定位——帮助你管理已有的关注关系，而不是帮你发现新内容。想看什么自己搜、自己关注，节奏由你定。如果你想探索新 UP 主，这仍然是官方客户端首页推荐流的强项。这种设计让 Bilby 在启动速度、内存占用、信息密度上都保持了轻量，适合中低端机流畅运行。
