## ✨ EasyClaw 是什么：让 AI Agent 真能干活的数字员工平台

EasyClaw 是一款主打「让 AI Agent 真正落地干活」的自动化工具，它的核心理念很直接——你跟它说人话，它帮你搞定电脑上的事。和普通的对话式 AI 不同，EasyClaw 具备实际的操作能力：可以读写本地文件、控制浏览器、调用各类 API、定时执行任务，还能同时调度多个 Agent 并行干活。

从产品形态上看，EasyClaw 提供桌面客户端和云端 CloudBot 两套入口，国内与海外也各有独立站点（easyclaw.cn 对应 easyclaw.com）。桌面版安装在你自己的电脑上，负责本地自动化场景；云端版 24/7 在线运行，专门处理定时触发和远程触发的任务。两者账号体系互通（企业版积分池共享），但运行环境互相独立。

EasyClaw 的行为体系由三个核心组件驱动：SOUL.md 定义人格和行为准则（相当于性格），MEMORY.md 存储你的偏好和历史经验（相当于记忆），Skills 是具体可调用的操作能力（相当于技能）。三者配合起来，EasyClaw 不只是一个每次从零开始的对话机器人，而是会积累经验、越用越懂你的数字员工。

当前 EasyClaw 的 Skill 生态通过 ClawHub 社区平台运行，已有 5000+ 社区技能覆盖电商运营、股票投资、内容创作、代码开发等垂直场景，用户可以一键安装别人分享的 Skill，也可以把自己的工作流封装成 Skill 上传分享。

## 🔧 EasyClaw 安装全流程：从下载到跑通第一个任务

EasyClaw 本身对硬件要求不高——AI 推理跑在云端，你本地只需要稳定的网络连接和足够的运行内存。官方给出的最低要求是 16GB 内存，推荐配置也是 16GB+，GPU 完全不需要。真正需要花心思的不是安装本身，而是**让它能长时间稳定运行**的环境配置。

### 桌面版安装（Windows / Mac）

安装过程跟普通桌面软件没什么区别，双击安装包一路下一步即可。装好后第一次启动会引导你做账号登录、基础技能初始化和模型选择。

> [!NOTE]
> 桌面版安装时请留意杀毒软件的误报提示——EasyClaw 需要控制你的本地进程和浏览器，这类行为特征容易被某些安全软件拦截。如果被拦了，把 EasyClaw 的安装目录加入杀毒软件白名单即可。

### 系统休眠与电源配置（关键）

EasyClaw 桌面版**电脑关了就停**，但电脑不手动关机也可能因为系统休眠导致任务中断。这是新手最常踩的坑，必须提前处理：

**Mac 用户：**

1. 临时方案——终端执行 `caffeinate`，命令运行期间 Mac 不休眠
2. 长期方案——从 Mac App Store 安装 Amphetamine，设置定时任务自动防休眠
3. 系统设置 → 显示器 → 高级 → 关闭「自动进入睡眠」

**Windows 用户：**

1. 控制面板 → 电源选项 → 更改计划设置
2. 「使计算机进入睡眠状态」改为「从不」（接通电源时）
3. 高级设置 → 电源按钮和盖子 → 合上盖子时 → 不执行任何操作

> [!WARNING]
> 长时间运行时务必插电。不管 Mac 还是 Windows，电池模式下系统为了省电可能触发更激进的节能策略，EasyClaw 随时可能被挂起。

### 云端 CloudBot 开通

云端版不需要安装任何东西，直接在浏览器打开 CloudBot 的入口站点（国内云或海外云），用同一个账号登录即可开始使用。云端版天生 24/7 在线，适合放定时任务和远程触发的工作流。

### 版本更新后的检查

EasyClaw 会定期推送更新，内容包括新功能、Bug 修复、Skills 优化和模型适配。更新完成后建议快速检查三件事：

- MEMORY.md 是否正常加载（自定义的偏好设置有没有丢）
- 已安装的 Skills 是否正常响应
- 定时任务是否还在（更新过程可能重置调度器）

## 📖 EasyClaw 使用实战：技能生态、多Agent协作与桌面云端协同

### 技能生态：让龙虾越用越聪明

EasyClaw 的 Skill 生态是它区别于普通 AI 对话工具的最大亮点。整个生态的运作逻辑很简单：社区开发者把某类工作流封装成 Skill → 上传到 ClawHub → 其他用户一键安装。目前 ClawHub 上已有 5000+ 社区技能，每天还在增加。

Skill、MEMORY.md、SOUL.md 三者构成了 EasyClaw 完整的行为体系：

| 组件 | 作用 | 类比 |
|---|---|---|
| SOUL.md | 定义人格和行为准则 | 性格（比如「用中文回复、来源要标注」） |
| MEMORY.md | 存储偏好和历史经验 | 记忆（比如「老板喜欢周报格式、日报要 9 点前发」） |
| Skills | 具体的操作能力 | 技能（比如「会发飞书、会搜网页、会写代码」） |

一个完整的任务执行流程是这样的：**用户指令 → SOUL.md 过滤（符合人格准则吗？）→ MEMORY.md 补充（用户有什么偏好？）→ Skills 匹配（用哪个技能？）→ 执行 → 返回结果**。

安装第三方 Skill 时需要注意安全：Skill 本质上是一段操作步骤，来路不明的 Skill 可能包含不透明的操作。建议优先选官方或知名社区贡献者维护的 Skill，安装前先打开 Skill 目录里的 SKILL.md 看看里面定义了什么，只从 ClawHub 或官方推荐渠道获取。

### 多Agent协作：一句话需求，Boss自动拆解并行

EasyClaw 的多 Agent 协作机制，是它处理复杂任务的核心能力。举个真实的竞品分析场景：

你只需要跟主 Agent（Boss）说一句话：「帮我做一份竞争对手 A 和竞争对手 B 的 Q3 竞品分析报告，内容包括用户规模、核心功能、定价策略、市场动态，然后发到我的飞书。」

Boss 会自动拆解任务并调度子 Agent：

1. **数据爬虫专家**（子 Agent 1）和（子 Agent 2）同时并行采集竞品 A 和 B 的公开数据——总耗时直接减半，不用等一个采完再采另一个
2. 爬虫完成后返回结构化数据，Boss 转交给**数据分析员**（子 Agent 3）生成对比表格和图表
3. 数据整理好后交给**文案写手**（子 Agent 4）按风格要求生成结构化报告
4. Boss 检查报告完整性后，调用飞书技能把 PDF 发送给你

整个过程你只说了一句话，剩下的任务拆解、并行调度、数据流转、报告生成、消息发送，全由系统自动完成。

多 Agent 不是越多越好——2~4 个是比较合理的数量，太多了管理成本高、积分消耗快，反而得不偿失。另外，如果子 Agent 的 SOUL 和 MEMORY 没配置好，调度了也干不好，这一点在使用前要先花时间调通。

### 桌面版与云端 CloudBot 的协同策略

桌面版和云端 CloudBot 的能力是**互补而非替代**的，各自有天生的优势和劣势：

| 维度 | 桌面版 | 云端版（CloudBot） |
|---|---|---|
| 能做什么 | 操作本地电脑、读写本地文件、控制浏览器 | 24/7 在线跑定时任务、远程查询、发消息 |
| 不能做什么 | 电脑关机就停摆 | 碰不到本地文件和应用 |
| 数据位置 | 本地 | 云端 |

最推荐的搭配策略是——**桌面管本地，云端管定时**：

- 桌面版负责：本地文件整理、批量重命名、跑 Python 脚本、开发辅助、浏览器自动化、电脑开着时执行的临时任务
- 云端版负责：每天早 8 点行业日报推送、每小时竞品价格监控、每周五自动生成周报初稿、出差路上远程触发数据查询

桌面版和云端版可以用同一个账号，企业版积分池共享，但有几个坑需要注意：

> [!TIP]
> 两套系统的 MEMORY.md **不共享**——如果你希望两边都遵守某个偏好（比如日报格式），需要在两边各自的 MEMORY.md 里都写一份。飞书、Telegram 等渠道配置也需要分别在两套系统里独立配置。个人版的积分消耗也是各自独立计算的。

什么时候只需要桌面版？只做本地自动化、电脑大部分时间开着、对 24/7 在线没有要求的时候。什么时候只需要云端版？不需要碰本地文件、只需要定时任务和远程查询、不想维护电脑休眠开机的那些事的时候。

一句话总结：桌面版是你的「本地数字员工」，云端版是你的「在线数字员工」——两者配合，一个管家里，一个管外面，谁也不累。
