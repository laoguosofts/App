## ✨ Armoury Crate 是什么

Armoury Crate 是华硕（ASUS）为 ROG（Republic of Gamers）系列硬件打造的**统一控制中枢**。它把原本分散在各个设备上的驱动、监控、灯效、超频调节功能，全部收拢到一个界面里——主板、显卡、散热器、键盘、鼠标、内存灯条，只要是 ROG 或兼容 Aura Sync 的设备，都能在 Armoury Crate 里集中管理。

对台式机玩家来说，Armoury Crate 的价值在于**一站式超频与灯效同步**：你不需要分别装 GPU Tweak、AI Suite、Aura Sync 独立版，一个软件搞定所有硬件调节。对笔记本用户来说，它是**性能模式切换 + 风扇策略 + 屏幕色彩管理**的核心工具——五档性能模式一键切换，MUX 独显直连开关、屏幕刷新率切换也都集中在这里。

核心功能可以归纳为四大类：

| 功能模块 | 能做什么 |
| --- | --- |
| **性能监控** | CPU/GPU/内存/磁盘实时折线图、温度、功耗、风扇转速 |
| **超频调校** | CPU 倍频、GPU 核心/显存频率、功耗墙、风扇曲线自定义 |
| **灯效同步** | 所有 ROG RGB 设备统一特效、自定义分区、跟随游戏联动 |
| **情境设定档** | 根据当前运行的游戏/应用自动切换性能模式和灯效 |

Armoury Crate 只支持 Windows 平台，且**仅兼容华硕自家硬件**（主板、显卡、笔记本）。如果你用的是其他品牌的主板或显卡，装了也用不了核心功能。

## 🔧 安装与版本核对

> [!WARNING]
> **不要用旧安装包**。Armoury Crate 更新频繁，旧版可能缺少对新硬件的支持，甚至在 Windows 更新后出现兼容性问题。每次安装前都应该去机型支持页面找最新版。

### 安装前置条件

在动手装之前，先确认几件事：

1. **操作系统**：Windows 10 64 位 1909 及以上，或 Windows 11
2. **硬件兼容**：华硕主板（Intel/AMD 平台均可）、华硕显卡、或 ROG 笔记本
3. **卸载旧版**：如果之前装过 Armoury Crate 或 Aura Sync 独立版，**先卸载干净再装新版**——残留的服务和驱动是最常见的崩溃原因

### 安装步骤

1. 从下载页获取最新版安装器，**右键以管理员身份运行**
2. 安装器会自动检测你的硬件型号，勾选「Armoury Crate」主组件，其他可选组件按需勾选（GameVisual、Aura Sync 通常默认一起装）
3. 选安装路径（默认 `C:\Program Files (x86)\ASUS\Armoury Crate`），不要装在系统盘以外的盘符——Armoury Crate 的服务需要开机自启，非默认路径可能导致权限问题
4. 点「安装」，等待驱动和服务部署完成
5. **安装完必须重启电脑**，重启后联网等待自动更新到最新功能版本

### 核对是否安装成功

重启后打开 Armoury Crate，检查这几项：

- 左侧导航栏能否正常显示所有模块（首页、设备、Aura Sync、GameVisual 等）
- 「设备」页面能否列出你的主板、显卡、散热器等硬件，且没有黄色感叹号
- 首页中央的性能模式切换按钮能否点击，切换时屏幕有短暂闪烁（正常的显卡驱动重载）

如果设备列表为空或有感叹号，通常是驱动没装全——在设置里找「更新中心」手动扫描更新，或去华硕官网下载对应硬件的最新驱动。

## 📖 使用入门：从首页到深度调校

Armoury Crate 的界面信息量很大，第一次打开容易懵。下面按「看状态 → 调性能 → 玩灯效 → 自动化」这个顺序，把四个高频使用场景拆开讲。

### 首页仪表板：一眼看清整机状态

首页是每次打开的默认界面（可在设置里改），布局分三个区域：

**左侧导航栏**列出全部一级模块，常用的几个：

| 模块 | 什么时候用 |
| --- | --- |
| 设备 | 调风扇曲线、灯光、音频、内存设置 |
| Aura Sync | 整机 RGB 灯效同步中心（比「设备 → 灯光」更完整） |
| GameVisual | 屏幕色彩模式切换（FPS 模式、影院模式等） |
| 情境设定档 | Scenario Profiles——让软件自动切模式 |
| 设置 | 通用选项、更新中心、后台驻留开关 |

**中央大号按钮**是五档性能模式切换：静音、平衡、性能、Turbo、手动。点一下即刻生效，切换时有 1~2 秒的显卡驱动重载闪烁（正常现象）。新手建议先用「平衡」档，跑 3A 游戏时切「Turbo」，笔记本接电源时用「性能」。「手动」档是给超频玩家的——点旁边的「编辑」按钮就能进高级调校界面，拉 CPU 倍频、GPU 频率、功耗墙、风扇曲线全都能改。

**下方系统信息区**是一排功能卡片：CPU/GPU 温度和使用率、内存用量、存储空间、风扇转速、显卡模式。每个卡片都能直接点进去——比如 CPU 卡片点进去就是资源监视器的 CPU 实时图表，风扇卡片点进去就是风扇曲线编辑器。

### 资源监视器：跑压力测试时的好帮手

资源监视器是 Armoury Crate 里最被低估的功能之一。它提供 CPU、GPU、内存、磁盘四大类的实时折线图和关键读数——和 Windows 任务管理器的区别在于，它**直接和 Armoury Crate 的其他模块联动**，看完温度飙高，点一下图表就能跳到风扇曲线编辑器。

默认显示最近 60 秒的实时数据，时间跨度可以改成 10 秒、5 分钟、15 分钟。刷新频率默认 1 秒，对性能敏感的可以改成 2 秒。跑 3DMark 或 Cinebench 压力测试时，建议把时间跨度设为 5 分钟，同时开 CPU 和 GPU 两个通道，观察温度最终稳定在什么数值、风扇转速曲线是否跟上、功耗有没有撞到你设的功耗墙。

> [!TIP]
> **资源监视器不替代任务管理器**。它只看硬件层面的指标，不列出进程。想看哪个程序在吃 CPU/GPU 还是得用任务管理器——资源监视器负责「发现问题」，任务管理器负责「定位原因」。

### Aura Sync：让整机灯效统一

Aura Sync 是 Armoury Crate 的灯效同步核心。在它出现之前，每个 ROG 设备各有各的灯效设置界面，没法跨设备同步——Aura Sync 把这一切合并成一个控制中枢，主板、显卡、键盘、鼠标、散热器、内存灯条的灯效统一管理。

进入 Aura Sync 页面后，左侧会列出所有已识别设备。灰色或带警告图标的条目表示连接有问题，先检查线材或重启设备。主板最多识别三类灯效通道：板载 LED、5V ARGB 接针设备（散热器风扇、内存灯条、RGB 灯带）、USB 外接设备（键盘、鼠标、耳麦）。

首次使用的三步很简单：打开 Armoury Crate → 点左侧 Aura Sync → 等 5~10 秒扫描完设备 → 在下方特效栏选一个效果（比如 Rainbow 彩虹）→ 点「套用」。所有设备应该同时亮起来。

> [!NOTE]
> Armoury Crate 有两个灯效入口别搞混：「设备 → 灯光」只改本机（笔记本机身、台式机板载 LED）的灯效；Aura Sync 管所有同步设备包括外接键鼠。**常规使用以 Aura Sync 为主**。

### 风扇曲线：温度与噪音的平衡点

在「设备 → 风扇」页面，可以为 CPU 风扇和机箱风扇分别绘制转速曲线。横轴是温度（通常 30°C 到 90°C），纵轴是风扇转速百分比。新手可以先选预设的「静音」「标准」「全速」三种曲线，觉得不够再自己拖节点改。

一个实用建议：把 40°C 以下的风扇转速设为 0%（完全停转），60°C 以下设为 30~40%，70°C 之后再线性拉高。日常办公和浏览网页时风扇完全静音，跑游戏时自动跟上——这比一直让风扇维持在 50% 转速舒服得多。

### 情境设定档：让电脑自动适应你的使用场景

Scenario Profiles 是 Armoury Crate 里最「智能」的功能。你可以设置规则：当某个游戏或应用启动时，自动切换到指定的性能模式、灯效方案、风扇曲线。比如：

- 启动《赛博朋克 2077》→ 切 Turbo 模式 + 红色脉动灯效 + 激进风扇曲线
- 启动 Netflix → 切静音模式 + 蓝色呼吸灯效
- 拔掉笔记本电源 → 自动切静音模式 + 降低屏幕亮度

设置方法：进入「情境设定档」→ 点「新增」→ 选择触发条件（进程名、窗口标题、时间段都行）→ 选择要切换的配置文件。保存后下次启动对应应用就会自动生效。

### 彻底卸载：出问题时的最后手段

如果 Armoury Crate 反复崩溃、重装后问题依旧，或者想换版本重新来一遍，普通卸载不够干净——需要走完整的清理流程。

完整清理分七步：正常卸载程序 → 运行华硕官方卸载工具 → 手动禁用残留服务（`services.msc` 里找 LightingService、ARMOURY CRATE Service、ASUS Com Service）→ 清理任务计划程序里的 ASUS/Aura/Armoury 条目 → 手动删除 `%LOCALAPPDATA%\ASUS\Armoury Crate` 等残留目录 → BIOS 里关闭 Armoury Crate 开关（可选）→ 最后重启。

> [!WARNING]
> **普通控制面板卸载 ≠ 清理干净**。Armoury Crate 卸载工具和 Aura Sync 卸载工具是两个不同的程序，如果你同时装了两个，分别跑一次才够。残留的服务和驱动是重装后继续崩溃的主要原因。
