## ✨ TC Games 是什么

TC Games 是一款基于真机投屏的跨平台游戏辅助工具——它把你的安卓手机画面实时投射到电脑屏幕上，同时把键鼠操作转换成手机上的触摸事件，让你用电脑的键鼠体验手机游戏。不同于安卓模拟器在电脑里虚拟一套完整系统，TC Games 选择「真机投屏」技术路线，游戏始终在真实手机上运行，画面采集和输入事件转发由电脑端负责。

这套技术路线带来的核心差异很明显：CPU 和内存占用比模拟器低得多，低配集显电脑也能流畅跑；触摸事件经过的链路更短，USB 连接下延迟通常在 30ms 以内；所有 App 在真实手机环境里原生运行，厂商定制系统的行为与手机上完全一致，不存在模拟器上常见的闪退、无法登录、画面异常等问题——尤其是需要通过安全检测的游戏和银行类 App，真机投屏方案直接绕过了这类门槛。

对于游戏玩家来说，TC Games 还有一个容易被忽视的优势：游戏服务器看到的就是一台真实手机，不会把你标记为模拟器玩家，因此可以与手机端好友正常组队匹配，而不是被系统扔进模拟器玩家池。

当然它也有自身的边界：手机端 App 的权限模型不会因为投屏而改变，手机电量和发热会持续消耗，长时间使用建议接充电器，连接方式也受到物理接口或 WiFi 质量的限制。如果你需要在电脑上多开多个安卓实例，模拟器更合适；如果你追求最低延迟和最真实的手机游戏体验，TC Games 是更好的选择。

## 🔧 安装步骤

TC Games 的安装分为两个部分：电脑端客户端和手机端 Agent，两边都装完并且成功连接才算完成整个安装流程。

### 电脑端安装

1. 从下载页面获取 Windows 安装包，双击运行
2. 选择安装路径（建议使用默认路径，避免权限问题）
3. 等待安装完成，首次启动时如果 Windows 弹出安全提示，选择允许运行即可

> [!WARNING]
> 如果安装时被杀毒软件拦截或误报，属于常见现象——真机投屏需要创建虚拟驱动和网络服务，白名单放行即可，不是恶意行为。

### 手机端安装与权限配置

手机端 Agent 是连接的关键，安装后需要完成以下权限配置：

1. 打开「开发者选项」，开启 **USB 调试**（不同品牌手机路径略有差异：小米在「设置 → 更多设置 → 开发者选项」，华为在「设置 → 关于手机 → 连续点击版本号七次」后开启）
2. 用 USB 数据线连接电脑，手机弹出「USB 调试授权」时点允许，并勾选「始终允许使用这台计算机进行调试」
3. 在手机下拉通知栏中将 USB 连接模式切换为 **文件传输（MTP）**，不要停留在「仅充电」模式

### 首次连接验证

连接成功后，电脑端 TC Games 界面会显示你的手机屏幕画面。此时可以简单测试一下：在电脑上移动鼠标，观察手机屏幕上是否出现对应的触控反馈；按下键盘的几个按键，确认手机端 Agent 有响应提示。

如果是 WiFi 连接场景，确保手机和电脑在同一个局域网下，手机端 Agent 会自动搜索并配对同网段内的电脑。

## 📖 使用入门

### 键鼠灵敏度调节：让准心跟手

鼠标灵敏度决定了「鼠标移动多少距离」对应「手机屏幕上视角转动多少角度」。如果灵敏度太高，鼠标轻微一滑就转了大圈；太低则需要大幅移动鼠标才能转一圈——两种情况都会影响操作体验。

调整入口在 TC Games 电脑端的设置面板里，找到鼠标灵敏度调节项，边调边测试直到手感合适。FPS 游戏对灵敏度要求最高：低倍镜（全息/红点）建议稍高一些，便于快速锁定近距离目标；高倍镜（2x/3x）保持中等，兼顾速度和精确；狙击镜（4x/6x/8x）调到最低，精确瞄准远距离目标。TC Games 为不同倍镜提供独立的灵敏度调节，可以分别设置。

> [!TIP]
> 每个游戏内部也有自己的鼠标灵敏度设置，建议先在游戏内调到一个基准值，再用 TC Games 的灵敏度做微调，两者叠加后效果更可控。FPS 游戏起步区间建议 40~70，根据手感微调。

VIP 版还有一个关键辅助功能叫虚拟准心——开启后鼠标指针就是游戏内的准心位置，移动鼠标到屏幕上的哪个位置，游戏准心就跟随到哪里，比「鼠标 → 视角 → 准心」的传统路径快得多。MOBA 游戏则恰恰相反，不需要 FPS 那种快速转视角，建议将灵敏度调低，让鼠标点击更精准地命中技能按钮和地图位置。

### WASD 方向键失灵排查

WASD 控制是手游键鼠化最核心的操作方式，但也最容易出问题。典型表现包括：按住 W 不放但角色不移动、角色自动往某个方向走、只能走直线不能走对角线、松开按键后角色还在动。遇到这些情况，按以下顺序排查：

**首先检查按键映射的坐标**——进入键位编辑模式，找到 WASD 对应的摇杆标记，确保标记精确拖拽到游戏画面中虚拟摇杆的正中心，覆盖范围与摇杆大小匹配后保存。这是最常见的原因。

**其次确认游戏操作模式没有变化**——很多游戏有多种操作模式（左手摇杆/右手摇杆/陀螺仪+摇杆等），如果游戏更新后默认模式变了，原来配置好的 WASD 坐标就全部错位了。在游戏设置中找到「操作模式」，保持标准的「左手摇杆 + 右手视角」模式即可。

**再检查键盘按键冲突**——电脑上可能有其他程序占用了 WASD 键（比如其他游戏客户端、快捷键管理工具），或者 TC Games 里的 WASD 键位与其他功能的快捷键冲突了。关闭后台程序，检查 TC Games 快捷键设置，必要时把 WASD 映射到其他按键试试。

最后确认 WASD 模式选型是否正确——TC Games 有两种控制方式：

| 模式 | 原理 | 适用场景 |
| --- | --- | --- |
| 传统 WASD | W=上、S=下、A=左、D=右，按一次触一次 | 8 方向精确移动，不需要细腻控制 |
| 摇杆模式 | 按住鼠标 = 拖动虚拟摇杆 | 任意方向连续控制，FPS 游戏首选 |

如果选错了模式，手感会明显不对。比如 FPS 游戏需要细腻的方向控制但用了传统 WASD，角色移动会显得僵硬。在键位编辑面板中切换模式即可。

> [!NOTE]
> 如果以上都排查过还是不行，最彻底的方案：删掉当前键位重新配置一套，检查 TC Games 和手机端 Agent 是否为最新版，完全卸载重装。

### 连接频繁中断的稳定方案

投屏连接断开是另一个高频痛点，不同连接方式的排查思路也不同。

USB 连接掉线的头号原因是数据线质量差——很多便宜的数据线用一段时间后就会接触不良。建议换一根质量好的品牌数据线，优先插主板后置 USB 口，前面板口经常接触不良。另外 Windows 默认会在闲置时自动关闭 USB 设备省电，需要手动关闭：打开设备管理器 → 通用串行总线控制器 → 右键 USB 根集线器 → 属性 → 电源管理 → 取消勾选「允许计算机关闭此设备以节约电源」。

WiFi 连接中断的常见原因是路由器信道干扰——周围邻居的 2.4G WiFi 信号容易互相干扰。解决思路是优先切换到 5G WiFi，如果必须用 2.4G，就手动选择一个干扰较少的信道（1/6/11 三个信道最常用，避开后选信号好的）。同时要检查手机 WiFi 省电设置：进入 WiFi 高级设置，关闭「WiFi 省电模式」，打开「始终保持 WiFi 连接」。

> [!WARNING]
> 如果频繁断连严重影响使用，推荐终极稳定组合：USB 数据线连接 + 设置关闭 USB 省电。无线信号干扰和路由器问题全部绕开，稳定性拉满。

HDMI 转接线连接时要注意转接器发热——长时间运行可能过热断连，建议使用正规品牌支持 4K 60Hz 的转接器，并保持通风。手机长时间 HDMI 输出也会明显发热，某些机型会自动断开视频输出保护硬件，这时可以改用 USB 投屏（发热更低）。

连接中断后 TC Games 通常能自动重连。手动恢复顺序：先检查物理连接，重启手机端 Agent，不行就重启电脑端 TC Games，最彻底的方案是手机设置里强制停止 TC Agent 并清除缓存。

### 虚拟准心：FPS 游戏的关键辅助

虚拟准心功能让鼠标指针直接对应游戏准心位置，省去了「鼠标 → 视角」的中间换算环节，大幅提升 FPS 游戏中的瞄准速度和精度。使用条件是 VIP 版，配置步骤很简单：开启功能，在游戏内设置「准心位置跟随视角」（如果游戏支持），然后移动鼠标测试准心响应速度即可。

功能开启后你会发现预瞄速度明显提升，鼠标移到哪准心就到哪，开枪时机的把握比传统方式快了不止一拍。这个功能配合合适的灵敏度设定，是 TC Games 在 FPS 场景下体验最核心的配置之一。
