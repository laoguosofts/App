## ✨ FamiStudio 是什么：8-bit 音乐人的家用合成器

FamiStudio 是一款面向 NES/Famicom 平台的 8-bit 音乐编辑软件，目标用户是想在 PC 或移动设备上动手写几首复古风格曲子的玩家和创作者。它模拟了红白机原装的音频硬件——方波、三角波、噪声、DPCM 采样四种音源通道，提供钢琴卷帘式的谱面编辑器、乐器包络绘制器、工程级琶音管理等一整套工具链，最终可以导出 NSF、NES ROM 以及常见的音频格式。

和 FamiTracker 等同类工具相比，FamiStudio 的独特之处在于跨平台支持（Windows / Mac / Linux / Android / iOS）、触屏友好的手绘操作、以及零门槛的免费分发策略——整个软件体积不到 10MB，下载解压即用，不需要安装任何运行时依赖。无论是想快速体验 8-bit 编曲的新手，还是需要专业工具链完成完整 ROM 制作的资深 chiptune 音乐人，都能在里面找到合适的工作方式。

## 🔧 安装步骤：绿色解压，开箱即用

FamiStudio 采用免安装的绿色分发模式，所有平台的安装过程本质上就是下载压缩包并解压。以 Windows 平台为例，从下载页获取最新版本的 ZIP 包后，选择一个路径解压即可（建议路径不要包含中文或特殊字符，避免部分工具链读取时出现编码问题）。解压后直接运行 `FamiStudio.exe`，首次启动会自动创建用户配置目录。

> [!TIP] 版本核对建议
> 下载完成后先看一眼压缩包的文件名或解压后的 `version.txt`，确认版本号与下载页标注的一致。0.x 版本迭代较快，有时旧工程在新版本里打开会出现效果参数默认值变化的情况，保持版本对齐能减少排错成本。

移动端安装则简单很多——安卓用户直接从应用商店搜索下载，iOS 用户同理。移动端版本与桌面版功能基本对齐，只是操作方式针对触屏做了适配（长按手绘包络、双指捏合缩放等）。

如果计划从 FamiTracker 迁移旧工程过来，先确认手头的 FTM 文件是官方 0.4.6 版本导出的，第三方修改版导出的文件不保证兼容。导入过程中软件会自动进入 FamiTracker 节拍模式，速度语义与 Tracker 保持一致——如果工程稳定后想切回 FamiStudio 原生节拍模式获得帧级编辑能力，可以在歌曲设置里手动切换，但切换是粗粒度的，建议先通听一遍再决定。

## 📖 使用入门：从鼠标三键到琶音包络的完整工作流

### 桌面版操作逻辑：三键鼠标即全能

桌面版几乎所有操作都能用一只三键鼠标完成，分工极其一致——左键负责添加和删除，右键呼出菜单与框选，中键按住拖动平移视图、滚轮缩放。没有中键或用触控板的用户可以进设置 → 输入，开启「Alt+左键模拟中键」来替代平移操作，触控板用户则可以直接开启双指滑动平移、捏合缩放的原生控制方案。

> [!NOTE] 拿不准先右键
> 软件几乎所有对象都有上下文菜单，菜单里的项目就是该对象的全部能力清单。遇到不确定能不能点、能不能改的地方，先右键看一眼，比到处找按钮高效得多。

工具栏还可以开启 QWERTY 输入模式，把电脑键盘映射成两个八度的钢琴键，边弹边录进谱面——这个功能对捕捉旋律灵感特别有用，不用在卷帘里一格一格点音符了。

### 乐器与包络：画一条曲线定义音色

FamiStudio 的每个乐器由四条包络（音量、方波占空比、音高、DPCM 采样）驱动，包络编辑器的操作是绘制风格：单击某一帧设置数值，按住拖动连续画曲线，拖动右上角箭头改变包络总长度（长度归零即等于禁用这条包络）。

两个特殊点位决定了包络的高级行为：**循环点（Loop）** 在包络底部条带左键点击设置，播到末尾后跳回循环点无限重复——持续音的颤音就该这么画，画一小段正弦然后循环它，而不是手画几百帧；**释放点（Release）** 右键点击设置，当谱面里的音符带上"释放"标记时，包络跳到释放点播完剩余部分，钢琴踏板式的自然衰减全靠它。

包络的数值本质上就是一串数字，支持文本化的复制粘贴——右键拖动选中一段数值可以复制为纯文本，反过来任何以空格、逗号、分号分隔的数字序列都能直接粘贴进来。用 Excel 或 Python 算好一条指数衰减曲线再贴进来，比手画精确得多。包络不跨乐器共享，但搬家极易：按住一条包络按钮拖到另一个乐器上就完成复制，这意味着你可以养一个"母版音色库工程"，随取随用。

### 琶音：让单声道方波演奏和弦

NES 硬件每个通道同一时刻只能发一个音，琶音（Arpeggio）就是解决这个限制的关键技术——它让单个音符快速轮换出多个音高，方波通道靠它就能演奏完整和弦。

FamiStudio 有两种琶音体系：**乐器琶音包络** 属于某个乐器，画在该乐器的包络区里；**工程级琶音** 是全工程共享的独立对象，任何乐器都能挂。工程级琶音的价值在于复用——定义一条"大三和弦"序列（0-4-7），之后任何乐器、任何音符挂上它都是大三和弦，不用为每个乐器重画，也不用在谱面里塞一堆碎音符。创建琶音的流程很简单：琶音区点加号新建，齿轮图标改名换色，点琶音右侧的音符图标在卷帘区编辑序列（纵轴是相对音程，横向是轮换顺序），谱面里给音符挂上就能生效。

常用的琶音玩法包括：存几条常用和弦（大三 0-4-7、小三 0-3-7、大七 0-4-7-11）当和弦键盘用；快速双音轮换造出"伪双声道"的丰满感；极短序列挂在噪声通道上做金属感鼓点点缀。琶音同样支持右键替换和工程清理，没被任何音符使用的琶音可以一键删除。

### 从 FamiTracker 迁移旧作

Tracker 老玩家搬家时先确认三件事：格式版本必须是官方 0.4.6、导入后自动进入 FamiTracker 节拍模式、以及这是"尽量还原"而非"无损克隆"。

常用效果转换对照如下：

| Tracker 效果 | 转换结果 |
| --- | --- |
| 0xy 琶音 | 转为琶音，按值命名 |
| 1xx / 2xx / 3xx / Qxx / Rxx | 全部转为滑音音符 |
| 4xy 颤音 | 速度按对照表换算 |
| Axx 音量滑 | 完整支持 |
| Bxx 跳转 | 转为循环点 |
| Cxx 停止 | 截断歌曲并移除循环点 |
| Fxx 速度 / Gxx 延迟 / Pxx 微调 | 完整支持 |

三大已知差异需要特别注意：**音高包络语义不同**——Tracker 是相对式（逐帧累加），FamiStudio 默认绝对式，同时挂音高与琶音包络的乐器两边行为不同（Tracker 每个琶音音重置包络，FamiStudio 并行跑），这类乐器导入后基本都要手动修；**滑音是有损的**——软件会自动挑选最接近的转换方式（16 半音内优先音符滑奏，否则滑音效果），来回导一圈后听感可能有差；**VRC6 锯齿**——不受占空比影响，音量互导后可能差一倍，校听为准。

迁移工作流建议：先导入通听一遍，把"明显不对"的通道记下来，打开错误日志对照问题通道；音高包络类问题进乐器参数里换模式重调；工程稳定后再考虑切到 FamiStudio 节拍模式获得帧级编辑能力。
