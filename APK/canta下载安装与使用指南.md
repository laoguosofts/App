## ✨ Canta：Android 预装应用的"精准手术刀"

Canta 是一款面向 Android 设备的第三方卸载工具，主打**社区驱动的安全分类**。不同于普通应用管理器只能显示"有 / 没有"，Canta 会为每一个系统应用打上 Universal Debloater 社区维护的**四级风险徽章**——绿色安全、黄色谨慎、红色关键、紫色高危，让用户在动手之前就能清楚知道"卸了这个东西大概会出什么事"。

它的定位不是折腾工具，而是**精准减法**：对那些厂商 ROM 塞进来却又卸不掉的重复浏览器、运营商 SIM 工具、自家游戏中心、预装健康应用……Canta 可以在不 root 的前提下把它们从系统分区里安全移除。前提是设备已经完成 Shizuku 配对——这是 Canta 的底层权限通道，也是整个安装过程里唯一需要耐心的环节。

Canta 免费开源，包名 io.github.samolego.canta，由海外开发者 Samo Hribar 维护。国内主流应用商店（应用宝、华为、小米、OPPO / vivo）普遍没有上架，所以下载渠道需要留意——这也是安装环节最容易卡壳的地方，后面会专门说。

## 🔧 安装与准备

Canta 的安装分两步：**装 Canta 本身** 和 **搞定 Shizuku 配对**。前者一分钟搞定，后者取决于你用哪种配对方式。

### 安装 Canta APK

1. 从上面的下载渠道拿到最新版 APK
2. 允许文件管理器 / 下载器「安装未知来源」——这是 Android 系统权限，不是 Canta 特有的
3. 点击安装，完成后桌面会出现 Canta 图标

> [!WARNING]
> 如果安装时报"解析错误"或"与设备不兼容"，通常是 APK 架构不匹配（比如下成了 armeabi-v7a 但设备是 x86），重新找对应架构的 APK 即可。

### 安装 Shizuku

Shizuku 是 Canta 的底层权限服务，负责代替 root 执行高权限操作。没有它，Canta 只能读取应用列表、不能真正卸载。

安装步骤：

1. 下载 Shizuku APK（国内同样搜不到，GitHub Releases 或 F-Droid 找 `shizuku-project/Shizuku`）
2. 安装完成后打开 Shizuku，它会列出多种配对方式
3. 选择一种配对：常见的有 **无线调试配对**（Android 11+，开发者选项里开无线调试 → 配对码）和 **USB 调试配对**（插数据线 → adb shell 执行 Shizuku 的启动命令）
4. 配对成功后 Shizuku 状态显示「已运行」
5. 回到 Canta，它会自动检测到 Shizuku 服务

> [!TIP]
> Android 16 用户注意：部分官方 Shizuku 版本在 Android 16 上存在兼容问题，社区有专门的兼容分支可以使用，遇到启动失败可以留意。

## 📖 使用入门

### 核心判断力：四个徽章

Canta 最有价值的功能其实不是"卸载"，而是**在卸载之前告诉你"什么能卸、什么不能碰"**。这个判断力来自 Universal Debloater 社区维护的预装应用分类仓库——全球 Android 爱好者按厂商贡献清单，Canta 每次启动自动拉取最新版本。

| 徽章 | 含义 | 建议 | 典型例子 |
| --- | --- | --- | --- |
| 🟢 Safe to Remove | 非必需应用 | 放心选，新手首选 | 重复浏览器、运营商 SIM 工具、厂商游戏中心 |
| 🟡 Advanced | 可能影响部分功能 | 仔细看描述再决定 | Pixel Launcher（卸了显示异常）、健康应用（计步器失效） |
| 🔴 Expert | 系统关键路径 | 一般不建议选 | 输入法框架、Vulkan 驱动、WebView 服务 |
| 🟣 Unsafe | vital system components | Canta 默认不让选，必须手动开开关 | SystemUI、Launcher、Settings 核心 service |

三个要点需要记牢：

- 徽章是**社区判断**，不是物理真理——同一个包名在不同厂商 ROM 里角色可能不同，A 品牌标 🟢 的应用在 B 品牌上可能是 🔴
- 🟢 不代表"零副作用"——Digital Wellbeing、原生日历这类标绿的应用，卸了之后部分厂商的屏幕时间统计和日历同步就会坏
- 没徽章的应用 = 社区还没收录，通常是极新的、小众厂商的、或用户自己装的。拿不准就先查包名，装在 `/vendor` 分区的一律别动

### 主界面操作流程

打开 Canta，主界面就是所有应用的列表，顶部有一个过滤器。基本操作：

1. **过滤器筛选**：选徽章颜色 + 应用类型（系统应用 / 用户应用），快速缩小候选范围
2. **逐个选中**：点应用条目进入详情页，可以看到完整的包名、签名、数据用量和社区描述。描述里会写清楚"这个应用大概是干什么的、卸了可能有什么影响"
3. **批量勾选**：回到列表，多选多个要卸的应用
4. **点回收站**：Canta 会弹出确认对话框，再次确认后执行卸载
5. **已卸载 tab**：所有卸过的应用都在这里，后悔了可以一键恢复

> [!TIP]
> 卸完建议立即重启手机让后台进程彻底清掉，然后进几个常用应用（浏览器、相机、设置、电话）快速测试一下，观察 24 小时看有没有系统报错。

### 隐藏功能：Select All（版本号连击解锁）

Canta 有个藏起来的「全选」按钮——**快速连击设置页底部的版本号 7 次**就能解锁。解锁后，当你在过滤器里选了「徽章 = 🟢」（推荐）的条件，批量操作栏里会多出一个 Select All，点一下自动把所有绿色徽章应用全部选中。

为什么藏起来？因为风险高：一键选全部绿色应用，如果清单质量差或你没仔细核对，后果可能出乎意料。Canta 选择藏着是有意为之——只有知道自己在做什么的用户才会去找这个功能。

用完要不要锁回去？**没有开关**。版本号连击是一次性解锁，下次打开 Canta 还能用。想锁回去只能清除 Canta 数据或卸载重装。所以解锁前想清楚——如果只是偶尔用一次，卸完就清 Canta 数据重置吧。

### 高风险开关：Allow Unsafe Selections

设置里有一个叫「允许不安全选择」的开关，旁边明写着 bootloop 警告。开之前 Canta 在主界面和筛选器里**完全隐藏**紫色徽章的应用；开之后它们会出现在列表里，和绿色一样能选中卸载。

为什么默认锁着？紫色对应的是**系统启动关键组件**——SystemUI 卸了没锁屏没状态栏、Launcher 卸了没桌面图标、Settings 核心 service 卸了进不了设置、Vulkan 驱动卸了渲染全崩、输入法框架卸了没键盘。对 99% 用户这些碰都不该碰。

| 操作 | 恢复难度 |
| --- | --- |
| 卸载 🟢 / 🟡 / 🔴 后后悔 | Canta 里一键恢复 |
| 卸载 🟣 后 bootloop | 必须恢复出厂（用户数据全清） |

真要开的话：只卸你确定安全的那一个特定包，卸完马上重启验证，用完把开关关回去。Preset（预置清单）不受这个开关限制——即使开关关着，Preset 里包含的紫色包 Apply 后一样能选中。进阶用户可以在 Preset 里放好清单，用的时候 Apply 就行，不用单独开开关。

### 卸完记得存 Preset

如果一次卸载后手机一切正常，建议把当前的卸载列表存成 Preset——以后重刷 ROM 或换同厂设备时一键 Apply，不用再逐个手动勾。这也是 Canta 进阶用法里最实用的省时间手段。
