## ✨ Twitch 是什么

Twitch 是全球规模最大的游戏直播和互动社区平台。诞生于 2011 年，最初专注于游戏直播领域，如今已发展为涵盖游戏、音乐、创意制作、体育赛事、生活聊天等多元内容的综合性直播社区。平台上既有职业电竞选手的赛事直播，也有独立创作者的游戏实况、音乐演奏，以及各类技术教程和创意内容分享。

对于观众而言，Twitch 提供了实时弹幕互动、频道关注订阅、游戏掉宝奖励等丰富的参与方式；对于创作者而言，平台提供了完整的内容管理、数据分析、收益变现工具链。用户群体以年轻一代为主，社区氛围强调实时互动和社群归属感。

## 🔧 多平台安装与注意事项

Twitch 提供多平台客户端，不同平台的安装方式和注意点各有区别。

### 桌面端（Windows / macOS）

桌面端客户端适合长时间观看、多窗口管理以及作为主播推流控制端使用。

1. 从下载页获取对应操作系统的安装包，Windows 平台通常为 `.exe` 格式，macOS 为 `.dmg` 格式
2. 双击运行安装程序，macOS 用户需将 Twitch 应用拖入「应用程序」文件夹
3. Windows 安装过程中如遇杀毒软件误报，属于常见现象——安装包为数字签名的官方版本，可安全放行
4. 安装完成后首次启动会引导登录已有账号或注册新账号

### Android 移动端

Android 端适合移动场景下快速观看直播和参与互动。

1. 优先通过 Google Play 商店搜索安装，确保获取到最新官方版本
2. 对于无法访问 Google Play 的用户，可从下载页获取 APK 文件手动安装
3. 手动安装前需在系统设置中授权「未知来源」应用安装权限（设置 → 安全 → 允许安装未知应用）
4. 建议在安装后关闭未知来源权限，仅对本次安装授权即可

### iOS 移动端

iOS 平台由于系统限制，只能通过 App Store 官方渠道获取。

1. 在 App Store 搜索「Twitch」
2. 确认开发商为 Twitch Interactive, Inc. 后点击安装
3. 安装过程可能需要输入 Apple ID 密码或使用 Face ID 验证

> [!WARNING]
> 安装后建议核对版本号：客户端设置页或应用商店页面应显示与下载页标注一致的版本号，避免安装第三方二次分发的非官方版本。

## 📖 核心功能与进阶玩法

### 掉宝玩法：看直播领游戏奖励

掉宝（Twitch Drops）是 Twitch 与游戏厂商合作推出的活动——观看指定主播的直播满一定时长，即可获得游戏内道具、皮肤、货币等奖励。掉宝奖励的前提是将你的 Twitch 账号与游戏厂商的账号绑定。

**绑定的核心逻辑**很简单：掉宝奖励最终要发到你的游戏内账号里，而 Twitch 只知道你在 Twitch 上的账号身份。绑定就是告诉游戏厂商「这个 Twitch 用户就是你这边那个玩家」。没绑定的话，观看时长可能被追踪到了，但奖励发不出去，等于白看。

虽然不同游戏厂商的绑定页面界面不同，但通用流程大同小异：

1. 在 Twitch 端进入掉宝活动页面，点击「连接 / Connect」按钮
2. 浏览器跳转到游戏厂商的账号登录页面，用该游戏的账号登录
3. 厂商页面显示「确认关联」，点击确认后页面自动跳回 Twitch
4. Twitch 显示绑定成功，全程通常不超过 2 分钟

> [!TIP]
> 一个 Twitch 账号同时只能绑定同一家厂商的一个游戏账号。如果想换绑，需要先在厂商账号设置页里解除 Twitch 关联。

各主要厂商的绑定入口汇总如下：

| 厂商 | 登录账号 | 绑定入口 |
| --- | --- | --- |
| 暴雪 | Battle.net / 战网账号 | 掉宝页面 Connect 按钮跳转 |
| Riot（LOL / Valorant） | Riot Games 账号 | Connect 按钮 → Riot 登录页 |
| 动视（使命召唤） | Activision 账号 | Activision 账号页面里的 Twitch 关联 |
| 育碧 | Ubisoft Connect 账号 | Connect 按钮 → Ubisoft 登录 |
| Epic Games（堡垒之夜） | Epic Games 账号 | 同上 |

绑定后无需额外操作，正常去看开启掉宝的直播即可，Twitch 会自动追踪观看时长，达标后通知领取。

### Prime Gaming：Amazon Prime 用户的联动福利

Prime Gaming 是 Amazon Prime 订阅服务的一部分——只要是 Amazon Prime 会员，就自动享有 Prime Gaming 全部福利，无需额外付费。在 Twitch 平台上的核心联动福利包括：

**免费频道订阅（每月 1 次）**：每个 Prime 会员每月可在 Twitch 上使用一次免费 Tier 1 频道订阅（价值约 $4.99）。进入想订阅的主播频道，点击订阅按钮找到「使用 Prime Sub」选项确认即可。注意每月限量一次、过期不累积。

**游戏内福利包（每月轮换）**：Prime Gaming 每月与不同游戏厂商合作推出限时领取的游戏内道具包。热门游戏如英雄联盟、无畏契约、PUBG、使命召唤等都曾推出过 Prime 专属福利。每个福利包需单独点击「领取」，领完后还需要在对应游戏里关联账号才能收到道具。

**每月免费游戏**：Prime Gaming 每月会放出一组可免费下载并永久保有的 PC 游戏，通过 Amazon Games App 或 GOG 下载。

关联 Amazon Prime 到 Twitch 的步骤：在网页端登录 Twitch，点击顶部导航的 Prime Gaming 入口，按提示登录 Amazon 账号完成关联即可。

### 创作者仪表板：主播的管理工作台

如果你计划在 Twitch 开播，创作者仪表板（Creator Dashboard）是管理频道的核心后台。网页端入口为：登录 Twitch → 右上角头像 → 创作者仪表板。

仪表板包含以下主要模块：

| 模块 | 功能 |
| --- | --- |
| 概览（Overview） | 最近直播数据、观众趋势、收益摘要、频道健康度评分 |
| 直播管理（Stream Manager） | 开播前的标题、分类、标签设置和开播通知 |
| 视频（Video Producer） | VOD 回放管理、缩略图上传、简介编辑 |
| 分析（Analytics） | 详细的观众数据、流量来源、留存率、峰值时段 |
| 收益（Monetization） | 订阅管理、Bits 收入、广告设置 |
| 社区（Community） | 频道点数、自定义表情、徽章、自动聊天规则 |

手机 App 里的主播功能比较有限，主要用于开播前填信息和开播中看数据，仪表板的大部分管理功能需在电脑网页端操作。

### 频道管理基础：自动规则与人工配合

频道管理涉及自动规则、人工管理员、社区准则三件事配合完成。

**自动防垃圾工具**在频道设置 → 安全与隐私 → 聊天保护中可找到，主要功能包括：

- **慢速模式（Slow Mode）**：限制用户发言间隔，防止刷屏
- **关注者模式（Followers Only）**：只允许关注超过指定时长的人发言
- **订阅者模式（Sub Only）**：只允许订阅者发言
- **重复消息过滤**：自动屏蔽内容过于相似的重复消息
- **链接过滤**：自动屏蔽含外站链接的消息
- **关键词屏蔽**：自定义敏感关键词，命中自动屏蔽

这些规则默认关闭，可根据频道情况选择性开启。新手频道人少时不开也没问题，人多起来后逐步启用。

**频道管理员（Moderators）**是从信任的观众中选出来帮忙管理的人，拥有临时禁言、永久封禁、清空聊天、临时调整聊天模式等权限。一般频道规模的 Mod 配置建议：

| 观众规模 | 建议 Mod 数量 |
| --- | --- |
| 几十人 | 0~1 个（主播自己管） |
| 几百人 | 2~3 个 |
| 上千人 | 5+ 个，分时段轮班 |

> [!NOTE]
> 管理员权限不可轻授——一次 `/mod` 命令就能让对方拥有封禁所有观众的能力，务必从长期关注、熟悉频道氛围、值得信任的观众中挑选。

在频道简介里放一份清晰的社区规则能大幅减少管理员工作量。好的频道规则应语言简短（3~5 条核心规则）、正面表达（说「请尊重所有人」比「不要骚扰别人」效果更好）、有后果提示（说明违规处理方式）。
