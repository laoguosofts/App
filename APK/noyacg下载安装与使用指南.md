## ✨ NoyAcg 是什么

NoyAcg 是一款开源的漫画阅读器，专为手机端漫迷打造。它通过技术手段聚合了多个公开漫画平台的资源，用户在一个应用里就能同时追国漫、日漫、韩漫以及港台、欧美等不同地区的作品，并且支持多源切换——某个源加载失败或翻译不满意时，换一个源就能继续看。

在功能层面，NoyAcg 提供了相当丰富的自定义选项。翻页方式支持点击左右、音量键、滑动、上下滚动四种模式，阅读参数里可以调整画面缩放、自动裁边、亮度、色彩滤镜，甚至支持按漫画保存独立设置（日漫用单页双页、韩漫用滚动下拉，切换时自动切换配置）。夜间模式除了界面变暗，还能设置定时自动开关、跟随系统深色模式，部分黑白漫画在反色显示下效果会更好。

订阅追更也是核心功能之一。订阅漫画后应用会周期性检测更新，系统通知栏弹出提醒；如果收不到通知，通常是后台运行权限被系统省电策略杀掉了。支持导入本地漫画文件，格式覆盖 CBZ、CBR、ZIP 压缩包以及 JPG/PNG 图片文件夹。整体定位是「把漫迷看漫画这件事从找资源到追更新一站式解决」的工具。

## 🔧 安装步骤

NoyAcg 主要面向 Android 平台，安装流程和大多数第三方 APK 类似，但有几个地方需要注意。

### 未知来源授权

从官方下载页拿到 APK 后，首次安装时手机可能会弹窗拦截。不同品牌的授权路径略有差异，但核心都是在系统设置里打开「允许安装未知来源应用」。以 MIUI 为例：设置 → 隐私保护 → 特殊权限设置 → 安装未知应用 → 找到 NoyAcg 的下载来源（比如浏览器或文件管理器）→ 允许。

> [!WARNING] 授权后记得关闭
> 装完 NoyAcg 之后，建议把「允许安装未知来源」的开关关掉，避免其他来源的 APK 随意安装。

### 版本核对

安装前核对两个信息：APK 文件大小和版本号。官方下载页会标注每个版本的文件体积，下载完成后对比一下，差距过大可能是下载不完整或文件被篡改。版本号可以在安装包详情里看到，和官网对得上就没问题。

### 安装完成后的首次启动

打开应用时，Android 13 及以上版本会弹出通知权限请求，允许即可——这是订阅更新通知能正常推送的前提。首次启动后建议先进入应用设置，确认一下后台运行权限是否已经到位（不同品牌的设置路径在后续常见问题里有详细列表）。

## 📖 使用入门

### 找漫画：多源聚合怎么用

NoyAcg 聚合了多个公开漫画平台的资源，每部漫画可能对应好几个来源。进入漫画详情页后，章节列表上方会有源切换的下拉菜单。多源切换有三个实用场景：

- 某个源加载失败或图片裂了，切到另一个源继续看
- 同一部漫画不同翻译组的版本质量不同，挑自己满意的
- 不同源的更新时间有差异，总有一个先更新

平台内置了题材分类筛选，按热血、恋爱、悬疑、搞笑、科幻等标签加上状态（连载中/已完结）、评分、更新时间组合过滤，比单纯搜漫画名效率高很多。资源类型覆盖国漫、日漫、韩漫三大主力，也兼顾港台和欧美作品。

### 调设置：打造专属阅读体验

NoyAcg 的自定义入口集中在两处：阅读界面点击屏幕中央弹出的工具栏，以及应用设置里的「阅读设置」。以下是几个值得优先调整的参数。

**翻页方式**是最影响阅读手感的设置。四种模式各有适用人群：

| 模式 | 适合场景 |
| --- | --- |
| 点击左右翻页 | 喜欢传统翻页手感，习惯点击操作的用户 |
| 音量键翻页 | 躺着看、单手操控时最方便 |
| 滑动翻页 | 手势流畅型用户，左右滑动自然过渡 |
| 上下滚动 | 韩漫条漫专用，竖屏长图拉到底 |

翻页动画建议设为「无动画」，长时间阅读时减少视觉干扰。如果喜欢仪式感，淡入淡出或翻书效果也可以，但动画越多性能消耗越大。

**画面裁剪和缩放**对画质影响很大。很多漫画自带黑边或白边，开启「自动裁边」后画面会智能识别并去掉多余边框，阅读区域最大化。默认缩放比例设为 100% 最稳妥，觉得对话框文字太小可以双指捏合临时放大，或在阅读设置里调整「对话文字缩放」比例。

**夜间模式**分两层：界面变暗是基础，更深一层是漫画反色显示。黑白漫画反色后线条会更干净，但彩漫反色后色彩会很奇怪，建议彩漫只开界面夜间模式、保持画面原色。如果有定时开关功能，可以设置晚上 9 点自动开启、早上 7 点自动关闭，或者跟随系统的深色模式。

亮度调节有三种方式：工具栏滑块手动调、跟随系统亮度、智能亮度根据画面自动微调。实际使用中，深夜关灯场景推荐 10%~20% 亮度搭配夜间模式；白天阳光下拉到最高亮度确保看清；室内正常光线 50%~70% 就够了。

> [!TIP] 按漫画单独设置
> 如果同时看日漫和韩漫，可以分别给它们保存独立的阅读设置：日漫用点击翻页 + 双页模式 + 小字号，韩漫用上下滚动 + 大字号 + 自动裁边。切换漫画时应用会自动切换到对应的配置。

### 追更新：订阅与通知

在漫画详情页点「订阅」按钮就能加入追更列表。应用会每隔几小时自动检测订阅的漫画是否有新章节，有更新就通过系统通知栏推送提醒。

如果订阅了但收不到通知，按以下顺序排查：

1. 确认漫画真的有更新，手动打开章节列表看一下
2. 确认订阅状态，按钮显示「已订阅」才生效
3. 检查系统通知权限是否被关掉，路径通常是手机设置 → 应用管理 → NoyAcg → 通知 → 允许显示通知
4. 检查应用内的通知设置，订阅更新通知的开关是否打开
5. **关键：后台运行权限**——Android 为了省电会杀掉后台应用，通知推送也就发不出来。各品牌的设置路径不一样：

| 品牌 | 设置路径 |
| --- | --- |
| 小米/红米 | 设置 → 应用设置 → 应用管理 → NoyAcg → 自启动 → 开启；省电策略选「无限制」 |
| 华为 | 设置 → 电池 → 启动管理 → NoyAcg → 允许自动运行；锁屏清理内存加白名单 |
| OPPO/vivo | 设置 → 电池 → 应用冻结/后台管理 → NoyAcg → 允许后台运行 |
| 三星 | 设置 → 电池和设备维护 → 电池 → 后台使用限制 → NoyAcg → 允许后台活动 |
| 原生 Android | 设置 → 应用 → NoyAcg → 电池 → 电池限制 → 无限制 |

> [!NOTE] 手动刷新比等通知更主动
> 应用的更新检测是周期性的，不是实时推送。如果想第一时间知道有没有更新，进入订阅列表下拉刷新，应用会立即检查所有订阅漫画，有更新的话立刻弹出通知。部分版本支持自定义检测频率，可以调短一点。

如果所有订阅都收不到通知，大概率是系统权限或后台运行的问题，按上面第 3、5 步仔细检查一遍。还是不行就卸载重装，让权限重新初始化。如果只有某一部漫画收不到通知，可能是那部漫画的源不稳定，切换到其他源试试，或者先取消订阅再重新订阅。

### 导入本地漫画

除了在线阅读，NoyAcg 也支持导入本地漫画文件。格式方面，CBZ、CBR 是业界标准的漫画归档格式（压缩包内含有序图片），ZIP 通用压缩包也能识别，直接的 JPG/PNG 图片文件夹按文件名排序就能读。导入后进入漫画库，按本地漫画分类就能找到。
