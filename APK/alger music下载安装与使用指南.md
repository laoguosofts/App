## ✨ AlgerMusicPlayer 是什么

AlgerMusicPlayer 是一个以网易云音乐为核心数据源的第三方跨平台播放器。它通过登录网易云账号直接拉取你已有的歌单、收藏和关注列表，配合 UNM（统一音源模块）自动匹配灰色歌曲的替代音源，让因版权受限无法播放的曲目也能正常试听和下载。

在音质方面，如果你持有网易云 VIP 账号，Alger 会解锁无损和 Hi-Res 级别的播放与下载能力；而普通用户也能享受标准到高清区间的在线播放。下载文件的命名模板、缓存策略、音源优先级等细节都开放了自定义，适合追求整齐管理本地音乐库的重度用户。

适用场景很广：网易云 VIP 用户想要无损下载、灰色歌曲占比高想听听有没有替代音源、多设备歌单对齐、用文件管理器批量归档本地音乐——这些都是 Alger 的强项。它不修改网易云服务端的歌单结构，在 Alger 里的收藏和取消收藏操作会同步回去，但创建歌单、删除歌单内歌曲等写操作因版本不同可能有所限制，敏感操作前建议先用网易云官方客户端确认一下。

## 🔧 安装步骤

AlgerMusicPlayer 支持 Windows、Android、macOS 和 Linux 等主流平台，各平台的安装方式略有差异。

**Windows 用户**：下载 exe 安装包后双击运行，安装向导会提示选择安装路径。默认路径在系统盘 Program Files 下，如果 C 盘空间紧张可以自定义到其他盘。杀毒软件首次运行时可能会因程序联网行为弹出误报提示，这是播放器需要拉取网易云数据和 UNM 音源匹配导致的——在杀毒软件里加一条白名单即可。安装完成后桌面上会生成快捷方式，首次启动前确保系统已安装对应版本的运行环境（通常安装包自带，无需额外操作）。

**Android 用户**：下载 APK 后安装时需要在系统设置中开启「未知来源」权限。不同安卓版本的开启入口略有差异，一般在「安全设置」或「隐私」菜单下可以找到。如果手机自带的应用商店里有同名应用，优先从应用商店安装，可以免去手动权限配置的麻烦。

**版本核对提醒**：下载前建议核对一下下载页面标注的版本号和发布日期，避免下载到过期的安装包。Alger 处于活跃迭代期，新版本会修复音源匹配问题和播放卡顿，跟进更新是个好习惯。

## 📖 使用入门

### 登录与歌单同步

首次打开 AlgerMusicPlayer，界面会引导你登录网易云账号。登录完成后，Alger 会**自动执行全量同步**——拉取你创建的所有歌单、你收藏或订阅的他人歌单、以及歌单内的全部歌曲条目。同步完成后，左侧导航栏的结构与网易云官方客户端基本一致。

之后每次打开 Alger，它会检查网易云服务端的歌单变更（新增歌曲、歌单更新等），自动做**增量同步**，不需要每次都手动触发。如果你在手机网易云里新建了歌单或加了歌，等自动同步可能有几秒延迟，可以在 **设置 → 账号** 页面点击「手动同步歌单」强制刷新，立即可见。

> [!TIP]
> 跨设备歌单对齐时要注意：Alger 里的收藏和取消收藏操作会写回网易云服务端，但创建歌单、删除歌单内歌曲等写操作因版本不同可能不支持。敏感操作前建议先用网易云官方客户端确认一下实际状态。

### 灰色歌曲的特别表现

网易云官方客户端里显示为灰色、无法播放的歌曲，在 Alger 里会保持同样的灰色图标位置不变，但 UNM 模块会在后台自动尝试匹配其他平台的替代音源。匹配结果分三种情况：

| 状态 | 含义 |
| --- | --- |
| 灰色图标保持 | 网易云不可播，UNM 也没找到合适的替代音源 |
| 正常图标 + 可点击播放 | UNM 成功替换了音源，在 Alger 里能正常听 |
| 正常图标 + 点进去是别的歌 | UNM 匹配到了重名的错误音源 |

歌单本身不会因为灰色歌曲被过滤或隐藏——你可以看到完整歌单，逐首尝试播放，由 UNM 逐个去解。这是 Alger 相比其他播放器的一大优点：它不替你做判断，而是把选择权交给你。

### VIP 账号的高品质体验

登录网易云 VIP 账号后，Alger 会自动解锁更高的音质档位：

| 功能 | 普通用户 | VIP |
| --- | --- | --- |
| 在线播放音质 | 标准 ~ 高清（128~320kbps） | 无损 / Hi-Res（最高 24bit/192kHz） |
| 下载音质 | 跟随音源 | 可下载无损 |
| 灰色歌曲解析 | 可触发 UNM，但音源质量不一定高 | VIP 音源也参与 UNM 优先级 |
| 独家曲目 | 部分版权受限 | VIP 可听更多（灰色解析仍有盲区） |

不过 VIP 对灰色歌曲的帮助有个微妙的边界：灰色歌曲通过 UNM 解析后，播放和下载的音源来自 QQ、酷我等其他平台，这些替代音源通常不支持无损下载，最高可能也就 320kbps MP3——灰色歌曲的音质上限由替代音源决定，不是网易云 VIP 等级。

在 **设置 → 下载 → 下载音质偏好** 里可以配置默认下载音质：

- 跟随音源（推荐，自动选最高可用）
- 强制 128kbps（节约磁盘）
- 强制 320kbps（平衡音质与体积）
- 强制无损（磁盘够大的话）

### 下载文件命名模板

Alger 的下载文件命名模板在 **设置 → 下载 → 文件名模板** 里配置，支持以下变量：

| 变量 | 含义 | 示例值 |
| --- | --- | --- |
| `{track}` | 曲目号 | `01` |
| `{title}` | 歌曲名 | `夜曲` |
| `{artist}` | 艺术家 | `周杰伦` |
| `{album}` | 专辑名 | `十一月的萧邦` |
| `{year}` | 发行年份 | `2005` |
| `{genre}` | 流派 | `流行` |

模板写法直接拼变量，比如：

- **经典简洁**：`{track}-{title}` → `01-夜曲.mp3`（适合已按艺术家/专辑分好目录的情况）
- **完整信息**：`{track}-{artist}-{title}` → `01-周杰伦-夜曲.mp3`（适合不按专辑分目录的混放场景）
- **无损收藏风**：`{year}-{artist}-{album}-{track}-{title}` → `2005-周杰伦-十一月的萧邦-01-夜曲.flac`（配合 Foobar2000 等扫描归档）

> [!NOTE]
> Alger 会自动过滤 Windows 不允许的文件名字符（`\ / : * ? " < > |`）替换为下划线 `_`，文件名超长时会自动截断加后缀，不会因为这些原因导致下载失败。

### 缓存清理策略

在线播放产生的缓存文件积累过多时会拖慢播放速度、占用磁盘，定期清理一下是个好习惯。Alger 在 **设置 → 缓存** 页面提供了三种清理方式：

**手动选择性清理（推荐）**：按音乐缓存、歌词缓存、MV 缓存、播客缓存四类分别清理。每个类型都会先显示当前占用了多少 MB 或 GB，你可以根据磁盘状况决定清哪些——MV 和播客通常体积最大，优先考虑这两类。

**一键全部清理**：直接清空所有类型的缓存。注意这不会影响已下载的音乐文件、登录凭证、设置配置、播放历史、歌单数据和本地扫描的音乐索引——这些是分开存储的。清理后第一次在线播放会慢几秒，需要重新拉取缓存，第二次就恢复正常速度了。

**删除缓存目录（极端）**：如果 Alger 本身出了缓存相关的 bug，或者你想彻底重置，关闭 Alger 后手动找到缓存目录整个删掉，重新打开会自动重建。

| 信号 | 说明 |
| --- | --- |
| C 盘空间越来越少 | 缓存积累太多，占了系统盘 |
| 播放变慢 / 卡顿 | 缓存过大或缓存文件损坏 |
| 想重新拉最新歌词 | 旧缓存里的歌词可能已过期 |
| 切换了音源优先级 | 旧缓存还是老音源的，清了重拉 |

以上四种情况出现时，就该考虑清理一下缓存了。
