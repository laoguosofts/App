## ✨ BeReal 是什么：反焦虑的真实社交

BeReal 是一款主打「真实」的社交应用，每天会在一个随机时间推送通知，要求用户在 2 分钟内用前后摄像头同时拍下当下的画面并发布。没有滤镜、没有修图、没有点赞数、不能从相册上传——这一连串的「不做」构成了 BeReal 的独特气质。

它的核心理念可以概括为**减法设计**：主动砍掉滤镜系统、修图工具、点赞计数、相册上传甚至 AI 生成内容，把用户从「内容生产者」的身份中解放出来，回到「生活分享者」的角色。你不需要准备、不需要挑选、不需要修饰——只需要在那一刻、在那个地方、用你真实的条件，拍一张照片发出去。

这种设计吸引了大量厌倦传统社交平台表演压力的用户。它也发展出了 RealPeople（认证个人）和 RealBrand（认证品牌）的官方认证体系，让品牌能在不破坏真实感的前提下与粉丝互动。RealMoji——用前置摄像头自拍表情来回应朋友——更是彻底颠覆了传统的点赞模式。

适合谁用？如果你觉得刷朋友圈/刷 Instagram 时总在比较谁的照片更好看、谁的点赞更多，如果你厌倦了精心修图半小时只为发一张自拍，BeReal 可能是一种更轻松的社交方式。

## 🔧 安装步骤

### Android 用户

1. 打开 Google Play，搜索「BeReal」
2. 找到官方应用（开发者为 BeReal SAS），点击「安装」
3. 等待下载完成后自动安装
4. 如果从第三方渠道获取安装包，需在系统设置中允许「未知来源」应用安装；安装完成后建议关闭该权限

> [!TIP]
> 建议优先从官方应用商店下载，第三方安装包可能存在版本滞后或安全风险。安装前核对应用包名应为 `com.bereal.android`。

### iOS 用户

1. 打开 App Store，搜索「BeReal」
2. 找到官方应用，点击「获取」
3. 使用 Face ID / Touch ID / Apple ID 密码确认下载
4. 下载完成后自动安装在主屏幕

> [!NOTE]
> BeReal 的 iOS 版本要求 iOS 14.0 及以上，安装前可检查系统版本是否符合。

### 首次启动

安装完成后首次打开应用，需要完成以下初始化：

1. 允许**相机权限**（前后摄像头都要——BeReal 同时拍前后两张）
2. 允许**通知权限**（必须开启——否则收不到每日随机通知）
3. 允许**位置权限**（可选，用于添加地理位置标签）
4. 注册账号，可以用手机号或电子邮箱

## 📖 每日仪式与互动玩法

### 每日一次的随机通知

BeReal 每天会在一个随机时间点推送通知，收到通知后你有**2 分钟**时间完成拍摄并发布。这个时间点全球统一，但没有人知道具体是什么时候——可能是早上通勤的地铁上，可能是午休时间，也可能是深夜加班。

2 分钟窗口是「推荐时限」而非硬性截止。过了 2 分钟你仍然可以随时发布当天的 BeReal，发布时会显示「晚了 X 分钟发布」，这个标记对所有能看到你 BeReal 的人可见。

> [!WARNING]
> 关键规则：**只有你发布了自己的 BeReal，才能查看好友当天的 BeReal**。不管你是 2 分钟内还是超时发布，这个公平机制都适用。

### RealMoji：自拍表情代替点赞

BeReal 没有点赞系统，取而代之的是 **RealMoji**——用前置摄像头自拍一个表情来回应朋友的 BeReal。

创建 RealMoji 的步骤：

1. 在朋友的 BeReal 上，点击右下角的笑脸图标或双击卡片
2. 选择一个表情槽位（共有 6 个槽位）
3. 实时预览前置摄像头画面，做出想要的表情
4. 按下白色按钮捕捉，检查效果后保存

你可以创建大笑、惊讶、竖大拇指、捂脸等多种表情，分别存放在不同槽位。回应朋友时点击笑脸图标，选一个 RealMoji 发送即可。每个 BeReal 只能发一个 RealMoji，但可以随时更换你的反应——朋友会看到最新的那个。

还有一种 **Instant RealMoji**：长按笑脸图标可以即时拍一个一次性反应，不会保存到槽位里，适合临时有感而发的瞬间。

### 认证账号 RealPeople 与 RealBrand

BeReal 有一套官方认证体系，面向知名个人和品牌：

| 维度 | 普通用户 | RealPeople | RealBrand |
| --- | --- | --- | --- |
| 认证标识 | 无 | 有 RealPeople 标识 | 有 RealBrand 标识 |
| 粉丝群 | 无 | RealFans 体系 | RealFans 体系 |
| 发现页曝光 | 仅好友的好友 | 是 | 是 |
| 专属内容 | 无 | 可以给 RealFans | 可以给 RealFans |

认证账号除了和普通用户一样发布 BeReal 外，还能运营 RealFans 粉丝群、发布粉丝专属内容，并在发现页面获得额外曝光。申请认证需要已有 BeReal 账号，且能提供知名身份或品牌的证明材料。

### 减法设计背后的逻辑

BeReal 的一系列「不做」并非功能缺失，而是经过深思熟虑的产品选择：

- **无滤镜无修图**：砍掉「选哪款滤镜、调多少磨皮」这条充满焦虑的决策链，让用户从内容生产者回到生活分享者
- **禁止相册上传**：强制「现在拍、现在发」，你不能提前准备、不能事后挑最好的那张，只能在那一刻用真实条件拍摄
- **无点赞计数**：用 RealMoji 反应替代冷冰冰的数字累积，社交回应回到「人」的层面
- **零 AI 政策**：官方首页明确标注「no AIs allowed」，在 AI 生成内容泛滥的今天，把真实性作为平台核心价值

这种设计的代价也很明显——喜欢修图、喜欢 AI 辅助创作的用户可能觉得太单调，品牌账号的运营方式也和传统社交平台完全不同。但 BeReal 选择坚持立场，把「反焦虑」和「真实感」做到极致。

### 超时发布的宽松机制

BeReal 允许超时发布但标记时间，体现了它一贯的反焦虑哲学：

- 给你时间压力（2 分钟倒计时）→ 促进即时分享
- 不给你硬性惩罚（超时也能发）→ 不让错过变成负担
- 诚实标记（「晚了 X 分钟」）→ 不伪装成完美

超时发布不影响 Streak 连续打卡计数——只要当天发布就算数，也不影响 Memories 档案记录。常见的超时场景包括开会中收到通知不方便拍、睡觉中收到通知醒来补拍、手机不在身边找回后立即发布等。

从 2024 年起，RealMoji 反应和评论也会被保存到 Memories 档案里，你不仅能回顾自己发过的 BeReal，还能看到当时给朋友发了哪些反应。
