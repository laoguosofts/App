## ✨ clipboard 是什么：把安卓剪贴板用成生产力工具

clipboard 是一款面向安卓系统的剪贴板管理增强工具。它解决了系统自带剪贴板"只存一条"的核心痛点，把每一次复制都自动纳入可搜索、可分类的历史库，配合悬浮窗就地调用和备忘模板功能，让日常复制粘贴这件小事变得顺手且高效。

核心能力集中在三个方向：**约 1000 条长期历史**的自动记录与搜索、**悬浮窗/悬浮按钮**的快捷调用（无需唤起键盘）、以及**备忘模板**的固定短语库。对客服、运营、内容创作者这类高频复制粘贴的人群来说，它更像一个轻量的文本管理中枢——把散落各处的复制内容收进同一个可搜索的仓库，再用悬浮层随时贴出来。

值得一提的是，clipboard 与安卓输入法自带的剪贴板并不冲突，两者是并存而非替代关系。输入法剪贴板偏"手边托盘"（几十条上限、随输入法清理），clipboard 则是"档案库"（千条历史、可备份导出），各自覆盖不同场景。

## 🔧 四步装好：转存、下载、安装、打开

整个安装流程两三分钟即可完成。不同品牌手机的菜单名称略有差异，以下步骤以通用安卓系统为准。

1. **转存**：先进入网盘分享页，把安装包转存到自己的网盘账号——这样做的好处是将来重装或换机时可以直接从自己的网盘取，不依赖原始分享链接是否还有效。

2. **下载**：在自己的网盘里点下载，安装包会落到手机下载目录。可以顺便核对一下文件大小和版本号，确认是你想要的那一份。

3. **安装**：打开系统文件管理器，找到刚下载的安装包并点开。
   > [!WARNING]
   > 未从应用商店安装时，安卓系统会弹出"不允许安装未知来源应用"的安全拦截。这是正常机制——按弹窗提示跳到设置页，允许**这一次**安装即可，授权通常只对当前安装生效，装完自动收回，不需要长期打开。

4. **打开**：安装完成后直接点"打开"，你会看到闪屏一闪而过，随后进入主界面——此刻它就是你的新剪贴板了。

装好后的第一件事，官方推荐做两件小设置：

- 点主界面右下角的编辑按钮，把一条你最常用的文本（比如手机号、收件地址或常用邮箱）存进列表，从这一条开始养成使用习惯；
- 进设置里把**自动记录**打开，让系统每次复制动作都自动进历史。

安装完成后，下载目录里的安装包可以安全删除——应用本体已经装进系统，真正值得保留的是**转存在你自己网盘里的那份**，将来重装、换机还要靠它。

## 📖 使用入门：从悬浮窗到历史管理，一篇看懂

clipboard 的用法可以按"日常轻量使用"到"进阶深度管理"分成几个层次来理解。

### 三层剪贴板的分工

安卓手机上的剪贴板其实有三层，clipboard 是其中的第三层补充：

| 层级 | 提供者 | 特点 |
|---|---|---|
| 系统剪贴板 | 安卓系统 | 只存当前一条，任何应用都能用 |
| 输入法剪贴板 | 搜狗/百度/讯飞等 | 随输入法走，键盘工具条内调用 |
| clipboard | 本工具 | 悬浮层就地取用 + 约 1000 条历史 + 备忘模板 |

装了 clipboard 后，前两层照常工作——你不会被剥夺任何原有能力。同一次复制可能在输入法剪贴板和 clipboard 两边都留痕，这属于正常现象，互相不影响对方的记录和清理。

实际使用中两派方法都成立：

- **悬浮流**：日常全走 clipboard（悬浮窗就地粘贴，不用把键盘调出来），输入法剪贴板当它不存在；
- **键盘流**：正在打字时用输入法剪贴板顺手，查更久远的历史时才进 clipboard——把它当"档案库"，键盘剪贴板当"手边托盘"。

### 备份与恢复：把历史装进一个文件

clipboard 的官方备份通道是设置页的 **Import / Export**，它能把**剪贴板历史和备忘**整体打包成一个数据文件导出，需要时再整体导入恢复。

> [!TIP]
> 官方描述里特别注明备份范围包含**历史和备忘两者**，不只是备忘。动手导出前确认一下你的备忘模板也能一并带走。

导出流程很简单：

1. 进入设置 → Import / Export；
2. 点 **Export**，数据文件会生成到设备的文档目录；
3. 把这个文件存到你信任的地方——网盘、电脑、另一个文件夹都行。

恢复时把备份文件放到新环境能访问的位置，进设置点 **IMPORT** 就完成了。

以下几种场景**务必先备份**：卸载重装（换签名版本必须先卸载，卸载即清数据）、恢复出厂或清应用数据、换新手机、以及批量清空历史之前。换机迁移的完整路径就是"旧手机 Export → 传文件 → 新手机装好后 Import"四步，数据会原样回到手上。

频率建议：轻量用户每季度备份一次，重度收藏型用户（历史里攒了大量资料）每月一次即可。

### 主题与外观：四种模式按需选

clipboard 提供四种主题模式，各自适配不同的使用场景：

| 模式 | 适合场景 |
|---|---|
| 浅色 | 白天为主、室内明亮环境 |
| 深色 | 夜间重度使用、暗光环境 |
| 跟随系统 | 懒人首选——系统切换日夜模式时自动跟着变 |
| 纯黑（AMOLED） | OLED 屏幕用户——纯黑像素不发光，深夜不刺眼还省电 |

> [!NOTE]
> 纯黑主题的价值与屏幕材质绑定：LCD 屏幕上纯黑只是"很深的灰"，省电和观感收益都打折扣；OLED 屏幕上才是"真·熄灭像素"。

几个实用搭配建议：

- **悬浮窗浅色 + 系统深色**：悬浮窗内容要贴着各种应用出现，浅色窗口在多数背景上对比更清晰；
- **全跟系统走**：把主题色定死一个喜欢的，明暗交给系统——维护成本最低；
- **睡前党**：纯黑主题 + 最低亮度，悬浮按钮透明度也拉低——半夜取验证码不闪眼。

主题切换即时生效，不需要重启应用，悬浮窗、主界面、设置页全套跟着变。

### 与输入法剪贴板的关系：各司其职不重叠

clipboard 的悬浮窗功能虽然和输入法剪贴板有部分重叠，但价值定位完全不同：

- 输入法剪贴板**要先唤起键盘**才能用，且上限低、不可备份；
- clipboard 的优势恰恰在"键盘不在场"的场景（看网页、逛应用商店时存内容、取历史）和"长期积累 + 搜索"（千条历史、模板库、备份导出）。

> [!WARNING]
> 不建议两边同时重度维护备忘或收藏——挑一处当唯一真相源，另一处只做临时缓冲，否则找内容时永远要想"这条存在哪"。
