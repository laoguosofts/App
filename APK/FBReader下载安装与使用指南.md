## ✨ FBReader 是什么

FBReader 是一款跨平台的开源电子书阅读器，支持 Android、iOS、Windows、macOS、Linux 以及各种电纸书设备。它能打开 ePub、FB2、MOBI、PDF、RTF、TXT 等几乎所有主流电子书格式，而且完全没有广告——免费版就能覆盖日常阅读的全部需求。

这款阅读器最大的特点是**把排版控制权彻底交给用户**：字号、行距、段距、首行缩进、页边距、文字对齐方式、日夜间主题、背景图、字体……每一项都能独立微调，调完退出设置立即生效。对于喜欢折腾阅读体验的人来说，这种自由度在同类软件里并不多见。

FBReader 还内置了 OPDS 书源支持，装完就能直接浏览公共领域目录和官方合作的电子书商店（Readino，150 万+ 藏书）。如果有自己习惯的书源，复制 URL 添加自定义目录即可。云同步功能可以在多台设备间同步阅读进度、书签和书库，手机上看到一半的书，打开电纸书继续读就行。

## 🔧 安装步骤

### Android

1. 从下载页拿到 APK 文件后，在文件管理器里点开安装包
2. 如果首次安装非商店来源，系统会弹出「未知来源」提示——去 **设置 → 安全 → 允许安装未知应用**，给文件管理器授权
3. 安装完成后打开 App，首次启动会让你选择书籍存放路径，可以选内置存储或 SD 卡

> [!WARNING]
> 国产 ROM（小米、华为、OPPO 等）可能会在后台拦截安装过程。如果点了安装包没反应，长按安装包试试「使用其他应用打开」，或者临时关闭安全中心的安装拦截。

### iOS

直接在 App Store 搜 FBReader 下载安装就行。iOS 限制从外部导入 EPUB 文件——需要通过「文件」App 把书拷到 FBReader 的文档目录，或者在 Safari 里点开 EPUB 后选择「用 FBReader 打开」。

### 桌面版（Windows / macOS）

从下载页获取对应系统的安装程序：

- **Windows**：运行 `.exe` 安装包，选择安装目录（建议保持默认），完成后桌面会有快捷方式
- **macOS**：打开 `.dmg`，把 FBReader 图标拖进应用程序文件夹。首次打开如果被 Gatekeeper 拦截，右键 → 打开 → 确认即可

### 安装后核对

打开 App，确认能看到内置的 OPDS 目录列表，点进去能正常浏览和下载试读——说明安装没问题。如果界面是英文，去设置里把语言切换成中文。

## 📖 阅读体验定制与进阶玩法

FBReader 的核心竞争力在于**深度可定制的阅读体验**——默认的白底黑字虽然能用，但花个十几分钟调一调，阅读舒适度能上一个台阶。

### 排版参数全调

打开任意一本书进入阅读界面，点屏幕中央呼出工具栏，选「设置」图标就能看到全部排版选项。每一项都是独立的滑块或数值输入：

| 参数 | 说明 |
|---|---|
| 字体大小 | 以 pt 为单位调整，实时预览 |
| 行距 | 行与行的垂直间距，手机上 1.3~1.5x 比较舒服 |
| 段距 | 段落之间的额外留白，段落分明不挤 |
| 页边距 | 上下左右四个方向的留白，平板可以设宽一些 |
| 文字对齐 | 默认两端对齐（版面整洁），中文觉得别扭可以切左对齐 |
| 首行缩进 | 中文阅读建议开启 2 字符缩进 |

> [!TIP]
> 不同设备推荐不同的起始参数：手机 16~18pt + 1.3~1.5x 行距；平板大屏幕可以提到 20~24pt + 1.5~1.8x；电纸书建议 20~24pt + 1.4~1.6x，段距缩小到 2pt 更紧凑。

标题字号也会根据书籍内部的 h1/h2/h3 标记自动放大，放大比例同样可以在外观设置里微调。

### 自定义背景图与纸质风格

默认的纯白或纯黑背景偏生硬，换成带纹理的图片能大幅提升纸质书的感觉。FBReader 允许为**日间**和**夜间**分别设置不同的背景：

- 日间背景：米黄羊皮纸纹理、木纹纸质感、轻微纸纤维噪点都不错
- 夜间背景：深色纯色比深色图片更舒服（省内存也不刺眼）

设置路径：设置 → 外观 → 背景，可以选纯色值或图片文件。

| 场景 | 日间背景 | 夜间背景 |
|---|---|---|
| 仿纸张阅读 | 羊皮纸米黄纹理 | 深灰纯色 |
| 护眼模式 | 淡米黄纯色 | 深蓝黑纯色 |
| 复古风 | 褐色纸纹理 | 暗棕纯色 |

背景图建议用低对比度纹理，避免大色块图案导致文字看不清。电纸书上彩色背景会被转成灰度，直接用 EInk 主题配纯色背景效果最好。

### 云同步：多设备进度无缝衔接

FBReader 的 Book Network 云同步可以在你的手机、平板、电纸书、桌面之间同步：

- 阅读进度（翻到哪一页）
- 书签和标注
- 书库目录

开启同步后，需要选择同步触发条件：

| 模式 | 说明 |
|---|---|
| 仅在 WiFi 下同步（默认） | 省流量，最稳妥 |
| 始终同步 | WiFi + 移动网络都同步 |
| 手动同步 | 关掉自动，需要时点按钮触发 |

每台设备的同步条件是**独立配置**的——手机设 WiFi 优先省流量，电纸书设始终同步（反正连 WiFi），桌面版设手动同步自己掌控，完全没问题。

> [!NOTE]
> Android 国产 ROM 的省电模式可能会杀掉后台同步进程。如果发现手机上同步总是延迟，去系统设置里把 FBReader 加入省电策略白名单。

### OPDS 书源与资源获取

FBReader 预装了几个内置 OPDS 目录，装完就能直接浏览。其中值得关注的是 Readino 官方书店——FBReader 官方合作的电子书商店，超过 150 万本书，英、美、澳地区读者可以直接在 App 内浏览、购买和下载。

如果内置目录不够用，可以在 MobileRead Wiki 的 OPDS 页面找到全球各种语言的公开目录——复制目录 URL 后，在 FBReader 的「书籍来源」里选「添加自定义目录」粘贴即可。

> OPDS 不是找书的唯一途径。很多人习惯在 Calibre 里管理书库，通过 USB 或云盘把文件传到设备，FBReader 与这种工作流完全兼容。
