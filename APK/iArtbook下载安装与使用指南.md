## ✨ iArtbook 是什么

iArtbook 是一款面向安卓用户的中文绘画与填色应用，由深圳市征弘科技有限公司出品。它的定位介于「休闲解压填色」和「轻度自由创作」之间，内置涂色花园、数字填色、像素填色三条休闲路线，也提供完整的自由绘画工作台——数十支仿真笔刷、图层面板、取色调色都齐。如果你想在手机上随手画画、或者找一款能安静填色半小时的解压工具，它都能覆盖。

中文安卓版的主标签是「画册 / 创作 / 像素 / 我的」（2.2.7 版本），2.3.x 版本调整为「画室 / 探索 / 教程 / 我的」——两条版本路线界面略有差异，但核心功能一致。

## 🔧 认准与安装

### 三道核对，装对不踩坑

应用商店里至少有三款名字相近、图标都带笔刷的 iArtbook，看截图很容易装错。按以下顺序核对，能 100% 锁定目标：

1. **包名核对（最可靠）**：系统设置 → 应用详情里看包名，必须是 `com.tktn.ycfn`。包名是系统层面的唯一标识，不会因为显示名改来改去而变化。
2. **主界面核对**：打开应用后，2.2.7 版底部四个标签是「画册 / 创作 / 像素 / 我的」，首页有涂色花园、灵感配色入口；2.3.x 版底部标签是「画室 / 探索 / 教程 / 我的」。如果是一屏英文和专业画笔参数，那是另一款 iOS 系列的。
3. **版本号核对**：中文安卓版长期停留在 2.x 区间，看到 10.x 的直接跳过。

| 三款 iArtbook 对比 | 平台 | 版本区间 | 界面特征 |
| --- | --- | --- | --- |
| **中文安卓版（本站介绍）** | 安卓 | 2.x | 中文、画册/创作/像素四标签 |
| iOS 专业绘画版 | iPhone / iPad | 10.x+ | 英文、无限图层、Apple Pencil |
| 安卓轻量款 | 安卓 | 另体系 | 功能偏轻量涂鸦，包名不同 |

### 安装步骤

1. 从下载页获取 APK 文件，保存到手机本地；
2. 进入系统设置 → 安全与隐私 → 开启「未知来源应用安装」权限（不同品牌手机入口略有差异）；
3. 点击 APK 文件按提示完成安装；
4. 首次启动时，**务必同意存储权限**——拒绝后每次保存/导出都会失败，之后要到系统设置的应用权限页手动补开。

> [!TIP] 安装后的版本核对
> 装好后打开应用 → 我的 → 关于，确认版本号在 2.x 区间、包名对应 `com.tktn.ycfn`，三项都对上就没问题。

## 📖 从填色到自由绘画：全面入门

iArtbook 的两条核心路线——休闲填色和自由绘画——在界面上是分开的，底部标签切换即可。先从你感兴趣的一条开始，熟了再交叉。

### 休闲填色三条路线

填色页是精简界面，没有图层和笔刷系统，只有色块和填充工具。三条路线各有侧重：

- **涂色花园**：预设好线稿，点色块自动填色，最解压、零门槛；
- **数字填色**：按数字对应颜色填，类似数字油画，适合不想动脑只想打发时间的人；
- **像素填色**：在像素格子里填色，完成后可以导出像素艺术作品。

三条填色路线界面类似，但素材库不互通——画册标签里能切换不同主题的线稿包。

### 自由绘画工作台：五区认全就不慌

绘画工作台是 iArtbook 里最专业的一屏，按五个区域理解：

| 区域 | 位置 | 作用 |
| --- | --- | --- |
| 顶部工具栏 | 画布上方 | 当前工具（画笔/橡皮）、撤销重做、「三个点」菜单 |
| 左侧滑条 | 屏幕左边两根小条 | 实时调节笔刷大小与透明度，画画过程中另一只手就能滑 |
| 画纸 | 中央 | 双指开合缩放、双指拖动平移 |
| 图层入口 | 底部工具栏 | 管理图层顺序、可见性 |
| 调色入口 | 底部工具栏 | 取色与调色板 |

顶部「三个点」菜单里藏了几个高频功能：**Save 导出**到相册、**选框（套索）**圈选区域配合填充、**翻转画布**水平镜像检查画面——画脸画歪一翻就现形。

左侧滑条是手机绘画最高频的操作，笔落在纸上之前，另一只手滑左侧条就能实时改笔刷大小，不用点开任何设置打断笔势。画阴影过渡时用另一根条调透明度，非常顺手。

### 笔刷系统：日常三支队够了

iArtbook 内置数十种仿真笔刷（铅笔、水彩、炭笔等），各自支持粗细、透明度和纹理调节。新手先熟这三支，其他都是换质感的变体：

| 笔刷类型 | 适用场景 |
| --- | --- |
| 铅笔 | 起稿打草稿，线条轻、好改 |
| 描线笔（勾线类） | 定稿勾线，线条实、粗细可控 |
| 水彩/晕染类 | 铺底色与柔和过渡 |

调粗细和透明度有两种方式：画布左侧滑条（最常用，实时生效）、笔刷详情面板（改默认状态）。炭笔有颗粒感、水彩有晕开感，想调质感在笔刷详情里找纹理相关参数微调即可。

> [!NOTE] 试笔好习惯
> 新画布上别直接画正稿——先在角落用这支笔画几笔，感受轻重变化时线条粗细变不改、透明度滑到一半是什么效果、快速运笔会不会断墨。三个都满意再开工，比画到一半换笔重画省时间得多。

### 我的板块：账号、VIP 与缓存

「我的」是设置与账号中心。画画功能不在这儿，但有三件事要靠它：

1. **保存失败先到这儿确认**：首次启动拒了存储权限之后每次导出都会失败——去系统设置的应用权限页补开；
2. **空间紧张时清缓存**：清除缓存只清临时数据，正常绘画文件不会被清掉，但**卸载应用会连作品一起删**——换机或重装前先把作品导出到相册；
3. **VIP 会员**：解锁部分内购内容，免费版和付费版在核心填色与绘画功能上没有本质区别。

> [!WARNING] 卸载 = 删作品
> iArtbook 的本地作品存储在应用私有目录，卸载应用会一并清空。定期导出到相册是最稳妥的备份方式。
