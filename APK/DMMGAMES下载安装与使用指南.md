## ✨ DMMGAMES 是什么

DMMGAMES 是日本 DMM.com 集团旗下的游戏分发与运营平台，同时覆盖 PC 和移动端两个生态。PC 端通过 DMM GAME PLAYER 启动器管理下载型游戏，移动端靠 DMM GAMES STORE APP 分发手游。运营的游戏品类以二次元、模拟经营、策略 RPG 为主，大家耳熟能详的赛马娘 Pretty Derby、碧蓝档案、鲁鲁修 Lost Stories 都是 DMMGAMES 的代表作。

对国内玩家来说，DMMGAMES 的吸引力主要来自两个方面：一是很多日本本土热门手游在国际服之外同时推出 DMM 渠道版，数据互通但活动节奏独立；二是 PC 启动器提供了大屏高帧率体验，手机上玩腻了可以无缝转移到桌面。一个 DMM 账号同时打通 PC 和移动端，两边的游戏库、存档、DMM 点余额都是同步的。

## 🔧 DMM GAME PLAYER 与 STORE APP 安装

### PC 端安装（Windows）

DMM GAME PLAYER 对系统有明确要求：Windows 10 版本 1809 及以上，或 Windows 11；CPU Intel Core i3 / AMD Ryzen 3 起步；内存 4GB 以上（推荐 8GB）；启动器本体约 200MB，游戏下载空间每款 1~20GB 不等。低于 1809 的 Windows 会直接被启动器拒绝安装，先跑 Windows Update 升到最新版再装。

安装过程非常简单：双击 exe 安装包 → UAC 弹窗点「是」→ 进度条自动走完 → 弹出登录界面。整个过程没有自定义路径、组件选择之类的选项，安装器全自动。默认安装路径是 `C:\Program Files\DMMGamePlayer`，如果系统盘空间紧张，装完后在设置里把下载目录改到其他盘即可。

> [!WARNING] 装完先检查两件事
> 1. 启动器默认日语界面，第一次打开先去设置里切到繁体中文
> 2. 默认下载目录在系统盘，一定要改到空间充裕的盘，不然装两三个游戏 C 盘就爆了

常见安装问题：杀毒软件可能把 exe 误报为病毒，这是签名信誉度不够导致的误报，暂时关闭实时防护装完再开；Windows SmartScreen 提示「未识别的应用」时点「仍要运行」就行；启动器打不开时先确认系统版本 ≥ 1809，再检查显卡驱动是否最新，还是不行就右键用管理员权限运行。

### 移动端安装

iOS 端直接在 App Store 搜「DMM GAMES STORE」，点获取按钮安装，和装普通 APP 没区别。Android 端如果 Google Play 搜不到或下载慢，可以从官方渠道获取 APK 手动安装——需要在系统设置里允许「未知来源应用安装」，装完记得把权限关掉，别长期开放。

## 📖 DMMGAMES 使用入门

### GAME PLAYER 主界面导览

安装完启动器，第一次登录后进入主界面，四个核心标签页构成了日常使用的全部操作面：

**我的游戏**是默认首页，列出账号下所有已购买、已下载、已领取的游戏卡片。每张卡片上有启动、下载、更新、暂停四种状态按钮，游戏是否就绪一眼就能看出来。商店页是 PC 游戏的浏览入口，但非日本 IP 会触发地域限制，大部分付费游戏显示不可用，免费游戏不受影响。搜索页提供独立搜索栏，按游戏名、开发商、类型关键词直接过滤，比商店分类更高效。设置页管全局参数——下载目录、自动更新开关、启动器开机自启、语言切换都在这里。

首次启动建议按这个顺序操作：切语言到繁体中文 → 检查并修改下载目录 → 领一款免费游戏（比如 War Thunder DMM 版）测试下载和启动流程是否正常。

### STORE APP 一键安装手游

STORE APP 最大的体验优势就是一键安装机制——不像手动装 APK 要处理浏览器授权、文件管理器、未知来源权限等好几步，STORE 内部的下载安装流程完全自动：点下载按钮 → STORE 向 DMM 服务器请求最新 APK 链接 → 内部下载 → 下载完自动调用系统安装器 → 自动安装 → 按钮变成「起動」可以直接开玩。下载过程中可以随时暂停、继续、取消，切出 STORE 去干别的下载在后台继续，状态栏会显示进度条。但注意别手动滑掉 STORE 的最近任务，强制退出会中断下载。

装完的游戏有三个入口启动：STORE 的「我的游戏」标签、手机桌面图标、同一个 DMM 账号登录 PC GAME PLAYER 后的「我的游戏」（前提是游戏支持 PC 端运行）。游戏有新版本时 STORE 会给卡片标黄色感叹号，更新是覆盖安装，**不会清除存档或登录状态**，放心更。也可以在设置里开自动更新，Wi-Fi 环境下 STORE 会自动更新所有已装游戏。

### 事前登录与推送设置

事前登录（预约）是 DMM 推广新游的常规手段——免费玩家花 5 秒点一下就能拿到上线后领取的额外抽卡券、限定道具或稀有角色。很多热门游戏（赛马娘、碧蓝档案、鲁鲁修 Lost Stories 等）的预约奖励都很可观，上线直接领。STORE 里标有「事前登録」的游戏卡片点进详情页，按一下「事前登録する」按钮就完成了，预约数量不限。

推送通知的设置分 Android 和 iOS 两个平台：

| 平台 | 操作路径 | 注意点 |
|------|----------|--------|
| Android | 首次启动弹窗允许 / 系统设置 → 应用管理 → STORE → 通知权限 | 后台下载别被电池优化杀掉，把 STORE 加到白名单 |
| iOS | 系统设置 → 通知 → STORE → 允许通知 + APP 内部设置确认 | iOS 双层权限（系统层 + APP 层），两层都要开 |

通知类型分五类，建议事前登录提醒**必须开**（预约了才知道上线），游戏活动更新和新版本通知也建议开（限时活动和版本更新很容易错过），促销和资讯类可关。

没收到推送时按这个顺序排查：系统通知权限开了吗 → 手机勿扰模式是不是开着 → STORE 有没有被电池优化杀掉后台 → iOS 用户试试手动刷新 STORE 或重启手机。

### 安装失败与下载卡住排查

PC 端启动器安装如果卡在下载或启动环节，先看 Windows 版本是不是够、磁盘空间够不够、杀软有没有拦截。移动端 STORE 下载卡住大概率是网络问题——DMM 下载服务器在日本，对中国大陆 IP 速度不稳定，试试切换 Wi-Fi、暂停后重新继续，反复卡住就用代理加速。

手机端安装按钮点了没反应时检查三点：存储空间至少腾 500MB 出来、Android 版本是否达标、小米 / OPPO / 华为的安全中心有没有拦截 STORE 调用系统安装器（把 STORE 加到安全中心白名单）。装完打开闪退先关后台 APP 腾内存，每次都闪退大概率是兼容问题，去 STORE 里该游戏的评论区看看有没有其他玩家遇到同样情况。
