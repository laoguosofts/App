## ✨ Simple Live 是什么

Simple Live 是一款开源的多平台直播聚合应用，一个 App 把虎牙、斗鱼、B 站、抖音四家主流直播平台的内容集中在一起。顶栏标签切换就能在各平台间跳转，不用在手机桌面上来回找不同平台的官方 App 图标。

它的核心定位很明确——**纯观看体验优先**。界面上没有首页新闻推荐、没有短视频引流、没有广告弹窗和打榜任务，进到直播间就是画面本身。对于不喜欢各平台官方 App 那种"全家桶"式杂糅设计的用户来说，Simple Live 提供了一种更干净的观看方式。

适用场景覆盖得比较广：游戏直播爱好者可以在多家平台之间灵活切换；大屏电视用户可以用 Android TV 版配合遥控器在客厅看直播；电脑桌面常驻用户可以开着小窗口挂直播间；还有那些只想安静看直播、不想被各种推送打断的纯观看者。

Simple Live 支持的平台和终端组合相当完整：Android 手机、iOS、Windows 桌面、Android TV 都有对应的版本。

## 🔧 怎么装 Simple Live

Simple Live 的安装方式因平台而异，Android 最直接，iOS 最特殊。下面分别说清楚。

### Android 手机安装

Android 是安装最顺畅的平台。从下载入口拿到 APK 文件后：

1. 打开文件管理器，找到下载的 APK
2. 首次安装会弹出「未知来源应用」提示，进入系统设置开启允许未知来源安装
3. 点击安装，等待进度条走完即可
4. 安装完成后首次打开，如果弹杀毒误报提示（部分国产手机 ROM 对非应用市场来源的 APK 比较敏感），选择「信任」或「继续安装」就行

> [!NOTE]
> 安装完成后建议核对一下版本号——打开 App 设置里的「关于」页面，和下载页标注的最新版本比对，确保拿到的是对应版本。

### iOS 版安装（比较特殊）

Simple Live 开源项目本身不发布官方签名包，iOS 版本由社区分发，主要有三种渠道：

**TestFlight（推荐，最省事）**

1. 用 Safari 打开社区提供的 TestFlight 邀请链接
2. App Store 下载安装 TestFlight App（免费）
3. 在 TestFlight 里接受邀请，然后安装 Simple Live
4. TestFlight 有测试名额限制，试用期结束后需要等下一轮

**自签安装（适合有 Apple ID 的用户）**

- **AltStore / SideStore（iOS 15+）**：电脑上装 AltServer（Windows 和 macOS 都支持），数据线连接 iPhone 并信任电脑，下载 Simple Live 的 IPA 文件，AltServer 里选「安装 IPA」→ 选 iPhone → 输入 Apple ID → 开始自签。手机端到「设置 → 通用 → VPN 与设备管理」里信任开发者证书即可。
- **巨魔 TrollStore（iOS 14~16）**：部分型号支持的永久签名工具，一次安装长期有效，不需要七天重复签。

> [!WARNING]
> 自签应用的签名有有效期——免费 Apple ID 签的 7 天过期，付费开发者账号签的 365 天过期。过期后需要重新执行自签流程。

### Windows 桌面版

Windows 版支持小窗口悬浮和后台驻留，适合在工作间隙挂着直播间。安装方式：

1. 下载 zip 包或安装程序
2. zip 包直接解压到任意目录（建议放到非系统盘，避免权限问题）
3. 双击 SimpleLive.exe 即可运行，首次运行如果被 Windows Defender 拦截，选择「仍要运行」
4. 需要开机自启的话，把快捷方式放进 `shell:startup` 目录

## 📖 Simple Live 使用入门

装完打开后，默认界面会列出四家平台的热门直播间。下面从几个最实用的功能点入手，说说怎么把 Simple Live 用得顺手。

### 基础观看：切平台、搜房间

顶部标签栏默认排列了已接入的直播平台，点一下就切换。进入某个平台后，页面会展示热门推荐列表，支持下拉刷新。搜索功能在各平台页面右上角，输入主播名或房间号就能直达。

> [!TIP]
> 抖音平台的搜索功能在默认状态下可能不完整甚至直接失败——这是因为 Simple Live 只带了 ttwid Cookie 兜底，搜索需要完整 Cookie。后面会讲到怎么导入。

### 画质与弹幕设置

进入直播间后，画面区域点击会弹出控制层。画质切换面板在右下角（或右上角，因平台而异），通常有流畅、高清、超清、蓝光、原画等档位可切。

弹幕相关的开关和设置集中在直播间设置里：可以关闭弹幕、调整弹幕透明度和滚动速度、选择弹幕字号。

### 导入 Cookie：解锁更多能力

这是 Simple Live 进阶使用的关键。四家平台中，**抖音和斗鱼对未登录用户的限制最明显**，导入 Cookie 后能解锁不少能力。

**抖音 Cookie** 默认状态只能看直播，但搜索主播可能失败、接口并发限流（同时开多个直播间容易被限）、弹幕不稳定。导入完整 Cookie 后这三个问题一起解决。获取方式：桌面浏览器打开抖音网页版并登录，按 F12 进开发者工具，切到「应用 → Cookie → www.douyin.com」，把所有条目完整复制下来（别只复制 ttwid 一个字段）。

**斗鱼 Cookie** 的核心作用是解锁画质——未登录可能被限制在 1080P，蓝光和原画档不显示。导入后画质档位恢复完整，弹幕发送频率限制也会解除。获取方式类似：浏览器登录斗鱼，F12 → 「网络」标签 → 刷新页面 → 点任意请求 → 复制 Cookie 字段全部内容。

Cookie 导入路径统一是：**设置 → 账号管理 → 对应平台 → Cookie 登录**，粘贴进去或从 txt 文件导入都行。手机端推荐用文件导入——手动粘贴几百字符容易截断出错，先在电脑上存成 `douyin.txt` 传到手机，再用 Simple Live 的「从文件导入」功能读取就好。

> [!NOTE]
> 不同平台 Cookie 有效期不一样。斗鱼通常几天就失效，如果突然发现画质又退回 1080P，八成是 Cookie 过期了，重新获取导入即可。抖音和 B 站的 Cookie 有效期相对长一些。桌面版（Windows / macOS / Linux）的 Cookie 导入最方便——直接点内置的「浏览器登录」按钮，在弹出的官方网页登录后 Simple Live 自动读取 Cookie，不用手动复制粘贴。

### iOS 版特色功能

如果你是 iPhone 用户，Simple Live iOS 版有几个特别优化的点值得一说：

- **画中画（PiP）**：iOS 14+ 原生支持，播放时按 Home 键就自动进入小窗模式，可以在手机上一边刷其他 App 一边挂直播间
- **手势操作**：iOS 风格的左右上下滑动分别调节亮度和音量，手感和系统原生播放器一致
- **横竖屏自动切换**：iPhone 旋转时画面自动适配，不需要手动切换方向

iOS 端 Cookie 导入推荐用文件分享——手动粘贴长文本容易出错，把 Cookie 存成 txt 后通过「文件」App 分享给 Simple Live 更稳妥。

### 桌面版实用技巧

Windows / macOS / Linux 桌面版适合在电脑上常驻：

- **小窗口悬浮**：播放时切换到小窗口模式，可以拖到屏幕任意角落，不挡其他窗口
- **后台驻留**：关闭主窗口后直播间继续在后台播放，任务栏图标显示直播状态
- **多窗口同时开**：在桌面性能允许的前提下，可以同时开多个直播间互不干扰

### 界面个性化

Simple Live 的界面走的是极简风格，默认深色主题，但在设置里可以切换。各平台图标、字体大小也能在外观设置里微调。如果你觉得默认的直播间列表太密或太疏，调整一下网格间距就能改变观感。
