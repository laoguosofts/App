## ✨ Pulsar 是什么

Pulsar 是一款专为 Android 打造的本地音乐播放器，主打轻量快速和高度可定制的曲库浏览体验。它不依赖云端账号，直接扫描设备上的音频文件就能用，支持 mp3、flac、wav 等常见格式，界面简洁干净，没有多余的广告干扰。

它的核心优势在于**多维度曲库组织**和**丰富的播放控制**：同一批歌曲可以按专辑、艺术家、文件夹、流派、歌曲、播放列表六个维度快速切换浏览，让找歌这件事不再是负担。声音调校方面，免费版就提供声道平衡和 ReplayGain 响度均衡，Pro 版更是解锁了完整的均衡器和音效预设。

适合谁用呢？如果你习惯把音乐文件直接拷到手机里管理、对播放器的界面组织有自己的偏好、或者单纯想要一个不联网就能好好听歌的工具，Pulsar 是值得考虑的选择。

## 🔧 安装步骤

Pulsar 是 Android 平台的应用，安装方式和大多数 APK 一样，但有几个细节值得注意。

### 从 APK 文件安装

1. 从下载页获取最新版本的 APK 文件，确认文件大小在合理范围（几十 MB 级别，异常偏小可能是损坏文件）
2. 把 APK 拷到手机里（或者直接用手机浏览器下载）
3. 打开文件管理器，点击 APK，首次安装未知来源应用时系统会弹出授权提示
4. 进入手机设置 → 安全 → 找到「未知来源」或「安装未知应用」，允许当前文件管理器安装应用
5. 回到文件管理器重新点击 APK，按提示完成安装

> [!WARNING]
> 安装前建议核对 APK 的版本号与下载页标注的一致；如果手机安全中心提示风险，确认来源可靠后放行即可。

### 从 Google Play 安装

打开 Google Play，搜索 "Pulsar"，找到官方开发者发布的版本，直接点安装。这个渠道的好处是会自动更新，不用每次手动下载新 APK。

### 装完怎么确认是正确版本

打开 Pulsar 后进入设置页，拉到最底部能看到版本号，和下载页对照一下。首次启动时它会扫描本地音乐文件，扫描完成后主界面就会显示你的曲库。

## 📖 使用入门

### 六个标签页，换个角度看同一批歌

Pulsar 主界面顶部有六个浏览标签，本质上是同一批音频文件的六种组织方式：

| 标签 | 组织方式 | 适合场景 |
| --- | --- | --- |
| 专辑 | 按专辑分组，默认首页 | 想完整听完一张专辑、靠封面找歌 |
| 艺术家 | 按歌手/艺人分组 | 「我想听周杰伦的歌」这种明确需求 |
| 文件夹 | 按文件真实所在目录分组 | 音频标签信息不可靠、习惯按目录整理的人 |
| 流派 | 按曲风分组 | 按心情选风格，比如想听点爵士或者电子 |
| 歌曲 | 全部歌曲平铺 | 搜索特定曲目、批量排序 |
| 播放列表 | 自建与智能列表 | 有固定听歌组合、通勤歌单之类的 |

标签顺序和显隐都能改——进设置页找到「Change tab items」，按住每项右侧的四线图标上下拖动即可。播放列表标签默认是隐藏的，想用常驻就到这里打开。另外屏幕左缘往右滑能拉出导航抽屉，里面集中了各分组和播放列表的快捷入口，在绝大多数页面都能拉出来。

### 随机播放总捣乱？三个角色先分清

不少人遇到过这种情况：明明点的是列表第一首歌，结果全列表乱序播放；或者每次打开都在随机模式停不下来。这其实是三个设置相互纠缠的结果：

1. **悬浮随机按钮**：每首歌详情页都有一个大的悬浮随机按钮，按下后当前列表被随机化播放
2. **Keep shuffle mode（保持随机模式）开关**：设置 → 播放选项里，决定随机状态要不要粘住后续播放
3. **默认点播行为**：直接点列表里的某一首歌

规则拆开就清楚了：直接点列表第一首歌 = 顺序播放（完全不经过随机按钮）；按了悬浮随机按钮 = 本轮乱序，循环键管循环方式；Keep shuffle mode 开着时，哪怕你点单曲也会进入随机模式——这就是「明明点的这首怎么全乱了」的元凶。想点哪首放哪首，关掉这个开关就行。

循环有三档：列表循环（整个队列放完从头再来）、单曲循环（当前这首无限重播）、不循环（放完整个队列就停）。底部按钮区的循环键可以直接切换。

> [!TIP]
> 快速自诊：点单曲也乱序 → Keep shuffle mode 开着了；想顺序播却在随机 → 别点悬浮随机按钮，直接点列表第一首；每次打开都随机 → 同上，随机状态被保持住了。

### 桌面小部件，随时随地控播放

Pulsar 的小部件只有一种定义，但可以**自由调整大小**——默认 4×1，按住边缘能拉成 4×2、5×2、4×4 等任意占位（不同桌面启动器的实际格数略有差异）。添加步骤：长按桌面空白处 → 选「添加小部件 / 窗口小工具」→ 列表里找到 Pulsar → 按住拖到桌面。

点击行为有讲究：点控制区（上一首/暂停/下一首按钮）直接操作播放；点空白区域则进入应用的正在播放页面。

如果发现小部件上的信息长时间不刷新，多半是启动器缓存或应用被系统冻结了——先重启启动器（或手机）试试，仍异常的话检查电池优化设置，把 Pulsar 加入后台白名单。锁屏上的播放控制不靠小部件，走系统媒体通知渠道。

> [!NOTE]
> 小部件是免费版功能，不需要 Pro 版。

### 耳机偏音？调声道平衡

Sound balance（声道平衡）是免费版就能用的声音调整，入口在设置页里。它做的事很简单——调整左右声道的比例，让左耳声音大一点或者右耳大一点。

适用场景主要三类：单侧听力不佳，把弱侧声道调大补偿；耳机本身偏音（比如某一侧单元老化），往声音小的那一侧补；纯个人偏好的平衡感调整。

使用时注意三点：这是整体平移，不改变各声道内部内容；数值别拉太满——极端比例下人声（通常居中录制）会明显偏向一侧，听起来很奇怪；换耳机后记得复位，不同耳机的偏音程度不同，一套参数不是万能的。

免费版能动的声音调整还有一样：ReplayGain 音量均衡——前提是你的 mp3 文件带增益标签，它能拉平歌与歌之间的响度差，避免某些歌突然变得特别响或特别轻。频段调整、低音增强、混响这类实时音效只在 Pro 版里才有。
