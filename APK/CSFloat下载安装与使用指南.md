## ✨ CSFloat 是什么

CSFloat 是一个面向 CS:GO 与 CS2 玩家的饰品交易服务平台，核心价值在于把 Steam 社区市场里那些看不见的验货数据——浮点值、图案种子、世界排名——直接叠显在网页和库存页面上，让买卖双方在下单前就能看清品相，而不是靠截图碰运气。

它的产品形态分两块：一是浏览器扩展（市场检查器），Chrome 与 Firefox 双端均有上架，完全开源，MIT 许可证，源码托管在 GitHub，可自行审计与编译；二是移动 App，把市场筛选、数据库浏览、成交通知塞进了口袋，碎片时间也能盯盘扫货。两块组合起来覆盖了「发现 → 验货 → 成交」的完整链路。

关键事实一览：

- **双平台覆盖**：Chrome 应用商店与 Firefox 附加组件中心均提供官方扩展，移动 App 在主流应用分发渠道可获取
- **开源可审计**：扩展源码公开，验货数据通道可信，不存在第三方篡改风险
- **超十亿件索引**：内置 FloatDB 数据库，CS 系列游戏饰品的浮点参数、模板、排名一应俱全

## 🔧 安装步骤

### 浏览器扩展安装（Chrome 系）

1. 打开 Chrome 应用商店，搜索扩展名称「CSFloat Market Checker」，认准开发者为本平台官方
2. 点击「添加至 Chrome」，在弹出的权限提示框里确认授权
3. 安装完成后打开任意 Steam 市场列表页，几秒内页面上会自动出现浮点列——无需额外注册或配置即可使用

基于 Chromium 的浏览器（Edge、Brave 等）多数可以直接安装 Chrome 版本；但个别「去谷歌化」内核与部分隐私浏览器存在兼容问题，建议优先使用 Chrome 或 Firefox。

### 浏览器扩展安装（Firefox 系）

1. 打开 Firefox 附加组件中心，搜索同一扩展名称
2. 点击「添加到 Firefox」并授权
3. 同样在 Steam 页面自动生效

> [!NOTE]
> 扩展通过商店自动更新，大版本（v3+）发布说明可在官方 GitHub 仓库的 Releases 页面查看。手动从第三方网站下载安装包的做法不推荐——验货工具要求数据通道可信，一律走官方商店渠道。

### 移动 App 安装

1. 在 Google Play 或 App Store 搜索「CSFloat」
2. 点击安装，等待下载完成
3. 首次启动时按提示授权网络与推送权限

> [!TIP]
> 安装完成后建议检查两项：一是打开 Steam 交易报价页面，若顶部出现启用提示横幅，点「启用」——这关系到销售状态能否自动更新；二是不要把扩展权限改成「点击时才运行」，否则市场页不会自动加载数据，报价验证也会断更。

## 📖 使用入门

### 验货核心：浮点与排名

浮点值（Float）是 CS 饰品磨损程度的量化指标，范围 0.00 到 1.00，数值越低代表磨损越轻。但光有数值不够——同一件饰品，0.06 和 0.07 的观感可能天差地别，这就需要结合 3D 检视来判断。

扩展把浮点值、图案种子、世界排名这些数据直接叠显在 Steam 社区市场与库存页面上。逛市场时每张商品卡片都会带：价格与折扣百分比、浮点进度条与数值、世界排名、卖家在线状态徽章。手机扫货的效率不输电脑——品相判断有了可靠依据，不再靠截图碰运气。

### 3D 模型检视：不开游戏看枪

验货最大的痛点是「截图会骗人，模型不会」。扩展内置了 3D 检视能力：在 Steam 市场或库存页点开饰品后选择 3D 查看，浏览器里直接渲染出这件饰品本体的真实 3D 模型，鼠标拖动即可 360° 旋转。

| 位置 | 入口 |
| --- | --- |
| Steam 市场页 | 饰品条目上的 3D 查看按钮 |
| Steam 库存页 | 扩展详情面板里的 3D 按钮 |
| CSFloat 市场 | 商品详情页的检视入口 |

通过 3D 检视可以看清：图案模板的实际落位效果——蓝顶位置、渐变走向、花纹分布；掉漆点位的真实分布，判断这件 0.06 的观感值不值价；贴纸在模型上的实际位置与刮痕；多普勒相位和宝石类的完整色彩表现。

这些正是平台开源检视系统的能力：通过 Steam 检视链接拉取游戏内渲染数据，浏览器端还原。游戏内截图反映的是渲染结果，3D 模型则是可交互的原始数据——买高值品相件时，两者组合基本消灭了「货不对板」的空间。

> [!WARNING]
> 3D 渲染走浏览器 WebGL，对硬件有一定要求。老旧核显建议关闭其他高负载标签页；浏览器需启用硬件加速，这也是平台整体流畅度的前提。

### 移动 App：碎片时间盯盘

App 不是网页的缩水版，而是把「发现 → 验货 → 成交」三段塞进了碎片时间。搜索页把网页版市场的筛选能力完整搬了过来：

- **结果计数与排序**：如「1.5M Items Found」，排序器里 Top Deals（最优折扣）是默认快捷项，可切换浮点排名等口径
- **类型标签**：All Items（全部）/ Auctions（拍卖）/ Unique Items（独特物品）分区浏览
- **完整筛选器**：条件与网页版同源

App 内置 FloatDB 浏览功能，超十亿件的饰品索引随身带——搜款式、套筛选、看单品的浮点/模板/排名/截图，数据库能力与网页端一致。

**手机扫货的三件套组合**：

1. 设置推送盯着目标款式
2. 到货提醒一响，打开高级搜索复核品相与价格
3. 想长期蹲的，回到网页版挂条件求购单，手机只管接收成交通知

下单流程与网页版完全同构：选定商品 → 确认支付 → 进入 P2P 交付（卖家 30 分钟接单 / 2 小时发货）。对蹲货与竞价的玩家来说，手机端反而比桌面端更高效。

### KYC 实名认证

KYC（Know Your Customer，了解你的客户）是金融合规的标准流程，平台把 KYC 交给合作伙伴 SumSub 处理。

| 场景 | 是否需要 KYC |
| --- | --- |
| 使用 ACH、iDeal 等银行类方式充值 | 必须 |
| 部分账户的信用卡充值（风控触发） | 客服可能要求 |
| 使用预付卡充值 | 必须 |
| 解除「定价过高」上架限制 | 必须（另需绑 Stripe） |
| 提高支付风险分数 | 建议 |
| 首次提现（Stripe 入驻环节） | 必须 |

**基本规则**：

- 必须年满 18 岁才能完成 KYC；未满 18 岁须由父母或法定监护人同意并监督使用平台
- 同一个 KYC 身份不能关联两个不同的平台账号；冒用他人身份规避规则的用户会被永久封禁

**流程概要**：

1. 从平台账户页进入 KYC 入口，跳转至 SumSub
2. 按提示提交证件（护照/身份证/驾照）与所需信息
3. 等待自动核验（通常较快，个别情况人工复核）
4. 通过后，相关充值与提现功能解锁

被拒绝后官方通常不提供详细原因，若确信是误判可创建支持工单申诉。KYC 数据由 SumSub 持有，介意实名的话可以选择不走银行通道、只用加密货币类方式——代价是功能受限，取舍自行判断。

> [!NOTE]
> KYC 通过 + Stripe 入驻完成 = 提现通道就绪。费率与到账方式以平台最新公布为准。
