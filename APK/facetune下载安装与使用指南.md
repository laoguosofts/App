## ✨ Facetune 是什么

Facetune 是一款专注于人像精修的移动端应用，以"修得自然"为核心卖点——它不像很多一键美化工具那样把人变成另一个样子，而是在保留你本人特征的基础上做精致化调整。从磨皮祛痘到面部轮廓重塑，从虚拟美妆到 AI 创意换发型，Facetune 把人像修图需要的几乎所有功能都整合进了手机端。

它的工具逻辑非常清晰，按用途分成了十几个分组：Retouch 负责皮肤精修（磨皮、祛痘、美白），Reshape 管面部轮廓调整（瘦脸、眼睛、鼻子），Makeup 提供虚拟妆容，AI 分组则放了近年最热门的创意功能——换装、脸型分析、头像生成等。滤镜库和光影调整（亮度/对比度/色温）作为基础工具常驻在侧边栏。

Facetune 的另一个特点是迭代节奏快，平均每两三个月就有一次大版本更新，界面布局和功能位置会跟着调整。好消息是新版本内置了搜索功能，直接搜功能名就能定位，不用再一个个翻分组找。

**适合谁用？** 自拍爱好者、内容创作者、电商主图修图者——只要你经常需要处理人像照片，Facetune 的"自然感"调校和 AI 辅助识别会让修图效率比传统液化工具高出不少。

## 🔧 安装步骤

### iOS 安装

1. 打开 App Store，搜索 "Facetune"（注意认准官方开发者 Lightricks Ltd.）
2. 点击获取，输入 Apple ID 密码或用 Face ID/Touch ID 确认
3. 下载完成后直接点击图标启动

iOS 端不需要额外授权，应用商店的审核机制已经替你把关了。

### Android 安装

Android 端有两种安装渠道：

- **Google Play**：打开 Google Play Store，搜索 "Facetune"，直接安装即可
- **第三方安装包**：如果你是从下载入口获取的 APK 文件，需要先允许"未知来源"应用安装

> [!WARNING] Android 未知来源授权
>
> 从浏览器下载 APK 时，首次安装会弹出"未知来源"提示。操作路径：设置 → 安全 → 安装未知应用 → 选择你的浏览器 → 允许。安装完成后建议关闭这个开关，避免误装其他来源不明的应用。

### 版本核对建议

安装完成后，第一次打开应用建议检查版本号——不同版本的功能位置和命名可能有差异。在应用内 Settings → About 里可以看到当前版本。如果发现某些教程截图里的功能在你这里找不到，大概率是版本号对不上，更新到最新版通常能解决。

## 📖 从零基础到熟练：Facetune 核心使用全解析

### 界面导航：功能在哪找

Facetune 版本更新频繁，底部 Tab 栏的分组名称和数量可能变化，但核心分组的逻辑始终稳定：

| 分组 | 包含内容 | 最常用工具 |
| --- | --- | --- |
| Retouch | 皮肤精修 | Smooth（磨皮）、Heal（祛痘）、Whiten（美白/牙齿美白） |
| Reshape | 面部重塑 | Face Slimmer（瘦脸）、Eyes、Nose、Mouth |
| Makeup | 虚拟美妆 | 腮红、修容、眉形 |
| Hair | 发型发色 | AI 发型推荐、发色调整 |
| AI Tools | AI 创意功能 | Face Shape Detector、AI Clothes Changer、背景移除 |
| Filters | 滤镜库 | 预设滤镜，含 Beauty 子分类 |
| Enhance | 一键美化 | 自动提亮、自动调色 |
| Lights | 光影调整 | 亮度、对比度、色温、高光阴影 |

> [!TIP] 找不到功能？
>
> 新版 Facetune 内置了搜索功能（主界面或编辑器顶部的放大镜图标）。直接输入功能的英文名或中文名，比如 "wrinkle" 或 "去皱"，会显示匹配的工具和位置提示。这是版本更新后最直接的找工具方式，比一个个翻分组快得多。

### 瘦脸：让脸变瘦但不奇怪

瘦脸（Face Slimmer）是 Reshape 分组里讨论最多的功能。它的背后是一套 AI 面部识别模型——自动定位面部 68 个关键特征点，把整张脸分成"安全调整区"和"谨慎调整区"。手指拖动时只影响安全区的轮廓，不会把五官一起拖歪。

**基本操作步骤：**

1. 进入 Reshape → Face Slimmer
2. 选择"整体瘦脸"模式（部分版本提供多个模式）
3. 笔刷大小选中等（刚好覆盖半张脸宽度）
4. 从下颌线最宽处向内轻推
5. 从颧骨两侧向内轻推（视脸型需要）

**不同脸型的瘦脸重点不同：**

| 脸型 | 重点区域 | 操作方向 |
| --- | --- | --- |
| 圆脸 | 脸颊和下颌 | 从脸颊两侧向内收，下颌线向内推 |
| 方脸 | 下颌角 | 下颌角处向内推，让角度变圆 |
| 梨形脸 | 下颌线 | 只修下颌线，不动颧骨（保持平衡） |
| 心形脸 | 颧骨 | 微调颧骨最宽处向内一点点 |
| 鹅蛋脸 | 基本不需要 | 可轻轻整体内收增加精致感 |

进阶用户可以跳过 Face Slimmer 这个"全自动"工具，用 Reshape 分组里更细粒度的工具单独调整——Jaw 只管下颌线，Cheeks 单独调苹果肌位置，Forehead 让额头变宽或变窄。

> [!WARNING] 瘦脸的度
>
> Face Slimmer 的默认调整范围已经经过调校，极限位置也不会让脸变成"蛇精"。但如果反复刷同一个位置还是会越来越瘦。建议每次修改后长按界面上的眼睛图标对比原图，觉得变化太明显就减回来。超过 10% 的面部轮廓改变很容易被看出来。

### AI 脸型分析：先定位再动手

Face Shape Detector 是 Facetune 2024 年底推出的 AI 辅助工具，它不直接修图，而是帮你做"定位"——上传一张正面清晰的人像照片后，AI 会识别你的脸型（圆形、椭圆形、方形、心形、长方形等），分析五官比例，然后推荐适合的发型、妆容和配饰。

很多人修图都凭感觉：瘦脸就往窄的拉，磨皮就拉满。但实际上不同脸型的人适合的修饰方向完全不同——圆脸越修越尖反而不自然，方脸的下颌角才是真正的问题区域。Face Shape Detector 相当于一个 AI 化妆师，告诉你应该从哪里开始调整，而不是盲目地"瘦就是美"。

做完脸型分析后，回到 Reshape 和 Makeup 分组按照建议操作。比如知道自己是圆形脸，就不要在颧骨上打高光（会更圆），改用 Glow 在苹果肌中心打圆形高光。

### 保持自然感：修图不能丢掉你自己

Facetune 以"自然"著称，但即使用 Facetune，如果操作不当也会翻车。这里有八个保持自然感的关键原则：

**1. 不要改变你的核心辨识度**——特定的痣或胎记（除非在正脸中央特别显眼）、自然的酒窝梨涡、独特的眉形、标志性的发型，这些是"你"的标志。磨皮祛痘可以，但不要把痣也顺手点了。

**2. 眼睛只增强不改变**——Details 强化眼神光（15-20% 足够）、Eye Color Editor 换瞳色（选自然的颜色）没问题，但 Reshape 把眼睛变大要控制在 5-10% 以内，超过就假。内双变外双、单眼皮变双眼皮这种医学级改变，修图做不到自然。

**3. 脸型微调优先于大变**——Face Slimmer 20% 以内的调整最自然。原则：让脸更好看，但不能让人一眼看出"你整过容"。

**4. 牙齿美白也要有个度**——Whiten 30% 以内，保持"自然白"。天然牙齿是略带象牙色的，不是纯白。牙齿太白会像贴片，反而抢了焦点。

**5. 保持皮肤纹理**——Smooth 后一定要用 Texture 恢复一点纹理（15-20%），或者在磨皮时就控制强度，不要磨到完全没毛孔。Details 工具可以在关键位置强化纹理。

**6. 光影一致性**——修图后检查高光是否在光源方向（通常是上方偏前），阴影是否在相反方向。不要在脸上出现矛盾的光影。

**7. 嘴型和表情不要硬改**——Reshape 嘴角上扬可以（10% 以内），但不要强行创造一个微笑。AI Smile Filter 可以让自然微笑更灿烂，但不要在严肃照片上硬加笑容。

**8. 定期对比原图**——长按眼睛图标来回切换是保持自然感的最好方法。切换时如果觉得"哇这变化好大"就说明过了，减回来；觉得"好像没太大变化，但确实好看了"就是完美状态。

出现以下特征时，说明修过了，需要往回拉：

| 假感特征 | 可能原因 | 修正方法 |
| --- | --- | --- |
| 像蜡像 | Smooth 太狠 + 没保留纹理 | Texture 恢复 + 降低磨皮 |
| 脸变小变尖得离谱 | Face Slimmer 过 | 减到 10-15% |
| 牙齿闪瞎眼 | Whiten 过 | 降到 20% |
| 眼睛像卡通 | Eyes Reshape 过 | 降到 5% |
| 不像自己 | Reshape + Makeup + 滤镜叠加过 | 回到基础只磨皮提亮 |
| 边缘有明显接缝 | AI 换发型/背景后没处理边界 | Smooth + Details 在边缘过渡 |
