## ✨ MiXplorer 是什么

MiXplorer 是一款面向 Android 平台的全能型文件管理器，主打一个 App 把所有存储入口打通。从手机内部存储、SD 卡、USB OTG，到 Google Drive、OneDrive、Dropbox 等主流云盘，再到局域网 SMB/NAS、WebDAV、FTP/SFTP，甚至 DLNA 流媒体服务器，统统集成在同一份侧边抽屉里，点击即连。

它的核心竞争力不止于"能连"——内置了 WebDAV/FTP/HTTP/DLNA 四种服务器模式，可以把手机本身变成网络节点，让平板、电脑、其他手机直接访问手机上的文件；内置 APK 签名器支持 v1/v2/v3 三种签名方案，无需电脑就能在手机上给 APK 重签名；还有双面板浏览、标签管理、批量操作、Root 访问等进阶功能。

MiXplorer 有免费版和付费 Silver 版之分。免费版已经覆盖了绝大多数个人用户的需求，包括云存储、SMB、WebDAV、USB OTG、内置服务器等全部核心功能；Silver 版额外提供 HTTPS 服务器、ADB over WiFi、高级加密等增强项。对于只是想把手机和家里 NAS、云盘打通的普通用户，免费版完全够用。

适合谁用？如果你手上有多台设备要互传文件、有 NAS 需要从手机访问、用多个云盘需要一个统一入口、或者喜欢折腾手机文件系统和 APK 定制，MiXplorer 会比系统自带的文件管理器好用得多。系统自带的文件管理器通常只覆盖本地存储和少数主流云盘，局域网访问、USB OTG、WebDAV、APK 签名这些能力基本都没有。

## 🔧 安装步骤

### 获取 APK 的渠道选择

免费版由于未在 Google Play 上架，获取渠道主要有三类：XDA 开发者论坛的官方发布帖是最权威的来源，版本更新最快；APKPure 和 APKMirror 等社区镜像站版本稍滞后但界面友好；Malavida 等分发站也能下。Silver 版付费后可直接从 Google Play 或 Galaxy Store 安装，享受自动更新。

### 安装流程

1. 下载 APK 文件到手机本地存储（建议先下到电脑再用 USB 传到手机，避免手机上直接装时的浏览器缓存问题）
2. 如果是首次在手机上安装非 Play 来源的 APK，系统会弹出"未知来源"提示，进入设置开启"允许安装未知应用"即可。不同 ROM 的入口略有差异，一般在「设置 → 安全」或「设置 → 应用管理 → 特殊权限访问」里能找到
3. 用文件管理器找到下载的 APK 文件，点击确认安装，等待完成
4. 安装完成后打开应用抽屉，找到 MiXplorer 图标启动

### 首次启动权限授予

MiXplorer 启动后会依次请求多项权限，全部允许即可：

> [!TIP]
> 存储访问权限是最关键的——Android 11 及以上需要授予"所有文件访问"权限，否则 App 无法浏览内部存储目录。相机和蓝牙权限是可选的（用于扫码添加网络存储和蓝牙文件传输），不用可以拒绝。通知权限建议允许，后台服务器运行时需要持续通知栏常驻。

### 版本核对与安装验证

安装完成后，进入 MiXplorer 设置 → About，核对版本号是否与下载页一致。如果之前装过旧版 MiXplorer，同一签名的新版本可以直接覆盖安装；不同签名的版本需要先卸载旧版再装。

### 常见安装阻塞

- **解析软件包时出现问题**：可能是下载的 APK 文件损坏（网络中断），重新下载一份；也可能是 Android 版本过低
- **安装被系统拦截**：国产 ROM（MIUI、EMUI、OneUI 等）对非商店来源的 APK 可能有额外扫描和拦截，关闭"安全扫描"或在开发者选项里开启"USB 调试安装"
- **空间不足**：确认内部存储有至少 200MB 可用空间

## 📖 使用入门

### 熟悉主界面

默认界面分为三个区域：顶部工具栏显示当前路径面包屑、搜索框和标签管理按钮；中部主区域展示文件列表，支持图标视图、列表视图、网格视图三种切换；侧边抽屉从左边缘向右滑动打开，是整个 App 的"控制中心"——内部存储、SD 卡、USB OTG、云存储、SMB/NAS、书签分类、服务器入口、设置全部在这里。

手机横屏时默认自动切换成双面板模式，左边浏览目录结构，右边显示当前目录内容，操作起来效率更高。如果想手动开关双面板，在设置 → Display → Landscape mode 里可以调整。

### 添加第一个存储器

点击侧边抽屉底部的「+ 添加存储器」按钮，会弹出完整的存储类型列表。每添加一个存储器，后续每次启动都会自动出现在侧边抽屉里，一点即连。

**云存储**：支持 Google Drive、OneDrive、Dropbox、Box、Mega、pCloud 等主流服务，点进去会跳转到对应服务的 OAuth 授权页面，授权完成后自动挂载。注意企业账户可能有 IT 策略禁止第三方 App 访问，这种情况需要联系管理员放开。如果连接不上，先排查网络是否正常（科学上网环境下 Google 服务需要确认 VPN 全局生效），OAuth 授权过期时长按侧边抽屉的云盘入口 → 移除 → 重新授权即可。

**SMB / NAS 连接**：这是手机访问家里 NAS 最常用的方式。确保手机 WiFi 和 NAS 在同一个子网；确认 NAS 的 SMB 服务已开启（群晖 DSM / 威联通 QNAP 控制面板里能查到）；填写 NAS 的 IP、共享文件夹路径、账号密码。部分路由器开启了 AP 隔离（访客模式常见），会导致设备间无法互访，这种情况下需要关闭 AP 隔离或让手机连回主 WiFi。

**WebDAV 连接**：OwnCloud、Nextcloud、Yandex、Mail.ru、HiDrive 等都兼容 WebDAV。99% 的连接失败是密码问题——这些服务都不能用登录密码，必须用"应用专用密码"。另外 Nextcloud 的 URL 格式是 `https://域名/remote.php/dav`，不是裸域名。自建私有云用自签证书时，如果 SSL 验证通不过，可以临时关闭 SSL 测试。

**FTP / SFTP**：适合连接自建 FTP 服务器，或者手机之间通过 FTP 互传。SFTP 基于 SSH，比 FTP 更安全。

### 把手机变成网络节点：内置服务器

MiXplorer 不仅仅是"客户端"，还能开四种内置服务器，让其他设备直接访问手机上的文件：

| 服务器类型 | 用途 | 典型场景 |
|-----------|------|----------|
| **WebDAV Server** | 基于 HTTP 的文件操作协议 | Joplin/Obsidian 笔记同步到手机、macOS Finder 直接读写手机 |
| **FTP Server** | 传统文件传输协议 | 电脑用 FTP 客户端批量下载手机文件 |
| **HTTP Server** | 浏览器直接访问 | 手机插电脑不方便时，用电脑浏览器打开手机 IP 就能下载 |
| **DLNA Server** | 流媒体协议 | 家里电视、投影仪直接播放手机上的视频 |

**以 WebDAV 服务器为例**，启动步骤是：右上角 ⋮ → Servers → WebDAV Server → 启动 → 设置根目录（默认当前浏览目录，也可以指定一个专门的同步文件夹）→ 显示地址 `http://手机IP:端口`。默认端口 8080，如果同时开了 HTTP 服务器需要把其中一个改端口。客户端接入时，任何支持 WebDAV 的应用都能填这个地址 + MiXplorer 设置的用户名密码来访问——Joplin 笔记同步、macOS Finder 的 Go → Connect to Server、Windows 资源管理器的映射网络驱动器都原生支持 WebDAV。

> [!WARNING]
> 开服务器务必设置用户名密码认证，不要匿名。Silver 版还支持 HTTPS 模式，比纯 HTTP 安全得多。用完及时关闭，不用时让手机一直监听端口既耗电又有安全隐患。国产 ROM （MIUI、EMUI、OneUI 等）默认会杀后台进程导致服务器中断，记得给 MiXplorer 加入电池优化白名单（无限制）和自启动白名单。

### 手机上直接给 APK 重签名：内置签名器

Android 要求所有 APK 必须签名才能安装。传统做法需要 Java + Android SDK + keystore，流程复杂。MiXplorer 把签名器直接集成在了手机上，点击任意 APK 文件 → 弹出选择 → 签名，就能完成。

支持三种签名方案：

| 方案 | 兼容性 | 适用场景 |
|------|--------|----------|
| v1（JAR） | Android 5.0+ 全覆盖 | 最兼容，老旧设备也能装 |
| v2（整文件） | Android 7.0+ | 推荐选择，速度更快、防篡改更强 |
| v3（v2 增强） | Android 9.0+ | 支持证书轮换，厂商更新签名密钥时用 |

一般选 **v1 + v2 组合**，兼容 Android 7.0 及以上的绝大多数设备。证书有两种来源：自动生成临时证书（每次签名换证书，适合一次性修改，不同证书的 APK 不能互相覆盖安装），或者导入自己的 `.keystore` 文件（相同证书能覆盖安装，适合长期维护自己的 App 或修改版）。自己的证书可以在电脑上用 keytool 生成，或 Android Studio 的 Build → Generate Signed Bundle 功能生成后传到手机导入。

签名后的 APK 默认在原 APK 同目录，文件名加 `-signed` 后缀。如果签名后装不上，先检查签名方案是否选对、设备是否允许安装未知来源，另外如果之前装了同一包名但签名不同的版本，必须先卸载旧版再装——不同签名之间不能覆盖安装。

### 常见问题排查速查

**传输慢**：NAS 到手机用 5GHz WiFi 比 2.4GHz 快得多；SMB3 > SMB2 > SMB1；大文件建议用 HTTP 服务器直连电脑，绕过云盘中转。USB OTG 传输慢大概率是线缆质量差或接口限速。

**内置播放器打不开视频**：安装 Codecs 插件（核心功能 + VLC 解码器覆盖最全）；部分编码（HEVC 10-bit、AV1）即使 VLC 也只能软件解码，性能差；可以在播放器设置里强制切换软件/硬件解码模式测试。

**压缩包解压失败**：加密压缩包先确认密码；分卷压缩包（.001/.002…）要确保所有分卷在同一目录且完整；RAR/ZIP 解压提示 CRC 错误说明源文件损坏，重新下载；超大压缩包注意临时目录空间够不够。

**App 偶发崩溃**：先清缓存（设置 → 应用管理 → MiXplorer → 清除缓存，不要清除数据，会删偏好）；确认是最新版（旧版本有已知崩溃 bug）；彻底修复可以 Export 偏好 → 卸载 → 手动删除内部存储里的 `.mixplorer` 目录 → 重装 → Import 偏好。
