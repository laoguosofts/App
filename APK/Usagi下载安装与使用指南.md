## ✨ Usagi 是什么

Usagi 是一款开源的 Android 漫画阅读器，出自 Kotatsu 系开源谱系，沿着 Kotatsu → Yumemi → Usagi 这条迭代链逐步演进。它沿用 GPL-3.0 协议，在原版 Kotatsu 的基础上修补了社区长期反馈的缺陷，同时增加了几项独有的能力。

Usagi 的定位很明确：给漫画爱好者一个轻量、灵活、可定制的阅读体验。核心功能包括图源管理、按名称/题材/标签/作者搜索、收藏与订阅、自动阅读进度保存、书签标记、章节跳转、离线下载，以及标准漫画模式和 Webtoon 滚动模式两种阅读器。Material You 风格的界面适配不同 Android 版本，Modern 和 Classic 两套预设风格覆盖不同偏好。

相比原版 Kotatsu，Usagi 最显著的变化有三点：**图源插件化**（JAR 插件导入，图源更新不再依赖应用发版节奏）、**低配优化**（支持 Android 5.0 起步，内存和渲染都针对低端芯片做了调整）、**内置网络隧道**（可绕过部分地区的网络访问限制）。界面配色、背景、字体大小都可以在设置里微调，阅读体验更贴近个人习惯。

> [!NOTE] Usagi 的图源由社区维护，不同图源的内容覆盖范围、搜索支持程度、更新频率都不一样。新手建议先装 2~3 个互补的图源，逐步摸索哪几个对你常用的内容源最稳。

## 🔧 安装步骤

Usagi 是 Android 平台的 APK 安装包，安装过程需要处理未知来源授权。

1. **下载 APK**：从下载页获取最新版本的安装包，建议优先选标注「稳定版」的构建
2. **核对版本号与文件大小**：安装包体积通常在 10~20MB 之间，如果差异过大可能是下载损坏，建议重试
3. **允许未知来源安装**：打开系统设置 → 安全 → 应用安装权限，为文件管理器或下载工具勾选「允许安装未知来源应用」
4. **执行安装**：点击下载好的 APK 文件，系统弹出安装确认时点「安装」。部分旧设备或国产系统可能需要额外确认「此来源不受信任」的警示
5. **首次启动检查**：安装完成后打开应用，先不要急着导入图源，先跑一遍设置里的「关于 → 版本信息」，确认构建号与下载页标注一致

> [!WARNING] 某些国产 ROM 会在安装 APK 时自动校验签名，如果弹出「签名不一致」提示，说明你之前装过签名不同的同名应用，需要先卸载旧版本再装。提前备份好图源列表和阅读进度。

## 📖 使用入门

### 图源管理——阅读体验的基础

Usagi 本身不内置任何漫画内容，所有内容都来自你导入的第三方图源。图源是 JAR 格式的插件，每个图源对应一个或多个漫画站点的解析逻辑。

导入图源的方式：设置 → 图源管理 → 从本地文件导入或从仓库添加。Usagi 支持在线图源仓库，里面有社区维护的上百个图源，按热度和更新时间排序。启用图源后，它们会自动出现在浏览栏、搜索和收藏功能里。

### 搜索与发现

Usagi 的搜索入口在底部「浏览」栏的右上角放大镜图标，部分界面风格下顶部直接就是搜索框。支持四种搜索方式：

- **按名称搜索**：输入漫画名或部分名称，已启用的所有图源并行搜索，结果按图源分组展示
- **按作者搜索**：部分图源支持按画师/作者名搜索，找到某位作者的全部作品
- **按题材/标签筛选**：浏览栏和推荐位都可以按少年、少女、青年、奇幻、校园、悬疑等题材筛选
- **推荐位发现**：浏览栏里带题材筛选的推荐位，从已启用图源拉取热门、新上架或特定题材的漫画，不用进搜索页就能发现新东西

搜索结果的质量和两个因素直接相关：你启用了多少图源，以及这些图源对搜索的支持程度。只装一两个图源的话搜索范围就会很窄，建议多装几个互补的图源。

### 阅读体验

Usagi 的阅读器有两种模式：**标准模式**（翻页）和 **Webtoon 模式**（滚动）。在阅读界面可以随时切换。

自动保存阅读进度是默认开启的——上次读到第几页、用的什么模式，下次打开同一章节直接跳回原位。进度数据保存在本地，开启应用内自动同步后同账号多设备之间也会同步。

书签和进度是两个独立功能：进度是系统自动记录的，书签是你主动标记的页面。在阅读界面唤出控制面板，点小旗子图标就在当前页加了书签，再点一下就是删除。书签入口在历史或收藏栏的菜单里，也可以在阅读进度服务的设置里管理。

章节跳转长漫画里特别实用——控制面板里的章节列表按钮展开后，直接跳到任意一章，不用一章一章往后翻。另外可以在设置的「阅读」分类里开启「章节结束后自动进入下一话」，读完当前章自动加载下一话，省掉手动返回详情页再选下一话的步骤。

### 图源连接问题排查

导入图源后点进去一直在转圈、或者提示「无法连接」「解析失败」是开源阅读器最常见的问题。Usagi 内置了一套应对手段，可以按顺序排查：

**第一步：确认图源本身还能用**。很多第三方图源是社区维护的，目标站点改版、域名更换、临时下线都会导致图源失效。先在浏览器里直接访问目标站点，看能不能打开。

**第二步：切换网络环境**。某些站点在移动网络和 Wi-Fi 下表现不一样，换个网络试试。

**第三步：更新图源到最新版**。旧版本图源可能跟不上站点的最新结构，图源管理页里一般能看到更新提示。

**第四步：启用内置隧道**。Usagi 的独特能力之一——内置网络隧道可以绕过部分地区的网络访问限制。在设置 → 网络里找到隧道相关开关，开启后再试同一个图源。

> [!TIP] 隧道只提供基础的网络绕过能力，不是万能的。某些站点防护级别更高，还是连不上。能打开浏览页但点进章节后内容空白，通常是图源解析逻辑和站点当前结构不匹配，这类问题用户侧基本解决不了，只能等图源维护者适配。

一个图源偶尔能连偶尔不行，多半是目标站点本身的稳定性问题（服务器过载、临时维护），不是 Usagi 的 bug。可以在订阅里设置更新间隔，错开高峰时段。
