## ✨ Caustic：一台手机能装下的完整电子音乐工作室

Caustic 是一款专为移动设备设计的完整电子音乐制作应用——把传统 DAW（数字音频工作站）里的合成器、鼓机、音序器、混音台和效果器全部塞进一台手机或平板里。它的定位很明确：给想做电子音乐但不想背笔记本 + 一堆硬件的人，提供一套走到哪写到哪的随身制作环境。

应用内置了多台风格各异的合成器：减法合成的 Subsynth、群声合成的 SawSynth、FM 调制的 FMSynth、物理建模的 KSSynth、采样鼓机 BeatBox、PCM 采样合成器、Pad 底垫合成器……每台机器都有独立的参数面板和钢琴卷帘，支持 Pattern 循环录制、Song 模式编排整首曲目、MIDI 键盘实时演奏和力度录制。混音台提供 16 通道、每通道独立的 EQ 和 3 段效果器插槽（合唱、延迟、混响、过载、压缩等）。

从 Loop 片段到完整曲目，从 Idea Sketch 到成品导出 WAV，Caustic 覆盖了电子音乐制作的全流程。它特别适合 Trance、EDM、Techno、Lo-fi 等依赖合成器音色和鼓机节奏的风格，也能胜任简单的器乐创作。

## 🔧 安装步骤

### Android 平台

1. 在浏览器中打开下载页，找到最新版本的 APK 文件链接，点击下载
2. 下载完成后，在文件管理器中找到 APK 文件并点击安装
3. 如果系统提示「未知来源」，需要进入 **设置 → 安全**，打开「允许安装未知来源应用」或对当前浏览器授予安装权限
4. 安装过程中如果弹出杀毒软件误报提示，选择「继续安装」即可——APK 是公开分发的正版安装包
5. 安装完成后首次启动会请求存储权限，全部允许以确保 Song 文件、预设和导出音频能正常读写

> [!WARNING]
> 务必核对下载的 APK 文件大小与下载页标注一致。Caustic 的安装包通常在 30~60MB 区间，如果大小差异明显，建议重新下载避免损坏。

### iOS 平台

直接在 App Store 搜索「Caustic」，点击获取按钮即可自动安装。iOS 平台不存在未知来源授权的问题，安装过程全程标准化。

### 解锁完整版

Caustic 免费版提供了完整的核心功能（所有合成器、鼓机、Pattern 录制、混音台），但导出时会有水印提示。解锁完整版需要在应用内购中一次性购买，解锁后可导出无水印的 WAV / OGG / MIDI 文件。

## 📖 使用入门

### 机架与机器概念

打开 Caustic，你看到的主界面是**机架（Rack）**——上面插着一排"机器"（合成器、鼓机、效果器）。每台机器独立工作，有自己的参数面板和钢琴卷帘。典型的机架布局：

| 位置 | 机器 | 角色 |
| --- | --- | --- |
| 1 | BeatBox | 鼓机，8 通道采样鼓组 |
| 2 | Subsynth | 主奏 Lead，减法合成 |
| 3 | BassLine | 贝斯音轨 |
| 4 | PadSynth | 底垫铺底 |
| 5~8 | 效果器 | 延迟、混响、压缩等 |

不同风格的曲目可以自由增减机器数量和类型。

### Pattern 模式与 Song 模式

Caustic 有两种工作模式，理解它们的区别是高效创作的前提：

- **Pattern 模式**：每台机器各自循环自己的 Pattern（通常是 4~8 小节），你可以逐台录制、逐台调整，像搭积木一样把各声部拼起来。适合 Idea Sketch 和片段录制。
- **Song 模式**：把多个 Pattern 按时间线编排成整首曲目，支持自动化（旋钮随时间变化）。适合正式编曲和导出成品。

新手建议从 Pattern 模式开始，先把各声部的 4 小节循环录好，再切到 Song 模式拼接成完整结构。

### MIDI 键盘实时录制

如果手上有 USB MIDI 键盘或蓝牙 MIDI 控制器，Caustic 支持实时演奏录制——这是比手动画音符高效得多的工作流。

**基本录制步骤**：

1. 连接 MIDI 设备后先测试：选 Subsynth，直接弹键盘，能听到声音就说明连接正常
2. 切到 Pattern 模式，设置好 Pattern 长度（1x/2x/4x/8x）和 BPM
3. 打开节拍器，按 **Record** 按钮（屏幕闪红表示录制就绪）
4. 按 **Play** 开始播放节拍器，同时在 MIDI 键盘上弹奏音符
5. 弹完需要的段落，按 **Stop**——Caustic 自动做两件事：把音符量化对齐到网格、保留你弹奏时的力度变化
6. 切到钢琴卷帘微调：删除多余音符、补漏、调整力度和时长

> [!TIP]
> 录制是**覆盖式**的——再次录制会清除旧内容。如果只是小问题，直接在钢琴卷帘里改，不用重录。录制力度时弹得自然一点，不要全用一样的力，力度变化会让音轨有呼吸感。

**录制期间可以随时切换机器**：正在录 Subsynth 时切到 BassLine，BassLine 立刻进入录制模式，Subsynth 之前录的不受影响——不用每台都点 Record / Stop，一次 session 里可以连续录完所有声部。

部分控制器有打击垫（Pad），非常适合录 BeatBox 的鼓点：切到 BeatBox → Pattern 模式 → Record → 用 Pad 跟着节拍器敲，Stop 后自动对齐到 16 步网格，比在触摸屏上点格子效率高太多。

### 合成器预设管理

每台机器的完整参数可以存成**预设（Preset）**——调了一个好音色立刻存下来，下次一键加载。预设文件存放在设备的 `/caustic/presets/<机器类型名>/` 目录下，是纯文本 XML 格式，可以拷到其他设备分享。

预设面板在每台机器参数面板的中间靠上，有一个小 LCD 屏幕：

- **点击** LCD → 弹出预设浏览器选一个加载
- **左右滑动** LCD → 快速前后切换预设
- **长按** LCD → 保存当前参数为新预设

> [!NOTE]
> 预设只能在**同类型机器**之间使用——Subsynth 的预设不能加载到 FMSynth 上，参数结构不同。保存时起一个能描述音色的名字（如 "Acid Bass 303"、"Trance Lead"），几个月后你绝对认得出哪个是哪个。

预设和 Pattern 是两个容易混淆的概念：**预设存旋钮参数（音色），Pattern 存音符序列（节奏）**。一个机器 = 一个预设 + 一个或多个 Pattern。保存 Song 文件时，Caustic 会自动把当前所有机器参数存进去，下次打开音色精确还原——预设的作用是跨 Song 复用音色。

### 物理建模合成器 KSSynth

KSSynth 基于 Karplus-Strong 物理建模算法，模拟琴弦被拨动后的振动衰减过程，能生成极其逼真的拨弦、弓弦和共振音色——包括吉他、贝斯、钢琴、钟琴等。

核心参数：

| 控件 | 功能 | 物理类比 |
| --- | --- | --- |
| Sustain | 持续时间 | 琴弦长度 × 衰减系数 |
| Damping | 阻尼系数 | 琴弦在空气中的能量损失 |
| Pickup Position | 拾音器位置 | 0% = 琴桥（尖锐），100% = 琴枕（温暖） |
| Brightness | 亮度 | 低通滤波器截止频率 |

**典型音色速查**：

| 目标音色 | 关键参数组合 |
| --- | --- |
| 拨弦吉他 | Sustain 2000~3000ms + Damping 40~50% + Pickup 30% |
| 电贝斯 Slap | Sustain 1200ms + Damping 70%（快速衰减，干脆感）+ Brightness 80% |
| 钢琴音 | Sustain 4000~6000ms + Damping 20%（慢慢衰减）+ Release 1000ms |
| 弓弦乐 | Damping 10~20% + Sustain 8000ms 以上（极慢衰减） |

KSSynth 加效果器可以进一步美化音色：Saturation 模拟电吉他失真、Slap Delay 适合电贝斯、小房间 Reverb 模拟原声吉他箱体共鸣。局限性是复音数有限（每多一个音符 CPU 多算一整条振动衰减链），通常设为 4~8 比较稳妥，不擅长 Pad 类持续音。

### 超锯齿群声合成器 SawSynth

SawSynth 专门实现了 Roland JP-8000 发扬光大的**超锯齿波（Supersaw）** 技巧——把 7~11 个微失调的锯齿波叠加，产生厚密的群声合唱效果，是 Trance、EDM 主奏 Lead 的标配音色来源。

核心参数：

| 控件 | 功能 | 典型值 |
| --- | --- | --- |
| Saw Wave Count | 叠加锯齿波数量 | 7~11 个 |
| Detune Amount | 每个波之间的微失调量 | 5~15 cents |
| Stereo Spread | 立体声场分布 | 30~60% |

调一个标准 EDM Lead 的参数参考：Saw Wave Count 9 + Detune 8 cents + Stereo Spread 40% + 低通滤波 Cutoff 70% + Filter Env Attack 10ms Release 500ms，再挂 1/8 拍 Delay 和小空间 Reverb 就是成品。

为什么超锯齿比单锯齿好听？多个微失调的锯齿波在频域上产生密集谐波结构，天然的相位抵消让波形随时间缓慢变化，听起来有"生命感"而非机械循环，不需要额外加 Chorus 效果器就能得到合唱效果。

SawSynth vs Subsynth 的选择逻辑：**做群声合成用 SawSynth**（标准 EDM Lead），需要深度滤波扫频、FM 调制或多波形切换时用 Subsynth（经典模拟合成）。

### 导出与成品收尾

当 Song 模式的编排完成后，可以导出三种格式：

| 格式 | 用途 | 大小 |
| --- | --- | --- |
| WAV | 无损成品，适合混音后母带处理 | 大 |
| OGG | 压缩格式，适合分享和网络传播 | 小 |
| MIDI | 音符数据，适合进 DAW 二次编辑 | 极小 |

完整版解锁后导出无水印。免费版导出的音频开头会有 Caustic 水印提示音，适合个人学习使用。
