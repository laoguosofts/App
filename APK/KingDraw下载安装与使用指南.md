## ✨ KingDraw 是什么

KingDraw 是一款面向化学领域的结构式绘制工具，主打轻量、免费、跨平台三个特点。它能在 Windows 电脑、手机和平板上运行，覆盖从基础的单键双键绘制到立体化学构象、反应机理图等进阶场景。

核心功能包括：数百种化学键和环形模板、内置化学基团库、IUPAC 名称与结构式互转、智能美化、云端存储与多端同步。对于需要画结构式的化学专业学生、科研工作者和教师来说，KingDraw 提供了一套免费可用的日常绘制方案，界面风格接近行业标准工具，上手门槛低。

与传统化学绘图软件相比，KingDraw 的优势在于移动端体验——手机上也能快速画反应机理并导出图片分享，适合组会展示、随手记录等轻量化场景。PC 端则提供完整的工具箱和文件管理能力，能满足论文插图、汇报材料等正式输出需求。

## 🔧 安装步骤

### Windows 版

1. 从下载页获取安装包，确认文件大小与版本号
2. 双击安装包启动向导，按提示选择安装路径（建议默认路径即可）
3. 安装过程中如果被 Windows Defender 或杀毒软件拦截，选择「仍要运行」——这是未签名安装包的常见情况
4. 安装完成后在桌面或开始菜单找到 KingDraw 图标，首次启动需要几秒加载素材库

> [!WARNING]
> 安装完成后建议先在「帮助 → 关于」里核对版本号，确保是当前最新版。旧版本可能缺少某些键型模板或存在已知 bug。

### 移动端（iOS / Android）

1. 打开 App Store 或 Google Play，搜索「KingDraw」
2. 点击安装，等待下载完成
3. 首次启动时授予存储权限，用于保存本地工程文件

### 安装验证

安装好后可以画一个简单的苯环来验证：左侧工具栏选苯环模板，在画板上点击放置，能看到完整的六元环结构就说明安装没问题。

## 📖 使用入门

### PC 版界面五大区域

打开 KingDraw Windows 版后，绘图界面由五个区域组成，了解它们的分工能大幅提升操作效率：

| 序号 | 区域 | 位置 | 主要功能 |
|---|---|---|---|
| 1 | 菜单栏 | 顶部 | 文件 / 编辑 / 视图 / 帮助 等通用功能 |
| 2 | 操作栏 | 顶部工具栏区 | 高频工具：拖拽、框选、常用键 |
| 3 | 左侧工具栏 | 左侧 | 完整绘图工具箱：键、环、电荷、基团 |
| 4 | 画板区 | 中央 | 结构式绘制的主工作区 |
| 5 | 文件管理区 | 右侧边栏 | 本地文件 / 云端文件管理 |

左侧工具栏是绘图的核心所在，里面包含了化学键组（单键、双键、三键、楔形键、氢键、离子键等）、环形模板组（环丙烷到环辛烷、苯环、椅式结构）、电荷工具、括号工具、内置化学基团库、长链与折叠环链绘制器，以及流程图用的箭头和模型工具。熟练掌握这一块，基本就能应对绝大多数绘图需求。

> [!TIP]
> 菜单栏的「视图 → ACS1996 规范」是论文插图的救命开关，一键就能把键长、字号、线型等全部调整为 ACS 期刊标准样式，不用手动一项项改。

### 化学键绘制与键角调整

KingDraw 提供两种方式调整化学键的角度和长度：

| 方式 | 适用场景 | 操作特点 |
|---|---|---|
| 绘制时旋转 | 单个键的角度调整 | 绘制过程中按住旋转点拖动 |
| 框选后调整 | 已有关的精确微调 | 先选框选工具再拖动键端点 |

绘制过程中，每次旋转自动吸附 15°，如果需要任意角度自由旋转，按住 `Alt` 键再拖动旋转点即可。这是最快的调整方式——画键的时候一次调准，不用事后返工。

如果已经画好的键长度不对，推荐用框选工具（快捷键 `Q`）点击键的某一端点，然后拖动到想要的位置，键会实时跟随伸缩。也可以选中整个结构后，把鼠标放在选框边缘整体拉伸或压缩，适合结构整体需要放大缩小的情况。

KingDraw 还自带一些辅助对齐机制：拖动键端点时靠近另一个结构的端点会自动吸附；苯环模板的键角固定 120°，不用手动调整；如果手动拉乱了键长想恢复标准 ACS 规范，选中结构后使用「智能美化」功能一键规范化。

### 椅式环己烷构象

环己烷的优势构象是椅式，KingDraw 在左侧工具栏环模板区域底部专门提供了左右两种椅式模板，方便直接画立体化学要求高的结构：

| 模板 | 名称 | 特征 |
|---|---|---|
| 左侧椅式 | 六元环的左开口椅型 | 常用于展示平伏键 / 直立键 |
| 右侧椅式 | 六元环的右开口椅型 | 与左侧椅式呈镜像对称 |

使用方法和普通环模板一样：选模板 → 画板上点击放置 → 旋转调整角度（按住 `Alt` 自由旋转）。画好椅式骨架后，需要手动添加楔形键来标记平伏键（大致与环平面平行，用虚线楔形）和直立键（大致垂直于环平面，用黑体楔形）——KingDraw 不会自动标记这两种键型，需要自己判断取代基方向。

如果要把椅式 A 翻转成椅式 B（构象翻转 / 环翻转），选中整个椅式结构复制一份，用翻转工具或水平镜像得到镜像结构即可。

椅式模板在甾醇分子的环系绘制、糖的吡喃型结构展示、构象异构体对比等场景下都非常实用——三个六元环稠合的甾醇母核依次用椅式模板叠加就能搞定，葡萄糖的吡喃型也能用椅式模板清晰展示取代基的平伏 / 直立方向。

### 导出、保存与分享

画完结构式后的输出环节，KingDraw 支持多种方式：

**图片导出（PC 端）**：文件 → 导出 → 选择 PNG 格式 → 设置分辨率和背景色 → 保存。移动端更简单，画好后点右上角「分享」→「保存为图片」，直接进手机相册。

分辨率选择建议：论文插图至少 300 dpi（ACS 期刊要求 600 dpi 更佳），汇报 PPT 200 dpi 足够，网页展示 150 dpi 就行。

**工程文件保存**：`Ctrl+S` 保存当前画板的 `.king` 文件到本地，`Ctrl+Shift+S` 另存为其他格式或文件名。登录账号后自动同步到云端，多端访问时文件自动同步。

**协作分享**：移动端支持直接从 APP 内通过微信、邮件、短信分享，可以选择 PNG 图片或 `.king` 工程文件；PC 端则更适合导出为 `.mol` 或 `.cdx` 格式发给同事——ChemDraw 和 KingDraw 都能打开这些通用格式，方便互相评论修改。

一个常见的论文插图工作流是：KingDraw 画结构 → 用智能美化 + ACS1996 规范调整布局 → 导出 600 dpi PNG → 插入论文正文 → 最后确认版式符合期刊投稿要求。

### IUPAC 互转与化学属性面板

编辑菜单里有两个实用功能：「结构式转名称」和「名称转结构式」——输入或画出结构，KingDraw 能自动生成标准 IUPAC 命名，反过来输入名称也能画出结构，对核对命名正确性很有帮助。视图菜单下还可以打开化学属性面板，查看分子式、分子量、氢键供受体数量等信息。
