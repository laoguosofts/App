## ✨ FairEmail：把安全和隐私放在第一位的开源邮件客户端

FairEmail 是一款专注于**隐私保护和安全通信**的 Android 邮箱客户端，由荷兰开发者 Marcel Bokhorst 独立维护。不同于市场上多数邮箱客户端将功能和广告摆在首位，FairEmail 的核心设计理念是：不追踪你、不收集你数据、不让发件人知道你何时打开了邮件。

FairEmail 支持 IMAP 和 POP3 协议，无论你用 Gmail、Outlook、Yahoo 还是自建邮箱服务器，都能统一接入。免费版已经覆盖了大多数用户的日常收发需求——无限账户、多身份管理、统一收件箱、OpenPGP 加密、反追踪图片防护、反钓鱼重格式化、消息认证警告（DMARC/SPF/DKIM）、全文搜索，这些功能全部内置。Pro 版本提供过滤规则、回复模板、定时发送、应用级锁定、S/MIME 加密等高级效率工具，但所有基础通信功能从不锁在付费墙后面。

FairEmail 没有广告、没有分析追踪、没有后台服务常驻——它甚至不会主动同步邮件，只有在你打开应用时才拉取新消息，这样的设计让它在续航和隐私两方面都有突出表现。如果你对邮箱客户端的隐私政策心存疑虑、或者需要一个能把 Gmail 全家桶账号和自建邮箱统一管理的工具，FairEmail 值得认真考虑。

## 🔧 FairEmail 安装与首次配置全程

### 系统要求与安装

FairEmail 对设备要求极低——Android 5.0 Lollipop 及以上即可运行，安装包约 30 MB，后续邮件数据存放在内部存储或 SD 卡。安装过程就是标准的 Android APK 安装流程，允许"未知来源"安装后点击 APK 文件确认即可。

> [!WARNING]
> 安装前请核对文件名中的版本号与下载页标注的最新版本是否一致。FairEmail 更新频率不高，但每个版本都有针对性的安全补丁，建议保持跟进。

### 快速设置向导

首次启动 FairEmail 会进入快速设置向导，两步带你完成第一个账户的接入：

**第一步：选择账户类型**

向导可以自动识别主流邮箱服务：

1. **Google / Gmail**：Play Store 版和 GitHub 版会跳转到 Google OAuth 授权页，确认后自动完成 IMAP 和 SMTP 配置，无需手动填服务器地址和密码
2. **Outlook / Live / Hotmail**：同样支持 OAuth 一键授权
3. **其他邮箱**：输入邮箱地址，FairEmail 会尝试根据域名自动匹配服务器配置
4. **手动设置**：直接跳到 IMAP/SMTP 参数输入界面

**第二步：设置身份**

账户认证完成后，向导让你确认发信身份（Identity）：显示名称（收件人看到的发件人名称）、默认签名、默认回复地址（如果和发件地址不同）。这些都可以稍后在设置里修改，向导里留空也不影响。

设置成功后进入主界面——左侧抽屉列出账户和文件夹，中间是统一收件箱或你选择的某个文件夹，底部是消息预览。

### 设置失败的常见应对

快速设置不是万能的，以下四种情况比较常见：

| 问题 | 解决方案 |
| --- | --- |
| 邮箱服务商未被自动识别 | 进入手动设置，查该邮箱的 IMAP/SMTP 服务器地址 |
| 需要应用专用密码而非常规密码 | 参考各邮箱服务商的帮助文档生成应用专用密码 |
| VPN 干扰认证 | 开发者明确提到 VPN 经常导致邮箱服务器拒绝认证，关掉再试 |
| F-Droid 版本用 Gmail | F-Droid 无 OAuth 支持，必须手动走应用专用密码路线 |

初始设置完成后，任何时候都可以在设置中添加新账户、修改现有账户或添加多个发信身份。FairEmail 没有账户数量上限。

## 📖 FairEmail 使用入门：从收发到进阶玩法

### 写信界面：比看起来更强大

在 FairEmail 中打开写信界面有三种方式：右下角铅笔图标、邮件详情页的「回复/全部回复/转发」、通知栏快捷操作。界面从上到下依次是：发件人身份选择条、收件人 To、抄送 CC 和密送 BCC（点击 To 行末尾的 + 展开）、主题、附件行、格式工具栏、正文编辑区。

格式工具栏支持加粗、斜体、下划线、有序/无序列表、引用块、段落样式（H1~H4）、字体大小、对齐方式。FairEmail 不支持表格编辑——开发者在 FAQ 中明确说明 Android 原生文本编辑器对表格支持有限，如果需要发送带表格的邮件，建议在电脑端写好 HTML 邮件再发送。

FairEmail 在收件人补全上有一个贴心设计：即使你拒绝授予联系人权限，它也能使用自己维护的收发历史地址池来自动补全，不会把你的通讯录上传到任何服务器。

附件方面，支持图片、文档、压缩包等多种类型，点击附件行的 + 按钮通过系统文件选择器添加。长按已添加的附件可以移除或选择「作为附件发送」（把当前邮件作为附件嵌入另一封邮件）。Pro 功能会自动生成 vCard 和日历邀请附件。

> [!NOTE]
> FairEmail 在加载远程图片（邮件正文里引用的外部图片 URL）时默认弹出确认对话框——这是反追踪机制的一部分，防止发件人通过图片加载确认你打开了邮件。本地附件不受这个限制。

FairEmail 在编辑邮件时会持续将内容自动保存到草稿文件夹，即使系统重启或后台被杀，重新打开后草稿还在。手动保存的路径是右上角菜单 → 保存草稿。

### 免费版与 Pro 版：边界在哪里

FairEmail 采用**一次买断、终身使用**的付费模型，Play Store 内购价格约 €7.49（人民币约 55 元），没有任何订阅费用。开发者明确说过，每当他把某个功能列为 Pro，总会有人抱怨"这个功能应该免费"——所以在掏钱之前，先看看免费版能做什么：

| 功能类别 | 免费版 | Pro 版 |
| --- | --- | --- |
| 账户管理 | 无限 IMAP/POP3 账户、无限身份、统一收件箱 | 账户/身份/文件夹自定义颜色和头像、彩色星标 |
| 安全与隐私 | OpenPGP 加密/解密、反追踪图片防护、反钓鱼重格式化、DMARC/SPF/DKIM 警告 | S/MIME 签名和加密、应用级生物识别/PIN 锁定 |
| 同步与通知 | IMAP IDLE 推送、离线存储和操作 | 按账户/文件夹/发件人独立设置通知声音、同步调度（自定义同步时间段） |
| 内容处理 | 会话线程视图、双向同步、全文搜索 | 过滤规则（发件人/主题/关键词自动分类）、贝叶斯垃圾邮件分类器、搜索索引、回复模板 |
| 效率工具 | 快速设置向导 | 消息推迟（Snooze）、定时发送、日历邀请接受/拒绝、导出全部设置 |

免费版没有任何基础通信功能被锁在付费墙后面。如果你只是需要一个好用的邮箱客户端、管理多个账户、偶尔收发邮件，免费版大概率够用。Pro 功能针对的是有高频邮件处理需求的用户——多账户管理、自动分类、定时发送、回复模板这些效率工具，对于客服、人事、项目协调等岗位非常实用。

### 回复模板：Pro 版的效率利器

回复模板是 Pro 功能之一，允许预设常用回复话术，写信时一键插入。这在每天要对大量相似问题回复的场景下特别有用——比如标准感谢回复、标准拒绝回复、项目组的固定口径回复。

模板绑定到身份——不同身份可以有各自的模板列表。每个模板支持以下占位符变量，使用时会自动替换为真实值：

| 占位符 | 替换为 |
| --- | --- |
| `{sender_name}` | 发件人显示名 |
| `{sender_email}` | 发件人邮箱地址 |
| `{subject}` | 当前邮件主题 |
| `{date}` | 当前日期 |
| `{time}` | 当前时间 |

在写信界面点击右上角菜单 → 插入模板，从列表中选一个即可，变量会自动替换。模板可以在设置 → 手动设置 → 身份 → 回复模板区域创建、编辑、删除和预览。

> [!TIP]
> 模板适合覆盖 80% 相似回复的骨架，然后每次手动修改差异部分。不建议把整封邮件（包括所有细节）都做成模板——那样反而会让你习惯一键回复，可能漏掉重要的个性化调整。免费版没有回复模板功能，但可以用签名（每个身份一份固定签名自动附加到每封邮件末尾）、自动文本建议和草稿箱复制粘贴来部分替代。

### 账户扩展与长期使用

FairEmail 没有账户数量上限，你可以随时在设置 → 手动设置 → 账户中添加新账户，也可以为同一个邮箱账户创建多个发信身份（比如一个用于工作、一个用于私人联系）。每个身份可以独立设置显示名称、默认签名和回复模板。

长期使用时的一些维护建议：

- **检查同步设置**：默认自动推送是开启的，但如果你担心耗电，可以在设置中改为定时同步或手动拉取
- **利用离线操作**：FairEmail 支持完整的离线阅读、撰写、标记，网络恢复后自动同步到服务器
- **全文搜索**：免费版也支持全文搜索，但 Pro 版的搜索索引功能可以加快大量邮件的搜索速度
- **定期备份**：Pro 版支持加密导出全部设置，换机迁移时非常方便
