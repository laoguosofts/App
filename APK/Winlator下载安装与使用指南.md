## ✨ Winlator 是什么

Winlator 是一款运行在 Android 手机上的 Windows 程序兼容层——简单说就是让你在安卓手机里跑 exe 的工具。它把 Wine（Windows API 兼容层）、Box86/Box64（x86 到 ARM 的实时指令翻译）、PRoot（无 root 容器）以及 Mesa、DXVK、VKD3D 等一系列成熟的开源组件拼装成一套完整方案，用户不需要 root 就能用上。

它能做什么？老玩家拿它玩经典 PC 游戏（比如《星际争霸》《仙剑奇侠传》《GTA 罪恶都市》），开发者可以在手机上测试一些 Windows 小工具，折腾党则在性能和兼容之间反复调参。它不是云游戏、也不是远程桌面——程序真正跑在你的手机硬件上，靠 CPU 的实时翻译撑起来。

版本线从 v6.1 一路演进到 v11.2，每个大版本都有明确的路线图：v7.0 加入了 DX12 转译，v8.0 内置了文件管理器，v10.0 补上了 Mali GPU 的 Vortek 驱动，v11.0 则升级到 Wine 10.10 并加入了 HUD 模式和手柄震动。发版节奏是 Beta → Final → Hotfix 三段式，出问题先看是不是 Beta 版，别拿测试版的 bug 否定整个版本。

适合谁？有安卓手机、偶尔想怀旧一把 PC 游戏、愿意花十分钟调调参数的折腾党。如果你对性能要求极高、手机是高通骁龙 8 Gen 1 及以上，体验会明显好一截；Mali GPU 机型在新版本也能用，但驱动路线不同。

## 🔧 安装步骤

### 下载前的准备

先确认手机硬件：**最低要求 Android 8.1+、骁龙 710 起步**；推荐骁龙 865 或以上，内存 8GB 更舒服。Mali GPU（联发科、三星部分机型）从 v10.0 开始有了 Vortek 驱动支持，但早期版本可能需要切换图形驱动路线。

### 下载并安装 APK

1. 从上文下载入口获取 APK 文件，确认版本号与官方标注一致；
2. 手机首次安装第三方 APK 需要**开启未知来源授权**：设置 → 安全 → 安装未知应用 → 选择你用来下载的文件管理器或浏览器 → 允许；
3. 点击 APK 安装，全程下一步即可，安装完成后首次启动会申请存储和相机权限，**全部允许**——容器需要读写手机存储来映射驱动器。

### 第一次启动要做的事

> [!WARNING] 首次启动必等它跑完初始化
> 第一次打开 Winlator 会在后台解压根文件系统（约几百 MB），这一步不能跳过也不能杀掉进程，耐心等加载圈转完再操作。

进入主界面后你会看到：顶部有个「+」号用来创建容器，中间是容器列表，底部是快捷方式管理。刚装完是空的——先建第一个容器再说。

### 版本号核对

装完后在应用设置里能看到 Wine 版本和 Box64 版本号。确认一下：Wine 应该在 9.x 或 10.x 系列，Box64 有稳定版本号输出。如果看到的是 alpha 或 nightly 标记，说明装的是测试版，建议换正式版。

## 📖 使用入门

### 容器：给每个程序一间独立的 Windows 房间

Winlator 最核心的概念就是**容器**——你可以把它理解成一台独立的虚拟 Windows 电脑。每个容器有自己的 C 盘、自己的注册表、自己的开始菜单，装在里面的程序互不干扰。

为什么要这样设计？假设你想同时玩一款老游戏（需要 DirectX 9、低分辨率）和一款新一点的游戏（需要 DXVK、高分辨率），如果塞在同一个 Windows 环境里，两套驱动参数会互相打架。分开容器，各配各的设置，出问题删掉容器即可，手机里自己放的游戏文件不会跟着消失。

**容器与快捷方式是上下两层关系**：

| | 容器 | 快捷方式 |
| --- | --- | --- |
| 是什么 | 隔离的 Windows 环境 | 指向容器内某个 exe 的启动器 |
| 有自己的设置吗 | 有，是默认值 | 有，但只「覆盖」容器的个别项 |
| 存程序吗 | 存（装在容器里的软件） | 不存，删快捷方式不删程序 |
| 数量关系 | 一个容器 | 可建任意多个，全挂在容器下 |

一句话记住：**容器定基调，快捷方式做微调**。容器里没改的设置，快捷方式可以单独改；容器里改了，所有没覆盖该设置的快捷方式跟着变。

容器在磁盘上对应一个目录（形如 xuser-编号），里面的 `.wine/drive_c` 就是「C 盘」。容器列表里长按可以编辑、复制、删除或运行——复制适合升级前留后路，删除就是连环境带程序一锅端。

### 创建第一个容器

点击主界面的「+」，给容器起个名字（比如「游戏容器」「老软件容器」），然后你会看到一堆可选项。不用全弄懂，按下面的节奏来：

1. **Wine 版本**：选应用默认的那个就行（一般是 Wine 9.2 或 10.x Custom），版本太旧兼容差、太新可能有 bug，默认档最稳；
2. **图形驱动**：默认选 Mesa/Turnip（高通骁龙机型），Mali GPU 选 Vortek，Intel GPU 选 Zink；
3. **DXVK / VKD3D / D8VK / D7VK**：保持默认开启——这几条是 DirectX 到 Vulkan 的转译层，不开启很多游戏直接闪退；
4. **DirectDraw 渲染**：老游戏（2D 为主）可以开 CNC DDraw 或直接走 OpenGL，哪个好用哪个；
5. **屏幕分辨率**：先设成手机屏幕物理分辨率，跑起来后再调窗口化或全屏；
6. **CPU 预设（Box64）**：默认选 Compatibility（兼容档），下文会详细解释四档预设的取舍。

### 把 exe 和游戏文件放进手机

容器通过驱动器映射访问手机存储，默认 D: 就是 Download（下载）目录。所以最顺手的做法是：**把 exe 和游戏文件都放进手机的 Download 目录**，容器里打开 D 盘就能直接看到。

三种常见导入途径：

| 途径 | 适用场景 | 注意点 |
| --- | --- | --- |
| 手机直接下载 | 小体积安装包、单文件绿色版 | 不要在容器里开陌生网站下载（Z: 盘会让容器看到全部存储） |
| USB 数据线传输 | 几个 GB 的大游戏包、电脑已有完整目录 | 保持目录结构完整——很多 Windows 游戏靠相对路径找资源，拆散了就跑不起来 |
| 网盘转存 | 中转大文件、换设备同步 | 下载完成后确认文件在可访问的目录里，别停留在网盘私有缓存 |

> [!TIP] 放好之后的检查单
> 1. 压缩包解压无误，exe 双击属性正常
> 2. 大小与来源页标注一致
> 3. 绿色版游戏目录结构没拆

### Box86 / Box64 预设：翻得准还是翻得快

安卓是 ARM 芯片，Windows 程序是 x86/x86_64 指令，中间的实时翻译由 Box86（32 位程序）和 Box64（64 位程序）完成。翻译器有一堆可调开关，在「翻得准」和「翻得快」之间取舍——预设就是官方配好的几组开关组合。

容器设置里 Box86 预设和 Box64 预设分开各选一份。**现代游戏多是 64 位，Box64 预设影响最大**；老游戏常带 32 位启动器，两份都生效。

四档预设的取舍：

| 预设 | 取向 | 什么时候用 |
| --- | --- | --- |
| Stability（稳定） | 最保守，全部从准 | 莫名崩溃、花屏、结果算错时 |
| Compatibility（兼容） | 默认档，准中带快 | 不确定就用它，大多数游戏的起点 |
| Intermediate（中级） | 关闭部分保护换速度 | 兼容档太慢、性能档又不稳的中间态 |
| Performance（性能） | 全关保护求最快 | CPU 瓶颈且运行稳定的游戏 |

遇到问题直接照官方排查表调：

| 症状 | 动作 |
| --- | --- |
| 帧率低、CPU 吃满 | 换 Performance |
| 随机崩溃、卡死 | 换 Stability |
| 花屏、颜色错 | 换 Stability |
| 物理引擎表现诡异 | 回 Compatibility 或 Stability |
| Unity 游戏崩 | Stability，或加启动参数 `-force-gfx-direct` |
| Performance 下偶发不稳 | 退 Intermediate |

预设改动即时生效，重开游戏即可，无需重装任何东西。普通玩家用四档内置预设足够，不必去碰自定义预设（预设下拉框旁的管理按钮可以逐项手调翻译器开关，但数值越高越快越险，而且自定预设存在本机偏好里，**不随容器备份导出**）。

### 快捷方式与启动参数

容器建好后不能直接从手机桌面启动程序——你需要在容器内找到 exe，创建一个快捷方式。快捷方式可以单独覆盖容器的某些设置（比如某个游戏单独换一个 Box64 预设），还能加启动参数。

常见启动参数示例：
- `-windowed` 或 `-w`：窗口化启动（很多老游戏默认全屏会闪退）
- `-resolution 1280x720`：指定分辨率
- `-force-gfx-direct`：Unity 游戏渲染问题的常见修复
- `-nointro`：跳过启动 logo（部分游戏支持）

快捷方式参数写错了不会破坏容器，最多就是启动报错，改回来就行。

### 性能调优的整体顺序

调性能别乱试——按这个顺序来最省时间：

1. **先换预设**：从 Compatibility 往 Performance 试，稳不住就退一档；
2. **换图形驱动**：Mali 用户试 Vortek，高通用户优先 Turnip；
3. **改分辨率**：降到 1280×720 或更低，很多老游戏在高分辨率下反而更慢；
4. **关不必要的后台**：手机内存紧张时 Winlator 会抢资源，留够 2GB 以上空闲；
5. **更新 Box64 和 Mesa**：应用设置里可以在线更新翻译器和 GPU 驱动，新版本常有性能提升。

> [!NOTE] 关于根权限
> Winlator 本身不需要 root，PRoot 组件在无 root 环境下也能运行 Linux 子系统。但 root 后可以开启一些额外特性（比如更完整的存储访问），非必须。
