## ✨ nPlayer 是什么 — 移动影音播放的全能选手

nPlayer 是一款面向 iOS 和 Android 平台的专业级视频播放器，主打本地高清播放与网络流媒体远程访问两大核心能力。它原生支持几乎所有常见的视频和音频编码格式——H.264、HEVC/H.265、AV1 高清解码，DTS HD、Dolby TrueHD 无损音频，以及 SSA/ASS 特效字幕完整样式解析，不需要额外转码或安装解码包。

这款播放器的定位不是给只想随手刷短视频的 casual 用户准备的，而是瞄准那些手上真有一批资源需要认真看的人——家里有 NAS 影视库的家庭影院用户、追海外剧需要精细调校字幕的字幕党、收藏了大量 4K REMUX 高清片源的发烧友，还有把视频存在 FTP/SFTP 服务器、云盘 Box/Dropbox/OneDrive/Yandex Disk 上随时需要远程拉取观看的流媒体观众。从自建 VPS 公网服务器到局域网 SMB 共享，从 UPnP/DLNA 设备到 WebDAV 同步盘，nPlayer 把各种远程访问协议做了统一整合，让一个 App 同时充当本地播放器和远程资源中枢。

字幕系统是 nPlayer 的一大强项。除了常规的 SRT、SSA/ASS 多轨字幕支持，它还内置了 OpenSubtitles 在线字幕搜索、以毫秒为单位的字幕延迟精细调节、以及「随字幕定位」快进快退自动对齐字幕位置等进阶功能。对于追求极致视听体验的用户来说，这些细节往往决定了一部片能不能看得舒服。

## 🔧 安装步骤 — 各平台注意事项

### iOS 平台

iOS 用户安装相对简单，直接在 App Store 搜索「nPlayer」点击获取即可。App Store 版本经过苹果审核，不需要额外处理权限设置。安装完成后第一次打开，系统会询问「允许 nPlayer 访问你的照片和视频」，选择允许才能让 nPlayer 扫描本地相册中的视频文件。

### Android 平台

Android 侧载安装的流程稍复杂一些：

1. 从官方下载渠道获取 APK 安装包，**务必核对文件大小和版本号**，避免下载到旧版或被篡改的二次打包版本
2. 如果是 Android 8.0 及以上系统，在安装前需要去「设置 → 安全 → 安装未知应用」中，为用来打开 APK 的文件管理器或浏览器授予「允许安装未知来源应用」权限
3. 点击 APK 开始安装，过程中如果弹出杀毒软件风险提示，可以忽略——nPlayer 本身是正规播放器，误报多见于某些国产手机厂商的预装安全组件
4. 安装完成后首次启动，系统会请求存储权限，选择允许后 nPlayer 才能访问设备上的本地视频文件

> [!WARNING]
> Android 用户侧载安装时一定要从官方可信渠道获取 APK，不要随意下载论坛或云盘上不明来源的二次打包版本。如果需要 VPN 连接海外服务器访问远程资源，也建议使用系统级 VPN 设置，避免在第三方修改版中嵌入恶意代码。

### 安装后核对

安装完成后可以通过以下几个点快速确认是正版原版：

- App 内「关于」页面显示的版本号与下载时的版本一致
- 首次启动没有强制弹出的广告弹窗或捆绑下载提示
- App 签名正常——Android 可通过包管理器查看签名指纹，iOS 则看 App Store 开发者信息

## 📖 使用入门 — 从基础播放到进阶玩法

### 本地文件播放

打开 nPlayer 后默认进入「本地」标签页，系统会自动扫描设备存储中的视频文件。首次使用建议手动点一次刷新按钮，确保所有视频都被索引到。点击文件即可直接开始播放，nPlayer 会自动识别视频编码并启用硬件加速解码。

播放界面的基础操作是：单击屏幕显示/隐藏控制栏，左右滑动调整播放进度，上下滑动（左侧）调节亮度，上下滑动（右侧）调节音量。这些手势映射可以在设置中自定义。

### 字幕设置与同步调整

字幕是 nPlayer 最值得花时间熟悉的功能模块。播放视频时如果需要外挂字幕，点击控制栏的字幕图标，可以选择本地 SRT/ASS 文件或者直接在线搜索 OpenSubtitles 数据库。

**字幕不同步的微调**是经常遇到的情况。造成字幕时间轴不准的常见原因包括：字幕从不同版本的视频上提取（比如蓝光字幕配流媒体视频）、视频开头被剪辑过（片头被去掉了）、或者网络流媒体本身有缓冲延迟。nPlayer 提供了以**毫秒为单位**的精细调校能力：

- 播放时点击屏幕显示控制栏 → 进入字幕设置 → 找到「字幕延迟」滑块
- 向右拖（正值）= 字幕往后延迟，适合字幕出得太早、声音还没到嘴型的情况
- 向左拖（负值）= 字幕往前拉，适合声音已经出来、字幕还没显示的情况
- 调整单位 1000ms = 1 秒，可以精细到几十毫秒级别

判断方向的小技巧：听人物说话时，字幕先蹦出来但声音还没到嘴型——这叫字幕出早了，需要**延迟**（正值）；声音已经出来了、嘴型都动了，字幕还没显示——这叫字幕出晚了，需要**提前**（负值）。

> [!TIP]
> 部分版本支持快速手势来调节字幕延迟：按住屏幕左侧 + 上滑 = 延迟 +100ms，按住屏幕左侧 + 下滑 = 延迟 -100ms。具体手势映射可以在设置中查看和自定义。nPlayer 会为每个视频单独记住字幕延迟设置，下次打开自动应用上次的校准值。

另外还有一个好用的功能叫「随字幕定位」（Seeking with Fitting Subtitles）。开启后，快进快退时播放器会自动跳到最近的字幕位置，方便快速定位到有对话的片段，而不是漫无目的地拖进度条。

### 文件夹锁定 — 保护私密视频

nPlayer 提供了两级安全保护来守护你的私人影音内容：

| 层级 | 说明 | 适用场景 |
| --- | --- | --- |
| **应用级密码** | 打开整个 nPlayer App 都需要密码 | 把手机借给别人用的时候 |
| **文件夹级密码** | 只有特定文件夹需要密码才能查看 | 私密视频、个人隐私内容 |

设置文件夹密码的操作很直观：在本地文件列表中**长按**想要保护的文件夹 → 弹出菜单选择「锁定文件夹」 → 设置 4 位或更长的密码 → 确认密码。锁定后该文件夹会显示为锁图标，点击进入时才需要输入密码。

如果觉得每次输密码太麻烦，可以在设置里开启 Touch ID 或 Face ID 替代——锁定文件夹直接用指纹或脸部识别解锁，体验上更流畅。

> [!NOTE]
> 文件夹密码**没有找回机制**，忘了密码 = 里面的文件彻底无法访问。建议把密码记在安全的地方。另外，卸载 nPlayer 会清除密码设置，但文件夹内的视频文件本身不会被删除——它们只是不再被 nPlayer 的密码系统保护了。

### 远程访问：FTP/SFTP 跨公网连服务器

当你需要从公网服务器（而不是家里的局域网 NAS）访问视频文件时，FTP 和 SFTP 是最常见的选择。适用的场景包括：自建 VPS 或云服务器上的视频库、海外服务器上的影视资源、公司内网服务器通过端口映射访问、或者通过 FTP 共享的公开资源。

**FTP vs SFTP 的区别**：

| 特性 | FTP | SFTP |
| --- | --- | --- |
| 加密 | 明文传输 | SSH 加密 |
| 默认端口 | 21 | 22 |
| 安全性 | 低 | 高 |
| 防火墙穿越 | 可能需要被动模式 | 简单 |
| 推荐场景 | 公开匿名资源 | 账号私有资源 |

**强烈建议优先使用 SFTP**，避免密码和视频内容在公网上裸奔。

添加服务器的操作步骤：打开 nPlayer → 进入「网络」标签 → 点击 + → 选择「FTP」或「SFTP」→ 填写服务器信息（自定义标题、服务器公网 IP 或域名、端口号、账号密码）→ 保存后自动测试连接。

如果 FTP 连接成功但**无法列出目录**，大概率是服务器需要被动模式。在 nPlayer 的 FTP 设置中勾选「被动模式」即可解决。连接失败的常见原因还有：防火墙未开放对应端口、服务器禁用了密码登录（SFTP 可能需要密钥认证，nPlayer 暂不支持）、或者网络超时。

> [!WARNING]
> 安全建议：不要用匿名 FTP 存放私有视频；SFTP 优先于 FTP 确保传输加密；定期更换服务器密码；服务器端尽量限制允许连接的 IP 地址段。

### NAS 家庭影院场景

如果你家里有 Synology 群晖、威联通等 NAS，存放着大量 MKV 高清电影和剧集，nPlayer 的 SMB 和 UPnP/DLNA 支持可以让你在手机或 iPad 上直接流式播放这些资源，不需要额外转换格式或下载拷贝。典型用法：在客厅、卧室用 iPad 直接访问 NAS 上的 4K 高清片源，或者投屏到智能电视/Chromecast 大屏观看。
