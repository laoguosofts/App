## ✨ Ryujinx 是什么

Ryujinx 是一款开源的 Nintendo Switch 模拟器，在 Yuzu 停摆后由社区接手续作，继续保持跨平台发布节奏。它能够在 Windows、macOS 和 Linux 上运行 Switch 游戏，支持图形后端切换、着色器缓存、PPTC 代码翻译加速、Mod 与金手指加载等完整功能链。

相比同类型模拟器，Ryujinx 的优势在于跨平台一致性较好，同一套密钥和游戏文件可以在不同系统之间直接迁移；图形后端提供 Vulkan 与 OpenGL 切换，兼容老机器也能发挥新硬件性能；Canary 金丝雀版跟随代码提交快速滚动，遇到游戏兼容问题时通常能在几天内拿到修复。

适合谁用：手上有 Switch 游戏资源、想在桌面端补齐体验的玩家；需要跨系统互通存档的多设备用户；喜欢折腾 Mod 和画质增强的模拟器爱好者。

## 🔧 版本选择与安装

Ryujinx 提供两条发布渠道，装之前先分清自己需要哪一条。

**两条渠道对比：**

| 渠道 | 节奏 | 适合场景 |
| --- | --- | --- |
| Stable（稳定版） | 周期性发布经过验证的改动，版本号如 1.3.3 | 日常游玩，出问题概率最低 |
| Canary（金丝雀版） | 跟随代码提交快速滚动，版本号位数很长 | 想第一时间拿到修复；能接受偶尔的新 bug |

两个渠道的数据目录完全通用，互换只影响主程序，密钥、游戏、存档都不动。日常建议用 Stable，某游戏在新版才修好的问题可以临时切 Canary 验证。

**按平台挑包：**

- **Windows**：选 `win_x64.zip`，解压即用，不需要安装器；ARM 架构的 Windows 设备才需要 ARM64 包
- **macOS**：选 `macos_universal.app.tar.gz`，一个包同时覆盖 Intel 与 Apple 芯片
- **Linux**：有 AppImage（免安装）和 tar.gz 两种，均分 x64 与 ARM64 架构；发行版仓库里通常没有，认准发布页

**Windows 安装步骤：**

1. **解压到合适目录**：把下载的 zip 解压到自选目录，例如 `D:\Ryujinx`。避开桌面、盘符根目录和 `Program Files`——前两者可能受权限保护，后者会导致配置写入失败
2. **首次运行**：进入解压目录，双击 `Ryujinx.exe`
3. **SmartScreen 提示**：Windows 可能弹出「已保护你的电脑」蓝框——点「更多信息」，再点「仍要运行」。社区构建没有购买代码签名证书，这条提示是常态
4. **运行时补装**：如果系统缺少 .NET 桌面运行时，首次启动会弹窗提示下载安装，照着装完再开即可

> [!WARNING]
> 杀毒软件若报「启发式/通用木马」类提示，多半是未签名模拟器主程序的常见误报。先核对发布页提供的 SHA-256 校验值（Windows 在命令行执行 `certutil -hashfile 文件名 SHA256`），确认文件完整后再决定是否添加排除项。

主窗口能打开就说明程序本体装好了——此时右下角状态栏会显示后端与系统版本信息，哪怕还没配密钥也没关系，接下来才是模拟器特有的几道关卡。

## 📖 首次启动与日常使用

Ryujinx 的完整启动链路要过六个关卡，按顺序打勾能省掉九成「为什么玩不了」的困惑。

### 六个关卡核对

1. **程序装好**：解压目录权限正常，主窗口能打开
2. **密钥就位**：把 `prod.keys` 放进程序目录的 `system` 子目录，重启后无密钥警告
3. **固件装好**：主窗口右下角应显示 System Version 版本号
4. **版本配套**：密钥与固件要来自同一时期的导出，混装会导致游戏无法运行或触发异常
5. **游戏进库**：在主窗口添加游戏所在目录，列表里能看到带图标与名字的游戏
6. **双击能玩**：双击游戏标题弹出游戏窗口，首次启动允许它编译一会儿着色器

> [!TIP]
> 首次启动慢是正常的。第一次跑某个游戏，CPU 翻译指令、GPU 编译着色器都是全新计算，卡顿明显；PPTC 与着色器缓存写入磁盘后，第二次启动速度会快很多。

### 图形后端与画质

图形后端提供 Vulkan 与 OpenGL 两个选项。Vulkan 性能更好、兼容性更广，新硬件优先选；OpenGL 在部分老机器或特定游戏上可能更稳定。分辨率缩放可以调到 2x 甚至更高，让游戏画面比原版更锐利，但倍率越高对显卡压力越大。

### 手柄与操作

Ryujinx 支持 Xbox、PS、Switch Pro 等主流手柄，也支持键鼠映射。手柄连接后在设置里手动分配按键即可，不需要特殊驱动。体感功能在部分手柄上可以启用，部分需要配合第三方驱动。

### Mod 与金手指

Ryujinx 支持加载游戏 Mod 和金手指代码。Mod 放在游戏对应目录下的 `mods` 文件夹，金手指代码粘贴到模拟器内置的 Cheats 管理器。两者都需要游戏版本匹配才会生效，游戏更新后旧 Mod 可能需要同步更新。

### 崩溃与黑屏排查

遇到崩溃或黑屏不要急着乱改设置，按下面的**控制变量法**逐层排查，一次只改一件事：

1. **别的游戏正常吗？**——只有一款游戏崩，是游戏兼容或文件问题；全崩，是环境问题（密钥、驱动、系统），排查方向完全不同
2. **改过什么？**——最近装了 Mod 或金手指？先全部停用再进游戏。这是「昨天还好好的」案例的头号元凶
3. **密钥固件动过吗？**——最近更新过密钥或固件的，先核对版本是否配套
4. **显卡驱动**——崩在图形初始化或花屏后崩的，更新驱动 + 切换图形后端对照
5. **游戏文件本体**——重新校验或换一份来源，排除半截文件
6. **内存管理器降档**——Host Unsafe 崩的，降到 Host Checked 或 Software 试
7. **清缓存重试**——该游戏的着色器缓存损坏会崩在编译阶段，右键 Cache Management 清一下

黑屏有声音说明游戏其实跑着，只是画面没出来——先试切换全屏（F11），再走显卡排查线；有画面没声音则是音频后端的问题，切换 OpenAL 与 SDL2 即可。

> [!NOTE]
> 游戏内过场、加载画面停留过久不等于崩溃。首次启动的翻译与着色器编译可能让画面停顿数十秒，窗口标题还有 FPS 数字在跳就说明没死——多等一会儿再说。

排查时顺手记四样信息：报错弹窗原文、日志尾部、当时的操作、改了什么。这些信息决定你自己能不能定位，也决定求助时别人能不能帮你。
