## ✨ MusicFree 是什么

MusicFree 是一款插件化、定制化、无广告的免费音乐播放器。它的核心思路很简单——软件本体只负责播放界面、歌单管理、歌词显示这些基础功能，而"从哪儿搜歌、播什么链接"这件事，完全交给用户自行安装的音源插件决定。

市面上常见的音乐工具要么是单一平台的官方 App（生态封闭，跨平台歌曲无法统一管理），要么是声称接入全网的聚合工具（大多闭源、有广告植入、版权边界模糊）。MusicFree 走了第三条路：播放器和音源解耦，宿主稳定，音源可插拔。想接网易云装网易云插件，想接 QQ 音乐装 QQ 插件，某个平台插件停更了换一个就行，播放器本身不受影响。

它的设计理念可以用四个关键词概括：小而美——专注做播放器，不做音源、不做账号体系、不做付费内购；自由选择——用哪个平台的音源、用什么版本的插件全部由用户自己决定；隐私友好——所有数据存本地，不收集任何个人信息；开源透明——基于 AGPL 3.0 协议，源码可审计。

> [!NOTE]
> MusicFree 不是破解工具。官方明确过滤所有 VIP、试听、付费歌曲，不做也不计划做破解功能。它定位为业余项目，开发者每天维护时间有限，处于不稳定测试版本。

适合这款播放器的用户画像很清晰：希望摆脱单一平台绑定的音乐爱好者、在意隐私不想被 App 收集行为数据的用户、有技术基础想自己写或修改插件的开发者、讨厌广告和付费弹窗的纯净派听众。

## 🔧 各平台安装指南

MusicFree 有两个独立的代码仓库——移动端和桌面版分开维护。桌面版基于 Electron 框架，支持 Windows、macOS、Linux 三大平台；移动端主要面向 Android（iOS 因系统限制分发渠道有限）。

### Windows 桌面版

Windows 用户有两种安装方式可选：

1. **.exe 安装包**：双击运行，按向导完成安装，自动创建桌面快捷方式，写入注册表。
2. **便携版**：解压即可运行，不写入注册表，适合 U 盘随身携带或多电脑使用。

> [!TIP]
> 如果从 GitHub 下载时遇到网络问题，可以尝试换成 GitCode 镜像仓库的 Release 页，速度通常更稳定。

### macOS 桌面版

macOS 提供 .dmg 安装镜像：

1. 双击 .dmg 文件打开挂载窗口。
2. 将 MusicFree 图标拖拽到「应用程序」文件夹。
3. 首次打开时如果系统提示"无法验证开发者"，右键点击应用 → 选择「打开」→ 在弹窗中点「打开」确认。
4. 同时支持 Apple Silicon（M 系列芯片）和 Intel 芯片，通常有两个独立的安装包可选，下载时注意对号入座。

### Linux 桌面版

Linux 提供多种格式的安装包以适配不同发行版：

| 格式 | 适用发行版 | 安装方式 |
| --- | --- | --- |
| .deb | Debian / Ubuntu / Linux Mint | `dpkg -i` 或 `apt install` |
| .rpm | Fedora / CentOS / openSUSE | `rpm -ivh` 或 `dnf install` |
| .AppImage | 通用格式 | 赋予执行权限后双击运行，无需安装 |

### 移动端

移动端主要面向 Android，安装包为 .apk 文件。首次安装时如果系统提示"未知来源"，需要在系统设置中允许该来源的应用安装。移动端的插件安装界面和流程与桌面版基本一致，但屏幕空间较小，管理多个插件时不如桌面版方便。

> [!WARNING]
> 安装后建议核对文件大小和版本号，避免下载到不完整或过时的安装包。可以在官方下载页对照各平台的文件校验值进行验证。

## 📖 使用入门

### 核心机制：插件驱动的音源系统

MusicFree 区别于其他播放器的根本在于音源插件机制。首次打开软件后，界面是空的——没有任何歌曲、没有任何歌单，只有一个播放器壳。这时候你需要先安装至少一个音源插件才能开始使用。

插件安装的入口在侧边栏的「插件设置」里，点击加号可以选择从网络安装还是从本地文件导入。网络安装会列出社区维护的示例插件仓库，里面包含了网易云、QQ 音乐、酷狗等主流平台的音源适配。本地安装则适合自己开发或第三方分享的插件。

插件装完之后，搜索框立刻就能搜到歌了，播放列表也能正常加载。播放器本身不关心歌从哪个平台来，只管播放和管理。

### 从外部歌单导入歌曲

MusicFree 支持从外部平台的歌单链接批量导入歌曲。操作方式很直观：复制原生音乐 App 的歌单分享链接，粘贴到导入功能里，稍等片刻就能看到曲目列表被拉取进来。

> [!NOTE]
> 导入时发现曲目数量比源歌单少，这是正常现象。最常见的原因是源歌单里有 VIP 或付费歌曲，被示例插件自动过滤掉了。插件设计行为就是不做破解，这不是 Bug。

丢失歌曲的原因大致分为五类：VIP/付费歌曲被过滤（最常见）、音源接口暂时不可用（网络波动或音源改版）、歌曲已从源平台下线、歌单中混入视频播客等非音乐内容、插件不支持该歌单格式。如果丢失的恰好是那些需要 VIP 或已经变灰的歌曲，那就是正常过滤；如果丢失的全是免费公开歌曲，可能需要检查插件版本是否需要更新。

### 歌词关联：让多首歌共用同一套歌词

这是 MusicFree 一个很有特色的功能。正常情况下每首歌匹配自己的歌词，但某些场景下你可能希望国语翻唱显示原版日语歌词、现场版使用录音室版的歌词、同曲不同填词的版本共用一份歌词文本。MusicFree 的歌词关联功能就是为这种场景设计的。

操作路径：打开歌曲详情页或播放页 → 找到歌词管理/关联设置的入口 → 选择「关联歌词」→ 搜索目标歌曲 → 确认关联。关联后，这首歌播放时会显示目标歌曲的歌词。

更有意思的是支持链式关联——可以让 A 关联 B、B 关联 C，这样 A、B、C 三首歌都会显示 C 的歌词。宿主会自动解析这个链路找到最终的源头歌词。链式关联的好处是如果之后修改了 C 的歌词文本（比如手动修正了 LRC 时间轴），所有关联链路都会自动生效。关联后显示的歌词有两种来源：插件返回的原生歌词（LRC 格式），或者用户在 MusicFree 中手动编辑过的本地歌词文本。

### 桌面版的独特优势

基于 Electron 的桌面版相比移动端有一些天然的便利：更大的操作面板让侧边栏、播放列表、歌词可以更宽敞地展示；系统级播放控制，在 Windows / macOS 的系统媒体控制中心可以直接操作播放暂停和切歌；全局快捷键支持播放控制、搜索、窗口最小化等常用操作；文件拖拽功能让本地音频文件可以直接拖入窗口播放。

### 插件更新与音源维护

音源平台的接口经常变化，插件需要跟进更新才能保持可用。如果发现某个平台突然搜不到歌了，大概率是插件版本落后了。进入插件设置，找到对应的插件检查是否有更新，更新后一般就能恢复。

> [!NOTE]
> 插件生态依赖社区维护，如果某个插件长期停更，可以尝试换用其他社区成员分享的同类插件。MusicFree 本身不绑定任何特定插件，换插件不会影响你的歌单和本地数据。
