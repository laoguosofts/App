## ✨ Meria 是什么

Meria 是一款运行在安卓手机上的 QQ 群机器人框架，主打轻量便携——不需要 PC、不需要服务器，一台闲置安卓机就能把它挂着跑。它的核心能力是「词库触发」：群成员发特定内容，机器人自动回应。从进群欢迎、违规提醒到点歌放歌、AI 对话，Meria 通过词库扩展包的方式覆盖各类群管和闲聊场景。

适合谁用？有自己的 QQ 群、想加自动化功能又不想折腾 PC 端框架的群主。尤其是管理多个小群的场景，手机端挂着 Meria，就能帮你盯着进群验证、违规发言，关键时刻替你省不少事。

## 🔧 安装与基础设置

Meria 是安卓 APK，安装流程跟普通应用没什么两样，但有几个点值得提前注意。

### 安装步骤

1. **下载 APK**：从下载页拿到安装包，注意文件大小——不同版本体积有差异，建议和官方标注核对一下，避免下到损坏或篡改的包。
2. **允许未知来源**：安卓 8.0 以后系统会单独针对每个应用开启「允许安装未知来源应用」权限。在手机设置里找到浏览器或文件管理器（你用哪个工具装的就开哪个），把这个开关打开。
3. **安装**：点 APK 一路下一步就行。装完可以在应用抽屉里找到 Meria 的图标。
4. **登录 QQ 号**：打开 Meria，会弹出 QQ 登录界面。

> [!WARNING]
> **这里必须停下来想一想**——登录哪个号？是你的主号吗？如果是，**关掉 App，重新考虑一遍**。

### 主号隔离是铁律

**主号绝对不能登进任何第三方 QQ 机器人框架**，包括 Meria 在内。这没有例外。原因很简单：

- 风控引擎是账号级的——框架被识别，登录的那个号（不管主号小号）会被标记，后果从临时验证到永久封号都有可能
- 主号里有多年积累的好友、群聊、游戏数据、支付功能，跟机器人框架这种小工具混在一起，出了事损失的是资产
- 人总会犯错误，小号脑抽开了一堆功能影响的也是不重要的号

> [!TIP]
> 最稳妥的做法：拿一台**闲置安卓机**专门跑 Meria，主号只在主力手机的官方 QQ 里登。两台设备不交叉、网络环境尽量区分，这叫物理隔离。如果必须共用一台设备，至少给 Meria 加系统级应用锁，防止误操作。

## 📖 使用入门

装好、登好小号，接下来就是让 Meria 帮你干活的阶段。下面从几个最常见的实际场景出发，把核心知识点串起来。

### 先搞懂「词库」这个概念

Meria 的能力边界完全由词库决定。一个词库 = 一组触发规则 + 一组回复动作。比如「音乐类词库」里配了「点歌」「切歌」「暂停」这些触发词，对应点哪首歌、播不播、音量多大这些动作。你装哪些词库、每个词库怎么配，直接决定了机器人在群里干什么。

### 风控那点事——知道风险才能绕开风险

用非官方框架登录 QQ，本身就是平台明确不鼓励的行为。风控引擎关注的几个常见触发点：

| 触发点 | 说明 |
|---|---|
| 高频自动回复 | 短时间内在群里大量发相似消息 |
| 异常登录环境 | 设备特征异常、IP 频繁变化 |
| 多账号集中登录 | 多个号从同一设备/IP 同时登框架 |
| 被群成员举报 | 机器人刷屏、发广告、行为异常 |
| 加群退群太频繁 | 短时间内大量进出群 |

风控信号从轻到重分三级：

1. **需要验证**——登录要滑块、每登要短信、几小时就掉线重登。这是最温和的级别，手动过完验证、几天内别频繁操作，通常就过去了。
2. **临时限制**——登得上但发言被屏蔽/撤回，群管权限被撤。处理方式是**立刻停手**，让这个号安静 3~7 天，期间别用它做任何事，养号看看能不能恢复。
3. **永久封号**——登不上任何客户端，申诉也没用。换小号重新来过就行，幸好是小号损失可控。

> [!NOTE]
> 降低风控概率的几个小动作：同一群 10 秒内让机器人最多响一次；小号偶尔用官方 QQ 正常发几条消息（养号）；登录 IP 和设备尽量稳定；别让机器人刷屏，进别群前先打招呼。

### 大群（500+ 成员）的特殊压力

小群里 Meria 跑得很轻松，但大群对手机端框架的压力完全不一样，体现在三方面：

- **消息洪流**：高峰期每小时几百条消息，每条都要过一遍触发规则。AI 类词库每条都调 API，网络+延迟+费用三重消耗。
- **并发触发**：几秒内 N 个人同时发同一个触发词，框架要并发处理 N 次。词库的冷却时间配置在这里反而能救命。
- **风控关注**：大群本身就是风控敏感点，小号在大群里高频触发自动回复更容易被标记。

应对策略是**严格控制功能开启**：

| 功能 | 大群里要不要开 | 原因 |
|---|---|---|
| 进群欢迎 | 要，但用低频率 | 新人进群还是要欢迎 |
| 违规提醒 | 要 | 人多更需要秩序 |
| AI 自动对话 | 强烈建议关 | 大群消息量大，AI 回复不及时还费钱 |
| 点歌 | 可以开，但设频率限制 | 避免刷屏 |
| 小游戏/抽签 | 关或仅 @ 触发 | 闲聊功能在大群里制造噪音 |

如果你的群真的大到 Meria 顶不住，**PC 端框架在大群场景的稳定性和资源上限更好**。Meria 主打轻量便携，大群不是它的主场——这不是 bug，是定位选择。

### 音乐词库——闲聊群拉热场的利器

音乐类词库是 QQ 机器人圈子里最老牌也最受欢迎的玩法之一。核心逻辑很简单：群成员发「点歌 歌名」，机器人就在群里放音乐片段或音频消息，还能切歌、暂停、调音量。

典型触发词对照：

| 功能 | 触发词示例 |
|---|---|
| 点歌 | 点歌 晴天 / 点歌周杰伦的晴天 |
| 切歌 | 切歌 / 下一首 |
| 暂停 | 暂停 / 停一下 |
| 继续 | 继续 / 接着放 |
| 音量 | 音量调小 / 音量调大 |

不同音乐词库的音源不一样——有的走网易云、有的走 QQ 音乐、有的读本地文件。选词库时留意音源能不能覆盖你群里成员听歌的习惯，不然点歌时搜不到资源就是白装。

> [!TIP]
> 音乐词库在三种场景特别好用：闲聊群冷场时来一首歌立刻活络；粉丝群点偶像的歌一起听增加归属感；学习/工作群开背景音模式（但这类群建议关掉，别影响专注）。默认音量记得调一个基准值，太大声会打扰只想看消息的人。

### 如果主号误登了框架

万一脑抽把主号登进去了，按这个顺序操作：

1. 从框架里立刻登出主号
2. 打开官方 QQ 的「登录设备管理」，踢掉框架那台设备
3. 修改主号密码
4. 观察 1~2 天看有没有被限制
5. 以后严格执行主号隔离
