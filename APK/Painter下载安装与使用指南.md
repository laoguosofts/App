## ✨ Infinite Painter：移动端专业数字绘画工具

Infinite Painter 是一款面向移动设备的专业级数字绘画应用，主打"把绘画工作室装进平板"的理念。它的笔刷引擎模拟了铅笔、水彩、油画、马克笔等几十种真实绘画工具的笔触质感，同时支持图层系统、变换变形、非破坏性调整等桌面级绘图软件才有的功能。

对于插画师、漫画作者、概念设计师以及业余爱好者来说，Infinite Painter 的核心价值在于：**不依赖高端 PC 也能完成从线稿到上色的完整创作流程**。你可以在通勤路上用手机画速写，回家后在平板上接着精修，整个项目文件始终是同一个格式。免费版提供了位图层、纸层、笔刷系统、基础变换等核心功能，PRO 解锁后则开放图层组、蒙版、调整层、滤镜层、文字层、漫画面板等进阶特性。

> [!NOTE]
> 免费版默认提供 3 个位图层，足够完成大多数日常绘画需求。如果作品需要更复杂的分层结构，可以考虑升级 PRO。

Infinite Painter 支持的平台包括 Android 和 iOS，安卓版最低要求 Android 9（Pie），安装包体积约 135MB。它对主动式电容手写笔的压感和倾斜感应做了深度优化——三星 S Pen、Apple Pencil、华为 M-Pen 等主流手写笔都能被完整识别，笔刷会根据落笔力度自动缩放粗细、根据笔杆倾斜方向自动切换笔触形态。

## 🔧 安装步骤与环境准备

### 设备选择建议

Infinite Painter 对硬件有一定要求，不同设备的体验差异比较明显：

| 设备类型 | 体验评级 | 说明 |
| --- | --- | --- |
| 安卓平板（≥10 寸）+ 主动式手写笔 | ⭐⭐⭐⭐⭐ | 发挥笔刷引擎的最佳形态 |
| 安卓平板 + 被动式手写笔 | ⭐⭐⭐⭐ | 压感和倾斜不工作，其他正常 |
| 大尺寸手机（≥6.5 寸）+ S Pen 兼容 | ⭐⭐⭐ | 屏幕小但压感正常 |
| Chromebook | ⭐⭐⭐⭐ | 可同时接鼠标和手写笔 |

3GB 以上内存的安卓设备跑起来都没压力——一个 20 层、6000×4000 画布的大型项目，内存占用约 1GB。

### Android 安装流程

1. **检查系统版本**：确认设备运行 Android 9（Pie）或更高版本
2. **预留存储空间**：安装包约 135MB，建议预留至少 300MB 空闲空间（安装包 + 解压 + 运行缓存）
3. **允许未知来源安装**：如果不从应用商店安装，需要在系统设置 → 安全 → 安装未知应用中给浏览器或文件管理器授权
4. **点击安装包 → 确认权限 → 等待完成**
5. **首次启动**：应用会请求存储、手绘笔、麦克风等权限，按需授权即可

> [!WARNING]
> 某些设备的系统管家或杀毒软件可能会误报 APK 文件。只要下载来源可靠，可以安全放行。如果反复弹出拦截提示，建议改用应用商店版本。

### iOS 安装流程

iOS 用户直接从 App Store 搜索 "Infinite Painter" 下载即可，无需处理未知来源设置。Apple Pencil（第一/第二代）原生支持压感和倾斜感应，打开即用。

### 安装后检查清单

安装完成后建议做两个快速检查：

- **压感测试**：选软铅或炭笔刷，轻压画一条细线、重压画一条粗线——线条粗细应该明显不同。如果没有区别，检查手写笔兼容性或笔刷的压力曲线设置
- **画布创建**：新建一个任意尺寸的画布，确认可以正常绘画、保存、退出重开后文件仍在

## 📖 从线稿到上色：核心功能实操

### 图层系统：分层绘制的基石

图层是 Infinite Painter 的核心组织结构——每一层是独立的 RGBA 图像，像一叠透明玻璃纸堆叠在一起，上面的层盖住下面的层，透明区域能透出下层内容。

#### 图层面板里的六种层

| 类型 | 图标 | 作用 |
| --- | --- | --- |
| 位图层 | 普通缩略图 | 所有笔刷画出来的像素都在这里，最常用 |
| 纸层 | 底部特殊层 | 不可删除，定义底色和纹理 |
| 调整层 | 带齿轮 | 非破坏性地调节所有下层颜色（PRO） |
| 滤镜层 | 带滤镜图标 | 非破坏性地给下层加滤镜（PRO） |
| 文字层 | 带 T | 可编辑文字（PRO） |
| 漫画面板层 | 带格子 | 漫画面板边框分割线（PRO） |

免费版常用的就是**位图层 + 纸层**。养成给图层命名的好习惯——线稿 / 底色 / 上色 / 阴影 / 高光，回头找起来效率翻倍。

#### 图层操作速查

- **新建图层**：图层面板里点 + 号，会在当前活动图层的正上方创建空白层
- **选择活动图层**：点某一层 → 它变成蓝色高亮，所有笔刷操作只在这一层生效
- **隐藏/显示**：点图层缩略图左侧的眼睛图标
- **上下移动**：长按图层缩略图 → 拖到目标位置
- **复制图层**：长按 → 选 Duplicate，常用于给效果做备份或快速做对称
- **图层锁定**：长按 → 选 Lock，可单独锁定位置或全部锁定，防止误操作

#### 混合模式让画面更丰富

每一层可以独立设置不透明度和混合模式：

- **不透明度**：0% 完全透明，100% 完全不透明，拖动滑块实时预览
- **常用混合模式**：
  - Normal（正常）：完全覆盖
  - Multiply（正片叠底）：让重叠区域变暗 → 画阴影的好帮手
  - Screen（滤色）：让重叠区域变亮 → 画发光效果
  - Overlay / Soft Light（叠加 / 柔光）：增强对比或柔和过渡

### Clip 裁剪：分块上色的黄金搭档

Clip 是 Infinite Painter 里高频使用但容易被忽略的功能。简单来说，Clip 让上一层的内容**只留在下一层的形状范围内可见**——超出范围的部分自动隐藏，但像素本身并没有被删除，取消 Clip 后全部恢复。

> [!TIP]
> 做分块上色最常用的组合就是 **Clip + 填充笔刷**，每一种颜色单独一层，画错了只改那一层，线稿永远不会被污染。

一个典型的上色流程：

1. **线稿层**（单独一层，放在最上面）
2. **新建头发底色层** → 开 Clip → 用填充笔刷在线稿层上填头发区域 → 颜色自动被 Clip 限制在头发范围内
3. **新建头发上色层** → 开 Clip 到底色层 → 用普通笔刷渲染颜色变化 → 渲染也自动被限制在头发区域
4. 重复以上步骤给皮肤、衣服、眼睛等部位分别建层上色

Clip 在导出 PSD 时会被转换成 Photoshop 的 **Clipping Mask（剪贴蒙版）**，跨软件无缝衔接。

### 图层组与蒙版（PRO 功能）

当图层多到一定数量时，用图层组把相关的层打捆管理：

- **创建组**：在图层面板里长按第一层，再点其他层叠加选择 → 选 Group
- **组的操作**：整个组可以一起移动、缩放、旋转、改变不透明度和混合模式
- **典型场景**：人物插画里把"头发线稿 + 头发底色 + 头发上色 + 头发高光"四层打成一组叫 "Hair"；机械设定里把"主体 + 螺丝钉 + 阴影 + 标签"打成一组叫 "Main Body"

蒙版则是"遮罩"——黑色代表隐藏、白色代表显示、灰色代表半透明：

- **添加蒙版**：选一个位图层 → 长按 → 选 Add Mask
- **蒙版的关键规则**：蒙版独立于图层内容，你可以反复调整蒙版，图层内容始终在那里。用蒙版擦出来的是**透明**，不是"删除"。蒙版在 PSD 导出时原样保留

蒙版的实用场景：用软边橡皮擦除蒙版边缘 → 图层边缘自然渐隐；在蒙版上画白色锁定不想被擦除的区域 → 用大笔橡皮擦其他区域不会擦到这里；在蒙版上用渐变 → 图层只有渐变对应的部分可见。

### 多图层同时变换：保证对齐的效率工具

想象你画了一个角色，线稿在层 1、底色在层 2、上色在层 3——这三层永远是对齐的。如果发现整个角色画大了 20%，需要整体缩小：

- **不用多图层变换**：层 1 缩一遍，层 2 缩一遍，层 3 缩一遍 → 三次操作，每层位置要重新对齐
- **用多图层变换**：一次操作 → 三层同时缩小、同时移动、同时旋转 → 位置永远保持对齐

开启方法：

1. 进入任意变换模式（Basic / Anchor / Distort / Warp）
2. 图层面板里先点第一个要变换的层（让变换作用于它）
3. 继续点其他层的缩略图 → 每层被选中后缩略图周围出现**红色边框**
4. 被选中的多个层合并进同一个变换框，移动、缩放、旋转同时作用于所有层
5. 想取消某一层的选中？再点一下那个层的缩略图（红色边框消失）

可以叠加选择的范围很灵活：任意数量的层、图层组、层加选区都能一起变换。但调整层和滤镜层不能参与像素变换，文字层可以单独变换但不能和位图层混合。

### 手写笔：压感与倾斜的完整利用

Infinite Painter 对主动式电容手写笔做了深度适配：

| 手写笔类型 | 压感 | 倾斜 | 说明 |
| --- | --- | --- | --- |
| S Pen（三星官方） | ✅ | ✅ | 全系列机型完美支持 |
| Apple Pencil（iOS） | ✅ | ✅ | 第一/第二代全功能支持 |
| M-Pen（华为 MatePad） | ⚠️ | ⚠️ | 部分型号支持 |
| 被动式电容笔 | ❌ | ❌ | 仅导电橡胶头，无压力信号 |

确认压感是否生效的简单方法：选软铅、炭笔或水彩这类对压力敏感的笔刷，轻压画一条线、重压画一条线——如果两条线一模一样，可能是手写笔本身不支持压感，或者需要在画笔编辑器的 Dynamic → Pressure → Size 里调整压力曲线。

支持倾斜感应的手写笔还有额外福利：笔刷向一侧倾斜时，笔触变成宽面，像真的马克笔或侧锋铅笔；某些纹理笔刷在倾斜时纹理方向跟着笔触方向转。
