## ✨ Screener 是什么

Screener 是一款运行在 Android 设备上的截图后期处理工具——它不负责截屏本身，只接管截好的画面，把它们套进仿真的手机、平板或智能手表外壳，配合屏幕眩光、机身投影和背景系统，在几分钟之内就能产出一张接近商业广告级别的设备渲染图。

在国内应用市场和工具站里，这款应用普遍以「带壳截图」之名被收录——「壳」指的就是那些手工制作的设备边框素材。原名 Screener 取自屏幕一词，副标题 Better Screenshots 直译过来就是「更好的截图」，开发者的定位相当清晰：给普通截图加上「被真机显示」的观感。

Screener 的核心能力可以浓缩为三个关键词：**设备边框**（手机、平板、智能手表的外壳素材，截图嵌入后就像真机在显示）、**光影特效**（屏幕眩光模拟环境光在玻璃上的反光，投影让机身在背景上落出影子）、**背景系统**（纯色、图片、模糊三类背景可选，成品图的观感一半靠它）。界面结构也很克制，主界面的功能入口集中在一个侧边抽屉里，分为收藏夹、三种边框样式（Flat / 3D / Minimal）以及设置与关于。

## 🔧 安装步骤

Screener 是 Android 专属应用，不提供 PC 或 iOS 版本。安装流程与普通 APK 一致，但有几个注意点需要提前了解。

### 下载渠道与版本确认

目前能获取到 Screener 的渠道大致分为三类：

| 渠道 | 版本情况 | 注意事项 |
| --- | --- | --- |
| Google Play | 官方最新版，持续更新 | 需要 Google 服务环境 |
| 官方下载站 | 直接分发 APK，版本与商店同步 | 需确认域名可靠性 |
| 国内软件站 | 多为第三方搬运或汉化版 | 版本可能停留在 2.2 时代 |

> [!WARNING]
> 若选择第三方汉化版或搬运版，务必核对文件大小与 MD5，避免下载到被二次打包的修改包。官方 APK 的体积通常在 10MB 以内。

### 安装流程（以 Android 原生安装为例）

1. 在设备的文件管理器中找到下载好的 APK 文件；
2. 首次安装外部来源 APK 时，系统会弹窗请求**未知来源安装权限**——按提示跳转到设置页，为当前文件管理器或浏览器授予「允许安装未知应用」的权限；
3. 返回文件管理器，重新点击 APK 即可进入安装流程；
4. 安装完成后点击「打开」，首次启动会请求相册/存储权限（用于读取截图和保存成品图），全部允许即可。

> [!TIP]
> 部分国产 ROM 会在安装界面额外弹出杀毒误报提示，一般可以忽略——Screener 是 Google Play 官方上架的应用，本身不含任何恶意行为。

### 装完怎么核对

打开应用后，侧边抽屉里应该能看到 Flat / 3D / Minimal 三种边框样式入口，点击任意一种进入边框库，如果能看到 HTC One M8、Huawei P8、Samsung Galaxy S8 等机型的缩略图网格，说明安装正常。

## 📖 使用入门

Screener 的加工流程可以理解为一条流水线：选样式 → 挑边框 → 放截图 → 调光影 → 铺背景 → 保存分享。每一步都是实时渲染，不需要点「预览」就能直接看到效果。

### 边框库：100 多种手工边框怎么挑

官方对边框库的介绍是「100 多种手工制作的设备边框，还在持续增加」。边框按三种样式分类：Flat（平坦）、3D（立体）、Minimal（简约），其中 Flat 分类的机型覆盖最广、更新最勤。

边框库同时支持手机和智能手表，切换方式是顶部的 SMARTPHONES / WATCHES 两个页签。手机部分的早期清单涵盖了 Google Nexus 全系列、Samsung Galaxy S5 / Note 3、HTC One M7~M9、Sony Z 系列、LG G2~G6 / V30、华为 P7~P10 与荣耀、小米 2S~红米 Note、魅族 MX 系列、一加 OnePlus One~5 以及 iPhone 6 等。

> [!NOTE]
> 这些边框素材以 CC BY 4.0 协议授权——成品图可以自由商用，边框素材本体不能直接改动或单独分发。

**没有你的机型怎么办？三步走：**
1. 先确认样式分类选对——近两年的新机型大多收录在 Flat 分类里；
2. 下拉边框库强制联网刷新，有时新版本边框是后续推送的；
3. 实在没有就找分辨率相同的不同机型边框代替，成品图效果几乎看不出差别。

### 加工流水线：从截图到渲染图的完整步骤

#### 第一步：放入截图

Screener 不负责截屏。先在手机上用系统截图功能（电源键 + 音量下，或三指下滑等）截好画面，再打开 Screener，点击任意边框进入编辑界面，从相册中选择刚才截好的图片。截图会自动缩放适配边框的屏幕区域。

#### 第二步：调光影效果

底部工具栏提供两个关键特效：

- **屏幕眩光（太阳图标）**：模拟真实拍摄中玻璃屏幕反射环境光的效果。点按即可开关，再点方形图标旁的切换可以调节投影。眩光几乎是「广告感」的一半来源，但需要读者看清屏幕文字时（比如教程截图）建议关掉，高光会盖住一部分界面内容。
- **机身投影（方形图标）**：让设备在背景上落出一层柔和的影子，增强立体感。投影可以调节方向和大小，与眩光叠加不冲突。

> [!TIP]
> 关于眩光的取舍：社交晒图、封面图、3D 样式——强烈建议开；教程类截图、功能展示图——建议关，保证文字清晰可读。

#### 第三步：铺背景

背景分为纯色、图片、模糊三种。纯色背景可以选系统预设的几十种色板，也可以自定义；图片背景从相册中选择；模糊背景则是把某张图片做高斯模糊处理后作为底色，适合需要突出设备本身的场景。

#### 第四步：实时渲染与保存

Screener 的整个编辑过程都是实时渲染——每一次调整，画布直接刷新，不用点「预览」按钮。加工完成后，点击右下角的保存图标，成品图会写入相册的 Screener 目录下，也可以选择直接分享到社交应用。

### 中文界面问题

一个绕不开的话题：**Screener 官方版本没有中文**，Settings 页里也没有语言切换项，界面跟随系统语言的逻辑同样不覆盖中文。

好在真正要用到的界面词汇量极小，日常操作只需十来个词：

| 英文 | 中文对应 |
| --- | --- |
| Flat / 3D / Minimal | 平坦 / 3D / 简约 |
| Smartphones / Watches | 手机 / 手表 |
| Favorites | 收藏 |
| Settings / About / Rate | 设置 / 关于 / 评分 |
| Save / Share | 保存 / 分享 |
| Download / Download all | 下载 / 全部下载 |

如果完全用不惯英文，也可以考虑第三方汉化版——代价是版本普遍停留在 2.2 时代，边框库和功能都落后于官方最新版。两条路的取舍很简单：想要最新边框和稳定性，花十分钟记住上面的对照表就行；想要全中文界面，就接受版本滞后的现实。
