## ✨ XP3Player 是什么——iOS 平台上最干净的 GalGame 模拟器

XP3Player 是一款专门为 iOS 设备设计的 KiriKiri 2 引擎模拟器。如果你是 GalGame 玩家，想要在 iPhone 或 iPad 上运行 PC 端的 GalGame 资源，XP3Player 就是目前市面上最成熟、体验最好的选择之一。

KiriKiri（简称 KrKr）是日本 GalGame 界使用最广泛的脚本引擎，像《Fate/stay night》《月姬》《CLANNAD》这些经典作品都用它开发。XP3Player 的核心工作就是把原本跑在 Windows 上的 KiriKiri 脚本解释器移植到 iOS 上，让你手里的 GalGame 资源直接在手机上启动。

它的定位非常明确——**不做全能型模拟器，只专注 KiriKiri 2**。但也正因为专注，它在这个细分领域的完成度极高：画面渲染、音频播放、存档读写、游戏内菜单全部跑通，没有多余的功能拖后腿。

最难得的是它的隐私姿态：在 App Store 里明确声明「不收集任何数据」，没有广告弹窗、没有追踪 SDK、没有崩溃上报、没有远程 A/B 测试。买断制 ¥58 一次付费，后续免费更新。对于一个 GalGame 玩家来说，这种「纯本地、无打扰」的体验太重要了——你不想让任何第三方知道你在玩什么。

## 🔧 安装指南——iOS 侧载与版本核对

XP3Player 是 iOS 专属应用，安装路径和普通 App Store 应用有区别。

### App Store 正版安装（推荐）

如果你拥有海外区 Apple ID，直接在 App Store 搜索「XP3Player」付费购买即可。这是最省心的方式，系统自动处理签名和更新，应用启动即运行，无需额外操作。

### 侧载方式（国内用户常见路径）

国内 Apple ID 无法直接购买海外区付费应用，常见的替代方案是通过 SideStore 或 LiveContainer 等侧载工具安装。侧载本质上是用个人开发者证书为 IPA 签名再安装到设备，注意以下几点：

> [!WARNING]
> 侧载应用的证书有效期通常只有 7 天，过期后需要重新签名。如果你的设备是 iOS 16.6.1 及以上，遇到签名到期可能需要重新走一遍侧载流程——别慌，这是 iOS 的限制，不是 XP3Player 本身的问题。

### 版本核对与下载注意点

拿到应用后，建议首次启动时确认以下信息：

1. **版本号**：进入应用设置 → 关于，确认当前版本是否在 1.3.2 以上。1.3.2（2017 年 3 月）修复了 OpenGL 颜色渲染失真和纹理泄漏两个关键 bug，低于此版本可能遇到画面偏色或长时间运行后崩溃
2. **文件大小**：正版安装包约 20MB 左右，侧载来源如果提供的 IPA 体积异常（比如只有几 MB 或超过 50MB），建议换一个源确认
3. **签名状态**：侧载安装后首次启动前，记得在 iOS 「设置 → 通用 → VPN 与设备管理」中信任对应的开发者证书，否则应用会被系统拦截

## 📖 使用入门——从资源导入到流畅游玩

XP3Player 的使用流程可以概括为三步：**导入游戏资源 → 解压识别 → 启动运行**。下面按操作顺序拆解。

### 第一步：识别你的游戏资源

拿到一个 GalGame 压缩包后，先解压看看里面的结构。判断标准非常简单——**有没有 `data.xp3` 文件**。

KiriKiri 引擎的游戏文件夹结构通常长这样：

```
游戏文件夹/
├── data.xp3        ← 主资源包，XP3Player 靠它启动游戏
├── patch.xp3       ← 汉化补丁或官方补丁，可选
├── startup.tjs     ← 游戏启动脚本
└── game.exe        ← Windows 版启动文件，iOS 上忽略
```

`data.xp3` 是核心标志——有它就说明这是 KiriKiri 引擎的作品，XP3Player 基本可以跑。没有的话大概率是其他引擎（RPG Maker、Unity、Ren'Py 等），得找对应引擎的模拟器。

> [!TIP]
> 如果你不确定引擎类型，可以查游戏的百科页面或在搜索引擎里搜「游戏名 + 引擎」。大多数 GalGame 的引擎信息都是公开的。

### 第二步：导入与解压

XP3Player 支持通过多种方式把游戏传到设备上：WiFi HTTP 服务器、Files App 文件共享、Finder/iTunes 同步等。其中 WiFi HTTP 服务器最方便——在应用内打开后，用同网络的电脑浏览器访问一个局域网地址，直接拖拽文件夹上传即可。

资源传到位后，如果拿到的是 ZIP 或 RAR 压缩包，XP3Player 内置了解压功能：在文件管理界面**长按压缩包文件**，从弹出菜单选「解压到当前目录」。解压后的文件夹和压缩包同级出现。

> [!NOTE]
> 解压有三个常见踩坑点：
>
> - **RAR5 不兼容**：XP3Player 只支持 RAR4 格式，WinRAR 5.x 之后的新版 RAR 可能解不开。提前在电脑上解压好再传
> - **加密压缩包**：带密码的 ZIP/RAR XP3Player 解不了，先在电脑端用密码解压后传
> - **分卷压缩**：`part1.rar / part2.rar` 这种分卷格式必须在电脑上用 WinRAR 合并解压

另外要区分两个概念：

- **外部压缩包（ZIP/RAR）**——这是资源分发时的打包格式，必须手动解压成文件夹
- **XP3 封包（.xp3 文件）**——这是游戏本身的资源格式，不需要外部解压，XP3Player 运行游戏时会自动解析

别把 ZIP/RAR 直接丢进文档目录就期待能玩，那中间还隔着一层。

### 第三步：启动游戏与画面设置

解压完成后，在 XP3Player 的文件管理里找到游戏文件夹，点击里面的 `data.xp3` 文件即可启动游戏。

#### 渲染模式

XP3Player 的默认渲染器是 **OpenGL ES2**，这是 iOS 原生支持的图形 API，性能好、功耗低、画质最佳。正常情况下不需要改这个设置。

1.3.0 版本（2017 年 1 月）对视频播放模块做过一次完全重写，1.3.1 和 1.3.2 又紧急修复了 OpenGL 颜色渲染错误和纹理泄漏问题——如果你遇到画面偏色或长时间运行后闪烁，先检查版本是否在 1.3.2 以上，再考虑切换到软件渲染模式临时测试。

#### 画面缩放

4:3 经典 GalGame 在 16:9 的 iPhone 屏幕上会被拉伸变形。XP3Player 提供三种缩放方案：

| 选项 | 效果 | 推荐场景 |
|---|---|---|
| 自适应拉伸 | 铺满全屏，画面变形 | 不在乎画质、想最大化显示区域 |
| 保持宽高比 | 两侧留黑边，画面不变形 | 绝大多数情况的最佳选择 |
| 原始分辨率 | 1:1 显示 | iPad 大屏或高分辨率老游戏 |

进入游戏后长按屏幕弹出菜单 → 设置 → 渲染相关选项里可以调整。

### 关于隐私——你在一个干净的环境里

XP3Player 在 App Store 上的隐私声明写得很直白：**开发者不会从此 App 中收集任何数据**。没有广告 SDK、没有追踪、没有崩溃上报、没有远程服务器、没有地理位置请求，一次性买断制内购也没有。

它的两个涉及网络的功能——WiFi HTTP 服务器和文件传输——都严格限定在本地设备之间，不经过任何远程服务器。这和市面上一大堆嵌入 AdMob/AppsFlyer/Firebase Analytics 的应用形成鲜明对比。

当然也要注意边界：GalGame 资源本身的安全和侧载 IPA 的来源需要你自己把关，XP3Player 本身是干净的，但你放进文档目录的文件它不会替你做病毒扫描。
