## ✨ HoYoLAB 是什么：米哈游玩家的社区与工具箱

HoYoLAB 是米哈游（HoYoverse）为旗下全线游戏打造的官方社区应用，覆盖原神、崩坏：星穹铁道、绝区零、崩坏3、未定事件簿等主力产品。它既是一个围绕游戏内容的资讯与讨论平台，也是一套玩家日常用得到的实用工具集合——签到日历、战绩查询、互动地图、资源计算器，都按游戏分版块独立提供。

对于多游戏玩家来说，HoYoLAB 把过去分散在各游戏独立社区里的功能收拢到一个账号体系下，一次登录就能切换不同游戏的资讯流与工具面板。社区数据（关注、帖子、装扮）跟随账号迁移，换设备不会丢。新用户上手门槛低，应用内有清晰的版块导航和工具入口。

## 🔧 安装步骤与注意事项

HoYoLAB 目前主要面向移动端（Android 与 iOS），网页版可作为替代入口。安装流程各平台略有差异，下面分平台说明。

**Android 平台：**

1. 优先从应用商店搜索安装，能自动处理版本更新与权限申请。
2. 如果走 APK 安装包，首次安装需要在系统设置里开启「允许未知来源应用安装」或针对当前文件管理器授权。
3. 安装过程中如果被安全软件拦截提示，确认来源可信后选择继续安装即可。
4. 安装完成后建议先跑一次版本核对——设置里能看到当前版本号，和应用商店的最新版本对齐，避免因版本过旧漏掉签到活动或工具更新。

**iOS 平台：**

1. 直接从 App Store 搜索下载，无需额外设置信任开发者描述文件。
2. 首次打开会请求通知、位置等权限，按需授予即可——签到提醒需要通知权限，互动地图需要位置权限才能定位当前区域。

> [!TIP]
> 多游戏玩家建议直接用手机号注册或邮箱注册，后续再关联第三方登录作为日常快捷入口，避免只用第三方账号一旦丢失找回流程变曲折。

## 📖 使用入门：从登录到签到的完整路径

### 四种登录方式怎么选

HoYoLAB 的登录入口覆盖邮箱密码、Google、Apple 以及部分地区的社交账号。它们最终都指向同一个 HoYoverse 通行证，差异在于验证方式和找回难度：

| 方式 | 优点 | 注意事项 |
| --- | --- | --- |
| 邮箱 + 密码 | 最通用，不依赖第三方服务 | 邮箱必须长期可用，收不到验证码时要去垃圾箱翻 |
| Google 登录 | 安卓设备一键进 | 国内网络环境可能受限 |
| Apple 登录 | iOS 原生体验，中转邮箱保护隐私 | 依赖 Apple ID 登录态 |
| 社交账号 | 部分地区可用 | 账号被封或丢失时找回更麻烦 |

**推荐组合**：邮箱注册打底 + 关联一个第三方登录。邮箱是最终凭证，第三方登录用来日常快速进入。

### 收不到验证邮件怎么办

注册或新设备验证卡在「等验证码」是最常见的问题，按下面的顺序排查：

1. **等 10 分钟再重发**——不要连续点击重发，短时间多次请求反而容易触发邮箱服务商过滤。
2. **翻垃圾箱与促销文件夹**——自动化邮件被误判进垃圾箱是最高频原因，找到后记得标记「非垃圾」。
3. **加白名单**——把 `noreply@email.hoyoverse.com` 及 `email.hoyoverse.com` 域名加入邮箱联系人或白名单，再重新发送验证码。
4. **确认邮箱没拼错**——自动补全可能选错后缀，注册时务必检查一遍。

> [!NOTE]
> 注册成功后立刻完成邮箱正式绑定，不只是能收码，而是把邮箱固化为账号凭证。新设备验证、找回密码都靠这个通道。

### 覆盖哪些游戏，功能怎么隔离

HoYoLAB 不是单一游戏社区，而是全产品线的集合入口。每款游戏有独立的版块、签到日历、战绩工具：

| 游戏 | 社区版块 | 签到 | 专属工具 |
| --- | --- | --- | --- |
| 原神 | ✓ | ✓ | 提瓦特互动地图、旅行者日记、战绩 |
| 崩坏：星穹铁道 | ✓ | ✓ | 战绩、养成计算器 |
| 绝区零 | ✓ | ✓ | 战绩、小组件 |
| 崩坏3 | ✓ | ✓ | 战绩 |
| 未定事件簿 | ✓ | ✓ | — |

**重要提醒**：签到、战绩、互动地图都是**按游戏独立**的。原神的树脂便签看不到星穹铁道的开拓力，每款游戏都要单独绑定 UID、单独进对应的签到页。

### 提瓦特互动地图怎么用

原神玩家最常用的工具之一。全提瓦特的宝箱、神瞳、矿物、怪物标点都在上面，支持筛选和自定义标记。

基础操作：

1. 从 app 内工具区进入，或直接用网页版。
2. 顶部选择区域（蒙德、璃月、稻妻、须弥、枫丹、纳塔等），地图自动缩放到对应范围。
3. 右侧面板勾选想看的标点类型（神瞳、宝箱、矿物、怪物），地图上就铺开对应图标。
4. 双指缩放、单指拖动，和普通地图应用一致。

实用场景：找神瞳时只勾神瞳一项，围着当前区域走一圈对照收集；找材料时勾角色天赋材料或武器突破矿，缺什么补什么。每个游戏版本更新后地图都会跟进新增区域与标点。

### 换设备与登录冲突

- 换手机后用同一账号体系登录即可，社区数据（关注、帖子、装扮）会跟随账号恢复。
- 新设备首次登录可能触发新设备验证，通过绑定邮箱收验证码确认。
- 同一账号多设备同时在线一般没问题，但频繁切换有时会触发安全验证，按提示走邮箱验证即可。
