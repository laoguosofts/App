## ✨ NewPipe 是什么

NewPipe 是一款专为 Android 设备打造的开源视频流媒体客户端，它的核心理念是「轻量、无广告、尊重隐私」。与市面上主流的视频 App 不同，NewPipe 不依赖任何官方 API，通过自行开发的 Extractor 解析 YouTube、SoundCloud、PeerTube 等多个平台的视频流，让用户在一个应用里自由浏览和下载跨平台内容。

NewPipe 的优势在于它的克制设计——不内置广告、不跟踪用户行为、不申请多余权限。安装后即可直接使用，不需要登录任何账号，所有订阅、观看历史、下载记录都保存在本地设备上。对于在意隐私、想摆脱广告轰炸的用户来说，它是 YouTube 和 SoundCloud 的理想替代客户端。

适用人群很广：想安静看视频不想被广告打断的普通用户、喜欢订阅多个频道追踪更新的重度观众、需要下载视频离线观看的通勤族，以及对 PeerTube 这类去中心化视频平台感兴趣的技术爱好者，都能在 NewPipe 里找到自己的使用场景。

## 🔧 安装步骤

### 下载 APK

NewPipe 以 APK 形式分发，不在 Google Play 商店上架。你可以从上面的下载入口获取最新版本的安装包。下载完成后，通知栏会提示文件已保存。

> [!TIP]
> 下载时注意核对版本号和文件大小——NewPipe 的 APK 通常在 2~4MB 之间，如果文件异常偏小或偏大，建议换一个来源重新下载。

### 允许未知来源安装

Android 6.0 及以上版本默认禁止安装非官方应用商店的 APK。点击下载完成的 APK 后，系统会弹出「安装被阻止」的提示，按照以下步骤授权：

1. 点击「设置」或「允许本次安装」
2. 在设置页找到「允许安装未知应用」开关
3. 找到你用来下载 APK 的应用（如浏览器或下载管理器）
4. 打开开关，返回安装界面继续

> [!WARNING]
> 授权后记得在安装完成后关闭这个开关，保持系统安全性。

### 完成安装

点击 APK 文件，确认应用权限请求（网络访问是必需的，其他权限在用到时才会按需申请），等待安装进度跑完即可。安装完成后可以在桌面或应用抽屉里找到 NewPipe 的图标。

### 常见安装问题

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 安装失败提示「解析错误」 | APK 文件损坏或不完整 | 重新下载，确保下载完成后再安装 |
| 安装被安全中心拦截 | 系统安全策略过于严格 | 在安全中心手动添加信任，或临时关闭安全扫描 |
| 安装后点击闪退 | Android 版本过低或 ROM 兼容性问题 | 确认系统版本在 Android 5.0 以上，部分精简 ROM 可能需要换一个安装版本 |

## 📖 使用入门

### 权限与隐私

NewPipe 遵循最小权限原则，安装时**不会一次性索要所有权限**，而是在使用到相关功能时弹出系统请求。它需要的核心权限包括网络访问（启动即请求，必须给）、存储读写（第一次下载视频时触发，下载功能必需）、悬浮窗显示（使用浮动播放器时按需申请）和后台启动（Android 12+ 后台播放时可能需要）。

值得一提的是，NewPipe **不会请求位置、联系人、短信、通话记录、麦克风、相机**这些敏感权限——这在同类应用中非常罕见，意味着它完全不会读取手机上的个人隐私数据。

> [!NOTE]
> NewPipe 不内置任何第三方统计 SDK、广告 SDK 或行为分析 SDK，不会向任何第三方服务器发送你的使用行为数据。

### 主界面导览

NewPipe 采用三栏设计：顶部搜索栏 + 服务切换、侧边导航抽屉、中间内容区域。

**顶部区域**的搜索框右边是当前服务的图标，点击可以在 YouTube、SoundCloud、PeerTube 等已启用的平台之间快速切换。左侧边缘右滑会打开**侧边导航抽屉**，里面包含订阅列表、Feed 时间线、下载管理、历史记录、播放列表、书签、设置入口以及服务管理。**内容区域**则根据当前页面动态变化——首页默认展示 YouTube 热门推荐，进入 Feed 后是订阅频道的最新视频流。

### 第一次播放与下载

播放视频很简单：在顶部搜索框输入关键词，从结果里点选视频卡片，加载完成后自动进入全屏播放器。播放器右下角有后台模式和浮动模式的切换按钮，后者可以让视频缩小成悬浮窗在其他应用上方继续播放。

下载视频则是在播放界面右上角点那个下载按钮（↓ 图标），弹出的面板里可以选择视频分辨率、格式、是否带字幕，还能自定义保存的文件名。确认后下载任务加入队列，可以在侧边抽屉的「下载管理」里查看进度和已完成内容。

### 存储访问框架（SAF）

Android 4.4+ 引入了 Storage Access Framework（SAF）来管理文件访问，NewPipe 用它来让你选择下载存储目录。与老式的直接文件系统访问不同，SAF 通过系统文件选择器让你主动授权某个目录，更安全也更灵活。

选择下载目录时如果文件选择器不弹出，大概率是系统缺少 DocumentsUI 组件（包名 `com.android.documentsui`），某些精简 ROM 会移除它。解决办法是在设置 → 应用里搜一下看能不能启用，找不到就从 F-Droid 装一个替代文件管理器（比如 Simple File Manager 或 Material Files）。

如果设置里下载目录旁边显示红色「不可访问」提示，通常是之前授权的目录被删除了、SD 卡被拔出或者 SAF 授权 token 过期——点更改按钮重新选一个目录就行。

> [!WARNING]
> Android 11 引入了 Scoped Storage 限制，建议把下载目录设在 `/内部存储/Download/NewPipe/` 或 `/内部存储/视频/NewPipe/`，不要放在 Android 沙箱以外的位置。多用户账户下 SAF 授权是隔离的，每个用户需要单独设置自己的下载目录。

### 去中心化的 PeerTube

PeerTube 是 NewPipe 支持的一个特色平台——它不是单一网站，而是由数千个独立服务器（称为「实例」）组成的去中心化视频网络，每个实例由不同组织或个人运营。NewPipe 默认不预装任何 PeerTube 实例，添加步骤也很简单：

1. 点击顶部服务图标 → PeerTube → 确认首次添加
2. 进入设置 → 服务 → PeerTube 实例管理 → 点「+」
3. 输入实例地址（如 `peertube.tv` 或 `framatube.org`）
4. 等 NewPipe 自动测试连接，成功后实例就出现在列表里

可以同时添加多个实例，搜索时会向所有已添加实例发送请求、结果汇总展示。订阅 PeerTube 频道后，最新视频会出现在 PeerTube Feed 里；如果频道在多个实例上同步，NewPipe 会自动解析到最稳定的实例。

| 实例 | 定位 | 语言 |
|------|------|------|
| peertube.tv | 大型综合性实例 | 多语言 |
| framatube.org | Framasoft 官方实例 | 法语为主 |
| peertube.social | 社交视频实例 | 多语言 |
| video.ccc.de | Chaos Computer Club | 德语为主 |
| tilde.pink | 社区实例 | 英语 |

在 NewPipe 里操作 PeerTube 和 YouTube 几乎一样，但本质上有几个差异：视频通常较短（5~30 分钟居多）、画质不如 YouTube 的高码率 4K、搜索结果可能没那么丰富。不过优点是完全去中心化，没有单一大公司控制内容分发。

### 数据管理

NewPipe 存储在设备上的数据包括订阅频道列表、Feed 分组配置、观看历史、搜索历史（如果开启）、书签和播放列表，还有你下载的视频和音频文件。所有数据都可以在设置 → 隐私和设置 → 历史记录里单独控制是否保存。

想清理数据也有多种方式：设置 → 存储 → 「清除应用数据」是一键清空全部（相当于恢复出厂设置，不可恢复）；也可以选择性地清除观看历史、搜索历史或缓存，各自独立互不影响。
