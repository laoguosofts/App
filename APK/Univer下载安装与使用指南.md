## ✨ Univer 是什么：口袋里的 3D 游戏创作工具

Univer（界面内部标识为 Univer Editor）是一款专为 Android 移动端打造的轻量化 3D 游戏创作工具，安装包体积仅 36MB。它把原本属于电脑端游戏引擎的三件事——3D 场景搭建、物理引擎驱动、可视化逻辑编辑——浓缩进了手机屏幕里，让脑海中的游戏创意在通勤、午休、排队等碎片时间里就能落地成一个能跑起来的作品。

一句话理解它的定位：如果 Unity、Unreal 这类桌面端引擎是专业工作室的重型装备，Univer 想做的是口袋里的便携创作工作站——不求替代专业管线，只求让"想法到试玩"这一循环在手机上一气呵成。内置海量免费 3D 模型素材库，涵盖角色、场景、道具三大类，拖拽即可快速搭建游戏场景；搭载可视化节点逻辑编辑器，零代码拖拽连线就能完成游戏交互规则与关卡设计；集成原生物理引擎，支持重力、碰撞、刚体运动等基础物理效果。

适合谁用？想亲手做点小游戏但不想扛电脑、不想学代码的学生党和独立作者；在地铁上刷到某个玩法突然想动手试试的灵感派；带着平板出门想把 demo 从 0 搭起来的创作者。它不挑设备，甚至中低端 Android 手机也能流畅运行编辑器——这正是"口袋创作"的意义所在。

## 🔧 怎么装：Android 安装与首次启动

Univer 是纯 Android 平台的移动端应用，安装分两条路径：应用商店直装和安装包侧载。

### 应用商店路径

1. 打开 Google Play 或华为 AppGallery，搜索 **Univer**（留意开发者名称，避免下到山寨壳）。
2. 确认图标和包名后点击安装，系统会自动拉取并校验。
3. 安装完成后点「打开」即可进入应用。

### 安装包侧载路径（适用于商店未上架的区域或需要特定版本）

1. 从下载页获取 APK 文件，保存到手机本地存储。
2. 首次安装需在系统设置里打开 **「允许安装未知来源应用」**——不同品牌手机路径略有差异（小米在「安全中心 → 隐私保护 → 特殊权限设置」，华为在「设置 → 安全 → 更多安全设置」，OPPO/vivo 在「设置 → 安全」），找到文件管理器或浏览器对应的开关即可。
3. 用文件管理器点击 APK，按弹窗提示完成安装。
4. 安装完成后建议回头把「未知来源」权限关掉，避免其他来源的 APK 误装。

> [!TIP] 版本核对
> 当前最新版本号为 **2026.1.1r1**，安装前请在应用内「设置 → 关于」或商店详情页确认版本号匹配。下载页的 APK 文件名通常带版本后缀，核对一下避免旧版本。

### 首次启动

打开应用后会进入项目列表页——目前应该是空的，只有「+ 新建项目」按钮。这里没有任何引导教程，直接点按钮开建即可；素材库和物理引擎的资源会在第一次进入编辑器时按需下载，不要着急。

> [!WARNING] 项目命名有硬性约束
> 新建项目弹窗里有一条醒目的黄色警告：**项目名中不能包含中文字符**。输入中文或中文标点会导致创建失败，换成英文单词、拼音或数字编号（如 `parkour-01`、`taofang`、`level-3`）就行。这是编辑器层的硬限制，不是 bug。

## 📖 使用入门：从一块平地到能跑的场景

Univer 的核心操作循环可以概括为：建项目 → 摆物件 → 连逻辑 → 跑起来试玩 → 回编辑器调整。下面按这个顺序把每个环节拆开讲。

### 编辑器界面一瞥

进入项目后就是 Univer Editor——顶部是物件选择栏（四类基本物件：角色、地形、道具、空物体），左侧是层级面板（管理场景内所有物件的父子关系和显隐），中间大区域是 3D 视口，底部有一个显眼的 **create** 按钮用来把当前选中的物件放进场景。视口右下角还有虚拟摇杆和升降控件，用来在编辑器里移动视角、调整物件位置。

### 场景搭建：从默认底座起步

新建项目默认已经自带天空和地面——一个半球包裹的蓝灰色天空加上一块足够大的平地面板，所以第一个项目**不用从零搭地形**，直接在底座上摆物件就能跑通全流程。

什么时候需要额外地形？三种典型场景：

| 需求 | 做法 |
| --- | --- |
| 做高度差玩法（平台跳跃） | 用地形方块堆台阶，配合升降控件精确对齐，试玩时验证跳跃路线能不能过 |
| 做区域分隔（地牢探索） | 用墙面方块划分不同房间，制造"下一个房间会有什么"的探索感 |
| 做视野遮挡（恐怖类/解谜类） | 转角、门洞让玩家视角看不全，试玩时的惊喜感来自看不见的地方 |

> [!NOTE] 素材库条目会随版本更新
> 具体有哪些地形方块、角色模型、道具素材，以你手上这版素材库实际展示为准。上面说的是使用思路，不是固定的素材清单。

### 物件放置与层级管理

在顶部物件栏选好类型（比如角色），点底部 **create** 按钮就能把一个实例放进场景。放多个重复物件继续点 create 就行，不需要复制粘贴。左侧层级面板会实时列出当前场景里所有物件，支持拖拽调整父子关系（比如把"灯泡"挂到"房间"下面，整个房间移动时灯泡跟着走），也可以点小眼睛图标临时隐藏不影响试玩。

### 物理与逻辑：让东西动起来

Univer 集成了原生物理引擎，**默认就有重力**——把一个方块扔到空中松手，它会掉下来砸到地面（前提是地面物件开了碰撞）。碰撞开关和刚体参数在选中物件后的属性面板里调，通常默认值就能用，需要精细控制时再改。

逻辑方面用的是**可视化节点编辑器**——打开逻辑面板，左侧是各种功能节点（"开始""当玩家碰撞""播放动画""改变位置"等），右侧是连线画布。拖拽节点到画布、连上线，就能实现："玩家角色碰到终点方块 → 播放胜利动画 → 弹出文字提示"这类交互。不需要写代码，全程拖拽连线。

### 运行模式：把场景跑起来

搭完场景、接好逻辑后，点编辑器右上角的 ▶ 按钮就能切到**运行模式**——编辑器界面收起，画面全屏显示，屏幕下方出现虚拟摇杆和跳跃/交互按钮。这时候你就以玩家视角进入了自己搭的场景，可以走动、跳跃、触发逻辑节点的效果。

> [!TIP] 试玩是迭代的核心
> Univer 的创作循环是"搭 → 跑 → 调"三件事反复来。不要一口气搭完所有东西再跑——搭完第一块平台就跑一次、放好第一个敌人就跑一次，边搭边试玩才能及时发现碰撞漏了、逻辑卡壳了这类小问题，避免堆到一起改起来麻烦。

试玩过程中发现问题怎么办？直接点屏幕顶部的返回箭头切回编辑器，刚才的改动不会丢。修正后再点 ▶ 重新跑，这个循环可以无限次重复。

### 项目管理与数据安全

Univer 的项目**默认保存在手机本地**，没有云同步也没有工程文件导入导出功能（出品方标注后续会推出）。这意味着：

- 卸载应用 = 所有项目数据清空，卸载前务必把所有项目重新打开确认已保存。
- 换机时旧手机的 Univer 不要立即卸载——迁移功能上线前，旧设备是你作品的唯一载体。
- 日常养成勤保存的习惯：每完成一个阶段性改动（比如搭完一段关卡、接好一组逻辑）就手动回项目列表确认一下，不要依赖自动保存。
- 清理手机存储、恢复出厂这类危险操作之前，先花 5 分钟逐个项目打开过一遍。
