## ✨ WigglyPaint 是什么：画出会动的抖动线条

WigglyPaint 是一款主打"动态抖动线条"的绘画工具——你画下一笔，它自动为线条赋予摇摆、颤动的动画效果。不是后期加特效，而是**每一条线条从落笔开始就在动**。

这种"活"的线条让 WigglyPaint 在社媒动图、表情包、手绘动画领域特别好用。8 款画笔各有不同的抖动曲线和节奏——Marker 粗重夸张、Spray 散点飘逸、Pink Crayon 蜡笔质感慢摆，选一支笔就选了一种动画性格。

它覆盖三种平台形态：iOS / Android 原生 App 功能最全、网页版 wigglypaint.com 免装即用（30 秒上手）。v2.0 之后又引入了背景图层、双编辑器风格切换等核心能力，从一个简单的动效画笔进化成了完整的动态绘画工作流。

适合谁用：社媒内容创作者想快速出动态贴纸、手绘动画爱好者、喜欢像素复古美学的独立设计师、以及任何想让静态线条"活"起来的人。

## 🔧 安装步骤：三种平台各走各的路

### iOS App（最完整的体验）

iOS 版本提供全部功能，包括 Live Photo 导出、Apple Pencil 压感支持、Classic / Modern 双编辑器。安装路径很简单：

1. 打开 App Store，搜索 "WigglyPaint"
2. 认准开发者账号，点击获取安装
3. 首次打开时给相册权限（导出 GIF / Live Photo 需要）

> [!TIP] Apple Pencil 用户请确保在系统设置里开启了 Pencil 压感，WigglyPaint 会自动识别并把压感映射到画笔粗细。

### Android App

Android 版功能略有缩减——主要差异是没有 Live Photo 导出，视频导出只支持 MP4 格式。安装流程：

1. 打开 Google Play，搜索 "WigglyPaint"
2. 点击安装，等待下载完成
3. 首次打开授予存储权限

> [!NOTE] 如果你的设备没有 Google Play，可以从官方下载页获取 APK 安装包，安装前记得在系统设置里允许"未知来源应用"。

### 网页版（最快，免装）

网页版是零门槛体验方式——不用注册账号、不用下载任何东西：

1. 浏览器打开 wigglypaint.com
2. 点击首页的 "Let's Draw!" 按钮
3. 直接进入画布开始创作

> [!WARNING] 网页版功能存在限制：不支持 Apple Pencil 压感、帧率较低、没有视频导出和 Live Photo。适合快速体验或临时应急，长期创作建议使用 App 版。

### 版本核对小技巧

装完之后打开设置面板（通常在右上角），找到版本号信息核对一下。目前最新主版本是 v2.0.x，如果你的版本明显落后，建议更新——背景图层和双编辑器切换是 v2.0 引入的核心功能，旧版本没有。

## 📖 使用入门：从画第一笔到导出成品

WigglyPaint 的设计理念是"打开就画"——没有欢迎页、没有项目列表、没有模板选择，App 或网页加载完直接就是画布。开发者说这是为了消除创作的启动阻力。

### 画布界面一览

刚进入画布时你会看到这些区域：

- **中央大块区域**：画布本身，直接画
- **左侧或底部（iPhone 竖屏）/ 右侧（iPad 横屏）**：颜色选择器 + 画笔切换面板
- **顶部工具栏**：撤销 / 重做 / 清空 / 导出按钮
- **右侧工具面板**：Classic / Modern 编辑器里布局略有差异

> [!NOTE] iPad 横屏时工具栏自动移到侧边栏，充分利用宽屏空间；iPhone 竖屏时底部布局让拇指完全够得着所有按钮。网页版的工具栏固定在右侧，从上到下依次是 8 支画笔 + 擦除器 + 清空按钮。

### 选画笔：决定你的线条性格

WigglyPaint 内置 8 款画笔，每款的抖动曲线、线条粗细、节奏都不一样。在工具栏上点画笔图标即可切换，当前选中的会高亮。

最常用的几支：

- **Marker**：粗重、抖动大、颜色鲜艳——画重点线条、轮廓勾边首选
- **Pencil**：相对稳定，轻微摆动——适合精细勾勒和打底稿
- **Spray**：散点效果 + 轻微摇摆——制造涂鸦感、颗粒感
- **Pink Crayon**：蜡笔质感 + 慢节奏摆动——温柔、可爱的风格
- **Eraser**：擦除器，和普通画笔一样有抖动感

建议的上手顺序：先用 Pencil 画基础轮廓，然后切 Marker 加粗重点线条，最后用 Spray 或 Pink Crayon 加装饰。

### 选颜色

调色板在画笔面板旁边。v2.0 之后颜色选择大幅扩充——从 8-bit 复古色到马卡龙梦幻色、到纯色块都有。点一下色块就切换当前绘画颜色。

> [!TIP] 背景颜色比你想的重要得多。柔绿色背景能让粉色角色更甜，深紫色背景能让小星星更亮——开发者的博客特别强调了这一点。不要只用白色背景，换个底色试试效果会完全不一样。

### 撤销、重做与清空

画错了就点顶部的撤销按钮（左箭头）。App 版支持多级撤销，可以一路退回到空白画布。

这里有个 Classic 编辑器的已知问题需要注意：

| 操作 | Modern 编辑器 | Classic 编辑器 |
|---|---|---|
| 普通撤销 | ✅ 可恢复 | ✅ 可恢复 |
| 清空后撤销 | ✅ 可恢复 | ❌ **无法恢复** |

Classic 编辑器中清空画布后，撤销无法恢复之前的内容。如果你习惯用 Classic 风格，**清空前务必确认作品已保存或已导出**。Modern 编辑器已经修复了这个问题。

### 背景图层（v2.0 新功能）

背景图层是 v2.0 的核心升级——之前画布只有前景层（你画的内容），现在可以加一层背景：

**用法步骤**：

1. 打开画布，找背景图层入口（工具栏或设置面板）
2. 选择 "Import Photo" 导入自己的照片，或直接选纯色背景
3. 如果是照片，可以调节透明度——淡到只够看清轮廓时最适合描摹
4. 在调淡的照片上直接画 Wiggly 线条

**三个典型场景**：

- **描摹**：找一张喜欢的角色轮廓图，降低透明度，用 Marker 在上面勾线——既保留原图构图，又加上 Wiggly 抖动效果
- **背景填充**：画好角色后，在背景层选纯色或导入纹理照片，让画面不再单调
- **增加层次**：前景用粗 Marker 画角色，背景导入风景照片调淡——角色就"站"在背景上而不是"贴"在上面

> [!WARNING] 背景图层目前只有一层，不能叠加多张照片。另外导出动画时只有你画的线条会动，背景照片不会跟随线条动起来。

### 双编辑器风格切换

v2.0.1 之后，Classic Pixel 和 Modern 两种编辑器风格可以随时切换——切换不会清空画布，同一张画可以用不同风格的界面操作。

Classic Pixel 是 v1.0 时代的原版风格，特点是粗像素边框、8-bit 复古感、像素图标工具栏。Modern 则更现代简约、留白更多。

| 对比项 | Classic | Modern |
|---|---|---|
| 视觉风格 | 像素复古 | 现代简约 |
| 清空后 undo | ❌ 无法恢复 | ✅ 可恢复 |
| 画笔尺寸调节 | 部分笔受限 | 更灵活 |
| 调色板 | 偏复古色系 | 色系更全 |
| 界面密度 | 偏密集 | 更留白 |

适合人群：追求像素画复古感的老用户选 Classic，新用户或喜欢干净界面的选 Modern。切换入口通常在画布右上角或设置里。

### 导出与分享

完成作品后点导出按钮，各平台支持的格式：

| 平台 | 可导出格式 |
|---|---|
| iOS App | GIF / MP4 / Live Photo / 帧序列 |
| Android App | GIF / MP4 |
| 网页版 | GIF |

导出后直接保存到相册或下载目录。GIF 是最通用的格式，分享到微信、Discord、Twitter 都没问题。iOS 用户如果是做壁纸，可以导出 Live Photo，设成锁屏后按压就能看到动态效果。
