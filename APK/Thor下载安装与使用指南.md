## ✨ Thor 是什么：安卓应用管理的一把瑞士军刀

Thor 是一款面向安卓系统的开源应用管理器，它的核心能力是**冻结（禁用）系统预装应用**——那些厂商塞在手机里删不掉、关不掉、还在后台偷偷耗电的应用，Thor 可以让它们一键消失，既不占资源也不碍事，需要时再一键恢复。

除了冻结系统应用，Thor 还能管理普通应用的批量操作、提取 APK 做本地备份、直接安装 APK/XAPK/APKS 拆分包。界面遵循 Material 3 规范，四个底部标签页覆盖了从概览到操作的完整链路：主页看统计、应用列表做管理、冻结页管状态、设置调权限和外观。

Thor 需要 Root 或 Shizuku 授权才能操作系统级应用。对于不想 Root 的普通用户，Shizuku 模式是最佳选择——通过无线调试配对，就能在不破坏系统完整性的前提下获得完整的管理能力。

## 🔧 Thor 安装与首次激活

### 基础安装

Thor 的安装包体积只有约 2.2MB，轻量到几乎不占空间。下载 APK 后：

1. 在手机文件管理器中找到下载的安装包，点击安装
2. 系统会弹出「未知来源」安全提示——这是因为 Thor 不在 Google Play 分发，属于正常情况
3. 点击「允许本次安装」或前往系统设置临时开启对应来源的安装权限
4. 安装完成后打开 Thor，授予**存储权限**和**电话权限**，Thor 会自动扫描设备上的全部应用列表

> [!TIP]
> Thor 的扫描过程会在首次打开时自动完成，之后每次启动都会增量更新，通常只需几秒钟。如果扫描卡在某个应用上久久不动，可能是那个应用本身有问题，可以在应用详情页强制停止 Thor 后重开。

### Shizuku 激活（推荐模式）

这是 Thor 能管理系统应用的关键前置。没有 Shizuku 或 Root，Thor 只能看到普通应用，系统预装一片空白。

完整激活链路：

1. 安装 Shizuku 应用（F-Droid 或 GitHub 均可）
2. 手机进入**开发者选项**，找到并开启「无线调试」
3. 点击「使用配对码配对设备」获取 6 位数字配对码
4. 打开 Shizuku，输入配对码完成配对，界面会显示配对成功
5. Shizuku 主界面点击「启动」，状态变为「正在运行」
6. 回到 Thor，设置页选择 Shizuku 模式，自动连接成功后就能看到完整的系统应用列表

### Root 模式（可选）

如果你的设备已经 Root，Thor 会自动检测并提示切换到 Root 模式，功能上与 Shizuku 完全一致，选择哪种取决于你更在意 Root 带来的其他便利还是 Shizuku 的灵活性。

### 安装完成后的检查点

| 检查项 | 预期结果 |
| --- | --- |
| Thor 设置页权限状态 | 显示「Shizuku 已连接」或「Root 已连接」 |
| 应用列表能看到系统应用 | 筛选 Chip 选「系统应用」后有内容 |
| 应用详情页操作按钮 | 冻结/解冻按钮可点击、无灰色禁用状态 |
| 主页活跃应用计数 | 数字合理，冻结后会变化 |

## 📖 Thor 使用入门：从第一次冻结到批量管理

### 界面总览

Thor 的界面是 Material 3 风格，四个底部标签页各司其职：

| 标签 | 核心场景 |
| --- | --- |
| 主页 | 活跃应用计数、应用来源分布图表、一键从文件安装 APK |
| 应用列表 | 搜索筛选、批量选择、单应用操作——使用频率最高的页面 |
| 冻结 | 查看已冻结应用、一键解冻恢复 |
| 设置 | 权限模式切换、外观主题（Light/Dark/System、AMOLED 纯黑、动态色彩） |

主页的活跃应用数卡片是直观的效果指示器——冻结越多，这个数字越小。点击卡片可以直接跳到应用列表。应用分布图表能帮你识别来源不明的应用——如果某个分类下堆了一堆应用而你完全记不起来源，值得逐个检查。

### 第一次冻结：从安全的开始

刚装好 Thor，建议按这个顺序操作，避免一上来就冻错东西：

1. **先浏览、不操作**——花几分钟翻翻应用列表，理解筛选 Chip 的用法
2. **挑明显冗余的先冻**——厂商预装的商城、助手、浏览器、资讯推送，这些是第一优先级
3. **批量处理**——长按任意应用进入多选模式，一次性勾几个同类应用批量冻结，熟悉批量操作的节奏
4. **APK 提取备份**——从 Google Play 装的重要应用，用 Thor 提取 APK 做本地备份，防以后商店下架

> [!WARNING]
> 绝对不要批量冻结所有系统应用——系统 UI、Launcher、Telephony 这些组件冻了会直接导致系统异常甚至无桌面。永远逐个确认再操作。

### 系统应用安全等级速查

Thor 用户社区通常把系统应用按安全等级分成三类：

| 等级 | 含义 | 典型代表 |
| --- | --- | --- |
| ✅ 安全 | 放心冻结，几乎无风险 | 厂商商城、游戏中心、浏览器、百度/腾讯/阿里系三方预装 |
| ⚠️ 谨慎 | 多数情况安全，但部分设备可能异常 | 厂商云服务、安全中心、文件管理器、计算器、笔记 |
| ❌ 危险 | 绝对不能冻 | Package Manager、Telephony、System UI、Launcher、Google Play Services |

判断某个应用能不能冻的实用技巧：

- **看图标**——类似小齿轮的大概率是系统服务，别冻；明显是厂商 logo 的大概率是预装应用，安全
- **看包名**——`com.google.android.xxx` 开头的别碰，`com.tencent / com.alibaba / com.baidu` 开头的放心冻
- **先查再冻**——Thor 应用详情页会显示用途、权限和依赖关系，不确定时先在这里看一眼，或搜一下社区有没有人踩过坑

### 冻结后的恢复路径

万一冻了不该冻的应用导致系统异常，三种场景各有救法：

- Thor 还能正常打开——进入冻结页，找到刚冻的应用一键解冻，重启设备即可
- Thor 打不开但系统还能操作——用系统设置的应用管理找到 Thor，强制停止并清除数据，Thor 会重置
- 设备几乎变砖——连接电脑用 ADB 手动解冻核心组件，或进 Recovery 恢复出厂（最稳，但会清数据）

> [!NOTE]
> 预防 > 补救。不确定的应用先查清楚再动手，Thor 的冻结操作虽然可逆，但冻到 Launcher 或 System UI 这种核心组件时，恢复起来还是挺麻烦的。

### 进阶：批量与筛选

Thor 的应用列表支持多种筛选组合：按应用类型（全部、系统、普通）、按冻结状态、按安装来源。配合搜索框按包名或应用名搜索，能快速定位目标。右上角菜单提供高级排序和批量选择入口。

长按应用卡片进入多选模式后，顶部显示选中数量，底部出现批量操作按钮——一次性冻十来个同类预装应用比逐个点效率高得多。选完确认再执行，Thor 不会无声地批量动你的东西。

### 个性化设置

基础可用后可以调调外观：设置 → 外观里有三种主题（Light / Dark / System），AMOLED 纯黑开关适合夜间使用（省电又护眼），Android 12+ 设备还能开动态色彩让 Thor 跟随系统主题取色。Thor 不使用花哨的过渡动画或渐变色背景，核心操作全部前置到主界面，这也是它被很多用户觉得"好用"的原因之一。
