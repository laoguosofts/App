## ✨ Persist 是什么——安卓音量自动化管家

Persist 是一款专注于安卓设备音量管理的自动化工具。它解决的核心痛点是：在不同场景下手动来回调节音量（开会静音、通勤外放、车载蓝牙、睡觉前静音……）既麻烦又容易忘。Persist 的做法是让用户预先定义一组组"预设"——比如"会议"预设把所有通道拉到静音、"通勤"预设给媒体设 30% 上限、"车载"预设把蓝牙音量锁在固定值——然后通过排程（时间到点、蓝牙连接、Wi-Fi 切换、耳机插拔、GPS 围栏等触发条件）自动在预设之间切换。

它的核心组件可以概括为三件事：**预设（Profiles）** 定义每个场景下各条音量通道的目标值；**排程（Schedules）** 决定什么时候启用哪个预设；**音量锁与上限** 确保音量不会被误触或其他 App 乱改。免费版已覆盖大部分日常场景，订阅 Volume Control+ 可以解锁口袋锁、来电排程等高级特性。

适合以下几类用户：经常开会需要静音但不想漏掉重要来电的上班族、每天通勤路上听音频怕炸响的学生、车载蓝牙音量忽大忽小的司机、以及任何觉得"我的手机音量怎么总是不对"的人。

## 🔧 安装步骤

Persist 是一款安卓应用，安装过程和普通 APK 类似，但因为涉及系统级音量控制，安装后首次启动时需要授予若干权限。

### 下载与基础安装

1. 从下载页获取最新版本的 APK 文件（建议核对文件大小和版本号，避免下载到旧版本或非官方渠道的包）
2. 打开系统文件管理器，找到 APK 文件，点击执行安装
3. 如果系统弹出"未知来源"警告，进入 **设置 → 安全 → 安装未知应用**，给文件管理器授予安装权限后重新点击安装
4. 等待安装完成，桌面会出现 Persist 图标

### 首次启动必做的权限配置

这是最容易被跳过但影响最大的一步。如果权限没全开，Persist 的音量锁和排程可能"看起来开了但实际不执行"。

> [!WARNING]
> 以下权限缺一不可——特别是 **通知监听** 和 **电池优化白名单**，没开的话后台进程很容易被系统杀掉，排程跑到一半就停了。

需要授权的项目：

| 权限 | 用途 | 操作方式 |
| --- | --- | --- |
| 修改系统设置 | 写音量值的核心权限 | 首次启动弹窗直接点允许 |
| 通知访问 | 监听音量变化 | 设置 → 通知 → 通知使用权，找到 Persist 打开 |
| 电池优化白名单 | 防止系统杀后台 | 设置 → 电池 → 电池优化，把 Persist 设为"不优化" |
| 开机自启 | 重启后自动恢复运行 | 设置 → 应用 → 自启动管理，开启 Persist |

装完之后可以在 Persist 主界面检查常驻通知是否出现——有常驻通知说明后台存活正常，这是音量锁和排程能稳定工作的基础。

## 📖 使用入门——预设、排程、锁与上限

Persist 的学习曲线不陡，但很多人第一次上手会被"预设""排程""锁""上限"这些概念堆在一起搞晕。下面按实际搭建顺序来走一遍。

### 第一步：先把 Default 预设调好

Persist 有一条内置规则——**所有排程结束时都会自动切回 Default 预设**。这条规则不能关闭，所以配排程之前一定要先把 Default 调成你真正的"日常档位"。

比如你的日常习惯是媒体 50%、响铃 80%、蓝牙 70%，那就进 Persist 的预设 tab，打开 Default 预设，把各条通道的值调好。之后任何排程（时间到点结束、蓝牙断开、耳机拔掉……）跑完都会回到这个默认状态。

> [!TIP]
> 如果同时有多个排程在跑，只有当**所有**激活当前预设的排程都结束时才会回 Default。比如"会议"（时间 9-18 点）和"车载"（蓝牙连车）同时运行，此时蓝牙先断开——不会立刻回 Default，"会议"预设继续生效，直到 18 点到点才切回。

### 第二步：创建你的第一个预设

点预设 tab 右下角的 + 号，给新预设起个名字（比如"会议"），然后添加音量设置：

- **音量锁（Volume Lock）**：把某条通道钉在精确值——静音（0）最常用。锁的特点是谁改都会弹回去，按音量键、系统设置、其他 App 都动不了。
- **音量上限（Volume Limit）**：和锁不同，上限是"允许调但不许超过"——比如媒体通道设 30% 上限，你可以从 0 调到 30，但绝对拉不上去。适合想保留灵活性又怕炸响的场景。

| | 音量锁 | 音量上限 |
| --- | --- | --- |
| 行为 | 钉在精确值，谁改都弹回 | 允许自由调，但绝对不超过封顶 |
| 典型值 | 0（静音）、60%（响铃固定） | 30%（媒体封顶）、50%（响铃最高） |
| 适合 | 想固定住某条通道 | 想保留灵活性但设一个最高线 |

几个高频预设的参考配置：

- **会议**：媒体 0 锁 + 响铃 0 锁 + 通知 0 锁
- **通勤**：媒体 30% 上限 + 响铃 80% 锁 + 导航通道单独设
- **车载**：蓝牙 70% 锁（过高容易回声）+ 媒体跟着蓝牙走
- **睡觉**：所有通道 0 锁 + 闹铃单独设（别把闹铃也锁静音了）

### 第三步：给预设挂排程

预设只是"是什么"，排程决定"什么时候生效"。Persist 支持的排程类型相当丰富：

- **时间排程**：设定开始和结束时间，比如"工作日 9:00 - 18:00 启用会议预设"
- **蓝牙排程**：连上某台设备（车载、耳机）时启用对应预设
- **Wi-Fi 排程**：连接或断开某个 Wi-Fi 时切换
- **耳机排程**：有线耳机插入或蓝牙耳机连接时触发
- **GPS 围栏**：进入或离开某个地理区域（比如公司/家）
- **日历排程**：读取系统日历的忙闲状态

一个常见的组合：时间排程"工作日 9:00-18:00 → 会议预设" + 蓝牙排程"连上车载 → 车载预设"。车载蓝牙断开时，时间排程还在跑，所以不会立刻回 Default，会议预设继续生效。

### VIP 白名单——重要联系人不会被静音闷掉

开会把响铃锁到 0，但又不想错过家人或领导的来电——VIP 白名单就是解决这个场景的。操作流程：

1. 新建一个预设（命名"VIP 来电"之类）
2. 添加 **来电排程（Incoming call schedule）**
3. 在排程里填写 VIP 联系人（名字 + 电话号，也可以直接从系统通讯录选）
4. 给这个预设加上 **响铃音量 = 100%** 的锁
5. 保存

当 VIP 联系人来电时，Persist 会临时切到这个预设把响铃拉满，**挂机后自动恢复到来电前的预设**（比如回到静音的"会议"预设）。其他普通联系人来电话不受影响，继续保持静音。

> [!NOTE]
> 来电排程特性依赖 Android 10 及以下的来电监听 API——Android 11+ 收紧了第三方应用监听来电的权限，这个功能可能不生效。如果你的系统版本是 Android 11+，可以改用日历排程 + 手动给 VIP 联系人在系统层单独设铃声的方式绕过。

### 口袋锁——放口袋里不怕误触

口袋锁是 Volume Control+ 的高级特性。它的作用是：灭屏 + 放在口袋里（通过 proximity 传感器检测）时，自动开启音量锁，防止走路时不小心按到音量键把媒体拉满。

> [!WARNING]
> 口袋锁属于 Plus 特性，免费版有试用期，试用期过后需要订阅或看广告积点来解锁。如果口袋锁开关能打开但灭屏后音量还是会被改，大概率是 Plus 特性没激活。

如果口袋锁不生效，按这个顺序排查：

1. 确认 Plus 特性已激活（不是在试用期内就是已订阅）
2. 检查 Persist 后台进程是否存活（常驻通知有没有出现、电池优化白名单有没有加）
3. 到 Persist 设置页搜"口袋锁"，确认开关真的是打开状态——部分机型重启后设置会被重置
4. 手动验证：开口袋锁 → 把音量拉到最高 → 灭屏放口袋 5 分钟（期间按几次音量键模拟误触）→ 亮屏检查音量有没有被改回
