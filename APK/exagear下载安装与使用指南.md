## ✨ ExaGear 是什么——安卓手机上的 Windows 游戏转译器

ExaGear 是一款运行在 Android 设备上的 x86 Windows 环境模拟工具，它通过内置的 Wine 内核 + ELTechs 自研转译层，让手机能够直接运行 Windows 的 exe 程序。核心玩法很简单：把 PC 上的老游戏或小型软件拷到手机里，用 ExaGear 打开就能跑，不需要云电脑、不需要远程桌面，本地直接转译执行。

它适合的场景集中在**"安卓上怀旧老 PC 游戏"**这一类：英雄无敌 3、模拟城市 4、红警 2、暗黑 2、仙剑奇侠传、各种 Flash 时代的单机小游戏……这些游戏都是 32 位、原生 Windows exe，用 ExaGear 直接跑比找安卓移植版或云游戏体验好得多——没有网络延迟、画面能开原生分辨率、存档存在本地。

当然它不是万能的。64 位程序直接不支持；需要 DirectX 10+ 的 3A 大作跑不动（Wine 内核覆盖不全）；依赖内核驱动的软件无解。能用它跑的游戏有一个共同特征：**32 位 Windows 程序、发布时间在 2015 年之前、主要依赖 DirectX 9 或更早的 API**。

版本方面，社区常用的有 ED302、ET、CRV5 三个分支，内核版本和内置驱动略有差异。ED302 内核更新、兼容性好；ET 触屏映射更激进；CRV5 则在音效模拟上做了优化。选哪个不用纠结——先用 ED302 跑，跑不了再换 ET 或 CRV5。

## 🔧 安装与环境配置

安装 ExaGear 不是简单的"装个 APK"就完事，它有两层结构：APK 应用本体 + OBB 数据包。OBB 里装的是 Wine 内核、运行库和转译层，体积比 APK 大得多。

### 安装步骤

1. **装 APK**：从下载页拿最新版 APK，在手机上安装。安装时系统会提示"未知来源"，允许即可。
2. **放 OBB**：这是最容易出错的一步。解压下载包里的 OBB 文件夹，确保路径是：
   ```
   /Android/obb/com.eltechs.es/
   ```
   （如果你的版本包名不同，就换成对应的包名路径）
3. **核对完整性**：打开文件管理器确认 OBB 目录里不是 zip 压缩包，而是解压后的文件结构。很多闪退就是 OBB 没解压到位。

> [!WARNING]
> 如果手机上同时装了多个 ExaGear 版本（ED302 + ET + CRV5），**每个版本的 OBB 目录必须独立**。ED302 的 OBB 不能给 ET 用，反过来也不行，混装会直接导致容器层闪退。

### 系统要求

| 项目 | 最低要求 | 舒适体验 |
| --- | --- | --- |
| 系统 | Android 7.0+ | Android 9.0+ |
| 架构 | ARM64 | ARM64 |
| RAM | 3GB | 4GB+（建议预留 2GB 空闲） |
| 存储 | 至少 5GB 可用空间 | 10GB+ |

Intel 芯片的旧 Android 设备（如部分 ZenFone）不支持，ExaGear 只认 ARM/ARM64。

### 厂商系统设置

安装完还得给 ExaGear 做几件事，否则大概率运行到一半被系统杀后台：

1. **加入后台白名单**：小米去"游戏加速"里加、华为去"游戏助手"里加、OPPO 去"游戏模式"里加——核心是禁止系统自动清理、允许悬浮窗覆盖
2. **授予全部权限**：存储、麦克风（部分 ROM 需要，否则无声）、后台弹出界面
3. **禁止省电限制**：把 ExaGear 设为"不限制"或"无限制"

> [!TIP]
> 玩之前先**重启一下手机**。Android 长时间运行后后台会积累缓存和僵尸进程，重启一次能腾出干净的 RAM，ExaGear 启动更顺利。

## 📖 使用入门：从零到跑起第一款游戏

安装配置搞定之后，真正上手 ExaGear 需要搞懂三件事：**容器是什么**、**触控操作怎么映射**、**闪退怎么排查**。

### 容器概念

ExaGear 的架构分三层：

- **APK 应用层**：就是你点开的那个图标，负责容器管理
- **容器管理层**：每个"容器"是一个独立的 Windows 环境，里面装的运行库、驱动、游戏都互相隔离
- **游戏运行层**：真正执行 exe 的地方

第一次打开 APK 会提示"新建容器"。容器方案选哪个？社区公认的三个预设及其适用场景：

| 预设 | 特点 | 适合 |
| --- | --- | --- |
| **CP10（Touchpad）** | 触控板式映射，抑制鼠标漂移最有效 | 绝大多数游戏的首选 |
| **Helium** | 接近直接点屏幕，光标灵敏度高 | 对定位精度要求极高的游戏 |
| **Cuprum** | Helium 的变体 | 特定不兼容 Helium 的游戏 |

有新游戏要跑时，建议先新建一个干净容器，不要在已经装了一堆运行库的旧容器里硬塞——旧容器的驱动状态可能和新游戏冲突。

### 触控操作：手指怎么变成键鼠

ExaGear 把手机屏幕模拟成一块 Windows 桌面，默认的触屏手势和 PC 操作对应如下：

| 触屏手势 | 对应 PC 操作 | 日常用法 |
| --- | --- | --- |
| **单击** | 鼠标左键点击 | 点图标、点按钮 |
| **长按（约 0.5 秒）** | 鼠标右键点击 | 打开菜单、选中单位 |
| **双指轻点** | 中键点击 | 部分有用 |
| **双指上下拖动** | 鼠标滚轮 | 翻页、缩放地图 |
| **单指拖动** | 鼠标拖动 | 移动窗口、框选单位 |
| **双指捏合** | 缩放 | 部分程序 |

屏幕边缘有一排浮动按钮，左上/右上通常是呼出虚拟键盘、切换触屏直控和虚拟鼠标。虚拟键盘带 F1-F12 功能键和方向键，玩老游戏基本够用。

**最常见的体验问题是鼠标漂移**——手指按哪里光标飘到旁边，拖不动单位、点不中按钮。这不是硬件问题，是触控方案选得不对：CP10（Touchpad）模式抑制漂移最有效，优先选它。如果某个游戏一直漂移，先换 CP 预设，不行再调灵敏度和同步设置。

屏幕大小也影响体验。5~6 寸手机上虚拟按键会挡掉大量画面，7 寸以上平板（尤其横屏）体验好很多——画面基本不被遮挡，精度也高。有条件的话，平板是 ExaGear 的最佳载体。

### 内存与性能

ExaGear 吃内存：空容器（只装运行库）约 500~800MB，加载游戏后取决于游戏本身——英雄无敌 3 约 300MB，模拟城市 4 约 1GB。**建议至少 2GB 空闲 RAM 才开始玩**。

内存不够怎么办？分三种情况：

- 2GB RAM 的低端机基本告别 ExaGear，最低要求 3GB，舒适使用 4GB+
- 4GB RAM 但系统占了大半 → 强制停止微信、浏览器、相册等大型应用，腾出空间
- 启动后几秒就被杀 → 厂商系统太激进，把 ExaGear 加到后台白名单里

厂商的"游戏加速""游戏助手""游戏模式"这些功能**有用但有限**：有用的部分是开启后会禁止后台清理、提升调度优先级、允许悬浮窗；没用的部分是它们改不了 ExaGear 内部的转译器行为，也改不了 Wine 的 API 模拟效率。建议打开，主要是不让系统在你玩到一半时把进程杀了。

虚拟内存（Swap）对 ExaGear 帮助不大——游戏需要的是即时可访问的 RAM，虚拟内存速度慢得多，开了反而可能更卡。除非 RAM 连启动都不够，否则别开。

### 常见问题快速定位

**启动即闪退**——先搞清楚是哪一层崩的：

| 闪退位置 | 排查方向 |
| --- | --- |
| 点桌面图标立刻回桌面 | APK 本体 + OBB 完整性 + 手机架构 |
| APK 能打开但进不了容器 | 容器文件损坏 / Wine 内核版本冲突 |
| 容器能启动但运行游戏秒退 | 游戏本身兼容性 + 运行库缺失 |

应用层闪退最常见原因就是 OBB 没放对位置或没解压。容器层闪退时新建一个干净容器试一下，干净容器能启动就说明旧容器被搞坏了，删掉重来。游戏层闪退大多是兼容性问题：64 位程序不支持，换 32 位；需要 DirectX 9+ 的换 ED302（内核更新）再试；需要内核驱动的无解。

**声音异常**——爆音或卡顿主要是 dsound.dll 版本不匹配。进容器 → 工具箱 → 驱动切换，把 dsound.dll 换到另一个版本重启再试。没有"最好版本"，只有"最适配当前游戏的版本"。完全没声音时还要检查：ExaGear 有没有麦克风权限（部分 ROM 需要）、游戏是否需要 OpenAL 运行库、游戏设置里声音是不是关了。

**中文乱码**——三步排查：先装 Core Fonts + Tahoma Font 扩展包；ED302/ET/CRV5 再装中文补丁（工具箱里有）；最后确认游戏本身是不是中文版本（有些俄版/英版没有中文字体资源）。

> [!NOTE]
> 闪退、爆音、乱码这些问题，**大概率不是配置错了，而是版本不匹配**。ExaGear 社区的解决方案几乎全是"换一个版本/换一个内核/换一个扩展包"，没有一招鲜。遇到问题别死磕当前配置，换个分支或预设试试。
