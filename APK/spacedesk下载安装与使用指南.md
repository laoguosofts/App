## ✨ spacedesk 是什么

spacedesk 是一套把闲置设备变成电脑副屏的开源方案——不需要额外硬件，只要主机端装一个驱动、副屏设备装一个查看器，通过 WiFi、USB 或浏览器就能把手机、平板、笔记本的屏幕拼进电脑的显示阵列。它在 Windows 主机上作为虚拟显卡驱动运行，在客户端则以原生应用或网页形式呈现，两端建立连接后，副屏就像一块物理显示器一样被 Windows 识别。

核心价值在于"回收闲置屏幕"：家里退役的旧平板、淘汰的安卓手机，不用再当电子书阅读器或视频播放器，接进电脑就能变成第二块、第三块显示器。无论是代码开发的多窗口布局、设计工作的工具栏外置、数据分析的监控面板常驻，还是演示场景的扩展桌面，都能直接受益于多出的屏幕面积。

它属于"软显卡"这类工具，与传统的硬件 KVM 或扩展坞思路完全不同——不依赖任何物理连线（WiFi 版本），也不需要额外供电，设备本身就是显示器。协议层支持多屏拼接、密码加密、断线重连等企业级特性，但对个人用户来说，开箱即用的体验才是真正的门槛。

## 🔧 安装步骤

spacedesk 的安装分两端：主机端（Windows 驱动）和副屏端（原生查看器或 HTML5 网页）。两端的安装方式差异较大，分别说明。

### 主机端安装

1. **从官网下载驱动安装包**——安装包为 `.exe` 格式，建议确认版本号与操作系统匹配（Windows 7/10/11 均支持）；
2. **双击运行安装程序**——安装向导会引导选择安装路径，默认路径即可，建议不要改到带中文的目录；
3. **驱动签名提示**——Windows 可能弹出驱动签名验证警告，这是正常现象，点击"仍然安装此驱动程序软件"继续；
4. **安装完成后重启**——驱动安装需要加载到系统内核，重启是必须步骤，跳过会导致服务无法启动；
5. **验证安装**——重启后桌面上会出现 spacedesk Driver Console 图标，打开后右上角开关处于 ON 状态即表示驱动正常运行。

> [!WARNING]
> 杀毒软件误报是 spacedesk 安装的常见阻碍。主机驱动会被 360、火绒等安全软件标记为可疑驱动程序，建议安装前临时关闭安全软件的驱动防护功能，或安装完成后在安全软件中将 spacedesk 加入白名单。

### 副屏端安装

**Android 设备**：在 Google Play 搜索 "spacedesk Viewer" 下载安装包，首次启动时若提示未知来源需在系统设置中授权。安装完成后应用会自动扫描局域网内的主机，无需额外配置。

**iOS 设备**：App Store 搜索同名应用下载，iOS 端安装权限管理较严格，一般不会出现未知来源提示。

**不想装软件？HTML5 网页查看器**：任何现代浏览器（Chrome、Opera、Safari）都能直接打开官方网页查看器地址，一个浏览器标签页就是一块副屏——无安装、无残留、跨平台。需要注意 Firefox 目前不支持，且网页版性能与延迟不如原生应用，适合临时救急场景。

## 📖 使用入门

两端装好之后，"连上"是第一件事，"用好"则取决于对连接介质和控制台的理解程度。

### 无线连接：最常用也最容易被网络教训

WiFi 无线连接是大多数人的首选——不接线、跨房间、随时断开重连。它的链路步骤很简洁：

1. 主机与副屏设备**接入同一个路由器**——同一 SSID 的 WiFi 或一台走网线一台走 WiFi 都行，关键是同网段；
2. 主机端 Driver Console 开关处于 ON 状态；
3. 打开查看器，等待发现列表刷出主机名，点击即可连接；
4. 如果列表迟迟不出现，通常是防火墙未放行或网段隔离，先从这两处排查。

> [!NOTE]
> 官方对各连接介质的性能排序是：**网线直连 > 网线经路由器 > WiFi 直连路由器 > USB 网络共享 > WiFi 经路由器**。WiFi 是无线链路里偏慢的一档，这是物理现实，不是设置问题。

WiFi 链路的体验预期要放端正：文档、表格、网页、监控面板这类静态内容基本感觉不到延迟；本地视频播放、窗口大范围拖动会有可感知卡顿；快节奏游戏、高帧率视频剪辑预览则不适合。提升无线体验的三件事：副屏设备尽量靠近路由器（5GHz 频段干扰少）、主机侧改用有线接入、查看器的 Quality/Performance 设置往流畅一端拉。

### 控制台导览：排障时不迷路

主机端所有管理动作集中在 Driver Console 一个程序里，左侧功能树、右侧设置区。理解功能树的区块划分，排障时能节省大量时间：

- **CONTROL 区块**：随系统启动自动开服务、密码保护与加密两项核心控制；
- **COMMUNICATION INTERFACES 区块**：列出所有网卡及其 IP，多网卡机器在这里决定对外暴露哪个网络，同时管理 USB 直连通道的开关；
- **CONNECTIONS 区块**：实时显示当前连接的设备数量与历史断连记录，是排障最快的状态仪表盘；
- **DIAGNOSTICS 区块**：三件套——系统与驱动信息、已安装安全软件列表、不兼容软件列表，连接异常时值得扫一眼；
- **VIDEOWALL 区块**：视频墙模式总开关，服务于多屏拼接展示场景。

控制台下方还有三个实用按钮：清空自身设置、清空 Windows 显示设置缓存、导出配置。断线延迟参数也在设置区，用于控制网络抖动时的容忍窗口。

### 视频墙：把多台旧设备拼成一面展示屏

视频墙是 spacedesk 官方明确列出的三大用法之一——把多台设备的屏幕拼成一整面墙，统一显示一幅大画面或一组内容，适合数字标牌、广告轮播、仪表盘展示。

搭建步骤并不复杂：主机驱动装好并开启 VIDEOWALL 开关，若干台旧手机旧平板装好查看器并接入同一局域网，逐台连接后在 Windows 显示设置里把每块屏按物理位置拖动排列，最后用播放器或展示软件把内容铺到整面"虚拟大屏"上。设备可以竖装、横装，Rotation 与自定义分辨率配合调整姿态。

与"多屏办公"的区别在于：办公场景要的是"每块屏各自独立显示不同窗口"，视频墙要的是"多块屏合成一幅画面"。设备成本很低，退役旧手机就是视频墙的黄金材料。店铺展示常年开机的场景里，Keep Monitor Active 必须打开，否则轮到它熄屏整面墙就缺角；链路尽量用近距 WiFi 或 USB 直连，配合断线延迟参数把网络抖动挡在体验之外。

### HTML5 查看器：临时救急的备胎方案

不是每台设备都允许装软件——公司电脑锁了安装权限、朋友的 Mac 不想留东西、Linux 没有原生查看器，这些场景下 HTML5 网页查看器就是备胎。它的定位是"临时看一眼、救急一下"，不适合长期主力副屏。

连接步骤与无线链路相同：主机驱动 ON 状态、设备浏览器打开官方网页查看器页面、输入主机 IP 或从列表选择、画面出现在浏览器标签页里按 F11 全屏。一台主机可以同时被原生端与网页端连接，互不冲突。浏览器兼容方面，Chrome、Opera、Safari 可用，Firefox 因性能限制目前不支持。
