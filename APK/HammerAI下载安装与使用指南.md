## ✨ HammerAI 是什么

HammerAI 是一款主打**本地离线**的 AI 角色聊天与图像生成工具。它的核心卖点是模型跑在本机、数据不出设备——对在意隐私或者网络条件不好的用户来说尤其实用。桌面端（Windows / macOS / Linux）和移动端都有覆盖，iOS 在 App Store 能直接装，Android 走官网分发渠道。

产品分两条主线：一条是**角色聊天**，可以导入或自建 AI 角色、跑本地模型对话；另一条是**图像生成**，内置 Flux、Stable Diffusion、NovelAI 等多款主流画图模型，提示词支持结构化拆解和负面提示词配置。官方文案把"被困荒岛前记得先下好模型"作为经典段子，侧面说明了它的离线使用定位。

免费版和付费版在云端模型用量上有分界，但本地模型聊天和角色创建是全开放的，不会被锁。很多新用户反馈最开始被防火墙的联网权限弹窗吓到——一个号称本地的软件为什么要联网？其实那是应用在本机拉起的随机端口本地服务器（类似 localhost:9841），界面通过它和模型进程通信，放内部网络就行，不用放行公网。

## 🔧 安装步骤（桌面与移动端）

### PC 端（Windows / macOS / Linux）

1. **核对版本与文件大小**：下载完成后先比对官网给出的文件大小，避免下载到损坏的包；
2. **路径选择**：默认路径一般是系统盘，模型文件会额外占用大量磁盘空间——建议把模型存储目录改到空间充裕的分区；
3. **防火墙弹窗处理**：首次启动时防火墙会提示放行网络请求，**只选"专用网络"或"内部"**，不要放行公网；
4. **模型下载**：首次开聊前需要下载至少一个本地模型，按需选就行，大模型几个 G 很正常。

> [!WARNING]
> 有些杀毒软件会把本地模型的推理进程误报——如果遇到拦截，把 HammerAI 安装目录整个加入白名单即可。

### 移动端

- **iOS**：App Store 搜 HammerAI 直接装，无额外步骤；
- **Android**：官网下载 APK，安装时需要开启"未知来源应用"授权，装完记得及时关掉这个开关。

## 📖 使用入门

### 图像生成：提示词怎么写

官方文档给的示范提示词藏着一套可以直接抄的结构——按「主体 → 外貌细节 → 机械/特殊特征 → 服装 → 场景与光线」的顺序推进，比堆形容词有效得多。画一个赛博朋克女机器人的例子：先写"未来感赛博朋克机器人女性、体格紧实"，再逐项点名面部与发型，然后点出题材决定的发光义体改造，接着是服装，最后用"夜色霓虹都市中站立"收尾。

**正面提示词**的三条原则：
- **具体压倒笼统**：写"霓虹夜景侧逆光"而不是"好看的背景"；
- **结构化优先**：模型对条理最敏感；
- **避免又长又糊**：模糊或过度复杂的描述是出图翻车的头号原因。

**负面提示词（Negative Prompt）** 是质量保底的固定项，通用配置是：

```text
blurry, low quality, pixelated, overexposed, unnatural lighting
```

风格性的排除（比如"不想要文字水印"）再按需追加，负面提示词一般不用大改。

### 画图模型怎么挑

图像生成不是绑死一个模型，按画风选是出图质量的第二杠杆：

| 模型 | 画风倾向 |
| --- | --- |
| Flux | 新一代通用模型，细节与光影表现力强 |
| Stable Diffusion | 生态最大，风格微调版本极多 |
| NovelAI | 二次元/插画向的老牌劲旅 |
| Realistic Vision | 纯写实摄影感 |
| MajicMIX | 写实人像向的社区精调模型 |
| DreamShaper | 兼顾写实与奇幻插画 |

挑模型的口诀：要真人感选 Realistic Vision 或 MajicMIX；要插画与二次元选 NovelAI 系；通吃选 Flux 起步再按需换。换模型的正确姿势是**固定种子换模型**——同一句提示词、同一个种子下对比，画风差异一目了然。

### 回复长度上限与 MLock：两个容易忽略的开关

参数区里两个开关直接决定回复会不会被腰斩、应用会不会崩：

- **Max Response Tokens**：调大则回复更完整但生成更慢；调小则出字快但长剧情会被截断。典型症状与处方：回复总是说到一半停 → 调大上限；模型转圈很久没动静 → **调小**上限（官方排障清单里的正式一步）；截断但不想加长 → 用 Continue 按钮让它接着说。
- **MLock（Memory Lock）**：控制模型占用的内存是否锁定。内存宽裕、追求稳定就开；内存贴着模型下限跑就关，让系统自己腾挪；聊着聊着闪退先关 MLock 再排查。

> [!TIP]
> 回复上限、MLock 和上下文长度三者在内存账本上是连坐的——配置低的老机器这三项全保守，别同时开大调高。

### 断网能不能聊

**能，只要模型在本地**。三个前提：模型已下载、走的是本地模型路线、角色已保存在本地。官方还教了一个验证办法：断开网络后照常聊天，对话不受影响即为真本地。应用要网络权限只是因为它在本机拉起了一个随机端口的本地服务器（类似 localhost:9841），界面通过它和模型进程通信，好处是模型吃满 CPU / GPU 时界面依然流畅。

图像生成目前依赖云端模型，离线状态下不可用；文本转语音在移动端 1.1 版加入本地合成后可以离线出声。判断一个功能是否依赖网络，看**模型在哪**就够了。
