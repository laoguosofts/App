## ✨ AzureArchive 是什么

AzureArchive 是一款面向蔚蓝档案（Blue Archive）玩家和创作者的**可视化剧情编辑器**。它的核心使命很简单：让不会编程的玩家也能通过拖拽节点、填写对话的方式，搭建出自己的 BA 剧情分支，并在鉴赏模式里体验完整的演出效果。

和常见的文字冒险引擎不同，AzureArchive 原生支持 BA 的角色立绘、背景图、BGM 和特效资源包，打开就能用，不需要自己从零搭建素材库。软件本身只提供编辑器界面和鉴赏播放能力，真正让角色「活」起来的是每个版本配套的资源包——里面打包了游戏提取的角色立绘、场景背景、音效和 BGM。

适合谁用：想写同人文但嫌 RPG Maker 太重的 BA 粉丝、做剧情测评 UP 主需要可视化脚本辅助、或者单纯想把自己脑补的老师与学生日常变成可玩片段的爱好者。软件完全免费，没有付费墙也没有内购。

## 🔧 Windows 安装步骤与版本核对

### 系统要求

AzureArchive 从 0.7.6 版本起**不再支持 Windows 7 和旧版 Windows 10**，要求 Windows 10 21H1（build 19043）及以上。如果你还停在 Win7 或早期 Win10，要么先升级系统，要么退回到 0.7.5 版本使用。

### 本体安装流程

1. 从官方下载页获取安装压缩包，解压到任意目录（建议路径不含中文和空格，避免资源加载异常）
2. 运行 `AzureArchive.exe` 启动软件——首次启动会弹出版本号界面，**记下这个版本号**，后面装资源包要用
3. 本体本身不带任何素材，打开后角色立绘和背景全是空的，这是正常现象

### 资源包安装（关键步骤）

资源包是 AzureArchive 能正常显示角色和场景的前提，而且**每个本体版本只认特定版本号的资源包**——差一版都不行，装错了会卡「等待中」或「检查更新」。

> [!WARNING]
> 版本不匹配 = 加载界面永远卡住。装资源包之前**务必对照下面的版本号表**，找到你当前本体版本对应的精确资源包版本号，再去下载那个版本。

| 本体版本范围 | 所需资源包版本 | 备注 |
| --- | --- | --- |
| 0.5.2 | 202309031848 | — |
| 0.6.0 ~ 0.6.5 | 202310151727 | iOS 需用 202310192335 |
| 0.6.6 ~ 0.7.5 | 202311082028 或 20242101810 | 装完断网防资源损坏 |
| 0.7.6 ~ 0.7.7 | 202405211324 | 旧版本需手动装 + 断网 |
| 0.7.8 | 202406030217 | 旧版本不再支持在线服务器 |
| 0.7.9 | 202408180000 | 此版本无移动端 |
| 0.7.9.1 及以上 | 202408202213 | 202412150051 仅 Win，部分特效不可用 |

资源包安装有两种方式：

**自动安装（在线资源模式）**：启动 AzureArchive 后在设置里选择自动安装，软件会从在线服务器拉取对应版本的资源包。注意移动端**不支持后台下载**，切出去下载就停；Wi-Fi 和移动网络切换也会中断，建议用稳定的 Wi-Fi 一次下完。

**手动安装（推荐）**：从下载页获取精确版本号的资源包 ZIP，在 AzureArchive 的安装界面选择手动路径，指向这个 ZIP 即可。手动安装更可控，也不受网络波动影响。

> [!TIP]
> 安装前至少留出 10GB 磁盘空间——本体 + 资源包解压后的临时文件都占空间，磁盘满了会卡在 `Extracting Archive...` 进度不动。

### 安装完成核对

重启 AzureArchive，如果能正常进入主界面、角色立绘和背景图都能看到，说明版本匹配成功。如果还卡在加载界面，继续往下看排查章节。

## 📖 使用入门：从节点到剧情

AzureArchive 的工作流核心是**节点编辑**——左侧节点工厂提供四种核心节点，拖进工作区、连线、填写内容，就完成了剧情搭建。

### 四种核心节点

| 节点名 | 作用 | 必连 |
| --- | --- | --- |
| Entry（入口） | 剧情唯一起点，项目新建时自动创建，不可删除 | 必须有一个出端连线连到 Script |
| Script（脚本） | 承载对话、角色、环境变化的主节点——剧情的血肉 | 可连入可连出 |
| Selection（选项） | 给老师的回应做分支，出端连线数决定选项数量 | 至少连两条出端到不同分支 |
| End（结束） | 剧情终点，可标记为「未完待续」或「结局」 | 只有入端，无出端 |

典型项目的创建顺序：新建项目 → Entry 节点就位 → 拖 Script 放进工作区 → Entry 连 Script → 在 Script 里写对话摆角色 → 需要分支时插 Selection → 收尾拖 End 节点。

> [!NOTE]
> Entry 节点删不掉是设计如此——它是剧情的锚点，全项目只能有一个。有连线的节点要先切断连线再删除，或者用节点工厂旁边的垃圾桶操作。

### Script 节点深度使用

Script 节点是最常用也最值得花时间研究的节点。点击它会打开**脚本节点检查器**，面板按功能分成多个区域：

- **节点名称框**：给当前节点起个能识别的名字（比如「晨间对话」「天台告白」），显示在工作区节点方块上
- **脚本列表**：一个 Script 节点里可以包含多条脚本，每条脚本对应一帧画面变化。用 `+` 按钮在当前选中脚本后插入新脚本，`-` 删除选中的
- **预览窗口**：实时看到当前脚本的画面效果，改完点 ▶ 刷新
- **角色栏位**：选中或交换角色的位置槽，每个栏位可以单独调 Role、Position、表情、Emoticon
- **对话输入框**：写当前脚本的对话内容
- **环境选项卡**：切换背景图和 BGM
- **额外指令栏**：输入 `#wait`、`#bgshake` 等内置指令，实现界面没覆盖的效果（比如暂停、背景震动）

把连续但角色位置没大变化的对话堆在同一个 Script 节点里、用多条脚本承载，比每条对话都拆成一个独立 Script 节点更紧凑，工作区也不会变得太乱。

### 卡住排查：从简单到复杂

按参考样本整理的排查顺序，加载卡住时按以下步骤逐一过：

**检查版本号匹配**（最常见原因）：打开软件看当前本体版本号，对照安装章节的版本表，确认装的资源包是不是对应版本。版本不对 = 永远卡住，没有例外。

**检查网络**：自动安装走在线资源模式时，移动端不支持后台下载，Wi-Fi 切换会中断。换成稳定 Wi-Fi 或直接走手动安装。

**检查缓存**：缓存异常会导致反复卡在同一进度。关闭 AzureArchive → 找到 `%AppData%\..\LocalLow\foxxlight\AzureArchive\data\settings` 文件夹 → 清空或删除 → 重启。

**手动解压兜底**：自动和手动安装都失败的话，把资源包 ZIP 手动解压到 `manual_install` 文件夹，启动 AzureArchive，版本匹配时会自动识别。

**磁盘空间**：至少保证 10GB 剩余——本体 + 解压临时文件都占空间，满了会卡 `Extracting Archive...` 进度不动。

> [!WARNING]
> 0.7.6 之后的版本旧版本不再支持在线服务器；0.7.9 没有移动端，Android / iOS 用户跳过；0.7.9.1 及以上版本，202412150051 资源包仅支持 Windows，部分特效不可用。

如果以上都试过还卡住，按 **F8** 调出报错日志（没有 F8 的设备在设置里开启调试控件，点击屏幕右侧的框），把报错信息贴到 GitHub Issue 或官方渠道咨询。

### 自定义资源包

官方还提供了**自定义资源包**（解压码 `0721`），包含无新音效和背景特效的精简版本，仅支持自定义安装。使用自定义资源包时可以导入自己的角色立绘替换原版，提前备份好 `overrides` 文件夹里的原有文件。
