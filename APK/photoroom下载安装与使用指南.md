## ✨ Photoroom 是什么

Photoroom 是一款面向电商卖家、独立品牌和内容创作者的 AI 图片编辑工具，核心能力是**自动抠图**——把产品从杂乱背景中一秒提取出来，然后替换成干净的纯白底图、场景背景或自定义模板。在此基础上，Photoroom 叠加了一系列服装电商专属的 AI 工具，包括 AI 背景生成、虚拟模特上身、隐形人台生成、智能去褶皱、AI 改色等，形成了一个从产品原片到上架成片的完整工作流。

这款工具最初从移动端起家，App Store 和 Google Play 的用户评分都在 4.7 以上，积累了数十万的专业卖家用户。发展到现在，Photoroom 已经覆盖 iOS、Android、Web、Windows、Mac 五个平台，账户全打通，云端项目自动同步。

**核心亮点快速一览：**

- **一键抠图**：AI 自动识别产品边缘，发丝、透明材质、复杂形状都能精准提取
- **服装 AI 全家桶**：虚拟模特、隐形人台、去褶皱、改色——专为服装电商设计的一整套工具链
- **模板驱动**：内置数千套电商详情页模板，套模板就能直接出上架图
- **多端协同**：手机拍 → Web 批量处理 → 桌面精细调整，云端无缝同步

Photoroom 的定位非常清晰——**服务电商场景的专业图像处理**，而不是通用设计软件。它把设计师几个小时的重复性工作压缩到几分钟甚至几秒内，让卖家可以用更低的成本产出更高质量的产品图。

## 🔧 如何安装 Photoroom

Photoroom 支持五个平台，各平台的安装方式有所不同，下面分别说明。

### iOS / Android 移动版安装

移动版是 Photoroom 功能最完整、交互最流畅的端，推荐作为主力使用：

1. 打开 App Store 或 Google Play
2. 搜索 **Photoroom**，认准官方开发者账号
3. 点击安装，等待下载完成
4. 首次启动会要求注册账户——可以用邮箱直接注册，也可以用 Google / Apple 账号一键登录

> [!NOTE] 系统要求
> - iOS 18+（iPhone）/ iPadOS 18+（iPad）
> - Android 版本以 Google Play 页面标注为准
> - 移动设备需要支持神经网络加速芯片，才能获得最佳的 AI 处理速度

### Web 版使用（无需安装）

Web 版适合有专业相机、需要上传高分辨率大图或批量处理大量图片的场景：

1. 在浏览器中打开 Photoroom 官网
2. 点击右上角「Sign In」登录账户（和移动端账户通用）
3. 直接拖拽图片到页面开始编辑

> [!WARNING] Web 版局限
> - 部分高级 AI 参数调整在移动端独占
> - 无离线能力，断网会丢失当前编辑进度
> - 处理速度不如原生 App 流畅

### 桌面版安装（Windows / Mac）

桌面版本质是 Web 技术栈的原生壳，功能与 Web 版基本一致，但原生窗口管理和文件拖入更便捷：

**Windows：**
1. 打开 Microsoft Store
2. 搜索 **Photoroom**
3. 点击「获取」安装

**Mac：**
> [!WARNING] Mac 版硬件要求
> Mac 桌面版**仅支持 Apple Silicon 芯片**（M1 / M2 / M3 / M4）。Intel Mac 用户请使用 Web 版或 iOS 设备。

安装步骤：
1. 打开 Mac App Store
2. 搜索 **Photoroom**
3. 点击「获取」安装

### 安装后的首次验证

安装完成后，建议做一次快速验证：

1. 用账户登录
2. 随便上传一张产品图
3. 确认背景移除功能正常工作
4. 检查账户配额显示是否正确（免费版应显示 250 次月度导出额度）

## 📖 Photoroom 使用入门

### 核心工作流概览

Photoroom 的核心使用逻辑可以概括为「上传 → 自动抠图 → 调整 → 导出」四步。虽然听起来简单，但 AI 工具链的组合使用才是 Photoroom 的真正威力所在。

```text
产品原片（手机拍 / 相机拍）
    ↓
【自动抠图】一键去除背景，得到 PNG 透明底产品图
    ↓
【背景处理】纯白底 / AI 场景生成 / 自定义模板
    ↓
【高级 AI（可选）】虚拟模特上身 / 隐形人台 / 去褶皱 / 改色
    ↓
【导出】JPG / PNG，按平台要求的尺寸规格
```

### AI 虚拟模特——服装卖家的生产力神器

虚拟模特（Virtual Model）是 Photoroom 服装 AI 工具链中最具代表性的功能。它的逻辑和传统棚拍正好相反：你只需要一张**平铺图**或**隐形人台图**，AI 会自动把衣服"穿"到虚拟模特身上，生成自然的穿搭效果图。

**准备输入素材：**

效果最好的输入是 **隐形人台图**（Ghost Mannequin 生成的），其次是高质量的平铺图。有真人模特的照片不推荐直接用于虚拟模特工具——应该先用 Photoroom 的背景移除功能去掉模特，再把干净的衣服图传给虚拟模特工具。

**选择模特参数：**

Photoroom 提供了非常细致的模特参数调整：

| 参数维度 | 可选范围 |
| --- | --- |
| 人种 / 肤色 | 亚裔、欧美、非裔、拉美等 |
| 身材体型 | 纤细、标准、丰满、高大 |
| 性别 | 男性、女性、非二元性别 |
| 姿势 | 站立、行走、坐姿、动态姿势 |
| 背景 / 场景 | 与 AI 背景生成器联动，模特可出现在任意场景 |

**多件衣服搭配：**

一个实用的技巧是同时搭配多件衣服——上衣 + 裤子 + 鞋子 + 配饰，可以组合成一整套完整穿搭，然后让同一个虚拟模特试穿。这个功能非常适合做电商详情页的「搭配推荐」模块，一件上衣可以快速生成不同裤子、不同鞋子的多套穿搭图。

> [!TIP] 服装细节保留
> Photoroom 的 AI 会尽量保留服装的版型、面料纹理、印花图案、颜色光泽这些细节。如果发现细节丢失严重，检查一下原始图片的分辨率——建议上传 1000px 以上的高清图。

**虚拟模特 vs 真人棚拍对比：**

| 对比项 | AI 虚拟模特 | 真人模特 + 棚拍 |
| --- | --- | --- |
| 成本 | 消耗 AI 积分 | 数百到数千元每套 |
| 耗时 | 10-30 秒 / 张 | 半天到一天拍摄 + 后期 |
| 可定制性 | 换人种 / 身材 / 姿势秒级切换 | 重新拍一套 |
| 真实感 | 接近真实但细看能识别 | 真实 |
| 批量规模 | 一次可生成数百张 | 每次拍摄有限量 |

**实战建议：** 高频快反的 SKU 用虚拟模特快速出图上线，品牌形象照和旗舰产品仍然用真人棚拍。

### AI 积分与订阅档位

Photoroom 从某个版本起引入了 AI 积分机制。这个机制很容易搞混，这里理清楚：

**积分消耗规则：**

- **核心抠图（背景移除）**：不限量，不消耗积分
- **消耗型 AI 工具**（虚拟模特、去褶皱、AI Expand 扩图等）：每次使用消耗积分
- 不同档位每月给到的积分额度不同

**四档定价总览：**

| 档位 | 年付月均 | 月导出额度 | AI 积分 | 核心差异 |
| --- | --- | --- | --- | --- |
| Free | $0 | 250 次 | 不单独计量 | 带水印、基础功能 |
| Pro | 约 $7.5 | 无限制 | 3,000 / 月 | 去水印、核心 AI 不限、批量 50 张 |
| Max | 约 $25 | 无限制 | 更高额度 | 含产品视频生成、批量 250 张、4K |
| Ultra | 定制 | 定制 | 定制 | SLA、SSO、API、专属支持 |

**免费版能用什么：**

- ✅ 每月 250 次导出生成
- ✅ 核心背景移除（Photoroom 招牌功能）
- ✅ 基础背景替换（纯白、纯色、预设模板）
- ✅ 移动端 + Web + 桌面端全部可用
- ❌ 导出右下角带 Photoroom 水印
- ❌ 高级 AI 功能（虚拟模特、隐形人台、去褶皱、改色等）不可用或次数有限
- ❌ 批量处理限制

**什么时候该升级：**

任何一条命中都值得考虑 Pro：

1. **水印影响使用**——产品图要上架电商平台或做营销素材时带水印不合适
2. **250 次不够用**——每月处理 300+ 张图，一半时间在等额度重置
3. **需要服装专属 AI 功能**——虚拟模特、隐形人台、去褶皱这些是免费版没有的高频刚需
4. **需要批量处理**——Pro 版支持批量 50 张 / 次，Max 版 250 张 / 次，能省大量重复劳动

> [!NOTE] 订阅管理注意事项
> iOS / Android 内购的订阅需要在各自的平台侧取消（Apple ID 订阅 / Google Play 订阅），不是在 Photoroom 应用内取消。升级即时生效，降级在下一个计费周期生效。

### 平台选择与工作流搭配

Photoroom 五端覆盖，聪明的做法是按工作流特点组合使用：

| 你的场景 | 推荐平台组合 |
| --- | --- |
| 手机拍产品、随时随地上新 | iOS / Android App |
| 专业相机拍大图、精细调整 | Web 版 + 桌面版 |
| 批量化生产（100+ 张 / 次） | Web 版 + 键鼠操作 |
| 多端协同（手机拍 → 桌面调 → 手机复查） | 全平台，云端同步 |

移动端 App 是 Photoroom 的原生主场，触屏选区、擦除 / 还原笔刷的手势操作最自然，批量处理和高级 AI 功能也通常**移动端优先上线**。Web 版和桌面版的优势在于大图处理和批量操作时键鼠更舒适。
