## ✨ Flud 是什么

Flud 是一款 Android 平台的 BT 种子下载器，由 Delphi Softwares 开发。它把桌面端 qBittorrent、μTorrent 这些工具才有的完整功能搬到了手机上——文件选择、优先级控制、顺序下载、RSS 自动订阅、速度曲线诊断，一个不落。

它的核心定位是：给那些想在手机上高效管理种子下载的用户，一个轻量但专业的解决方案。不管是追剧集、更新系统镜像、还是从开源社区拉取软件源码包，Flud 都能搞定。对于不想让后台下载白白耗流量、想精准控制每一个种子行为的人来说，Flud 的可选项和透明度比那些"一键下载"的简化工具强得多。

Flud 支持种子文件和磁力链接两种添加方式，内置 DHT、PeX、μTP 协议，能自动发现 peer、优化连接。界面采用 Material Design 规范，在种子列表、详情页、设置页之间切换清晰直观。免费版带少量广告，专业版（Flud Pro）解锁了 RSS 订阅、批量管理等高级功能。

## 🔧 Flud 安装详解

### 从 Google Play 安装

Flud 目前只在 Google Play 官方分发：

1. 打开 Google Play 商店，搜索 "Flud - Torrent Downloader"。
2. 确认开发者名称是 **Delphi Softwares**，避免下到仿冒应用。
3. 点击安装，等待下载完成——安装包体积不大，通常一两分钟内搞定。

> [!WARNING] 非 Google Play 渠道的风险
> 网上流传的各种"破解版""绿色版"Flud，来源不明且有安全风险。这款应用本身免费版功能已足够日常使用，专业版也只有一次性买断，完全没必要碰第三方修改包。

### 首次启动的权限授权

Android 11 及以上版本引入了**分区存储**限制，Flud 在首次启动时会弹出存储权限请求。这一步必须允许——不授权的话 Flud 没法保存下载的文件，甚至连种子元数据都写不了。

授权流程走完后，Flud 会让你**选一个下载目录**。之后它只能访问这个目录及其子目录。

### 设置默认下载目录

首次授权完成后，建议立刻检查一下下载路径：

1. 打开 Flud，点右上角菜单按钮。
2. 进入 Settings → Storage。
3. Download folder 就是默认下载位置，点进去可以切换到内部存储或 SD 卡的任意文件夹。

> [!NOTE] 关于 SD 卡
> Android 4.4 (KitKat) 之后，第三方应用写 SD 卡根目录的能力被系统硬性限制。Flud 下载到 SD 卡时，文件会落在 `Android/data/com.delphicoder.flud/` 下——这不是 Flud 的 bug，是 Android 的安全架构要求。如果你用文件管理器找不到，优先检查这个路径。

### 验证安装是否完整

装完之后，打开 Flud 看看主界面是否正常显示三个标签切换（Downloading / Finished / All），右下角的 + 号按钮是否存在。能进入设置页、切换下载目录不报错，基本就没问题了。

## 📖 Flud 使用入门

### 界面结构速览

Flud 主界面分三块：顶部工具栏、种子列表、底部悬浮按钮。每个种子一行，显示文件名、进度条、当前下载速度、种子数 / peer 数。点击任意一个种子就能进入**详情页**——这是日常诊断下载问题的第一现场。详情页里能看到文件列表、peer 列表、tracker 列表和实时速度曲线。

### 添加种子的两种方式

**种子文件**：拿到 `.torrent` 文件后，系统弹出"用什么打开"时选 Flud；或者在 Flud 里点右下角 + 号 → Add torrent file，手动从文件管理器选。Flud 会先解析种子元数据，列出里面包含的所有文件——**勾选你要下的，不需要的可以取消**，然后选目录点 ADD 就开始了。

**磁力链接**：更轻量，浏览器里点磁力链接会自动弹出 Flud 选择；或者复制磁力链接后，在 Flud 里点 + 号 → Add from clipboard（自动识别剪贴板里的磁力）或 Add from URL（手动粘贴）。磁力链接首次连接需要从 DHT 网络拿元数据，所以可能等几秒到几十秒，取决于 swarm 的 seeders 数量。

### 文件选择与下载优先级

这是 Flud 和简化版工具拉开差距的关键功能。BT 种子经常把一大堆文件打包在一起——电视剧全季、游戏 DLC 大包、源码仓库，真正要用的只是很小一部分。Flud 让你在添加种子时就挑好文件，下载过程中随时回来改勾选。

**添加时挑文件**：弹出文件列表后，每个文件有独立勾选框。点文件夹名旁的勾选框可以整组选 / 取消，右上角有全选 / 反选按钮。

**下载中途调整勾选**：主列表点进种子详情页 → Files 标签，改完即生效。取消勾选的文件不会继续下载；已经下完的文件取消勾选后会变成"跳过"状态，但文件不会自动删除，需要手动清理。

**优先级设置**：文件列表里每个文件右侧有三个标记——High（⬆ 优先拉取碎片，适合追剧时把想先看的几集设成高）、Normal（🔵 默认）、Low（⬇ 最后才轮到）。长按文件或文件夹 → Set priority 来改。优先级只影响拉取顺序，不影响总带宽，设成高优先级的文件不一定比其他文件快多少，只是更早被调度。

### 顺序下载让边下边播更顺畅

Flud 有一个独立开关叫 **Sequential download**（顺序下载）。默认是随机下载——BT 协议的标准行为，从 swarm 里随机拉取碎片，效率最高。顺序下载则是从文件开头到结尾按序拉取，配合边下边播的视频播放器体验更好，但整体下载速度可能略慢。

这个开关在**单个种子的设置**里，不是全局设置：点进种子详情页 → 右上角菜单 → Torrent settings → Sequential download。

### 速度曲线诊断：看懂你的下载瓶颈

点击任意种子进入详情页，速度曲线、peer 列表、tracker 列表就是诊断问题的三板斧。

**速度曲线怎么看**：横轴是时间，纵轴是速度，上面一条线是下载、下面一条是上传。三种典型模式：

| 曲线模式 | 可能原因 | 建议动作 |
| --- | --- | --- |
| 平稳跑满带宽 | 理想状态，没有问题 | 什么都不用改 |
| 忽快忽慢、剧烈波动 | seeders 在线/离线切换；网络本身不稳 | 试试开启顺序下载（视频种子） |
| 长期低速、接近零 | tracker 没连上；DHT 没发现足够 peers | 检查 tracker 状态，必要时手动添加公共 tracker |

**Peers 页关键指标**：详情页会显示 `Seeders: 246 (1,761)` 这样的数字——246 是当前在线可连接的 seeders，1761 是整个 swarm 的总 seeders。**如果第一个数字长期接近 0**，不管后面那个多高，你都没多少速度——说明 tracker 没连上，或者 seeders 通过 DHT 没被发现。另外看连接方向：`↓` 是你主动连过去（出站），`↑` 是对方连过来（入站）。如果只有 `↓` 没有 `↑`，说明端口映射没生效。

**Trackers 页诊断**：每个 tracker 有自己的 Status——OK / Updating / Error。常见错误："Unable to connect"或"Connection timed out"说明 tracker 挂了或被网络屏蔽；"Announce interval too short"是请求太频繁，等一会儿自动恢复。如果所有 tracker 全挂了，Flud 会退到纯 DHT/PeX 模式，只要 DHT 还开着就能找到 peers，只是效率低一些。你也可以手动补公共 tracker：详情页 Trackers 标签 → + 号 → 粘贴 URL → 保存。

> [!TIP] ETA 只是粗略参考
> Flud 显示的 ETA（预计剩余时间）是根据当前瞬时速度推算的，BT 下载速度本来就波动大，ETA 跳来跳去很正常。别指望它精准。

### RSS 自动订阅：设定一次以后不用管

RSS 自动下载是 Flud 最省心的高级功能之一——给它一个 RSS 源地址，配好关键词过滤规则，Flud 就会定时检查这个源，发现新资源且名称符合条件时自动添加种子并开始下载。适合追剧追更、关注更新频繁的资源发布源。

**配置步骤**：

1. Settings → RSS → 点右上角 + 号。
2. Name：给订阅起个好认的名字，比如"某字幕组剧集更新"。
3. Feed URL：填入 RSS 源地址，以 http:// 或 https:// 开头。
4. Update interval：多久检查一次——15 分钟到 24 小时可选。追更频率高的选短一点的间隔。
5. **Keywords**（关键！）：只下载文件名包含这些关键词的资源。多个关键词用空格或逗号分隔，全部匹配才算命中。
6. Exclude keywords：反选——文件名里包含这些词的一律跳过，比如 `sample trailer promo RARBG`。
7. Auto download：勾选上命中就自动开下；不勾的话只会出现在候选列表里等你手动点。
8. 选好下载目录，保存。

**关键词匹配技巧**：好的关键词规则能让 RSS 下载精准很多。用精确片名 + 年份（`Breaking.Bad 2008`）比模糊片名准得多；格式限定（`1080p`、`x264`）能过滤掉不需要的版本；多订阅分开建，一个源追美剧另一个追日漫，各自配不同关键词。

**管理已有订阅**：在 RSS 设置页能看到所有订阅——点击名称进入编辑界面改关键词和间隔；右侧开关可以临时关掉不检查；长按订阅 → Force update 可以不等下一次间隔、立即去查一次。

> [!NOTE] 先试运行再开自动下载
> 刚开始调关键词规则时，建议把 Auto download 设为关闭。RSS 命中的资源会出现在候选列表里（不是直接开始下），你可以一个个过目。观察几轮确认规则调对了，再开自动下载。

### 下载中途换存储位置

下载到一半想把种子从内部存储搬到 SD 卡？Flud 支持：长按种子 → Move to → 选择新的目标文件夹。Flud 会自动把已下载的数据移动过去，然后继续下载未完成的部分。移动过程中种子会暂停，等文件搬完自动恢复，大文件可能需要一些时间。
