## ✨ WearOS 是什么

WearOS 是一款专为 Wear OS 智能手表设计的第三方工具箱应用——把开发者工具、文件管理、应用安装、系统调试这些原本需要 adb 命令行才能搞定的事情，打包成了一个友好的图形界面，在手机上点几下就能完成。它的核心价值在于降低门槛：不需要装 Android Studio、不需要记 adb 命令、不需要 root 手表，普通用户也能玩转自己的 Wear OS 设备。

功能覆盖面很广：一键 ADB 无线调试连接、批量安装 APK、Split APK 拆分包合并安装、手表文件浏览与传输、电量模拟测试、应用数据清理、日志抓取……基本上折腾 Wear OS 时会碰到的常见需求，它都有对应的入口。对开发者来说是测试利器，对普通玩家来说是装表盘、传文件、调设置的好帮手。

支持的品牌覆盖了市面上主流的 Wear OS 手表：三星 Galaxy Watch 4/5/6 系列（One UI Watch）、谷歌 Pixel Watch、OPPO Watch、TicWatch 等，不同品牌的连接和调试方式略有差异，工具箱都做了适配。

## 🔧 安装与连接准备

WearOS 工具箱是 Android 手机端应用，安装过程跟普通 APK 没区别，但手表端需要先做一些准备工作才能顺利连接。

### 手机端安装

1. 从下载页拿到最新 APK，传到手机
2. 打开 APK 安装包——如果是第一次装外部来源应用，系统会提示允许「安装未知应用」
3. 安装完成后先别急着打开，手表那边还没准备好

> [!TIP]
> 如果装完打不开或闪退，大概率是 Android 版本太低（工具箱需要 Android 7.0+），或者手机系统对后台权限限制太严，在系统设置里把工具箱的「自启动」和「后台弹出界面」权限打开。

### 手表端：打开开发者模式

这是最关键的一步。每个 Wear OS 手表的开发者模式入口位置略有不同，但大体一致：

**三星 Galaxy Watch（One UI Watch）**

1. 设置 → 关于手表（About watch）→ 软件信息（Software information）
2. 连续点击「版本号」7 次，屏幕会提示「开发者模式已启用」
3. 返回设置，多出「开发者选项」

**其他品牌（原生 Wear OS）**

1. 设置 → 系统 → 关于 → 版本号
2. 同样连点 7 次激活

### 手表端：打开调试开关

进入开发者选项后，依次打开：

- **ADB 调试**（必开）
- **无线调试**（Android 11+ 设备有这个选项，推荐开）
- 如果只有「通过 WLAN 调试」也可以用

> [!WARNING]
> Galaxy Watch 系列默认会开启「调试期间保持屏幕唤醒」，其他品牌如果没有这个选项，连接期间注意别让手表自动灭屏——某些省电策略会把无线调试通道掐断。

### 连接成功率说明

不同品牌的无线调试稳定性有差异。Galaxy Watch 系列出厂系统默认允许 ADB 调试、Wi-Fi 信号稳定、One UI Watch 对开发者选项暴露最充分，连接成功率在所有品牌中属于最高的。国行版和国际版在开发者选项和调试开关上基本一致，不受影响。

## 📖 使用入门

连接成功后，工具箱的功能面板会全部解锁。下面从几个高频场景入手，讲讲实际怎么用。

### 安装第三方应用——包括 Split APK

这是工具箱最常用的场景之一。Google 从 Android 5.0 开始推广 App Bundle 格式，把一个应用拆成多个 split APK：base.apk（主包）、config.arm64_v8a.apk（CPU 架构适配）、config.zh.apk（中文语言）、config.xxhdpi.apk（高 DPI 资源）等。Google Play 会根据设备自动组合下载，但第三方 APK 站点（APKPure、APKMirror）下载的通常是多个 split 分散的。

**普通安装器只能装 base.apk**，缺少 config 包的话应用会闪退、显示异常或只有英文界面。工具箱的 Split APK 安装功能在底层用 `pm install-multiple` 命令正确推送所有 split，一次性合并安装。

操作流程：

1. 把同一个应用的所有 split APK 下载到手机同一个文件夹——识别方式：每个 split 文件名都包含同一个包名（例如 `com.example.app`），base 包最大、config 包较小
2. 在工具箱功能面板里点击「安装 Split APK」，进入专门的 split 安装界面
3. 选存放所有 split 的文件夹，工具箱会自动识别属于同一个应用的 split 并合并；如果文件夹里混了不同应用的 split，手动勾选属于同一个应用的那一组
4. 确认清单无误后点击开始，工具箱按 Android 标准顺序打包合并，推送到手表端安装

> [!NOTE]
> Split APK 安装是捐赠解锁的高级功能，免费版没有。有些 split 即使只装 base.apk 也能跑——config split 只是优化资源，不是强制依赖。只有在装完后发现应用不正常时才需要合并所有 split。

### 电量模拟——测试表盘和低电量表现

电量模拟可以**临时**让手表系统显示的电量变成任意值（1%~100%），不会改变真实电池状态，只是欺骗系统显示层。手表重启后自动恢复真实电量。

典型用途：

- **表盘测试**：很多表盘在低电量时会变色、隐藏元素或提醒充电，总不能真把电耗到 20% 来测试吧
- **应用测试**：某些应用低电量时会触发节能模式或提醒弹窗，模拟低电量可以测试这些逻辑
- **截图展示**：想要干净的、显示特定电量的表盘截图用于分享

操作步骤：

1. 工具箱电池工具面板里找到「电量模拟」入口
2. 输入框填上目标电量值（1~100），或用滑动条选择
3. 点击应用，手表电量显示立即变成目标值
4. 测试完后手表重启即可恢复，或在工具箱里点「还原真实电量」

> [!TIP]
> Galaxy Watch 对电池数据的暴露最完整，电量模拟在这个系列上效果最好。注意：模拟 100% 但实际电池只有 20%，用一会儿还是会低电量——纯粹是显示层伪装，没有实际续航效果。低电量时系统强制降低性能、关闭心率监测这些是硬件级的，模拟显示不会解除。

### 文件管理——像手机文件管理器一样浏览手表

工具箱连接手表后，功能面板里的「文件管理」打开一个简化的浏览器界面。手表的存储大致分为几个区域：

| 路径 | 内容 | 典型用途 |
| --- | --- | --- |
| /sdcard/Download | 下载的文件 | 确认推送的 APK 是否存在 |
| /sdcard/Pictures | 图片和截图 | 取出手表截图 |
| /sdcard/Music | 音乐 | 传音乐进手表 |
| /sdcard/Android/data/\<包名\> | 应用数据 | 检查缓存膨胀 |
| /sdcard/WatchFace | 部分第三方表盘路径 | 传自定义表盘 |

操作方式跟手机文件管理器类似：点击文件夹进入子目录、返回按钮回到上一级、长按可以复制/移动/重命名/删除。需要注意权限边界——/sdcard 下大多可读写，/data/data 下通常看不了（除非有 root），系统分区只读别动它。

### 应用管理与调试

工具箱还集成了应用卸载、应用数据清理、日志抓取等实用功能。连接稳定是前提——文件传输过程中如果 Wi-Fi 波动导致连接断开，文件可能传到一半就停了，重新连接后手动重试即可。
