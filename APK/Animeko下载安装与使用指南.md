## ✨ Animeko 是什么

Animeko 是一个跨平台的追番客户端，主打把在线源和 BT 种子源聚合到同一个播放界面里。它内置了大量视频源，覆盖当季新番和经典老番，用户点进一集就能自动选好可用的播放条目开始看——不用自己到处找网盘链接、不用在不同字幕组之间跳来跳去。

除了基础的找番、播片，Animeko 在追番体验上做了不少细节：和 Bangumi 账号联动自动标记追番进度、BT 缓存边下边播、弹幕覆盖、倍速与跳过 OP/ED，还有 v5.1.0 新增的设置导入导出，换设备时不用再从头调偏好。整体定位偏向"用起来顺手就好"的实用派工具，而不是追求极致画质的发烧向播放器。

支持的平台比较全：Android 有 APK 安装包，Windows 和 macOS 走通用安装器，Linux 用 AppImage 单文件分发，不需要 root、不需要改系统库。桌面端和移动端的数据目录相互独立，但登录同一个账号后追番记录能同步回来。

## 🔧 各平台安装要点

Android 和桌面端都是标准安装流程，但 Linux 版的 AppImage 格式对新手来说可能第一次见，这里把几个平台容易踩的坑统一提一下。

1. **核对版本号**——下载页会标出当前稳定版和更新日志，建议优先稳定版。v5.1.0 之后的版本才带设置导入导出功能，旧版用不了这个特性。

2. **Android 未知来源授权**——如果用 APK 安装，系统会弹出"允许此来源安装"的提示，勾上再点安装即可。装完可以进设置把权限关掉保持安全。

3. **Linux AppImage 权限**——下载下来的 `.appimage` 文件默认没有执行位，直接双击没反应。打开终端 `chmod +x ani-x86_64.appimage`，或者在文件管理器里右键属性给执行权限。放桌面快捷方式的话可以把文件移到 `~/Applications/`，再在 `~/.local/share/applications/` 里写一个 `.desktop` 条目。

> [!WARNING]
> AppImage 放 FAT32 等不支持执行位的文件系统上会报 `no such file or directory`，务必放在 ext4/xfs 等 Linux 原生分区。

4. **Windows 杀毒误报**——偶尔有用户反馈被 Defender 拦截，这是签名机制的常见现象。从下载页拿的版本没问题，添加排除项即可。

5. **数据目录位置**——各平台数据存放路径不同，Linux 是 `~/.local/share/me.him188.ani/`，清除这个目录等于清掉所有缓存和登录状态。

## 📖 使用入门

### 找番与日程视图

首页默认是当季新番的日程视图，按星期把正在播出的番剧排开，每列一天。每部番显示名称、日本时间的放送时刻和当前集数，点进去直接进条目详情。想看历史季度的番，从条目页按放送年份筛选，或者用搜索排序。

一个容易混淆的点：日程上显示"今天更新"不代表你这条源已经有片。BT 源和在线源通常要等日本那边播完后过一段时间才会同步出新集，日程只是告诉你官方播出时间，不是资源到位时间。定时刷新源列表就好。

### 播放与手动换源

点开一集后 Animeko 会自动选一条可用的播放源开始加载，但自动选的不一定是你想要的——可能是别的字幕组、分辨率不够，或者那条源临时挂了播不动。这时就要手动换源。

操作很直观：播放界面上有「换源」按钮，点开列出所有可用的条目，挑一条点上就会重新加载。换源面板有两种展示模式：

| 模式 | 显示内容 | 适合场景 |
| --- | --- | --- |
| 简单模式 | 源名称 + 快速预览 | 想快速试一条能不能播 |
| 详细模式 | 分辨率、字幕组名、体积、格式、Tier 等级 | 精挑 1080p + 特定字幕组 + AAC 音轨 |

> [!TIP]
> 不同源的缓存是独立的——你已经缓存了 A 源的某一集，换 B 源再缓存一份不会覆盖 A，想清旧缓存要手动去缓存列表删。

如果所有源都换过还是播不动，问题多半不在源本身：冷门老番无人做种可以改缓存慢慢等；所有在线源都白框或加载失败多半是版本偏旧，更新到较新版本；两种源都不行则检查一下网络出口，考虑用代理。

### 设置导入导出

v5.1.0（2025-10-23）之后加入了设置导入导出，换设备时这功能特别省时间。导出会把所有本机偏好打包成一个 JSON 文件，包括播放器画面拉伸方式、连播开关、自动跳 OP/ED、倍速、弹幕字号和透明度、网络线路、数据源列表、BT 做种开关和限速、主题外观等——大部分能在设置里手动调的项都在里面。

但登录态和账号关联数据**不会**被导出，这是安全考虑。缓存和下载进度也不会跟着走，毕竟缓存是本机大文件。所以新设备导入完设置后，记得重新登录 Bangumi 或 Animeko 账号，追番进度才能同步回来。

操作路径是 **设置 → 通用 → 导出设置 / 导入设置**，几秒就完事。正则过滤规则尤其值得保存——写了很多条之后手动再敲一遍很痛苦，定期导出一份存云端或者电脑上，万一哪天清数据重装能一键恢复。

### 桌面端的托盘与快捷键

Linux 和部分桌面环境下可能看不到托盘图标，这是已知问题。可以用快捷键把 Animeko 从后台切回来，不同桌面环境快捷键可能不同，建议进设置里确认一下当前绑定。
