## ✨ Maldives 是什么：一款专门跑 MV/MZ 引擎的安卓 RPG 游戏播放器

Maldives 是一款面向 Android 平台的 RPG Maker MV 与 MZ 引擎游戏专用播放器。如果你手头有这类用 RPG Maker 制作的独立游戏，不想开电脑、想在手机上随时随地跑起来，这款播放器就是为你准备的。

它的定位很明确——**只服务于 MV/MZ 这两款较新的 RPG Maker 引擎**。引擎识别、WebGL 渲染、NPOT 贴图补丁、虚拟手柄、用户脚本注入这些能力，都是围绕 MV/MZ 的运行时特点量身定做的，不做无关引擎的兼容。

核心功能点可以归纳为几个关键词：WebGL 硬件加速渲染、NPOT 大图自动补丁、屏幕虚拟手柄、用户自定义脚本注入、解包 Enigma 打包壳、存档与数据管理。从社区实测来看，它在 MV/MZ 游戏的兼容性和流畅度上表现比较扎实，尤其是面对那些 JoiPlay 上会黑图或卡帧的游戏，往往直接就能跑满 60 帧。

适合谁用？主要三类人：用 RPG Maker MV/MZ 制作的独立游戏玩家、跑老电脑游戏想在手机上续玩的怀旧党、以及动手能力强、想给游戏打补丁或注入辅助脚本的折腾向玩家。

## 🔧 安装步骤：Android 手机上的三步安装流程

Maldives 是 Android APK 安装包，安装过程跟大多数第三方 Android 应用一样——因为不在国内应用商店分发，主要需要解决"允许未知来源"这一件事。

**第一步：确认安装包来源靠谱**

从下载页获取的 APK 文件大小应该在官方说明的合理区间内。如果下载下来文件特别小或特别大，建议先核对一下版本号和文件大小说明，避免下到残缺或被篡改的包。

> [!WARNING]
> 不要从论坛网盘、微信群分享等来路不明的渠道下载 APK——第三方二次打包的软件可能被植入广告或恶意代码。

**第二步：允许未知来源安装**

Android 11 及以上的操作路径：

1. 打开系统**设置** → **应用和通知** → **特殊应用访问权限**
2. 找到并进入**安装未知应用**
3. 选择你用来下载 APK 的浏览器或文件管理器，把"允许此来源"的开关打开
4. 返回文件管理器，点击 APK 文件开始安装

Android 10 及更早版本路径略有不同，一般在**设置 → 安全**里就能找到"允许未知来源安装"的开关。

**第三步：完成安装并验证**

安装完成后，在手机应用列表里找到 Maldives 的图标，点开确认能正常进入主界面。首次启动如果弹出权限申请，全部授予即可——播放器需要存储权限来读取游戏文件夹。

> [!TIP]
> 安装后建议先跑一遍你计划玩的那款游戏，确认基础功能正常，再开始导入更多游戏。如果遇到安装后闪退，常见原因是 Android 版本过低或 APK 文件下载不完整。

## 📖 使用入门：从导入第一个游戏到跑通常见玩法

安装完成后，接下来的核心流程就是三件事：**判断手里的游戏能不能跑、导入游戏文件夹、启动运行并按需调设置**。下面按这个顺序展开。

### 先判断：你的游戏是 MV/MZ 引擎吗？

这是最关键的前置条件。Maldives **只支持 RPG Maker MV 和 MZ 两款引擎**的游戏，不支持 VX / VX Ace / XP / 2000 等老 Ruby 引擎，也不支持 Ren'Py、Unity、Kirikiri 等其他引擎的游戏。

判断方法很简单——解压游戏目录后，看两个特征：

| 特征 | 位置 |
| --- | --- |
| `Game.exe` | 游戏根目录（电脑端启动器，播放器不用它，但它是标志） |
| `www` 文件夹 | 跟 `Game.exe` 同层，里面必须有 `index.html` |

只要这两个特征都具备，就是 MV/MZ 引擎游戏，Maldives 可以直接运行。拿不准的时候用文件管理器打开游戏目录，确认 `www` 子目录里有 `index.html` 就稳了。

> [!NOTE]
> 少数 2015 年早期版本的 MV 游戏在存档环节会崩溃，这是播放器对老版引擎脚本兼容不完整导致的。如果你遇到这个问题，可以去社区寻找专门的存档补丁，或者考虑换其他 MV 播放器试试。

### 导入与启动

判断引擎没问题后，把游戏文件夹复制到手机存储的任意位置——建议新建一个 `RpgMakerGames` 目录专门放，方便管理。在 Maldives 主界面里点"导入游戏"或类似按钮，浏览到刚才复制的游戏目录就可以了。

启动后如果画面正常显示、操作响应灵敏，说明基础兼容性没问题。接下来根据体验调两个最常用的设置：

**虚拟手柄**：游戏运行时从设置或悬浮控制里开启，屏幕上会叠加一个方向键加功能键的组合。目前版本是十字方向键布局，最多支持六个按键（方向 + 确认 + 取消 + 菜单 + 快跑），覆盖 MV/MZ 游戏的常用操作。早期版本曾经是模拟摇杆形态，现在已经统一成十字方向键了。手柄适合走图和战斗，看长对话时触控更顺手，两套输入方式可以随时切换。

**NPOT 补丁**：如果启动后发现地图黑一块、角色看不见，大概率是游戏美术用了超大贴图，超过手机 GPU 纹理尺寸上限（社区提到的分界线是 4096 像素）。Maldives 内置的 NPOT 补丁会自动处理这些超尺寸贴图，保持 WebGL 硬件加速不关闭的前提下正常渲染。在设置里找到图像相关选项，确保 NPOT 处理已启用；5.02 起还加了 NPOT 压缩选项，能在修复黑图的同时控制显存占用。这个机制是它相比同类播放器的一大优势——JoiPlay 上同类型游戏往往需要手动关闭 WebGL 改用 CPU 渲染，卡到没法玩。

### 进阶玩法：用户脚本注入

设置主页的"其他脚本"分组下有一个"管理用户脚本"入口，这是 Maldives 留给进阶玩家的后门——可以给游戏注入自定义 JavaScript 补丁。典型的使用场景包括：

- **等不及播放器更新，用脚本绕过某个已知 bug**：比如某款游戏在特定对话节点会卡，社区有人写了绕过脚本，直接导入就能继续。
- **加辅助功能**：自定义按键映射、界面缩放、跳过已读对话之类的个性化需求。
- **折腾与魔改**：改运行参数、查看游戏内部状态，属于玩家圈的研究向玩法。

脚本直接执行在游戏环境里，所以有三个安全提醒：来路不明的脚本别碰（等于给游戏开后门）、游戏加脚本后行为异常先禁用全部脚本验证排除原因、它跟播放器内置的插件自动修复是两回事——自动修复是播放器自己处理，用户脚本是全手动的进阶操作。折腾坏了的话，禁用脚本就能恢复；如果涉及存档损坏，再考虑备份恢复。脚本的具体编写方法不在本站范围，去开发者社区找同好交流。

### 关于解包

Maldives 还有一个解包能力——可以拆开 Enigma 打包壳拿到内部资源。但要注意，**解包能力不等于运行能力**：如果拆出来的是 VX / VX Ace 等老引擎游戏的本体，还是需要对应的播放器来运行，Maldives 只负责 MV/MZ 的运行时。
