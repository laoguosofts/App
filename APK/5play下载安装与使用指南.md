## ✨ 5play 是什么

5play 是一个面向 Android 的第三方应用分发平台，主打海外应用、MOD 版本游戏和 Google Play 上受限地区的应用。对国产安卓机用户来说，它最大的价值在于——那些因为地区限制或缺少 GMS 框架而在官方商店装不了的应用，5play 基本都能找到。

平台采用自有 CDN + 对象存储架构分发 APK，部分应用还提供 XAPK 格式（APK + OBB 打包在一起），大型游戏的数据包安装步骤因此被简化。内容团队持续更新 MOD 版本，覆盖去广告、解锁 Pro、移除 GMS 依赖等多种修改类型，在 Android MOD 生态里属于标签明确、种类全的那一类。

适合谁用？大概这几类人比较有代表性：手里是国产安卓机（小米、OPPO、vivo、华为）、想用一些只在海外商店分发的 App；喜欢单机游戏 MOD、想跳过漫长肝度的玩家；或者单纯想多一个应用来源、不想被单一商店绑死的用户。

## 🔧 安装 5play 之前必须做的一件事：未知来源授权

从 Android 8.0（奥利奥）开始，Google 把"允许安装未知来源应用"这个全局开关改成了**按应用授权**——你想装从哪个应用里下载的 APK，就得在系统设置里单独给那个应用开权限。很多人第一次装 5play 时都会在这里卡一下：点了安装按钮，系统弹出"无法安装，来源未知"，但设置里找不到那个熟悉的全局开关了。

**步骤一：搞清楚给谁授权**

你用什么下的 5play 安装包，就给什么应用开权限。通常是浏览器（Chrome、Edge、Firefox、系统自带浏览器都算），少数情况是文件管理器。

**步骤二：找到设置页**

不同品牌 ROM 路径略有不同，但最快的方式永远是在系统设置顶部搜索栏直接搜"未知应用"或"安装未知来源"，大部分 ROM 能直接跳过去。如果搜不到，参考下面这张表逐个找：

| ROM 品牌 | 进入路径 |
| --- | --- |
| 原生 Android / AOSP | 设置 → 应用和通知 → 特殊访问 → 安装未知应用 |
| Xiaomi / MIUI / HyperOS | 设置 → 应用设置 → 特殊权限设置 → 安装未知应用 |
| OPPO / ColorOS | 设置 → 应用管理 → 特殊权限设置 → 安装未知应用 |
| vivo / OriginOS | 设置 → 应用与权限 → 系统应用设置 → 安装未知应用 |
| 华为 / HarmonyOS | 设置 → 安全 → 更多安全设置 → 安装未知应用 |

**步骤三：授权、装、再授权一次**

1. 在设置页找到你刚才下载 5play 的那个应用（浏览器或文件管理器），把"允许安装未知应用"的开关打开
2. 回到下载目录，点击 5play 的 APK，正常安装
3. 装完 5play 之后，**还得再给 5play 自己开同样的权限**——因为你之后在 5play 里点下载，系统会识别出"是 5play 在请求安装权限"，没有权限就装不了下一个应用

> [!TIP]
> 装完所有应用后，如果担心安全，可以回到设置把浏览器和 5play 的权限关掉，不影响已经装好的应用。

## 📖 使用入门：下载、安装、MOD 与 OBB 的完整玩法

### 基本下载流程

5play 的首页是应用分类和热门推荐，顶部有搜索栏。找到目标应用后进入详情页，点下载按钮就行。5play 的下载不经过 Google Play 通道，走的是自有 CDN + 对象存储组合，客户端会自动选一个速度最快的节点。

但这个架构也有几个天然弱点——部分节点在国内被限速、下载链接有 24 小时有效期、CDN 节点偶尔切换。所以下载出问题是**常见现象**，不是 5play "又崩了"。

> [!NOTE]
> 下载速度异常慢或掉到 0 时，先取消当前下载（不是暂停），在首页底部切一下语言（英语或俄语），再回到详情页重新点下载。语言切换后后端选节点的逻辑可能变了，会走另一条通道。如果还不行，打开飞行模式 10 秒再关掉，强制手机刷新网络连接。

### XAPK 和手动放置 OBB

Google Play 限制单 APK 最大 100MB，大型游戏（现代战争、GTA、PUBG Mobile）的素材、音效、地图资源远超这个数。Google 的解法是 APK 控制在 100MB 以内，额外资源以 **OBB（Opaque Binary Blob）** 形式分发，应用装好后会自动去 `Android/obb/<包名>/` 目录找对应的 OBB 文件加载。

从 Google Play 直接安装的应用不需要管 OBB，Play 商店会自动把 OBB 放到正确位置。但从 5play 下载时分两种情况：

- **XAPK 下载**（推荐）：一个下载按钮下好 XAPK，安装器自动处理 OBB，不用手动放
- **APK + OBB 分别下载**：两个独立下载按钮，APK 直接下，OBB 通常是 ZIP 压缩包

5play 上部分大型游戏的 MOD 版本就是 APK + OBB 分开发布——因为 MOD 版改了 APK 代码，直接用 XAPK 打包安装器解压时可能出错。这时候得手动处理。

手动放置的步骤：先分别下好 APK 和 OBB ZIP → 用文件管理器把 ZIP 解压出 `.obb` 文件 → 在 `Android/obb/` 下创建以应用包名命名的目录（包名从 Google Play URL、APK 文件名或 5play 详情页都能查）→ 把 `.obb` 文件拷进去 → **先装 APK，装完不要立即打开**，等确认 OBB 位置对了再启动应用。

> [!WARNING]
> 最常见的三个坑：包名目录一字不差写错了一个字符；OBB 文件直接放在 `Android/obb/` 根目录而不是二级包名目录；复制大文件时被系统杀掉进程导致文件不完整。复制完务必核对文件大小和 5play 详情页标注的 OBB 体积是否一致（±5% 属于正常）。

### MOD 版本：改了什么、哪些能用、哪些别碰

MOD 是 "Modified" 的缩写，指基于原版 APK 做过二次开发的修改版。5play 上的 MOD 标签明确、种类全，常见的修改类型可以归纳为这几类：

| 修改类型 | 原理 | 典型效果 |
| --- | --- | --- |
| 去广告 | 移除代码中的广告位调用 | 原版里的横幅、插屏、激励视频广告全部消失 |
| 解锁 Pro / 高级版 | 修改付费验证代码 | 原版需要内购的高级功能直接可用 |
| 无限资源（游戏） | 替换游戏数值或资源文件 | 金币、钻石、能量无限用 |
| 移除 GMS 依赖 | 替换原版调用 Google Play Services 的代码 | 国产机也能运行原本依赖谷歌框架的应用 |
| 重新签名 | 修改后必须用新签名 | 安装时提示"与原版签名不同"，正常现象 |

MOD 不是万能的。需要服务器端校验的功能（云端存档、竞技匹配、银行支付）MOD 改不了或者改了会出问题。哪些适合用 MOD、哪些绝对不要碰，可以按下面这个边界判断：

| 类型 | 建议 | 原因 |
| --- | --- | --- |
| 单机游戏、去广告的工具应用 | ✅ 放心用 | 不涉及云端账号，纯体验提升 |
| 银行 / 支付 / 加密货币 | ❌ 绝对别碰 | 任何修改版都不值得冒险 |
| 通讯 / 社交（Telegram、LINE、Discord） | ❌ 绝对别碰 | 账号安全敏感，MOD 版可能拦截消息或窃取密钥 |
| 竞技类在线游戏（PUBG、MLBB） | ❌ 绝对别碰 | 反作弊系统检测到会封号 |
| 在线 RPG / MMORPG | ⚠️ 单机部分可以改 | 涉及在线同步的功能可能有问题或封号 |

判断一个 MOD 版安不安全，按四步走：先看应用类型（银行、通讯类直接放弃）→ 看 5play 上的评分（4.0 以上才考虑）和评论区反馈 → 详情页安全扫描区块有没有标记"可疑"→ 下载完用手机安全软件扫一遍，有告警就别装。
