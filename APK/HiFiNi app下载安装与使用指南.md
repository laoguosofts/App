## ✨ HiFiNi app 是什么

HiFiNi app 是一款面向无损音乐爱好者的社区型应用。它把音乐分享、曲目排行、用户互动整合在同一个界面里，注册用户可以发布资源帖、参与讨论、积攒积分，访客则能在不登录的情况下自由浏览和试听。核心功能可以概括为三件事：找歌、下歌、跟同好交流——界面简洁，分区清晰，榜单系统是它的特色。

**适合谁用：** 追求高音质无损资源的音乐爱好者、想发现冷门好歌的听众、愿意分享自己收藏的社区贡献者。如果你只是想随便听听在线流媒体，HiFiNi 可能显得偏"硬核"；但如果你对母带、FLAC、内嵌封面这些词不陌生，这里会很对味。

## 🔧 安装步骤

HiFiNi app 主要面向 Android 平台，下面按 Android 的安装流程来说明。

### 安装包下载与校验

从下载页拿到安装包后，建议做两件事：

1. **核对文件大小**：安装包体积通常在几十到上百 MB 之间，下载完成后比一下下载页标注的大小，差太多就重下
2. **核对版本号**：下载页会标注当前最新版本，装完进 app 设置里再对一遍

### Android 未知来源授权

这是最常见的安装卡点：

> [!WARNING]
> 如果系统拦截安装并提示「未知来源应用」，需要手动开启权限。不同品牌手机的入口略有差异：
>
> - **原生 Android**：设置 → 安全 → 安装未知应用 → 找到你的文件管理器或浏览器 → 允许
> - **小米/红米**：设置 → 隐私保护 → 特殊权限设置 → 安装未知应用
> - **华为/荣耀**：设置 → 生物识别和密码 → 安装未知应用

开权限后重新点安装包就能正常装了。整个过程对手机没有安全风险——这个权限的含义只是"允许从应用商店之外的渠道安装"。

### 装完怎么核对

打开 app 能正常进入首页、看到榜单和帖子列表，说明安装成功。如果闪退或白屏，先确认系统版本是否满足最低要求，不行就换一个下载渠道重新装。

## 📖 使用入门

### 浏览与试听（免登录）

HiFiNi 的浏览体验对访客非常友好——不登录也能完整浏览帖子、试听音频、看榜单。社区刻意把"听"和"参与"分成了两道门槛：耳朵可以直接进，伸手互动才需要账号。这让第一次来的用户没什么压力，刷几分钟榜单就能大概知道社区里在流行什么。

### 注册与登录（什么时候需要）

以下动作触发登录墙：

- 回复帖子（含部分帖子回复后可见提取码）
- 每日签到
- 发布自己的资源帖
- 开通 VIP 会员
- 给帖子点赞或获赏金币

注册流程是标准的论坛式注册——在 app 里点进上面任何一个需要登录的功能，系统会自动弹出登录/注册界面。注册后得到一个 UID（个人唯一的用户编号），默认成为普通会员，个人信息卡会显示 UID、积分、主题数、帖子数这些指标。登录后首页角落会出现头像和 UID，侧边栏多出签到、我的积分等入口，回复区域的输入框也会解锁。

### 提取码看不见怎么办

这是 HiFiNi 新用户最常遇到的困惑。帖子下载区域的提取码有三层权限设置，看不见分三种情况：

| 情况 | 表现 | 解决办法 |
| --- | --- | --- |
| VIP 专享 | 提示"VIP 专享，登录后付费解锁" | 开月卡（约 ¥10/30 天）、用金币单次解锁、或换一个帖子搜同一首歌 |
| 回复后可见 | 提示"回复帖子后可见提取码" | 登录账号 → 拉到帖子底部回复区 → 写一句回复（别灌水）→ 刷新页面 |
| 没有下载区域 | 帖子里压根没下载模块 | 大概率是发帖者误操作或违规被处理了，只能换帖 |

正常提取码是 4 位字母数字组合（比如 "8X2A"），出现在网盘链接旁边。解锁后如果 app 还不显示，完全退出再重新打开帖子，一般就能刷出来。

### 用榜单找好歌

HiFiNi 的榜单系统是社区的一大特色，不同榜单适合不同需求：

**日榜**——按当天浏览量排序，是最灵敏的热度指标。想知道"今天社区里大家都在听什么"，直接刷日榜就好。它每天刷新，能捕捉到刚出两三天就爆火的帖子。部分周末发的帖子可能在周一冲上前列。

**周榜**——把时间窗拉长到一周，过滤掉偶发的单帖爆发，留下来的是稳定有人在刷的内容。典型热帖的榜单生命周期是：日榜爆火 → 冲上周榜 → 在月榜停留 → 积累浏览量后进入热门榜长期留存。如果一首歌在这整个链条里都能看到，基本可以确定是社区公认的好资源。日常刷的建议是先看日榜抓新鲜，再切周榜看趋势，日榜刷到的帖子如果能在周榜里再看到，说明确实有稳定热度。

**热听榜**——这是全站曲目级别的热度排行，和最新发布榜、积分榜、发帖达人榜、歌手榜并列。和其他榜单不同的是，热听榜是独立的全站曲目排行页，不受分区限制，直接聚合各分区里浏览量最高的资源帖。能上热听榜前列的帖子，通常有"臻品母带""顶级无损""内嵌封面歌词"这类高规格标注，或者曲目本身是经典热单，也可能出自社区活跃的资源贡献者。

> [!TIP]
> 榜单页顶部可以在多种榜单之间切换，日常养成刷榜单的习惯，比漫无目的地搜歌效率高得多。

### 金币与积分系统

社区有一套金币积分体系，日常签到、回复帖子、发布好资源都能积攒。积分高了可以在积分榜上看到自己的名字，金币则可以用来做单次解锁（比如碰到 VIP 专享的帖子，用金币兑换一次看看值不值）。发帖贡献量大的用户会出现在发帖达人榜上——这对愿意分享的用户是一种正向反馈。

### 常见操作路径

| 想做什么 | 怎么操作 |
| --- | --- |
| 找今天最火的歌 | 首页 → 榜单 → 日榜 |
| 找经典好资源 | 首页 → 榜单 → 热门榜 / 热听榜 |
| 搜特定歌手 | 用搜索框直接搜，或从歌手榜切入 |
| 下载一首歌 | 进帖子 → 看到网盘链接和提取码 → 复制到网盘 app 打开 |
| 发帖分享 | 登录后点发帖入口 → 选分区 → 填标题和内容 → 上传网盘链接 |
