## ✨ PIASCORE 是什么

PIASCORE 是一款面向音乐演奏者的智能乐谱管理与练习助手，核心价值在于把「看谱、练习、标注、调音」这一整套流程装进一台 iPad（或 iPhone）里，不需要再在纸质乐谱、独立节拍器 App、独立调音器 App、录音 App 之间反复切换。

它的主要功能包括：乐谱导入与分类管理、自动翻页与自动滚动、手写标注（画笔/图章/文字/形状）、内置节拍器、内置调音器、录音、虚拟键盘配合练习，以及 Setlist 演出列表管理。

对不同类型的演奏者来说，PIASCORE 的意义略有不同：

- **吉他手、钢琴手、小提琴手**：告别翻谱麻烦，自动滚动配合节拍器能把练习节奏固定下来，长期坚持可渐进提速。
- **管乐演奏者**：演出时用 Setlist 预排好曲目顺序，自动翻页不打断演奏，比纸质乐谱方便太多。
- **音乐老师**：把伴奏音频和乐谱绑定播放，给学生做示范时不用另外接音频设备。
- **练习生和自学者**：手写标注直接画在乐谱上，录音对比反复听，学习曲线大幅缩短。

它在 App Store 上有免费版和完整版两种形态——免费版能看谱、翻页、基本标注，进阶功能（自动滚动、节拍器高级设置、完整版调音器、录音长时段等）需要内购解锁。

## 🔧 安装步骤

PIASCORE 原生支持 iOS 和 iPadOS 平台，安装流程非常简单，但有几个注意事项值得提前了解。

### 下载前的准备

1. **确认设备系统版本**：PIASCORE 对 iPadOS / iOS 版本有最低要求（目前主流版本均可运行）。如果是旧设备，建议先核对应用商店页面的兼容说明再下载。
2. **存储空间预留**：应用本体并不大，但乐谱文件（尤其是带高清图片或 PDF 的大型总谱）会占用额外空间。建议预留 **1~2 GB** 的可用空间，避免导入大量乐谱后存储告急。
3. **了解免费版限制**：免费版能满足看谱、翻页、基本标注，但自动滚动、高级节拍器、完整版调音器、长时段录音等功能需要内购解锁。如果只是偶尔看谱，免费版够用；如果是日常练习主力，完整版性价比更高。

### 安装过程

1. 打开 **App Store**，搜索「Piascore」，找到带官方开发者标识的应用（开发商为 Piascore Inc.）。
2. 点「获取」——由于是免费安装，不需要支付任何费用。
3. 下载安装完成后，点击应用图标启动。
4. 首次启动会弹出隐私权限请求，按提示允许即可。

> [!TIP]
> 麦克风权限**一定要开**——调音器、录音都要用到。如果首次没开，可以在系统设置里手动授权。

### 安装后第一次核对

打开应用后，你会看到**目录（Catalog）界面**——这是默认首页。界面中心是空的（还没导入乐谱），底部有 Tab 栏（Download 是下载入口），左下有 #Tag 标签入口，右下有 Setlist 入口。如果看到的是类似布局，说明安装成功。

> [!WARNING]
> 从第三方渠道下载的 IPA 安装包无法在非越狱 iOS 设备上安装。请始终通过 App Store 正版获取，避免安全风险。

## 📖 使用入门

PIASCORE 的功能面很广，但新手只需抓住两个核心界面（目录界面 + 乐谱视图）和四个高频工具（自动滚动、节拍器、调音器、手写标注），就能覆盖大部分日常场景。下面按「从导入乐谱 → 到练习 → 到调音」的完整链路带你走一遍。

### 两个核心界面速览

PIASCORE 的界面结构非常清晰，几乎所有操作都围绕这两个界面展开：

| 界面 | 入口 | 核心功能 |
| --- | --- | --- |
| 目录（Catalog） | App 默认首页 | 乐谱管理：浏览、搜索、排序、删除、编辑元数据 |
| 乐谱视图 | 点击任意乐谱卡片进入 | 实际看谱 + 所有练习工具：自动滚动、手写标注、节拍器、调音器、录音等 |

目录界面的主体是乐谱卡片（网格视图，默认模式），每张卡片显示封面 + 标题 + 艺术家。右上角齿轮进 Settings，`...` 更多菜单里可以切换网格/列表视图、调整排序方式。

乐谱视图的底部是一组固定工具栏，从左到右依次为：

| 工具 | 功能 |
| --- | --- |
| Page | 翻页布局、动画、自动滚动、页码顺序 |
| Bookmark | 书签、快速跳转 |
| Adjust Page | 页面裁剪、放大、旋转 |
| Writing | 手写标注：画笔、图章、文字、形状、橡皮擦 |
| Info | 乐谱元数据编辑、导出 |

左侧工具栏（触摸屏幕时弹出）是音乐工具箱，包含节拍器、调音器、虚拟键盘、录音、音乐播放器、视频六项，这些工具可以在后台运行，不会中断看谱。

### 乐谱管理：让目录不凌乱

随着乐谱越积越多，合理管理很重要。PIASCORE 提供了三层组织方式：

**标签（Tag）分类**：给重要乐谱打标签，比如「古典」「流行」「练习曲」「演出曲目」。目录界面左下角的 #Tag 入口可以按标签筛选，比单纯靠搜索高效得多。

**Setlist 演出列表**：排练或演出前，用 Setlist 把曲目按实际演奏顺序排好。每个 Setlist 可以独立设置、独立练习，演出时直接切换 Setlist 就能进入对应曲目，非常方便。

**定期清理**：已经练完、不再需要的曲子可以删掉——注意 PIASCORE 本身不支持撤销删除，但只要有原始文件或云备份，随时可以重新导入。

> [!NOTE]
> 导入乐谱后，建议立即修正标题和艺术家信息——很多 PDF 自带的元数据可能不准确，改一下后续搜索和排序会省心很多。

### 节拍器：内置 = 不用切 App

PIASCORE 内置节拍器的最大优势是**和乐谱同在一个界面**——不用切走 App 就能打拍子，而且可以和自动滚动配合，两者同步运行。

#### 启动与设置

在乐谱视图里，触摸屏幕让左侧工具栏弹出，点节拍器图标就能启动。设置 BPM（每分钟节拍数）有三种方式：

| 方式 | 精度 | 适用场景 |
| --- | --- | --- |
| 拖动滑块 | 粗略 | 快速找到大概速度 |
| 数字输入 | 精确 | 已知目标 BPM 时直接输入 |
| 从乐谱自动识别 | 依赖乐谱质量 | 部分 PDF 的速度标记（如 ♩ = 120）能自动读取 |

节奏模式支持 4/4、3/4、2/4、6/8 等，还可以把第一拍设成**不同的声音**（比如「叮」 vs 普通「哒」），更容易找准小节边界。

#### 与自动滚动配合的三个典型场景

**场景一：日常练习定速**

1. 启动节拍器，调到目标 BPM
2. 启动自动滚动
3. 微调滚动速度，让乐谱滚动节奏刚好贴合节拍器
4. 这样每次练习速度一致，便于渐进提升

**场景二：渐进提速练习**

1. 从较慢的 BPM 开始（比如目标速度的 60%）
2. 练熟后逐步调高 BPM，每次调 5~10
3. 每调一次，自动滚动也要同步调速
4. 直到达到目标速度

**场景三：段落速度变化**

有些曲目中间速度会变（慢-快-慢），可以用 Setlist 把不同速度的段落分开设好 BPM 和滚动速度，排练时预演一遍记住切换点。

> [!WARNING]
> 演出中**绝对不要**开除节拍器——演出用的是提前调好速度的自动滚动，节拍器只在排练时用。

### 调音器：看谱间隙随手调

内置调音器的优势和节拍器类似——不用切 App，看谱间隙就能校准音准。

#### 覆盖音域

PIASCORE 调音器覆盖 **E1 到 A8**，几乎所有常见乐器都能覆盖：

| 乐器 | 用到的音域 |
| --- | --- |
| 钢琴 | A0-C8 |
| 吉他 | E2-E4 |
| 小提琴 | G3-A7 |
| 长笛 | C4-D7 |
| 大提琴 | C2-E6 |

音阶制式支持平均律（最常用，钢琴/吉他默认）、纯律（小提琴/大提琴更贴近自然）、Kirnberger III（巴洛克古乐）等，不确定选哪个就用平均律。

#### 调音基本步骤

1. 启动调音器，iPad 麦克风对准乐器声源
2. 依次弹要调的音（比如吉他从 E6 → A5 → D5 → G4 → B4 → E4）
3. 看仪表指针：左偏 = 音偏低（松弦），右偏 = 音偏高（紧弦），中间绿色区域 = 完成
4. 每个琴弦调完再拨一下，确认稳定在中间

#### 麦克风建议

- 对准音孔（吉他）或琴马附近（小提琴）
- 关掉风扇、空调等噪音源
- 距离约 30~50 厘米效果最佳
- 户外风大时，用 iPad 朝向乐器背面的麦克风

### 手写标注：画在乐谱上的思考

Writing 工具是很多 PIASCORE 用户最常用的功能之一——直接在乐谱 PDF 上手绘标注，比在纸质乐谱上写了擦、擦了写方便得多。

可用的标注类型包括：**画笔**（自由手绘线条）、**图章**（常用符号如强弱记号、重复记号）、**文字**（输入简短文字说明）、**形状**（矩形、圆形、箭头）、**橡皮擦**。每个元素都可以独立移动、缩放、删除，标注完的乐谱可以导出 PDF 留存。

### 对比总结

PIASCORE 内置的功能和独立 App 各有优劣，简单对比一下：

| 维度 | PIASCORE 内置 | 独立 App |
| --- | --- | --- |
| 节拍器精度 | 够用 | 更高，支持 subdivision |
| 调音器精度 | 够用 | 更高，有频谱视图 |
| 便捷性 | 不用切 App，看谱+练习三位一体 | 需要切换 App |
| 价格 | 完整版内购包含 | 免费/付费各有 |
| 专业功能 | 基础够用 | 更完善 |

日常练习用 PIASCORE 内置工具完全足够；如果需要极其精确的调音、复杂的节奏循环练习，可以先用专业独立 App 练熟，练的时候用 PIASCORE 看谱。
