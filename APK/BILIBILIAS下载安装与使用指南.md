## ✨ BILIBILIAS 是什么

BILIBILIAS 是一款专注于 B 站视频解析与离线缓存的开源工具，运行在 Android 平台。它的核心能力很明确——从 B 站接口拉取视频的音视频流，然后把它们以可管理的方式存到本地设备上，方便在没有网络的场合回看。和 B 站 App 自带的离线缓存相比，BILIBILIAS 提供了更灵活的解析入口（分享链接、BV 号、UP 主 UID 多种方式）、更细粒度的画质选择，以及对番剧合集、UP 主批量投稿等场景的专门支持。

关于这款工具，最容易产生误解的一点需要先说明白：**BILIBILIAS 不做任何付费权益绕过**。它调用的完全是你自己的 B 站账户能拿到的接口资源——你用 B 站 App 看视频时能选到的最高画质是什么，在 BILIBILIAS 里能缓存到的上限就是什么。未登录默认 480P，普通账户 1080P，大会员才能拿到 4K 乃至 HDR。工具本身不解锁任何东西，只是帮你把已经有权限观看的内容存到本地。

BILIBILIAS 的版本迭代经历过一次架构级的升级：1.x 系列最后停在 1.1.5，和 2.x/3.x 使用完全不同的数据模型与存储路径，主维护者明确不支持就地覆盖安装升级，老用户需要先备份再卸载重装。2.1.5 版本引入了可选登录机制，之后不登录也能使用基础解析和缓存功能，只是画质上限受限。当前主流使用的是 2.x 和 3.x 系列。

这款工具适合三类用户：经常需要离线看 B 站内容的通勤党；希望系统收藏和管理学习视频素材的创作者或学生；以及关注某些 UP 主、想批量缓存其投稿的观众。如果你只是偶尔看看视频，B 站 App 自带的离线缓存已经够用；但如果你对画质、组织方式有更高要求，BILIBILIAS 能补上这块空缺。

## 🔧 安装与首次启动

BILIBILIAS 是 Android 应用，安装流程和大多数第三方 APK 一致。下面按顺序说明整个过程，包括老版本迁移的特殊情况。

### 新安装步骤

1. 从下载入口获取最新版 APK 文件，确认文件大小和版本号与下载页面标注一致。
2. 在手机上打开文件管理器找到 APK，点击安装。如果弹出「未知来源」警告，需要在系统设置中允许当前文件管理器或浏览器的安装权限。不同品牌手机的设置入口略有差异，通常在「安全」或「隐私」分类下。
3. 安装完成后首次启动，应用会依次请求存储权限、网络权限等必要授权，全部确认即可。

> [!NOTE]
> 部分国产 ROM 的权限管理更严格，首次启动后如果发现缓存的视频保存不到预期路径，检查一下应用是否被禁止了写入外部存储的权限。

### 从 1.x 旧版本迁移

1.x 版本（应用名可能带空格显示为「BILIBILI AS」）无法就地升级到 2.x/3.x，必须完整走一遍备份 → 卸载 → 重装 → 迁移的流程：

1. **备份下载文件**：打开文件管理器，找到旧版的存储路径（常见位置是 `内部存储/Download/BILIBILIAS/` 或 `Android/data/包名/files/`），把整个文件夹复制到一个安全的临时位置。
2. **清除数据并卸载**：在系统设置 → 应用管理中找到旧版，先点「清除数据」，再点「卸载」，确保不留残留。
3. **安装新版本**：按新安装步骤装上 2.x 或 3.x，首次启动授予必要权限。
4. **找回旧文件**：新版本默认存储路径是 `Download/BILIBILIAS`，把之前备份的文件夹拷贝到这里即可。注意新版本不会自动扫描识别旧文件，可能需要在应用内手动重新解析对应视频的 BV 号来确认关联。

> [!WARNING]
> 1.1.5 是 1.x 的最后版本，已不再维护，存在已知 Bug 和安全问题。如果你还在用 1.x，建议尽快完成迁移，不要停留在旧版上。

## 📖 使用入门

### 核心操作：分享链接粘贴解析

这是 BILIBILIAS 最通用的解析方式，适用于绝大多数场景。无论你是从 B 站官方 App、浏览器还是其他任何地方拿到的视频链接，只要粘贴进去就能自动识别。

操作很简单：在 B 站 App 中打开视频或番剧页面，点右下角的分享按钮，选择「复制链接」。复制下来的可能是短链接（`b23.tv/xxxxxx`），也可能是 B 站标准的「标题 + 短链」完整文案，两种 BILIBILIAS 都能正确解析。回到 BILIBILIAS 的工具页面，在顶部输入框里长按粘贴——粘贴完成的瞬间就会自动解析，不需要点任何额外按钮。解析成功后，输入框下方会出现视频卡片，展示封面、标题、UP 主、时长、分 P 数等信息；如果是番剧还会显示当前集数和总集数。

解析失败时，先排查三个常见原因：复制的内容里是否真的包含 `b23.tv` 或 `bilibili.com` 字样；手机网络是否正常（解析需要联网访问 B 站接口）；极少数情况下 B 站短链接会过期，直接粘贴完整长链接重试即可。

### 画质选择与账户权益

BILIBILIAS 不绕过 B 站的付费墙，调用的完全是你自己账户能拿到的接口。画质上限和账户权益的对应关系非常直接：

| 账户状态 | BILIBILIAS 最高画质 |
| --- | --- |
| 未登录 | 480P（部分视频可能更低） |
| 已登录普通用户 | 1080P（视频本身提供时） |
| B 站大会员 | 4K / HDR / 杜比视界（视频本身提供时） |

有两个细节值得留意。第一，4K 视频体积很大，几分钟片段就可能超过 1GB，缓存前确认设备存储空间充足。第二，即便你是大会员，某些视频因为版权原因本身就不提供 4K 选项，这种情况下 BILIBILIAS 的画质选择里也不会出现 4K——这是 B 站后端的限制，不是 BILIBILIAS 的问题。

如果不慎选了超出自己权益的画质（这种情况很少见，因为 UI 只会显示你实际能拿到的选项），BILIBILIAS 会自动降级到账户实际可获取的最高清晰度，降级发生在 B 站接口返回层面，不是工具刻意为之。

### UP 主主页解析

除了单个视频，BILIBILIAS 还能解析 UP 主主页，适合批量缓存某位创作者的多条投稿。有两种方式进入：

- **分享链接方式**：在 B 站 App 中打开 UP 主个人主页，点分享复制链接，或直接分享给 BILIBILIAS，工具会自动识别链接中的 UID 并拉取信息。
- **直接输入 UID**：如果你知道 UP 主的数字 UID，在工具页面输入框里直接键入即可，和识别 BV 号一样自动触发解析。

解析成功后进入 UP 主主页页面，可以看到头像、昵称、个性签名、粉丝/关注/获赞/播放量等统计数据，以及该 UP 主的全部投稿列表。这里需要说明的是，BILIBILIAS 的 UP 主主页做了精简，目前只提供头像、签名、数据展示和投稿网格，没有完整复刻 B 站 App 主页的动态、专栏、收藏夹、追番列表等功能。它的定位很聚焦：让你快速了解这位 UP 主是谁、有多少投稿，然后方便地从投稿列表中选择视频进行缓存——配合批量下载功能可以一次性处理多条投稿。如果你需要浏览完整的动态或社区互动，还是应该回到 B 站 App 中查看。
