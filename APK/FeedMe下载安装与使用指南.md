## ✨ FeedMe 是什么

FeedMe 是一款轻量、高效的 RSS 阅读工具，在 Android 平台上积累了大量忠实用户。它的核心定位很明确——把散落在各个网站、博客、公众号里的更新统一收进一个界面，让你不用每天打开十几个 App 就能追踪所有关注的内容源。

FeedMe 支持三种订阅源接入方式：直接添加 RSS/Atom 链接、导入 OPML 清单、或者登录 Feedly、Inoreader、Feedbin 这类云端订阅服务。对于已经在其他 RSS 平台有订阅积累的用户来说，云端账号一键同步的体验尤其省心。

这款应用最被人称道的地方在于它的**同步策略精细化控制**——你可以为每个订阅源单独指定要不要下载图片、要不要抓取 Web 全文，而不是一个开关管到底。配合五种列表布局（极简、摘要、列表、卡片、视觉）和 AI 标题翻译、AI 摘要等智能化功能，FeedMe 既能满足纯文字扫新闻的快节奏需求，也能支撑深度阅读的沉浸式体验。

> [!NOTE]
> FeedMe 主要面向 Android 平台用户，PC 端目前没有原生应用，但可以通过网页版或第三方客户端访问云端订阅数据。

FeedMe 适合三类用户：第一类是每天追几十上百条更新、需要快速筛选的信息猎手；第二类是喜欢深度阅读、想把长文章整篇离线保存的内容爱好者；第三类是同时关注中英文源、需要翻译辅助的双语读者。不管你是 RSS 老玩家还是刚入门的新手，FeedMe 的灵活配置都能适配你的阅读习惯。

## 🔧 安装步骤

FeedMe 的安装过程和大多数 Android 应用类似，但有几个细节值得注意。

### 从应用商店安装（推荐）

1. 打开 Google Play 或国内应用商店
2. 搜索「FeedMe」，找到开发者为「FeedMe Team」的条目
3. 点击安装，等待下载完成后自动安装

> [!WARNING]
> 国内部分应用商店的 FeedMe 版本可能滞后于官方最新版，如果遇到功能缺失或同步问题，建议从官方渠道获取安装包。

### 手动安装 APK

1. 从官方下载页获取最新 APK 文件
2. 将 APK 传输到手机（数据线、云盘均可）
3. 在手机文件管理器中点击 APK，系统会提示「未知来源」授权
4. 进入「设置 → 安全」，允许安装未知来源应用
5. 返回文件管理器重新点击 APK，按提示完成安装

安装完成后，建议立即打开应用检查版本号是否与下载页标注一致，避免装到旧版本。

## 📖 从零开始用好 FeedMe

### 第一次启动：接入你的订阅源

FeedMe 打开后第一件事就是添加订阅。如果你之前用过 Feedly、Inoreader 这类云服务，直接登录是最高效的方式——FeedMe 支持 OAuth 授权，不会保存你的账号密码，只拿短期 token 来同步数据。

以 Feedly 为例，接入流程很简单：在服务列表里选 Feedly → 系统浏览器打开授权页 → 用 Google 或邮箱登录 → 点「授权」→ 浏览器自动跳回 FeedMe，所有分类和订阅源就都进来了。Inoreader 同样支持 OAuth，Feedbin 则用邮箱加密码鉴权。FeedMe 允许同时登录多个不同服务的账号，侧栏里会分别显示，互不干扰。

如果你没有云端账号，也可以直接在 FeedMe 里粘贴 RSS 链接，或者导入之前导出的 OPML 文件。

### 选一个适合你的列表布局

FeedMe 的文章列表页提供了五种布局，覆盖了从「只想扫标题」到「想看图文混排」的各种场景：

| 布局 | 显示内容 | 适合场景 |
| --- | --- | --- |
| 极简 | 仅标题 + 源名 | 每天几十上百条更新、快速筛选 |
| 摘要 | 标题 + 一两行摘要 | 想在列表页就判断值不值得点开 |
| 列表 | 标题 + 较长摘要 + 小缩略图 | 科技博客、新闻站这类偏文字的订阅源 |
| 卡片 | 标题 + 大缩略图 + 摘要 | 图文混排网站、产品评测站 |
| 视觉 | 强调图片的大卡片 | 摄影、设计、产品图站 |

切换方式也很方便：列表页动作条上的「眼睛」图标 → 选「布局」→ 挑一个。或者进设置里设一个全局默认。FeedMe 甚至允许你为**不同订阅源设置不同的默认布局**——Hacker News 用极简、少数派用摘要、Dribbble 用视觉，这样每个源都以最舒服的方式呈现。

### 看懂那个小小的四象限图标

在订阅管理界面，每个类别和订阅源右侧都有一个小图标，它告诉你这个源同步时会不会下载**图片**和**全文**：

- **左半部分**实心 = 下载图片，空心 = 不下
- **右半部分**实心 = 下载全文（Web 页面），空心 = 不下

四种组合对应四种同步策略。为什么要单独设？不是每个源都值得花流量下载。Hacker News 是纯链接聚合，都不下；少数派图文混排长文多，都下载；微信公众号图片多但不一定值得全下，只下全文。这个图标让你不用点开每个源的设置就能一眼看清同步配置。

修改方式有三种：在订阅源设置对话框里单独改、在全局设置里改完一键应用到所有源、或者全局设好默认后对少数特殊源精确调整。完整同步时 FeedMe 会先检查这个图标，再决定下什么内容。

### AI 标题翻译：追英文源不再跳过

FeedMe 内置了 AI 标题翻译功能，对同时追中英文源的用户特别实用。启用后，列表页的每篇文章标题会变成「原标题 (翻译后)」的格式，不用点开文章再让浏览器翻译。

启用需要两步：先在设置 → 服务 → 翻译里配置 AI API Key（和 AI 摘要共用同一套配置），然后在订阅源或类别设置里打开「翻译」开关。你可以在类别级别统一控制，也可以给英文源单独开、中文源关着。

标题翻译和 AI 摘要配合起来效果很好：列表页看「英文标题 (中文翻译)」快速筛选 → 点开有兴趣的看 AI 摘要抓住要点 → 想读完整篇切 Web 读全文。几百条订阅也能高效处理，不会因为「太多英文不想看」跳过好内容。

> [!TIP]
> AI 功能会消耗 API token，如果订阅源多、更新频繁，建议留意 token 用量。翻译质量取决于你用的模型，GPT-4 或 Claude 系列的效果明显优于免费模型。
