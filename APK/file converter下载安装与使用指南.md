## ✨ File Converter 是什么

File Converter 是一款专为安卓设备打造的全能文件转换工具，由 Ice Cold Apps 开发。它覆盖了图像、音频、视频、文档、电子书、标记语言等数十种格式之间的相互转换，让你不用再在手机上装一堆专格式转换器——一个应用搞定日常遇到的绝大多数格式转换需求。

应用的核心特点在于**不挑来源**：除了选择手机本地已有的文件，你还可以直接拍照、录视频、录音、粘贴网页 URL 甚至输入一段纯文字作为转换输入。转换完成后支持一键分享到微信、邮件、网盘，也可以批量处理多个文件。

转换模式上提供云端和离线两种选项：非音视频类转换默认走云端，速度更快且支持更多参数；视频等大文件则可以选择本地离线转换，文件不出手机更省心。整个应用不需要注册账号，打开即用，所有操作流程围绕一个绿色「+」按钮展开——选来源、选格式、开始转换，三步走完。

适合的用户场景非常广泛：学生党转换课件文档、自媒体创作者处理素材格式、办公族把网页保存成 PDF、旅行中把手机录像转成通用格式发给朋友……凡是遇到「这个文件格式打不开/发不出去/不兼容」的情况，File Converter 基本都能派上用场。

## 🔧 安装与首次启动

### 系统要求与安装包信息

在动手安装之前，先确认一下你的设备条件：

| 项目 | 规格 |
| --- | --- |
| 操作系统 | Android 5.2 及以上 |
| 安装包体积 | 约 34.7 MB |
| 所需权限 | 存储读取与写入 |

### 两种安装方式

#### 应用商店安装（推荐）

在 Google Play 或其他安卓应用商店搜索「File Converter」，认准开发者名称是 Ice Cold Apps，点击安装即可自动完成。这种方式最省事，后续还能收到官方推送的版本更新。

#### APK 手动安装

如果从外部渠道获取到 APK 文件，需要先开启「未知来源安装」权限。不同品牌手机的设置路径不一样：

| 手机品牌 | 设置路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 更多设置 → 系统安全 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| OPPO / vivo | 设置 → 安全 → 允许安装未知来源应用 |
| 三星 | 设置 → 生物识别与安全 → 其他安全设置 → 安装未知应用 |

设置完成后点击 APK 文件，确认安装等待进度条走完即可。

> [!WARNING] 安装包体积核对
> 下载的 APK 理论大小应在 34MB 左右，建议用文件管理器核对一下实际体积，避免下载到损坏或篡改过的安装包。

### 首次启动的两个关键点

安装完成后打开应用，你需要处理两件事：

1. **授予存储权限**：第一次启动会弹窗请求存储读写权限，必须点击「允许」，否则应用无法读取待转换的文件，也无法保存转换结果
2. **语言切换**：应用默认跟随系统语言。如果看到全英文界面，可以在顶部菜单中找到语言选项，切换到中文（简体）

> [!TIP] 不需要注册账号
> File Converter 不强制要求登录或绑定手机号，打开即用，注册是完全可选的操作。

### 快速验证链路通畅

权限授予后建议立刻跑一个简单的转换测试：

1. 从文件管理器找一张几十 KB 的小图片
2. 打开 File Converter，点右下角绿色「+」按钮
3. 选择「文件」→ 选中那张图片
4. 进入「图像转换器」→ 随便选一个目标格式（比如 PNG → JPG）
5. 点击「start conversion」

顺利完成转换 = 整条链路通畅。如果中间报错，多半是权限没给全，回到系统设置检查一下。

## 📖 使用入门：从第一次转换到进阶技巧

### 完整转换流程（手把手）

整个转换操作围绕右下角那个绿色「+」按钮展开，五步法走通：

**第一步：选择输入来源**

点「+」之后会弹出菜单，最常用的是「文件」选项，直接浏览手机存储找到目标文件即可。选完后界面底部会出现一条绿色预览条，显示文件名、格式和大小——这就是即将被转换的输入源。

**第二步：选择目标格式**

点击主界面中央的分类标签（图像转换器、视频转换器、文档转换器等），进入后看到该类别下所有支持的输出格式列表。找到你想要的格式直接点选即可。

**第三步：确认转换摘要**

选择格式后进入转换摘要页，这里展示三个关键信息：
- **Input**：源文件的名称和大小，快速核对有没有选错
- **Output → Settings**：输出参数设置（可选，默认值通常够用）
- **Conversion**：转换方式——云端图标表示走服务器处理，手机图标表示本地离线转换

**第四步：开始转换**

点击底部绿色的「start conversion」按钮，进入进度页。圆形进度条会实时显示百分比，想随时取消就点红色「cancel」。

**第五步：获取结果**

转换完成后自动跳到结果页，会展示：

| 可用操作 | 说明 |
| --- | --- |
| SHARE | 通过系统分享菜单发到微信、邮件、网盘 |
| EMAIL | 直接通过邮件发送 |
| Convert | 继续把同一个文件转成其他格式 |
| Save as | 自定义保存路径和文件名 |
| Rename | 重命名输出文件 |
| Delete | 删除这个转换结果 |

> [!NOTE] 历史结果去哪找
> 所有转换结果都会保存到应用内部的「已转换」列表中，随时可以打开查看或再次分享。也可以在设置中修改默认保存路径。

### 不止一种文件来源

File Converter 的输入方式远不止「选本地文件」这一种。点「+」按钮可以看到多种来源选项：

| 输入方式 | 自动进入的转换器 | 适合场景 |
| --- | --- | --- |
| 本地文件 | 取决于文件类型 | 已有文件的格式转换 |
| 拍照 | 图像转换器 | 拍文档页直接转 PDF 或 OCR |
| 录视频 | 视频转换器 | 现场录像后转通用格式 |
| 录制音频 | 音频转换器 | 录音后压缩成 MP3 |
| 从网址转换 | 文件转换器 | 保存网页为 PDF / Markdown |
| 从文字转换 | 文件转换器 / 标记转换器 | 文字转语音、生成 Markdown |
| 多选 | 同类别批量 | 一次处理多个同类型文件 |
| 网络服务器 | 取决于文件类型 | 从 WebDAV / NAS 远程拉取 |

其中比较实用的几个：

**从网址转换**：粘贴一个网页 URL，应用会下载页面并转换成 PDF、DOCX 或 Markdown。适合收藏文章、保存网页资料等场景。需要注意的是部分网站可能屏蔽自动访问，带登录态的动态页面可能无法正确抓取。

**从文字转换**：输入一段纯文字，可以直接合成 WAV/MP3 音频（TTS 文字转语音）、排版成 Markdown/HTML、或者生成 EPUB 电子书。做有声书或快速生成结构化文档很方便。

**多选批量转换**：一次挑 5-10 个文件排队转换，适合成批处理照片压缩或文档格式统一。批量模式下等待时间会随着文件数量和体积线性增长，建议不要一次塞太多。

### 视频转换进阶

视频转换器支持的输出格式非常全面，覆盖了从通用 MP4 到专业 MKV 的十一种格式：

| 格式 | 典型用途 |
| --- | --- |
| MP4 | **最通用**，手机/电脑/电视全兼容 |
| WebM | **网页视频首选**，HTML5 原生支持 |
| MKV | 开源容器，支持多音轨和字幕 |
| MOV | 苹果 QuickTime 原生格式 |
| AVI | 经典 PC 视频格式 |
| WMV / FLV / 3GP / 3G2 / MPEG / OGV / DPG | 各种历史或专用场景 |

选择格式时可以参考这个建议表：

| 场景 | 推荐格式 | 理由 |
| --- | --- | --- |
| 发给任何人任何设备 | MP4 | 兼容性无死角 |
| 上传到网页 / 公众号 | WebM | 体积小，HTML5 原生支持 |
| 高清无损存档 | MKV | 开源多轨道，方便后期编辑 |
| 仅苹果生态内分享 | MOV | 原生支持 AirPlay |

### 体积优化实操

视频文件动辄几百 MB 甚至上 GB，转换时调几个参数就能大幅压缩体积：

| 参数 | 优化效果 | 注意事项 |
| --- | --- | --- |
| 编码器 H.264 → H.265 | 体积减 30%-50% | H.265 兼容性略差，老设备可能无法播放 |
| 分辨率 4K → 1080P | 体积减 75% | 肉眼在手机上看不出区别 |
| 帧率 60fps → 30fps | 体积减半 | 动作类视频可能略显不流畅 |
| 音频码率 128K → 64K | 音频体积减半 | 音质有细微损失 |
| 视频码率调低 | 按比例缩小 | 过低会出现画面马赛克 |

> [!TIP] DRM 视频无法转换
| Netflix、爱奇艺、腾讯视频等平台的离线缓存文件带有 DRM 保护，任何合法转换器都无法处理，这是行业共同限制。

### 云端 vs 离线模式

转换摘要页的 Conversion 区域可以切换转换方式：

| 模式 | 图标 | 特点 |
| --- | --- | --- |
| 离线本地 | 手机图标 | 文件不出手机，速度取决于手机 CPU 性能 |
| 云端 | 云图标 | 上传到服务器处理，速度更快，支持更多参数 |

日常使用中非音视频类转换默认走云端，体验更流畅。视频大文件如果担心网络或隐私，可以切到离线模式让应用在本地处理。

### 常见问题排查

**选完文件点格式没反应**：File Converter 需要存储权限才能读取文件。去系统设置 → 应用 → File Converter → 权限，确认存储权限已授予。

**转换中一直卡住不动**：非音视频转换需要稳定的网络连接。先检查 Wi-Fi 或移动数据是否正常，公司或校园网络可能屏蔽了外部请求，试着切换手机流量再试。

**转换完成找不到结果**：结果默认保存在应用专属目录，侧栏「已转换」里能看到全部历史记录。也可以在设置中修改默认保存路径到你熟悉的位置。
