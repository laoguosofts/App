## ✨ PikPak 是什么

PikPak 是一款主打云下载与在线播放的网盘工具，核心卖点在于把磁力链、种子文件这类 P2P 资源的"搬运"工作挪到云端完成，用户拿到的是一个已经下载好的、可以直接在线预览的云盘文件。对影视追剧者、Telegram 频道重度用户来说，它解决的是本地下载慢、BT 种子经常断种的老问题。

产品覆盖 Android、Windows、macOS 和网页端，多端同步文件；PC 客户端的播放器支持音频、视频、图片混合在线预览，浏览器扩展可以一键把网页资源收入云盘。免费账户提供 6GB 空间和基础速度，会员档约 10TB 空间、更快的下载速度，并解锁 WebDAV、在线解压等进阶功能。

适合哪些人用？如果你经常需要保存网页上的资源链接、追剧时不想等本地下载、或者手头有大量需要整理的媒体文件，PikPak 这套云中转的思路会比传统网盘的"手动上传/下载"路径更省力。

## 🔧 安装指南

### Android 手机端

1. 从下载入口获取 APK 安装包，保存到手机本地。
2. 如果是 Chrome 浏览器直接下载的，系统会弹出安装提示；如果是第三方文件管理器，找到 APK 文件点开即可。
3. 首次安装可能需要授权"允许安装未知来源应用"——不同品牌手机的入口位置略有差异，一般在设置 → 安全 / 隐私 相关分区里。

> [!WARNING]
> 部分国产 ROM 会在点开 APK 时额外弹出安全扫描提示，选择"继续安装 / 允许本次安装"即可，不是安装包有问题。

### Windows 与 macOS 电脑端

1. 访问下载入口，选择对应的系统版本（Windows 64 位 / macOS Intel / macOS Apple Silicon）。
2. 下载完成后双击安装程序，按向导一路下一步：选择安装目录、确认协议、等待进度条走完。
3. macOS 首次打开时若提示"来自未知开发者"，右键点击应用图标 → 打开，系统会给出二次确认弹窗，点"打开"即可。

### 浏览器扩展

PC 端最顺手的额外入口是官方浏览器扩展，Chrome 和 Edge 用户都可以在各自的扩展商店里搜索安装。装好之后，网页里凡是可下载的资源链接旁边都会多出一个云盘小图标——不用复制链接、不用打开新标签页，点一下就直接存进云盘。

## 📖 核心使用技巧

### 混合播放：不退出播放器切内容

Windows 与 macOS 客户端的播放器从 2.3.2 版本起支持多媒体混合播放体系，键盘方向键是它的主轴。播放音频时，用方向键直接切到下一个视频或图片文件，画面无缝衔接——适合边听讲座音频边翻配图资料，或者追剧时随手切换下一集。

视频、音频、图片三类文件的在线预览可以混合进行，播放器右上角的"更多"按钮还提供三种画面适配模式：

| 模式 | 效果 | 适用场景 |
| --- | --- | --- |
| 适合内容 | 完整显示画面，留黑边 | 宽高比常规的电影、短视频 |
| 保持内容长度 | 以宽度为准铺满 | 老电影（窄幅画面） |
| 保持宽度 | 以高度为准铺满 | 竖屏视频 |

快捷键习惯上，方向键控制进度与切换单元；图片场景下滚轮缩放、双击或点击三次放大查看细节。

### 浏览器扩展：网页资源一键收入云盘

桌面端刷网页时，扩展会自动扫描当前页面，标出其中的资源链接和可下载媒体。遇到想保存的东西，点链接旁的云盘图标——或者点开扩展弹窗里的添加按钮——资源就加入你的云盘任务了。

扩展做不到的场景也要有预期：它识别的是页面公开呈现的链接，动态加载内容或需要登录权限的资源可能抓不到。而且保存的任务同样消耗云盘空间与每月传输配额，别当成"无限免费"的收集箱。

### 误删了文件怎么办：回收站恢复

删除操作不会立即销毁文件，回收站作为缓冲区给手滑和误判留了退路。恢复流程很简单：进入"我的"页面打开回收站 → 找到误删的文件或文件夹 → 点还原。文件会回到云盘，在文件列表里可以确认。

但有两个容易被忽略的细节：

> [!NOTE]
> 从文件查重、最近添加这类聚合视图里批量删除的文件，还原后不一定逐个回到原父目录，可能集中出现在某个位置。大量整理请养成先进具体文件夹再操作的习惯。
>
> 回收站里的文件通常仍占用云盘空间——空间告急时清空回收站是常用的腾地方手段，别以为"删到回收站就不占空间"。

好的删除习惯能省掉不少恢复的麻烦：批量删除前先核对选择列表，聚合视图里的多选尤其容易带上不想要的文件；重要资料可以先转存一份到保险库；定期整理比攒到堆积后大扫除更不容易误删。

## 📊 免费与会员怎么选

两档差异集中在空间、速度与专属功能三块，按官方 2025 年 9 月公告的规则对比如下：

| 项目 | 免费 / 区域会员 | 全球 Premium |
| --- | --- | --- |
| 云盘空间 | 6GB | 约 10TB |
| 基准下载速度 | 8MB/s | 20MB/s |
| 超配额后实际上限 | 10MB/s | 25MB/s |
| WebDAV 接入 | ✗ | ✓ |
| 在线解压文件 | ✗ | ✓ |
| 移除广告 | ✗ | ✓ |
| 云下载次数 | 有上限 | 无限 |

免费账户的 6GB 够跑通流程、存少量文件，但对影视收藏者来说远远不够——官方称 10TB 空间可容纳约 8000 个视频文件，这才是这款产品的完整形态。

决策建议：轻量尝鲜、偶尔存点东西，免费够用；长期收藏、影视追剧、TG 资源重度用户，10TB 空间与更大的配额才值得花那个钱。
