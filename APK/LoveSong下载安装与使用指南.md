## ✨ LoveSong 是什么

LoveSong 是一款面向演唱会应援场景的移动端工具 App，由粉丝后援会联合开发，定位是"粉丝应援的贴身助手"。它把传统应援现场分散的几件事整合到了一个应用里：实时查看官方公告和应援指南、蓝牙连接智能灯牌和 mini 灯箱、扫码收集演出限定印章、以及未来规划中的粉丝社区。

App 目前处于内测阶段，已发布的版本覆盖核心功能四件套：公告推送、应援物管理、蓝牙连接、印章打卡。界面走的是简洁实用路线，没有花里胡哨的功能堆砌，重点放在现场稳定性和操作效率上——毕竟演唱会现场时间紧、干扰多，能少点一步是一步。

LoveSong 的主要用户群是经常跟演出跑的核心粉丝和后援会成员，尤其适合需要协调应援动作、收集纪念印章的场景。普通观众也能用来看公告和扫印章，但蓝牙连灯牌这类功能更偏向有应援物的用户。

## 🔧 安装与权限配置

LoveSong 目前主要支持 Android 平台，iOS 版本需关注官方后续公告。安装过程和普通 App 类似，但有几个关键步骤不能跳过。

### 基础安装

1. 从官方下载页获取安装包（APK 文件）
2. 如果是首次安装非应用商店来源的 APK，需要在系统设置里授予"未知来源"安装权限：
   - **小米 / 红米**：设置 → 隐私保护 → 特殊权限设置 → 安装未知应用 → 找到浏览器或下载工具 → 允许
   - **OPPO / vivo**：设置 → 安全 → 允许安装未知来源应用
   - **华为 / 荣耀**：设置 → 安全 → 更多安全设置 → 未知来源应用下载
3. 点击安装包，按提示完成安装

> [!TIP]
> 安装完成后先别急着打开，建议再做两件事：**授予位置权限**和**加入后台白名单**。蓝牙扫描在 Android 12+ 上需要位置权限辅助定位搜索，不给的话可能搜不到灯牌。

### 首次打开的权限请求

第一次启动 LoveSong 会依次请求几项权限：

| 权限 | 是否必须 | 说明 |
|------|----------|------|
| 蓝牙 | 必须 | 连接灯牌和 mini 灯箱的核心权限 |
| 位置 | 必须 | Android 12+ 的蓝牙扫描依赖位置权限 |
| 通知 | 推荐 | 接收公告推送，建议允许 |
| 相机 | 按需 | 扫码收集印章时需要 |

### 加入后台白名单（演出前必做）

部分安卓手机系统会在后台自动杀 LoveSong 进程来省内存或省电——**演出中途被系统杀死 = 蓝牙断连 = 灯牌失控**。出发前在家就要把白名单配好：

- **小米 / 红米**：设置 → 应用设置 → 应用管理 → LoveSong → 省电策略 → 无限制；自启动 → 允许
- **OPPO / vivo**：设置 → 电池 → 后台管理 → LoveSong → 允许后台运行；启动管理 → 允许自启动
- **华为 / 荣耀**：设置 → 电池 → 省电模式 → 关闭；设置 → 应用和服务 → 应用启动管理 → LoveSong → 自动管理关闭，手动管理里三项都勾上
- **三星**：One UI 默认不杀后台，确认 LoveSong 没被省电限制即可

## 📖 核心功能使用详解

### 蓝牙连接灯牌：从配对到稳定控制

蓝牙连接是 LoveSong 最核心也最容易出问题的功能。理解几个关键概念能让你的应援顺畅很多。

**先搞清楚：灯牌能亮 ≠ 电量够连接。** 很多人以为灯牌亮着就是电量充足，但蓝牙低功耗搜索和连接需要比单纯点亮 LED 更高的电压和电流。电压不够时灯牌可能勉强亮着，但蓝牙芯片起不来——这就是为什么"连不上"的排查清单里，换新电池永远排第一位。

连接的基本流程很简单：打开 LoveSong → 打开手机蓝牙和位置 → 按下灯牌配对键（通常是长按某个按钮直到指示灯闪烁）→ 回到 App 点击"搜索设备" → 在列表里选中你的灯牌 → 等待连接成功。连接成功后就能在 App 里改文字、切颜色、调亮度。

#### 演出中途蓝牙断连怎么办

断连的表现是灯牌突然停在最后一次设置的内容上不变了，App 蓝牙状态从 Connected 变成 Not Connected。常见原因有四类：

**场馆内 2.4 GHz 频段干扰**。演唱会现场无线麦克风、专业灯光控制器、观众的充电宝和无线耳机都在抢这个频段。对策：手机和灯牌尽量保持半米以内（贴着放），手机放在身前口袋不要塞进金属背包，身体不要挡在手机和灯牌之间。

**手机被系统杀后台**。这是出发前没配白名单的后果。临时救急可以回到手机任务管理界面，把 LoveSong 下拉加锁（锁定后不会被清理），或者临时关闭省电模式。

**灯牌电量不足**。蓝牙连接比单纯亮灯更耗电，演出中途灯牌电量不够时蓝牙芯片会先停。对策：出发前换新电池、带一组备用电池、灯牌调到较暗的亮度（如果支持）。

**手机蓝牙缓存错乱**。系统蓝牙长期运行可能出现缓存问题。最简单的修复：蓝牙开关关一下再开（不用重启手机），回到 LoveSong 重新连接。

> [!NOTE]
> 最坏情况的自救：灯牌断连时**不要慌**——它会保持最后一次的颜色和文字，不会突然熄灭。手动挥棒比急着排查更重要。中场休息或安可前再快速排一次，那时候人少了、干扰也小了。如果一直连不上，当作"手动应援"，手动挥灯牌的仪式感一样拉满。

#### 电池管理要点

出发前对照这个清单检查，能减少现场 80% 的连接问题：

**灯牌侧：**
- 有足够电量（干电池换新的，锂电充满）
- 能正常开机、进入配对模式
- 连接后灯珠能正常亮

**手机侧：**
- 电量 50% 以上（蓝牙持续耗电，建议带充电宝）
- 蓝牙和位置权限已授予
- LoveSong 已加入后台白名单

不同类型灯牌的电池注意点：干电池款的应援棒出发前换新最稳；内置锂电款提前充满、带充电宝以防万一；USB 供电的 mini 灯箱直接接充电宝，比电池稳定。

中途断电的应急处理：如果能快速换电池就换（安检不会拦备用电池）；不能换的话把灯棒拿到电池仓位置晃一晃，有时电池接触不良晃晃就能短暂恢复；最坏情况当作"安静应援"，别影响周围人。

延长续航的小技巧：不用蓝牙连接时可以关掉手机蓝牙（灯棒电量和蓝牙连接是分开的）；灯棒调到较暗的亮度省电；中场休息关掉灯棒能省不少电。

### 印章收集：扫码打卡的那些事

印章打卡是 LoveSong 的另一个常用功能——演出现场会有多个限定印章点位，用 App 扫二维码就能收集。常见问题包括：扫了码没入账、不在有效范围内、定位不准。

遇到印章相关问题的排查思路：首先确认自己在有效打卡范围内（通常是距离点位十几米内）；然后检查定位权限是否正常、GPS 信号是否稳定；如果还是没入账，看看有没有最新公告提到服务器维护或印章临时调整。

> [!WARNING]
> 印章入账延迟比较常见，现场人多的时候服务器压力大，扫码后等个 1~2 分钟再刷新看看，不要反复扫同一个码。

### 公告与内置 FAQ：遇到问题先自查

设置页里有一个内置 FAQ 入口，排在历史绑定之后、蓝牙设置之前的位置。后援会把常见问题自查放在显眼位置，说明内测阶段确实会遇到各种问题。

正确的问题排查顺序是：**先看内置 FAQ**（都是针对 LoveSong 具体问题的答案，比搜索引擎搜"安卓蓝牙连不上"效率高得多）→ **再看最新公告**（有没有临时通知如"服务器维护""印章点位调整"）→ **最后找现场工作人员**（如果是开场前连不上灯牌这类紧急问题，现场工作人员可能知道是否是批量问题）。

FAQ 的覆盖范围包括：蓝牙连接问题（搜不到灯牌、频繁断开、位置权限没给会怎样）、印章打卡问题（扫了没入账、定位不准）、账号相关（注册登录、换手机数据还在不在）、以及闪退、功能入口找不到、版本更新等常见问题。内测阶段 FAQ 会随着新版本持续补充，每次更新后建议过一遍。

### 粉丝社区：规划中的功能

LoveSong 的产品定位从最早的"应援工具"逐步扩展到粉丝生态。后援会在规划里提到了粉丝社区方向：让粉丝有一个集中的线上聚集地、留言打榜的互动载体、以及影音资源的整合平台。

社区功能目前处于规划阶段，已发布版本未开放。它不会替代微博、微信群、B站等现有渠道，定位更像是官方背书的集中入口——内容有一定权威性、粉丝之间可以站内互动、并且会和 LoveSong 的其他功能打通（比如在社区里晒印章收集进度、晒应援棒）。

为什么现在不急着开社区？因为社区需要大量运营投入——审核内容、管理板块、处理纠纷、保持活跃度。后援会目前优先把工具属性的核心功能打磨好，社区等基础稳定了再开。
