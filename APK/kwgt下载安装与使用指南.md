## ✨ KWGT 是什么

KWGT（全称 Kustom Widget）是一款专为 Android 设备设计的小组件自定义工具，由 Kustom Industries 开发维护。与系统自带小组件不同，KWGT 给了用户近乎完全自由的设计权限——从最基础的时钟、天气面板，到功能丰富的仪表盘、音乐控制器、Home Assistant 智能家居面板，只要有想法就能做出来。

它的核心机制分为两层：一是**元素编辑系统**，画布上可以放置文字、形状、图片、进度条、圆弧等基础元素，每个元素的大小、位置、颜色、透明度都能精确控制；二是**函数引擎**，内置了上百个读取系统信息的函数（电池电量、CPU 使用率、日历日程、天文数据、运动健康等），支持条件判断、数学运算、字符串处理，让小组件具备动态响应能力。

KWGT 与同系列的 KLWP（动态壁纸）和 KLCK（锁屏）共同组成 Kustom 三件套，三者之间可以共享全局变量（Globals），实现从锁屏到壁纸再到桌面的统一风格和条件联动——比如手机到家时，锁屏显示欢迎语、壁纸切换暖色调、桌面小组件上的家居控制按钮自动亮起，这一切由一个 Global 变量驱动，改一处就全站生效。

KWGT 有免费版和付费的 Pro Key 两个版本。免费版可以创建和编辑预设，也能加载官方 Featured Pack；Pro Key 解锁了第三方 Pack 皮肤包加载、高级函数、自定义字体等进阶能力，对于想深度使用或安装创作者皮肤包的用户来说是值得的投资。

## 🔧 安装步骤

KWGT 是 Android 专属应用，最低支持版本随 Play 商店说明为准。安装过程与普通 App 无异，但首次使用时需要掌握几个关键权限和设置点。

### 第一步：安装主应用

1. 从应用商店或上方下载入口获取 APK 文件
2. 如果是手动安装 APK，系统会弹出「未知来源」提示——进入设置开启允许安装未知来源应用，或在安装弹窗中点击「允许本次安装」
3. 安装完成后，桌面不会自动出现小组件，需要手动添加

> [!WARNING]
> 部分国产 ROM（华为、小米、OPPO）的系统省电策略会在后台杀掉 KWGT 进程，导致小组件停止刷新。建议安装后立即在系统设置里把 KWGT 加入「自启动白名单」和「电池优化忽略」。

### 第二步：添加小组件到桌面

1. 长按桌面空白处 → 选择「小组件」或「微件」
2. 找到 KWGT，会看到几种不同尺寸的占位小组件（2×2、3×3、4×2 等）
3. 长按其中一个拖到桌面合适的位置，松手后会自动弹出 KWGT 编辑器

### 第三步：授权基础权限

首次打开 KWGT 时，建议在侧边栏 → Settings 里检查以下权限：

| 权限 | 是否必开 | 用途 |
|---|---|---|
| 存储访问 | 必开 | 导入导出预设、读取背景图 |
| 日历访问 | 按需 | 使用 `$cal()$` 函数读取日程 |
| 位置信息 | 按需 | 天气和天文函数（日出日落）需要 |
| 通知使用权限 | 按需 | 音乐控制函数 `$mi()$` 读取正在播放的媒体 |

> [!TIP]
> 权限不是越多越好。只开启你实际用到的函数对应的权限——权限越多，系统越容易判定为活跃后台，反而更省电。

## 📖 进阶玩法与核心功能

KWGT 的学习曲线可以分为三个阶段：**基础元素编辑**、**函数与动态数据**、**全局变量与跨 App 联动**。下面重点展开后两者——这是 KWGT 区别于普通小组件的核心价值所在。

### 函数引擎：让小组件活起来

KWGT 内置了数十组函数家族，每个函数家族对应一类系统信息的读取能力。函数的写法统一为 `$函数名(参数)$`，可以放在任意支持动态值的属性字段里。

#### 电池与系统状态

| 函数 | 示例效果 |
|---|---|
| `$bi(level)$` | 返回当前电量百分比（0-100） |
| `$bi(charging)$` | 充电中返回 true，否则 false |
| `$bi(temp)$` | 电池温度，单位°C |
| `$sys(cpu)$` | CPU 使用率 |
| `$sys(ram)$` | 已用内存 |
| `$sys(nextalarm)$` | 下一次闹钟的触发时间 |

这些函数可以组合到文字内容里直接显示，也可以配合条件判断实现动态样式。比如让电量低于 20% 时自动变红：

```
$if(bi(level)<20, '#FF0000', '#333333')$
```

把这行代码放到 Paint Color（文字颜色）字段里即可生效。

#### 日历、天文与网络

KWGT 能读取日历日程、计算当地天文数据、查询 WiFi 详情：

```
电量 $bi(level)$% · 温度 $bi(temp)$°C · WiFi $wi(ssid)$
```

这行代码在一个文本元素里同时展示了三个不同来源的系统信息。天文函数 `$ast(sunrise)$` 和 `$ast(sunset)$` 可以显示今天的日出日落时间，月相函数 `$ast(moonphase)$` 直接返回月相名称。

#### 运动健康（Google Fit）

如果手机上安装了 Google Fit，`$fit()$` 函数家族可以读取今日步数、消耗卡路里、运动距离和昨日睡眠时长：

| 函数 | 说明 |
|---|---|
| `$fit(steps)$` | 今日步数 |
| `$fit(calories)$` | 今日卡路里消耗 |
| `$fit(sleep)$` | 昨日睡眠时长（分钟） |

### 全局变量（Globals）：跨元素、跨 App 的共享状态

全局变量是 KWGT 最有特色的机制之一。它让一个预设内所有元素都能读写同一份数据，甚至跨 App（KWGT 与 KLWP/KLCK）共享。

#### 创建和使用

在预设编辑界面的 Globals 标签页可以创建新变量：起英文名称、设初始值（数字、字符串、颜色都可以）。创建后，任意属性里用 `$gv(变量名)$` 就能读取，用 `$gv(变量名, 新值)$` 就能写入。

典型场景：在根元素创建一个 `theme_color` 变量，值为 `#3388FF`，然后整个预设里所有需要用这个颜色的地方都写 `$gv(theme_color)$`。以后想换主题色，只要改一次变量值，整个预设的颜色会同时更新。

#### 跨 App 共享

KWGT 的 Globals 和 KLWP（动态壁纸）的 Globals 是互通的。你可以在 KWGT 里创建一个 `theme_mode` 变量，然后在 KLWP 壁纸和 KLCK 锁屏里都读取它——点击桌面上的某个按钮切换这个变量的值，三个界面会同时响应变化。

#### Tasker 集成

进阶玩家可以通过 Tasker 的 Kustom 插件，让外部自动化任务读写 KWGT 的 Globals。比如 Home Assistant 检测到手机到家时，通过 Tasker 把 `at_home` 变量设为 true，KWGT 的 Home Assistant 控制面板就会自动亮起所有按钮。

### Pack 皮肤包：创作者生态

如果你不想从零开始设计，可以从 Play 商店下载第三方 Pack 皮肤包。一个 Pack 通常包含 20-50 个配套预设（时钟、天气、音乐、仪表盘等），统一视觉风格，装上去就能用。

| 对比项 | .kwgt 文件 | Pack 皮肤包 |
|---|---|---|
| 文件类型 | 独立预设文件 | APK 应用包 |
| 预设数量 | 1 个 | 10+ 到 50+ |
| 分发渠道 | Reddit / Telegram / 网盘 | Play 商店 |
| 价格 | 大多免费 | 免费 / $0.99-$4.99 |
| 适用版本 | Free 和 Pro 都能导入 | 第三方 Pack 通常需要 Pro Key |

> [!NOTE]
> Pack 安装后不会在桌面生成图标——它是 KWGT 的内容库。打开 KWGT 主应用 → 侧边栏 → Load Pack，就能看到已安装的 Pack 列表，点进去选一个预设应用即可。

### Kustom 三件套联动实战

KWGT、KLWP、KLCK 三者配合使用时，可以构建出完整的个性化桌面系统：

- **统一日夜切换**：用一个 Global `theme_mode` 驱动三个 App 同时切换配色和背景——白天用明亮色调，夜间自动转暗色
- **音乐跨界面同步**：KWGT 音乐小组件、KLWP 壁纸背景、KLCK 锁屏控制按钮，三者都读 `$mi(playing)$$mi(title)$$mi(cover)$`，封面、标题、播放状态自然保持同步
- **Home Assistant 扩展**：到家时 Tasker 写入 `at_home` 变量，KLCK 锁屏显示欢迎语、KLWP 壁纸转暖色调、KWGT 家居控制按钮全部就绪

> [!WARNING]
> 华为版和 Play 版的 Kustom 三件套包名不同（华为版带 `.huawei` 后缀），Globals 不互通。大多数用户只需要安装 Play 商店的标准版即可。
