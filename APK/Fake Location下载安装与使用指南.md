## ✨ Fake Location 是什么

Fake Location 是一款面向 Android 平台的虚拟定位工具，核心功能是向其他应用提供自定义的 GPS 坐标。简单说就是把手机的位置"瞬移"到任意地方——社交应用签到换个城市、地图类应用测试跨区域功能、打车外卖类工具定位到热点商圈，都是它最常见的使用场景。

从官方功能表里能看到的能力包括：静态坐标模拟、摇杆手动移动、路线回放、GPS 漂移抖动、海拔模拟、独立模拟（仅对指定应用生效）、WiFi 与基站环境伪装，以及配套的反检测选项。免费版开放基础定位与摇杆，专业版解锁环境伪装、海拔、独立模拟等高阶功能。

软件的使用门槛分两档：免 ROOT 模式借助 Android 开发者选项的模拟位置通道即可工作，适合不想折腾系统的普通用户；ROOT 模式能拿到更底层的系统权限，开启独立模拟等高级功能，稳定性和兼容性也更好。

> [!NOTE]
> 不同应用对虚拟定位的敏感程度差异很大。社交、地图、签到类应用通常表现尚可，检测机制严格的金融、出行类应用可能需要 ROOT 模式甚至搭配反检测功能才能生效。

## 🔧 安装与前置准备

Fake Location 的安装本身就是一个普通的 APK 安装过程，真正需要花心思的是前置环境配置——这也是很多新手卡在第一步的地方。

### 安装 APK

1. 从下载页拿到安装包后，在手机文件管理器里点开安装；
2. 首次安装会提示"未知来源应用"，允许当前文件管理器的安装权限即可；
3. 建议核对一下安装包大小与下载页标注是否一致，避免下载不完整导致安装失败。

### 免 ROOT 模式必做：开发者选项指定模拟位置应用

这是免 ROOT 模式能跑通的**唯一前置条件**，不设置这一步，应用里点什么都不会生效：

1. 打开系统设置 → 关于手机 → 连点「版本号」七次，直到提示已进入开发者模式；
2. 返回设置主界面，找到「开发者选项」入口（各品牌路径不同，小米在「更多设置」里，华为在「系统和更新」里，三星 One UI 在设置根目录）；
3. 在开发者选项里找到「选择模拟位置信息应用」，选中 Fake Location。

> [!TIP]
> 这个开关在手机里没装任何可选应用时是灰色的，所以**务必先装好 Fake Location 再去找这个开关**。实在找不到开发者选项的位置，直接在系统设置的搜索框搜「开发者」或「模拟」最快。

### ROOT 模式可选准备

如果打算上 ROOT 模式，需要先在 Magisk 或其他 ROOT 管理器里授予 Fake Location root 权限，部分机型还需要把 SELinux 调到宽容模式才能完整发挥底层能力。这部分的门槛比免 ROOT 模式高不少，通常只有用到独立模拟、反检测等付费高阶功能时才值得折腾。

## 📖 完整使用入门

环境配好之后，改定位本身并不复杂，但要把效果做真、做稳，里面有不少细节值得留意。

### 第一次改定位：四步走通全流程

1. **进入位置模拟页**：打开应用首页就是位置列表，右下角有个加号按钮；
2. **添加位置点**：点加号进入大地图，三种选点方式任选——直接在地图上长按定位、搜索框输入地名、或手动填入经纬度坐标；
3. **确认选点**：目标位置右下角打钩，回到位置列表；
4. **启动模拟**：点击启动，等模拟生效后切到目标应用验证位置是否改变。

> [!WARNING]
> 启动模拟前先把手机的真实 GPS 定位关掉，或切到「仅设备」以外的模式——避免真实信号和模拟信号打架导致位置来回跳。发现改不成功时可以短暂打开 GPS 刷新一下，成功后再关掉，这是社区老玩家总结的实操节奏。

### 启动后一直在转圈怎么办

部分情况下点启动模拟会长时间转圈，但模拟实际已经工作了——别等它转完，直接切到地图或社交应用看看位置变没变。如果真的没生效，排查方向通常是：开发者选项的模拟位置应用是否正确指定、目标应用是否开启了混合定位（GPS + WiFi + 基站综合计算可能绕过纯 GPS 模拟）、手机系统版本是否过旧。

### 让位置"动起来"：摇杆与路线

静态坐标模拟只是 Fake Location 能力的底线。摇杆功能可以在地图上实时拖动，让坐标随手指移动；路线模拟则能预设一条路径（比如家 → 公司 → 超市），按设定的速度自动回放。两者搭配 GPS 漂移抖动功能，能让模拟的位置不再死死钉在一个点上，更像真人在移动。

### 海拔模拟：补齐第三维

现代手机的 GPS 数据是三维的——经纬度之外还有海拔。Fake Location 的海拔模拟功能（专业版）就是用来补齐这个维度的。气压计已是中高端安卓机标配，部分应用会用气压估算的高度做交叉验证。你把自己定位在高原城市但海拔读数还是平原值，就很容易穿帮。

使用上没有复杂门槛：解锁专业版后在位置模拟里找到海拔选项，按目标位置的实际海拔填入数值就行。平原城市普遍几十米，高原城市两到四千米，室内场景与地面差一层楼约 3 米。拿不准具体数值可以查一下公开的地理资料。海拔模拟是个"锦上添花"的功能，先把坐标与移动做好再考虑它不迟。

### 独立模拟：让不同应用看到不同的位置

默认情况下 Fake Location 的模拟对全系统生效——所有读位置的应用都拿到同一个虚拟坐标。独立模拟（ROOT + 专业版功能）反过来，只对指定应用生效，其余应用照常读真实位置。

这个功能解决的是"全系统模拟的天然副作用"：社交应用给虚拟位置，地图导航就不能再用了，不然会被导到别人城市。开启独立模拟后，从应用列表里勾选要作用的目标应用，正常启动模拟，只有名单内的应用读虚拟值。名单外的应用完全不参与模拟，等于对它们关闭了全部伪装。

### 进阶思路：反检测与环境伪装

Fake Location 还有一整套环境伪装和反检测工具：WiFi 模拟、基站信息模拟、检测痕迹隐藏等。这些功能主要针对检测机制严格的应用场景，需要 ROOT 模式配合才能完整使用。独立模拟控制的是"谁看到假的"，反检测控制的是"谁看到这款软件存在"，两者常常搭配着用。
