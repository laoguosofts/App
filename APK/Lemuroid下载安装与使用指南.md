## ✨ Lemuroid：一台安卓设备上的 23 台复古游戏机

Lemuroid 是一款基于 Libretro 内核框架构建的 Android 多系统复古游戏模拟器。它把 Atari、Nintendo、Sega、PlayStation、NEC、SNK、WonderSwan 和 FinalBurn Neo 街机等八大家族共 23 种游戏机平台整合进同一个应用，让你在一台手机或平板上就能统一管理和运行从 20 世纪 70 年代到 PSP 时代的大量经典游戏。

与分别安装 GBA 模拟器、NDS 模拟器、PSX 模拟器等单系统应用的组合相比，Lemuroid 的核心优势在于一个统一的游戏库界面、一套通用的虚拟按键方案和跨平台一致的存档机制——学习一次操作逻辑，就能通吃全部平台。应用完全免费、无广告、开源社区维护，也没有任何强制内购。

Lemuroid 不是 RetroArch 的简单换皮。虽然底层都调用 Libretro 内核以保证模拟精度和兼容性，但 Lemuroid 在上层做了大量面向普通玩家的 UI 简化和自动化：扫描目录自动建库、默认核心自动匹配、触控按键按平台自动适配，这些在 RetroArch 里需要手动配置的环节，在 Lemuroid 里开箱即用。

> [!NOTE]
> Lemuroid 本身不内置任何游戏文件，也不是游戏分发平台。你需要自备从自己合法拥有的游戏机中导出的游戏备份文件（ROM 或镜像），Lemuroid 只负责识别、组织并运行它们。

当前最新稳定版为 v1.17.0，2026 年 4 月发布，主要更新包括 Nintendo DS 麦克风支持、全新设计的触控按键、沉浸模式与动态背景色、改进的 HD 模式、手柄快速存档/读档快捷键，以及后台切换时的存档保障。

## 🔧 安装步骤

Lemuroid 是 Android 原生应用，最低支持 Android 8.0（API 26）。安装流程和普通 APK 一致，但有几个注意点：

1. **下载安装包**：从 Google Play 一键安装最省心；如果用 APK 直链下载，注意核对文件名中的版本号（如 `lemuroid-v1.17.0.apk`），避免下载到过期版本。

2. **允许未知来源安装**：Android 8.0 以上在浏览器或文件管理器中首次安装 APK 时，系统会弹出「不允许安装未知应用」的提示。点击提示中的设置按钮，找到对应浏览器或文件管理器，开启「允许安装未知应用」开关即可，不需要修改全局安全设置。

3. **空间预留**：APK 本身约 40MB，安装后约占 120MB 内部存储。另外游戏 ROM 文件和存档数据建议放在外部 SD 卡或 USB 存储，Lemuroid 在首次扫描时会让你选择游戏文件所在的目录。

> [!WARNING]
> 部分国产手机系统（MIUI、EMUI、OneUI 等）的安全中心可能对模拟器类应用有额外的行为限制，比如后台被杀、存储权限被回收。建议安装后在系统设置里把 Lemuroid 加入电池白名单、锁定后台任务，并确保授予"所有文件"访问权限。

4. **首次启动**：打开 App 后会引导你选择游戏文件目录。选择包含 ROM 的文件夹即可，Lemuroid 会自动扫描识别支持的格式并匹配数据库元数据，扫描完成后主界面就会按系统分组展示你的游戏库。

## 📖 使用入门

### 游戏库浏览

扫描完成后的主界面按系统家族自动分组展示：Atari、Nintendo、Sega、PlayStation、街机等，每个家族有一个大标题，板块里列出识别到的全部游戏条目。点击板块标题进入该系统的专属列表页，可以按字母、添加时间或最近游玩时间排序。

主界面和专属列表页顶部都有搜索框，输入标题、发行商或年份关键词即可实时过滤。搜索对中文标题的支持取决于 ROM 文件名本身——如果原始 ROM 内部的标题数据是英文，就搜不到中文关键词。设置里还能调整筛选条件：是否只显示最近游玩的游戏、是否隐藏没有封面的条目、是否排除某些系统板块。

Lemuroid 会记住每个游戏的上次启动时间，切换到「最近」视图可以按启动时间倒序排列，经常玩的游戏永远在顶部，不用每次翻找。

### 触控按键布局

进入游戏后呼出菜单，找到「控制覆盖层编辑」或「自定义按键」选项进入编辑模式。编辑模式下所有按键边缘会出现虚线轮廓，右上角有保存、恢复默认、新增按键的快捷按钮，此时触控操作只作用于按键编辑，不会触发游戏内的动作。

**移动按键**：手指按住按键拖到目标位置后松手；**缩放按键**：双指捏合放大或缩小，或用 + / - 按钮调整直径；**删除按键**：长按按键弹出菜单，选择删除（十字键和模拟摇杆等核心按键不能删除）。

如果默认布局缺了某个按钮（比如想多加一个 Select 键），编辑模式下点击「新增按键」，选择按键类型（动作按钮、十字键、模拟摇杆、触摸区），再选择它映射的模拟按键（A / B / X / Y / Select / Start 等），拖拽到合适位置、调整大小即可。

> [!TIP]
> 调整布局时避开游戏本身的 UI 区域——RPG 的菜单和对话窗口常在屏幕底部，射击游戏的生命值和弹药数在角落，摇杆和按键别挡住这些位置。常用参考布局：十字键/模拟摇杆放屏幕左侧最边缘，动作按钮放右侧最边缘围成菱形或扇形，Start/Select 放屏幕顶部或底部中间不太会碰到的位置，快进和存档快捷键放角落。

调整完点保存，这套布局就绑定到当前平台了。调乱了想重来，点「恢复默认布局」一键回到预装版本。

### 与其他模拟器的定位差异

Lemuroid 基于 Libretro 内核，模拟精度和兼容性与 RetroArch 基本一致，区别完全在上层。RetroArch 追求全功能、可深度定制的前端，Lemuroid 追求普通玩家装完就能玩。

| 环节 | Lemuroid | RetroArch |
| --- | --- | --- |
| 目录选择 | 系统文件选择器选一个文件夹即可 | 需要在菜单里手动添加内容目录 |
| ROM 扫描 | 自动识别格式、匹配数据库 | 需要手动调用扫描器，可能失败 |
| 分类展示 | 按系统自动分组 | 默认扁平列表，需手动建播放列表 |
| 封面 | 自动下载或识别内置封面 | 默认没有，需手动开启缩略图下载 |

单系统模拟器（GBA.emu、DraStic、DuckStation 等）的优势在于对特定平台的功能挖掘更深——比如 DraStic 的 NDS 双屏自定义、DuckStation 的 PSX 高分辨率渲染器。但如果游戏库横跨多个平台，在不同 App 间切换、管理多套存档、记不同的按键布局会非常麻烦。

> [!NOTE]
> 选择建议：想把 23 种游戏机全部搬到手机、一个界面统一管理选 Lemuroid；某个平台有深度需求选对应单系统模拟器；有能力折腾配置、追求极致定制选 RetroArch。

### 存档与快进

Lemuroid 默认开启自动存档恢复——每次打开游戏，自动回到上次关闭时的状态。快速存档提供多个可命名的存档槽位，手柄快捷键（长按某个按钮）可一键存读。快进有独立的快捷键，默认倍数在设置里调整。
