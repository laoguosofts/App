## ✨ 1Panel 是什么

1Panel 是一款面向 Linux 服务器的现代化运维管理面板，主打「开源、轻量、好用」三个标签。它把网站部署、数据库管理、应用商店、备份恢复、容器编排这些日常运维活儿，全部收拢到一个浏览器就能操作的 Web 界面里，省去了大量手写命令和配置文件的麻烦。

核心功能可以用几条线来概括：**网站管理**支持静态、PHP、反向代理等多种站点形态，域名、证书、伪静态、防盗链、重定向一站式配置；**应用商店**收录了两百余款开源应用，WordPress、Halo、MySQL、Redis、MaxKB 这类明星项目点一下就能装上；**备份体系**覆盖了单站备份、数据库备份、计划任务定时备份，还有一个整机系统快照功能专门解决「整台机器搬家」的难题；**容器管理**对接 Docker，需要自定义部署的应用直接拉镜像跑容器；再加上面板级的防火墙、日志监控、一键升级等辅助能力，基本覆盖了个人站长和小团队运维的日常场景。

适合谁用呢？正在从宝塔面板迁移、或者刚接触 Linux 运维的新手站长，一台 VPS 上要同时跑好几个网站和数据库的小团队，想给自己的服务器加一层图形化管理界面又不想装太重的东西的用户——这些都是 1Panel 的典型受众。它不要求你有深厚的命令行功底，浏览器里点一点、填几个参数就能把事情办成，同时又不会把面板做太厚，保持着比较轻的资源占用。

## 🔧 安装部署全流程

1Panel 的安装走的是服务器命令行一键脚本模式，不跑在 Windows 或 macOS 本机上——它是你 VPS 上的 Web 管理面板，所以安装前你得先有一台干净的 Linux 服务器（主流发行版如 CentOS、Ubuntu、Debian、Rocky Linux 都支持）和 root 权限。

### 安装前的准备清单

在敲安装命令之前，先确认几件事：

1. **系统版本**：到服务器里跑一下 `cat /etc/os-release`，确认发行版在官方支持列表里；
2. **内存和磁盘**：面板本身不重，但装完应用商店里的东西后内存消耗会上去，2G 内存是比较舒服的起步配置；
3. **端口规划**：面板默认监听一个自定义端口（安装时会让你设），应用商店里的应用各自有端口，提前心里有数避免冲突；
4. **关闭 SELinux 和防火墙预拦截**：安装脚本会尝试自动处理，碰不上时手动 `setenforce 0` 一下更稳。

> [!WARNING]
> 安装脚本需要 root 权限执行，并且会自动安装 Docker、OpenResty 等依赖组件。建议在一台新装的干净服务器上跑，避免和已有的运行环境打架。

### 一键安装命令

官方提供了一条覆盖主流发行版的安装脚本，复制到服务器终端里执行就行：

```bash
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && bash quick_start.sh
```

执行过程中脚本会提示你设置面板的**端口号**、**用户名**和**密码**——这三个值记好，一会儿浏览器登录要用。脚本跑完后终端会输出一行访问地址，格式是 `http://你的服务器IP:端口号`。

### 安装后的首次登录

浏览器打开上面那个地址，用刚才设的用户名密码登进去。第一次登录面板会引导你做一些基础配置，比如选择镜像源（国内服务器选国内镜像源能大幅加速后续应用安装）、确认时区等，跟着向导走完就进入面板主界面了。

> [!TIP]
> 登录后**第一件事**是去「设置 - 面板设置」里把面板端口从默认的 8888 改成一个不常见的高位端口，并且在「安全入口」里加一个自定义路径（比如 `/1p-admin-xxxxx`），两者都做了之后面板被扫到暴力破解的概率会低很多。

### 升级与卸载

面板自带一键升级能力，在「设置 - 关于」页面有升级按钮，点一下就能拉新版本镜像重启服务。也可以用命令行工具 `1pctl update` 在终端里完成升级。卸载稍微麻烦一点，官方文档里有完整的清理脚本，直接照搬执行即可，不要手动删文件，容易残留配置目录。

## 📖 使用入门：从建站到运维的核心玩法

面板装好了，接下来干什么？1Panel 的功能模块不少，但日常高频使用的其实集中在几条主线上：应用商店装东西、网站管理建站点、备份机制保数据、容器面板跑自定义服务。这几条线串起来，基本就是个人站长用 1Panel 的完整路径。

### 应用商店：两百多款开源应用的挑选思路

应用商店是 1Panel 最显眼的入口——登录后主界面左侧点「应用商店」就能看到。按官方分类口径，目前收录了两百余款应用，大致分布是：实用工具八十余款、AI 相关二十余款、数据库二十余款、DevOps 与开发工具三十余款，其余分散在运行环境、Web 服务器、云存储、中间件、多媒体、邮件、安全、CRM、BI 等分类里。WordPress、Halo、OpenResty、MySQL、Redis、MaxKB 这类明星应用都常驻首页推荐位。

商店里的应用分两种形态：**本地应用**直接从商店页面点安装，镜像和参数全由面板托管，升级、备份、状态都在面板里闭环；**在线应用**则会跳转到外部部署说明，适合需要高度自定义的场景。大部分用户只需要关心前者。

挑应用前建议做三个检查动作：一是看维护方，优先选官方精选或社区活跃的；二是看端口占用，装之前过一遍这台机器已有哪些端口，别撞上了；三是看资源需求，数据库和建站程序都有最低内存要求，低配机器装太多会被 OOM 教训。

商店解决的是「常见需求」，如果需要手动装容器化的东西？绕过商店，直接用「容器」菜单拉镜像跑容器就行。两者分工明确：商店管生命周期（升级备份一键化），手动容器管灵活度。

### 网站管理：域名、证书、伪静态与防盗链

点左侧「网站」进入网站管理，点「创建网站」选好类型（静态、PHP、反向代理、TCP/UDP 代理）、填域名和根目录，一个站点就建起来了。建完之后点每个站点的「配置」按钮进入配置页，分三个标签：**基本**是访问入口和域名管理，**日志**是访问和错误日志，**资源**把网站和数据库关联起来（关联后备份网站会连数据库一起备）。

访问入口类配置里，常用的有：

- **域名设置**：增删主域名和附加域名、调整端口，换域名时在这里加一条解析过去即可；
- **默认文档**：访问目录时自动加载的文件名列表（如 index.html），静态站必配；
- **真实 IP**：前面有 CDN 或负载均衡时，配置可信来源让日志记录访客真实 IP；
- **密码访问**：给站点或指定路径加一层 HTTP Basic 认证，测试环境和内部工具站的好帮手；
- **流量限制**：按方案限带宽，多站共享一台小水管机器时防止一个站吃光流量；
- **CORS**：配置允许的来源、方法、请求头与预检缓存时间，携带凭证时不能把来源设为通配范围。

配置完之后，网站「配置 - 伪静态」里把三件流量小工具配齐：**伪静态规则**把 `index.php?id=123` 转成 `post/123` 这类友好 URL，对 SEO 和用户观感都有帮助，WordPress、Halo 这类程序装完第一时间就要配，否则后台开了固定链接会大面积 404；**防盗链**通过校验请求 Referer 来源挡住第三方站点直接外链你的图片和附件，把自己的域名加进白名单、决定是否允许空 Referer、设定盗链触发时的响应方式——图片站和下载站建议一上来就配，带宽账单会感谢你；**重定向**用于旧地址转新地址，换域名、改目录结构、强制加或去 www 都靠它，面板支持按域名或路径规则配置跳转目标和跳转码（301 永久、302 临时），换域名迁移时配合站点配置里的域名增删，一条 301 就能保住搜索引擎权重。

> [!NOTE]
> 伪静态、防盗链、重定向这三项都作用在 HTTP 层（OpenResty 处理请求的阶段），如果请求根本没到达站点——被防火墙拦了、被云安全组挡了——这些配置再对也不起作用，排查时先确认流量能到达。

### 备份与计划任务：从单站到整机的四道保险

备份体系是 1Panel 的另一个亮点。它不是单一的备份按钮，而是四层分工：

| 场景 | 用什么 |
|---|---|
| 每日数据保险 | 计划任务里的数据库与站点定时备份 |
| 换机器整机搬家 | 系统快照 |
| 面板升级前的保险 | 系统快照（或云平台磁盘快照双保险） |
| 单个应用回滚 | 应用级备份 |

普通备份针对单项资产——一个库、一个站、一个应用。**系统快照是面板整体打包**——面板配置、应用、网站、数据库等要素按范围快进一个归档，存到备份账号（S3、阿里云 OSS、七牛云等都支持）。创建快照时可以选择是否包含 Docker 镜像：包含的话体积会大很多，但恢复后不用重新拉镜像，带宽和对象存储充裕就带上；还能指定忽略的应用，某些不需要跟随迁移的大应用可以排除掉。

第三方测评当年把快照列为「一大亮点」，因为它直接解决了「整台机器搬家」这个运维难题——换服务商、换机房时，按四步走就行：旧机创建快照（含镜像）推送到云端备份账号 → 新机装好同版本 1Panel 并配置同一个备份账号 → 新机从快照恢复，面板配置与应用整体回归 → 验证网站、数据库、计划任务逐项过一遍，域名解析切过去。面板命令行 `1pctl restore` 还能用于面板服务本身损坏的抢修。

### 进阶：容器管理、日志与安全

日常运维中还会经常用到几个模块。**容器**菜单直接对接 Docker，手动拉镜像、跑容器、看容器状态都在这里，适合商店里没有的自定义服务。**计划任务**除了定时备份，还能配置 URL 探活、日志清理、自定义 Shell 脚本，相当于一个 cron 的图形化前端。**主机监控**提供 CPU、内存、磁盘、网络的实时图表，排查性能问题时很方便。**防火墙**在面板里就能做端口放行和规则管理，不用再跳出去敲 `iptables`。

> [!TIP]
> 面板升级前一定要打一个系统快照当保险——升级过程中如果 Docker 镜像拉取失败或者配置迁移出错，直接从快照恢复比手动回滚快得多。另外，快照体积包含镜像时会膨胀得很快，定期检查备份账号的空间消耗，别等备份存不进去才发现。
