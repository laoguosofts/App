## ✨ DevCheck 是什么

DevCheck 是一款面向 Android 设备的硬件检测与诊断工具——它不依赖 root 权限，就能把手机里几乎所有硬件模块的实时状态、详细参数和读数拉出来展示。从传感器列表、网络信号、电池温度到 CPU 频率、内存占用，每一项都有清晰的可视化面板和实时曲线。

它最典型的使用场景是**二手机验机**：买机之前跑一遍传感器、气压计（间接判断气密性）、网络信号、电池循环次数，能快速筛掉一批存在暗病的机型。日常使用中也可以当"硬件健康仪表盘"——夏日充电时盯一下电池温度、后台跑下载时看 CPU 有没有满负载、出门前确认移动网络信号强度够不够。

DevCheck 分免费版和 Pro 版。免费版覆盖了大部分常用读数面板；Pro 版在此基础上增加了桌面小组件、悬浮窗、Wi-Fi 扫描、网络映射、GPS 精度测试等进阶工具，对于经常折腾硬件的用户更值。

## 🔧 安装步骤

DevCheck 的安装包是标准的 Android APK，目前版本要求 Android 7.0 及以上。安装过程本身不复杂，但有几个高频报错点需要提前知道。

### 安装前准备

1. **确认系统版本**：设置 → 关于手机里看 Android 版本号。4.1 到 6.x 的旧机型装不上当前版本，需要找更早的历史版本
2. **预留存储空间**：APK 解压安装时需要包体一到两倍的空间，建议至少留出 50MB 可用
3. **卸载其他版本**：如果手机里已经装过来自应用商店的 DevCheck，先卸掉再装这份——签名不一致会被系统直接拒绝

### 开启未知来源权限

用浏览器或文件管理器下载 APK 后，第一次点开安装时系统会弹"不允许安装未知来源的应用"。关键点是：权限要给**你正在用它下载的那个应用**——比如用浏览器下载就给浏览器开，用文件管理器点开就给那个管理器开。安装弹窗里当场弹出的快捷开关点了同样算数。

> [!TIP]
> 不同品牌手机的权限入口位置略有差异，但系统弹出的安装确认框里通常就有一个"设置"跳转按钮，直接点过去开权限最省事，不用自己去设置里找。

### 三种常见报错对号入座

| 报错提示 | 原因 | 解决办法 |
|---|---|---|
| 不允许安装未知来源的应用 | 下载来源的权限没开 | 给对应 App 开"未知来源"权限 |
| 解析包时出现问题 / 应用未安装 | 下载不完整或签名冲突 | 重新下载 APK；先卸载其他版本 |
| 装完闪退 | 系统版本低或存储满 | 确认 Android ≥ 7.0；腾出 50MB 空间 |

## 📖 使用入门

装完打开 App，底部有几个标签页——传感器、网络、电池、CPU、内存等等，每一页都是独立的读数面板。下面挑几个最常用、最有实用价值的面板来说。

### 传感器面板：拉全清单 + 实时曲线

传感器页会把设备上**所有已注册传感器**按类型分组列出来：加速度计、陀螺仪、磁力计（电子罗盘）、距离传感器（打电话灭屏用）、光线传感器（自动亮度）、气压计、重力传感器、旋转矢量、心率传感器（部分旗舰机型）、步数计数器……每一条都标注了类型、厂商、最大测量范围、分辨率和功耗。

其中加速度计、陀螺仪、气压计、距离传感器、光线传感器这几个，点进去能看**实时曲线**——每秒刷新一次。你可以试着做几个小动作观察变化：

- 手机轻轻晃一下，加速度计曲线会跟着抖
- 快速旋转手机，陀螺仪曲线会明显波动
- 手指用力按压屏幕中央再松开，气压计曲线会先升后降

> [!NOTE]
> 气压计曲线有个二手机验机的间接技巧：把手机平放在桌面，打开气压计实时曲线，用力按压屏幕中央再松开。密封完好的机型气压曲线会跟着明显先升后降；按下去纹丝不动的，就要怀疑密封胶可能失效了。这个方法是间接参考手段，不能替代正式检测，但顺手按一下就能快速筛掉一批有问题的机型。

### 网络面板：双卡双栏一目了然

网络页采用**左栏 Wi-Fi、右栏移动网络**的双栏布局。双卡手机会自动把两张 SIM 卡的信息分别列出来，不用额外切换。

Wi-Fi 栏能看到连接状态、当前 SSID 和 MAC 地址、信号强度（dBm 值，越接近 0 越强）、协商速率（比如 864 Mbps）、频段（2.4GHz / 5GHz / 6GHz）、本机 IPv4 / IPv6 地址，还有 WAN 出口 IP——这个公共 IP 很有用，能一眼判断手机当前是否走了代理或 VPN。

移动网络栏则列出每张卡的运营商、网络类型（2G / 3G / 4G / 5G / NR）、接入模式（NSA 非独立组网还是 SA 独立组网）、信号强度。Pro 版还能进入工具标签页使用 Wi-Fi 扫描、网络映射器和 GPS 精度测试。

### 桌面小组件（Pro 版）

Pro 版提供了多种尺寸的桌面小组件，可以把 DevCheck 的核心读数直接放到锁屏或桌面，不用打开 App 就能实时看：

- **电池大组件**：电量百分比、温度、充电状态——夏日高温下充电时一眼确认没有过热
- **内存组件**：已用 / 总容量、实时占用率
- **CPU 组件**：各核实时频率和负载条——后台下载时不想切 App，也能确认 CPU 有没有满负载
- **网络组件**：Wi-Fi / 移动网络信号强度和 IP 地址
- **迷你组合组件**：一行显示多个指标

添加方式和一般小组件一样：长按桌面空白处 → 添加小组件 → 找到 DevCheck → 选择尺寸样式拖到桌面。部分机型支持锁屏小组件，需要在锁屏设置里单独开启。

### 电池、CPU、内存面板

除了传感器和网络这两个最常用的，电池面板能看到当前电量、温度、健康度、循环次数——买二手机时电池循环次数是关键指标。CPU 面板展示各核心的实时频率和负载，后台跑游戏或下载时可以盯着看有没有降频。内存面板则显示已用和空闲的详细数字，帮助判断杀后台够不够用。

### 工具标签页

Pro 版的工具标签页里还有几个实用工具：Wi-Fi 扫描能看到周围信道占用情况，帮你选一个没人用的 5GHz 信道；网络映射器可以绘制局域网设备拓扑；GPS 工具则能测试定位精度和卫星数量。这些对于经常折腾网络环境或户外跑定位的用户来说很方便。
