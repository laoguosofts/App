## ✨ AnyGen 是什么

AnyGen 是一款面向知识工作者的 AI 生产力工具，核心定位是"让 AI 参与到你内容创作的每一个环节"——从模糊想法到研究、从结构草稿到精修成文、从文档到幻灯片的形态转换，全流程由 AI 辅助完成，同时保留人类的最终决策权。

它和市面上主流 AI 工具的一个关键区别在于底层路线：文档和幻灯片都走原生结构生成，而不是先出 HTML 再转换。这个技术选择带来的直接体验是——导出的 .pptx 图表可以双击改数据、导出的 .docx 格式零丢失、企业模板能被精准跟随，这些都是 HTML 路线工具做不到的。

AnyGen 的能力覆盖了几个高频办公场景：文档生成（研究报告、提案、文章）、幻灯片生成（原生 PPTX）、Skills 复用（把跑通的工作流打包成可复用模块）、Memory 三层记忆（让 AI 持续记住你的偏好）。它支持的典型输出形态包括 .docx 和 .pdf 两种文档格式，以及完整可编辑的 .pptx 演示文稿。

从产品设计上看，AnyGen 把人机协作分成了三种模式：对话式（让 AI 帮你改）、局部选中式（精准扩写/翻译某一段）、全手动编辑（AI 只做辅助），用户可以根据自己对内容的掌控需求自由切换。还有一个双 Agent 校验机制——生成的文档内容会被独立的 Verification Agent 交叉验证，减少事实错误。

## 🔧 安装与注册

AnyGen 主要以云端服务形式运行，安装流程相对轻量，核心步骤是完成账号注册和基本环境配置。

**第一步：注册账号**

打开浏览器访问 AnyGen 的官网首页，点击右上角的 Sign Up 按钮进入注册流程。支持三种注册方式：邮箱注册、Google 账号一键登录、GitHub 账号一键登录。推荐使用邮箱注册，便于后续独立管理账号和密码。

> [!TIP]
> 注册过程中会让你选择工作领域（产品经理 / 研究员 / 市场运营 / 其他），这会影响 AI 初始的偏好预设。如果后续发现默认输出风格不对路，可以在 Settings → Personalization 里随时调整。

**第二步：基础环境准备**

由于 AnyGen 的幻灯片模块需要调用 PowerPoint 的原生渲染能力，如果你的电脑上安装了 Microsoft Office（2019 或更高版本，含 Office 365），导出 .pptx 时效果更佳。没有 Office 也不影响基本使用，导出后可以用 WPS 或在线 PowerPoint 查看器打开。

浏览器建议使用 Chrome、Edge 或 Safari 的最新稳定版，Firefox 兼容性偶有问题。

**第三步：首登引导**

首次登录后 AnyGen 会弹出引导流程，核心内容包括：

1. 创建第一个 Project（Project 是 AnyGen 的工作空间概念，每个 Project 有独立的 Memory 和 Skills 配置）
2. 选择是否开启 Memory 自动记忆（Cite Conversation History）
3. 选择是否开启修改审批模式（AI 的每次编辑改动都会先展示 diff，你确认后才生效）

> [!WARNING]
> 如果你的工作涉及企业内部敏感信息，建议关闭"自动记忆"并开启"修改审批模式"——前者防止 AI 把敏感信息存入 Memory，后者让你对 AI 的每一次输出做最终把关。

## 📖 使用入门

AnyGen 的核心价值不在于"AI 能写文档"，而在于它把**研究、写作、可视化**三个环节打通成了一个闭环。下面从几个高频场景出发，看看它具体怎么用。

### 文档生成：四阶段工作流

AnyGen 把文档生成拆成了四个阶段，而不是像传统 AI 那样一次吐出大段文字。这个设计的好处是你在每个阶段都能介入调整，不会被 AI 的"先入为主"带偏。

**阶段一：模糊需求 → AI 自动研究**

你只需要用自然语言描述一个模糊的目标，比如"做一份 2026 年新能源汽车市场趋势分析报告"。AI 会自动联网搜索相关公开信息，梳理出市场规模、主要玩家、技术趋势、政策环境等几个维度的初步研究框架。这个过程不需要你手动查资料，AI 会把它认为有用的信息都收集起来。

**阶段二：对话澄清方向**

AI 不会直接开始写，而是先通过问卷或对话问你几个关键问题。比如它可能会问："这份报告面向什么读者？投资人、行业从业者还是产品经理？"、"市场规模数字偏向全球、中国还是亚太地区？"、"要不要包含价格走势和供应链分析？"。这些问题帮 AI 把你的模糊需求收窄成具体的执行方案。

**阶段三：分阶段输出结构化内容**

AI 不会一次性生成整篇文档，而是分章节逐步输出。每生成一个章节后你可以立刻审阅，用对话模式让 AI 改写语气，或者用局部选中模式让 AI 扩写某一段、翻译成英文。这个"边写边改"的节奏和人写文档的习惯很像，比等 AI 一次吐完再整体推翻重写要高效得多。

**阶段四：插入图表和数据可视化**

在文档的任意位置，你可以随时让 AI 插入研究数据表、生成可编辑的数据可视化图表、或者配图和插图说明。图表生成后是 AnyGen 编辑器里的原生对象，可以拖拽调整大小、双击改数据点——不是那种嵌进去就不能动的静态图片。

> [!NOTE]
> AnyGen 官方提到的高频文档场景包括：研究报告、提案、文章、邮件、产品页/着陆页内容、图画书（图文结合）、视频/音频转结构化文章、PDF 结构保留翻译。这些场景覆盖了绝大多数日常办公写作需求。

### 原生 PPTX：为什么底层路线决定体验

如果说文档生成是 AnyGen 的入门功能，那原生 PPTX 生成是它的差异化竞争力。目前市面上 AI 演示工具普遍走"先生成 HTML → 再转 PPTX"路线，AnyGen 选择了更难的一条——直接生成原生 PPTX 结构。

这个技术选择带来的体验差距是全方位的：

| 维度 | AnyGen（原生 PPTX） | HTML 路线工具 |
|---|---|---|
| 导出 PPTX 格式 | 像素级精确 | 常见断裂、字体替换 |
| 图表 | 原生对象，可双击改数据 | 静态图片 |
| 模板跟随 | 解析 Master Layout | 只能继承颜色和字体 |
| 编辑工具 | 完整 PowerPoint 级 | 网页级，受限 |
| 局部 AI 控制 | 精准更新单个元素 | 不可预测，可能波及其他 |

举几个具体的例子：你上传公司的 PPTX 模板后，AnyGen 会解析母版布局、提取品牌色和字体规范、理解占位符结构，新生成的每一页都会自动遵循这些规范。HTML 路线工具最多能继承品牌色和字体名，但多层级母版、特殊占位符都无法正确还原。还有图表——AnyGen 生成的图表导出后是 PowerPoint 可识别的原生图表对象，双击就能弹出编辑界面改数据，和你手动在 PowerPoint 里做的图表一模一样。

### Skills：把跑通的工作流打包成可复用 SOP

Skills 是 AnyGen 里一个很实用但容易被忽略的功能。简单说，Skill 就是一个"可复用的工作流模板"——你把一次成功的任务流程打包成 Skill，下次遇到类似任务直接调用，不用再从头描述。

AnyGen 提供了四种创建 Skill 的方式：

| 方式 | 速度 | 精度 | 适合场景 |
|---|---|---|---|
| **对话创建** | 最快 | 中 | 快速原型、探索性 Skill |
| **打包成功** | 中 | 高 | 标准化已验证流程 |
| **上传文件** | 快 | 取决于文件质量 | 团队共享、跨设备迁移 |
| **手写指令** | 最慢 | 最高 | 对细节有严格要求 |

其中"打包成功"是官方最推荐的方式——当你刚完成一个任务且对结果满意时，直接说"把我刚才这套工作流打包成一个 Skill，叫 XXX"，AI 会从你的实际执行记录中提取步骤、输入、输出结构和关键决策点，自动生成 Skill。因为是从真实执行中提取的，比从零描述更准确。

AnyGen 还提供了一个官方 Skill 库，路径是 Explore skills，里面按 Recommended / Converters / Marketers / Students 等分类整理了常用 Skill，新手可以一键添加快速上手。

### Memory 三层机制：让 AI 持续记住你的偏好

Memory 解决的是"每次新任务都要重新说一遍我的偏好"这个痛点。AnyGen 的 Memory 分三层，叠加生效：

| 范围 | 生效于 | 典型内容 |
|---|---|---|
| **Global Memory** | 所有任务 | 职位、偏好语气、常用格式、通用领域知识 |
| **Project Memory** | 特定 Project 内 | 项目规则、品牌规范、历史决策 |
| **Temporary Memory** | 当前任务内 | "这次只看北美市场"、"用数据 A 而不是数据 B" |

优先级从高到低是 Temporary > Project > Global。比如你在 Global Memory 里设了"不要用太正式的语气"，但在某个 Project 里存了"品牌规范：专业正式的商务口吻"，那这个 Project 里所有产出都会按 Project Memory 走。

Memory 有三种存储方式：手动设置（Settings → Personalization → Memory）、对话存储（在任务里直接说"请记住 XXX"）、自动记忆（开启 Cite Conversation History，AI 从对话历史里自动提取）。

> [!WARNING]
> Memory 里存的是稳定、跨任务有价值的信息——比如身份角色、风格偏好、常用流程。临时任务要求（"这次报告周五前要"）用对话临时说就行，敏感信息（密码、身份证号）绝对不要存。官网也强调 Memory 完全可控，你随时可以查看、修改、删除任意条目。

### 一个实际使用场景

拿一份 Q4 经营分析报告为例，完整流程大概是这样的：

1. **准备阶段**：上传财务 CSV 和上季度报告作为参考材料
2. **发起任务**：说"做一份 Q4 经营分析，需要营收趋势、成本结构、区域对比，给老板看"
3. **AI 自动研究**：联网查行业同期数据，生成报告框架
4. **对话澄清**：AI 问几个问题，你告诉它"区域对比重点看华东和华南，营收趋势做 12 个月的线图"
5. **分章节输出**：AI 逐章节生成，每个章节后你微调语气或补充数据
6. **图表插入**：在"营收趋势"那一页让 AI 生成可编辑的折线图，双击调整几个关键数据点
7. **导出交付**：审阅完成后导出 .docx 或 .pdf

整个过程中，AI 负责研究和草稿生成，你负责方向把控和关键细节调整——这是 AnyGen 设计的人机协作节奏。
