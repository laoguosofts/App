## ✨ HypeRate 是什么——把心率变成直播互动的利器

HypeRate 是一款专为直播场景设计的心率数据采集与叠加工具。它通过蓝牙连接心率带或智能手表，把你的实时心率数值转换成浏览器源可以直接嵌入 OBS、Streamlabs 等直播软件的数据覆盖层——让观众在观看游戏、户外、健身等直播内容时，同步看到主播的生理状态。

核心功能围绕心率数据展开：实时 BPM 显示、心率分区（Zone 1-5）、峰值统计、心率趋势判断，还能作为触发器控制外部系统——心率过高时触发场景切换、灯光变色、自动发弹幕等互动玩法。除了桌面端直播场景，HypeRate 还支持 IRL 户外直播模式，利用手机 GPS 和 Apple Weather API 叠加速度、海拔、温度、G-Force 加速度等多维数据面板，让远在千里之外的观众也能"身临其境"感受主播的运动环境与体力消耗。

对开发者而言，HypeRate 提供 Unity、Godot、Unreal Engine 三大主流引擎的官方插件，可以把心率数据直接注入游戏逻辑——心率越高敌人越凶、心率低时角色自动回血、心率稳定性影响最终得分，把生理信号变成真正的游戏机制。

## 🔧 HypeRate 安装步骤与注意事项

### 硬件准备

HypeRate 本身是软件，但需要搭配**蓝牙心率设备**才能采集数据。兼容性最广的方案：

| 设备类型 | 推荐型号 | 连接方式 |
|----------|----------|----------|
| 心率胸带 | Polar H10、Garmin HRM-Pro | 蓝牙直连手机/电脑 |
| 智能手表 | Apple Watch、Garmin Forerunner、Galaxy Watch | 通过手表配套 APP 广播心率数据 |
| 替代方案 | 部分游戏手柄内置心率（如 Xbox Elite） | 有限支持 |

> [!NOTE]
> 心率胸带的信号稳定性通常优于智能手表——胸带直接贴合皮肤，感应面积更大；手表则容易因运动时手臂晃动或皮肤接触不良导致数据跳变。如果是长时间直播或运动场景，优先考虑胸带。

### 移动端安装（iOS / Android）

1. **App Store / Google Play** 搜索 "HypeRate" 下载安装
2. 首次启动时允许**蓝牙权限**和**位置权限**（IRL 户外模式需要）
3. 如果使用 Apple Watch：在 iPhone 上安装 HypeRate Companion APP，它负责把手表的心率数据广播给 HypeRate 主 APP
4. 如果使用 Android + Garmin：在 Garmin Connect APP 里开启心率广播，HypeRate 会自动扫描到

> [!WARNING]
> Android 用户注意：国产 ROM（小米 MIUI、华为 EMUI、OPPO ColorOS）有激进的后台清理机制。安装完成后务必进入「设置 → HypeRate → 电池」选择「允许后台活动」或「无限制」，否则锁屏后蓝牙会被系统自动断开，直播中途心率覆盖层突然消失就是这个原因。

### 桌面端安装（Windows / macOS）

1. 从官网下载对应系统的安装包
2. Windows 运行 `.exe` 安装向导，macOS 打开 `.dmg` 将 HypeRate 拖入 Applications
3. 首次启动后在设置里输入你的邮箱注册 HypeRate ID（这个 ID 是全局唯一的，OBS 插件、Stream Deck 插件、游戏引擎插件都用同一个 ID 连接）
4. 桌面端可以直接通过电脑蓝牙连接心率带，不需要手机中转

### OBS 插件安装

1. 官网下载 OBS 插件安装包
2. 关闭 OBS Studio
3. 运行安装程序，它会自动把插件文件复制到 OBS 的 plugins 目录
4. 重新打开 OBS，在「视图」菜单下应该能看到 HypeRate 面板
5. 在浏览器源里填入 `https://hyperate.app/overlay/?id=你的HypeRateID` 即可嵌入覆盖层

### 版本核对

安装完成后建议立即检查更新：APP 内「设置 → 关于」查看版本号，桌面端「Help → Check for Updates」。旧版本可能存在蓝牙连接 Bug，尤其是某些品牌手表（如 Garmin）的兼容性修复经常只在最新版推送。

## 📖 HypeRate 使用入门——从基础覆盖层到高级互动玩法

### 基础用法：OBS 心率覆盖层

最常见的直播场景。流程很简单：

1. 手机或桌面端连接心率设备，HypeRate APP 显示实时 BPM
2. OBS 里添加一个**浏览器源**，URL 填 HypeRate 生成的覆盖层链接
3. 调整浏览器源尺寸和位置（通常放在画面角落，不挡主体内容）
4. 开播后观众就能看到实时跳动的心率数值

覆盖层的样式可以在 HypeRate 网页端自定义：颜色、字体、大小、显示 BPM 还是心率分区，都可以调整。心率分区（Zone 1-5）的逻辑是：Zone 1 放松（<100 BPM）→ Zone 2 有氧（100-120）→ Zone 3 燃脂（120-140）→ Zone 4 无氧（140-160）→ Zone 5 极限（160+）。覆盖层可以根据当前分区自动变色，比如 Zone 5 时整个数字变红闪烁。

### Stream Deck 集成——用心率控制直播设备

如果你有 Elgato Stream Deck，HypeRate 官方提供了插件让 LCD 按键直接显示心率数据，还能设置触发器。安装方式：Stream Deck 应用内打开商店 → 搜索 "HypeRate" → 安装后在左侧动作列表拖一个 HypeRate 动作到任意按键。

每个按键可以独立配置显示内容：

| 显示模式 | 适合场景 |
|----------|----------|
| 实时 BPM 大字显示 | 直播时低头一眼看到当前心率 |
| 峰值心率统计 | 整场会话的最高值，事后复盘用 |
| 心率分区彩色模式 | 根据 Zone 1-5 自动变色，Zone 5 时按键全红 |
| 心率趋势图标 | 上升箭头 / 下降箭头 / 平稳波形，直观反映心跳变化 |

触发器才是真正的玩法核心——当心率达到某个条件时，Stream Deck 自动执行动作：

- **心率 > 160 BPM** 时按钮变红闪烁，同时触发 OBS 场景切换到"紧张时刻"滤镜
- **心率 < 90 BPM** 时按钮变绿，关闭紧张时刻覆盖层回到正常画面
- **心率持续 30 秒 > 150** 自动发 Twitch 弹幕"兄弟们我真的慌了"
- **心率 > 140 且 游戏事件触发** 播放警报音效

如果没有 Stream Deck，Touch Portal（手机屏幕当按键面板）也有 HypeRate 插件，配置方法几乎一样。

### IRL 户外直播模式——把手机变成移动数据采集中心

IRL 模式是 HypeRate 面向户外、运动、极限挑战类直播的杀手锏功能。它利用手机 GPS、蓝牙心率、Apple Weather API 采集多维数据，然后打包成可嵌入直播画面的小部件。

可用组件非常丰富：

| 组件 | 数据来源 | 适合场景 |
|------|----------|----------|
| 心率 BPM | 蓝牙心率设备 | 体力消耗可视 |
| 速度 / 距离 / 海拔 | 手机 GPS | 跑步/骑行/爬山 |
| G-Force 加速度 | 手机加速度计 | 跳伞/蹦极/极限运动 |
| 温度 / UV / 风速 | Apple Weather API | 所有户外场景 |
| 卡路里消耗 | 心率 + 体重参数 | 健身/运动 |
| GPS 实时地图 | Google Maps / OpenStreetMap | 路线可视化 |

配置步骤：HypeRate APP → 进入 "IRL / Outdoor" 标签页 → 勾选要显示的组件 → 选择排列方式（大面板 / 独立小部件 / 地图+侧边栏）→ 选设计模板 → 生成 URL 嵌入 OBS。

> [!TIP]
> IRL 模式下 GPS 是核心数据来源，但也最耗电。建议准备 20000mAh 以上的移动电源，同时降低手机屏幕亮度（APP 不需要亮屏也能后台采集），关闭 Wi-Fi 和蓝牙其他设备节省电量。户外信号不好时 APP 会缓存 GPS 数据，信号恢复后自动续传，但直播推流本身更耗电——通常需要两台设备：手机负责采集，电脑负责推流。

### 游戏引擎插件——把心率变成游戏机制

这是 HypeRate 最有想象力的功能：官方为 Unity、Godot、Unreal Engine 三大引擎提供插件，让开发者把玩家心率直接接入游戏逻辑。底层原理是 HypeRate APP 采集数据后通过 WebSocket 推送给云端，引擎插件从云端接收心率数据，然后在事件回调里驱动游戏逻辑。

三个引擎的插件状态对比：

| 引擎 | 插件状态 | 安装难度 |
|------|----------|----------|
| Unity | 官方维护（35000+ 开发者） | 中等，C# 脚本 |
| Godot | 官方维护 | 简单，GDScript 易上手 |
| Unreal Engine | 官方维护 | 中等，蓝图可视化 |

典型玩法创意：

- **恐怖游戏**：心率越高敌人刷新越频繁、移动速度越快、AI 攻击性越强，玩家越紧张游戏越难
- **健身游戏**：心率 Zone 2（有氧区）时训练效率 +50%，Zone 4 以上（高压区）时耐力消耗加快
- **节奏游戏**：心率决定游戏 BPM，玩家心跳越快节奏越快
- **评分系统**：心率波动越小（全程平稳），最终得分越高——考验玩家的心理素质

Unreal Engine 的优势是纯蓝图可视化，完全不用写代码：拖一个 "Heart Rate Updated" 事件节点，连一个 "BPM > 150？" 分支，是则 Set Enemy Speed ×1.5，否则 ×1.0——拖拽几步就完成了心率驱动的游戏难度调节。

### 常见故障排查——蓝牙断连修复

心率设备蓝牙断连是使用中最频繁遇到的问题，按概率排序的排查清单：

**第 1 步：检查电量**（概率最高）
心率胸带有 LED 指示灯，亮红灯 = 低电量；Apple Watch 低于 20% 会自动停止蓝牙广播以省电；桌面端直连时在 Connection 面板里可以直接看电量。充电解决。

**第 2 步：检查心率带感应区是否干燥**（第二常见）
胸带款的感应区需要微湿才能稳定工作。取下胸带，用清水湿润 logo 下方的两个金属触点，擦干多余水但保持微湿，重新戴上确保紧贴皮肤。运动前 1 分钟先湿润感应区能显著提升信号稳定性。

**第 3 步：蓝牙设备过载**
一个手机/电脑同时连接太多蓝牙设备会导致心跳不稳定。断开不需要的设备，尤其是无线键鼠——它们用 2.4GHz 频段，和蓝牙心率设备竞争信号。

**第 4 步：距离和干扰**
蓝牙有效范围 10 米内（无障碍物），一堵承重墙让范围减半。2.4GHz Wi-Fi、微波炉、USB 3.0 扩展坞、厚金属手机壳都可能干扰蓝牙信号。手机/电脑尽量放在心率设备 5 米以内，Wi-Fi 切到 5GHz 频段，暂时关闭 USB 3.0 扩展坞。

**第 5 步：HypeRate APP 版本**
旧版本可能有已知的连接 Bug，App Store / Play Store 或官网下载最新版覆盖安装。

HypeRate 内置自动重连机制：断连后 3 秒开始尝试，间隔指数退避（3s → 10s → 30s → 60s），连续 5 分钟失败后停止。如果发现没自动重连，强制退出 APP 再打开通常能恢复。
