## ✨ Walk Play 是什么

Walk Play 是一款专门为安卓 USB-C 耳机/DAC 设计的**参数均衡调音应用**。它通过 USB OTG 协议连接你的耳机或解码设备，用 DSP 芯片实时处理音频信号，让你能够精确调整声音的各个频段——低音厚度、人声清晰度、高频齿音都能自己掌控。

和手机自带的图形均衡器（只有几个固定频段滑条）不同，Walk Play 用的是**参数均衡器（PEQ）**，每个频段都有三个可自由调整的参数：频率点、增益、品质系数。这意味着你不仅能决定调哪个频段、调多少，还能决定调整的范围有多宽——调音精度和灵活性远超普通 EQ。

Walk Play 没有上架任何应用商店，只能通过官网、EPZ Audio 驱动页或夸克网盘获取 APK 安装包。开发者腾腾高科提供了云端预设存储，你可以为不同场景、不同耳机各存一套调音方案，换设备或重装都能同步回来。

适合谁用：手里有 USB-C 接口的有线耳机或 DAC、对声音有追求、愿意花时间折腾调音的安卓用户。如果你觉得地铁里人声被盖没了、深夜听耳机齿音刺耳、FPS 游戏里脚步声分不清方向——Walk Play 就是为此而生的。

## 🔧 安卓安装步骤详解

Walk Play 的安装比普通 APP 多一道坎——因为它不在应用商店上架，安卓默认会拦截未知来源的 APK。下面把整个流程拆解开。

### 第一步：下载 APK

从官方渠道获取安装包：官网 szwalkplay.com 的下载页、EPZ Audio 官方驱动页，或开发者分享的夸克网盘。下载时留意文件大小——正常的 APK 应该在官网页面显示的数值附近，差得太多可能是下载不完整或被篡改过。

> [!WARNING] 只从官方渠道下载
> 任何第三方下载站、微信群转发的 APK、陌生网盘链接都不要装——可能被植入恶意代码。Walk Play 已知的安全分发渠道只有官网、EPZ Audio、夸克网盘三处。

### 第二步：开启"安装未知应用"权限

这是**最关键也最容易卡住的一步**。Android 11 及以上版本（绝大多数 2021 年后的手机）权限开启路径统一：

1. 打开手机**系统设置**
2. 搜索 "安装未知应用" 或 "Install unknown apps"
3. 找到你用来下载 APK 的那个 APP（Chrome、夸克网盘、系统文件管理器等）
4. 点进去，把 **"允许从此来源安装"** 开关打开
5. 返回文件管理器，重新点击 APK 安装包

不同品牌的设置菜单路径略有差异，下面是常见品牌的对照表：

| 品牌 | 设置路径 |
| --- | --- |
| 小米/Redmi（MIUI/HyperOS） | 设置 → 更多设置 → 隐私保护 → 特殊权限设置 → 安装未知应用 |
| 华为/Honor（HarmonyOS/MagicOS） | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| OPPO/vivo/iQOO（ColorOS/OriginOS） | 设置 → 安全（或隐私）→ 允许安装未知应用 |
| 三星（One UI） | 设置 → 生物识别和安全 → 安装未知应用 |
| 原生安卓（Pixel 等） | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

### 第三步：应对"风险应用"确认弹窗

开启权限后，部分国产系统还会弹第二次确认——这是**所有非应用商店来源 APK 的统一提示**，不是真的有风险：

- 弹窗说"检测到未知来源应用"时，点击 **"继续安装"** 或 **"仍然安装"**
- 如果有"安全安装"和"普通安装"两个选项，选**普通安装**（安全安装会引导你去应用商店，而 Walk Play 根本不在那里）

### 第四步：常见安装失败排查

| 现象 | 可能原因 | 解决方法 |
| --- | --- | --- |
| 点击安装包没反应 | 文件管理器不兼容 / APK 文件损坏 | 换系统自带"文件"APP 打开；核对文件大小；删掉重下 |
| 提示"安装包已损坏" | 下载中断或被多线程工具破坏 | 用浏览器单线程下载；删掉重新下载 |
| 提示"与现有应用冲突" | 之前装过不同版本 | 先卸载旧版 → 设置 → 应用 → 找到 Walk Play → 卸载清理数据 → 重装 |

## 📖 调音入门与进阶

Walk Play 的核心价值在于调音。理解 PEQ 的三个参数是第一步，然后是跑通音频链路，最后用好预设存储。

### PEQ 三参数：Gain、Q、Frequency 各自控制什么

参数均衡器（PEQ）和图形均衡器的区别在于——图形 EQ 给你固定频段的滑条，而 PEQ 的**每个频段都有三个自由参数**：

**Frequency（频率点）** 决定滤波器作用在哪个频率。Walk Play 覆盖 20 Hz 到 20 kHz 的完整音频频谱，大致可以这样分段：

| 频段 | 范围 | 调音目标举例 |
| --- | --- | --- |
| 低频 | 60-250 Hz | 增加鼓点重量、低音厚度 |
| 中低频 | 250-500 Hz | 增加人声温暖感 |
| 中频 | 500-2000 Hz | 提升人声清晰度 |
| 中高频 | 2000-6000 Hz | 削齿音、加空气感 |
| 高频 | 6000-20000 Hz | 加泛音亮度 |

**Gain（增益）** 决定在该频率点提升或衰减多少 dB。正值提升、负值衰减。安全范围是 **-6 dB 到 +6 dB**，极端调整（±12 dB 以上）容易引入削波失真。同时提升多个频段时，总增益不要超过 +12 dB——Preamp 可以帮你减掉这个冗余。

**Q（品质系数）** 决定滤波器的带宽。Q 值越高，影响范围越窄（只影响 Frequency 附近一小段）；Q 值越低，影响范围越宽：

- Q = 0.707：1 倍频程带宽，覆盖范围宽，适合调整整体质感
- Q = 1.0：日常调音最常用的带宽
- Q = 2.0：窄带，适合消除特定频率的刺耳点
- Q = 5.0：非常窄的尖峰，用于消除单个频率的共振峰

> [!TIP] 新手的三条调音纪律
> 1. **先定 Frequency 再动 Gain**：先把频率点拖到目标频段中心，再调增益，最后调 Q——别反过来
> 2. **一次只动一个频段**：同时动两三个频段你就分不清到底是哪个起了作用
> 3. **小步慢调**：每次 Gain 变 1-2 dB，耳朵比你想象的敏感

### 跑通音频链路：插上耳机没声怎么办

Walk Play 通过 USB OTG 协议与耳机/DAC 通信——OTG 不仅传数据，**还给耳机供电**。如果插上耳机没声，按下面的顺序排查，每一步都确认过再进下一步：

**1. OTG 开关确认（最常见原因）**

很多安卓手机的 OTG 开关**每次使用都需要手动开**——重启手机或换 USB 口后可能自动关闭。正确顺序是：**拔下耳机 → 开 OTG → 再插耳机**。

验证方法：插一个普通的 USB 闪存盘，看手机能不能识别并打开文件管理器。U盘能开 = OTG 正常。

**2. 音频输出路径切换**

部分安卓手机插入 USB 耳机后，不会自动把音频输出从"扬声器"切到"USB 设备"。手动检查：

| 品牌 | 输出路径设置 |
| --- | --- |
| 小米/Redmi | 设置 → 声音与振动 → 音频输出 → 选 USB 设备 |
| 华为/Honor | 设置 → 声音和振动 → 声音输出 → 选 USB |
| 三星 | 设置 → 声音和振动 → 音频输出 → 选你的 USB 设备 |
| 原生安卓 | 下拉通知栏快捷设置 → 音频输出 |

**3. 音量检查**

Walk Play APP 或网页调音台里的**系统音量**是不是调到了 0？安卓系统音量（手机侧键）是不是调到了 0？DAC/耳机本身有没有物理音量旋钮？三处都确认一下。

**4. DSP 调音兜底验证**

Walk Play 的 DSP 调音是覆盖式的——如果不小心把所有 EQ 频段拉到最低、或者 Preamp 拉到最低，DSP 输出会是几乎静音。快速验证：切到**"全零预设"**（所有 EQ Gain = 0，Preamp = 0，原始滤波器），播放一段确定有声音的测试音频。全零预设下有声音 = 调音设置有问题，全零预设下也没声 = 继续往下排查。

**5. 硬件问题兜底**

以上都过了还是没声：换一根确认是数据线（不是充电线）的 USB 线、换另一台手机试这个耳机、确认 DAC/耳机有没有电或物理电源开关。

```
Walk Play 调音 → DSP 芯片 → USB 数据输出 → DAC 供电/解码 → 耳机喇叭
     ↑                ↑            ↑              ↑            ↑
   EQ/Preamp    OTG 供电      USB 线质量      DAC 工作状态   耳机本身
```

### 预设管理：好的命名让你三个月后也认得出

Walk Play 的云端存储让你可以存**不限数量**的自定义预设。但如果起名叫"预设1""新预设"，三个月后你自己都不知道哪个是什么。推荐的命名结构是：

`[使用场景] + [调音目标] + [适配耳机]`

| 好的命名 | 一眼能看出什么 |
| --- | --- |
| FPS 游戏 脚步声清晰 TP35Pro+Supermix4 | 玩 FPS、想听清脚步、给 TP35 Pro 配 Supermix 4 调的 |
| 通勤地铁 低频耐听 P40 | 地铁环境、低频够但不轰、给 P40 调的 |
| 深夜爵士 温暖松弛 平板耳塞 | 深夜用、爵士、整体松弛、平板耳塞 |
| 播客有声书 人声突出 | 听播客、重点人声、通用预设 |

> [!NOTE] 多耳机场景
> 如果你有多只 USB-C 耳机，**必须把耳机型号写进预设名**——不同耳机的调音完全不同，不标注型号的预设等于白存。可以用 emoji 快速区分大类：🎮 游戏、🚇 通勤、🎵 音乐、🎙️ 播客、🌙 深夜。

定期整理预设——过时的删掉、相似的合并、常用的排前面。每月花 5 分钟做这件事，比三个月后翻一堆"预设1""预设2"高效得多。
