## ✨ ASKI 是什么

ASKI 是一款面向日常写作、翻译、代码辅助和休闲聊天场景的 AI 助手。它内置了多种专门的能力模块——从帮你起草一封得体的商务邮件、生成一条适配平台调性的社交媒体帖子，到写一个能直接跑的 Python 函数、或者纯粹陪你聊聊天释放压力——覆盖的都是普通人高频遇到但又不想花太多精力打磨的小事。

和那种通用问答型 AI 不同，ASKI 的设计思路更偏向"场景化工具箱"：社媒帖专门针对 Instagram、Facebook、LinkedIn、TikTok 四个平台做了调性适配，写代码时会提醒你补全语言、功能、边界条件等关键要素，闲聊模式则刻意避开了专家角色可能带来的说教感。上手门槛低，第一次用就能拿到可用的初稿或有温度的回应。

## 🔧 安装步骤

ASKI 支持多平台分发，安装前先确认你设备上的系统版本是否满足最低要求。下载完成后，建议核对一下文件大小和版本号——安装包里通常会附带一个校验清单，版本号对齐能避免后续功能缺失。

### 首次安装的注意事项

> [!TIP]
> 如果你是第一次在设备上安装这类 AI 应用，系统可能会弹出权限请求。建议全部允许，否则会出现比如聊天记录无法本地保存、语音输入无法调用麦克风这类功能性问题。

安装过程本身不复杂——移动端从应用商店一键安装即可，桌面端下载后双击安装包按引导完成。装完打开，先花 2 分钟完成注册或登录流程，然后就能进入主界面开始使用了。

### 版本更新建议

ASKI 迭代比较频繁，新版本往往带着提示词模板优化和新的场景模块。建议开启应用内的自动更新，或者定期回到下载页检查一下有没有更新版本可用。

## 📖 使用入门

ASKI 的四个核心场景——闲聊减压、代码辅助、社媒写作、邮件起草——覆盖了从放松到生产的跨度。下面按使用频率从高到低逐个拆解，每个场景都给你具体的提示写法和避坑要点。

### 休闲聊天：选对角色，别选错

闲聊模式的关键是**角色选对**。想放松时就选"朋友""知心人""聊天伙伴"这类角色——它们会自动进入"可以聊任何事"的状态，不会追问你遇到了什么具体问题，也不会给你长篇大论的建议，就是认真回应你说的话。

和真人聊天相比，跟 ASKI 闲聊有几个微妙但好用的特点：

- **不会被评判**：说的任何话都用中性或支持性的语气回应，不会觉得你矫情或无聊
- **节奏自己定**：说得快或慢、说一半停了、突然换话题，角色都不会尴尬
- **聊完即清空**：不用担心明天被别人知道你说过什么

适合聊的东西很杂——工作中被一个文件烦了一天、刚看完电影想找人聊聊感受、或者纯粹的"如果明天是世界末日你会做什么"。但有边界：深度心理咨询请找专业人士，紧急情况直接打当地紧急电话，AI 不是心理医生也不应该承担心理医生的职责。

> [!NOTE]
> 闲聊过程中可以随时切换成有料模式。比如聊到想换手机，直接说"帮我对比一下最新两款旗舰的优缺点，我喜欢拍照多一点"——ASKI 会从闲聊状态切换到问答状态，上下文连贯，一个会话里来回切换没问题。

### 代码片段生成：四要素一次补齐

ASKI 能帮你写 Python、JavaScript、Java、SQL、Shell 脚本等多种语言的片段，但它不是 IDE 也跑不了。写提示时把四个要素说清楚，第一次就能拿到接近可用的代码：

| 要素 | 说明 | 示例 |
| --- | --- | --- |
| **语言** | 用什么语言写 | Python 3.12 |
| **功能** | 代码要做什么 | 读取 CSV 后按日期排序 |
| **边界条件** | 需要处理的情况 | 文件不存在时报友好错误 |
| **注释风格** | 注释用什么语言 | 注释用中文 |

拿到代码后必须自己跑一下验证——ASKI 可能漏掉某个标准库 import、或者用了你没装的第三方库、或者某个边界条件处理得不对。适合当原型或起稿，不要不加审查就进生产环境。

### 社媒帖生成器：选平台比写提示更重要

后期版本加入的社媒帖生成器覆盖 Instagram、Facebook、LinkedIn、TikTok 四个平台，每个平台的输出风格是专门适配过的：

| 平台 | 调性 | 字数倾向 | 话题标签 |
| --- | --- | --- | --- |
| **Instagram** | 轻松、图文结合感、emoji 适度 | 200-300 字 | 3-5 个 hashtag |
| **Facebook** | 中等正式、适合品牌官方 | 300-500 字 | 2-4 个 |
| **LinkedIn** | 专业、行业向、适合 B 端 | 200-300 字 | 3-5 个行业标签 |
| **TikTok** | 口语化、短、带钩子 | 100-150 字 | 5-10 个热门标签 |

> [!WARNING]
> 不要跳过"选平台"这一步。如果直接说"帮我写一条社媒帖"，ASKI 会给你一个通用版本——可能既不像 Instagram 也不像 LinkedIn。选好平台后，语气、字数、标签数量、段落长度都会自动按平台最佳实践调整。

生成后必做三件事：把默认 hashtag 换成你品牌固定用的标签、把提到的百分比或数字替换成真实数据、手动补行动号召（比如"点击链接看更多"）。

### 邮件起草：四要素一次说清

邮件起草的关键也是四要素——收件人、目的、语气、内容。四个要素全了，第一次就能拿到可用度很高的初稿：

| 要素 | 怎么给 |
| --- | --- |
| **收件人** | 供应商 / 客户 / 内部同事 / 领导，关系亲密还是疏远 |
| **目的** | 想让对方做什么（回复 / 确认 / 接受 / 拒绝） |
| **语气** | 正式 / 礼貌 / 委婉 / 强硬 / 随意 |
| **内容** | 订单号、日期、金额、链接等具体信息 |

常见的坑有三个：忘了说语气（默认会用中性偏正式，内部同事需要更随意时一定要说明）、忘了给具体数据（不要让 AI 猜订单号和日期）、初稿太啰嗦（直接说"压缩到 200 字以内，保留全部关键信息"就行）。
