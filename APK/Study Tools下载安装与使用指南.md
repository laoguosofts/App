## ✨ Study Tools 是什么

Study Tools 是一款面向 Android 单机游戏的数值调整工具，核心思路是读取游戏的本地存档文件或进程内存，让玩家对金币、属性、画质、速度等参数进行自由修改。它同时提供无 Root 和 Root 两种运行模式——无 Root 模式主打零门槛、直接改存档文件；Root 模式则深度进入进程层，解锁内存搜索、动态锁定等高阶能力。

和市面上大量主打"一键修改""自动外挂"的同类工具不同，Study Tools 走的是一条更克制的路线：不做联网游戏的服务器端数值篡改，不搞充值货币破解，专注把**单机游戏本地可改的那部分**做好做透。这也解释了为什么它能在同类里保持相对稳定的用户群——定位清晰、不越界、维护成本可控。

适用人群很明确：喜欢单机 RPG、模拟经营、放置类游戏，不想被数值 grind 卡住进度，但又不想折腾 Root 的 Android 玩家。有一定动手能力（能看懂包名、分清楚本地和服务器数据）的用户能把它用得最顺手。

## 🔧 安装与权限配置

### 安装步骤

1. 从官方下载地址获取 APK 安装包，建议直接下载到手机本地存储
2. 进入手机设置 → 安全或隐私 → 开启「允许未知来源应用安装」（各品牌路径略有差异，小米、OPPO、vivo 需在安装时弹窗确认授权）
3. 点击 APK 文件按提示完成安装

> [!WARNING]
> 安装来源不明的 APK 存在安全风险，务必从官方渠道下载。安装完成后建议关闭「允许未知来源」开关。

### 首次启动后的权限处理

Study Tools 需要几项必要权限，进入应用后逐一授予：

- **存储访问权限**：读取和修改游戏存档文件的基础
- **无障碍服务**：部分机型上用于识别游戏进程窗口
- **Root 权限**（仅 Root 模式用户）：首次进入 Root 模式时 Magisk 会弹窗请求授权，勾选"始终允许"

### 版本核对

建议安装后在应用设置里看一眼版本号，和下载页标注的最新版本对照。版本过旧可能存在兼容性问题或已知 Bug。

## 📖 从选目标到改参数：使用入门

### 第一步：认准包名，别选错游戏

Study Tools 的目标列表里每个应用都带包名，格式一般是 `com.开发者名.产品名`。**包名是唯一的**——同一台手机上同一个应用只有一个包名，而显示名可能重复（比如同装了国内版和国际版都叫"三国杀"）。

选目标时要避开三类条目：

| 要避开的 | 判断依据 |
|----------|----------|
| 系统进程 | `com.android.*`、`com.miui.*`、`com.huawei.*` 等厂商系统包 |
| 同名应用 | 国际版常带 `.global`、`.kr` 等后缀，装了多版本的建议卸载多余的 |
| 其他游戏工具 | 加速器、辅助器也会被识别，改自己没意义 |

> [!TIP]
> 选完目标进入调整界面后，先切回游戏确认正常运行、没崩溃，再回来改一个小参数验证——能生效就说明选对了。

### 第二步：改典型参数

**金币/货币类**是成功率最高的类型，操作流程通用：

1. 进游戏看一眼当前金币数（比如 350）
2. 切到 Study Tools 搜 350，改成想要的值（比如 999999）
3. 切回游戏确认金币变了

但要注意：联网游戏的充值货币（钻石、点券）在服务器端，改了也会回退；联网游戏的金币也可能在服务器，表面显示变了、实际买东西时提示余额不足。

**角色属性**（生命、攻击、防御、速度、暴击率）操作类似——进角色详情页记数值、搜、改。不过属性改太大可能被游戏内部校验拒绝，建议**分步调**：250 → 500 → 999。还有一类游戏的属性是等级推导的（攻击 = 基础值 × 等级系数），直接改存不了值，得改等级。

**画质与分辨率**不走"搜数值再改"的路子，Study Tools 在配置界面直接提供选项或修改游戏的 config.ini。改太高超出手机硬件能力反而卡顿，按硬件实际来。

**游戏速度倍速**是模拟经营和放置类玩家最常用的功能——2x、3x 倍速加速生产和成长，但改到 10x+ 可能导致游戏逻辑错乱。带时间锁的游戏（比如每 8 小时领奖励）倍速能不能绕过，取决于游戏读设备时间还是服务器时间。

**灵敏度与操作参数**（FPS、赛车类的触控灵敏度、陀螺仪灵敏度）调大后操作难度明显降低，改完一定要适应一下新手感再打难关。

### 第三步：实时验证的正确姿势

改完参数**不要只看 Study Tools 里的显示**——那里只是你填的值，不代表游戏真的读到了。

标准验证流程：

1. Study Tools 里改完参数，**不要强制停止游戏进程**（让游戏继续在后台跑）
2. 按最近任务键切回游戏
3. 找到参数对应的界面看值有没有变
4. 进一步做"消费测试"——改了金币去商店买东西看能不能花出去；改了攻击力去打一只怪看伤害数字

很多游戏的数值显示和实际效果是两回事：表面上金币显示 999999，但商店购买时还是按原值扣；属性面板显示攻击力 9999，但打怪伤害还是原值。这类情况说明游戏在读另一处服务器值或进程内存值。

验证时还有几个细节：

- 改完先等 1~2 秒再切回——某些游戏读取配置有延迟
- 不要同时改多项——如果同时改了金币和攻击力，切回发现只变了一个，你搞不清楚哪个没改对
- 显示变了但实际不工作，等于没改

### 改了没生效的排查顺序

按三级排查走：

**第一级**——选的游戏进程对不对？改的数值类型对不对（金币是本地还是服务器）？

**第二级**——游戏是不是刚更新过（存档结构可能变了）？是不是一次改了多项？

**第三级**——存档文件是不是被游戏加密了？换个参数试试（比如改速度不行但改金币行，说明不是完全不能改）。

排查完这三级还不行，大概率这款游戏的数值不在本地、或者 Study Tools 的过滤没识别到正确目标。

### Root 模式的能力增量与代价

Root 模式包含无 Root 模式的全部功能，额外解锁：

| 能力 | 说明 |
|------|------|
| 进程内存搜索 | 直接读游戏进程内存，定位任意值 |
| 动态值锁定 | 把实时变化的数值锁死（比如血量恒定为 9999） |
| 运行时注入 | 游戏运行过程中实时修改参数 |
| 完整功能可用 | 所有高级调整选项被解禁 |

简单理解：无 Root 模式改**存储层**（存档文件），Root 模式改**进程层**（运行时内存）。

> [!WARNING]
> 解锁 Root 有实打实的代价：解锁 bootloader 会清空手机全部数据；绝大多数品牌保修直接失效；微信支付、支付宝、手机银行等会检测 Root 状态拒绝运行；系统 OTA 升级经常失败，每次升级后可能需要重新刷 Magisk。

**不要为了单一款游戏专门去 Root**。先确认三个问题：你对哪款游戏的无 Root 能力确实不够用？这个游戏值不值得承担上面所有代价？你有没有设备完整备份的能力？三个问题有任何一个答案模糊，建议继续用无 Root 模式先跑一段时间再说。很多人刷了 Root 最后发现还是回到本地存档修改更稳定。
