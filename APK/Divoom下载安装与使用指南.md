## ✨ Divoom 是什么

Divoom 是一家专注于**像素艺术显示屏**和**桌面信息设备**的品牌，产品线覆盖从纯 LED 点阵像素屏到 IPS 透明相框，从入门级蓝牙小屏到多屏仪表盘。它的核心吸引力在于：硬件本身颜值高、APP 生态完整、社区像素画资源丰富。

Divoom 的硬件家族大致分三条线：Pixoo 纯屏系列（只有屏幕、无音箱、主打像素艺术）、带音箱的 PixelBox/Ditoo 系列、以及 Times 家族的信息屏产品线（Times Gate 五屏仪表盘、Times Frame 透明相框）。所有产品都通过 Divoom APP 控制，APP 内置像素画编辑器、Widget 数据面板、社区画廊三大核心能力。

适合谁用？桌面美化爱好者、数码玩家、需要同时监控多组实时数据的加密货币交易者或内容创作者、想要给爸妈送一份有互动感的礼物的人——这些都是 Divoom 的高频用户画像。

## 🔧 怎么安装与配对

Divoom 的安装分两步：先装 APP，再把硬件设备和 APP 配对。不同型号的硬件配对方式略有差异，但流程大体一致。

### 第一步：安装 Divoom APP

**移动端（主要使用方式）**：

1. 打开手机上的应用商店（Google Play 或 App Store）
2. 搜索「Divoom」，找到官方开发者发布的 APP
3. 下载并安装，首次启动时允许通知和蓝牙权限

> [!NOTE]
> Divoom APP 是所有硬件的控制中心，像素画编辑、Widget 设置、固件升级全部通过 APP 完成。目前没有独立的桌面端软件，PC 上需要用安卓模拟器来运行。

### 第二步：硬件设备配对

**Pixoo 系列（蓝牙连接）**：

1. 用 USB-C 线给 Pixoo 通电（Pixoo-16 / Pixoo-Max 无内置电池，必须插电）
2. 打开 Divoom APP → 首页点「+」→ 选「添加设备」
3. APP 自动扫描附近的蓝牙设备，在列表里找到你的 Pixoo
4. 点击配对，屏幕上会显示配对成功提示

**Pixoo-64 / Pixoo-64Ⅱ / Times Gate / Times Frame（Wi-Fi 连接）**：

1. 设备通电，等待指示灯进入配对模式（通常是呼吸灯）
2. APP 添加设备时选「Wi-Fi 设备」
3. APP 会弹出 Wi-Fi 配置页面——**注意 2.4G / 5G 频段**：Pixoo-64 只支持 2.4G，Pixoo-64Ⅱ 支持双频，Times Gate 和 Times Frame 也只支持 2.4G
4. 输入 Wi-Fi 密码，APP 通过蓝牙把凭证推给设备，设备再连上网

> [!WARNING]
> 如果你的路由器只开了 5GHz 频段，Pixoo-64 / Times Gate / Times Frame 将无法连接。需要在路由器管理页面开启 2.4G 频段，和 5G 共存即可。

### 配对完成后做这三件事

1. **固件升级**：APP 会自动检测是否有新固件，有就升级。新固件往往会解锁新的 Widget 类型和显示效果。
2. **选一个初始像素画**：社区画廊里有 70 万+ 现成作品，随便选一个推送到屏幕上，第一眼就能看到效果。
3. **设置第一个 Widget**：比如天气时钟——在 APP 的 Widget 面板里勾选「天气」「时钟」，几秒后屏幕上就会实时显示温度和时间。

## 📖 Divoom 使用入门

下面从几个高频使用场景切入，帮你快速上手 Divoom 的核心玩法。

### 一、Pixoo 系列：纯像素艺术屏的玩法

Pixoo 系列是最纯粹的像素艺术显示方案，没有音箱、没有多余功能，就是一块屏幕。适合已经有音响系统、只想在桌上摆一块"小画框"的玩家。

**Pixoo-16 / Pixoo-Max（蓝牙款）**：

Pixoo-16 有 256 颗 RGB 灯珠（16×16），Pixoo-Max 有 1024 颗（32×32）。两者都通过蓝牙连接手机，**断开蓝牙后只能显示最后一次缓存的内容**——这意味着如果你想让屏幕实时刷新数据（比如股票价格），手机必须一直保持蓝牙连接。

核心玩法包括：像素艺术显示、时钟面（带实时天气温度）、社交媒体计数（YouTube 订阅数 / Twitter 粉丝数）、音乐可视化（随节奏闪烁）、噪声检测（环境噪音大时触发表情或提示）、倒计时、计分板。

**Pixoo-64 / Pixoo-64Ⅱ（Wi-Fi 款）**：

Pixoo-64 把像素密度提升到 4096 颗灯珠（64×64），更重要的是它用 **Wi-Fi 替代了蓝牙**。这带来一个关键差异：**能实时同步在线数据**。

- 股票行情、加密货币价格（BTC / ETH）需要持续联网刷新
- Twitch 粉丝数、League of Legends / Fortnite 游戏数据也需要联网
- 蓝牙屏一旦断开手机连接就定格了，Wi-Fi 屏则独立联网、24 小时在线

Pixoo-64Ⅱ 是 Pixoo-64 的小升级，主要增加了**5GHz Wi-Fi 支持**——如果家里路由器两个频段都开，它会自动选信号好的那个。除此之外功能完全一样。

### 二、Times Gate：五屏仪表盘

Times Gate 在一块硬件上堆了 **5 块独立的 LCD 屏幕**，每块 128×128 像素，可以同时显示完全不同的内容。它的定位就是桌面信息仪表盘，目前没有同类替代品。

最适合的用户画像：**加密货币交易者**（BTC 一块、ETH 一块、大盘指数一块、新闻标题一块、Logo 动画一块）、**内容创作者**（YouTube 订阅数、Twitch 粉丝数、直播倒计时、品牌 Logo 各占一屏）、**游戏玩家**（游戏时钟、天气、Discord 在线好友、游戏内金币、像素动画）。

连接方式是 2.4G Wi-Fi（不支持 5GHz），必须插电使用，没有内置电池。单屏的显示模式可以调整：居中显示（内容缩到中间、周围黑边）、拉伸填充（内容拉满屏幕）、原始尺寸（保持分辨率居中）。

每块屏幕的方向也可以单独旋转——比如屏幕 1 正方向、屏幕 2 倒转，制造视觉趣味。屏幕之间的内容互相独立，你在 APP 里分别给每一块选 Widget 或像素画就行。

### 三、Times Frame：透明相框 + 远程发图

如果说 Times Gate 是给数据党准备的，Times Frame 就是给家庭和送礼场景设计的。它用一块 **10.1 英寸透明 IPS 面板**（1280×800 分辨率），看起来像悬浮在底座上的相框，同时又能叠加显示 Widget。

**核心卖点一：透明 IPS 面板 + 照片/Widget 同时显示**

照片可以作为背景，Widget（时钟、天气、番茄钟、股票）叠加在上面。叠加方式有三种：半透明悬浮框（不遮挡太多照片）、实色矩形框（照片背景被框挡住）、无边框（Widget 文字直接叠在照片上）。Widget 面板的位置可以在屏幕上自由拖拽，不同位置适合不同构图的照片。

**核心卖点二：多用户远程发图**

Times Frame 是 Divoom 产品线里**唯一支持多用户远程发图**的设备。原因很实际：它用 IPS 液晶屏有足够好的照片效果，而且自带 **64GB 本地存储**（能存 70 万张照片或 6000 分钟视频）。其他型号要么分辨率不够（Pixoo 系列只适合像素艺术）、要么没有内置存储（Times Gate 纯实时联网）。

开启流程很简单：Divoom APP → Times Frame 详情页 → 找"邀请成员"入口 → 生成二维码或邀请链接 → 发给对方。对方**不需要买任何 Divoom 硬件**——只要手机上装了 Divoom APP 就能往你的 Times Frame 推送照片、短视频、像素表情。

权限分两级：标准权限（只能推送内容、不能改设置）和管理员权限（还能添加/移除其他成员、修改播放设置）。大部分场景用标准权限就够了。

推送后，照片自动进 Times Frame 的本地存储，播放列表自动更新（可以设置是插队立即显示还是排队等当前轮播完），你的手机 APP 会收到推送通知。

**典型使用场景**：

- 给爸妈送礼：帮他们配好 Wi-Fi，之后你从自己手机上随时推送新照片（旅行、做饭、宠物日常），爸妈不需要学任何操作
- 异地情侣：互相发照片、"想你了"的文字，对方桌面立刻浮出来
- 家庭共享：全家每人的 Divoom 账号都加进来，照片轮播变成家庭情感聚合点

Divoom 官方特意强调了隐私设计：照片传输端到端加密、送达后清除传输痕迹、全部存在本地 64GB 而非云端。管理员可以随时撤销任何成员的邀请，也能删除设备上的任何照片。

### 四、屏幕外观与色温调节

**方形屏默认不需要调方向**，但 Pixoo 系列 APP 里有"旋转"选项，可以把显示内容旋转 90° / 180° / 270°——适合把音箱横过来放的创意场景。Times Frame 默认横放，也能切竖放模式，屏幕里的照片和 Widget 自动旋转 90°，更适合书架或高的仪表盘。

**色温调节**主要影响 LCD 屏幕（Times Gate / Times Frame）——冷色调偏蓝适合游戏房间深夜用，暖色调偏黄适合卧室餐桌。LED 点阵屏（Pixoo 系列）的色温是固定的，调不了。

Times Frame 还有一些电子相框专属设置：照片过渡效果（硬切 / 淡入淡出 / 擦除 / 缩放）、叠加层自动隐藏（照片刚切换时先显示完整照片，几秒后 Widget 浮现）。

### 五、定时休眠与屏幕关闭

定时休眠时可以选两种关闭方式：

| 方式 | 效果 |
|---|---|
| 调至最暗 | 屏幕还在亮，只是调到最低亮度（通常还能隐约看到时钟数字）。适合当小夜灯或不晃眼的闹钟背景。 |
| 完全黑屏 | 屏幕彻底熄灭，不消耗电力，不显示任何内容。省电最彻底。 |

放在卧室的话推荐"调至最暗"模式——既能当小夜灯用，闹钟响铃时也不需要等屏幕恢复。
