## ✨ marvisapp 是什么：一款预置多 Agent 的 AI 电脑管家

marvisapp 是腾讯推出的一款跨平台 AI Agent 产品，定位为"AI 电脑管家"——它的核心思路不是让用户从零搭建工作流，而是**出厂预置 6 个专职 Agent**，用户说一句话，主 Agent 自动拆解任务、调度多个 Agent 并行干活，过程和结果都有日志透明展示。

四端覆盖（Windows / macOS / Android / iOS），主打三大能力：电脑远控与跨端协同、本地文件与图库检索、多 Agent 自动调度。目标人群包括普通职场用户和电脑操作不熟练的用户——官方明确说，"先学会怎么搭工作流"这一步往往就是他们的终点，所以选择了零配置上手的路线。

和市面上强调"自定义空间"的 Agent 产品不同，marvisapp 把重点放在**开箱即用**上：不用写 Prompt 模板，不用手动配 Skill，直接输入需求就行。当然自定义的路没有关掉——预置之外仍支持 MCP / CLI 接入、自定义 Skill 导入，只是深度定制留给进阶用户。

## 🔧 安装步骤：四端安装要点与版本核对

marvisapp 的四端安装渠道清晰，各平台注意点不同，下面逐个说明。

**Windows 版**

Windows 是当前功能最完整的平台，系统层能力首发覆盖（系统设置调用、深度文件管理、本地模式均可用）。安装包从官网下载，双击运行按向导完成即可。

> [!NOTE]
> 安装过程中若杀毒软件弹误报，属于常见现象——建议从官方渠道下载安装包后，将安装目录加入信任列表。

**macOS 版**

Mac 版核心能力齐备（对话、多 Agent、文档/图库检索、跨端接管都有），但系统层操控能力和本地模式**正在陆续补齐**（官方口径：本地模式已在短期路线上）。安装包同样从官网下载，macOS 可能会提示"来自未知开发者"——打开系统设置 → 隐私与安全性，在底部确认允许即可。

**Android 版**

2026 年 5 月产品首发时 Android 与 Windows 同步上线，渠道包括应用商店搜索和官网跳转下载。安装时如果跳出"允许安装未知来源应用"的提示，在系统设置里给对应浏览器或文件管理器授权即可。

**iOS 版**

iOS 比安卓晚约一个月，2026 年 6 月中旬跟进上线。下载渠道只有 App Store 搜索，官网的 iOS 下载按钮也会跳转到应用商店对应页面。开发者主体应为腾讯公司——如果搜不到或看到功能差异，以官方最新版为准，移动端功能仍在持续迭代。

> [!WARNING]
> 安装完成后务必核对版本号——四端版本需要一致才能保证跨端协同正常工作。

## 📖 使用入门：六大预置 Agent、跨端远控与双平台差异

marvisapp 的使用门槛低，但功能覆盖面比多数人想象得宽。下面从几个高频场景展开。

### 预置六个 Agent，开箱即用

这是 marvisapp 最核心的设计。文件、系统、应用、网页、搜索等日常场景各有专职 Agent 负责，用户直接说需求，主 Agent 自动判断该调度谁、要不要并行。官方的定位很明确：普通用户不需要先学概念、再搭工作流——上手成本接近零。

对于新用户的建议是，**先别碰自定义**，把预置的六个 Agent 用熟。它们覆盖的场景比想象得宽，用一段时间后你会自然知道哪些活该交给谁——只不过这个判断已经由主 Agent 替你做了。

### 手机连接电脑：从"聊天助手"变"电脑遥控器"

这是整本手册里性价比最高的一个动作——做完它，App 才从单纯的对话助手变成真正的电脑遥控器。流程很简单：

1. 两端都装好客户端，登录**同一个 QQ / 微信账号**；
2. 登录后同一账号下的在线设备会**自动发现**，手机端顶部可以切换"我的手机"/"我的电脑"；
3. 远程操控需要被操控设备**事先授权**，不可强制连接——电脑端会弹出授权请求，确认后建立连接。

连接之后解锁的能力包括：实时查看电脑屏幕画面、触屏远程操控电脑、跨端索取文件、任务跨端续做。安全机制方面，远程操控会话采用端到端加密，授权始终掌握在被控设备手里，任何人无法绕过。

一个值得注意的细节是**交叉远控**——不同体系系统之间可交叉远控，iPhone 可以远控 Windows，安卓手机可以远控 Mac。家庭成员设备系统不一致也不影响。

### Windows 和 Mac 的功能差异

这是官方产品文档反复强调的问题。答案是：**当前阶段 Windows 版功能最完整**，这是"先深后广"的取舍，不是两端都做得浅。

| 能力 | Windows | Mac |
|---|---|---|
| 核心对话与 Agent 能力 | ✅ | ✅ |
| 文档 / 图库检索 | ✅ | ✅ |
| 跨端接管 | ✅ | ✅ |
| 系统层能力（系统设置调用等） | ✅ 首发覆盖 | 后续版本陆续补齐 |
| 本地模式 | ✅ 可用 | 即将上线 |

为什么会有差异？系统层级的能力必须逐个平台做原生适配——每个操作系统的设置结构、权限模型、硬件接口都不一样。Windows 侧与微软的合作让系统设置的理解更原生，团队先在 Windows 上把这条线做深做稳，再向 macOS 迁移。

对于不同用户的建议：主力机是 Windows 的现在就能用到完整能力；主力机是 Mac 的，对话、多 Agent、文档检索、跨端接管已可用，系统层能力关注后续版本；双机用户同账号四端互通，交叉组合都支持。

> [!TIP]
> Mac 版的功能差异**不影响手机 App 的远控能力**——移动端是协同入口，核心差异集中在电脑端的系统层操作，手机连 Mac 照样能看画面、接管、取文件。

### 进阶：自定义扩展

当你把预置 Agent 用熟后，可以按需探索自定义空间——支持接入 MCP / CLI（模型上下文协议）、导入自定义 Skill，以及后续持续扩展的应用授权与端侧模型能力。不过这部分属于进阶玩法，先把基础能力用透再考虑扩展也不迟。
