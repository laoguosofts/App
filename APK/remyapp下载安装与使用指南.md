## ✨ Remyapp 是什么

Remyapp 是一款面向鸿蒙生态的立体空间拍摄与重建应用。它的核心玩法很直观：对着一个物体或场景绕着走一圈拍完，应用会把这段环绕视频重建出可以交互的三维沉浸空间——你能在图库里直接转动、缩放、从不同角度看同一个厨房角落、花束或家具。

与传统的照片和视频相比，立体内容保留了拍摄时的空间层次感，朋友收到后能自己"走到"那个位置再看一遍。应用还支持给重建完成的沉浸空间套用滤镜，生成实景特效视频导出到社交平台，以及与系统图库深度集成的一键保存。

适合谁用呢？喜欢拍生活细节的人可以把家里的小角落存成立体回忆；做家居展示或空间记录的人能绕过专业 3D 扫描设备，只用手机就能出成品；想给朋友寄礼物却想先让对方"看一眼"实物的，用它拍一下花束或小摆件再分享过去，效果比一张静态照片好得多。

## 🔧 Remyapp 安装步骤

Remyapp 主要面向鸿蒙系统，安装方式与普通应用略有不同，下面分情况说明。

**鸿蒙机型安装**

1. 从官方下载页或应用市场获取安装包
2. 如果通过浏览器下载，系统可能弹出「未知来源安装」提示——进入设置 → 安全 → 更多安全设置，打开「允许未知来源应用安装」开关
3. 安装完成后首次启动，应用会申请相机、存储等必要权限，按提示逐一授权即可

> [!WARNING]
> 权限一定要在首次启动时全部授予，中途拒绝某项权限（比如相机）会导致拍摄功能静默失效，重新授权需要在系统设置里手动调整，比较麻烦。

**版本核对建议**

安装完成后，进入应用内「设置 → 关于」查看版本号，与下载页标注的最新版本比对一致即可。如果版本号明显偏低，说明下载时拿到了旧包，建议删除后重新获取。

**存储空间**

立体重建的成品比普通照片大不少——单条沉浸空间占用通常在数十到上百 MB。安装时确保手机剩余存储至少留出 1GB 空间给重建数据，后期素材积累多了可以定期清理旧的重建条目，或者及时存进图库作为独立副本保留。

## 📖 Remyapp 使用入门：从拍摄到成品的完整流程

### 第一步：拍摄——绕着走一圈就对了

打开应用进入拍摄页，屏幕中央会出现一个圆圈标记。这个圆圈不是装饰，而是整个拍摄过程的"锚"——应用靠它知道你在绕着什么转、转到哪里了。

**圆圈对准位置的选择很有讲究**：

| 拍摄对象 | 圆圈应该套在哪 |
| --- | --- |
| 花束 | 花束主体中间，略高于花瓶口 |
| 单人沙发等家具 | 靠背正中 |
| 房间角落 | 房间几何中心，约腰部高度 |
| 桌面摆设组合 | 桌面中心，略低于视线 |
| 相对静止的人物 | 躯干正中 |

对准之后开始绕着目标走，速度以稳定为主、不要忽快忽慢。如果绕行中圆圈跟丢了，停下来重新对准再继续——宁可中断一次，别让半圈素材作废。主体太小的时候可以凑近一点让圆圈尽量贴合，背景占画面比例越低，重建越准。

### 第二步：等待重建

拍完之后应用会提示重建。素材需要上传云端处理，这是产品形态决定的，重建时长取决于场景复杂度和网络状况，一般几分钟内可以完成。等待期间可以把应用切到后台，但不要杀掉进程。

### 第三步：给成品加滤镜调氛围

重建完成只是开始。应用支持给沉浸空间添加滤镜，让立体内容也能调出不同情绪——同一份厨房场景，原样看是纪实感，套上暖色滤镜就是傍晚的松弛氛围，换个冷调则成了清晨的安静。

选滤镜的大致思路：

- 厨房做饭瞬间 → 暖调，突出生活气息
- 花束与植物 → 清透亮调，保留花瓣细节
- 房间角落 → 低饱和，让摆设成为主角
- 旅途房间 → 自然色，还原当时的现场感

> [!TIP]
> 滤镜是"观看层"，不会毁掉原始重建结果，随时可以切回原样。但它可能掩盖重建瑕疵，建议先原样看一遍成品确认几何完整、没有破洞，再上滤镜。

### 第四步：保存与分享

成品可以保存到华为图库，与系统深度集成。操作路径很简单：打开要保存的沉浸空间 → 找到保存入口 → 确认后进入图库。

存进图库的是独立副本，删掉应用里的原条目不影响图库里的留存。长期保留的成品建议都存一份到图库，抗误删也方便后续走系统级分享。

分享前要考虑对方是什么设备：

- **同为鸿蒙设备**：可以直接分享立体形态，对方收到后能完整交互查看
- **非鸿蒙设备**：立体内容会以降级形态呈现。想让任何人都能看到完整效果，建议导出实景特效视频再发

碰一碰分享（近距离直传）不需要对方安装应用，收到的内容在支持立体查看的设备上直接可用。朋友圈等社交平台推荐发特效视频——任何平台都能直接播放，不挑设备。

### 常见痛点提醒

- **重建效果不好**：拍摄时圆圈没对准、绕行路径不完整、光线太暗都会影响重建质量。拍之前留意场景的光线均匀度，避免一半亮一半暗
- **隐私顾虑**：素材上传云端完成重建是产品设计，拍自己家时尽量避开卧室、证件、门牌号等敏感区域
- **存储空间告急**：立体影像单条体积大，定期清理旧条目或及时存图库作为副本
