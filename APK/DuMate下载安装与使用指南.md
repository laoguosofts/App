## ✨ DuMate 是什么

DuMate 是百度推出的一款桌面 AI 智能体工具，定位是"你电脑里的 AI 搭档"。它能直接理解自然语言指令，在本地设备上帮你处理文件、分析数据、自动化重复操作——不需要你会写代码，也不需要切换十几个应用来回复制粘贴。

它的核心能力可以归为三块：**文件智能管理**（合同、纪要、简历里自动抓重点）、**多源数据分析**（跨 Excel 自动建关系做透视、同比环比分析）、**安全沙箱运行**（所有操作在本地隔离环境里完成，数据不出设备）。

DuMate 同时提供免费版和两档付费方案：免费版每天 1000 积分足够日常轻度体验，Pro 版 25000 积分 / 月（¥59）适合每天跑 3~10 个任务的用户，Max 版 100000 积分 / 月（¥129）面向重度用户或团队共用场景。付费用户还能同时获得 Comate AI 对话产品的会员权益。

如果你每天有大量 Excel 要清洗、合同要过目、数据要汇总，但又不想花时间手动做 VLOOKUP 和数据透视，DuMate 可以直接上手。

## 🔧 安装与初始配置

DuMate 支持 Windows 和 macOS 两大桌面平台，Windows 本地沙箱功能从 v1.0.31 开始支持，Apple Mac 从第一版起就具备。以下以 Windows 为例说明安装流程。

### 安装步骤

1. **下载安装包**：通过官方下载页面获取最新版本的 `.exe` 安装程序，文件大小通常在几百 MB 量级——建议对比文件哈希值或版本号，确保下载的是最新正式版而非内测包。

2. **运行安装程序**：双击安装包，Windows SmartScreen 可能会弹出安全提示（这是因为 DuMate 的数字签名不是所有杀毒软件都认识的常见签名），点击"更多信息"→"仍要运行"即可。

   > [!WARNING]
   > 如果你的企业电脑有严格的杀毒策略，安装过程中 DuMate 的沙箱组件可能被误隔离。建议在杀毒软件里为 DuMate 安装目录添加白名单，否则安装后首次启动会报"沙箱初始化失败"。

3. **选择安装路径**：默认安装到 `C:\Program Files\DuMate`，可以自定义到其他盘符。建议安装在空间充足的盘——DuMate 下载的 Skill 包和沙箱缓存会逐步增长。

4. **完成安装并启动**：安装向导结束后勾选"立即启动 DuMate"，首次启动会引导你选择工作区文件夹——**这是整个安全模型的根基**，仔细选好。

### 初始配置关键点

#### 工作区文件夹

首次启动 DuMate 时，它会让你选一个文件夹作为"工作区"。默认情况下 DuMate 只能在这个文件夹里读写文件——不挂载的目录它看不到也操作不了。

- 工作区可以随时在设置里改
- 需要让 DuMate 访问其他目录时，手动"挂载"即可（v1.0.10 新增的功能）
- 涉及敏感数据的目录**不要**挂载，除非你确定需要

#### 权限设置

DuMate 的权限面板里可以逐项开关：

| 权限项 | 建议 | 说明 |
| --- | --- | --- |
| 浏览器访问 | 按需开启 | 需要 DuMate 帮你爬网页或填表单时才开 |
| 应用访问 | 按需开启 | 需要操作特定应用（如 Excel）时才开 |
| 联网 | 按需开启 | 纯本地任务可以关掉，增强安全 |
| 自定义技能 | Pro/Max 用户 | 免费版功能已够用，自定义技能需要付费 |

#### 风险操作二次确认

删除文件、发送邮件、提交表单、调用付费 API 这类高风险操作，DuMate **强制暂停等你手动确认**，并列出具体的操作清单。这层保护是写在代码里的，即使指令写错了也不会直接执行。

> [!TIP]
> 第一次使用时建议先拿一份测试文档和测试 Excel 跑一圈，确认权限模型和沙箱行为都理解了再放真实数据进去。

## 📖 核心功能上手

DuMate 的能力远不止"AI 聊天"——它是一个能真的动你文件、动你数据的智能体。下面从最常用的几个场景切入。

### 关键信息提取：从长文档里直接拎重点

一份 30 页的合同，真正重要的信息可能只占 5%，但你得把 100% 都读完才能确认哪部分不重要。DuMate 能直接帮你把那 5% 拎出来。

它支持从以下类型的文档里自动提取结构化信息：

| 文档类型 | 可提取内容 |
| --- | --- |
| 合同 | 甲乙方、签约日期、金额、付款条件、违约条款、到期日 |
| 会议纪要 | 决议事项、行动项、责任人、截止日期、争议点 |
| 财务报表 | 收入、成本、利润、同比环比、关键比率 |
| 简历 | 姓名、学历、工作经历、技能关键词 |

关键在于指令要**具体**。模糊的"帮我总结一下"产出有限，换成：

> 帮我提取这份合同的甲乙方、总金额、付款时间节点、违约责任，每条标注原文出处和页码

DuMate 会产出一份结构化的数据表，每条后面带原文位置，可信度大幅提升。

### 多表关联分析：让分散的数据自己说话

手动做 VLOOKUP 拼好几张 Excel 表、再拉数据透视——中间任何一个引用错了就得重来。DuMate 能在 1~2 分钟内自动完成。

你只需要用自然语言描述分析目标：

> 我有去年和今年各 12 份月度销售 Excel，全部合并成一张总表，按「产品 × 渠道 × 月份」做同比分析，找出今年相比去年增长最快和下滑最严重的产品-渠道组合，生成一份分析报告 Word

DuMate 会自动识别数据之间的隐含关系——主键关联（订单号、客户 ID、产品 SKU）、时间关联（按月/季度对齐不同粒度数据）、层级关联（区域→城市→门店），然后计算同比、环比、占比、增长率等派生指标，最终输出带图表和文字结论的报告。

和手动数据透视相比，它最大的优势是**迭代快**：改分析维度不需要重新拖字段，直接说"换个维度试试"就行。

### 安全沙箱：数据不出设备

这是 DuMate 区别于很多云端 Agent 工具的核心设计。所有 AI 对文件、应用、浏览器的操作都在本地隔离的沙箱里完成，不直接访问你的系统，断网也能正常运行基础功能。

v1.0.34 新增了安全工作区重置功能——想完全清空 DuMate 的本地数据时一键重置，清除所有缓存和中间产物，但会保留账号和订阅数据（那是云端的），适合交接、清理、怀疑数据泄露时使用。

权限粒度做到了三层：文件夹级（工作区 + 手动挂载）、操作级（浏览器/应用/联网逐项开关）、风险级（删除/发送/提交必须二次确认）。

| 任务类型 | 单次消耗 | Pro 版（25000 积分）能做 | Max 版（100000 积分）能做 |
