## ✨ Cinetry 是什么——把分散的视频源收进同一个播放器

Cinetry 是一款多源聚合播放器，核心理念是「一处接入，统一播放」。它能同时对接 Jellyfin、Emby、苹果 CMS 接口、夸克网盘、115 网盘等多种媒体源，把原本散落在不同平台、需要切换不同 App 才能看的视频内容，全部收拢到一个界面里。不管你手里有几个媒体服务器、几个网盘账号，Cinetry 让你只用一个播放器就能浏览、搜索、播放所有资源。

适合什么样的人用？如果你家里搭了 Jellyfin 或 Emby，又从朋友那里分到了几个分享库，同时自己的网盘里也存了不少片子——Cinetry 就是为这种场景设计的。它的聚合搜索可以跨所有资源库同时检索，你不用再分别打开每个服务器去找想看的片；多服务器一键切换让你在不同资源库之间跳转只需要点一下；硬解播放支持 H.265、AV1 等高码率编码，4K HDR 也能流畅播放。

从 0.7 版本开始，Cinetry 陆续补齐了资源库独立开关、离线缓存、边存边播、深色模式、青少年模式等功能，已经从一个简单的聚合播放器长成了功能完备的媒体管理中枢。不同平台的硬解内核（Android 上有 MDK、EXO、AVP 三种可选）、缓存管理、服务器实时连接状态提示这些细节，也让它在日常使用中足够贴心。

## 🔧 安装步骤

Cinetry 支持 Android、iOS、Windows、macOS 四大平台，各平台的安装方式略有不同。下面分别说明。

### Android 安装

1. 从下载入口获取 APK 安装包，建议先核对文件大小和版本号是否与页面描述一致。
2. 如果是首次安装来自官方网站的 APK，系统可能会拦截「未知来源」——进入手机设置 → 安全 → 允许未知来源安装，或在安装弹窗里选择「本次允许」。
3. 安装完成后打开 App，首次启动会请求存储、网络等必要权限，全部点允许即可。

> [!WARNING]
> 如果安装后打开立刻崩溃或闪退，多半是硬解内核与设备 GPU 不兼容。进入播放器设置 → 解码器内核，把 MDK 切换到 EXO 或 AVP 试试；如果都不行，先关闭硬解开关用软解兜底。

### Windows / macOS 安装

1. 从下载入口获取对应系统的安装包（Windows 为 `.exe`，macOS 为 `.dmg`）。
2. Windows 用户注意：部分杀毒软件可能会误报安装包——如果确认是从官方渠道下载的，可以选择信任并放行。
3. macOS 用户打开 `.dmg` 后把 Cinetry 图标拖进「应用程序」文件夹即可；首次打开如果系统提示「来自未识别的开发者」，到系统设置 → 隐私与安全性里点「仍要打开」。

> [!TIP]
> 安装完成后建议先检查版本号——在设置 → 关于页面可以看到当前版本。如果低于 0.7.11，部分功能（如资源库批量编辑）可能不可用，建议升级到最新版。

### 安装后的初步校验

打开 App 后做三件事确认一切正常：

1. 随便搜一部片，确认聚合搜索能正常返回结果。
2. 点开一个视频播放几秒，确认没有花屏、卡顿或音画不同步。
3. 进入设置 → 缓存管理，确认页面能正常显示缓存占用信息。

## 📖 使用入门

### 接入你的第一个资源库

打开 Cinetry 后的第一步，是把你手头的媒体源接进来。支持的资源库类型包括：

| 类型 | 示例 | 接入方式 |
| --- | --- | --- |
| 自建媒体服务器 | Jellyfin、Emby | 填入服务器地址 + 账号密码 |
| 苹果 CMS 接口 | 各种影视站 CMS | 填入接口地址 |
| 网盘 | 夸克网盘、115 网盘 | 授权登录 |
| 本地文件夹 | 手机 / 电脑本地视频 | 选择扫描目录 |

添加资源库时 Cinetry 会自动测试连接，显示实时连接状态——绿色表示在线、灰色表示无法连接。配置信息会加密保存在本地，下次打开不需要重新输入。

> [!NOTE]
> 如果手里有多个资源库，建议给它们起好记的名字，比如「家里的 Jellyfin」「朋友分享的 Emby」「夸克网盘电影库」，后续切换和搜索时更容易分辨。

### 资源库的三个独立开关

接入多个资源库后，Cinetry 允许你对每个库独立设置三个开关——这是从 0.7.11 版本开始支持的实用功能：

- **首页开关**：控制这个库的内容是否显示在首页。典型用法是主力库打开、分享库关闭，让首页看起来干净，搜索时仍然能搜到所有源。
- **搜索开关**：控制这个库是否参与全局搜索。测试用的库或文件型资源库可以关闭，避免搜索结果被无关内容污染。
- **成人开关**：标记该库是否包含成人内容。这个开关本身不屏蔽内容，但当系统启用青少年模式时，所有标记为成人的库会被自动隐藏。

批量编辑功能可以一次选中多个资源库，统一修改开关设置——手里有 10 个以上分享库时能节省不少时间。新建资源库时三个开关默认都是打开状态。

### 多服务器一键切换

当你配置了多个资源库后，页面顶部会显示当前正在浏览的服务器名称，点击就能展开完整列表。切换服务器时：

- 首页内容会变成目标服务器的分类和推荐
- 侧边栏全局导航保持不变
- 正在播放的视频不受影响，可以继续放
- 各服务器的播放进度会分别同步

一个典型的日常使用流程是：早上看朋友分享的 Emby（更新快、新片多），晚上切回自家 Jellyfin（收藏了经典片、画质更好）。或者先用 CMS 接口快速浏览热度榜，找到想看的再切回自家服务器看高清版。

### 聚合搜索——跨所有库同时找片

Cinetry 的全局搜索会同时查询所有已接入且搜索开关打开的资源库。你不需要知道一部片存在哪个服务器或网盘里，搜一次就能看到所有匹配结果，然后挑选画质最好或加载最快的源来播放。

### 硬解播放的调试技巧

如果播放时遇到卡顿、掉帧、花屏或音画不同步——关闭硬解后正常——说明问题出在本地硬解码环节，不是视频源的问题。排查顺序如下：

**先看编码格式**。不同设备 GPU 的硬解支持范围不同：

| 编码格式 | 常见支持情况 |
| --- | --- |
| H.264 (AVC) | 几乎所有现代 GPU 都支持 |
| H.265 (HEVC) | 较老设备可能不支持；iPhone 7+、骁龙 820+、Intel 7 代+ 支持 |
| AV1 | 只在最新的高端 GPU 上支持 |
| VP9 | Android 上支持好，其他平台支持有限 |

如果视频用的是你 GPU 不支持硬解的编码格式，开硬解必然卡——最简单的解决方法就是关闭硬解。

**再试切换硬解内核**（仅限 Android）。Cinetry 提供 MDK、EXO、AVP 三种硬解内核，不同内核在不同手机上的兼容性不同。设置路径：播放器设置 → 解码器内核。如果用 MDK 卡，试试切到 EXO 或 AVP。

**然后考虑分辨率和码率**。4K HDR 10bit + 高码率（≥ 80Mbps）的视频对 GPU 压力很大；杜比视界、杜比全景声等高级格式在低端设备上可能解码不动。如果服务器端有转码能力，可以让服务器转码后再推流。

**最后注意散热**。手机长时间硬解播放会发热，过热后 GPU 会降频导致掉帧。可以给手机配背夹或风扇，连续看 2 小时以上主动暂停一会儿让设备降温。

> [!TIP]
> 软解虽然耗电多、占 CPU，但兼容性最好。对 1080p 以下内容，现代 CPU 软解完全无压力；只有 4K HDR 高码率内容硬解才是刚需。排查硬解问题时，先切软解确认不是视频源问题，再逐个尝试硬解内核和编码格式。

### 缓存管理——别让存储空间悄悄被占满

离线缓存方便但累积起来很快——一部 4K 影片就能占 30GB 以上。Cinetry 在设置 → 缓存管理页面提供了完整的查看和清理能力：

- **查看占用**：总缓存大小、每个影片各占多少、设备剩余空间一目了然。
- **单个清理**：看完的影片选中点删除，精细控制保留哪些缓存。
- **批量清理**：0.8.3 版本起新增一键清理按钮，定期整理或存储空间告急时使用。

需要注意的是，Cinetry 管理的缓存文件与普通下载文件不同——它在系统文件管理器里是不可见的，清理缓存只会删除 Cinetry 自己管理的内容，不会影响你用其他 App 下载的文件。目前还没有内置「缓存 N 天后自动删除」的策略，如果需要自动化清理可以配合系统级工具。
