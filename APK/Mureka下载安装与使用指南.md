## ✨ Mureka 是什么：从一句话到一首歌的 AI 创作工具

Mureka 是一款面向音乐创作者与普通用户的 AI 音乐生成平台。它的核心卖点是把"给一段文字描述就能出一首歌"这件事做到了真正可用——不只是做 demo 片段，而是直接产出完整编曲、带人声的 2 到 4 分钟成品，覆盖流行、摇滚、电子、民谣等多种风格。

平台提供了两条主要创作路径：**Easy 模式**让用户用一句话描述想法即可快速出多版草稿，适合灵感探索与方向确认；**自定义模式**则开放了歌词、风格、参考音频等更细粒度的输入，配合多轨编辑 Studio 和分轨分离能力，可以把草稿打磨到发行级。

除了独立创作，Mureka 还内置了**视频配乐（Soundtrack）**功能——上传短视频，AI 会解析画面的场景、情绪与节奏，自动生成贴合内容的原创音乐并合成回视频，解决了短视频创作者最头疼的版权与情绪匹配问题。

对于已经有 DAW 工作流的专业用户，Mureka 生成的作品支持**最多 12 轨分离**与 MIDI 导出，可以把 AI 的旋律创意无缝带进 Logic、Ableton、FL Studio 等主流工作站继续加工。

整体来看，Mureka 适合三类用户：想快速把灵感变成可听作品的业余爱好者、需要批量产出短视频配乐的内容创作者，以及希望用 AI 辅助旋律创意的专业音乐人。它不是要替代传统创作流程，而是在"从想法到可听版本"这一步把门槛降到了前所未有的低。

## 🔧 安装与访问：Web 优先，移动端跟进

Mureka 目前的主要使用形态是 **Web 端**，直接在浏览器中访问即可使用全部核心功能，无需下载安装包。这对跨平台用户（Windows / macOS / Linux）来说非常友好，统一入口也省去了多版本同步的麻烦。

### Web 端访问步骤

1. 打开浏览器（推荐 Chrome、Edge、Safari 最新版本）；
2. 访问 Mureka 的官方站点；
3. 使用邮箱或第三方账号登录，新用户注册即送每日免费金币额度。

> [!NOTE] 免费额度说明
> 免费用户每天约有 50 金币的生成额度，大致对应 4 首 Easy 模式的完整歌曲生成。建议把额度花在方向探索上，把细修留给 Studio 编辑工具，避免在低价值的试错上浪费。

### 移动端使用

移动端目前以**浏览器 H5 适配**为主，iOS 用户可以通过 Safari 的"添加到主屏幕"功能获得接近原生 App 的体验；Android 用户同理可使用 Chrome 的"安装应用"选项。官方小程序与独立 App 形态正在持续跟进中。

### 环境注意点

- 浏览器需支持 Web Audio API 与 WebGL（主流浏览器均已支持）；
- 首次加载会下载模型资源，建议在 Wi-Fi 环境下完成；
- 视频配乐功能需要上传本地视频，注意网络带宽与浏览器权限设置。

## 📖 使用入门：从 Easy 模式到 Studio 精修

Mureka 的创作流程大致可以分为三步：**快速出草稿 → 多轨编辑精修 → 导出或发布**。下面基于四个真实参考样本的内容，把每一步的关键操作和注意事项拆解清楚。

### 第一步：Easy 模式——一句话出多版草稿

Easy 模式的定位是"从想法到可听版本的最短路径"。你只需要用一两句话描述想要的歌曲，AI 会一次生成两版完整编曲，时长通常在 2 到 4 分钟。

**输入示例**："一首轻快的夏日民谣，女声演唱，有吉他和口琴，适合公路旅行"

#### Easy 模式的四条已知边界

> [!WARNING] 动手前先了解这些限制，避免把时间花在它不擅长的地方

1. **仅支持文字输入**：暂不支持语音哼唱，想让 AI 根据旋律参考来生成，需要切换到自定义模式；
2. **每次两版、时长常规**：不能精确指定时长，AI 会自动判断合理长度；
3. **上下文不跨会话**：修改意图只在当前对话内有效，新开聊天会清空上下文；
4. **描述优先级**：AI 会自动补全标题、歌词与风格描述，你不能逐句指定歌词内容——这一点对有精确歌词需求的用户尤其重要。

#### 什么时候该用 Easy 模式

- 灵感探索阶段，想快速验证某个风格或情绪方向；
- 写歌练手，一天产出多版草稿比较哪个方向更好；
- 有大致想法但还没想好细节，让 AI 先铺个底。

### 第二步：自定义模式与 Studio——把草稿打磨成作品

Easy 模式出的两版草稿往往还达不到"可发"的标准。这时候就该进入自定义模式或 Studio 多轨编辑环节。

自定义模式相比 Easy 开放了更多输入项：你可以**贴入完整歌词**、指定**参考音频或哼唱旋律**、选择更细分的风格标签。对于有精确歌词需求的用户，这是必经之路——别指望 Easy 模式能猜中你写好的诗或品牌口号。

Studio 是 Mureka 的多轨编辑器，它的核心能力是**段落级重建**和**分轨分离**：

- 对某一段不满意（比如第二段副歌想换个走向），可以直接在 Studio 里把那个段落替换成新生成的版本；
- 从完整歌曲中分离出最多 **12 条独立轨道**（人声、贝斯、鼓、各类乐器），分离出来的轨道可以直接在 Studio 里继续编辑，不必先导出；
- 对编曲密度适中、效果链简单的作品，分离质量明显更好；复杂混音会出现"串音"（相邻轨道互相漏声），这是 AI 分离能力的物理边界。

### 第三步：视频配乐（Soundtrack）——上传视频自动出音乐

如果你是短视频创作者，Soundtrack 模式可能是 Mureka 最实用的功能之一。它解决了两个痛点：**版权不干净**（生成的音乐是原创的，可放心商用）和**情绪对不上**（AI 会根据画面来匹配音乐的情绪与节奏）。

#### 支持的视频规格

- 格式：MP4、MOV、MPEG；
- 大小：不超过 300MB；
- 时长：不超过 3 分钟。

#### 完整操作流程

1. 在创作菜单中切到 **Soundtrack** 标签；
2. 上传要配乐的视频文件；
3. 用文字补充要求——"轻快的夏日街拍氛围"比"生成配乐"有效得多；
4. 点击创建，等待 AI 分析画面并生成配乐；
5. 试听后调整**原视频声音与配乐的音量平衡**；
6. 点击下载，配乐与画面直接合成为最终成片。

> [!TIP] 配乐描述技巧
> 描述画面情绪而不是重复画面内容；有旁白的视频建议选纯音乐避免人声打架；画面有情绪转折点的，可以在描述里点出转折时刻，让配乐跟着变。

### 第四步：导出与 DAW 衔接

Mureka 生成的作品可以导出三种物料，各有适用场景：

| 导出物料 | 适合场景 | 局限 |
| --- | --- | --- |
| 分轨音频 | 在 DAW 里重新混音、加效果、换乐器采样 | 文件数量多，注意整理命名 |
| MIDI 文件 | 换音色、改音符、重编旋律 | 对旋律类乐器还原最准，复杂和弦与打击乐效果有限 |
| 整轨音频 | 只想快速取成品听或分享 | 无法分轨加工 |

一个典型的 DAW 衔接流程：把主旋律导出为 MIDI → 拖进 Logic/Ableton 的乐器轨 → 换上自己的音色 → 继续编排和混音。这样既保留了 AI 的旋律创意，又发挥了你在专业工具里的控制能力。

### 第五步：发布与社区互动

作品库里的歌默认只有自己可见。想让别人听到，从歌曲菜单发起**发布（Publish）**操作即可。发布后作品进入可被发现的池子，其他人可以在探索页听到、点赞、评论，甚至基于你的作品做 Remix。

> [!NOTE] 发布状态下的两个限制
> - 改标题与封面要**先取消发布**再操作，改完再重新发布；
> - 从作品库删除的歌曲**不可恢复**，发布前确认不再需要。
