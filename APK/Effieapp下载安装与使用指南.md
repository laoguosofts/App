## ✨ Effieapp 是什么

Effieapp 是一款面向知识工作者的跨平台写作与笔记应用，主打「纯文本 + 大纲 + 思维导图」三合一的沉浸式写作体验。它的核心理念是让用户专注于内容本身，用一个扁平化的列表就能管理复杂的文稿层级——你写的每一段文字都可以通过大纲视图重新组织、拖拽排序，一键展开成思维导图。

和传统的文档编辑器不同，Effieapp 不强迫你先搭框架再填空。空白处直接打字，写着写着自然形成段落；想整理思路时切换到大纲模式，整段内容可以拖到任意位置重新编排；需要可视化展示时，一键生成思维导图或长图分享。这种「先写后理」的工作流特别适合需要频繁调整结构的场景——比如方案初稿、论文草稿、读书笔记整理。

Effieapp 支持多端同步（Windows、macOS、iOS、iPadOS、Android），所有设备上的文稿实时更新。Pro 会员享有更多导出模板和图片存储空间。

## 🔧 安装步骤

Effieapp 的安装在各平台上都比较简单，没有复杂的环境依赖。以下分平台说明注意事项。

### Windows

1. 从下载页获取 `.exe` 安装包
2. 双击运行安装程序，按向导完成安装
3. 默认安装路径为 `C:\Program Files\Effie`，可自定义
4. 首次启动需要登录账号（邮箱、Apple ID、GitHub 三种方式可选）

> [!TIP]
> 如果杀毒软件弹出误报提示，选择「允许」即可——这是主流安全软件对小众软件的常见误判，安装包来源可靠时无需担心。

### macOS

1. 下载 `.dmg` 文件，双击打开
2. 将 Effie 图标拖入「应用程序」文件夹
3. 首次启动右键点击应用 → 「打开」，绕过 Gatekeeper 安全提示
4. 登录账号后即可使用

### iOS / iPadOS / Android

直接在 App Store 或对应 Android 应用商店搜索 Effie 下载安装即可，移动端无需特殊授权。

### 安装后验证

启动后创建一篇新文稿，随便输入几行文字，尝试用 `# ` 创建标题、用 `- ` 创建列表。如果大纲视图里能看到层级结构，说明安装正常、标记语法解析正常。

## 📖 使用入门

### 大纲驱动的写作流

Effieapp 的大纲是整个应用的灵魂。你写的每一个段落都会自动成为大纲里的一条，在左侧边栏以树形结构展示。操作逻辑很简单：

- **Tab 缩进** — 在段落开头按 Tab，当前段落会变成上一段的子项，大纲层级自动增加
- **Shift + Tab** — 取消缩进，层级提升一级
- **拖拽** — 在大纲视图里直接拖动段落到任意位置，包括跨层级移动
- **折叠 / 展开** — 点击大纲标题左侧的三角图标，整段内容可以折叠起来

这种设计让 Effieapp 特别适合处理层级复杂的内容。写论文大纲、做方案拆解、整理读书笔记，都可以先铺开内容再慢慢理顺结构。

### Markdown 标记语法

Effieapp 支持基础 Markdown 语法，输入时自动识别渲染。最常用的几个：

| 功能 | 语法 | 说明 |
| --- | --- | --- |
| 标题 | `# ` / `## ` / `### ` | 不同级别自动识别 |
| 加粗 | `**文字**` | 两侧双星号 |
| 斜体 | `*文字*` | 两侧单星号 |
| 列表 | `- ` / `1. ` | 无序和有序 |
| 分隔线 | `---` | 单独一行三个短横线 |

iOS / iPadOS 版在编辑界面长按键盘上方的格式按钮，会弹出标记语法快捷面板——不用记快捷键，直接点选就行。

### 插入图片

Effieapp 提供了三种加图片的方式，按方便程度排序：

1. **拖放** — 从文件管理器直接拖进编辑区，松手自动插入到光标位置
2. **粘贴** — 截图或复制图片后，按 Ctrl + V（Win）/ ⌘ + V（Mac）粘贴
3. **Markdown 语法** — `![图片说明](URL)` 适合引用网络图片

拖放和粘贴的图片会自动保存在 Effie 的本地数据文件夹里，随文稿一起云同步。图片前后最好各留一个空行，避免和正文贴得太紧。

### 插入表格

Effieapp 的表格操作以键盘为主，不需要手写 Markdown 表格语法：

- **快捷键** — Windows 按 Ctrl + T，macOS 按 ⌘ + T
- **/ 命令面板** — 输入 `/table` 回车即可插入
- **Tab** — 跳到下一个单元格，最后一个单元格按 Tab 自动新增一行
- **方向键** — 上下左右移动
- **右键单元格** — 删除行、删除列、插入行列

Effieapp 的表格是轻量的，不支持合并单元格、公式计算、数据排序等复杂操作，适合简单的对比表、数据清单。导出时可以选择转为标准 Markdown 表格、Word / PDF 原生表格或 Effie 原生格式。

### 导出精美长图

Effieapp 最有特色的导出方式是长图——把文稿一键变成视觉精美的图片，适合在朋友圈、小红书、微博等社交平台分享。

Effie 提供 50+ 种导出样式模板，覆盖简约风（适合个人笔记）、卡片风（适合观点拆解）、杂志风（适合深度文章）、海报风（适合观点宣言）四种主要风格。

操作上各平台略有差异：

- **iOS / iPadOS** — 打开文稿 → 点右上角三个点 → 「以图片形式分享」→ 选模板 → 保存或分享
- **Windows / macOS** — 在卡片栏右键点击文稿 → 「导出」→ 「导出成图片」→ 选存储位置

和手动截图相比，长图导出的优势很明显：自动排版统一设计、整合成一张长图、固定宽度和字号阅读舒适，窗口再小也不会出现文字密密麻麻的情况。

### 适合什么场景

Effieapp 的「先写后理」工作流尤其适合这些情况：

- **方案初稿** — 先把所有想法铺出来，再用大纲拖拽重新组织
- **论文写作** — 章节层级清晰，素材段落可以随意搬运重组
- **读书笔记** — 多本书的笔记可以合并在同一份文稿里对比
- **会议纪要** — 记录后用大纲快速整理成结构化条目

如果你主要需要电子表格的公式计算、合并单元格等能力，Effieapp 的表格就显得不够用了，这时 Excel 或 Google Sheets 会更合适。
