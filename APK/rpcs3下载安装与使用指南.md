## ✨ rpcs3 是什么

rpcs3 是目前活跃维护的开源 PlayStation 3 模拟器，让 PC 玩家能在电脑上运行大量 PS3 游戏。项目始于 2011 年，由全球社区贡献，至今已实现对数千款 PS3 游戏的模拟覆盖，其中相当一部分达到了可流畅通关的程度。

模拟器的核心价值在于"延续"——PS3 已停产多年，数字商店也逐步关闭，rpcs3 成为了留存这些经典游戏的最可行方案。它同时兼容光碟备份、数字版安装包和自制程序三种来源形态，支持真机存档导入导出、奖杯系统、联机网络等真机功能的模拟实现。

目前 Windows 是最成熟的平台，Linux 和 macOS 也在维护中。硬件门槛方面，CPU 单核性能远比显卡重要——这是 PS3 的 Cell 架构特性决定的，模拟器需要实时做 PPU/SPU 的双路重编译。

## 🔧 安装与固件配置

安装本身并不复杂，但 PS3 模拟器有一个其他主机模拟器不常见的前置步骤——**安装官方固件**。这是理解 PS3 系统架构的关键，固件装错或没装，模拟器的大部分功能都是残缺的。

### 安装包获取与解压

1. 从下载页拿到最新构建版本，通常是 7z 或 zip 压缩包。
2. 解压到一个非中文路径（例如 `D:\Emulators\rpcs3\`）——**路径带中文可能引发编译失败、存档写不进等怪问题**，老版本对非 ASCII 路径敏感。
3. 解压完成后，目录里应该有 `rpcs3.exe`、`dev_hdd0`、`dev_flash` 等子目录结构。

### 固件安装

固件是 PS3 的系统镜像文件，模拟器启动任何游戏之前都需要它：

1. 获取 PS3 官方固件文件（后缀通常是 `.pup`），版本选最新稳定版即可。
2. 打开模拟器 → **File → Install Firmware** → 选中 `.pup` 文件，等待安装完成。
3. 安装成功后，固件文件会被分解到模拟器的 `dev_flash` 目录，主界面不会有提示弹窗，但后台已就绪。

> [!WARNING]
> 固件安装是**单向不可逆**操作，装完就不用重复。别在模拟器目录里手动删固件文件，也别反复安装不同版本——容易导致内部状态混乱。

### 杀毒软件与实时扫描

模拟器在首次启动新游戏时会做大量的 PPU/SPU 重编译，这个过程的 CPU 占用和文件写入量都很大。建议把整个模拟器目录加入杀毒软件的排除列表，否则：

- 实时扫描会拖慢编译速度，帧数直接掉一档；
- 部分杀软会把编译产物误判为可疑文件，产生隔离或提示弹窗，打断运行流程。

## 📖 使用入门

### 游戏导入：三种形态各走各的路

PS3 游戏在模拟器里有三种常见形态，导入方式完全不同，先认清你手里的游戏属于哪一类：

**文件夹版（光碟备份）** —— 最常见的形态。光碟备份出来是一个游戏文件夹，里面有 `PS3_GAME` 子目录，外层可能带 `PS3_UPDATE`、`PS3_DISC.SFB` 等标记文件。导入时把**包含 `PS3_GAME` 的外层文件夹**的上级目录指给模拟器即可——别选错层级，选到 `PS3_GAME` 里面一层就找不到标记文件了。

**PKG 数字版** —— PSN 商店的数字版安装包，后缀 `.pkg`。通过 **File → Install .pkg** 导入，装完自动出现在游戏列表。数字版常伴随更新补丁和 DLC 的独立 PKG，按「本体 → 更新 → DLC」的顺序依次安装，部分还需要配套的授权文件（RAP）在 Manage 菜单导入。

**单文件 ELF/SELF** —— 自制小程序和部分独立游戏是单个 `.elf` 文件，直接 **File → Boot SELF/ELF** 运行即可，不会进主列表。这是验证模拟器环境的最快路子——随便跑一个自制程序成功，说明固件、解码器、显卡整条链都是通的。

> [!TIP]
> 游戏目录建议固定在一个根目录下（例如 `D:\PS3Games\`），每款游戏一个子文件夹，导入时指向这个根目录即可。每款游戏 5—10 GB 起步，大作更高，盘位提前留好。

### 开玩之前先查兼容表

"我这游戏能不能玩"有标准答案，别靠试。每款游戏在官方兼容列表里都有一个详情页，学会读它，五分钟省掉一下午的试错时间。

**标准查表流程：**

1. 搜游戏名或序列号（游戏文件夹里 `PARAM.SFO` 对应的编号，列表里也显示）——序列号是更准的定位方式，同款游戏不同地区版本等级可能不一样。
2. 看等级：Playable 直接开玩；Ingame 看已知问题能不能忍；Intro 以下等更新。
3. 看测试信息：详情页标注测试者的构建版本与日期，如果测试日期已是一两年前，实际状态大概率比标注更好——项目一直在进步。
4. **抄推荐设置**：不少游戏的详情页写了需要开启的图形开关（如 Write Color Buffers），先抄再开，比自己从零试快十倍。

详情页之外，官方论坛的每个游戏专帖长期汇总讨论，遇到详情页没写的怪问题先翻这里。社区评测和实机视频则是判断"可玩档在你的配置上是什么帧数"最直观的参考。

### 帧数太低怎么办

帧数低不是单一问题，按"代价从零到大"排列的优化清单：

**第零层：先确认瓶颈在哪。** 模拟器窗口标题栏可以开帧率显示，拿一个稳定场景读数。CPU 瓶颈的特征是 GPU 负载不高、降画质帧数不变——这类问题看硬件层；GPU 瓶颈则是降分辨率/缩放档位帧数立涨，画质类优化有效。

**第一层：免费优化（不改画质）。** 确认 PPU 与 SPU 解码器都是 LLVM 双重编译（这是默认值，但总有人动过）；开启异步着色器编译消除大头卡顿；关掉杀毒软件对模拟器目录的实时扫描；笔记本记得插电切高性能模式——省电模式直接腰斩性能；关掉后台吃 CPU 的程序，浏览器几十个标签页是帧数杀手。

**第二层：画质换帧数（感知损失最小排序）。** 各向异性过滤回 Auto（如果手动拉满过）——几乎无损失；分辨率缩放降一档——200% 降 150% 的感知差异远小于帧数收益；抗锯齿关掉——低帧下没人在意锯齿；特效级图形开关逐个关。

> [!WARNING]
> 不要为了帧数去关 Write Color Buffers 这类兼容开关——那换来的不是帧数而是黑屏。

**第三层：游戏侧配置。** 查兼容详情页的推荐配置组合，很多重负载游戏有官方推荐；每游戏独立配置只给这一个游戏降画质，别的游戏不受影响；确认掉帧是否集中在特定场景（大量敌人、过场）——那可能是游戏本身的兼容问题而非你的配置问题。

**第四层：硬件升级。** 换 CPU 是主升级路线，单核性能与架构年代是关键指标；显卡只在"你想要高倍缩放画质"时才值得升——PS3 模拟对显卡的要求远低于 CPU；内存 16 GB 起步，多数游戏用不满，但编译缓存与系统余量需要它。

### 存档管理：真机与模拟器双向搬运

模拟器的存档体系与真机高度兼容，双向搬运完全走得通：

**从真机导入存档：** 真机系统菜单把存档复制到 U 盘 → 接入电脑找到存档目录（按游戏序列号命名的文件夹）→ 模拟器 Manage → Save Data 导入，或在文件系统层直接放进对应用户的存档目录。

**重签问题是唯一绊脚石：** 真机存档带有账号签名信息，模拟器模拟的用户账户与真机账号不同，部分游戏会认定存档"不是我的"而拒读——表现为导入成功但游戏里显示"存档数据损坏"。社区有存档重签工具可以解决，把存档的签名改成模拟器用户账户的；也可以先试模拟器侧"复制到主机存储"的正规流程，一部分存档会自动被接受。逐游戏情况不同，卡住先搜"游戏名 + 存档 + 导入"的社区经验。

**导出方向同样成立：** 模拟器存档可以导出成 U 盘结构，理论上可回真机（同样受签名校验影响，比导入更挑游戏）。定期备份很重要——模拟器用户的存档目录就是普通文件夹，整个复制走就是备份，奖杯数据也在附近目录，一并带走。

**用户账户管理：** Manage 菜单的 User Accounts 管理模拟的用户账户，存档挂在账户下。多账户用于区分不同人的存档；单人玩家一个账户足够，别乱删账户——连带存档一起没。
