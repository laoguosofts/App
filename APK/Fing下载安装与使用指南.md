## ✨ Fing 是什么

Fing 是一款面向家庭和小型网络环境的智能网络扫描与监控工具。它能快速发现当前 Wi-Fi 下所有连接的设备，识别设备类型和厂商信息，并提供网络诊断、测速、DNS 检测等实用功能。对家庭用户来说，Fing 最常见的用途是排查蹭网设备、了解自家网络拓扑、以及在网速变慢时快速定位问题。

Fing 有免费版和 Premium/Professional 订阅两档。免费版提供手动扫描、单次测速、基础设备识别等核心能力，足以覆盖日常排查需求；订阅版则增加了定时自动测速、实时网络监控、设备上下线告警、暂停上网等高级特性，适合对网络质量有持续关注的用户。

## 🔧 安装步骤

Fing 支持多平台部署，各平台安装方式略有差异，下面分别说明。

### Android 安装

1. 打开 Google Play，搜索 "Fing" 找到官方应用
2. 点击安装，等待下载完成
3. 如果遇到未知来源警告，进入系统设置 → 安全，允许安装未知来源应用
4. 安装完成后首次打开，授予定位权限和网络访问权限

### iOS 安装

1. 打开 App Store，搜索 "Fing"
2. 点击获取，Face ID 或密码确认后开始下载
3. iOS 系统会自动完成安装，无需额外权限设置

### Windows / macOS Desktop 安装

Fing Desktop 是常开型应用，需要一台 24/7 运行的电脑来支撑订阅版的持续监控功能。

1. 访问官方下载页，选择对应操作系统版本
2. 下载完成后双击安装包
3. Windows 用户注意：杀毒软件可能误报，添加信任即可
4. 安装过程中选择安装路径，建议保留默认值
5. 安装完成后启动 Desktop，登录账号（订阅用户登录 Premium/Professional 账号）

### 树莓派 / NAS / Docker Agent 部署

Fing Agent 是面向极客用户的轻量部署方案，适合没有常开电脑的家庭。安装方式取决于部署环境，一般需要克隆 Agent 仓库后执行安装脚本。

> [!NOTE] Desktop 或 Agent 是订阅版"被监控的网络"功能的前提。如果只有手机 App 而没有 Desktop 或 Agent，即使买了 Premium，也只能手动扫描，享受不到持续监控和实时告警。

## 📖 使用入门

### 首次扫描：看看你家 Wi-Fi 到底连了什么

打开 Fing App，连接到自家 Wi-Fi 后，点击扫描按钮。几秒钟后，你会看到一张完整的设备清单——每台设备的 IP 地址、MAC 地址、厂商识别甚至设备类型都会列出来。

> [!TIP] 第一次扫描后，花 5 分钟对照清单逐个标记。给家里每台设备起个好认的名字，比如"客厅电视""儿子的 iPad"，后面排查未知设备时会方便很多。

如果清单里出现了你不认识的设备，有两种处理方式：

- **Pause（暂停上网）** —— 临时断网，随时可以一键恢复。适合小孩到点该放下平板、临时访客想收网的场景
- **Block（拉黑）** —— 永久拒绝连接，适合确定是邻居蹭网或完全陌生的设备

两者的区别一目了然：

| 场景 | 选 Pause 还是 Block |
|------|---------------------|
| 小孩刷平板刷到晚上 10 点了，该睡觉 | Pause |
| 小孩还没做完作业想玩游戏 | Pause |
| 朋友来做客，想不让某人用 Wi-Fi | Pause（临时访客）|
| 发现是邻居长期蹭网 | Block |
| 完全不认识的设备 | Block |

暂停或拉黑功能依赖路由器的 UPnP 协议或管理员权限。如果 Fing 无法控制你的路由器，相关按钮会显示不可用状态。

### 持续监控：让网络自己告诉你出了什么事

免费版只能手动点扫描，但订阅版的核心价值在于"被监控的网络（Monitored Network）"——让 Fing Desktop 或 Agent 持续运行，自动感知网络中的每一次变化。

| 方面 | 手动扫描（免费版） | 被监控的网络（订阅） |
|------|-------------------|---------------------|
| 扫描触发 | 手动点按钮 | 定时自动（每 5 分钟或持续轮询）|
| 设备变化 | 只有扫描时才知道 | 实时感知，立即推送 |
| 事件记录 | 只在扫描结果里 | 完整时间线，可回看 |
| 设备上下线 | 每次扫描才知道 | 持续追踪，秒级发现 |
| 告警 | 无 | 主动推送到 App + 邮件 |

Premium 订阅支持 2 个被监控网络，Professional 支持 3 个以上。一个物理位置对应一个被监控网络就够用了——家是 1 个，父母家是 1 个，办公室再来 1 个。你也可以在同一个网络上跑多个 Agent，它们会协同工作，不会重复占用名额。

### 定时测速：让数据说话

手动测速只能知道"此刻"网络怎么样，但你真正想知道的可能是——我家网络每天都稳定吗？是不是每晚 8 点就开始变慢（运营商晚高峰）？升级路由器后整体提升了多少？

Premium 的定时测速可以解决这些问题。让 Desktop 或 Agent 每隔固定时间自动跑一次测速，Fing 会帮你：

- 记录所有结果，生成日/周/月趋势图
- 网络明显变慢时主动推送告警
- 汇总到地区 ISP 评分系统，对比本地区平均水平

你还可以设置一个"期望的最低网速"——比如 100M 光纤设下载速度低于 50 Mbps 时告警。这样只要网速低于预期，Fing 就会主动通知你，不用你天天盯着。

> [!TIP] 免费版虽然没有定时测速，但可以养成每周手动测 1-2 次的习惯，每次在备忘录里记下结果。累积 1-2 个月后也能看出大致趋势。

测速产生的数据是和运营商沟通时最硬的证据。运营商说"你这就是 100M 带宽"，但你一周的测速记录显示每晚 8 点只有 30M——拿着这个记录去投诉，底气就足了。

### DNS 检测：隐藏在网络卡顿背后的隐形杀手

很多人遇到网页打开慢，第一反应是带宽不够，但其实 DNS 解析慢也可能是元凶。域名解析就像电话簿查号——你输入域名，DNS 把它翻译成服务器 IP。如果 DNS 响应要花 1 秒，每次打开网页都得等这 1 秒，即使带宽再高也没用。

Fing 可以帮你快速定位 DNS 问题：

- 查看当前网络配置的 DNS 服务器地址
- DNS 延迟测试：测当前 DNS 的平均响应时间，同时对比几个主流公共 DNS
- 手动输入域名做 DNS 查询，看它能解析出哪些 IP

DNS 响应时间的好坏可以用一个简单的表来判断：

| 响应时间 | 评价 |
|----------|------|
| < 20 ms | 非常好 |
| 20~50 ms | 可以 |
| 50~100 ms | 一般，可以考虑换 |
| > 100 ms | 慢，建议换 |

如果你的运营商 DNS 慢，不妨试试公共 DNS：

| 服务 | 主 DNS | 备用 DNS | 特点 |
|------|--------|----------|------|
| Cloudflare | 1.1.1.1 | 1.0.0.1 | 速度快、隐私保护好 |
| Google | 8.8.8.8 | 8.8.4.4 | 稳定、全球覆盖 |
| 阿里 DNS | 223.5.5.5 | 223.6.6.6 | 国内速度好 |
| 腾讯 DNS | 119.29.29.29 | 182.254.116.116 | 国内速度好 |
| 114 DNS | 114.114.114.114 | 114.114.115.115 | 老牌国内 DNS |

最简单的改 DNS 方式是在路由器里改——改完所有连这台路由器的设备都用新 DNS。打开浏览器输入路由器管理地址（通常 192.168.1.1 或 192.168.0.1），登录后找到 DHCP 设置或 DNS 设置，把主/备用 DNS 改成推荐值保存即可。临时试试的话，也可以在手机 Wi-Fi 设置里单独改。
