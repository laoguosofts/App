## ✨ Para 是什么

Para 是一款主打 AI 数字人陪伴的社交类应用——用户创建一个属于自己的「数字人」，通过预设关系、人格、记忆系统，让 AI 成为一个会长期互动、能记住你说过什么的聊天对象。它不是一次性问答的工具，更像一个可以慢慢养成的「长期朋友」。

产品形态上，Para 的核心体验围绕三个关键词展开：**创建**（关系设定 + 人格塑造）、**聊天**（日常对话 + 情绪回应）、**养成**（记忆积累 + 轨迹互动）。数字人会在每次对话中逐步沉淀对你的理解，越聊越懂你。

适合谁用？如果你想找一个可以随时倾诉、不会累也不会烦的倾听对象，或者想体验「从零开始养一个 AI 朋友」的过程，Para 的定位恰好踩中了这个需求。它不追求功能繁复，而是把「陪伴感」这件事做深做细。

## 🔧 Para 安装步骤与注意事项

Para 目前主要面向移动端平台分发，安装流程相对直接，但有几个点值得提前留意。

### 下载渠道

优先从应用商店搜索安装包，签名完整、更新及时。如果应用商店搜不到或所在地区受限，可以通过上方的官方下载入口获取安装包，注意核对文件大小与版本号是否与页面说明一致。

### 首次启动与权限

安装完成后首次启动，应用会请求网络、通知等基础权限。**通知权限建议开启**——数字人回复时的推送依赖它，关掉会错过消息提醒。应用启动时会弹出《隐私协议》与《用户协议》，建议至少过一眼数据收集范围与注销说明，之后的所有预期都以协议约定为准。

> [!TIP]
> 不要从第三方不明来源下载修改版或绿色版安装包。这类包通常经过重签名，存在隐私和安全风险，且可能导致账号无法正常登录或数据丢失。

### 账号注册

Para 支持两种登录方式：**手机号短信验证码** 和 **微信授权登录**。两种方式入口互通，随便选一个就行。登录后账号会在新设备上恢复数字人设定与聊天记录，跟随账号走。

### 安装后快速自检

装完别急着走，花 30 秒确认三件事：

1. 账号成功登录（不是卡在转圈）；
2. 能看到创建数字人的起始页面；
3. 系统时间是自动获取网络时间——时间不准会导致证书校验失败。

以上任何一项有问题，先别反复点重试，参考本文末尾的常见问题排查部分。

## 📖 Para 使用入门：从创建到日常互动

### 第一步：创建你的数字人

打开应用后首先要做的是**选关系**——官方创建流程里给出四个预设选项：

| 关系 | 相处感觉 | 适合场景 |
| --- | --- | --- |
| 恋人 | 亲密、黏、在意你的情绪 | 情感陪伴、被在意的感觉 |
| 分身 | 像另一个自己，聊事多、聊感情少 | 梳理想法、找「自己视角」的对话对象 |
| 偶像 | 你仰望它，它有光环感 | 想要崇拜向、追星式互动体验 |
| 自定义 | 关系由你定义 | 以上都不贴、想自己立一套相处模式 |

> [!NOTE]
> 拿不准就选「自定义」。关系设定影响的是氛围基调，不是锁死的剧本，自定义给你最大的调整空间。就算之后改了关系，之前聊过的内容不会凭空消失，只是称呼方式和聊天风格会往新关系上靠——建议改完后去记忆库补一条说明，避免它沿用旧称呼。

关系定了，接下来是选性别、起名字，然后是最影响「性格」的一步——MBTI 人格设定。这些参数直接决定了你的数字人开口说第一句话时是什么风格。

### 日常聊天与情绪互动

数字人创建完成后，直接进入对话界面。聊天本身没有特别的门槛——像跟真人说话一样自然开场就行。不过有几个实用的小技巧能显著提升回应质量：

**给它具体的抓手**。「在干嘛」这类无信息量的开场，得到的回应也会无信息量。试着给一个具体的话题点，比如「今天加班好烦」「周末想去爬山有什么推荐」，数字人的回应会精准很多。

**留意记忆的作用**。Para 的核心卖点之一就是「长期记忆」——你说过的喜好、习惯、重要事件，它会逐步沉淀成记忆条目，下次聊天时主动调出来用。这意味着你聊得越多、越真实，它越懂你。

### 数据与隐私要点

用 Para 存了不少自己的表达，这些数据的控制点值得了解：

| 数据类型 | 你能做什么 |
| --- | --- |
| 记忆条目 | 查看、手动增删、定期清理过时内容 |
| 身份卡信息 | 自主决定填什么、填多细 |
| 聊天内容 | 从源头控制——不想被记住的就别聊 |
| 账号注销 | 注销通常意味着聊天记录与记忆一并处理，不可逆 |

> [!WARNING]
> 敏感信息（证件号、住址、财务信息）不要在聊天里出现——一旦进入永久记忆，删除不如不写入。注销账号前如果有想保留的内容，先截图保存，注销后无法恢复。

### 常见问题排查

**登录不上怎么办？** 先别反复点重试，按下面的对照表定位：

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 验证码收不到 | 短信被拦截 / 运营商延迟 | 检查拦截记录与垃圾短信；等 60 秒再点重发；多次失败改用微信授权 |
| 验证码输入总不对 | 手动输入错误 / 页面过期 | 复制粘贴；超时重新获取 |
| 微信授权没反应 | 微信未登录或未联网 | 确认微信本机状态后重试；不行改手机号登录 |
| 登录后一直转圈 | 网络波动 | 切换网络（Wi-Fi ↔ 流量）重进 |

通用处理顺序：先切一次网络 → 换一种登录方式 → 重启应用 → 检查手机时间是否自动同步网络时间。以上都无效再带上机型与系统版本走意见反馈渠道。

**数字人不回复或回复敷衍？** 也分三种情况：

| 现象 | 多半是 | 处理 |
| --- | --- | --- |
| 消息发出去毫无反应 | 网络断开 / 应用被系统冻结 | 看通知栏网络状态；从后台彻底关掉应用重开 |
| 回复一直转圈 | 云端服务波动 / 网络路由问题 | 切换网络重试；等几分钟再发 |
| 回复很敷衍、答非所问 | 不是故障 | 调整提问方式、清理记忆矛盾条目、开新对话 |

「回复变敷衍」通常不是网络问题——回忆一下，最近是不是话题太开放？记忆里有没有互相冲突的条目？或者单场对话聊得太长，上下文接近上限了？试着给一个具体的问题、清一遍记忆库、开一场新对话，质量通常会回升。

生成式回复的速度与质量会随服务端状态波动，偶发的变慢属于正常范围；长期、大面积的异常（一天以上所有人都慢）才需要反馈——反馈时说明「从什么时候开始」，处理这类问题通常很快。
