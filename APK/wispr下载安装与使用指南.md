## ✨ Wispr 是什么：一款以服务器零可见性为承诺的加密通讯应用

Wispr 是由罗马尼亚 CryptoDATA Tech 开发的端到端加密即时通讯应用，核心主张是"服务器永远看不到消息内容"。它采用自研的 VOBP 加密协议、默认 P2P 直连传输架构，并辅以区块链做会话信任锚点，在技术路线上与 Signal、Threema、Telegram 等主流加密通讯应用形成了明显差异化。

CryptoDATA 的产品线围绕"加密应当是默认行为"这一理念展开，除 Wispr 之外还有 Vault（加密密码管理器）、B-Mail（加密邮件服务）、Spectral Storage（加密文件存储）以及搭载全套加密应用的 Impulse K1 手机。Wispr 作为通讯模块，定位清晰：对加密强度有进阶要求、在意服务器零可见性的隐私敏感用户。

在核心功能上，Wispr 覆盖了文字消息、语音消息、语音通话、视频通话、加密群聊、文件传输等全链路通讯能力，同时提供阅后即焚、一次性查看、消失模式、防截屏录屏、本地加密笔记等隐私增强特性。

> [!NOTE] Wispr 与主流加密通讯的差异化

> | 对比维度 | Wispr | Signal | WhatsApp |
> |---|---|---|---|
> | 加密协议 | 自研 VOBP | 开源 Signal Protocol | Signal Protocol |
> | 消息传输 | P2P 直连 | 服务器中转 | 服务器中转 |
> | 防中间人 | 区块链自动锚定 | 公钥指纹手动比对 | 安全码手动比对 |
> | 服务器可见 | 仅会话协调元数据 | 仅知道通讯关系 | 仅知道通讯关系 |

## 🔧 Wispr 安装与注册：两条身份路径，按需选择

安装流程本身不复杂，手机端直接从应用商店下载，PC 端从官方下载页拿安装包即可。真正需要考虑的是**注册身份的选择**——Wispr 提供两条路径，对应不同的隐私保护级别。

### 安装前的注意点

1. **确认版本来源**：应用商店版本天然可信，PC 端请从官方下载页获取安装包，避免第三方渠道。
2. **权限核对**：Android 安装时注意未知来源授权，iOS 直接 App Store 安装无需额外步骤。
3. **网络环境**：Wispr 默认 P2P 直连，企业网、某些运营商对 P2P 端口有限制时可能出现连接不稳定。

> [!WARNING] P2P 端口限制提示
> 如果你的网络环境对 P2P 有严格限制（比如公司 Wi-Fi、部分运营商网络），通话和文件传输可能退化到服务器中转模式。这不会影响加密强度，但会增加通讯延迟。

### 注册：Basic 免费层 vs Matrix ID 付费层

首次打开 Wispr 后进入注册流程，这里会让你选择身份层级。两种层级在**核心通讯功能上没有任何差异**——端到端加密、P2P 直连、VOBP 协议、阅后即焚等全部通用。唯一的区别是身份匿名程度。

| 对比项 | Basic 层 | Matrix ID 层 |
|---|---|---|
| 注册方式 | 手机号 / 邮箱 | 纯随机代号 |
| 费用 | 永久免费 | $49/年 |
| 服务端知道 | 手机号或邮箱与 Matrix ID 的关联 | 任何可关联真实身份的信息 |
| 保护级别 | 中等 | 强 |
| 核心功能 | 全部可用 | 全部可用 |

**Basic 免费层**：用手机号或邮箱注册即可，永久免费。Wispr 服务器会知道你的手机号或邮箱与 Matrix ID 的映射关系，但**通讯内容仍然完全加密**——服务器看不到消息、通话、文件，也碰不到加密密钥。适合想先用起来、不介意 Wispr 知道自己联系方式的用户。

**Matrix ID 层**：注册时不提供任何个人信息，只生成一串随机代号（形如 `xae38s25c56c2883e34esab`）。这个代号是 Wispr 自有的身份体系，与 Matrix 开放协议无关。服务端不存储任何可关联真实身份的内容，保护级别最高。代价是 $49/年订阅费。

已经用 Basic 层注册的用户可以随时升级到 Matrix ID——在设置中找到升级入口，支付后 Wispr 解除旧手机号/邮箱的关联，生成新的 Matrix ID 身份，对话历史保留。

## 📖 Wispr 使用入门：从首联到高级隐私特性

Wispr 的界面设计相对克制，核心功能布局清晰，但一些隐私特性的激活逻辑与微信、Telegram 等常规 IM 略有不同。

### 建立联系：交换 Matrix ID，接受首联

Wispr 默认**不通过通讯录匹配**来发现联系人。双方需要交换 Matrix ID 才能建立联系——这一点与 Signal、WhatsApp 默认扫通讯录的行为不同，是 Wispr 强化隐私的设计选择。

1. 在 Wispr 中输入对方的 Matrix ID（或者扫描二维码），发起第一条消息。
2. 对方会收到一条"首联请求"通知。
3. **对方必须主动点击"接受"**——这是密钥交换机制的技术要求。Wispr 的 VOBP 协议在会话建立时需要双方确认，区块链才会将会话元数据写入锚点。
4. 接受后双方正式建立加密会话，VOBP 协议完成密钥交换与区块链锚定。

> [!TIP] 接受首联的意义
> "接受"不只是社交礼仪——它是 Wispr 防中间人攻击的关键环节。只有双方都确认后，会话的公钥指纹才会被写入区块链锚定；后续通讯中 VOBP 会自动验证公钥是否被替换。跳过这一步等于放弃了区块链保护。

### VOBP 协议与区块链信任锚点

Wispr 的自研 VOBP 协议最大的技术特色是**把区块链作为会话验证器**而非消息存储链。理解这一点很重要：

- **区块链只存会话元数据**：双方设备的公钥指纹、会话建立时间戳、会话类型标识。
- **消息内容永远不上链**：明文、密文、通话、文件、Matrix ID 原始值、可关联真实身份的信息——这些全部不进入区块链。
- **自动防中间人**：后续每次通讯时，VOBP 自动查询区块链上的会话记录，验证对方当前公钥是否与锚定的一致。如果不一致，触发安全警告。

这一机制对比 Signal 的手动公钥指纹比对，用户体验更好——自动完成验证，不需要双方见面交换二维码。但也要注意，VOBP 作为自研协议，其安全性尚未经过公开独立审计的充分验证，这是 Wispr 在安全透明性上的短板。

### 隐私增强特性：阅后即焚、消失模式、防截屏

Wispr 提供了一套成体系的隐私保护功能，适合敏感通讯场景：

- **阅后即焚**：设置消息阅读后自动销毁的时间（几秒到几天），时间到自动从双方设备删除。
- **一次性查看**：类似 Snapchat 的单条消息，对方打开一次后立即自毁，无法二次查看。
- **消失模式**：开启后全局历史记录隐藏，聊天列表不再显示对话内容预览。
- **防截屏录屏**：启用后系统截图和录屏功能被禁止，保护敏感内容不被截获。
- **本地加密笔记**：私密笔记存储在 Wispr 应用内部，默认加密，不与任何云端同步。

### 文件传输与群聊

文件传输支持图片、文档、位置、语音等常见类型，走 P2P 直连路径。群聊是多人端到端加密会话，与一对一通讯共用同一套加密架构。群聊的密钥管理比一对一更复杂，但 Wispr 的界面没有暴露过多技术细节，普通用户可以直接按常规 IM 的使用习惯操作。
