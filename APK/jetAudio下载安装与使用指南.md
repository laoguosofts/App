## ✨ jetAudio 是什么

jetAudio 是一款在 Android 平台活跃多年的本地音乐播放器，主打对 Hi-Res 无损音频、多种罕见音频格式的原生支持，以及一套相当丰富的播放增强功能。它不是那种依赖在线曲库的流媒体播放器，核心定位是"把你手机或家里 NAS 上已经有的本地音乐库，用尽可能好的效果放出来"。

jetAudio 有免费版和 Plus 付费版两条线，免费版已经足够日常使用，付费版解锁 MIDI WaveTable 合成器、更多均衡器预设和部分高级功能。对于追求音质、手里有大量无损音频文件的用户来说，jetAudio 是 Android 平台上少数仍然在持续更新、功能完整度较高的选择。

它的核心能力大致可以归为三类：一是**广泛的格式支持**，包括 FLAC、APE、WAV、ALAC 等无损格式，以及 .mid / .midi 这种很多播放器直接放弃的格式；二是**原生 SMB 流媒体**，不用把文件下载到手机就能直接播放 NAS 或 Windows 共享文件夹里的音乐；三是**丰富的播放辅助功能**，定时关闭、A<->B 循环、淡入淡出、摇晃切歌等都是内置选项，不需要额外装插件。

## 🔧 安装步骤

jetAudio 主要面向 Android 平台，iOS 版本功能相对有限，以下以 Android 安装为主。

1. **确认来源**：从官方下载页面获取 APK 文件，或者直接在 Google Play 搜索 jetAudio 安装。Play 商店的版本自动处理更新，APK 版本需要手动升级。

2. **Android 未知来源授权**：如果走 APK 安装路线，系统会弹出"是否允许安装未知来源应用"的提示。不同厂商 ROM 的入口略有差异——原生 Android 在设置 → 安全 → 安装未知应用里给文件管理器授予权限；小米、OPPO、vivo 等需要在设置 → 应用管理里找到对应文件管理器，开启"允许安装未知应用"开关。

   > [!WARNING]
   > 从未知来源安装应用时，务必确认 APK 来源可信。jetAudio 的官方下载页会标注文件的 SHA256 哈希值，安装前可以用哈希校验工具比对一下。

3. **安装与首次启动**：安装完成后首次打开，jetAudio 会请求存储权限（Android 13+ 需要额外授予"所有文件访问权限"才能完整扫描本地音乐）。同意后 jetAudio 会自动扫描手机存储里的音频文件，生成本地音乐库索引。

4. **核对版本**：安装完成后在设置 → 关于 jetAudio 里可以看到当前版本号，和下载页标注的最新版本对比，确认没有装错版本。

## 📖 使用入门

### 本地音乐浏览与播放

首次启动完成存储权限授权后，jetAudio 会自动扫描手机内部存储和 SD 卡里的音频文件。主界面左侧边栏提供了按**艺术家、专辑、文件夹、流派**四种方式浏览音乐的入口，和大多数 Android 播放器的组织逻辑一致，但细节上有几个 jetAudio 独有的设计：

- **文件夹视图**直接对应手机存储的真实目录结构，不依赖系统媒体库的扫描结果。这对那些按自己习惯组织文件、不愿意让媒体库重新排序的用户特别有用。
- **专辑封面**支持从内嵌标签（APIC/ID3v2）读取，也可以按专辑名在线匹配下载。如果封面加载失败，可以长按专辑条目手动指定图片文件。

主播放界面的交互以手势为主：**向左滑切下一首、向右滑切上一首、向下滑退回浏览界面**，点击专辑封面可以在封面图、频谱可视化、波形可视化三种显示模式间循环切换，长按则进入可视化效果选择器。

浏览界面同样支持长按单曲进入多选模式，多选后可以批量添加到播放队列、批量标记收藏，甚至在多选模式下左右滑动快速连续多选，这对整理播放列表时很省时间。

### 手势与快捷操作

除了主界面的滑动手势，jetAudio 还提供了几种实用性很强的快捷操作：

**摇晃切歌**：在设置 → 播放里开启"摇晃切换下一首"，拿起手机用力摇晃一下就能切歌。灵敏度分低、中、高三档，建议口袋里放手机时调到低灵敏度，避免走路时误触。

**音量键快速切歌**：部分 Android 机型支持在熄屏状态下用音量键长按切换曲目。jetAudio 默认支持此行为，如果你的机型没反应，可以在设置 → 播放 → 音量键行为里切换触发模式。

**锁屏控件**：锁屏界面会显示专辑封面和上一首 / 播放暂停 / 下一首三个大按钮，Android 7.0+ 还支持锁屏通知下拉显示完整播放队列——不需要解锁就能浏览接下来要听的歌。

### 通过 SMB 协议播放 NAS 和家庭共享音乐

jetAudio 原生支持 SMB 2.0 和 SMB 3.0 协议，可以**流式播放**家里 NAS 或 Windows 电脑共享文件夹里的音乐，不需要把文件下载到手机存储。这对那些家里有大容量音乐库、不想反复拷贝文件的用户来说是个杀手级功能。

配置步骤：

1. 确保手机和目标设备在**同一个局域网**下（同一个 Wi-Fi）
2. jetAudio 侧栏 → 网络标签 → SMB → 右上角「+」
3. 填写**主机名或 IP**（比如 NAS 的局域网 IP 192.168.1.100）、**共享文件夹名**（比如 Music 或 share）、以及**用户名密码**（如果共享文件夹设了权限保护）

保存后该服务器会出现在 SMB 列表里，点进去就能像浏览本地文件夹一样浏览共享目录里的音乐。jetAudio 以 HTTP range request 方式分块读取文件，只把当前播放需要的数据缓冲到内存，不会在本地产生临时副本。

> [!NOTE]
> 如果连接不上老 NAS，可能是 NAS 只支持 SMB 1.0。去 NAS 管理界面把 SMB 最低版本调到 SMB 2.0 即可解决。

播放中断时（Wi-Fi 断开或路由器重启）jetAudio 会自动暂停，恢复网络后点继续就能从断前位置接着播，不会从头来。

### 播放增强功能

jetAudio 提供了一组"锦上添花"的播放辅助功能：

**定时关闭（Sleep Timer）**：主播放界面 → 更多菜单 → 定时关闭，最长支持 24 小时倒计时。睡前听歌助眠的典型用法，建议搭配交叉淡入淡出开 2~3 秒，定时关闭前几分钟会自然淡出，不会突然停。

**A<->B 循环**：在一首曲子里标记两个时间点（A = 起点、B = 终点），标记完成后 jetAudio 会反复在 A 和 B 之间循环播放。练琴时反复练某一段、语言学习时反复听某一句歌词，都是这个功能的典型场景。

**淡入淡出**：设置 → 播放 → 单曲淡入淡出（Fade In / Fade Out），可以分别设置 1~10 秒的淡入和淡出时长。淡入让一首歌开头慢慢变大声，淡出让结尾慢慢变小，对轻柔开场曲和安静收场的曲子效果明显。

**平衡调节**：设置 → 播放 → 平衡（Balance），在左右声道之间做 -100 到 +100 的偏移补偿。大多数时候保持中间 0 即可，某只耳机或音响有问题时可以临时补偿。

还有屏幕常亮（外接车载支架或桌面固定播放时不让屏幕自动熄屏）、方向锁定（强制横屏或竖屏）等小选项，按需开启即可。

### MIDI 格式播放（Plus 版独有）

这是 jetAudio Plus 版的一个"惊喜附赠"功能——内建了一个名叫 **jetAudio WaveTable** 的合成引擎，使用自研采样音色库覆盖 GM（General MIDI）标准的 128 种乐器加打击乐组，让 Android 上少数能原生播放 .mid / .midi 文件的播放器之一。

MIDI 文件本身只是"指令"（第 3 拍弹 C5 音、力度 100），没有实际音频数据，必须靠合成器把指令翻译成声音。Android 原生不带 MIDI 合成器，jetAudio 这一套自研 WaveTable 填补了这个空缺。

支持的格式是 .mid 和 .midi（Standard MIDI File，Type 0 / Type 1），不支持 .kar（卡拉 OK MIDI）和 .rmi（老 Windows RIFF MIDI 容器）。需要注意的是，jetAudio WaveTable 用的是预置采样，不是物理建模合成器，也不支持自定义 SoundFont（.sf2 / .sfz），所以 MIDI 音色细节上和专业 VST 合成器有差距。对于想在手机上快速预览 MIDI 草稿、听老游戏 OST 里 MIDI 格式的用户来说够用了，专业 MIDI 制作还是建议电脑端配合 FL Studio 或 Cubase。
