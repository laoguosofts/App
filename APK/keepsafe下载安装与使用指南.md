## ✨ Keepsafe 是什么

Keepsafe 是一款专注于个人隐私保护的照片与视频保险箱应用，核心思路很简单：把你不想被任何人看到的图片、视频甚至文档，全部加密锁进一个只有你自己能用 PIN 码打开的"数字保险柜"里。市面上同类应用不少，但 Keepsafe 的几个特点让它在隐私圈口碑不错——截图时自动黑屏覆盖、多设备加密云同步、闯入者输错 PIN 会被前置摄像头偷拍，还有一套 Premium 专属的安全武器库。

它适合哪些人？有私密照片不想被手机相册里乱滑、有工作敏感文档怕误发到微信、或者单纯想把旅行回忆留给自己一个人慢慢翻的用户。免费版就能满足日常收藏，Premium 订阅解锁云存储、闯入警报等高级功能。

## 🔧 安装步骤

Keepsafe 主要面向 Android 和 iOS 双平台，安装过程因系统略有差异。

### Android 安装流程

1. 从应用商店或上面的下载页获取 APK 安装包
2. 如果是第三方渠道下载的 APK，首次安装前需在系统设置中开启「允许安装未知来源应用」权限（不同品牌手机的入口位置不一，通常在"安全设置"或"应用管理"中可以找到）
3. 点击安装包按提示完成安装
4. 首次启动 App 会引导你设置 **4-8 位 PIN 码**，这是打开保险柜的唯一钥匙，务必设置一个自己不会忘记但别人猜不到的组合
5. 设置 PIN 后系统会提示填写**恢复邮箱**——这是你日后忘记 PIN 时找回保险柜内容的唯一途径，请务必填一个真实且长期使用的邮箱

> [!WARNING]
> PIN 码一旦设置无法在 App 内直接查看，也没有"显示密码"选项。如果怕忘，建议记在独立的密码管理器（如 Bitwarden、1Password）里，不要写在手机的备忘录或便签上。

### iOS 安装流程

App Store 直接搜索 Keepsafe 下载安装即可，系统会自动完成签名和权限授予。首次启动同样需要设置 PIN 码和恢复邮箱，流程与 Android 基本一致。

### 安装后的首次检查

安装完成后，建议做三件事确认一切正常：

1. 打开 App 输入 PIN 能正常进入主界面
2. 尝试在系统相册选中一张照片，看是否弹出「保存到 Keepsafe」的分享选项
3. 进入 App 设置，检查「截图保护」是否默认开启——在 App 内截图时屏幕应当全黑

## 📖 使用入门

### 把照片藏进保险柜

Keepsafe 最基础的功能就是把系统相册里的照片"搬"到 App 内部。进入 App 后点击底部的「添加」按钮，可以从系统相册选择图片，也可以直接用 App 内置的相机拍照。导入后，原图是否从相册删除取决于你的设置——Keepsafe 默认会保留原图，你可以在设置里开启"导入后删除原图"，实现真正意义上的"只在 Keepsafe 里才能看到"。

> [!TIP]
> 如果你有一堆旧照片想批量转入保险柜，可以在系统相册里多选后一次性分享到 Keepsafe，它会自动帮你建好对应的相册结构。

### 私人云同步：让多设备共享同一个保险柜

Keepsafe 私人云与普通云盘的区别在于——数据是**加密后**才上传的。Google Photos、iCloud 这类云盘是把原图原样传上去，云端可以看到、可以被推荐算法分析；而 Keepsafe 私人云上传的只有加密后的文件块，云端服务器也解不开。开启方式很简单：侧边栏或设置里找到「私人云 / Private Cloud」选项，登录 Keepsafe 账号，选择要同步的相册，等待首次同步完成即可。

| 版本 | 云端存储上限 | 费用 |
| --- | --- | --- |
| 免费版 | 有限（通常数百张量级） | 包含在免费安装中 |
| Premium | 最多 10,000 个文件 | 订阅 ¥158~238/年 |

> [!NOTE]
> Premium 的"10,000 个文件"按文件数量算，不按 GB 算。无论几百 KB 的小图还是几百 MB 的视频，都算 1 个文件——如果你经常存大视频，配额消耗会比较快。

### Premium 闯入警报：谁在偷输你的 PIN

这是 Premium 版一个很有亮点的安全功能。触发条件是连续输错 PIN 码（默认 3 次，可调整），触发后 Keepsafe 会：

1. 界面上显示"密码错误"的正常提示，不暴露任何异样
2. **静默调用前置摄像头拍一张照**（无闪光灯、无快门声）
3. 记录当时的时间戳和 GPS 位置（如果允许了定位权限）
4. 如果你开了云同步，照片会自动上传到入侵日志

下次你解锁 Keepsafe，就能在设置 → 安全 → 闯入警报里看到完整的入侵尝试列表——每一条都有照片、时间、大致位置。

| 场景 | 有用程度 |
| --- | --- |
| 家里小孩乱玩手机 | ✅ 非常有用 |
| 室友/朋友借手机时手痒 | ✅ 有用 |
| 被伴侣检查手机 | ⚠️ 有一定作用但不是解决方案 |
| 手机被偷、专业黑客攻击 | ❌ 拍的可能是戴口罩的偷手机者，对方可能先恢复出厂设置 |

这个功能**不是阻止入侵的手段，而是记录入侵证据的手段**——它帮你知道谁在打你的保险柜的主意，然后决定后续怎么处理。触发次数建议保持默认的 3 次就好，调太灵敏的话自己手抖输错也会拍一堆没用的。

### 安全分享：两种方式按需选

想把保险柜里的某张照片发给某个人，Keepsafe 提供两种分享方式：

| 特性 | Safe Send | 公开链接 |
| --- | --- | --- |
| 查看方式 | 临时网页/App 内 | 普通网页 |
| 时间限制 | 固定几秒到几分钟 | 自己设过期日期（几小时到几年） |
| 对方能否保存 | ❌ 无法保存 | ⚠️ 网页端可能可以保存 |
| 能否转发 | ❌ 一次性 | ✅ 对方可以转发链接 |
| 一次性 | ✅ 看完即失效 | ❌ 在过期日期前可无限次打开 |

Safe Send 适合"只想让某个人短暂看一眼"的场景——比如发张证件照给同事，20 秒后自动消失，不留痕迹。公开链接适合"想让很多人都能看"的场景——比如发婚礼照片让亲戚们慢慢看，可以设 1 周后过期，过期后链接自动失效、任何人打开都会看到"链接已过期"的提示。

> [!WARNING]
> 公开链接本质上是一个"知道 URL 就能访问"的页面，没有密码保护。不要用公开链接分享真正敏感的内容（证件照、私人照片），这类内容应该用 Safe Send。另外，公开链接**不会自动过期**——它会一直有效直到你手动设置过期或手动关闭，这一点很容易被忽略。

### 忘记了 PIN 码怎么办

Keepsafe 的 PIN 找回**只有一条路：恢复邮箱**。触发入口在 PIN 输入界面底部（只有输错过几次 PIN 后才会出现），流程是：点击「忘记密码」→ 输入首次设置时填的恢复邮箱 → 邮箱收到重置邮件 → 点击邮件链接设置新 PIN → 回到 Keepsafe 用新 PIN 解锁。

⚠️ 新 PIN 生效后，**本地照片不受影响**——只是换了一把钥匙。

但如果恢复邮箱也用不了（填了假邮箱、邮箱被注销、设置时跳过了邮箱填写），情况就比较棘手了：

| 情况 | 照片命运 |
| --- | --- |
| 有云备份 + 记得账号密码 | ✅ 在新设备登录账号，自动同步恢复 |
| 有云备份但忘了账号密码 | ❌ 彻底没救 |
| 没云备份 + 忘了 PIN | ❌ 本地加密照片无法找回 |

这就是加密保险柜的设计目的——别人拿了你的设备也打不开，代价是**你自己忘了也打不开**。没有任何后门或"工程师入口"能绕过 PIN 码。

> [!WARNING]
> 卸载 Keepsafe 重装**不会**帮你找回忘记的 PIN——卸载时会清除 App 私有目录，加密照片也会一起消失。恢复出厂设置同样会清除所有应用和数据。请务必在设置 PIN 时填真实邮箱，并把 PIN 和账号密码记在独立的密码管理器里。
