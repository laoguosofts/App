## ✨ Ridibooks 是什么：韩国内容品类最完整的数字阅读平台

Ridibooks（常简称 Ridi）由韩国 RIDI Corporation 开发运营，最初是一家专注电子书的平台，经过多年演进已发展成覆盖**网络漫画（웹툰）、漫画（만화）、网络小说（웹소설）、电子书（전자책）、杂志（잡지）** 五大品类的一站式数字内容生态。在韩国数字阅读市场上，Naver Webtoon 主打漫画、Kakao Page 侧重连载平台、Yes24 以传统电子书见长，而 Ridi 的差异化恰恰在于全品类覆盖——一个 App 内解决几乎所有数字阅读需求，用户不用在多个平台之间来回切换。

除了内容品类完整，Ridi 的阅读器也是韩国竞品中功能最丰富的：TTS 文字转语音、自定义用户字体、PDF 颜色反色、音量键翻页、段落宽度调节等，这些功能在其他平台要么没有、要么只能在部分设备上使用。订阅方面，Ridi Select 月费约 4,900 韩元（合人民币 25 元左右）即可无限畅读精选作品，对于重度读者来说成本远低于单篇买断。

Ridi First 是平台推出的独家内容品牌，类似 Netflix Originals——与作者签约后作品只能在 Ridi 首发和独家运营，不会在 Naver、Kakao 等竞品平台同步连载。独家内容让 Ridi 拥有了竞品无法复制的作品库，同时 Ridi First 也是平台挖掘和扶持新人作者的主要渠道。对于海外用户来说，Ridi 旗下还有 Manta.net 英文 webtoon 服务，支持全英文界面和海外信用卡直接订阅，是 Ridi 生态内面向英语读者的替代方案。

Ridi 的用户群体覆盖相当广：韩国本土普通读者一站式解决漫画、小说、书籍、杂志的阅读需求；韩语学习者借助阅读器分屏笔记功能配合浏览器翻译扩展进行双语对照学习；海外韩流爱好者通过海外信用卡直接购买韩文正版作品；还有数字阅读重度用户，特别看重阅读器功能、离线下载、多设备同步等体验细节。需要注意的是，Ridi 官方不提供应用内自动翻译功能，全产品界面为韩语。网络小说可以通过 Web 阅读器配合浏览器翻译扩展使用，但漫画是图片形式，浏览器翻译无法生效。

## 🔧 安装步骤：移动端与桌面端分别操作

### Android 安装

1. 打开 Google Play，搜索「Ridibooks」找到官方应用
2. 点击「安装」等待下载完成（应用体积约 30~50MB，建议在 Wi-Fi 环境下下载）
3. 如果是通过第三方渠道获取的 APK 安装包，需要先在设备设置中开启「允许未知来源应用安装」或「允许此来源」权限
4. 安装完成后点击「打开」即可启动

> [!WARNING] 第三方 APK 安全提示
> Ridi 官方渠道只有 Google Play 和 App Store。通过第三方网站获取的 APK 包存在被篡改或植入恶意代码的风险，建议优先选择官方商店下载。

### iOS 安装

1. 打开 App Store，搜索「Ridibooks」
2. 确认开发者为 RIDI Corporation 后点击「获取」
3. 使用 Face ID / Touch ID 完成身份验证后自动下载安装

### Windows / macOS 阅读器

桌面端阅读器适合在电脑上进行长时间深度阅读，尤其是网络小说和电子书品类体验更佳。

1. 访问官方下载页选择 Windows 或 macOS 版本
2. Windows 用户下载 `.exe` 安装包，macOS 用户下载 `.dmg` 镜像文件
3. Windows 端双击 exe 按向导完成安装，注意选择好安装路径
4. macOS 端双击 dmg 将 Ridi 图标拖入「应用程序」文件夹
5. 首次启动如遇系统安全提示（macOS 常见），在「系统设置 → 隐私与安全」中允许应用运行

### 安装后的首次校验

安装完成后启动应用，在登录页面选择「注册」或直接用已有账号登录。登录成功后进入主界面，可以看到五大品类的导航入口和推荐内容，这就说明安装没问题。首次登录会提示授权通知权限和存储权限，建议全部允许，否则会影响离线下载和更新提醒功能。

## 📖 使用入门：从书架管理到阅读器深度定制

### 书架管理：自定义分类让海量内容井井有条

Ridi 默认按品类（漫画 / Webtoon / 小说 / 电子书 / 杂志）组织内容，但对于重度读者来说，默认分类往往不够用。自建书架允许你按自己的方式重新组织已拥有的作品：把所有韩语学习资料单独放一个书架、把追了很久的长篇连载放一组方便集中更新、把看过想二刷回顾的书单独放，甚至可以按心情类型（治愈系 / 爽文 / 学术 / 考试专用）来分。

**在 App 内创建书架的步骤**：打开 Ridi App → 进入「我的 → 我的书架」→ 点击右上角「编辑」或书架管理按钮 → 选择「创建新书架」→ 输入书架名称后确认。创建完成后就可以开始往里面添加作品了。

Ridi 没有明确的书架数量限制，但建议控制在 5~15 个比较合适，名称简洁明了方便自己识别。一个作品可以同时放在多个书架里，Ridi 不强制唯一归属——这一点与默认品类不同，默认品类中一部作品只在一个品类下。

添加作品到书架有三种方式：从作品详情页找到「添加到书架」按钮选择目标书架；从书架管理页面进入某个书架后批量勾选要加入的作品；PC / Mac 阅读器还支持直接用鼠标拖拽作品封面到目标书架，更直观。

书架的分类信息会在所有登录同一 Ridi 账号的设备上自动同步——PC 阅读器、移动端 App、Web 阅读器三者之间，新增的书架、书架里的作品、书架名称都会实时同步。

### 隐藏与删除：让书架列表保持清爽

有些作品不想让别人看到、或者自己想暂时从主列表移除但不想真的删掉，这时候用「隐藏」功能。隐藏后的作品从主列表消失，但仍然在购买记录中，随时可以在「隐藏作品」列表里恢复。而「删除」则是从设备移除某作品，主要用于释放存储空间或真的不想留了——删除后本地下载的文件会被清理，但作品仍在购买记录中，随时可以重新下载。两者都会在所有设备同步。

### 阅读器背景色与夜间护眼

Ridi 阅读器在不同品类下提供不同的背景色选项。电子书和网络小说的背景色最丰富，有白色（白天阳光下对比度最高）、米色（室内夜间柔和护眼）、浅灰（长时间阅读减少眼疲劳）、深灰（夜间暗环境深色模式）、黑色（最暗的纯黑环境模式）五种选择。漫画 / Webtoon 的背景色选项较少，主要改变漫画页面**周围**的颜色，漫画本身的画面不会变色。PDF 阅读器额外支持「颜色反色」功能，会把白底黑字翻成黑底白字，夜间阅读学术 PDF 时非常有用。

切换背景色的操作很简单：打开任意作品 → 点击屏幕中央唤出菜单 → 底部找到背景色选项 → 选择想要的颜色。需要注意的是，背景色和文本排版设置一样，是**按作品 / 系列保存**的，不会全局应用到所有作品。这种设计虽然不如系统级深色模式方便，但好处是可以按作品分别设置——比如学术电子书用深灰背景，轻小说用米色背景，完全由阅读场景决定。

Ridi 没有全局的深色模式开关，深色阅读体验完全依赖阅读器内的背景色设置。夜间阅读时建议组合使用：深灰或黑色背景色、适当调大字号减少眼睛对焦压力、1.5 倍或更大行距、屏幕亮度调到环境光略亮一点的水平、手机保持在 30~40cm 的正常阅读距离不要贴太近。

### 海外用户的四种使用路径

Ridi 韩国主站支持 Visa / Master / JCB / Amex 海外信用卡直接支付，界面虽为韩语但购买流程不受影响。海外用户还有四条可选路径：直接用 Ridi 韩国 App 购买和下载正版作品；用 Web 阅读器配合浏览器翻译扩展阅读网络小说（漫画是图片形式无法浏览器翻译）；通过韩国代购充值 Ridi Cash 再由海外账户消费（有一定风险，建议优先用海外信用卡直付）；或者直接用 Ridi 旗下 Manta.net 英文服务——全英文界面、海外信用卡订阅、内容与韩国主站大量重叠，Ridi First 独家作品也会优先被选入 Manta。
