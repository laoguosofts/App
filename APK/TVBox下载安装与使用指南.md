## ✨ TVBox 是什么：一个聚合全网影视源的免费播放器

TVBox 是一款运行在安卓设备上的视频聚合播放器，核心思路是**不自带内容**，而是通过「接口」接入第三方数据源，把分散在各个平台的影视资源（点播、直播、动漫、综艺等）统一聚合到一个界面里。用户只需要添加几个有效的接口地址，就能在 TVBox 里搜索、筛选、播放几乎所有主流影视内容，相当于把视频网站的前端搬到了本地。

它最早在电视盒子圈子流行，现在也被广泛用于安卓手机、平板等设备。界面专为遥控器操作优化，首页按分类展示内容卡片，配合方向键就能完成绝大多数操作。播放器支持本地字幕加载、清晰度切换、倍速播放、画质调节等常见功能，对追求折腾的用户还有自定义播放内核、源优先级排序、本地文件浏览等进阶玩法。

> [!NOTE]
> TVBox 本身是一个**开源的播放器框架**，不存储任何影视资源，所有内容均来自用户自行配置的第三方接口。接口的可用性和内容版权由接口提供者负责，使用时请遵守相关法律法规。

## 🔧 安装步骤：手机和电视盒子两条完整路径

TVBox 不进应用商店，所以安装方式统一是**手动安装 APK 文件**。无论是手机还是盒子，第一步都是把 APK 文件放到设备能访问到的地方，然后用文件管理器打开。APK 体积约 28 MB，安装过程通常十几秒内完成。

> [!WARNING]
> 如果系统弹出「解析包时出现问题」或「安装失败」，大概率是下载的 APK 损坏或手机 CPU 架构不匹配——TVBox 只含 ARM 架构，Intel/AMD 芯片的设备无法安装。

### 手机安装（最简单，三步走完）

1. 手机浏览器或网盘 App 下载 APK，默认存放在 `Download` 或网盘下载目录；
2. 打开系统文件管理器，找到 APK 文件；
3. 点击文件，系统弹出安装确认界面，点「安装」即可。

如果是首次安装非应用商店的应用，系统可能会要求开启「未知来源」权限——在设置里找到安全相关选项，允许安装未知来源应用后再试。

### 盒子安装（三条路，按情况选）

盒子上装 APK 稍麻烦些，因为很多盒子默认没有文件管理器。三条最常用的方法：

**方法一：U 盘（最通用，推荐新手）**

1. 电脑把 APK 文件拷到 U 盘根目录；
2. U 盘插到盒子的 USB 口；
3. 盒子打开自带的文件管理器找到 APK；
4. 点安装。

如果盒子自带文件管理器识别不了 APK（部分 ROM 限制了安装外部应用），装一个第三方文件管理器再打开即可。

**方法二：ADB（最技术向，适合有基础的用户）**

1. 盒子设置里打开 USB 调试或网络调试，记下盒子 IP；
2. 电脑安装 ADB 工具；
3. 命令行依次执行：
   ```
   adb connect 盒子IP:5555
   adb install -r tvbox.apk
   ```
   `-r` 参数表示覆盖安装（签名一致时）。

**方法三：推送安装（手机联动，最省心）**

一些手机 App（如投屏软件）自带「推送安装」功能——手机和盒子在同一局域网内，手机找到盒子后可以直接把 APK 推过去安装。适合不想折腾 U 盘和 ADB 的用户。

### 遥控器操作提示

盒子上操作 TVBox，遥控器方向键导航基本够用。但有些设置项（比如手动输入接口地址）用遥控器软键盘非常痛苦——建议**外接一个 USB 鼠标**或**用手机遥控器 App** 来完成配置。

安装完成后，可以在盒子应用列表或手机桌面找到 TVBox 图标，点击即可启动。

## 📖 使用入门：从接口配置到影视播放的完整路线

安装只是第一步，真正让 TVBox 「活」起来的是**接口配置**。没有接口的 TVBox 就是一个空壳播放器，所有内容都靠用户自己接入。

### 第一步：添加接口地址

打开 TVBox，进入「设置」→「接口设置」或「数据源管理」页面。这里需要输入接口的 URL 地址——这些地址通常由第三方维护者发布，格式多为 JSON 或 m3u。

> [!TIP]
> 新手不必一次性加太多接口，先加 3~5 个口碑较好的源，确保每个源都能正常出内容，再加更多。接口地址不是越多越好，太多反而会拖慢搜索和播放速度。

### 第二步：多源管理与优先级排序

同时开多个源的好处显而易见：

- 一个源挂了还有别的；
- 不同源的覆盖内容有差异——A 源有院线片、B 源有老剧、C 源有冷门动漫，聚合起来内容更全；
- 同一部剧可能多个源都有，播放时可以切换不同解析线路。

进入接口管理页，你会看到每个源旁边都有几个关键操作：

| 操作 | 作用 |
| --- | --- |
| 启用开关 | 一键开启或关闭该源；关掉的源不会被请求也不会出现在聚合列表里 |
| 测试/连通性检测 | 手动点一下，TVBox 会尝试请求该源并报告是否通 |
| 编辑 | 修改接口地址 |
| 删除 | 移除这个源 |
| 排序 | 上下拖动调整优先级 |

**优先级排序的影响**：同时开启多个源时，TVBox 对搜索结果和播放线路的排序通常遵循「接口管理页从上到下」的顺序。排在最上面的源的结果会优先展示。建议把最稳定、最常用的源放在最上面，备用源放在后面，直播源单独在直播设置里管理（不受点播源优先级影响）。

### 判断一个源是否还能用

接口源是第三方维护的，随时可能失效。定期检查很有必要：

**方法一：直接浏览**——关掉其他所有源只留这一个，看分类和剧集能不能加载出来。首页空白或加载卡死 = 这个源挂了。

**方法二：浏览器直接访问**——在手机或盒子的浏览器里打开那个接口地址，返回 JSON/m3u 文本说明源地址还通；404/空页/HTML 页面说明源挂了。注意：有些源虽然地址还能访问，但内部的数据接口已经失效——浏览器能打开 JSON，但 TVBox 里还是加载不出内容。

**方法三：切换测试**——在 TVBox 设置里快速启停某个源，观察首页分类是否跟着变。关掉 A 源后分类少了 = A 源是活的；关掉后没变化 = A 源本来就没在工作。

建议每月花几分钟做一次源的健康度维护：全部源打开 → 浏览几个分类、搜一部剧、点进去播 → 标记哪些源加载慢或根本出不来内容 → 删掉完全失效的源 → 网上找新的接口地址补进去。

### 第三步：搜索与播放

接口配置好后，回到首页就能看到聚合的影视内容了。TVBox 的首页通常按分类 Tab 展示——电视剧、电影、动漫、综艺、直播等，每个分类下是热门内容卡片。

遥控器方向键在卡片间移动，确认键进入详情页。详情页展示剧集简介、集数列表和可选的解析线路（同一部剧如果多个源都有，会列出多条播放线路供切换）。选好线路点确认，播放器就开始工作了。

### 本地文件浏览：在 App 里直接找视频

TVBox 内置了一个简单的文件浏览器，入口通常在侧栏菜单或首页 Tab 里，名称可能是「文件浏览」「本地文件」或「我的文件」。

进入后你会看到一个目录列表，类似普通文件管理器的根目录：内部存储、外部 SD 卡、U 盘、局域网共享（如有）。遥控器方向键上下移动焦点，确认键进入目录或播放视频文件，返回键回到上一级，菜单键呼出操作菜单。

快速定位视频文件的几个技巧：

- 按路径找——知道视频存在哪就直接进那个目录（如 `Download`、`Movies`、`BaiduNetdisk` 等）；
- 按格式找——如果 TVBox 支持文件类型过滤，选择只显示视频文件；
- 按大小找——视频文件通常都比较大，从大到小排序能优先看到视频。

> [!NOTE]
> TVBox 内置的文件管理器功能简单——定位、打开、删除（部分版本）。如果需要更复杂的操作（批量复制、重命名、创建文件夹等），还是得回到系统自带的或第三方的文件管理器里操作，TVBox 只负责播放。

U 盘识别方面，插上后 TVBox 的文件浏览界面里应该立刻能看到一个新的存储条目。如果看不到，等 5~10 秒让系统挂载 U 盘，退出文件浏览重新进一次。如果还是看不到，可能是盒子 ROM 限制了 USB 存储挂载——装一个第三方文件管理器先确认 U 盘被识别。

### 第四步：给外语片加字幕

很多海外剧集（尤其是日韩、欧美）的视频源本身不含中文字幕，或者字幕翻译质量很差。这时可以自己找字幕文件（srt / ass / ssa 格式），用 TVBox 的「本地字幕」功能加载进去。

支持的字幕格式：

| 格式 | 扩展名 | 说明 |
| --- | --- | --- |
| SubRip | .srt | 最通用、兼容性最好 |
| Advanced SubStation Alpha | .ass / .ssa | 支持更丰富的样式（字体、颜色、位置） |
| VTT | .vtt | WebVTT，部分版本支持 |

操作步骤很简单：

1. 先用电脑找到字幕文件（建议用和视频文件相同的文件名，只是扩展名不同，方便自动匹配）；
2. 把字幕文件拷贝到设备的某个可访问目录；
3. 打开 TVBox 进入想看的剧集，进入播放界面；
4. 呼出播放器设置菜单，找到「字幕」或「加载字幕」选项；
5. 选择「从本地文件导入」，用文件管理器找到刚才拷进去的字幕文件；
6. 选中后确定，字幕会立刻覆盖在视频画面上。

如果字幕时间轴和视频对不上（慢几秒或快几秒），最常见的原因是字幕版本和视频源的裁剪不同（比如视频被剪掉了片头 20 秒，但字幕是完整时间轴）。解决方法是在播放器设置里找「字幕偏移」选项——正数表示向后延迟、负数表示向前提前，一步步调对齐。如果偏移量太大，可能需要重新找匹配当前视频源的字幕版本。

部分版本还支持字幕的自动加载和样式调整：

- **自动加载**：如果字幕文件和视频文件在同一个目录下、文件名相同（只是扩展名不同），TVBox 会自动识别并加载。例如 `video.mp4` 和 `video.srt`，进入 `video.mp4` 播放时自动加载 `video.srt`；
- **样式调整**：字体大小（大/中/小）、位置（画面底部/中下部）、颜色（白色默认/黄色等）、背景（半透明黑底/无底）；
- **热切换**：同一部剧有多个字幕文件（简中、繁中、英文）时，可以在播放器字幕设置里随时切换，不需要退出播放界面。

### 进阶玩法概览

TVBox 的进阶功能还有很多：

- **播放器内核切换**——部分版本支持 ExoPlayer、ijkplayer、VLC 等多种内核，不同内核在硬解兼容性、字幕样式上各有优势；
- **清晰度切换**——同一集可能有多条解析线路，每条线路的清晰度不同，在播放界面可以随时切换；
- **收藏与历史**——把常看的剧加入收藏，观看历史方便下次续看；
- **直播源管理**——直播源和点播源分开管理，互不影响，可以添加 IPTV m3u 列表；
- **局域网共享访问**——从 NAS 或电脑共享盘直接在 TVBox 里浏览和播放视频，不需要把文件拷到本地。

这些功能的具体实现方式因版本而异，遇到问题时查文档或搜一下社区分享的配置方案就行。
