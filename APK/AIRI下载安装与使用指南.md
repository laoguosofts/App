## ✨ AIRI 是什么

AIRI 是一款运行在桌面的 AI 桌宠应用，以 Live2D 或 VRM 形象常驻屏幕，支持语音对话、TTS 发声、STT 听声，核心亮点在于可自由切换意识模型和角色卡，让用户把它从一个简单的虚拟助手培养成有独立个性的 AI 伙伴。适合想要桌面陪伴感、又不满足于单一对话功能的玩家，也适合把 AI 嵌入日常信息流或自媒体工作流的内容创作者。

它的架构分三块：形象渲染（Live2D / VRM）、意识模块（对接各家大模型服务商）、机体模块（发声和听觉）。三者解耦，意味着你可以换形象、换模型、换音色而不影响其他部分。配置门槛集中在"意识页"——这也是官方文档和第三方教程反复强调的关键。

## 🔧 安装步骤

AIRI 支持 Windows、macOS 和 Android，各平台安装流程略有差异，但核心要点一致。

### Windows 安装

1. 从下载页获取最新安装包，**务必核对版本号**——beta 版功能多但可能不稳定，正式版适合日常使用。
2. 双击运行安装程序，选择安装路径（建议不要放在系统盘根目录，避免权限问题）。
3. 安装完成后桌面会出现快捷方式，首次启动可能需要几秒钟加载 Live2D 资源。

> [!WARNING] 杀毒软件误报
> 部分杀软可能将 AIRI 的注入模块标记为可疑，属于误判。如遇拦截，将安装目录加入白名单即可。

### Android 安装

1. 下载 APK 文件后，进入手机「设置 → 安全 → 允许未知来源」授权安装。
2. 安装完成首次启动，需要授予悬浮窗权限和麦克风权限（如果要用语音功能）。
3. 安卓版功能与桌面版略有差异，部分机体模块的高级设置需要桌面端完成。

### 安装后的验证

启动后检查两个点：主窗口是否正常显示 Live2D 形象，托盘图标是否出现在右下角。如果形象白屏，先在主窗口点「展开 → 刷新」，不行就重启应用。

## 📖 使用入门

AIRI 的上手曲线主要在意识模块的配置，搞定之后日常使用就非常顺滑。下面从主窗口、发声模块、聊天窗口到常见问题排查，逐个过一遍。

### 主窗口控件速览

桌面版启动后，屏幕上立着她的 Live2D 形象，窗口上有五个控件：

| 控件 | 作用 |
| --- | --- |
| 展开 ⌃ | 拉出九宫格菜单，包含登录、设置、切换角色、刷新、移至屏幕中央等 |
| 打开聊天 | 呼出聊天窗口，这是日常对话的主入口 |
| 听觉控制 🎤 | 点击后可与她说话，需要先在设置里配好语音识别 |
| 扬声器 | 官方标注暂略，功能待完善 |
| 移动 ✥ | 鼠标左键长按拖动，改变窗口位置 |

点「展开」后还有九个隐藏选项值得记住：切换暗色模式、取消置顶、总是显示 / 悬停时隐藏（穿透模式相关）、移至屏幕中央（窗口找不到时的救命按钮）。

### 发声模块配置（TTS）

让 AIRI 把文字回复读出来，需要三步走，任何一步漏了都会「有文字没声音」：

1. **配凭据**：打开「设置 → 服务来源 → 语音合成」，选服务商、填 API Key。不同服务商的计费模型不同，日常用量选免费额度够用的即可。
2. **选声音**：打开「设置 → 机体模块 → 发声」，选中刚配的服务商和模型，再从该模型提供的音色里挑一个。
3. **试听验证**：在发声页输入一段测试文本播放，听到声音即配置成功。

> [!TIP] 顺序别反
> 必须先选服务商和模型，音色选项才会出现。不同服务商显示的字段名可能不同，以实际界面为准。

还有一个大坑：AIRI 自带的本地 Kokoro 语音**不支持中文**。中文用户如果不想自己配语音服务商，出来的声音会是乱七八糟的外语腔，别以为是配置错了。

### 聊天窗口与多会话

主窗口点「打开聊天」进入聊天界面。这里有两个高频功能：

- **停止朗读**：启用语音合成后，她朗读回复时输入区会出现「停止朗读」按钮。点击只停当前语音播放，已经生成的文字回复不会丢——不想听长篇大论时放心点。
- **对话列表**：输入区左侧「对话」按钮打开列表，按最近更新时间排列，可以切换、新建、删除对话。**删除不可恢复**，清历史前先确认。

多会话的推荐布局：日常闲聊用一个长期会话，写作或头脑风暴按项目各开一个，测试新模型专门留一个「沙盒」会话弄乱就删。

### 常见问题：不回复消息的排查

配好了凭据却没反应，按命中率从高到低查：

**第一嫌疑：意识页没选服务商和模型。** 这是官方文档反复提醒的点——仅保存服务商凭据不会自动启用它。「设置 → 服务来源」里配好一切，但「设置 → 意识」里没有同时选中服务商和模型，她就不会说话。

**第二嫌疑：模型列表为空。** 部分服务商不提供模型列表，或密钥没有列表权限，需要手动照抄服务商文档里的精确模型 ID（展示名称不是 ID），一个字符不能差。

**第三嫌疑：凭据与额度。** 密钥带了多余空格或换行、账户余额不足、密钥过期——重贴一次或去服务商控制台确认。

**第四嫌疑：本地服务没跑。** 用 Ollama、LM Studio 等本地方案时，服务要先启动，Base URL 必须是 AIRI 所在设备能访问到的地址。本地模型加载较慢，加载期间发消息可能长时间无响应。

**第五嫌疑：不是故障的「慢」。** 思考模型会先默想再回复，等十几秒很正常。日常对话换非思考模型即可。

排查口诀：**意识页选没选 → 模型 ID 对不对 → 密钥额度有没有 → 本地服务跑没跑 → 是不是思考模型**。
