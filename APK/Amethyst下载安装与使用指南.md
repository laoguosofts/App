## ✨ Amethyst：手机上跑 Minecraft Java 版的启动器

Amethyst 是一款面向 Android 设备的 Minecraft Java 版启动器，由社区团队 AngelAuraMC 基于 PojavLauncher 的技术积累继续开发而来。它让你在手机或平板上直接启动 Java 版 Minecraft，支持原版、Forge、Fabric、NeoForge 等多种加载器组合，也能导入 CurseForge 或 Modrinth 格式的整合包。

启动器的前身 PojavLauncher 安卓版在 2025 年初停更后，社区接过了代码库继续迭代。Amethyst 从 2026 年 4 月的 1.0 首个稳定版开始，以大约每两周一版的节奏跟进 Minecraft 快照更新，渲染器从一代的 LTW 换为 MobileGlues、HolyGL4ES 换为 Krypton Wrapper，Java 运行时也改为启动器内在线下载管理。

适合谁用：想在手机上体验 Java 版模组生态的玩家、已有整合包想搬到移动端的用户、不想局限于基岩版功能的老玩家。不适合：只玩基岩版、或对触控操作没有需求的纯 PC 用户。

## 🔧 安装步骤

Amethyst 的安装本质上就是一个 Android APK 的安装过程，没有复杂的前置环境，但有几个注意点需要留意。

**第一步：允许未知来源安装**

由于启动器不在应用商店分发，系统默认会拦截安装。进入手机设置，找到「安全」或「隐私」相关选项，允许当前浏览器或文件管理器安装未知来源应用即可。不同品牌手机的菜单路径略有差异，但关键词都是「未知来源」或「安装未知应用」。

> [!WARNING]
> 只从信任的渠道下载 APK 文件。下载页提供的版本为官方整理的当前稳定版，安装前核对文件大小与版本号是否与下载页说明一致。

**第二步：安装并首次启动**

点击 APK 完成安装后打开启动器，首次启动会弹出一个重要提示——启动器需要申请存储权限来管理游戏目录、模组文件和存档，务必全部允许。权限没开的话，后续导入整合包、保存设置都会失败。

**第三步：Java 运行时准备**

从 1.1.0 版本开始，Amethyst 不再内置 Java 运行时，首次进入配置时会自动弹出管理器下载对应的 Java 版本。这一步需要联网，下载完成后无需手动配置，启动器会自动关联到新建的配置。

> [!NOTE]
> 如果使用的是较老版本的启动器，Java 运行时可能已内置，跳过此步即可。建议始终从官方下载页获取最新版。

## 📖 上手与核心功能

启动器装好打开，主菜单底部横幅显示的就是当前激活的「配置（profile）」——这是理解整个 Amethyst 操作体系的核心概念。

### 配置体系：一切操作的中枢

一个配置 = 一套完整的启动方案，它把以下要素打包在一起：

- 要启动的**游戏版本**（如原版 1.21.1，或 fabric-loader-0.17.3-1.21.1 这样的加载器组合）
- 专属的**触控/手柄控制布局**
- 独立的 **JVM 内存参数**
- 可自定义的**游戏目录路径**
- 指定的 **Java 运行时**与**渲染器**

配置之间完全隔离。你可以同时存在「1.7.10 怀旧档」和「1.21.1 模组档」两个配置，一键切换，各自的模组、存档、设置互不污染。这是官方推荐的组织方式——每个常玩的版本建一个独立配置，折腾模组或换渲染器前先复制一份配置当试验品。

### 创建第一个配置

主菜单底部横幅点击展开后，选「新建配置」，按向导选择游戏版本和加载器（纯原版、Forge、Fabric、NeoForge 任选其一）。Amethyst 内置了版本列表，直接点选即可，不需要自己找 jar 文件。

### 登录账户

启动器支持两种账户：微软账户（正版验证）和本地账户。微软账户登录时，官方文档给的一个被频繁忽略的技巧是——**先用浏览器登录一次 minecraft.net**，完成正常验证后回启动器再试，很多莫名其妙的登录问题就直接解决了。其他排查要点：

1. 确认账户拥有 **Minecraft: Java Edition** 授权，只有基岩版不行
2. Xbox Game Pass 通道的账户要检查玩家名是否已设置
3. 家庭组儿童子账户受微软侧限制，只能在 PC 官方启动器玩 Java 版
4. 微软认证服务器偶尔会有波动，换个时间或换个网络环境重试

本地账户依赖设备上登录过的微软账户，全新设备只有本地账户是进不了游戏的。想先体验再决定的话，启动器提供演示模式（Demo.Player）可以直接试玩。

### 模组与整合包

Amethyst 支持 CurseForge 和 Modrinth 格式的整合包导入。对于手动安装模组，有一个高频踩坑点值得单独说明：

> [!WARNING]
> 如果日志里对 mods 文件夹里的文件全部报 `Permission denied`，这不是模组本身的问题——通常是你把模组文件**剪切**进 mods 目录导致的。安卓文件系统在剪切时不会跟随权限标志，启动器读不了。修法很简单：删掉 mods 里的模组，回到原下载位置改用**复制**（不是剪切）重新放进去就行。

单个模组崩了才需要排查兼容性、加载器版本、前置模组缺失等问题。

### 渲染器与性能

1.0 版本之后渲染器换了代际：MobileGlues 取代 LTW，Krypton Wrapper 取代 HolyGL4ES。默认配置下启动器会根据设备自动选择合适的渲染器，一般不需要手动切换。如果遇到画面异常或严重掉帧，可以在配置编辑器里尝试切换渲染器，同时注意 **Sodium 模组的开关**会联动性能设置。

### 版本跟进

Amethyst 跟着 Minecraft 快照迭代。每个大快照发布后，启动器通常在一到两周内跟进发布支持版本。当前 1.1.7 版本已支持 26.3-snapshot4+，并且 LWJGL3ify 开箱即用、SDL 3.4.12 带来了手柄陀螺仪支持。更新时直接安装新版 APK 覆盖即可，已有的配置和存档数据不会丢失。
