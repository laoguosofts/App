## ✨ Seedance 2.0 是什么

Seedance 2.0 是字节跳动 Seed 团队推出的新一代 AI 视频生成模型，在文生视频、图生视频、多模态参考与编辑三类任务上均表现突出。官方发布时同步公开了内部基准测试集 SeedVideoBench-2.0 的多维评测数据，与 Sora、Veo 3.1、Kling 3.0 等旗舰模型同台对比，在指令遵循、运动质量、音画同步、编辑一致性等维度处于外圈领先位置。

相比一代，2.0 的主战场是多模态能力——拿现成素材改片、续拍、做镜头复刻这类"导演级操控"任务，2.0 的动作逻辑、特效风格与剧情叙事的参考一致性显著占优。如果你手里有一堆素材想快速攒短片、做营销物料、或者想让 AI 照着分镜脚本直接拍视频，这一代比纯文生场景更值得上手。

适用场景覆盖短视频创作、品牌营销、影视预演、游戏宣发、电商主图视频等。支持最多 9 张图片混投参考、多段视频同时借鉴动作/运镜/特效三类元素，并开放 API 供批量生产流水线接入。

## 🔧 安装与接入方式

Seedance 2.0 不是传统意义上的"下载安装"软件，主要通过云端 API 和即梦 Dreamina 平台两种方式使用，分别适合开发者批量生产和普通用户即时体验。

### 方式一：即梦 Dreamina 平台（适合个人用户）

1. 打开即梦 Dreamina 官网，注册并登录账号
2. 在模型选择器里切换到 Seedance 2.0（注意区分 Mini / Fast / 完整版，三者效果和限流不同）
3. 直接在编辑器里上传图片/视频素材 + 写提示词，点击生成即可

> [!TIP] 版本选择建议
> 日常试玩和预览用 Mini / Fast 版本，生成速度快、并发额度宽松；需要最终成片时切完整版。4K 分辨率是稀缺资源，个人账号并发上限仅 1 条，建议排队时先提交较低分辨率任务保持流水线通畅。

### 方式二：火山方舟 API（适合批量生产）

1. 注册火山引擎账号并完成企业实名认证（个人账号也能接，但并发和 RPM 额度差距大）
2. 在方舟控制台创建 API Key，记录 Access Key 和 Secret Key
3. 按官方 SDK 文档接入，任务创建是"创建任务 + 轮询状态"的异步模式，不要用同步思维写调用方

> [!WARNING] 企业认证的价值
> 企业认证后并发数从 3 提到 10、RPM 从 180 提到 600，批量生产场景这一步几乎是必做的。不认证也能用，但吞吐会被死死卡住。

## 📖 使用入门

### 多图参考：让素材各司其职

Seedance 2.0 支持最多 9 张图片混投，官方把多图玩法归纳为四类模板。通用句式核心是每个图片编号都要指明它负责什么——图片顺序即叙事顺序，编号写错模型会乱套。

**Logo 参考**：对品牌 Logo 呈现要求高的场景，专门用一张干净 Logo 图做参考，不要指望模型"顺便"画对品牌标识。

**多主体参考**：一张图里有多个角色（比如猫猫和狗狗同框），模型能分辨不同主体并保持各自形象一致性。

**多元素各就各位**：五个名额五种岗位——人物、服装、配角、场景、角标各占一个位置，像拼积木一样组合素材库里的现有资源。

**分镜图参考（导演级玩法）**：把手绘分镜脚本图 + 若干素材图一起投喂，模型能按分镜结构和顺序直接产出一段完整短片。会画分镜（或能让 AI 画分镜）的人从此多了一条捷径。

> [!NOTE] 实操要点
> 9 张图是上限不是指标，按"对画面影响大小"分配名额即可。元素越多越要逐个点名，漏一个模型就自由发挥一个，很可能跑偏。

### 视频参考：动作、运镜、特效三类复刻

视频参考是 Seedance 2.0 最体现"导演级操控"的能力。上传一段参考视频，让新片继承它的动作编排、镜头语言或特效风格。官方将其分为三类：

**动作参考**：解决"复杂动作写不出来"的痛点。与其用文字描述一套武打设计，不如直接给一段动作参考视频。动作细节、运动轨迹都会被忠实复刻。

**运镜参考**：运镜是纯文字最难描述的东西——推拉摇移的速度、节奏、衔接方式，参考视频一给就解决。适合需要复刻经典镜头语言的场景。

**特效参考**：把"特效素材库"变成提示词的一部分。金色粒子、翅膀生成轨迹、发光特效等，直接给一段你喜欢的特效视频当模板。

三类可以同时指派给同一段视频，也可以拆开各借一样东西。多段视频上限 3 段、总时长 15 秒，名额要花在刀刃上。

### API 接入注意事项

如果你打算走 API 做批量生产，以下几点直接决定你的流水线能跑多快：

| 维度 | Seedance 2.0（企业） | Seedance 2.0（个人） | Fast / Mini |
| --- | --- | --- | --- |
| 最大 RPM（非 4K） | 600 | 180 | 600 / 180 |
| 最大 RPM（4K） | 15 | 15 | 不支持 |
| 最大并发（非 4K） | 10 | 3 | 10 / 3 |
| 最大并发（4K） | 1 | 1 | 不支持 |

RPM 限制每分钟新任务提交数，并发限制同时在跑的任务数。视频生成任务耗时以分钟计，实际上并发是更紧的约束。个人账号理论吞吐约每小时 45~90 条（非 4K、并发 3），排产前用这个量级校准业务预期，不够就先跑企业认证。

架构上建议采用异步任务模式 + 本地队列化提交 + 指数退避重试。预览任务用 Mini / Fast 高并发跑，筛选后的成片任务切主模型串行渲染，整体吞吐与成本最优。密集轮询不会加快生成，只会浪费请求配额，官方示例是 30 秒一轮。

### 评测数据怎么读

官方评测集 SeedVideoBench-2.0 覆盖指令遵循、运动质量、画面美感、音频表现力、音画同步等维度，结果代表官方口径，第三方榜单可能给出不同排序。官方自己承认的短板包括细节稳定性、拟真度、动态生动性，以及音频侧多人口型匹配和偶现失真。选型时可以参考：主力场景是多模态参考与编辑就选 2.0，纯文生视频场景与其他旗舰模型的差距感知上没那么大。
