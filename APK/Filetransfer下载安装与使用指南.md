## ✨ Filetransfer 是什么

Filetransfer 是一款面向 Android 设备的轻量级 FTP 服务器工具，它把手机变成一个局域网文件服务器，让电脑端通过标准 FTP 协议直接读写手机存储。和蓝牙、云盘互传、厂商互传等方案相比，Filetransfer 的核心差异在于**不走云端中转**——手机和电脑在同一个 WiFi 下直接建立点对点连接，文件只在两台设备之间流动，不经过任何第三方服务器。

这个定位让它特别适合两类场景：一类是对隐私敏感的文件（私人照片、工作文档、录音录像），数据不出本地网络就意味着没有中间存储的暴露风险；另一类是大文件批量传输，云盘要先上传再下载，流量翻倍、速度受服务商限速，而 Filetransfer 直接跑满 WiFi 带宽，省流量也省时间。

Filetransfer 本身体量很小，功能聚焦——启动 FTP 服务、配置端口和账号、前后台切换，没有多余的 UI 和广告。它利用 Android 的前台服务机制在后台常驻运行，传输过程中不会被系统杀掉，通知栏有一条常驻服务通知标明状态。电脑端不需要安装任何客户端，资源管理器、Finder、终端里带 FTP 的工具都能直接连上。

## 🔧 安装与配置要点

### 系统要求

Filetransfer 面向 Android 平台，支持安卓 6.0 及以上版本。PC 端不需要安装任何软件——Windows 资源管理器、Mac Finder、Linux 文件管理器都自带 FTP 客户端能力，直接在地址栏输入 FTP 地址即可连接。

### 安装步骤

1. **下载 APK**：从下载页获取最新版本的安装包文件。下载时留意文件大小——这类轻量 FTP 工具的 APK 通常只有几 MB，如果拿到的文件异常大或异常小，建议重新下载
2. **开启未知来源安装**：安卓系统默认禁止安装应用商店外的 APK。进入 **设置 → 安全**，找到「安装未知应用」或「允许未知来源」，给你的文件管理器或浏览器授权安装权限
3. **安装 APK**：点击下载好的 APK 文件，按提示完成安装
4. **首次启动与权限授予**：这一步是后续一切正常工作的前提。首次打开 Filetransfer 时，系统会弹出多个权限请求窗口，**每个弹窗都要点"允许"**——尤其是安卓 11+ 上会出现的「所有文件访问权限」，这个权限决定了 FTP 服务器能看到完整的存储还是只有几个空目录

> [!TIP] **权限给错了怎么办？**
>
> 首次启动时如果手滑点了"拒绝"，随时可以在系统设置里重新打开。路径：**设置 → 应用和通知 → 找到 Filetransfer → 权限**，把存储、文件访问、所有文件等权限全部打开。权限修改后需要重启 FTP 服务才能生效——FTP 服务器只在启动时读取一次权限状态。

### 后台保活设置（推荐）

如果希望传输大文件时不被系统杀掉后台进程，建议额外做两步设置：

1. 在手机的**近期任务列表**中，把 Filetransfer 应用锁定（各品牌手机的操作方式略有不同，小米是下拉卡片、华为是长按卡片选择锁定）
2. 在系统设置的**电池优化**里，把 Filetransfer 设为「不限制」或「无限制」

完成这两步后，Filetransfer 的 FTP 服务就能在后台持续稳定运行，长时间传输不会中断。

### 传输前的快速检查清单

启动 FTP 服务之前花 10 秒钟确认三件事，能避免大部分"连上了但不能用"的困扰：

| 检查项 | 怎么确认 |
|--------|----------|
| 手机已连接网络 | 通知栏 WiFi 图标亮着，或者热点已开启 |
| 存储权限已放行 | Filetransfer 主界面能看到文件目录，不是空的 |
| 后台保活已开（可选） | 近期任务里应用已锁定 |

## 📖 使用入门

### 第一回合：启动 FTP 服务

打开 Filetransfer，主界面中心有一个「启动」按钮。点一下之后，应用在后台依次完成几件事：

1. 从当前活跃的网络接口获取局域网 IP 地址——WiFi 路由器下通常是 `192.168.1.x` 或 `192.168.0.x`，手机开热点时是 `192.168.43.x`
2. 在该 IP 上绑定默认端口 **2121**，开始监听客户端连接请求。如果 2121 被其他应用占用，会自动切到下一个可用端口
3. 根据存储权限配置，准备好对外暴露的文件目录
4. 切换到 Android 前台服务模式，通知栏出现常驻通知表明服务正在运行

启动成功后，主界面中央会出现 `ftp://IP:2121` 格式的地址——这就是电脑端要输入的连接地址。服务开关也会从「启动」变成「停止」（红色）。

> [!NOTE] **启动失败怎么办？**
>
> 常见的启动失败场景有三种：（1）点启动没反应——大概率是 WiFi 断了或热点没开，先确认网络连通；（2）提示端口被占用——进入设置把端口改成 2222 或 30000 之类不常用的端口；（3）启动后电脑连上是空的——几乎肯定是存储权限没给全，去系统设置补权限再重启服务。

### 第二回合：电脑端连接

确保电脑和手机在同一个局域网（同一个 WiFi 路由器下，或者手机开热点让电脑连上去），然后：

**Windows 用户**：打开资源管理器，在地址栏输入 `ftp://手机IP:2121`（比如 `ftp://192.168.1.100:2121`），回车。资源管理器会把 FTP 站点当成一个普通文件夹打开，左侧导航栏还可以把它「固定到快速访问」。

**Mac 用户**：Finder →「前往」菜单 →「连接服务器」→ 输入 `ftp://手机IP:2121` → 点击连接。

**Linux 用户**：文件管理器的「连接到服务器」功能，或者直接用终端 `ftp 手机IP` 命令。

连接成功的标志是能看到手机存储的根目录，里面包含 `DCIM/`、`Pictures/`、`Download/`、`Documents/`、`Movies/` 等标准目录。

> [!WARNING] **连上但文件列表是空的？**
>
> 这几乎 100% 是存储权限没给全。很多人首次启动时手滑点了"仅允许照片媒体访问"而不是"所有文件访问权限"，结果 FTP 服务器只能暴露一个空壳。去 **设置 → 应用 → Filetransfer → 权限**，把「所有文件访问权限」打开，然后**强制停止应用再重新启动 FTP 服务**——权限只有在 FTP 服务启动时才会重新读取。

### 第三回合：传输文件

连接建立后，FTP 站点和普通本地文件夹没有本质区别——可以直接把电脑文件拖进手机目录，也可以把手机文件拖到电脑上。常用的操作：

- **导出手机照片**：进入 `/DCIM/Camera/`，全选后拖到电脑文件夹
- **导入电脑文件**：把电脑上的文档或 APK 直接拖进手机的 `/Download/` 目录
- **批量清理**：在 `/Download/` 里选中不需要的文件直接删除，手机端同步生效

### 手机存储目录速查

FTP 根路径下各目录的对应关系：

| 你要找的内容 | FTP 路径 |
|--------------|----------|
| 相机拍的照片 | `/DCIM/Camera/*.jpg` |
| 相机拍的视频 | `/DCIM/Camera/*.mp4` |
| 系统截屏 | `/Pictures/Screenshots/` |
| 下载的 APK | `/Download/*.apk` |
| PDF 文档 | `/Download/*.pdf` 或 `/Documents/` |
| 微信保存的图片 | `/Android/data/com.tencent.mm/MicroMsg/*/WeChat/` |
| 微信视频 | `/Android/data/com.tencent.mm/MicroMsg/*/Video/` |
| 音乐文件 | `/Music/` 或 `/Download/*.mp3` |

不同品牌手机可能有少量定制目录（小米有 `MIUI/`、华为有 `EMUI/` 等），这些是厂商专属文件，FTP 下能看到但一般不需要操作。

> [!TIP] **FTP 路径 vs 手机文件管理器**
>
> 两者指向同一份存储，只是展示方式不同——文件管理器的"内部存储"就是 FTP 的根路径 `/`，但 FTP 会把 `Android/data/` 这类系统隐藏目录也显示出来。在 FTP 里对文件的任何修改，回到手机文件管理器里也会同步变化。但**不要手动删除或修改 `Android/data/` 下的文件**——删错了可能导致应用数据损坏或重置。

### 停止服务

传输结束后，回到 Filetransfer 主界面点「停止」。应用会依次关闭 FTP 端口监听、断开所有已连接的客户端、退出后台服务状态，通知栏的常驻通知也会消失。这一步很重要——让手机回到正常的低功耗状态，不要让 FTP 服务在后台一直空转。

### 常见问题速查

**Q: 电脑输地址连不上、超时？**
A: 先确认手机 IP 地址有没有变（WiFi 重连后 IP 可能更新），再检查路由器有没有开 AP 隔离——某些公共 WiFi 或企业网络会隔离客户端之间的通信，导致两台设备互相不可见。家用路由器一般默认关闭 AP 隔离。

**Q: 传输速度忽快忽慢？**
A: WiFi 信号强度、路由器负载、是否同时在跑其他大流量任务都会影响速度。如果在同一个房间里速度还很慢，试试把路由器的 2.4GHz 和 5GHz 分开，两台设备都连 5GHz 频段。

**Q: 能不能设置账号密码？**
A: 可以在 Filetransfer 的设置里配置 FTP 用户名和密码。默认是匿名连接（无密码），在公共场所使用时建议加上账号密码，防止同局域网内的其他设备误连。

**Q: 手机开热点的方式安全吗？**
A: 手机热点模式下，FTP 服务同样只对连接热点的设备开放，安全边界和同一个 WiFi 路由器下是一样的。热点本身有 WiFi 密码保护，不知道密码的设备连不上热点自然也连不上 FTP。
