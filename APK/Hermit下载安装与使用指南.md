## ✨ Hermit 是什么：把网页变轻应用的沙盒神器

Hermit 是一款 Android 平台的轻应用创建器（Lite App Builder），核心能力是把任意网站打包成独立的轻量级应用。它不是浏览器，而是一套基于 WebView 的沙盒系统——每个轻应用拥有隔离的 Cookie、存储和进程，原生 App 几十上百 MB 的体积在它这里只占几 MB。

对重度手机用户来说，Hermit 的价值不止于省空间和省电量：同一网站多开账号、给社交网站常驻隐身模式、为不同场景隔离 Cookie 轨迹——这些在传统浏览器里很难做好的事，在 Hermit 的沙盒模型下都是原生支持的。资讯、论坛、电商、翻译、查询类的轻量工具，换成 Hermit 轻应用后，原生 App 可以直接卸掉，后台不再耗电、不再偷偷收集数据。

不过它也不是万能的。依赖摄像头实时处理、需要复杂通知推送的即时通讯、大型游戏、银行支付这些场景，原生应用的能力 Hermit 暂时还替代不了。稳妥做法是先把轻应用装上试用一周，确认功能齐全再卸载原应用。

## 🔧 安装与卸载：两步做对才真的省

Hermit 本身的安装没什么难度——APK 直接装、Google Play 一键装都可以。但有两个容易被忽略的细节，影响到你能不能真正获得它的省电省空间优势。

### 第一步：安装 Hermit 本体

APK 安装时如果系统拦截了"未知来源"，到设置里给文件管理器或浏览器开一次权限就行，装完可以关掉。Google Play 版本更省心，不需要手动管权限。安装包体积在 5 到 10 MB 之间，整个 App 占的空间非常小。

### 第二步：创建轻应用后记得卸载原生 App

这是 Hermit 团队在入门指南里专门拎出来强调的事——**轻应用装好后尽快卸掉对应的原生应用**。你可能觉得轻应用都装了，原 App 留着也不影响，实际上：

- 原生 App 几十上百 MB 的存储空间还在
- 原生 App 的推送保活和自启动机制还在后台耗电
- 原生 App 还在通过各种方式收集你的数据

> [!TIP]
> 稳妥的做法是：轻应用装好 → 试用一周 → 确认所有常用功能正常 → 再卸载原生。不要刚装上就急着删，万一有些边缘功能轻应用还覆盖不到。

哪些适合换、哪些先别动，大致可以这样判断：

| 适合换轻应用 | 暂时别换 |
| --- | --- |
| 资讯、新闻、天气 | 依赖摄像头实时处理（扫码、直播、AR） |
| 论坛、社区、追更站 | 需要复杂推送的即时通讯（WhatsApp、Telegram） |
| 移动网页版体验好的购物电商 | 大型游戏或重度依赖原生能力的应用 |
| 社交（移动网页版功能齐全的前提下） | 银行、支付类（安全优先） |
| 工具类（翻译、单位换算、查询） | |

## 📖 使用入门：从创建第一个轻应用到玩沙盒

### 基础：创建一个轻应用

打开 Hermit 主界面，点右下角的加号，输入网站域名或直接粘贴网址，Hermit 会自动解析 favicon 作为图标，生成一个独立的轻应用。创建完成后，主屏幕上会多出一个新图标，点开就是那个网站的完整移动网页版——但这次，它拥有自己的 Cookie 和存储，跟浏览器完全隔离。

### 进阶玩法一：同一网站多开账号

这是 Hermit 被提及最多的用法之一。Chrome 或 Firefox 虽然也有 Profile 切换，但切来切去很麻烦；隐身模式一退出就清数据，没法长期用；装两个浏览器既占空间又不优雅。Hermit 的做法干净得多——**同一个网站创建两个轻应用，各绑一个沙盒，各登一个账号，同时在线互不干扰**。

Google Play 评论里有用户专门提到这点：有两个甚至三个 Twitter/X、两个 Reddit、两个知乎——一个工作身份、一个私人兴趣，两个轻应用并排放在桌面上，邮件来了直接点开对应那个，不用切 Profile 不用切浏览器。

### 进阶玩法二：给社交网站开永久隐身

Facebook、Instagram、X 这些网站对追踪非常激进——Cookie、像素、甚至 ETag 都在跨站追踪你的行为。在 Hermit 里，你可以给这些网站创建一个**永久隐身模式的轻应用**：每次打开都不带正常浏览的 Cookie，关掉自动清除，从根上切断追踪链。

### 进阶玩法三：利用沙盒触发新用户优惠

这是用户自己发现、Hermit 官方功能设计刚好允许的非官方用法：某些付费墙网站会给新用户前几篇免费读，换一个全新的沙盒就是一个全新的"新用户"，就能继续读。把付费墙网站也放进沙盒里，说不定能省点订阅费。

### Premium 功能：用户脚本与 Bookmarklets

这是 Hermit 付费版的核心，一次性买断解锁，不是订阅制。它支持两类脚本：

| 类型 | 扩展名 | 运行方式 | 典型场景 |
| --- | --- | --- | --- |
| User Script | `.user.js` / `.user.es` | 每次页面加载自动运行 | 自动改 CSS、去掉弹窗、加功能按钮 |
| Bookmarklet | `.js` / `.es` | 手动从 Quick Settings 触发 | 清除 Cookie、提取页面链接、快速分享 |

Bookmarklet 设计成只能手动点触发——防止你不小心跑了会破坏页面的脚本。Hermit 内置了一批官方提供的脚本，包括自动切换桌面版、自动展开折叠内容、页面截图、提取文本等，在主应用的 User Scripts → Library 里能一键装。

你也可以自己写 JavaScript 脚本直接粘贴进 Hermit。有一点要注意：出于安全原因，Hermit 不支持 `@grant`、`@require`、`@resource` 标签，所有脚本依赖必须内联在同一个文件里。

### 常见问题：后台耗电

Hermit 设计上是退出即停的低功耗模式，但在某些手机上还是会显得耗电——小米、华为、OPPO 等厂商修改了安卓的进程管理机制，比原生 Android 激进得多地杀后台，Hermit 被频繁重启就会启动慢、耗电、体验差。

> [!WARNING]
> 如果轻应用切走后回来要重新加载、Web Monitors 通知不准时，大概率就是厂商的激进杀后台在作祟。解决方法是把 Hermit 从电池优化里排除并加入后台白名单。

各厂商 ROM 的路径不太一样：

| ROM | 设置路径 |
| --- | --- |
| MIUI | 设置 → 应用设置 → 应用管理 → Hermit → 省电策略 → 无限制 |
| ColorOS | 设置 → 电池 → 应用冻结 → 关闭 |
| OneUI | 设置 → 电池和设备维护 → 应用电池管理 → Hermit → 不限制 |
| MagicUI | 设置 → 电池 → 耗电排行榜 → Hermit → 启动管理 → 允许自启动 |

如果都不奏效，终极方案是换接近原生 Android 的 ROM——LineageOS、Pixel Experience 这类不会乱改进程管理。
