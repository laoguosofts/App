## ✨ Color Picker 是什么——口袋里的标准色卡阅读器

Color Picker 是一款面向安卓设备的取色工具应用，由独立开发者 Mikhail Gribanov 开发维护，2016 年上架 Google Play 商店。它的核心思路很直接：把手机相机对准任何实物，屏幕上的取色框实时刷出这颗颜色的标准色名和色号——比如「97% COPPER，#AD6E33」。

它解决的是一个非常具体的窘境：肉眼猜色猜不准，色号问不出来。刷漆想跟旧墙一个颜色、布料想配一颗接近的线、网页想复刻一张海报里的蓝——这些场景里「看起来差不多」没有用，你需要的是 RAL 9010 或 #F44336 这种可以下单、可以写进代码的读数。

它的能力用四件事可以概括：**读**——相机实时取色与图片定点取色，取色框可调形状与大小；**对**——内置 1000+ 标准色卡（RAL Classic、Material Design、HTML 色名、日本传统色等），取色时直接报出最接近的标准色和匹配度百分比；**拆**——专家模式把一颗颜色拆成色温、主波长、亮度，以及 HEX/RGB/CMYK/HSL/CIE LAB 等一整套色值体系；**存**——历史记录、相近色推荐、自定义色卡、CSV 导入导出，取过的颜色都能带走。

日常判断红绿灯、挑衣物、分辨水果生熟、认界面状态色，都是「对准 → 读名」一步的事。设计师采集配色、装修时对墙漆色号、色盲用户识别身边物体颜色，这些需求都能覆盖。

## 🔧 Color Picker 安装步骤详解

Color Picker 仅支持安卓平台，安装流程与普通安卓应用一致，但有几点需要注意。

### 安装前置条件

- **系统版本**：应用要求 Android 5.0 及以上，覆盖目前绝大多数在役设备
- **存储空间**：安装包体积较小，留出 20MB 以上即可
- **相机权限**：首次启动时需要授予相机权限，否则无法使用相机取色功能

### 两种安装路径

**路径一：Google Play 商店（推荐）**

1. 打开 Play 商店，搜索 Color Picker: Find Name & Code
2. 确认开发者为 Mikhail Gribanov，点击「安装」
3. 等待下载完成后自动安装，首次启动授予相机权限

**路径二：安装包侧载**

1. 从下载页获取最新版本的 APK 文件
2. 将 APK 传输到手机内部存储或 SD 卡
3. 手机端打开文件管理器，找到 APK 文件点击安装
4. 如果提示「未知来源」，进入设置 → 安全 → 允许安装未知来源应用，再次点击安装

> [!WARNING]
> 侧载安装时务必确认安装包来源可信，不要从第三方来路不明的网站下载，避免安全风险。

### 安装后快速核验

1. 打开应用，相机画面应该直接铺满屏幕，顶部有工具栏图标
2. 将取色框对准任意物体，观察屏幕下方是否显示色名和 HEX 色值
3. 进入设置页查看版本号，与下载页标注的最新版本对比确认一致

## 📖 Color Picker 使用入门——从第一次取色到进阶玩法

### 相机取色：最常用的日常场景

打开应用后默认进入相机取色模式。把中心的取色框对准你想识别的物体，屏幕下方会实时刷新读数：色名、匹配度百分比、HEX 色值一行齐。默认活动色卡是 Common colors（900 个日常色名），适合大多数场合直接读出颜色名称。

匹配度辅助判断把握大小：96%+ 可以放心采信，偏低时多取两个点位确认。

### 相机控制：让读数稳定下来

取色读数飘，多半不是应用的问题，是相机参数在变。顶部工具栏的那排图标就是用来把这些变量摁住的。推荐按以下顺序排查：

1. **锁定白平衡**——最关键的一项。自动白平衡会让相机不断「纠正」颜色（比如把暖光环境往冷里拉），读数随之漂移；锁定后相机停止调色，读数立刻稳定下来
2. **调曝光**——解决「读数比肉眼看着偏亮或偏暗」
3. **闪光灯补光**——暗处补光时注意闪光是「过曝源」，离得近时读数会偏亮偏白，适当拉远距离或改用环境光
4. **放大取色框**——仍不稳时把取色框放大用区域平均，比单像素读数更抗干扰

> [!TIP]
> 相机读数永远「相对白平衡成立」。锁白平衡后再读，同一个物体在同一个光环境下读数可复现——这正是对色需要的。而自动白平衡下，同一面墙上午读和下午读可能差出一截。

### 图片取色：屏幕和照片上的颜色

想取屏幕上某个图标或网页配色？直接截图，然后在应用里选择图片取色模式，导入刚才的截图。图片取色是像素级读数，没有光线干扰，比相机取色更准，特别适合设计参考和界面配色复刻。

### 色盲辅助：把「猜颜色」变成「读颜色」

色觉障碍者可以把活动色卡停在 Common colors，对着想知道颜色的东西取色——读数直接报色名，不看色样、不听描述，名字即答案。三个实用技巧值得记住：

- **读名字，不读色值**：HEX 对色盲用户没有意义，色名才是有效输出。可以在自定义色卡里建一张「高频对象卡」，把自己常遇到的颜色（衣柜色、办公室工位色）改写成中文用途名
- **用相近色校准语境**：「这衣服算深蓝还是黑？」详情页的相近色列表会同时列出 Black 和深蓝系色名与各自距离，比单点读数更有信息量
- **同色判断用历史**：两件东西是不是一个颜色？各取一颗，在历史记录里并排比对色值与匹配度，比肉眼在不同光线下判断可靠

> [!NOTE]
> 它不能「治疗」色觉差异，但能把「猜颜色」变成「读颜色」——很多场景下，这就够改变了。相机取色读的是像素，不是「人眼观感」：光照、阴影、反光都会让读数偏移，重要判断永远以现场常识为准，应用只作辅助。

### 历史记录：你的取色账本

取过的每一颗颜色都自动进历史，不用手动保存。每条历史记录包含四要素：色样条（整行底色即该颜色）、色名加 HEX、来源色卡、时间。历史页是整款应用的「账本」，三件常做的事：

- **重开**：点任意条目进颜色详情页，相近色、全套色值、复制分享都在
- **编辑**：给颜色改名字——把系统给的「Cyan A200」改成「阳台墙」之类的实际用途名，方便回溯
- **清理**：多选删除配合导出做「留档再清空」的节奏

历史记录的典型用法可以用这张表概括：

| 场景 | 动作 |
| --- | --- |
| 对色作业（刷漆/采购） | 按时序就是现场取色单，去店里直接翻 |
| 设计采集 | 改名归组，再导出 CSV 进素材库 |
| 换手机 | 先导出 CSV，新机导入，流水搬家 |

> [!WARNING]
> 历史记录不存原图：图片取色后删除原图，读数和色样仍在，但无法回到取色画面重取。清除应用数据或卸载会丢历史，重要流水务必先导出 CSV。

### 专家模式与色卡切换

需要更深度的颜色分析？切换到专家模式，应用会把一颗颜色拆成色温、主波长、亮度，以及 HEX/RGB/CMYK/HSL/CIE LAB 等一整套色值体系。做设计或印刷相关工作时，这些数据比单纯的色名更有参考价值。

内置的标准色卡覆盖了多个领域常用的色系：RAL Classic（工业涂料标准）、Material Design（谷歌设计规范）、HTML 色名（网页开发）、Traditional colors of Japan（日本传统色）等。根据你的使用场景切换活动色卡，匹配结果会更精准。
