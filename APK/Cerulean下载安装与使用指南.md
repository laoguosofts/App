## ✨ Cerulean 是什么——随身的安卓工具箱

Cerulean 是一款面向 Android 平台的轻量级工具箱应用，核心思路是「一个顶 N 个」——把日常高频用到但又不值得装独立 App 的小工具聚合在一处。PDF 转换、表情包制作、视频链接解析、应用权限检查……这些散落在各种 App 里的零碎功能，在 Cerulean 里都能直接用，而且几乎全部离线运行、不收集数据。

对于追求极简的用户来说，Cerulean 的价值在于**消除功能碎片化**：手机里装 20 个 App 只为每个用一次，远不如装一个工具箱随取随用。对于学生、自由职业者、内容创作者这类经常要处理杂事的群体，它尤其好用——拍张纸质文档合成 PDF 发给同事、刷 B 站时想离线存一个教程、朋友照片加两个字做个表情，这些事在 Cerulean 里几步就能搞定，不用跳来跳去折腾。

> [!NOTE]
> Cerulean 的核心定位是「轻量工具箱」，所有内置工具都是基础功能——不会取代专业 PDF 编辑器、专业修图软件或专业下载器。它解决的是「偶尔用一次」的场景痛点。

## 🔧 安装步骤

Cerulean 的安装包体积不大，整个过程简单直接，但有几个细节容易踩坑。

**第一步：下载并核对版本**

从上方下载页获取最新安装包后，建议先核对一下文件大小和版本号——避免下载到过期版本或来源不明的二次打包包。如果安装包比同类应用明显小很多或大很多，都值得留意一下。

**第二步：允许安装未知来源**

如果是从应用商店外获取的 APK，Android 系统默认会拦截。操作路径因系统版本而异：

1. 进入手机 **设置** → **安全** 或 **隐私**
2. 找到 **未知来源** 或 **安装未知应用** 选项
3. 选择你用来下载安装包的浏览器或文件管理器，允许其安装应用

> [!WARNING]
> 部分国产 ROM（MIUI、EMUI、ColorOS）会对非应用商店安装的 APK 触发额外安全扫描。如果提示"风险应用"但安装包来源可信，可以继续安装——这是国产 ROM 的通用策略，不代表应用本身有问题。

**第三步：安装并首次启动**

点击安装包一路点"下一步"即可。首次启动时应用会弹出基础权限请求——存储访问、相机、麦克风等，按需授权即可。如果只打算用部分工具（比如只用来做 PDF 转换），对应权限不给也能正常运行未涉及的功能。

**第四步：核对安装完整性**

装好后可以进应用的 **关于** 页面看一下版本号是否和下载页标注的一致，再随便打开一个内置工具（比如表情包制作）试一下能不能正常进入——能进就说明安装 OK。

## 📖 日常高频工具怎么用

Cerulean 把几十个内置工具按功能分了组，包括文字处理、图片处理、网络工具、系统管理等。下面挑几个最常用、最能体现它价值的工具，结合实际场景讲讲怎么操作。

### PDF 转换——随手把纸质文档变电子档

PDF 转换是 Cerulean 文档处理类里用得最多的工具，支持图片转 PDF 和 PDF 转图片两个方向。

**图片转 PDF 的典型场景**：办公时手头没有扫描仪，用手机把一堆纸质文档分别拍照，然后在 Cerulean 里把这些图片合成成一个完整 PDF 发给同事。操作步骤很简单：打开 PDF 转换工具 → 选"图片转 PDF" → 从相册挑图（可以多张一起选，选中的顺序就是 PDF 里的页码） → 设好输出参数（页面大小、方向） → 点转换。几秒钟就能生成一个 PDF 文件，保存在手机存储里。

反向操作——PDF 转图片——也很实用，比如看到 PDF 里某一页的插画特别好看，转成图片就能单独提取出来存了。

> [!TIP]
> Cerulean 的 PDF 转换是轻量级的，不支持加密 PDF 的解密，也做不了复杂的页面重排、文字编辑。如果是专业 PDF 编辑需求还是得装专门的 App。但就"偶尔把几张图合成一个 PDF 发出去"这件事来说，没必要装一个几百 MB 的专业工具。

### 表情包制作——三分钟搞定专属表情

表情包制作工具属于图片处理分组，主打"给一张图加几个字就能发表情"。操作完全零门槛：先选底图（可以从相册挑朋友照片、宠物照片，也可以用实时拍照），然后输入表情文字内容，选好字体颜色、字号和描边效果，手指拖动文字到合适位置，预览满意后保存到相册。

几个实用建议：文字颜色选白色或黄色，搭配黑色描边——这样在任何背景的底图上都看得清；字号尽量调大，表情在聊天缩略图里也不能糊；字体选粗体，别用太花的艺术字体影响识别。

保存到相册后，在微信聊天窗口打开表情收藏，就能添加为自定义表情随时用了。

### B 站视频解析——想离线看的教程直接存

网络工具里 B 站视频解析是最受欢迎的功能之一。操作逻辑很清晰：先在 B 站 App 里打开想保存的视频，点分享复制链接；回到 Cerulean 里粘贴这个链接，点解析按钮，几秒后就能拿到视频直链下载地址或视频封面。

能解析的内容包括普通 BV 号视频、av 号视频，以及直接提取视频页的封面图。但有两个需要注意的点：**大会员专享内容**可能只能解析出低画质版本，或者完全无法解析；B 站的反爬机制一直在变，如果某段时间突然解析失败，通常等 App 更新后就能恢复。

> [!NOTE]
> 解析和下载的内容仅供个人离线观看使用，请勿二次上传到公共平台或用于商业用途。

### 应用权限查看——揪出偷偷申请不必要权限的 App

这个工具在系统管理分组，功能是集中查看手机上所有应用的权限申请情况。为什么要用它？因为安卓 App 申请的权限常常让你摸不着头脑——一个手电筒 App 要通讯录和短信权限干嘛？一个计算器 App 要位置信息又是为什么？

进 Cerulean 的"应用权限查看"，选一个应用进去就能看到它申请的所有权限清单，每项后面标着是已授权还是被拒绝。可以直接跳转到系统权限设置页逐项开关，不用一个个打开应用的设置去找。

**三个高频排查场景**值得记住：

**场景一：某个工具打开没反应或功能缺失**——八成是权限没给。分贝仪没数值（麦克风权限）、尺子不能用（相机权限做量角器）、保存图片失败（存储权限）。来 Cerulean 查一下权限状态，没给的进系统设置手动允许就行。

**场景二：某 App 申请了一堆没必要的权限**——发现手电筒 App 要通讯录、短信、位置权限，典型的权限滥用。如果是正规 App 手动关掉不需要的权限；如果是来源不明的 App，直接卸载。

**场景三：权限被系统自动关掉了**——MIUI、EMUI 这类国产 ROM 会在长时间不用某 App 后自动关掉它的权限省电。如果发现某个工具突然不能用了，来这里检查一下权限状态往往就能定位问题。

| 权限类型 | 风险等级 | 典型滥用场景 |
|---------|---------|-------------|
| 精确位置 | 高 | 手电筒、计算器申请位置权限 |
| 麦克风 | 高 | 非语音类 App 申请录音权限 |
| 相机 | 高 | 纯工具类 App 申请相机权限 |
| 通讯录 | 中 | 单机类 App 申请联系人读取 |
| 存储 | 中 | 小工具申请全盘存储权限 |
| 自启动 | 中 | 不需要常驻的 App 申请自启动 |

### 实际使用建议

Cerulean 内置了几十种小工具，上面只挑了最常用的几个。其他工具比如压缩图片、二维码生成、时间戳转换、设备信息查看等，逻辑都类似——选工具 → 输入素材 → 点处理 → 出结果。上手过一两个之后，其他工具摸索起来基本没学习成本。

一个实际建议：**先把自己最常用的 3~5 个工具熟悉透**，剩下的等遇到具体需求时再进来找——没必要一上来就把所有工具都跑一遍。工具箱应用的好处就是随用随开，不用提前规划。
