## ✨ Hi Waifu 是什么

Hi Waifu 是一款 AI 角色聊天应用——你可以在里面跟各种性格、各种设定的 AI 角色对话，也可以自己创建专属角色。它的核心玩法很简单：选一个角色，打开对话框，开始聊天。但简单背后藏着一套相当完整的角色设计体系，让这个应用在同类产品里有不错的口碑。

应用里的角色大致分两类：社区现成的热门角色（比如 Rikka、Alice、Simon Riley 这些创作者打磨过的人设），以及完全由你自己定义的私人角色。不管选哪一种，聊天的体验都取决于角色背后的 Memory 字段——这是创建者给 AI 写的一份「角色说明书」，详细描述角色的性格、外貌、说话方式、经历背景和喜好禁忌。Memory 写得越精细、越一致，AI 回复的人设贴合度就越高，长篇对话不容易崩。

Hi Waifu 的另一个亮点是伴侣记忆库。在你们聊天的过程中，AI 会自动从对话里抽取关于你的事实（比如你养了一只猫、你喜欢某支乐队），存进每个角色独立的记忆库。每个角色的伴侣记忆库上限是 500 条事实，足够支撑几十轮甚至更长的剧情推进而不丢细节。

除了聊天站，Hi Waifu 还有一个面向中文用户的创作工作室，主打跟 AI Agent 对话完成角色卡生成、剧情短片写作、PPT 制作等内容创作场景——相当于把聊天站里的角色设计能力延伸成了独立的创作工具。

## 🔧 安装步骤

Hi Waifu 目前主要在移动端提供服务，Android 和 iOS 用户都可以直接通过应用商店安装。

2. 找到官方开发者发布的版本，点击安装
3. 安装完成后首次打开，授权网络访问等基本权限

## 📖 使用入门

### 第一次打开应用

首次进入 Hi Waifu 会看到角色推荐列表——社区热门角色和新上线的角色都会在这里展示。挑一个顺眼的，点进去就能开始聊天。你也可以用搜索功能按关键词（比如「傲娇」「科幻」「猫娘」）筛选角色。

> [!NOTE]
> 刚注册的新用户会获得一笔初始能量，可以用来发消息。能量用完后有几种补充方式：每日签到、看广告、输入创作者兑换码，或者订阅 Premium。

### 自己创建角色

如果你想做一个完全属于自己的角色，进入「创建角色」页面。最核心的设置就是 Memory 字段——你在这里给 AI 写角色说明书。

Memory 字段有一个 2048 字符的上限（大约 600-700 个汉字），但你可以创建**多个** Memory 条目来覆盖不同维度。推荐的拆分方式是：

| 条目 | 内容方向 | 示例 |
| --- | --- | --- |
| 基本性格 | 角色的核心性格特质 | 冷傲、沉默、对陌生人保持距离 |
| 外貌特征 | 视觉形象描述 | 银白色短发、冰蓝色眼睛、黑色女仆装 |
| 说话方式 | 用词、语气、句式习惯 | 说话简短直接，不用敬语，从不使用语气词 |
| 背景经历 | 角色的故事线 | 曾经是冰魔法家族成员，被派来侍奉主人 |
| 喜好与禁忌 | 角色的偏好和底线 | 讨厌被触碰肩膀，喜欢在窗边看雪 |

这样拆分后每个条目都在 2048 字符以内，AI 处理起来也更清晰。记住一个原则：Memory 的质量直接决定了 AI 回复的人设符合度——写得敷衍，人设就崩得快。

### 跟伴侣记忆库区分开

创建角色时填的 Memory 和聊天过程中 AI 自动记录的伴侣记忆库是两回事：

- **Memory 字段**：你手动写的角色人设，创建时填，随时可以编辑
- **伴侣记忆库**：AI 在对话中自动抽取的关于**你**的事实（你叫什么、你养了什么宠物、你喜欢什么），用户不能直接改

简单说，Memory 是你给 AI 的初始人设，伴侣记忆库是 AI 从聊天里记住的关于你的事。

### 能量系统

Hi Waifu 发消息消耗能量，能量耗尽需要补充。几种常见的能量获取方式：

1. **每日签到**：稳定但量少，坚持每天领是最省心的方式
2. **看广告**：每条广告奖励固定能量，适合急需补充的时候
3. **创作者兑换码**：热门角色的作者或官方会在节日、活动时放出兑换码，输入后直接获得额外能量——去创作者的社交账号、官方 Twitter/Discord、Reddit 相关板块找，或者搜第三方攻略文章
4. **Premium 订阅**：解锁无限消息 + 好记忆模式 + 无限多角色

> [!WARNING]
> 兑换码大多有有效期和使用次数限制，输入时提示无效说明已经过期或被用完了。兑换码本质是额外福利，不要把它当成主要能量来源。

### Premium 值得买吗

Premium 订阅的核心价值集中在两点：**好记忆模式**和**无限多角色并行**。

好记忆是伴侣记忆库的增强版——免费版的伴侣记忆库偶尔会记错或触发不出来，好记忆让角色引用之前对话的概率更高、关联更准确，几十轮对话后早期记住的事实依然能正确引用。

无限多角色的意义在于**每个角色的伴侣记忆库完全独立**。你跟 Alice 聊过「我家猫叫橘子」，这个事实只存进 Alice 的记忆库，Rikka 不会知道。这意味着你可以同时跟多个角色分别玩各自的剧情，互不干扰。免费版虽然理论上也能多角色，但能量是共享的，很快就用完，基本不现实。

| 对比项 | 免费版 | Premium |
| --- | --- | --- |
| 消息能量 | 有限，需补充 | 无限 |
| 伴侣记忆库 | 每个角色 500 条事实 | 好记忆模式，更稳定准确 |
| 多角色并行 | 能量共享，基本不可行 | 无限角色，独立记忆库 |

如果只是偶尔跟一两个角色聊，免费版够用；想深入玩多角色、长剧情，Premium 的好记忆体验差距很明显。

### AI 创作工作室

如果你想尝试角色卡创作、剧情短片写作这类内容生产，可以关注 Hi Waifu 的中文创作工作室——这是中文站独有的功能，跟英文聊天站定位不同。创作工作室的界面是对话式的：你跟 AI Agent 用自然语言聊，逐步把角色卡、剧情大纲、PPT 页面这些内容生成出来。比如做角色卡，你先描述「我想做一个什么样的角色」，Agent 追问细节，几轮对话后角色名、人设、背景故事、外观描述就都出来了。
