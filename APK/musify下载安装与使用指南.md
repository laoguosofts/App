## ✨ Musify 是什么

Musify 是一款面向安卓设备的开源、无广告、免费音乐播放器。它不依赖任何单一流媒体平台，而是通过聚合多种外部来源为用户提供搜索、播放和下载能力。整个应用没有插屏广告、没有启动弹窗、也没有强制付费升级——所有功能从第一天起就是完整可用的。

适合谁用呢？如果你对主流音乐平台的广告疲劳了，或者因为地区限制想听的歌在某些平台上没有，又或者单纯想试试一款由社区驱动、代码完全透明的播放器，Musify 值得装一下。它的界面走的是 Material Design 风格，操作直观，学习成本很低。

## 🔧 安装步骤

Musify 是一款安卓应用，最低系统要求是 Android 7.0（Nougat，API 24）。安装流程与大多数第三方 APK 一致，但有几个细节值得注意。

### 未知来源授权

如果你的系统没有开启"允许未知来源安装"，安装时会被拦截。操作路径因品牌 ROM 而异：

1. 安装界面弹出拦截提示时，通常有一个"去设置"或"允许本次安装"的入口，点进去
2. 在系统设置里找到 Musify 对应的安装权限开关，打开它
3. 返回安装界面重新点击安装

> [!TIP]
> 国产 ROM（小米、华为、OPPO、vivo）的权限管理位置比较深，如果拦截界面没有直接跳转按钮，可以手动进 **设置 → 安全 → 安装未知应用** 查找。

### 渠道选择：GitHub 版还是 F-Droid 版

Musify 同时在 GitHub 和 F-Droid 上发布 APK。两个版本功能基本一致，但**包名不同**——这意味着你手机上不能同时装两个版本，也不能从一个渠道升级到另一个渠道。建议选一个渠道一直用下去。

| 对比项 | GitHub 版 | F-Droid 版 |
| --- | --- | --- |
| 更新频率 | 较快，新版本先在这里发布 | 有审核延迟，略慢 |
| 自动更新 | 需手动检查或在应用内开启 | 跟随 F-Droid 客户端自动更新 |
| 代码审查 | 社区自行审阅 | 经 F-Droid 官方审查 |

### 安装后的验证

装完打开应用，首次启动会有一些基础设置引导（语言、主题、音质偏好）。走完引导流程后，随便搜一首歌试试能不能正常播放——能播就说明安装没问题。如果点开就闪退或黑屏，直接跳到"使用入门"章节的故障排查部分。

## 📖 使用入门

Musify 的核心玩法可以浓缩成几个高频场景：搜索播放、歌单管理、跨平台迁移、后台收听。下面按从易到难的顺序逐一说明。

### 搜索与播放

这是最基础也最常用的功能。应用首页顶部有搜索框，输入歌曲名、歌手名或专辑名就能得到结果列表。点一首直接播，播放在线流媒体源，不需要登录任何音乐账号。

播放过程中可以：

- 锁屏继续播放，锁屏界面显示歌曲信息和基本控制按钮
- 切到其他应用后台继续播，通知栏常驻小播放器
- 调节音质档位（设置里可选，高音质消耗更多流量）

> [!NOTE]
> 后台播放依赖安卓系统的前台服务权限。某些国产 ROM 默认会在灭屏后杀死后台进程，如果遇到灭屏就停的情况，去 **电池优化 / 自启动管理** 里把 Musify 加到白名单即可。

### 歌单与收藏

找到喜欢的歌，点右下角心形图标即可加入收藏。收藏的单曲、专辑、艺术家都在"我的"页面里集中管理。

自建歌单的方式是：在播放列表里长按某首歌 → 选择"添加到歌单" → 新建或加入已有歌单。歌单可以重命名、可以删除、也可以分享链接给别人。

### 从 Spotify 一键搬歌单

这是 Musify 非常实用的一个迁移功能。如果你之前用 Spotify 攒了好几年歌单，不想在 Musify 里一首一首重建，可以直接导入：

1. 在 Spotify 里打开想搬的歌单，点分享，复制歌单链接
2. 回到 Musify → 音乐库 → 找"导入歌单"入口
3. 粘贴刚才的链接，Musify 自动解析并拉取曲目列表
4. 导入完成，歌单里能看到同名的新歌单

整个过程不需要登录 Spotify 账号，也不需要导出任何文件，Musify 通过公开链接直接解析。不过有一点要提前知道：**导入后不保证所有曲目都能匹配上播放源**。Spotify 上的曲目在 Musify 的来源平台上可能因版权或下架原因找不到，匹配不上的条目会保留在歌单里但点播放时会提示找不到。冷门曲目和地区限制曲目比较容易出现这个情况。

### 数据导出与迁移

Musify 没有账号体系，也没有云端同步。所有歌单、收藏、偏好设置都只存在本机。这意味着换手机或卸载重装之前，**必须手动导出数据文件**，否则歌单和收藏会全部丢失。

导出操作在设置的"数据"或"备份"分组里，点"导出数据"即可。导出的文件包含歌单元数据、收藏列表、偏好设置和收听回顾，但**不包含已下载的离线歌曲**——下载文件体积大，导出操作保持轻量。所以换机时完整迁移分两步：

1. 旧手机导出数据文件 → 传到新手机
2. 新手机导入数据恢复歌单 → 逐首重新下载离线歌曲

导出文件不要改扩展名、不要手动解压、不要用文本编辑器打开——它是 Musify 自己读的私有格式，改了就导不回去。建议把导出文件存到 Download 目录或云端做双备份，千万不要只存在应用私有目录里，卸载应用时私有目录会被清空。

### 离线下载

喜欢的歌可以下载成本地离线文件，这样没有网络时也能听。下载方式是在播放列表里长按某首歌 → 选择"下载"，或者长按歌单 → "下载整张"。下载完成后，在"我的"页面的下载队列里可以看到进度和已下载的曲目。

> [!WARNING]
> 下载的离线歌曲文件不会被数据导出文件包含。换机时不要忘了单独处理这些文件——可以直接拷贝存储目录里的音频文件，也可以在恢复歌单后重新下载。

### 闪退排查

如果遇到点开就闪退的情况，按以下顺序排查，从最简单的开始：

1. **重启手机**——很多闪退是系统内存紧张或进程卡死导致的，重启能释放内存、终止僵尸进程，不少闪退重启后就好了
2. **确认系统版本**——Musify 要求 Android 7.0 及以上，低于这个版本跑不动
3. **清除应用缓存**——系统设置 → 应用管理 → Musify → 清除缓存，这个操作不会清空歌单、收藏和离线歌曲，可以放心试
4. **清除应用数据**——如果清缓存没用，就清数据，这会清空全部离线歌曲、歌单和偏好设置，但能解决大部分缓存损坏问题。**操作前必须先导出数据保住歌单**
5. **卸载重装**——先导出数据，卸载，重启手机，从原来的渠道（GitHub 或 F-Droid）重新下载最新版 APK 安装。**注意不要混渠道装**，两个渠道包名不同，混装会触发包名冲突
6. **换设备验证**——以上全试过还是闪退的话，可能是当前设备的 ROM 不兼容。找另一台原生安卓设备装 Musify 试试，如果能正常打开，说明问题在 ROM，不是 Musify 本身
