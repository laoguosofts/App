## ✨ Quickstep 是什么

Quickstep 是 Android 系统内置的桌面启动器核心组件，基于开源项目 AOSP Launcher3 扩展开发。它不是一个可以从应用商店下载的独立 APP，而是预装在系统分区中的系统级程序——你每一次触摸主屏幕、打开应用、切换任务，背后都有 Quickstep 在工作。

从 Android 9 Pie 开始，Quickstep 成为 Android 手势导航的执行引擎，负责接管上滑回主页、上滑停留打开最近任务、边缘滑动返回等全套手势操作。Google Pixel、一加、OPPO 等主流厂商的机型都直接采用 Quickstep 方案，部分定制 ROM 虽然在 Launcher3 上做了更深改造，但底层逻辑依然参考 Quickstep 的设计。

Quickstep 包名为 `com.android.launcher3`，属于开源 Android 项目的一部分。相比于普通第三方 Launcher，它的优势在于和 SystemUI 的深度集成——手势动画、最近任务视图、分屏模式的快捷入口，这些功能在系统层面就打通了，不需要额外适配。

虽然你可能从不会主动打开 Quickstep，但它覆盖了你每天使用手机的所有高频场景：主屏幕图标排列与小部件、应用抽屉的展开、最近任务的多任务视图、底部滑动与边缘返回的手势导航、主屏幕的快速搜索。对大多数用户来说，Quickstep 就是"手机桌面"本身。

## 🔧 Quickstep 安装与版本说明

Quickstep 是系统预装组件，正常情况下不需要单独安装。但如果你遇到手势失效、Launcher 崩溃等问题，可以通过以下方式恢复或更新。

### 确认你的设备是否自带 Quickstep

并非所有 Android 设备都使用 Quickstep。部分国产 ROM 在 Launcher3 上做了更深的定制，底层逻辑虽然类似但操作路径不同。

> [!TIP]
> 在手机设置里搜索"手势导航"或"系统导航"，如果能找到"手势导航"选项，基本可以确认你的设备基于 Quickstep 或其定制版本。

### Quickstep 版本与 Android 系统版本的对应关系

| Quickstep 功能 | 最低 Android 版本 |
| --- | --- |
| 基础手势导航（上滑回主页、边缘返回） | Android 9 |
| 最近任务视觉效果 | Android 10 |
| 手势导航与 SystemUI 深度集成 | Android 11 |
| 分屏模式快捷入口 | Android 12 |
| 底部左右快速切换应用 | Android 13 |

> [!WARNING]
> 旧版本 Android（Android 8.1 及更早）使用传统三键导航，不包含 Quickstep 手势系统。如果你的设备仍在 Android 8 以下，建议先升级系统。

### 遇到问题时的修复方式

如果 Quickstep 出现进程异常或手势失灵，可以按以下优先级尝试修复：

1. **重启手机**——最简单也最有效，能解决绝大多数进程死锁问题
2. **清除 Quickstep 缓存**——设置 → 应用 → Quickstep（或"系统桌面"）→ 存储 → 清除缓存
3. **重置桌面布局**——同上路径选择"清除数据"（注意会清除桌面图标布局）
4. **切换导航方式再切回**——先选三键导航，重启后再切回手势导航

## 📖 Quickstep 使用入门

Quickstep 的核心价值在于手势导航系统。相比传统三键导航，手势能释放更多屏幕空间，也能让操作流程更流畅。下面从开启设置、基础手势、进阶技巧三个层面说明。

### 开启手势导航的设置路径

不同品牌 ROM 的设置入口差异很大，以下是主流机型的快速对照：

| 品牌 / ROM | 开启路径 |
| --- | --- |
| 原生 Android / Google Pixel | 设置 → 系统 → 手势 → 系统导航 → 手势导航 |
| 小米 / HyperOS | 设置 → 桌面 → 系统导航方式 → 全面屏手势 |
| OPPO / ColorOS | 设置 → 便捷工具 → 导航方式 → 两侧滑动手势 |
| 一加 / OxygenOS | 设置 → 系统 → 系统导航方式 → 屏幕导航 |
| 三星 / One UI | 设置 → 显示 → 导航栏 → 全屏手势 |
| 华为 / HarmonyOS | 设置 → 系统与更新 → 系统导航 → 手势导航 |

切换到手势导航后，底部导航栏会消失，屏幕多出一截可用空间。底部会出现一条细细的白色横线作为手势提示，部分机型可以在设置里隐藏。

### 四种基础手势

Quickstep 的手势导航核心只有四个动作，覆盖了日常 90% 以上的手机操作：

- **快速上滑**：从屏幕底部快速向上滑一下，立即返回主屏幕。这是最高频的手势，练几分钟就能熟练
- **慢速上滑 + 停留**：从底部慢慢向上滑，感受到震动反馈时停留，打开最近任务视图（多任务卡片）
- **边缘向内滑**：从屏幕左边缘或右边缘向内滑动，返回上一级页面。左手持机的用户可能一开始用右边缘别扭，多试几次就适应了
- **底部左右滑动**：在屏幕最底部的手势提示线区域向左或向右水平滑，直接在**最近两个应用之间来回切换**——这是 Quickstep 独有的高效操作，比打开最近任务更快

### 底部左右切换的实用场景

底部左右快速切换是最容易被忽略但效率提升最大的手势。它**只涉及两个应用**——当前和上一个。如果需要跳到第三个应用，还是得打开最近任务视图。

典型的日常场景：

**聊天 + 查资料**：在微信和朋友聊着，突然想搜点东西。上滑回主页打开浏览器查，底部向右滑一下瞬间回到微信。比每次都要上滑打开最近任务方便太多。

**游戏 + 看攻略**：打游戏时需要对照攻略截屏，切到相册看完再滑一下回到游戏，游戏进程完全不受影响。

**工作文档 + 参考对照**：一边编辑 PPT 一边对照 Word 文档或网页。两个应用间反复切换，底部滑一下比桌面端的 Alt+Tab 还顺手。

### 手势失灵时的排查思路

如果你发现上滑不回主页、边缘返回没反应、抽屉打不开这类问题，可以按以下优先级排查：

**第一步：确认手势导航是否开启**——这是最容易忽略的"伪问题"。你以为手势开着，实际上系统设置里还是三键导航。回到设置路径重新确认一遍。

**第二步：检查第三方 Launcher 冲突**——如果装了 Nova、Microsoft Launcher、Smart Launcher 等第三方桌面，Quickstep 的手势可能被接管。到设置 → 应用 → 默认应用 → 主屏幕，确认是 Quickstep。

**第三步：开发者选项的手势开关**——Android 11+ 部分 Quickstep 版本需要在开发者选项里开启"强制使用全屏导航模式"。连续点击"关于手机 → 版本号"7 次进入开发者模式，搜索这个开关。

**第四步：应用内禁用了系统手势**——全屏游戏、银行/支付 APP、视频播放器可能主动禁用系统手势。去主屏幕测试手势，如果主屏幕也不工作，问题不在应用本身。

**第五步：进程异常或系统 bug**——最直接的处理方式还是重启手机。如果重启没用，可以尝试"回到三键导航 → 重启 → 再切回手势导航"的重置流程。

> [!NOTE]
> 部分 ROM 版本存在已知的手势 bug，比如小米 HyperOS 早期版本、OPPO OxygenOS 11、三星 One UI 4.1 在折叠屏上的边缘返回问题。如果以上排查都无效，检查一下系统更新，OTA 通常会修复这类问题。
