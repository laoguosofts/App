## ✨ Soundraw 是什么

Soundraw 是一个以**版权安全为底座、以专业编辑为差异点**的 AI 音乐生成平台。它瞄准的是内容创作者和独立音乐人两类群体——前者不想花大价钱买专业录音棚软件，也不想踩到版权雷区；后者则希望 AI 生成的节拍能继续精调、导出分轨，用来唱人声然后自主分发。

市面上大多数 AI 音乐工具要么只能"一键生成然后下载"，根本不能编辑；要么训练数据来源不透明，存在灰色版权风险。Soundraw 选择在训练环节就切断这个隐患——它的 AI 模型只学习平台内部制作人原创的音乐素材，对所有训练数据拥有完整的、可追溯的版权。你生成的每一首 beat，其旋律片段、鼓型、贝斯线都不是从知名艺人公开歌曲里"偷"来的，不存在被判定为侵权的灰色地带。这一点在 2024 至 2025 年 AI 音乐行业风波频发的背景下尤为关键，多家同行因版权纠纷被起诉或被迫下架功能，而 Soundraw 从源头上规避了这个问题。

Soundraw 的核心竞争力不是"一键出歌"，而是一个完整的生产链：**生成 + 编辑 + 导出**三件套。2025 年 3 月发布的 V2 版本进一步强化了差异化——新增**风格融合（Genre Blending）**功能，允许用户同时选择两种风格（如 Hip-Hop + Orchestra、Trap + Lo-Fi），AI 自动融合生成独一无二的混合节拍，这在之前的 AI 音乐工具里几乎没有先例。

平台形态上，Soundraw 同时提供 Web 端（soundraw.io）和移动端应用（SOUNDRAW Grid，iOS + macOS）。移动端主打 loop 堆叠工作流和自然语言描述（输入"明亮的钢琴"就能生成匹配的 loop）；Web 端则是完整的生成 + 编辑 + 导出全流程，是大多数用户的主力战场。

## 🔧 安装与账号注册

### Web 端：无需安装，浏览器即用

Soundraw 的 Web 端不需要下载任何客户端——打开浏览器访问 soundraw.io，点击首页的 "Generate Music" 按钮就能直接进入生成界面，甚至**未注册用户也能试用**。注册账号后可以保存项目、提升下载额度，推荐使用邮箱或 Google 账号一键注册。

> [!TIP]
> 首次使用建议先注册账号再生成——匿名用户生成的节拍无法保存，关闭浏览器就丢了。注册免费，Grid Free 计划还能每月获得 8 次免费下载额度。

### 移动端 Grid 安装

移动端 SOUNDRAW Grid 目前支持 iOS 和 macOS 双平台：

1. 打开 App Store（iOS）或 Mac App Store（macOS）
2. 搜索 "SOUNDRAW Grid"，认准官方开发者标识
3. 点击获取 / 安装，等待下载完成
4. 首次打开后，用与 Web 端相同的账号登录，项目库会自动同步

> [!NOTE]
> Android 用户暂时没有原生 Grid 应用。可以用手机浏览器访问 Web 端，体验完整的生成 + 编辑流程——Soundraw 的 Web 端做了移动端适配，操作体验基本够用。

### 关于版本核对

Soundraw 的 Web 端是持续在线更新的，不需要手动升级，每次访问都是最新版本。移动端 Grid 应用会在 App Store 推送更新通知，建议保持自动开启——V2 风格融合等新功能都需要较新版本才支持。

## 📖 从生成到导出：完整使用流程

Soundraw 的核心流程可以浓缩在 60 秒内走完（不含决定风格的犹豫时间），下面按操作顺序拆解。

### 第一步：选择风格并生成

打开 Web 端后，点击首页 "Generate Music" 按钮进入生成界面：

1. **选择风格**：从 30+ 种预设风格里挑选一种。V2 用户可以再勾一种风格做融合（比如 Hip-Hop + Orchestra），两种风格会被 AI 自动混搭生成独特的混合节拍
2. **设置时长和 BPM**：直接用默认值也行，想精准控制就手动调节——通常 60 秒到 180 秒是比较常用的范围
3. **Mood 和 Theme**：这两个参数影响生成的情绪走向（比如"悲伤""欢快""励志"），新手可以先跳过，后期微调时再用
4. **点击 Generate**：AI 开始工作，通常 3-10 秒就能出结果。融合风格（V2）比单一风格慢 1-2 秒，高峰时段（美东下午）可能再多等几秒

> [!WARNING]
> 如果等了超过 15 秒还没出结果，刷新页面重试即可——通常是临时网络问题。Soundraw 的服务器负载偶尔会波动，但重试基本都能成功。

### 第二步：试听与微调

生成结果出来后，先试听。不满意有三种调整路径：

- **Regenerate**：同一参数重新生成一批——这个操作**不消耗下载额度**，可以无限次试，直到出满意的为止
- **改参数再生成**：换风格、调 BPM、改情绪参数，重新跑一遍
- **进入 Mixer 编辑器**：这是 Soundraw 区别于多数同行的杀手锏——支持 Bar 级别的多轨道编辑，可以对每一个 section 的每一条轨道（鼓组、贝斯、旋律、和声等）做音量、静音、循环等微调

### 第三步：下载导出

满意后点击下载按钮，选择格式：

| 计划 | 可选格式 |
| --- | --- |
| Creator | 仅 mp3 |
| Artist Starter | 仅 mp3 |
| Artist Pro / Unlimited | mp3、wav、wav + Stems 分轨 |
| Enterprise | 全部格式 |

> [!TIP]
> **一次下载消耗一首额度**（同一首节拍下载多次算多次消耗）。建议确认好最终格式再点下载——先试听满意、Mixer 里调好，再一次性下对格式。Regenerate 不算消耗额度，所以可以大胆试错。

### 第四步：分享与保存

Soundraw 内置了分享功能——点分享图标，系统会自动生成一个在线试听链接，可以直接发给朋友或嵌入博客。链接访问者能试听但**不能下载**，保护你的创作。

注册用户生成的节拍会自动保存到项目库，随时回来继续编辑。项目库是**跨设备同步**的——Web 端保存的项目在 Grid 移动端也能看到（同一个账号登录即可）。

### 关于下载额度的注意事项

Soundraw 的 Web 端和移动端 Grid 有**独立的额度体系，互不通用**：

| 平台 | 免费额度 | 说明 |
| --- | --- | --- |
| Web Creator | **无限**（仅 mp3） | 生成和下载都不限制 |
| Grid Free | 每月 8 次 | 每次生成/下载消耗一次额度 |
| Artist 三档 | 10~20 首 / 月 | 按月重置，不累积到下月 |

年付用户的额度也是按月重置的，不是一次性给一年总量。额度用完后等下个月自动恢复，或临时升级档位——Soundraw 会按剩余天数计算差价自动升级，新档位额度即时生效。

### 进阶：移动端 Loop 堆叠与自然语言

SOUNDRAW Grid 移动端有两个 Web 端没有的特色玩法：

- **Loop 堆叠工作流**：把不同 loop（鼓型、贝斯线、旋律片段）像积木一样自由组合，快速搭建自己的节拍结构
- **自然语言描述生成**：直接输入"明亮的钢琴"或"低沉的贝斯"这类文字描述，AI 会生成匹配的 loop——适合没有乐理基础但想精准控制音色的用户

### 进阶：MCP Server 接入（开发者）

社区开发者基于 Soundraw B2B API V3 构建了 MCP Server，让 AI Agent（如 Claude）可以调用 Soundraw 自动生成音乐、参数化控制风格、甚至输出游戏集成代码。适合快速原型验证和开发者探索场景。

> [!NOTE]
> 社区 MCP Server 是逆向工程和公开案例推导的产物，Soundraw 没有公开 B2B API V3 的完整文档，也没有在官方层面支持 MCP 集成。API 参数和端点可能随时变化，稳定性没有官方保障。正式生产环境建议直接联系 Soundraw 官方签订 Enterprise 合同。
