## ✨ Layout 是什么

Layout 是 Meta 旗下推出的一款免费拼图应用，专为手机端快速组合多张照片而设计。它的核心定位很明确——**把几张图快速拼成一张，然后直接发**。没有多余的编辑功能，没有账号体系，没有社交属性，打开就能用，拼完就走。

Layout 面向的用户群非常广：喜欢发朋友圈九宫格的内容创作者、想把一天三餐拼在一起记录生活的普通用户、做自媒体需要快速产出配图的博主——只要你有"多张图想合成一张"的需求，Layout 都能覆盖。它支持最少 2 张、最多 9 张照片的自由组合，提供竖分、横分、九宫格、L 形大格等多种版式，还能拖动分隔条微调每一格的比例。

这款应用最大的特点是**极简**。打开没有登录注册、没有欢迎引导、没有侧边栏设置，直接进入选图界面。全部操作集中在选图界面和编辑界面的顶部与底部，学习成本几乎为零。对于只想"快速拼一张图发出去"的场景来说，这种克制反而成了优势——不需要在十几款功能堆砌的拼图应用里犹豫选哪一款。

Layout 本身不提供滤镜、贴纸、文字等装饰功能，也不会修改你的原图。它只负责"排"——把你选好的照片按版式排好、支持微调、输出成图。如果需要滤镜效果，可以在其他应用里先给每张照片处理好，再用 Layout 拼图，滤镜会原样保留。

## 🔧 Layout 安装步骤

Layout 是一款跨平台应用，Android 和 iOS 都有官方版本。iOS 用户直接去 App Store 搜索安装即可，Android 用户有两种获取方式。

### Android 安装

**方式一：Google Play（推荐）**

1. 打开 Google Play Store
2. 搜索「Layout from Instagram」——注意完整版名，避免同名山寨应用
3. 找到开发者为 Instagram 的那一个，点击安装
4. 等待下载完成自动安装

**方式二：APK 安装**

如果 Google Play 不可用，可以通过下载页获取 APK 文件手动安装。安装前需要做一步准备：

1. 进入手机 **设置 → 安全 / 隐私**
2. 找到「未知来源」或「安装未知应用」选项
3. 为浏览器或文件管理器开启允许安装未知来源应用的权限
4. 下载 APK 到本地，点击文件按提示安装

> [!WARNING]
> 务必核对下载的 APK 文件大小和版本号，避免下载到被篡改的第三方修改包。安装完成后建议关闭未知来源权限，保持手机安全。

### 首次启动权限

安装完成后打开 Layout，首启会依次弹出两个权限请求：

| 权限 | 是否必须 | 说明 |
| --- | --- | --- |
| 照片 / 存储 | **必须允许** | 需要读取相册照片作为拼图素材，也需要写入权限保存成图回相册 |
| 相机 | 按需允许 | 允许后才能使用 Photo Booth 连拍功能；只用相册照片拼图可以不给 |

两项权限处理完，直接进入拼图界面，没有任何引导流程。

### 核对是否安装成功

- 应用图标为白底黑色拼图图案
- 打开后直接进入相册照片网格界面
- 没有登录注册页面
- 底部能看到 Gallery / Faces / Recents 三个 Tab

## 📖 Layout 使用入门

Layout 的完整流程可以归纳为「选图 → 排版 → 微调 → 保存」四步。下面基于常见的使用场景逐步展开。

### 选图：Gallery 相册 Tab

打开 Layout 后默认停留在 Gallery Tab，它会扫描手机系统相册的全部图片，按拍摄时间倒序排列——最新拍的在最上面。轻点照片即可选中，再次轻点取消。

> [!TIP]
> 选图时按你希望出现在成图里的顺序依次点击。Layout 会按选入顺序自动填入版式的格子，不需要后面再手动调整位置。如果顺序错了，可以用长按换位来修正。

Gallery 有几个值得注意的点：

- 最少选 2 张、最多选 9 张
- 已选中的照片在滚动翻页时不会被清除
- 选满 9 张自动进入编辑界面
- Gallery 直接读取系统 MediaStore 数据库，所以相机拍的、截屏的、微信保存的图片都能看到
- 云端相册的在线图片看不到，需要先下载到本地

Gallery 不支持按相册分组、按类型筛选或搜索照片，这是 Layout 在选图阶段刻意保持极简的设计。如果需要精细筛选，建议在系统相册里提前整理好，再回 Layout 选图。

### 长按换位：调整照片顺序的最快方式

如果选完图发现某张照片的位置不对——比如你想把"主照"放在左上（通常是视觉重点位置），而它被排在了右下——Layout 提供了一个非常快捷的手势来交换位置。

操作很简单：

1. 在编辑界面**长按**任意一个照片格子（约 0.5 秒）
2. 被长按的格子会进入浮动状态（轻微放大 / 高亮）
3. 再**轻点**另一个格子
4. 两张照片的位置立即交换

整个过程不需要菜单、不需要拖拽、不需要确认——长按 + 轻点就完成了。交换后蓝色分隔条会自动适配新版式，不需要手动重新拉。可以连续换位，比如 A→B→C→A 这样循环。

> [!NOTE]
> 长按换位**只能交换两个格子**。想把一张照片移到三个格子之外的位置，需要逐步交换（先和 B 换，再和 C 换）。Layout 不支持"拖动照片跨越多个格子"。

### 场景一：美食日记——一天三餐拼成一张

这是 Layout 最经典的用法。一天里拍了早餐、午餐、晚餐三张照片，想拼在一起发朋友圈记录"今天吃了什么"。

**推荐操作流程**：

1. Gallery 里依次选中早餐 → 午餐 → 晚餐的照片（按时间顺序）
2. 选竖分 3 格或横分 3 格版式——Layout 会按选入顺序自动填入
3. 如果顺序不对，用长按换位交换
4. 拖动分隔条微调比例——某一顿特别好看可以拉大那格
5. 保存 → 发朋友圈

**两种排版风格**：

| 风格 | 版式选择 | 适合场景 |
| --- | --- | --- |
| 时间轴竖分 | 3 格竖分 | 朋友圈、微博（竖直阅读习惯） |
| 时间轴横分 | 3 格横分 | 微信公众号文章配图等横向分享 |

照片本身的构图对拼图效果影响很大。建议拍照时统一拍摄角度（都从正上方 45° 俯视，或都从侧面）、保持照片尺寸相近、光线条件接近——这样拼起来更协调，Layout 自动裁剪的效果也更好。

### 场景二：九宫格密集排布

如果一天不止三餐（加餐、下午茶、夜宵也算），选 6 或 9 张拼成密集排布，信息密度更大。Layout 的 L 形大格配合分隔条拖动，可以让"周六大餐"那格更突出。

也可以扩展到一周：把周一到周日的美食各挑一张，7 张用不规则排布拼成一张图，作为周末回顾的封面。

### 加边框 vs 无边框

Layout 提供了边框开关，两种风格各有适用场景：

| 风格 | 边框 | 效果 |
| --- | --- | --- |
| 温馨日记感 | 有边框 | 每顿像一张独立的小卡片，温馨 |
| 简约干净 | 无边框 | 多张无缝拼在一起，画面紧凑 |

### 保存与输出

编辑完成后点击保存，Layout 会把成图写入系统相册。默认输出为正方形或版式对应的宽高比，画质保留原图分辨率。保存后可以直接从相册分享到微信、朋友圈、Instagram 等任何社交应用。
