## ✨ FreeMind 是什么：一款老牌开源思维导图工具

FreeMind 是一款轻量级的开源思维导图软件，最早诞生于 2003 年，至今仍保持着稳定的更新节奏。它的核心定位非常清晰：**结构化思维的纸笔替代品**——用一张节点树承载大纲、笔记、计划、知识卡片，不靠花哨功能取胜，而是把「快速搭建层级、灵活调整结构」这件事做到极致。

作为一款 Java 跨平台软件，FreeMind 可以在 Windows、macOS、Linux 上直接运行，解压即用的分发方式也让它在便携场景里特别受欢迎。它的原生格式 `.mm` 是导图圈公认的开放交换格式，MindManager、Freeplane 等主流工具都能直接读取或导出，迁移成本几乎为零。

适合谁用？大致有三类：喜欢极简界面、不想被「全家桶」式功能打扰的人；需要在 U 盘里随身带一份个人知识库的人；已经习惯了键盘快捷键、追求纯命令式操作效率的人。反过来，如果你想要云同步、多人协作、内置甘特图或精致的卡片 UI，FreeMind 可能不是最佳选择——它的设计哲学就是「把自己做好，其他的交给生态」。

## 🔧 安装与启动：解压即用的跨平台方案

FreeMind 没有传统意义上的「安装向导」，它的安装过程本质上就是下载压缩包 → 解压到任意目录 → 双击启动脚本。不过这里面有几个容易踩坑的地方，建议在动手之前先过一遍。

### 前置条件：Java 运行环境

FreeMind 是纯 Java 程序，启动时会检测本地是否有 Java Runtime Environment（JRE）。**如果你的电脑上还没装 Java，需要先去官网下载并安装 JRE 8 或更高版本**——建议选 LTS 版本（目前推荐 JRE 17），兼容性最好。

> [!WARNING] 常见误区
> 不要只装了 JDK 而不配置环境变量——FreeMind 的启动脚本默认查找系统的 `java` 命令，如果找不到，即使你装了 JDK 也会启动失败。安装完成后打开终端跑一句 `java -version` 确认有输出即可。

### Windows 平台安装步骤

1. 下载 Windows 版压缩包（通常是 `.zip` 格式），文件大小约 50~80MB。
2. 解压到一个没有中文路径和空格的目录，比如 `D:\Apps\FreeMind`——路径干净能避免启动脚本里路径解析出问题。
3. 进入解压目录，双击 `FreeMind.bat` 启动；如果想让它成为默认双击 `.mm` 文件的程序，右键 `.mm` 文件 → 打开方式 → 选择 `FreeMind.bat` 即可。
4. 首次启动可能会弹出杀毒软件误报提示（因为是 Java 自启动脚本），选择「允许运行」即可。

### macOS / Linux 平台安装步骤

两个平台基本都是：下载对应架构的压缩包（macOS 注意区分 Intel 与 Apple Silicon），解压到 `/Applications` 或 `~/Applications`，第一次运行前在终端里给启动脚本加执行权限（`chmod +x FreeMind.sh`），然后双击 `.sh` 文件或在终端执行脚本启动。macOS 上如果弹出 Gatekeeper 拦截提示，去「系统设置 → 隐私与安全性」里点「仍要打开」即可。

> [!NOTE] 便携版方案
> 如果你想把 FreeMind 装在 U 盘里随身走，有一个官方支持的做法：在启动脚本的 Java 命令中加入 `-Duser.home=.` 参数。这会把用户配置目录锁定在 U 盘当前目录，所有个人设置、最近打开的文件记录都会跟着 U 盘走，不污染宿主电脑。脚本本身是纯文本的，用记事本就能改。

### 解压后的目录长什么样

解压完成后，目录里一定会有一个 `lib` 文件夹（里面是主程序 jar 和依赖包），一个启动脚本（`.bat` 或 `.sh`），以及几个配置文件。这些东西一个都别删——删了启动就报类找不到。导图文件（`.mm`）可以放在任何位置，程序打开时不会往目录里写东西。

## 📖 使用入门：从第一张图到效率流

FreeMind 的界面极简到有点「寒酸」——没有侧边栏、没有状态栏、只有菜单栏、工具栏和中间一张空白画布。但只要你花半小时摸一遍快捷键和核心交互，就会发现这玩意儿设计得极其顺手。

### 从零开始：第一张导图怎么画

启动后你会看到一个孤立的根节点「中心主题」，双击它或按 `F2` 就能输入内容。接下来就是 FreeMind 的灵魂操作：**按 Insert 键添加子节点，按 Enter 键添加同级节点**。两条键配合方向键和 Tab/Shift+Tab，几乎能完成所有结构搭建工作。

```
Ctrl+N    → 新建导图
Insert    → 在当前节点下添加子节点
Enter     → 在当前节点后添加同级节点
F2        → 编辑当前节点文字
Delete    → 删除当前节点
Ctrl+S    → 保存（建议养成高频保存的习惯）
```

画着画着你会发现：拖拽节点可以直接改变层级（往别的节点上拖就变成子节点），按空格可以快速折叠/展开一个分支，这些操作连鼠标都不需要挪太远。

### 让颜色成为信息通道

FreeMind 的颜色快捷键设计得非常顺手，**三个按键管整个节点的视觉表达**：

- **Alt+C**：给当前节点（或选中的多个节点）上色，弹出调色板选颜色。
- **Alt+B**：混合色——把当前颜色和背景色调和出一个柔和的中间色，适合做层级渐深的效果。
- **Alt+E**：给连线（边）单独上色，线的颜色独立于节点颜色。

> [!TIP] 实用的颜色约定
> 颜色一随机用就成了装饰，真正高效的做法是给颜色分配语义：红色 = 未开始/紧急、橙色 = 进行中、绿色 = 已完成、灰色 = 搁置或废弃。写作场景也可以照搬这个思路：红 = 未动笔、橙 = 写作中、绿 = 成稿。约定一旦建立，一张上百节点的大图扫一眼就能知道全局状态。

进阶的颜色技巧是**层级感配色**：靠根越近颜色越深，越远越浅（用 Alt+B 往浅里调），视觉上自然形成层级。或者只给第二层主分支上色，第三层以后全部继承连线色——图面干净且分支归属一目了然。

### 物理样式：一键套用整套格式

一个一个调颜色、字号、形态太费时间，FreeMind 提供了**物理样式（Physical Style）**机制——把节点颜色、字体、背景色、形态这些外观属性打包成一个预设，**F1 到 F9 直接对应九个常用预设**，按一下数字键，整套格式秒达。更多预设可以绑定到 `Ctrl+F1` 至 `Ctrl+F9` 等组合键。

样式定义文件（官方文档提到是名为 `patterns` 的 XML 文件）存放在程序目录里，动手能力强的用户可以直接编辑这个文件，做出自己的样式库。

### 从其他软件迁移：三条路线任选其一

如果你手上已经有一堆 MindManager、XMind 或 OmniOutliner 文件想搬过来，FreeMind 给了三条路：

**官方直接导入**：功能列表里有「从 MindManager X5 导入」的条目，MindManager 的文件可以直接吃进来。后续版本的格式兼容性以实际尝试为准，不行就先用老版本中转或走通用路线。

**通用文本搬运**：FreeMind 有「智能剪贴」机制——任何带缩进的大纲文本直接粘贴，行首空格会自动变层级。其他导图软件基本都能导出带缩进的纯文本或 OPML 格式，先落文本再粘贴过来，这条路最稳。

**迁出 .mm 红利**：反过来想把 FreeMind 的导图搬到别的软件也很轻松。`.mm` 格式本身是导图圈的通行交换格式，MindManager、Freeplane、XMind 等主流工具都能直接打开。不想写脚本的话，先导出成纯文本或 HTML，绝大多数目标工具都能吃这两种产物。

| 路线 | 适合场景 | 注意事项 |
|---|---|---|
| 官方导入 MindManager | 有较老版本的 MindManager 文件 | 新版本格式兼容性需实测 |
| 缩进文本粘贴 | 任何带层级的大纲 | 缩进层级决定节点层级，先清理好格式 |
| .mm 直拷 | 同生态导图软件互转 | Freeplane 零成本，格式完全同源 |

### 迁移前的三个检查点

1. 大图先导出一份 HTML 或 PNG 当对照件——迁移后可以逐块核对是否丢失内容。
2. 加密节点在迁移中会失效或需要重新加密，敏感分支先单独解密处理。
3. 挂了大量本地链接的图，迁移后抽查几条链接路径是否仍然有效——换了环境路径可能断。
