## ✨ PixVerse 是什么

PixVerse 是一款从零构建视频基础模型的生成式 AI 视频平台，核心目标是让创作者跳过拍摄、时间线剪辑、渲染等传统视频制作中最耗时的环节，直接用一句话提示词或一张现有图片，在几秒到几分钟内生成可以发布的 AI 视频。

与很多套壳第三方模型的同类工具不同，PixVerse 持续迭代自研视频基础模型（V4.5 → V5 → V5.5 → V5.6 → V6），在多模态统一生成、实时交互式世界引擎、角色一致性保持等方面形成了鲜明的差异化定位。它不仅面向个人创作者，也提供企业级 API、CLI、Team Plan 团队协作能力，覆盖从创意原型到生产落地的完整链路。

PixVerse 的用户画像相当广泛：短视频创作者可以用它快速验证脚本概念、生成动态素材；营销团队可以批量制作产品预告视频、社交广告素材；代理商和工作室用来探索风格方向、产出提案视觉概念；开发者则通过 API 和 CLI 将视频生成能力接入自己的业务系统。

**输出规格方面**，V6 模型典型支持 720P / 1080P 分辨率、5~15 秒单段时长、16:9 / 9:16 / 1:1 三种画幅比例，输出格式为 MP4。

> [!NOTE]
> PixVerse 维护经 DNV 认证的 ISO/IEC 27001 信息安全管理体系，对个人和企业用户的数据安全有明确承诺。内容使用许可则取决于订阅方案，商业发布前应确认自己的方案是否覆盖。

## 🔧 安装与接入方式

PixVerse 的形态决定了它没有传统意义上的"安装包"——它是一个 AI 视频生成平台，主要通过三种方式接入：Web 网页端、命令行工具（CLI）、RESTful API。下面分别说明。

### Web 网页端（最常用）

网页端是大部分用户的首选方式，打开浏览器直接访问 PixVerse 官网即可开始创作，无需安装任何软件。首次使用需要注册账号，邮箱注册或第三方登录都支持。注册完成后会获得一定的免费 Credits，用于消耗生成视频。

> [!TIP]
> 建议首次使用时先在官网完整走一遍注册流程，并在个人中心查看自己的 Credits 余额和订阅状态，避免创作到一半才发现额度不足。

### CLI 命令行工具

面向开发者的场景，PixVerse 提供了 npm 包形式的 CLI 工具。安装命令：

```bash
npm install -g pixverse
```

安装完成后，在终端中可以直接调用 `pixverse` 命令生成视频、图片、音乐等多模态内容。CLI 方式特别适合批量生成或集成到自动化流水线中。

### RESTful API

API 平台提供完整的 RESTful 接口，支持批量生成、状态查询、视频下载等能力。开发者可以用任意语言的 HTTP 客户端接入，PixVerse 也提供了与 Claude Code、Cursor、Codex 等 AI 编码助手的 Skills 集成，让生成能力直接出现在 IDE 里。

### 安装注意事项

| 接入方式 | 适用人群 | 前置条件 |
| --- | --- | --- |
| Web 网页端 | 所有人，尤其是新手 | 浏览器 + 网络 |
| CLI 工具 | 开发者、自动化场景 | Node.js + npm |
| RESTful API | 企业级集成、批量生产 | 编程能力 + API Key |

> [!WARNING]
> 所有接入方式都需要联网使用，PixVerse 是云端推理服务，本地不进行 AI 计算，对网络质量有一定要求——建议在稳定的宽带环境下使用，避免生成中途断网导致 Credits 消耗了但视频没拿到。

## 📖 PixVerse 使用入门

PixVerse 的创作核心是提示词（Prompt）。AI 模型靠提示词理解你想要什么画面，提示词的质量直接决定生成结果的质量——写得准不准、具体不具体，比文字长短重要得多。

### 核心能力速览

在开始写提示词之前，先梳理一下 PixVerse 的核心能力矩阵，知道你手里有哪些工具：

**基础生成**——文生视频（Text-to-Video）输入文字从零生成动态视频；图生视频（Image-to-Video）上传一张静态图片让它动起来，适合已有视觉素材的场景。

**叙事增强**——多镜头生成（MultiShot）一次生成广角、中景、特写等多个连续镜头并自带转场逻辑；AI 模板提供预设的高质量提示词和叙事脚本，一键生成爆款风格视频；Agent 对话式创作则用自然语言对话让 AI 帮你拆解创意、写提示词、调整方向，不需要自己写复杂 prompt。

**精控能力**——主体参考上传参考图以在多个镜头中保持视频主体的外观一致性；多帧控制上传起始画面和结束画面以精确控制视频的轨迹和过渡；视频编辑功能可以对已生成的视频修改风格、主体、元素、背景和光照。

### 提示词公式：写得准才能生成好

PixVerse 官方推荐的提示词公式是：

> **主体 + 场景 + 动作 + 运镜 + 灯光 + 声音 + 格式**

这不是一个死板的模板——你可以根据需要省略或调整某些维度。但理解每个维度的作用，会让你的提示词更清晰、更稳定。

**主体（Subject）**是画面中的核心角色或物体，明确的主体能让模型把注意力集中在关键元素上。好的主体描述是"穿白色运动服的年轻女性"，而不是"一个女孩"。

**场景（Setting）**告诉模型主体处于什么环境里——室内还是室外、什么时间、什么氛围。好的场景描述是"清晨的林荫道，金色阳光透过树叶洒下"，而不是"户外街道"。

**动作（Action）**是视频的灵魂——让画面"活"起来。动作描述要具体：走、跑、转身、漂浮、拍打、打开。好的动作描述是"用前爪轻轻拍打木制风车，叶片缓慢旋转"，而不是"在玩风车"。

**运镜（Camera Direction）**决定观众用什么视角看画面。常用运镜指令包括推进（push in）、拉远（pull back）、平移（pan）、跟拍（tracking shot）、环绕（orbit）、特写（close-up）、航拍（aerial shot）、手持（handheld）。好的运镜描述是"镜头从侧面跟拍，缓慢推近"，而不是"镜头动一动"。

**灯光（Lighting）**塑造画面的情绪基调。PixVerse 能响应具体的光照描述：晨光 / 黄昏光 / 月光 / 霓虹 / 棚拍光、自然光 / 人造光、柔和 / 硬光、暖色 / 冷色。好的灯光描述是"温暖的晨光从侧面照射，金属边缘反射光斑"，而不是"光线很好"。

**声音（Sound）**从 V5.5 版本开始支持原生音频生成。声音让视频从"有画面"变成"有氛围"。好的声音描述是"滚滚浪涛、呼啸风声、遥远城市嗡鸣"，而不是"有声音"。

**格式（Format）**告诉模型输出的技术规格——分辨率（720P / 1080P）、时长（5 秒 / 8 秒 / 10 秒 / 15 秒）、画幅（16:9 / 9:16 / 1:1）、风格标签（电影感 / 写实 / 动漫 / 商业广告）。

### 正反示例对比

把笼统的描述改写成具体的提示词，效果会天差地别：

❌ 不好的提示词：
> 一个女孩在森林里走，光线很好，镜头跟着她。

✅ 好的提示词：
> 穿米白色针织衫和橄榄绿长裤的年轻女性，在秋日落叶铺满的林间小径上缓慢行走，偶尔低头捡起一片枫叶。镜头从侧面 2 米远处跟拍，柔和的黄金时刻阳光透过枫树洒下斑驳光影。远处有鸟鸣和风吹树叶的沙沙声。分辨率 1080P，画幅 16:9，时长 8 秒。

### 实战提示词示例

下面覆盖几个常见场景的提示词，你可以直接套用或替换主体、场景来适配自己的需求。

**产品展示类**——智能音箱：

> 哑光黑色智能音箱放在胡桃木桌面上，镜头从左侧缓慢推进。温暖的晨光从侧面照射，金属边缘反射出柔和的光斑。LED 灯环从灭到蓝渐变亮起，发出柔和的启动提示音。10 秒，16:9，1080P。

**人物与角色类**——宇航员漂浮：

> 成年宇航员漂浮在航天器居住舱中，轻轻从墙面蹬离，周围的小物件（一支笔、一个袋子）逼真地跟着漂浮。镜头像真实零重力稳定器般缓慢漂浮运镜，24-35mm 观感，自然光。背景中隐约能看到大型圆形舱门外的星空。声音：宇航服麦克风中极其轻微的呼吸声、布料摩擦声、物件轻碰的柔和敲击声。8 秒，16:9，1080P。

**动物类**——虎斑小猫：

> 橘色虎斑小猫坐在温暖阳光照射的公寓桌面上，用前爪轻轻拍打木制风车，木质叶片缓慢而自然地旋转。小猫带着好奇的神情注视着叶片，片刻后注意到旁边的蓝色毛线球，轻轻拍了一下让它滚动。镜头保持固定机位，加入非常细微的缓慢推进。照片级动物摄影质感，黄金时刻光线，浅景深。声音：微小的猫爪拍击声、叶片转动的轻柔摩擦声。10 秒，16:9，1080P。

**风景与环境类**——樱花飘落：

> 一棵开满粉白色樱花的大树，花瓣在轻柔的春风中缓缓飘落。镜头用低角度向上仰拍部分樱花枝，阳光透过花瓣形成美丽的丁达尔效应。背景是模糊的日本传统庭院。声音：轻柔的风声、远处寺庙的钟声。8 秒，16:9，1080P。

**抽象艺术类**——霓虹城市夜景：

> 赛博朋克风格的未来城市夜景，无数霓虹招牌和广告牌照亮了整个城区。镜头从高空俯瞰视角缓慢下降，穿过密集的高楼之间，最终停留在一条拥挤的街道上方。空气中有轻微的雾气和雨滴反射。声音：远处的车流声、霓虹灯的细微电流声、背景电子乐。10 秒，9:16，1080P。

### 口型同步与原生音频

从 V5.5 版本开始，PixVerse 不再只是生成"哑视频"——它可以同时生成视频里的声音，包括对白、音效、环境音、背景音乐四种类型。更重要的是，它还有**口型同步（Lip Sync）**能力：如果提示词里写了说话内容，生成的视频中人物的嘴型会和说出的话对齐。

开启声音选项后，PixVerse 会在生成视频的同时根据你在提示词中写的声音描述生成对应的音轨。声音的写法可以按类型区分：

- **环境音最容易上手**，直接在提示词末尾加"声音：轻柔的海浪声 + 远处的海鸥叫声 + 若有若无的风声"
- **音效和动作配对写**，比如"小猫用前爪轻轻拍打木制风车……声音：微小的猫爪拍击声、叶片转动的轻柔摩擦声"
- **对白需要口型同步**，写法是"穿西装的中年男人转向镜头，表情严肃，开口说话：「项目必须在下周完成」。声音：低沉稳重的男声，语速适中"
- **背景音乐**单独描述氛围即可，比如"背景有轻柔的钢琴音乐，音量较低，营造出宁静的氛围"

### 声音质量与口型同步的边界

原生音频和口型同步的效果有它的适用范围：

| 能力项 | 效果较好 | 效果一般 |
| --- | --- | --- |
| 环境音和音效 | ✅ 自然度高 | — |
| 简单对白 | ✅ 节奏和情绪基本准确 | — |
| 长对白或复杂语音 | — | ⚠️ 可能出现吞音、发音不准 |
| 背景音乐 | — | ⚠️ 可用但不期待专业编曲 |
| 口型同步 | ✅ 清晰正面人脸、短句、单人 | ⚠️ 背面人脸、遮挡嘴、多人对话、长句绕口令 |

> [!WARNING]
> 声音描述只有在界面的"声音"选项手动开启时才会生效。如果关闭了声音选项，提示词里写再多音效描述也不会有实际效果。而且声音开启会略高消耗 Credits，注意预算。

### 通用原则总结

1. **具体胜过冗长**——一个详细的主体描述比十个笼统形容词有用
2. **一个镜头一件事**——8 秒视频里塞两个动作就已经很紧张了
3. **调动多种感官**——不仅描述画面，还描述声音和氛围
4. **重复身份锚点**——如果需要角色一致性，在每次镜头切换时重复关键特征
5. **减少冲突**——不要在一个提示词里写互相矛盾的要求
