## ✨ ZoomEarth 是什么

ZoomEarth 是一款专注全球气象可视化的工具，把卫星云图、预报模型、热带气旋追踪等数据整合到同一张地图上。和市面上主打本地天气预报的应用不同，它的核心优势在于**全局视角**——从赤道太平洋的台风生成到极地涡旋的演变，一张地图拉到底，数据来源涵盖 DWD ICON、NOAA GFS 等多个全球预报机构。

这个应用最早在台风季靠飓风追踪功能出圈：热带系统从初生云团到五级飓风的全程轨迹、强度、风圈一路实时更新，配合 10 分钟一档的实况卫星云图，几乎成了台风爱好者和沿海居民每年夏天的标配。除了台风追踪，它还提供九种预报图层（降水、风速、阵风、气温、体感温度、湿球温度、湿度、露点、气压）以及降雨雷达，能覆盖从"明天带不带伞"到"这个低压中心会不会往我家方向走"的各种问题。

ZoomEarth 同时提供**网页版和手机应用**两个入口，背后是同一个服务、同一套数据，交互方式各有侧重：电脑前研究天气过程用网页版更顺手，出门在外盯台风云图则手机应用更方便。两种入口都不要求注册账号，Pro 订阅才需要跨设备同步。

## 📖 使用入门

### 台风追踪：三步上手看家本领

台风追踪是 ZoomEarth 最出名的功能。当地面上有热带系统活动时，海面上会出现带图标的轨迹线，线上每个点是过去某一时次的定位，颜色与粗细对应强度等级，向前延伸的部分是预报路径。第一次用可以按下面的路径走：

1. **找到它**：地图自动显示当前活动的热带系统，也可以从侧栏的台风列表里直接点选
2. **看轨迹线**：过去的定位点连起来就是实际走过的路径，向前延伸的虚线是模型预报的未来轨迹
3. **点开信息表**：点击轨迹或图标，弹出逐时次的日期、时间、类型、风速、气压表

单独看轨迹线只是一条线，配合图层看才明白全貌。卫星影像层看云系结构和眼墙的旋转感；气压层找低值中心就是台风的心脏；风速/阵风层看风场铺开的范围，估外围影响；台风靠近陆地后再切到雷达层看外围雨带的临期落点。

> [!WARNING]
> 应用里的轨迹是多机构数据的可视化，不是官方预警。涉及撤离、停课、船只回港等决策，务必以中央气象台或当地气象部门的官方发布为准。

### 九种预报图层：按问题对号入座

ZoomEarth 的预报地图来自 DWD ICON 和 NOAA GFS 两个全球预报模型，一共九种图层，每层回答一个具体问题。推荐的看图顺序是**气压打头、风跟上、温度收尾、降水收口**：

| 图层类型 | 它帮你回答什么 |
| --- | --- |
| 降水预报 | 接下来哪里下雨下雪、云铺到哪 |
| 风速 / 阵风 | 平均风多大、突发大风的峰值有多猛 |
| 气温 / 体感 / 湿球温度 | 实际温度、人觉得多冷多热、高温高湿天的热应激风险 |
| 湿度 / 露点 | 空气多潮、闷不闷 |
| 气压 | 低压高压在哪、天气系统怎么走 |

先看气压层找出低压中心和高压脊，天气系统的骨架就出来了——低压区往往多云大风，高压区往往晴朗少风。再跟风场和阵风图确认风险范围，最后用温度和降水层判断舒适度和雨雪落点。

> [!TIP]
> 预报图层的时间轴是未来推演，越远越不确定。想看"雨是不是马上到"这种临期问题，应该切到雷达层而不是预报层。

### 卫星影像慢半拍的真相

很多人第一次用会觉得卫星云图"慢半拍"——ZoomEarth 官方描述里说每 10 分钟更新一档，但画面带 20 到 40 分钟的延迟。这不是 ZoomEarth 的短板，而是上游链路的固有节奏：静止卫星拍完一张全球盘面后，要经过地面接收站下传、气象机构定位校正拼图质检、可视化服务取图切片分发，每个环节都要时间。任何用同样数据源的产品都躲不掉。

用图时可以做两个校正：看图先看时间戳，图角上标注的拍摄时间才是真实身份，别跟窗外此刻的天气对表；移动的东西留提前量，台风和雨带都在走，图上的位置是半小时前的位置，粗略估算移动速度后往前推一截。

### 网页版 vs 手机应用怎么选

两个入口背后是同一个服务、同一套数据，但交互方式和使用场景差异明显：

| 你的场景 | 推荐入口 |
| --- | --- |
| 台风季随时盯着云图走位 | 手机应用 |
| 电脑前研究一次天气过程 | 网页版 |
| 只想临时查一次、不想装东西 | 网页版 |
| 想要警报推送与定位直达 | 手机应用 |

网页版的大屏优势在看气压场、卫星云图这类需要全局视角的图层时特别明显，选中地点后逐小时温度和风速列表直接铺在侧边栏。手机应用的优势在于调取定位顺滑——打开就跳到你所在的位置，不需要手动搜索地名，而且热带气旋警报推送等新功能会优先在应用端落地。
