## ✨ Phonto 是什么

Phonto 是一款主打"在图片上优雅地加字"的移动应用，从 2013 年由个人开发者 youthhr 首发 Android 版起，已经迭代了十多年。它不做模板社区、不做滤镜相机，就专注一件事：给图片添加你想要的文字。这种克制反而让它在社媒创作者、学生党、独立设计师里口碑极佳——字体多到 400+ 内置、自定义字体导入全平台通吃、字距行距描边阴影每一项都能精细到像素级。

适合谁用呢？经常给小红书/微博配图加标题的学生党、做课件封面的老师、在社团里做宣传海报的干事、甚至是想给老照片加个日期戳的长辈——只要你觉得系统相册加字太简陋、专业设计软件太重，Phonto 刚好卡在"手机上就能搞定、效果拿得出手"那个点上。它不是 PS，也不是 Canva，它就是一个把"文字 + 图片"这件事做到极致的小工具。

## 🔧 怎么安装 Phonto

Android 用户拿到 APK 安装包后，第一步要处理的是系统权限。如果是从应用商店直接安装，点安装就能完成；如果是手动下载 APK，首次安装时系统会提示"未知来源应用"，需要进设置里给浏览器或文件管理器开一下"允许安装未知应用"的权限——不同手机品牌入口位置略有差异，通常在「设置 → 安全 → 安装未知应用」里能找到。

> [!WARNING]
> 两个版本包名不同（com.youthhr.phonto 原版 vs Polymath 新版），可以同时装在一台手机上互不冲突。如果只想要纯净的加字工具选 youthhr 原版，想要模板贴纸全套选 Polymath 新版。

iOS 用户简单得多——App Store 搜索 Phonto，确认开发者是 Polymath Company Limited，点获取就完事，不需要处理任何权限。安装完首次打开时会弹出"允许访问照片"的请求，选允许才能从相册选底图。

安装后的核对方法很直接：打开 App 看首页能不能正常显示内置字体列表、随便导入一张图片看编辑界面能不能正常加载——能进编辑界面就是装对了，有问题大概率是 APK 下载不完整或版本不匹配。

## 📖 用 Phonto 做出像样的图

打开 App 导入图片后，点击画布就能直接添加文字。默认给你一个白色无描边的字体，接下来就是 Phonto 真正厉害的地方——每一项属性都能单独精细调。

### 字体：不喜欢内置的？自己装

Phonto 只认两种格式：`.ttf`（TrueType）和 `.otf`（OpenType）。其他格式比如 `.woff`、`.woff2` 都不识别，下载到压缩包先在电脑端解压再导入。Android 导入最方便——浏览器下载完 `.ttf`，通知栏点文件选"用 Phonto 打开"，一键 Install 就装好了，或者用文件管理器找到文件点开也行。iOS 版稍麻烦一些，可以把字体发邮件在手机上打开、或者用 Finder/iTunes 拖进去、新版还支持从系统"文件"App 直接选。装好的字体都在字体库底部的「My Fonts」标签页里，和内置字体分开管理。

> [!TIP]
> 免费字体不等于商用免费。Google Fonts、DaFont 上的免费字体大多允许个人使用，但商用需要额外授权，做海报或短视频封面之前留意一下。

### 描边：让小字在复杂背景上不消失

文字颜色调完切到 Stroke 子标签，这里有三个独立参数：颜色（和文字颜色一样的选色器，还能做渐变）、宽度（建议 1–5 之间，太粗像大字报、太细没效果）、透明度（调到 70–90% 比较自然）。最经典的组合是白字加黑描边——在深色背景上立刻"跳出来"。进阶玩法是给描边也上渐变：颜色选择器右下角切渐变模式，四个方向可选，文字本体一层渐变、描边又一层渐变，叠起来比单渐变好看很多。但小字号别试渐变描边，会糊在一起。

### 对象擦除和抠图：v4.4 之后才有的进阶功能

如果你的版本是 v4.4 或更新（Polymath 新版才有，youthhr 原版没有），左下角三横线菜单里有 Eraser 和 Cutout Tool 两个选项。Text / Sticker Eraser 可以用手指"涂"过想删的区域，Phonto 自动识别并删除里面的文字层、贴纸层——清理零散的多层元素比一层层选删快得多。Cutout Tool 是自动抠图，底图里的人、产品、动物都能一键抠出来变成独立图层，然后单独移动、加文字、换背景，和 Phonto 的图层管理完全兼容。

### 版本选择：原版还是新版

| 对比项 | youthhr 原版（com.youthhr.phonto） | Polymath 新版 |
| --- | --- | --- |
| 内置字体 | 200+ | 400+ |
| 体积 | ~24MB | ~100MB+（含模板） |
| 核心加字功能 | ✅ 全部支持 | ✅ 全部支持 |
| 模板/贴纸 | ❌ | ✅ |
| 擦除/抠图 | ❌ | ✅（v4.4+） |
| 更新频率 | 低，只修 Bug | 高，每周更模板 |
| 适合人群 | 只想要纯净加字 | 一站式海报设计 |

两个版本包名不同、可以共存，用惯原版不想丢又想试试模板的话两个都装也没问题。

### 一些实用小技巧

- **字距和行距**：长段文字导入后，默认行距通常太紧导致字挤在一起，行距调到 1.2–1.5 读起来舒服很多；标题字距可以稍拉开一点（调到 5–10），更有设计感。
- **弯曲文字**：进入 Curve 选项，文字可以沿圆弧弯曲——做弧形标题、印章效果很好用，支持顺时针和逆时针两个方向。
- **图层管理**：复杂排版时会堆很多层文字和贴纸，点画布左下角的图层图标可以看到全部层，拖动调整顺序、点击眼睛图标隐藏/显示，和专业设计软件的图层面板逻辑一致。
- **导出**：默认导出无水印 JPG，PNG 格式可选——需要透明背景就选 PNG。
