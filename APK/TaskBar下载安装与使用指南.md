## ✨ TaskBar 是什么——给安卓加个桌面级任务栏

TaskBar 是一款开源的安卓启动器增强组件，它在系统层面叠加了一个可悬浮、可固定的任务栏，让安卓设备获得接近 Windows 桌面的多任务操作体验。

普通安卓的桌面逻辑是以"主屏+翻页"为核心，应用列表藏在应用抽屉里，系统自带的最近任务栏功能也比较基础。TaskBar 直接绕过这套范式——它把一个可调节的任务栏常驻在屏幕顶部或底部，点击弹出开始菜单列出**全部已安装应用**（包括系统应用），常用应用可以钉在托盘，配合自由窗口和桌面模式，让大屏设备真正用上桌面化的交互方式。

从 2016 年起，Android-x86 和 Bliss OS 这类桌面化安卓发行版就把 TaskBar 内置为默认启动器组件。开源、无广告、不收集用户数据，加上对多设备形态的适配，让它在"安卓桌面化"这个小众但稳定的需求圈里积累了多年口碑。

适用场景很广：平板接键鼠模拟轻量办公 PC、Android TV 盒子侧载后获得完整应用列表、折叠屏展开后同时开多个自由窗口、PC 上跑 Android-x86 获得原生桌面体验——这些都是 TaskBar 的主力战场。手机上也能用，单手顶部任务栏配合自动折叠，日常切换应用效率提升明显。

## 🔧 安装步骤——按设备形态分情况处理

TaskBar 的安装方式跟设备类型直接相关，不同平台差异挺大。

### Android 手机 / 平板（最常见）

1. 从下载页拿到 APK 文件，传到设备本地
2. 系统设置 → 安全 → 允许未知来源应用安装（部分机型路径在"应用管理"或"隐私"里）
3. 用文件管理器打开 APK，点安装
4. 装完打开 TaskBar，按照引导依次授予权限

> [!WARNING]
> **悬浮窗权限是最关键的一步**，没给这个权限，任务栏根本显示不出来。部分国产 ROM（MIUI、OneUI、ColorOS）对悬浮窗管控更严，建议到安全中心把 TaskBar 的悬浮窗、自启动、后台常驻全部打开。

### Android TV 盒子（侧载）

1. 盒子设置 → 安全和限制 → 未知来源 → 开启
2. 安装方式三选一：U 盘插盒子用文件管理器打开 APK、adb 命令 `adb install taskbar.apk`（盒子和电脑同 Wi-Fi，开无线调试）、或者用 ES 文件浏览器等第三方安装器
3. Android TV 遥控器方向键 + 确认键就能操作 TaskBar 开始菜单

> [!NOTE]
> Android TV 9 及以下版本大概率不支持悬浮窗权限，TaskBar 会作为普通应用打开，能列出全部应用但不能悬浮覆盖。Android TV 10+ 部分设备支持，取决于厂商实现。

### Android-x86 / Bliss OS（PC 上跑安卓）

这两个发行版从系统层面就集成了 TaskBar，通常**已经预装好了**：
- Android-x86 7.1-rc2 及以后版本：预装
- Bliss OS 所有 x86 版本：预装

如果预装版本较旧，可以自行更新：打开浏览器去 F-Droid 或 GitHub 下载最新 APK，覆盖安装即可。更新后配置通常会保留，但也可能需要重新设置一遍。

### 安装后的核对

装完打开 TaskBar，做两件事：
1. 拨一下总开关，确认任务栏确实出现在屏幕上（顶部或底部，取决于你选的位置）
2. 点任务栏弹出开始菜单，看看应用列表是否正常

如果拨开关后任务栏一闪就没了，大概率是悬浮窗权限或后台白名单没到位——回到排错章节逐条检查。

## 📖 使用入门——主力场景深挖

TaskBar 的功能远不止一个悬浮任务栏，结合不同设备形态可以玩出很多花活。

### 手机：单手高效切换

手机屏幕小，TaskBar 的核心价值是**减少翻页和找应用的操作成本**：

- 任务栏放**顶部**比底部更容易单手够到，大拇指不用挪太远
- 托盘固定 3-5 个最常用的应用（微信、浏览器、相机这类），太多会让任务栏过宽反而碍事
- 自动折叠开启——玩游戏或看视频时任务栏自动收起来不挡视线，退出全屏应用后又自动展开
- 自由窗口在手机上效果有限，两个小窗挤在一块儿不太实用，但边看视频边回消息、临时开个计算器或便签这几个场景还是挺方便的

### 平板：TaskBar 的主力舞台

平板大屏 + 桌面模式 + 自由窗口，这三样组合起来才是 TaskBar 的完整形态。根据使用姿态不同，配置建议也跟着变：

| 姿态 | 任务栏位置 | 托盘数量 | 固定应用数 | 额外建议 |
|---|---|---|---|---|
| 双手手持 | 底部 | 5 个 | 8 个 | 自由窗口开两个（视频+消息） |
| 支架+键鼠 | 顶部或底部 | 5-7 个 | 8-12 个 | 键鼠优化必开，右键/悬停/快捷键全部启用 |
| 接显示器（Type-C 视频输出） | 看屏幕方向 | 5-7 个 | 按需要 | 完整桌面模式（Android 10+），两块屏各有各的 TaskBar |

**接显示器**这个场景特别值得提一下——Type-C 视频输出到显示器，再接蓝牙键鼠，平板瞬间变轻量 PC。桌面模式下两块屏幕独立运作，各有各的 TaskBar 和应用窗口，浏览器开网页、笔记软件写东西、文件管理器传文件，基本的办公需求都能覆盖。

### 折叠屏手机

折叠屏展开后其实就是个小平板，TaskBar 在内外屏的表现也跟着屏幕形态切换：
- **外屏（小屏）**：和普通手机一样，顶部任务栏 + 单手操作
- **内屏（展开）**：和平板一样，可以同时开多个自由窗口，甚至模拟桌面模式

大多数折叠屏厂商自带桌面模式支持，TaskBar 可以和厂商方案共存，互不干扰。

### Android TV 盒子：补全应用列表

Android TV 原生 Launcher 有个通病——只把热门视频应用放在首页，装了几十上百个应用后，想找一个冷门应用特别费劲。TaskBar 的开始菜单能列出**全部已安装应用**，包括系统应用和你装的每一个，这个缺口一下就填上了。

配置较强的盒子（比如英伟达 Shield TV Pro）接显示器 + 键鼠 + TaskBar，还能当轻量 PC 用：浏览器查资料、笔记软件记事、文件管理传东西，基础办公不在话下。

### Android-x86 / Bliss OS：桌面化安卓的默认选项

如果在 PC 上跑安卓，TaskBar 基本是绕不开的组件。Android-x86 从 7.1-rc2 起就内置，Bliss OS 所有版本都预装——说明这两个桌面化安卓发行版从设计思路上就把 TaskBar 当成了标配。

体验上接近轻量 Linux 桌面：开机就是桌面界面、底部任务栏列出应用和托盘、应用可以自由窗口化、键鼠默认启用。硬件门槛也不高，Intel/AMD x86-64 架构的 PC，4GB 内存以上、8GB 硬盘空间就能跑。

### 自由窗口与权限——踩坑要点

自由窗口是 TaskBar 最吸引人的功能，但也是最容易出问题的地方。勾了自由窗口选项但应用还是全屏打开，按概率从高到低排查：

1. **系统最近任务没清空**——这是最常见的。目标应用必须完全关闭（不在最近任务列表里），从 TaskBar 菜单点开才会以小窗打开
2. **adb 授权没做（Android 8.0/8.1/9）**——用 USB 线连电脑，执行 TaskBar 弹窗里那条 adb 命令，成功后再试
3. **应用本身声明了不可调整大小**——少数银行、VR 应用不支持自由窗口，TaskBar 也强制不了
4. **ROM 限制**——部分国产 ROM 修改了系统窗口管理，这种情况只能等开发者适配或换 ROM

> [!TIP]
> **拨了总开关没反应**时，先确认悬浮窗权限、后台白名单、电池优化这三项都处理了，再重启手机。这是排错优先级最高的三件事，解决了基本就能跑起来。

### 和系统自带方案的对比

为什么用 TaskBar 而不是系统自带的启动器？核心差异在这几点：

- 开始菜单列出**全部**应用，包括部分厂商 Launcher 会隐藏的系统应用
- 自由窗口更灵活（可拖动、可缩放），很多厂商系统的分屏功能限制多
- 桌面模式不依赖厂商定制，原生 Android 10+ 都能用
- 开源可控，无广告、无数据收集
