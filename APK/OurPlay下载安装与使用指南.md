## ✨ OurPlay 是什么

OurPlay 是一款面向国内玩家的外服手游运行工具。它把三件事打包在一个 App 里：**网络加速、实时汉化、外服游戏分发**——装了它，日韩美服的手游就能在国内 Android 手机上跑起来，不再需要分别折腾加速器、翻译器和找游戏包。

它的核心受众很明确：想玩《碧蓝档案》《赛马娘》《边狱巴士》这类日服精品手游、但不想被语言和网络两道坎挡住的玩家。官方商店界面主打"外服手游一键畅玩"的定位，社区里也聚集了不少同好，攻略和组队信息更新得快。

支持的平台目前以 Android 为主，同时提供 Windows 电脑版——手机上肝了半年的号可以扫码同步到电脑端接着玩，模拟器兼容性和加速环境也一并配好，不需要自己单独装模拟器。

> [!NOTE]
> OurPlay 运行时不修改游戏文件本身，实时汉化走的是系统级文本转译路线，游戏正常更新不受影响。这和市面上一些"修改版安装包"是完全不同的两条路。

## 🔧 安装步骤

### Android 手机安装

1. 从下载页拿到 APK 安装包后，传到手机或直接手机下载
2. 打开手机「设置 → 安全 → 允许未知来源安装」（不同厂商路径略有差异）
3. 点击 APK，按提示完成安装

> [!WARNING]
> 安装包建议从下载页拿，第三方渠道的版本可能被篡改。安装前核对文件大小——官方版本通常在 30~50MB 区间，偏差太大就别装了。

4. 首次启动会申请网络权限和存储权限，全部允许即可
5. 登录 OurPlay 账号（手机号或邮箱注册都行），进入主界面

### Windows 电脑版安装

1. 下载页提供安装包，双击运行
2. 安装路径可自选，建议默认位置即可
3. 首次启动会自动检测并配置运行环境（包括模拟器内核、加速组件），这个过程需要几分钟
4. 登录同一个 OurPlay 账号，与手机端数据互通

安装完成后打开「我的游戏」是空的，接下来就是找游戏、加速、开玩——这三步在使用入门里细说。

## 📖 使用入门

### 加速：先看三个指标再定节点

OurPlay 加速时会在界面上显示**综合提速、网络延迟、丢包率**三个数据，这是判断加速效果好不好的直接依据，别只凭体感说"卡还是不卡"。

**网络延迟**是操作到达游戏服务器再返回的时间，毫秒计。50ms 以下基本跟手，50~100ms 日常够用，100~150ms 竞技类开始吃力，150ms 以上就明显卡了。日服从国内连能进 60~90ms 算不错，物理距离决定了天花板。

**丢包率**是数据包传输中丢失的比例，越低越好，理想接近 0。丢包才是"瞬移、回档、指令丢失"的元凶——延迟高只是慢，丢包是直接断动作。OurPlay 的 UDP 超维抗丢包技术就是冲这个来的。

**综合提速**用来对比开加速前后的提升幅度，单独看绝对值没意义。一个实用习惯：第一次加速某款游戏时记下三个指标的值，之后感觉"变卡了"就回来对比——数据变化比体感客观，能快速定位是节点问题、时段问题还是本地网络问题。

> [!TIP]
> 延迟一直偏高就换节点；丢包率波动大就切换 WiFi/移动流量；两个都不理想先检查本地网络，别只盯着加速器。

### 汉化：知道它能翻什么、不能翻什么

OurPlay 的"一键汉化"不是万能翻译机。它做得好的集中在三类文本：**剧情对话（主线、活动字幕）、技能与数值说明（技能描述、装备属性、养成材料）、界面菜单（按钮、设置项、公告标题）**。日系手游是主战场，边狱巴士、碧蓝档案、赛马娘、世界计划、咒术回战这类常驻推荐位的汉化资源相对完善。

但有些内容它天生翻不了：

| 类型 | 原因 |
| --- | --- |
| 语音配音 | 汉化只处理文本，语音保持原声 |
| 图片内嵌文字 | 立绘、Logo、活动图上的字是图像，无法实时转换 |
| 玩家昵称与聊天 | 其他玩家起的名字、发的消息不归汉化管 |
| 实时生成的文本 | 随机词缀、动态拼接的描述可能转换不稳定 |

实时机翻的路线决定了译文准确但未必优雅——玩法术语（技能机制、装备搭配）建议结合游戏社区的中文攻略对照理解，OurPlay 内置社区里就有大量这类内容。另外汉化资源依赖应用版本更新，刚上线的日韩新游汉化通常晚于游戏本身几天到几周，这不是故障，等应用推送新版即可。

### 电脑版：扫码同步手机游戏

手机上肝了半年的号，想在电脑上接着玩？OurPlay 电脑版的扫码同步就是干这个的。

流程很简单：

**电脑端**：打开 OurPlay 电脑版并登录同一个账号，找到扫码/同步手机游戏的入口，屏幕上会出现二维码。

**手机端**：打开 OurPlay App，用内置扫码功能扫电脑端二维码，确认同步。

**电脑端**：盯进度条，传输完成后游戏自动出现在「我的游戏」里。

同步的是**游戏本体和账号进度**——电脑端自动下载安装对应版本，存在服务器里的进度随账号登录恢复；但本地数据不在同步范围内。前提是那款游戏在电脑端的支持列表里——毕竟电脑端需要为它准备模拟器运行环境。

> [!NOTE]
> 同步失败常见原因：两端账号不一致、电脑端二维码未完整显示或手机摄像头权限没开、网络波动导致进度条卡住（体积大的游戏传输时间长，别急着取消）。

### 电脑版游戏库：三种添加路径

打开电脑版主界面，「我的游戏」卡片区右上角有「添加游戏」按钮，旁边是官方提供的游戏库。游戏库按平台/类型划分（电脑游戏和手游区分标识），也支持直接搜游戏名全平台跨出结果。

添加游戏有三条路：

| 路径 | 适用场景 |
| --- | --- |
| 游戏库内直接下载 | 主流外服手游，一键装好 |
| 扫码同步手机游戏 | 手机上已经在玩的游戏 |
| 手动添加 | 其他途径安装的游戏 |

游戏出现在「我的游戏」后点击即可一键启动——OurPlay 电脑版会自动处理运行环境和加速节点分配，不需要额外配置。找不到想玩的游戏时，先确认游戏名拼写（外服游戏常有官方译名差异），部分游戏暂未开放电脑端支持，以库内可搜到为准。
