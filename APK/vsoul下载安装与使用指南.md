## ✨ VSoul 微灵是什么

VSoul 微灵是一款面向 AI 角色互动场景的客户端工具，核心思路是用「四层灵魂档案」的结构化方式来定义一个 AI 角色——身份底稿、关系坐标、世界背景、表达纹理，再加上一个开场事件，让角色从诞生之初就有明确的位置感和行动逻辑。它不是通用聊天机器人，也不是写作助手，而是让你和你创建的 AI 角色之间建立起一种可持续的互动关系。

微灵的典型使用场景包括日常陪伴式的闲聊互动、剧情共创式的角色扮演、灵感讨论式的多视角创作辅助，以及表达练习式的沟通模拟。四种模式各有侧重，但底层逻辑是一致的：先把角色的灵魂定义清楚，再让它在你设定的场景里行动。

除了角色创建和互动，微灵还支持角色卡的导入导出，包括 PNG 和 JSON 两种格式，方便在不同工具之间迁移或精细调整设定。社区里也有大量用户分享的角色卡可以参考和学习。

## 🔧 安装步骤

微灵支持多平台分发，以下以 Android 安装为例说明注意事项。

**1. 获取安装包**

从下载入口页面获取对应平台的最新安装包，下载完成后核对文件大小是否与页面标注一致，避免下载到不完整的文件。

**2. 允许未知来源安装**

Android 系统默认禁止安装来源不明的应用。进入系统设置 → 安全 → 未知来源，允许当前文件管理器或浏览器的安装权限。不同 ROM 的设置路径可能略有差异，找不到时可以在设置里直接搜索「未知来源」。

> [!WARNING]
> 只允许安装你确认来源可靠的安装包。未知来源开关用完后建议关闭，避免其他应用静默安装。

**3. 安装与首次启动**

点击安装包执行安装流程，安装完成后首次启动会请求存储权限和网络权限，建议全部允许——角色卡的导入导出和在线资源获取都需要这些权限。

**4. 版本核对**

首次启动后进入设置页面，确认版本号与下载页面标注一致。如果版本过低或安装异常，建议卸载后重新下载安装。

## 📖 使用入门

### 四种互动模式怎么选

微灵在开始互动前建议先明确本次的目标，四种模式各有侧重，选对模式能显著提升互动质量：

| 模式 | 核心目标 | 判断标准 |
| --- | --- | --- |
| 日常陪伴 | 分享当下、整理想法 | 自然对话、边界清楚 |
| 剧情共创 | 推进故事、延续关系 | 动机合理、情节连贯 |
| 灵感讨论 | 多视角发现创作空白 | 问题到位、建议可用 |
| 表达练习 | 比较不同说法的效果 | 措辞准确、语境合适 |

四种模式可以切换，但最好一次只做一件事。今天想推进剧情就不要同时让角色帮你改方案，目标明确的互动，角色回应的质量会明显更高。

### 创建角色：四层灵魂档案

微灵的角色定义采用四层结构，每一层解决一个维度的问题：

- **身份底稿**：角色是谁、经历过什么、有什么能力和限制
- **关系坐标**：你和角色怎么认识、信任程度如何、有过哪些共同事件
- **世界背景**：当前的时间、地点、规则，角色所处的物理和社会环境
- **表达纹理**：说话的语气、用词节奏、叙事视角，让角色有独特的语言质感

再加上一个**开场事件**，描述角色当前在哪里、正在做什么、等待回应的问题是什么。这五部分组合起来，角色就有了完整的灵魂起点。

> [!TIP]
> 临时场景信息不要写进长期设定字段。比如某次互动里角色被困在电梯里，这属于临时场景，不要写进世界背景或身份底稿，否则下次互动它还会记得自己被困在电梯里。

### 导入 JSON 角色卡

微灵支持 JSON 格式的角色卡，适合需要精细调整设定的场景。JSON 角色卡不携带图片，只携带文字设定，用任何文本编辑器都能打开和修改。

导入步骤很简单：

1. 把 JSON 文件保存到设备
2. 进入创意工坊，点击「导入角色卡」
3. 选择 JSON 文件，等待解析完成
4. 检查角色设定确认无误后开始互动

一个典型的 JSON 角色卡包含这些核心字段：

```json
{
  "name": "角色名字",
  "identity": "身份底稿——姓名、经历、能力、限制",
  "relationship": "关系坐标——如何认识、信任程度、共同事件",
  "world": "世界背景——时间、地点、规则",
  "expression": "表达纹理——语气、用词、节奏、叙事视角",
  "opening": "开场事件——地点、当前事件、等待回应的问题"
}
```

> [!NOTE]
> JSON 语法严格，引号、逗号、括号必须成对，任何一个错误都会导致解析失败。保存前建议先复制一份备份。字段名是英文，字段值可以是中文。

PNG 和 JSON 两种格式可以互相转换。你可以把微灵中创建好的角色导出为 JSON，用编辑器修改后再导入。

### 角色偏航拉回

互动中角色可能偏离设定——称呼错了、行为突变、语言风格飘移、信息错乱、剧情失忆都是常见表现。出现偏航时不要急着改档案，按以下顺序排查：

**第一步：检查当前目标是否清楚。** 互动开始前有没有写清楚本次目标？角色的当前目标有没有过期？目标不清楚时角色最容易随波逐流。

**第二步：检查关系坐标是否过期。** 上次互动后关系有没有变化？信任程度和当前互动匹配吗？共同事件里有没有需要更新或删除的？

**第三步：检查设定是否冲突。** 四层设定内部有没有矛盾？身份底稿的限制和表达纹理的风格是否一致？世界背景和关系坐标有没有冲突？

**第四步：检查场景是否具体。** 互动开场有没有给角色足够的具体信息？它知道自己在哪里、刚刚发生了什么、现在应该做什么吗？

修改时**一次只改一类设定**，改完重新测试，这样才能知道到底哪一项起了作用。如果角色只是这一轮说偏了——比如上下文干扰或温度太高——直接用临时指令拉回就行，不用改档案：

- 「纠正：我刚才问的是便利店的事，不是咖啡店」
- 「请用你平时的语气回答」
- 「你不应该知道这个信息」

临时指令对 AI 有效，但长期问题还是要通过修改档案解决。

### 分享前的版权检查

如果你打算公开分享自己创建的角色卡，以下四步检查法能帮你规避常见问题：

**立绘图片：** 是自己画的吗？网上找的图片原作者有没有允许二次使用？来源不明的图片建议替换。微灵允许上传自己的图片作为角色形象。

**设定原创性：** 有没有直接搬运其他作品的完整人设？有没有使用知名 IP 的角色名称或标志性设定？「一个会用元素能力的角色」是灵感启发，「一个来自木叶村的忍者」是直接搬运，后者不适合公开分享。

**隐私信息：** 设定里有没有出现真实人名、地名、联系方式或私人场景？分享的角色卡应该是完全虚构的。

**内容边界：** 有没有可能冒犯特定群体？有没有涉及违法违规或有争议的题材？

确认以上四点都没有问题后，通过微灵内的导出功能生成 PNG 或 JSON 角色卡即可分享。
