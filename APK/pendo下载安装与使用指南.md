## ✨ Pendo 是什么

Pendo Note 是一款走时间线路线的个人记录工具，来自 Lychee Isle 工作室。它把笔记、待办、日程三种内容统一铺在一条按时间排序的流水线上——你在任何时刻写下的一行念头、一条任务、一个约会，都会落到时间轴上对应的位置，点进去就是完整条目，划出来就是一段连续的记录。

和 Notion、Obsidian 这类"写大文档"的工具定位不同，Pendo 的主打是**快速、频繁、轻量的碎片化记录**。界面没有文件夹层级、没有复杂的项目空间，打开就是一条时间线，写一条、继续下一条，回头翻的时候按时间自然组织好。对习惯随手记、碎片式记录的人来说，时间线的组织方式比传统笔记软件的"文件夹+标签"更直观——你上周三写的那条"下午开评审"，在时间线上的位置就是它和"昨晚刷到的好文链接"、"中午想的创意"连在一起，上下文自带。

核心功能包括：时间线主界面、Calendar Event IQ 自然语言日程、C/T/E 单字母快捷命令、待办沉底与循环待办、标签加颜色分类、清单粘贴识别、图文长图快照、双指调字号。iOS / macOS / iPadOS / watchOS 端已经迭代到 8.x 版本，安卓端走独立的 2.x 线——两条线各自迭代，核心记录功能不受版本线影响，只是 iOS 端有 AI 助手 Catbot、iCloud 全量同步、Apple Watch 表盘等独有卖点，纯记录用户用不上也不影响体验。

适合谁用：把 Pendo 当成"时间轴日记本"的人、每天记录多频次碎片念头的人、希望日程自动写入系统日历的人。如果你习惯写长篇结构化文档、需要知识库的双向链接或代码块高亮，Pendo 不是合适的选择。

## 🔧 安装与首次启动

Pendo Note 的安卓安装包体积约 71MB，通过网盘转存分享，不走直链分发。整个安装流程大致五步：转存分享链接到自己的网盘、下载到手机本地、允许"未知来源"安装、授予日历和通知权限、首次打开开始记录。

### 转存并下载

打开下载入口的分享页面，首次进入需要登录网盘账号（没账号当场注册手机号即可）。在分享页勾选 Pendo Note 安装包，点击"转存"让文件进入自己的网盘空间——转存后链接变成你自己的，长期有效，不怕原链接失效。然后打开网盘客户端（应用商店搜网盘名称），找到刚转存的 APK 文件点击下载，下载完成后文件落到手机本地存储对应的目录。

### 允许安装未知应用

点开 APK 文件时，Android 系统默认会弹出"禁止安装未知应用"或"安装可能有害的应用"警告——这是 Android 的常规安全提示，不是 Pendo 有问题。按提示找到网盘客户端（或你打开 APK 的那个应用）的"允许安装未知应用"开关，打开后回到安装页继续。

> [!WARNING]
> 不同品牌手机的菜单名称略有差异：小米、OPPO、华为、三星的路径不完全一样，以手机实际为准。常见入口路径是"设置 → 安全 → 更多设置 → 安装未知应用"。找不到时直接在设置里搜"未知应用"或"安装权限"。

### 授予关键权限

安装完成首次打开时，建议按需授予两个权限：

1. **日历读写权限**：Calendar Event IQ 自然语言日程写入系统日历的前提——不开这个权限，你在 Pendo 里写的"明天 9 点开会"不会进入系统日历
2. **通知权限**：待办和日程提醒需要——不开就收不到推送

两个权限都是可选的，但不开就用不了对应的核心功能。如果第一次忘了开，之后在应用设置 → 权限里随时可以补开。

### 三个常见卡点

**提示被阻止安装**：多是"安装未知应用"权限没给到，按上面的路径去设置里打开即可。

**提示存在冲突的应用**：说明手机里装过同包名的其他来源版本（包名 `com.pendoapp.pendo`），两个安装包签名不一致就会拒装。先卸载旧版本再装这一份。卸载前如果旧版有重要数据，先在应用设置里找备份导出入口。

**装好了但日历里没事件**：按这个顺序排查——先确认应用设置里日历权限是"允许"；再打开系统自带日历应用，确认它本身能正常建事件、有已登录的日历账户（Google Calendar、Exchange 等）；最后在 Pendo 里写一条最简单的事件比如"明天 9 点测试"，看链路通不通。

## 📖 使用入门

Pendo 的学习曲线非常平缓——打开就是时间线，写一条、继续下一条，不需要先学一堆概念。真正能把 Pendo 用好的人，都会熟悉以下几个核心操作和工作流。

### 时间线主界面

打开应用第一眼看到的就是时间线——按时间倒序排列，最新的条目在顶部，每条显示一小段预览。点进去是完整内容，可以继续编辑或删除；往左滑或往右滑可以按日期切换视图。

时间线是 Pendo 的核心骨架，所有功能都围绕它展开。它不是"笔记列表"也不是"日历格子"，而是一条连续的、随时可以往里插入新条目的时间轴。

### C / T / E 单字母快捷命令

输入框里直接打单个字母触发对应模式：

- **C** → 创建日历事件（Calendar）。比如 `C 明天下午3点和客户开会`，Pendo 会自动解析时间并写入系统日历
- **T** → 创建待办（Todo）。`T 整理周报`，待办会沉到时间线底部，完成后勾选会打上删除线
- **E** → 创建普通条目（Entry）。默认模式，就是一段文字记录

单字母命令的好处是**不用离开键盘、不用切菜单**，想写什么直接打就行。这是 Pendo 和其他笔记工具最不一样的地方——记录的过程越短越好，中间没有任何多余的点击。

### Calendar Event IQ

这是 Pendo 最有特色的功能之一。你不用选日期、填时间、选时区，直接用自然语言写就行：

- "明天 9 点到 11 点半开周会"
- "下周五下午 3 点和设计团队对接"
- "每天晚上 7 点跑步"（循环日程）

Pendo 会解析里面的时间信息，自动生成日历事件并写入系统日历。它的解析准确度不错，常见的中文时间表述基本都能识别。唯一需要注意的是——要给它日历读写权限，不然写进系统日历这一步走不通。

### 待办与标签

Pendo 里的待办有两个特点：

1. **沉底显示**：时间线按时间倒序排，但待办会自动沉到底部，不会被一堆笔记淹没。完成后勾选，待办会加上删除线并从底部消失，回到正常时间线位置
2. **循环待办**：可以设置"每天"、"每周"、"每月"循环，比如"每天早上 8 点喝水"会在每天同一个时间点自动生成一条待办提醒

标签用 `#` 开头加颜色分类，比如 `#工作`、`#灵感`、`#读书`。点一个标签就能筛选出所有带这个标签的条目，相当于快速检索。

### Markdown 支持范围

先说结论：**Pendo 只支持一部分基础 Markdown**，不是完整的 Markdown 编辑器。它的定位是快速记录工具，不是排版精美的文档编辑器。

确认支持的语法：

- 标题（#、##、###）——部分版本只支持二级及以下
- 无序列表（-）和有序列表（1.）
- 加粗（**）和斜体（*）
- 行内代码（`代码`）

不支持或不确定的语法：

- 代码块（三反引号）——安卓 2.x 版本可能不支持完整代码块高亮
- 表格——建议用纯文本排版代替
- 链接和图片——Markdown 语法可能不识别；图片用 Pendo 自带的插图按钮
- 任务列表（- [ ]）——不要用，Pendo 有自己的 T 命令创建待办

> [!TIP]
> Pendo 的强项是快速记录不是精美排版。建议用列表组织思路、用加粗标注重点，不要硬凑复杂格式。需要精美排版时，在 Pendo 里写好 → 导出长图或复制文字 → 粘到 Notion / Obsidian / Typora 里继续。

另外，iOS 8.x 版本的 Markdown 支持比安卓 2.x 更完整（有代码块、有链接）。如果你 iOS 和安卓都在用，以较简的安卓版支持范围为准，iOS 端肯定能兼容。

### 每周复盘图表

Pendo 的图表功能把"你写了多少"变成了可视化的曲线或柱状图——不是精确的统计报表，而是一眼扫过去就能理解自己最近的状态。

图表分三种：

**每日图表**：横轴 24 小时，纵轴是该小时内的记录条数。能看到你是不是习惯早上 7-9 点写东西、下午 3-5 点有没有效率低谷、深夜 11 点是不是反而灵感爆发。

**每周图表**：横轴周一到周日，纵轴每天的记录总量。能快速回答"自己是不是周末反而记录少"、"哪几天最忙"这类问题。

**类型分布**：某些版本还能按类型分开显示——笔记数量走势、待办完成数量走势、日程数量走势。

iOS 8.x 端图表入口通常在日历视图底部的小图标，或主界面侧边栏的"统计 / 回顾"入口。安卓 2.x 是否支持图表功能以实际界面为准——如果找不到独立的图表入口，可以手动用日历视图做简易回顾，每天格子的内容数量变化本身就是一种视觉回顾。

### 图表 + 日历视图 + 时间线的三回顾工作流

Pendo 设计得最巧妙的地方，是让这三个视图配合起来做回顾——从宏观到微观、从整体到细节，全程在同一个应用里完成，不需要切换：

1. **先看图表**——有个整体印象：这周每天的记录量走势怎么样，哪几天活跃、哪几天懒了
2. **切到日历视图**——点一下"最忙的那一天"，看看具体是哪天、是不是有原因（加班、生病？）
3. **切到时间线**——逐行回顾那天做了什么、想了什么
4. **写一篇周总结**——加个标签，下周继续

周五晚上或周六早上花 5-10 分钟走一遍这个流程，比盯着一堆统计数字有用得多。

### 安卓与 iOS 版本差异

Pendo 最大的平台差异可能就是版本号了——iOS / macOS 端已经迭代到 8.x，安卓端还在 2.x 徘徊。这是双版本线策略，不是哪个平台被抛弃。两条线互相独立，安卓端不会直接吃到 iOS 的功能更新，iOS 也不会因为安卓版本号低就退回去。

| 平台 | 版本线 | 发布节奏 |
|------|--------|----------|
| iOS / macOS / iPadOS / watchOS | 8.x | 较快，每月可能有小更 |
| Android | 2.x | 独立较慢 |

iOS 8.x 有而安卓 2.x 没有的功能：AI 助手 Catbot、iCloud 全量同步、Apple Watch 表盘、VisionOS 支持、更完整的 Markdown 支持。但核心记录功能——时间线主界面、Calendar Event IQ、单字母命令、待办沉底、标签分类、图文长图快照——两条线是一致的。

> [!NOTE]
> 不要拿着 iOS 8.x 新功能的教程去套安卓 2.x——按教程操作发现界面不一样是正常的，不是你装了错误版本。反过来如果你是 iOS 用户，那 2.x 安卓有的功能你肯定也有，不用担心功能覆盖问题。
