## ✨ Qiz 是什么

Qiz 是一款以**多维兴趣标签**为核心匹配引擎的垂直社交 App。它不走颜值优先的老路，而是让用户自主选择兴趣爱好、人格分析、生活方式、职业学业等多维度标签，系统基于标签交集计算匹配优先级——标签重合度越高，推荐越靠前。

和 Soul 的性格标签、积目的潮流标签不同，Qiz 的标签体系完全由用户自己主导，不是系统测试题给的，也不是单一维度的。一个用户的标签可能同时覆盖"二次元""独立游戏""咖啡精酿""MBTI 某型""程序员"等多个层面，这种多维设计让匹配的精确度明显高于单一维度的社交产品。

Qiz 的社区氛围主打"真人 + 兴趣"——注册需要手机号验证，头像和简介会经过基础审核，发帖和聊天内容也有自动化审核机制。这种审核过滤掉了机器人、营销号和低质量账号，留下了真正想找到同好的用户。应用商店评论里高频出现"没有一个机器人""氛围比较舒服""认识好多三观契合的朋友"这类评价。

## 🔧 安装步骤

Qiz 目前以 Android 版本为主，iOS 版本可通过 App Store 正常获取。下面按平台分别说明安装流程。

### Android 安装

1. **获取安装包**：推荐从上面的官方下载页获取，或直接在应用商店搜索"Qiz"。应用商店渠道的好处是自动更新、来源可信；官方下载页的好处是可以拿到历史版本和详细的版本说明。
2. **允许未知来源（仅手动下载 APK 时）**：如果从官方下载页拿到的是 APK 文件，安装前需要在系统设置里允许"未知来源应用安装"。不同手机的设置路径略有差异，一般在「安全设置」或「隐私设置」里能找到这个开关。

> [!WARNING]
> 安装完成后建议把"未知来源"开关关闭，避免其他来源的恶意 APK 被误装。应用商店渠道安装不需要这一步。

3. **安装并验证**：安装完成后打开 App，进入登录/注册界面，用手机号完成注册流程。注册时系统会提示完善个人资料，**务必勾选至少 3 个兴趣标签**才能启动匹配算法——这是 Qiz 用户最容易踩的新手坑，没认真选标签就进发现页会发现推荐列表是空的。

### 安装验证清单

| 检查项 | 说明 |
| --- | --- |
| 版本号核对 | 安装后进入「设置 → 关于」核对版本号与下载来源的版本一致 |
| 标签数量 | 个人资料里至少 3 个标签，最多可选 20 个 |
| 推送权限 | 首次启动时允许通知权限，否则收不到匹配提醒 |

## 📖 使用入门

### 第一步：认真选好兴趣标签——匹配的基石

标签体系是 Qiz 一切的起点。匹配算法不看你的头像颜值、不看灵魂测试分数，**只看标签的交集**。两个"喜欢二次元"的人，如果其中一个还选了"独立游戏"和"猫奴"，另一个选了"小众音乐"和"精酿"，匹配优先级就会不同。

选标签时建议遵循几个原则：

- **至少 3 个、最多 20 个**：少了匹配算法不启动，多了会失去区分度
- **按真实兴趣选，别为了"显得有趣"硬选**：标签是你和同好连接的桥梁，虚假标签只会让匹配结果偏离
- **可以随时改**：标签修改后匹配算法实时重新计算，如果发现推荐越来越偏，回头看看标签是不是需要更新了

### 第二步：交友探索页的三种浏览模式

进入发现页后，你会看到**推荐、新人、附近**三种浏览模式。系统的默认推荐已经是基于标签相似度计算过的结果了——推给你的人，标签已经和你有交集。

如果觉得系统推荐太宽太泛，想更精准，可以用**兴趣标签筛选**功能。这是叠加在系统推荐之上的手动过滤：选择一个或多个标签后，三种浏览模式都只展示带有这些标签的用户。筛选逻辑是 OR 关系——选了多个标签，展示的是有任意一个标签的用户。

> [!TIP]
> 标签筛选 + 在线状态 + 地理位置 = 三重精准筛选。想找当前在线的同好聊天，就叠加"在线"过滤；想找本地同好约线下，就叠加"附近"过滤。但如果匹配结果本来就少，再加筛选可能直接没了，这时候建议放宽条件。

标签筛选的几个实用细节：

1. 先看系统推荐有没有问题，再考虑手动筛选——系统推荐本身已经是标签相似度计算后的结果
2. 多个标签别选太多，3~5 个足够了，选太多等于没选
3. 筛选完记得取消，不影响下次浏览
4. 筛选条件对三种浏览模式都生效，不冲突

### 第三步：兴趣广场与评论区互动

兴趣广场是 Qiz 的社区核心，用户在这里发布图文、视频、语音帖子。很多人只点赞不评论，但**评论区才是挖宝的地方**——

- 看谁评论了同一个"冷门漫画"的帖子，进去看看他的兴趣标签，如果也匹配就直接打招呼
- 在评论区接梗接龙，和同好聊开来甚至能直接组群
- 多人混战中用 @ 精准通知某个人，把话题拉回正轨

2.1.8 版本给评论区加了三大增强功能：**表情包、照片、@**。表情包让表达更轻松，照片让互动更生动（比如对方发了美食图你回复一张自己做的同款），@ 让多人讨论更有序。这三件事叠加起来，兴趣广场就从单向发布变成了真正的社区。

### 第四步：社区氛围的保护伞——真人审核

Qiz 的社区氛围好，很大程度上归功于它的审核机制。真人审核不是"实名认证"——不会让你填身份证号，也不会把真实姓名对外展示。它的核心是**让社区里的账号尽量都是真实的人**，而不是机器人、营销号、匿名骚扰号。

审核内容大致包括：

- 手机号验证防止批量注册
- 头像真实性审核（网图可能被拒绝）
- 简介质量审核（防止纯广告、纯灌水）
- 发帖和聊天内容的自动化审核（识别关键词、敏感词）
- 举报后的人工复核

如果被审核拒绝，常见原因是头像不是真人、简介涉及敏感词、发帖内容违规或被举报核实违规。修改内容后可以重新发布，误判的情况下可以联系客服申诉。

### 使用小贴士汇总

| 场景 | 建议 |
| --- | --- |
| 刚注册推荐为空 | 检查是不是标签没选够 3 个 |
| 匹配结果太泛 | 试试标签筛选，3~5 个精准标签 |
| 找不到话题 | 去兴趣广场评论区挖同好，比直接打招呼自然 |
| 账号被限制 | 检查头像和简介，避免敏感词，申诉要提供具体理由 |
| 想拓宽社交面 | 别加标签筛选，让系统自由推荐 |
