## ✨ Keeta 是什么

Keeta 是美团面向全球市场推出的即时配送平台，总部位于中国，当前主要覆盖香港、中东多个国家（巴林、沙特、卡塔尔、科威特、阿联酋）和巴西三大海外区域。作为全球最大外卖平台的出海产品，Keeta 把美团在中国市场每天处理超过 8000 万笔订单积累的整套能力体系——派单算法、配送预估、商家运营 SaaS 工具、质量保障机制——完整输出到境外市场，相比从零搭建的本地平台在技术投入上节省了数年时间。

相比 Deliveroo、Foodpanda、iFood、Rappi 等国际同行，Keeta 的差异化不只是"又一个外卖 App"。它同时运营无人机配送、企业团餐（Keeta for Business）、共享充电宝、开放 API 等多条延伸业务线，是目前海外外卖平台中业务覆盖最广的玩家之一。在市场选择上，Keeta 避开了竞争白热化的欧美和东南亚成熟市场，精准切入香港（文化最接近，作为出海试水）、中东（高消费、少竞争、客单价高）、巴西（拉美最大市场、单一 iFood 垄断有突破机会）三个消费力强、外卖渗透率仍在提升的区域。

本地化运营也是 Keeta 的关键策略——巴西用 Pix 支付和葡语界面，中东适配阿拉伯语和清真认证渠道，香港保留中文和本地茶餐厅分类，既保证全球技术栈的效率，又尊重本地用户习惯。

## 🔧 安装步骤

Keeta 主要面向移动平台，支持 Android 和 iOS。安装流程因平台略有差异，以下是通用步骤。

### Android 安装

1. **确认系统版本**：Keeta 要求 Android 7.0 及以上版本
2. **通过应用商店安装**：打开 Google Play，搜索 "Keeta"，确认开发者信息后点击安装
3. **非商店渠道安装**：如果所在区域 Google Play 受限，可从官方下载页获取 APK 安装包。安装前需进入手机「设置 → 安全 → 允许未知来源应用」开关授权
4. **首次启动**：安装完成后打开应用，授予位置权限、通知权限和相机权限（用于扫描取餐码）

> [!WARNING]
> 非官方渠道获取的 APK 存在安全风险，务必从正规来源下载。安装时如出现杀毒软件警告，需谨慎核对文件来源。

### iOS 安装

1. **系统要求**：iOS 13.0 及以上版本
2. **App Store 安装**：直接在 App Store 搜索 "Keeta"，点击获取安装
3. **区域限制处理**：如果当前 Apple ID 所在区域不支持 Keeta，可考虑切换商店区域或等待应用在更多地区开放
4. **首次启动**：打开应用后同样需要授予位置和通知权限

### 安装后的核对

- 检查应用图标和名称是否正确（Keeta，黄色主色调）
- 确认应用版本号与下载渠道公布的最新版本一致
- 启动后能正常加载首页商家列表，说明安装成功

## 📖 使用入门

安装完成只是第一步，下面从账号注册、核心功能、进阶玩法三个层面带你快速上手 Keeta。

### 账号注册与登录

Keeta 的账号体系有几个值得注意的特点：

**一个手机号只能注册一个账号**，不支持同一手机号多开。新人礼包通常只对全新账号开放，如想用新手机号重新注册，需要确认该手机号从未注册过 Keeta。

注册方式支持**手机号验证码**和 **Google / Apple 第三方账号**两种路径，但无论哪种方式，最终都要求绑定一个本地有效手机号——这是因为 Keeta 的订单通知、安全验证都依赖短信通道。如果你是中国大陆手机号，在香港、中东、巴西等海外市场可能无法正常接收短信，建议使用当地运营商号码。

> [!TIP]
> Keeta 不设传统密码，全程通过手机号验证码登录。验证码有效期通常为 60 秒，过期后点击「重新发送」即可，两次发送间隔至少 30 秒。如果长时间收不到验证码，优先检查短信是否被标记为垃圾短信。

### 下单流程：从点外卖到自取

**标准外卖配送**：打开首页后，顶部会根据你的定位推荐附近商家。进入商家后浏览菜单、加购商品、结算——和主流外卖 App 体验基本一致。结算页可以选择配送地址、支付方式和备注要求。Keeta 的派单算法会综合距离、骑手密度、天气、商家备餐时间给出较准确的送达预估时间（ETA），这是美团出海最核心的技术优势之一。

**到店自取（Self Pickup）**：这是 Keeta 的差异化功能之一，对于想省配送费、顺路经过商家的场景特别实用。自取和外卖用同一份菜单、同样的价格，唯一的区别是省去骑手配送环节——你直接到商家地址取餐。操作上，在首页顶部切换「外卖 / 自取」标签，列表就会自动过滤出支持自取的商家。结算页会显示自取时间预估和商家地址，到店后告知店员 "我是 Keeta 自取订单"，报订单号或出示取餐码即可。

| 对比维度 | 自取 | 外卖配送 |
| --- | --- | --- |
| 费用 | 商品原价 | 商品原价 + 配送费（有时为 0） |
| 时间 | 到店时间 + 备餐时间 | 备餐时间 + 骑手配送时间 |
| 食品新鲜度 | 直接从厨房取 | 骑手运输可能影响温度 |
| 适合场景 | 顺路、步行可达、想省运费 | 恶劣天气、不想出门、公司订餐 |

> [!NOTE]
> 自取服务并非所有商家都提供，商家需要主动开通。高峰期商家可能优先处理外卖订单，如果到店后等待超过 10 分钟，可以联系 Keeta 客服介入协调。

### 其他实用功能

**多支付方式**：Keeta 支持在账号里绑定多张信用卡或借记卡，巴西用户还可以使用本地 Pix 支付，中东市场支持当地主流支付渠道。结算时可自由选择任意一张已绑定的卡片。

**多设备登录**：同一个 Keeta 账号可以在多台手机上登录，订单、优惠券、钱包余额会自动同步。如果是多人共用场景（比如家庭或同事代付），这个设计很方便，但建议开启手机锁屏密码保护账号安全。

**优惠券与新人福利**：Keeta 进入新市场时补贴力度通常远大于本地平台，新人礼包金额高、推广期零配送费、零商家佣金，还会和本地明星或品牌联名活动快速建立认知。老用户也能通过分享、完成订单任务等方式持续获得优惠券。

**订单追踪**：下单后可以在应用内实时查看骑手位置、ETA 更新、商家备餐状态。Keeta 还提供「准时宝」服务——如果订单超时，系统会自动发放一定金额的优惠券作为补偿。

### 延伸业务探索

如果你不仅想点外卖，还对 Keeta 的其他业务感兴趣：

- **企业团餐**：通过 Keeta for Business，企业可以为几十人到上万人规模的员工群体提供定制化餐饮方案，支持 API 深度对接企业内部系统
- **开放 API**：SaaS 平台和开发者可以通过开放接口把 Keeta 的订单和菜单管理能力接入自有系统，适合餐饮 POS、企业订餐系统的服务商
- **共享充电宝**：Keeta 在部分市场的餐饮场景铺设了共享移动电源柜，如果你是线下商家，可能有机会成为场地合作方获得分成

这些延伸功能目前只在香港、巴林等部分市场逐步开放，具体以所在地区的实际情况为准。
