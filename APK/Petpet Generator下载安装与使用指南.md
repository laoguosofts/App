## ✨ Petpet Generator 是什么

Petpet Generator 是一款专门制作"摸头 GIF 表情包"的在线工具。把任意一张头像或图片传进去，它会自动生成一段循环播放的"被摸头"动画——圆滚滚的挤压感、随机变形的节奏，像一只小宠物被轻轻按脑袋的感觉。

这类动图最早在 Discord、Twitter 等海外社区流行，后来漂洋过海进了微信、QQ 群聊，现在已经是玩梗界的基础款表情素材。Petpet Generator 把整套制作流程做成了网页版，不用装任何软件、不用懂动效，拖一张图进去、调几个滑块，几秒就能出成品。

它的核心玩法很简单：上传素材图 → 选一个手型 → 调挤压速度和幅度 → 导出 GIF。但参数组合起来能玩出的花样不少——快速大挤压是"莫挨本喵"的抗拒感，慢速小变形是"招财猫猫"的喜庆感，换上兔兔、小丑、达摩等模板素材又是完全不同的味道。

适合谁用？群聊里常年找不到合适表情包的人、想给朋友做专属定制表情的人、做社区运营需要表情包素材的人，基本上只要你在任何聊天平台发过图，就能用得上。

## 📖 使用入门：从一张图到一个摸头表情

整个制作流程可以拆成四步：准备素材 → 上传 → 调参数 → 导出。下面按实际操作顺序走一遍，中间穿插能让成品效果变好的经验和技巧。

### 准备什么样的素材图最适合

正方形、主体居中的头像效果最好。如果图片比例太极端（比如长条屏截图或超宽全景图），上传后预览区域会自动裁剪或压缩，挤压变形也容易跑偏。建议先用手机相册里随便一张自拍或宠物照试试，有感觉了再换更精致的素材。

支持的格式包括 PNG、JPG、JPEG 和 WebP。GIF 动图也能传，但工具只会取 GIF 的第一帧做素材，不会把动图本身继续套新动效——这一点很多初学者踩过坑。

### 上传图片的三种姿势

上传是整个流程唯一需要点操作的环节，有三种方式，各有适用场景：

- **本地文件选择**：点击"Choose File"从文件管理器挑图。最稳、成功率最高，99% 的情况一次就成。适合已存好的头像、之前下载的图片。
- **拖拽上传（网页版专属）**：直接把图片文件拖进网页的上传区域。网页版最顺手的方式——开网页、拖图、直接开始调参数，全程不用点按钮。
- **粘贴图片 URL**：粘一个图片网址让工具自己去取。这是最不稳定的方式，很多网站有盗链保护会返回空图或 403。粘了没反应就别反复试同一个链接，说明那个网站禁外链，存到本地再用文件选择上传就行。

| 异常现象 | 常见原因 | 解决办法 |
| --- | --- | --- |
| URL 粘贴后一直空转 | 源站禁外链 | 下载到本地再用文件选择 |
| 文件选择按钮点了没反应 | 格式不支持 | 检查是不是 PNG/JPG/WebP |
| 上传后图片被拉得很扁 | 原图比例太极端 | 先剪成方形再上传 |
| 预览区域全黑 | 图片文件损坏 | 换一张图重新来 |

### 调参数：四个旋钮决定最终效果

图片传上去之后，参数面板会显示几个可调节的核心值。不用一开始就追求"完美参数"——先拉一遍每个滑块、感受一下变化规律，再往想要的方向微调。

**挤压幅度（squish）**：决定图片被按下去的程度。数值大 = 挤得狠、反差感强；数值小 = 轻轻按一下、偏温和。做"莫挨本喵"那种抗拒感的表情就往大了拉，做"招财猫猫"那种喜庆可爱的就控制在中间值。

**动画速度（speed）**：决定循环的节奏。快节奏 = 跳脱、有冲击力；慢节奏 = 优雅、舒缓。喜庆场景（生日、升职）建议中等偏快，吐槽场景（别烦我、无语）可以拉到最快。

**输出尺寸（output size）**：决定导出 GIF 的像素大小。这个值直接关系到文件体积——尺寸越大、帧数越多，GIF 文件越大。

> [!TIP]
> 发微信表情栏的话 output size 选 128px 以内最保险，超过 2MB 的 GIF 会被微信自动压成静态图，很多人做好了却发不出去就是卡在这里。Discord 免费用户建议 256px 以内，微博和小红书控制在 200px 以内。

**手型选择**：决定"摸头"用什么手。默认是最常见的人手，还可以换成猫爪、拳头等。换个手型能让同一个素材的效果完全变味——猫爪摸招财猫比人手摸更搭，拳头摸"莫挨本喵"多了一层暴力反差。

### 热门模板库：一键加载省时省力

如果从零调参数觉得麻烦，可以去模板库逛一圈。模板是官方预调好的参数组合 + 自带示例素材，点开之后预览区立刻显示效果、参数面板也自动调成模板对应的数值。比较火的几个模板：

- **招财猫猫**：圆滚滚的招财猫被摸头，中等速度、适中挤压。过年、生日、开店等喜庆场景首选。
- **莫挨本喵**：瞪着人的黑白猫被强行摸头，高速大挤压。用来吐槽"别烦我"特别合适，反差感拉满。
- **狂喜兔兔**：蹦蹦跳跳的兔子，节奏轻快、挤压适中。考试过了、升职加薪、游戏通关这类庆祝场景。

模板的用法很简单：在模板库浏览 → 点进去加载 → 直接导出，或者在模板基础上换自己的素材、调参数、换手型再导出。好处是省时间、有现成的"手感"可以参考，不会出现"参数组合出来效果很奇怪"的情况。

### 导出：点一次按钮就完事

参数调好后，找到面板里的"Export"或"下载"按钮点一下，GIF 文件立刻生成并开始下载。网页版会弹出浏览器的下载框，默认存到 Downloads 目录；安卓版保存到相册或应用输出目录，部分机型需要手动选"保存到相册"。

导出后建议做两件事：

1. **先发给自己测试**：发到自己的微信/QQ/任何聊天窗口，确认 GIF 还在动、没有被压成静态图。
2. **不满意就重做**：生成免费又快，参数改一下重新导出就行。不用心疼"好不容易调好的版本"——reset 重来反而是常态。

### 跨平台分享的坑

不同聊天平台对 GIF 的限制差异很大，发之前务必自测。核心问题永远是体积——文件越大越容易被压成静态。如果发现"导出后发到群里不动了"，按这个顺序排查：

1. 把 output size 从 256px 降到 128px
2. 降低 speed（帧数减少 = 文件变小）
3. 降低 squish（变形程度降低 = 每帧更简单 = 压缩率更高）
4. 以上都试过还是太大，用第三方 GIF 压缩工具压一下
