## ✨ Breeze：开源跨平台的统一漫画阅读入口

Breeze 是一个基于 Flutter 开发的开源第三方漫画客户端，它的核心理念很朴素——把你追的所有漫画平台装进同一个 App。和 Tachiyomi、Cimoc 等同类开源阅读器相比，Breeze 的跨平台覆盖更广（Android、iOS、Windows、macOS、Linux、鸿蒙通吃），插件体系基于云端分发的插件商店而非本地文件导入，更强调登录各平台的原有账号，不用在客户端里做本地存储为主的离线管理。

这个项目完全免费开源，不包含任何广告位，也不收集用户数据用于追踪——这是开源项目的核心承诺。代码任何人都可以审计，网络请求走的是各漫画平台的官方接口，本地数据受操作系统安全机制保护。如果你同时追着好几个漫画平台、不想装一堆 App，或者在意开源透明、反感广告和追踪，Breeze 正好踩在这些需求点上。开发者也可以自己写插件扩展漫画来源，整个社区一直在迭代更新，版本节奏比较密集。

## 🔧 安装步骤

Breeze 的安装在不同平台上体验差异挺大，挑你用的那台设备对着来就行。

### Android

1. 从下载页拿到 APK 文件，传到手机或直接用浏览器下载。
2. 如果首次安装第三方 APK，系统会弹出「未知来源」警告——去设置里给当前浏览器或文件管理器授予「安装未知应用」权限。
3. 安装完成点击打开，首次启动会依次请求通知权限、存储空间访问和网络访问。**存储空间权限必须允许**，否则下载的漫画章节没法离线保存；通知权限可选，关掉就收不到新章节更新提醒。

> [!WARNING] 务必核对 APK 的版本号和哈希值——开源项目每次发版都会在 Release 页附上校验和，别装来路不明的二次打包版本。

### iOS

iOS 不允许直接安装第三方 App，需要用侧载工具。主流方案有三个：AltStore（免费，需要开发者账号）、Sideloadly（界面友好，支持免账号临时签名）、TrollStore（利用系统漏洞实现永久安装，仅限特定 iOS 版本）。任选其一，按工具说明把 Breeze 的 IPA 文件签名后装到手机上即可。

### Windows / macOS / Linux

桌面端的安装都比较省心：Windows 下载安装器一键走完；macOS 要么用 `brew install --cask breeze` 一行命令搞定，要么下 DMG 拖进 Applications；Linux 用户可以从 Flathub 装 Flatpak 包，或者用 Debian/Ubuntu 的 DEB 包。

### 鸿蒙

鸿蒙系统可以直接尝试安装 Android APK，如果出现兼容性问题，用 GSpace 这类兼容容器也能跑起来。

## 📖 使用入门

装完打开 Breeze，主界面底部固定三个标签：**书架**、**发现**、**更多**。右上角始终有搜索图标，可以在已安装插件内搜漫画。第一次打开书架是空的，插件也没装——别慌，跟着下面三步走就能跑起来。

### 第一步：装插件

这是 Breeze 和同类阅读器最大的不同点。打开「发现」标签，点击顶部「插件商店」入口，里面按名称或作者列出了所有漫画来源插件。找到你常用的平台（比如哔咔、禁漫天堂），点「下载」安装。安装完成后回到插件管理页，把开关打开启用。插件商店是云端分发的，不用手动找 apk 文件导入，也不会扫你手机里的本地目录。

> [!TIP] 插件商店打开一片空白？先检查网络连接，其次确认 Breeze 版本是否过旧——老版本可能拉不到最新的插件列表。

### 第二步：登录账号

插件装好之后进「更多」标签，在已启用的插件区域找到对应来源，点登录按钮用你在那个平台的**原有账号**登录。Breeze 不创建新账号，它只是个客户端。这里也是新手最容易懵的地方——很多人在插件商店里瞎找登录入口，其实登录只在「更多」标签的插件管理区域里。

### 第三步：开始追漫

登录成功后回到发现页或者直接在书架里浏览，点漫画封面或标题进入详情页，可以预览内容、加入收藏、下载章节。书架默认三个 Tab：收藏、历史、下载，右下角有个来源切换图标，点一下能切换到不同的插件来源——不过每个来源的收藏、历史、下载都是各自独立的，切换只是换了个视图。

### 书架管理进阶

收藏列表一旦超过一屏，文件夹分类就很有必要。Breeze 支持在收藏页长按空白处新建文件夹，拖拽漫画条目进去，文件夹还能嵌套，每个文件夹单独排序。分类思路可以按阅读优先级（在追 / 完结待补 / 老漫回味）、按来源（哔咔收藏 / 禁漫收藏），或者按题材。

追更未读功能从 v3.0.30 引入，收藏页默认按更新时间排序，刚更新的漫画自动排最前，配合小红点标记一眼就能看到。如果某部漫画更新了但你暂时没兴趣，手动点「已读」清掉小红点就行。v3.0.34 还加了「未读汇总」页，把所有有未读的漫画集中到一处，每次打开先刷一遍更新很高效。追更完一大波之后，「全部已读」一键清掉所有小红点。

书架还有两个细节值得提：一是 v3.0.24 引入的「默认 Tab + 排序记忆」，可以设置每次打开书架默认落在哪（推荐收藏），同时记住上次用的排序方式（推荐按观看时间，比按更新时间更能反映你的真实阅读行为）；二是 v3.0.25 起点漫画封面可以直接开始阅读，跳过详情页，这个小改动让追更效率高了一截。

### 阅读体验与进阶设置

Breeze 的阅读器流畅度是它的核心竞争力。从 v3.0.27 起新增了几个实用设置：

- **预加载图片**：可以设置翻页前提前加载当前页之后的 N 张图片（建议 3-5 张），翻页不会白屏等网络。预加载过多占内存和带宽，过少翻页卡顿，找个平衡点。
- **预加载章节**：追更连载中漫画时，让 Breeze 自动把刚更新的下一章提前缓存到内存，和图片预加载配合起来连续追更体验很丝滑。
- **自动翻页**：可以配置翻页间隔（2-10 秒）、翻页方向（跟随全局或独立配置），v3.0.27 起还能关掉暂停键，真·解放双手。音量键翻页也支持，把自动翻页和物理按键配合起来。
- **SOCKS5 代理**：在设置里配置一次 SOCKS5 代理地址，所有插件的网络请求都走代理——国内用户配合「更新下载加速」开关一起用，插件下载速度会明显提升。
- **屏蔽关键词**：添加关键词后，搜索结果和发现页中包含该关键词的条目会被自动过滤，适合过滤不想看的题材或常见广告关键词。

主题方面有三种模式可选：跟随系统、浅色主题、深色主题。v3.0.33 优化了深色/浅色切换逻辑，夜间用深色主题比较护眼。还有个动态取色开关，开启后 Breeze 会根据当前漫画封面的颜色，动态调整状态栏和进度条的颜色，视觉上更协调。

> [!NOTE] v3.0.32 起可以给**单部漫画**设置独立的阅读参数——某部漫画用双页横版、其他用默认竖版；某部关闭超分、其他开启；某部用从左到右翻、其他用从右到左。独立设置在漫画详情页找入口，优先级高于全局设置。这个功能对习惯不同漫画不同读法的人来说是刚需。

### 常见误区

最后提几个新手最容易踩的坑：书架空不是坏了，是没装插件或没启用没登录；插件商店空白先查网络和版本；登录入口在「更多」标签的插件区域，不在插件商店里；每个来源的收藏、历史、下载都是独立的，切换来源不会丢数据只是换视图。
