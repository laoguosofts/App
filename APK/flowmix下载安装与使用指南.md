## ✨ Flowmix 是什么——一款面向全场景的全局 EQ 工具

Flowmix 是一款运行在 Android 平台上的全局均衡器应用。它的定位并不是"又一个播放器"，而是**系统级的音频后处理层**——在任何音乐、视频、游戏声音输出之前，先经过 Flowmix 的 EQ 链路进行校正和润色。

它的核心能力可以归纳为三件事：**频响拟合、精细调音、多设备管理**。

频响拟合方面，FlowEq 模块内置了 Realab 等公共耳机测量数据库，你只需选好自己的耳机型号和目标曲线（常见的有 Harman IE、ReaLab Target 等），点一下就能自动生成一条 PEQ 或 Raw 格式的均衡器配置，省去了逐频点手动调整的繁琐。

精细调音方面，Flowmix 同时提供四种调节入口：PEQ 调节器（可视化拖拽控制点）、127 段 Raw 调节器（精确到 0.1dB 的全频段微调）、EQ 强度控制（整体或分频段灵活混合）、Int 向导调节器（六步问答式傻瓜调音）。配合 ISO 226 等响补偿和声道平衡，足以覆盖从普通听歌到耳机发烧友的全部需求。

多设备管理方面，每副耳机、每个蓝牙音箱都能绑定独立的 EQ 配置，切换设备时自动加载；登录 YKload 账号后还能云端同步，换机时一键恢复所有配置。

从用户画像来看，Flowmix 覆盖了四类典型人群：追求频响平直的耳机发烧友、只想让声音好听一点的普通音乐爱好者、需要听声辨位的 FPS 游戏玩家、以及有多副耳机多台设备的音频爱好者。免费版已经包含了大部分核心功能，四种调节器和云同步全部可用。

## 🔧 安装步骤与首次授权

Flowmix 以 APK 形式分发，安装过程和普通 Android 应用类似，但有几个注意点值得留意。

**第一步：准备安装**

先到下载页面获取最新版的 APK 文件，建议下载完成后核对一下文件大小和版本号，避免下到旧版本或残缺文件。Flowmix 的安装包体积在 20MB 左右，如果你的文件明显偏小，大概率是下载不完整，建议重新下载。

**第二步：安装与权限授权**

1. 在手机文件管理器中找到下载好的 APK，点击安装
2. 如果系统提示"未知来源安装被禁止"，需要进入系统设置，临时允许当前文件管理器的安装权限
3. 安装完成后首次打开，Flowmix 会引导你授予两项关键权限：
   - **音频设置权限**：这是 EQ 生效的前提，必须授予
   - **通知权限**：用于显示 EQ 开关状态和配置提示

> [!WARNING]
> 音频设置权限是 Flowmix 的核心依赖。如果跳过这一步或后续被系统回收，EQ 链路不会接通，你会发现"开了但没效果"。这是排查 Flowmix 不生效的第一站。

**第三步：验证 EQ 是否真的在干活**

很多人装完打开就去调参数，然后一脸懵地问"为什么没变化"。这里推荐用三种方法交叉验证：

1. **EQ 强度 0% 和 100% 对比**：底栏中央的 Flow 开关保持 ON，把 EQ 强度滑块从 0 拉到 100，播放同一首歌反复切换
2. **Flow ON / OFF 切换**：直接点底栏中央的大按钮，声音应该立刻有明显差异——典型反馈是 ON 之后声音变"收"了、某些频段被削了
3. **极端 EQ 测试**：用 Raw 调节器把 200Hz +10dB、10kHz -10dB，这个极端设置下还没变化的话，基本可以确定权限没开或有冲突

> [!NOTE]
> 如果三种方法都没检测到差异，按以下顺序排查：确认底栏按钮显示「Flow ON」→ 确认 EQ 页面选中了一条配置 → 检查系统音效是否设为原音模式 → 关闭 Wavelet、Poweramp Equalizer 等其他 EQ App 的控制权 → 重启 Flowmix。

## 📖 使用入门——从一键拟合到精细调音

Flowmix 的使用路径可以粗分为两种：**走 FlowEq 一键拟合**（推荐初学者和发烧友）和 **走 Int 向导 / FlowAI**（推荐只想让声音好听的用户）。不管走哪条路，最后都会落到 EQ 强度和四种调节器的配合上。

### 路线一：FlowEq 一键拟合（发烧友首选）

这是 Flowmix 最有价值的功能，整个流程只需一分钟：

1. 打开 FlowEq 模块，在耳机数据库里选择你手头那副耳机的型号
2. 选择一个目标曲线——Harman IE 是比较通用的选择，ReaLab Target 则更偏向追求平直频响的用户
3. 选择拟合输出格式：PEQ 拟合生成 ≤20 个参数均衡器滤波器，方便后续手动微调；Raw 拟合直接生成 127 段全频段 EQ，精度最高但调整略复杂。**第一次拟合建议先用 PEQ**，方便看清 FlowEq 到底改了哪些地方
4. 拟合完成后，切到 EQ 页面，先把强度调到 70%~80% 试听——很多时候 FlowEq 给的结果"理论正确但听感过激"，整体降一点比单点修改更自然

> [!TIP]
> PEQ 拟合和 Raw 拟合可以随时互转。Flowmix 内部所有调节器最终都会转成 Raw 格式，所以拟合完之后随时可以切换调节器继续编辑，不存在"选错了就得重来"的问题。

### 路线二：Int 向导与 FlowAI（零门槛上手）

如果你对 EQ 参数完全没概念，Flowmix 提供了两条快捷路径：

- **Int 向导调节器**：跟着六步问答走，在"低音 vs 高音""鼓点 vs 节奏""人声靠前 vs 器乐靠前"之类的对比中选出你喜欢的声音，全程不需要懂 EQ 参数
- **FlowAI 智能调音**：登录 YKload 账号，一键让云端 AI 分析优化你当前的 EQ 配置。适合调了半天还是觉得"差点意思"的用户

五分钟搞定之后，用 EQ 强度滑块控制效果深浅就行，简单直接。

### 四种调节器怎么配合用

Flowmix 的四种调节器不是互斥的，而是按"拟合 → 微调 → 混合"的顺序串联使用的：

| 调节器 | 定位 | 适合场景 |
|---|---|---|
| FlowEq | 一键拟合入口 | 拿到一副新耳机时快速生成初始配置 |
| PEQ 调节器 | 可视化拖拽微调 | 对某些频段不满意，想精确拉一个控制点 |
| Raw 调节器 | 127 段精细编辑 | PEQ 拟合后还有细节想抠，或者完全手动从 0 开始调 |
| Int / FlowAI | 傻瓜调音 | 不想折腾参数，只想快速得到好听的声音 |

### EQ 强度：别让拟合结果白跑了

EQ 强度控制的是"拟合出来的配置到底应用多少"——0% 等同于关闭 EQ，100% 全额应用，中间值是两者之间的插值。Flowmix 提供两种调节模式：

**整体模式**：一个滑块管全部，适合快速调整整体效果深浅、或者想在两条配置之间"插值"（比如 Realab Target + 80% 强度 ≈ Harman IE 风格）。

**分频段模式**：把全频段分成七个经典频段，每个可以单独设强度——低频太轰就把低频频段降到 50%，高频太扎就把明亮度频段单独降到 60%，非常灵活。

推荐的尝试顺序：先用整体模式从 80% 开始试 → 如果某一侧还是过，用分频段模式单独降那一侧 → 微调 ±5% 找到甜蜜点。

### 游戏玩家的专属用法

如果你用 Flowmix 配合吃鸡、FPS 类游戏，重点关注两个功能：

- **PEQ 针对性频段提升**：2kHz~6kHz 是人声、脚步声、金属撞击声的主要分布频段，把这段提升 3~6dB，同时把低频（20~250Hz）降低 2~4dB，可以让敌人的位置判断明显清晰
- **声道平衡**：如果左右耳机单元音量有差异，或者单侧听力稍弱，可以单独调整某一侧的增益

注意部分游戏启用"低延迟音频模式"后会绕过系统层处理，Flowmix 可能无法生效，遇到这种情况建议关闭游戏内的特殊音频模式。

### 多设备用户的云同步

Flowmix 最省心的功能之一：每副耳机、每个蓝牙音箱都能绑定独立的 EQ 配置，切换设备时自动加载。换新手机时登录同一个 YKload 账号，所有配置一键恢复，不需要重新调。速颜分享功能还能让你把朋友调好的 EQ 一键导入试用——别人调出来的好听配置，你也能直接拿来听。
