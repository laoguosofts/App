## ✨ Sam Helper 是什么

Sam Helper 是一款专为三星设备打造的系统增强工具，凭借无需 Root 即可实现丰富系统级操作的特性，在三星用户群体中广受欢迎。它集成了设备信息查询、系统设置调整、Good Lock 模块管理、网络模式切换等实用功能，帮助用户绕过三星系统的封闭限制，对手机进行更精细的个性化配置。

这款应用的核心设计理念是**安全无熔断**——通过 Shizuku、ADB 等授权方式获取系统写权限，全程不触碰 Knox 安全熔断机制，让用户既能享受深度定制的乐趣，又不必担心失去官方保修和 Samsung Pay 等依赖 Knox 的服务。

无论你是想修改屏幕分辨率和 DPI 来获得更舒适的显示效果，还是需要快速切换 5G/4G 网络模式以平衡速度与续航，Sam Helper 都能提供直观的操作界面和一键式解决方案。它尤其适合那些喜欢折腾系统、追求极致使用体验的三星 Galaxy 系列用户。

## 🔧 Sam Helper 安装与授权指南

### 安装前的准备

在开始安装之前，你需要确认设备型号和系统版本。Sam Helper 支持绝大多数三星 Galaxy 系列机型，但部分冷门地区版本可能存在兼容性问题。建议保持系统为官方固件，避免在 Root 或刷过第三方 ROM 的设备上使用。

### 安装步骤

1. 从下载渠道获取 APK 安装包后，使用文件管理器找到并点击安装
2. 如果系统提示「未知来源」，请在设置中允许来自该文件管理器或浏览器的安装权限
3. 等待安装完成，首次启动 Sam Helper

### 首次授权要点

Sam Helper 首次启动时会依次请求多项权限，以下是各项权限的用途和授权建议：

| 权限类型 | 用途 | 是否必需 |
|----------|------|----------|
| 存储访问权限 | 读取写入文件、提取 APK、操作 Android/data 目录 | ✅ 必需 |
| 应用列表访问 | 读取已安装应用、Lock & Labs 管理 | ✅ 必需 |
| 无障碍服务 | 系统设置修改、自动化操作 | 推荐开启 |
| Shizuku 授权 | 分辨率、刷新率等高级功能的系统级写权限 | 高级功能必备 |

> [!TIP]
> 建议首次启动时尽量授予全部权限，避免后续使用高级功能时反复跳转设置页面。权限被拒绝后想重新授予，可以进入「设置 → 应用程序 → Sam Helper → 权限」手动开启。

### Shizuku 的配置

Shizuku 是 Sam Helper 实现无 Root 高级功能的核心组件。它通过 ADB 调试协议获取系统级写权限，整个过程安全可控，不会触发 Knox 熔断。配置 Shizuku 需要用 USB 数据线连接电脑，执行 ADB 授权命令，首次配置成功后即可保持持久生效。

## 📖 Sam Helper 使用入门

### 快速查看设备信息

打开 Sam Helper 后，首页会展示设备的核心信息概览，包括型号、Android 版本、One UI 版本、电池状态等。进入「关于手机」页面可以查看更详细的硬件参数，其中 Knox 状态是值得重点关注的一项。

#### Knox 状态解读

Samsung Knox 是三星的企业级安全平台，从芯片级到应用层构建了多层防护。设备的 Knox 状态决定了安全等级：

| 状态 | 含义 | 对使用的影响 |
|------|------|--------------|
| Normal / Official | 官方状态 | 全部功能正常，保修有效 |
| Custom | 自定义状态 | Root 或刷过第三方 ROM，部分安全应用可能受限 |
| Warranty Void | 保修失效 | 已触发 Knox 熔断，**不可逆**，失去官方保修和 Samsung Pay 等依赖 Knox 的服务 |

> [!WARNING]
> Knox 熔断一旦触发无法恢复。Sam Helper 的所有功能都不会触发 Knox 熔断，这也是它相比 Root 方案最大的优势。日常使用中要避免刷第三方固件、谨慎使用可能修改系统分区的模块。

### 调整屏幕显示参数

Sam Helper 最受欢迎的功能之一是修改屏幕分辨率和 DPI。进入「系统设置 → 显示」相关选项，可以自定义分辨率、刷新率、动画速度等参数。

#### 修改分辨率的实用技巧

1. **开启锁定比例**——这是最关键的安全措施，防止宽高比严重失衡导致黑屏
2. **幅度控制在原生分辨率的 20% 以内**——过于激进的调整容易超出硬件支持范围
3. **修改后不要立刻杀掉 Sam Helper 进程**——保持后台运行以便在出现问题时触发紧急恢复

#### 黑屏应急恢复方案

如果分辨率修改后出现黑屏、触控失灵等紧急情况，按以下优先级尝试恢复：

**方法一：Sam Helper 按键重置（首选）**
确保 Sam Helper 还在前台运行，长按音量减键 3-5 秒即可触发紧急恢复，即使屏幕完全黑屏也能生效。

**方法二：ADB 远程恢复**
用 USB 数据线连接已安装 ADB 的电脑，执行两条命令即可恢复默认显示：

```
adb shell wm size reset
adb shell wm density reset
```

**方法三：安全模式**
长按电源键 → 长按关机图标 → 安全模式。安全模式下第三方应用被禁用，分辨率自动恢复默认。

**方法四：系统设置重置**
进入「设置 → 常规管理 → 重置 → 重置所有设置」，这会重置包括分辨率在内的所有系统设置，但不会删除用户数据。

### 网络模式一键切换

在「系统设置 → 移动网络模式」中，Sam Helper 提供了五种网络模式供选择：

| 模式 | 适用场景 |
|------|----------|
| 5G/4G/3G/2G 自动 | 日常使用推荐，智能选择最快信号 |
| 4G/3G/2G 自动 | 跳过 5G，想省电且不需要 5G 时 |
| 4G 仅 | 信号好且追求稳定性时锁定 LTE |
| 3G 仅 | 偏远地区可能 3G 覆盖更好 |
| 2G 仅 | 极端省电场景，基本不能上网 |

> [!NOTE]
> 5G 网络在相同信号强度下比 4G 多耗电 15-30%。如果你主要在 Wi-Fi 下使用手机，或所在区域 5G 信号覆盖差，切换到 4G/3G/2G 自动模式可以有效延长续航。部分运营商的网络模式由 SIM 卡锁定，这不是 Sam Helper 的问题。

### Good Lock 模块管理

Sam Helper 集成了 Good Lock 的快速管理入口，可以一键启用或禁用各个模块，无需打开 Good Lock 应用本身。对于喜欢折腾三星自定义套件的用户来说，这是一个非常方便的快捷入口。

### 进阶使用建议

- 首次接触 Sam Helper 时，先熟悉设备信息查询和网络模式切换等低风险功能
- 分辨率修改涉及显示层，务必按照安全操作指引进行，并保持 ADB 连接电脑作为保底手段
- Shizuku 授权的高级功能是 Sam Helper 的灵魂，花半小时配置好 Shizuku 能解锁大部分实用特性
- Sam Helper 的常规操作都在系统允许的边界内进行，不会影响 Knox 状态，这是它最值得信赖的一点
