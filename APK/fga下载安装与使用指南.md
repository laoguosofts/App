## ✨ FGA 是什么

**FGA（Fate/Grand Automata）** 是一款专为 Fate/Grand Order（FGO）玩家打造的 Android 自动化工具，它基于 Android 官方无障碍服务 API 实现——不需要 root 权限就能在后台代替用户完成战斗循环、技能释放、换人服切换、狗粮投喂、技能升级等重复性操作，让日常 Farming、刷活动、从者强化等流程彻底解放双手。

FGA 的核心定位很明确：它**不修改游戏数据**、不注入任何破坏性脚本，而是通过系统正常的输入事件模拟来完成操作——本质上就是让手机自己"按正确节奏点屏幕"。这种设计意味着它的权限范围非常受限，安全性比许多同类工具更高。

适合人群：每天需要花大量时间在 FGO 里刷本、想把碎片时间利用起来、或者同时养多个账号的玩家。

## 🔧 安装与权限配置

### 安装包基本信息

FGA 是 Android 应用，安装前需要确认：

| 项目 | 说明 |
|---|---|
| 平台 | Android 7.0+ |
| 体积 | 约 15~20 MB |
| 权限 | 无障碍服务（核心）、悬浮窗、存储访问、电池优化白名单 |
| 服务器 | 日服 / 美服 / 国服 / 台服 / 韩服（首次启动时选择） |

### 安装步骤

1. 从下载页获取 APK 安装包，拷贝到手机存储
2. 打开 APK 时如果提示"未知来源安装被阻止"，进入系统设置 → 安全 → 开启"允许安装未知来源应用"（部分 ROM 在应用管理里单独授权）
3. 安装完成后，首次启动会进入 **Onboarding 引导流程**，语言选择是第一步
4. 找到"简体中文"并点击确认，后续引导和应用界面就全部是中文了

> [!TIP]
> FGA 的界面语言和 FGO 游戏服务器是**两个独立设置**——可以界面用中文、玩日服 FGO，互不影响。语言偏好会被写入系统 SharedPreferences，下次启动自动记住。

### 核心权限配置

引导流程会依次引导配置三个关键权限，**任何一个没配对都会导致 FGA 无法正常工作**：

#### 1. 无障碍服务（TapperService）——最核心的权限

无障碍服务是 FGA 能"帮你点屏幕"的基础，开启步骤：

1. 在引导的"无障碍服务"步骤点击"打开设置"
2. 系统跳转到无障碍设置页面，找到 **"Fate/Grand Automata"**
3. 点击进入，将开关切换到"开启"，系统弹窗确认时点"允许"
4. 返回 FGA，引导继续

> [!WARNING]
> **无障碍服务容易被系统自动关闭**，这是 FGA 用户最常见的问题。如果运行中突然不工作了，第一反应就是检查无障碍开关。

#### 2. 电池优化白名单

几乎所有国产 ROM 都会把无障碍服务纳入电池优化范围，后台运行一段时间后就会被系统杀掉。解决办法：

| ROM | 路径 |
|---|---|
| MIUI / 红米 | 安全中心 → 授权管理 → 自启动管理 → 给 FGA 开自启动 |
| EMUI / 鸿蒙 | 手机管家 → 应用启动管理 → 把 FGA 设为"自动管理" |
| One UI（三星） | 设置 → 应用 → FGA → 电池 → 允许后台活动 |
| 其他原生 Android | 设置 → 电池 → 电池优化 → 找到 FGA → 设为"不优化" |

#### 3. 悬浮窗权限

悬浮按钮是 FGA 的操作入口——没有它你没法启动脚本。引导流程会跳到对应设置页面，找到 FGA 并允许显示悬浮窗即可。

### 权限边界说明

FGA 的无障碍服务**只做两件事**：

- 在屏幕特定坐标执行点击/滑动/长按
- 读取当前前台应用的包名（判断是不是 FGO、是哪个服）

它**不会**读取密码、聊天记录、通讯录等隐私数据，也不会拦截用户操作或修改任何应用数据。

## 📖 FGA 核心功能使用指南

### 战斗自动化——技能制作器 Skill Maker

这是 FGA 最核心的功能：把一场战斗需要释放的技能序列编成指令，然后让 FGA 在战斗循环中自动执行。

#### 从者技能编码

FGA 用 9 个小写字母 **a~i** 对应队伍中 3 个从者 × 3 个技能：

| 从者位置 | 技能 1 | 技能 2 | 技能 3 |
|---|---|---|---|
| 1 号位 | a | b | c |
| 2 号位 | d | e | f |
| 3 号位 | g | h | i |

每个技能还可以加数字表示目标位置（己方 1/2/3 或敌方 1/2/3），比如 `a1` 表示释放 1 号位从者的技能 1、目标己方 1。

#### 御主技能编码——j / k / l

御主技能是独立于从者技能的另一组按钮，编码用 **j、k、l** 三个字母：

| 编码 | 对应 | 说明 |
|---|---|---|
| j | 御主技能 A | 随换人服变化（初始换装 = NP 充能） |
| k | 御主技能 B | 初始换装 = 加攻击 |
| l | 御主技能 C | 初始换装 = 换人 |
| n | 独立换人按钮 | 格式 `n<起始位><替补位>`，如 `n12` |

> [!NOTE]
> 御主技能的含义**随换装切换而改变**——换了战斗制服、魔术协会制服等，j/k/l 对应的技能就完全不同了。写指令时一定要清楚自己用的是哪个换装，建议按换装名称分开保存战斗配置。

#### 换人服换人操作（n 编码）

换人是御主技能 C 的特殊用法，Skill Maker 提供了独立的换人按钮，编码格式为 `n + 起始位 + 替补位`：

- `n12` = 首发位置 1 换出去，替补位置 2 换进来
- `n21` = 首发位置 2 换出去，替补位置 1 换进来

> [!WARNING]
> 换人服每次战斗**只能用一次**，用完三个御主技能全部进入冷却。Skill Maker 不会阻止你在同一战斗里加两次换人，但运行时会失败。正确做法是把换人放在技能序列最后，换人后再释放替补从者的技能。

#### 指令序列示例

用一个完整例子理解所有编码组合：

```
a1 → j1 → b2 → n12 → g1 → g2 → t1 → 0
```

**逐条解读**：
1. `a1` —— 放 1 号位从者的技能 1，目标己方 1
2. `j1` —— 放御主技能 A（初始换装 = NP 充能），目标己方 1
3. `b2` —— 放 1 号位从者的技能 2，目标己方 2
4. `n12` —— 换人：首发 1 换替补 2
5. `g1` / `g2` —— 替补进来的从者（原 3 号位）的技能 1 和 2
6. `t1` —— 选敌方 1 为目标
7. `0` —— 释放宝具并攻击

### 从者自动强化——Servant Enhancement

除了战斗自动化，FGA 还提供了从者自动强化脚本，可以在战斗循环的间隙自动完成狗粮投喂、技能升级、追加技能升级等操作。

#### 两种触发模式

| 模式 | 说明 | 适用场景 |
|---|---|---|
| **战斗循环中自动触发** | 检测到 EXP 槽快满 / 技能没满 / 材料充足时，自动暂停战斗 → 强化 → 回到关卡菜单 → 继续 | 日常长期 Farming 循环 |
| **手动单独运行** | 战斗停止后（AP 用完、礼物箱空了）手动启动，集中强化所有从者 | 新抽到从者快速升级、活动结束后集中强化 |

#### 自动强化能做什么

| 功能 | 标准 FGA | Preview Build |
|---|---|---|
| 自动喂狗粮（EXP 槽快满时） | ✅ | ✅ |
| 自动升技能 | ✅ | ✅ |
| 自动升追加技能 | ❌ | ✅ |
| 自动升礼装 | ❌ | ✅ |
| 礼装 EXP 炸弹批量升级 | ❌ | ✅ |

#### 配置参数

启动自动强化脚本后可以调整以下参数：

- **狗粮优先级**：3 星先喂 / 2 星先喂 / 按效率喂（默认按效率）
- **升技能优先级**：战斗配置里用到的技能优先
- **QP 保留值**：强化前至少保留多少 QP，防止花光影响日常（默认 1000 万）
- **自动升追加技能**：Preview Build 专属开关

#### 实战场景

一个典型的战斗 + 强化全自动循环：

```
跑了 50 轮日常 Farming
  ↓
FGA 检测到阿拉什 EXP 快满 + 技能没满
  ↓
自动暂停战斗，返回主界面
  ↓
进强化界面，喂狗粮到满级，升技能 1
  ↓
QP 检查通过，返回关卡菜单
  ↓
继续战斗循环
```

> [!TIP]
> 自动强化和战斗脚本是**单线程串行执行**的——战斗循环中触发强化会先暂停战斗、做完强化再继续，不会冲突。

### 无障碍服务常见故障排查

无障碍服务是 FGA 的命脉，但也是最容易出问题的地方：

| 症状 | 可能原因 | 解决办法 |
|---|---|---|
| FGA 悬浮按钮点了没反应 | 无障碍服务被系统杀掉 | 去无障碍设置重新开启 + 检查电池优化 |
| 运行 10~30 分钟后自动停 | ROM 后台限制 | 加白名单 + 部分 ROM 需要手动锁定无障碍服务 |
| 系统更新后失效 | 无障碍被重置 | 手动重新开启，不行就重启手机 |
| 反复自动关闭 | Android 11/12/13 系统 bug | 关闭 → 重新开启，或升最新补丁等待 FGA 适配 |

### 标准 FGA vs Preview Build

Preview Build 是 FGA 的预览版本，在强化功能方面有明显增强：

| 对比项 | 标准 FGA | Preview Build |
|---|---|---|
| 战斗自动化 | ✅ | ✅ |
| 自动喂狗粮 | ✅ | ✅ |
| 自动升技能 | ✅ | ✅ |
| 自动升追加技能 | ❌ | ✅ |
| 自动升礼装 | ❌ | ✅ |
| 礼装 EXP 炸弹 | ❌ | ✅ |

如果你需要追加技能和礼装的自动化强化，可以尝试 Preview Build。
