## ✨ Quicker 是什么

Quicker 是一款专为 Windows 设计的场景化快捷面板工具，自我定位为"指尖工具箱"。它的核心思路和传统启动器不同——不是帮你"找图标、开软件"，而是把常用软件里的高频操作装进一张随叫随到的小面板里，鼠标点一下就完成。给 Excel 加边框、给选中的文字翻译、把剪贴板内容批量处理掉，这些碎片化的重复操作都可以压缩成一个个按钮。

三个核心概念构成了 Quicker 的使用骨架：**快捷面板**默认单击鼠标中键弹出，位置跟随鼠标，上半部分是固定的全局面板区，下半部分随当前软件自动切换上下文；**动作**是面板上的每个按钮，简单的可以是"启动记事本"，复杂的能串起几十个步骤的自动化流程；**场景**则是为某个软件（按进程名识别）建立的专属配置，切换到 Excel 时面板自动换成 Excel 的动作页——这就是"场景化"三个字的来源。

适合谁用？长时间泡在 Office、浏览器、代码编辑器里的办公族与开发者；讨厌记快捷键、更愿意"点点鼠标"的用户；有重复性操作需要自动化、但又不想学编程的重度 Windows 用户。官方还提供了浏览器扩展和安卓客户端作为配套生态，面板遥控器、动作库分享社区也一直在活跃。

## 🔧 安装步骤与注意事项

Quicker 是典型的 Windows 桌面软件，安装过程整体顺畅，有几个环节值得留意。

### 安装流程

1. **获取安装包**：从下载入口拿到安装程序，建议核对文件大小与官方标注一致，避免下载过程不完整。
2. **运行安装程序**：双击后系统可能弹出 UAC 权限提示，确认来源可靠后允许即可。
3. **选择安装路径**：默认安装到系统盘，可以自定义到其他盘符；安装完成后自动在后台运行。
4. **首次启动确认**：首次弹出的设置窗口会引导你完成初始配置，建议把"开机自启动"选项打开，避免每次手动唤醒。

### 杀毒软件误报

> [!WARNING]
> 某些安全软件可能对快捷指令类工具产生误报，属于行业常见现象。如遇拦截提示，建议将安装目录和程序加入信任名单，或在安全软件社区查询该类工具的已知处理方式。

### 装完怎么验证

- 按下鼠标中键，如果屏幕上弹出跟随鼠标的半透明面板窗口，说明安装成功。
- 任务栏右下角系统托盘应出现 Quicker 图标，右键图标可进入设置窗口。
- 在设置窗口里可以查看当前版本号，建议确认是下载页面标注的最新稳定版。

## 📖 使用入门：动作、轮盘与悬浮的玩法

### 面板的两层结构

第一次弹出面板时，你会看到它天然分成上下两半。上半部分是**全局动作区**，不管在什么软件里都能用，适合放常用的启动器、剪贴板工具这类跨场景的动作。下半部分是**上下文动作区**，随当前活动窗口的进程名自动切换——你在 Excel 里时它显示 Excel 的动作页，切回浏览器就换成浏览器的。一层面板最多可以放 28 个动作按钮，对于日常使用足够充裕。

> [!TIP]
> 刚上手不建议一上来就把面板塞满。先把最常用的三五个动作装好，用几天感受一下哪些真的高频，再逐步扩充。面板太拥挤反而会让找点按钮的时间比手动操作还长。

### 轮盘菜单：划一下就触发

除了面板，Quicker 还有一个核心交互——**轮盘菜单**。它的思路很像一些游戏里的技能轮盘：按住设定好的鼠标键，屏幕上弹出一个圆盘，鼠标滑到哪个扇区松开，就触发那个位置的动作。

轮盘有三圈结构。内圈和外圈是屏幕上可见的两圈，每圈默认 8 个位置；扩展圈不显示，触发区域是轮盘外的整个屏幕——鼠标移出轮盘后按方位松开即触发，相当于 8 个"朝某方向划一下"的手势，最适合盲操作。扩展圈是专业版能力，免费版可以先用可见的两圈。

触发和使用的基本流程：

1. 在设置窗口的轮盘菜单页面指定一个触发键——这个键会被占用，别选常用键；
2. 按下触发键并立即移动鼠标，轮盘弹出；
3. 滑到目标扇区松开即触发；移出轮盘松开则触发扩展圈对应方位。

松开前还有几个附加技巧值得记：在目标位置上按 F1 可以重复触发连按连发；按 Shift 松开则打开动作的右键菜单；按 Esc 或点左键取消整个轮盘。

### 从动作库装现成动作

不想从零开始搭面板？Quicker 社区动作库里有 8000 多个现成动作可以直接装，截图 OCR、聚合翻译、文件归档这类高频需求基本都能找到。装完之后，面板上的动作右上角会出现更新角标——软件每次启动自动检查已装动作的更新情况。

更新管理有几个实用手段。设置窗口里有批量更新界面，支持全选、多选配合 Ctrl/Shift 点击，对不想被打扰的动作可以设置"忽略更新"。1.38.9 及以后版本支持自动更新，对没有在本地修改过的动作，启动时自动升级到最新版。更新出问题怎么办？1.38.25 及以后可以切换动作版本，把动作退回本地曾用过的历史版本，手动切换后动作会去掉自动更新标记避免又被升上去。

> [!NOTE]
> 多台电脑同时使用时，自动更新可能造成配置冲突。官方提供的解决方案：只在一台电脑上编辑和更新动作，其他电脑保持只读同步。可以在本机创建文件 `c:\qk_disable_actionupdate.txt` 来跳过该电脑的动作更新检查。

### 悬浮动作页：常驻屏幕的迷你面板

悬浮按钮一次只能拖一个动作，但如果你需要的是一组动作常驻屏幕，官方提供了**悬浮动作页**——把整个动作页变成一个小浮标，悬浮在工作区周围，不用时自动收缩为一个小圆点，基本不占屏幕空间；需要时展开圆点，页上的动作照常点击执行。

| 对比项 | 悬浮按钮 | 悬浮动作页 |
| --- | --- | --- |
| 承载内容 | 单个动作 | 一整页动作 |
| 适用周期 | 短期任务，用完即关 | 阶段性项目，常驻几天到几周 |
| 版本限制 | 免费版 1 个 | 专业版功能 |

典型使用场景包括：双屏工作时副屏角落挂一页"素材整理"动作，主屏干活随手点；客服或运营岗把话术、查询类动作挂一页在聊天窗口旁边，不用每次弹面板；直播或演示时把翻页、标注类动作挂在演示区域旁边。

> [!WARNING]
> 悬浮页和悬浮按钮的共同反面教材是贪多。屏幕角落浮标一多，效率工具就变成了视觉噪音。原则是：三天以上不用的，收回场景动作页，让自动切换的上下文区替你记忆。

### 免费版 vs 专业版

| 功能 | 免费版 | 专业版 |
| --- | --- | --- |
| 动作数量 | 基本够用 | 无限制 |
| 轮盘菜单 | 可见两圈，无扩展圈 | 完整三圈 + 扩展圈 |
| 悬浮按钮 | 1 个 | 多页悬浮动作 |
| 自动更新 | ✅ | ✅ |
| 切换历史版本 | ✅ | ✅ |

免费版对于日常轻量使用完全够，专业版的扩展圈轮盘和多页悬浮更适合重度场景化需求的用户。
