## ✨ 洛雪音乐（LXMusic）是什么

洛雪音乐（LXMusic）是一款跨平台的第三方音乐聚合客户端，支持 Windows、macOS、Linux 桌面端以及 Android 移动端。它本身不提供曲库，而是通过可插拔的「音源脚本」机制，从多个主流音乐平台获取歌曲搜索、播放、歌单等能力，让用户在一个界面里完成跨平台的音乐检索和管理。

核心能力可以概括为三件事：一是**多源聚合搜索**——启用不同的音源脚本后，搜索时会并行向各平台发起请求，结果合并后统一展示；二是**歌单管理**——自建歌单、收藏在线歌单、拖拽排序、多选批量操作都支持；三是**自定义音源**——如果你有 JavaScript 基础，可以自己写音源脚本接入新的平台。

它适合谁用：厌倦了在多个音乐 App 之间切换的人、喜欢折腾音源脚本的技术玩家、以及只想在一个界面里听歌的普通用户。桌面版功能完整度高于移动版，自定义音源管理、数据迁移、批量排序这些进阶操作都集中在桌面端。

## 🔧 安装与首次启动

### 桌面版安装（Windows / macOS / Linux）

Windows 用户通常拿到的是 Setup 安装包，双击后按向导走完即可。安装过程中注意两点：

1. **安装路径自选**——默认装到系统盘 Program Files 下，如果系统盘紧张可以改到其他盘。
2. **杀毒软件可能误报**——第三方音乐客户端偶发被安全软件拦截，属于常见现象，添加信任放行即可。

macOS 用户下载 `.dmg` 文件，打开后把洛雪音乐图标拖进 Applications 文件夹。首次启动时 macOS 可能提示「无法打开，因为来自身份不明的开发者」，到系统设置 → 隐私与安全性里点「仍要打开」就能绕过。

Linux 用户可以选择 AppImage（免安装）或 deb / rpm 包，发行版不同包格式不同，按官方页面说明挑对应格式即可。

### 移动版安装（Android）

下载 APK 后如果遇到「未知来源」拦截，需要在系统设置 → 安全 → 允许安装未知来源应用（不同厂商 ROM 位置可能有差异）。安装完成后建议回到设置里把这个开关关掉，防止其他来源的 APK 被误装。

> [!WARNING]
> 移动版的数据目录在系统沙箱内，普通权限无法直接访问。所以卸载前如果想保留歌单，务必先在软件内完成桌面↔移动同步，或者用云盘备份。

### 便携模式（绿色版）

洛雪音乐支持便携模式——在可执行文件同级目录下新建一个名为 `portable` 的文件夹，启动后所有数据就会存到这个文件夹里，不写系统盘。这对 U 盘使用、多台电脑间数据复制都方便。便携模式也可以通过启动参数 `--portable` 强制开启。

### 安装后核对

启动成功后进「设置 → 关于」看版本号是否和下载页标的一致。如果版本号对不上，说明装的是旧包，去下载页拿最新的重新装一遍。

## 📖 使用入门：从音源配置到歌单管理

### 第一步：导入音源脚本

首次启动的洛雪音乐是空壳，没有音源就搜不到任何歌。导入音源脚本是使用的前提：

1. 打开「设置 → 自定义源管理」。
2. 点击导入按钮，选择 `.js` 脚本文件。
3. 勾选启用，看到「初始化成功」就没问题。

> [!TIP]
> 导入后如果显示「初始化失败」，按 `Ctrl + Shift + I` 打开开发者工具，Console 标签里能看到具体报错信息——是平台接口变了还是脚本本身有问题，从这里能定位。

不是所有音源脚本都支持歌单导入，部分只实现了搜索和播放能力。如果你需要导入外部歌单，在音源管理界面看一下该脚本的能力声明，确认它包含歌单接口。

### 第二步：搜索与播放

音源就绪后，顶部搜索框直接搜歌名、歌手或专辑名。搜索结果按音源聚合展示，同一首歌可能有多个平台的版本。点击播放时可以在不同音源之间切换，找音质最好的那一个。

播放队列分三层：当前队列、稍后播放列表、收藏列表。右键歌曲可以把它加到稍后播放，或者直接添加到某个自建歌单里。

### 第三步：歌单排序——两种方式别搞混

洛雪音乐里有两件独立的事容易混淆：**列表本身的顺序**和**列表内歌曲的顺序**。

#### 列表本身的顺序（桌面版）

在「我的列表」面板中，**按住 Ctrl 键**（macOS 是 Command）进入拖动模式，然后用鼠标拖拽列表名到目标位置。试听列表是系统固定的，始终在最前，不能拖动。松开 Ctrl 键退出拖动模式，排序自动保存。

#### 列表内歌曲的顺序

进入某个歌单详情页后调整歌曲排列。两种方式：

- **鼠标拖拽**——按住歌曲条目直接拖到目标位置，适合单首微调。
- **批量排序**——先多选（按你想要的顺序依次点击），然后点「批量排序」按钮。**选中的先后顺序就是最终排列顺序**——比如依次点了 A → C → B，排序后就是 A → C → B。

> [!NOTE]
> 调整列表内歌曲顺序，只影响显示顺序。播放时如果用随机模式，排序结果不会改变随机算法的输出。排序主要是为了浏览和手动点歌方便。

### 第四步：导入外部歌单

从网易云、QQ 音乐、酷狗等平台复制歌单链接后，在洛雪音乐里找「打开歌单」入口粘贴导入。

**99% 的导入失败原因是歌单源没选对**。洛雪音乐不支持跨源打开歌单——你粘贴的是网易云的链接，就必须确保当前启用了网易云的音源脚本，并且「打开歌单」对话框里歌单源下拉菜单选的也是网易云音乐。

排查按这个顺序来：

1. 确认歌单源下拉菜单选的平台和链接来自的平台一致。
2. 确认音源脚本支持歌单获取接口（不是所有脚本都实现了）。
3. 确认粘贴的是歌单详情页的完整 URL（不是单曲链接或短链接）。
4. 确认原歌单存在且公开，浏览器里能打开。

如果某个平台暂时没有可用的音源脚本，还有个最笨但最可靠的替代方案：在原平台打开歌单，逐首在洛雪音乐里搜索确认能播，然后手动加到自建歌单里。

### 进阶：自己写音源脚本

洛雪音乐的自定义源接口是公开的，有 JavaScript 基础就能上手。脚本文件 `.js` 开头必须有元信息注释块（`@name`、`@description`、`@version` 等），然后从 `globalThis.lx` 导入宿主注入的 API：

| API | 作用 |
|---|---|
| `request(url, options, callback)` | 发起 HTTP 请求，不受同源策略限制 |
| `on(eventName, handler)` | 注册事件处理函数，宿主会发送 `search`、`musicUrl`、`pic`、`lyric` 等请求 |
| `send(eventName, data)` | 向宿主发送响应数据 |

脚本加载完成后要发送 `inited` 事件，声明自己支持哪些音质（比如 128k、320k、flac）。调试时按 `Ctrl + Shift + I` 打开开发者工具看 Console 输出。

> [!WARNING]
> 自行编写音源脚本时注意合规：不要绕过平台反爬机制、不要用于商业用途、遵守第三方平台的服务条款。洛雪音乐官方不托管也不背书任何第三方音源脚本。

### 数据存哪里了——备份与迁移

桌面版的歌单、收藏、设置、音源脚本默认存放在系统标准用户数据目录：

| 平台 | 默认路径 |
|---|---|
| Windows | `%APPDATA%\lx-music-desktop` |
| macOS | `~/Library/Application Support/lx-music-desktop` |
| Linux | `~/.config/lx-music-desktop` |

Windows 上按 Win + R，输入 `%APPDATA%\lx-music-desktop` 回车就能快速打开。

数据目录里核心是 `LxDatas` 文件夹（歌单、收藏、设置都在这里），`cache/`、`pic/`、`lyric/` 是缓存内容，删了也不影响功能会自动重建。

**什么时候该备份**：重装系统前、卸载洛雪音乐前（Setup 安装版卸载可能删数据）、跨版本大升级前、迁移到新电脑时。整个 `LxDatas` 文件夹复制过去即可恢复，比跨端同步更原始但更可控。

> [!WARNING]
> 数据目录 ≠ 下载目录。下载目录是你在「设置 → 下载设置」里自选的、存放下载到本地的音频文件（flac / mp3）的路径，和数据目录完全独立。
