## ✨ KonaBess 是什么：安卓 GPU 调校一站式方案

KonaBess 是一款面向安卓设备的 GPU 频率与电压调校工具。它的核心能力是让用户直接读取和修改设备的频率表与电压表——这两张表决定了 GPU 在不同负载下跑什么频率、吃多少电压。通过调优这两组参数，玩家可以实现降压降发热、超频提帧率等效果，是社区俗称"驯龙"（骁龙调校）圈里的主力工具之一。

KonaBess 支持 Magisk 模块刷入模式，不需要你反编译 boot.img，改完 dtb 直接打包刷入即可。界面上提供频率表编辑器、电压曲线编辑器、配置导入导出等核心功能，覆盖从原厂备份到超频方案落地的完整流程。适合哪些人用呢？如果你会刷 Magisk、愿意花半小时测一轮稳定性、希望手机玩游戏时更凉快或者帧率更高，KonaBess 就是为你准备的。

> [!NOTE]
> KonaBess 只作用于骁龙系 GPU（Adreno 系列），联发科、天玑、麒麟等平台暂无支持。刷入前请确认你的设备 SoC 型号。

## 🔧 安装步骤：Magisk 模块方式刷入

KonaBess 以 Magisk 模块 zip 包的形式分发，安装流程和普通 Magisk 模块一致：

1. **确认前置条件**：设备已获取 Magisk Root，且当前运行的 ROM 支持 Magisk 模块挂载。如果还没装 Magisk，先去 Magisk 官方仓库安装管理器并完成 Root。
2. **下载模块 zip**：从上方下载入口拿到最新版本的 KonaBess Magisk 模块包，放到手机内部存储方便找到的位置。
3. **在 Magisk 管理器中安装**：打开 Magisk 管理器 → 模块 → 从本地安装 → 选择刚才的 zip 包 → 等待刷写完成 → 重启设备。
4. **重启后验证**：重启完成后打开 KonaBess App，如果能正常识别设备 GPU 信息（频率表、电压表都有数据），说明模块安装成功。

> [!WARNING]
> **刷入前务必备份当前 boot.img**。虽然 Magisk 模块通常不会破坏 boot 分区，但任何涉及底层 dtb 修改的操作都存在风险。用 `adb backup` 或 Magisk 的"保存当前启动镜像"功能先存一份。

> [!TIP]
> 如果你之前刷过其他 GPU 调校模块（比如 Vulkan 驱动补丁、其他频率表模块），建议先卸载那些模块再装 KonaBess，避免多模块同时改 dtb 导致冲突。

安装完成后，KonaBess 的 App 图标会出现在桌面。第一次打开时会请求 Root 权限，允许即可进入主界面。

## 📖 使用入门：从降压到超频的完整路径

KonaBess 的核心界面围绕频率表和电压表两张表展开。下面结合实际操作流程，把主要功能和调校思路串起来。

### 先搞懂：频率、电压、功耗的三角关系

在动手之前，理解一条硬件公式能帮你少走很多弯路：

**P = C × V² × f**

功耗由三个因素决定，其中电压 V 的影响是**平方级**的，而频率 f 只是线性。这意味着——电压降一点点，功耗就能降一大截；反过来，想大幅提功耗就得动电压。这也是为什么社区最推崇的调校路线是"降压不降频"：原厂频率表不动，每档电压往下压 20~50mV，性能基本不变但发热明显下降，投入产出比最高。

频率和电压必须配对。频率越高，晶体管翻转需要的时间窗口越短，就得给更高的电压才能保证稳定。GPU 频率表从上到下电压递增正是这个道理——305MHz 只需要 0.70V，905MHz 峰值档可能要 0.95V。超频时如果只拉频率不补电压，GPU 大概率在高负载下花屏或重启。

### 频率表编辑器：只动峰值档

频率表列出了 GPU 可用的所有频率档位。调校时请记住一个原则：**中间档位和最低档尽量不动，只考虑峰值档**。

最低档（通常 305~350MHz）是 GPU 空载时跑的频率，本来功耗就低于 0.5W，再降没什么续航收益，反而可能增加 GPU 从低到高跳频的响应延迟。中间档位是厂商根据 DVFS 策略精心设置的，覆盖从轻到重的负载过渡，乱改可能导致某些场景下 GPU 找不到合适的频率而跳频卡顿。

安全的频率表操作只有两种：

| 操作 | 做法 | 风险 |
|---|---|---|
| **超频峰值档** | 把最高档往上拉 100~200MHz | 中，需要配合调压和稳定性测试 |
| **插入过渡档** | 在原峰值档和超频档之间插入新档位，让频率跳变更平滑 | 低 |

### 电压曲线编辑器：降压是核心手段

电压曲线就是频率表和对应电压的配对图。KonaBess 里电压单位通常是 uV（微伏），界面显示值除以 1000 就是实际电压（950000 = 0.950V）。

降压操作很直观：选中某个频率档，把电压值往下调。社区推荐的起步幅度是**每档先降 30mV**，刷入后跑一轮压力测试（比如 Geekbench GPU、游戏 benchmark），如果稳定再继续往下压 10~20mV，直到找到你这颗芯片的"最低安全电压"。

> [!WARNING]
> **不要一次给所有档位压 100mV 以上**。每颗芯片的体质不同（硅抽奖），原厂给的标称电压已经留了余量但远没有你想的那么大。一次降太狠大概率花屏重启，渐进式调整才是稳妥做法。

调压前必须确认频率表已经最终定好——频率表和电压表是一对一配对的，新增了超频频率档就得给它配对应电压，删了频率档电压表里也不能留着对应项。

### 配置导入导出：永远留退路

KonaBess 内置的配置导出功能不只是"备份"，更是整个调校流程的安全网。建议在以下节点一定要导出：

- **调校前**：先把原厂配置导一份存好，这是最重要的退路
- **每次修改一个维度后**：降压方案、超频方案各存一份，命名里加上日期和调校目标
- **稳定运行一周后**：这个方案就是你的"成熟方案"，换 ROM 或重刷模块后可以直接导入

推荐的文件命名格式：`konabess_<芯片型号>_<日期>_<调校内容>.json`，比如 `konabess_sm8350_20261014_uv40.json` 一眼就能认出是骁龙 888、10 月 14 日、降压 40mV 的方案。

导入配置只是把数据加载到内存，**还需要重新 Repack 和刷入**才会生效。导入后在 KonaBess 里确认频率表和电压表都正确加载了，再执行刷入操作。

### 两条调校路线怎么选

综合上面的操作，社区实际上走两条路线：

**路线 A：降压不降频（新手推荐）**
频率全部保持原厂，每个档的电压向下微调 20~50mV。性能基本不变，发热明显降低，续航也有提升。风险最低，也是社区最常见的用法。

**路线 B：超频 + 适度加压**
把峰值频率往上拉 100~200MHz，给新的峰值档位加一点电压（通常 +30~60mV，体质好的芯片可能 +20 就够）。目标是提升游戏帧率。风险较高，需要反复测试稳定性，花屏、闪退、重启都是常见反馈。

选哪条路取决于你的目标：想凉快一点就走路线 A，想游戏多跑几帧就走路线 B。两条路线也可以组合——超频后再给所有档适度降压，前提是你的芯片体质撑得住。
