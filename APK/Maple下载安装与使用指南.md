## ✨ Maple 是什么

Maple 是一款面向学生和数学爱好者的移动计算器 App，它的核心卖点不止于算对一道题——而是把「输入 → 求解 → 画图 → 检查」这一整条学习链路打通了。你可以随手敲一个表达式看实时 2D 曲线，也可以拍一张作业本照片让它帮你识别并给出分步解题过程。内置的 Sumzle 小游戏还能在休息时练一练运算直觉。

适合谁用呢？高中以上阶段做微积分、方程组、函数图像题的同学最能吃满它的全部能力；初中阶段用来快速验算解方程、画函数走势也完全够用。它不替代课本和老师讲解，但当你卡在某一步想知道「这步到底算对了吗」「这条曲线为什么长这样」的时候，Maple 是那个能给你即时反馈的工具。

## 🔧 安装步骤

### Android 安装

从下载页拿到 APK 文件后，安装过程并不复杂，但有两个容易踩坑的点需要留意：

1. **允许未知来源安装**：首次从浏览器安装 APK 时，系统会弹出「禁止安装未知应用」的提示。进入手机设置 → 安全与隐私 → 安装未知应用，找到你用的浏览器（Chrome、Edge 等），把「允许安装应用」打开，回到安装包再点一次就能正常安装了。
2. **核对安装包版本**：安装前建议看一眼文件名里的版本号和下载页标注的是否一致，避免装到旧版本。如果之前装过 Maple，直接覆盖安装即可，登录账号后之前的云端数据会自动同步。

> [!NOTE] 杀毒软件误报
> 部分手机自带的安全中心对第三方 APK 可能会弹风险提示，这是 Android 的通用安全机制，并非 Maple 本身有问题。只要安装包来自下载页的正规渠道，放行即可。

### iOS 安装

iOS 用户相对省心——直接在 App Store 搜「Maple Calculator」下载安装，无需额外授权。首次打开时申请通知权限可以按需选择，不影响核心计算功能的使用。

### 装完核对

安装完成后打开 App，随手输一条 `3x+4=8`，点击对勾如果能正常给出解和结果页，说明引擎工作正常。如果直接卡主不出结果，先检查网络连接再考虑重启 App 或重装。

## 📖 使用入门

### 把题目输进去

Maple 的输入界面有一套专门的数学键盘，分数、根号、积分、极限这些符号都能直接点出来，不用在普通键盘里切来切去。支持三种输入方式：

- **手动输入**：适合符号较多、排版复杂的公式题
- **语音输入**：直接念数学表达式，对口述比较清晰的场景很方便
- **拍照识别**：把作业本或教材上的题目拍下来，App 会做 OCR 识别后转成可编辑的表达式

> [!TIP] 拍照识别的小技巧
> 拍照时尽量让题目铺满取景框、光线均匀，避免手抖模糊。手写体的识别率比印刷体稍低，如果某道题识别错了，在编辑框里手动改正再继续就行。

### 结果页怎么看

Maple 的结果页不是只给一个最终答案，而是把「求解过程 + 2D/3D 图形 + 分步解题」整合在一页里：

- **最终答案**：最显眼的位置直接给出结果
- **Plot 图形区**：含变量 x 的表达式会自动生成 2D 曲线，方程组会画出每条方程的图再给交点解，极限题会画出函数在趋近点附近的走势
- **分步解题**：展开后能看到完整的推导步骤，适合对照自己的解题过程查漏

#### 2D 绘图操作要点

画图不是一个独立模式，而是融在求解流程里的——输入表达式、点对勾，图形往往直接出现在结果页的 Plot 条目里。图形区支持双指捏合缩放、单指拖动平移，坐标系默认直角坐标、刻度自动排布。读的时候可以对照这几个自查项：

| 自查点 | 说明 |
| --- | --- |
| 过零点 | 曲线与 x 轴的交点就是方程的实数解，和 Solve 给的答案对一对 |
| 对称性 | 偶函数左右对称、奇函数原点对称，不对称大概率是式子输错了 |
| 周期 | 三角函数题先估周期，和理论值（如 sin 的 2π）对比验证 |
| 趋势 | 分母零点附近曲线冲天的竖直渐近线，正是极限题的考点 |

### 遇到联网问题怎么办

「拍照转圈不出结果」「步骤加载失败」「上传没反应」——这三类故障共享同一个根源：它们都是云端功能。排查时先随手输一条 `3x+4=8` 点对勾：

- **有结果** → 引擎正常，问题在网络侧，继续往下查
- **也没结果** → App 本体异常，重启 App 试试，还不行就重装

网络侧的排查顺序：

1. 开关飞行模式再关掉，重置手机网络栈
2. 换网络（Wi-Fi 换流量、流量换 Wi-Fi），校园网/公司网常有应用白名单拦截
3. 弱网时别连点，等 30 秒再试，AI 识别对延迟敏感
4. 错峰使用，官方服务端偶发维护时换个时段通常自愈

### Sumzle——数学版的 Wordle

App 里还藏着一个内置小游戏叫 Sumzle，官方介绍是「像 Wordle，但玩的是数学和等式」。玩法是在数字与运算符的网格里圈出一条真正成立的等式，你的选择会得到绿/橙/灰的颜色反馈，据此逼近那条隐藏等式。通关后会提示「See you again tomorrow!」——每天一局的节奏，全网同款题目。

三档难度怎么选：小学高年级或刚上手用最低档先熟悉颜色反馈逻辑；初中日常消遣用中间档；高中以上想要烧脑就上 Challenging 档。判断标准是能在 3 次尝试内命中的难度就是合适难度，屡次超 5 次就降一档，别挫伤兴致。

别把它当纯消遣——在网格里凑等式本质上是在练数感与运算直觉，这种快速判断力对考试里的选项排除、估算验算都有迁移价值。适合安排在写作业间隙换脑子，完成一个学习番茄钟后玩一局作为奖励，每天一局的机制也天然防沉迷。
