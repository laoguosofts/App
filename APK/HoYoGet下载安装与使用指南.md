## ✨ HoYoGet 是什么：米哈游抽卡记录的"取数钥匙"

HoYoGet 是一款运行在安卓设备上的开源工具，专门解决一个问题：把米哈游系游戏（原神、崩坏：星穹铁道、绝区零）客户端里藏着的抽卡记录接口链接取出来。

这个链接本身就是游戏"历史记录"页面背后的数据通道——打开游戏里的抽卡历史时，客户端就在向这个地址分页请求数据，只是游戏没有把地址显示出来。HoYoGet 做的事就是把这条 URL 截下来，交给你。

取出的链接可以粘贴到任意支持米哈游抽卡记录接口的分析工具里，自动生成统计报告：总抽数、保底进度、五星角色/武器分布、命座/精刃数等等。常见的分析工具包括微信小程序"提瓦特小助手"以及各类社区工具——HoYoGet 与这些分析工具**完全无关**，它只做链接获取，工具选型由用户自己决定。

HoYoGet 的核心功能：

- **账号登录获取**：通过游戏登录态直接拉取链接，最方便但需要登录
- **ADB / Shizuku 获取**：借助 Shizuku 读取游戏日志，从日志输出中拦截链接，免 root、免登录，流程稍复杂但独立性更强
- **界面显示 / 自动复制**：获取成功后可选择直接展示或写入剪贴板，方便下一步粘贴

适用人群：想做抽卡数据统计、回顾自己的抽卡历程、核对保底进度的米哈游玩家。工具本身不做任何游戏内操作，也不绕过游戏机制——它读取的就是游戏客户端自己输出的内容。

## 🔧 安装步骤

HoYoGet 目前仅支持安卓平台，安装流程和普通 APK 类似，但需要注意来源授权和 ADB 相关依赖。

**基础安装（账号登录获取方式）**

1. 从下载页下载最新 APK 文件到手机
2. 如果是首次安装非应用商店来源，进入「设置 → 安全 / 隐私 → 安装未知应用」，为文件管理器或浏览器授予安装权限
3. 打开 APK 完成安装
4. 首次启动时按提示授予必要权限

> [!TIP]
> 务必核对下载文件的版本号——HoYoGet 更新较频繁，旧版本可能因接口变更无法正常获取链接。下载页会标注当前最新版本号。

**ADB / Shizuku 方式的前置安装**

如果打算用 Shizuku 路径获取链接，需要额外安装 Shizuku 服务。Shizuku 是 RikkaApps 开发的开源工具，以 adb 或 root 权限启动一个服务进程，让普通应用借用系统级权限读取其他应用的日志——这正是 HoYoGet 拦截抽卡链接的技术基础。

Shizuku 有三种启动方式，按便捷程度排序：

| 启动方式 | 适用条件 | 操作门槛 |
| --- | --- | --- |
| 无线调试（Android 11+） | 安卓 11 及以上、手机自带无线调试 | 最低，手机内完成配对即可 |
| 电脑启动 | 有 USB 数据线 + 电脑安装 adb | 中等，一次性在电脑跑命令 |
| root 启动 | 已 root 的设备 | 最高，但启动后最稳定 |

安装 Shizuku 后，在 HoYoGet 内点击「授权 Shizuku 访问」，完成一次绑定即可。

**安装完成后的核对**

打开 HoYoGet，进入「关于」页面确认版本号与下载页一致。ADB 路径的话，先手动打开 Shizuku 确认服务处于运行状态（主界面会显示"正在运行"），再回 HoYoGet 看授权状态是否为已连接。

## 📖 使用入门：从获取到分析的完整流程

### 第一步：选获取方式

打开 HoYoGet 主界面，会看到两种获取路径：

**账号登录**：用你自己的米哈游账号登录，工具直接调用接口拉取链接。最省心，但需要在工具内完成登录操作，隐私敏感的用户可能更倾向下面这种。

**Shizuku / ADB 获取**：不需要登录游戏账号。流程是：先启动 Shizuku 服务 → HoYoGet 确认 Shizuku 授权 → 点 HoYoGet 的「开始获取」→ 切回游戏 → 打开抽卡页面 → 点左下方的「历史记录」（原神）或「查看详情 → 历史记录」（崩铁）。打开历史记录的瞬间，游戏客户端就会向接口请求数据，HoYoGet 通过 Shizuku 监听游戏日志，把这条请求地址截下来。

> [!WARNING]
> Shizuku 路径必须**先启动服务、再打开游戏历史记录**，顺序反了会导致日志监听没跟上，获取不到链接。

### 第二步：拿到链接

获取成功后 HoYoGet 会在界面提示，可以选择直接复制到剪贴板，或者临时显示在界面上。界面显示功能用完后记得关掉——不要长时间让链接暴露在屏幕上。

链接的本质是一个带身份授权参数的 URL，指向你的抽卡记录接口。两个关键属性：

1. **私有性**：它指向的是**你的**抽卡记录，别人拿到就能读你的完整记录，包括 UID、角色养成进度、资源投入节奏——这些是定向诈骗的优质画像信息
2. **时效性**：链接有有效期，过期后需要重新走一遍获取流程

### 第三步：粘贴到分析工具

打开你选择的抽卡分析工具（微信小程序"提瓦特小助手"是社区常用的一个），找到抽卡分析入口，粘贴链接，等待拉取完成，报告就自动生成了。

报告里通常会包含：

- 总抽数统计（分卡池）
- 五星角色 / 武器的数量与分布
- 保底进度离下次五星还有多少抽
- 命座 / 精刃数累计
- 抽卡日期时间分布

> [!NOTE]
> HoYoGet 官方文档明确说明：提瓦特小助手等其它应用/小程序与 HoYoGet **完全无关**。HoYoGet 只做链接获取，其它工具的行为（显示广告、收集信息等）由对应工具自行负责。选择分析工具时请自行甄别信任度。

### 第四步：保管好链接

链接只粘贴给你主动选择、信得过的工具——不要发群聊、不要发私信、不要发给"帮你分析"的陌生人。用完后清空剪贴板，界面显示过链接的看完即关。

虽然链接有时效，过期后自然失效，但别仗着时效大意——在有效期内它就是你抽卡记录的读取钥匙。

HoYoGet 自身的数据边界：操作在本地或与米哈游服务器之间完成，隐私数据不上传第三方。风险集中在"你把链接交给谁"这一环。

### 常见问题速查

**获取失败怎么办？**

先检查 Shizuku 是否真的在运行（Shizuku 主界面要有"正在运行"状态），再确认 HoYoGet 的 Shizuku 授权是否生效。如果用账号登录路径，确认登录态没过期。还有一种可能：旧版本 HoYoGet 与当前游戏版本的接口不兼容，升级到最新版通常能解决。

**链接粘贴后工具报错？**

可能是链接已过期，回去 HoYoGet 重新获取一次。也可能是工具本身暂时出问题，换个工具试试——链接是通用的，只要接口没变就能被多个工具接受。
