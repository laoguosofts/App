## ✨ Reminder 是什么

Reminder 是一款把待办清单、四象限分类、OKR 目标管理和云同步打通的多模块提醒类应用。它不像市面上很多"单点功能"的待办 App——只做清单不做目标，或者只做目标不跟具体任务挂钩——Reminder 的设计思路是把"今天要做什么"和"这个季度要达成什么"放在同一个体系里，让子任务自动汇总到主待办、KR 进度自动推送到 OKR 总体进度。

核心功能可以归为四个模块：**随手备忘**（快速记录灵感和事项）、**待办清单**（支持子任务、分类筛选、四象限视图）、**OKR 目标管理**（目标 + 关键结果 + 待办关联）、**云同步**（多设备数据一致）。对于个人用户来说，它可以替代"备忘录 + 日历 + 目标 App"三件套；对于小团队来说，OKR 模块自带 KR 与待办的关联，省掉了在多个工具之间来回切的麻烦。

Reminder 的适用场景很广——日常待办、项目拆解、季度 OKR 追踪、甚至换手机时的数据迁移，都覆盖到了。如果你之前用过"只能记不能管"的待办应用，或者"目标和执行两张皮"的 OKR 工具，Reminder 值得试一试它的四模块打通体验。

## 🔧 安装步骤

Reminder 支持 Android 和 iOS 双平台，安装流程以 Android 为例说明（iOS 用户直接走 App Store 即可，无需额外设置）。

### Android 安装流程

1. **获取安装包**：从下载页拿到 APK 文件，建议用浏览器自带下载管理器，避免第三方下载工具篡改文件。
2. **开启未知来源安装**：首次安装非应用商店来源的 APK 时，系统会拦截提示"未知来源"。进入**设置 → 安全 → 安装未知应用**，找到你用来打开 APK 的应用（比如文件管理器或浏览器），打开开关。
3. **安装**：点击 APK 文件，按提示确认权限（通知、存储空间、网络等），等待安装完成。
4. **核对版本**：打开 Reminder 后进入**设置 → 关于**，确认版本号与下载页标注的一致。如果不一致，可能是下载了旧版，建议重新获取。

> [!WARNING] 务必核对版本号
> 有些下载链接会缓存旧版 APK，安装前花两秒钟对一下版本号——旧版可能缺少 OKR 模块或云同步的稳定性修复。

### 常见安装问题

| 问题 | 可能原因 | 解决方法 |
|---|---|---|
| 安装包解析失败 | APK 文件损坏 | 重新下载，换个下载工具试试 |
| 安装到一半卡死 | 存储空间不足 | 清理至少 500MB 空余再装 |
| 安装后闪退 | 系统版本过低 | Reminder 要求 Android 8.0+，旧设备需升级系统 |

## 📖 使用入门

### 待办清单：从"大杂烩"到结构化管理

Reminder 的待办清单不是把所有事项堆在一起，而是通过**子任务**、**分类**和**四象限**三个维度让清单变得有条理。

**子任务**是最实用的功能。一条主待办可以挂多条子任务——比如"换手机"这条主待办，可以拆成"备份旧机数据""转移照片视频""下载常用 App""激活新号"四条子任务。子任务逐个标记完成后，主待办会自动反映总体进度（4 条完成 2 条 → 主待办显示 50%）。全部子任务完成后，主待办自动标记为已完成，不需要手动再点一次。

> [!TIP] 什么时候用子任务
> 当一件事可以拆成 3 个以上有先后顺序的小步骤时，就建子任务。如果只是"买牛奶 + 买面包"这种并列清单，没必要挂子任务，直接建两条独立待办就行。

**分类**用来给待办打标签，在三个地方发挥作用：待办清单顶部的分类 tab 可以快速筛选（点"工作"就只看工作相关的待办）；日历视图里每条待办会显示分类对应的颜色条，一眼区分类型；统计报告里可以按分类查看完成度。

**四象限视图**则是把待办按"紧急/重要"两个维度分到四个格子里——紧急且重要的自动排最上面，重要但不紧急的规划到后面，紧急但不重要的考虑委派，都不重要的直接删。这个视图和清单视图可以来回切换，适合不同的查看习惯。

### OKR：让目标和执行不再两张皮

很多人知道 OKR（目标 + 关键结果），但实际用起来经常遇到一个问题——目标写了、KR 也写了，但 KR 和每天的待办之间没有任何关联，KR 完成了多少全靠手动更新。Reminder 在这个点上做了打通：**每条 KR 下面可以挂具体的待办事项**，待办完成后 KR 进度自动推进。

创建 OKR 的流程很直接：

1. **起目标名称（O）**：定性的、有方向感的描述，比如"2025 年 Q1 拿下区域头部客户，建立标杆案例"——不要把数字写进 O 里，数字留给 KR。
2. **选周期**：季度（最标准）、月度（目标聚焦时）、半年度或年度（方向型目标）。
3. **设状态**：进行中（默认）、已完成、暂停、取消——做完再改也可以，不是必须现在定。
4. **至少加一条 KR**：这是 Reminder 的强制约束，没有 KR 不能保存 OKR。

KR 的写法有讲究。好的 KR 要满足 SMART 原则：**具体**（不说空话）、**可衡量**（有数字）、**可达成**（有挑战但能做到）、**相关**（和 O 直接挂钩）、**有时限**（OKR 周期结束日）。

| KR | 好不好 | 原因 |
|---|---|---|
| 签订 2 个年消费 100 万以上的客户合同 | ✅ | 具体、有数字、和 O 直接相关 |
| 把产品演示稿做精美 | ❌ | 不可衡量（"精美"太主观）、是手段不是结果 |
| 联系 50 家潜在客户 | ⚠️ | 可衡量但不够——"联系"只是过程，改成"让 20 家同意演示"更好 |

KR 建好之后，在 KR 详情页里可以添加关联的待办事项——比如"签订 2 个年消费 100 万以上的客户合同"这条 KR，可以拆出"给 A 客户发方案""跟 B 客户开需求评审会""准备合同模板"三条待办。待办逐条完成后，KR 的进度条会自动推进，OKR 的总体进度也会跟着所有 KR 的进度加权计算出来。整个过程不需要手动输入数字，省了很多维护成本。

### 云同步：换手机不再头疼

Reminder 的云同步支持多设备数据一致——在旧手机上建的待办，打开新手机自动就能看到。换手机迁移数据有两种方法，推荐用云同步：

**方法一：登录账号云同步（推荐）**

1. 旧手机先确认云同步完成——设置里看"上次同步时间"，或者新建一条测试待办等几秒看新手机上有没有出现；
2. 新手机装 Reminder → 登录同一个账号；
3. 数据自动拉下来：待办、备忘、分类、OKR、设置全在。

**方法二：手动备份 → 恢复**

如果账号登不上或云同步不工作，可以用设置里的"数据备份"导出备份文件，通过 QQ/微信文件传输助手、USB 或网盘传到新手机，然后在新手机上走"数据恢复"选这个文件。备份文件是几天前做的话，中间产生的数据会丢失，所以这个方法适合紧急兜底。

> [!NOTE] 换手机前的自检
> 旧手机一定要**退出登录**（不是只卸载应用），否则两边同时同步可能产生冲突。做一份手动备份存在电脑上作为兜底也不麻烦。
