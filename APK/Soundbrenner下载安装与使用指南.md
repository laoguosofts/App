## ✨ Soundbrenner 是什么——戴在手腕上的振动节拍器

Soundbrenner 是一类专为音乐人设计的可穿戴振动节拍器设备，核心思路是把传统节拍器的"嘀嗒"声转化为手腕上精准的触觉振动脉冲，让乐手在练习和演出中不靠耳朵听、靠皮肤感知节拍。产品线覆盖 Pulse（手环式振动器）、Core 2 / Core Steel 2（兼具手表功能的智能节拍器）以及 Spark 等配件，配合同名 App 使用，支持 iOS 和 Android 平台。

这套方案解决的是传统节拍器长期存在的几个痛点：舞台上音箱太吵盖过 click 声、录音室监听混音混入节拍器声污染母带、耳朵要同时处理乐器和节拍两条信息通道导致注意力分散。Soundbrenner 采用 7G 振幅的 ERM 偏心转子马达——比普通智能手机的振动强约七倍——确保在 180 BPM 以上的快速段落，每一下脉冲依然独立可感、不被肌肉动作淹没。

除了节拍器本身，Core 系列还内置了调音器（支持麦克风和压电接触两种模式）、Ableton Link 无线同步、练习追踪统计、以及闹钟/计时器/秒表等手腕端时间工具，是一套围绕"练习→录音→演出"全链路设计的音乐辅助生态。

## 🔧 安装步骤

Soundbrenner 的安装分两部分：手机 App 安装 + 可穿戴设备配对。

### 手机 App

1. **iOS 用户**：打开 App Store，搜索 "Soundbrenner"，确认开发者名称后点击获取。首次启动时系统会请求麦克风权限（调音器功能需要）和蓝牙权限（设备配对需要），建议全部允许。
2. **Android 用户**：打开 Google Play，搜索 "Soundbrenner"，点击安装。Android 首次启动同样需要授权麦克风和蓝牙定位权限（部分机型蓝牙扫描需要位置权限）。

> [!WARNING]
> 如果从第三方渠道下载 APK 安装包，安装前需要在系统设置里允许"未知来源"或"特殊应用安装"。安装后首次启动若提示"应用未认证"，通常是签名校验问题，建议改用官方商店版本。

### 硬件设备配对

1. 长按 Pulse / Core 侧面的电源键开机，设备进入配对模式（LED 指示灯快闪）。
2. 打开 Soundbrenner App，进入「设备」页面，点击「添加新设备」。
3. App 会通过蓝牙扫描附近的 Soundbrenner 设备，点击扫描到的目标设备名称完成配对。
4. 配对成功后，App 会引导你完成首次振动强度测试——跟着屏幕上的节拍确认手腕能清楚感觉到每一下脉冲，再根据个人偏好微调强度。

> [!TIP]
> Core 2 支持同时连接两台手机（比如工作机和私人机），但同一时刻只能有一台设备保持 Link 同步。多乐队成员共用一台 Core 排练时，记得先断开上一个人的手机再连下一个。

### 固件更新

首次配对后 App 会自动检查设备固件版本，有新版本时弹窗提示更新。更新过程大约 2-5 分钟，期间保持设备电量充足、不要断开蓝牙。固件更新通常会修复振动精度、优化 Link 同步稳定性，建议每次看到更新都及时装上。

## 📖 使用入门

### 基础节拍器操作

打开 App 首页就是节拍器界面，转轮调节 BPM（30-300 范围），下方按钮切换拍号（2/4、3/4、4/4、6/8 等常用拍号一键选择）和分拍（四分、八分、十六分、三连音）。点击中间的播放按钮启动节拍器，Pulse / Core 同步开始振动——默认重音第一拍振动脉冲稍长、弱拍短促，方便你通过触觉区分小节结构。

> [!NOTE]
> 如果你戴的是 Core 2，可以直接在手腕上调 BPM：底部按钮切换到节拍器模式，转轮转动即调整速度，长按转轮切换拍号。不用每次掏手机。

### Ableton Link 无线同步

这是 Soundbrenner 最实用的功能之一——让节拍器和 DAW（Ableton Live、Logic Pro、FL Studio 等）共享同一个时钟。录音室工作流里典型的操作顺序是：

1. 在 DAW 里先设好整首歌的 BPM、拍号，有速度变化段落的话画好速度轨道。
2. DAW 端开启 Ableton Link 开关，Soundbrenner App 里同样打开 Link。
3. 确认 App 节拍器和 DAW 节拍器的启停、BPM 完全一致（启动时 App 会显示"已通过 Link 同步"提示）。
4. 乐手佩戴 Pulse / Core，录音开始前 App 自动 Count-in 一拍，然后 DAW 开始录制——振动节拍全程同步，录音轨里干干净净没有 click 声。

Link 模式下，DAW 速度轨道里的渐变（比如一段从 80 BPM 拉到 120 BPM）会自动传递给 Soundbrenner，振动节拍随之加速或减速，不需要手动调任何东西。多轨录制场景里，不同乐手哪怕分开时间录音，只要各自的 Soundbrenner 都 Link 到同一台 DAW，录出来的音轨天然对齐。

### 渐进变速训练（Plus 订阅功能）

渐进变速（Incremental Tempo Change）让节拍器在一段练习内自动渐变 BPM，是 Speedbrenner Plus 订阅的核心功能。设置路径：节拍器界面 → 设置 → Incremental Tempo Change。你需要定四个参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| 起始 BPM | 你当前能稳住的速度 | 60 |
| 目标 BPM | 想推到的极限速度 | 100 |
| 变化间隔 | 每几小节或每几秒变一次 | 每 4 小节 |
| 变化幅度 | 每次变多少 BPM | +1 |

典型方案：吉他扫拨练习，起始 120 BPM（你能稳下来的最大速度），目标 200 BPM，每 4 小节 +2 BPM，分拍设八分音符。你在 120 BPM 下练 4 小节，节拍器自动升到 122，再练 4 小节升到 124……一路推到 200 再原路返回。

> [!TIP]
> 开渐进前先用普通节拍器在起始 BPM 练 2-3 分钟，确认节奏稳了再开。不要在起始速度还没站稳的时候就开渐进，等于在节奏不稳的基础上还叠加加速，训练效果会打折扣。

### Core 手腕上的时间工具

Core 2 手腕内置三种时间工具，和节拍器可以同时运行、振动通道独立：

- **闹钟**：每日固定时间振动提醒，本地运行不受手机 DND 影响。演出前集结、上课起床都能设。
- **计时器**：倒计时，到点振动。健身组间休息（90 秒一组）、练习时长上限（比如今天只练 45 分钟音阶）都适用。
- **秒表**：正计时，简洁的启停操作。

演出时一个实用组合：Core 开节拍器后台运行，同时开计时器设 2 分钟（开场 riff 的时间上限）。段落结束 Core 振动提醒，你快速切计时器到 5 分钟继续主歌，全程不用掏手机。

同时开节拍器和计时器时，Core 屏幕可以切换两种显示模式——长按底部按钮切换：节拍器模式主显示 BPM、计时器在下方；计时器模式主显示倒计时、BPM 在下方。日常推荐计时器模式，倒计时的信息价值更高。

### 触觉节拍的独特优势

很多人第一次用 Soundbrenner 会问：不就是振动吗？和手机振动有什么区别？关键在两个细节：

第一是振动强度。7G 振幅的 ERM 马达比普通手机强七倍，普通手机放在口袋里的振动在快速演奏时很快被肌肉动作淹没，但 Soundbrenner 哪怕 180 BPM 以上，每一下脉冲依然独立清晰。

第二是反馈信息密度。振动不只是"有个脉冲"——重音的脉冲稍长、弱拍短促，不同拍位的振动模式可以区分。配合 Pulse / Core 上的 RGB LED 外环（8 颗灯珠跟随节拍闪烁），强光下、戴帽子余光扫到手腕时都能确认节拍正常运行。

也正因如此，Soundbrenner Core 2 虽然能当日常手表用，但它的核心身份仍然是振动节拍器——智能手表功能是附赠的。Apple Watch 或其他智能手表的振动马达要兼顾通知、来电、闹钟等多种场景，振动力度和精度都达不到节拍器需要的级别。

### 调音器的两种模式

Core 内置调音器有两种工作方式，根据环境噪音选：

- **麦克风调音（MEMS）**：录音室相对安静时直接用 Core 自带的 MEMS 麦克风拾音，操作方便不用额外配件。
- **压电接触调音**：录音室里有其他乐器声或监听残留时，用磁吸压电配件夹在琴身上，通过琴体振动传导到 Core，完全不受环境噪音干扰。

演出时中途重调琴弦不用找手机、不用开调音器 App，抬手腕就能调，几秒搞定。
