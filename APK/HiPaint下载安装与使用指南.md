## ✨ HiPaint 是什么

HiPaint 是一款面向移动设备的专业级绘画应用，主打高性能画笔引擎和完整的图层工作流。它在安卓平台上提供了接近桌面级绘图软件的功能深度——从基础的涂鸦记录到商业插画创作，都能覆盖。核心能力包括：多图层管理、Alpha 锁定与蒙版无损编辑、丰富的滤镜与色彩调节、主动式触控笔和数位板的压力感应支持，以及 PSD 格式的读写兼容。

与同类应用相比，HiPaint 的优势在于对外设的完整适配和图层系统的专业度——它支持 Wacom 数位板、主动式蓝牙触控笔，并提供了可自定义的压力曲线校准。对于习惯了桌面绘图软件的用户来说，HiPaint 的操作逻辑更接近传统桌面画具而非简化版涂鸦工具。

适用人群方面，它既能满足普通用户的日常绘画需求，也能支撑专业插画师的移动创作流程。如果你经常需要在外出时快速完成草稿、线稿甚至完整插画，HiPaint 会是一个比平板自带涂鸦工具更靠谱的选择。

## 📖 HiPaint 使用入门

### 图层操作：Alpha 锁定与蒙版

HiPaint 的图层系统是它区别于普通涂鸦应用的核心。其中两个高频使用但容易搞混的功能是 Alpha 锁定和图层蒙版。

Alpha 锁定（α Lock）开启后，当前图层的画笔操作**只能修改已有像素所在的区域**——完全透明的地方画不上东西。一个典型的场景是：你先用色块工具填了一块颜色，现在想在边缘做柔化或加深。开启 Alpha 锁定后，用软边气笔在色块边缘涂深色，颜色只会停留在色块内部，边界保持整洁，不会涂出去。

| 特性 | Alpha 锁定 | 剪贴蒙版 |
| --- | --- | --- |
| 限制范围 | 当前图层自己的像素边界 | 下方图层的像素边界 |
| 适合 | 在同一图层内操作 | 在新图层上叠加 |
| 可逆性 | 直接关闭锁定即可恢复 | 取消剪贴即可恢复 |

图层蒙版则是另一种无损编辑方式。蒙版本质上是一张 8 位灰度图：**黑色代表完全隐藏、白色代表完全显示、灰色代表部分透明**。编辑蒙版时看到的灰阶不会直接显示在画布上，而是作为原图层的「可见性遮罩」。比如你想让某个图层做渐隐效果，直接用渐变工具在蒙版上拉一层从白到黑的渐变，原图就会自然地从全显过渡到全透明——而且这不是擦除，蒙版随时可以关掉恢复完整图层。

| 特性 | 直接擦除 | 蒙版 |
| --- | --- | --- |
| 操作 | 永久删除像素 | 临时隐藏像素 |
| 后悔了 | 用历史快照恢复 | 随时关闭蒙版恢复全图 |
| 适合 | 确定不要了 | 试错、做渐隐、复杂隐藏 |

### 色彩平衡：三档调节控制色调倾向

HiPaint 内置的色彩平衡滤镜可以对画面的阴影、中间调、高光三个亮度区间分别调整色彩倾向。这个功能对于纠正照片色偏或赋予画面特定氛围非常实用。

色彩平衡提供三对相对的颜色轴：青—红、洋红—绿、黄—蓝。拖动滑块朝某个颜色方向移动，画面对应亮度区间就会增加那个颜色。例如暗调档把「黄」轴往负方向拉，暗部会变冷；高光档「黄」轴正方向拉一点点，高光补黄回来平衡整体色调。

几个常见的色调调法：

- **校正偏黄照片**：暗调档「黄」轴负方向拉 → 暗部偏冷；高光档「黄」轴正方向拉一点点 → 高光补黄平衡
- **夕阳金橙色调**：阴影档拉向「红」和「黄」 → 暗部变暖；中间调拉向「红」 → 整体暖橙；高光档拉向「青」一点点防止过暖
- **日系清新**：整体保持绿和红的微妙平衡，高光偏蓝，阴影略偏青 → 清透低饱和感

色彩平衡负责**色调倾向**，曲线工具负责**明暗层次**。两者经常配合使用：先用曲线把明暗关系调对，再用色彩平衡赋予氛围色。

### 导出透明 PNG：隐藏背景层是关键

HiPaint 默认导出时会自动给画布加上纯白色背景层——即使你完全没画过背景。这导致很多人导出的 PNG 看上去是白底而非透明底。正确的导出透明 PNG 的步骤是：

1. 在图层面板中找到背景层（默认白色背景）
2. 点击该图层左侧的眼睛图标隐藏背景层
3. 确认画布上想保留的内容都在，背景层已隐藏
4. 打开导出对话框，选择「导出为 PNG」
5. **确保没有勾选「添加白色背景」选项**
6. 导出完成后得到的就是真正的透明 PNG

验证透明是否生效的方法：把导出的 PNG 放到纯白色背景上看，应该能透过去显示下面的白色。透明 PNG 的常见用途包括社交媒体头像、表情包贴纸、Web 页面配图、视频剪辑的 Alpha 通道叠加层等。

### 连接触控笔与数位板：开启压力感应

HiPaint 对外设的支持分两类：**主动式触控笔**（含 Wacom）和**被动式电容笔**。主动式触控笔自带电池、支持压力感应，比如 Wacom Bamboo、Apple Pencil、华为 M-Pen 等；被动式电容笔不带电池，只能模拟手指点击，没有压力感应功能。

连接步骤根据设备类型略有不同。Wacom 数位板通过 USB 或蓝牙连接后，在系统设置中确认被识别，然后在 HiPaint 的「设置 → 设备连接」中选择对应数位板配对即可。主动式触控笔则需要先完成蓝牙配对，再进入「设置 → 绘图设置 → 触控笔」开启「使用压力感应」开关，此时用触控笔在画布上测试，线条粗细应该会随笔尖压力变化。

> [!TIP]
> 不同触控笔的压力曲线不同，可以在「压力曲线」中选择预设或自定义。软响应适合精细线条，硬响应适合素描排笔。

数位板和手绘板通常带有物理快捷键和滚轮，HiPaint 支持在快捷键设置中自定义每个按键的功能，比如切换画笔/橡皮、撤销/重做、缩放、切换图层等。
