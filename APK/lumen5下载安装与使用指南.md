## ✨ Lumen5 是什么：AI 驱动的文字转视频平台

Lumen5 是一款面向内容创作者和营销团队的 AI 视频制作工具，核心能力是**把一段文字自动生成分场景视频**。你只需要粘贴一篇文章、一段脚本甚至是几个要点，平台就能通过 AI 识别内容主题、匹配视觉素材、自动分配场景节奏，生成一条结构完整的短视频。

它的目标用户非常明确：没时间学专业剪辑软件、又需要持续产出视频内容的运营人员、自媒体博主、品牌营销团队。对比传统的「脚本 → 拍摄 → 剪辑 → 配乐」流程，Lumen5 把中间的视觉匹配和场景编排交给 AI，人只需要把控内容方向和品牌调性。

除了核心的文字转视频，平台还提供完整的品牌一致性管理——字体、配色、水印可以固化成品牌套件全片套用；媒体库支持上传自有素材并在项目间共享；团队档位内置协作闭环，从预览分享到场景级评论再到审阅通过，一条链路走完。

> [!NOTE]
> Lumen5 主要以在线 SaaS 形式运营，浏览器即可使用，无需安装桌面客户端。如果你在找传统意义上的「安装包下载」，请留意下方「下载入口」块的说明。

## 🔧 平台使用前置准备：注册与环境确认

Lumen5 本质上是一个网页应用，严格来说没有传统软件的「安装」步骤。但正确的前置准备能让后续的视频制作流程更顺畅。

**浏览器选择**：推荐使用 Chrome、Edge 或 Safari 的最新版本。平台的编辑器依赖较新的 Web 技术栈，旧版浏览器可能出现功能缺失或性能问题。打开官网注册账号后，首次进入编辑器会看到一个快速引导，教你粘贴第一篇文本。

**账号档位确认**：

| 档位 | 核心差异 | 适合人群 |
| --- | --- | --- |
| 免费档 | 有限渲染次数、带平台水印、部分高级功能锁定 | 个人试用、偶尔做条视频 |
| 付费档 | 去水印、自定义字体上传、品牌套件、共享素材文件夹 | 商业团队、持续产出需求 |

> [!WARNING]
> 自定义字体上传、团队协作、共享素材文件夹这些功能都属于付费档位，订阅前核对官方定价页的功能清单，避免上线后才发现缺少关键能力。

## 📖 使用入门：从第一篇视频到品牌化运营

### 素材是视频的根基：媒体库管理

平台自带一个相当完整的素材库，图片、视频片段、背景音乐都有覆盖。但真正让你的视频和别人拉开差距的，是**上传自有素材**——产品实拍、活动照片、公司出镜片段，这些才是观众能记住的「你的东西」。

上传入口在编辑器左侧媒体库面板的 Uploads 标签。支持的格式清单：

| 类型 | 格式 |
| --- | --- |
| 图片 | JPG、PNG |
| 视频 | MP4、MOV |
| 音频 | MP3、WAV |

不符合格式的文件先转一下再传。上传前建议过三道关：

1. **授权自查**：人物肖像、客户 Logo、字体版权——商用前确认来源干净；
2. **质量过筛**：手机拍的视频先看稳不稳、曝光对不对，模糊素材进了成片更明显；
3. **体积与时长**：超长视频先剪好再传，或者用平台专门的长视频剪短视频通道。

素材库的整理策略很重要——同一账号的所有项目共享这个库。推荐按项目或月份建文件夹、同一素材打多标签（比如产品图同时打「产品」和「发布会」），定期清理模糊和闲置素材。团队档位还支持共享素材文件夹，成员把审定过的品牌素材放进去，全组统一取用。

### 字体：全片统一，主副搭配

字体是影响成片观感的最大变量之一。在编辑器右侧 Style 标签里选择字体，**选中即应用到整条视频的所有场景**——没有逐场景设字体的选项。这保证了视觉一致性，也意味着挑字体要在开工前想清楚。

字体列表分两个位置：

- **主字体（primary）**：用于大标题和重点文字，选有性格的——粗壮、圆润、锐利各表不同气质；
- **副字体（secondary）**：用于辅助说明文字，清晰第一、装饰性第二。

一个组合定了就别每条视频换，观感的连续性比单条的新鲜感值钱。中文字体的覆盖范围以编辑器列表实际显示为准，中文视频开工前先确认目标字体对中文字符的支持，缺字会回退成默认字形、观感割裂。

> [!TIP]
> 内置字体库没有你要的品牌字体？付费档位支持上传 TTF 或 OTF 格式的自定义字体文件，上传后能存进品牌套件全团队共用。商用字体上传前务必确认许可覆盖「线上视频制作」这个用途。

### 文字颜色与高亮：不动背景只改字色

全局配色在 Style 标签的调色板层面搞定，但实际编辑中更常见的需求是**背景色满意、只想改某行字的颜色**。操作路径很直接：点击要改的文字进入编辑状态 → 顶部工具条点 Text color 或 Highlight 图标 → 弹出菜单里选色。

弹出菜单的结构值得记住：

- **当前色**：菜单顶部显示这块文字现在用的颜色；
- **调色板色**：下面一排是 Style 标签里定好的颜色，从这里选能保证全片用色统一；
- **新增颜色**：脱离调色板自由取色，支持 HEX/RGB/HSL 精确输入。

文字色和高亮色的分工不同：Text color 换的是整块文字本身的颜色，Highlight 是给选中部分加色底来突出局部关键词。一屏文字的典型组合是浅底深字为主、一两个关键词用品牌色高亮，层级清楚、观众视线有落点。字色是场景级操作，改完三五个场景后进预览整体过一遍，重点检查强调色是否一致、可读性是否充足。

### 预览分享：让同事和客户不装软件直接看片

视频做到一半想让人把关，传统流程是导出低清版、传网盘、发链接，对方看完提意见你再导一版。Lumen5 把这一段搬进了平台：**任何项目随时可以生成一个预览链接**，对方点开就能看，不用注册账号、不用下载任何东西。

预览页上能做的事远不止播放：

- 右侧有逐场景的评论面板，同事边看边在对应场景下留言；
- 底部工具条直达转录、翻译、改尺寸、复制链接。

三种高频用法：

1. **内部审核**：草稿阶段就把链接丢进工作群，比开会过片高效得多；
2. **客户确认**：把预览链接发给客户确认方向，不用给对方开账号权限；
3. **跨部门协作**：法务、品牌、产品各看各的，意见全部集中在一个项目的评论流里。

> [!NOTE]
> 预览链接的本质是「知道链接即可访问」，发给谁自己把关，敏感内容只发内部渠道。对外正式发布请走渲染下载流程，预览链接不是发布渠道。

### 一条省额度的工作流建议

把预览分享用成**固定环节**：每条视频发布前必走一轮「链接发出 → 收评论 → 修改 → 再预览」，两轮稳定后再渲染。渲染会消耗额度（免费档有次数限制），草稿阶段的意见都收完再渲染，一次到位最省。
