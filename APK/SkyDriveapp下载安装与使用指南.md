## ✨ SkyDriveapp 是什么

SkyDriveapp 是微软 OneDrive 的轻量客户端封装，核心能力是将本地文件与微软云盘无缝同步，同时继承 OneDrive 的勒索防护、版本历史、多端访问等完整生态。

它适合几类用户：需要跨电脑/手机/平板实时同步工作文档的职场人、习惯用手机拍照备份但担心丢数据的普通用户、以及希望用一个统一入口管理云端文件的个人用户。通过 Microsoft 账户登录后，所有上传的文件自动归入 OneDrive 体系，可以在任何平台继续访问和编辑。

SkyDriveapp 的优势在于背靠微软生态——Windows 10/11 内置、Office 文档直接在线协作、勒索防护提供一键还原、免费账户也有 5 GB 初始空间。与市面上其他网盘相比，它的文件随选机制（本地不存原件、需要时再下载）对磁盘空间紧张的用户特别友好。

## 🔧 安装与登录配置

### Windows 10/11 系统：无需安装直接启用

Windows 10 和 11 已内置 SkyDriveapp 客户端，首次使用只需找到应用并登录：

1. 按 `Win` 键搜索「OneDrive」或查看系统托盘右下角是否有云朵图标
2. 如果没找到，可在开始菜单 → 设置 → 应用 → 可选功能中检查状态
3. 打开后输入 Microsoft 账户邮箱和密码完成登录
4. 首次登录会弹出「这是你的 OneDrive 文件夹」提示，点击下一步即可使用默认路径

> [!TIP]
> 默认同步路径是 `C:\Users\<用户名>\OneDrive`，磁盘紧张时可以点击「更改位置」选择 D 盘或移动硬盘。

### Windows 7/8 系统：独立下载安装

较老版本 Windows 需要手动下载安装包：

1. 从上方下载入口获取安装程序
2. 双击运行安装向导
3. 安装完成后自动弹出登录界面

> [!WARNING]
> Windows 7 的同步支持已于 2021 年 3 月结束服务，如果仍在使用建议升级系统或改用网页端访问 OneDrive.com。

### 首次登录向导详解

登录成功后会依次引导完成几项核心设置：

| 设置项 | 说明 | 建议 |
|--------|------|------|
| 文件夹位置 | 默认 `C:\Users\<用户名>\OneDrive` | 磁盘紧张时改到其他盘 |
| 同步范围 | 选择要同步到本地的文件夹 | 新手选默认「全部同步」，后续随时可改 |
| 文件随选 | 默认对所有用户启用 | 本地不占空间，打开时自动下载 |

向导走完后，系统托盘的云朵图标变成白色实心，表示正在后台同步初始文件夹。右键云朵图标 → 设置 → 账户，如果显示你的 Microsoft 邮箱，就说明安装和登录都成功了。

## 📖 使用入门：从同步到防护的全流程

### 文件同步的基本逻辑

SkyDriveapp 的核心就是同步——把本地文件夹和云端 OneDrive 保持一致。同步有三种触发场景：

- 你在本地 OneDrive 文件夹里新增/修改/删除文件 → 自动上传云端
- 你在网页端或其他设备上修改了云端文件 → 自动下载到本地
- 共享文件夹的其他成员修改了内容 → 本地自动更新

> [!NOTE]
> SkyDriveapp 默认启用「文件随选」机制：OneDrive 文件夹里的文件看起来都在本地，但只有真正打开时才下载到磁盘。右键文件可以手动切换「始终在此设备上保留」或「仅联机可用」。

### 手机照片自动备份

这是 SkyDriveapp 最实用的功能之一，可以让手机照片再也不怕丢：

**Android 开启步骤：**

1. 安装登录后，通常会弹出「开启相机胶卷」引导页，直接点「开启」
2. 或事后手动：左上角头像 → 设置 → 相机胶卷 → 打开开关
3. 选择上传时机（推荐仅限 Wi-Fi，省流量又安全）

**iOS 开启步骤：**

1. 左上角头像 → 设置 → 相机胶卷备份 → 打开开关
2. 选择 Wi-Fi 或任何网络
3. 可选开启「包含视频」
4. 如果上传经常中断，检查 iPhone 设置 → OneDrive → 后台应用刷新是否开启

备份的照片会自动存到云端「相机胶卷」文件夹，按拍摄日期组织子文件夹。换新手机时登录同一个 Microsoft 账户，照片会自动出现在云端，下载到本地即可。

### 网页端：不需要安装的管理中枢

SkyDriveapp 客户端之外，OneDrive.com 网页端是完整的管理入口，任何设备浏览器打开就能用：

- **没装客户端**：任何电脑浏览器直接访问，临时取文件特别方便
- **完整管理功能**：勒索软件一键还原、订阅管理、存储详情、关联设备管理——这些高级功能只在网页端提供

**网页端 vs 客户端功能对比：**

| 对比项 | 网页端 | 桌面客户端 | 手机客户端 |
|--------|--------|-----------|-----------|
| 自动同步 | ❌ | ✅ | ❌ |
| 离线访问 | ❌ | ✅ | ✅（手动下载） |
| 勒索一键还原 | ✅ | ❌ | ❌ |
| 需要安装 | ❌ | ✅ | ✅ |
| 跨设备通用 | ✅ | 绑定 OS | 绑定移动 OS |

### 勒索软件防护与整体还原

SkyDriveapp 继承的 OneDrive 勒索防护是付费账户最核心的安全功能。如果云端文件被加密或大面积损坏，可以一键还原：

**什么时候需要还原：**

- 勒索软件攻击后，本地和云端文件被加密
- 误操作导致批量重命名或覆盖
- 账户被入侵后攻击者破坏了云端内容

**还原步骤（必须在网页端操作）：**

1. 用一台**未被感染**的安全设备浏览器访问 OneDrive.com
2. 登录 Microsoft 账户
3. 如果收到勒索警告横幅，点击「还原」直达还原页面；否则访问 OneDrive.com/restore
4. 在时间轴上拖动滑块选择攻击前 1-2 小时的安全还原点（避开蓝色异常区域）
5. 预览确认后点击「还原」——操作立即开始，没有回头路

> [!WARNING]
> 整体还原只能回到过去 **30 天内**的时间点，还原点之后新建的所有文件会被删除。免费账户不支持此功能，建议存储重要文件的用户升级到 Microsoft 365。

**还原后本地处理：**

云端还原成功后，本地 OneDrive 客户端检测到变更会自动同步，用云端正常版本覆盖本地被加密的文件。记得还原完成后用杀毒软件全盘扫描确认病毒已清除，并检查账户安全设置（更改密码、开启两步验证、删除可疑登录设备）。
