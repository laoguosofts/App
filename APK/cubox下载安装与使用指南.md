## ✨ Cubox：让碎片阅读真正沉下来的稍后阅读工具

Cubox 是一款跨平台的收藏与稍后阅读工具，核心理念是「收 → 看 → 整理」一条龙。无论是手机上刷到的文章、桌面浏览器里想留着慢慢读的长文，还是微信里别人转发的干货链接，Cubox 都能帮你统一收进一个地方，按自己的节奏慢慢消化，最后整理成结构化的知识库。

它的覆盖相当广：iOS、Android、Mac、Windows、网页端，外加四大主流浏览器都有官方扩展，账号打通之后，任何一端收藏的内容在所有设备上自动同步。桌面端扩展更是关键入口——一键收藏、只存片段、原网页高亮标注、搜索引擎查重提醒这些功能，让收藏这件事从「打个标签就忘了」变成「进来就能用」。

适合谁？信息摄入量大的人。比如每天刷公众号、技术博客、行业资讯，收藏夹积灰到找不到当初为什么存这篇的；或者有学习项目需要大量参考资料，想把散落各处的内容集中管理。Cubox 不是那种花哨的笔记软件，它更像一个帮你把信息洪流过滤、沉淀、归档的漏斗。

## 🔧 安装与首次上手

### 桌面端：浏览器扩展是核心入口

Cubox 在四个主流浏览器里都有官方扩展，这是桌面端最高频的操作入口：

| 浏览器 | 安装方式 |
|---|---|
| Chrome | 应用商店直接搜 Cubox 安装；国内访问商店不便时，下载页提供 crx 包手动加载 |
| Edge | Edge 加载项商店搜索安装 |
| Safari | Mac 上通过独立的 for Safari 应用授权扩展 |
| Firefox | 官方附加组件网站安装 |

> [!TIP]
> 扩展装完一定要登录跟手机端同一个账号。登录后扩展会自动接管所有收藏动作，收藏的内容直接进你的云端库，不用在设备之间手动搬。

### 移动端：常规安装流程

iOS 用户在 App Store 搜索 Cubox 直接安装；Android 用户在应用市场或官网下载 apk 文件。Android 如果是首次安装非商店来源的包，系统会提示「未知来源」，在设置里给该应用授权即可。

> [!WARNING]
> Cubox 的 Pro 和 Pro+AI 会员分档，免费版功能也不少，但嵌套收藏夹、AI 摘要之类进阶功能需要解锁。下载安装本身不收费，会员在应用内或网页端按需购买。

### 首次登录：选一个主账号

首次打开会让你用微信、Apple ID 或邮箱注册登录。一个常见的坑：微信登录和 Apple ID 登录各自建一个独立账号，如果两台设备用了不同登录方式，看起来就像「数据丢了」。**所有设备必须登录同一个账号**。

## 📖 使用入门：收藏、整理与排查

### 扩展里能做什么

浏览器扩展装好后，你在任何网页上都有四个动作：

1. **一键收藏整页**：点扩展图标，弹窗里可以顺手改标题、选收藏夹，存完即同步
2. **剪藏片段**：不想存整篇，只选中某一段再点扩展，只存选中的部分——对长文章里只要某一节的场景特别好用
3. **原网页高亮**：不离开当前页面，直接用扩展提供的标注工具划重点，标注自动进你的库
4. **搜索引擎查重提醒**：你在 Google、Bing 搜东西时，扩展会悄悄告诉你「这个结果你之前收藏过」，既避免重复劳动，也帮你想起之前收了什么

桌面重度用户推荐「扩展 + 网页版」组合，Mac 用户再配一个 Mac 助手补足系统级快捷收藏，Windows 用户直接用网页端或 PWA 就够。

### 收藏夹：像书架一样分层

Cubox 对收藏夹和标签的分工很清晰：收藏夹是书架，负责「归属」，同一个主题或项目的内容放一起；标签是便利贴，负责跨类别的维度标记，一篇内容可以贴多个标签但只能归属一个收藏夹。

免费版是单层收藏夹，数量不限；Pro 会员解锁嵌套之后可以创建子收藏夹。但层级不要搞太深，经验上不超过三层——层数一深，存放和查找都要靠记忆导航，违背了收藏的初衷。

一套被广泛验证的分层思路：

- **顶层按人生板块**：工作、学习、兴趣、灵感——这些大分类五年都不会变
- **中层按项目**：某个具体项目、某次调研、某门课——做完可以整体归档
- **拿不准的先丢未分类**：宁可堆在未分类也不要猜一个错分类，攒多了用智能列表兜底

> [!NOTE]
> Cubox 允许「先收藏后整理」，这是官方认可的节奏。不需要一开始就把结构调到完美，内容积累起来再动手整理反而更务实。

### 收藏夹和智能列表怎么配合

收藏夹是手动放进去的秩序，智能列表是按规则自动生成的秩序——两者不冲突。同一批 AI 主题的内容，你可以把最核心的参考资料放进「工作 / AI 项目」收藏夹，同时用智能列表按标签自动聚合所有带了 #AI 标签的内容，两个视图各有用处。

### 会员到期了数据还在吗

在。官方在定价页和 FAQ 里反复强调这一点：即使会员到期不续费，账号数据会被完整保留，随时可以导出你的链接和标注。在订阅制工具里这是少见的承诺——对很多人来说，这是比「功能多强」更实在的安全感。

自动续费方面：App Store 渠道默认续订，不打算续就在到期前去系统订阅管理关掉；网页支付宝渠道到期不自动续订，想续手动再买就行，提前续费还能锁价。

### 同步出问题按这个顺序排查

多端数据不一致是最常见的困扰，官方 FAQ 加上社区实操经验，排查顺序固定四步：

1. **手动刷新**：下拉刷新或进设置点同步，先排除「只是还没轮到」
2. **确认账号**：检查各端登录的是不是同一个账号——微信登录和 Apple ID 登录各建各的号，混用了数据就在另一个账号里
3. **重启应用**：刷新数据、完全退出重启、再不行就重新登录
4. **网络环境**：部分站点的解析和封面资源在国内访问受限，同步慢与此相关，耐心等

### 账号注销前记得导出

官方提供删除账户和数据的入口，但注销前一定要先做一次完整导出，Cubox 支持导出为 Markdown、HTML 和 PDF 三种格式。关于数据安全，官方声明账户和数据其他用户看不到，不出售和使用个人数据，产品里也没有社交推荐和算法推送。
