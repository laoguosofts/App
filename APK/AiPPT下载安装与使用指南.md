## ✨ AiPPT 是什么

AiPPT 是一款主打"一句话生成 PPT"的 AI 演示文稿工具，面向从学生到企业团队的广泛用户群。它的核心逻辑很清晰：用户输入主题或一段文字大纲，AI 自动完成选题、找素材、排版、配色全套流程，几秒内产出一份可编辑的 PPT 文件。

工具矩阵覆盖五种形态：网页版、Windows 客户端、Office/WPS 插件、iOS App 以及面向开发者的开放平台 API。同一个账号跨端同步，功能有重叠但各有侧重——很多人遇到的"怎么这里没有这个功能"，其实是用错了形态。

网页版适合首次体验和临时设备，注册即用；客户端把作品管理收拢在本地视角，适合固定工位的重度用户；插件让你不用离开 PowerPoint/WPS 就能生成、换模板、统一字体；手机 App 主打改稿和会前快速过一遍，小屏不适合大规模排版但胜在便捷；开放平台 API 则为有开发资源的团队提供把生成能力接进自家产品的路径。

除了生成主线，还有两个容易被忽略的配套：独立模板站（2025 年 11 月上线的新版）支持按主题、颜色、风格筛选下载模板文件；给 PowerPoint 和 WPS 用的设计增强插件内置 30 余款设计工具与五大素材库。这两套与生成主线互相独立，可以只当模板库用，也可以全套打通。

## 🔧 安装步骤

### 网页版——零安装直接用

最简单的方式：浏览器访问平台官网，注册账号即可。这条路径适合第一次接触 AiPPT 的用户，注册后能完整体验从创建到导出的全链路，不用折腾任何安装步骤。

> [!TIP]
> 网页版功能随版本更新最快，但也意味着界面和功能位置可能随时调整，重度办公用户建议尽快切换到客户端或插件。

### Windows 客户端安装

1. 从官网下载客户端安装包，文件大小约几十 MB；
2. 双击安装包，选择安装路径——默认装在系统盘，建议改到非系统盘方便后续备份；
3. 安装完成后首次启动会提示登录账号，用网页版注册的同一账号登录即可；
4. 登录后工作台会显示你在网页版上的全部历史作品，确认一下同步是否正常。

> [!WARNING]
> 安装过程中如果被杀毒软件误报拦截，优先在杀毒软件里把 AiPPT 加入信任区，而不是关闭防护。官方签名的安装包不会包含恶意代码。

### Office/WPS 插件安装

插件的安装门槛比客户端略高，需要满足：

- 已安装 Microsoft PowerPoint（2016 及以上版本）或 WPS Office；
- 系统为 Windows 或 macOS；
- PowerPoint/WPS 允许加载第三方插件（部分企业 IT 策略可能会禁用）。

安装完成后打开 PowerPoint 或 WPS，菜单栏会多出一个 AiPPT 入口，里面包含生成、换模板、统一字体等全部功能。

### iOS App 安装

App Store 搜索"AiPPT"直接下载即可，免费版就能跑通全部核心功能。

## 📖 使用入门

### 先选对形态

第一次使用时最容易踩的坑就是选错形态。下面这张速查表帮你快速定位：

| 你的场景 | 推荐形态 | 理由 |
| --- | --- | --- |
| 第一次体验、临时设备 | 网页版 | 零安装，完整体验链路后再决定 |
| 每周都要出稿 | 客户端 + 插件 | 客户端管作品、插件让你在 PowerPoint 里直接生成 |
| 会前手机上改改稿 | iOS App | 小屏便携，改标题和顺序够用 |
| 要接进自家产品 | 开放平台 | 有 API（自定义界面）和 iframe（快速嵌入）两种接法 |

### 自定义模板——投入产出比最高的二十分钟

官方模板再好用也是别人的风格。如果你的公司有固定 VI（logo、标准色、字体规范），或者团队有惯用版式，自定义模板功能值得花一次时间认真标一遍——之后每次生成都能自动套用。

完整流程分四步：

1. **进入**：工作台"快速创建"区点"自定义模板"入口；
2. **上传**：把本地的 PPT 模板文件传上去——适合上传的模板最好是结构完整的，封面、目录、章节过渡、内容页、尾页都齐的那种，内容页还需要留好明确的"内容位置"；
3. **打标**：进入编辑器后逐页标注角色。右侧面板会出现六种标签：主题页、目录页、章节页、内页、尾页、页面配色；
4. **保存**：完成后点保存，下次生成时模板选择里就能看到你的自定义模板了。

> [!NOTE]
> 打标是整个流程里唯一需要动脑的一步。标对了 AI 生成的每页内容都落对位置；标错了后面每份稿子都要手动救。公测期功能，保存前多检查一遍。

五种页面角色各自的标注要点：

| 角色 | 标注时确认 |
| --- | --- |
| 主题页（封面） | 标题占位符存在，合成时保留画布全部内容 |
| 目录页 | 目录结构与章节标题能一一对应 |
| 章节页 | 有章节序号或标题占位 |
| 内页（内容页） | 必须有标题位置概括该页要点——这是最容易漏的 |
| 尾页 | 文案占位就位 |

两个最易错的地方：一是页面配色的深浅模式选反——深底选深色、浅底选浅色，选反了文字颜色会自动配错；二是主题色漏设——做企业稿时六个颜色一组的主题色不能省，个人用户可以跳过。

打标完成后用这份模板真生成一次 3-5 页的短稿验收，逐页核对封面标题位置、目录条数、内页正文是否溢出、尾页是否正常出现。一次验收，长期受益。

### 免费版额度怎么读

免费版能完整跑通"生成-编辑-导出"链路，但次数额度紧，适合低频用户和试用评估。关键权益：

| 权益项 | 额度 |
| --- | --- |
| AI 生成 PPT | 每天 2 个，累计共 6 个 |
| AI 积分 | 注册即送 1000 |
| 一键优化 | 配色、背景、字体字号 |
| 文档导入 | 支持 Markdown 和思维导图 |
| 文件库容量 | 100MB |
| AI 图像生成 | 每月 50 次 |
| AI 助手 | 每天 10 次 |

两个容易忽略的细节：一是"每天 2 个、共 6 个"是两层限制——日上限 2 个，免费期内总量 6 个，用完 6 个后日额度也不再恢复，这和很多产品"日刷新"的逻辑不同；二是 Markdown 和思维导图导入明确列在免费权益里，说明大纲导入这条路免费可用。

> [!TIP]
> 低频用户的省钱用法：每天 2 个生成额度留给真正要交的稿，试验性需求先用大纲阶段过瘾（大纲确认不消耗成品额度）；生成前把生成设置和专家画廊调好，一次生成到位——重试烧的是自己的额度。

升级时机的信号：日 2 次不够用、需要更高质量模型、文件库频频爆、要用高级图像模型。临时大项目也可以按月买，用完即止。

### 生成链路里藏的精控项

在点击生成之前，花一两分钟调一下生成设置能显著减少返工：

- **专家画廊**：官方收集了一批特定场景的优质生成案例作为"风格种子"，选一个和你的主题接近的，可以让 AI 输出更贴合该场景的审美；
- **生成设置**：控制生成的页数区间、配色倾向、是否需要封面和尾页等，这些设置在大纲阶段就能调，不消耗生成额度；
- **大纲确认**：大纲是 AI 生成的骨架，先过一遍大纲再让 AI 填内容，比直接生成后大改效率高得多。
