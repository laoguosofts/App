## ✨ JISOO App 是什么

JISOO App 是韩国女团 BLACKPINK 成员金智秀（JISOO）个人的官方粉丝应用，由 BIBIDI PTE.LTD 开发运营。这款 App 为全球粉丝提供了一个直接接触智秀的专属渠道，涵盖独家照片与视频发布、私人聊天互动、直播观看、行程日历等核心功能，是粉丝获取一手资讯和进行近距离互动的官方平台。

App 提供免费和会员两种使用模式。免费用户可以浏览大部分公开内容、查看行程日历、接收推送通知；订阅会员则能解锁私人聊天、投票参与、独家内容以及直播观看等高级权限。

隐私方面，开发者在 App Store 的 App Privacy 页面明确声明：**「开发者不会从本应用收集任何数据」**。这意味着你的位置、通讯录、浏览记录、设备识别信息等都不会被采集，麦克风和摄像头数据也仅在你主动使用相关功能时才会被调用。

## 🔧 安装步骤

### iOS 用户（iPhone / iPad）

1. 打开 **App Store**，在搜索框输入 "JISOO App"
2. 确认开发者为 **BIBIDI PTE.LTD**，点击获取安装
3. 首次打开时，系统可能会请求推送通知权限和相册权限，按需授权即可
4. Apple Silicon Mac（M1 及以上芯片）也可以直接从 Mac App Store 下载安装，实现桌面端使用

### Android 用户

1. 打开 **Google Play**，搜索 "JISOO App"
2. 确认开发者信息后点击安装
3. 如果在国内无法直接访问 Google Play，可前往上方官方下载页获取安装包（APK 文件），安装前需在系统设置中开启「允许安装未知来源应用」
4. 安装完成后，首次打开建议在系统设置中检查 App 的权限配置，按需授予或关闭

> [!NOTE]
> 安装前务必核对开发者名称为 **BIBIDI PTE.LTD**，避免下载到仿冒应用。iOS 用户直接从 App Store 下载最为安全。

### 安装后的验证

打开 App 后完成注册登录流程（支持邮箱注册），进入首页能看到智秀的最新动态和照片流，说明安装成功。建议检查一下「我的 → 设置 → 关于」中的版本号，确保是较新的版本以获得更好的功能支持。

## 📖 使用入门

### 账户注册与安全

App 支持邮箱注册，注册完成后可在「我的」页面管理个人信息。以下是几个重要的账户安全习惯：

- **使用强密码**：建议至少 8 位，包含大小写字母和数字，避免使用生日、手机号等容易被猜测的组合，且每个应用使用独立密码
- **保护注册邮箱**：注册邮箱是找回账号的唯一方式，确保邮箱能正常登录，并为邮箱本身开启两步验证
- **不要共享账号**：一个会员账号仅限一人使用，违反条款可能导致账号被终止且不退款

### 核心功能概览

安装登录后，你会发现 JISOO App 的功能围绕「内容消费」和「互动沟通」两大板块展开：

**内容消费**：首页持续更新智秀发布的照片和视频，部分独家内容仅限会员查看；行程日历方便粉丝追踪智秀的公开活动安排；推送通知确保你第一时间收到新动态。

**互动沟通**：订阅会员可以发送私人消息与智秀对话，还能参与 App 内的投票活动；直播功能是会员的核心福利之一，提供独家的实时观看体验。

### 自动翻译（聊天必备）

对于中文用户来说，智秀发布的内容和聊天消息大多是韩文或日文。App 从 v2.7 版本开始内置了**自动翻译**功能，彻底解决了语言障碍问题。

开启方法很简单：

1. 进入与智秀的私人聊天窗口
2. 点击聊天界面右上角的设置图标
3. 找到「自动翻译」选项并打开
4. 选择目标语言为**简体中文**

开启后，智秀发来的消息会自动翻译成你选择的语言直接显示，无需手动逐条点击翻译按钮。原始韩文内容仍可随时切换查看。

> [!TIP]
> 自动翻译是会员专享功能，如果找不到开关，请确认你的 App 版本在 v2.7 以上且已完成会员订阅。

### 直播使用注意事项

直播是会员最期待的功能，但也是违规风险最高的环节。以下行为会触发账号处罚：

| 禁止行为 | 违规后果 |
| --- | --- |
| 录屏直播内容 | 警告，多次可能终止会员 |
| 评论区刷屏 | 评论功能临时限制（数小时至数天） |
| 发送不当言论 | 评论删除 → 账号警告 → 严重封禁 |
| 共享会员账号 | 账号立即终止，不退款 |

v2.11 版本后开放了截图权限，但**仅限个人使用**，不要大量截图打包外传或用于商业用途。录屏仍然严格禁止，系统会自动检测并触发警告。

### 隐私权限管理

虽然官方声称不收集用户数据，但 App 仍会向系统申请一些权限，你可以按需调整：

- **位置权限**：可能用于日历事件相关功能，设为「从不允许」不影响核心使用
- **推送通知**：由 Apple/Google 提供的系统级服务，App 本身不收集通知内容
- **相册权限**：保存照片或发送图片时需要，可以选择仅允许选择的照片

### 退订与会员管理

会员采用自动续费制，但可以随时取消订阅：

- **iOS 用户**：App Store → 你的账号 → 订阅 → 找到 JISOO App → 取消
- **Android 用户**：Google Play → 支付和订阅 → 管理订阅 → 取消

取消后订阅有效期保持到当前周期结束，不会再产生扣费。

> [!WARNING]
> 账号注册邮箱是找回密码和恢复会员状态的唯一凭证。如果更换邮箱，请确保在旧邮箱还能登录时及时更新。

### 常见问题速览

**聊天是真实回复吗？** 根据应用描述和官方声明，回复来自智秀本人，但她不可能每条消息都亲自回复，会在自己的时间查看并回复粉丝消息，频率和数量不固定。

**免费用户能看到什么？** 免费用户可浏览大部分照片和视频（部分独家内容除外）、查看行程日历、接收通知。会员额外解锁私人聊天、投票、独家内容和直播。

**支持电脑使用吗？** iOS 版本可在 Apple Silicon Mac（M1 及以上）上运行；Android 版本可通过 BlueStacks 等模拟器在 Windows 上使用。

**为什么没有推送了？** 依次检查：系统通知权限是否关闭 → 手机是否处于勿扰/专注模式 → App 内通知偏好是否关闭了对应类型。
