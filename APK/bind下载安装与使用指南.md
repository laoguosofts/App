## ✨ Bind 是什么

Bind 是一款面向情侣和亲密关系的实时定位与状态共享应用。它的核心定位很明确——让两个人在不追问的情况下，就能知道对方在哪里、在做什么、手机是不是在手上。不同于市面上那些主打"追踪"或"防出轨"的同类产品，Bind 从设计理念上强调双向和自愿：所有权限都是双方互相授予，关掉一个开关彼此就同时失去查看能力。

它能做的事情大致分成三类。第一类是位置相关的基础能力：实时位置查看、出入指定地点的自动提醒、轨迹历史回放。第二类是手机状态报备：屏幕亮灭、使用时长、电量、充电状态，每 1~3 分钟自动刷新一次，双方同步可见。第三类是情侣之间的轻娱乐协作：同屏看视频、同步听歌、远程闹钟叫醒——这些功能虽然不是 Bind 独有的，但和定位状态结合在一起，场景感就完全不一样了。

适用人群很清晰：异地情侣高频通话想知道对方是不是安全到家、共同生活的伴侣想确认"他现在是在加班还是在路上"、甚至是父母想给未成年孩子多一层放心——只要双方自愿安装并互相绑定，就能使用。

## 🔧 安装步骤

Bind 同时支持 iOS 和 Android 双平台，两边的安装流程差异不大，但首次授权环节各有细节需要注意。

**iOS 安装流程**

1. 打开 App Store 搜索 "Bind"，确认开发者名称后点获取。
2. 首次打开会依次请求位置权限、通知权限、屏幕使用时间权限。
3. 位置权限选"始终允许"——选"仅使用应用时"会导致后台定位失效，出入自动提醒功能不工作。
4. 屏幕使用时间权限是 Bind 读取手机状态的关键。系统会弹出专门的授权页，点"将所有分类"打开，否则对方看不到你的手机使用数据。
5. 通知权限建议全部开启，自动报备和出入提醒都依赖推送。

**Android 安装流程**

1. 如果应用商店无法获取，可以从官方下载页获取安装包。安装前需要在系统设置里允许"未知来源"安装。
2. 首次打开会请求位置、通知、后台启动、Usage Stats（使用情况访问权限）、电池优化白名单这五项权限。
3. Usage Stats 是 Android 上的屏幕使用时间接口，系统不会自动弹窗——需要手动跳转到"设置 → 隐私 → 使用情况访问"页面找到 Bind 并开启权限。
4. 电池优化白名单务必开启，否则系统会在锁屏后杀死 Bind 的后台进程，所有定位和状态更新都会中断。
5. 部分国产 ROM（小米、华为、OPPO）需要额外在系统安全中心里把 Bind 加入自启动名单，否则重启后应用不会自动运行。

> [!WARNING]
> **权限缺失的后果很隐蔽**。很多人装完 Bind 发现"对方一直显示在家但人明明出门了"，排查下来 90% 是位置权限没选"始终允许"或者没加电池白名单。装完之后打开应用跑 5 分钟，让对方走一段路，确认位置能正常更新再放心。

**版本核对**

下载页提供的版本号和应用商店里的版本号可能有差异。建议始终以最新版本为准——Bind 的权限模型和定位算法更新比较频繁，旧版本可能无法正常获得系统级权限。

## 📖 功能上手与日常使用

### 实时位置与自动报备

这是 Bind 最基础也最常用的能力。打开应用，对方头像下方就是实时位置摘要，格式通常是"XX 路，步行中"或"在家，停留 15 分钟"。位置每 1~3 分钟自动刷新一次，精度取决于系统定位能力——室外通常能做到 10 米以内，室内会跳回到楼栋级。

自动报备是一个很实用的衍生功能。你可以在"设置 → 地理围栏"里添加几个常用地点（家、公司、学校），对方进出这些地点时，Bind 会自动推送一条通知。不需要对方主动发消息，你就能知道"他到公司了"或者"他已经离开家了"。

### 手机使用状态

在对方头像下方，除了位置还有一排状态图标——这是 Bind 的特色功能之一：

- 拿着手机时显示握拳手势图标，放下手机不动时变成灰色圆圈，正在充电会叠加闪电标记。
- 下拉可以看到今日使用时长（屏幕亮着的累计时间）、今日解锁次数、最近一次拿起手机的时间戳。

> [!NOTE]
> Bind 不记录具体使用了什么应用——你在用微信还是刷抖音，对方只会看到"在玩手机"，不会知道具体内容。这一点在隐私设计上做得比较克制。

**双向授权是核心**。你能看对方的手机状态，前提是对方也授权了这个权限；反过来对方关掉权限，你也立刻看不到他的。随时可以在"我的 → 隐私设置 → 手机动态"里关闭。

### 桌面小组件与锁屏横幅

不想每次打开 App 才看对方状态？Bind 提供了三种尺寸的桌面小组件和锁屏常驻横幅。

**桌面小组件（三个尺寸）**

| 尺寸 | 显示内容 |
| --- | --- |
| 小 | 头像 + 位置摘要（如"在家充电"） |
| 中 | 头像 + 位置 + 距离 + 今日步数 + 电量 |
| 大 | 以上全部 + 轨迹缩略图 + 纪念日倒计时 |

添加方式因平台而异：iOS 长按桌面空白处点"+"搜索 Bind；安卓各品牌路径不同——小米在"添加工具"、华为在"窗口小工具"、Pixel 在"Widgets"里。

> [!TIP]
> 小组件不更新时不用慌。iOS 的刷新频率受系统限制（15 分钟一次），安卓部分品牌（小米 MIUI）可以在小组件设置里手动调低刷新间隔。如果长时间停在旧数据，长按移除后重新添加一次通常就能恢复。

**锁屏横幅**

锁屏横幅是一小块常驻信息条，解锁前就能看到对方动态。比如对方在路上时显示"Ta 正在 XX 路，步行中" + 距离，到公司后变成"Ta 已到达公司，停留 23 分钟"。iOS 16 以上支持锁屏小组件，安卓原生支持锁屏常驻刷新。

内容可以自定义：只显示位置、只显示手机状态、或者都显示。隐私敏感的字段（比如精确地址）可以隐藏，还能设置静默时段（比如凌晨 2~6 点不显示）。

### 免费版与会员版怎么选

很多人以为 Bind 是纯付费应用——其实核心定位和自动报备都是免费的。下表一目了然：

| 功能 | 免费版 | 会员版 |
| --- | --- | --- |
| 实时位置查看 | ✅ | ✅ |
| 出入自动提醒 | ✅ | ✅ |
| 手机状态/电量报备 | ✅ | ✅ |
| 同屏看视频 | ✅ 有次数限制 | ✅ 无限制 |
| 同步听歌 | ✅ | ✅ |
| 桌面小组件 | ✅ 基础版 | ✅ 高级版 |

会员的价值集中在三个维度：

- **更精细的定位**：楼层级精准定位（免费版最高到楼栋）、自定义地理围栏形状（免费版只能画圆）、最快/最高速度统计。
- **更长的历史**：30 天轨迹回放（免费版只有当天）、约会地点完整历史（免费版只看最近 5 次）、月度行程自动报告。
- **无限制的娱乐**：同屏看视频无次数限制、主题色全部解锁、语音通话时长包折扣。

**选购建议**：刚装 Bind 先用免费版跑一周，把权限设对、同屏功能用几次、出入提醒触发几次。异地情侣高频使用推荐上会员——楼层定位 + 历史轨迹是免费版没有的硬差异。只是偶尔用用的话免费版完全够用。
