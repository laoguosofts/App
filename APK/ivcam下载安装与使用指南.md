## ✨ ivcam 是什么

iVCam 是一款把手机变成电脑高清摄像头的工具软件——在手机上装 App、电脑上装客户端，两端连上之后，手机的摄像头画面就会以虚拟摄像头的形式出现在电脑系统里，直接被 OBS、Zoom、微信、浏览器等所有能调用摄像头的软件识别使用。

它支持 iOS 和 Android 两端手机，电脑端覆盖 Windows。连接方式灵活，Wi-Fi 自动发现、手动输 IP、USB 数据线三种都能走，传输的画面默认走硬件解码，对电脑 CPU 占用很低。适合做直播补机位、远程网课摄像头、视频会议外设，或者直接替代电脑自带的低画质摄像头。

| 对比项 | 手机原生摄像头 | 普通 USB 摄像头 | iVCam |
|---|---|---|---|
| 最高画质 | 依赖手机硬件，通常 4K | 受限于摄像头本身，多为 1080p | 跟随手机摄像头规格，可到 4K |
| 延迟 | 本地 | 低 | 取决于连接方式，USB 最低 |
| 便携性 | 随身 | 需额外携带 | 利用已有手机 |
| 多机位扩展 | 需多台手机各自录像 | 需多根 USB | 一台电脑可连多台手机同时工作 |

## 🔧 安装步骤

iVCam 的安装分两端——手机端和电脑端，顺序无所谓，但两端都装好才能连接。

**手机端：**

1. App Store 或 Google Play 搜索「iVCam」，认准开发者名称，直接点安装。
2. 首次打开 App 时，系统会弹出摄像头权限请求，**必须允许**——这是 iVCam 的数据源。
3. 如果是 Android 手机，部分机型还会请求麦克风和通知权限，一并允许即可。

> [!TIP]
> iOS 用户注意：App Store 上有多个同名 App，务必确认图标和开发者信息与官方一致再下载，避免装到仿冒品。

**电脑端（Windows）：**

1. 从下载页拿到安装包，双击运行安装程序。
2. 安装过程一路默认即可，程序会自动把虚拟摄像头驱动注册到系统。
3. 安装完成后首次启动，Windows 防火墙可能弹出网络请求——**允许专用网络**，否则 Wi-Fi 连接会被阻断。

> [!WARNING]
> 电脑端安装时如果杀毒软件拦截驱动注册，选择「允许此操作」。iVCam 的虚拟摄像头驱动是核心组件，被误拦截后画面不会出现在系统里。

**装好后核对：**

- 电脑打开「设备管理器 → 摄像头」，能看到「e2eSoft iVCam」设备。
- 手机打开 App，首页应该显示等待连接状态。
- 两端都能正常启动、不报错，就算安装成功。

## 📖 使用入门

### 硬件解码：让 CPU 歇一歇

iVCam 客户端默认开启硬件解码——视频用显卡解码，显卡不支持或解码失败时会自动回退 CPU 解码。CPU 解码不是不能用，而是占用高，4K 视频软解时 CPU 会明显吃紧，连带系统变卡。

硬件解码的门槛不算高：NVIDIA GTX 750 Ti / 760 及以上、AMD Radeon R9 285 及以上、Intel 核显普遍支持 H.264 与 HEVC。近十年的显卡基本都在线内。

客户端的硬件解码相关设置集中在 **设置 → Miscs** 菜单，共三处可调：

- **Hardware Decoding 开关**：画面黑屏、花屏时先把它开/关切换一次，很多异常能直接解决。
- **Hardware Decoder 选择**：显卡可能有多个解码后端，逐个切换试出效果最好的那个。
- **Preferred GPU 指定显卡**：双显卡电脑（核显 + 独显）可以指定 iVCam 用哪块 GPU。直播软件和 iVCam 抢一块卡时，把它们分到不同 GPU 上能明显缓解卡顿。

日常使用中，遇到 CPU 占用持续很高就先确认硬解已开；画面黑屏或异常就切换硬解开关、换解码器；直播 + iVCam 同时卡时用 Preferred GPU 分卡。进阶玩家还能改注册表把解码和编码拆到两块卡上，但日常用 Preferred GPU 就够。

### 画面频闪：帧率快门对上市电

画面出现规律性的明暗滚动或条纹波动，尤其在灯下拍摄时明显——这就是频闪。成因是摄像头快门 / 帧率与灯具的交流电频率不同步：市电以 50Hz（中国 / 欧洲）或 60Hz（美国 / 日本）驱动灯光亮度波动，摄像头采样节拍没对上就会拍到亮度差的帧。

最直接的对策是把帧率压到市电频率以下：

- **50Hz 市电环境**（国内绝大多数）→ 帧率设 **25fps**，官方推荐值。
- **60Hz 市电环境**（美国日本等）→ 帧率设 **30fps**。

如果帧率调了还闪，继续把快门（曝光时间）压到市电频率以下。手机端长按画面进入 AE/AF LOCK，然后上下滑动调整曝光时间；电脑端打开相机设置窗口调曝光时间滑杆。快门慢于市电频率，每帧都能接住完整的亮度周期，频闪自然消失。代价是快速运动画面的拖影会变明显，静态场景无所谓。

还有一个容易忽略的原因：**人脸美颜功能在某些灯光环境下本身就会引起闪烁**——排除了市电因素还闪时，把美颜关掉试试。

> [!NOTE]
> 快速判断归因：换到自然光 / 靠窗环境不闪了 → 灯光频闪，用上面三条对策；任何光线下都闪且是无规律的闪 → 不是市电问题，去查软件层设置和驱动版本。

### 多台手机连一台电脑：多机位玩法

一台电脑可以同时连接多台手机，比如一台拍正面、一台拍侧面，或一台拍桌面特写。iVCam 客户端支持多实例运行，每个实例接一台手机，是独立的虚拟摄像头设备。

连接方式：

- 每台手机都装 iVCam App，连到同一台电脑。
- 连接第二个及之后的实例时，手动 IP 里的实例号填对应序号（如 iVCam #2 连第二个实例）。
- 自动发现模式下多台手机会自动分配到空闲实例。

电脑端多开几个 iVCam 客户端窗口即多实例，每个窗口对应一块摄像头画面，分辨率、帧率、解码设置可以独立配置——特写机位开高清、全景机位开 720p 控带宽。

但多机位是带宽和 GPU 的双倍消耗，提前算账：

- **带宽**：两台 1080p 手机同时 Wi-Fi 传输，路由器内网吞吐要扛住两路流，两端插网线或上 5GHz 几乎是必选项。
- **解码**：两路 1080p 双路硬解，老显卡先确认余量再上。
- 混合方案：一台走 Wi-Fi 一台走 USB，把压力分摊。

在 OBS 里用多机位时，分别添加多个「视频采集设备」来源，设备选各实例的 e2eSoft iVCam 设备，场景里自由布局与切换。

### 录像文件打不开或卡顿：修复与预防

iVCam 的录像直接落盘手机传来的数据（不重编码），由此带来两种典型问题：

| 症状 | 本质 | 处理 |
|---|---|---|
| 文件打不开 / 播不出 | 录制中途程序崩溃，MP4 收尾信息没写上 | 视频修复工具 |
| 能播但卡顿、剪辑软件里音画不同步 | 传输丢帧导致文件帧率不固定 | 转恒定帧率 |

崩溃损坏的 MP4，索引 / 收尾块缺失，用视频修复类工具重新封装即可恢复。修复成功率取决于损坏程度，**越早修越好**，别反复用播放器去试坏文件。

卡顿 / 不同步的文件，用格式转换软件把 MP4 转成恒定帧率（如 30fps 固定），转完再进剪辑软件，同步问题基本消失。

录像质量的上游是传输质量，丢帧必然写进文件。从源头预防的配置按优先级：

1. **USB 连接**——官方推荐的第一预防项，比 Wi-Fi 断流概率低得多。
2. 录像设备选 iVCam 麦克风，减少一路独立录音的同步风险。
3. 降低分辨率 / 质量 / 帧率，让传输留有余量。
4. App 端信号图标满格再开录。
5. 直播场景改用 OBS 录 iVCam 画面，走推流端的重编码录像，帧率恒定。

> [!TIP]
> 快速判断该修还是该转：拿卡顿的文件在多个播放器里播——所有播放器都打不开 → 修；都能播只是剪辑软件里出问题 → 转。两种处理互不冲突。
