## ✨ Miru 是什么

Miru 是一款开源的多源媒体聚合播放器，核心思路是把视频、漫画、小说三种媒体类型统一放进同一个应用里，通过扩展系统对接不同的内容源。你可以把它理解成一个"媒体浏览器"——Miru 本身不提供内容，而是通过社区编写的扩展脚本，从各种公开站点抓取数据，再用统一的界面呈现出来。

Miru 支持 **bangumi（视频番剧）、manga（漫画）、fikushon（小说）** 三种扩展类型，左侧标签栏切换，中间区域加载对应扩展返回的内容。卡片式展示、详情页进入、内置阅读器/播放器接管——整个交互路径在三种类型间基本一致，学会一种就能复用。

适合谁用？如果你习惯在多个站点之间切换追番、看漫画、找小说，Miru 把这些入口集中到了一个应用里；如果你喜欢折腾，也可以自己写扩展对接想要的源——扩展本质上就是一段 JS 脚本，按规范导出几个函数就能接入。

## 🔧 安装步骤（以 Android 为例）

Miru 官方提供三种 Android APK 架构，选对了安装就不会报错：

| 文件名 | 架构 | 适用设备 |
|---|---|---|
| app-arm64-v8a-release.apk | ARM64 64 位 | 2020 年后主流手机（推荐） |
| app-armeabi-v7a-release.apk | ARMv7 32 位 | 旧款低端手机 |
| app-x86_64-release.apk | x86 64 位 | Android 模拟器 |

> [!TIP]
> 不确定手机架构？直接装 arm64-v8a。选错了只会报"无法解析安装包"，不会损坏设备，换正确版本重试即可。

**安装流程**：

1. 把 APK 拷到手机（或手机浏览器直接下载）；
2. 在手机上点击 APK 文件；
3. 系统弹出"未知来源"警告时允许继续；
4. 安装完成后在桌面找到 Miru 图标打开。

> [!NOTE]
> Android 8.0+ 需要在"设置 → 安全 → 安装未知应用"里给浏览器或文件管理器开启权限，才能正常安装 APK。这是系统安全机制，不是 Miru 的问题。

首次启动时 Miru 会请求网络访问和存储权限——扩展需要联网获取内容、缓存图片和下载片段，全部允许即可。如果后来想改权限，在系统"设置 → 应用管理 → Miru → 权限"里调整。

更新版本时直接覆盖安装，应用私有目录不会被清除——收藏、阅读进度、扩展配置都会保留。需要全新安装的话，先卸载旧版本再装新的。

## 📖 使用入门

### 扩展仓库管理：内容源的核心

Miru 本身只是一个空壳，真正的内容来自扩展。首次安装后，右侧"仓库管理"区会列出已配置的扩展仓库，展开后可以浏览里面的扩展并逐个安装。

官方仓库不可能覆盖所有媒体源，社区里有大量第三方维护的扩展仓库，可能包含官方没收录的视频源、漫画图源、小说源，或者更及时的更新版本。添加自定义仓库的步骤：

1. 打开 Miru 右侧"仓库管理"区；
2. 点击"添加仓库 / Add Repo"按钮；
3. 在弹出框里输入仓库的 JSON 列表 URL；
4. 确认后 Miru 拉取仓库列表，展开浏览并安装。

> [!WARNING]
> 只从可信来源获取仓库地址。恶意扩展可能执行不透明代码，虽然 Miru 的沙箱能隔离大部分风险，但不要给扩展额外的网络或存储权限。

仓库可以随时启用/禁用（禁用后扩展全部失效但不卸载）、单独卸载某个扩展、或者删除整个仓库（同时卸载该仓库的所有扩展）。你可以同时添加多个仓库，Miru 会把所有扩展按类型自动分组管理。两个仓库可能收录同一个媒体源的不同扩展，装哪个由你选——同时装也可以，互不冲突。

### 漫画阅读：翻页与图片加载

切换到左侧"漫画"标签后，中间区域加载所有已安装 manga 扩展返回的内容。点击卡片进入详情页，选择任意章节后，漫画阅读器接管，把扩展返回的图片 URL 数组按顺序加载渲染。

阅读器支持多种翻页/滚动模式：

| 模式 | 说明 | 适用场景 |
|---|---|---|
| 垂直滚动（默认） | 所有章节图片排成一条长列表，上下滑动即可 | 大多数漫画的默认阅读方式 |
| 单页翻页 | 一次显示一张图片，左右/前后翻页 | 追求大图高清 |
| 双页模式 | 一次显示两张图片，模拟实体书 | 适合横版漫画 |
| 横向滚动 | 从左到右横向滑动 | 自定义偏好 |

阅读器会预加载当前图片的前后几张、懒加载未滑到的图片以节省流量，双击或手势可以放大查看细节。

如果某张图片加载不出来，常见原因和排查顺序：

1. **扩展返回的 URL 失效** — 图片源站点改版或链接过期，切到下一章看看其他图片能不能正常加载；
2. **防盗链** — 目标站点需要 Referer 头，这是扩展开发者的问题；
3. **跨域** — Web 版尤其常见，桌面客户端基本不会遇到；
4. **网络问题** — 挂代理或换个网络环境试试。

整本漫画大部分图片都加载不出来，说明这个漫画源扩展大概率已失效，换另一个漫画源扩展试试。

### 小说阅读：跨扩展搜索与阅读器设置

左侧"小说"标签对应 fikushon 类型扩展，切换后中间区域加载所有已安装 fikushon 扩展的最新内容。小说卡片的 update 字段通常显示最新章节标题或最近更新日期。

点击卡片进入详情页后，最重要的是章节目录——网络小说动辄几百上千章，Miru 会分页渲染或提供滚动目录。顶部搜索框在小说标签下会并行调用所有 fikushon 扩展的搜索方法，装多个小说扩展能大幅提高搜到想要作品的概率。

三种扩展类型里，fikushon 是最新加入的，官方仓库收录最少。由于小说扩展只需要处理文本请求，不需要像视频扩展那样处理流、也不需要漫画扩展那样处理图片防盗链，**自己写一个小说扩展的难度相对最低**——核心逻辑就是请求目录、请求章节正文、剥离 HTML 标签、按段落切分。想要某个特定小说站支持的话，可以考虑自己动手试试。

进入小说阅读器后，可以调整字号、行距、背景色等，让长时间阅读更舒适。阅读器设置里还能切换翻页模式、自动滚屏（适合条漫类小说）、图片适配方式等。
