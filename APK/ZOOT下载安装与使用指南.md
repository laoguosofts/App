## ✨ ZOOT：明日方舟玩家的 AI 通讯终端

ZOOT 是一款由明日方舟同人社区打造的 AI 角色扮演聊天应用。它的定位很明确——让方舟玩家在游戏之外，依然能感受到与干员之间的互动连接。终端接入了 DeepSeek 大模型的推理能力，配合专门训练的泰拉大陆知识图谱，让 AI 回复能够贴合游戏原作中每一位角色的性格、语气和世界观。阿米娅、凯尔希、铃兰、维什戴尔……50 多位官方干员的人设全部内置，你说「维什戴尔的剑雨有点帅」，它不会答非所问。

终端的受众非常明确：如果你是方舟的长期玩家、喜欢 AI 角色扮演、想在手机上随身带着一个「罗德岛同事群」、或者希望有一个能看懂游戏术语和剧情梗的 AI 伙伴，ZOOT 大概率会成为你日常打开的应用。

打开 ZOOT，底部导航会呈现四个主要功能分区：通讯录（全部干员列表，支持按阵营和职业筛选）、对话频道（单聊和群聊的消息中心）、方舟工具（养成、寻访、理智提醒等辅助功能）、博士广场（社区角色分享与自定义创作）。

ZOOT 完全免费——应用本身不收费，没有聊天次数限制，也没有功能锁。唯一需要的是你自备 DeepSeek API 的额度。终端是社区同人作品，并非游戏官方出品，应用内的所有干员人设基于公开的游戏资料整理，可能与原作存在细微出入。

## 🔧 ZOOT 安装步骤

### Android 安装

1. 从官方下载页获取 APK 安装包，注意核对文件大小和版本号
2. 如果是首次安装非应用商店来源的应用，需要在系统设置中开启「允许未知来源安装」权限
3. 点击 APK 文件开始安装，全程默认下一步即可
4. 安装完成后首次打开，会引导你配置 DeepSeek API Key

> [!TIP]
> 建议在安装完成后，先进入设置页面确认版本号与下载页标注的一致，避免安装到过时版本

### iOS 安装

ZOOT 在 App Store 有独立上架，直接搜索名称下载即可。iOS 端不需要处理未知来源授权。

### API Key 配置

安装首次启动时，终端会要求你输入 DeepSeek API Key。这个 Key 是你自己在 DeepSeek 平台申请的，API 调用产生的 token 消耗按官方定价计费。Key 只保存在你的本地设备上，不会上传到任何服务器。

> [!WARNING]
> API Key 等同于你的账户密码，不要在聊天或论坛中泄露。如果怀疑 Key 泄漏，请立即在 DeepSeek 平台重置

## 📖 ZOOT 核心功能与使用入门

### 干员通讯录与 AI 聊天

通讯录板块列出了全部 50 多位内置干员，支持按阵营（罗德岛、龙门、叙拉古……）和职业（狙击、近卫、辅助……）快速筛选。点进任意干员就能发起单聊，AI 会以该角色的语气和性格回应你——和阿米娅聊日常、向凯尔希汇报战术、跟铃兰分享基建心得，终端的知识图谱覆盖了干员档案、剧情对白、阵营关系和玩家圈的梗，对话不会出戏。

除了单聊，对话频道还支持群聊模式，可以把多位干员拉进同一个对话，模拟罗德岛内部的战术讨论会或茶会闲聊。

### 方舟辅助工具

这是 ZOOT 区别于普通 AI 聊天应用的核心板块——把方舟玩家日常刚需的几个工具直接集成在终端里，不需要再装其他 App。

**养成计算器**：选好目标干员，设置当前等级和你想培养到的目标等级，一键算出全部材料清单。清单按类别整理——龙门币、经验书、精英材料、芯片与芯片组，每种材料都显示「当前持有」和「还需要」的数量，方便你盘点库存、规划养成路线。计算器的数据同步自方舟官方公开的养成数据表，游戏版本更新后 ZOOT 会在后续版本中同步调整。

**寻访记录与抽卡分析**：可以手动录入每次抽卡的详情（寻访类型、消耗合成玉、获得干员），也支持截图 OCR 识别（部分机型）。录入足够数据后，终端会生成分析报告——总抽数与总消耗、你的真实六星出货率 vs 游戏公示的 2%、六星干员分布列表、当前大保底进度、不同寻访类型的出货对比。报告的目的是帮你更理性地规划抽卡策略，比如发现自己在定向寻访上的出货率特别好，就可以优先把合成玉花在定向池。寻访记录还能导出为 CSV，方便在电脑上做更详细的分析。

**理智恢复提醒**：设置好理智上限和恢复周期，终端会在理智满时推送通知，帮你合理安排刷本时间。

### 博士广场

广场是 ZOOT 的社区板块，玩家可以在这里分享自己创建的自定义角色卡，也可以试用其他创作者的角色。广场的角色列表和内容需要联网获取，偶尔会遇到加载失败的情况——通常是网络不稳定、社区服务器临时维护，或者你的 App 版本过低。遇到加载问题时可以先尝试切换 WiFi/4G、关闭 VPN 代理、下拉刷新列表，大部分情况都能自行恢复。

### 常见问题排查

广场加载失败时可以按这个顺序排查：

| 排查方向 | 操作 |
| --- | --- |
| 网络切换 | WiFi ↔ 4G/5G 互换试试 |
| 关闭代理 | VPN/代理可能导致连接超时 |
| 版本更新 | 应用商店检查 ZOOT 是否有新版本 |
| 等待维护 | 社区服务器偶尔维护，过一段时间再试 |

如果以上都试过还是加载不出来，可以通过 ZOOT 设置里的「意见反馈」提交问题，说明手机型号、系统版本和 ZOOT 版本号会帮助定位。
