## ✨ ZeroAI 是什么

ZeroAI 是一款运行在安卓设备上的开源 AI Agent 智能体应用，它把上游 ZeroClaw 的 Rust 核心精简移植到手机端，让你在口袋里就能拥有一个能对话、能调用工具、能记住上下文的 AI 助手。和市面上普通的聊天机器人不同，ZeroAI 不只是回答问题——它可以被接入 Telegram、Discord、邮箱等多种消息通道，在后台作为守护进程持续运行，甚至支持 Rhai 脚本扩展自定义工具链。

核心的智能体逻辑由 Rust 编写，运行内存不到 5MB、冷启动低于 10ms，二进制体积仅 8.8MB，常驻手机不拖慢系统，电量开销可控。架构上所有子系统（AI 模型、消息通道、记忆后端、工具集、运行时、隧道）都通过 trait 接口解耦，意味着你可以自由替换模型供应商（DeepSeek、Qwen、Ollama 本地部署都行）、切换记忆存储方式、甚至自己实现一个新的消息通道。

适合谁用？如果你是喜欢折腾 AI Agent 的开发者、想在手机上跑本地模型的极客、或者需要一个能定时执行任务的自动化助手，ZeroAI 值得一试。如果你只想要开箱即用的对话体验，可能需要先适应它偏技术向的配置方式。

## 🔧 安装步骤

ZeroAI 以 APK 形式分发，安装过程和普通安卓应用基本一致，但有几点需要注意：

### 下载与核对

1. 在下载页获取最新版本的 APK 文件
2. 安装前核对文件大小和版本号，避免下载到不完整或过时的包
3. 如果设备有杀毒或安全软件拦截，选择允许安装即可——开源项目没有恶意行为

> [!WARNING]
> ZeroAI 是实验性项目，部分代码由 AI 辅助生成。建议先在备用设备或模拟器上验证，不要直接在主力机的主账号上长期运行重要任务。

### 安卓未知来源授权

安装步骤涉及开启未知来源权限：

1. 将 APK 文件传到手机（浏览器下载、USB 传输均可）
2. 点击 APK 文件，系统提示「允许安装未知来源应用」
3. 根据手机品牌不同，可能需要进入设置 → 安全 → 安装未知应用，选择文件管理器或浏览器并授权
4. 授权后回到安装界面继续，完成安装

### 安装后验证

1. 打开 ZeroAI，首次启动会进入配置引导
2. 配置一个 AI 模型供应商的 API 密钥（DeepSeek、Qwen 等，或者填 Ollama 本地地址）
3. 完成后进入主界面，发一条简单消息测试是否能正常回复

> [!NOTE]
> 部分 OEM 厂商（如小米、OPPO）的系统会在后台杀掉守护进程。如果发现 ZeroAI 经常掉线，需要在系统设置里把它加入自启动白名单和电池优化白名单。

## 📖 使用入门

### 记忆系统：让它真的「记得住」

ZeroAI 默认使用 SQLite 混合搜索作为记忆后端——向量存储用 SQLite BLOB 配合余弦相似度搜索，关键词搜索用 FTS5 虚拟表加 BM25 评分，两者加权合并得到最相关的历史片段。好处是零外部依赖，不需要搭建 Pinecone 或 Elasticsearch，一个本地文件就搞定。

你也可以在设置里切换其他记忆模式：

| 记忆后端 | 适用场景 | 特点 |
|---|---|---|
| SQLite 混合搜索（默认） | 绝大多数用户 | 零依赖、混合搜索效果好 |
| PostgreSQL | 生产级部署、多设备共享 | 需要数据库服务 |
| Markdown 文件 | 喜欢手工编辑记忆内容 | 人类可读、可 git 管理 |
| 无记忆 | 每次对话独立、测试用 | 完全无状态 |

> [!TIP]
> 记忆文件存在手机本地，不会自动同步到云端。如果要换设备或重装系统，记得先备份 SQLite 文件。应用卸载时系统会清除数据目录，别等到删了才想起来。

### 会话开销统计：/cost 命令

ZeroAI 不内置模型额度，所有调用都走你自己的 API 密钥。如果你同时配了多家模型（比如 DeepSeek + Qwen + Ollama），想知道某个会话到底花了多少钱，直接输入 `/cost` 就能看到：

```
/cost
Session cost: $0.023
  Provider: DeepSeek V3 — 1,247 input / 389 output tokens
  Provider: Qwen Plus — 521 input / 112 output tokens
```

它会列出当前会话里每家供应商的 token 用量和对应费用。这个命令特别适合三个场景：跑完一轮复杂任务后查一下账单，切供应商之前对比费率是否合理，或者在免费额度快用完时及时收手避免触发限流。比起跳去供应商后台翻账单，/cost 的零摩擦体验确实方便不少。

### Rust 核心架构速览

ZeroAI 的核心逻辑全部在 Rust 里，代码结构清晰：

- **tools** — 工具集合，包括搜索、网页抓取、HTTP 请求、视觉能力、Rhai 脚本等
- **memory** — 记忆后端实现
- **config** — TOML 格式的配置解析
- **runtime** — 智能体运行时，负责任务调度和步骤执行
- **channels** — 消息通道网关，支持 Telegram、Discord、邮箱、TTY 等
- **gateway** — 消息路由层，负责通道 ↔ 智能体之间的转发

所有子系统都通过 trait 接口定义，替换模型供应商、增加新的消息通道、换一套记忆存储都不需要改动核心代码。ZeroAI 作为下游项目，砍掉了上游 ZeroClaw 里桌面端和服务器端才需要的模块（比如 Docker 沙箱、systemd 服务管理、Cloudflare Tunnel），保留了安卓客户端真正用到的部分。

### 安全使用建议

作为一个实验性项目，ZeroAI 虽然功能丰富但仍在快速迭代。以下是几个实际使用中值得注意的点：

**先跑简单任务测试能力**。用不重要的任务验证它的表现——自动汇总新闻、定时发测试消息到 Telegram，跑几天看看稳定性再考虑加复杂任务。

**自动执行功能谨慎开启**。邮箱自动发信、自动删除文件这类高风险操作，建议先改成「起草建议」模式，让智能体给你出方案，确认后再手动执行。

**隔离账号原则**。Telegram Bot、邮箱账号等用专门的测试账号，不要用日常主账号。万一智能体行为异常，隔离账号可以把影响范围控制住。

**关注上游更新**。ZeroAI 虽然是 fork，但会跟随上游 ZeroClaw 的架构演进。版本迭代快意味着新功能来得勤，但也可能带来 API 变化，旧教程可能过时。
