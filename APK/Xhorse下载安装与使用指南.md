## ✨ Xhorse 是什么

Xhorse 是一套面向汽车锁匠行业的钥匙编程与防盗匹配工具产品线，由一系列硬件设备和配套 App 组成。它覆盖了从日常的遥控拷贝、芯片识别，到专业的防盗盒读写、OBD 钥匙学习，再到奔驰宝马等豪华品牌的特殊功能——锁匠师傅用它来给车主增配钥匙、修复防盗系统、处理各类锁具相关的疑难杂症。

产品线按定位大致分三档：入门级的 Mini Key Tool 手持小盒子，主打遥控和芯片的高频操作；中端的 MIDI / VVDI2 经典 PC 外置盒，适合固定工位做深度数据编辑；旗舰级的 Key Tool Plus 全能平板，把芯片、遥控、OBD、BGA 直读、配匙机控制全部整合在一台 Android 平板里，外出救援和室内工位都能胜任。核心配套还有 VVDI Prog 编程器、Dolphin / Condor 数控配匙机等，形成完整的锁匠工具生态。

**谁适合用**

- 职业锁匠：日常接单离不开的主力工具，覆盖市面上绝大多数车型
- 汽修厂技师：需要做钥匙匹配、防盗修复的场景
- DIY 玩家：给自己家里的车增配一把钥匙（非一键启动场景）
- VVDI 老用户：手里有 VVDI2，想补一个便携的遥控/芯片工具

Xhorse 的核心优势在于"覆盖面广"和"生态完整"——一套工具能搞定从国产车到德系豪华车的大部分钥匙问题，社区案例也多，遇到问题容易找到参考。

## 🔧 安装步骤

Xhorse 不是传统意义上的"装个软件就能用"——它是硬件 + App 的组合，安装流程分 App 安装和硬件连接两部分。

### App 安装

1. **Android 设备（Key Tool Plus 平板 / 自己的安卓手机）**
   - 从 Google Play 或官网下载 Xhorse App
   - 如果是手动下载 APK，安装前需要在系统设置里开启"未知来源"授权
   - 装完打开 App，首次启动会要求登录账号（Xhorse 官方账号）

2. **PC 端（VVDI2 / VVDI Prog 用户）**
   - 从官网下载对应型号的 PC 客户端软件
   - 安装时选择安装路径（建议默认路径，避免权限问题）
   - 驱动会自动安装，装完重启电脑

### 硬件首次连接

1. **用 USB 线把设备连到电脑或平板**
2. 设备开机（部分设备需要长按电源键 3~5 秒）
3. App / PC 软件会自动识别设备型号并显示连接状态
4. **首次连接强烈建议先升级固件**——Key Tool Plus → 更新中心 → 升级固件 + IMMO 数据库 + PROG 数据库，旧版固件可能对新款车型或芯片类型支持不完整

> [!WARNING]
> 升级固件过程中**绝对不要断电或拔线**——中途断开可能导致设备变砖。升级前确保电量充足（至少 30% 以上），升级时间一般 2~5 分钟。

### 验证设备是否正常

- Key Tool Plus：屏幕点亮后进入主界面，顶部显示设备序列号和积分余额
- Mini Key Tool：开机后屏幕显示主菜单，按任意键可以进入功能选择
- VVDI2：PC 软件连接成功后，设备上的指示灯会从红色变成绿色

## 📖 Xhorse 核心功能使用入门

### 遥控操作——拷贝、生成、测试

遥控是日常最常见的需求：车库门遥控坏了要配一个，车钥匙丢了要拷贝一把。Xhorse 的遥控功能分三种：

**遥控拷贝**：把原遥控的频率和码型完整复制到新的遥控子机里。操作路径很简单——选择"汽车遥控"或"车库门遥控"，把频率选对（常见的 315 MHz 或 433 MHz），原遥控靠近设备顶部线圈 1~10 cm，同时按下锁车键等待抓取，然后放入 VVDI 通用遥控子机执行拷贝。整个过程大概 30 秒。

**遥控生成**：没有原遥控、或者原遥控已经坏了的时候用这个功能。选择"遥控生成"，按车型 → 年份 → 遥控型号一步步选下去，设备会自动生成对应的码型，写入 VVDI 通用子机。

**频率测试**：不确定原遥控的频率是多少时，用频率测试功能——按下原遥控的任意按键，设备会显示它发射的频率值，选对频率再拷贝就不会出错。

> [!NOTE]
> Mini Key Tool 虽然小巧，但遥控功能和 Key Tool Plus 基本一致，唯一的区别是 Mini Key Tool 没有 OBD 接口，不能做车辆防盗匹配。如果只是日常拷贝遥控和芯片，Mini Key Tool 已经够用了。

### 芯片操作——识别、克隆、生成

每一把汽车钥匙里都嵌有一颗米粒大小的芯片（Transponder），内部存储着与车辆防盗模块匹配的 ID 码。芯片是防盗的核心，钥匙能启动车辆全靠它。

**芯片识别**：把钥匙放进设备顶部的感应线圈，点击"开始识别"，2~5 秒后屏幕会显示芯片类型（ID46、ID47、ID48、TI、NEC 等）、厂家和加密状态。如果识别失败，多半是线圈没放居中，多换几个位置试试。

**芯片克隆**：分两种情况。未加密的老式芯片（比如 ID46）可以本地直接克隆——读取原钥匙数据，放入 VVDI 通用芯片写入，全程不消耗积分。加密芯片（比如 ID48）需要在线计算，云端根据原钥匙的加密数据算出克隆所需的码，这时候会消耗一个 Token 或等价积分。

**芯片生成**：从零开始为特定车型创建一颗匹配的芯片。选择地区 → 品牌 → 车型 → 年份，放入 VVDI 通用芯片，点击生成。部分车型（比如奔驰）需要额外的 PIN 码或 CS 码才能完成。

**VVDI 超模芯片**是 Xhorse 的特色——它是一颗可以反复擦写、重新初始化的通用芯片，不像传统空白芯片只能用一次，经济性好很多。

### OBD 防盗匹配——给车辆写新钥匙

当钥匙丢了、或者需要给车增配一把新钥匙时，就需要做防盗匹配了。这个功能需要把设备通过 OBD 接口连到车辆的诊断口（驾驶位下方），直接和防盗盒通信。

以 Key Tool Plus 为例，操作流程大致是：

1. OBD 线一端插 Key Tool Plus，另一端插车辆诊断口
2. 在 App 里选择"防盗匹配" → 选择车型 → 选择防盗系统类型
3. 系统会提示需要哪些信息（PIN 码 / CS 码 / 防盗盒数据等）
4. 按提示完成在线计算或本地读取，然后执行钥匙学习
5. 学习成功后，新钥匙就能启动车辆了

> [!WARNING]
> OBD 匹配过程中车辆**必须通电但不启动发动机**，电瓶电压建议保持在 12V 以上。如果电瓶亏电，匹配过程中突然断电可能导致防盗盒锁死，处理起来会非常麻烦。

### MQB49 5C/5D 模块常见报错

处理大众奥迪 MQB49 平台（5C/5D 模块）的钥匙匹配时，"CLK Line Not Connected"（时钟线未连接）是高频报错。CLK 线是防盗模块与编程器通信的关键信号线，负责同步双方的通信节奏。

**快速排查流程**：

1. **先检查免焊适配器的弹簧针**——70% 的情况是 CLK 针松了或接触不良。拔掉适配器，用镊子轻轻把 CLK 位置的弹簧针弹出来一点，重新夹好确保夹具到位
2. **用探针顶住 CLK 焊点重试**——读取过程中用一根细探针用力顶住 CLK 焊点，能增大弹簧针与焊点的压力，改善接触
3. **升级固件和数据库**——Xhorse 在 2023 年更新过 CLK 检测逻辑，旧版固件的识别阈值可能太高
4. **对照焊接图确认 CLK 线位置**——不同 VAG 车型的 5C/5D 模块 CLK 焊点位置略有不同，打开设备里的焊接图仔细核对
5. **拆模块接 VVDI Prog 读**——如果以上都试了还不行，把模块拆下来直接接 VVDI Prog 读，还是读不到 CLK 说明模块本身坏了

### 选设备：Mini Key Tool / VVDI2 / Key Tool Plus 怎么挑

三者功能高度重叠，但形态和侧重差异很大：

| 对比项 | Mini Key Tool | VVDI2 | Key Tool Plus |
| --- | --- | --- | --- |
| 形态 | 手持小盒子 | PC 外置硬件盒 | 10.1" Android 平板 |
| 防盗匹配（OBD） | ❌ | ✅ | ✅ |
| 芯片 / 遥控操作 | ✅ | ✅ | ✅ |
| BGA 直读 | ❌ | ✅（配合 Prog） | ✅ |
| 配匙机蓝牙 | ❌ | ❌ | ✅ |
| 价格 | ~1000 | ~3000（基础版） / ~5000（Full） | ~12000 |

选购建议很直接：

- **预算有限 / 先练手**：Mini Key Tool 足够覆盖日常 70% 的遥控和芯片操作
- **已有电脑 / 固定工位 / 主要做 VAG 老款**：VVDI2 Full 版性价比高，配一个 Mini Key Tool 补遥控操作
- **不想配电脑 / 外出救援多 / 一站式**：Key Tool Plus 虽然贵，但一台设备覆盖所有功能的便利性远超价差

> [!TIP]
> VVDI2 基础版不建议买——后续逐一补买授权的总价比直接买 Full 版还贵。一步到位 Full 版最划算。
