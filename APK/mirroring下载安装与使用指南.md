## ✨ Mirroring 是什么

Mirroring 是一款面向 Android 手机的投屏配套应用，配合 USB / Wi-Fi 同屏器硬件，把手机画面实时镜像到电视、投影仪等大屏设备上。它本身不替代手机里的视频或演示应用，而是作为「中间桥梁」把手机侧的任何画面——包括追剧、赛事直播、PPT 文档、健身跟练——同步到大屏端，同时承担音频通路和反向控制翻页的协调工作。

和系统自带的投屏功能不同，Mirroring 的核心优势在于**有线路线的确定性**：走 USB 连接时不依赖会议室或酒店的 Wi-Fi，插线即投、连上线就开始充电，适合演示、出门在外等网络不可控的场景；家里常驻一个无线同屏器时，它又能提供随开随投的便利。两条路线在同一应用内共存，无需切换不同工具。

典型使用场景覆盖赛事演唱会大屏看球看演出、会议室 PPT 演示、家庭追剧与网课投屏、健身跟练时动作跟拍等——凡是「手机上的内容需要放大到大屏上观看或分享」的场合，都能派上用场。

## 🔧 Mirroring 安装指南

Mirroring 运行在 Android 手机上，安装过程和常见 APK 类似，但有几个和投屏硬件相关的准备步骤需要提前确认。

### 安装前的硬件清单

在安装应用之前，先把需要准备的东西核对齐全：

- **同屏器硬件**：USB + HDMI 同屏器（有线路线）或 Wi-Fi 同屏器（无线路线），也可以两种都备一个
- **数据线**：USB-A 或 USB-C 数据线，取决于手机接口；部分同屏器自带线材
- **大屏设备**：电视或投影仪，确认有 HDMI 输入口

> [!TIP]
> 同屏器不是 Mirroring 应用内置的功能，而是独立的硬件。应用本身负责驱动和协调，硬件负责信号转换。首次使用时如果没有同屏器，可以先只装应用熟悉界面。

### APK 安装步骤

1. 打开下载页，找到适配当前手机的最新版本，点击下载 APK 文件
2. 下载完成后，点击文件触发安装；如果系统弹出「未知来源」提示，进入设置中允许本次安装或允许该下载来源
3. 安装完成后在应用列表中找到 Mirroring，首次打开时授予所需权限（显示在其他应用上方、蓝牙、位置等）
4. 进入应用主界面，确认版本号与下载页标注的一致

### 同屏器首次连接

有线路线的首次连接：

1. 同屏器 HDMI 端插入电视或投影仪的 HDMI 输入口
2. USB 端通过数据线连接手机，手机弹出 OTG 提示时确认开启
3. 等待电视大屏出现手机画面，同时手机蓝牙自动或手动配对同屏器的音频设备

无线路线的首次连接：

1. 同屏器 HDMI 端插入大屏，给同屏器通电
2. 手机和同屏器连接到同一个 Wi-Fi 网络
3. 打开 Mirroring 应用，在设备列表中找到同屏器并点击连接

> [!WARNING]
> 酒店、咖啡厅等公共 Wi-Fi 环境下，无线投屏经常因网络隔离策略而无法互通。出门演示时优先走有线路线，不用去碰对方的路由器设置。

## 📖 Mirroring 使用入门

装好应用、连上同屏器之后，Mirroring 的使用围绕两个核心选择展开：走有线还是无线？以及根据场景调整细节设置。下面从路线选择、具体场景操作、常见问题三个维度展开。

### 路线选择：有线 vs 无线

Mirroring 提供两条投屏路线，各自的取舍可以用下面的对照表快速判断：

| 维度 | 有线（USB 线 + 同屏器） | 无线（Wi-Fi + 同屏器） |
| --- | --- | --- |
| 网络依赖 | 零依赖，酒店、会议室、无网环境都能用 | 需要手机与同屏器互通的网络环境 |
| 画面稳定性 | 沿线传输，不受路由拥堵与信号干扰影响 | 受信号强度、同频干扰影响，人多时可能波动 |
| 手机供电 | 连接即充电，长投不掉电 | 持续耗电，长时间投屏建议插着电源 |
| 活动自由度 | 手机被线拴住，距离受限 | 手机可自由走动，换房间也能继续 |

按场景来选：

- **追剧、网课、会议演示**：设备基本不动，选有线——稳、清晰、顺便充电
- **健身跟练、边做家务边投屏**：人在客厅里来回走，选无线——自由度优先
- **出门在外（酒店、展会、拜访客户）**：环境网络不可控，选有线——不用碰对方路由器
- **临时给家人看个照片、放段视频**：选无线——不用翻线材，点开就投
- **打游戏**：对延迟敏感，有线优先；若用无线，尽量靠近同屏器与路由

两条路线并不互斥——日常在家可以留一个无线同屏器常插电视，包里塞一个有线同屏器应急，同一台手机、同一个应用自由切换。

### 会议演示：当场连上不出错

会议室演示最怕的不是画质不够好，而是「当场连不上」。Mirroring 在演示场景下的标准流程如下：

1. **到场先接设备**：同屏器 HDMI 进投影仪或会议电视，USB 线连手机，OTG 打开
2. **连蓝牙音频**：会议室有外接音响就接音响的蓝牙；没有就走同屏器自带的音频输出
3. **打开演示文件**：手机上的 PPT、文档、在线文档都可以，画面实时镜像到大屏
4. **反向控制翻页**：大屏侧接上鼠标或翻页器（视硬件支持），翻页不再需要碰手机，避免遮挡投屏画面

演示前花两分钟过一下这张彩排清单：

- 演示文件在手机上能正常打开，字体与动画不缺失
- 手机开启勿扰模式——微信弹窗出现在会议室大屏上是经典事故
- 备好 B 方案：演示文件同时发一份到自己邮箱或存在两个应用里
- 若用无线：确认会议室断网时你仍能通过热点直连模式连上同屏器

演示收尾时记得断开投屏、拔线收好、清掉公共设备上的授权弹窗默认设置，不留个人痕迹。

### 赛事演唱会大屏观赛

世界杯、奥运会、演唱会、晚会这类场景的核心诉求是**共享氛围**——几个人围着一部手机看球和围着电视看球，体验完全是两回事。赛前花五分钟把这五项检查一遍：

1. **连接路线选好**：固定客厅用有线（边投边充最稳），走动观看用无线
2. **画面确认**：大屏出画面、声音在电视侧，别等开赛才发现没声
3. **电量安排**：无线投屏的话手机先插上电源
4. **网络让路（无线时）**：家里人先暂停大流量下载，给直播流让带宽
5. **锁屏调长**：上半场四十五分钟，别让自动锁屏搅局

演唱会、晚会类内容多为长时连续节目，对画质更敏感——舞台灯光暗场多，低码率下暗部糊得快。如果视频应用本身支持应用内推送，走推送模式通常比纯镜像画质更好。投屏支持录屏截图的话，精彩瞬间可以随手截存，赛后回放也方便。

### 声音有画面没：三层音量排查

画面正常、声音缺席，说明投屏链路本身是通的，问题集中在音频通路上。按下面的最短路径排查，大部分无声问题在第一步就能解决：

1. **三层音量拨一遍**：手机媒体音量 → 蓝牙设备音量 → 大屏音量，逐层确认非静音
2. **确认蓝牙已连接**（有线路线）：手机蓝牙列表里同屏器设备显示「已连接」；显示「已配对」不等于「已连接」，点一下设备条目触发连接
3. **检查输出设备选择**：连了蓝牙但声音仍从手机出——在播放中的视频或系统媒体输出设置里，手动把输出切到同屏器蓝牙
4. **取消配对重新配**：蓝牙状态卡住时，删除配对记录重配一次，刷新两端状态

几种特殊情形的处理：

- 只有某个视频没声：换本地视频验证。个别内容的音轨受 DRM 保护，和黑屏有声是镜像问题，原理相同——属于内容方的限制，换推送模式或改用本地文件可以绕开
- 无线投屏没声：先确认走的是镜像还是推送模式——推送模式下手机端静音不影响大屏出声，这是正常现象
- 外接音响无声：音响作为独立蓝牙设备连手机时，确认它和同屏器蓝牙别抢——同一时间手机通常只向一个蓝牙音频设备输出

> [!NOTE]
> 投屏前顺手把三层音量拨到位，是成本最低的预防动作。三层音量关系记不牢时，把这当作每次投屏前的固定习惯。

### 无线体验优化

无线路线的多数体验问题（卡顿、断连、延迟）都可以通过几个简单的优化动作明显缓解：

- 手机尽量靠近路由器，减少 Wi-Fi 信号穿墙
- 同屏器避开微波炉、蓝牙设备等 2.4GHz 干扰源
- 选择不太拥挤的 Wi-Fi 信道（可以用 Wi-Fi 分析类应用查看）
- 长时间投屏时保持手机充电，避免电量不足触发系统省电策略限制后台

如果试过这些之后仍不满意，直接换成有线路线是最彻底的解法。
