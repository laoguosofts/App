## ✨ PCMark 是什么

PCMark 是 UL Benchmarks（原 Futuremark）推出的 Windows 系统综合性能基准测试工具，和大家熟知的 3DMark 同属一家。如果说 3DMark 专注显卡和游戏性能，PCMark 就是给整台电脑做一次全面的"体检"——从日常办公到专业创作，从启动速度到续航表现，一次性把整机各方面的性能量化成分数。

PCMark 10 是目前的主流版本，内置了 Essentials（基础日常）、Productivity（办公生产力）、Digital Content Creation（数字内容创作）、Gaming（游戏性能）等多个测试组，覆盖了从轻薄本到游戏本再到台式工作站的各种使用场景。它的优势在于**结果可复现、数据库庞大**——全球数百万用户上传了跑分结果，你可以很方便地和同硬件配置的其他用户做横向对比，判断自己的电脑表现是正常还是异常。

适合哪些人用呢？如果你在选购新电脑、升级硬件后想确认性能提升有多少、或者觉得自己的电脑变慢了想排查瓶颈，PCMark 是非常靠谱的工具。硬件评测媒体也普遍用它作为生产力性能的标准基准。

## 🔧 安装步骤

PCMark 10 目前只有 Windows 版本，对系统版本的要求是 Windows 10 21H2 或更高，推荐 Windows 11。安装包体积约 2GB（含所有测试场景素材），安装完成后占用空间约 5GB。

**安装过程本身非常简单：**

1. 双击下载的安装程序，弹出 UAC 提示时点"是"
2. 选择安装路径（默认 `C:\Program Files\UL\PCMark 10`，建议保持默认）
3. 等待进度条走完，点击"完成"

> [!NOTE]
> 安装路径不要包含中文或特殊字符，部分测试场景的素材加载会因为路径编码问题失败。

**装完后验证一下：**

打开 PCMark 10 客户端，首页应该能看到完整的测试组列表。点击左上角菜单 → About，可以看到版本号（目前最新是 v2.1 系列）。如果客户端能正常加载所有测试项的缩略图，说明安装完整。

**关于版本选择：**

PCMark 10 有三个版本差异需要了解：

| 版本 | 价格 | 核心区别 |
| --- | --- | --- |
| Basic Edition | 免费 | 只能跑 Home 基准，不能上传结果 |
| Advanced Edition | 付费 | 解锁所有基准（Express / Extended / Applications）、可上传结果到 3dmark.com、支持自定义测试 |
| Professional Edition | 企业付费 | 在 Advanced 基础上增加批量部署、命令行自动化、商业授权 |

个人用户下载免费版就能满足日常需求，Home 基准已经覆盖了 Essentials + Productivity 两个核心测试组。想跑 DCC 和 Gaming 测试组需要升级到 Advanced。

## 📖 使用入门

### 跑分前必须做的环境准备

PCMark 官方说明：在性能一致的系统上重复运行，分数精度通常优于 ±3%。但这个精度是有前提的——**每次运行的环境要相同**。现实中影响分数的变量非常多：Windows 后台自动更新、杀毒软件实时扫描、OneDrive 等云同步、游戏启动器自动登录、RGB 灯效软件占用 CPU、CPU/GPU 温度过高降频、电源模式没开"最佳性能"、笔记本没插电……这些变量叠加起来可能导致两次跑分差异超过 10%。

> [!WARNING]
> 笔记本用户请务必接通电源后再跑分。电池模式下 CPU/显卡可能降到一半性能，分数直接打对折。

**按优先级排序的清理清单：**

必须做的（影响最大）：
1. 笔记本接通电源 + Windows 电源模式设为"最佳性能"
2. 关闭浏览器、游戏启动器、云同步工具（右键托盘图标 → 暂停同步）、杀毒软件实时扫描（测完一定要开回来）
3. 等待系统空闲 2~5 分钟（内存释放、磁盘索引暂停）
4. 确保 CPU / GPU 驱动是稳定版本

强烈建议做的：
5. **重启电脑**——这是最干净的起始状态，重启后直接开 PCMark 跑可以省掉手动关一堆后台的麻烦
6. 检查 CPU 温度，如果刚玩完游戏等冷却 5 分钟再跑
7. 临时暂停 Windows Update（设置 → Windows 更新 → 暂停更新 7 天）
8. 临时关闭 RGB 灯效软件（iCUE、Aura Sync、SignalRGB 等）

可选的（对精度要求极高时）：
9. 禁用 Windows 搜索索引
10. 关闭通知中心
11. 拔掉 USB 外设（U盘、移动硬盘）

UL Benchmarks 官方建议在"干净系统"上测试（全新安装 Windows + 仅装驱动和 PCMark），但日常用户不用强求。**关键是每次测试前清理到相同的状态**——两种策略都可以，但一定要用同一种策略来做横向对比。

**多轮跑分取平均：** 即使环境完全一致，分数也会有 ±3% 的波动。一般用户跑 1~2 次即可，精确对比建议跑 3 次取中位数。如果 3 次差异超过 5%，说明环境有问题，回去排查。

### 后台程序清理的具体方法

后台程序抢占 CPU / 内存 / GPU / 存储资源是跑分波动的主要原因，按影响程度排序：

| 后台程序类型 | 抢占的资源 | 影响程度 |
| --- | --- | --- |
| 杀毒软件实时扫描 | CPU + 存储 | 中（测试文件触发扫描） |
| 云同步（OneDrive、百度网盘） | 存储带宽 + CPU | 中（后台同步大文件） |
| 浏览器（有大量标签页） | CPU + 内存 | 高（每个标签页一个 Chromium 进程） |
| Windows Update | 所有资源 | 高（下载 + 安装 + 重启） |
| 屏幕录制/远程控制 | 显卡 + 存储 | 高 |
| 游戏启动器（Steam、Epic） | CPU + 内存 + 网络 | 低~中 |
| RGB 灯效软件 | CPU | 低（常驻后台消耗） |

最快的清理方式还是**重启电脑后直接跑**，重启本身就清空了大部分后台程序。重启后的操作顺序：等 2~5 分钟（启动项加载完、磁盘空闲）→ 关掉浏览器、杀毒、云同步 → 开 PCMark → 首页点 Run。

长期保持干净系统可以精简启动项：任务管理器 → 启动 → 禁用不必要的启动项，建议只保留显卡驱动面板、杀毒软件、输入法。

跑完后别忘了恢复：杀毒实时防护开回来、云同步恢复、Windows Update 恢复。长期关闭杀毒或云同步会带来安全和数据丢失风险。

### 认识 PCMark 的测试组

PCMark 10 的各个测试组（Workload）分别模拟不同场景下的真实使用行为：

**Essentials 基础日常**——这是最贴近日常使用的测试组，包含 App Start-up（应用启动速度）、Web Browsing（网页浏览）、Video Conferencing（视频会议）。主要考验存储速度、CPU 单核性能和网络稳定性。对硬件要求不高，但能直观反映一台电脑"用起来顺不顺手"。

**Productivity 办公生产力**——包含 Spreadsheets（电子表格）、Writing（文档写作）、Photo Editing Light（轻量图片处理）。主要考验 CPU 多核性能、内存容量和存储带宽。如果你是上班族，每天用 Office 三件套，这组分数直接对应你的工作效率。

**Digital Content Creation 数字内容创作**——这是硬件要求最高的测试组，面向专业创作者。包含三个 Workload：

| Workload | 核心测试内容 | 主要考验硬件 |
| --- | --- | --- |
| Photo Editing | 在图像编辑软件中处理高分辨率图片 | CPU、GPU、内存 |
| Video Editing | 在视频剪辑软件中处理多轨视频 | CPU 多核、GPU、存储（读写） |
| Rendering and Visualization | 3D 场景渲染和实时可视化 | CPU 多核（渲染）、GPU（可视化） |

核显跑 Photo Editing 可能只有独显分数的 30%~50%，差距远大于 Essentials 和 Productivity 中的差异。Rendering and Visualization 部分，纯 CPU 多线程任务对核心数极度敏感，8 核以上才有意义，16 核/24 核渲染工作站在这里有压倒性优势。

UL Benchmarks 官方建议：对于编辑照片、视频或其他数字内容，PCMark 10 Digital Content Creation 分数 ≥ 3450 为宜。实际参考范围：带核显的轻薄本 DCC 约 2000~4000，中低端独显约 5000~8000，中高端独显约 10000~20000。

> [!TIP]
> 没有独显的电脑几乎不可能在 DCC 上拿到高分。如果你是创作者，选购电脑时一定要看 DCC 测试的成绩，而不是只看 Essentials 和 Productivity——后者主要看 CPU + 内存 + 存储，核显台式机甚至可能比带独显的创作本分数还高，但这不代表它能胜任创作工作。

### 用 3dmark.com 做横向对比

拿到分数后第一个问题通常是：这个分数好不好？在同样配置的电脑里算什么水平？直接在 PCMark 客户端里拿到的分数只是一个数字，要判断它的真实水平，最好的方式是去 3dmark.com 对比。

3dmark.com 是 UL Benchmarks 官方的基准测试结果分享平台，收录了数百万条真实用户的跑分数据。你可以在 PCMark 客户端里点"上传"按钮把结果传上去，然后点击 Compare results 跳转到对比页面。如果想搜索特定硬件的跑分，也可以在 3dmark.com 手动搜索——搜索框选择 PCMark 10 → 高级搜索 → 输入具体的硬件型号（比如 "Intel Core i5-13500"、"NVIDIA RTX 4060"）。

对比页面的核心是一个分数分布曲线图：灰色区域是平台数据库中所有使用相同 CPU + GPU 组合的 PCMark 10 分数分布，曲线越高代表这个分数附近的用户越多；橙色高亮是你的分数在分布中的位置。页面会告诉你"你的分数高于 XX% 的 PCMark 10 分数"、"同硬件中位数是多少"、"同硬件最低分和最高分"。

| 你的分数在分布中的位置 | 含义 | 建议 |
| --- | --- | --- |
| 右半侧 | 高于同硬件平均 | 环境配置良好，继续保持 |
| 中间 | 接近同硬件中位数 | 正常范围 |
| 左半侧 | 低于同硬件平均 | 需要检查环境或排查问题 |
| 曲线之外（远低于） | 明显异常 | 立即排查 |

**搜索硬件时要注意几点：** 型号尽量精确到完整名称（"Intel Core i5-13500" 而不是模糊的 "Core i5"）；注意区分笔记本版和台式机版（同型号 CPU 笔记本受限于散热和功耗，性能低很多）；对比时注意参考用户的显卡驱动版本——驱动更新可能带来 ±5% 的分数差异，半年前的驱动和最新驱动的分数不可直接对比。

**分数明显低于同硬件中位数的常见原因：**

| 原因 | 典型影响 |
| --- | --- |
| 笔记本用电池模式跑 | 分数下降 30~50% |
| 后台程序干扰 | 分数下降 5~15% |
| CPU/GPU 过热降频 | 分数下降 10~20% |
| 内存单通道 | Spreadsheets 下降 20~30% |
| 显卡驱动版本旧 | DCC 组下降 5~15% |
| 存储老化/接近寿命 | App Start-up 下降 10~20% |

如果排查完环境还是低很多，可能是硬件本身有问题——CPU 硅脂老化、SSD 固件有 bug、内存颗粒有问题都有可能。
