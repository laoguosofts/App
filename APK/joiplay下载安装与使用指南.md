## ✨ JoiPlay：把 PC 独立游戏搬去手机的模拟器

JoiPlay 是一款运行在 Android 上的游戏模拟器，核心能力是让原本只能在 Windows PC 上跑的独立游戏直接在手机上运行。它通过内置的插件系统分别适配 RPG Maker 系列、Ren'Py、TyranoBuilder、Construct、Godot、HTML5、Flash 等多种游戏引擎，覆盖了大量独立游戏和视觉小说。

相比其他模拟器，JoiPlay 的优势在于**引擎覆盖广**、**插件独立更新**、**对 Android 新系统适配积极**。对于喜欢玩独立 PC 游戏但又不想被电脑绑住的玩家来说，它提供了一种"随身带游戏库"的可能性——通勤、午休、躺在床上都能接着 PC 上的进度继续玩。当前（2026 年）主线稳定版为 1.21.000，Godot 插件已加入，Android 11+ 的 Scoped Storage 也已适配到位。

## 🔧 安装步骤与注意事项

JoiPlay 的安装对象是 Android 设备（智能手机或平板），最低要求 Android 7.0 以上。安装过程和普通 APK 类似，但有几个关键点需要注意。

### 第一步：准备安装包

1. 从上面的下载入口获取最新稳定版 APK 文件
2. 同时下载你需要的引擎插件——**JoiPlay 主程序是模拟器框架，每种引擎需要单独的插件**。常用插件：RPG Maker Plugin（覆盖 XP/VX/VX Ace/MV/MZ）、Ren'Py Plugin（覆盖 7.x 和 8.x 视觉小说）、HTML5/Canvas Plugin、Flash/Ruffle Plugin
3. 把 APK 文件传到手机（数据线、QQ/微信文件传输、网盘下载都行）

> [!TIP]
> **务必核对版本号**：主程序版本和插件版本最好来自同一时期的发布。比如主程序 1.21.000 搭配 RPG Maker Plugin 1.22.008、Ren'Py 8.5 Plugin 1.01.00，这样兼容性最稳。混用大版本可能导致插件加载失败或游戏闪退。

### 第二步：允许未知来源

Android 默认禁止安装非应用商店的 APK，需要手动开启：

1. 打开手机 **设置 → 安全（或隐私）→ 安装未知应用**
2. 找到你将用来打开 APK 的那个应用（文件管理器、浏览器等），点进去勾选 **允许**
3. 不同品牌手机路径略有差异——小米在"设置 → 隐私保护 → 特殊权限设置 → 安装未知应用"，华为在"设置 → 安全 → 更多安全设置 → 安装未知应用"

### 第三步：安装 JoiPlay 和插件

1. 先安装 **JoiPlay 主程序 APK**，安装完成后不要急着打开
2. 逐个安装引擎插件 APK（可以在文件管理器里批量点装）
3. 全部装完后打开 JoiPlay，首次启动会请求存储权限——**一定要点允许**，否则 JoiPlay 访问不到你存的游戏文件

> [!WARNING]
> **不要同时装多个同类型插件**：比如 Ren'Py 有 7.x 和 8.x 两个插件，虽然 JoiPlay 能共存，但如果同一个游戏被两个插件同时尝试加载会出问题。建议只装你实际用到的引擎插件，保持精简。

### 第四步：验证安装

打开 JoiPlay，进入 **Settings → About** 或 **Plugins** 页面，确认：

- Core 版本号与你下载的 APK 一致
- 已安装的插件都显示为 Active/Enabled 状态
- 存储权限已授予（Settings → Storage 里能看到游戏扫描路径）

## 📖 使用入门：从添加游戏到跑通

安装好 JoiPlay 和插件后，接下来就是把你想玩的 PC 游戏加进来、调设置、开始玩。下面覆盖最常见的使用场景和容易踩的坑。

### 添加游戏：把 PC 游戏搬去手机

JoiPlay 不内置游戏库——你需要自己把 PC 上的游戏文件拷贝到手机里。流程如下：

1. 手机连电脑，把整个游戏文件夹（比如 `Doki Doki Literature Club/`）复制到手机存储的某个位置（建议建一个 `JoiPlay Games/` 目录统一放）
2. 打开 JoiPlay，点界面上的 **+ Add Game**
3. 选择游戏文件夹，JoiPlay 会自动识别引擎类型（RPG Maker / Ren'Py / HTML5 等）
4. 填一下显示名称（可改），选一个封面图，点 Save

> [!NOTE]
> 有些游戏压缩包解压后会出现"多个文件夹嵌套"的情况——比如解压出来是 `GameName/GameName-1.0/`，里面才是真正的游戏文件。JoiPlay 需要定位到**包含游戏配置文件**的那一层目录（RPG Maker 是 `Game.ini`，Ren'Py 是 `game/` 子目录，HTML5 是 `index.html`）。如果 JoiPlay 识别不到引擎，多半是目录选错了。

### 虚拟手柄：手机上的触控操作

JoiPlay 提供了完整的虚拟手柄系统，2026 年 1 月的重构版本让布局文件格式标准化了。进入任何一个游戏后，按手机的返回键或从屏幕边缘滑出游戏菜单，就能看到虚拟手柄设置：

- 默认布局提供 **方向键 + 四个动作键 + Esc/Enter** 等常用按键
- 可以自定义每个按键的位置、大小、透明度
- 支持导入/导出布局文件，同一类型的游戏可以复用同一份布局
- 物理手柄（蓝牙或 USB）也能直连，按键映射在 **Settings → Controllers** 里配置

对于 Ren'Py 视觉小说，建议把 **Esc** 键映射到虚拟手柄的一个显眼位置（比如右上角）——因为 Ren'Py 的存档/读档/回滚菜单都是通过 Esc 唤起的。另外可以把 **鼠标滚轮上下** 映射到手柄按键，方便回看对话历史。

### HTML5 游戏的画面适配

HTML5 导出的游戏（包括 TyranoBuilder、Construct 制作的）在手机上最常见的问题是**画面尺寸不对**——要么像手机里的小窗口，要么被拉伸变形。

JoiPlay 提供了三种全屏策略：

| 策略 | 效果 | 适用场景 |
| --- | --- | --- |
| 保持比例 + 居中（推荐） | 画面按原始比例显示，多余空间黑边 | 最稳，不会裁切也不会变形 |
| 填满屏幕（拉伸） | 强制铺满整个手机屏幕 | 不推荐——4:3 画面被拉成 16:9 会变形 |
| 保持比例 + 扩展 | 保持比例但填满屏幕宽度 | 上下可能黑边，适合宽屏游戏 |

如果画面太小（像个小窗口），说明游戏的缩放倍率太大了——进入游戏设置 → 找 HTML5 / Canvas / Zoom 相关选项，把缩放值从默认的 1.0 调低到 0.6~0.8（1080p 屏幕）或 0.7~0.9（720p 屏幕）。也可以直接修改游戏 `index.html` 里的 `var scale = 1.0` 这一行，但在 JoiPlay 设置里调更方便。

### Ren'Py 视觉小说的存档与回滚

Ren'Py 引擎的视觉小说在 JoiPlay 上体验特别好——因为**完整实现了** Ren'Py 引擎独有的存档系统：

- **无限存档槽**：没有数量上限，想存多少存多少
- **自动保存**：定期自动存档，崩溃了也不怕丢进度
- **回滚（Rollback）**：可以"撤销"刚刚说过的对话和做出的选择——按 Esc 打开菜单就能回退
- **历史回看**：翻回去看之前读过的所有对话

存档文件存在 Android 应用的私有目录下，普通文件管理器看不到。如果要备份存档或传给 PC，有两种方法：一是在 JoiPlay 里找 "Export Save" 选项（取决于插件版本），二是用 ADB 命令拉取。

> [!WARNING]
> **卸载 JoiPlay 或插件会清空存档**——因为存档在应用私有目录里。如果要清理手机或换版本，一定要提前备份存档文件。另外清理手机垃圾时，把 JoiPlay 和 Ren'Py 插件加到清理工具的白名单里，不然容易把存档当成缓存删掉。

### 游戏不支持怎么办

碰到 JoiPlay 跑不动的游戏，先分清楚是哪种情况：

1. **引擎根本不覆盖**：Unity、Unreal 引擎的游戏 JoiPlay 目前不支持（2026 年），只能放弃
2. **引擎覆盖但特定游戏跑不了**：这种情况可能有解

引擎兼容度参考（2026 年数据）：

| 引擎 | 兼容度 | 说明 |
| --- | --- | --- |
| RPG Maker XP/VX/VX Ace/MV/MZ | 90%+ | 王牌引擎，覆盖广 |
| Ren'Py 7.x / 8.x | 90% | 主力引擎 |
| HTML5 纯网页 | 95% | 最稳 |
| TyranoBuilder | 90%+ | 内置支持 |
| Construct 2/3 | ~70-75% | HTML5 路径 |
| Flash（Ruffle） | ~60% | 靠 Ruffle 插件 |
| Godot 3.6/4.3 | ~50% | 2025 年才加，主要支持 2D |
| Unity / Unreal | 0% | 不支持 |

同引擎其他游戏能跑、唯独某一个不行，常见原因有：游戏作者用了 Windows 特定 API、加了 DRM 保护、或依赖 Node.js 后端。可以尝试换插件版本、找游戏有没有 HTML5 导出版、或用 PC 远程桌面串流到手机。

### 版本更新：选哪个通道

JoiPlay 有四个更新通道，频率和适用人群不同：

| 通道 | 频率 | 来源 | 适合谁 |
| --- | --- | --- | --- |
| alpha（内测） | 可能每周多次 | Patreon 银牌及以上 | 想追新的重度用户 |
| beta（测试） | 约每 1~2 周 | Patreon 铜牌及以上 | 普通赞助用户 |
| 稳定版 | 约每月一次 | 官网公开下载 | 所有用户 |
| Google Play | 极慢（可能停更） | 应用商店 | 不推荐 |

插件更新比主程序更频繁——2026 年 2 月主线稳定版 1.21.000 发布时，RPG Maker Plugin 已经是 1.22.008、Ren'Py 8.5 Plugin 是 1.01.00。插件跟着引擎版本迭代走，不受核心 APK 大版本节奏限制。
