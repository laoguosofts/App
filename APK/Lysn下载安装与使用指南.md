## ✨ Lysn 是什么——K-pop 粉丝的私信通道与社区

Lysn 是一款专为韩流（K-pop）粉丝打造的移动端应用，其核心产品是 **bubble** 服务——付费订阅后可以与喜爱的偶像进行类似一对一的私信聊天，艺人会定期发送文字、照片、视频等内容，粉丝也可以回复消息。除了 bubble 私信通道，Lysn 还集成了艺人粉丝俱乐部社区功能，支持 BASIC 免费会员和 ACE 付费会员两级体系，ACE 会员享有更多专属权益和社区互动。

Lysn 的主要使用群体是韩国及全球范围内的 K-pop 粉丝，涵盖 iOS 和 Android 双平台。对于想要近距离追偶像、获取独家内容的粉丝来说，Lysn 是目前主流且官方授权的渠道之一。使用前需要注意的是，bubble 采用订阅制，按艺人单独计费，订阅关系存储在 Lysn 服务器端，不会因为本地操作丢失。

> [!NOTE]
> bubble 订阅按艺人独立生效，你可以同时订阅多位艺人，每位艺人的使用券和消息历史相互独立，互不影响。

## 🔧 安装步骤——双平台安装与注意事项

Lysn 在 iOS 和 Android 平台的安装流程略有差异，以下分别说明。

### iOS 用户（iPhone / iPad）

1. 打开 **App Store**，搜索「**Lysn**」
2. 找到由 **DearU** 开发的官方应用（认准开发者名称，避免下载仿冒版本）
3. 点击 **获取** → 安装
4. 首次打开应用时，系统会请求推送通知权限，建议选择「允许」，否则会错过艺人发送的新消息提醒

> [!TIP]
> iOS 版 Lysn 的 bubble 使用券自动续费由 App Store 订阅系统管理，取消续费需要在 App Store → 个人资料 → 订阅中操作，Lysn 应用内无法直接取消。

### Android 用户

1. 打开 **Google Play**，搜索「**Lysn**」
2. 同样认准 **DearU** 开发者发布的版本
3. 点击 **安装** → 等待安装完成
4. 首次打开时授予必要的权限（推送通知、照片存储等）

### 安装后核对

安装完成后建议做以下检查：

| 检查项 | 方法 |
| --- | --- |
| 是否为最新版本 | 应用商店 Lysn 页面查看更新日志 |
| 推送权限是否开启 | iOS：设置 → Lysn → 通知；Android：设置 → 应用 → Lysn → 通知 |
| 存储权限是否开启 | iOS：首次保存图片时弹窗允许；Android：设置 → 应用 → Lysn → 权限 |

## 📖 使用入门——从 bubble 订阅到 ACE 会员

Lysn 的核心功能可以分为 bubble 私信通道和粉丝俱乐部社区两部分，下面结合常见使用场景展开。

### bubble 使用券的兑换码与赠送

bubble 使用券除了在应用内直接购买，还支持通过兑换码（Gift Code）的方式获取。兑换码的来源包括艺人粉丝活动奖励、社区运营活动中奖、朋友购买后赠送、品牌合作推广等。

兑换码的使用流程：打开 Lysn → 点击右下角 More（☰）→ 找到 Gift Code 或 Redeem Code 入口 → 输入兑换码 → 确认兑换。兑换成功后使用券立即到账，再按照选择订阅成员的流程指定你想订阅的艺人即可。

> [!WARNING]
> 兑换码是一次性使用的，兑换成功后立即失效，且兑换后的使用券不支持退款。大多数兑换码有兑换截止日期，过期后无法使用，请在有效期内完成兑换。

如果想把使用券送给朋友，Lysn 支持两种赠送方式：一是在 Store 页面购买时直接选择「赠送（Gift）」选项，受赠人会收到 Lysn 消息通知；二是部分地区支持购买后生成兑换码，通过 KakaoTalk、Line 等社交应用分享给朋友，韩国地区用户甚至可以在 KakaoTalk 中直接完成跳转兑换。

### 照片视频的查看与保存

艺人在 bubble 聊天中发送的照片和视频是粉丝最关注的内容之一。查看图片时，在聊天室中找到缩略图 → 点击进入全屏查看模式 → 同一消息有多张图片可以左右滑动切换 → 双指缩放放大或缩小。查看视频则是点击播放按钮进入全屏播放器，支持播放/暂停、进度条拖动和音量调节。

保存到相册的操作：图片在全屏查看模式下长按 → 选择「保存到相册」；视频在播放过程中点击播放器的分享/保存按钮 → 选择「保存到相册」。保存位置因平台而异——iOS 的系统相册相机胶卷中，部分机型会单独创建 Lysn 相册分类；Android 则在 DCIM/Lysn 或 Pictures/Lysn 目录下。

> [!TIP]
> 如果保存失败，iOS 用户请检查「设置 → Lysn → 照片」是否选了「所有照片」权限，选「添加照片」权限只能保存到特定相册；Android 用户请确认「存储/照片和视频」权限已开启，并检查文件管理器中是否有 DCIM/Lysn 目录——部分安卓机型的安全文件夹或应用分身模式可能干扰文件保存。

### ACE 会员码的购买与激活

Lysn 粉丝俱乐部有 BASIC 和 ACE 两级会员，ACE 是付费升级档，解锁更多专属权益。购买 ACE 会员码需要先确认你已经在 Lysn 中加入了该艺人的粉丝俱乐部社区（成为 BASIC 会员），并能在社区中找到自己的粉丝俱乐部会员号——这个会员号购买时必须准确输入，输错会导致无法激活。

完整购买流程分为五步：

1. **跳转 YES24**：进入艺人社区 → 点击 Settings（齿轮图标）→ Modify Membership Information → Upgrade to ACE → 点击 Buy ACE Membership Code → 确认跳转 YES24 外部站点
2. **YES24 完成支付**：选择会员码类型 → 选择数量 → 进入购物车 → **关键步骤：输入粉丝俱乐部会员号**（回到 Lysn 复制粘贴，确保完全正确）→ 选择支付方式 → 完成支付
3. **获取会员码**：YES24 通过短信和邮件发送会员码（数字+字母组合），通常 5-10 分钟内收到
4. **回到 Lysn 激活**：打开 Lysn → 进入同一位艺人的社区 → 找到「Enter ACE Membership Code」输入框 → 输入会员码 → 点击 Confirm
5. **确认升级成功**：社区主页显示「ACE」等级，个人资料出现 ACE 电子会员卡

会员码本身有兑换截止日期（通常购买后 30-90 天内必须激活），过期作废；激活后按艺人设定的周期生效，一般为 365 天。

### 误退聊天室的找回方法

操作 Lysn 时容易混淆两个概念：从聊天室返回 CHATS 列表是正常行为，不影响任何东西；但从 CHATS 列表中左滑或长按删除聊天室条目，虽然看起来聊天室丢了，实际上订阅关系和历史消息都还在服务器上——删除操作只是一个本地 UI 的临时隐藏。

找回方法很简单：打开 Lysn → 右下角 More（☰）→ 进入 bubble 页面 → 找到你仍然订阅中的使用券（显示「有效」状态）→ 点击使用券 → 重新选择该艺人 → 保存后聊天室会重新出现在 CHATS 列表中，历史消息也完整保留。

> [!NOTE]
> 只有一种情况真的会影响订阅：订阅到期未续费。此时需要重新在 Store 购买使用券，选择同一艺人后进入聊天室，手动触发「加载之前的消息」来恢复历史记录。

为了防止误删，建议操作 CHATS 列表时尽量用点击而不是左滑——左滑容易误触删除。如果手机有「撤销删除」功能，删除后立即摇晃手机可能弹出撤销选项（仅限部分 iOS 机型）。
