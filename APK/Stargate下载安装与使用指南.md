## ✨ Stargate 是什么——MC 基岩版联机的另一种选择

Stargate 是一款面向《我的世界》基岩版（Minecraft Bedrock Edition）玩家的跨网联机工具。它通过深空中继节点作为中间层，让身处不同网络（移动数据、家庭 Wi-Fi、校园网等）的玩家能够无需公网 IP、无需复杂端口映射，直接在同一个房间里一起建造、探索和玩小游戏。

作为 Alpha 阶段的免费工具，Stargate 的定位很明确：它不替代 Minecraft 本身，也不提供游戏内容，而是专注于解决「基岩版联机难」这个老问题。对于不想折腾局域网搭建、也不想长期租用服务器的小圈子玩家来说，Stargate 提供了一条成本极低（甚至零成本）的联机路径。

它能做什么？简单来说：

- 房主在自己的设备上开房间，设置好房间号，把房间号发给朋友，朋友就能直接进来
- 支持多人同时联机（具体上限取决于房主网络和深空节点状态）
- 内置语音通道，进房间即可加入聊天
- 房主可以踢出违规玩家、管理黑名单、授予临时管理员权限
- 自动节点选择 + 手动切换，应对不同地区网络差异

谁适合用 Stargate？

- 几个朋友想临时一起玩，但没人有公网 IP 或不会搭服务器
- 校园网/公司网环境下，UDP 被封导致其他联机方案失效
- 想快速开个房间和陌生人一起体验，但又不想花时间维护服务器
- 已经在用 Hamachi、蒲公英之类的工具，但想试试更轻量的替代方案

如果你属于以上任何一种情况，Stargate 值得下载试试。

## 🔧 Stargate 安装步骤详解

### Android 安装流程

Stargate 在 Android 上以 APK 形式分发。安装前请确保：

1. 你使用的是 **Minecraft 基岩版**（Bedrock Edition），而非 Java 版。Stargate 目前只支持基岩版
2. 手机系统版本满足 Stargate 最低要求（以官方下载页标注为准）
3. 允许安装来自未知来源的应用（首次安装时需要授权）

**具体步骤：**

1. 从官方下载页获取最新版 APK 文件
2. 打开文件管理器，找到下载的 APK，点击运行
3. 首次安装时如果系统弹出「不允许安装未知来源应用」提示，点击 **设置** → 找到你的浏览器或文件管理器 → 开启 **允许安装未知应用**
4. 回到安装界面，点击 **安装**，等待完成
5. 安装完成后，首次打开 Stargate，系统会请求以下权限，请全部允许：
   - **悬浮窗权限**（联机时需要在游戏界面显示操作菜单）
   - **网络权限**（联机通信必需）
   - **自启动权限**（防止后台被系统杀掉导致断连）
6. 如果手机电池优化限制了 Stargate，请进入 **电池优化设置** → 找到 Stargate → 设为 **不优化**

> [!WARNING] 关于版本核对
> 下载前请务必确认 APK 版本号与官方发布的最新 Alpha 版一致。使用过期版本可能遇到已知的断连 Bug、兼容性问题或安全漏洞。安装前建议用杀毒软件扫描一遍 APK 文件。

### iOS 安装说明

iOS 设备上安装 Stargate 需要通过 TestFlight 或企业签名渠道。以官方发布的 iOS 分发方式为准，安装后在系统设置中信任开发者证书即可正常运行。

### 安装完成后怎么核对

第一次打开 Stargate，完成深空 Aurora 账号登录后，检查以下两点确认安装无误：

- 主界面能正常显示，没有崩溃或白屏
- 三横线菜单 → 设置 → 游戏启动路径，能正确识别到你手机上的 Minecraft 基岩版安装路径

## 📖 Stargate 使用入门——从建房到管理房间

### 第一步：登录深空 Aurora 账号

打开 Stargate 后，首先需要使用深空 Aurora 账号登录。Aurora 是深空平台的统一账号体系，注册过程简单，使用邮箱或手机号即可完成。如果已经有 Aurora 账号，直接登录即可。

登录成功后，主界面会出现「创建房间」和「加入房间」两个核心按钮，底部还有公开房间列表、好友列表等入口。

### 第二步：创建房间

点击主界面的 **创建房间**，按以下流程操作：

1. 选择你想联机的 Minecraft 存档。存档列表直接读取手机上的基岩版存档目录，找到想分享的世界即可
2. 设置房间人数上限（一般建议 4-8 人，超过后房主网络压力会明显增大）
3. 设置房间隐私：
   - **私人房间**（推荐）：只有拿到房间号的人能加入，适合熟人圈子
   - **公开房间**：会出现在 Stargate 的公开房间列表里，任何人搜索到都能加
4. 点击 **创建**，等待几秒后房间创建完成，会显示 **房间号** 和 **邀请二维码**
5. 把房间号直接发给朋友即可，朋友在 Stargate 主界面点击 **加入房间**，输入房间号就能进来

> [!TIP] 建房小贴士
> 房主的手机需要保持亮屏或处于前台状态。如果手机锁屏、杀后台或关机，整个房间会断开。建议建房前插好电源、保持电量充足。

### 第三步：加入房间

收到朋友发来的房间号后：

1. 打开 Stargate → 主界面 → **加入房间**
2. 输入 4-6 位房间号
3. 点击确认，等待连接成功
4. 成功后 Stargate 会自动拉起 Minecraft，直接进入联机世界

如果遇到加不进房间的情况，先确认几个基础点：房间号有没有输错、房主的 Stargate 有没有关闭房间、双方的 Minecraft 基岩版版本号是否在同一个次版本（比如都在 1.20.x）。

### 第四步：联机中的房主管理

联机过程中，房主可以随时通过 **Stargate 悬浮窗** 管理房间。悬浮窗会覆盖在游戏画面上方，点击可展开操作菜单。

**踢人与黑名单**

| 情况 | 推荐处理 |
|------|----------|
| 炸图、偷箱子 | 立即踢出 + 加入黑名单 |
| 故意导致全房卡顿 | 踢出 + 黑名单 |
| 语言骚扰或吵架 | 先警告，不听再踢 |
| 新手不懂规矩拿了东西 | 先沟通，再决定 |
| 网络差频繁掉线重进 | 不踢，让他改善网络 |

操作路径：悬浮窗 → 玩家列表 → 点击目标玩家 → 选择 **踢出房间**，可勾选 **同时加入黑名单**。

踢出和加入黑名单的区别：

- 仅踢出：玩家本次进不来，房主下次开新房可以再进
- 踢出 + 黑名单：该玩家之后永远加不上房主开的任何房间，搜索也搜不到

**临时管理员**

房主可以给信任的朋友授予临时管理员权限，让他帮忙管理房间秩序。管理员能做的事有限：

- 可以踢出玩家（但不能拉黑）
- 可以切换游戏模式
- 可以查看房间设置

但管理员 **不能** 关闭房间、修改人数上限或管理房主权限。授予方法：悬浮窗 → 房间设置 → 管理员 → 添加玩家。

### 第五步：断线了怎么办

掉线是联机工具的常见问题。关键是先判断 **只有你掉了还是所有人都掉了**：

**只有你掉线**，按优先级排查：

1. **切换 Stargate 节点**：设置 → 节点选择 → 手动切另一个备用节点，重进房间
2. **换个物理网络**：Wi-Fi 不行就切 4G/5G，移动数据不行就换个 Wi-Fi
3. **检查手机杀后台**：给 Stargate 开启自启动权限、锁定后台、电池优化设为「不优化」
4. **手机过热或低电量**：插电、去壳降温，过热时手机会强制降频或断网
5. **更新 Stargate 到最新版本**：旧版本可能有已知的断连 Bug
6. **确认 MC 版本匹配**：你和房主要在同一个基岩版次版本号

**所有人同时掉线**，问题不在你：

- 房主网络断了、手机杀后台、没电关机 → 等房主恢复后重开
- 深空节点故障 → 关注官方渠道公告，临时可以用 Hamachi 或局域网顶上

**断线后快速重连**：不要让房主重新建房。回到 Stargate 主界面，点加入房间 → 重新输入房间号。Stargate 的重连机制会帮你恢复到断线前的游戏状态。

### 设置项速查

打开 Stargate → 左上角三横线菜单 → 设置页面，以下是几个值得调整的选项：

| 设置项 | 建议 |
|--------|------|
| 自动拉起游戏 | 保持开启（默认）。建房/加房完成后自动打开 MC，省事 |
| 游戏启动路径 | 如果装了多个 MC 版本（国际版 + 国服），确认这里选对了 |
| 节点选择 | 推荐自动。遇到连接问题时手动切换备用节点 |
| 悬浮窗透明度 | 默认 50%-70% 即可，太透明容易看不清 |
| 语音开关 | 开着，联机语音比打字高效太多 |
| 自动加入语音 | 开启，进房间自动进入语音通道 |

以下设置 **不要随意改**：端口号、网络协议、调试模式。这些是开发和高级排错用的，普通玩家保持默认就好。

### 安全使用要点

Stargate 官方宣称联机数据采用端到端加密传输，中继节点只转发加密包无法解密。账号登录走 HTTPS，不收集 MC 存档数据。但安全不能只靠工具，用户自己也要做几件事：

- 私人房间只拉认识的人，公开房间里别放珍贵物品
- 只从官方渠道下载 Stargate APK，安装前杀毒扫描
- 定期备份 MC 存档（防炸图、防误删）
- 不在公共 Wi-Fi 下登录深空 Aurora 账号

> [!NOTE] 关于安全机制的边界
> 端到端加密只保护传输中的数据，设备本身被入侵依然无能为力。防作弊依赖版本匹配，如果有人用了更新的作弊手段可能暂时检测不到。Stargate 目前仍在 Alpha 阶段，安全机制也在持续完善中。
