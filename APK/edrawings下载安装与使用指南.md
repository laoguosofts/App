## ✨ eDrawings 是什么

eDrawings 是 Dassault Systèmes SolidWorks 推出的一款轻量级 CAD 文件查看与评审工具，核心定位是让非建模人员也能无障碍打开、旋转、批注三维装配体与二维工程图。它本身不做建模，专注于「接收别人做好的设计文件，快速看懂、快速反馈」这条链路。

官方把它分成两个档位：免费的 eDrawings Viewer 和付费的 eDrawings Professional。免费版足以应对绝大多数「打开、旋转、看动画、看爆炸视图」的场景，专业版则补上了精确测量、剖面查看、移动零部件、质量属性读取等深度审阅能力，是设计评审组织者、采购核件、客户验收这类角色的得力工具。

支持的文件格式覆盖了主流 CAD 生态：SolidWorks 原生的 .sldprt / .sldasm / .slddrw，eDrawings 自有格式 .eprt / .easm / .edrw，以及 DXF、DWG、STL、3DXML 等常见中间格式。打开文件后你可以自由旋转、缩放、平移，播放预烘焙的动画，切换爆炸视图看装配顺序——整个过程比启动完整建模软件快得多，对硬件的要求也低得多。

很多团队用它来做「设计评审的统一入口」：建模方把文件另存为 eDrawings 格式发出去，收件人不管用什么电脑，装好查看器就能看，不需要装整套 SolidWorks 或其他 CAD 软件。文件本身还能附带批注、尺寸、测量点等审阅标记，评审结束后可以把意见回传建模方。

## 🔧 安装步骤

### Windows 桌面版

官方安装包提供完整的向导式安装流程。下载完成后双击运行 `.exe` 文件，按以下步骤操作：

1. **选择安装类型**：首次安装推荐「典型安装」，只装核心组件体积最小；如果需要配套的插件和关联模块，选「自定义」自行勾选。
2. **确认安装路径**：默认路径是 `C:\Program Files\eDrawings`，建议保持默认，避免关联文件时路径解析异常。
3. **等待安装完成**：首次安装大约需要 1-3 分钟，安装过程中会注册文件关联，完成后桌面上会生成 eDrawings 快捷方式。

> [!TIP] **安装完成后立刻做一件事**：找一份测试文件打开，确认 .eprt / .easm / .edrw 能正常关联到 eDrawings 而不是被其他软件占用。如果关联错了，在文件上右键 → 打开方式 → 选择 eDrawings 并设为默认。

### macOS 版

Mac 用户注意两个边界：官方只提供免费查看器，没有专业版；同时 Mac 版无法对 DXF/DWG 格式使能测量。安装流程相对简单：下载 `.dmg` 文件，双击挂载后把 eDrawings 图标拖进「应用程序」文件夹即可。首次打开可能需要在系统偏好设置 → 安全性与隐私里放行「来自未知开发者」的提示。

### 移动端（iOS / Android）

手机版走应用商店渠道，直接搜索 eDrawings 安装即可。移动端的强项是配合 AR 功能做实体摆放——把 CAD 模型投到真实空间里看比例和布局，现场沟通特别方便。免费版和专业版在移动端的区分相对模糊，大部分基础功能都开放，只是专业版订阅能解锁额外的审阅工具。

## 📖 使用入门

### 打开文件的基本姿势

启动 eDrawings 后直接把文件拖进窗口，或者用「文件 → 打开」选择文件。首次打开某个大型装配体可能需要几秒加载，加载完成后模型会自动居中显示。左侧窗格列出了装配体的零部件清单，可以点开单个零件查看、隐藏/显示、切换颜色。

### 旋转、缩放、平移

三个操作都在工具栏上有对应按钮，也可以用鼠标操作：

- **旋转**：按住鼠标左键在画面里拖动，模型绕中心旋转
- **缩放**：滚轮前后滚动，或按住鼠标右键拖动
- **平移**：按住中键（或 Alt + 左键）拖动画面

> [!NOTE] 专业版里还有一个便捷操作：选中某个零件后按 F 键，视图会自动聚焦到这个零件上，适合在大装配体里快速定位。

### 爆炸视图：一眼看清装配结构

如果发文件的人在建模软件里做好了爆炸配置，打开装配体文件后可以在左侧窗格找到「爆炸视图」面板。面板里列出了所有可用的爆炸配置，选中一个就能在爆炸状态与收拢状态之间无缝切换。拖动面板上的滑块，爆炸程度可以在「轻微错位」到「完全拉开」之间连续调节——想停在什么位置就停在什么位置。

爆炸状态下所有查看工具照常工作，专业版用户还能在爆炸状态下测量间隙、做剖面查看，是评审里的常见组合动作。需要注意的是，爆炸配置是建模软件里预先定义好的，查看器端只能展示和切换，不能新建或编辑爆炸步骤。爆炸步骤里甚至可以包含「旋转零部件」类型——零件边旋转边平移拉开，这类步骤同样能逐步回放。

### 测量：按钮为什么是灰的

很多人第一次用测量功能时会发现按钮是灰色的，点不动。这不是软件坏了，而是一套「权限跟随文件」的机制——测量能不能用，在文件保存那一刻就定了。

| 文件来源 | 使能条件 |
| --- | --- |
| 自有格式（.eprt / .easm / .edrw） | 保存时必须勾选「允许测量此文件」 |
| 查看器里另存的自有格式 | 原始文件本身已使能 + 另存时补勾「启用测量」 |
| SolidWorks 原生文件 | 仅专业版/白金版许可保存的文件才能在免费查看器里测量 |

两个例外需要记住：**专业版查看器**不受上面第三条限制，不管建模时用什么许可保存，专业版里都能测，这也是很多人升级专业版的直接原因；**Mac 版对 DXF/DWG 无法使能测量**，Windows 版则支持这两类二维文件。

如果你是发文件的人，建议默认全部勾上「允许测量」——量尺寸的需求几乎总会出现，除非文件涉密或发给外部供应商。

### 移动零部件：把挡住的件挪开

看装配体时最烦的就是目标零件被外壳罩得严严实实，旋转缩放都绕不开。专业版提供了两条解法：

**移动零部件（Move Component）**：选中要挪的零件，沿任意方向拖离原位。官方把它与测量、剖面并列为爆炸状态下可用的专业版工具——先拉开爆炸视图再挪件，内部结构能完全暴露。

**隐藏/显示**（免费版替代方案）：打开零部件窗格，找到遮挡件取消显示，看完再恢复。缺点是隐藏是「整体消失」，不能保留空间参照；移动则保留了「它应该在附近」的直觉，不容易迷失位置感。

> [!TIP] 挪动操作只是查看手段，交付前一定要把件放回去（或重新打开文件），避免误导下一轮审阅。挪小件（螺栓、卡扣）比挪大件（壳体）更能保留整体感。

### 剖面查看与批注

剖面查看是专业版的核心审阅能力之一，支持 XY、YZ、XZ 三个方向的平面剖，也可以自定义剖切平面。剖面之后模型的内部结构一目了然，壁厚、间隙、配合关系这些平时藏在外壳里的细节全部暴露出来。

批注能力分两种视角：**写**是专业版专属，**读**是免费版就能用。别人发来的带批注文件，免费版可以完整查看所有云线、文字标注和尺寸标记；但要自己创建和编辑批注，就需要专业版许可。批注类型包括云线圈注、文字评论、尺寸标注、点到点测量，评审意见可以直接贴在图上对应的位置。

### 免费版 vs 专业版怎么选

两个版本共用同一个查看器外壳，差异集中在「看」之外的能力：

| 能力 | 免费查看器 | 专业版 |
| --- | --- | --- |
| 打开自有格式与常见 CAD 格式 | ✅ | ✅ |
| 动画、爆炸视图、3D 指针 | ✅ | ✅ |
| 查看他人批注 | ✅ | ✅ |
| 创建/编辑/保存评审批注 | ❌ | ✅ |
| 精确测量（不受许可限制） | ❌ | ✅ |
| 剖面查看 | ❌ | ✅ |
| 移动零部件 | ❌ | ✅ |
| 质量属性（重量/体积） | ❌ | ✅ |
| 另存为单文件网页 HTML | ❌ | ✅ |
| VR 头显评审 | ❌ | ✅ |

判断标准很直接：只需要打开、旋转、看动画——免费版完全够用；需要在图上圈问题、量尺寸、剖开看内腔——这是专业版的核心场景，设计评审组织者基本都需要。
