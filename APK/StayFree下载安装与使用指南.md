## ✨ StayFree 是什么：一款真正能帮你管住手机的应用

StayFree 是一款专注于时间管理与应用拦截的工具类应用，核心思路很直接——当你想专注的时候，它帮你挡住那些让你分心的东西。不同于其他同类应用只做提醒或统计，StayFree 的核心卖点是**真正可执行的拦截**：支持按时段自动触发的定时拦截、可量化的每日使用上限、跨设备的同步计划，以及辅助功能驱动的应用内拦截层。

它的主要功能模块包括：Focus Mode（专注模式，一键进入完全无干扰的状态）、Schedule Blocks（定时拦截，到点自动生效）、Daily Limits（每日限额，超时即拦）、跨设备同步（手机、平板、电脑共享同一套计划），以及浏览器扩展支持（在电脑端拦截网站）。

StayFree 适用于几类典型场景：工作日需要强制不碰社交软件的上班族、考试周想彻底戒掉短视频的学生党、睡前容易刷手机停不下来的用户，以及任何希望建立更健康数字习惯的人。

## 🔧 安装步骤：Android 端与浏览器扩展两部分

### Android 主应用安装

1. 从官方下载页获取 APK 安装包，核对文件大小后点击安装
2. 如果系统提示「未知来源」，进入 **设置 → 安全**（部分机型是 **设置 → 隐私**），开启「允许安装未知来源应用」权限

> [!WARNING]
> 首次安装后务必完成权限配置：辅助功能服务（用于应用内拦截）、Draw Over Other Apps（用于拦截弹出覆盖层）、使用情况访问权限（用于统计应用使用时长）——缺任何一项都会导致拦截效果打折。

3. 打开 StayFree，按引导依次授予权限，完成后可以开始使用

### 浏览器扩展安装（电脑端拦截网站用）

StayFree 的跨设备同步需要在电脑端安装对应的浏览器扩展。Chrome 用户打开 Chrome 网上应用店，Firefox 用户打开附加组件商店，搜索 StayFree 安装后登录同一账号即可。扩展支持 Focus Mode 下在浏览器中直接拦截被禁网站。

### 多设备配对

如果你有多台设备需要共享拦截计划，在第二台设备上安装后，打开 StayFree 的「Manage Devices」页面，从主机生成配对码输入，两台设备登录同一账号后数据会自动合并。

## 📖 使用入门：从定时拦截到专注计划，把手机时间抢回来

### 定时拦截：最省心的入门玩法

Schedule Blocks 是 StayFree 最受欢迎的功能之一——你只需要提前告诉它「每天工作日 9 点到 18 点拦掉这些应用」，到点拦截自动开启，过了时段自动解除，你不需要每天手动操作。

典型的定时拦截组合包括：工作日 9:00-18:00 拦掉所有社交媒体和短视频、晚上 22:00 到次日 7:00 的睡前屏蔽、考试周每天 8:00-22:00 的学习时段专项拦截。创建一个定时计划只需要五步：打开 StayFree → Focus Mode → 点击「+」新建 → 起名并选生效日期与时段 → 勾选要拦截的应用和网站 → 保存。

> [!TIP]
> StayFree 支持多计划并存，同一天内可以有多份不同时段的计划。如果两份计划的时段有重叠，重叠部分的拦截规则会自动取并集——两个计划里的所有被拦内容在那个时段都会生效。

### 自动专注计划：让 Focus Mode 自己启停

自动专注计划就是 Focus Mode 的 Schedule Blocks 版本。你可以为 Focus Mode 设一份时间表，比如「工作日 9:00-18:00 自动激活 Focus Mode」，到点自动开启、过点自动关闭。

一个经典的每日计划组合通常是这样的：

| 计划名称 | 生效时段 | 生效日期 | 拦截范围 |
| --- | --- | --- | --- |
| 工作时段 | 09:00 - 18:00 | 周一至周五 | 社交 + 短视频 + 游戏 |
| 午休放松 | 12:00 - 13:30 | 周一至周五 | 不拦（休息） |
| 睡前屏蔽 | 22:00 - 次日 07:00 | 每天 | 全部非必要应用 |
| 周末松弛 | 不自动激活 | 周六、周日 | 不拦 |

工作日白天强制不碰干扰源，午休给点弹性，睡前挡掉刷手机，周末不自动拦——这个组合的好处是工作日的"不费脑子"和周末的"不过度约束"同时兼顾。

### 临时覆盖：今天例外怎么办

计划永远赶不上变化——有时候今天加班需要多开一会儿，或者想摸鱼半天。StayFree 允许你**临时手动覆盖**自动计划：

- 自动计划进行中 → 可以手动解除拦截，此时 StayFree 进入「手动临时覆盖」状态
- 自动计划未在进行 → 可以手动提前激活，此时 StayFree 进入「手动提前激活」状态

关键点在于：手动覆盖**不会改掉自动计划本身**，第二天到点还是自动生效。手动覆盖状态会在计划原定的结束时间自动让权给自动计划，不需要你记得手动切回去。

### 拦截不触发怎么办：四类常见原因排查

遇到 Focus Mode 激活了但被拦应用还能打开的情况，按以下顺序排查效率最高：

**被拦清单没勾对**：Focus Mode 拦什么完全取决于你配置清单时的勾选。很多时候你以为某个应用被加进去了，其实只勾选了"社交"类分类但没单独勾那个 App。打开计划仔细核对一下勾选清单。

**辅助功能或覆盖层权限被撤销**：Android 的权限系统会在特定条件下自动撤销应用权限（比如长期不用、电池优化强制休眠）。这两个权限任何一个掉了，拦截效果都会大幅下降——检查权限重新授权即可。

**手动覆盖状态没解除**：你之前可能手动解除过自动计划，那个手动覆盖状态还在面板里挂着。打开 Focus Mode 面板看一下显示的是「自动计划」还是「手动激活/覆盖」，如果是后者点击 Deactivate 彻底解除。

**Daily Limits 超时后动作设置**：如果用的是 Daily Limits 功能，检查超时后动作是不是设成了「通知」或「可关闭弹窗」——这两种只会提醒不会真拦。改成「阻断」才会真正拦截。

### 跨设备同步问题排查

多设备配对了但数据没合并或 Focus Mode 没同步触发时，先查三件事：两台设备是不是登录了**同一个账号**（配对码只是建立连接关系，数据汇总靠账号标识）、是不是都在正常联网、系统时区是不是一致（时区不一致会导致自动计划在不同时间点触发）。
