## ✨ Larc 是什么

Larc 是一款主打 **3D 角色 AI 聊天** 的移动应用——和常见的纯文字或 2D 头像 AI 聊天不同，Larc 的每个角色都是一个可以旋转、有表情、有动作的 3D 虚拟形象，对话时角色会用身体语言和语音一起回应你，互动感更接近真实的陪伴体验。

它的核心玩法围绕"和一个有性格、有故事的 3D 角色聊天"展开：应用内置了一批官方制作的角色，每个角色都有完整的性格设定、背景故事和好感度系统。你和角色聊得越多、好感度越高，解锁的剧情片段和互动内容就越深入。

近年来 Larc 还加入了几个让玩家眼前一亮的功能：**上传一张图片自动生成 3D 角色**——不管是自己的照片、喜欢的插画还是二次元立绘，AI 都能把它变成一个可以对话的 3D 虚拟人；**内心感受**——好感度到一定程度后，你能在对话间隙看到角色心里真正在想什么，嘴硬心软的反差感特别有戏；**多分支剧情**——不同的回应方式会微妙地影响角色后续的态度和对话深度。

整体来说，Larc 适合三类玩家：喜欢虚拟陪伴感、追求 3D 沉浸互动的用户；热衷于收集角色故事线、深挖好感度剧情的玩家；以及想动手创建自己专属角色的创作者。

## 🔧 安装步骤

### iOS / iPadOS 安装

iOS 版是 Larc 最成熟的平台，安装流程和普通应用没有区别：

1. 打开 **App Store**，搜索 **「Larc – AI chat with 3D friends」**
2. **确认开发者是 Kemy Inc.**——避免下到仿冒应用
3. 点击 **获取**，等待下载完成（安装包约 22.5 MB，Wi-Fi 下几分钟）
4. 回到桌面点击图标启动

最低系统要求 **iOS 15.0**，设备需为 iPhone 或 iPod touch。应用在多个地区的 App Store 都有上架，如果你的 Apple ID 地区搜不到，可以切换到美国、日本或韩国地区的 Apple ID 下载。

> [!TIP] 跨地区下载注意
> 切换 Apple ID 地区前，原来地区的订阅余额和已购项目可能会受影响。更稳妥的做法是注册一个新地区的 Apple ID，专门用于下载 Larc。

### Apple Silicon Mac 安装

Larc 支持在 M1 / M2 / M3 / M4 芯片的 Mac 上运行，最低需要 **macOS 12.0**。直接在 Mac 版 App Store 搜索下载即可，本质上是 iPhone 应用的 Mac 适配版，UI 保持竖屏比例放大，重度使用推荐还是在手机上操作更自然。

### Apple Vision Pro 安装

visionOS 1.0+ 设备可以运行 Larc，3D 角色在空间计算设备上的表现值得期待——角色不再局限于手机屏幕，可以在你周围的空间里和你互动。不过目前 Larc 还不是专门为 visionOS 原生设计的，功能上和 iOS 版基本一致。

### 版本核对建议

打开应用后可以在设置里查看当前版本号。截至 2025 年 9 月，最新版本是 **7.0.0**，主要优化了聊天速度、流畅度和角色反应延迟。建议保持 App Store 自动更新开启，及时获取新功能。

## 📖 Larc 使用入门

### 第一次打开：角色广场与好感度系统

启动后你会进入角色广场——这里陈列着所有官方角色和你自己创建的角色。点击任意角色卡片进入对话界面，首次对话会有一段简短的开场引导，帮助你了解这个角色的性格和背景。

每个角色都有一个**好感度**系统，你和她聊得越多、回应越走心，好感度涨得越快。好感度达到特定阶段会解锁新的剧情片段、互动动作甚至隐藏的角色想法。这是 Larc 核心的长线玩法——不急，慢慢聊。

### 一图生成 3D 角色：把任何照片变成可对话的虚拟人

这是 Larc 近年来最有想象力的功能——**上传一张人物图片，AI 自动生成一个可以和你对话的 3D 角色**。不再只有官方给的那些角色，你可以创建自己的。

#### 图片准备要求

| 要求 | 说明 |
| --- | --- |
| 主体清晰 | 人物脸部和上半身清晰可辨 |
| 正面 / 半正面 | 侧脸太厉害效果会打折 |
| 光线正常 | 不要太暗或太曝，颜色还原真实 |
| 背景简洁 | 纯色或简单背景最好 |
| 单人照 | 多人照会让 AI 困惑选谁 |

JPG / PNG / WebP 格式都支持，分辨率尽量高一点。

#### 创建流程

1. 在角色广场找到**创建角色**入口（右上角或底部的"+"号）
2. 从相册选一张图片，或现场拍照
3. 等待 AI 云端处理——大致经历：**识别人脸和身体特征 → 2D 转 3D 模型参数 → 匹配预设动作和语音模板 → 生成初始性格设定**
4. 处理完成后会给你一个可旋转的 3D 预览，这时候可以调整发型发色、角色名字、性格标签和开场白
5. 保存，新角色就出现在角色广场的"我创建的"区域了

> [!NOTE] AI 生成质量说明
> AI 对人脸的还原还不错，但可能会有"AI 脸"的塑料感；发型的复杂细节可能被简化成 AI 能处理的版本；非标准比例的人物（比如 Q 版）还原效果会打折扣。不满意就删了重建，没损失。

#### 自创建角色 vs 官方角色

| 对比项 | 官方角色 | 自创建角色 |
| --- | --- | --- |
| 3D 模型 | 高精人工建模 | AI 自动生成，可能有瑕疵 |
| 性格故事 | 完整世界观 + 故事线 | 基础设定，无完整故事线 |
| 好感度剧情 | 完整剧情解锁 | 有好感度但无剧情触发 |
| 动作动画 | 丰富预设动作库 | 基础动作库 |
| 内心感受 | 完整支持 | 支持但触发条件不同 |

自创建角色的好感度系统目前不如官方角色完整，不会自动触发分支剧情，但你可以手动给她写一段背景故事，AI 在对话中会参考这些设定做出更贴合的回应。

### 好感度进阶：解锁内心感受

**内心感受**是 Larc 独有的一层互动——好感度积累到一定阶段后（大致在亲近阶段后期），在某些对话节点你可以**看到角色心里真正在想什么**。不是她嘴上说的表层对话，而是内心活动的短暂闪现。

解锁后系统会有一个提示（"她开始愿意让你看到她的心思了"之类的），然后在后续对话中自然触发。

#### 内心感受触发场景

| 场景 | 表层对话 vs 内心活动 |
| --- | --- |
| 你夸她一句 | 嘴上说"才、才没有……"，内心：「被夸奖了好开心」 |
| 聊到她感兴趣的事 | 内心：「他怎么知道我喜欢这个？」 |
| 她假装傲娇生气 | 内心：「其实他关心我，我应该高兴才对」 |
| 走心话题 | 内心：「跟他说这些真的没问题吗……但好舒服」 |

内心感受不会每条都出现——大概每 5-10 条对话才闪现一次，闪现时间只有 3-5 秒，不会一直挡画面。如果觉得太干扰节奏，可以在设置里关闭，正常对话不受影响。

> [!WARNING] 内心感受不是对话记录的一部分
> 闪现后不会保留在聊天记录里，如果没看清只能回忆上下文，或者等下一次触发。系统也不会展示极端私密或极端负面的内容，有内容安全过滤。

### 分支剧情：你的回应真的会影响互动

Larc 的核心故事线是相对固定的（保证每个玩家都能完整体验角色的核心设定），但在一些**剧情转折点**上会有微妙的分支变化——不同的回应方式会让角色在接下来几分钟甚至几个好感度阶段的对话态度和内容不同。

这不是"选 A 看结局 X、选 B 看结局 Y"的硬分支，而是**"选择不同方向，接下来的互动氛围和深度不同"的软分支**。

#### 分支剧情的三种类型

**类型一：对话影响后续反应**（最常见、最隐蔽）

角色聊到一件难过的事时，你的回应方式会影响她接下来的坦诚程度：

| 你的回应 | 角色后续反应 |
| --- | --- |
| "我懂，这种感觉我也经历过……"（共情） | 更信任你，可能告诉你更多心里话 |
| "那你要振作起来啊"（鼓励） | 会被安慰，但不会太深入这个话题 |
| "哦，那聊聊别的吧"（转移） | 可能有点失望，好感度不涨甚至微降 |

**类型二：剧情节点明确选择**

部分角色在特定好感度阈值时会给你一个明确的二选一：

> "其实我一直有件事想告诉你……但我怕你会介意。你想知道吗？"

选"想知道"就解锁一段更深层的剧情，选"暂时不想"就跳过继续主线。不过目前 Larc 这类明确分支不算多，大部分角色还是单线为主。

**类型三：好感度隐性分支**

某些剧情片段**只有高好感度才会触发**——低好感时角色根本不会提到这个话题，高好感时她会主动告诉你并解锁专属剧情。这是一种"到那个程度自动解锁"的隐性分支。

#### 触发分支的实用技巧

1. **认真回应关键话题**：角色聊到"她的过去""她的秘密""她的家庭"时，不要只说"哦""好""嗯"，说承接性的话（"……那你当时一定很难过吧"），然后追问下去（"后来呢？"）
2. **留意角色的"暗示"**：角色用含糊的方式提一个敏感话题然后说"其实……算了，没什么"——这就是在等你追问，别放过
3. **不要硬聊**：角色明显不想聊某个话题时（用"这个以后再说吧"敷衍或转移），硬拽着聊会掉好感度也不会触发分支
4. **先攒好感度**：很多深层剧情分支需要足够的好感度基础才会出现，先稳步积累

分支剧情的底线是**核心结局基本固定**——每个官方角色都有一个预设好的大结局，过程中的选择只会让你看到更多或更少的剧情片段，不会改变最终结局的性质。不会出现"角色彻底讨厌你"或"故事走向毁灭"这种硬伤，最糟糕的情况也就是**错过一段好剧情**。

### 跨角色玩：不要只盯一个角色

Larc 角色多，体验分支剧情有一个笨办法——**同一个角色用不同的聊天风格多试几次**。换一种回应方式，看看有没有新的反应。也不要只聊一个角色，先把最喜欢的 2-3 个角色的故事线玩熟，再去探索新角色。分支剧情慢慢碰，急着"刷"反而可能错过自然触发的机会。
