## ✨ WinKawaks 是什么

WinKawaks 是一款面向 Windows 平台的经典街机模拟器，主要支持 CAPCOM 公司的 CPS1/CPS2 基板游戏以及 SNK 的 Neo-Geo 系列。如果你想在电脑上重温《拳皇 97》《街头霸王 Zero》《圆桌骑士》《恐龙快打》这些童年街机厅里的招牌作品，WinKawaks 是目前仍在被广泛使用的老牌选择之一。

这款模拟器的核心优势在于兼容性稳定、操作简单，内置的 Kaillera 联机客户端让玩家可以跨越网络和朋友一起对战——这也是它至今没有被新一代模拟器完全取代的原因。对于不想折腾复杂配置的怀旧玩家来说，WinKawaks 提供了一条"解压即用"的低门槛路线：下载模拟器本体 → 放入 ROM → 载入游戏，三步走就能开玩。

**适合谁用**：想在 PC 上玩街机老游戏的怀旧玩家；想和朋友在网上对战拳皇、街霸的联机党；对 MAME 等全能模拟器的复杂设置望而却步、只想跑几款经典 CPS/Neo-Geo 游戏的轻量用户。

## 🔧 安装步骤

WinKawaks 以绿色压缩包形式分发，**不需要传统的安装向导**，解压即可运行。但正因为"解压即用"的特性，很多新手会在路径选择和杀毒软件误报上卡住。

### 安装流程

1. **解压压缩包**：建议解压到一个固定位置，比如 `D:\Games\WinKawaks\`。**不要解压到桌面或系统盘的 Program Files**——后者在 Windows 10/11 下可能因为权限限制导致存档和配置文件无法写入。

2. **核对目录结构**：解压后应该能看到 `WinKawaks.exe` 主程序、`roms\` 子文件夹、`kaillerasrv.exe`（联机服务器端）、`winkawaks.ini`（配置文件）等。`roms\` 文件夹是放置游戏 ROM ZIP 文件的目录，名字不能改。

3. **杀毒误报处理**：WinKawaks 本体不是病毒，但部分杀毒软件（尤其是国产免费杀软）会对模拟器类工具报启发式病毒。遇到这种情况**不要直接删除**，将 WinKawaks 安装目录加入杀毒软件的信任列表或白名单即可。

> [!WARNING]
> 不要在各种"汉化增强版""绿色精简版"二次打包的分发站下载——这些版本可能被植入恶意代码。优先从可信渠道获取原始压缩包。

4. **首次启动测试**：双击 `WinKawaks.exe` 启动。如果没有 ROM，主界面的游戏列表会是空的——这是正常的，说明模拟器本身没问题。

## 📖 使用入门

### 基本操作

启动 WinKawaks 后，通过 `File → Load game` 打开 ROM 列表窗口。勾选右侧的 `Only Available` 可以过滤掉本地没有的游戏，只显示你 roms 文件夹里实际存在的 ROM。选中一款游戏点击 OK 即可载入。

载入游戏后，默认处于**窗口模式**——画面显示在一个带灰色边框的独立窗口里。随时按 `Alt + Enter` 可以在窗口和全屏之间切换。

### 窗口模式 vs 全屏模式

两种模式各有利弊，适合不同场景：

| 对比项 | 窗口模式 | 全屏模式 |
| --- | --- | --- |
| 画面占用 | 独立窗口，可调整大小 | 填满整个显示器 |
| 切应用 | 直接点其他窗口，无闪烁 | Alt+Tab 切换会闪屏 |
| 适合场景 | 日常玩、查攻略、截图录像 | 联机对战、沉浸体验 |
| 像素效果 | 缩放后可能模糊 | 原生分辨率，像素锐利 |

日常使用推荐 **窗口模式 + 2~3 倍窗口缩放**（快捷键 `Ctrl+2` / `Ctrl+3`），配合 1280×720 或 1920×1080 的窗口大小，既能看清像素又不会占满屏幕。对战时再切回全屏，减少干扰。

> [!TIP]
> 某些多显示器环境下全屏会黑屏——按 `Alt+Enter` 切回窗口，在 Video 菜单里关闭 Full Screen 勾选，重启后重新调整分辨率设置即可。也可以直接改 `winkawaks.ini` 里的 `fullscreen` 字段为 `0`，强制窗口启动。

### 联机对战（Kaillera）

Kaillera 是 WinKawaks 内置的联机协议，支持两个以上玩家在网络上对战同一款街机游戏。以下是从 0 到打通公网对战的完整路径。

#### 第一步：启动联机客户端

**不需要先载入游戏**——Kaillera 客户端在游戏外启动。从主界面菜单选择 `File → Start netplay...`，会弹出 Kaillera 客户端窗口。点击窗口里的 `Enter IP...` 按钮，输入服务器的公网 IP 地址（纯数字格式，比如 `202.108.22.13`），然后点击 Connect。

连接成功后窗口会刷新，显示服务器名、在线人数和当前游戏房间列表。

> [!NOTE]
> Kaillera 没有中心化的官方服务器列表。服务器 IP 通常靠玩家在论坛、贴吧、QQ 群里分享；不想依赖别人的话可以自己搭一个本地服务器。

#### 第二步：加入或创建房间

连接成功后有两种方式进入对战：

- **加入已有房间**：在下方列表里找到想玩的游戏（比如 The King of Fighters 97），选中后点 `Join`，进入等待界面等其他人准备好后点 Start Game。
- **自己创建房间**：点 `Create new game`，在弹出的 ROM 选择窗口里选中本地 roms 目录里有的游戏，点 OK 创建房间。你成为房主，其他人可以从服务器列表里看到你的房间并 Join。

#### 关键约束：ROM 版本必须一致

**所有参与者的同一款游戏 ROM ZIP 文件 CRC 值必须完全匹配**。如果有人 ROM 版本不同，Join 会被服务器拒绝，或者勉强加入后对战画面不同步、操作无反应。创建房间前先和朋友确认各自用的是同一个版本（比如都是 World 版或都是某个 Hack Plus 版）。

#### 自己开服务器：端口放行

如果你想让互联网上的朋友连接你的本地服务器，需要完成两个环节：**Windows 防火墙放行** + **路由器端口映射**。Kaillera 服务器使用 **UDP 协议监听 27888 端口**（默认值，可在 server.ini 里修改）。

##### Windows 防火墙

启动 `kaillerasrv.exe` 时 Windows Defender 防火墙通常会弹出安全警告，勾选"允许访问"并确定即可。如果之前没注意到弹窗，手动补放行：

1. 按 Win 键搜索 "Windows Defender 防火墙" 打开
2. 左侧菜单点击「允许应用或功能通过 Windows Defender 防火墙」
3. 点击「更改设置」→「允许其他应用...」→「浏览」找到 `kaillerasrv.exe`
4. 添加后确认专用/公用网络都勾上，点击确定保存

##### 路由器端口映射（公网对战必做）

光 Windows 放行不够，路由器还需要把外部发来的请求转发到运行 `kaillerasrv.exe` 的内网机器上。通用步骤：

1. 浏览器打开路由器管理页面（通常是 `192.168.1.1` 或 `192.168.0.1`），输入管理员密码
2. 找到「端口映射」「虚拟服务器」「NAT 转发」等类似菜单
3. 新建规则：协议 UDP、外部端口 27888、内部端口 27888、内网 IP 填你电脑的 IPv4 地址（cmd 里 `ipconfig` 查看）、启用勾选
4. 保存规则，部分路由器需要重启

不同品牌路由器的菜单路径略有差异：TP-Link 在"应用管理 → 虚拟服务器"；小米在"常用设置 → 端口转发"；华为在"更多功能 → 安全设置 → NAT 服务"。

> [!TIP]
> 验证端口映射是否生效：让朋友用手机流量（不要和你在同一 Wi-Fi 下）打开 Kaillera 客户端，输入你的公网 IP 尝试连接。能连上就说明映射成功。

如果用云服务器（阿里云、腾讯云等）开 Kaillera，流程更简单——只需要在云平台控制台的安全组里放行 UDP 27888，再在服务器操作系统防火墙里放行同一个端口，公网 IP 直接填即可，不需要额外的端口映射。

### 联机故障排查

朋友连不上你的 Kaillera 服务器？按以下五步定位问题环节，先测最简单的、逐步增加复杂度：

#### 第一步：局域网先测

**目的**：把问题缩小到"外部网络"还是"服务器本身"。

1. 你的电脑启动 `kaillerasrv.exe`
2. 用同 Wi-Fi 下的另一台设备（或手机模拟器）连接你的**内网 IP**（cmd 里 `ipconfig` 看 IPv4，比如 `192.168.1.100`）
3. 看能不能连上：

| 局域网能连上 | 局域网连不上 |
| --- | --- |
| ✅ 服务器本身没问题 | ❌ 服务器或本机防火墙问题 |
| → 问题在端口映射或公网 IP | → 继续查 Windows 防火墙 |

#### 第二步：Windows 防火墙放行

局域网连不上的话，先排查这个：

1. `Win+R` 输入 `wf.msc` 打开高级防火墙
2. 入站规则 → 新建规则 → 程序 → 选择 `kaillerasrv.exe` → 允许连接
3. 出站规则同样建一条
4. 同时确认 `WinKawaks.exe` 也有对应的防火墙规则（联机客户端也用 UDP）

#### 第三步：路由器端口映射

局域网能连上但公网朋友连不上：

1. 打开路由器管理页，检查端口映射规则是否正确
2. 确认外部端口、内部端口都是 27888（或和 server.ini 里改的端口一致）
3. 内网 IP 指向的是当前运行 `kaillerasrv.exe` 的那台电脑
4. 保存后部分路由器需要重启

#### 第四步：服务器软件版本匹配

客户端（WinKawaks）和服务器（kaillerasrv）版本建议用同一套——都从同一个完整版压缩包里取。不同版本的客户端和服务器可能存在协议差异导致连接失败。

#### 第五步：ROM CRC 匹配

能连上服务器但 Join 不上房间？大概率是 ROM 版本不匹配。Join 时如果弹出 "ROM CRC mismatch" 提示，说明双方的 ROM ZIP CRC 值不同。让房主告诉你他用的 ROM 具体版本名（World 版、Asia 版、Hack Plus 版等），下载相同版本的 ROM 即可。

ROM CRC 不匹配的两种表现：
- 加入房间时：Join 被服务器直接拒绝
- 勉强加入后开始对战：双方画面不同步、操作无反应、卡住不动

#### 其他常见联机问题

- **按键延迟过高（>150ms）**：换离你更近的公网服务器；局域网对战应该只有 1~5ms 延迟；国内联机尽量选国内服务器
- **有人掉线整个房间崩了**：Kaillera 没有断线重连机制，某个人网络抖动或断连会导致 Lockstep 不同步。解决办法是找网络稳定的服务器，或者考虑使用 GGPO / Parsec 等新一代联机协议
- **服务器列表是空的**：检查 `kaillerasrv.exe` 是否还在运行，服务器窗口显示的在线数和房间数是否正常
