## ✨ P2PSearcher 是什么

P2PSearcher 是一款面向 P2P 网络的资源搜索工具，覆盖 ED2K（eMule）和 DHT（磁力链接）两大主流协议族。它本身不存储资源，而是通过连接全球的 P2P 节点网络，把网络上正在被分享的文件实时索引出来，让用户可以用关键词快速定位到目标资源。

与传统的电驴客户端不同，P2PSearcher 把重点放在「搜」而不是「下」——搜索结果直接给出磁力链接或 ED2K 链接，用户拿到后可以交给自己习惯的下载器（迅雷、Motrix、eMule 等）处理，灵活性更高。同时它还内置了云播预览功能，搜到资源后不用下载就能先看开头几秒钟到几分钟，快速确认资源对不对。

这款工具在 Windows 和 Android 平台都有发布，PC 版功能更完整，安卓版则主打轻量化和随时随地搜。它适合那些经常需要在 P2P 网络上找资源、又不想装一个体积庞大的电驴客户端的用户。

## 🔧 安装步骤

### 安卓版安装

P2PSearcher 安卓版体积只有 6-7MB，兼容 Android 5.0 及以上系统，安装后占用空间不超过 20MB。对于存储紧张的老手机来说这个体积非常友好。

安装方式分两种：

1. **应用商店安装**：在第三方安卓应用商店里搜索「P2PSearcher」或「种子搜索神器」，找到后点击下载自动安装。商店会处理好来源验证和权限配置，适合不想折腾的用户，但版本审核通常有滞后性。
2. **APK 直装**：从下载页获取 APK 文件，通过微信传输助手、QQ 或 USB 连接传到手机，然后用文件管理器点击安装。

> [!NOTE]
> APK 直装前需要先在手机设置里开启「允许安装未知来源应用」或「安装未知应用」。Android 10 及以上版本会针对每个应用单独询问这个权限，安装完 P2PSearcher 后可以在设置里关闭对应权限开关，保持其他应用的默认安全设置。

首次打开后软件会请求存储权限和网络权限，允许即可。

### Windows 版安装

Windows 版通常提供绿色解压包或安装程序。安装程序双击运行后按向导走完：

1. 选择安装路径（建议不要装到系统盘根目录，避免权限问题）
2. 等待安装完成
3. 首次运行时如果被杀毒软件拦截，选择「允许」或「添加信任」——P2P 类软件经常被误报，属于正常现象

安装完成后建议检查一下版本号，确保是下载页上最新的稳定版本。旧版本可能存在搜索不到结果、云播加载失败等已知问题。

## 📖 使用入门

### 基本搜索流程

打开 P2PSearcher 后，在顶部搜索框输入关键词，回车或点击搜索按钮即可。搜索结果会列出文件名、大小、种子数（或源数）、上传时间等信息。

几个实用的搜索技巧：

- **关键词组合**：用空格分隔多个关键词可以缩小搜索范围，比如「电影名 4K」或「软件名 绿色版」
- **结果排序**：按种子数排序可以优先看到源多、下载快的资源；按上传时间排序可以找到最新分享的版本
- **结果筛选**：部分版本支持按文件类型（视频、音频、压缩包等）过滤，快速排除不相关的结果

### 获取链接和下载

在搜索结果上右键或点击对应按钮，可以：

- **复制磁力链接**：直接粘贴到迅雷、Motrix、IDM 等下载器即可
- **复制 ED2K 链接**：适合用 eMule 客户端下载
- **保存种子文件**：有些结果支持直接下载 .torrent 文件

拿到链接后，P2PSearcher 的任务就完成了。它不参与下载过程，下载交给专业下载器处理会更稳定、速度更快。

### 云播预览

搜到资源后如果想先看看内容对不对，可以用内置的云播功能。点一下云播按钮，P2PSearcher 会把磁力链接转给对接的云播引擎，引擎从 P2P 网络拉取数据转码后提供预览。

云播的预览时长不是 P2PSearcher 定的，是由对接的云播引擎服务商决定的——这是服务商的成本控制策略。典型的时长分布：

| 预览时长 | 适合场景 |
| --- | --- |
| 30 秒 - 1 分钟 | 快速确认文件类型、开头能否正常播放 |
| 2 分钟 | 看开头确认版本和画质 |
| 5 分钟 | 检查片头、剧情、字幕音轨是否完整 |
| 10 分钟以上 | 基本够看一集剧集或电影的主要段落 |

画质方面，云播通道通常提供 360p（流畅）、480p（标清）、720p（高清）、1080p（全高清）几个档位。画质上限取决于资源本身——如果搜索结果里文件名就写着 "480p" 或 "webrip"，云播引擎再强也给不出更高画质，这时候切换通道没用，得换一个更高清的资源重新搜。

> [!TIP]
> 如果默认云播通道加载失败或画质不好，可以切换到其他通道试试。不同通道的引擎服务、时长限制和画质档位都不一样，挨个试总能找到合适的。新版本的 P2PSearcher 通常会接入新引擎、移除失效引擎，遇到通道大面积挂掉时可以考虑升级。

### NAT 和网络穿透

P2PSearcher 作为 P2P 节点，需要能被其他节点主动连接才能搜到更多结果。家用路由器通常做了 NAT（网络地址转换），多台设备共用一个公网 IP，路由器后面的设备只有内网 IP（如 192.168.x.x），外部节点连不进来。

如果 NAT 类型是「对称型」，P2PSearcher 的 DHT 节点连接质量会很差，搜索结果也会变少。解决办法有几个：

1. **开启 UPnP**：在路由器管理后台（浏览器打开 `http://192.168.1.1` 或 `http://192.168.0.1`）找到 UPnP 开关（通常在「高级设置 → 网络 → UPnP」分类下），设为启用。开启后 P2PSearcher 启动时会自动告诉路由器申请端口映射，外部节点就能通过公网 IP + 端口找到它了。不同品牌路由器命名略有差异：TP-Link 叫「UPnP 设置」，小米叫「UPnP 自动端口映射」，华为叫「NAT 穿透」。
2. **启用 NAT 穿透**：如果路由器不支持 UPnP，P2PSearcher 的网络设置里有 UDP hole punching 选项，通过打洞技术尝试建立直连。
3. **穿透模式**：这个主要解决 ED2K 服务器被屏蔽的问题，和 NAT/UPnP 是不同层面的设置。在 NAT 限制严重的环境下，同时开启穿透模式 + UPnP + NAT 穿透三个选项效果最好。

> [!WARNING]
> UPnP 虽然方便，但意味着外部应用可以自动请求开放端口。公共网络（网吧、酒店 WiFi）里不要开 UPnP；用完 P2PSearcher 后可以在路由器里关掉 UPnP，或者只保留 P2PSearcher 用到的端口。

### 云播故障排查

云播失败是最常见的问题之一，但通常不影响搜索和链接导出——真遇到云播完全用不了，直接复制磁力链接交给下载器就行，下载到本地用 VLC、PotPlayer 之类的播放器看效果还更好。

按概率排序，排查方向如下：

1. **云播通道挂了**：默认通道播不了、换一个就能播，说明是通道本身的问题。多个通道都不行 → 先下载到本地看。
2. **资源本身有问题**：文件损坏、只有片段没有完整文件、种子已经断种、加密格式云播引擎解不开。验证方法：换另一个搜索结果里的同类资源试试。
3. **磁力链接无效**：把磁力链接粘贴到迅雷看能不能找到节点，下载器也找不到 → 这个资源已经死了。
4. **网络层问题**：所有资源都云播不出来，大概率是 P2P 节点连接不上或云播服务商 CDN 可达性问题。开启穿透模式试试，或换手机热点测一下。
5. **预览时长用完**：部分通道限时 1-2 分钟，用完自动停止，这是设计不是故障。
