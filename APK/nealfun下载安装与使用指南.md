## ✨ nealfun 是什么：一个装了 40+ 网页小游戏的 APK 合集

nealfun 是一款 Android APK 合集应用，把 Neal Agarwal（neal.fun 创始人）开发的 40 多个独立网页项目打包在一起，让你在手机上一个应用就能玩遍所有 neal.fun 的作品。

打开 nealfun，屏幕上直接就是一排一排的卡片——Infinite Craft、Progress、Universe Forecast、Baby Map、Absurd Trolley、Life Checklist……点哪张卡片就打开哪个项目，内嵌浏览器视图直接加载对应的 neal.fun 网页，不需要再装 40 个独立 App。

neal.fun 系列的核心特点是**轻量、创意、零摩擦**：每个项目都是一个小点子，有的是互动小游戏，有的是数据可视化，有的是心理测试。没有账号、没有登录、没有新手教程，打开就能玩，玩完就关掉。

> [!NOTE]
> nealfun APK 是 neal.fun 源站内容的镜像合集，会持续跟进 neal.fun 上的新项目更新，但存在一定延迟。源站新增的项目不一定第一时间出现在合集中。

## 🔧 安装步骤（Android APK）

nealfun 以 APK 形式分发，不经过 Google Play，安装需要手动操作。

### 安装流程

1. **下载 APK 文件**：从下载页获取最新版本，文件大小通常在 10~20MB 之间（仅内嵌浏览器 + 卡片列表，本身不携带游戏资源，游戏运行时从 neal.fun 服务器加载）。
2. **开启未知来源授权**：Android 默认禁止安装来自应用商店以外的 APK，需要手动授权。不同系统版本路径略有差异：
   - Android 8+：设置 → 安全 → 安装未知应用 → 选择你的文件管理器或浏览器 → 允许
   - Android 7-：设置 → 安全 → 未知来源 → 勾选
3. **点击安装包执行安装**：用文件管理器找到下载的 APK，点击后按提示一路下一步即可。
4. **安装完成后首次打开**：直接进入卡片列表，无需任何额外配置。

> [!WARNING]
> 安装前务必核对 APK 文件的哈希值或文件大小，避免下载到被篡改的二次打包版本。建议仅从官方下载页获取安装包。

### 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 安装时提示「解析包错误」 | APK 下载不完整，删除后重新下载；或系统版本低于 Android 最低要求 |
| 安装被手机管家拦截 | 在手机管家的安全检测中放行该 APK，或将其加入信任列表 |
| 安装完成后点卡片打不开项目 | 检查网络连接（nealfun 依赖网络加载 neal.fun 网页）；或尝试清理应用数据后重开 |

## 📖 使用入门：从 Infinite Craft 到宇宙时间线

### 打开应用的第一步

安装完成后首次打开 nealfun，你会发现它和绝大多数 Android App 都不一样：

1. 没有欢迎向导
2. 没有创建账号或登录页面
3. 没有权限请求弹窗（网络权限由 Android 系统自动授予）
4. 直接就是一张一张的项目卡片列表

这不是省略步骤，是 neal.fun 系列**故意去掉了所有可以去掉的摩擦**。打开就能玩，玩完就关掉。

### Infinite Craft：无限合成游戏

Infinite Craft 是 neal.fun 系列最火的项目之一——给你四个基础元素（火、水、土、风），把两个元素拖到一起合成新元素，新元素再和别的元素合成，最终发现几千种元素。

在 nealfun 合集里点 Infinite Craft 卡片，应用会打开内嵌浏览器加载 neal.fun/infinite-craft。这和你自己用 Chrome 打开那个网址本质上没区别，但体验上有几个明显限制：

| 功能 | nealfun 合集内网页版 | Google Play 官方单游戏版 |
| --- | --- | --- |
| 交互方式 | 触摸拖拽 | 原生点按（两个元素一碰就合） |
| 存档 | 浏览器 localStorage（清缓存就丢） | 独立存档文件 |
| 画布 | 有限侧边栏 | 无限画布（可缩放平移） |
| 分类搜索 | 基础 | 完整分类、排序、隐藏 |
| 导入导出 | 无 | 支持 |
| 离线 | 不行 | 部分功能可用 |

如果你觉得合集里的 Infinite Craft 体验不够好，Google Play 上的 Infinite Craft by Neal 是 Neal 专门为移动端做的优化版本——原生触摸交互、无限画布、独立存档、导入导出全都有。但那个版本只有 Infinite Craft 一个项目，想要同时玩 neal.fun 其他 40 多个项目，还是得靠 nealfun 合集。

> [!TIP]
> 想在电脑上玩 Infinite Craft？直接用浏览器打开 neal.fun/infinite-craft，鼠标拖拽比手指精准得多，大屏幕也不会挤。但网页版存档同样存在浏览器 localStorage 里，清缓存就没了，注意手动备份。

### Progress 和 Universe Forecast：一切都是进度条

Progress 是 neal.fun 里最"安静"的项目之一——没有音效、没有动画、没有游戏元素，就是一排一排不断变化的进度条，每一条代表某件事的"完成度"：

- **2026 年过去了多少**：大横条，左边绿色，右边空白，每秒推进一点
- **Voyager 1 飞了多远**：旅行者 1 号 1977 年发射，目前是距离地球最远的人造物体，已飞出太阳风层顶约 160 天文单位
- **下次日全食还有多久**：倒计时
- **你的寿命进度条**：输入出生年月，算出预期寿命过了多少（这一条对一些人来说有点扎心）
- **全球当前人口**：实时跳动的数字

每条进度条都可以点开，查看更详细的信息。这种"用最朴素的交互传达最微妙情绪"的手法，是 Neal 作品里反复出现的风格——你会忍不住一直刷新，想看看 Voyager 又飞了多少，会好奇"今年到底过了多少了"。

Universe Forecast 是 Progress 的"宇宙级版本"：

- **近地小行星下次近距离掠过**：日期、距离
- **太阳熄灭还剩多少年**：约 50 亿年（变成红巨星、吞噬地球）
- **仙女座星系和银河系碰撞**：约 40 亿年后
- **宇宙热寂**：约 10¹⁰⁰ 年（理论上的时间，宇宙所有能量平均分布、再也没有任何事件发生）

两者的区别是单位——Progress 的单位是"天"或"年"，Universe Forecast 的单位是"亿年"甚至"10¹⁰⁰ 年"。

### Baby Map 和 Where Does the Day Go：数据可视化两则

这也是两个把抽象数据变得有体感的小项目：

| 项目 | 内容 |
| --- | --- |
| Baby Map | 世界地图上实时标记每个国家的出生率，动态跳动的小点表示"刚刚又有一个婴儿出生" |
| Where Does the Day Go | 把 24 小时摊开成一个饼图，直观看到"一天的时间都去哪了"——睡觉、工作、吃饭、通勤各占多少 |

和 Progress / Universe Forecast 一样，都是用视觉化的方式让数字变得有情绪。

### 为什么没有账号

从 neal.fun 源站到 nealfun APK 合集，一贯的产品理念是：**打开就能玩，玩完就关掉**。账号系统在这里完全不需要：

- 没有需要同步的数据（合集里不存任何游戏进度）
- 没有需要个性化的内容（卡片列表对所有人一样）
- 没有社交功能（不分享、不评论、不关注）
- 没有云存档

社区数据（比如 Absurd Trolley 的全球投票结果、Who Was Alive 的全球平均完成度）采用**匿名聚合**——点击投票后直接发到后端，不带任何身份信息。后端只知道"有一个匿名用户投了这个选项"，不知道是谁投的。

从隐私角度看这是最干净的设计之一：不收集个人身份信息、不收集设备信息、不做行为追踪、不推送个性化广告。Google Play 上 Infinite Craft by Neal 的数据安全页面也明确标注：不与第三方共享用户数据，不收集用户数据。
