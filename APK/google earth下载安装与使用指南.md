## ✨ Google Earth 是什么

Google Earth 是 Google 推出的一款虚拟地球软件，通过整合全球卫星影像、航拍照片、街景实拍和 3D 地形数据，把整个地球搬到你的屏幕上。从 2005 年发布至今，它已经从一个新奇的地图玩具发展成了地理爱好者、教育工作者、户外探险者和专业 GIS 从业者都离不开的工具。

你可以用它做很多事：飞到地球任何一个角落看最新的卫星照片、切换到街景 360° 沉浸式云游、拖动时间轴看同一地点几十年间的变化、在地球仪上标注地标和路径、导入 KML 数据做地理信息可视化、甚至开飞机模拟器从大气层俯瞰地表。三个版本覆盖不同场景——Pro 桌面版功能最全、移动端 App 随身便携、网页版零安装跨平台。

适合的人群很广：学生用它上地理课比教科书直观、摄影师出门前用街景踩点找机位、徒步爱好者提前规划路线标记补给点、城市研究者对比不同年代的城市扩张。只要你对"我们住的这颗星球"感兴趣，它都能给你新鲜感。

## 🔧 安装步骤

桌面版 Google Earth Pro 支持 Windows 和 macOS 两个平台，安装过程不复杂但有几个注意点。移动端 App 在应用商店点一下就装好了，网页版更省事，打开浏览器就行。

**Windows 桌面版：**

1. 从下载页拿到安装包（约 80MB），双击运行
2. 安装路径默认 `C:\Program Files\Google\Google Earth Pro\`，建议保持默认避免后续修复工具找不到位置
3. 安装过程中如果 Windows Defender 弹窗，允许 googleearth.exe 通过——它需要联网拉取卫星影像
4. 装完后桌面会有快捷方式，启动即可

> [!WARNING]
> 某些企业/学校的安全策略会拦截 Google 相关域名，如果 Pro 启动后影像一直加载不出来，先换手机热点测试能不能正常联网，再考虑联系网管开放端口 80 和 443。

**macOS 桌面版：**

1. 下载 `.dmg` 文件，双击挂载
2. 把 Google Earth Pro 图标拖进 Applications 文件夹
3. 首次打开如果系统提示安全警告，进「系统设置 → 隐私与安全性」点"仍要打开"

**移动端 App：**

- 安装包大小约 100MB+，首次打开会额外加载约 30MB 的基础卫星影像缓存
- iOS 和 Android 版都免费，功能集基本一致

**装完核对：**

启动 Pro 后几秒内应该能看到蓝色的卫星底图。如果卡在加载画面或黑屏，别着急卸载——下面的使用入门里有完整的启动问题排查步骤。

## 📖 使用入门

### 基础操作：在地球上飞来飞去

桌面版的操控围绕鼠标和键盘展开：左键拖动旋转地球、滚轮缩放、右键拖动倾斜视角看 3D 地形。想要快速飞到某个城市，直接在左上角搜索框输入地名——Pro 会自动把地球转过去并聚焦。

移动端靠手势完成所有操作：单指拖动旋转、双指捏合缩放、双指上下拖动倾斜到 3D 视角、双指旋转调整方向、快速双击快速飞到放大区域。iPad 和 Android 平板屏幕更大，手势操作的体验最接近桌面版。

> [!TIP]
> 想沉浸式逛景点？找到街景小人图标拖到地球上任意一条蓝线上就能进入街景模式，Pro 桌面版用方向键走动，移动端配合手机陀螺仪可以转头看四周——足不出户逛遍全世界的名山大川。

### 版本差异：Pro、移动、网页三版对比

三个版本功能互补，按你的使用场景选：

| 功能 | Pro 桌面版 | 移动端 App | 网页版 |
| --- | --- | --- | --- |
| 卫星影像 + 3D 地形 | ✅ | ✅ | ✅ |
| 街景 360° | ✅ | ✅（陀螺仪转头） | ✅ |
| 历史影像时间轴 | ✅ | ✅ | ✅ |
| KML/KMZ 导入 | ✅（含 Shapefile） | ✅（仅 KML/KMZ） | ✅ |
| 地标/路径/多边形标注 | ✅ | ✅（触屏画） | ✅ |
| Flight Simulator | ✅ | ❌ | ❌ |
| Earth Studio 动画 | ✅ | ❌ | ❌ |
| 飞行 Tour 录制 | ✅ | ❌ | ❌ |
| 高级测量工具 | ✅（含面积/周长） | ⚠️（仅基础距离面积） | ⚠️ |

登录 Google 账号后，移动端做的标注会自动同步到云端，在 Pro 和网页版的 Projects 里都能看到。但桌面版用 Shapefile 导入的图层在移动端看不到——那是 Pro 独有的高级格式。

### 常见问题排查：启动卡住和黑屏

Pro 启动时卡在加载画面、中间地球区域黑屏、或者直接闪退，这些问题大多能按顺序逐步排查解决：

**第一步：彻底关闭重开。** 有时上一次运行的进程没完全退出，第二次打开就卡住了。Windows 用 Ctrl+Shift+Esc 打开任务管理器，在详细信息里找到所有 `googleearth.exe` 进程结束掉；Mac 用 Cmd+Option+Esc 强制退出。

**第二步：切换渲染引擎。** 如果有界面框架但地球全黑，大概率是显卡驱动和渲染引擎不兼容。打开 Pro 安装目录的 `client\repair_tool.exe`，找到「切换渲染引擎」选项，从 OpenGL 切到 DirectX（或反过来），应用后重启。

**第三步：repair_tool.exe 一键修复。** 这个内置工具可以清空缓存、修复 myplaces.kml 地标文件、重建偏好设置、切换渲染引擎。建议按工具里的推荐顺序依次尝试，每做一步重启 Pro 验证。

**第四步：检查 myplaces.kml 是否损坏。** 如果总是卡死在加载位置面板的阶段，可能是某个地标的 KML 格式有问题。找到 myplaces.kml 文件（位置在用户数据目录），重命名为 myplaces_backup.kml 先备份，然后重新打开 Pro——它会用空白文件启动。如果能打开，说明确实是旧文件损坏，可以手动从备份里提取还需要的地标，或者从之前导出的 KMZ 恢复。

**第五步：更新显卡驱动。** 过时的驱动是黑屏和渲染异常的高发原因。NVIDIA 去 GeForce 官网、AMD 去 Radeon 官网、Intel 去核显驱动页面下载最新版，更新后重启电脑再试。

前面都不行才走最后一步——彻底卸载重装。控制面板里卸载 Pro，手动删除 `%APPDATA%\Google\GoogleEarth` 和安装目录残留，重启后从官方下最新版装回去。**重装前务必备份 myplaces.kml！**

### 性能优化：加载慢、卡顿、影像不显示

卫星影像加载很久不出来、拖动地球卡帧、3D 地形渲染慢，这些问题从网络和本地两个方向优化：

**网络方面：**

- 确保能正常上网（浏览器访问 earth.google.com 测试），有线比 WiFi 稳定
- 公司/学校网络可能限制了 Google CDN 端口，换手机热点验证
- 防火墙或杀毒软件可能拦截 googleearth.exe，检查个人防火墙的阻止列表，确认端口 80 和 443 对 Pro 开放
- 缓存损坏也会导致加载失败：工具 → 选项 → 缓存 → 清空缓存 → 重启

**图形和内存方面：**

- 3D 建筑、地形、云层三个图层最耗资源，卡顿先关这三个试试
- 工具 → 选项 → 图形标签页：纹理质量从高降到中、地形质量从高降到中或低、动画质量调低
- 物理内存 4GB 以上的话，把 Pro 的内存缓存设到 512MB–1GB，让它多把看过的图片缓存在内存里
- 关闭同时运行的浏览器、视频播放器等程序，给 Pro 留足 CPU 和内存

**离线缓存技巧：**

长期网络不稳定的话，可以提前缓存常用区域。打开 Pro 慢慢浏览目标区域——它会自动把看过的影像存到磁盘缓存。把磁盘缓存设到最大 2000MB，缓存满了之后该区域内的卫星影像、地形、3D 建筑都能离线浏览。断网测试一下，能正常显示就说明缓存到位了。

> [!NOTE]
> 系统资源监控：任务管理器里看 Pro 的 CPU 占用，正常浏览应该在 10–30%，播放 Tour 或开飞机模拟器时可能到 80%+；内存正常在 500MB–2GB，超过 2GB 建议清理缓存。

### 地理数据导入：KML 和 KMZ

KML 是 Google 为地球地理数据定义的 XML 格式，用来描述地球上的点、线、面、地标、图片叠加和相机视角——Google Earth 默认的地理数据交换格式就是它。KMZ 是 KML 的压缩包形式，本质是 zip 文件，里面包含 KML 本体加上它引用的图片、图标等资源。分享数据时优先用 KMZ，不会出现"导入后图片丢失"的问题。

**导入方法：**

- Pro 桌面版：文件 → 打开 → 选择 `.kml` 或 `.kmz`，或者直接把文件拖进 Pro 窗口
- 网页版：左侧面板 → Projects → 导入 → 选文件
- 导入后地标和路径直接叠加在地球仪上，Pro 还会把数据放进「临时位置」文件夹，可以手动拖动整理

**导入后继续编辑：**

KML 数据不是死板的——地标可以移动位置、改图标、加说明文字和图片；路径可以增删节点、改颜色和粗细；多边形可以调边界点、设填充透明度。Pro 版还能给整个文件夹应用自定义样式模板，统一所有条目的外观。

**导出分享：**

自己创建的地标、路径、测量结果都能导出成 KML/KMZ 发给别人——对方双击就在自己的 Pro 里打开。规则很简单：包含本地图片或自定义图标的用 KMZ，纯文字坐标的简单地标用 KML。

**KML 能描述的远不止地标：** 图片叠加（把老地图贴到现代卫星影像上对比）、相机视角（指定某点怎么看）、Tour（飞行演示轨迹）、时间跨度（临时活动场地只在特定时段显示）、NetworkLink（从远程动态加载数据）。

> [!TIP]
> 常见导入问题速查：文件打不开先确认扩展名真的是 `.kml` 而不是改后缀的 `.xml`；中文乱码是编码不对，用记事本另存为 UTF-8 再导入；导入了但地球上没显示——看左侧面板里的条目有没有勾选，双击那个条目地球会自动飞过去。
