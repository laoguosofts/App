## ✨ Nomad 是什么：一款为平板而生的 3D 雕刻工具

Nomad 是一款主打平板端的 3D 雕刻应用，主打「拿起手写笔就能雕」的轻量化体验——不需要工作站级硬件，也不需要复杂的拓扑前置流程，从一颗球体推到大形、刻出细节、顶点绘画上材质、导出 STL 送 3D 打印，全流程在同一套界面里完成。

它的核心设计思路是把传统 PC 雕刻软件里的高频操作重新适配到触屏手势上：双指缩放、三指旋转、单手就能调笔刷半径，配合压力感应手写笔，手感接近在纸上画素描而不是在电脑上点菜单。从官方入门示例来看，一个卡通人头从起步到加表情细节，只用粘土笔刷、平滑、上色三个基础工具就能跑通，上手门槛比 Blender / ZBrush 这类专业桌面软件低得多。

**四类典型用户**构成了它的主流使用场景：角色与概念艺术家用来在移动途中快速起草稿和雕表情小稿；3D 打印爱好者雕完直接导出 STL，用减面工具控一下体积就能送打印；从 2D 插画转过来的画手不需要展 UV，顶点绘画模式下拉一下颜色和粗糙度滑块就有材质感；学生和教学场景则看重它一次性买断、无订阅的授权模式——桌面版还提供教室批量授权，一把钥匙多个激活名额。

开始前需要知道几个能力边界：目前没有时间轴动画，骨骼绑定还在规划中，想摆姿势只能靠父子级与枢轴点；软件定位是雕刻，做严格的 low-poly 建模并不顺手；实时渲染引擎最多四盏灯，需要模拟更多光源时要靠自发光材质加全局光照「伪造」；安卓机型性能差异大，官方开发者原话是三星 Galaxy Tab S9 会比 iPad Air 慢一个数量级，安卓用户建议先装免费试用版测一测再决定。

## 🔧 安装步骤

### iOS / iPadOS

1. 打开 **App Store**，搜索 Nomad，认准开发者名称后点击获取。
2. 首次启动会请求文件存储权限——建议全部允许，否则项目文件无法正常保存。
3. 如果购买过 Pro 版，在应用内「设置 → 授权」用购买账号登录即可解锁全部功能。

> [!TIP]
> iOS 用户不用处理未知来源授权，也不用担心杀毒误报——App Store 分发的应用直接装。但要注意：**不要用第三方助手同步安装**，可能导致授权验证丢失。

### Android

1. 从官方渠道下载 APK 安装包到设备或电脑。
2. 如果是电脑传到手机，先用文件管理器定位到 APK 文件，点击安装。
3. 系统可能弹出「未知来源」警告——前往 **设置 → 安全 → 安装未知应用**，给当前文件管理器开权限后重试。

> [!WARNING]
> 安卓生态机型繁杂，不同品牌的安全策略不同。三星 / 小米 / 华为的安全中心可能会把 APK 安装当作风险行为拦截，按提示手动放行即可，属于正常现象，不是安装包有问题。

### 桌面版（Windows / macOS）

桌面版通过官网安装包分发：下载 `.exe` 或 `.dmg` 后双击运行，按向导选路径安装。安装路径建议放在非系统盘（例如 `D:\Nomad\`），避免 C 盘空间紧张影响项目文件存储。首次启动同样需要登录购买账号解锁 Pro 功能。

安装完成后建议立刻打开一个新工程，随便雕几笔测试笔刷压力感应是否正常——这是发现设备兼容性问题最快的方式。

## 📖 使用入门：从一颗球到完整作品

### 第一步：先把基础手感跑通

第一次打开应用，从场景菜单里拖一颗球体进视窗——这是官方入门教程的标准起步，也最能快速体会 Nomad 的核心交互。拿起手写笔，先用默认的 **粘土（Clay）笔刷**推一下球体会有什么感觉，再切换到 **平滑（Smooth）笔刷**把坑填平，最后选个颜色用 **顶点绘画**直接在球面上画一道。十分钟内把「推、平、画」三件事走一遍，基本就能判断这款软件的手感对不对你的胃口。

如果觉得顺手，下一步建议立刻跑一次 **体素重拓扑（Voxel Remesh）**——雕着雕着面会被拉长变形，这是所有雕刻软件都会遇到的问题，体素重拓扑用体素计算把网格重新布点，什么破几何都能吃，专治拉伸面。它的底层原理和 ZBrush 的 Dynamesh 类似，但操作只在一个滑块：调分辨率，勾不勾「构建多重分辨率」顺便生成低层控制网。

### 布尔运算：两种合体方式的取舍

场景菜单的布尔面板提供两条路，选哪种取决于你对精度和分辨率的需求：

- **体素合并（Voxel merge）**：保留体积，把物体融合后按统一密度重新布线。它经过体素计算，什么破几何都能吃，但分辨率不够时会丢细节。
- **布尔（Boolean）**：尽量保留原有多边形，只在相交处缝合。结果更干净锐利，但要求网格封闭（watertight）。底层用的是 Emmett Lalish 的 Manifold 库。

一个容易踩坑的点：布尔面板**不看按钮选项，看是谁被隐藏**。

| 状态 | 运算 |
|---|---|
| 两物体都可见 | 并集（Union） |
| 一方隐藏 | 差集（隐藏者被减去） |
| 两方都隐藏 | 交集（只留重叠部分） |

所以跑布尔前先把该隐藏的物体先隐藏好，跑完记得把需要的物体重新点亮。实战里打孔、镶嵌、拼接盔甲件，精确布尔是首选；如果失败提示「网格不封闭」，切体素合并几乎总能出结果。还有个冷门用法：单个物体也能用体素合并按钮——等效一次均匀重拓扑，专治拉伸面。布尔前给目标区域套遮罩并勾选保护，运算后细节不受伤。

### 折痕与收缩：把锐利细节做出来

折痕（Crease）和收缩（Pinch）是两支配合使用的挤压类笔刷，负责布料折痕、肌肉分界、疤痕、铠甲缝隙这类锐利结构。

**折痕笔刷**沿笔划压出 V 形凹槽，默认是下凹；切换到 Sub 模式则反转行为——不再下凹而是凸起一条脊，做皱纹、唇线、浮雕棱线时不用换工具，直接按一下开关就行。

**收缩笔刷**本身不产生深度，它把笔划路径两侧的顶点向中线聚拢，让边缘变「紧」、变锐。它的价值在于和折痕成对出现：先用折痕压出缝，再用收缩把缝的两壁夹锐，得到的折线远比单用一支笔干净。

> [!NOTE]
> 挤压类工具对多边形密度极其敏感——面数不够时，折痕只会把大块面拉出难看的斜坡。开工前先切到底部工具栏的 Wire 模式看一眼线框，密度不够就跑一次体素重拓扑，或在细节区局部启用动态拓扑。

顺手的小技巧：两支笔刷都受衰减曲线影响，平顶衰减的折痕更均匀，尖峰衰减的收缩更集中；做对称细节时左右一致是默认行为，不用额外操心；如果突然发现「笔刷失灵」，先想想是不是加了遮罩——被遮罩区域不会被任何笔刷影响，这是最常见的「失灵」原因。

### 启动崩溃的自救办法

启动即崩，通常是应用在加载自己文件夹里的某个文件时出问题——多数情况是项目过大撑爆内存。好消息是应用自带一道保险：加载文件前会先把文件挪进 `can_be_deleted/` 文件夹，成功加载后再移回去；**加载中途崩溃，下次启动会自动跳过这个文件夹**，所以启动崩溃通常不会滚雪球。

自救顺序按这个来：

1. 找到应用主文件夹。
2. **先重命名 `settings.json`**——这一步能阻止它自动加载上次未关闭的项目，多数启动崩溃到这步就解决了。
3. 仍不行，把最近的文件从各资源文件夹（`projects`、`matcaps`、`environments` 等）往外移。
4. 再不行，直接重命名这些资源文件夹，应用会当作不存在——效果等同一次干净安装。
5. 怀疑某个文件其实没问题？可以再尝试加载一次；`can_be_deleted` 里的文件有机会被重新收编。

如果是**加载项目时崩**（非启动时），小文件可以发给开发者排查；大文件按内存不足处理——关后台、新建项目再打开、合并图层减负，最终解法还是换大内存设备或用桌面版兜底。平时预防：大工程节点性另存副本，坏一个还有上一个；装完重要更新后先开小项目确认正常，再碰大工程。

### 顶点绘画：不上 UV 也能上材质

传统 3D 工作流里，画贴图前必须先展 UV——这是劝退 2D 插画师的一道门槛。Nomad 的顶点绘画绕过了这个环节：直接在模型表面选颜色、拉粗糙度和金属度滑块，即时就有材质感。上手曲线比传统贴图工作流平缓得多，适合那些「我想快速让它看起来像样」的需求。

### 建议的第一条体验路径

第一次接触的用户，建议按「球体起步 → 体素重拓扑 → 布尔运算 → 折痕收缩 → 顶点绘画」这条链走，每一步都用自己的作品实践而不是光看教程。这条链走完基本就算入门了——后续要补的是具体功能的深挖，而不是重新搭工作流。
