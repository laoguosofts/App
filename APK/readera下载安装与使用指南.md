## ✨ ReadEra 是什么

ReadEra 是一款专注 Android 平台的免费电子书阅读器，起源于俄语开发者社区，目前支持 EPUB、PDF、MOBI、FB2、DOC/DOCX、RTF、TXT、CHM、Djvu、CBR/CBZ 等十几种主流电子书和文档格式。它不内置任何广告，也不强制注册账号，安装后打开就能直接扫描本地文件开始阅读——这一点在同类产品里算是比较干净的。

ReadEra 的核心定位很明确：**本地文件优先的全能阅读器**。它既不做在线书店，也不推云端书库，所有书籍都来自你自己设备上的文件——无论是内部存储还是 SD 卡。应用的主要价值体现在三个层面：一是多格式兼容（尤其是对 FB2、Djvu、CBR/CBZ 这类相对小众的格式支持比较到位），二是阅读体验定制（字体、行距、字号、对齐方式都可以精细调节），三是 Premium 付费版提供的 Google Drive 云同步和一些进阶导航功能。

适合谁用？如果你手机里存了不少电子书文件，或者经常需要阅读 PDF 论文、漫画压缩包（CBR/CBZ），ReadEra 值得一试。如果你只在应用商店里买书然后在对应的阅读器里读，那可能不需要它。

## 🔧 安装步骤

ReadEra 是 Android 独占的应用，没有 iOS 或桌面版本。安装过程本身不复杂，但有几个 Android 版本相关的细节值得注意。

### 安装前置条件

- **系统要求**：Android 5.0（Lollipop）及以上版本。目前绝大多数在售的 Android 手机都能满足
- **存储空间**：应用本体占用不大，通常 50MB 以内。但书籍文件会额外占用存储——如果你的书比较多，建议预留几 GB 空间
- **SD 卡**（可选）：如果打算把书籍放在 SD 卡上，需要 Android 11+ 的分区存储权限

### 安装流程

1. **获取 APK**：从上面的下载页下载安装包，或者直接在 Google Play 搜索安装
2. **允许未知来源**（如果是侧载 APK）：系统设置 → 安全 → 打开"允许安装未知来源应用"（部分品牌叫"安装未知应用"或"允许此来源安装"）
3. **安装**：点击 APK 文件按提示完成安装。Google Play 安装不需要这步，一键搞定
4. **首次启动**：打开 ReadEra，应用会弹出权限请求——建议全部允许（存储权限是必需的，否则看不到任何书籍）

> [!TIP]
> 安装后先核对一下版本号。进入 ReadEra → 设置 → 关于应用，可以看到当前版本。如果和下载页标注的不一致，建议卸载重装。

### SD 卡权限补充（Android 11+）

从 Android 11 开始，系统对 SD 卡的读写做了分区存储限制。ReadEra 虽然能扫描到 SD 卡上的文件，但如果没有"所有文件访问"权限，就只能读不能写——复制、移动、删除文件这些操作会静默失败。

补权路径因品牌而异，但通用步骤是：**设置 → 应用管理 → ReadEra → 权限 → 打开"所有文件访问"或"允许读取所有文件"**。小米、华为、OPPO 的权限入口名字略有不同，但逻辑一致。

> [!WARNING]
> 即使给了"所有文件访问"权限，SD 卡的**写入权限**仍然需要单独授权。ReadEra 第一次尝试在 SD 卡上移动文件时，系统会弹出"选择 SD 卡根目录"的弹窗——务必选对根目录，不要选某个子目录，否则后续写操作仍然不能用。

## 📖 使用入门

### 文件管理：书架、文件夹和分组

ReadEra 的书架界面默认按"书籍和文档"分组显示所有可识别的文件。但它的侧边栏里藏着几个很实用的分组入口：

- **文件夹**：这是 ReadEra 内置的简化文件管理器。和系统文件管理器相比，它只显示 ReadEra 有权限访问的目录，并在每个文件夹后面标注支持格式的文件数量（比如 `Books/科幻 (12)`）。你可以在这里直接新建文件夹、复制、移动、重命名或删除文件——全部在应用内完成，不需要跳去系统文件管理器。
- **下载**：按最后修改时间排序，方便快速找到刚下载的新文件。
- **合集**：手动创建的分类组，比如"待读清单""经典名著""技术文档"。一本书可以同时属于多个合集。

**快速定位文件的建议**：知道文件在哪个目录下 → 用"文件夹"分组直接跳；知道文件名或作者 → 用"书籍和文档"分组顶部的搜索框；想做批量操作 → 长按任意书进入多选模式，然后移动或删除。

### 阅读设置：把排版调到顺眼为止

ReadEra 的阅读设置面板提供了丰富的可调项，每一项都直接影响阅读舒适度。打开任意一本书 → 点击页面中央 → 底部弹出设置面板，里面的可调项主要有：

| 设置项 | 默认值 | 调节范围 | 说明 |
|---|---|---|---|
| 字体 | 系统默认 | 下拉选择 | ReadEra 不内置字体，调用设备已安装的系统字体 |
| 字号 | 随设备 | 0-100（步进 5） | 不是越大约好，要和行距、页边距联动 |
| 字体粗细 | 中 | 滑块 0-100 | 效果取决于字体内置了多少字重档 |
| 行距 | 100% | 滑块 50%-200% | 相对于字号的倍数，120-130% 是比较舒适的起点 |
| 文本对齐 | 两端对齐 | 两端对齐 / 左对齐 + 连字符开关 | 中文推荐左对齐，英文推荐两端对齐 + 连字符开启 |
| 页边距 | 默认 | 开关 | 手机上建议开启，防止手指蹭到边缘文字 |

> [!NOTE]
> PDF 和 Djvu 是固定版式格式，以上这些重排设置对它们不生效。PDF 的缩放、边距裁剪有独立的设置入口。

**中文排版的几个实用建议**：中文不存在连字符概念，所以连字符开关关掉；对齐方式用左对齐，两端对齐会在字间插入不必要的空格；字号 35-45、行距 120-130% 是手机上比较舒服的组合。

Premium 版用户还可以上传自己的 TTF/OTF 字体——比如专门为电子书设计的衬线字体，或者喜欢复古风格换一个手写字体。上传的字体只在 ReadEra 内生效，不会替换系统字体。

### Premium 云同步：Google Drive 作为中介

Premium 版最大的卖点之一是基于 Google Drive 的自动云同步。它的同步范围比一般阅读器的"同步阅读进度"要广得多：

| 同步内容 | 说明 |
|---|---|
| 书籍文件 | 上传副本到 Drive，原文件仍在本地 |
| 阅读进度 | 精确到页面位置 |
| 书签、引文高亮、注释 | 每本书的全部标记 |
| 阅读设置 | 每本书独立的配色、字号、行距等 |
| 合集分组 | 手动创建的合集 + 里面的书 |

> [!TIP]
> 有个容易误解的点：Premium 的"同步书籍"不是把你手机里的原文件移到 Drive，而是上传**副本**。原文件始终留在本地，Google Drive 是备份源 + 多设备分发源，不是主存储。这意味着即使没有网络，ReadEra 依然能读取本地文件正常阅读。

开启同步的步骤很简单：先购买 Premium → 侧边栏找到同步入口 → 登录 Google 账号并授权 → 等待首次全量上传。后续同步不是实时的，通常在应用启动时、书架界面停留几秒后、网络恢复时触发，有几秒到几十秒的延迟是正常的。

### 页面缩略图：Premium 专属的快速导航

Premium 版在目录/书签面板里多了一个"页面缩略图"标签页。打开后，ReadEra 扫描整本书，为每一页生成缩略图并排网格显示——相当于把整本书的每一页都拍成了缩小版。

这个功能在以下场景特别好用：

- **PDF 论文精读**：目录可能只标了"图 3 在第 12 页"，但图实际在第 17 页。缩略图让你一眼看到每一页的内容，快速定位
- **漫画跳页**：CBR/CBZ 是纯图片流，想跳到某一卷结尾，缩略图比按页号跳直观得多
- **快速浏览整本书结构**：缩略图网格比目录更直观，一眼就能看出哪部分是核心内容

缩略图是按需生成的——第一次用时才生成，之后缓存起来。清理 ReadEra 缓存会删掉缩略图，下次再用时需要重新生成。
