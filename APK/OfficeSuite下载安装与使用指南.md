## ✨ OfficeSuite 是什么

OfficeSuite 是一款跨平台的五合一办公套件，把文档编辑、电子表格、演示文稿、PDF 处理和电子邮件整合在同一个应用里。它的核心定位是"移动端也能用的全能办公工具"——无论是手机上临时改一份 Word，还是平板上做一个简单的 Excel 表格，抑或是在旅途中签个 PDF 文件，都能在这一个 App 里完成，不用在五六个独立应用之间来回切换。

套件支持主流的 Office 文件格式（.docx、.xlsx、.pptx、.pdf），也支持老版本的 .doc、.xls、.ppt 格式。对于经常在手机或平板上处理办公事务的人来说，它最大的便利就是"打开就能用"——不需要额外下载转换工具，也不依赖特定的云存储服务。

> [!NOTE]
> 免费版和付费版的差异主要在高级功能上：条件格式、相机扫描转 PDF、多设备同步这些需要 Premium 订阅。基础的文档读写和简单编辑，免费版已经够用。

## 🔧 安装步骤

### Android 安装

1. 从上面的下载链接获取 APK 安装包，或者直接从 Google Play 安装
2. 如果是从非 Play 商店渠道下载的 APK，首次安装时系统会提示"未知来源"——进入设置，找到"安全"或"应用安装"选项，允许安装未知来源应用
3. 点击 APK 文件确认安装，等待进度条走完即可
4. 安装完成后首次打开，建议用邮箱注册一个 MobiDrive 账号——套件自带 5GB 云存储，注册后可以跨设备同步

> [!WARNING]
> 如果手机里已经装过旧版本的 OfficeSuite，直接覆盖安装就行，已有文件不会丢失。但如果是从其他渠道（比如第三方应用市场）下载的版本，安装后可能无法正常登录，建议卸载后从官网渠道重新安装。

### Windows 安装

1. 从下载页获取 Windows 安装程序（通常是 .exe 或 .msi 文件）
2. 双击运行安装程序，默认安装路径在 C 盘 Program Files 下
3. 安装过程中如果被 Windows Defender 或其他杀毒软件误报为可疑程序，这是常见现象——套件体积较大、签名验证偶有延迟，可以选择"允许本次运行"继续安装
4. 安装完成后桌面上会生成快捷方式，同时开始菜单里也能找到

### 安装后的核对

安装完成后，打开应用检查几个点：

- 文档编辑器能正常打开一个 .docx 文件
- 表格编辑器能正常打开一个 .xlsx 文件
- 设置页面里的版本号与下载页标注的版本一致

如果某一个模块打开闪退，大概率是安装包下载不完整——删除后重新下载安装即可。

## 📖 OfficeSuite 怎么用

### 主界面快速熟悉

打开 OfficeSuite 后，主页顶部是五个核心模块的入口图标：蓝色的文档、绿色的电子表格、橙色的演示文稿、红色的 PDF、绿色信封的电子邮件。图标下方有几份预置的示例文件，可以点开快速体验各模块的基础操作。

左上角的汉堡菜单可以拉出抽屉，里面有一些实用功能："新建"快速创建空白文件、"打开"浏览本地和云端文件、"扫描"用相机把纸质文件转成 PDF。底部导航栏有三个按钮——左侧进入 MobiDrive 云盘，中间是当前主页，右侧是内置的协作聊天功能。

进入任意模块的编辑器后，顶部菜单栏会变成该模块的专属颜色。比如文档编辑器是蓝色菜单栏，表格编辑器是绿色。每个编辑器都有独立的菜单项，比如文档编辑器有"审阅"选项，表格编辑器有"公式"选项，这和桌面版 Office 的布局逻辑是一致的。

### 电子表格：单元格格式与合并

在表格编辑器里，选中一个或多个单元格后，顶部菜单栏的"页面布局"选项卡可以设置各种格式。

**数字格式**是最常用的操作之一。默认情况下数字直接显示，但通过下拉菜单可以切换成货币、百分比、日期、分数等不同格式。比如原始值是 0.85，设置成百分比后就显示 85%；设置成货币后会带上 ¥ 或 $ 符号。需要注意的是，**文本格式有特殊用途**——如果要输入身份证号、手机号、以 0 开头的产品编码，务必先把单元格格式设为文本，否则前导 0 会被去掉，或者长数字会被自动转成科学记数法。

**合并单元格**的操作是选中多个相邻单元格（横向或纵向都行），然后点"页面布局 → 合并单元格"。有三种合并方式：合并后居中适合做表头、合并单元格保留左上角内容清空其余、跨选区合并按行横向合并。拆分的操作更简单——选中已合并的单元格，点"取消合并"就行。

**条件格式**是 Premium 版的实用功能。比如一张考试成绩表，想让低于 60 分的单元格自动标红、60 到 80 分的标黄、80 以上的标绿，用条件格式一次设置好之后，后续填入的分数会自动套用对应颜色。数据条、色阶、图标集这些可视化选项也都是同样的用法——选中数据范围，选规则类型，设条件和样式，确认完成。

### 文档编辑器：插入表格与格式

在文档里插入表格，点击"插入 → 表格"，会出现一个小网格。手指在网格上滑动选择行列数（最多 10×10），松手后表格自动插入到光标位置。表格宽度默认铺满文档两侧边距。

表格插入后被选中时，顶部菜单栏会多出一个专门的"表格"下拉菜单。这里能做的操作包括：在当前行上方或下方插入新行、在当前列左右插入新列、删除行列、合并或拆分单元格。调整大小更直观——直接用手指拖动单元格的边框线就能改变行高或列宽，也可以用"自动调整"让表格根据内容或窗口自动适配。

**将文本转换为表格**是一个挺省时间的功能。如果你手头有一段用制表符或逗号分隔的纯文本，选中后点"插入 → 表格 → 将文本转换为表格"，选择对应的分隔符类型，OfficeSuite 会自动拆分并创建好行列结构。反向操作也有——"表格 → 转换 → 将表格转换为文本"，适合把表格数据导出成纯文本格式。

表格里的文字格式和普通段落一样，可以设置字体、对齐、列表。还有一个容易忽略的细节——表格单元格内的文字可以设置**垂直对齐**（顶部、居中、底部），在"表格属性"里调整，做简历或报价单的时候会用到。

### 连接云盘，跨设备同步

OfficeSuite 内置了 MobiDrive 云存储，但如果你已经在用 Google Drive、OneDrive、Dropbox 或 Box，也可以把这些云盘全部连接进来。好处是一个界面就能管理所有云盘文件，不用在不同 App 之间切换，编辑完直接存回原来的云盘位置。

连接步骤很简单：打开左侧菜单 → "打开" → 在文件来源列表里找到目标云盘（比如 Google Drive）→ 点击后会跳转到对应的登录页面 → 输入账户并授权。OfficeSuite 用的是 OAuth 授权，不会存储你的云盘密码，随时可以在云盘的第三方应用管理页面撤销授权。

连接完成后，无论是主页浏览还是编辑器里"文件 → 打开"，文件来源列表里都会并列显示所有已连接的云盘。点击某个云盘就能浏览它的文件夹结构，找到 Office 文件直接点开编辑。编辑完"另存为"时，在保存位置选对应的云盘，文件就会存回原来的位置，其他设备上的云盘同步也能拿到最新版本。

> [!TIP]
> 跨云盘转移文件不能直接拖拽，用"打开文件 → 文件 → 另存为 → 选目标云盘"的方式间接复制过去就行。建议每个项目确定一个主存储位置，避免同一个文件同时存在多个云盘上导致版本不一致。
