## ✨ GoMusic 是什么

GoMusic 是一款面向 Android 平台的轻量级在线音乐播放器，主打「聚合搜索 + 本地收藏 + 多端同步」的一站式听歌体验。它不依赖单一音源，而是从多个公开音乐接口拉取搜索结果，用户在一个界面里就能搜到全网的歌曲资源。

核心功能可以概括为三个关键词：**搜得到、存得住、管得好**。搜索页支持按歌名、歌手、专辑名快速定位歌曲，点一下直接播放；收藏夹可以把喜欢的歌存下来，还支持从网易云导入整份歌单——不用一首一首手动搜；播放控制覆盖了底部常驻控制条、通知栏控件、锁屏操作三个层级，切到别的应用也能无缝控歌。

适合谁用？主要是这几类场景：不想装多个音乐 App 的轻量用户、有跨平台歌单迁移需求的老玩家、开车或通勤需要免手动操作的场景。它不走会员订阅路线，所有功能都可以直接用。

## 🔧 安装步骤

GoMusic 提供标准 APK 安装包，Android 6.0 及以上版本可直接安装。整个过程不复杂，按下面走就行。

1. **下载 APK 文件**：从下载入口拿到安装包，保存到手机本地存储或 SD 卡
2. **开启未知来源安装权限**：这是 Android 安全机制的要求。进系统设置 → 安全 → 安装未知应用，找到文件管理器或浏览器，允许其安装 APK
3. **执行安装**：点 APK 文件，按提示点"安装"，等几秒就好
4. **首次启动授权**：打开 GoMusic 后需要授予网络访问、存储读取两个权限，这是它能搜索和缓存歌曲的前提

> [!WARNING]
> 部分国产 ROM（华为、小米、OPPO）的安全中心会对第三方 APK 发出风险提示，确认来源可信后点"继续安装"即可，不会有实际安全问题。

安装完成后建议核对一下版本号——进入应用设置或关于页面，和下载页标注的版本号对上就说明装对了。

## 📖 使用入门

### 播放控制：三层全覆盖，不切应用也能控

听歌的时候，大部分时间其实都在干别的——刷微信、看视频、聊电话。GoMusic 的播放控制设计成了三个层级，覆盖了不同场景：

**第一层：底部常驻控制条**。只要有歌在播，不管你在搜索页、收藏夹还是本地音乐页，底部都挂着一条控制条。五个按钮从左到右分别是上一首、播放/暂停、下一首、可拖动的进度条、播放模式切换。进度条支持手指按住前后拖动，想跳到副歌段直接拖过去，精确到秒。播放模式循环图标点一下切换一种：顺序播放（默认）、随机播放、单曲循环。

**第二层：通知栏控件**。播放时系统通知栏会挂一条 GoMusic 的常驻通知，显示当前歌曲名、播放/暂停、上一首/下一首按钮，部分版本还有歌词预览。下拉通知就能操作，不用解锁、不用切回应用。锁屏界面也会显示同样的控件——开车时手机放支架上，锁屏就能切歌，非常省心。

**第三层：后台保活**。如果切走应用后歌直接停了，那是系统把后台进程杀了，不是 GoMusic 的问题。进系统设置给 GoMusic 放行电池白名单和自启动权限就能解决。

### 歌单导入：网易云 ID 粘贴就行

从网易云搬歌单过来是 GoMusic 的高频需求。整个流程四步搞定，不碰账号密码，完全公开接口拉取：

1. 从网易云 App 或网页版拿到歌单的纯数字 ID（一般在歌单分享链接里）
2. 进 GoMusic 的收藏夹，找到歌单导入入口（收藏页顶部或底部）
3. 粘贴纯数字 ID，点"导入"
4. 等加载完成——几十首的歌单很快，几百首稍慢一点

导入成功后整份歌单直接出现在收藏夹里，可以整份连播或随机听。再次导入新歌单会追加到已有收藏，不会覆盖。想从头听到尾就切顺序模式点第一首，想随机就换模式。

> [!TIP]
> 为什么能做到？GoMusic 不登录、不授权，只是用歌单 ID 去网易云公开接口拉取歌曲列表，然后在自己的搜索源里匹配并收藏。整个过程不涉及任何登录凭证，安全无风险。

### 睡眠定时：晚上听歌必开

睡前开着歌听，设个定时自动停，是最低成本的防呆设置。在播放详情页右上角菜单或设置 → 播放设置里能找到睡眠定时入口，一般提供 15 / 30 / 60 分钟的预设时长，部分版本支持自定义。

设置后倒计时开始走，屏幕或通知栏会显示剩余时间，到点自动暂停当前播放（不是关应用）。想提前停就进定时设置点"取消"，想延长有些版本可以追加 15 分钟。定时不会自动保存，下次播放默认不自动停。

> [!NOTE]
> 忘了定时的后果：手机放一晚上一直播，电量烧光、机身发热、某些机型甚至会因长时间高耗电触发系统重启。30 分钟预设足够你睡着后自动停歌，别嫌麻烦。

### 后台播放的关键设置

想让 GoMusic 切到后台也能持续播放，需要给它放行几项系统权限。不同品牌 ROM 的叫法不同，但核心都是这几个：电池优化白名单（允许后台活动）、自启动开关（应用启动管理里放行）、通知权限（必须开，否则通知栏控件不出现）、锁屏显示权限（锁屏界面显示播放控件需要）。

华为和小米这类定制系统会更激进地杀后台，这四个权限一个都不能少。进系统设置挨个找，把 GoMusic 拉进白名单就稳了。
