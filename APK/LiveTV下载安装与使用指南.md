## ✨ LiveTV 是什么

LiveTV 是一款面向安卓设备的直播电视应用，核心功能是在智能电视、电视盒子、安卓手机平板上收看数百个频道——从央视综合到各省卫视，从港澳台频道到地方台，按分类栏组织在主界面左侧，找台时直接在对应栏目里翻找即可。它的特点是频道来源多、更新快，适合想要在客厅电视上替代传统 IPTV、同时又不想被运营商节目单束缚的用户。

这款应用的使用门槛不高：电视端装一次、遥控器操作，日常打开就是直播画面，不需要额外付费订阅或注册账号。频道列表随版本更新迭代，新版本通常会同步引入新的播放线路，遇到个别台临时黑屏时升级往往就能恢复。

## 🔧 怎么装到电视上

LiveTV 以 APK 安装包形式分发，安装流程的核心只有两步：**开权限、装文件**。以下以电视 / 盒子为例，手机端逻辑类似。

### 第一步：开启未知来源安装权限

安卓系统默认只允许从自带应用商店装应用，LiveTV 作为第三方 APK 需要先在系统设置里把安装口子打开。

通用路径（绝大多数设备适用）：

1. 遥控器进**设置**（齿轮图标）；
2. 找**安全**或**安全与隐私**；
3. 找到**允许安装未知来源应用**开关，打开。

> [!NOTE]
> 较新的安卓系统（安卓 8 之后）采用**按应用逐个授权**机制，不再是全局开关。典型路径是：设置 → 应用 → 特殊权限 → 安装未知应用 → 选中你用来打开 APK 的文件管理器 → 允许。如果你点安装包时提示「未允许来自此来源的应用」，就是这种机制——把提示里提到的那个应用授权即可。

### 第二步：通过 U 盘安装

权限打开后，把下载好的 APK 文件复制到 U 盘，插到电视 USB 接口上：

1. 打开电视自带的文件管理器（或你装过的第三方文件管理器）；
2. 定位到 U 盘里的 APK 文件；
3. 点击安装，等待进度走完。

> [!WARNING]
> 安装前核对一下 APK 文件名和大小，避免下错版本。运营商定制的 IPTV 盒子大多锁死了第三方安装——没有未知来源开关、装什么都装不上，这种情况需要换一个开放的普通安卓盒子。

### 关于电视盒子的选择

如果你的电视系统太老装不上新应用，给电视外接一个安卓盒子是经典解法。选购时重点关注四点：

| 要点 | 具体要求 |
| --- | --- |
| 系统版本 | 直接选安卓 9 及以上，确保装得上、高清流解码顺畅 |
| 网络接口 | 优先带网线口（RJ45）的型号，有线连接比 Wi-Fi 稳定 |
| 解码能力 | 确认支持 H.264 / H.265，避免高清台掉帧、音画不同步 |
| 系统开放性 | 买前问一句客服「支持安装第三方应用吗」，绕开锁死的定制盒子 |

两类坑要避开：宽带送的 IPTV 定制盒子（锁死安装）、预装大量不可卸载应用的低价杂牌盒子。

## 📖 使用入门与常见问题

### 频道怎么找

LiveTV 不做搜索框式的找台，而是把几百个频道按属性分进不同的分类栏。主界面左侧的分类栏是找台的骨架，常见栏目包括：央视频道（CCTV 各频道完整序列）、卫视频道（湖南、浙江、江苏等各省上星卫视）、港澳台频道、台湾频道、地方频道、体育类、生活频道，以及你自己标记过的**我的收藏**——常用台标记一次，下次打开直达。

每栏内部以编号排序列出，央视栏按频道号从小到大，电视端可以直接用数字键快速跳转。找不到想看的台时，先确认它属于哪个属性、去对应栏目翻找；部分频道在不同版本里可能被归入不同栏（比如体育类既可能在专门栏目也可能在央视栏里），换相邻栏目再看一眼；找到了但画面不出多半是源的问题，下文讲黑屏排查。

### 黑屏了怎么办

黑屏是直播应用最高频的问题，但九成情况不用重装——关键是先分清**单频道黑屏**还是**全频道黑屏**，两者病根不同：

**单频道黑屏**（其他台正常），按这个顺序排查：

1. **换播放源**——播放画面里按左右方向键（手机端点右半屏），把该频道的线路轮一遍，多数黑屏在这一步就解决了；
2. **等再试**——所有线路都黑，可能是源临时维护，过半小时到几小时再切回来看；
3. **更新版本**——黑了超过一天的台，升级到最新版试试，新版本常带新线路；
4. **接受现实**——个别源是彻底下线了，等后续版本修复，期间先看同类型的替代频道。

**全频道黑屏**（所有台都不出画面），按序查这三处：

1. **网络通不通**——用电视自带浏览器或别的联网应用验证，断网修网；
2. **重启应用**——彻底退出 LiveTV 再打开，清掉异常的播放状态；
3. **重启设备**——电视 / 盒子断电三十秒再上电，老设备这招万能。

黑屏伴生症状的快速对照：

| 伴随症状 | 更可能的原因 |
| --- | --- |
| 有声音没画面 | 线路的流异常 |
| 反复缓冲转圈 | 带宽不足或线路拥堵 |
| 提示网络异常 | 家里网络问题 |
| 应用直接闪退 | 应用数据异常，考虑重装清缓存 |

> [!TIP]
> 直播源是别人维护的服务器，「某个台今天不行」是这类应用的日常而非故障。排查顺序走完仍黑屏的频道，放一放——明天说不定自己就好了。

### 日常使用的几个小技巧

- **遥控器键位**：左右方向键切换播放源、数字键直接跳转频道号、确认键呼出播放器菜单；
- **收藏常用台**：在频道列表里长按或选中后按菜单键，标记过的台会出现在「我的收藏」栏目，下次打开不用重新翻；
- **更新频道列表**：新增频道靠版本更新带入，建议开启应用内的自动更新提醒，或每隔一段时间手动检查一下有没有新版本。
