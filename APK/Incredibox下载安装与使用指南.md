## ✨ Incredibox 是什么

Incredibox 是一款让你用"拖图标到小人身上"来做混音的创意音乐应用。七个角色排成一排，左边是一排排声音图标，你把图标拖到角色身上，角色就开始循环播放对应的声音——有的唱 beatbox，有的打鼓，有的念 rap，有的弹旋律声部。每个角色同时只能穿一件"衣服"，要换声部直接拖新图标过去就行。

它的核心设计思路是**让创作门槛极低，但玩法又足够深**。从 Beat（节拍）开始定节奏，再逐层叠加 Melody（旋律）、Voice（人声）、Effect（效果）四类声部，怎么组合都不会完全难听——声音库是经过专业设计的，天然就能配出和谐的混音。玩到一定程度，你会发现某些特定声部组合还能触发隐藏的动画奖励：所有角色突然跳一段编排好的舞蹈、自动合唱一段和声、背景出现特效粒子，这让创作从"堆声部"变成了"找彩蛋"。

目前官方提供九个风格截然不同的版本，从经典的 Alpha、Brazil 桑巴、Jeevan 印度宝莱坞、到 Sunny 阳光 funk、Vida 拉丁风情，每个版本都有自己专属的声音库和奖励动画。付费版还开放了 Mods（社区自制声音包）、MP3 导出、安全模式等进阶功能。适合什么人？想快速做出一段好听混音的入门者、想给孩子找一款有音乐启蒙意义的应用的家长、以及想随时掏出手机即兴玩一段的音乐人，都能找到各自的玩法。

## 🔧 安装步骤

### 移动端安装（iOS / Android）

移动端安装最简单，直接走应用商店渠道即可。在 App Store 或 Google Play 搜索 "Incredibox"，找到官方开发者的应用点安装。免费版即可体验两个版本的全部功能，付费版解锁全部九个版本。

> [!NOTE]
> 注意区分免费版和付费版——商店里通常会有两个条目：一个标着 "Incredibox"（免费版，带内购），另一个是一次性买断的完整版。两个渠道最终解锁的内容是一样的，只是付费方式不同。

### 桌面版安装（Mac / Windows）

桌面版有三个获取渠道，各有优势：

| 渠道 | 支持系统 | 适合场景 |
|------|---------|----------|
| Mac App Store | macOS 10.10+ | 只用 Mac，偏好原生商店体验 |
| Microsoft Store | Windows 10+ | 只用 Windows，偏好原生商店体验 |
| Steam | macOS + Windows | 跨平台用户，买一次双系统通用 |

Steam 版是跨 Mac 和 Windows 双平台的，买一次两个系统都能装，适合同时拥有两台机器的用户。Mac App Store 版只能在 Mac 上运行，Microsoft Store 版只能在 Windows 上运行。

> [!TIP]
> Apple Silicon（M1/M2/M3）芯片的 Mac 用户还有额外选择：除了 Mac App Store 的原生桌面版，还能通过 App Store 直接安装 iOS 版的 Incredibox（通用 App 机制），体验上没有本质区别，只是界面布局更像手机版。

### 安装后的版本核对

安装完成后打开应用，可以在设置或关于页面看到当前版本号。免费版默认解锁 Alpha 和 Brazil 两个版本，付费版或内购后解锁全部九个版本。如果发现版本缺失，先检查付费是否成功到账，退出应用重新登录账户一般就能同步。

## 📖 使用入门

### 基本操作：拖放图标

Incredibox 的核心操作就是"拖图标到角色身上"，但要玩出好的混音，需要理解几个关键细节。

每个版本大约有 20~30 个声音图标，按类型分成四类，图标本身就是简化的图形，看一眼就能大概判断是什么声音：

- **Beat（节拍）**：鼓点、节奏骨架，通常偏暖色，建议**从 Beat 开始**——先放一个节拍定好 BPM，再加其他声部会容易很多
- **Effect（效果）**：电子音效、滤镜、氛围点缀，偏冷色，适合在混音的开头或结尾添加层次感
- **Melody（旋律）**：可辨识的曲调，绿色或亮色标记，决定了混音"好听"的程度
- **Voice（人声）**：人声片段、说唱、合唱，通常有特殊标记

激活声部的操作：手指（或鼠标）按住图标，拖到任意一个角色身上松手。角色会换上图标对应的"衣服"，并开始循环播放这个声音。七个角色最多七个声部，不要塞太满——留几个角色空着反而让混音更干净。

同一个角色不能同时穿两件衣服，拖新图标到已激活的角色身上会自动替换掉原来的声音。如果想移除某个声部，把已激活角色身上的图标拖回图标栏或拖出界面就行。

角色身上还有两个常用按钮：**静音（Mute）** 让该声部暂时抑制但不取消，再次点击恢复；**独奏（Solo）** 只让这一个角色的声音播出，其他全部静音，适合单独听某个声部的细节。

### 探索奖励：不只是堆声部

当你同时激活某些特定的声音组合时，会触发隐藏的**动画奖励（Bonus）**——所有角色一起跳一段编排好的动作、自动演唱一段预录好的和声、背景可能出现特效粒子。这些奖励是官方精心设计的，不是随机触发的。

每个版本都有自己专属的奖励组合清单，而且有些奖励需要先解锁前置奖励才能触发。当你尝试触发一个还没解锁前置条件的奖励时，界面会弹出 "BONUS LOCKED" 提示——意思是先完成上一个奖励再来。

奖励让创作从单纯堆声部变成了找彩蛋：你会忍不住试"如果把这两个放在一起会发生什么"。不用刻意去搜奖励攻略，先用心做出一段好听的混音，奖励是锦上添花的惊喜，不是必须完成的任务。

### 录制与导出

混音做好后可以直接录制。付费版支持 MP3 导出，录好的作品可以在 Mixlist 里回放和分享。录制时奖励动画会自然被包含进去，分享给朋友时他们也能看到完整的动画效果。

### 安全模式：给家长的儿童保护

付费版内置了安全模式（Safe mode），在设置页面打开后，会屏蔽所有社区内容、外部链接和公开分享，让孩子只玩纯本地的九个版本，不接触其他用户的混音。保存的混音自动标记为私人，不会被任何人看到。

| 功能 | 常规模式 | 安全模式 |
|------|----------|----------|
| 九个版本 | ✅ | ✅ |
| 本地混音创作 | ✅ | ✅ |
| 录制保存 Mixlist | ✅ | ✅ |
| MP3 导出 | ✅ | ✅ |
| 分享链接 | ✅ | ❌ |
| Top 50 / Live 列表 | ✅ | ❌ |
| 社区 Mods | ✅ | ❌ |
| 外部跳转链接 | ✅ | ❌ |

建议在孩子第一次接触时打开安全模式，让他先专注于创作本身。等孩子熟悉之后，如果想让他分享自己的作品，可以暂时关闭但最好监督。

### 桌面版 vs 移动端

桌面版和移动端功能完全一致，差异主要在操作方式和使用场景：

| 对比项 | 桌面版 | 移动端 |
|--------|--------|--------|
| 操作方式 | 鼠标拖放 | 手指触控 |
| 屏幕空间 | 大，图标角色更清晰 | 小，更紧凑 |
| 适合场景 | 严肃创作、长时间使用 | 随身玩、碎片时间 |

鼠标拖放更精确稳定，但很多用户觉得手指拖放更像"玩"——在桌面上用模拟器跑 Android 版的人不少。桌面版适合长时间坐在屏幕前认真摆弄声部组合，移动端适合碎片时间随手即兴一段。
