## ✨ Anytype 是什么：本地优先的一体化知识管理平台

Anytype 是一款主打"本地优先"理念的知识管理工具——不同于依赖云端存储的传统笔记软件，它把所有数据加密后存在你自己的设备上，通过端到端加密实现多设备同步，服务器只负责数据转发，看不到任何明文内容。它的核心载体叫 **Vault（知识保险库）**，每个 Vault 是一个独立加密空间，用 12 词恢复短语就能在任何设备上完整恢复。

在功能层面，Anytype 把笔记、待办、数据库、协作讨论、网页发布融合进了同一个编辑器。你写的每一页内容都是一个 **对象（Object）**，对象之间可以互相链接形成图谱，也可以按 Type 归类成可筛选、可排序的小型数据库。内置的五种视图——Grid、List、Gallery、Kanban、Calendar——让同一组数据随用随变，想怎么看就怎么看。界面外观、侧边栏行为、通知声音、对象打开方式都可以按需调整，社区翻译覆盖了几十种语言。

它适合什么人？如果你想要一个"数据所有权在自己手里"的第二大脑，如果你需要在一个工具里同时处理笔记、任务、资产管理和团队协作，如果你厌倦了 SaaS 订阅续费焦虑、想先用后付，Anytype 值得你花时间试试。

## 🔧 安装步骤：全平台覆盖，首次启动需留意恢复短语

Anytype 官方提供五个平台的安装包，安装流程各有细节。

### Windows 桌面版

1. 从官方下载页获取 `.exe` 安装程序
2. 双击运行，选择安装路径（建议放在 SSD 上以获得更好的 Vault 读写性能）
3. 安装完成后首次启动，App 会在后台生成本地加密存储目录，这一步完全离线，不产生网络请求

### macOS 桌面版

1. 下载 `.dmg` 文件，双击打开
2. 将 Anytype.app 拖入 Applications 文件夹
3. 首次启动如果遇到 Gatekeeper 拦截，到"系统设置 → 隐私与安全性"里点"仍要打开"

### Linux 桌面版

Anytype 提供 `.AppImage` 和 `.deb` 两种分发格式。AppImage 不需要安装，直接赋予执行权限双击即可运行；`.deb` 包适合 Debian/Ubuntu 系发行版，用 `dpkg -i` 安装。

### Android / iOS 移动端

在 Google Play 或 App Store 直接搜索 Anytype 下载安装即可，移动版支持指纹/PIN 锁屏，建议开启以保护加密数据。

> [!TIP]
> 安装完成后**不要急着删安装包**。版本号核对可以在 App 内部「设置 → 关于」里找到，和下载页标注的版本一致再做下一步。
>
> Windows 用户如果遇到杀毒软件误报加密模块，将 Anytype 主程序和数据目录加入白名单即可——它用的是成熟的本地加密库，不是恶意代码。

## 📖 使用入门：Vault 初始化、视图系统与协作讨论全流程

### 第一次启动：12 词恢复短语是你的一切

打开 Anytype 后点击 **Create a new Vault**，App 会在设备上完成四件事：生成 12 词恢复短语、创建本地加密存储、初始化默认的 Personal Channel、可选地连接 Anytype Network。整个初始化过程**完全离线**，不向任何服务器发送明文数据。

12 个随机英语单词是后续恢复 Vault 的唯一钥匙——App 会让你**立刻写在纸上**（截图和云笔记都不算安全），然后随机抽查几个词验证你确实记住了。这 12 个词通过密钥派生函数转换成加密密钥，从你完成确认的那一刻起，它们就再也不会以明文形式出现在屏幕上。

> [!WARNING]
> 恢复短语丢了 = Vault 彻底找不回来。App 没有任何后台备份、没有账号密码找回、没有客服能帮你恢复。请**至少备份两份纸制副本**，放在不同位置，条件允许的话扫描后用另一个加密工具归档。

Vault 创建完成后会进入一个空的 Personal Channel——这就是你的默认工作空间。侧边栏列出 Channels、按 Type 分组的对象、搜索入口和图谱。此时可以点 `+` 创建第一个 Page 对象，用 Slash Menu（输入 `/`）快速插入标题、待办、图片等块。如果想在多台设备间同步，App 会提示是否连接 Anytype Network——这一步生成一个匿名的 ANY ID，用来发布网页、接受协作邀请，但它**不是**你的加密密钥，恢复短语和 ANY ID 永远独立存在。

### 视图系统：五种布局随用随变

Anytype 的核心能力之一是**视图系统**——同一组对象可以用不同方式展示，底层数据不变，只是"怎么看"变了。五种布局各有适用场景：

| 布局 | 适合 | 核心特点 |
| --- | --- | --- |
| Grid（表格） | 有大量属性的对象集合，习惯电子表格思维 | 每行一个对象，每列一个 Property，支持排序、筛选、列宽拖拽、批量编辑 |
| Kanban（看板） | 状态流转管理，Scrum/Sprint 风格 | 每列是一个状态值，卡片拖拽即改状态，可设 WIP Limit 控制进行中任务上限 |
| Gallery（画廊） | 图片驱动、作品集、商品目录 | 大尺寸卡片，封面图为主，网格自动排列 |
| List（列表） | 紧凑浏览大量对象，移动端体验好 | 每行一个对象，紧凑卡片，纵向滚动效率高 |
| Calendar（日历） | 时间驱动的日程、任务截止管理 | 按天/周/月查看，需要至少一个 Date 类型 Property 决定位置 |

每个 Type 或 Collection 可以同时创建多个视图——比如一个 Task Type 可以同时有 Grid 表格视图、Kanban 看板视图、Calendar 截止日期视图，随时切换互不冲突。新建视图时还可以预置 Filters（哪些对象出现）和 Sorts（按什么顺序排列），复杂筛选条件支持 AND/OR 组合。

### Discussions：把讨论钉在具体内容上

Anytype 有两种协作方式——Chat 和 Discussions，定位完全不同：

| 维度 | Chat（Channel 级） | Discussions（对象级） |
| --- | --- | --- |
| 位置 | 独立聊天流 | 直接附加在某个对象的某个块上 |
| 适用场景 | 跨对象自由对话 | 针对对象特定部分的反馈和讨论 |
| 随对象走吗 | ❌ | ✅ 对象到哪，Discussion 到哪 |
| 能引用块吗 | 手动引用 | 自动锚定到具体块和文字范围 |

在对象上发起 Discussion 有三种方式：选中文字后用浮动工具栏的 Quote in Discussion、鼠标悬停在块上从 Block Handle 三点菜单进入、或者用 Slash Menu 输入 `/discussion` 创建嵌入式讨论块。Discussion 锚定到具体的块和文字范围——即使对象里其他内容都改了，原来的 Discussion 依然指向它创建时的那段文字快照，讨论者能看到完整的"讨论锚点"。这让它特别适合审稿场景：同事逐段阅读，在发现问题的段落上选中文字、Quote in Discussion、评论，你收到通知点开 Discussion 直接跳到那段原文，整个过程不需要切换到外部聊天工具。

### 界面与个性化设置

Vault Settings 的入口在 Vault Sidebar 左下角头像，或者操作系统菜单里的 Anytype → Settings → Vault。界面外观方面，主题支持 Light / Dark / Auto 三种——Auto 跟随操作系统主题自动切换，白天晚上都能舒服看。侧边栏可以设置自动隐藏，鼠标离开侧边栏区域后自动收起，移到左侧边缘再展开。对象打开方式默认全屏打开，如果偏好能在两个对象之间快速对比，可以关闭 Open objects in fullscreen，改成侧边弹窗模式。对象链接样式也有 Card 和 Text 两种选择——Card 显示为带图标+标题+类型标签的卡片，适合嵌入页面视觉化展示；Text 就是纯文本超链接，适合正文里的密集链接。

Grid 视图里点击对象标题的行为也可以自定义：默认是打开对象，如果习惯了在 Grid 里直接编辑标题，把 Click to edit title in Grid view 打开就行。消息发送偏好支持 Enter 发送 / Ctrl/Cmd + Enter 发送两种模式，对 Chat 和 Discussions 评论同时生效。拼写检查支持 40+ 种语言，中文目前建议关闭因为按词/字检查效果有限。完整快捷键列表可以在任何编辑器里按 `Ctrl/Cmd + /` 查看。

### 实际工作流举例

假设你在写一份产品需求文档，同事帮你审稿：你写完需求文档 → Drop into Chat 给同事 → 同事打开对象逐段阅读 → 在发现问题的段落上选中文字、Quote in Discussion、评论 → 你收到通知、点开 Discussion 旁边的评论图标跳转定位 → 回复讨论，整个协作在对象内部闭环。同时你可以给需求文档对象设置一个 Select 类型的 Status 属性（草稿/审核中/已发布），然后创建一个 Kanban 视图按状态分列，所有需求文档对象作为卡片在列之间拖拽，Kanban 会自动更新 Status Property 的值。到了项目截止日，切到 Calendar 视图按截止日期排列，一眼看到日程冲突。

这套流程里没有在多个 SaaS 之间来回切换，没有数据格式导入导出，所有信息和协作都在同一个 Vault 里闭环。这就是 Anytype 的本地优先 + 对象数据库 + 视图系统 + 讨论协作组合拳的威力——给你的不是又一个笔记软件，而是一个数据所有权在你自己手里的微型协同工作空间。
