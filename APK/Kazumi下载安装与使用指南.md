## ✨ Kazumi 是什么：规则驱动的番剧播放器

Kazumi 是一款面向番剧爱好者的跨端播放器，核心特点是**规则驱动的片源检索架构**——应用本体不硬编码任何视频源，所有搜索、嗅探、播放的能力都由一条条「规则」定义。你可以把它理解成一个带内置浏览器嗅探引擎的播放器骨架，片源的丰富程度取决于你喂给它多少规则。

默认自带三条内置规则，用于刚装完时验证应用的检索、嗅探、播放三个环节是否正常；正式使用时需要补充社区维护的规则库，把可用片源池垫起来。应用内播放是核心场景，同时支持把视频交给外部播放器（如 PotPlayer）、DLNA 投屏到电视、以及带进度同步的「一起看」。弹幕方面提供关键词 + 正则两种屏蔽方式，可对 BiliBili、Gamer、DanDan 等多个来源统一生效。

目前已覆盖 Android 和 Windows 桌面端，版本迭代节奏稳定，近年新增过 Bangumi 同步改进、追番计数器、实验性 Windows ARM 支持等功能。适合那些不想被单一站点卡死、希望自己掌控片源来源的番剧重度用户。

## 🔧 安装步骤

### Android 端

1. 从下载页拿到 APK 文件后，首次安装需要在系统设置里允许「未知来源」应用安装——路径通常是「设置 → 安全 → 安装未知应用」，找到文件管理器或浏览器后勾选允许。
2. 点击 APK 按提示完成安装，装完别急着关闭安装器，点「打开」直接进应用。
3. 首次启动后，建议先去「我的 → 关于 → 检查更新」确认一下当前版本号，确保拿到的是最新的稳定版。

> [!TIP]
> Android 11 及以上系统对未知来源安装的权限控制更严格，每次用不同文件管理器下载都要单独授权一次，别嫌麻烦，这是系统级安全机制。

### Windows 桌面端

1. 下载页提供的是标准安装包，双击运行后选择安装路径（默认 `C:\Program Files\Kazumi`），一路下一步即可。
2. 如果你的杀毒软件误报，通常是因为应用内置了 WebView 嗅探引擎——它需要在播放时分析网页返回的视频流地址，这个行为和常见的视频下载工具类似，加入白名单即可。
3. 安装完成后桌面会生成快捷方式，首次启动建议在「关于」页确认版本号与发布渠道标注一致。

> [!WARNING]
> 安装完成后，别着急删下载的安装包——新版本到来前它是你手头最靠谱的回滚介质。

## 📖 使用入门：从三条内置规则到顺手追番

### 先跑通内置规则

刚装好的应用进「我的 → 规则管理」，你会看到列表里已经有三条出厂自带的示例规则。这三条规则的意义不是让你靠它追完所有番，而是**拿来验证整个链路通不通**：用它搜一部你熟悉的番，点开能正常播放，说明应用本体的检索、嗅探、播放三个环节都是好的，后续如果新规则出了问题，内置规则就是最好的对照组。

内置规则的第二个作用是**当写作模板用**——想自己写规则的人，点开看字段填法，每一行填什么、什么格式，答案就在眼前。但它的局限也很明确：三条规则覆盖的站点不可能囊括所有想看的番，搜不到大部分内容是正常现象，不是应用坏了；而且目标网站改版后内置规则会失效，要等应用更新替换。所以内置规则的正确定位是「出厂测试件」，先拿它确认应用没问题，然后尽快补充社区规则。

### 规则越多，选择越多

番剧详情页点「开始观看」后，应用会列出**每条规则**在这部番上的搜索结果——规则越多，这里出现的可用源越多。多备几条互补的规则，比死磕一条全功能规则更现实。规则的管理、排序、删除操作都在规则管理页里，随时可以调整。

### 外部播放与反盗链边界

不喜欢内置播放器、或者想用 PotPlayer 等第三方播放器的高级功能（更强滤镜、字幕引擎、音轨切换），可以试试「外部播放」——入口在**视频播放页右上角三个点菜单**里。它把当前视频交给系统里的其他播放器打开。

但外部播放有一个绕不开的边界：**部分视频源做了反盗链保护**。Kazumi 能正常播这些源，靠的是 WebView 嗅探过程中对反盗链的特殊处理；而外部播放器拿到的只是一个普通视频地址，无法复刻这套处理。所以如果遇到「这部番外部播放黑屏或报错、内置播放正常」，结论很简单：换回内置播放器看这部，或者换一个无反盗链的源。这不是 bug，是能力边界。

三个「换地方看」的功能别搞混：

| 功能 | 送到哪 | 依赖 |
| --- | --- | --- |
| 外部播放 | 本机的其他播放器 | 播放器已安装 |
| DLNA 投屏 | 局域网内的电视等设备 | 同一网络 |
| 一起看 | 与朋友的播放器进度同步 | SyncPlay 服务器 |

### 弹幕屏蔽：关键词够用，正则进阶

弹幕屏蔽在「我的 → 弹幕设置 → 关键词屏蔽」里配置，支持两种匹配方式：

- **关键词**：填什么屏蔽什么，弹幕文本里包含该词就不再显示。适合屏蔽剧透词、特定人名、刷屏口头禅，一条一条加，数量不限。
- **正则表达式**：以 `/` 开头并且以 `/` 结尾的条目会被当作正则处理。比如 `/\d+/` 屏蔽所有纯数字弹幕，`/剧透|结局|死了/` 屏蔽含任一词的弹幕，`/前方.{0,4}高能/` 屏蔽「前方高能」的变体刷屏，`/^[0-9]+分$/` 屏蔽打分刷屏。不熟悉正则的话，先用关键词挡住九成干扰，剩下的一两成再针对性写。

屏蔽规则对 BiliBili、Gamer、DanDan 三个弹幕来源统一生效，不需要按来源分别配置。如果某部番的弹幕整体质量差到没眼看，与其堆屏蔽词，不如在播放页菜单里直接关闭当部作品的弹幕——按番处理比全局规则更干净。

> [!NOTE]
> 一份调好的屏蔽词列表也是个人资产，换设备或重装都不想重敲一遍。屏蔽词属于可同步的数据之一，可以跟着观看记录、收藏一起上云备份。

### 日常维护：关于页的五个实用项

「我的 → 关于」这一页挂着五件工具，日常维护都用得上：

- **自动更新**：默认开启，应用自动检查新版本；旁边的「检查更新」可以手动触发，当前版本号也显示在这里，提问题或对照更新日志前先确认一下。近一年从 2.1.x 更新到 2.3.x 系列，期中加入过 Bangumi 同步改进、追番计数器、实验性 Windows ARM 支持等，最新版本以项目发布页为准。
- **错误日志**：遇到问题需要提 Issues 时，官方要求附带日志文件。右下角按钮可清除或复制——提问题时先复制日志内容，清掉旧日志，重新复现一次拿到干净的错误现场。配合播放设置里的调试模式，能拼出完整的故障信息。
- **清除缓存**：清除的是番剧封面缓存，清掉后下次加载需要重新下载封面。适合封面显示错乱、换了同步账号想强制刷新、或磁盘紧张时顺手清一波。规则、观看记录、设置都不在缓存之列，清缓存不动你的数据。
- **关闭时行为（桌面端）**：设置每次关闭窗口是退出还是最小化到托盘，默认每次询问。常驻托盘的话后台挂着随叫随到，不想要后台占用就选直接退出。

如果遇到的是播放类问题，先走播放排错三层法；是规则类问题就对照规则排错表；都解决不了，带着这里的日志与版本号去项目 Issues 区求助。
