## ✨ Rotation 是什么——让手机屏幕方向听你指挥

Rotation 是一款专为 Android 设备设计的屏幕方向控制工具。它解决的核心痛点是：系统自带的自动旋转要么太迟钝、要么乱跳，手动切换又太麻烦。Rotation 让你能够为每个应用、每个事件（通话、充电、插耳机、锁屏……）独立指定屏幕方向，真正实现"谁在前台、谁说了算"。

想象几个场景：躺着接电话时屏幕自动切竖屏贴耳朵更舒服；车载蓝牙通话时保持横屏适配车机；某些视频 App 强制横屏、某些社交 App 强制竖屏——这些 Rotation 都能做到，而且完全后台自动运行，不需要你反复拉通知栏切开关。

功能上，Rotation 提供了**应用规则**和**事件条件**两套并行的方向控制机制。应用规则针对特定 App 生效，事件条件针对特定系统状态生效，两者可以组合使用，并且有明确的优先级排序。内置的全局开关允许一键暂停所有规则，应对投屏演示等临时场景。

> [!NOTE] Rotation 是 Android 专属工具，iOS 用户无需继续阅读——iOS 系统层面限制了第三方应用接管屏幕方向的能力。

## 🔧 安装步骤

Rotation 的安装和普通 Android App 类似，但有几个需要提前注意的地方。

### 下载与验证

1. 从上一节提供的下载页获取安装包（APK 格式）
2. 下载完成后建议核对一下文件大小和版本号——避免下载到不完整的包或过时版本
3. 如果是从非应用商店渠道安装，系统会弹出"未知来源"提示——这是正常的，允许即可

> [!WARNING] 某些国产 ROM（MIUI、EMUI、ColorOS）的文件管理器会对 APK 安装做额外拦截。如果遇到"解析包时出现问题"或"不支持此安装包"，请确认下载的 APK 是否完整，或者尝试换一个文件管理器打开。

### 首次安装后的权限授予

安装完成首次打开 Rotation，它会引导你授予几项关键权限：

| 权限 | 用途 | 不给的后果 |
|---|---|---|
| 读取设备状态和身份 | 检测是否在通话中 | 通话事件静默失效 |
| 开机自启动 | 重启后自动拉起服务 | 每次重启后所有规则白搭 |
| 通知访问权限 | 监听前台应用切换 | 应用规则无法实时生效 |
| 常驻通知 | Android 13+ 后台保活 | 服务容易被系统杀掉 |

**全部都要给。** 少一个权限就意味着对应的功能组件要么静默失效、要么后台活不下去。

### 后台保活设置（非常关键）

Rotation 是后台服务，装完后必须做这两件事，否则用着用着规则就不生效了：

1. **电池白名单**：系统设置 → 电池 → 电池优化 → 找到 Rotation → 设为"不优化"
2. **厂商自启动权限**：不同 ROM 路径不同，但核心都是"让 Rotation 开机自动运行 + 后台不被杀"

- MIUI：安全中心 → 自启动管理 → 找到 Rotation → 允许
- EMUI：手机管家 → 启动管理 → 手动管理 → 允许自启动
- ColorOS：设置 → 应用 → 自启动管理 → Rotation 打开

> [!TIP] 加完白名单和自启动权限后，建议重启一次手机验证服务真的起来了——拉通知栏看有没有 Rotation 的常驻通知，再打开一个设了强制横屏的 App 测试方向是否正确切换。

## 📖 使用入门

安装配置完成后，就可以开始为你的常用 App 和系统事件设置方向规则了。下面从应用规则和事件条件两个维度展开。

### 应用规则：给每个 App 定方向

应用规则是 Rotation 最核心的功能。打开 Rotation → 应用 / Apps → 点击添加规则，选择目标 App，然后为它绑定一个方向模式。方向模式包括：

- **强制竖屏**：不管系统怎么想，这个 App 永远竖屏
- **强制横屏**：同上，永远横屏
- **自动旋转**：跟随设备物理方向传感器
- **跟随系统默认**：不干预，让系统自己决定

批量管理也很方便。当你建了十几个应用规则后，规则列表按应用名字母顺序排列，每条显示应用图标、绑定的方向模式和一个启用/禁用开关。整体开关可以一键暂停所有规则（临时投屏演示时特别有用），单条开关则允许你只关某一个。长按规则条目可以删除或复制，点进去可以快速编辑方向模式。

维护习惯上，建议定期回头清理——有些 App 你可能已经不用了，删掉对应的规则让后台检测更轻。同类 App 尽量统一模式，比如所有视频类都强制横屏、所有社交类都强制竖屏，便于记忆和维护。

### 事件条件：系统状态触发方向切换

除了特定 App，系统状态变化也能触发方向切换。Rotation 内置了多种事件条件：

**通话事件**是最常用的事件条件之一。Rotation 检测到手机处于通话中（包括来电振铃阶段），就会自动应用你为通话事件指定的方向模式。挂断后自动恢复之前的状态。典型用法包括：

- 躺着接电话：设通话时强制竖屏，耳朵和脸更舒服
- 车载蓝牙通话：设通话时保持横屏，适配车机场景
- 视频通话：设通话时强制竖屏，人像画面更好看

通话事件需要"读取设备状态和身份"权限才能正常工作。不给这个权限，通话事件检测会静默失效。

**充电、插耳机、锁屏、插入底座**等事件同理，都可以单独绑定方向模式。进入 Rotation → 条件 / Events 就能找到并配置。

### 事件优先级：多事件同时触发时谁听谁的

你可能会遇到这种情况：正在充电（想强制横屏）+ 插着耳机（想保持竖屏）+ 同时在打电话（想强制竖屏）——三个事件同时生效，方向该听谁的？

Rotation 提供了**事件优先级**设定页来解决这个问题。进入 Rotation → 条件 → 事件 → 事件优先级，可以看到所有事件从上到下排列，排在上面的优先级更高。默认优先级从高到低依次是：通话、锁屏、耳机、充电、底座。通话默认最优先，因为通话时方向不舒服对体验影响最大。

长按某条事件可以上下拖动调整顺序，改完立即生效，不需要重启服务。

> [!TIP] 记住：应用规则的优先级**永远在事件条件之上**。如果当前前台 App 有应用规则，那不管什么事件同时触发，应用规则说了算。只有当没有任何应用规则匹配前台 App 时，事件条件才会接管。大部分用户不需要改默认优先级顺序——通话优先、锁屏其次是合理的，只有特殊需求时才需要调整。

### 重启后规则失效怎么办

如果重启手机后发现所有方向规则都不生效了，按以下顺序排查：

1. **Rotation 服务有没有开机自启**——Rotation → 设置 → 开机时运行，这个开关必须打开。同时检查系统层面的自启动权限是否授予（MIUI/EMUI/ColorOS 各有独立的自启动管理页面）。App 内部开关 + 系统权限，两个都要有。

2. **后台有没有被系统省电策略杀掉**——确认电池白名单已加上，常驻通知权限已授予（Android 13+）。没有常驻通知的话，Android 系统更倾向于杀掉后台服务。

3. **厂商系统后台限制过严**——少数国产 ROM 后台策略特别激进。可以尝试：把 Rotation 加进"后台弹出界面"白名单；在多任务界面长按 Rotation 卡片锁定；切换到更激进的电池模式。

重启后验证服务真的起来了的方法：等 30~60 秒给开机自启动留时间，拉通知栏看有没有 Rotation 常驻通知，打开一个设了强制横屏的 App 看方向是否正确切换，再进 Rotation App 看服务状态。三个都 OK 才算真的跑起来了。
