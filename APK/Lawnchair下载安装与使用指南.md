## ✨ Android 启动器的 Pixel 范儿之选

Lawnchair 是一款开源的 Android 桌面启动器，直接从 AOSP Launcher3 fork 而来——换句话说，它和 Google 自家 Pixel 手机使用的 Pixel Launcher 共享同一套底层代码。在此基础上，Lawnchair 做了两件让它脱颖而出的事：一是保留了 Pixel 风格的简洁观感，默认外观与 Pixel 桌面高度一致；二是把几乎所有可调参数都开放出来，从网格行列数、图标大小、Dock 圆角到搜索算法、抽屉文件夹、双击息屏手势，每一个视觉和交互细节都能在设置里找到对应的调节开关。

作为开源社区驱动的项目（Apache 2.0 协议），Lawnchair 与常见的闭源商业启动器不同：它没有内置广告、没有付费解锁、源码完全公开可审计。对于在意隐私、喜欢折腾、又偏爱 Pixel 原生质感的 Android 用户来说，Lawnchair 是目前社区口碑最好的选择之一。

它适合这样的用户：已经用腻了厂商预装的桌面（MIUI、ColorOS、OneUI 等定制 ROM 的桌面通常自定义空间有限）、想换一套更干净清爽的桌面、愿意花半小时调整网格和手势但又不想彻底抛弃 Pixel 风格的用户。如果你追求最极致的稳定性和零折腾体验，那原生 Pixel Launcher 可能更省心；如果你想要最成熟的生态和最多的专属手势，Nova Launcher 依然是行业标杆；但如果你要的是「Pixel 外观 + 深度自定义 + 开源无广告」这三个的交集，Lawnchair 几乎是唯一的选项。

## 🔧 安装与切换到默认桌面

### 前提条件

Lawnchair 支持 Android 8.0 及以上的设备，绝大多数主流机型都可以直接安装。但在以下两种情况可能需要额外注意：

> [!WARNING] 深度定制 ROM 兼容性
> MIUI、ColorOS、One UI 等厂商深度定制的 ROM 会对桌面有自己的拦截逻辑，安装后可能出现部分系统手势异常、小部件无法添加等问题。建议先在备份设备上测试，再考虑主力机切换。

### 安装步骤

1. 从上面的下载入口获取 APK 文件（Google Play 用户直接在应用商店安装即可）
2. 如果是手动下载的 APK，首次安装需要授权「未知来源」：进入系统设置 → 安全 → 允许安装未知应用 → 选择浏览器或文件管理器
3. 安装完成后，按 Home 键——系统会弹出「选择启动器」的对话框
4. 在列表中找到 Lawnchair，点击「始终」或「设为默认」

> [!TIP] 如何确认切换成功？
> 切换后如果看到桌面顶部的 At a Glance 天气小部件、底部白色 pill 搜索条，那就是 Lawnchair 的默认外观，说明切换成功。

### 恢复默认桌面

如果想换回原来的桌面，不需要卸载 Lawnchair：

1. 进入系统设置 → 应用 → 默认应用 → 主屏幕应用
2. 在列表中选择原来的启动器（比如 One UI Home、MIUI 桌面）
3. 回到桌面即可切回

## 📖 使用入门：从默认到定制的完整路径

### 手势交互——让桌面操作更高效

Lawnchair 的手势系统是它最常用的功能模块之一。所有手势配置都集中在「主屏幕设置 → 手势」里，支持的手势类型包括：双击空白处、上滑/下滑、主页键长按、捏合缩放等，每个手势都可以从一个动作列表里自由分配。

社区推荐的极简导航组合通常是：**双击 → 息屏**（最常用的一键操作，需要授予无障碍权限）、**向上滑动 → 打开应用抽屉**（默认值）、**向下滑动 → 显示通知**（比从状态栏拉下来更快）、**主页键长按 → 打开搜索**。对于追求效率的用户，可以把双击分配给常用快捷方式（比如扫码）、把下滑分配给日历或天气应用、把捏合分配到所有页面总览。

手势也有边界条件：它们只在主屏幕空白处触发，图标和文件夹上不会响应；全面屏手势导航可能与系统手势冲突；厂商 ROM 的拦截逻辑也可能导致某些手势失效。如果觉得某些手势意外触发（比如缩放图片时在桌面误触捏合），可以随时在手势设置里把对应项设为「无」来禁用。

### 图标包应用——一键换桌面风格

图标包是自定义桌面最直接的方式。Lawnchair 完全符合 Android 图标包规范，市面上绝大多数图标包都能直接使用。安装图标包本身就是装一个普通 APK，然后在 Lawnchair 里应用：**长按桌面空白 → 主屏幕设置 → 主题 → 图标样式 → 选择已安装的图标包**，确认后立即生效。

Lawnchair 同时支持两个图标系统：图标包提供的完整彩色图标，以及 Material You 引入的「主题图标（Themed Icons）」——后者是单色剪影风格，由系统取色后自动上色。两者可以叠加使用：先用图标包提供基础图标，再让主题图标在其上叠加一层主题色风格。

大部分图标包只覆盖热门应用（200-500 个），冷门应用会回退到系统默认图标，这是正常现象。解决办法包括：换覆盖更全的图标包、使用 Lawnicons（Lawnchair 团队维护的图标包，覆盖 1000+ 应用）、或者单个自定义未覆盖的图标（长按图标 → 自定义 → 选择新图标）。社区推荐的图标包包括：Lawnicons（Pixel 风格，官方推荐）、Arcticons（单色线性，3000+ 应用）、Delta（渐变多彩，口碑好）等。

### 深度定制的入口——主屏幕设置菜单

Lawnchair 的所有自定义都从「主屏幕设置」进入——长按桌面空白处即可调出设置面板。设置分为多个分类：**主题**（图标样式、主题图标、颜色）、**桌面**（网格行列、图标大小、页面指示）、**Dock 栏**（圆角、宽度、背景）、**应用抽屉**（文件夹、搜索、排序）、**搜索**（搜索算法、结果数量）、**数据**（备份与恢复）、**手势**（前面介绍过的完整手势配置）。

一个值得单独提到的小功能是 **At a Glance 小部件**——它是 Lawnchair 默认显示在桌面顶部的天气/日程小工具，信息密度不高但恰到好处。如果你嫌它占位置，可以在桌面设置里关闭；如果想换其他天气源，也可以替换成第三方的桌面小部件。

### Root 设备的增强选项——QuickSwitch

如果你的设备已经获取了 Root 权限（通过 Magisk 等方式），可以额外安装 QuickSwitch——一个开源的 Magisk 模块，用来替换 Android 原生的最近任务界面。QuickSwitch 最实用的功能是**应用内手势返回桌面**：在应用内自定义一个滑动手势，直接跳回桌面，相当于一键退出当前应用。此外还可以定制最近任务卡片的圆角大小、移动「清除全部」按钮的位置、改变卡片切换动画。

安装 QuickSwitch 需要：设备已 Root、Magisk 版本较新、从 GitHub Releases 下载模块 ZIP、在 Magisk Manager 里安装后重启。未 Root 的设备不需要考虑这个模块——Lawnchair 的核心功能完全不依赖它。需要注意的是，Android 大版本更新后 QuickSwitch 可能会因为最近任务内部 API 变化而短暂失效，需要等待作者跟进适配。

### 备份与迁移

定制好桌面布局后，记得定期备份。Lawnchair 自带的备份功能在「主屏幕设置 → 数据 → 备份/恢复」里，可以把当前的桌面布局、图标包、手势配置、抽屉排序等全部设置保存到本地文件。换手机或者刷系统前先备份，新设备安装 Lawnchair 后直接恢复，就能把整套桌面原封不动搬过去。
