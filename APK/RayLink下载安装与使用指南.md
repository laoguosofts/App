## ✨ RayLink 是什么

RayLink 是一款面向个人与企业用户的远程控制软件，主打跨平台远程桌面连接、文件传输和设备管理。它的核心思路是让用户在一台设备上就能安全地访问和操控另一台远程设备，无论是家里的台式机、公司的工作站，还是客户现场的电脑，都能随时随地建立连接。

与市面上其他远程工具相比，RayLink 提供了比较完整的一套"远程办公 + 远程运维"能力：支持 Windows、macOS、Android 等多平台互控，内置隐私模式、远程投屏、网络唤醒等进阶功能，并且在数据传输上采用端到端加密来保障会话安全。对于经常需要远程协助客户、在家访问公司电脑、或者给朋友修电脑的用户来说，它是一个覆盖度相当不错的选择。

在实际使用中，RayLink 的账号体系设计得比较清晰——主控端和被控端都需要登录账号才能正常使用，登录状态会影响免密连接、设备分组、会员权益等多项功能的生效。主力被控设备建议用同一个账号常驻登录并开启开机自启动，这样设备列表里永远在线；帮别人修电脑时则不要让对方登录你的账号，改用设备码加密码的方式临时连接，会话结束后对方那里不会残留你的账号信息。

## 🔧 安装与账号登录

### 下载与安装注意点

安装 RayLink 之前，建议先核对一下系统版本：远程投屏等部分进阶功能仅支持 Windows 10 及以上 64 位系统使用；远程开机（网络唤醒）也只在 Windows 被控端上可用。安装包大小通常在几十兆量级，下载完成后可以比对一下文件哈希值或版本号，确认没有拿到损坏或过期的安装包。

> [!WARNING]
> Windows  Defender 或第三方杀毒软件偶尔会把远程控制类软件误判为可疑程序。如果安装时被拦截，可以在杀毒软件里给 RayLink 加个信任，或者临时关闭实时防护再安装。

### 注册与登录

RayLink 目前支持两种登录方式：**微信扫码登录**和**邮箱账号密码登录**。两种方式各有适合的场景——微信登录快捷，适合个人用户快速上手；邮箱登录适合需要多账号管理的场景，比如 IT 运维人员用工作邮箱统一管理多台设备。

登录的具体步骤很简单：打开客户端，进入登录界面，选择对应的登录方式按提示操作即可。首次使用会引导完成注册和账号验证，验证通过后自动登录。

### 登录状态带来的影响

登录账号后，几个关键功能会自动生效：

- **免密连接**：主控和被控登录同一账号时，发起连接不需要再输入密码，直接点击设备列表里的目标设备就能连上；
- **我的设备分组**：被控端登录后，该设备自动出现在同一账号的「我的设备」列表里，方便后续分组管理；
- **移动设备授权**：手机作为被控端的前提，是主控和被控端使用相同账号；
- **会员权益**：通道优先级、帧率上限、传输速度等权益跟随账号，换设备登录也不会丢失。

如果客户端启用了锁定密码，忘记后的恢复方式可以在客户端的帮助或故障排查页面找到对应指引。

## 📖 核心功能与实用技巧

RayLink 的基础远程连接功能大多数同类软件都有，这里重点聊几个比较实用、也容易被忽略的进阶功能和操作细节。

### 隐私模式：远程时让对方"看不见"你在做什么

隐私模式（也叫防窥模式）是远程会话的"保密开关"——开启后，被控设备的物理屏幕会变成一块显示"正在远程控制中"的黑屏，旁边路过的人只能看到黑屏提示，而主控端这边一切照常操作。

这个功能的典型使用场景包括：在公司工位处理私人事宜不想让同事看到、IT 管理员远程处理涉及敏感数据的机器、或者在公共空间放置被控机时防止他人瞄屏。不过隐私模式目前只有在**受控端为 Windows 10 及以上 64 位系统**时才能开启。

开启步骤：先通过 RayLink 正常连接目标设备，然后在远程控制界面的工具栏里点击隐私模式图标就能启用。如果主控和被控登录的是**同一账号**，点击后直接生效；如果是跨账号连接，则需要被控端同意后才能开启。解除的方式有两种——会话结束后再点一次隐私模式图标恢复正常显示，或者被控端现场的人可以按 **Ctrl + Alt + Del** 强制解除，这是给屏幕主人留的物理后门。

> [!TIP]
> 隐私模式挡的是"眼睛"（旁观者的视线），挡不了"会话本身"。主控和被控之间的数据链路靠端到端加密保障安全，整体安全体系可以在 RayLink 的安全文档里查阅。

容易混淆的几个相关功能可以用一张表区分清楚：

| 功能 | 作用 |
|---|---|
| 隐私模式 | 被控端屏幕变黑屏，防止旁人围观 |
| 禁用受控键鼠 | 远程期间锁定被控端的键盘鼠标输入 |
| 鼠标锁定 | 限制主控端指针不出远程窗口范围 |

### 远程开机：让关机的机器自己醒过来

远程开机解决的是一个很实际的痛点——远端机器断电或关机后，RayLink 客户端下线，远程桌面根本够不着。RayLink 通过网络唤醒（Wake-on-LAN，WOL）来实现远程开机，但它不是软件单方面就能搞定的，需要四个硬件条件同时满足：

**前提一：仅支持 Windows 被控端**——目前只有 Windows 设备能被远程唤醒。

**前提二：同局域网需要一台辅助开机设备**——唤醒包只能在本局域网内发送，被控机器所在网络里必须有另一台保持 RayLink 在线的设备（比如 NAS、软路由或常开的小主机），由它向已离线的目标机器发送唤醒指令。目标机器离线后，唤醒包无法凭空穿过公网送达。

**前提三：主板 BIOS 开启 WOL**——进 BIOS（开机按 Del 或 Esc），在「Power Management（电源管理）」相关选项里找到以下任一项设为 Enabled：Wake on LAN / Boot on LAN、PME Event WakeUp / Resume by MAC LAN、Wake-Up by PCI card 等。不同主板命名略有差异，找到其中一条启用即可。注意**笔记本基本不支持 WOL**，拿不准可以咨询硬件厂商。

**前提四：网卡驱动开启唤醒能力**——有线网卡大部分支持，无线网卡一般不支持。进入设备管理器找到目标网卡 → 属性 → 电源管理 → 勾选"允许此设备唤醒计算机"；再到"高级"选项卡，把"关机网络唤醒""魔术封包唤醒"设为开启。

> [!NOTE]
> 配好远程开机后，建议同时开启被控端的"开机自启动"功能，这样机器一开机就能自动挂到你的设备列表里。如果关机后很久仍然唤不醒，可以检查路由器里是否需要做 IP 和 MAC 地址的 ARP 绑定。

### 远程投屏：共享画面 vs 借来当副屏

远程投屏和远程控制解决的是不同的问题——远程控制是"我操作你的机器"，远程投屏是"我共享画面给你看"或者"借你的屏幕来用"。RayLink 的远程投屏有镜像屏和扩展屏两种模式，方向完全相反：

**镜像屏**是把本机的屏幕共享给其他设备观看，对方只能看不能操作。适合开会演示、教学投屏、给客户展示方案这类"推画面"的场景。操作方式是：菜单栏选择「远程投屏」→ 点击【开始镜像屏】→ 选择要镜像的设备（可以多选，一次推给多台）→ 同账号直接成功，跨账号则等待被控端同意。镜像过程中可以在设备列表里调整画质和帧率。

**扩展屏**则是把其他设备变成本机的第二块显示器——本机桌面延伸到对方屏幕上，自己还能继续操作。适合笔记本外接平板当副屏、出差时用酒店电脑扩屏干活这类"拉屏幕"的场景。操作上和镜像屏类似，但扩展屏**只能选一台**目标设备，不能多选。

两种模式的对比一目了然：

| 对比项 | 镜像屏 | 扩展屏 |
|---|---|---|
| 内容方向 | 本机 → 对方（推出去） | 对方屏并入本机（拉过来） |
| 对方可否操作 | 不可观看不可操作 | 是本机的延伸桌面，可操作 |
| 目标设备数量 | 可多选 | 仅一台 |

远程投屏有两个硬性的开启条件：**主被控均需安装 8.1.1.8 及以上版本**，且主被控仅支持 Windows 10 及以上系统。另外显示适配器驱动需要是 2018 年以后的版本，而且不能被其他投屏或推流软件占用。
