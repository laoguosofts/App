## ✨ Venera 是什么

Venera 是一款面向漫画读者的跨平台本地阅读器，桌面端覆盖 Windows、macOS 与 Linux，移动端提供 Android 版本。它的定位很明确：把本地漫画文件（ZIP、CBZ 等归档格式）整理进统一的阅读工作台，同时内置了网络漫画源的接入能力，让喜欢收藏和追更的用户在一个应用里就能完成导入、阅读、下载与管理。

核心功能集中在三个方向：**端侧漫画库管理**——导入本地压缩包、自动解包、按分组组织收藏；**沉浸式阅读**——工具栏自动隐藏、可配置的预加载与缓存策略、高清图片渲染；**网络追更**——接入漫画源脚本、订阅更新、本地收藏与账号收藏两套并行体系。

适合谁？如果你手上攒了一堆 CBZ 文件想找个轻量的阅读器统一收纳，同时又希望顺手能追网络连载，Venera 这套「本地优先 + 网络可选」的思路刚好对上胃口。它不做云端强制同步，也不锁死存储格式，老漫画玩家和新入坑的都能上手。

## 🔧 多平台安装步骤

### Android

从可信来源下载 APK 后安装即可。如果系统弹出「未知来源」拦截，需要在设置里允许当前下载来源的安装权限——这是 Android 的常规安全提示，仅在首次安装外部 APK 时触发，后续同来源安装不再需要。

> [!WARNING]
> 安装完成后建议核对包名与版本号，避免第三方渠道打包时混入额外组件；同时保持应用商店的同版本信息作为对照。

### macOS

桌面端提供 dmg 磁盘镜像：

1. 双击 dmg 文件挂载镜像
2. 把 Venera 图标拖进「应用程序」文件夹
3. 首次打开若遇 Gatekeeper 拦截（非 App Store 来源的常规提示），到系统设置 → 隐私与安全里点击「仍要打开」即可

卸载时直接把应用图标拖到废纸篓即可，不会留下额外的系统组件。

### Linux

Linux 按发行版对号入座，三个主流系列的包型都覆盖了：

| 发行版 | 包型 | 安装方式 |
| --- | --- | --- |
| Debian / Ubuntu | deb 包（x64 / ARM64 两种架构） | 系统包管理器或 `dpkg -i` 命令行 |
| Arch | .pkg.tar.zst | 手动安装或从 AUR 仓库获取社区维护的包 |
| 其他发行版 | AppImage | 赋予可执行权限后直接运行，无需安装 |

> [!TIP]
> Linux 桌面版依赖 GTK3 与 WebKit2GTK 两个库。主流发行版基本预装，但精简环境（如最小化安装的服务器桌面）可能需要先补齐，否则界面与网页内容渲染会出问题。ARM64 设备（部分开发板与国产 Linux 笔记本）务必选对架构的包，x86 包在 ARM 上装不了。

### 版本核对

装完之后首次启动，在设置或关于页面确认一下版本号是否与下载页标注的一致。近期版本更新（v1.6.3）专门优化了图片缩放逻辑，看大图糊或卡的用户建议直接上当前最新版。

## 📖 使用入门

### 把漫画装进应用

安装完成后的第一步是把漫画文件导入进来。Venera 支持 ZIP、CBZ 等常见归档格式，导入方式也比较灵活：可以从文件管理器直接拖进应用窗口，也可以在应用内点「添加本地漫画」选择文件或目录。导入时的弹窗里就能顺手选好收藏分组，进门就定位，避免「先进仓库再整理」的堆积。

### 阅读器调校：让翻页跟手起来

阅读流畅度由三件事共同决定——预加载深度、缓存策略、缩放画质，三项都在设置里可调。

**预加载**的逻辑是提前加载后面若干页，翻页时图片已经就位。调大更跟手但更耗流量，调小省流量但翻页可能等图。网络源阅读建议适度调大；本地与已下载漫画因为文件就在磁盘上，预加载参数的影响基本可以忽略。

**缓存**方面，应用按设备可用内存**动态调整图片缓存大小**——大内存设备缓存更深，老设备自动收敛。在线阅读过的图片会进磁盘缓存，二次打开不用重新拉。排查占空间时可以清缓存，这个操作不会影响下载数据与收藏记录，放心清。

**缩放画质**由图片按缩放级别调整渲染质量，平衡清晰度与内存占用。近期版本（v1.6.3）专门优化了缩放逻辑，看大图糊或卡的用户先升级再说。慢网场景下建议组合使用：预加载调大一些用等待时间换连续翻页；优先把喜欢的作品下载离线看；仍卡顿的源再排查是不是源站点本身出了问题。

> [!NOTE]
> 设置改动即时生效，无需重启阅读器；不同设备手感不同，建议各调各的，不必跨设备同步阅读器设置。

### 沉浸模式：看漫画时什么都不显示

阅读器的界面哲学是「看漫画时什么都不显示，想要时一秒唤出」。一段时间不操作，工具栏与状态信息自动隐藏；点击屏幕中间区域，随时唤出或再次隐藏——这个节奏不需要配置，全靠点击掌控。

**沉浸模式**开启后会隐藏系统状态栏等界面元素，把整块屏幕留给漫画。搭配桌面端全屏（F12）效果更完整，想退出时正常手势或按键即可唤出系统界面，不会锁死。

状态信息可以按需显示：页码位置（当前页/总页数，可常显）、电量、时钟——长时间追更党可以把时钟开着防熬夜，常显页码则让你不唤出控件也能看到进度。安卓端还有**屏幕旋转控制**，躺读时锁定方向很实用。

### 收藏与分组：几百本也不乱

收藏是 Venera 资产管理的核心，以**分组**组织，分组随你自由创建。基本操作很直观：详情页里点收藏按钮选分组；收藏页里建分组，名字随意——「连载中」「已完结」「画集」都行；条目可以在分组间移动或移除（不影响文件与下载）。

几百本还能不乱，靠的是**一条漫画只进一个主分组**的原则。常见的分组维度有三套：

| 分组维度 | 示例 |
| --- | --- |
| 阅读状态 | 在追的、攒着看的、看完的 |
| 内容形态 | 本地导入的、网络源追的 |
| 用途 | 下载完毕随时重看的、只收藏做个记号的 |

按「阅读状态」分是最不容易崩的一套：状态变了就挪分组，分组直接变成待办清单。需要注意的是，网络源的账号收藏是另一套体系，和本地收藏分组各自独立；想自动盯更新的是订阅功能，不是收藏本身。
