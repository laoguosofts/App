## ✨ Blacklyte 是什么：给电竞玩家做的智能游戏桌生态

Blacklyte 是一个面向硬核电竞玩家的桌面硬件品牌，核心产品是 **Atlas 电动升降游戏桌**——一张能随游戏节奏变色、能记住你坐姿站姿高度、能和游戏进程实时联动的桌子。围绕这张桌子，品牌还做了像素显示屏、配套的 **Atlas Driver 桌面软件**和 **Blacklyte 手机 App**，形成了一套"硬件 + 驱动 + 移动端"的完整生态。

Atlas 桌的核心卖点有三个：**Game Sync 游戏联动**（击杀瞬间桌面爆红光）、**双物理高度记忆位**（坐姿站姿一键切换）、**全身 RGB 灯带**（支持 Screen Sync / Rhythm Sync / Scenes 多种灯光模式）。配套的 Atlas Driver 是 Windows 端的中枢，负责硬件控制、灯光效果、游戏监听；手机 App 则管资讯推送、积分系统、NFC 保修绑定和远程调灯。

如果你是 Valorant / LOL / CS2 这类竞技游戏的常客，又刚好在折腾桌面氛围，Blacklyte 这套东西确实能让你的桌面"活"起来——但它不是通用外设，不玩电竞、不追求 RGB 的话可能觉得溢价偏高。

## 🔧 Atlas Driver 与 Blacklyte App 安装步骤

Atlas Driver 和 Blacklyte App 是两个独立安装包，分别对应 PC 和手机，互不依赖但联动使用。

### Atlas Driver（Windows 端）

1. **下载安装包**：在下载页获取最新版本的 Atlas Driver 安装程序（.exe），文件大小约 120MB
2. **以管理员权限安装**：右键安装程序 → 以管理员身份运行 → 选择安装路径（建议默认路径，避免中文目录）
3. **首次运行必须管理员**：安装完成后，右键 Driver 快捷方式 → 属性 → 兼容性 → 勾选"以管理员身份运行此程序"。Game Sync 功能需要读取游戏进程内存，非管理员权限下会直接失效

> [!WARNING]
> 杀毒软件拦截是高频问题。Game Sync 读取游戏内存在 Windows Defender、360、火绒等软件看来是"高风险操作"——安装后务必把整个 Blacklyte 安装目录加入杀毒软件的**完全信任列表**，否则会出现 Driver 启动后托盘图标显示"离线"、Game Sync 完全无响应的情况。

### Blacklyte 手机 App（iOS / Android）

1. **确认设备支持 NFC**：App 版本 2.0.7 起支持 NFC 保修卡绑定，iPhone 6+ 和主流 Android 机型均支持
2. **开启 NFC 开关**：
   - iOS：设置 → 通用 → NFC → 开启
   - Android：设置 → 连接 → NFC → 开启
3. **应用商店搜索 Blacklyte** 下载安装，打开后注册或登录账号

## 📖 四件你需要知道的核心玩法

### 一、Game Sync：让桌面跟着游戏节奏动起来

Game Sync 是 Atlas Driver 最酷也最容易出问题的功能——它监听游戏进程的内存变化，捕捉击杀、死亡、胜利等事件，触发桌面 RGB 灯带的对应效果（击杀闪红光、胜利全桌呼吸、死亡变暗）。

#### 快速排查清单

Game Sync 不生效时按以下四步查，通常 5 分钟能定位：

1. **Driver 状态**：托盘图标必须显示"正在监听"或"已连接"，左侧模式栏必须停在 Game Sync，不能在 Scenes / 自定义
2. **管理员权限**：右键 Driver → 属性 → 兼容性 → 确认勾了"以管理员身份运行"
3. **杀毒放行**：检查 Windows Defender 事件查看器、360 隔离区、火绒应用控制，把 Blacklyte 目录加入信任
4. **效果映射**：Driver 主界面 → Game Sync → 确认"击杀"事件有绑定效果、强度不是"弱"、灯带没被手动关掉

> [!NOTE]
> 遇到 Vanguard（Valorant 反作弊）或 BattlEye（PUBG、Apex）拦截时，先关 Game Sync 再玩。品牌会在游戏更新后 1~3 天推送 Driver 适配更新，打开 Driver 设置 → 更新 → 手动检查即可。

如果 Game Sync 一直不工作，可以先用 **Screen Sync**（屏幕颜色变化驱动 RGB）或 **Rhythm Sync**（游戏音效驱动 RGB，枪声、爆炸有节奏反馈）代替——这两个功能不需要读游戏内存，反作弊不会拦截，效果稍弱但稳定。

### 二、高度记忆：坐姿站姿一键切换

Atlas 桌有**两套高度预设系统**，理解它们的区别才能用对：

| 系统 | 数量 | 存储位置 | 调用方式 |
|------|------|----------|----------|
| **物理记忆位** | 2 个 | 桌体硬件（断电不丢） | 手控条双击 / Driver 点击 |
| **软件预设** | 无限 | Atlas Driver 软件 | 只有 Driver 能调用 |

日常只用两个物理记忆位就够了——坐姿一个（手肘放桌面时前臂略高 5cm，约 720mm）、站姿一个（桌面在腰臀之间，约 1100~1200mm）。设置推荐用 Driver 软件：左侧点设备卡片 → 拖动高度滑块到精确毫米值 → 点滑块旁的 ⭐ 图标存为预设 1 / 预设 2。比摸手控条长按 2 秒更直观，数值一目了然。

调用时手控条双击上段切预设 1、双击下段切预设 2，或者 Driver 主界面直接点预设卡片。

> [!TIP]
> 物理记忆位存储在桌体硬件里，正常情况断电不丢。只有断电超过 24 小时（内置超级电容耗尽）或恢复出厂设置才会丢失，重设一遍就行。软件预设卸载 Driver 时选"保留配置"也能保住。

### 三、App 首页的三个内容板块：资讯、赛程、活动

Blacklyte App 首页不是通用游戏新闻聚合器，它有自己的内容策略——偏电竞方向、自家活动优先、软营销穿插。三个板块各有分工：

**游戏资讯**板块覆盖 Valorant、LOL、CS2、Dota 2 等竞技项目的赛事报道、版本更新和选手动向，支持收藏、分享、评论，点进资讯在内置浏览器阅读完整文章，部分文章底部会关联自家硬件的评测或使用技巧。

**比赛赛程**板块按时间排序展示近期重要赛事，支持按游戏类型筛选，每场比赛显示时间、对阵双方、赛事名称和直播平台跳转链接，比赛结束后自动更新比分和战报。

**官方活动**板块推送 Blacklyte 自己的活动（LVL UP EXPO 展会、新硬件发布会、用户晒单）和与游戏厂商联合的合作活动（皮肤兑换、内购福利），活动详情页说明参与方式、奖品和截止日期。

首页顶部或"我的"标签里有个显眼的**每日签到**按钮——连续签到 7 天得额外积分，签到后会推送当日精选资讯，跳转阅读又能赚积分，算是资讯和积分的连接点。

### 四、NFC 保修卡绑定：扫一下完成产品登记

从 2025 年下半年起，Blacklyte 每台硬件的包装里都附赠一张 NFC 卡片，两个用途：**注册产品保修**（不用手动输入序列号）和**奖励积分**（Atlas 桌约 1000 分，像素屏约 500 分）。

绑定流程：App → 我的 → 我的产品 → 点右上角 "+" 或 "NFC 绑定" → 把卡片贴近手机背面顶部（感应区）→ 保持 1~2 秒 → 手机震动后 App 自动识别产品型号和序列号 → 确认信息点绑定。成功后"我的产品"列表新增记录，显示保修期限（通常 2 年，购买日起算），积分立即到账。

卡片通常在说明书夹里或硬件本体上贴。如果丢了可以手动输入序列号绑定（Atlas 桌腿内侧、像素屏底部有印），但手动绑定没有积分奖励。每张 NFC 卡片只能绑定一个账号，二手硬件新主人用手动序列号注册即可。
