## ✨ Obtainium：让开源应用自动追新的 Android 更新器

Obtainium 是一款开源的 Android 应用更新工具，核心理念是把应用的发布页面当作应用商店来使用。不同于传统应用商店从自家服务器分发应用，Obtainium 直接追踪 GitHub Releases、GitLab Tag、F-Droid 仓库、APKMirror 页面乃至任意网页上的 APK 下载链接，一旦检测到新版本就自动推送通知，甚至可以在满足条件时静默安装。

对于习惯了在 F-Droid、IzzyOnDroid 等开源社区找应用的用户来说，Obtainium 解决了一个长期痛点：每个应用可能分布在不同平台，逐个手动检查更新既麻烦又容易遗漏。Obtainium 把这些分散的来源统一汇聚到一个界面里，一键扫描全部已跟踪应用的版本状态。

Obtainium 采用 GPL-3.0 协议开源，源码完全透明。它本身不托管任何应用，只负责从你指定的来源页面抓取版本信息和下载链接，权限需求也非常克制——核心只需要网络访问和存储写入，不会读取通讯录、位置等隐私数据。

> [!NOTE]
> Obtainium 支持的 Android 版本跨度较大，主流机型（Android 8.0 及以上）都能正常运行，部分旧版设备可能需要注意 CPU 架构匹配。

## 🔧 安装步骤与注意事项

Obtainium 提供两种主流安装渠道，各有侧重：从 GitHub Releases 页面直接下载 APK，或者通过 F-Droid 客户端安装。两者功能一致，但 F-Droid 版的签名与 GitHub 版不同，升级时需要先卸载旧版。

### 从 APK 直接安装

1. 在浏览器打开下载页，找到最新版本的 APK 文件链接。Obtainium 的发布页通常同时提供多个架构版本——arm64-v8a、armeabi-v7a、x86_64，根据你的设备选择对应的架构。不确定的话可以优先下载通用版（universal），体积稍大但兼容性最好。

2. 下载完成后打开 APK，Android 系统会弹出安全提示，需要手动授权未知来源安装。进入系统设置 → 安全 → 安装未知应用，允许当前浏览器或文件管理器安装应用即可。不同厂商的 Android 定制系统在设置路径上略有差异（小米、OPPO、vivo 等品牌可能在权限管理里），找不到的话可以直接在设置搜索栏搜"未知来源"。

> [!WARNING]
> 从第三方来源安装应用时，建议先核对 APK 的签名指纹或文件哈希，确保没有被篡改。Obtainium 官方发布页通常会同步提供 SHA-256 校验值。

3. 点击安装按钮，等待几秒完成。首次启动时 Obtainium 会请求存储访问权限和后台运行权限，全部授予即可正常使用。

### F-Droid 版安装

如果你已经在用 F-Droid 客户端，直接在搜索框输入 "Obtainium"，找到后点击安装。F-Droid 版的好处是自带自动更新机制，Obtainium 自身的新版本也能通过 F-Droid 通道推送，不需要手动去 GitHub 检查。

### 版本兼容提示

| 渠道 | 包名 | 签名 | 能否与另一版并存 |
|------|------|------|------------------|
| GitHub Releases | dev.imranr.obtainium | GitHub 签名 | 否，需卸载后换装 |
| F-Droid | dev.imranr.obtainium.fdroid | F-Droid 签名 | 否，需卸载后换装 |

两种渠道的 Obtainium 包名不同，但签名也不同，因此不能直接覆盖升级。如果之前装了一个版本想换另一个渠道的，必须先卸载再装。应用列表的配置数据可以通过导出功能先保存，换版后再导入恢复。

## 📖 使用入门：从零搭建你的追新清单

装好 Obtainium 之后，第一件事应该是**把 Obtainium 自己加进跟踪列表**，这样后续有新版本发布时它会自己提醒自己更新，形成闭环。

### 界面总览

打开 Obtainium 后，底部有四个标签页：**应用列表**、**添加应用**、**更新队列**、**设置**。应用列表页显示所有已跟踪的应用，每一行展示应用图标、当前版本和最新版本号，有更新的会高亮显示版本差。点击应用名称进入详情页，可以查看版本历史、更新日志和下载源配置。

### 添加应用：从一个链接开始

添加应用是 Obtainium 的核心操作，支持多种来源类型，最常用的几种：

**GitHub 源**——粘贴任意 GitHub 仓库的 URL（`https://github.com/用户名/仓库名`），Obtainium 会自动识别并进入发布页抓取最新标签。默认取最新的 Release 资产，也可以手动指定排序方式（按标签名、按发布时间），或者过滤特定架构的 APK 文件。如果遇到 GitHub API 请求额度耗尽（未登录状态约每小时 60 次），可以在设置里配置个人访问令牌，额度会提升到每小时 5000 次。

**GitLab 源**——与 GitHub 源类似，粘贴 GitLab 项目 URL 即可。建议配置 read_api 权限的访问令牌，否则部分私有仓库或大仓库的版本信息可能抓不到。

**F-Droid 与 IzzyOnDroid 源**——直接按应用名称搜索，Obtainium 会去对应的仓库索引里匹配。F-Droid 签名的应用与 GitHub 签名的应用即使是同一个软件，在 Obtainium 里也会被识别为不同的跟踪条目，注意区分。

**HTML 兜底源**——这是 Obtainium 最灵活也最强大的功能。任何一个网页，只要里面有 APK 下载链接，你都可以把这个页面的 URL 丢给 Obtainium，让它从 HTML 里自动提取。配置时需要填写两个关键信息：一是"版本提取正则"，告诉 Obtainium 怎么从页面文本里解析出版本号；二是"APK 链接正则"，定位到下载按钮的 URL。进阶设置里还有"中间链接"参数，适用于点击下载按钮后先跳到一个跳转页、再生成真实下载地址的场景。

> [!TIP]
> HTML 源的正则写不好时，可以先去 Obtainium 的众包配置库（社区共享的配置集合）里查有没有现成的。很多热门应用已经有社区成员提交过经过验证的正则，直接套用即可省去手动调试的时间。

**国内商店源**——Obtainium 对国内主流应用商店做了适配，包括应用宝、酷安、vivo 应用商店、华为应用市场。添加时选择对应的商店源，输入应用名称或商店页面 URL，Obtainium 会在该商店内搜索并跟踪版本更新。需要注意的是，不同商店的版本号格式有时不统一（有的用日期、有的用递增数字），遇到版本检测失灵时可以在应用详情页手动触发强制刷新。

### 进阶配置：让更新自动化

添加应用时或之后进入应用详情页，可以配置不少个性化选项：

- **仅跟踪**模式：只监测版本变化不下载安装，适合只想知道有没有新版本但不想自动下载的场景。
- **正则筛包**：当一个发布页有多个 APK（不同架构、不同功能变体）时，用正则精确匹配你想要的那一个，比如只拿 arm64 架构的标准版。
- **架构筛选**：根据设备 CPU 架构自动过滤不适用的 APK，避免下错包。
- **通知开关**：可以单独关闭某个应用的更新通知，适合不想被频繁打扰但又想保留跟踪的应用。

### 后台更新与静默安装

Obtainium 默认只在你手动打开时检查更新，想让它在后台自动跑需要配置 WorkManager 或前台服务。进入设置 → 后台更新机制，选择合适的运行模式，然后设置更新检查间隔（最小 1 小时）和约束条件（仅 Wi-Fi 下、充电时等）。

如果希望下载完成后自动安装而不是弹出安装界面，需要满足"静默安装"的前提条件。最简单的方式是配置 Shizuku——一个免 root 的 Android 提权工具，通过 ADB 授权后 Obtainium 就能获得安装权限，实现后台无感更新。已 root 的设备则可以直接启用 Root 安装器，更直接也更稳定。

> [!NOTE]
> 即使不配置静默安装，Obtainium 也会在更新可用时发送系统通知，点击通知就能跳转到下载界面手动安装，体验也不差。静默安装只是锦上添花的便利功能。

### 批量管理：高效维护你的应用清单

跟踪的应用多了之后，批量管理功能就很重要。Obtainium 支持：

- **导入导出配置**：应用列表可以导出为 JSON 文件备份，换手机或重装系统后一键恢复。设置里有"自动导出"选项，开启后每次改动都会自动保存到指定路径。
- **分类与筛选**：可以给应用打标签分类（比如"日常"、"工具"、"测试版"），列表页按分类分组显示，也能按筛选条件快速定位。
- **批量导入应用**：准备一个纯文本文件，每行一个应用的源链接，Obtainium 可以一次性批量添加。

### 外观与主题

Obtainium 原生支持深色模式，在设置 → 外观里可以跟随系统或手动切换。Android 12 及以上设备还支持 Material You 动态取色，应用图标和主题色会根据壁纸自动适配。语言方面支持简体中文，装好后在设置里切换到中文界面即可。
