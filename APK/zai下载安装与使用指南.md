## ✨ ZAI 是什么：一款基于双向同意的实时位置共享应用

ZAI 是一款主打**双向同意**的实时位置共享应用，核心定位就是让两个人在地图上互相看到对方的位置。与市面上那种偏向「单方面查岗」的工具不同，ZAI 从产品设计上就把「双方都装、双方都同意」定为铁律——只有两个人都完成安装、互加好友、各自搞定手机权限和后台保活，地图上才会同时出现彼此的头像和位置。

这种双向机制不是体验短板，反而是它的边界：一方面避开了「未经同意获取他人行踪」的法律和伦理风险，另一方面也让定位可靠性建立在双方各自把手机设置好的前提上，而不是指望一方远程操控另一方的设备。

ZAI 的免费版本就已经覆盖了核心需求——实时位置双向共享、好友聊天、查看电量和地址、基础地图，这些都不需要花钱。会员解锁的主要是历史轨迹回溯、到达离开提醒和去广告，但官方明确说过：**买不买会员都不影响定位成功率**，不充值也不会让位置更新变慢或变差。

除了实时位置，ZAI 把「远程查电量」做成了另一个高频核心功能。好友的电量百分比直接显示在地图头像和好友卡片上，你不用开口问对方还剩多少电，看一眼地图就知道。这个小设计在出行守护、解释「没回消息」、判断位置停更原因等场景下都特别实用。

> [!NOTE]
> ZAI 不是监控工具，它的定位是朋友、家人之间的位置互看。装之前先想清楚：你看到对方的同时，对方也能看到你。

## 🔧 ZAI 安装步骤：优先商店渠道，避免老版本踩坑

### 安卓设备

1. **打开应用商店**（应用宝 / 小米商店 / 360 应用任选其一），搜索「ZAI」。
2. **核对应用信息**：确认包名与作者一致，应用宝当前版本为 **v2.4.9**（2026 年 1 月更新），评分 4.9。
3. **点击安装**，等待下载完成后自动安装。
4. **首次打开**，按应用内指引完成定位权限授权。

> [!WARNING]
> 不要随便装第三方 APK 历史版本。网上流传的老版本（如本站采集样本 v1.0.3，约 25MB，2020 年前后）包名与官方商店不一致，且缺少后台定位、英文支持等大量后续修复。位置共享应用的后台能力高度依赖版本迭代——装老版本等于主动继承老问题，位置不更新时先确认自己是不是装了旧包。

### iPhone 设备

1. **打开 App Store**，搜索「ZAI」。
2. **核对版本要求**：需 iOS 14.0 或更高。
3. **点击获取**，Face ID / Touch ID 确认后自动下载安装。
4. **首次打开**，允许定位权限，并在系统设置里额外开启「运动与健身」权限（ZAI 的后台定位依赖这个开关）。

### 电脑上能不能用

可以。通过**应用宝电脑版**在电脑上运行安卓版，适合不方便看手机的场景使用。不过电脑端本质上还是跑安卓版，功能与手机端一致，不做额外适配。

## 📖 ZAI 使用入门：从安装到互看位置的完整路径

### 第一步：注册与登录

首次打开应用，用手机号一键注册登录即可。不需要邮箱验证也不需要填复杂资料，注册完就能开始加好友。

### 第二步：添加好友（必须双向确认）

ZAI 的位置共享**不是单方面的**，加好友这一步必须双方都完成：

1. 在应用里通过手机号或昵称搜索对方，发送好友申请。
2. 对方在自己手机上的 ZAI 里**确认接受**申请——单方添加不算数。
3. 双方都确认后，好友关系正式建立。

> [!TIP]
> 如果加了好友但地图上还是一片空白，先确认：**对方手机上是不是真的装了 ZAI？是不是也接受了你的申请？** ZAI 最常见的「位置不显示」原因就是这两条之一。

### 第三步：后台保活（最容易翻车的环节）

位置共享要持续更新，应用必须在后台保持活跃。这是很多人设置完权限就忘了的一步，也是位置不更新的头号原因。

**安卓端**：
- 打开**自启动**权限（各品牌手机在设置 → 应用管理 → ZAI → 自启动里找）
- 把 ZAI 加到**省电白名单**里，不要让系统在低电量时杀掉
- 最近任务界面**锁定** ZAI（下拉卡片或点锁定图标，不同品牌操作略不同）

**iPhone 端**：
- 系统设置 → ZAI → 定位 → 选择「**始终**」（不是「使用应用时」）
- 关闭低电量模式（低电量模式下系统会收紧后台刷新）

### 第四步：核心功能上手

#### 实时位置互看

这是 ZAI 最核心的能力。完成上述步骤后，打开地图就能看到已添加好友的实时位置，对方同时也能看到你。位置随对方手机的移动实时更新。

#### 远程查电量

好友的电量百分比直接显示在地图头像和好友卡片上，并且会随位置一起更新。这个功能的三种高频用法：

| 场景 | 具体做法 |
| --- | --- |
| 出行守护 | 孩子放学路上电量见底，提前提醒充电，避免真正需要联系时失联 |
| 解释「没回消息」 | 对方 5% 电量又关机失联时，你提前就知道该打TA身边人的电话，而不是干等 |
| 判断位置停更原因 | 位置不更新 + 电量归零 = 多半是没电关机，不是设置问题 |

还可以在好友卡片上发**提醒操作**，给对方手机发一个提示音——低电量时这招尤其管用。
