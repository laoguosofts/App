## ✨ K2er 是什么——把手柄和键鼠接进安卓游戏

K2er 是一款面向安卓平台的**外设映射工具**，核心作用是把手柄按钮与摇杆、键盘按键、鼠标点击与滑动，直接对应到手机屏幕上的触控区域。它不是模拟器，也不走虚拟化路线——安装好之后，你用 Xbox、PlayStation、Switch Pro 等主流手柄，或者任意 USB 键鼠，就能像在主机和 PC 上那样操作手游。

四个核心卖点覆盖的都是玩家真痛点：**外设映射**（键鼠/手柄直接接游戏）、**高级宏**（组合键一次触发、轮转切换、循环执行）、**场景配置文件**（每个游戏、每个模式独立一套键位，可导出分享）、**原生兼容性**（走安卓辅助功能服务，不改游戏进程、不克隆 App）。FPS 射击、MOBA 竞技、赛车驾驶、动作 RPG、格斗对战，K2er 的映射能力理论上覆盖所有安卓游戏类型——甚至不限于游戏，电子书翻页、视频播放控制这些触屏场景也能接管。

和市面上常见的模拟器、App 克隆、输入法劫持方案相比，K2er 走的是另一条路：通过安卓系统内置的辅助功能服务（Accessibility Service），在后台监听外设输入，然后向屏幕指定坐标发送标准的触控事件。游戏接收到的就是和手指完全一样的点击与滑动信号，签名、包名、进程结构都没有被改动，反作弊检测到的概率自然低得多。延迟表现也更好——不经过虚拟机中转，辅助功能 API 响应在几毫秒以内，键鼠和触屏原生手感之间的差异几乎感觉不出来。

> [!NOTE]
> 辅助功能服务是 Google 官方提供的无障碍接口，初衷是帮助行动不便的用户使用手机。K2er 只是把这个系统级接口用在了外设映射上，完全合法合规，不涉及任何破解或注入行为。

适合谁用？首先是 FPS / MOBA 玩家——触屏瞄准和放技能始终不如键鼠稳定；其次是赛车和动作 RPG 玩家，手柄摇杆的线性控制比触屏虚拟摇杆顺滑得多；还有喜欢躺着玩的休闲游戏玩家，手柄替代触屏操作体验提升明显。

## 🔧 K2er 安装步骤——权限配置是关键一环

K2er 的安装本身不复杂，但首次安装后必须正确配置辅助功能权限，否则外设插上去没有任何反应。

### 下载与安装包核验

1. 通过下载页获取安装包，建议核对文件大小和版本号是否与页面标注一致
2. 安卓平台首次安装非应用商店来源的 APK 时，系统会弹出「未知来源」提示——允许后即可继续
3. 部分手机（小米、红米、黑鲨等）在安装完成后还需要额外的权限设置，详见下文

### 开启辅助功能权限（必须步骤）

这一步是 K2er 能否正常工作的前提：

1. 打开手机「设置」→「辅助功能」或「无障碍」
2. 在已安装服务列表中找到 K2er，点击进入
3. 打开开关，系统会弹出权限说明，确认后授权

> [!TIP]
> 如果在辅助功能列表里找不到 K2er，通常是安装没成功或者手机系统做了深度定制把入口藏起来了——小米/红米用户去「更多设置 → 无障碍」找，ColorOS 用户去「设置 → 系统设置 → 无障碍」找。

### 连接外设

- **手柄**：支持蓝牙或 USB 直连。蓝牙手柄用手机蓝牙配对即可；有线手柄用 OTG 转接头连接手机
- **键鼠**：USB 键鼠通过 OTG 转接头连接，多数情况下系统自动识别，K2er 无需额外驱动
- **多设备同时工作**：手柄 + 鼠标、键盘 + 鼠标 + 手柄可以同时接入，各按键独立映射互不冲突

### 安装后的首次检查

安装并授权完成后，建议做一次快速自检：

1. 打开 K2er 悬浮窗，确认辅助功能状态显示为「已开启」
2. 连上手柄或键鼠，在悬浮窗的外设列表里能看到设备名称
3. 进一款游戏试试——如果按键没反应，大概率是辅助功能没开对，回到设置里重新确认

## 📖 K2er 使用入门——从零配置到流畅上手

安装和权限搞定之后，接下来就是具体的键位配置。K2er 的功能模块很多，从基础的十字键到进阶的宏和场景切换，逐步深入才能发挥它的全部潜力。

### 核心功能模块一览

| 功能模块 | 适用场景 | 配置要点 |
| --- | --- | --- |
| 十字键 | WASD 键盘移动 | 放置在游戏虚拟摇杆中心、调匹配的半径、绑定 Shift 做奔跑切换 |
| 瞄准摇杆 | FPS/TPS 视角控制 | 绑定手柄右摇杆或鼠标移动、调边界和死区防止漂移 |
| 宏 | 连招、轮转状态、循环执行 | 录制操作序列、设置精确延迟、绑定快捷键触发 |
| 场景配置 | 同一游戏的不同模式 | 创建独立配置文件、切换时一键加载 |
| 死区调整 | 摇杆漂移（镜头自动转） | 每个摇杆映射单独调、8-20% 范围视漂移程度而定 |

### 基础十字键配置——WASD 模拟虚拟摇杆

十字键是键盘玩家移动的核心，用四个快捷键分别对应上下左右，同时按下产生对角移动。配置步骤：

1. K2er 悬浮窗 → 编辑键位 → 添加「十字键」
2. **放置位置**：拖到游戏虚拟摇杆的**中心位置**（左下通常是移动摇杆）
3. **录入四个快捷键**：分别按下 W、A、S、D（或方向键）
4. **调半径**：让虚拟摇杆的滑动范围匹配游戏中虚拟摇杆的视觉大小——数值大→移动快方向灵敏，数值小→精确但慢，一般设为视觉大小的 1.5-2 倍
5. **设置奔跑切换（可选）**：绑定 Shift 做「更改半径快捷键」，开启「长按以更改」后，正常按 WASD 是大半径奔跑，按住 Shift + WASD 是小半径慢走精确控制

> [!WARNING]
> 十字键的半径和释放延迟影响手感很大——释放延迟设为 0 是松开立即停（干脆），设 100-200ms 有滑行缓冲（模拟惯性）。初次配置建议先从 0 开始，根据游戏体验微调。

### 瞄准与鼠标——FPS 射击游戏的命脉

FPS 游戏里瞄准是最考验映射精度的部分。K2er 的鼠标控制核心参数：

- **边界**：瞄准摇杆的可移动范围，太大可能导致光标飞出屏幕，太小则转动不够灵活
- **死区**：摇杆归中时的偏移容忍度，死区太小会有漂移（镜头自己慢慢转），太大则轻推没反应
- **归中模式**：停止推动后摇杆自动回到中心，对于 FPS 瞄准这个功能通常关闭更自然

| 漂移程度 | 推荐死区 | 验证方法 |
| --- | --- | --- |
| 轻微（镜头慢慢转） | 8-12% | 完全松开摇杆等 5-10 秒，视角不动即可 |
| 中度（镜头较快转） | 12-18% | 轻推摇杆 10-15% 能立即响应 |
| 严重（镜头快速转） | 15-20% | 猛推时视角快速无延迟转动 |

> [!NOTE]
> 每个摇杆映射的死区是**独立**的——瞄准摇杆（FPS 视角）、移动摇杆（十字键）、MOBA 技能摇杆都要分别检查和调整，调好一个不代表其他都对。

### 宏功能——进阶玩家的效率神器

宏是 K2er 进阶玩法的灵魂，可以把多个操作打包成一个快捷键：

- **录制组合键**：把一串操作录下来，按一下触发完整序列——比如 MOBA 里一键释放三个技能
- **轮转状态**：同一个快捷键按第一次触发一套命令，按第二次触发另一套，循环切换——比如开背包 / 关背包、切换武器 1 / 武器 2
- **循环执行**：按住快捷键自动循环一串命令——比如持续按住某个技能键
- **延迟控制**：每个命令之间设置毫秒级精确延迟，适合帧敏感的格斗游戏连招

宏的配置需要在游戏里实际录制，录制时注意游戏的实际响应节奏来设置延迟，不要一味追求快——太快了游戏接收不到完整的点击序列。

### 场景配置文件——一套键位走天下

不同游戏、同一款游戏的不同模式对键位的需求完全不一样。K2er 支持为每个游戏创建独立的映射配置，同一游戏内还能按场景拆分——比如 GTA 里上车和下车是两套不同配置。配置可以保存、导出、分享，换设备也不怕丢。

实际操作中建议的命名规则：`游戏名-场景名-外设类型`，比如 `GTA-步行-键鼠`、`GTA-驾驶-手柄`，方便日后维护和切换。

### 常见问题与排障

**摇杆漂移**：99% 的情况是摇杆硬件有轻微漂移，调大对应映射键的死区即可解决。如果死区调到 20% 以上还是漂移，大概率是硬件漂移太严重，建议换手柄试试。

**小米 / 红米 / 黑鲨手机外设无反应**：这些品牌对后台服务限制较严，除了辅助功能权限外，还需要在电池管理里把 K2er 设为「无限制」，在自启动管理里允许自启动，避免系统清理后台时把 K2er 杀掉。

**十字键漂移**：如果不是手柄摇杆而是键盘十字键导致视角自动移动，检查是不是键盘某个键卡住了（打开记事本按 WASD 看能不能正常输入），或者删掉十字键重新添加一次。

**安装包来源疑问**：优先通过官方下载入口获取，核对版本号和文件大小；不要从第三方不明来源下载，避免安装包被改动。
