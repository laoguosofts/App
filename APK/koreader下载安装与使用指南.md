## ✨ KOReader：墨水屏设备上的全能开源阅读器

KOReader 是一款专为电子墨水屏设备打造的开源电子书阅读器，从 2012 年开始持续迭代至今。它的核心价值很简单：让 Kobo、PocketBook、reMarkable、Kindle 乃至 Android 平板和 Linux 桌面这些不同形态的设备，都能用同一套深度可调的阅读体验打开几乎所有主流电子书格式。

和系统自带阅读器相比，KOReader 的优势集中在几个关键维度上：格式覆盖上，EPUB、MOBI、PDF、DjVu、CBZ/CBR、FB2、DOCX、Markdown 统统支持，连漫画和文献论文都能流畅处理；排版上，内置的 CRE 流式重排引擎允许逐像素调节字号、字体、行距、边距，甚至深入 CSS 层面微调标题和引文样式，这在墨水屏上直接决定了眼睛疲劳度；设备生态上，除了 Kindle 因系统封闭需要越狱，其他主流墨水屏设备都有原生安装包，reMarkable 2 甚至需要 KOReader 才能摆脱原生写作板的定位，变身真正的阅读器。

KOReader 完全免费开源，无内购、无广告、无账号绑定。安装包体积通常在 40MB 以内，即使是内存紧张的老设备也能流畅运行。对于已经在用墨水屏设备的用户来说，装上 KOReader 往往是买回来之后第一件值得折腾的事。

## 🔧 安装指南：按设备平台选对安装包

KOReader 覆盖的平台非常广，不同设备的安装流程差异也比较大。下面按主流平台分别说明，你只要对号入座就行。

### Android / 安卓墨水屏设备

Android 是 KOReader 生态最完善的平台之一，绝大多数墨水屏安卓设备（文石、掌阅、墨案等）都可以直接安装。

1. 在应用商店（Google Play 或国内安卓应用市场）搜索 KOReader 下载安装
2. 如果通过 APK 安装包手动安装，需要在系统设置中开启「未知来源应用」或「允许此来源安装」权限
3. 安装完成后首次启动，系统可能会弹出存储权限请求，务必授予，否则 KOReader 无法扫描本地书籍

> [!TIP]
> Android 11 及以上版本的分区存储机制（Scoped Storage）对文件访问做了限制。如果 KOReader 无法显示书库，检查应用的存储权限是否开启了「所有文件访问」，而不是默认的「仅媒体文件」。

### Kobo / PocketBook 专用设备

这两类墨水屏设备都有成熟的社区安装方案。

- **Kobo**：需要先安装 NickelMenu 或 KOLauncher 这类第三方启动器，再把 KOReader 的 Kobo 专用包（`.kobo.zip`）复制到设备根目录，重启后由启动器扫描添加。
- **PocketBook**：相对简单，将 `.pbz` 安装包放入设备系统目录，在设备的「应用」或「程序」菜单中找到并安装即可。

> [!WARNING]
> Kobo 设备安装第三方应用后，官方系统更新可能会覆盖 KOReader。每次系统大版本升级后记得重新检查 KOReader 是否正常启动。

### reMarkable 写作板

reMarkable 原生系统定位是电子写作板，不支持第三方应用直接安装，但通过社区工具 Toltec 可以安装 KOReader，把写作板变成强大的阅读器。

安装前先确认你的 reMarkable 型号：

| 设备型号 | 推荐安装包 | 体积 |
|---|---|---|
| reMarkable 2 / Paper Pro / Paper Pure | koreader-remarkable-aarch64-*.zip | 39.9 MB |
| reMarkable 1 / 老款通用架构 | koreader-remarkable-*.zip | 38.6 MB |

Paper Pro 和 Paper Pure 使用 aarch64 架构，必须选带 `-aarch64-` 的包，否则启动会直接崩溃。安装流程：USB 连接设备 → 复制安装包到应用目录 → 安装 Toltec 启动器 → 从启动器菜单打开 KOReader。整个过程不会影响 reMarkable 原生的写作和笔记功能，两个系统可以独立切换使用。

### Linux 桌面

KOReader 在 Linux 上有四种发行格式可选，操作复杂度和自动更新能力各有取舍：

| 发行格式 | 适合场景 | 自动更新 | 卸载难度 |
|---|---|---|---|
| **AppImage**（推荐） | 试用、便携、不想管包管理器 | 需手动换包 | 删文件即可 |
| deb 包 | Debian / Ubuntu 长期固定安装 | 需手动换包 | apt remove |
| Flatpak | 任何发行版、偏好自动更新 | 随 Flatpak 商店自动更新 | flatpak uninstall |
| tar.xz 便携包 | 不想装 AppImage 也不想用包管理器 | 需手动换包 | 删目录即可 |

AppImage 是最省心的选择：下载后 `chmod +x` 赋予执行权限，直接 `./koreader-xxx.AppImage` 就能跑，不写入系统目录。Flatpak 适合长期使用，装完之后随系统 Flatpak 商店自动更新，还自带沙箱隔离。

> [!NOTE]
> Linux 桌面安装 KOReader 后，强烈建议配合 calibre 使用——KOReader 可以作为 calibre 的无线设备直接收书，calibre 也能检索 KOReader 书库的元数据，OPDS 协议浏览 calibre 书库更是无缝。

### Windows / macOS

KOReader 没有 Windows 或 macOS 的官方正式版本。Windows 用户如果想在电脑上体验排版效果，可以用 Android 模拟器侧载 KOReader 的 APK；macOS 上需要克隆源码并编译开发者模拟器版本，适合有开发基础的用户。

## 📖 使用入门：从打开第一本书开始

安装完成、打开 KOReader 之后，你会发现它的界面设计完全服务于墨水屏设备——没有花哨的图标和动画，菜单层级扁平，所有阅读相关的操作都在阅读界面的屏幕边缘或底部就能呼出。下面从排版、漫画、PDF 三个最常用的场景切入，带你快速上手。

### 排版：墨水屏阅读体验的命脉

墨水屏上排版不是锦上添花，而是直接决定能不能长时间舒服地看书。KOReader 的双引擎架构按文件类型自动选择渲染方式：

- **CRE 流式重排引擎**：EPUB、MOBI、FB2、DOCX、Markdown 等流式格式都走这个引擎，打开后立即按你的设置重排，改字号、字体、边距全文即刻重绘
- **固定版式引擎**：PDF、DjVu、XPS、CBZ 等固定版式格式用这个引擎，版式精确但默认不能自由排版（可以通过 K2pdfopt 重排引擎转为流式）

在阅读界面点击屏幕底部即可唤出排版菜单，几乎所有参数都能独立调节：字号从 12px 到 48px、字重支持标准/粗体/特粗或百分比微调、字符间距 0% 到 ±50%、行距 1.0 到 3.0 倍、上下左右四边页边距独立可调、支持单栏/双栏/自动（屏幕宽时自动双栏）。调整完一本之后，可以单独保存为这本书的专属设置，也可以存为全局默认让所有书套用——KOReader 还提供「配置文件」功能，按书类（小说 / 论文 / 漫画）自动切换整套排版方案。

如果内置的排版微调还不够，KOReader 还有样式微调工具可以深入 CSS 层面：修改 `<h1>`/`<h2>` 标题样式、调整段落 `line-height` 和 `text-indent`、自定义块级引用的缩进和边框、隐藏或显示特定元素、调整图像大小和对齐方式。这对有 CSS 基础的用户来说相当于打开了一扇自定义大门。

多语言连字符词典是 KOReader 被低估的一个细节。内置十几种语言的断行词典，中英文混排时会自动选择正确的断行规则，解决了许多其他阅读器"中文断行生硬、英文单词被截断"的老问题。

### 漫画模式：把 CBZ/CBR 读得明明白白

除了纯文字电子书，KOReader 也是一款成熟的漫画阅读器。原生支持 CBZ（ZIP 格式）和 CBR（RAR 格式），把漫画文件放进设备书库，KOReader 会自动识别并开启漫画优化设置。

漫画和普通书最大的区别有两个：**翻页方向**和**分镜阅读**。翻页方向上，日系漫画默认从右到左翻（像原版杂志那样），美漫欧漫从左到右，KOReader 默认自动识别，但在「漫画设置」中可以手动指定。分镜阅读是 KOReader 的特色功能：自动识别漫画页面上的分镜格，放大到一个分镜的尺寸，翻页时自动跳到下一个分镜——避免了"看一半分镜、另一半还在屏幕外"的尴尬场景。自动识别不准时也可以手动创建区块：长按漫画 → 选择「创建区块」 → 框选每个分镜格。

墨水屏刷新率是漫画阅读的另一个痛点。KOReader 允许在漫画章节使用独立的刷新频率：文字书用全刷保证干净，漫画用较快刷新 + 少量残影来提升翻页速度。图像预处理工具也会自动启用，把彩漫转为干净的黑白线条、调整亮度对比度让墨迹锐利、按设备分辨率匹配图片尺寸。

| 维度 | 漫画模式 | 普通固定版式显示 |
|---|---|---|
| 自动区块识别 | ✅ 逐格放大阅读 | ❌ 整页显示 |
| 翻页方向 | 可设左右 | 只能左翻 |
| 图像预处理 | ✅ 自动 | ❌ 需手动 |
| 刷新频率 | 可调 | 固定 |

### PDF 与文献阅读

KOReader 处理 PDF 的核心工具是 K2pdfopt 重排引擎——可以把固定版式的 PDF 重新排成适合墨水屏的流式文本，字号、行距、边距按你的排版设置即时生效。这对论文、技术文档、扫描版 PDF 特别有用，不再需要来回翻页定位。

裁边和旋转功能在 PDF 阅读中也很常用：裁边可以去掉论文页脚的页码和章节号，让正文占满整个墨水屏；扫描版 PDF 如果有轻微歪斜，用矫正功能一键拉正。这些都不需要把 PDF 转成其他格式，在 KOReader 内部就能完成。

### 其他值得一提的功能

- **词典和百科**：长按单词直接查词，内置多语言词典系统，也可以调用维基百科等在线百科
- **笔记和高亮**：支持高亮、下划线、波浪线、手绘标注，笔记可以导出为 Markdown 或 HTML
- **OPDS 浏览**：可以作为 OPDS 客户端浏览 calibre 或其他 OPDS 服务器上的书库，无线收书
- **夜间模式与色温调节**：墨水屏也有夜间模式，可以降低背光亮度或切换反色显示
- **OTA 自更新**：在应用内的「更新」入口直接检测并升级到最新版本
