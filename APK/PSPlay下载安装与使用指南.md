## ✨ PSPlay 是什么

PSPlay 是一款第三方 Remote Play 客户端，让你在 Android 设备（手机或平板）上远程游玩自己的 PS4 / PS5 主机。它不是官方应用，但在兼容性和灵活性上做得不错——支持手动注册主机、自定义分辨率和码率、60fps 串流等官方客户端没有的选项。

简单说就是：主机放家里开着待机模式，你在外面掏出手机，通过 PSPlay 连上家里的 PS4/PS5，就能像坐在客厅一样玩游戏。对于通勤碎片时间想摸两把、或者不想独占大电视的玩家来说，这个方案挺实用。

不过有几点需要提前有预期：远程串流的体验受网络条件影响很大，局域网内一般没问题，公网远程则要看你家的上行带宽、NAT 类型、手机侧信号等一连串因素。PSPlay 本身不做什么加速魔法，它只是把 Remote Play 协议做得更可配置。

## 🔧 安装与主机绑定

### 手机端安装

Android 用户拿到 APK 后，首次安装需要在系统设置里允许「未知来源应用」。各品牌手机路径略有差异：小米在「设置 → 隐私保护 → 特殊权限设置 → 安装未知应用」，华为在「设置 → 安全 → 更多安全设置 → 安装未知应用」，找到对应文件管理器或浏览器，打开允许开关即可。

> [!WARNING]
> 安装完成后建议回到系统设置把「未知来源」关掉，日常保持关闭更安全。

iOS 侧因为没有侧载便利，一般走 TestFlight 渠道，在 App Store 搜 PSPlay 通常找不到——需要关注社区或官方渠道获取 TestFlight 邀请链接。

### 主机端前置设置

主机端有几个开关必须打开，否则 PSPlay 连不上：

1. 进入主机「设定 → 系统 → 远程游玩」，确保主开关已打开
2. 确认主机和路由器用网线连接（无线也行但稳定性差一截）
3. 主机登录常用的 PSN 账号，记下 Online-ID（公开昵称，不是邮箱）
4. 主机保持开机或待机——**待机模式下远程游玩默认是关闭的**，需要在「设定 → 系统 → 省电 → 待机模式下的功能」里把「保持与互联网连接」勾上

### 两种注册方式

PSPlay 注册主机有两种路：

| 方式 | 是否需要 PSN 账号 | 自动远程 | 适用场景 |
| --- | --- | --- | --- |
| 自动注册 | 需要在 PSPlay 里登录 | 支持（靠 PSN 关联公网主机） | 不想折腾路由器端口的用户 |
| 手动注册 | 不需要 | 不支持，需手动端口转发 | 低固件 PS4 / 不想在第三方输账号密码 |

手动注册的关键是拿到主机的 Online-ID，在 PSPlay 注册界面输入完 8 位注册码后，勾选「Register console manually」复选框，再填 Online-ID 和固件版本，三者匹配就能注册成功。固件版本务必选主机的实际版本——早期 PS4 固件（5.05、6.72 这类破解常见版本）下拉项里都有对应选项，选高了反而注册失败。

> [!TIP]
> 手动注册后自动远程连接不可用，想从外网连回家需要配置路由器端口转发。五个端口分别是：9302/UDP（PS5）、987/UDP（PS4）、9295/UDP+TCP、9296/UDP、9297/UDP——全部映射到主机的内网 IP。

## 📖 使用入门

### 第一次连上之后

注册成功、Local Connect 按钮变绿之后，点进去就是串流画面了。第一次连接会用默认的流媒体设置跑，画面和延迟可能不是最优——建议连上之后立刻进档案设置里调参数。

### 分辨率、帧率、码率怎么调

这三个参数是影响画面质量和流畅度的核心。

**帧率**：30fps 是稳，60fps 是丝滑。动作游戏、赛车、格斗和射击游戏值得开 60fps，但设备发热会明显、带宽占用也翻倍。RPG、策略、回合制 30fps 足够，而且长时间玩下来设备更稳。

**码率**：直接影响画面细节和抗马赛克能力。PSPlay 提供 2–50 Mbps 的滑块范围，不要盲拉满——超过主机编码能力或网络承载能力的设置，画面反而会因为丢包出现花屏。推荐从分辨率对应的中间值开始，逐步往上试探：

| 分辨率 | 30fps 推荐 | 60fps 推荐 |
| --- | --- | --- |
| 540p | 2–4 Mbps | 3–5 Mbps |
| 720p | 4–8 Mbps | 6–10 Mbps |
| 1080p | 8–15 Mbps | 10–20 Mbps |

> [!NOTE]
> 帧率和码率不是独立的。同样 10 Mbps，30fps 的单帧画质明显比 60fps 好——60fps 每秒传的数据量是两倍。网络条件有限时，**优先牺牲帧率保住码率**，画面糊掉比运动卡顿的体验更差。

用手机流量远程串流的用户还要注意流量消耗：5 Mbps 大约是每小时 2.25 GB，10 Mbps 就是 4.5 GB，一整天跑下来很容易超套餐阈值。

### NAT 类型：远程连不上的头号元凶

很多人 Local Connect 没问题、Remote Connect 永远超时，查下来都是 NAT 类型的问题。主机在「设定 → 网络 → 查看连接状态」里能看到 NAT 类型：

| NAT 类型 | 远程兼容性 |
| --- | --- |
| Type 1 | 完美 |
| Type 2 | 良好 |
| Type 3 | 较差——自动远程通常失败 |

Type 3 最常见的原因是运营商没给你公网 IPv4 地址，你被放在 CGNAT（运营商级 NAT）后面了。确认方法：主机显示的内网 IP、手机访问 whatsmyip.org 看到的公网 IP、路由器 WAN 口 IP——如果 whatsmyip 和路由器 WAN 口不一样，就说明在 CGNAT 后面。

解决路径按成本从低到高排：

1. **打运营商客服申请公网 IP**（最推荐）——电信 10000、移动 10086、联通 10010，话术参考「我家宽带 NAT 类型是 3，影响游戏远程串流，能不能帮我分配一个公网 IPv4」。多数地区免费给，部分需要营业厅办理
2. **已有公网 IP 但 NAT 还是 3**——检查路由器端口转发配置，五个端口有没有全部映射到位
3. **运营商死活不给**——用内网穿透工具兜底，ZeroTier 或 Tailscale 是最省心的方案，两端都装客户端后用虚拟 IP 手动 Remote Connect

### 连接超时怎么排查

Local 或 Remote 都转圈超时，按下面顺序走一遍，每做完一步就回去试连接：

1. **主机状态**——是否已开机/待机、是否登录 PSN、远程游玩开关是否开着、有没有其他设备（官方 PS Remote Play 也算）正占着会话
2. **网络拓扑**——本地连不上先确认手机和主机在同一 WiFi、路由器的访客网络隔离有没有开、手机同时开 WiFi 和移动数据时会不会优先走流量；远程连不上先确保本地能通
3. **重启**——主机、路由器（拔电源 30 秒）、手机三件套重启，然后重新走注册流程
4. **重新注册**——Profile 里删掉主机档案，回主机拿新的 8 位注册码，PSN 登录方式重新注册一遍

> [!WARNING]
> Error: IO_EXCEPTION_OCCURRED 通常就是网络层问题——远程连接查端口转发和公网 IP、本地连接查主机 IP 和同网段、自动远程查 NAT 类型和 PSN 登录。Wrong registration code 别只盯数字，Online-ID 的字母 O 和数字 0 也很容易输错。

### 常见误区

- **以为码率拉越高越好**——带宽不够时，高码率反而因为丢包导致画面出现马赛克、卡顿频繁，比低码率的稳定画面体验差得多
- **忽略待机设置**——主机待机模式默认不联网，必须手动勾上「保持与互联网连接」才能远程唤醒
- **访客网络坑**——很多家庭路由器的访客网络和主网络做了隔离，手机连访客 WiFi 是看不到主机的，两边必须在同一子网
- **把内网 IP 当成公网 IP 去连**——手动 Remote Connect 必须填公网 IP（whatsmyip 查到的那个），内网 IP 只能在同 WiFi 下用 Local Connect
