## ✨ WeNet 是什么

WeNet 是一套面向高校场景的校园网认证与自助服务系统，广泛覆盖国内多所大学的宿舍、教学楼、图书馆等场所。它提供统一的入网认证入口，让师生通过一个账号就能接入校园 WiFi 和有线网口，同时配套微信公众号、小程序和桌面客户端，支持套餐购买、流量查询、自助报修等日常操作。

对刚进校园的新生来说，WeNet 基本是每个学期开学都会用到的东西——报到后第一件事往往就是用学号登录 WeNet，连上宿舍 WiFi，然后开始下载课程资料、刷网课、查成绩。对老用户来说，每月领取免费学习流量、偶尔升级套餐、换了设备重新认证一下，也是 WeNet 提供的高频服务。

不同学校的 WeNet 实例在界面和功能上会有细节差异，但核心流程和使用逻辑基本一致：**微信通道负责账号和套餐管理，App/客户端负责认证上线，Portal 页面负责扫码联动**。这套组合打下来，基本能覆盖从入网到付费到多设备使用的全链路需求。

## 🔧 安装与初次上线

WeNet 的安装本身不算复杂，但第一次用的同学经常在认证环节卡住。这里按平台分步骤梳理。

### 手机端（Android / iOS）

1. **下载 App**：应用商店搜 "WeNet"，认准开发者为学校或运营商官方账号的版本
2. **首次打开**：授予定位和网络权限——校园网 Portal 有时会根据位置判断是否在校园范围内
3. **登录账号**：用学号 + 初始密码登录。初始密码通常是身份证后六位或学校统一分配的随机码，忘记了就走"重置密码"流程
4. **认证上线**：登录成功后，WeNet 会自动检测当前网络是否为校园网。如果是，点击"一键认证"即可上线；如果没自动检测到，手动进入"认证"页面选择校园 WiFi 名称

> [!TIP] 初次登录如果提示"账号未激活"，通常是学校网络中心还没把你的学号同步进 WeNet 系统——报到后等 1-2 个工作日再试。

### PC 客户端（Windows / macOS）

1. **下载**：从学校微信公众号的"下载中心"或网络中心官网获取安装包
2. **Windows 安装**：双击 .exe 一路下一步，注意安装路径不要选带空格的目录，避免个别 PPPoE 驱动加载失败
3. **macOS 安装**：把 .dmg 里的 WeNet.app 拖进"应用程序"文件夹，首次打开如果被 Gatekeeper 拦截，去"系统设置 → 隐私与安全性"允许
4. **PPPoE 拨号**：插好网线后打开客户端，切换到"有线网"标签，填入账号密码点击连接。报 691 错误是密码不对，报 651 错误是物理链路问题（网线松了或网口没开）

### 认证状态核对

上线成功后做两件事确认一下：

1. 打开微信公众号"我的网络"页面，确认账号状态显示"已上线"
2. 访问任意公网页面（比如搜索引擎），如果没有被重定向回认证页，说明链路正常

## 📖 日常使用指南

WeNet 的日常操作集中在三个场景：**流量领取、套餐管理、多设备切换**。下面按高频程度逐一展开。

### 每月免费流量领取

根据学校政策，在校生每月可获得 10-15G 的免费学习流量，当月领取当月有效，不累计到下月。领取入口不在 WeNet App 里，而是在微信通道：

**方式一：微信公众号**

1. 关注学校指定的 WeNet 服务公众号
2. 进入"我的网络 → 我的自理平台"，用学号登录
3. 首页找到"领取免费流量"或"学习流量"入口
4. 点击"立即购买"（按钮叫购买但实际上免费），系统自动把额度加到账户

**方式二：微信小程序**

微信搜索"校园无线网学习流量"，选择所在学校，系统自动识别身份后一键领取。

> [!NOTE] 免费流量优先覆盖校园网内访问（教务系统、图书馆、内网资源），部分高校会限制只在 8:00-22:00 教学时段使用。下载大型游戏或蓝光视频时，系统可能自动切换到付费套餐消耗。

### 付费套餐购买

免费流量用完了就得买付费套餐。**绝大多数学校的套餐购买只走微信通道**（公众号菜单或专属小程序），WeNet App 里通常只显示已购套餐、不提供直接购买入口。

标准购买流程：

1. 关注学校 WeNet 服务公众号
2. 进入"我的网络 → 我的自理平台"，学号登录
3. 首页点击"购买套餐"或"宽带产品"
4. 在套餐列表里按三个维度筛选：
   - **运营商**：电信 / 移动 / 联通，选覆盖宿舍信号好的那家
   - **套餐周期**：月 / 季 / 学期 / 学年，按消费能力选
   - **带宽等级**：100M 够用、200M 看 4K 视频更稳、千兆适合宿舍多人同时用
5. 确认金额 → 选择支付方式（微信支付 / 支付宝 / 校园卡）→ 完成支付

**支付成功后**，等待 1-3 分钟系统确认，然后回到公众号或 App 的"我的网络"页面查看套餐是否已生效。如果是运营商融合套餐，还需要额外完成"运营商宽带激活"步骤。

**支付失败怎么办**：微信扣费成功但套餐没到账时，不要急着重买——先等 5-10 分钟让网络中心和微信支付同步，然后下拉刷新"我的网络"页面，还是没到账就找公众号"在线客服"提供交易单号反馈。如果是微信支付本身报错（限额、网络异常、账号状态异常），换支付宝或从校园网切到手机流量重试即可。

**套餐优先级**：同时持有多个套餐时，系统按以下顺序消耗——临时流量包（有效期最短先用）→ 免费流量 → 月付/季付套餐 → 运营商融合套餐。想调整顺序，在公众号"我的套餐"页面可以手动设置。

> [!WARNING] 大部分校园网套餐购买后 **不支持退款**，买之前务必看清套餐描述和有效期。

### 宿舍有线网口使用

WiFi 在高峰期容易拥挤、带宽也有限，下载大文件、看 4K 视频或打联机游戏时，有线网口的优势非常明显。

**第一步：找到开通的网口**。宿舍里有好几个网口，但不是每个都开了——**进门两侧墙角的网口通常是开通的，床边或桌面附近的旧网口大多已停用**。判断方法很简单：插上网线后，开通的网口 LED 指示灯会亮黄灯或绿灯，电脑右下角小电脑图标变亮；停用的网口完全没反应。两侧都没亮？跟宿管员或网络中心联系，宿舍可能还没开通有线网权限。

**第二步：准备一根网线**。Cat5e（超五类）或 Cat6（六类）都行，长度按宿舍距离选 2-5 米，两端 RJ45 水晶头按压能听到"咔"的一声。学校文具店或京东搜"网线"，10 块钱就能买到。

**第三步：PPPoE 拨号**。插好网线后：

- **Windows**：打开 WeNet PC 客户端 → 选 PPPoE 模式 → 填入账号密码 → 连接
- **macOS**：系统设置 → 网络 → 以太网 → PPPoE 连接 → 填入账号密码 → 连接

**有线 vs 无线对比**：

| 对比项 | 有线网口 | 校园 WiFi |
| --- | --- | --- |
| 稳定度 | 不受干扰 | 高峰期可能拥挤 |
| 带宽 | 通常千兆 | 校园公共带宽，高峰限速 |
| 适合场景 | 下载大文件、4K 视频、游戏 | 手机、移动办公 |
| 便捷性 | 必须固定位置 | 到处可用 |
| 认证方式 | PPPoE | Portal |

**故障排查顺序**：网口灯亮不亮？→ 电脑显示"已连接"吗？→ 拨号报 651（物理连通但服务器没响应，重插网线重启电脑）还是 691（账号密码错）？→ 都不行就走在线报修提交工单。

### 手机扫码登录电脑

电脑连校园网后会自动弹出 Portal 认证页面，页面上除了账号密码输入框，还有一个二维码。手机 WeNet App 扫一下这个码，就能把手机端已登录的账号信息转发给认证服务器，电脑立刻上线——全程不用在键盘上敲学号密码。

**操作步骤**：

1. 电脑连上校园网 WiFi 或插好网线，等认证页面弹出（没弹就手动打开任意 http 网址触发）
2. 手机打开 WeNet App 确保已登录同一个账号，找到扫一扫入口（首页右上角或"更多"菜单）
3. 对准电脑屏幕上的二维码，扫描成功后手机弹出确认界面，点击"确认登录"
4. 电脑端认证页面自动跳转显示成功

这个功能在三个场景特别好用：**公共电脑不想输密码**（密码始终留在手机上，不留痕迹）、**电脑键盘不好使**（键帽坏了、外接键盘临时找不到）、**双设备快速切换**（手机先扫码激活，电脑复用认证状态）。

**扫不出来怎么办**：把电脑上的认证页面放大（Ctrl+滚轮）或调亮屏幕；提示"二维码已过期"就刷新认证页面重新生成；确认手机已用学号登录 WeNet；确认电脑连的是校园 WiFi 不是访客网。
