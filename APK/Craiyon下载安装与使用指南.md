## ✨ Craiyon 是什么

Craiyon 是一款 Web 端 AI 绘画工具，脱胎于 2021 年爆火的开源项目 DALL·E mini。它的核心玩法很简单——在提示词框里用自然语言描述你想要的画面，点击 Draw，几秒钟后就会返回九张风格各异的图像，摆在一个 3×3 九宫格里供你挑选。

和市面上其他 AI 绘画工具相比，Craiyon 最大的特点是**真·免费**：不需要注册账号、不需要付费、没有每日生成次数限额。任何人打开浏览器就能用，prompt 描述随便写一天都不会被打断。当然，免费也有代价——下载的图片右下角会带水印、高峰期排队速度会慢一些、生成结果默认进入公共画廊。

Craiyon 内置了丰富的风格预设（Anime、Oil Painting、Cyberpunk、Minimalist 等几十种）和画面比例选项，每次生成返回九张不同解读的结果，而不是假装"只有一个正确答案"。这种设计一方面展示了 AI 生成的不确定性，另一方面也给用户省去了反复改 prompt 逐个生成的麻烦——一次九张里挑一张好的用就行。

如果你是第一次体验 AI 绘画、想玩梗做表情包、或者正在练习 prompt 写法，Craiyon 免费版完全够用。对于有更高画质需求、需要私藏生成结果、或者想用 Retouch 精修功能的用户，Supporter 和 Professional 两档付费订阅提供了更快的队列、无水印下载、Private 模式和精修 credits。

## 🔧 使用前的准备工作

Craiyon 本质上是一个 Web 应用，不需要传统意义上的"安装"——打开浏览器就能用。不过有几点准备工作可以让你的体验更顺畅。

### 浏览器与网络

Craiyon 对浏览器没有硬性要求，Chrome、Edge、Safari、Firefox 主流浏览器都能正常运行。但在生成图像的过程中需要保持网络连接稳定，尤其是免费版高峰期（美国东部时间中午、中国凌晨）排队可能需要 1-2 分钟，网络中断会导致生成失败需要重跑。

### 免费 vs 付费的选择

| 维度 | 免费版 | Supporter $5/月 | Professional $20/月 |
|---|---|---|---|
| 注册 | 不需要 | 需要 | 需要 |
| 生成次数 | 无限 | 无限 | 无限 |
| 下载水印 | 有 | 无 | 无 |
| 画面比例 | 仅 1:1 | 多比例可选 | 多比例可选 |
| 私藏模式 | ❌ 默认公开 | ✅ 可选 Private | ✅ 可选 Private |
| 生成速度 | 高峰期 60-120 秒 | 优先队列 ~45 秒 | 最快 ~30 秒 |
| Retouch/Upscale/Animate | ❌ | 每月 120 credits | 每月 250 credits |
| 最高分辨率 | 标准 | HD | HD+ |

> [!TIP]
> 免费版真的是零注册零付费零限额——你可以上午 100 张玩梗、下午 200 张练习、晚上继续生成 moodboard，完全不会出现"今日额度已用完"的提示。唯一的限制是高峰期排队速度，但不会拒绝你的生成请求。

### 什么时候值得升级

很多用户从免费转到付费，通常是几个明确的触发场景：下载了满意的图但右下角的 logo 太碍眼；高峰期等 2 分钟以上已经不耐烦；生成了一些不想公开的内容；或者九张里挑了一张只想微调却苦于没有精修功能。如果以上几条中了两条以上，就值得考虑付费订阅。

## 📖 核心功能全解析

### 提示词（Prompt）怎么写

提示词是 Craiyon 生成的核心输入。它支持多语言识别——中文、日文、韩文、西班牙文、法文、德文都能正常工作，但英文 prompt 在精确性和稳定性上有明显优势。原因是模型的训练数据绝大部分来自英文互联网，"cinematic lighting"、"oil painting style"、"cyberpunk" 这类描述在英文社区使用频率高，模型学到的文字→图像对应关系就更明确。

> [!NOTE]
> 一个实用技巧：主体用中文描述具体场景，风格和质量词用英文关键词。比如"一只金毛寻回犬在秋天落叶里坐着，warm afternoon light, realistic photo"——用中文精准描述你想要的内容，用英文关键词给模型传递风格方向信号。

写好 prompt 的几个基本原则：主体要具体（"一只橘猫坐在窗台上晒太阳"比"一只猫"好）、风格要明确（加上你想要的画风关键词）、可以用逗号分隔多个描述元素。Exclude 负向提示词框可以填入你不希望出现的元素，比如"blurry, low quality, extra fingers"让模型避开常见瑕疵。

### 九宫格结果的操作

点击 Draw 之后，模型开始处理你的 prompt。处理完成后九张图像会以 3 行 × 3 列的网格形式整齐排列在提示词输入框下方。每张图都是模型对同一个 prompt 的"不同解读"——Craiyon 故意承认 AI 生成的不确定性，展示多种可能性而不是假装只有一个正确答案。

对每张生成结果你可以执行多种操作：

1. **下载**——免费版下载的图片右下角带 Craiyon logo 水印，付费 Supporter 及以上版本支持无水印高清下载
2. **放大查看**——点击图片全屏查看，仔细观察细节
3. **再生成类似的**——基于这张图 + 原始 prompt 再生成一批类似结果，相当于轻量变体功能
4. **用作参考图**——选中后上传为新 prompt 的参考图，让模型在它的视觉风格下继续创作
5. **Retouch 精修**——用自然语言描述你想改什么（如 "remove the extra finger"、"change the hat color to red"），消耗 edit credits
6. **背景移除**——直接跳转内置背景移除工具

挑选最好一张的标准：先看有没有明显在正确方向上的结果，即使有瑕疵；再判断哪些瑕疵可以用 Retouch 修复、哪些无法补救（如严重扭曲的人脸、六根手指）；如果全部不满意就换风格或改 prompt 再生成一轮，反正免费不限次数。

### 社区画廊与灵感

左侧导航栏的 Search 入口直接进入社区画廊。你可以浏览其他用户公开分享的生成结果、按关键词搜索、点击任意一张图查看它的原始 prompt 和生成参数、或者把感兴趣的图用作自己创作的参考。

社区画廊的价值远不止"看别人都生成了什么"——它是一个免费的 prompt 灵感库。搜一个关键词（比如 "cyberpunk"、"cat"、"forest"），你会发现哪些 prompt 组合效果好、哪些风格预设更适合你的主题、社区里正在流行什么创作方向。即使不用它的 prompt，单纯浏览社区图像也能给你带来风格灵感。

> [!WARNING]
> 一个重要事实：**免费版用户生成的图像默认会进入公共画廊**——任何人都能在 Search 里看到你生成的图像和对应的 prompt。这是产品设计，不是 bug。如果不希望图像公开，需要升级付费订阅（Supporter 及以上）后选择 Private 模式。

### 精修与进阶工具

Retouch 是付费订阅才有的功能——你用自然语言描述想改什么，模型直接在原图基础上做修改。比如九张里挑了一张构图满意但"手臂多了一根手指"的，直接输入"remove the extra finger"就能修掉。或者想换个帽子颜色、加一副太阳镜、调整光线方向，都可以用文字描述实现。Supporter 每月有 120 credits、Professional 每月有 250 credits，每次 Retouch 消耗一定数量。

背景移除功能可以把生成结果的背景直接去掉，适合需要把主体抠出来做合成的场景。这个功能也在付费订阅体系内。

### 高峰期与排队

Craiyon 在某些时段生成速度会明显变慢：美国东部时间中午 12:00-17:00 是欧美用户集中在线的高峰期，中国时间凌晨 0:00-6:00 相对空闲生成更快。付费用户有优先队列，高峰期等待时间明显短于免费用户。如果经常遇到 2 分钟以上的等待，可以考虑换个时段生成或者升级付费。
