## ✨ kerning 是什么

kerning 是一款面向图像生成与图生视频场景的 AI 创作工具，核心能力是把静态照片变成会动的短片——老照片眨眼转头、宠物摇尾巴、商品缓缓旋转、风景从白天过渡到夜晚，这些在社区里每天都有大量成片案例的题材，用 kerning 跑一遍提示词就能出片。

它的定位是轻量型图生视频工具，不追求复杂的多步骤工作流，主打"上传一张图 → 写一句话 → 导出"的极简链路。对没有剪辑基础、但又想把手头照片变活的普通用户来说，门槛和学习成本都比较低。

功能上，kerning 支持单图参考、多图参考（用来钉住主体一致性，让同一个人或同一只猫在多条视频里保持外观稳定）、首尾帧（白天→夜晚这种经典转场）、静态笔刷+动作笔刷配合约束局部动区域等。社区推荐流里密度最高的四类题材——老照片动起来、宠物日常、风景天夜转场、商品展示——都是它的高频使用场景。

## 🔧 安装与准备

kerning 是面向移动和桌面双端的应用，具体安装步骤依平台略有差异，但整体都很直接。

**移动端（Android / iOS）**

1. 在应用商店搜索软件名找到对应条目
2. 确认开发者和版本号与官方渠道一致后点击安装
3. 首次启动时按提示授权相册访问和存储权限——不给权限会导致上传不了本地照片

> [!NOTE]
> iOS 用户如果遇到应用要求"信任开发者证书"的提示，是企业签分发的正常流程——进入系统设置 → 通用 → VPN 与设备管理，找到对应证书点"信任"即可。

**桌面端（Windows / macOS）**

1. 从下载页获取安装包，注意核对文件大小和哈希，避免下载损坏或中途断流
2. Windows 安装时如果被杀毒软件拦截（常见于小众分发渠道），手动添加信任即可
3. macOS 首次运行被 Gatekeeper 拦截时，右键应用图标选"打开"→ 在弹窗里再点一次"打开"

> [!WARNING]
> 下载安装包时务必从官方渠道获取，不要从第三方站点下载来路不明的改包——AI 工具类应用涉及上传图片到云端处理，安全性优先。

## 📖 使用入门

### 先搞懂上传门槛：四条过关线

很多新手第一步就卡在"图上传不合格"上。kerning 对上传图片有硬性要求，四条必须同时满足：

| 项目 | 合格标准 | 常见踩坑 |
|---|---|---|
| 格式 | JPG / JPEG / PNG | HEIC（iPhone 默认格式）、GIF、WebP 都不认 |
| 体积 | ≤ 10 MB | 手机拍的原片可能超，相册里"编辑→保存一遍"就能压到 5 MB 以内 |
| 尺寸 | 宽高都 ≥ 300 px | 微信转发过的图经常被压缩到 400×600，刚过尺寸线但画质差 |
| 宽高比 | 1:2.5 ~ 2.5:1 | 太狭长或太扁（比如超长条形图）会被拒 |

> [!TIP]
> 养成习惯：上传时直接从相册选原图，别从微信聊天里保存图片——微信反复转发会二次压缩格式、尺寸和比例，很容易四条线里某一条没踩中。

HEIC 格式的 iPhone 用户最简单的解决办法是：把照片发给自己的微信文件传输助手，从电脑端下载保存，自动转成 JPG。GIF 动图截一帧当静图就行。

### 图生视频：最常用的基础流程

**单图参考（最常见）**

1. 上传一张照片（满足上面四条过关线）
2. 写提示词描述"想让它怎么动"
3. 选创意强度（0.4-0.5 偏低，模型更保守；0.7-0.8 偏高，会自由发挥）
4. 点击生成，等待导出

社区里出片率最高的提示词套路：

| 题材 | 提示词示例 | 难度 |
|---|---|---|
| 老照片眨眼 | 照片里的人眨一下眼，面部保持不变 | 低 |
| 宠物日常 | 猫轻轻摇尾巴，身体保持静止 | 最低 |
| 风景转场 | 从白天过渡到夜晚，光影自然渐变 | 中 |
| 商品展示 | 口红缓缓旋转一圈，镜头环绕一周 | 低 |

> [!NOTE]
> 新题材（比如"蘑菇变企鹅"这种魔改 prompt）出片率不稳定，建议先在成熟题材上练稳了再试。

### 进阶玩法：局部约束、多图参考、静态笔刷

#### 局部约束：眨眼脸却变形怎么办

新手常碰到的问题：想让照片里的人眨个眼，结果整张脸都变形了——模型把"眨眼"理解成了整个面部都参与运动。

解法有两个，配合使用最稳：

1. **提示词里写清不动的区域**。错误写法是"让这个人眨个眼"，正确写法是"面部保持不变，仅眼部自然眨动"——"保持不变"四个字是关键，模型需要被明确告知哪些区域不能动。

2. **静态笔刷钉死像素**。如果文字约束不够精确，给整张脸除了眼皮以外的区域涂静态笔刷，再用动作笔刷只圈眼皮，提示词写"眼皮自然上下闭合"。双重保险。

老照片的额外问题：画质低时模型可能"看不清"眼皮在哪，先把老照片放大修复（手机相册自带 AI 修复就行）再上传，细节保留会好很多。创意强度调到 0.4-0.5，减少模型"自由发挥"。

#### 多图参考：让主体保持一致

普通图生视频每次重新生成，人脸细节、五官间距、毛发颜色都可能不一样——跑第二条的时候人可能就不像同一个人了。多图参考就是用来解决这个"主体一致性"问题的：

- 上传同一主体的多张不同姿态、不同角度的照片
- 模型以这些图为参考，生成时锁定主体特征

适合多图参考的场景：想让同一个人跑多条视频（保证人脸都一样）、商业用途（品牌模特或 IP 形象必须稳定）、连续叙事视频（多个片段里主角不能换脸）、想测试不同动作但保持主体不变。

代价是灵感值消耗会比单图参考贵约 1.5-2 倍，但省了反复抽卡试"脸对不对"的时间。

### 常见问题快速排查

| 现象 | 可能原因 | 解决办法 |
|---|---|---|
| 图上传提示不合格 | 四条过关线某条没中 | 逐行核对格式、体积、尺寸、比例 |
| 生成出来脸变形 | 提示词没约束不动区域 | 写"面部保持不变，仅 XX 部位动" + 静态笔刷 |
| 同一主体第二张视频不像了 | 没开多图参考 | 上传同一主体多张不同姿态的照片 |
| 老照片细节糊 | 原图画质差 | 先放大修复再上传 |
| 提示词跑了没反应 | 灵感值不够或排队中 | 检查账户余额，高峰期等一会 |
