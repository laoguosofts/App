## ✨ AI Agent 是什么

AI Agent 是一款面向个人和团队的 AI 智能体平台，核心定位是让大模型从「聊天问答」升级到「任务执行」——你给它一句自然语言指令，它就能自己规划步骤、调用工具、在云端跑完整个流程，最后把结果交付给你。和传统的对话式 AI 不同，AI Agent 有记忆、会规划、能操作浏览器和代码环境，适合处理多步骤、需要持续跟踪的复杂任务。

它的能力大致覆盖几个方向：信息调研与汇总（行业动态、竞品分析、深度研究报告）、内容生成（幻灯片、文档、网页、视频脚本）、自动化编排（定时报告、事件触发工作流）、以及多种外部服务的连接器（Telegram、Slack、Notion、邮箱等）。免费档就能体验 Lite 模型，升级 Pro 后可以解锁 2.0 和 2.0 Max 模型、20 并发任务、视频生成和游戏开发等高级能力。

> [!NOTE]
> AI Agent 支持多端使用：网页端、桌面客户端、移动端 App 都能用同一个账号，任务在云端同步——手机发起的任务，电脑上能看到进度；电脑上完成的任务，手机会收到通知。

适合谁用呢？如果你每天需要处理大量重复性的信息整理工作、想把一些固定流程自动化、或者需要一个能帮你做深度调研的 AI 助手，AI Agent 的智能体模式比单纯的聊天模型效率高不少。但如果你只是偶尔问几个简单问题，免费档的 300 积分/天（不累积）基本够用；重度用户可以考虑 Pro 方案，积分按月给、没用完能续到下月。

## 🔧 安装步骤

AI Agent 的安装过程本身比较简单，但有几个容易被忽略的点值得提前注意。

### 多端安装概览

AI Agent 目前提供网页端、桌面客户端（Windows / macOS）和移动端 App（Android / iOS）三种入口。网页端无需安装，直接打开浏览器就能用；桌面客户端从官网下载安装包，运行后跟着向导走就行；移动端在 Google Play 或 App Store 搜索软件名下载。三种端用的是同一个账号体系，注册一次全端通用。

> [!WARNING]
> **登录方式永久绑定**是 AI Agent 账号体系最容易踩坑的规则。你当初用手机号注册的，以后就只能用手机号登；用邮箱或第三方账号（Google、Apple）注册的，以后只能用那种方式登。这不是 bug，是设计如此。换一种登录方式会进一个全新的空账号，之前的积分和任务记录都还在原来的账号里——不是丢号，是你进了另一个号。

### 注册时的注意事项

注册时请选择你长期稳定可用的方式，然后把它记在密码管理器里。AI Agent 不提供「找回登录方式」的功能，如果真忘了当初用什么注册的，只能挨个试你常用的手机号、邮箱和第三方账号，哪个能看到积分和历史记录，哪个就是当初注册的方式。

如果你有换手机号的计划，建议提前考虑用邮箱或 Google / Apple 账号注册——换了手机号之后，用原来的手机号登录肯定进不去了，只能注册新账号。

### 安装后的基础配置

首次登录后，建议先做两件事：

1. **完善个人资料**（头像、昵称），方便你在多设备上快速确认当前登录的是正确账号
2. **去设置里看一下「连接器」Tab**，把你常用的外部服务（Gmail、Slack、Notion、Telegram 等）连上——连接器是 AI Agent 自动化能力的基础，后面玩定时任务和事件触发都需要它们

## 📖 使用入门

AI Agent 的核心玩法不在于单次对话，而在于智能体模式、自动化编排和多端协同这三者的组合。下面从几个高频场景切入，帮你快速上手。

### 智能体模式 vs 聊天模式

AI Agent 有两种工作模式：

- **聊天模式**：就是传统的对话式 AI，一问一答，不消耗积分（免费），适合简单问答和快速草稿
- **智能体模式**：你给一个目标，AI Agent 自己拆解步骤、调用工具、在云端跑完整个流程，消耗积分，适合复杂的多步骤任务

一个典型的智能体指令例子：「帮我调研一下 2024 年 AI Agent 赛道的主要玩家，每家公司的核心产品和融资情况，整理成一份 Markdown 格式的报告，输出到我的邮箱」。这样的任务如果手动做可能要半天，智能体模式下可能十几分钟就能跑完，中间不需要你干预。

### 登录方式绑定的实际影响

除了注册时选好方式，日常使用中还有几个场景需要注意：

**换手机后登录**：换手机装了 AI Agent，习惯性点了微信登录（假设当初是手机号注册的），结果进了空账号，积分记录全没了——不是丢号，是你进了另一个账号。换回手机号登录就能看到原来的积分和任务。

**想换登录方式**：当前不支持直接切换。如果确实需要换方式登录，只能注册新账号，部分积分可以联系客服处理迁移，但不是所有情况都支持。

**多设备同时操作**：同一个账号可以同时在手机、平板、网页端、桌面端登录，任务云端同步。唯一注意点是多设备同时操作同一个任务时，避免在多个窗口同时发指令，可能会产生冲突。

### Telegram 接入——把 AI Agent 放进聊天应用

AI Agent 2.0 提供了 Telegram Agent 功能，不用打开客户端，在 Telegram 聊天里直接用完整的 AI Agent 能力：问问题、派发智能体任务、处理语音和图片、设置自动回复风格——用的是同一个账号、同一个积分、同一个任务历史。

连接过程很简单：打开 AI Agent 设置 → Agents Tab → 点「开启」，会生成一个入口链接和二维码。用手机扫或者在桌面端点链接，就能在 Telegram 里开始用了。

Telegram Agent 适合几个场景：

- **外出时派活**：地铁上发一条指令，到站收结果
- **语音输入**：开车或走路不方便打字，发语音让 AI Agent 转写并执行
- **快速查看进度**：电脑上跑着大任务，不想开电脑，Telegram 里看进度就行
- **快速确认**：AI Agent 某个任务等你确认，直接在 Telegram 里回复

积分消耗方面，聊天模式不消耗积分，智能体模式和客户端里一样消耗，Telegram 里的消息也是会话的一部分——如果客户端里开了一个会话，然后在 Telegram 里继续，AI Agent 能保持上下文连贯。

> [!TIP]
> Telegram 里可以设置 Agent 的回复风格：简洁（给最精华的）、结构化（列表和表格）、对话化（像聊天一样自然）。设置一次后始终用这个风格回复，适合你在不同场景下切换。

### Pro 方案的选择策略

AI Agent 免费档和 Pro 档的核心差异如下：

| 维度 | Free | Pro |
| --- | --- | --- |
| 模型 | 只有 Lite | Lite + 2.0 + 2.0 Max |
| 积分 | 300/天（不累积） | 4000~8000/月（按月给） |
| 并发 | 1 | 20 |
| 定时/事件任务 | 2 | 20 |
| 视频生成 | ❌ | ✅ |
| 游戏开发 | ❌ | ✅ |
| Alchemy 模式 | ❌ | ✅（Max 下） |
| 抢先 Beta | ❌ | ✅ |

Pro 有两档：$20/月给 4000 积分，$40/月给 8000 积分。除了积分额度和试用权益，其他能力完全一样。选择建议：

**选 $20 档**：每天平均 5~10 个智能体任务、主要做研究汇总和幻灯片生成、偶尔用视频生成、预算敏感不确定 Pro 是不是长期需要。

**选 $40 档**：每天平均 15~20 个任务、经常用视频生成和 Alchemy 模式、需要并发 10+ 个任务、想先试用 7 天再决定。按年订阅享受 17% 折扣，折算下来 $20 档年付 $199.2、$40 档年付 $398.4。

> [!TIP]
> Pro 支持随时升级和降级。Free 升 Pro 立即生效，按剩余天数折算首月费用；Pro 升级补差价；Pro 降 Free 到当前计费周期结束后才生效，不会立刻降级。Cloud Computer 是单独付费的，任何方案都能买，不走积分。

### 定时与事件触发——让 AI Agent 自动跑

AI Agent 2.0 的自动化能力叫「Automations」，不再只是简单的定时到点跑，而是支持两种触发方式的自由组合：

**定时触发**：每天、每周、每月固定时间。适合每日数据汇总报告（每天早 9 点生成并发给团队）、每周竞品动态周报（每周一早）、每月账单整理（每月 1 号）、定期检查网页更新。

**事件触发**：AI Agent 能监控外部服务的事件，发生时自动启动任务。2.0 支持的触发来源包括：

| 来源 | 可触发事件 |
| --- | --- |
| 邮箱（Gmail 等） | 新邮件、特定发件人、含特定关键词 |
| 日历（Google Calendar 等） | 日程变动、会议临近提醒 |
| Slack | 新消息、特定频道、@提及 |
| Notion | 数据库条目新增/修改、页面更新 |
| 广告平台 | 广告性能指标变化（如 ROAS 低于某值） |
| 自定义连接器 | MCP 连接器接入的任何事件 |

典型的事件触发场景：

- **邮件 → 任务**：收到客户邮件 → 自动创建 CRM 记录 → 自动回复确认邮件
- **日历 → 提醒**：会议前 2 小时 → 自动生成会议摘要 → 发到 Slack 频道
- **Slack → 调研**：在 Slack 某频道 @ AI Agent → 自动调研 → 结果发回频道
- **Notion → 周报**：每周五下午 → 汇总 Notion 这周所有新建条目 → 生成周报 → 发邮箱

设置 Automations 的基本步骤：先在设置里连接对应的服务（连接器），用自然语言写触发条件和任务指令，选择执行环境（AI Agent 云端免费，Cloud Computer 适合常驻运行的自动化），然后设置是否跳过人工确认。

免费档有 2 个定时任务额度，Pro 档有 20 个，事件触发任务数量不单独限制。每次执行都消耗积分，和手动跑一样。
