## ✨ AionClaw 是什么——能交付成品文件的桌面级 AI 智能体

AionClaw 是一款桌面级 AI 智能体工具，它的核心定位是把 AI 能力从"聊天问答"升级到"执行具体任务"。市面上常见的 AI 聊天机器人停留在"给你一段代码或方案"，而 AionClaw 会在本地实际跑起来——生成的网站会自动启动开发服务器预览、定时任务会按设定时间自动执行、数据抓取会直接把结果存到你指定的本地目录。这种"能交付成品文件"的能力，让它适合电商运营、独立开发者、内容创作者以及需要重复自动化工作的各类用户。

用户用自然语言描述需求，AionClaw 会自动拆解任务、调用内置或社区技能、执行浏览器/文件/代码操作，最终交付可运行的结果。比如一个能上线的网站项目、一份竞品价格监控的定时任务、或者电商选品分析报告——整个过程单人单会话就能完成，不需要懂技术细节。

核心功能模块包括：浏览器自动化（打开网页、点击、填写、抓取）、文件操作（读取、写入、整理）、代码生成与调试、定时任务调度、技能市场（可扩展的第三方技能）、数字专家（垂直领域的 AI 角色）。

## 🔧 安装步骤——Windows 和 macOS 分别怎么装

AionClaw 支持 Windows 和 macOS，安装过程比较直接，但有几个点需要提前注意。

**Windows 安装流程：**

1. 从下载页获取安装包（通常是 `.exe` 格式），双击运行
2. 如果 Windows SmartScreen 弹出"未识别的应用"警告，点击"更多信息 → 仍要运行"——这是新发布软件的常见情况，不是恶意软件
3. 选择安装路径，建议保持默认或指定一个非系统盘目录（比如 `D:\AionClaw`），避免系统盘空间紧张
4. 安装完成后桌面会生成快捷方式，首次启动需要登录账号

> [!NOTE]
> **首次启动需要网络连接**。AionClaw 的 AI 能力依赖云端模型，首次启动会自动拉取必要的配置和登录态，离线环境下只能使用已安装的本地技能，且功能受限。

**版本核对和磁盘空间：**

安装完成后，在客户端"设置 → 关于"里查看版本号，和下载页标注的最新版本对比。如果版本号不一致，建议重新下载最新安装包覆盖安装——AI Agent 这类工具更新频繁，旧版本可能缺少某些技能或存在兼容性问题。

完整安装大约需要 500MB-800MB，加上后续生成的项目文件和缓存数据，建议预留 2GB 以上空间。如果安装了较多社区技能，占用还会进一步增加。

## 📖 使用入门——从核心概念到四个实战场景

### 先搞懂两个核心概念

理解 AionClaw 的使用，先区分两个基本概念：

- **数字专家**：垂直领域的 AI 角色，比如"软件开发专家""电商运营专家""文案创作专家"。每个专家内置了该领域的专业知识和工作流程，选择合适的专家来发起任务，输出质量会比通用模型好得多。
- **技能（Skill）**：可扩展的功能模块。浏览器操作、文件处理、竞品监控、代码生成……这些都是技能。用户可以在技能市场安装第三方技能，也可以自己创建。专家 + 技能的组合，决定了 AI 能做什么、怎么做。

### 场景一：电商竞品价格监控

这是 AionClaw 最适合的垂直场景之一。电商运营每天要手动查竞品价格、看 SKU 销量、汇总店铺数据，这些重复工作可以交给 AI 自动跑。

**设置定时任务的典型方式——用自然语言描述：**

> "帮我做一个竞品价格监控的定时任务：每 2 小时检查这 5 个竞品页面的价格和销量，价格变动超过 ±5% 时立即通知我，每天晚上 8 点给我一份当日价格变动汇总，数据存到 D:\工作\竞品监控\"。

AionClaw 会自动执行完整流程：
1. 打开你给的 5 个竞品 URL
2. 提取每个商品的名称、当前价、原价、销量、评价数
3. 和上一次的数据对比（第一次运行自动建立基准线）
4. 价格变动超阈值 → 立即推送到飞书或企业微信
5. 晚上 8 点 → 自动生成 Excel + Markdown 报告

第一次运行时，如果店铺后台需要登录，浏览器模块会弹出登录窗口，手动扫码一次之后就会记住 Cookie，后续全自动化。

根据实测数据，5 个 SKU 的竞品监控手动每次约 20 分钟，自动化后月省约 10 小时；每日店铺数据汇总手动每次 15 分钟，自动化月省约 7 小时。

> [!WARNING]
> **反爬合规注意**：淘宝、京东等平台有反爬机制。不要设置太频繁（建议 2 小时以上间隔），优先用已审核的社区技能（通常已处理反爬问题）。如果频繁触发滑块验证，降频或改用官方开放平台 API。只爬取公开可见的页面内容，不做破解，被平台警告时立即停止相关任务。

### 场景二：电商选品的品类趋势分析

选品阶段要分析品类爆发趋势、价格区间分布、热销 SKU 特征，手动做一次要 2 小时起步。AionClaw 可以通过"浏览器操作"技能自动抓取搜索结果、清洗数据、统计分析。

**典型命令示例：**

> "帮我分析一下淘宝上'宠物自动喂食器'这个品类最近的趋势：抓取搜索结果前 3 页，统计各价格区间的商品数量，分析销量前 10 的 SKU 有哪些共同特征（品牌、功能、价格段），给出 3 个值得切入的细分方向，存为 Markdown 报告"。

执行后会输出结构化的分析结果：比如 100-200 元占 40%、200-500 元占 35%，销量前 10 个 SKU 均价 380 元、都带摄像头和 App 远程控制、评价关键词集中在"准时"和"静音"，并给出具体的细分方向建议（100 元以下极简款、带摄像头中端款、多猫家庭大容量款等）。

### 场景三：用一句话生成可运行网站

传统网站开发从 PRD 到上线要 2-6 周、涉及 5-10 人，AionClaw 可以在单会话里 30-60 分钟交付一个能跑的项目。

**你只要说清楚需求：** 首页放什么、几个页面、风格偏好、是否要移动端适配。软件开发专家接手后自动走完这条链路：

1. **技术选型**：先告诉你打算用什么栈（比如 Next.js + Tailwind CSS），不懂技术直接同意就行，懂的话可以说"我想用原生 HTML"或"改成 Vue"
2. **逐页生成**：首页 → 关于页 → 联系页 → 共享组件（导航栏、页脚），每生成完一个页面自动验证能否正常渲染
3. **本地运行调试**：自动启动开发服务器、打开浏览器预览、检查移动端布局是否正常
4. **交付完整项目**：包含 pages/、components/、styles/、public/、package.json、README.md、部署说明等

交付的不是一段代码片段，而是一个完整可运行的项目目录。推到 GitHub 连 Cloudflare Pages 就能上线，整个过程不写一行代码。

> [!TIP]
> **能力边界**：AionClaw 擅长中小规模展示型网站和原型。复杂动画、完整后端系统、高度定制化设计还是需要专业开发者。拿到交付物后可以继续让它迭代——"首页加一个新闻动态模块""换一个墨绿色 + 米色的配色方案"，都能直接改好重新构建。

### 技能市场的两种版本：已审核 vs 社区版

AionClaw 的技能生态是社区驱动的，任何人都能发布技能，所以质量有参差。官方做了两层区分来保障用户体验：

| 维度 | 已审核技能 | 社区版技能 |
| --- | --- | --- |
| 审核方式 | 官方人工审核 | 无审核，自动发布 |
| 质量保证 | 官方测试过典型场景 | 发布者自己保证 |
| 安全保证 | 代码已扫描，无恶意行为 | 未经扫描 |
| 兼容性 | 当前版本客户端已测试 | 可能和某些版本不兼容 |
| 更新频率 | 官方或维护者定期更新 | 取决于发布者 |
| 信任标识 | 有"官方认证"徽章 | 无特殊标识 |

**日常使用优先已审核技能**——涉及文件操作、数据处理、可能读取本地文件的，强烈建议选已审核版本，安全性和兼容性更有保障。

社区版适合用在已审核版本没有、但你对发布者有基本信任的场景。判断社区版技能靠不靠谱，可以看四个信号：下载量（经过更多用户检验）、评论内容（有没有具体说"帮我搞定了 XX 问题"）、更新时间（最近 1-2 个月有更新说明在维护）、发布者历史（同一个发布者有多个人气技能说明质量普遍靠谱）。

**安全红线：** 绝对不要装以下类型的社区版技能——要求提供额外 API Key 的（AionClaw 官方技能不需要额外 Key）、描述模糊但声称能"免费获取会员功能"的、安装后要求运行 `.exe` 或 `.bat` 文件的。这些大概率有恶意行为，可能窃取本地数据。

### 个人版 vs 企业版

AionClaw 分成两套产品线，选择取决于团队规模和需求：

| 维度 | 个人版 | 企业版 |
| --- | --- | --- |
| 目标用户 | 个人、< 5 人小团队 | 5 人以上团队、中型企业 |
| Token 补贴 | 注册送额度 + 每日登录 | 专属 1 亿 Token 补贴 |
| 自定义 Skill | 只能自己用 | 团队共享、管理员统一管理 |
| 自定义专家 | 只能自己用 | 团队共享、统一知识和标准 |
| 安全检测 | 无 | 赠送 10 次 Skill/Agent 安全检测 |
| 技术支持 | 社区/App 客服 | 专属企业顾问 + 一对一培训 |
| 数据归属 | 仅个人本地 | 可集中存储 + 管理员查看 |
| 计费模式 | 积分包/月卡年卡 | 按账号数 + 定制服务费 |

企业版的核心价值在于**团队级的 Skill 和数字专家共享**——比如创建一个"公司统一文案风格专家"，内置品牌调性、常用话术、排版规范，全公司所有人用这个专家时输出质量可控；或者开发"XX ERP 数据导出" Skill，全公司所有人都能用，不用每个人自己写一遍。另外还有数据合规（敏感操作审批流程）、私有化部署、管理员统一查看团队数据和安全日志等企业级能力。

> [!NOTE]
> **小团队要不要上企业版？** 5 人以下的团队，每个人买一个个人专业版年卡（约 80 元/月/人），总费用约 400 元/月。唯一的问题是 Skill 和专家不共享，需要每个人自己配置一遍。5-10 人之间建议先跑 1-2 个月个人会员试试——确认 AI 确实能帮大家省时间，再上企业版不迟。
