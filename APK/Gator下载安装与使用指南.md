## ✨ Gator 是什么

Gator 是一款面向 Android 的系统维护工具，核心围绕「清理」和「管理」两件事——System Cleaner 负责清理残留、缓存、日志和浏览器历史，App Manager 管理应用卸载，Exporter 帮文件搬家到 SD 卡，Scheduler 可以设定时自动跑清理。整个 Dashboard 用卡片式布局，四五个主要功能一眼能点进去。

这款工具没有花里胡哨的功能堆砌，主打一个「把系统维护这件事做干净」。日常使用场景就是：感觉手机变卡了跑一次清理、想腾空间搬文件到 SD、设置一个定时计划让它每周自己跑一次。

## 🔧 安装步骤

### 下载前注意

下载安装包前先确认文件大小和版本号——不同渠道的包可能版本不同，优先选官方下载页提供的版本，第三方应用商店偶尔会滞后一两个版本。

> [!WARNING]
> 安卓平台侧装安装包需要打开「未知来源」授权：系统设置 → 应用 → 找到浏览器或文件管理器 → 安装未知应用 → 允许。授权完就可以正常安装了。

### 安装流程

1. 下载完成后用文件管理器找到 APK，点击打开
2. 系统弹出「是否允许安装」时选确认
3. 等待安装进度条走完，桌面会出现 Gator 图标

> [!NOTE]
> 部分机型的系统安全策略会对第三方安装包做风险提示——只要是从官方下载页获取的包，选择「仍然安装」即可。

## 📖 Gator 使用入门

第一次打开 Gator 会引导授予必要权限——最关键的是「允许访问所有文件」，System Cleaner 和 Exporter 都依赖这个权限才能正常扫描。没有这个权限的话，清理结果会非常有限，SD 卡搬运功能直接扫不出东西。

### System Cleaner：日常清理主力

System Cleaner 是用得最多的功能，打开后会扫描四类内容：

| 清理项 | 说明 | 大小参考 |
| --- | --- | --- |
| 残留文件 | 卸载应用后留下的目录和空文件 | 几十 MB 到几百 MB |
| 应用缓存 | 各应用产生的临时缓存 | 几百 MB 到几 GB |
| 系统日志 | 系统和应用的日志文件 | 通常很小 |
| 浏览器历史 | 浏览器缓存的网页数据 | 几十 MB |

> [!TIP]
> 如果设备已经 root，System Cleaner 会多出一项「临时 root 数据」——这是 Magisk 等 root 工具运行时产生的临时脚本片段，普通清理工具扫不到。没 root 的设备上这一项不会出现，属于权限限制而非故障。

扫描完成后勾选要清的项，点清理就完成了。日常使用建议一两周跑一次，缓存长得最快，通常一次能清出几个 GB。

### App Manager：应用管理

App Manager 可以批量卸载应用、查看应用详情。一个容易困惑的点是——系统自带应用的卸载按钮是灰的、点不动。这不是 bug，是 Android 的分区保护机制：系统应用放在 `/system/app/` 或 `/system/priv-app/` 分区，运行时只读，没有 root 权限的进程删不掉。

| 设备状态 | 卸载按钮表现 |
| --- | --- |
| 无 root | 系统应用按钮灰掉，用户应用正常可卸 |
| 已 root | 全部应用都能卸载 |

没 root 但想控制预装应用，替代方案比硬删更稳妥：系统设置里「禁用」应用、关掉推送通知、或者桌面隐藏图标——效果跟卸载差不多但不会碰系统分区。

### Exporter：文件搬到 SD 卡

Exporter 是 Gator 里比较特殊的一个功能——它做的是「移动」而不是「复制」，文件会从原位置搬到 SD 卡，原位置自动删除。常见的坑有几个：

**扫完列表是空的**——先查 SD 卡是否被系统识别（设置 → 存储里能不能看到），再查 Gator 的「所有文件访问」权限有没有被系统收回。权限被自动收回是 Android 的省电策略导致的，偶尔会发生，重新打开就行。

**搬一半弹无权限**——目标目录可能不允许写入。不要用 SD 卡根目录的系统级文件夹（比如 `/DCIM`、`/Android`），Exporter 自动创建的「Gator Export」文件夹通常没问题。先拿文件管理器手动往 SD 卡拷个小文件验证能不能写进去，确认卡本身没坏再跑 Exporter。

**搬完原位置文件还在**——这是 Android SAF 框架的一个常见行为：它把「移动」拆解成复制 + 删除，复制成功但删除原文件那步可能被系统拦截。如果 SD 卡上已经有了，手动把原位置那份删掉就行，纯浪费空间。

> [!WARNING]
> 某些机型把 SD 卡格式化成「内部存储扩展」后，系统会把 SD 卡和内部存储合并成一个存储池，不再当作外置存储识别——这种情况下 Exporter 确实找不到外置设备，用不了。想恢复的话需要在系统设置里把卡重新格式化为「便携存储」（会清空卡上数据）。

### Scheduler：定时自动清理

Scheduler 解决的是「不想记得手动清理」的需求——设定好时间和周期，Gator 到点自己跑 System Cleaner。

创建定时计划很简单：Dashboard 最后一张卡片点进去 → 选执行时间和周期 → 勾选要自动执行的清理项 → 保存。推荐凌晨 3 点左右执行，设备闲置概率最高，不会被弹窗打断。

但有两个必须知道的限制：

一是**缓存清理需要无障碍服务**。Android 限制应用后台直接清其他应用缓存——Google Play 版本的清理工具都受这个限制，Gator 也不例外。没开无障碍服务的话，Scheduler 仍然会跑，但缓存那项会被跳过，残留、日志、浏览器历史这三类能正常自动清。

二是**电池优化可能收回权限**。Android 省电策略会定期检查后台 App 活跃程度，如果判断 Gator「不活跃」就会收回后台唤醒权限，定时器自然就不触发了。如果发现定时计划没按时执行，先去系统设置的电池优化里把 Gator 加到白名单。
