## ✨ AuvFun 是什么

AuvFun 是一款专为动漫爱好者打造的在线观看应用，主要面向 Android 平台用户。它聚合了多个动漫资源源站，提供番剧搜索、播放、收藏、追番提醒等一站式功能，让用户能够在一个 App 里高效管理自己的追番列表。

核心功能包括：多数据源切换、智能搜索、收藏夹分组管理、观看记录云端同步、主题皮肤自定义等。对于追番量较大、希望跨设备无缝续播的用户来说，AuvFun 的账号体系和云端同步能力能省去不少手动找进度的麻烦。

AuvFun 对设备要求不高，Android 5.2 及以上版本即可运行，日常使用中内存占用适中，长时间播放也不太容易触发系统杀后台（但仍建议在系统设置里把它加入省电白名单）。

## 🔧 安装步骤

AuvFun 仅提供 Android APK 安装包，安装过程和大多数第三方应用一样，需要处理「未知来源」权限。

**第一步：允许未知来源安装**

进入手机「设置 → 安全（或应用）→ 安装未知应用」，找到你用来下载 APK 的浏览器（比如 Chrome、UC），将「允许安装未知应用」开关打开。不同机型入口名称略有差异——小米叫「安装未知应用」，华为叫「允许安装未知来源应用」，OPPO 在「安全中心」里。

> [!WARNING]
> 这一步很关键，如果没开权限直接点安装包会提示「无法解析安装包」或直接跳回。装完建议关掉这个权限，避免误装其他来源不明的 APK。

**第二步：下载并安装**

1. 用浏览器打开下载页，下载对应版本的 APK 文件
2. 下载完成后在通知栏点 APK 文件名，或用文件管理器找到下载目录下的 APK
3. 弹出安装界面后点「安装」，等待几秒完成
4. 安装完成点「打开」即可启动 AuvFun

**第三步：核对版本**

首次启动后进入「我的 → 设置 → 关于」，确认版本号和你下载渠道标注的一致。如果版本号对不上，可能是下载到了旧版，建议重新下载覆盖安装。覆盖安装不会清除账号数据和本地缓存，放心操作。

> [!TIP]
> 安装前建议核对一下 APK 文件大小，避免下载到残缺包导致后续闪退。下载页通常会标注文件体积，一般在 20~40MB 之间，偏差超过 5MB 就要警惕了。

如果安装时手机提示「该应用可能包含恶意内容」，可以忽略继续安装——这是 Android 的标准安全提醒，AuvFun 本身是正规的番剧观看工具。

## 📖 使用入门

AuvFun 的界面设计比较直观，底部 Tab 栏一般是「首页 / 分类 / 搜索 / 我的」四大模块。新用户上手大概需要 10~15 分钟熟悉主要功能，下面分几个高频场景介绍。

**多数据源切换**

AuvFun 内置了多个番剧资源源站，用户可以自由切换。不同源的番剧更新速度、清晰度、字幕质量可能有差异。切换入口通常在播放页的源选择下拉菜单，或者设置里的「数据源管理」。如果遇到某部番在当前源搜不到、或者播放卡顿，换一个源往往能解决。

**主题皮肤切换**

AuvFun 从 v2.1 版本开始支持多套内置主题皮肤，入口在「我的 → 设置 → 主题与外观」。常见的主题包括默认深色、默认浅色、粉色少女、赛博朋克、简约纯白、宫崎骏主题等，每套主题都是预设好的整套视觉方案，一键切换后立即生效，首页、分类页、播放页、设置页会全部替换。

| 主题名 | 风格 | 适合人群 |
|--------|------|----------|
| 默认深色 | 深灰底 + 白色文字 | 夜间 / 低光环境看番 |
| 默认浅色 | 白底 + 深色文字 | 白天光线充足环境 |
| 粉色少女 | 粉紫色渐变 | 喜欢柔和色调的用户 |
| 赛博朋克 | 霓虹蓝紫 + 荧光边框 | 喜欢炫酷科技风的用户 |
| 宫崎骏主题 | 柔和绿蓝色调 + 手绘感 | 吉卜力工作室风格爱好者 |

部分版本还支持主色调自定义（在预设色板里选）、字号三档调节（大/中/小）、夜间自动切换（设定时间段比如晚上 7 点到早上 7 点自动切深色）。主题设置和账号绑定，换设备登录同一账号后主题偏好会同步过去，清缓存也不会删掉。

**收藏夹分组管理**

追了十几二十部番剧后如果不整理，收藏夹会越来越乱。AuvFun 支持创建自定义分组来分类管理，比如可以按追番节奏分组：

| 分组名 | 放什么 |
|--------|--------|
| 正在追 | 当前每周追的连载中番剧 |
| 看完等完结 | 还在连载但暂时搁置的 |
| 想入坑 | 听说口碑好但还没开始看的 |
| 二刷 | 看过一遍想重温的经典 |
| 剧场版 | 剧场版动画电影 |

添加收藏很简单：在番剧详情页或播放页点星号图标即可，收藏后图标变成实心。部分版本支持点收藏时直接选择分组。分组管理操作方面，可以在收藏夹页点「+」创建新分组、长按番剧选择「移动到」其他分组、删除分组后该组内番剧会自动移到「全部收藏」里不会丢失。

> [!TIP]
> 把连载中的番剧加入收藏后，更新时会收到通知栏推送（前提是开了通知权限），收藏页也会在最新更新的番剧旁显示「新」或「N 话已更新」标记，点标记能直接跳到最新一集开始播放。

**观看记录云端同步**

这是 AuvFun 比较实用的一个功能——v2.2 及以上版本登录账号后，观看记录会自动同步到云端。每部番剧看到第几集、第几分钟、上次观看时间都会被记录下来。换设备时，只要登录同一个账号，打开番剧详情页点「继续观看」就能直接跳到上次暂停的位置，连倍速、清晰度、弹幕设置也会自动恢复。

**闪退或卡顿排查**

AuvFun 偶尔会出现闪退或卡顿，大部分情况能通过简单步骤修复。如果一打开就闪退，多半是版本 bug 或系统兼容问题，先试试更新或覆盖安装；如果看一会儿就卡，可能是内存不够，关掉后台多开的视频类和游戏类应用、或者把 AuvFun 加入系统省电白名单。还有一种情况是长时间运行后临时数据堆积，可以在 AuvFun 设置里清缓存——注意是「清缓存」不是「清数据」，后者会把账号登录、观看记录、收藏夹本地部分全部清掉。

| 现象 | 可能原因 | 快速尝试 |
|------|----------|----------|
| 一打开就闪退 | 版本 bug 或系统兼容问题 | 更新 / 覆盖安装 |
| 看一会儿卡 | 内存不够或后台进程多 | 清后台 / 重启手机 |
| 长时间运行变慢 | 临时数据堆积 | 清缓存 |
| 只有某个页面闪退 | 特定数据源有问题 | 换源或跳过那个 |

如果以上都试过还闪退，最后手段是卸载重装——卸载前先在 AuvFun 里退出登录（确保账号数据云端有），卸载后重启手机再装，登录账号后收藏夹和观看记录会从云端同步回来。但要注意，游客模式下（不登录）的收藏夹和观看记录只在本地，卸载就没了。
