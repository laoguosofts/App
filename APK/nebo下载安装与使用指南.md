## ✨ Nebo：手写笔记的智能魔法

Nebo 是法国 MyScript 公司开发的一款手写笔记应用，它的核心卖点是 **Interactive Ink 技术**——把手写笔迹实时转化为可搜索、可编辑的结构化数字内容，支持 66 种语言识别，还能自动识别手写数学公式、转换完美几何形状。2025 年初，MyScript 对产品线做了品牌整合：iOS / Android 端的 Nebo 正式更名为 **MyScript Notes**，Windows 端继续保留 Nebo 原名，但三端数据格式完全兼容、使用同一个 MyScript 账号、云同步互通。

对于学生来说，Nebo 可以替代纸质笔记本做课堂记录，课后直接搜索手写内容复习；对于职场人士，它能把会议纪要的手写草稿快速转成可编辑的文档导出；对于手写爱好者，笔势编辑（勾除、下划线、断点、连接）让手写内容像打字一样好改好整理。免费版已经开放了绝大部分核心功能，足够充分体验它的能力——真正需要付费的核心分界线其实只有两个：**每本笔记本 5 页的页数限制**，以及 **AI 功能（总结、解释、测验、闪卡）**。

> [!TIP]
> 如果你在改名前已经买过 Nebo 的终身版，完全不用担心——iOS / Android 端自动获得 MyScript Notes 的永久使用权，Windows 端继续用 Nebo 原名，功能不变，所有后续更新继续免费。在 App Store / Google Play 搜索 MyScript Notes 安装后登录原来的账号，点一下"恢复购买"就能解锁完整版。

## 🔧 安装步骤（三端对照）

安装过程非常顺畅，各平台都是标准的应用商店安装流程，下载量在几十 MB 到一百多 MB 之间。安装前建议先确认设备系统版本在官方要求之上，避免装完启动异常。

### iOS / iPadOS 安装（MyScript Notes）

1. 打开 **App Store**，搜索 **MyScript Notes**（注意不是 Nebo，已经更名）
2. 点击获取，等待下载安装完成
3. 首次启动选择"新建 MyScript 账号"或"登录已有账号"
4. 如果之前买过 Nebo 终身版，登录后在设置里点 **"恢复购买"** 即可解锁完整版

### Android 安装（MyScript Notes）

1. 打开 **Google Play**，搜索 **MyScript Notes**
2. 点击安装，完成后启动应用
3. 登录或注册 MyScript 账号
4. 老用户点"恢复购买"解锁终身版

### Windows 安装（Nebo）

1. 打开 **Microsoft Store**，搜索 **Nebo**（Windows 端保持原名）
2. 点击获取，安装完成后启动
3. 登录 MyScript 账号与移动端数据同步
4. Windows 版目前只有买断制，没有订阅选项

> [!NOTE]
> 免费版默认开启，不需要主动选择。想升级付费版：iOS / Android 在应用内购买订阅或终身买断；Windows 在 Microsoft Store 内购买。付费后所有移动端设备最多同时登录 10 台。

## 📖 核心功能与使用技巧

### 先搞清楚：免费版到底能用什么

免费版开放了 Nebo 的绝大部分核心能力，足够让你体验到它最拿手的东西。下面是免费版 vs 付费版的功能对照：

| 功能 | 免费版 | 付费版 |
|------|--------|--------|
| Interactive Ink 手写识别 | ✅ | ✅ |
| 手写转文字（套索选 → 转） | ✅ | ✅ |
| 66 种识别语言 | ✅ | ✅ |
| 笔势编辑（勾除/下划线/断点/连接） | ✅ | ✅ |
| 荧光笔 / 高亮 | ✅ | ✅ |
| 套索工具（选/移/删/转文字） | ✅ | ✅ |
| 完美形状转换 | ✅ | ✅ |
| 手写数学公式识别 | ✅ | ✅ |
| PDF 导入与批注 | ✅ | ✅ |
| PDF 导出 | ✅ | ✅ |
| 搜索手写内容 | ✅ | ✅ |
| 云同步（iCloud/Google Drive/Dropbox） | ✅ | ✅ |
| **每本笔记本页数** | **限 5 页** | **无限** |
| **AI 功能（总结/解释/测验/闪卡）** | ❌ | ✅ |
| **高级导出（Word/LaTeX/PPT）** | ❌ | ✅ |

> [!TIP]
> 关于 5 页限制的澄清：限制只针对**新建的笔记本**，已经写了 5 页的笔记本不会被删第 6 页（但不能再加新页）；白板和 PDF 模式不受页数限制，可以继续使用；可以创建多个 5 页以内的笔记本组合使用。

### 两种高亮方式，各有用场

Nebo 提供了两种给内容加高亮标记的方法——**荧光笔工具**和**笔势下划线**，它们效果类似但用途不同：

| 方式 | 操作 | 特点 | 适合场景 |
|------|------|------|---------|
| 荧光笔工具 | 切换到荧光笔 → 选择颜色 → 直接画 | 文字背景上色，独立于手写笔画层 | PDF 批注、课堂笔记、多颜色编码 |
| 笔势下划线 | 保持书写笔 → 在内容下方画波浪线 | 不切换工具，纯手写节奏 | 快速强调、纯文本导出保留、打字内容加下划线 |

荧光笔的好处是可以用不同颜色做编码系统——黄色标核心重点、红色标疑问、蓝色标自己的补充思考、绿色标已掌握内容，后期复习时一眼就能看出哪些需要重点过。荧光高亮是独立层，可以单独删除不影响底下的手写内容。

笔势下划线的优势是效率更高——不用切换工具，写着写着发现要强调，直接在下方画条线就行。而且下划线在纯文本导出时还能保留为 `__下划线__` 格式，荧光笔背景色就丢了。纯文本导出、打字内容强调、或者追求手写节奏不中断时选下划线更合适。

### 误删了怎么办？三级恢复机制

Nebo 提供了从最快到最兜底的三层恢复手段，按顺序排查就行：

**第一级：撤销（最快）**

刚删错立刻发现时用。Windows 按 `Ctrl+Z`，iPad / Android 两指轻点屏幕，或者点工具栏的 ← 箭头。可以撤销的操作包括：最后写的那一笔、最后一次勾除、最后一次下划线、最后一次套索删除、最后一次形状转换。撤销步数几乎没有限制，可以一直回到打开笔记时的初始状态。

**第二级：回收站（版本 5.8+）**

过了撤销窗口想找回删除的笔记本、文件夹或集合时用。打开 Nebo 主界面，在库视图顶部或侧边栏找到"回收站"，长按或右键要恢复的项目 → 恢复，项目会回到原来的位置。注意：回收站只能恢复整个笔记本 / 文件夹 / 集合，**笔记本内的单个页面删除是永久的**，回收站救不了单页。

**第三级：云同步版本历史（兜底）**

本地删了、回收站也清了，还想找回更早版本？Nebo 自动同步到云端时，Google Drive / Dropbox 会保留文件的版本历史。打开 drive.google.com 或 dropbox.com，找到 Nebo 同步的文件夹，右键文件 → 版本历史记录，选择想恢复的版本就行。iCloud Drive 不直接提供版本历史，但 macOS 的 Time Machine 可以恢复。

> [!WARNING]
> 以下内容删了是真的恢复不了：笔记本内的单个页面（Nebo 不保存单页历史）、页面上的部分手写笔画（超过撤销窗口就没了）、PDF 导入的原文件（Nebo 只存批注不存原 PDF）、清空回收站后的项目。

### 什么时候值得花钱升级

免费版其实能用蛮久的——每本 5 页，创建多个笔记本组合使用，笔势编辑、手写转文字、PDF 批注这些核心功能全开放，足够撑到你真正觉得 AI 功能或无限页数必要的时候。几个值得升级的信号：笔记本经常写满 5 页说明用得频繁、需要导出 Word 做正式文档、考前想做 AI 测验和闪卡、用了 6 个月以上免费版说明能长期使用。

定价方面，年订阅约 $15 / 年，终身买断约 $15–20 一次性——终身买断在使用超过 1 年后就开始划算。iOS 和 Android 都提供 7 天免费试用，可以先从订阅的试用开始，试用期结束前取消订阅，再买终身。移动端最多同时登录 10 台设备（iOS + Android 合计）。
