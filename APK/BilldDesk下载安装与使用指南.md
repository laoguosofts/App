## ✨ BilldDesk 是什么：一款跨端开源远程桌面

BilldDesk 是一款开源的远程桌面软件，主打"全端覆盖 + 批量群控"。它同时支持 Windows、macOS、Android 和 Web 浏览器四种端，四种端之间可以形成九种远控组合——电脑控电脑、电脑控安卓、安卓控电脑、安卓控安卓、网页端发起远控等等，几乎覆盖了远程协作中能遇到的全部场景。

在基础远控之外，BilldDesk 还提供了不少进阶能力：屏幕墙可以一屏同时查看数十台被控设备的实时画面，群控模式能对多台设备同时发送相同的键鼠指令，Windows 端的进程保活确保被控进程崩溃后自动重启。这些功能让它不只是个人远程办公的工具，也适合云手机工作室、游戏工作室、远程运维等需要批量管理设备的场景。

硬件加速方面，NVIDIA GTX 10 系列以上、AMD 显卡均支持 H264/H265/AV1 硬件编解码，低带宽下也能保持流畅的画面传输。

## 🔧 安装步骤与注意事项

BilldDesk 支持 Windows 10/11/Server 2019/2022、macOS 15+、Android 8-16 以及主流浏览器。安装前建议先核对自己的系统版本是否在支持列表内——Windows 7 不支持，客户端会直接提示不兼容。

### Windows 端安装

1. 下载官方安装包，双击运行
2. 选择安装路径，建议使用默认路径（`C:\Program Files\BilldDesk\`）
3. 安装过程中 BilldDesk 会尝试注册一个 Windows 后台服务（用于进程保活功能），如果杀毒软件弹窗提示，选择允许
4. 安装完成后 BilldDesk 会自动启动并在系统托盘显示图标

> [!WARNING]
> 360 杀毒等国产安全软件经常把 BilldDesk 的后台服务误报为可疑程序。建议在安装前先退出杀毒软件，或在信任列表中提前添加 BilldDesk 相关进程和服务。如果进程保活服务被杀掉，BilldDesk 被控端会失去自动重启能力。

### macOS 端安装

1. 下载 `.dmg` 安装包，打开后将 BilldDesk 拖入应用程序文件夹
2. 首次启动时右键点击 BilldDesk → 选择「打开」，绕过 Gatekeeper 安全检查
3. 在「系统设置 → 隐私与安全性」中授予三类权限：**录屏权限**、**辅助功能**（键鼠控制）、**麦克风权限**

> [!TIP]
> macOS 权限配置不当是看不到远程画面或无法控制被控端的最常见原因。如果远程连接后只有黑屏或键鼠没反应，优先检查这三项权限是否都已开启。

### Android 端安装

1. 从下载页获取 APK 文件，或在 Google Play 搜索安装
2. 首次启动需要授予三项 Android 权限：**屏幕捕获**、**无障碍服务**、**悬浮窗权限**
3. 安卓端既可以作为主控端远程控制电脑或其他安卓设备，也可以作为被控端被远程

## 📖 使用入门：从单控到群控的核心玩法

### 基础远控流程

无论是哪种端，远程控制的基本流程都是一样的：主控端输入被控端的**设备码**和**连接密码**，被控端确认同意后建立连接。远控建立后，主控端可以看到被控端的实时画面，并通过键鼠（或触屏手势）进行操作。

### 跨端远控矩阵

BilldDesk 的四端覆盖形成了一张完整的远控矩阵：

| 主控端 → 被控端 | 电脑端 | 安卓端 | 网页端 |
| --- | --- | --- | --- |
| 电脑端 | ✅ 完整远控 | ✅ 完整远控 | ✅ 仅观看 |
| 安卓端 | ✅ 完整远控 | ✅ 完整远控 | ✅ 仅观看 |
| 网页端 | ✅ 完整远控 | ✅ 完整远控 | ✅ 仅观看 |

电脑端和安卓端作为被控端时支持完整的键鼠操作，网页端作为被控端时仅支持被观看画面。

### 安卓手机远程电脑的触控手势

安卓端远程控制电脑时，主要通过触屏手势模拟键鼠：

| 手势 | 对应电脑操作 |
| --- | --- |
| 单指移动 | 鼠标移动 |
| 单指点击 | 鼠标左键点击 |
| 单指长按 | 鼠标右键点击 |
| 双指点击 | 鼠标中键点击 |
| 双指滑动 | 鼠标滚轮滚动 |
| 双指张开/合拢 | 画面放大/缩小 |

远程窗口上方有浮动工具栏，提供虚拟键盘（Ctrl/Alt/Shift/功能键）、截图、结束远程、画质调整等快捷操作。如果用移动数据远程，建议把画质降到 720P 或更低以节省流量。

### 屏幕墙：批量查看多台设备

屏幕墙是 BilldDesk Pro 的高阶功能，可以在一个界面中同时显示多台被控设备的实时画面，像监控墙一样。适用场景包括云手机工作室、游戏工作室、远程运维、教育培训等需要批量管理设备的场景。

> [!NOTE]
> 屏幕墙需要 Pro 版客户端，开源版不支持。被控端系统目前仅支持 Windows 和 macOS，暂不支持 Android 被控端的屏幕墙。

屏幕墙的基础操作：登录同一个 BilldDesk 账号 → 在屏幕墙界面选择要显示的设备 → 被控端同意后画面出现在屏幕墙中。点击任一画面可以切换到单控模式，专注操作某一台设备。群控模式（对多台设备同时发送相同指令）同样需要 Pro 版支持。

### 进程保活：Windows 端的无人值守保障

BilldDesk Pro 在 Windows 端支持进程保活功能。安装后会注册一个后台服务，定期监控 BilldDesk 被控进程。如果进程意外崩溃、被杀毒软件误杀或被用户手动关闭，后台服务会自动把它重新启动，确保远程通道始终可用。

进程保活和开机自启是两个互补的功能：开机自启保证"开机就有"，进程保活保证"不中途掉"。如果进程保活没有正常生效，可以在 BilldDesk 设置中检查开关是否已开启，或尝试重装客户端重新注册 Windows 服务。

### 画质与硬件加速

NVIDIA GTX 10 系列以上、AMD 显卡均支持 H264/H265/AV1 硬件编解码，低带宽下也能保持流畅传输。1080P + 60 FPS 的画质下，远程控制一分钟可能消耗数 MB 到数十 MB 流量，建议在 Wi-Fi 环境下使用，移动数据远程时降低画质。
