## ✨ Key Mapper 是什么——把物理按键变成你的万能快捷键

Key Mapper 是一款专为安卓设备打造的按键重映射工具。它做的事情一句话就能说清：把手机上那些默认功能固定的物理按键——音量键、电源键、指纹传感器甚至外接手柄键盘的按钮——重新定义成你想要的任何动作。核心设计分三层：**触发器**（按下什么键触发）、**动作**（触发后干什么）、**约束**（在什么条件下才生效），三层自由组合，覆盖的玩法几乎没有边界。

日常使用里最常见的场景包括：把音量减改成一键启动相机、把电源键双击改成手电筒、游戏里把组合键映射成手柄按钮、阅读应用里用指纹下滑翻页、甚至把多键序列设成快捷指令模拟键盘连招。只要是安卓设备上能触发的系统动作或应用跳转，理论上都能被 Key Mapper 接管。

这款工具对三类用户特别有价值：**重度手游玩家**（自定义游戏操作、用物理键替代触控）、**残障辅助需求者**（把物理键映射成辅助功能）、**老设备复用者**（让淘汰的物理键焕发第二春）。它不需要 root，依赖的是安卓无障碍服务和系统授权，安装门槛低，但需要认真对待首次启动时弹出的几个权限告警——跳过后键映射大概率会随机失效。

## 🔧 安装与首次配置——三条告警一个都别跳

### 安装流程

1. 从下载页面拿到 APK 文件，在手机上点击安装。如果提示「禁止安装未知来源应用」，去 **设置 → 安全** 里打开「允许安装未知来源应用」开关
2. 安装完成后首次启动，应用会引导你完成三次权限授权——**这三步必须全部通过**，否则键映射无法稳定工作

### 首次启动的三条告警

Key Mapper 首次启动时主页顶部会列出三条待处理告警，每条右侧都有一个 **FIX** 按钮，点一下就跳到对应的系统设置页面：

| 告警项 | 为什么需要 | 跳过的后果 |
|---|---|---|
| 无障碍服务 | Key Mapper 的核心服务，负责后台监听按键事件 | 所有键映射完全不生效 |
| 电池优化 | 安卓厂商的省电策略会随时清理后台服务 | 键映射用着用着突然失效，重启应用后又好 |
| 免打扰访问 | 音量键与勿扰模式深度绑定，录制音量键触发器时必需 | 音量键在勿扰模式下失灵或无法正确接管 |

> [!WARNING] 电池优化是最高频的问题
> 「上午还能用、下午就没了」——十有八九是电池优化把后台服务清掉了。华为、小米等厂商的清理策略尤其激进，除了关掉电池优化外，还要在自启动管理里放行 Key Mapper。社区维护的 dontkillmyapp.com 按品牌整理了每个机型的完整关闭路径，找不到入口时去那里查。

### 验证安装成功

三个权限全部授权后，主页的黄色告警会消失。此时创建一个最简单的键映射来验证：比如把音量减改成打开计算器。锁屏放一晚，第二天不解锁直接按音量键——如果计算器还能弹出，说明服务稳定了。

## 📖 使用入门——从录下第一个按键到玩转进阶手势

### 录制触发器：五步搞定单键映射

触发器是键映射的入口，告诉 Key Mapper 「按下什么键时触发」。完整录制流程只有五步：

1. 主页点底部的**加号**，进入键映射编辑页
2. 默认停在 **TRIGGER** 标签，点红色的 **Record trigger** 按钮
3. 按下你想改功能的物理键（比如音量减），它会被记进列表
4. 按法不对就补设置：短按/长按/双击（点击类型），多键时选同时按/依次按
5. 点保存图标，触发器就挂在键映射上了

> [!NOTE] 录制音量键的特殊提示
> 录制音量键时会立刻弹出免打扰访问错误提示——这是音量键特有的前置权限，按提示授权即可。其他按键（比如电源键、手柄按键）一般不会报错。

### 多键组合：并行与序列两种模式

Key Mapper 支持两类多键组合，覆盖不同场景：

- **同时按（并行）**：先点第一个键、再点第二个键，保持都按住。适合模拟 Ctrl 式的组合键，全部按住才触发
- **依次按（序列）**：按顺序按下再松开，每个键之间有超时（默认 1000 毫秒）。适合「连招」式触发，比如依次按音量加、音量减、电源键执行某条指令

触发器录错了也不怕——点已录按键右侧的三点菜单，可以改点击类型、删掉重录，录制的按键还能拖动排序（序列模式下顺序就是按下顺序）。还有一个容易忽略的开关：**不覆盖默认行为**，打开后按键会同时执行原功能和你的动作（比如音量键既调音量又开应用），默认是关闭的。

### 关掉电池优化：根治随机失效

Key Mapper 的无障碍服务需要在后台**常驻**监听按键。安卓厂商为了省电，普遍会对后台服务做电池优化——本质是允许系统随时冻结或杀掉不活跃的应用。两者天然冲突：系统一旦清理 Key Mapper，所有键映射立刻失效，而且你不会收到任何提示，只是按键「突然恢复原样」。

关闭路径很简单：主页点「电池优化」告警右侧的 **FIX** 按钮，系统会打开电池优化列表，在里面找到 Key Mapper，选择**不优化**（部分机型叫「无限制」「允许后台运行」「关」）。

> [!TIP] 厂商差异
> 华为与小米的后台清理格外激进，除了电池优化外还要在自启动管理里放行 Key Mapper。2GB 及以下内存的设备内存压力本身就大，边玩游戏边用 Key Mapper 时更容易被挤掉，建议把其他后台应用也清一清。

### 免打扰访问：音量键重映射的前置条件

如果你打算重映射音量键——这是 Key Mapper 最常见的用途之一——免打扰（勿扰模式）访问权限是绕不开的一步。音量键在安卓里和勿扰模式绑定得比想象中深：没有勿扰访问权限的话，音量键映射要么在勿扰模式下失效，要么根本无法正确接管音量键。授权的本质是允许 Key Mapper 读取和写入勿扰配置，从而在按键时正确处理音量行为。

授权步骤：在主页点「免打扰访问」告警右侧的 **FIX** 按钮（或直接点触发器下方的错误提示），系统会打开「勿扰访问权限」列表，找到 Key Mapper 勾选**允许**，返回键映射编辑页，错误提示消失即可。

不用音量键的话这条权限可以跳过——你只映射手柄、键盘或指纹手势时，主页不会出现这条告警。

### 指纹手势：挖掘被忽略的输入通道

指纹传感器不只是解锁工具。部分安卓设备的指纹区（通常是后置指纹）还能识别**上、下、左、右四个方向的滑动**，Key Mapper 在 2.2.0 版本之后支持把这四个方向手势重映射成动作，相当于多了四个免费的快捷键。

但这个功能的兼容性碎片化严重，设备分三类：

| 设备类型 | 能识别方向手势 | 允许第三方读取 | 能否重映射 |
|---|---|---|---|
| 第一类 | ✅ | ✅ | 完整支持 |
| 第二类 | ✅ | ❌ | 无解（系统锁死） |
| 第三类 | ❌ | — | 无解（多为屏下指纹） |

判断方法很简单：直接进应用试一遍，主页切到 **Fingerprint** 标签，四个方向手势各占一格，能录下手势就能用，录不到就属于后两类——**不必再折腾**，这是硬件与系统层的能力边界，不是软件问题。手势的动作选项和键映射基本一致，长按类选项换成了滑动语义（按住直到再次滑动、重复直到再次滑动），约束（应用前台、时间、充电状态）也同样可用。

实用场景参考：指纹下滑=下拉通知栏（不用够屏幕顶部）、指纹左右滑=切歌（口袋里盲操作）、指纹上滑=打开相机（快拍场景）。

### 常见问题速查

- **按键识别不到**：先检查无障碍服务有没有启动，再确认电池优化已关闭。部分机型的特定按键（比如某些游戏手柄的 home 键）系统层就拦截了，Key Mapper 无法绕过
- **映射不覆盖默认行为怎么办**：在触发器的三点菜单里打开「不覆盖默认行为」开关，按键会同时执行原功能和自定义动作
- **游戏里键映射冲突**：建议在约束里指定「仅在某应用前台时生效」，避免影响其他场景
