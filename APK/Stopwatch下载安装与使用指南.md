## ✨ Stopwatch 是什么：把秒表浮在屏幕上的计时工具

Stopwatch 是一款面向 Android 平台的悬浮秒表应用，核心卖点是把计时器直接以悬浮窗的形式常驻屏幕——无论你是在玩游戏、看视频、刷网页还是切到任何其他应用，计时数字始终可见，点按一下就能开始或暂停，全程不需要跳出当前场景。

这款应用主打轻量和专注：没有臃肿的社交功能，没有强制的广告推送，打开就是计时界面。支持最多五个计时器槽位同时运行，每个槽位可以独立设置秒表或倒计时模式，配不同颜色区分状态。对于需要边做别的事边盯着时间的用户来说，它比系统自带秒表和大厂方案都更顺手。

常见的使用场景包括：厨房炖煮多道菜同时计时、健身训练组间休息、游戏里记副本刷新倒计时、学习时用番茄钟控制专注时长——任何"需要计时但不想切应用"的时刻都能用得上。

## 🔧 安装步骤：三到五分钟搞定悬浮权限

Stopwatch 是 Android 应用，安装过程和普通 APK 类似，但悬浮窗权限需要手动开启。下面一步步走。

### 第一步：安装 APK

从下载页拿到安装包后，在手机上点开文件管理器找到 APK 文件直接安装。系统可能会弹出「未知来源应用」的拦截提示：

> [!WARNING]
> Android 8.0 及以上版本首次安装外部 APK 时，需要给当前文件管理器授予「允许安装未知应用」权限。路径通常在：设置 → 安全 → 安装未知应用 → 选择你用的文件管理器 → 开启允许。

授权后回到 APK 点击安装即可。完成后桌面上会出现 Stopwatch 的图标。

### 第二步：开启悬浮窗权限

这是关键一步，权限没开会导致秒表无法浮在其他应用之上。悬浮窗权限的官方名称叫「显示在其他应用上层」，各品牌手机的开启路径不同：

| 品牌 | 参考路径 |
| --- | --- |
| 原生安卓 / Pixel | 设置 → 应用 → Stopwatch → 权限 → 附加权限 → 显示在其他应用上层 |
| 小米 / 红米 | 设置 → 隐私保护 → 特殊权限 → 显示在上层（悬浮窗） |
| 华为 / 荣耀 | 设置 → 应用 → 权限管理 → 更多 → 悬浮窗 |
| OPPO / vivo | 设置 → 安全（或隐私）→ 悬浮窗管理 |
| 三星 | 设置 → 应用 → 选择应用 → 权限 → 显示在其他应用上层 |

> [!TIP]
> 最快的方法：在系统设置顶部搜索框直接输入「悬浮窗」或「上层」，系统会自动定位到权限入口。从应用内也可以跳转——打开 Stopwatch 主界面，首次使用时会弹出权限引导，点确认直接跳到设置页。

### 第三步：验证权限生效

开完权限后，回到 Stopwatch 主界面，把任意一个秒表的开关**先关掉再打开**——这一下是重建悬浮窗的动作，很多人开了权限但悬浮窗不出现，卡的就是没做这一步。如果还是不出现，检查一下系统有没有省电模式在限制后台弹窗。

## 📖 使用入门：手势、槽位与场景配置

安装完成后打开 Stopwatch，主界面是五个空槽位，每个槽位可以独立运行。下面从最基础的手势开始，逐步讲到日常高频场景的配置方法。

### 悬浮窗手势总览

Stopwatch 的全部操作都围绕悬浮窗本体进行，不需要回到主应用点按钮：

| 手势 | 作用 | 使用场景 |
| --- | --- | --- |
| 点一下悬浮窗 | 开始 / 暂停计时 | 最常用的动作，任何时刻都能操作 |
| 双击悬浮窗 | 复位清零 | 一轮计时结束后重新开始 |
| 长按悬浮窗 | 退出该秒表 | 槽位用完了清理掉，会弹确认框防误触 |

> [!NOTE]
> 暂停状态下悬浮窗颜色会自动切换成另一种配色，不用凑近读数字就能一眼看出哪个表在跑、哪个停了。运行色和暂停色可以在设置页自定义。

### 锁定位置防误拖

悬浮窗随手能拖到屏幕任意位置，这是优点也是误触来源——玩游戏时拇指蹭一下，秒表就从角落飞到屏幕中间了。Stopwatch 在设置页提供了「锁定秒表位置」开关：

1. 主应用 → 设置页 → 打开「锁定秒表位置」
2. 锁定后，拖动手势失效，游戏、口袋、包里的碰撞都不会挪乱位置
3. 但计时手势（点按、双击、长按）完全不受影响——锁的是位置，不是操作

推荐的使用节奏：刚装好或刚调整完外观（大小、颜色、透明度）时先不锁定，把秒表拖到屏幕上缘或侧边、拇指活动区外的位置摆好，再打开锁定长期使用。

### 倒计时与到点提醒

除了正计时秒表，每个槽位还支持切换到倒计时模式，这在厨房场景特别好用。设置步骤：

1. 在槽位上点开编辑面板，切换到「倒计时」模式
2. 设定目标时长——炖煮 30 分钟、炒菜 45 秒，按工序来
3. 勾选「到点震动」，手机不用盯屏幕也能接收到提醒

> [!TIP]
> 长时间倒计时建议搭配「循环倒计时」功能：设置好一个时长后勾上「结束后重复」，到点震一下自动重新开始。比如需要每隔 10 分钟翻面一次的烹饪工序，设 10 分钟循环就不用反复手动操作了。

### 多表同屏：五道菜同时盯

Stopwatch 最实用的功能之一就是五个槽位独立运行，每道菜一个表：

- 汤设 40 分钟红色标签、青菜设 15 分钟绿色、米饭设 25 分钟白色，颜色一配谁在走谁到了一眼分清
- 手机斜靠在灶边（平放时震动偏弱），菜谱视频在全屏播放，五个倒计时浮在视频上同时跑
- 油手操作全程只碰悬浮窗，不摸手机屏幕——点按暂停、双击清零都在浮窗上完成，干净又省心

锁屏状态下悬浮窗依然可见，长时间炖煮不用特意开屏幕常亮也能瞟一眼时间。
