## ✨ AirMirror 是什么

AirMirror 是 AirDroid 产品线中专门负责「远程控制」的客户端——简单说就是**一台手机远程操控另一台手机**的工具。它跑在控制端（发起远程的那台），配合被控端安装的 AirDroid 个人版，让你在任何有网络的地方都能看到对方手机的屏幕、点按对方手机的界面、甚至打开对方的摄像头远程看画面。

它的核心能力分两条独立的功能线：**远程访问**和**远程协助**。远程访问是你自己登录 AirDroid 账号、远程管自己的设备——比如在外头帮家里老人看看手机状态、或者把闲置旧安卓改造成远程监控摄像头。远程协助是你作为协助方、帮一台没你账号的设备解决问题——比如远程帮朋友调设置、教父母用某个 App。两条线的会员体系也是分开的，买错会员是很多新用户踩过的坑。

AirMirror 的远程控制不需要 root——被控端只要在 Android 7.0+ 上开启辅助权限（无障碍服务）就能实现系统级的点按和滑动，安全风险比 root 方案低得多。局域网内的远程访问功能完全免费、无限时长、不消耗任何流量配额，是这个工具最吸引人的地方。外网远程则消耗 AirDroid 会员的流量额度，免费账户每月有 200MB 的配额。

> [!NOTE] iOS 版 AirMirror 有一个有趣的特性：它不支持远程访问模式下的远程控制功能（苹果系统限制），但远程相机和屏幕镜像功能可以跨平台使用——iOS AirMirror 发起远程相机请求，Android AirDroid 响应，画面照样能传回来。

适合谁用？多台设备需要跨地点管理的个人用户、想远程监护家里老人小孩的家庭、偶尔需要远程帮朋友解决手机问题的技术党、以及想把闲置安卓机改造成监控摄像头的折腾党。

## 🔧 AirMirror 安装与初始化设置

AirMirror 本身的安装很简单，但想用得顺畅，被控端的初始化配置才是关键——尤其是 Android 厂商 ROM 的各种权限拦截，是很多人第一次用就卡住的地方。

### 控制端（AirMirror）安装

1. 在手机应用商店搜索「AirMirror」并安装（iOS / Android 均有对应版本）
2. 首次打开 AirMirror，登录你的 AirDroid 账号（远程访问模式）——如果还没有账号，在 AirDroid 官网或任意 AirDroid 产品端注册一个

> [!TIP] 远程协助模式不需要 AirDroid 账号——协助方直接在 AirMirror 里发起协助请求，被控端安装 AirDroid Remote Support 并输入 9 位连接码即可，是匿名的一次性会话。

### 被控端（AirDroid 个人版）关键配置

远程访问模式下，被控端需要安装 AirDroid 个人版并完成以下几步一次性配置：

1. **登录同一 AirDroid 账号**——控制端和被控端必须登录同一个账号才能看到彼此
2. **开启辅助权限**——进入系统设置 → 辅助功能 / 无障碍，找到 AirDroid 远程控制辅助服务并打开。这是远程控制能模拟点按的系统级通道，不 root 就能用
3. **在 AirDroid App 内打开远程功能开关**——进入「个人」→「安全及远程功能设置」，分别打开远程控制、远程相机、屏幕镜像的开关

| 权限 | 通用路径 | 作用 |
| --- | --- | --- |
| 辅助权限 | 设置 → 辅助功能 → AirDroid → 开启 | 远程控制的基础 |
| 悬浮窗 | 设置 → 应用 → AirDroid → 显示悬浮窗 → 允许 | 显示 AirDroid 状态 |
| 通知权限 | 设置 → 应用 → AirDroid → 通知 → 全部允许 | 接收远程请求通知 |
| 相机权限 | 设置 → 应用 → AirDroid → 相机 → 允许 | 远程相机功能 |

### 小米 / MIUI 专项配置

小米系统的后台管理策略比原生 Android 严格得多——**如果不手动开「后台弹出界面」权限，AirMirror 的远程功能在小米设备上 99% 无法工作**。完整配置清单如下：

| 权限 | 路径 | 重要性 |
| --- | --- | --- |
| 后台弹出界面 | 设置 → 应用管理 → AirDroid → 权限管理 → 后台弹出界面 → 允许 | **核心权限，缺了远程全断** |
| 自启动 | 设置 → 应用管理 → AirDroid → 自启动 → 允许 | 防止开机后未启动 |
| 省电限制 | 设置 → 电池与性能 → AirDroid → 无限制 | 防止休眠被杀进程 |
| 辅助权限 | 设置 → 更多设置 → 无障碍 → 已下载的服务 → AirDroid → 开启 | 远程控制基础 |

找不到入口的话，在系统设置搜索框里直接搜「后台弹出界面」或「AirDroid」，系统会给你直达路径。

## 📖 AirMirror 使用入门

完成两端安装和权限配置后，就可以开始真正用起来了。远程访问和远程协助是两条完全不同的使用路径，下面分别拆解。

### 远程访问：控制自己的设备

远程访问模式下，控制端和被控端登录同一 AirDroid 账号，两台设备互相可见。在 AirMirror 主界面的设备列表里点击目标设备，会进入功能选择页，这里有三个核心入口：远程控制、远程相机、屏幕镜像。

**远程控制**是最常用的功能——点击后 AirMirror 会发送点按指令给被控端的辅助服务，被控端实时响应。你可以在 AirMirror 界面看到被控端屏幕画面，手指点哪里被控端就跟着点哪里。局域网内完全免费、无时长限制，外网则消耗流量配额。

**远程相机**是 AirMirror 独有的亮点功能——从控制端直接唤起被控端的摄像头，支持切换前后置、开关闪光灯、单向聆听。远程相机的典型玩法：

- 旧安卓机改监控：闲置安卓装 AirDroid 放家里，你在外头随时用 AirMirror 远程打开摄像头看一眼
- 远程定点拍摄：被控端架在固定位置，控制端远程触发拍摄（配合远程控制模式操作被控端的相机 App）
- 远程单向聆听：开启后可以听到被控端周围的声音，但被控端听不到你的声音——适合远程听家里婴儿哭声或老人呼救

> [!WARNING] 远程相机仅支持远程访问模式，不支持远程协助模式。而且 iOS 被控端由于系统限制，无法被 AirMirror 远程唤起摄像头。

远程相机的画面质量和网络状况强相关：局域网下最高 1080P / 30fps，外网良好时 720P / 15-20fps，弱网会自适应降级到 5fps 以下。流量消耗方面，720P 大约每分钟 15-30MB，1080P 约每分钟 40-60MB。

**屏幕镜像**本质上是单向的画面传输——控制端能看到被控端屏幕，但不能操作。适合演示、查看被控端状态等轻量场景。

### 远程协助：帮别人解决问题

远程协助模式不需要登录同一 AirDroid 账号。流程是：协助方在 AirMirror 里点击「远程协助」→ 被控端安装 AirDroid Remote Support 并进入 → 被控端会看到一个 9 位连接码 → 协助方输入连接码 → 两端建立会话。

协助会话的免费版每天有 2 分钟时长限制——2 分钟内可以共享屏幕、手势引导、语音或文字聊天。如果需要在协助中**远程控制被控端**（比如帮客户深度修复问题、设置复杂配置），就需要购买 Remote Support 套餐，套餐时长从 2 分钟变成无限，同时解锁远程控制、会话录制、多客户管理等高级功能。

远程协助模式下被控端不需要预先开辅助权限——会话建立后 AirDroid Remote Support 会临时安装一个叫 AirDroid Control Add-on 的插件，会话结束后自动关闭。这和远程访问模式的设备级永久授权形成对比，两种技术路径各自适用不同场景。

### 免费版能用多少

很多新用户对 AirMirror 的会员体系一头雾水，这里用一张表快速理清楚：

| 功能 | 免费版 | 会员版 |
| --- | --- | --- |
| 远程控制（局域网） | ✅ 完全免费 | ✅ |
| 远程控制（外网） | 200MB/月流量配额 | 无限流量 |
| 远程相机（局域网） | ✅ 完全免费 | ✅ |
| 远程相机（外网） | 消耗流量配额 | 无限流量 |
| 单向聆听 | ❌ | ✅（AirDroid 高级会员） |
| 远程协助时长 | 每天 2 分钟 | 无限（Remote Support 套餐） |
| 远程协助中远程控制 | ❌ | ✅（Remote Support 套餐） |

> [!NOTE] AirMirror 的会员体系是两套独立的：AirDroid 高级会员管远程访问的外网流量、单向聆听等；Remote Support 套餐管远程协助的时长和远程控制。**这两个会员不能互相替代**——买了 AirDroid 高级会员不代表远程协助的远程控制功能解锁，反过来亦然。

简单记：**自己的设备远程访问买 AirDroid 高级会员；帮别人远程协助买 Remote Support 套餐**。

### 辅助权限 vs root：为什么不用 root

AirMirror 的远程控制通过 AirDroid 个人版的辅助权限（无障碍服务）实现，不需要 root。对于绝大多数场景来说，辅助权限完全够用——点按、滑动、返回、Home 这些操作都能模拟，电量消耗也极低（开发者声明每 24 小时耗电约 1%）。

| 特性 | 辅助权限 | root |
| --- | --- | --- |
| 是否需要 root | 否 | 是 |
| 模拟点按 | ✅ | ✅ |
| 深度系统操作 | ❌ | ✅ |
| 厂商兼容性 | 部分 ROM 需额外设置 | 任何 ROM |
| 安全风险 | 低 | 高 |

辅助权限一旦开启会一直保持开启，直到你手动关闭。如果不再使用 AirMirror 远程控制，建议手动关闭辅助权限减少后台开销。
