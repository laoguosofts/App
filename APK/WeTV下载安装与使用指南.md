## ✨ WeTV 是什么

WeTV 是腾讯视频面向海外市场推出的正版流媒体应用，覆盖 Android、iOS、Web 等多个平台，为海外华人及东南亚观众提供华语剧集、泰剧、韩剧、日漫、综艺、电影和纪录片等多元内容。

片库的主体是国内腾讯视频的原创剧集——《庆余年》《雪中悍刀行》《斗罗大陆》动画版等热门作品大多会在境外版本同步上线或延迟上线，古装、现代、悬疑等类型都有，字幕随片源提供中、英、泰、印尼等多种语言。除了华语内容，面向泰国、印尼等主要市场，WeTV 还收录了大量泰剧、印尼剧和本地综艺，部分华语剧甚至配有泰语、印尼语配音。韩剧和日本动漫是第三大板块，多与版权方按地区合作上线。综艺方面，国内热门选秀、观察类、喜剧类综艺通常延迟一到数天上线，配合多语字幕，对境外华人来说是剧集之外最常用的板块。

> [!NOTE]
> 同一部剧在不同国家可能因授权差异而无法观看，遇到「内容不可看」提示时，这通常是地区版权限制而非应用故障。注册前建议先浏览网页端的分类页，确认想看的剧是否在当前区域可用。

适合的用户群体包括：身处海外想追国内热播剧的华人观众、对泰剧/东南亚本地内容感兴趣的亚洲观众，以及需要多语字幕辅助观看外语内容的用户。界面语言可在设置中自由切换，上手门槛很低。

## 🔧 安装步骤

WeTV 支持 Android 和 iOS 两大移动平台，以及网页端直接观看，以下分别说明安装注意事项。

### Android 安装

1. **Google Play 渠道**：直接在应用商店搜索 WeTV，点击安装即可，无需额外设置；
2. **APK 安装包渠道**：从官方下载页获取 APK 文件后，在首次安装时系统会弹出「允许未知来源应用安装」的提示，前往设备的「设置 → 安全 → 未知来源」中临时开启权限，安装完成后建议关闭以防其他应用误装；
3. **版本核对**：安装完成后在个人中心的「设置 → 关于/版本」中确认版本号与下载页标注一致，避免安装到旧版。

> [!WARNING]
> 跨区域下载 APK 时注意文件大小核对——正常安装包体积在 30~50MB 之间，明显偏小的文件可能是下载不完整或被篡改，建议删除后重新下载。

### iOS 安装

在 App Store 直接搜索 WeTV 安装即可。若在当前地区的 App Store 无法找到，需要切换 Apple ID 的地区设置（设置 → 账户 → 媒体与购买项目 → 查看账户 → 国家/地区）到支持 WeTV 的地区，再搜索下载。

### 网页端

不需要安装任何客户端，直接在浏览器访问 WeTV 官方网站即可注册、登录和观看，功能与移动版基本对齐，适合临时使用或不想占用手机存储空间的用户。

## 📖 使用入门

安装完成并登录账号后，WeTV 的核心使用流程可以围绕「找剧 → 追剧 → 离线看 → 个人管理」四个环节展开。

### 浏览片库与找剧

首页按内容类型划分为电视剧、综艺、动漫、电影、纪录片等大项，每个分类下还有更细的子分类。对于明确想看的剧，直接用顶部搜索框输入剧名或演员名即可。片库查询时注意几点：同一部剧在不同国家可能因授权差异而看不到；每周更新的剧集更新时间以详情页的集数列表为准；注册前可以先浏览网页端的分类页，确认目标内容是否在当前区域可用。

详情页除了正片集数入口，下方还有经常被忽略的「幕后花絮」等区块。花絮区里藏了不少正片之外的加分内容：未开播剧集的预告片帮助决定要不要追；拍摄花絮、演员采访、导演解说等短视频可以在正片更新的间隙用来垫时间；精彩片段从正片剪出高光段落，适合回忆剧情或安利朋友。需要注意的是，详情页中部的播放列表是正片的集数入口，花絮区是短视频的入口，两者分开排布，别把花絮序号当成正片集数——有些剧的花絮也按数字排列，但时长和内容明显不同。

### 追剧与看单

找到想看的剧后，点击详情页的「加入看单」按钮即可把剧集收藏起来。看单功能可以在个人中心集中管理收藏的所有剧集，追更进度会自动同步。对于多周更新的剧集，看单还会在有新集上线时推送通知，不用反复手动检查。

### 离线缓存与观看

想在没有网络的环境下继续看剧（比如飞行途中），可以提前把剧集缓存到本地。缓存操作在剧集详情页的每一集旁都有下载按钮，选择需要的集数开始缓存即可。

缓存完成后，离线观看本身非常简单：断网状态下打开应用，进入个人中心的「我的下载/离线缓存」，列表里点开已缓存的剧集选择集数播放，播放体验与在线基本一致——进度条、倍速、手势都可用。

但离线与在线的体验存在几个差异值得提前知道：

| 功能 | 在线 | 离线（缓存） |
| --- | --- | --- |
| 播放、进度、倍速 | 可用 | 可用 |
| 弹幕 | 实时 | 无实时弹幕 |
| 字幕切换 | 多语可选 | 一般固定为缓存时的字幕 |
| 更新新集 | 自动 | 需要恢复联网后再缓存 |

重点是第三条：**缓存打包的是当时的字幕**。多语字幕需求的话，缓存前确认缓存设置里包含你要的语言。

> [!TIP]
> 长途出行的推荐配置：出发前一晚在 Wi-Fi 下完成缓存，别指望机场或酒店的网络；按行程时长估算量，每小时行程约对应一集 45 分钟内容，再多冗余一集；飞行模式下提前测播一集，确认缓存完整——下载中断的集数离线播放会失败，重新下载即可。

### 个人中心功能

应用的绝大多数「非看剧」操作都集中在个人中心，各分区用途一次说清：

| 分区 | 放什么 |
| --- | --- |
| 账号信息 | 头像、昵称、登录状态 |
| 我的 VIP | 会员状态、到期日、订阅管理 |
| 看单 | 收藏的剧集列表 |
| 观看历史 | 看过的内容和进度 |
| 我的下载 | 离线缓存管理 |
| 设置 | 语言、版本、关于等 |

设置里最常用的三项是：语言切换（方便不同语言用户）、关于/版本（查看当前版本号和检查更新）、帮助/反馈（问题反馈渠道）。

记住一个规律：**跟「我」有关的东西在个人中心，跟「剧」有关的东西在详情页**。找不到某个功能时，先想它是账号属性还是内容属性。
