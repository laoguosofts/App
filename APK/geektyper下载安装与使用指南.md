## ✨ GeekTyper 是什么——一秒变"黑客"的模拟终端

GeekTyper 是一款**模拟黑客打字效果**的互动网页应用：打开一个主题，对着键盘随便敲，屏幕上就会以电影般的终端风格输出一段段代码、命令行或系统日志。它不做任何实际的技术操作，纯粹是一个视觉表演工具——但效果足够以假乱真，让每个使用者都能体验一把"高手敲代码"的仪式感。

核心玩法很简单：**选主题 → 全屏 → 敲键盘**。任意键都会触发下一段预设好的代码输出，Enter 键触发 Access Granted 弹窗作为"表演高潮"，侧边栏还有进度条、扫描动画、等级徽章等多种道具按钮。Web 版直接在浏览器里运行，手机版则把常用功能做成了屏幕按钮，随时可以演上一段。

适合谁用？只要你有以下场景之一，GeekTyper 都能派上用场：直播时想加个酷背景、给朋友演示电脑出问题的"假象"、拍短片需要假代码画面、想在朋友聚会上装一把黑客、或者单纯觉得敲代码很解压想换个花样。它门槛极低——不需要任何编程基础，上手就是会敲键盘就能玩。

## 🔧 安装与启动——Web 版零安装、手机版直达

### Web 版（推荐，零门槛）

GeekTyper Web 版是纯前端应用，**不需要安装任何东西**。打开浏览器、访问官网、选一个主题，直接就能敲。整个页面运行在浏览器里，刷新即可重置状态。

> [!TIP]
> 第一次体验强烈建议按 **F11 全屏**——去掉地址栏、标签页、书签栏后，整个屏幕只剩下终端界面，视觉上完全不像一个网站，效果差异巨大。

### 手机版

手机版在交互上做了专门优化：AUTO / STOP、进度条、特效触发这些功能都做成了屏幕上常驻的按钮，不需要记键盘快捷键。虚拟键盘顶排右侧就是 AUTO 等功能键一排，点一下就能开自动播放或触发其他效果。

启动注意事项：

1. 从官网进入手机版主题页面时，如果虚拟键盘没自动弹出，**点一下屏幕空白区域**通常就能弹出
2. 某些手机浏览器的安全设置可能拦截键盘事件——如果敲了没反应，换 Chrome / Edge / Firefox 试试
3. 刚从设置返回主题页面时偶尔会出现焦点丢失，**刷新页面**是万能解法（GeekTyper 不保存任何用户数据，刷新无副作用）

## 📖 使用入门——从三步开局到进阶玩法

### 第一步：挑个对场合的主题

打开首页会看到一排主题缩略图网格，第一行是最热门的——Tegnio、Cyberpunk、SHIELD、SCP。如果不知道选哪个：

- **刚入门想稳** → 先点 Plain Terminal，黑白极简，最不花哨也最像电影里老派黑客终端
- **想装得专业** → SHIELD 或 SCP，政府机构安全终端范儿
- **想有赛博朋克感** → MILITECH Cyberpunk
- **想可爱反差** → Minecraft 或 MLP Typer

主题选择本身就是个边玩边试的过程——点开任何一个主题进去都能再换，也能回首页重新选。

### 第二步：F11 全屏——最关键的一步

带地址栏、标签页、书签栏的浏览器窗口，一眼就能看出是个网站。F11 之后，它变成了一个**独立的终端系统**，没有任何"这是浏览器"的视觉痕迹。物理键盘的存在也变得更有仪式感——手指放在键位上，手腕轻轻晃两下，然后突然按下去，这个身体语言本身就是表演的一部分。

> [!WARNING]
> 某些浏览器 F11 全屏后如果焦点没正确聚焦到内容区，可能不响应键盘。全屏后按一下 Tab 键，或者用鼠标点一下终端区域，确保焦点回来。

### 第三步：敲键盘——怎么敲都行，但别持续敲

**任意键都能触发效果**，系统不关心你敲了什么，只管"下一段代码该出了"。但敲法有讲究：

- **慢快结合**最像真的。敲三下停一秒，再飞快敲五下，再停——人类操作就是有节奏变化的，持续匀速敲击反而会穿帮
- **不要低头看键盘**。对着屏幕，余光扫键位，假装你在专注看输出
- **配合 Enter 键**——敲到屏幕上已经滚了一大片代码，突然按一下 Enter，Access Granted 弹窗跳出来，表演高潮瞬间就位

### AUTO 自动播放模式

按 AUTO（Web 版快捷键在帮助菜单里查，手机版直接有屏幕按钮），GeekTyper 就会**持续自动输出代码**——不需要敲任何键。屏幕上代码以固定速度滚动，直到你按 STOP 或对应的停止快捷键。

AUTO 适合的场景：

- **背景画面**：开一个主题全屏 AUTO，放在旁边当装饰性画面——直播间背景、学生短片的素材画面、朋友聚会的氛围屏
- **远程演示**：需要录屏但不想手忙脚乱敲键盘，AUTO 匀速输出也能凑成一段演示
- **"让系统自己处理"的剧情**：敲一会儿代码 → 开 AUTO → 假装系统在自动执行任务 → 等进度条走完 → Enter 收尾

AUTO 最大的局限是**匀速**——代码以固定节奏持续输出，没有快慢停顿的变化。如果旁边有人盯着看，匀速反而容易穿帮。推荐用法：**AUTO 和手动交替**。开 AUTO 跑一会儿 → 手动敲几下打断 → 停一下 → 再 AUTO → 再手动。这样节奏有变化，更像真人在操作。

### Access Granted 弹窗——每个主题的"成功"结尾

Access Granted 弹窗是整个 GeekTyper 表演的**句号**。不管你前面敲了多少代码、点了多少按钮、触发了多少进度条——没有这一下弹窗，整个表演就是"没结尾"。按 Enter 键就能触发它。

不同主题的弹窗风格各不相同，列举几个典型的：

| 主题 | Access Granted 文案 | 视觉效果 |
| --- | --- | --- |
| SCP | ACCESS GRANTED —— Level 6 Authorization | 绿色大字弹窗 + 等级徽章 |
| SHIELD | Agent Authentication Confirmed | 特工卡片弹窗 |
| Matrix | Welcome to the Matrix | 矩阵数字雨背景 |
| Cyberpunk | Access Granted —— MILITECH Corp | 红黑霓虹弹窗 |
| Plain Terminal | ACCESS GRANTED | 系统标准弹窗 |
| Minecraft | [REDACTED] | 像素方块风 |

大部分主题的 Access Granted 弹窗会在 3-5 秒后**自动消失**，然后回到正常等待状态。但它也可以保持——看主题实现。如果你想让它停留给别人看，不要按任何键或点任何按钮。弹窗消失后可以继续敲代码、继续点侧边栏按钮、甚至再按一次 Enter 触发新的弹窗——GeekTyper 里没有"一局结束"的概念，你想玩多久玩多久。

Tegnio 主题支持自定义 Access Granted 的**文字、颜色、显示时长**——在 Tegnio 的配置面板里找到对应的弹窗设置项，改成你喜欢的任何文案就行。

### 打字没反应？排查一下

如果敲了半天屏幕上不出代码，按顺序检查：

1. **浏览器焦点不在页面上**（最常见）——点击 GeekTyper 页面内任何空白区域，确保焦点回来
2. **F2 / TAB 帮助菜单还开着**——再按 F2 / TAB 关掉帮助菜单
3. **手机版虚拟键盘没弹出来**——点一下屏幕空白区域，或者检查系统设置里的键盘权限
4. **浏览器禁用了键盘事件**——换 Chrome / Edge / Firefox 试试，或者检查网站权限
5. **终极方法**——刷新页面。GeekTyper 是纯前端，刷新不丢数据。刷新还不行，换个主题或换个浏览器
