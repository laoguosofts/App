## ✨ LibLibAI 是什么

LibLibAI（中文俗称"哩布哩布AI"）是一个把模型社区和在线生成整合在一起的中文 AI 创作平台。你可以把它理解成国内版的 Stable Diffusion 模型库社区——创作者把自己训练的 Checkpoint、LoRA、ComfyUI 工作流上传分享，使用者直接在浏览器里在线调用这些模型出图，也可以把模型文件下载到本地跑。

平台由北京奇点星宇科技有限公司运营，2023 年上线后逐步从单一的 SD 生态扩展到 FLUX、混元、可灵、Seedance 等更多基础模型，功能也从单纯的文生图延伸到视频创作、LoRA 在线训练等完整链路。

和市面上那种"给三五个固定模型让你拼提示词"的在线生图工具相比，LibLibAI 的核心差异在于**风格问题交给模型解决**。同一个提示词，配上写实人像底模和二次元动漫底模，产出完全天差地别——所以站内最核心的动作不是写长提示词，而是选对模型。官方入门教程反复强调：直接搜索并使用合适的模型，往往比堆砌专业提示词描述画面效果要好得多。

平台上能做的事情覆盖面很广：WebUI 界面支持文生图、图生图、局部重绘、超分放大；浏览器里直接跑 ComfyUI 工作流不用装环境；LoRA 训练功能让你上传一组图片就能把自己的画风或人物炼成模型；接入了 Seedance、可灵等视频模型，支持图片、视频、音频组合驱动。

## 🔧 注册与上手准备

LibLibAI 本身是在线平台，不需要传统意义上的"安装"——但首次使用前需要做几项准备工作。

**注册账号**：打开官方主站，手机号注册即可。新用户通常会获得一定的初始积分额度，用来消耗在线生图。积分是在线生图的硬通货，文生图、图生图、高清修复等操作都会按张数和分辨率扣积分。

> [!TIP]
> 积分消耗跟图片数量和分辨率直接相关。新手阶段建议先用小分辨率（512×512）和少量张数（1~2 张）练手，等调参手感出来再逐步往上加。

**可选的本地部署**：如果你有一张显存 8GB 以上的显卡，可以把社区模型下载到本地，用 ComfyUI 或 WebUI 跑。好处是不消耗积分、离线可用，坏处是环境搭建门槛高。平台首页顶部有模型下载入口，下载的模型文件放到本地 ComfyUI 的 `models/` 对应目录即可识别。

**关于客户端**：LibLibAI 目前以 Web 端为主，没有强制要求安装桌面客户端。浏览器里打开主站就能用全功能，包括文生图、图生图、ComfyUI 在线工作流等。

## 📖 使用入门：从零跑出第一张图

第一次打开 WebUI 界面，面对密密麻麻的参数面板很容易懵。但出图的核心流程其实很清晰：**选模型 → 填提示词 → 定参数 → 生成 → 挑图**。下面按这个顺序走一遍。

### 第一步：选底模

左侧或顶部的模型选择器是整个流程的起点。新手最容易犯的错就是跳过这一步——直接用默认模型去写二次元提示词，结果出来的是写实人像，还纳闷提示词不管用。

LibLibAI 站内有上万个社区模型，按类型分主要有：

| 模型家族 | 适用场景 | 推荐分辨率 |
| --- | --- | --- |
| SD 1.5 系 | 通用、入门、二次元 | 512×512 / 512×768 |
| SDXL 系 | 高清人像、插画、写实 | 1024×1024 / 768×1024 |
| FLUX 系 | 复杂构图、写实、多风格 | 1024×1024 起步 |
| 混元系 | 中文理解好、人物稳定 | 1024×1024 |

> [!NOTE]
> 官方教程的建议是：直接去模型社区搜索你想要的风格关键词（比如"赛博朋克""水彩""日系插画"），按热度排序挑前排的模型用——社区里高赞的模型大概率比你自己瞎调参数管用。

### 第二步：写提示词

选好模型后，在提示词输入框里描述你想要的画面。不用追求专业术语堆砌，把主体、风格、构图说清楚就行。比如"一个穿着白色连衣裙的女孩站在樱花树下，阳光透过树叶洒落，日系动漫风格"——这样一段比"a anime girl"加几十个英文 tag 更直观。

新手的提示词可以遵循一个简单公式：**主体 + 环境 + 风格 + 细节**。主体是画面里的核心（一个女孩、一辆跑车），环境是背景（樱花树下、雨夜街道），风格是整体观感（日系动漫、油画质感），细节是加分项（阳光透过树叶、花瓣飘落）。

### 第三步：参数面板快速上手指南

填完提示词，往下滚动就是参数编辑区。从上到下高频参数如下：

| 参数 | 管什么 | 推荐起点 |
| --- | --- | --- |
| 采样方法 | 用什么算法收敛画面 | DPM++ 2M Karras（通用） |
| 迭代步数 | 画面精修几轮 | 15~25 步，再多收益递减 |
| 宽度 / 高度 | 出图分辨率 | SD1.5 用 512 档，XL/FLUX 用 1024 档 |
| 图片数量 | 一次出几张 | 4 张，用数量换概率 |
| CFG 提示词引导系数 | 画面贴着提示词走的程度 | SD1.5/XL 用 7，FLUX/混元用 3.5 |
| 随机种子 Seed | 画面随机性开关 | -1 为随机，想复现就填固定值 |

> [!WARNING]
> CFG 值不是越高越好。超过 15 容易出现"提示词里每个词都想硬塞进去"的畸形画面，低于 3 又会导致画面跑偏跟提示词没关系。按底模家族给的推荐值起步就行。

### 第四步：种子、批量和"抽卡"策略

AI 生图被叫作"抽卡"的根源就是随机性，驯服随机性的两件关键工具都在参数面板下部。

**随机种子 Seed**：-1 代表每次都是全新随机画面，适合探索构图；填固定值后，同提示词同参数下生成的画面高度相似——想在一张满意的底子上微调时就固定种子。种子输入框旁边有两个按钮：骰子一键随机化，循环箭头复用上一次的种子值。官方还提了一个"抄作业"技巧：在作品灵感页看中别人的图，用作者标注的种子能快速生成相似内容。

**图片数量**：提供 1/2/3/4/8/16 档。批量出图的意义是**用数量换概率**——探索期先开 4 张看方向对不对，构图不满意就保持 -1 继续抽，抽到满意再固定种子精修。8 张、16 张留给精度要求高的场合，注意积分按张数扣。

固定种子后的标准调参流程：**一次只改一个变量**——要么只改提示词里的风格描述，要么只改构图元素，对比前后差异再继续微调。这是所有 AI 生图调参的基本功。

### 第五步：分辨率与放大策略

宽度和高度直接决定出图像素尺寸，但不建议一上来就拉满。原因有两个：一是模型在自己训练分辨率之外硬画容易出现多人、重复肢体这类结构崩坏；二是积分消耗和生成时间都会随分辨率指数级增长。

正确的大图姿势是"先小后大"：

1. 学习和构图阶段，先用 512 档快速抽卡，确定满意的构图和种子。
2. 把种子固定下来，勾选高分辨率修复做二次放大。重绘幅度默认 0.75，想让放大的结果更贴原图就降到 0.3~0.35。
3. 这样拿到的大图既清晰又保持了原始构图，积分消耗还比直接画大图低。

横竖比也会影响构图逻辑——竖版适合单人全身和海报，横版适合场景和多人。改比例后建议连种子一起重新抽，旧种子在新比例下的构图未必还成立。

### 进阶功能一览

当你对基础流程熟悉后，可以逐步尝试以下进阶玩法：

- **高分辨率修复（Hires Fix）**：想要 1024 以上大图的标准方案，在参数面板中下部开关打开即可。
- **ADetailer**：自动检测并重绘脸部、手部，人像特写救星，老模型画远景人脸糊时特别有用。
- **ControlNet**：用参考图控制构图和姿态，进阶创作者用来精确控制画面结构的核心工具。
- **ComfyUI 在线工作流**：浏览器里直接跑节点化工作流，社区里有大量现成工作流可以一键调用，不用自己搭节点。
- **LoRA 在线训练**：上传一组图片，在线把自己的画风或人物炼成 LoRA 模型，训练完可以在出图时加载使用。

### 常见问题

**Q：为什么出来的图跟提示词差很远？**
A：先检查底模选对了没有——写实底模配上二次元提示词，出来的一定是写实人像。然后看 CFG 值是不是太低（低于 3 会跑偏），提示词是不是太笼统没说清主体。

**Q：出图速度很慢怎么办？**
A：最直接的办法是降分辨率（从 1024 降到 512）、减少迭代步数（从 30 降到 20）、少开高清修复和 ADetailer。这些都是积分消耗大户。

**Q：怎么保存一张满意的图以便下次调参？**
A：图右上角会显示这次生成用的完整参数（包括种子值），记下来或者点"复用参数"按钮，下次就能在这张的基础上微调。
