## ✨ PUBG Tool 是什么

PUBG Tool 是一款针对和平精英、PUBG Mobile 等射击游戏的画质与帧率解锁工具。它通过修改游戏配置文件的方式，让原本被设备型号或游戏设置锁死的高帧率、高画质选项得以开放，同时提供 SG 优化引擎、分辨率调整、音质解锁等进阶功能，帮助玩家在硬件条件允许的前提下获得更流畅、更清晰的游戏体验。

工具分为免费版和 Pro 版两个档位。免费版主打 120 帧解锁和基础参数调整，Pro 版则在此之上增加了自定义分辨率、EC/UC 双保存模式、6 项画面异常修复、音质解锁等进阶配置。对于普通手机用户来说，免费版已经足够；平板玩家或追求极致画质的玩家则更倾向于 Pro 版。

> [!NOTE]
> PUBG Tool 的核心逻辑是在本地修改游戏的配置文件，不涉及游戏服务端通信或内存注入，因此相比外挂类工具具有更低的封号风险。但任何第三方修改工具都无法保证 100% 安全，使用前请自行评估。

## 🔧 安装步骤

PUBG Tool 仅支持 Android 平台，安装前需要确认几个前置条件：

1. **系统版本**：Android 7.0 及以上，部分 Pro 功能可能需要更高版本
2. **存储空间**：安装包体积约 50MB~80MB，建议预留 200MB 以上空间
3. **未知来源授权**：由于不在 Google Play 分发，需要允许浏览器或文件管理器安装未知应用

### 安装流程

1. 从下载入口获取最新版 APK 文件，建议核对文件大小与官方说明一致，避免下载到篡改版本
2. 将 APK 传输到手机（或直接在手机浏览器下载），点击文件启动安装
3. 如果系统弹出「禁止安装未知应用」提示，进入设置 → 安全 → 未知来源，为当前安装来源开启权限后重试
4. 安装完成后首次启动，应用会请求存储权限、悬浮窗权限等必要授权，全部允许即可

> [!WARNING]
> 安装时如果手机安全中心或杀毒软件提示风险，这是 Android 对非商店应用的通用警告，并非 PUBG Tool 特有问题。确认来源可信后可忽略。

### Pro 版激活

免费版安装后即可使用基础功能，Pro 版需要额外激活：

- 购买渠道为 PUBG Tool 官方发卡网，支付后会获得一串卡密
- 在应用内找到 Pro 激活入口，输入卡密完成绑定
- 激活成功后建议**立刻手动备份卡密**——发卡网的查询有效期仅为购买后 1 个月，过期后后台会清理记录
- 如果不慎丢失卡密，可以开启飞行模式后打开应用，已激活设备会自动把卡密显示在屏幕上或复制到剪切板

## 📖 使用入门

### 基础功能：120 帧解锁

这是免费版最核心的功能。和平精英默认会根据设备型号限制帧率上限，旗舰手机通常能开到 90 帧，大部分机型被锁在 60 帧。PUBG Tool 的 120 帧解锁可以绕过这个限制：

1. 打开应用，在主界面找到「帧率」或「最大帧率」相关选项
2. 选择 120 帧（部分机型可选 144 帧）
3. 点击「保存并启动游戏」，应用会自动拉起和平精英
4. 进游戏后在画面设置里确认帧率选项是否已经解锁

> [!TIP]
> 帧率解锁是否生效取决于硬件实际能力。老机型即使解锁了 120 帧，GPU 也跑不到那个数值，反而可能发热降频。建议根据自己设备的实际表现调整。

### SG 优化引擎

SG 引擎是 PUBG Tool 内置的一套参数优化方案，用于在不改分辨率的前提下提升画面清晰度和稳定性。它会调整游戏配置中与渲染相关的若干参数，比如纹理质量、阴影距离、粒子效果等，让默认画质档位下的画面表现更好。

使用时在应用内找到 SG 引擎选项，选择一个预设档位（通常有低/中/高/自定义），保存后启动游戏即可。如果使用过程中遇到画面异常或游戏崩溃，可以尝试切换档位或关闭引擎再试。

### Pro 版进阶功能

#### 分辨率修改

Pro 版允许用户自定义游戏运行分辨率，从 720p 到 4K 都可以设置。提高分辨率能显著提升画面清晰度，但也会带来副作用——游戏内建的键位布局是基于一个固定的基准分辨率模板保存的，修改分辨率后，按键的相对位置和大小会和画面不匹配。

| 场景 | 键位错乱程度 |
| --- | --- |
| 手机 + 小幅分辨率调整 | 轻微，进游戏微调即可 |
| 平板 + 4K 跨度 | 严重，几乎需要全部重调 |
| 频繁切换分辨率 | 每次切换都要重调，容易混乱 |

如果确实需要修改分辨率，推荐的做法是：先在 PUBG Tool 里设好分辨率，保存启动游戏，进入对局后打开自定义键位布局，逐个调整按键位置和大小，保存为独立预设。不同分辨率对应不同预设，切换时同步切换就不会乱。

#### EC 与 UC 保存模式

Pro 版在设置界面提供了两种保存模式的选择，这是一个容易混淆但影响重大的选项：

- **EC 模式**：写入游戏配置文件的一个位置，支持部分平板的分辨率修改，稳定性较好，但不支持音质解锁
- **UC 模式**：写入另一个位置的配置文件，支持音质解锁，但在某些平板上分辨率修改可能不如 EC 稳定

简单来说，手机用户优先选 UC（可以解锁音质），平板用户优先选 EC（分辨率更稳）。如果平板还想要音质解锁，可以先试 UC 看看画面是否正常，不行再回到 EC，音质就只能放弃了。

切换模式前务必先点击「还原」清理旧参数，因为 EC 和 UC 写入的文件位置不同，残留的旧参数可能导致冲突。

#### 音质解锁

和平精英内建的音质选项分为低、中、高三档，高品质下枪声、脚步声、环境音的层次感明显提升，远距离的脚步声更容易被识别。但游戏默认可能把音质锁在中档，高端设备也用不上。

Pro 版的音质解锁功能可以把高品质选项开放出来。操作步骤：

1. 确认保存模式已切换到 UC
2. 找到「游戏音质」或「音效音质」相关选项
3. 选择最高档，保存并启动游戏
4. 进游戏后在声音设置里手动检查音质档位，确认是否解锁成功

> [!NOTE]
> 音质解锁只在 UC 模式下可用，EC 模式下对应选项会是灰色的、点不动。这不是 bug，是两种模式的设计差异。

#### 画面异常修复（1-6 项）

平板用户或大幅修改分辨率后，很容易遇到画面异常：人物高度拉伸变形、画面缩放比例不对、四分之一黑屏等。Pro 版提供了 6 个独立的修复开关，用户可以逐项测试。

正确的测试顺序是**一个一个地试**——先开第 1 项，启动游戏看效果；不行再开第 2 项；找到能修复的那一项就停，不要把 6 项全开。6 个修复项的具体技术含义官方没有公开，根据用户反馈大致可以归纳：

- **修复项 1-2**：调整垂直拉伸比例，解决人物高度变形
- **修复项 3-4**：调整水平缩放比例，解决画面过宽或过窄
- **修复项 5**：调整整体缩放基准，解决四分之一黑屏
- **修复项 6**：组合修复，针对华为、三星折叠屏等特殊机型

如果 6 项都修不好，可以尝试切换 EC/UC 保存模式、恢复默认分辨率，或者联系官方客服反馈具体机型问题。

### 常见问题排查

**键位错乱了怎么办？** 这是修改分辨率后的正常现象，不是 bug。最快的解法是恢复默认分辨率，或者进游戏手动重调键位布局。

**Pro 版激活失败？** 先检查网络连接，发卡服务器需要联网验证。如果网络没问题，核对卡密是否输入正确（注意不要多复制空格或换行符）。激活后建议立刻备份卡密。

**卡顿或发热严重？** 解锁 120 帧 + 提高分辨率会大幅增加 GPU 负载，老机型可能扛不住。尝试降低分辨率档位或关闭 SG 引擎的高负载参数。
