## ✨ We Learn 是什么

We Learn（随行课堂）是一款面向高校英语教学场景的数字化学习平台，服务于大学英语、高职英语、英语专业、多语种以及雅思托福等多个课程系列。平台与主流英语教材配套，提供听力、词汇、课文、口语、语法、单元测试等完整练习链，帮助学生进行课前预习、课堂互动和课后复习。

它的核心特色在于内置了口语跟读自动评分引擎——学生对着手机朗读，系统实时给发音打分，对没有口语搭档的自学者来说，这是全应用里最接近"有人陪你练"的体验。平台同时支持 APP 和网页端，手机端适合随时随地刷练习，电脑端则更适合做需要完整展示的课程内容。

除了教材配套的数字课程，We Learn 还通过班级机制衔接课堂教学：任课教师可以在班级里发布作业、测试、公告和补充资料，学生的学习进度与成绩会同步形成性评价数据。这种"数字内容 + 班级管理"的双重结构，让它既适合个人自主学习，也适合作为高校英语课程的配套工具。

## 🔧 安装步骤

We Learn 支持移动端 APP 和电脑网页端两种使用方式，安装路径各有不同。

**移动端 APP 安装**：

1. 在手机应用商店搜索 "We Learn" 找到官方应用，点击下载安装。
2. 首次打开时，系统会请求麦克风、存储等权限——口语跟读功能依赖麦克风录音，请务必允许，否则录音评分功能不可用。
3. 安装完成后，使用手机号或学校提供的账号登录即可。

> [!TIP]
> 麦克风权限是口语评分功能的前提。如果首次拒绝了权限，后续可以在手机系统设置的应用管理中手动开启，不需要重装 APP。

**电脑网页端使用**：

电脑端不需要安装客户端，直接通过浏览器访问课程中心即可。部分课程内容（特别是格式较复杂的多媒体内容）仅支持电脑端学习，手机浏览器打开可能出现兼容性问题。

**安装后的核对要点**：

- 登录后确认能看到自己的学习列表，已加入的课程正常显示。
- 尝试打开一门课程的目录标签，确认单元内容可以正常加载。
- 如果课程需要激活，按教材封底或教师提供的激活码完成激活流程。

## 📖 使用入门

### 课程主页的两大分区

点开任何一门已加入的课程，主页顶部都有两个并排的标签——**目录**和**班级**，这是整个应用最基础也最容易混淆的结构。

**目录标签**承载的是教材配套的数字课程内容：按单元划分的完整练习链，包括听力、词汇、课文、口语、语法、单元测试等板块。每个单元显示练习数量与完成进度，点开即可学习。日常自习、期末复习刷练习，用的都是目录里的内容。

**班级标签**承载的是任课教师发布的内容：作业与测试（有完成期限）、公告通知、教师分享的课件资料以及课堂互动入口。班级任务通常计入平时成绩，错过截止日期会影响考核。

> [!WARNING]
> 目录里的练习不进班也能做，但班级里的任务只有进班才能收到。很多学生错过作业，根本原因就是没分清这两个标签。建议每周固定时间把所有课程的班级标签翻一遍，确认没有漏掉的任务。

### 找课程的四个路径

课程明明存在但搜索框搜不到，这类问题有结构性原因——平台里的搜索入口不止一个，能力各不相同。按下面四条路径换着找，基本都能把课挖出来：

1. **换对搜索入口**：课程库/学习路径里的搜索栏是找课程的主搜索，首页搜索栏定位是通用入口，搜课程不是它的强项。在首页搜不到不代表课不存在，先切到课程库搜索栏再试。
2. **按分类浏览代替搜索**：搜索对课程名的精确度要求高，分类浏览则不依赖你记得全名。进课程库按分类走（大学英语、高职、英语专业、多语种、雅思托福、翻译），找到教材所属系列后按册次定位目标课程。
3. **星号变通搜索**：如果课程名或 ID 搜索仍无结果，尝试在名称前加星号（`*`）再搜索——这是平台搜索的一种变通用法，对不完全匹配的场景有效。
4. **向教师要准确信息**：让任课教师提供课程的确切名称或课程 ID，拿着准确 ID 到课程库里定位。

找到了但进不去的情况也要分类处理：需要验证码的课程确认激活码未使用；标价课程确认支付完成；只想先试试的看详情页有无体验入口。

### 口语跟读：让评分更高的细节

口语板块是 We Learn 最有辨识度的功能，内置的英语跟读自动评分引擎可以实时给发音打分。

**两种口语练习形态**：

- **Speaking Tasks（角色扮演）**：系统先给一段对话范例，你选择扮演角色 A 或角色 B，逐句跟读自己的台词。对分数不满意可以多次重录，直到达标为止。
- **Reading Aloud（朗读）**：给出完整句子或短文，逐句朗读录音。没有对话角色，纯练朗读流畅度与发音准确度。

**提分技巧**：

- 跟读前把原声听一到两遍，模仿重音位置，比直接照着拼写硬读得分高。
- 环境安静、语速正常——评分引擎对发音准确度与流利度敏感，抢读、拖长音都会拉低分数。
- 多录几次取满意的那次，引擎按提交的录音评分，没有次数限制。

### 课程播放故障排查

课程内容放不出来是高频故障，表现五花八门：点开练习白屏、音频条走不动、视频一直转圈。按下面的顺序排查，多数十分钟内能恢复：

**第一层：网络**——音视频内容对网络最敏感。校园 Wi-Fi 拥堵时切手机流量，或反之；宿舍床角、电梯间这类弱信号位置先挪地方；晚间全网拥堵造成的加载慢，错峰学习即可。

**第二层：端口选择**——部分课程因格式原因仅支持电脑端学习，手机端放不出的切到电脑浏览器再试。反过来，手机浏览器打开网页版放不出内容是预期内限制，别在这个组合上耗时间。

**第三层：课程与账号状态**——核对课程是否激活成功、是否登错了账号、课程是否在临时维护。

**第四层：客户端状态**——重启 APP 清掉卡住的音视频会话；在设置里清理应用缓存；顽固问题可以卸载重装（重装前确认账号密码记得）；版本过旧也可能与新课程格式不兼容，更新到最新版。

> [!NOTE]
> 视频进度不记录的特殊情况：看完视频后确认完整看完、没有拖动进度条，结束后稍等片刻再退出，让记录上传完成。长期不记录的需核对时长进度的统计口径，仍异常则联系客服。
