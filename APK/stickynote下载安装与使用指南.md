## ✨ Stickynote 是什么

Stickynote 是一款专注于桌面便签的 Android 应用——就像把真实的便利贴钉在手机桌面上，随时随地记一件事、写一个想法、列几条待办。它的核心逻辑很简单：**轻、快、看得见**。打开应用不超过半秒，写好的便签可以直接钉在桌面部件上，锁屏之外低头就能扫一眼，不用再打开任何日历或笔记 App 翻半天。

功能上它提供了打字和手写两种便签形态：打字便签适合快记、列清单；手写便签支持画笔、不同颜色、橡皮擦和撤销，适合画草图、涂重点。文件夹可以把便签分组整理，敏感内容可以单张上锁或整组加密。定时提醒、完整备份、颜色自定义这些实用功能也一应俱全。适合把"待办"钉在桌面上、需要快速记录、或者喜欢手写便签的安卓用户。

## 🔧 安装步骤

Stickynote 目前主要面向 Android 平台，安装方式和大多数 APK 应用一样——下面按常见情况一步步走。

**第一步：下载 APK**

从下载入口拿到安装包后，建议用文件管理器先核对一下文件大小和版本号，避免下载到损坏或过期的包。安装包体积不算大，核对一下能省掉装完打不开的麻烦。

**第二步：允许未知来源安装**

如果你的手机提示"禁止安装未知来源应用"，去系统设置里手动放行：

1. 打开 **设置 → 安全 / 隐私**
2. 找到 **"允许安装未知来源应用"** 或 **"安装未知应用"**
3. 选择你下载 APK 用的那个应用（浏览器、文件管理器等），把权限打开

> [!WARNING]
> 这个权限开完之后记得**用完就关**，不要长期对所有应用放行，避免恶意软件趁虚而入。

**第三步：安装并启动**

点开 APK 文件，点"安装"，等它走完进度条。装完直接点"打开"就能进应用了。启动后第一次会引导你设置几个基础权限（通知、存储访问），按提示授权即可——通知权限如果关了，定时提醒就弹不出来。

**第四步：核对版本**

进应用之后，去 **设置 → 关于** 看一下版本号，和下载页标的最新版本对得上就行。对不上说明装了旧包，卸载重下一遍。

## 📖 使用入门

Stickynote 的使用逻辑可以归为四个核心场景：写便签、整理便签、让便签真正"看得见"、以及确保便签不丢。下面就围绕这四点展开。

### 写便签——打字和手写两种形态

打开应用后点右下角的加号按钮（有些版本是左下角），可以选择新建**打字便签**还是**手写便签**。

打字便签的体验和任何文本编辑器差不多：点进去直接敲字，可以写多行、列待办清单、插简单的项目符号。标题栏单独留出来，便签多了之后靠标题定位会快很多。

手写便签是 Stickynote 比较有特色的部分。工具栏里有画笔、颜色选择、橡皮擦、撤销这几个核心按钮。写错一个字？用橡皮擦**点擦**或**线擦**抹掉就行；画了一整笔方向完全不对？点撤销按钮退回去。工具栏里找一下有没有"清空画布"的选项——有些版本藏在三个点的更多菜单里，整张画布想重来时用得上。清空是一次性操作，建议有价值的东西先截个屏再动手。

> [!TIP]
> 手写写之前可以先在脑子里大致构思一下，避免画了一大片才发现整体方向错了。用不同颜色分层次写内容，错了的部分颜色也容易区分，撤销和擦除都更有针对性。

### 整理——文件夹和加密

便签多了之后，文件夹是最重要的组织手段。长按某张便签可以弹出移动到文件夹的选项，也可以先建好空文件夹再逐一拖进去。文件夹和便签之间没有层数限制，可以建子文件夹。

敏感内容有两种加密方式：**整组文件夹上锁** 或者 **单张便签上锁**，两者可以配合用。单张上锁适合大多数正常用、只有个别敏感便签的场景——长那张便签、选"Lock"、设密码就行。被锁的便签在列表里会显示锁图标，点它弹密码框，解锁后才能看。文件夹密码和单张密码是**独立**的，不共享，恢复备份的时候加密过的便签需要原密码才能解开。

| 加密方式 | 覆盖范围 | 适合场景 |
|----------|----------|----------|
| 文件夹上锁 | 整个文件夹 + 里面所有便签 | 整组敏感内容集中存放、经常一起查 |
| 单张上锁 | 只锁这一张 | 大部分正常用、只有个别敏感便签 |

> [!WARNING]
> 不管是文件夹密码还是单张密码，**Stickynote 都没有密码找回途径**。设了之后一定要在手机之外也存一份——记在纸上、存进另一个加密的地方都行，别只靠脑子记。

### 让便签"看得见"——桌面部件和省电白名单

Stickynote 的精髓在于把便签钉在桌面上，而不是藏在应用里。长按桌面空白处选"添加部件"，找到 Stickynote 的小组件拖上去就能显示。部件样式有几种可选，可以根据桌面布局挑一个合适的。

然而安卓手机的省电策略对 Stickynote 不友好——小米、华为、OPPO、vivo 这些品牌都会在后台"清理"耗电应用。进程一被杀，桌面部件可能变空白、定时提醒弹不出来。解决办法就是把 Stickynote 加入**省电白名单**。

各品牌路径略有差异，核心是找"后台管理 / 省电策略 / 自启动"相关设置：

- **小米 / HyperOS**：设置 → 应用设置 → 应用管理 → Stickynote → 省电策略 → 设为"无限制"；自启动也要开
- **华为 / HarmonyOS**：设置 → 电池和性能 → 启动管理 → Stickynote 设为"手动管理"，自动启动、关联启动、允许后台活动三项全勾
- **OPPO / ColorOS**：设置 → 电池 → 耗电管理 → Stickynote → 允许后台活动，自启动管理里也要开
- **vivo / OriginOS**：设置 → 电池 → 后台管理 → Stickynote → 允许后台活动，应用管理里开自启动
- **原生安卓**：设置 → 应用 → 查看所有应用 → Stickynote → 电池 → 设为"不受限制"

设置完之后建议**手动重启一次手机**让新策略生效，然后建一张带 1 分钟后提醒的便签做个测试——能弹通知说明白名单生效了。

### 不丢——定期做备份

便签写了一堆，最怕的就是手机丢了、刷机了、或者应用出问题。Stickynote 自带完整的备份功能，路径是：**设置 → Backup → 选保存位置 → 开始备份**。

备份文件会打包：所有打字便签内容、所有手写便签图片、文件夹层级结构、颜色样式设置、以及加密的密码锁便签。文件名一般带日期，比如 `stickynote-backup-2026-10-15.stickynote` 这种格式。保存位置建议选 Download 文件夹，文件管理器里好找。

备份频率建议：**日常使用每周一次**；做系统更新、刷机、清理存储前强烈建议先备份；大量新建或删除便签后额外加一次。

> [!NOTE]
> 备份做好了不要只留在手机里——手机本身丢了或坏了等于白做。传到网盘、数据线导到电脑、发给自己的另一台设备，至少存一份在手机之外。这才是真正的备份。
