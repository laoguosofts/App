## ✨ TuneFree 是什么

TuneFree 是一款开源的音乐聚合播放器，它的核心思路很简单——**同时对接多家主流音乐平台的公开接口，把搜索、播放、收藏这些体验统一到一个界面里**。不用在网易云、QQ 音乐、酷狗之间来回切换找同一首歌，TuneFree 会自动帮你从多个音源里找最快、最稳的那条播放链路。

这玩意儿的受众其实挺广：想省事，不想装一堆音乐 App 的人；有收藏癖，歌单跨了好几个平台的老用户；喜欢折腾桌面端自定义外观的玩家，都能在这里找到舒服的用法。

几个值得单独提一下的设计点：**自动换源**机制能在播放到一半音源挂了的时候无感切换（用户感知大约 1~2 秒）；**扫码登录网易云**后可以把云端收藏和歌单全部同步进来，换设备也不怕丢；**主题外观**支持跟随封面动态变色，每首歌界面风格都跟着换，视觉效果挺有意思。

## 🔧 安装步骤

TuneFree 提供多平台支持，不同平台的安装方式各有差异，但总体都不复杂。

### 桌面端（Windows / macOS / Linux）

1. **下载安装包**：从下载页获取对应系统的最新版本，Windows 通常是 `.exe` 安装程序，macOS 是 `.dmg` 镜像，Linux 有 AppImage 和 deb/rpm 等格式可选
2. **安装路径选择**：默认路径即可，想装在 D 盘或其他自定义位置也没问题
3. **杀毒软件误报**：少数安全软件可能会对开源软件的未签名可执行文件产生误报，建议在信任该软件后将安装目录加入白名单，避免运行时被拦截

> [!WARNING]
> 安装完成后首次启动如果被系统防火墙弹窗拦截，选择「允许访问」即可——TuneFree 需要网络连接才能从各个音乐音源获取数据。

### Android 端

1. **下载 APK**：从下载页获取 APK 文件
2. **开启未知来源安装**：进入手机「设置 → 安全」，允许从未知来源安装应用（部分机型路径为「设置 → 应用管理 → 特殊权限」）
3. **安装并启动**：点击 APK 文件按提示完成安装

> [!TIP]
> 建议在安装后立即更新到最新版本。旧版本可能存在音源接口不兼容的问题，新版本通常会及时跟进各大音乐平台的接口变更。

## 📖 使用入门

装好打开后，TuneFree 的界面第一眼给人的感觉就是**简洁**——没有花里胡哨的推荐位，侧边栏放功能入口，主界面就是搜索框和播放器。这一节把日常使用中最核心的几个功能点拆解一下。

### 搜索与播放

打开应用后最显眼的就是顶部的搜索框。直接输入歌名、歌手或专辑名回车即可，默认会同时向所有已配置的音源发请求，返回结果列表里每首歌都会标注来自哪个平台。点任意一条结果就开始播放了。

播放器界面的交互比较直观：上一首 / 下一首 / 暂停是必备的，进度条可以拖拽跳转，右侧有「歌词」按钮可以打开歌词悬浮窗（桌面端支持置顶显示，看视频的时候跟着唱歌挺方便）。

### 自动换源——播放器的"隐形保镖"

这是 TuneFree 最实用的功能之一。第三方音乐平台的公开接口并不总是稳定运行——域名可能因为维护、风控、政策变更或网络波动临时不可用。如果正在听歌时突然断了，手动切音源再找同一首歌的可用版本会非常繁琐。

TuneFree 的自动换源机制分四个阶段工作：

1. **预检测**：点击播放按钮时，应用会同时向所有可用音源发起轻量级探测请求，优先连响应最快的那个作为首选播放源
2. **播放中监控**：音频流开始传输后，播放器持续盯着缓冲区状态——连续 3 秒没新数据到达就判定当前音源不可用
3. **自动切换**：播放器立即暂停，并行请求这首歌在其他音源的可用版本，一旦有音源返回有效地址就立刻恢复播放，用户感知约 1~2 秒
4. **标记与偏好调整**：被判定不可用的音源会在本次会话中被降权，后续搜索优先用其他稳定的音源

自动换源时播放器界面右下角会弹一个小提示，告诉你「已切换到 XX 音源继续播放」。如果所有音源都不可用，才会弹出明确的播放失败提示，建议稍后重试或检查网络。

> [!NOTE]
> 如果自动换源没触发（比如网络时断时续的假死状态），可以手动操作：在播放列表里长按或右键当前歌曲，选择「换源播放」，应用会立即放弃当前连接、重新从所有音源获取可用地址。

### 音源失效了怎么办

点击播放后如果播放器短暂缓冲就弹出「播放失败」或「无声音」，最常见的原因就是某个平台的解析接口临时挂了。快速恢复的方法按优先级排：

1. **手动切换音源**：搜索框右侧有音源栏，把当前音源切到其他可用音源（比如从 QQ 音乐切到网易云或聚合搜索），重新点播放
2. **等自动换源**：默认已开启，正常 1~2 秒内恢复。等超过 5 秒还没反应就用方法一
3. **切聚合搜索**：直接切到「聚合搜索」模式，应用会自动从所有音源返回结果并优先选可用的那个

罕见情况是三个音源同时受影响（服务端大规模故障或网络屏蔽了所有音源域名），这时检查下网络、确认 VPN / 代理节点是否正常、等 10~30 分钟再试，服务端故障通常能在这个时间内恢复。

### 扫码登录，把网易云收藏搬过来

TuneFree 本身**可以不登录直接用搜索、播放、下载**——不强制要求账号。但登录网易云账号后能解锁不少实用功能：

- 自动同步网易云收藏的全部歌曲
- 同步网易云上创建的歌单及其完整曲目
- 多设备间通过网易云账号保持收藏一致
- 导入网易云听歌历史用于个性化推荐

登录流程很简单：点应用右上角或侧边栏的「登录」按钮，选「网易云扫码登录」，界面弹出二维码（有效期约 2 分钟，过期点「刷新二维码」重新生成），然后打开手机网易云音乐 App，点搜索栏左侧的「扫一扫」图标扫码、确认授权就行。

授权成功后 TuneFree 会自动拉取收藏歌曲、歌单、关注的歌手等数据，首次同步可能需要几分钟（取决于你的网易云账号积累了多少内容），后续增量同步很快。

> [!NOTE]
> 扫码登录是网易云官方提供的 OAuth 授权方式，TuneFree 不会获取账号密码或 Cookie，仅在授权有效期内持有 access token。退出登录后 token 会被立即撤销，安全性不用太担心。

### 主题外观，让界面顺眼一点

TuneFree 的界面模式支持三种切换：

| 模式 | 说明 | 适用场景 |
| --- | --- | --- |
| 浅色 | 白底深字，默认亮色主题 | 白天光线充足、喜欢清爽风格 |
| 深色 | 深底浅字，护眼节能 | 夜间使用、OLED 屏幕省电 |
| 跟随系统 | 自动跟随 Windows / macOS 系统设置 | 懒人配置，系统切 App 就切 |

推荐重点关注**主题色定制**这个功能——TuneFree 有两种高亮色方案：

- **跟随封面**（动态主题色）：每首歌根据封面主色调自动匹配界面高亮色，听歌时界面颜色跟着歌曲封面变化，这是比较有特色的视觉效果
- **固定主题色**：从预设的几种主题色里选一种，全局保持统一风格

桌面端播放界面中心显示大尺寸专辑封面，封面背景做了高斯模糊处理作为界面主背景填充，侧边栏、歌词窗口也会显示对应歌曲的小封面。安卓端则有播放界面封面动画、状态栏沉浸色跟随封面动态变化、锁屏大封面加媒体控制这些细节。
