## ✨ New Bing 是什么——从搜索引擎到 AI 助手

New Bing 是微软在 2023 年初正式推出的 AI 增强版搜索引擎，随后逐步演变为统一的 Copilot 品牌。它的核心逻辑是用大语言模型（GPT-4 / GPT-4o）给传统搜索引擎加上一层"对话理解 + 综合回答"能力——不再是返回十个蓝色链接让你自己翻，而是直接把搜索到的信息整合、提炼、生成一段结构化的答案。

New Bing 的能力远不止搜索。它内置了 **多模态理解**（看图提问、OCR 识别）、**图片生成**（Bing Image Creator）、**网页上下文感知**（在 Edge 里对着当前页面提问）、**写作辅助**（Composer 模式起草邮件/文案/文档）等功能，同时通过浏览器侧栏、任务栏、移动应用等多个入口触达用户。

如果你只是想搜个东西，它能比传统搜索引擎省时间；如果你需要整理一篇研究报告、翻译一页 PDF、找一件衣服的同款，它能直接上手帮你做——这也是它区别于普通 AI 聊天机器人的关键：**它有搜索引擎的实时联网能力，也有浏览器的页面上下文感知能力**。

适合谁用？经常需要查资料、做研究、整理信息的人——学生写论文、职场人做调研、内容创作者找素材、普通用户解决日常问题，都能找到对应的使用场景。

## 🔧 多平台安装说明

New Bing 不是一个传统意义上的"单一下载包"——它以 Copilot 品牌渗透到多个产品中，安装路径取决于你用什么设备。

### Windows 桌面端（推荐搭配 Edge）

最顺畅的体验来自 Edge 浏览器集成。Windows 11 系统大多已预装 Edge，Windows 10 用户如果没有，可以从微软官网免费下载安装。装好后，Edge 右侧边栏默认就带有 Copilot 入口，点击紫色对话气泡图标即可开始使用。

> [!TIP]
> 调出 Copilot 的快捷键是 `Ctrl + Shift + C`（Windows）或 `Cmd + Shift + C`（Mac），记下来日常会省不少鼠标点击。

### 移动端

- **Android**：在 Google Play 搜 "Bing" 或 "Copilot"，两个都可以——Bing 应用侧重搜索入口，Copilot 应用侧重 AI 对话体验
- **iOS**：在 App Store 搜同样的关键词，下载后用 Microsoft 账户登录即可

> [!NOTE]
> 使用 New Bing / Copilot **必须登录 Microsoft 账户**——`@outlook.com`、`@hotmail.com` 等都可以免费注册。没有账户只能以访客身份试用非常有限的功能。

### 没有 Microsoft 账户？

去 account.microsoft.com 注册一个，只需要邮箱和密码，不强制绑定手机号。免费版已包含全部核心 AI 功能，图片生成有每日使用配额（用完后等重置即可）。

### 区域限制

部分国家/地区的账户可能无法使用完整功能，如果登录后发现功能受限，可以检查一下账户的区域设置。新注册账户偶尔会有几分钟的审核延迟，等一会再试通常就能正常使用了。

## 📖 使用入门——从搜索到 AI 助手的完整路径

装好、登录完账户后，真正的体验才刚开始。下面按日常使用频率从高到低梳理核心功能。

### Edge 侧栏：最深度的集成入口

Edge 和 Copilot 是原生集成的——不是简单加个网页快捷方式，而是把 AI 能力嵌进了侧栏、地址栏、右键菜单。独有的优势是 **页面上下文感知**：AI 能"看到"你正在浏览的网页内容，对着具体页面提问、摘要、对比。

调出 Copilot 有三种常用方式：

1. **右侧边栏图标**（最常用）—— 点击窗口右上角紫色对话气泡
2. **地址栏生成图片** —— 默认搜索引擎是 Bing 时，输入 `create image of 内容` 回车就能直接在搜索结果页生成图片
3. **右键选中内容提问** —— 网页上选中一段文字，右键点 "Ask Copilot"，侧栏自动打开且选中内容已预填

### 视觉搜索：给图提问

这是 New Bing 多模态能力的核心功能。传统以图搜图是找相似图片，New Bing 的视觉搜索是 **理解图片内容并回答你的问题**——你可以给一张图，然后用自然语言问任何关于这张图的问题。

视觉搜索的能力覆盖四类场景：

| 能力 | 举例 |
|------|------|
| 物体识别 | 拍一张路边的花 → AI 告诉你品种；拍一件家具 → 识别品牌型号 |
| 相似商品搜索 | 街拍里看到一件外套 → 帮你找同款和价格；家居图 → 找图里每件家具的购买链接 |
| 文字识别（OCR） | 拍一张外语文档 → 提取并翻译；手写笔记 → 转成可编辑文本 |
| 给图多轮提问 | "这是什么菜？怎么做？" "这台相机什么型号？大概多少钱？" |

视觉搜索在 Bing 搜索框、Copilot 对话、Edge 侧栏、移动端 Bing/Copilot 应用里都能用——桌面端在 Bing 搜索框右侧点相机图标，或在 Copilot 输入框里点上传按钮；移动端直接点搜索框旁的相机图标拍照或选相册图片。

### 隐私设置：控制哪些数据被发送

Edge 侧栏 Copilot 功能强大的代价是它能访问浏览器里的上下文信息。打开 Copilot 设置（侧栏右上角 "..." → 设置 → 隐私），你会看到几个关键开关：

**页面上下文（Page Context）** 控制 Copilot 是否读取你当前浏览的网页内容。日常使用建议保持开启（方便度提升太多），但在银行、医疗、工作内部系统等敏感网站场景，临时关掉更稳妥。关闭后 Copilot 变成独立 AI 助手，看不到你的页面，只能基于提问和联网搜索回答。

**个性化和内存** 控制 Copilot 是否使用你的过往数据做个性化推荐。开启时 Copilot 会参考你的 Bing/MSN 活动、浏览历史、Copilot 对话历史来做更贴合你偏好的回答；关闭后每次对话都是"全新开始"，隐私更好但个性化不足。

**使用对话改进服务** 决定微软是否可以用你的 Copilot 对话来训练和改进服务。开启时会有匿名化数据被用于模型训练，也可能有人类审核员审查少量对话；关闭后对话仍会被临时存储以生成回答，但不会被用于后续模型改进。

**浏览历史访问** 在"个性化和内存"开启时额外控制 Copilot 是否能看到你的 Edge 浏览历史。比如上周搜过 RAG 入门教程，本周再问相关问题时，Copilot 能记得你之前看过什么、直接接上。

> [!WARNING]
> 清除历史只清掉微软存储的 Copilot 对话记录，不影响 Edge 自己的浏览历史——两者独立管理，敏感场景下要注意分别清除。

### 账户类型与限制

New Bing / Copilot 的账户体系分三类，功能完整度差异明显：

| 账户类型 | 准入条件 | 核心差异 |
|----------|----------|----------|
| 个人免费账户 | 任意 Microsoft 账户 | 全部 AI 功能可用，图片生成有每日配额，对话历史自动同步 |
| 学校教育账户 | 学校提供的 Microsoft 365 教育许可 | 功能完整度取决于许可证类型（A3/A5 许可最完整） |
| 企业账户 | Microsoft 365 Copilot 企业许可（E3/E5 附加） | 支持 Enterprise Data Protection（EDP），管理员可管控功能范围，可配置连接器访问企业内部系统 |

个人用户直接注册免费账户即可满足绝大部分需求。企业版的 EDP 保护机制确保 Copilot 不会学习或存储企业敏感数据，这也是个人版和企业版最本质的区别。

### 常见登录问题排查

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 提示"此账户未授权" | 新注册账户有审核延迟 | 等几分钟再试，或先从 bing.com 登录 |
| 收不到验证码 | 邮箱/手机号填写问题 | 检查垃圾邮件，或换备用邮箱注册 |
| 一直转圈加载 | 网络连接问题 | 换浏览器/设备重试 |
| 登录后功能受限 | 区域不支持 | 检查账户区域设置 |
