## ✨ Poweramp：Android 本地音乐播放器的旗舰选择

Poweramp 是一款专为 Android 设备打造的本地音乐播放器，自 2010 年上线以来一直被发烧友视为 Android 平台音质天花板。它不做流媒体聚合，专注于把你手机里已经存好的本地音乐文件播到最好——支持几乎所有音频格式，内置专业级 EQ 均衡器、DVC 直控音量、Float32 高解析采样，以及对几万首大曲库的稳定支持。

它适合哪些人用？如果你有一个本地音乐曲库（FLAC / WAV / APE / DSD 之类的无损资源）、有一副或几副需要调音的耳机、或者折腾 USB DAC 外接解码，Poweramp 基本是绕不开的选择。普通用户如果只是偶尔听听 MP3，可能感受不到它的优势——但对音质有追求的人来说，它的 DSP 处理能力和音量控制精度是免费播放器无法比拟的，想确认自己的设备支持哪些特性，可以去 Poweramp 官网查一下完整的支持列表。

## 🔧 安装步骤与注意事项

Poweramp 目前有两个版本：**Poweramp Player**（播放器主体）和 **Poweramp Equalizer**（独立均衡器 App），两者可以单独使用也可以搭配使用。安装步骤都是标准的 Android APK 安装流程，但有几个注意点值得提前了解。

**安装前准备：**

1. 确认设备运行 Android 5.0 及以上版本（部分高端功能如 Float32 输出需要 Android 8.0+）
2. 留出至少 200MB 存储空间（App 本体不大，但扫描曲库时会生成索引缓存）
3. 如果是从 APK 安装，需要在系统设置里开启「允许未知来源安装」

**安装过程：**

1. 从下载入口拿到 APK 文件后，点击安装
2. 首次启动时授权「存储访问」权限——这一步必须给，否则扫不到你的音乐文件
3. 如果设备上装有 Google Play 服务，也可以直接从商店安装，自动处理权限

> [!WARNING]
> 安装 Equalizer 时如果系统弹出「覆盖安装」提示，说明之前装过旧版——建议先卸载再装新版，避免 EQ 预设丢失或 DSP 模块冲突。

**版本核对：** 安装完成后在「设置 → 关于」里可以看到当前版本号。Poweramp 的开发节奏稳定，每隔几个月会推送功能更新，建议保持在最新版以获得更好的兼容性和音质优化。

## 📖 使用入门：从基础到大库深度优化

### 曲库扫描与索引

第一次打开 Poweramp 后，它会自动扫描设备上的音频文件。扫描时不会解码任何音频内容——只读取文件路径、标签（ID3 / FLAC tag）、格式、采样率和时长这些元数据，全部存入 SQLite 数据库。这种轻量索引方式让它在几万首曲库下也能秒启动：冷启动 1~3 秒，热启动通常不到 1 秒，内存占用始终维持在几十 MB 量级。

> [!TIP]
> 大库用户可以在「设置 → 曲库 → 扫描」里开启「分块扫描」——扫描过程中随时可以暂停或杀进程，下次打开会从上次停止的位置继续，不会崩。

### DVC 直控音量：该不该开

DVC（Direct Volume Control）是 Poweramp 最独特的技术特性之一。普通 Android 应用调音量要经过系统混音器（AudioFlinger），以 1dB 为步进、大约 70~100 档；DVC 让 Poweramp 绕过系统音量，直接在整数位音频流上做衰减，步进更精细（255 档，每 0.5dB 甚至更细），动态范围也更宽。

**推荐开启的场景：**
- USB DAC 外接解码时，DAC 直接接收数字信号，动态范围最大
- 有线耳机（3.5mm / USB-C）输出，通常稳定
- 独立 DAP 设备，Android ROM 不会过度干预音频管线

**谨慎或不推荐开启的场景：**
- 蓝牙耳机 LDAC / LHDC 高码率传输，部分设备会信号不稳定
- 小米 / OPPO / vivo 等厂商定制 ROM，AudioFlinger 有自家音效处理插件可能冲突
- 系统级耳机音效（杜比全景声、实时原声等）已开启时

> [!NOTE]
> 第一次开 DVC 前，先把系统音量拉到最大，再在 Poweramp 里开启 DVC，然后用 Poweramp 自己的音量滑块调音量——系统音量键接管后，Poweramp 内部调节会同步生效。

### Float32 采样：什么时候有用

音频数据的常见存储格式是 16-bit / 24-bit / 32-bit 整数 PCM，而 Float32 是 Poweramp 内部 DSP 处理的格式——动态范围约 150dB，做 EQ 均衡、重采样、增益控制时精度更高。当你用 USB Exclusive Driver 连接 DAC、或走 AAudio Hi-Res 输出路径时，Poweramp 可以直接用 Float32 格式送信号给 DAC，省去最后一步整数转换和 Dither 抖动。

简单说：**USB DAC 场景开 Float32 能听出区别**——安静段背景更黑，动态范围确实更宽；手机 + 普通蓝牙耳机的组合区别不大，蓝牙本身的压缩已经覆盖了这个差异。

### 预设导出与跨设备迁移

如果你给某副耳机调好一套 EQ（AutoEq 自动校正 + 手动微调），想保存下来或带到另一台设备上用，Poweramp 的预设导出功能可以轻松搞定。

预设本质是一个 XML 格式的配置文件，包含 EQ 参数（每个频段的频率 / 增益 / Q 值）、Bass / Treble 数值、Stereo Expand 开关、Limiter 开关、DVC 模式以及你给预设起的名字和备注。导出方式：

- **单个预设：** EQ 界面 → 右上角预设菜单 → 选中一个预设 → 「导出」
- **批量导出全部：** 设置 → 音频 → 预设 → 「批量导出」

建议把导出的 `.equalizer` 文件存到云端同步目录（OneDrive、Dropbox、坚果云都可以），换机时直接从云端导入，Player 和 Equalizer 两个 App 共享同一套预设目录，在 Player 里调好的预设在 Equalizer 里直接能用，不需要重调。关于预设文件格式的更多细节，可以参考 Poweramp 官方文档里的预设导出专题。

### 专辑封面管理

Poweramp 按照「文件内嵌 → 同目录文件 → 网络下载」的优先级找封面。ID3 / FLAC 标签里带的内嵌封面最规范，其次是目录下的 `folder.jpg` / `cover.jpg` / `front.jpg` 等文件（默认支持多种命名，可在设置里自定义），最后才是从网络自动抓取。

自动扫描时可以让它顺便下载封面，但 AI 匹配不一定准——同一专辑多个版本时可能抓错。建议用标签编辑器手动选一张高清封面（800×800 以上），嵌入文件或保存为同目录 `folder.jpg`，显示效果最好。

| 常见封面问题 | 原因与解决 |
| --- | --- |
| 封面显示模糊 | 内嵌封面分辨率太低 → 手动下载高清版重新嵌入 |
| 同一专辑多封面 | 每个音轨内嵌了不同封面 → 批量编辑标签统一封面 |
| 封面下载失败 | 网络或 API 被墙 → 手动找图用标签编辑器嵌入 |
