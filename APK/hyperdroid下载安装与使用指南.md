## ✨ HyperDroid 是什么

HyperDroid 是一款 Android 桌面启动器，它把平板、折叠屏甚至手机的原生桌面改造成 Windows 11 风格的完整桌面环境。任务栏、开始菜单、窗口化应用、虚拟桌面、系统托盘——这些 PC 用户习以为常的桌面元素，在 HyperDroid 里全部搬上了 Android 设备，而且不是简单的皮肤替换，是一套完整的桌面化交互体系。

它的核心价值在于让大屏 Android 设备真正具备桌面级的多任务处理能力。10 英寸以上的平板配上 HyperDroid 和一套蓝牙键鼠，体验上已经接近一台轻量笔记本——可以并排开多个窗口、用虚拟桌面隔离不同工作场景、用文件管理器的侧边栏快速跳转目录。对折叠屏用户来说，展开态切换到 HyperDroid，原本的大半个屏幕突然变成了一个能真正"干活"的桌面空间。

HyperDroid 保留了 Android 的全部底层能力，通知、权限、应用生态都照常运行——桌面界面只是上层的交互重构，不影响设备本身的任何功能。

## 🔧 安装步骤

HyperDroid 是 Android 平台的启动器应用，安装流程和普通 APK 类似，但有几个需要注意的地方。

### 安装包获取与校验

从下载页拿到安装包后，先核对一下文件名和版本号。部分下载源会提供 MD5 或 SHA256 校验值，建议在安装前用文件管理器计算一次，确保文件完整且未被篡改。文件体积通常在几十 MB 到一百多 MB 之间，具体取决于版本和设备架构。

### 允许未知来源安装

HyperDroid 不在所有 Android 设备的官方应用商店上架，安装时需要开启"允许安装未知来源"权限：

1. 打开 Android 设置，进入 **安全** 或 **应用与通知** 分类
2. 找到 **特殊应用访问权限** 或 **安装未知应用**
3. 选择你用来打开安装包的应用（通常是文件管理器或浏览器）
4. 开启 **允许从此来源安装** 的开关

> [!WARNING]
> 开启未知来源安装后，务必只从可信的下载渠道获取安装包。安装完成后可以考虑关闭这个权限，降低设备安全风险。

### 设置默认启动器

安装完成后，按一下设备的 Home 键，系统会弹出"选择启动器"的对话框。勾选 HyperDroid 并选择 **始终**，之后按 Home 就会直接进入 HyperDroid 桌面。如果之后想切回原生 Android 桌面，在 HyperDroid 设置里找到"默认启动器"选项切换即可，不需要卸载。

### 首次启动配置向导

HyperDroid 首次启动会进入一个简短的配置向导，引导你完成权限授予（通知访问、无障碍服务、存储访问等）。这些权限是窗口化、虚拟桌面、文件管理器等核心功能正常工作的前提，建议全部授予。

## 📖 使用入门

### 系统托盘与快速操作

HyperDroid 的任务栏右侧是系统托盘区，图标会动态反映设备状态：

- **Wi-Fi / 蓝牙 / 音量 / 电池** 各自独立显示，点击可直接操作（比如点 Wi-Fi 图标弹列表、点音量图标拉滑块、点电池看详细电量）
- 托盘有一个 **∧** 折叠按钮，点击展开隐藏区，里面是后台运行的应用图标和更多系统状态
- 点击托盘最右侧的通知区，会弹出快速设置面板——聚合了 Wi-Fi、蓝牙、飞行模式开关、音量亮度滑块、屏幕旋转锁定、定位服务、勿扰模式，全部一键完成，不需要进完整的 Android 设置

托盘图标哪些始终显示、哪些折叠隐藏，可以在 HyperDroid 的 **个性化 / 任务栏** 设置里调整。

### 文件管理器的效率提升

HyperDroid 自带的文件管理器相比 Android 原生有明显的效率优势：

侧边栏预置了 **六个常用文件夹** 的快捷入口，从任何目录都能一键跳转，不需要一级一级返回再重进：

| 文件夹 | 用途 |
| --- | --- |
| 此 PC | 设备存储根目录、SD 卡、OTG 存储 |
| 下载 | 浏览器和 App 下载的文件 |
| 文档 | Word/PDF/TXT 等文档 |
| 图片 | 截图、保存的网页图片 |
| 视频 | MP4/MKV 等视频文件 |
| 音乐 | MP3/FLAC 等音频文件 |

图片和视频文件夹支持 **直接预览**：点图片弹出查看窗口，点视频直接播放，而且预览窗口本身也是窗口化的——可以缩放、置顶，边看边做其他事。

> [!TIP]
> 下载文件夹是 HyperDroid 用户最常访问的目录，安装包、浏览器下载的文件、App 缓存都堆在里面。定期清理（全选 Ctrl+A 后批量删除旧文件）能有效释放存储空间。

### 平板 vs 手机：屏幕尺寸决定体验

HyperDroid 的桌面化设计理念天生适合大屏设备，不同屏幕尺寸的体验差异很大：

| 设备类型 | 典型屏幕 | HyperDroid 体验 |
| --- | --- | --- |
| 10 英寸以上平板 | 25cm 左右 | 窗口大小合理，可并排 2-4 个窗口，文件管理器侧边栏宽敞 |
| 7-8 英寸平板 / 折叠屏展开 | 18-20cm | 窗口偏小但能并排 2 个，体验接近轻量笔记本 |
| 普通手机 | 15cm 以内 | 窗口化意义不大，桌面组件拥挤，建议只用浏览器和文件管理器 |

推荐的设备组合：移动办公首选 **10+ 英寸平板 + 蓝牙键鼠 + HyperDroid**；便携折中选 **折叠屏手机 + HyperDroid（展开态）**，折叠态切回原生 Android 桌面即可。

### 虚拟桌面：三指滑动切换工作场景

虚拟桌面是 HyperDroid v2.x 引入的高级功能——在同一台设备上创建多套独立的桌面工作空间，每个空间里有独立的窗口布局和运行中的应用。

操作手势（触屏）：

- **三指向左滑** → 上一个虚拟桌面
- **三指向右滑** → 下一个虚拟桌面
- **三指滑过当前桌面边界** → 自动创建新的虚拟桌面

如果接了物理键盘，按 **Win + Tab** 可以打开任务视图，手动创建或删除虚拟桌面。

典型的场景隔离用法：

| 桌面 | 用途 |
| --- | --- |
| 桌面 1 | 日常通讯（微信、Telegram、邮件） |
| 桌面 2 | 办公（浏览器、文档编辑器、笔记） |
| 桌面 3 | 娱乐（视频、音乐） |

切换场景只需三指一滑，窗口布局会自动保留——切出去回来后，窗口还在原来的位置。虚拟桌面的窗口布局切换性能良好，不会明显卡顿，因为它保存的是布局信息而不是重启应用。

> [!NOTE]
> 虚拟桌面适合做场景隔离，多窗口适合做实时协同（一边查资料一边记笔记）。两者不冲突，可以搭配使用。虚拟桌面删除时，桌面上的应用会自动移回主桌面，不会丢失数据。
