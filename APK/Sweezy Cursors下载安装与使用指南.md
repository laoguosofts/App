## ✨ Sweezy Cursors 是什么——横跨浏览器与系统的自定义光标平台

Sweezy Cursors 是一个面向全平台的自定义光标资源库，核心定位是让用户用最少的操作把游戏 IP、动漫角色、可爱贴纸等主题素材变成自己每天盯着的鼠标指针。从 2022 年上线至今，全站累计"加入 + 下载"超过 3450 万次，Minecraft 附魔下界合金剑、Solo Leveling 暗影箭、原神角色光标这类热门主题长期霸占首页 Top Cursors 榜单。

与市面上同类型产品不同，Sweezy 的光标产品横跨三个技术接口完全独立的场景——浏览器扩展、Windows 系统原生指针、Roblox 游戏内光标替换，三者互不依赖、可以自由组合。有人同时在 Chrome 装扩展、Windows 桌面也换了同款动画光标、玩 Roblox 时还想沿用同一套风格，Sweezy 都能覆盖到。

这款产品适合三类用户：喜欢折腾桌面个性化的 Windows 玩家、想给浏览器加点小彩蛋的日常用户、以及在 Roblox 里追求沉浸式体验的游戏玩家。它不做花哨的一键安装器，而是直接提供标准格式文件，把控制权交还给用户。

## 🔧 安装前先搞清楚——三个场景各装各的

Sweezy 最容易让新用户懵圈的地方就是它的产品结构——三个场景、三种安装方式、三套文件格式，彼此之间完全不通用。搞清楚自己到底要装哪一套，比急着下载文件更重要。

### 浏览器扩展——最省事的入口

浏览器扩展是 Sweezy 的主战场，60 万+ 安装量绝大部分来自这里。支持 Chrome、Edge、Brave、Opera、Vivaldi 等所有 Chromium 系浏览器，Firefox 和 Safari 没有官方版本。安装方式就是商店一键添加，装完后浏览器工具栏会出现一个小图标，点开就能浏览全站 2000+ 个光标包，点一下 Add 就替换了。

> [!NOTE]
> 浏览器扩展生效范围仅限**网页内容区**——系统页（新标签、设置、下载、扩展管理）和浏览器自身 UI（标签栏、地址栏、工具栏）上光标不会变。这是浏览器安全模型限制，不是 Sweezy 的问题。

### Windows 系统——原生指针方案

Windows 下换光标是操作系统层面的事，Sweezy 不做一键安装器，直接提供 CUR（静态）和 ANI（动画）两种微软原生格式文件。用户下载后需要自己放进一个固定文件夹，再到系统设置里手动绑定。步骤稍微繁琐一些，但好处是完全不需要装额外软件，Windows 原生支持，生效范围覆盖桌面、资源管理器和所有应用。

> [!WARNING]
> CUR / ANI 文件一旦下载完成，**不要随便挪动位置**。Windows 会把文件的绝对路径记在注册表里，文件被移动或删除后系统找不到原文件，会自动回退到默认光标。官方建议放在 `我的文档\Sweezy Cursors\` 或 `C:\Windows\Cursors\` 这类不会被随手清理的路径。

### Roblox 游戏——文件替换方案

Roblox 对自定义光标没有官方支持，社区通用做法是替换游戏安装目录下的 ArrowCursor.png 和 ArrowFarCursor.png 两个文件。Sweezy 专门提供 Roblox 用的 PNG 下载选项，会把动画光标转换成单帧静态图。缺点也很明显——Roblox 每次大版本更新都会还原这些文件，需要重新替换。

## 📖 Windows 安装与使用——最多人用也最需要耐心的场景

Windows 场景是 Sweezy 用户最集中、也最容易踩坑的环节。以下按从下载到长期维护的完整流程梳理。

### CUR 和 ANI 怎么选

Windows 光标有两种格式：CUR 是静态光标，就是一张透明背景的 PNG，通常几 KB；ANI 是动画光标，多帧图像 + 帧间隔 + 循环模式打包，通常 20~100KB+。每个光标详情页的下载按钮会标记提供哪些格式，有的只提供 CUR，有的同时提供两套。

| | CUR（静态） | ANI（动画） |
| --- | --- | --- |
| 文件大小 | 通常几 KB | 通常 20~100KB+ |
| 视觉效果 | 一个静止图标 | 循环小动画 |
| 适合人群 | 极简风、怕动画分散注意力 | 游戏主题、可爱风、想玩出花 |

### 绑定到系统指针

下载好文件并放到固定位置后，打开「设置 → 蓝牙与设备 → 鼠标 → 其他鼠标选项」，在弹出的窗口里切到「指针」选项卡。这里有十几个系统角色需要绑定，但 Sweezy 的光标包重点覆盖两个最常用的：

1. **Normal Select（正常选择）**——90% 时间你看到的箭头光标，点击它然后点「浏览」，选你下载的 CUR 或 ANI 文件
2. **Link Select（链接选择）**——鼠标悬停在可点击链接上变成的小手，同样 Browse 绑定

其余角色（文字选择、忙碌、精确选择等）用系统默认就好，除非你想整套都换。

> [!TIP]
> 动画光标文件较大，如果系统卡顿或某些应用里动画不流畅，可以换回对应的 CUR 静态版本。

### 保存方案——防止系统更新把光标还原

Windows 有个容易被忽略的坑：你手动 Browse 改了 Normal Select 等角色之后，如果不点「另存为」，这些改动只挂在当前选中的方案实例上。系统更新一次、或者某个驱动程序重置鼠标设置，改回去的就是你那套临时状态。

保存为独立方案后，它会作为一个完整配置写进注册表。不管什么原因导致光标还原，只需在方案下拉菜单里选中它，整套绑定瞬间恢复。具体步骤：

1. 确认 Normal Select、Link Select 等角色都已经 Browse 绑定好 Sweezy 文件
2. 点击右下角「另存为...」
3. 输入方案名，推荐带上光标主题方便识别，比如 "Sweezy Solo Leveling" 或 "Sweezy Hello Kitty"
4. 点击确定，方案会出现在下拉菜单底部

喜欢经常换主题的话可以保存多套方案，每次切换下拉菜单即可。每套方案都会引用之前 Browse 时指向的那些 CUR / ANI 文件——前提是文件还在原来的位置。

### 回到默认

如果想彻底回到 Windows 默认光标：在下拉菜单里选「Windows 默认（系统方案）」即可；或者选中某个具体角色，点「使用默认值」单独还原。
