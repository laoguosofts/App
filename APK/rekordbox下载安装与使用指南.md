## ✨ rekordbox 是什么

rekordbox 是 Pioneer DJ 推出的专业 DJ 备演与打碟软件，面向从新手到职业俱乐部 DJ 的完整工作流覆盖。它把「搜歌 → 整理 → 打点 → 备演 → 上台」这条线上的每个环节串成一条龙：本地曲库 + 流媒体接入统一管理，智能工具替你做推荐和打点决策，U 盘或手机一键导出就能上打碟台。

ver.7 版本引入的三层播放列表结构（文件夹 → 列表 → 曲目）让曲库组织更清晰，智能播放列表和相关曲目推荐则把软件从被动工具变成主动助手——你给条件它填歌、你打一首歌它推荐下一首。

适合谁用？刚入门想系统性整理歌单的新手、需要快速备演的俱乐部 DJ、偶尔去暖场的爱好者，以及和搭档 back-to-back 需要共享备演的团队。

## 🔧 安装步骤

rekordbox 支持 Windows、macOS 以及 iOS / Android 移动端，安装流程按平台各有差异。

**桌面端（Windows / macOS）**

1. 从下载页获取安装包（Windows 为 `.exe`、macOS 为 `.dmg`）。
2. 双击运行安装程序，macOS 用户首次打开需在「系统设置 → 隐私与安全性」中允许来自开发者的应用。
3. 安装向导默认路径即可，自定义路径时注意不要放在系统保护目录（如 Windows 的 Program Files 深层嵌套）。
4. 首次启动会提示登录账号——这是正常流程，即使使用 Hardware Unlock 设备也需先登录一次建立账号关联。

> [!NOTE]
> 杀毒软件可能误报安装程序，属于常见现象。建议从下载页获取的安装包直接运行，避免第三方改包版本。

**移动端（iOS / Android）**

1. App Store 或 Google Play 搜索 rekordbox 官方 App 下载安装。
2. Android 用户如遇安装被拦截，需在「设置 → 安全 → 未知来源」中允许对应应用来源。
3. 首次启动同样需要登录账号以同步曲库和设置。

> [!TIP]
> 安装完成后建议立刻检查版本号是否与下载页一致——软件更新频繁，新功能和 bug 修复通常只在最新版中可用。

## 📖 使用入门

### 曲库管理：让歌单有序

播放列表是备演的基本单位，rekordbox 用三层结构帮你组织：**文件夹 → 列表 → 曲目**。文件夹用来归组场景（比如「周五 bar 场」「婚礼专场」「Deep House 备选」），列表则是具体的备演清单。ver.7 在列表顶部加了「All Tracks」入口，可以直接看整个合集，拖进新曲也不用先选中再右键。

**智能播放列表（Intelligent Playlist）** 是最省力的功能——给条件，软件自动填。指定流派、BPM 区间、调性、艺人、备注，它从曲库里把匹配的曲目拉进来。两类典型用法：

- **风格化备演**：建一个「126~129 BPM、Am 附近、无说唱」的列表，每次导入新曲自动进池。
- **发现存货**：曲库里被遗忘的曲目，按条件重新捞出来。

**协作播放列表（Collaborative Playlist）** 对 back-to-back 搭档特别有用——共享的不只是歌名，还包括曲目顺序、BPM、网格、Cue 点这些元数据。不过有两个限制要提前知道：列表里的流媒体曲目，对方也需要订阅同一服务；本地曲目对方得自己买过才播得了。

### 相关曲目推荐：下一首接什么

曲库浏览器里点开一首歌的「相关曲目」，会按几个维度给出候选：

- **BPM + KEY 双近**：速度和调性都接近的曲子，接歌成功率最高。
- **同流派 30 天内**：最近一个月收的同风格货，新鲜感优先。
- **同艺人 / 同厂牌**：风格连续性最好保。

每个维度背后是你自己曲库的元数据——流派和调性标的越准，推荐越可用。

**Radar 功能** 把找歌半径扩到曲库外：Collection Radar 在本地存货里找相似，Streaming Radar 则延伸到已接入的流媒体曲库，听到曲库里没有的同路货可以直接加进列表（需对应服务订阅）。

> [!WARNING]
> 推荐只负责候选，落地还差三步：试听相性（EXPORT 模式里的 DUAL PLAYER 双播放器可以联动试验）、打好点位、导出带走。别看到推荐就直接上台。

### 订阅与付费：按需选择

各档均有月付与年付两种（年付约等于八折），可以随时在账号订阅页切换。几个关键规则：

| 项目 | 说明 |
|---|---|
| 14 天冷静期 | 月付或年付开始后 14 天内可申请退款 |
| 超 14 天取订 | 已付费用不退，当前计费周期结束前功能照常 |
| 年付中途升档 | 剩余年费按已过月数折算退还（每月降 10%） |
| 退款到账 | 约 3~7 个工作日按原路返回 |

决策路径建议：先把免费边界摸清 → 确认手里硬件解锁了哪些功能 → 只为解锁清单之外的功能付费。有 Hardware Unlock 设备的 DJ，很多场景下根本不需要订阅。

### 移动端救场：手机当 U 盘

rekordbox 移动 App 支持把手机以 USB 存储设备的身份接给 CDJ/XDJ——一根 USB 线连上，播放器把手机识别成曲库来源，里面的播放列表、Cue 点、网格原样可读。接线步骤：

1. 手机装好 App、曲库备妥（本地曲目 + 打好的点）。
2. USB 线连接手机与 CDJ/XDJ 的 USB 端口（iOS 需对应转接件）。
3. 播放器上选择该设备源，浏览播放列表，正常加载播放。

**什么时候比 U 盘好用**：朋友喊去暖场没带 U 盘，手机里的备演库直接顶上；在新设备上验证曲库效果不用反复插拔；手机曲库本来就随 Podcast、备忘、闹钟在身边，最不容易忘。

**边界也要清楚**：依赖线材质量与手机供电，长 set 大曲库场景仍建议正经 U 盘；流媒体在线曲目不在离线供曲范围内，可播的是同步到手机本地的内容。
