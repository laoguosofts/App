## ✨ Gamma AI 是什么：从 PPT 替代品到 Agent 驱动的可视化工作空间

Gamma AI 是一款以 AI Agent 为核心的可视化内容创作平台。和传统 PPT 工具的「从零搭页面」思路不同，Gamma 让你先用自然语言描述想做什么——比如「给我一份 Q3 竞品分析，包含三家对手的功能对比表和用户增长折线图」——Agent 会自动生成完整的 Gamma 文档，包括结构大纲、卡片布局、配图和数据可视化。用户后续在卡片层面微调，而不是从空白幻灯片开始排版。

核心能力可以归为三块：一是 Agent 对话生成，支持从零生成整套文档、对现有内容做重设计、局部修改（比如把第二张卡片的图表改成折线图并优化配色）；二是智能卡片生态，内置智能图表（柱状/折线/饼图等七种）、智能图示（流程图/架构图）、AI 图像生成与编辑等，每种卡片都在编辑器内完成，导出时保留为对象而非图片；三是协作与分享，支持评论锚定在具体段落或卡片上、Google Slides 导出继续在 GSuite 里协作、PDF/PPTX/PNG 等多格式输出。

平台采用 Web 端为主的策略，桌面与移动端浏览器均可使用，无需下载客户端安装包。账号体系有免费版（Watermark、基础功能）、Plus（去水印、扩展额度）、Pro（品牌自定义配色字体、Workspace 团队共享模板）等档位，个人用户通常从免费版起步，团队和企业场景按需升级。

## 🔧 如何安装与配置

Gamma 以 Web 端为主，大多数情况下无需传统意义上的「安装」——打开浏览器访问官方站点，注册账号即可开始使用。桌面客户端和移动端 App 作为可选补充，适合需要本地缓存或系统级通知的用户。

### 浏览器（推荐）

1. **选择浏览器**：推荐 Chrome / Edge / Safari 等主流现代浏览器，确保开启 JavaScript 和本地存储；低版本 IE 不支持
2. **注册账号**：邮箱注册、Google 账号、Microsoft 账号三种方式任选其一；团队场景建议统一用 Google Workspace 账号以便后续协作
3. **完成引导**：首次进入会弹出 Agent 引导界面，输入一句话描述你想创建的内容（比如「给我一份产品介绍」）即可看到 Gamma Agent 生成的第一份文档

> [!NOTE] 浏览器访问是最主流的使用方式。桌面客户端本质上是 Web 端的壳，功能一致，额外提供离线缓存和系统托盘通知。

### 桌面客户端（可选）

如果你的使用场景需要频繁离线编辑或系统级通知，可以安装桌面客户端：

1. 从下载页获取安装包，Windows 为 `.exe`，macOS 为 `.dmg`
2. Windows 双击安装 → 选择安装目录（默认 `C:\Program Files\Gamma AI`）→ 完成；macOS 拖入 Applications 文件夹
3. 首次启动需要登录账号，登录后界面与 Web 端完全一致
4. 如果杀毒软件误报（部分安全软件会把 Electron 壳客户端识别为可疑进程），把安装目录加入白名单即可

> [!WARNING] 桌面客户端目前仍属于早期版本，部分高级功能（如 AI 图像生成的精细编辑）可能优先在 Web 端更新。遇到功能缺失时请先尝试 Web 端。

### 移动端（可选）

iOS / Android 均可在各自应用商店搜索软件名下载，功能覆盖基础的浏览、评论、简单编辑；完整创作流程仍建议在 Web 端或桌面端完成。

### 安装后核对

- 登录后进入仪表盘，能看到模板库和最近创建的文档列表
- 在任意 Gamma 文档里输入 `/chart`，如果能弹出智能图表编辑器，说明核心功能正常加载
- 右上角头像 → 设置 → 账户，确认当前档位符合预期（免费版显示 Free，升级后显示 Plus / Pro）

## 📖 使用入门：对话式生成与卡片化编辑

Gamma 的使用方式可以理解为「Agent 对话 + 卡片微调」两阶段。Agent 负责生成初稿（结构、布局、视觉主题），用户在卡片层面补细节、插图表、加评论。四个典型功能点串联起来就是一套完整的创作工作流。

### 第一步：让 Agent 生成初稿

进入仪表盘后点击「新建 Gamma」，直接在对话框里用自然语言描述你的内容需求。好的提示词包含四个要素：**主题**（什么内容）、**受众**（给谁看）、**结构**（希望有哪几个部分）、**风格偏好**（正式/活泼/科技感等）。例如：「给我一份面向投资人的 Pitch Deck，包含市场背景、产品介绍、竞品对比、商业模式四个部分，风格要正式稳重。」Agent 会调用内部生成管线——多个模型协同（截至当前版本支持 Anthropic、OpenAI、Google 等 20+ 模型）——生成一套带主题的 Gamma 文档。

初稿生成后有两个调整选项：一是**换主题**（顶部工具栏主题按钮，或说「应用一个 XX 风格的主题」）——主题只改视觉层（配色、字体、圆角、阴影），不碰内容结构；二是**让 Agent 重设计**——Agent 会同时改视觉+微调内容+可能调整卡片顺序，灵活但结果有变化性。时间紧时直接从模板库选一个起点（按用途分类如 Pitch Deck、季度汇报，或按行业分类如 SaaS、金融、教育），模板打开就是完整骨架，修改内容即可。

> [!TIP] Agent 从零生成的 Gamma 比模板更不容易有「AI 味」——模板被很多人用过，Agent 对话式生成每次都独特。时间充裕优先走 Agent 路线，时间特别紧才用模板。

### 第二步：插入智能图表做数据可视化

当某张卡片需要展示数据时（对比、趋势、比例、分布），在卡片里输入 `/chart`，或从右侧插入菜单选「图表和图示 → 智能图表」。Gamma 内置七种图表类型：

| 图表类型 | 适用场景 | 示例 |
|---|---|---|
| 柱状图 | 类别之间的数值对比 | 不同地区的销售额 |
| 折线图 | 时间序列趋势 | 月度活跃用户 |
| 饼图 / 环形图 | 占比分布 | 收入构成 |
| 条形图 | 类别对比（横向，适合类别名较长） | 多竞品多指标并排 |
| 面积图 | 强调数量变化的趋势线 | 用户增长势头 |
| 散点图 | 两个变量的关系 | 功能相关性 |
| 堆叠柱状图 | 分组类别的组成变化 | 多档位季度对比 |

打开图表编辑器后，有三种输入数据的方式：直接在表格里填数据、从 Excel / Google Sheets 复制粘贴、或连接 Google Sheets（Pro 档）实现实时同步。表格每列可以通过下拉菜单添加/删除/改名/改变类型，支持多数值列做系列对比。

编辑器里可以调整配色（和当前主题自动匹配，也可以自定义）、数据标签、坐标轴标题、图例位置，图表类型随时可以换。满意后关闭编辑器，图表作为 Gamma 卡片的一部分存在——导出 PDF / PPTX 时保留为图表对象而非图片，这一点是嵌入外部图表做不到的。如果后续想改图表，选中后点闪光图标或在聊天里说「把第二张卡片的图表改成折线图并优化配色」，Agent 可以直接操作。

> [!NOTE] Gamma 智能图表适合绝大多数场景，但极复杂图表（3D、极多数据点、自定义图例逻辑）仍需要外部专业工具。只有在这些极端情况下才考虑嵌入外部图表。

### 第三步：应用主题或品牌风格

Gamma 内置 100+ 主题，每套主题包含配色方案、字体组合、圆角大小、阴影强度、间距密度等一整套视觉规则。应用主题后整套 Gamma 的每张卡片都会被重新着色和排版，但**内容不变**。

| 操作 | 效果 | 适合什么时候用 |
|---|---|---|
| 点击主题按钮选一个 | 纯视觉层改动，快、确定性强 | 内容和结构满意，只是视觉不好看 |
| 让 Agent 推荐主题 | Agent 把品牌风格翻译成主题选项 | 不确定用什么风格，想让 AI 给建议 |
| 聊天让 Agent 重设计 | Agent 同时改视觉+微调内容+调卡片顺序 | 想彻底重做视觉，保留部分内容 |

Plus 档可以去掉 Gamma 水印，Pro 档及以上支持品牌自定义：上传品牌色板（主色、辅助色、强调色），整套主题会从品牌色自动生成；上传自己的字体文件统一全文档；在 Workspace 里保存品牌模板，团队成员新建时自动应用。这对企业场景尤其重要——跨项目保持视觉一致，避免每个新 Gamma 风格乱飞。

### 第四步：评论与协作

内容开始成形后，团队协作靠的是「评论」而非直接编辑。评论锚定在具体位置——选中卡片里的某段文字，右侧出现评论图标，点击即可在那个位置发布评论；也可以对整张卡片（卡片底部或右上角的评论图标）发表卡片级评论。评论里可以 `@` 某个协作者，被 @ 的人会收到邮件或应用内通知。

Gamma 的右侧评论面板按卡片分组或按时间排序展示所有评论，每条评论显示已解决/未解决状态、作者和时间。典型工作流是：作者把 Gamma 分享给团队，给**评论权限**（不暴露编辑权限）；团队成员浏览后在有问题的地方评论提意见；作者进入编辑模式逐条查看评论 → 修改内容；修改完标记评论为「已解决」（已解决的评论默认折叠，保持界面整洁）。客户反馈收集同理，分享链接给客户并开评论权限，客户在问题位置评论，作者决定采纳哪些。

> [!TIP] Gamma 有两个沟通渠道，分工明确：**评论**锚定具体位置（一段文字 / 一张卡片），和内容绑定，适合提具体修改意见；**聊天**是全局对话，可以让 Agent 做操作，适合大方向讨论、换主题、生成新大纲这类全局指令。

评论功能目前有几个限制：不能附加文件（只能写文字）、不能嵌套回复（只有一层）、已解决的评论不能重新打开（只能删除后重新评论）、不支持按评论筛选。这些细节在协作初期可以用聊天补位，但日常评审中评论的锚定特性已经覆盖了绝大多数场景。

### 第五步：导出与发布

Gamma 支持四种导出格式，选择逻辑如下：

| 格式 | 视觉保真 | 可编辑 | 离线 | 适合场景 |
|---|---|---|---|---|
| 链接 | ★★★★★ | ✅（协作） | ❌ | 首选——Analytics + 完整交互 + 响应式 |
| PDF | ★★★★☆ | ❌ | ✅ | 分发归档，保真度最好 |
| PPTX | ★★☆☆☆ | ✅（降级后） | ✅ | 需要在 PPT 里继续编辑 |
| Google Slides | ★★☆☆☆ | ✅（降级后） | ❌ | Google Workspace 团队协作 |
| PNG | ★★★★★ | ❌ | ✅ | 单张卡片分享到社交媒体 |

PPTX 和 Google Slides 导出的底层机制相同——都是从 Gamma 的自由卡片格式降级到固定幻灯片格式，长卡片会被拆、自由定位可能错位、图表会变成图片。比较好的工作流是：在 Gamma 里**集中做内容和结构**（用 Agent 对话 + 卡片编辑），**不要在 Gamma 里花太多时间调精细布局**——反正导出后会错位，导出到 Google Slides 或 PPTX 后再做最终的布局修复和演示准备。

Google Slides 有一个独特优势：导入后可以继续用 Google 生态的 AI 功能（如 Google Workspace 的 Gemini）根据演讲者备注生成幻灯片、建议更好的图表类型、检查设计一致性。注意两套 AI 风格可能差异很大——Gamma 用 20+ 模型组合，Google Slides 里的 AI 只基于 Google 自己的模型。
