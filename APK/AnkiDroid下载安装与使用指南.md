## ✨ AnkiDroid 是什么

AnkiDroid 是 Anki 间隔重复系统在 Android 上的官方客户端。Anki 这套工具最早由一位日本开发者在 2006 年做成桌面端，后来社区和官方先后推出了 iOS、Android、Web 等多端。间隔重复（Spaced Repetition，简称 SRS）的核心思路很朴素：你忘得越快的内容，越该在下次复习里出现；记得越牢的，排期就越往后推。算法会根据你答题时选的 Again / Hard / Good / Easy 自动调整每张卡片的下次出现时间——**你只负责每天花固定时间复习，排期交给算法算**。

AnkiDroid 把这套机制完整搬到了 Android 设备上，界面是 Material Design 风格，从 Android 4.1 起都能装。和桌面版 Anki 相比，它的优势是**随身复习**：课间、地铁、睡前、吃饭排队——手机在手上就能把当天的复习量拉满。常见的用法是桌面端负责批量做卡片、导入共享牌组，手机端负责日常复习。

适用人群其实比想象中广得多：在校学生把课本知识点拆成问答对每天过一遍；语言学习者背五十音、JLPT 词汇、四六级单词；考证党（CPA、司法考试、医师资格）用过滤牌组把错题集中冲刺；职场人背 API 参数、专业术语库。不太适合的场景也有——编程、数学证明这种需要动手连续推理的事，AnkiDroid 帮不上太大忙，但可以当辅助工具背高频签名。

## 🔧 安装步骤

Android 设备安装 AnkiDroid 有两条路子，选一条就行：

1. **应用商店安装（推荐）**：打开 Google Play（或国内应用市场如酷安、应用宝），搜索「AnkiDroid」，认准开发者名下的官方应用，点安装。全程自动完成，不需要额外设置。
2. **APK 安装**：从下载页拿到 APK 文件后，在手机上打开文件管理器找到它。系统第一次从非应用商店来源安装会弹出「未知来源」提醒，按提示授权后就能继续安装。授权通常在「设置 → 安全 → 未知来源」里开启，安装完可以关掉，避免其他应用误装。

> [!NOTE]
> 安装前核对一下 APK 文件的大小和版本号——正版 AnkiDroid 的安装包在 15~20 MB 之间，版本号和下载页标注的应该一致。如果体积异常小或名字里带「破解版」「VIP」之类的字样，不要装。

装完第一次打开会让你选择语言，然后引导你登录 AnkiWeb 账号（用于多设备同步）或选择本地存储模式。没有账号也没关系，可以先跳过，直接进入应用开始使用。之后想同步时再去官网注册即可。

## 📖 使用入门

### 牌组与卡片：核心概念

AnkiDroid 的基本单位是**卡片**，卡片归属于**牌组**。一张卡片通常有正面和反面——正面是问题，反面是答案。你答题时先看到正面，想好自己的答案后点「显示答案」按钮，对照反面判断自己答对还是答错，然后选 Again / Hard / Good / Easy 四个按钮。算法根据你的选择算出下次这张卡什么时候再出现。

牌组可以自己创建，也可以直接从社区下载共享牌组。共享牌组库里最热门的类别是语言学习——日语五十音、英语四六级、法语不规则动词都有现成的。

### 每天新卡上限：最重要的参数

进入任意一个牌组，长按弹出菜单选「牌组选项」，你会看到「新卡 / 天」这个参数，默认值 20。**这个数控制每天最多有多少张从未见过的新卡进入你的学习队列**。建议启动期（前 2~4 周）设 20~30，稳态期每天轻松搞定后可以缓慢调到 30~50。考级前冲刺短期设到 50~100 也行，但要准备好复习量爆炸。坚持 30 天每天 20 张，远好过三天热情每天 50 张然后放弃。

### 学习步骤与毕业间隔

同一块面板里还有一串带单位的数字，比如 `1m 10m 1d`——这是新卡第一次看到后的排期序列。第一次 Good → 1 分钟后再出现巩固一下 → 第二次 Good → 10 分钟后 → 第三次 Good → 1 天后毕业，从学习阶段转入复习阶段。答 Again 会重置到 1 分钟重新走流程，Hard 间隔稍短，Easy 直接拉长不少。默认的 `1m 10m 1d` 适合大部分场景，不需要调整。

算法面板里可以在经典 SM-2 和新一代 FSRS 之间切换。FSRS 是官方推荐的新用户默认选择，预测更准。

### 过滤牌组：动态视图

过滤牌组和普通牌组的区别很关键——它**不是自己拥有卡片，而是从其他牌组里动态筛选**，属于一个视图。创建方式：进入牌组概览屏幕，顶栏有创建按钮，或在更多菜单里找。需要填名称、筛选条件（和卡片浏览器的搜索语法完全一样）、排序方式。

常用筛选语法：

| 想要的结果 | 搜索语法 |
| --- | --- |
| 所有标记过的卡片 | `tag:marked` |
| 最近 7 天答错的 | `rated:7 is:learn` |
| 今天到期的 | `is:due` |
| 某牌组里没标记的 | `deck:CPA -tag:marked` |

考前冲刺用 `tag:重点` 把重点卡集中复习；巩固薄弱点用 `rated:7 is:learn` 把最近答 Again 的卡拉出来让它们尽快毕业。过滤牌组会随 AnkiWeb 同步，但筛选条件里用的字段名如果另一台设备上不存在，过滤牌组会显示为空——这点要注意。

### 字体与排版

默认用系统字体（通常是 Roboto），对中文支持可能不完整，某些手机上会出现方框或字形替换。要换字体：导航抽屉 → 设置 → 字体，每个笔记类型的每个字段都能单独指定字体，也可以设一个全局默认。**字体文件需要先在手机系统层面安装**（把 ttf/otf 放进系统字体目录或用字体管理器装），AnkiDroid 的选择器才能看到。

中文推荐的几个选项：

| 字体 | 特点 |
| --- | --- |
| 思源黑体 | 现代无衬线，各粗细完整 |
| 霞鹜文楷 | 手写感、阅读友好 |
| Noto Sans CJK | Google 官方开源，跨平台一致 |

> [!TIP]
> 想改字号、颜色、对齐方式这些排版细节，不要在设置面板里找——这些属于模板层面的设置，要改卡片模板的 HTML/CSS。桌面版 Anki 上编辑模板更方便，有实时预览和语法高亮，改完同步到手机自动生效。

换字体只是渲染层的事，卡片内容、学习历史、下次排期都和字体无关，不会影响任何数据。

### 多端同步

登录 AnkiWeb 账号后，桌面版和手机端可以自动同步。同步的是整个 collection——牌组、卡片、学习历史、过滤牌组、过滤条件都会同步过去。切换算法（SM-2 和 FSRS）也不影响学习历史，只是之后的排期计算逻辑变了。
