## ✨ Cosmo 是什么：K-pop 粉丝的数字收藏与互动空间

Cosmo 是韩国 MODHAUS 推出的一款粉丝向应用，服务于 tripleS、ARTMS、idntt 等旗下组合的粉丝群体。它的核心玩法围绕 **Objekt 数字小卡** 展开——每张小卡对应组合里的一位成员，按赛季成套发行，可收藏、可合成、可转赠，还能持续产出一种叫 COMO 的虚拟积分。除了小卡体系，Cosmo 也集成了直播观看、社区互动等功能，是粉丝一站式追星的入口。

对新用户来说，Cosmo 的门槛不算高：注册账号就能领取欢迎卡、参与基础玩法；想深入收藏的人可以通过商城购买、活动获得，或者把手里的实体小卡扫码入库变成数字资产。卡面设计精细，赛季配色鲜明，收藏起来本身就是一种视觉享受。

## 🔧 安装与注册

Cosmo 目前主要面向移动端，Android 和 iOS 双平台都有官方版本。安装过程与常见应用类似，但有几点值得提前留意。

**Android 用户**从应用商店直接安装最省心；如果通过第三方渠道拿到 APK，需要在系统设置里开启「允许安装未知来源应用」。建议优先从官方渠道获取安装包，避免版本过旧或被二次打包。

**iOS 用户**在 App Store 搜索即可，部分区域可能需要使用对应地区的 Apple ID 下载。

安装完成后首次打开，应用会引导你完成账号注册。Cosmo 支持多种登录方式，邮箱、手机号或第三方账号绑定都可以。注册时需要选择你关注的组合（tripleS、ARTMS、idntt 等），系统会根据你的选择推荐初始内容。

> [!TIP]
> **注册即领欢迎卡**：完成账号创建后，进入 Collect 收藏页就能领取一张欢迎卡，这是你账号里的第一张 Objekt。别小看这张卡——它同样属于某个赛季，能参与后续的合成和玩法。

**版本核对小技巧**：在应用内「设置 → 关于」里可以看到当前版本号，下载前对照官方渠道的最新版本，避免用旧版错过新功能（近几个版本对直播体验、入库流程都有更新）。

## 📖 使用入门：从小卡收藏到直播互动

Cosmo 的功能可以粗略分成两大块：**Objekt 小卡体系**和**直播/社区互动**。新用户建议先从小卡入手，理解了赛季、卡面、合成这些基本概念，再去逛直播和社区会顺畅很多。

### 赛季：小卡的时间单位

Cosmo 的所有小卡按 **赛季（Season）** 成套发行。一个赛季对应一个主题套系，有自己的名字（社区里常见 BINARY01、CREAM01、ATOM01、EVER01，以及按季度命名的 Spring26 之类），每个赛季的卡共享服装造型和专属配色。赛季的侧边色条是收藏里快速分批的视觉线索——在 Collect 页按颜色一扫就知道哪张卡属于哪个赛季。

赛季对收藏者的影响是全方位的：

| 维度 | 赛季的影响 |
| --- | --- |
| 卡面造型 | 同一赛季的卡共享服装与摄影主题 |
| 侧边色条 | 每个赛季一个专属颜色，收藏页里一眼分批 |
| 卡的种类 | 每赛季固定配齐欢迎卡、基础卡、进阶卡 |
| 合成池 | Grid 合成只认同赛季同成员的整套卡 |

> [!NOTE]
> **赛季更替时已入收藏的卡不受影响**：上赛季的卡照常保留、照常产出 COMO，只是商城货架换成新主题。赛季初往往伴随购买活动与登录活动，是补卡的好时机。

对收藏者来说，按赛季集卡比东一张西一张更划算——Grid 合成需要同赛季同成员的整套卡才能触发，先挑一个成员的一个赛季集齐是最高效的路径。

### 卡面结构：读懂每一张小卡

数字小卡的正面是成员照片，右上角有一个「手电筒」开关，点开后会展开一条侧边条带。条带上印着三项关键信息：**成员名**、**编号**（如 211Z）和**组合名**（tripleS / ARTMS / idntt）。条带颜色对应赛季配色，实体卡出厂就带色条，数字卡靠开关调出。

卡的背面是六项标准信息：

| 信息 | 内容 |
| --- | --- |
| 组合 Logo | 所属团体的标识 |
| 成员名 | 与正面一致 |
| 卡型/等级 | Class 或 Type 名称 |
| 赛季名 | 这张卡属于哪个套系 |
| 成员签名 | 印刷的手写风签名 |
| 二维码 | 链接回 Cosmo，实体卡靠它扫码入库 |

> [!WARNING]
> **看懂卡面是一切操作的基础**：转赠、交换、找卡时大家约定俗成用「成员 + 赛季 + 编号」指代一张卡——这三样全在卡面上。看不懂某张卡产不产 COMO 时，从卡面的卡型入手对照等级体系查产出即可。

### 获得小卡：商城、活动与实体入库

新用户的第一张卡通常是注册时的欢迎卡。后续获取 Objekt 的途径大致有三类：

1. **商城购买**：赛季开跑时商城会上架新主题的卡，按单张或套装售卖
2. **活动发放**：登录活动、直播互动、社区任务都会送卡，赛季初的活动最密集
3. **实体卡扫码入库**：如果你有实体专辑、演唱会周边或官方季卡礼盒里的纸质小卡，可以扫码把它们变成数字收藏

实体入库的步骤很简单：翻到实体卡背面找到二维码，打开 Cosmo 的扫码功能对准扫描，确认卡面信息无误后入库完成。入库后的小卡会以编号尾缀 A 标识实体来源，与原生数字卡区分开。

> [!TIP]
> **扫码即绑定，没有「退货」**：实体卡入库前是纯纸质收藏品，不产出 COMO；入库后成为数字收藏的一部分，按等级产出 COMO 并参与转赠与玩法。是否入库、何时入库完全由你决定——如果你更想保持实体收藏的完整性，可以暂时不入库，只是会失去它的数字功能。

### 直播与社区互动

直播是 Cosmo 另一个核心功能，在 Room 页发起与观看。近几个版本对直播体验的更新非常密集，可见官方把它当主打功能养。免费用户也能用大部分直播相关功能，包括：

- **Live Chat**：实时弹幕聊天，与同好同屏互动
- **字幕与翻译**：直播中支持翻译字幕，语言偏好在设置里提前配好，直播时直接生效
- **画中画与后台播放**：边看直播边干别的，支持应用内小窗和后台音频

艺人直播结束后会生成回放，回放与原直播的聊天记录同步显示，还带翻译字幕。直播还有两个进阶形态：**Unit Live**（多名成员同框直播）和 tripleS 专属的**直播贴纸**。

订阅会员在直播相关权益上有额外的历史回放范围和专属互动权限，但不订阅的免费观看体验已覆盖大部分日常场景。
