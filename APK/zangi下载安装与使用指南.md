## ✨ Zangi 是什么

Zangi 是一款主打**端对端加密**的即时通讯应用，核心卖点概括下来就三条：消息和文件走分块加密通道、全球同类用户之间的语音和视频通话完全免费、单个文件支持最高 400 MB 的断点续传。它不是大厂体系里的"又一个聊天工具"，定位更偏向**重视隐私和大文件传输**的用户——不管是发几百 MB 的视频素材，还是想把聊天记录留在自己设备而不是服务器上，Zangi 的传输机制能兜住这些需求。

功能面上，常规 IM 该有的它都覆盖了：一对一聊天、群聊、语音消息、位置和联系人卡片共享、语音视频通话、离线消息推送；但做得比一般工具细的地方在于**媒体聚合页**（Shared Media，按类型汇总该会话所有附件）和**通话流量统计**（挂断后直接显示这一通用了多少 KB/MB），低流量或偶尔用手机当热点的用户很吃这一套。

隐私和安全是 Zangi 反复强调的方向：默认对消息和通话做端对端加密、服务器不留文件副本、举报达量自动处理恶意账号——当然也因为自动机制，存在被恶意围举报误伤的可能，需要对陌生人敞开私密号的用户自己掂量。

## 🔧 安装步骤

Zangi 目前覆盖 Android、iOS 和桌面端，主流的两种安装路径分述如下。

### Android

1. 从下载页或 Google Play 获取 APK 文件；
2. 如果从第三方渠道下载，**进入系统设置 → 安全（或隐私）→ 允许未知来源安装**，否则安装包会被系统拦截；
3. 点击 APK 按提示完成安装，首次启动会请求通讯录、麦克风、摄像头、定位四项权限——全部授予或按需授予均可，缺权限时对应功能（拨号、视频通话、位置共享）会受限；
4. 启动后用手机号或邮箱注册账号，收到验证短信后完成激活。

> [!WARNING]
> 第三方渠道下载的安装包务必核对文件大小和签名——Zangi 官方 APK 体积通常在合理区间内，异常偏小或报毒的包请直接丢弃。

### iOS 与桌面端

iOS 用户直接从 App Store 搜索安装即可，不需要处理未知来源授权。桌面端支持 Windows 和 macOS，从官网下载对应平台的安装包双击运行，注册流程与移动端相同。

### 安装后核对

首次登录后，打开设置 → 账号信息，确认版本号与下载页标注一致，私密号（Zangi ID）已生成——这是其他用户找到你的唯一标识，建议保存或分享给常用联系人。

## 📖 上手使用指南

安装完成后，日常用到的功能可以分成四块：**发消息和附件、打电话、管隐私、考虑要不要付费**。下面把每块的实用操作和注意事项梳理清楚。

### 发消息与附件：类型不限、400 MB 封顶

在任意会话（包括群聊）输入框旁点 **+** 号，附件菜单会列出五类内容：相册照片/视频（可现拍）、任意类型文件、联系人卡片、位置共享。官方 FAQ 给的限制只有一条——**单个文件上限 400 MB**，类型完全不受限，PDF、压缩包、APK 都行。

超大文件的传输走分块加密通道，断网再连会从断点续传，不用重发整个文件。这一点对于经常跨设备传素材的人很实用，比如手机拍的几十分钟视频直接发给朋友，不必先压缩再分割。

> [!NOTE]
> 免费用户发照片视频时应用会自动压缩画质——如果对分辨率有要求，比如摄影素材、设计稿件，**原画质传输是付费 Premium 功能**，见后文付费板块。

#### 附件发出去之后去哪了

两个容易忽略的实用入口：

1. **会话内的共享媒体聚合页**：打开会话 → 点顶部对方名字 → Shared Media，该会话所有照片、视频、文件、链接按类型聚在一起，可逐个保存、转发或删除，翻老文件比在聊天记录里翻快得多；
2. **设备本地存储**：所有附件保存在本机，设置里有「保留期限」选项（永久 / 1 月 / 1 周 / 3 天），定期清理可以省空间。

### 打电话：四种入口、免费全球通话

Zangi 同类用户之间的语音通话全球免费，走 Wi-Fi 或 2G~5G 数据都可以。拨号入口比想象中多，四种常用的：

| 入口 | 操作路径 |
| --- | --- |
| 键盘拨号 | Calls → Open Keypad → 输入私密号 → 点呼叫按钮 |
| 会话内 | 打开聊天 → 点右上角通话图标 |
| 联系人资料页 | Contacts / Calls / Chats 任意界面打开对方资料 → 点通话按钮 |
| 通话记录回拨 | Calls 列表点记录旁的 (i) → 选 Call / Video / Chat |

#### 呼叫状态怎么读

拨出后界面会依次显示几种状态，官方定义里有一个容易误解的点：

- **Calling** → 呼叫请求已发出；
- **Ringing** → 请求已送达对方，正在响铃；
- 计时开始 → 对方已接听；
- **Answering**（替代 Ringing 出现）→ **这是错误提示，不是在接通中**，直接重拨即可。

> [!TIP]
> 挂断后在 Calls 列表点该记录旁的 (i)，能看到这通电话的日期、时长和 KB/MB 流量用量——低流量套餐用户可以用它来估算通话成本。

通话中还能切换扬声器 / 听筒 / 蓝牙耳机，视频通话时可随时关闭摄像头。来电铃声在 Settings → Notifications → Call Sounds 里改，两个选项：Zangi 默认铃声 / 跟随系统铃声。

### 管隐私：拉黑与举报

拉黑和举报的操作分两条路径，效果也不同：

**拉黑**：从会话顶部点对方名字 → 下滑资料页 → 点 Block 确认；或从设置 → Privacy → Blocked → Add New 勾选联系人。拉黑生效后，对方无法再给你发私信或打电话，但**共同群聊不受影响**——群里你俩照样互相看得到消息，想眼不见只有退群。官方刻意不通知对方"你已被拉黑"，让判断迹象保持模糊以保护拉黑方。

**举报**：同样从对方资料页进，iOS 点名字下滑、Android 点右上角三点菜单 → Report，有两个选项：只举报、举报并顺手拉黑。官方建议的举报场景包括垃圾信息、可疑链接、骚扰和冒犯内容。

#### 举报与封禁机制

Zangi 的举报处理是**自动化**的：账号累计收到一定数量的举报后，系统自动移除该账号，不需要人工逐案复核。这意味着举报是有效武器，不需要凑很多人就能触发；但反过来说，**对陌生人敞开私密号有风险**——被恶意围举报的账号可能被自动移除，官方 FAQ 也承认误伤可能性存在。

#### 怎么判断自己是不是被拉黑了

官方列了四个迹象（同时强调刻意保持模糊，不保证判定准确）：看不到对方最后在线时间、头像不再更新、发消息永远只有单勾（送达但从未已读）、呼叫永远打不通。四条全中大概率被拉黑，但也可能是对方关了状态或长期没上线，需要结合上下文判断。

### 付费订阅：Premium 的实际价值

免费版和 Premium 的核心差异集中在媒体传输和一些增值能力上，官方没有强制升级的压力，日常聊天够用的话没必要订阅。

| 功能 | 免费版 | Premium |
| --- | --- | --- |
| 照片视频传输 | 自动压缩画质 | 原画质、不限大小 |
| 文件附件 | 类型不限、400 MB 上限 | 同免费版 |
| 通话 | 全球免费 | 同免费版 |
| 存储保留 | 可配置期限 | 同免费版 |

#### 原画质开关的操作

订阅 Premium 后，发送媒体时会多出一个 Original Size 开关：打开聊天 → 点 + → 选 File / Camera / Photo / Video → 选中要发的内容 → 打开 Send in original size → 发送。对方收到的文件就是原始分辨率和体积，可以让对方在 Shared Media 里保存后核对是否与你本地原件一致，验证开关是否生效。

适合开原画质的场景：摄影素材、设计稿件、视频原始素材的传递，甚至把 Zangi 当成无审查的大文件传输通道——分块加密 + 断点续传让几百 MB 的文件传起来比较可靠。
