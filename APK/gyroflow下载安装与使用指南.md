## ✨ Gyroflow 是什么：基于陀螺数据的视频稳定利器

Gyroflow 是一款利用视频素材内嵌陀螺仪数据进行精准防抖的跨平台桌面软件。不同于传统光流法稳定依赖算法推算画面位移，Gyroflow 直接读取相机或外接记录仪的真实姿态传感器数据，从物理层面还原每帧画面的运动轨迹——这让它在运动相机、FPV 穿越机、无人机等高抖动场景下的稳定效果远超常规方案。

软件支持 Windows、macOS、Linux 三大桌面平台，内置 Premiere Pro 与 After Effects 插件可直接挂到时间线零转码稳定。兼容的相机品牌覆盖 GoPro、DJI、Insta360、Sony、Blackmagic、RED 等主流厂商，其中 GoPro HERO 8 及以后、DJI O3/O4 图传、Insta360 One R/RS 等机型开箱即用，素材拖进去直接稳定无需额外标定。

适合谁用：运动相机通勤记录者、FPV 飞手、无人机航拍剪辑师、手持微单实拍爱好者——任何追求物理级防抖而非算法插值的创作者。

## 🔧 安装步骤：跨平台安装与校验

Gyroflow 是跨平台桌面软件，三大系统安装流程基本一致，核心差异在系统级权限处理。

### 主程序安装

1. **下载对应平台安装包**：Windows 用 `.exe` 安装器、macOS 用 `.dmg` 镜像、Linux 提供 `.AppImage` 免安装格式；
2. **Windows 用户**：双击安装器，默认路径或自定义路径均可——安装过程中若被杀毒软件拦截报可疑行为，添加信任即可（开源软件签名常见误报）；
3. **macOS 用户**：打开 dmg 把 Gyroflow 拖进 Applications 文件夹，首次启动右键 → 打开（绕过 Gatekeeper 未签名应用提示）；
4. **Linux 用户**：AppImage 格式直接 `chmod +x` 后双击运行，或解压 tar.gz 放到 `/opt` 下创建快捷启动。

> [!NOTE]
> 下载前核对文件大小——Windows 安装器约 120MB、macOS dmg 约 140MB，如果下载到的文件明显偏小大概率是传输中断，重新下载即可。

### 安装后校验

打开软件后拖入一段 GoPro 8+ 或 DJI Action 系列的视频片段，如果时间线上方自动显示镜头档案名称且画面立即呈现稳定预览，说明安装完整、硬件加速正常；如果弹框提示"找不到镜头档案"，多半是版本太旧，更新到最新版即可解决。

### Adobe 插件安装（可选）

主程序内置插件管理器——打开 Gyroflow 顶部菜单 → 插件 → 安装 Premiere/After Effects 插件，按向导完成。安装后重启 Adobe 软件，在特效面板搜索 "Gyroflow" 就能找到插件，拖到视频片段上直接生效。

## 📖 使用入门：从开箱即用精调到导出渲染

Gyroflow 的使用体验按素材类型分成两条截然不同的路径：免标定素材拖进去就稳，需标定素材要走完镜头标定、同步、参数精调三步。下面结合日常高频场景拆解完整工作流。

### 素材分两类：先搞清楚你的相机在哪个阵营

Gyroflow 能不能免标定，分界线不是品牌而是素材里是否自带开箱即用的姿态数据与镜头参数：

| 类型 | 典型代表 | 使用流程 |
| --- | --- | --- |
| 免标定即插即用 | GoPro HERO 8+、DJI Action、Insta360 One R/RS、Sony a1/a7 系列、Blackmagic BRAW、RED R3D | 拖入素材 → 自动识别镜头档案 → 微调参数 → 导出 |
| 需标定与同步 | RunCam/Caddx FPV 相机、手机陀螺记录、无人机飞控日志、尼康/松下/富士机身无陀螺机型 | 标定镜头 → 导入外部陀螺数据 → 同步时间轴 → 精调 → 导出 |

> [!WARNING]
> 如果相机本身不记录陀螺数据、也不接外接记录仪，Gyroflow 没有稳定依据——这不是软件 bug，是硬件前提。机身无陀螺数据的消费级相机（尼康、松下、富士、宾得）只能走外接陀螺记录仪方案。

### 免标定素材：三步出片

1. **拖入素材**：GoPro HERO 5 及以后都记录陀螺数据，HERO 8 及以后镜头档案也内置，拖进 Gyroflow 时间线自动挂上档案；
2. **微调稳定参数**：左侧面板三个核心参数——强度（默认 1.0，高抖动素材拉到 1.2~1.5）、防抖模式（平移/旋转/缩放全稳 vs 仅稳旋转等可选项）、滚动锁定（防止画面左右倾斜）；
3. **变焦模式选择**：稳定必然裁边，三种模式决定裁切策略：

| 模式 | 策略 | 适用场景 |
| --- | --- | --- |
| 不变焦 No zooming | 完全不裁 | 仅调试用，边缘露黑边 |
| 动态变焦 Dynamic zooming | 随画面起伏实时调裁切量 | 默认推荐，视野利用率最高 |
| 静态变焦 Static zoom | 全片按最大需求一刀切 | 无呼吸感但全程重裁 |

动态变焦默认搭配变焦速度 2~5 秒——速度越短呼吸感越明显，拉到 20~30 秒可基本消除呼吸感，代价是高抖动段会长时间保持大裁切。

### 需标定素材：两段式同步

FPV 飞手用 RunCam/Caddx、手机外接陀螺记录仪这类素材要走完整流程：先在 Gyroflow 里完成镜头标定与光流同步，确认时间轴底部的同步波形对齐后导出含陀螺数据的项目文件，再进 Adobe 插件挂上去——零转码直接进时间线。

### 导出渲染：GPU 加速与格式选择

导出面板顶部有 GPU 编码开关，推荐保持开启。常见导出报错与应对：

| 报错类型 | 原因 | 解决办法 |
| --- | --- | --- |
| HEVC / 未知 ffmpeg 错误 | 显卡太老或驱动过旧 | 先更驱动 → 换 H.264 → 完全关闭 GPU 用 CPU 渲染 |
| 像素格式不支持 | GPU 不支持当前 10bit 4:2:2 格式 | 追求画质选 CPU 渲染保 10bit；赶时间换 GPU 兼容格式 |
| 磁盘空间不足 | 高码率 ProRes/EXR 序列动辄几十 GB | 清出至少预留输出文件 1.5 倍的空间 |

> [!TIP]
> Adobe 插件直稳 vs 主程序渲染后导入：插件路径零转码、RAW 控制保留、改参数即时生效，但时间线回放吃性能；主程序渲染可批量但多一次编码。RAW 素材（BRAW/R3D）强烈推荐插件路径——转码会丢掉 RAW 全部后期空间。
