## ✨ Caveduck 是什么

Caveduck 是一款面向 AI 角色扮演爱好者的社区平台——用户可以和各种风格的 AI 角色自由对话，也可以自己创建角色、编写 Story 故事章节，甚至通过角色互动获得积分激励。平台聚合了多种主流大模型，从性价比高的轻量模型到推理能力强的旗舰模型，创作者和使用者都能按需求灵活选择。

对普通用户来说，Caveduck 提供了一个快速体验 AI 角色扮演的入口：注册后每天能领免费积分，直接进入社区挑选感兴趣的角色开聊就行。对创作者来说，亮点在于完整的角色+Story 体系和独特的激励机制——你创建的角色被别人使用时，平台会自动给你发积分激励，写得好的 Story 还能设置付费章节解锁。

平台的社区氛围比较活跃，关注创作者、收藏角色、互动活跃度这些社交功能都做了，适合想长期跟进某个创作者新角色和 Story 更新的用户。

## 🔧 安装与初始配置

Caveduck 主要是 Web 应用，桌面端不需要安装——打开浏览器直接访问官网就能用。移动端 Android 有独立客户端，从应用商店下载安装包即可。

### 首次使用前的准备

1. **注册账号**：游客身份可以体验基础功能，但注册后每天能多领 100p 免费积分（注册用户 300p vs 游客 200p），还能关注创作者、收藏角色、查看消费明细
2. **模型选择**：平台接入了 GPT-4o、GPT-4、GPT-3.5、Claude 3 系列、Deepseek V3 等多种模型，消耗的积分差异很大（便宜的模型一次对话只扣 4p，贵的旗舰模型要 250p），建议先默认用便宜模型，需要高质量回复时再切换

> [!TIP]
> 重度用户可以在账户设置里接入自己的 API Key——接入后平台积分完全不扣，直接按官方价格支付，是长期使用最省钱的方式。

### 积分余额提醒

免费积分每天领一次，领取后 24 小时冷却。注意余额上限是 10,000p——超过了就先领不到，等消耗下去才能继续领，别让余额顶满浪费了每日额度。

## 📖 核心功能使用指南

### 积分体系：怎么扣、怎么省

Caveduck 用 Wing 和 Feather 两种积分单位，功能等价。对话消耗、语音朗读、长期记忆扩展、Story 付费章节解锁都走积分。

**必扣 vs 不扣**：

| 场景 | 是否扣积分 |
|------|-----------|
| 有效对话（用户输入 + AI 回复） | ✅ 扣，按所选模型计费 |
| AI 初始开场白（Episode 第一句） | ❌ 不扣 |
| AI 生成错误回复（无有效内容） | ❌ 不扣 |
| Re-roll 重新生成 | ✅ 扣，算一次新消耗 |
| 语音朗读（每条消息） | ✅ 10p / Super Voice 80p |
| 长期记忆扩展到 2000 字符 | ✅ 每轮 +10p |
| Story 付费章节解锁 | ✅ 按创作者设置（默认 200p） |
| 切换 Persona / 浏览社区 | ❌ 不扣 |

> [!WARNING]
> Re-roll 虽然基于同一条用户输入，但 AI 确实重新生成了一遍回复，所以每次 Re-roll 都算一次新消耗。别无脑反复刷，想清楚再点。

消费明细在 Earn 页面可以完整查到——每条记录带时间戳和具体金额，对照开聊时间就能定位到哪轮对话花了多少。如果发现扣得比预期多，常见原因有：模型选贵了、输出上限拉太大、Re-roll 次数多、同时开了多个对话。

### 社区互动：关注 vs 收藏

遇到喜欢的角色时，你可以收藏这个角色（书签），也可以关注创建它的创作者。两者的区别：

| | 关注创作者 | 收藏角色 |
|--|----------|---------|
| 对象 | 人（创作者） | 物（单个角色） |
| 看到什么 | 创作者发布的所有角色和 Story | 单个角色的对话历史 |
| 适合场景 | 喜欢一个创作者的全部风格 | 只喜欢某几个具体角色 |

两个功能可以同时用——关注创作者 A，同时收藏 A 创建的角色 X、Y、Z。关注后在 Activity 页面能快速跳转到关注的创作者主页，不错过新角色和 Story 更新。

### Story 系统：Script 编写要点

Story 是 Caveduck 给创作者提供的加分项，用章节（Episode）和脚本（Script）来展示角色的世界观。创作者可以不写 Story，Setting 字段 + Episodes 已经能支撑一个好角色。但如果想深入展示角色的故事线，Story 能显著提升角色的吸引力。

每个 Script 是一个独立的阅读单元，有三个基本限制：最多 **300 字符**、每个 Episode 最多 **60 个 Script**。编写时关键是**一个 Script = 一个独立的阅读节拍**——一个角色的一句话、一段场景描写、一个动作，各自拆成独立 Script，不要把多种信息塞进同一段。

Script 有三种文本类型：

- **Character（角色）**：角色对白、内心独白、行动描写
- **Narration（旁白）**：场景描写、环境氛围、其他角色的反应
- **Player（玩家）**：给用户的互动暗示、阅读提示

付费章节的典型节奏是：前两集免费（日常铺垫 → 冲突转折），最后一集设付费（高潮揭秘），让用户先认识角色、产生兴趣，再为结局付费解锁。

### 创作者激励机制

这是 Caveduck 比较独特的设计：**你创建的角色被别人使用时，你会获得积分激励**。激励金额按用户使用的模型比例发放，比如用户用 GPT-4o（消耗 80p）和你的角色对话，你能拿到 5p 激励；用 Claude 3 Opus（250p）则给你 20p。

不过有几个不满足激励的情况：自己和自己创建的角色对话不算、游客用户和你的角色对话不算。激励以积分形式发到账户，需要在 Earn 页面手动领取。
