## ✨ WonderPen 是什么，适合谁用

WonderPen（妙笔）是一款专为单人创作者打造的结构化写作工具。它的核心思路很直接：用树状目录把长篇作品按卷-章-节组织起来，配合白板和卡片系统管理人物设定、世界观、伏笔等写作资料，让你在一个窗口里完成从构思到完稿的全过程。

和 Word、Notion 这类通用工具不同，妙笔围绕"长篇创作"做了不少针对性设计——比如章节大纲视图可以给每节挂自定义元数据、编辑器内置代码高亮和分栏对照、右侧边栏常驻卡片列表随时查阅设定而不用切窗。导出方面支持图片、PDF、Word、EPUB、HTML 网页、纯文本六种格式，选中顶层节点勾选子节点就能把整部著作一键合成完整的 PDF 或 EPUB 电子书，自动带目录和页码。

妙笔的目标用户画像清晰：网络小说作者（动辄上百万字、角色线索多）、技术书籍作者（正文和代码频繁切换）、论文与学术写作者（章节多、参考文献管理量大）、日记或博客合集长期积累者。如果你是单人独立创作、重视本地数据可导出、偏好简洁专注不花哨的界面——妙笔值得一试。它不擅长的场景也要心里有数：多人实时协作（没有评论修订模式）、复杂富文本图文混排、演示文稿制作、数据库式内容管理（元数据灵活性不如 Notion/Airtable）。

## 🔧 安装步骤与注意事项

妙笔在四个平台都有官方客户端，安装过程整体顺畅，但各平台有一些需要留意的小细节。

**Windows 平台**：安装包下载后双击运行，默认安装路径在系统盘 Program Files 下，自定义路径时建议选有足够空间的位置——云同步的本地副本会完整存储所有文档库数据。安装完成首次启动会提示登录账号（云端文档库绑定），如果暂时只想用本地功能也可以跳过。Windows Defender 或部分杀毒软件可能对未签名的安装包有提示，确认来源可信后放行即可。

**macOS 平台**：dmg 镜像双击打开后将 WonderPen 拖入 Applications 文件夹。首次启动遇到"无法打开来自未知开发者"的系统提示时，在系统设置 → 隐私与安全性中允许应用运行即可。

**移动端（iOS / Android）**：直接在 App Store 或 Google Play 搜索下载安装。Android 版本如果从官网渠道获取安装包，需要在系统设置中授权"允许安装未知来源应用"，装完可以随时关掉这个权限开关。

> [!TIP]
> 首次安装后建议立刻确认版本号是否与下载页标注一致，避免安装到过期版本影响云同步兼容性。

## 📖 使用入门：从新建作品到完稿导出

### 树状目录：组织长篇的骨架

新建作品后左侧就是树状目录，按卷→章→节三级结构展开。在某个节点上右键可以创建子节点、重命名、删除或拖动重组。长篇小说可以给每卷单独建一个节点，技术书籍可以按章节功能划分。妙笔不强制层级深度，短篇集也可以按篇目平铺。

一个实用技巧：大纲视图支持给每个章节挂**自定义元数据字段**——比如加上"写作状态""待确认""已完成"之类的标记，写论文时可以一目了然地看到各章节进度。

### 卡片列表：写作时的随身备忘

右侧边栏的卡片列表是妙笔的高频功能。它和白板不同——白板偏画布式自由布局放结构图和思维导图，卡片列表偏线性管理，用来放需要随时查阅的文字备忘。典型用法：

- **人物卡**：每个角色一张卡，填姓名、外貌、性格、口头禅、关键经历
- **设定卡**：世界观规则、魔法体系、时间线、地理背景
- **伏笔卡**：已经埋下的伏笔，写完一段随手记下来，后续回收不遗漏
- **灵感卡**：写作时突然冒出来的点子，立刻记上

> [!NOTE]
> Pro 版可以创建无限制个卡片列表，基础版只有 1 个。如果你作品资料多，建议不同类别的卡片分到不同列表里，比如"人物档案""世界观设定""待回收伏笔"各一个，查阅时切标签就行。

**快捷建卡方式**：在编辑器里选中一段文字 → 右键菜单选"添加卡片"，直接把这段转成卡片内容，标题自己改。写作中突然觉得某段描述很重要，不用离开编辑器就能建好卡。

### 代码高亮与分栏对照

写技术书籍或教程时，妙笔的编辑器内置代码块语法高亮，支持常见语言，导出时高亮效果能保留。同时打开分栏模式，可以一边写正文说明，另一边粘贴或对照参考文档，不用在两个窗口之间来回切换。

### 云同步：本地优先的断网也能写

妙笔的云端文档库走"本地优先"设计——编辑操作先写入本地完整副本，再由后台异步同步到云端。地铁上完全断网也能继续写，联网后修改自动补同步、推到其他设备。

同步状态的显示非常克制：只有云端库名称旁的云朵图标（正常显示、同步失败时变红带斜线），没有常驻的进度条。如果遇到网络正常但同步始终没动，可以点文档库名称菜单里的"全量同步"手动触发，手动同步要选对方向——向上（本地覆盖云端）还是向下（云端覆盖本地），选反了会丢数据，拿不准先导出一份备份最稳妥。

> [!WARNING]
> 官方明确建议：尽量避免两台设备同时离线编辑同一个文档库，各自联网后可能出现同步冲突。安全习惯是每部作品指定一台主力机写正文，移动端只用来查资料和轻量记灵感。

### 完稿导出：六种格式覆盖不同用途

顶部工具栏点"导出"按钮，弹出的窗口里选格式、范围和选项。六种格式各有适用场景：

| 格式 | 典型用途 | 注意事项 |
|---|---|---|
| 图片（PNG） | 章节预览、社交分享、嵌入文档 | 太长的文档导出图片可能失败 |
| PDF | 打印、正式交付、存档 | 用了自定义背景色/背景图要开启"打印背景" |
| Word（docx） | 二次编辑、提交出版社 | 尽量保留表格和代码块高亮 |
| EPUB | 电子书制作 | 标准格式，各类阅读器通用 |
| HTML | 在线发布、博客 | 可导出为单文件或保持目录树结构 |
| 纯文本 | 跨软件迁移、备份 | 目录层级也会一起保留 |

导出范围可以选"仅当前节点"或"当前节点及所有子节点"——选顶层作品节点勾上子节点，就能把整部著作一键合成完整的 PDF 或 EPUB，自动带目录和页码，长篇作品的完稿体验非常顺手。

几个细节提醒：**备注和标注不会被导出**，只存在妙笔内部；妙笔内部以 JSON 存储，但随时能导出纯文本保持目录层级，数据完全可迁移；复杂嵌套表格导出效果不理想的话，可以用 Pandoc 做二次转换。
