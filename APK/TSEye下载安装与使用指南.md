## ✨ TSEye 是什么——一款多品牌通用的安防监控远程管理 App

TSEye 是一款面向安防监控场景的移动端远程管理应用，由 Jennov 等品牌设备配套推出。它的核心定位是把多个品牌的 IPC（网络摄像机）、NVR（网络录像机）、DVR（硬盘录像机）统一拉进同一个 App 里，用户只需要一个账号就能随时随地查看家里、商铺或办公场所的多路监控画面。

相比每个监控厂商各自为政的官方 App，TSEye 的优势在于**多品牌兼容**——只要设备支持 ONVIF 协议或配套固件，不管是自有品牌还是 Govision、Tigris 等其他厂商的摄像头和录像机，都能被识别接入。这对于手头有不同年代、不同品牌监控设备的用户来说，省去了来回切换多个 App 的麻烦。

在实际功能上，TSEye 覆盖了实时预览、录像回放、PTZ 云台控制、运动侦测告警推送等常用操作。NVR 主机添加成功后，其下挂的所有通道摄像头会自动出现在设备列表中，点击单个通道就能进入全屏预览，也支持多路分屏同步查看（最多 32 路）。

## 🔧 安装步骤与首次配置

TSEye 目前主要支持 Android 和 iOS 两大移动端平台，下面分平台说明安装过程。

### Android 设备

1. **下载安装包**：从上面的官方下载页获取 APK 文件，或直接在应用商店搜索安装。
2. **未知来源授权**：如果使用 APK 直装，需要在系统设置中开启"允许安装未知来源应用"。不同手机厂商的入口略有差异，通常在「设置 → 安全 → 安装未知应用」路径下，找到浏览器或文件管理器并授权。
3. **核对版本号**：安装完成后打开 App，进入「我的 → 关于」确认版本信息，Android 当前最新版本约为 1.2.9。如果版本过旧，建议到应用商店更新。

> [!TIP]
> 部分国产 Android 系统（小米、华为、OPPO 等）对后台进程有严格管控，安装后建议在系统设置中把 TSEye 加入"自启动白名单"和"后台冻结白名单"，否则锁屏后告警推送可能延迟或丢失。

### iOS 设备

1. **App Store 安装**：直接在 App Store 搜索 "TSEye" 安装，无需额外授权。
2. **当前版本**：iOS 端最新版本约为 2.4.3。
3. **通知权限**：首次打开 App 时系统会请求通知权限，建议选择"允许"，否则运动侦测等告警无法及时推送。

### 首次启动与账号注册

安装完成后首次打开 App，需要用手机号注册一个账号。这个账号是你所有设备的云端身份标识，后续在新手机上登录同一账号就能同步看到之前添加的设备。

注册完成后，App 会引导你进入设备添加流程——这正是最容易出问题的环节，下一节会详细展开。

## 📖 使用入门——从添加设备到多路监控

### 添加设备：扫码优先，手动兜底

TSEye 支持两种设备添加方式，**扫码是首选**，手动输入作为备份：

**扫码方式**：找到 IPC 或 NVR 机身背板上的二维码贴纸，打开 App 点击"添加设备"后用摄像头对准二维码扫描即可。NVR 扫码成功后，其下挂的所有通道摄像头会自动出现在设备列表中，无需逐个添加。

> [!WARNING]
> 如果扫码提示"无效"或"设备已被占用"，可能是设备之前被其他账号绑定过。需要先联系原所有者解绑，或对设备执行硬件复位（长按 Reset 键 10~15 秒）后重新添加。另外注意部分二维码包含前缀字符如"SN:"，App 可能无法自动正确解析，这时改用手动输入序列号更稳妥。

**手动输入方式**：在机身标签上找到 Serial No. 或 P2P ID，在 App 添加界面选择"手动输入"后填入即可。

**局域网搜索方式**：确保手机和设备在同一 Wi-Fi 网段，App 会自动扫描局域网内的 ONVIF 设备。如果搜不到任何设备，最常见的原因是手机和设备不在同一网段（设备出厂默认 IP 可能是 192.168.1.108 而路由器网段是 192.168.64.x），需要先用厂商 IP 修改工具或浏览器登录设备 Web 界面修改 IP。另外路由器开启的 AP 隔离/访客网络隔离也会阻断发现。

### NVR/DVR 的通道管理

NVR 和 DVR 是两种常见的录像主机：

| 类型 | 全称 | 接入摄像头类型 | 常见通道数 |
| --- | --- | --- | --- |
| NVR | Network Video Recorder | IP 摄像头（IPC） | 4、8、16、32 路 |
| DVR | Digital Video Recorder | 模拟同轴摄像头（AHD/TVI/CVI） | 4、8、16 路 |

NVR 添加成功后，App 设备列表中会出现 NVR 主机条目，点击展开就能看到每个通道对应的摄像头画面。需要注意的是，**通道的分辨率、帧率、通道名等参数无法在 App 中远程修改**，必须通过 NVR 主机外接显示器（HDMI/VGA）配合鼠标在本地界面配置。

> [!NOTE]
> Hikvision（海康威视）NVR 与 TSEye 的兼容性存疑。海康有自己的 iVMS 系列远程查看 App，其 NVR 的 P2P 云服务采用私有协议，不完全对外开放。如果你使用的是海康 NVR，建议直接用海康官方 App，TSEye 更适合配套 Jennov、Govision、Tigris 等 ONVIF 兼容厂商的 NVR。

### ONVIF 协议：多品牌兼容的底层逻辑

TSEye 能跨品牌接入设备，核心依赖的是 ONVIF 协议。ONVIF（Open Network Video Interface Forum）是 2008 年由安讯士、博世、索尼联合发起的开放网络视频接口标准，目前已成为全球安防设备的事实标准。

只要设备标注"ONVIF Compatible"，就意味着它可以与任何遵循这套标准的软件平台对接。在 TSEye 场景下，ONVIF 主要支持：

- **视频流拉取**：实时预览和录像回放
- **PTZ 控制**：云台转向和变焦（仅限带云台的摄像头）
- **事件订阅**：运动侦测、输入输出告警推送
- **设备信息查询**：型号、固件版本、编码参数等

ONVIF 协议本身也在不断演进，不同版本 Profile 对应不同能力：

| ONVIF Profile | 主要能力 |
| --- | --- |
| Profile S | 视频流拉取、PTZ 控制、设备发现（最基础） |
| Profile G | 录像存储与检索 |
| Profile T | 双路视频流、H.265 支持 |
| Profile Q | 快速互操作（零配置接入） |

TSEye 通过自身的 P2P 云通道对接设备，在 Profile S 级别的功能上表现稳定。如果你的 IPC 不支持 ONVIF，但厂商同时提供了 TSEye 配套固件，可以刷固件后接入。部分小厂 IPC 会同时内置多套协议，灵活选择即可。

### 看不到画面时的排查思路

设备在线但预览黑屏、花屏或一直加载中，按以下顺序排查效率最高：

**第一步：检查码流能力匹配**。如果你用 5MP 或更高分辨率的 IPC 接入只支持 1080P 的老 NVR，NVR 无法解码高分辨率视频流，表现就是黑屏或一直转圈。解决方法是在 IPC 的浏览器配置界面把主流分辨率下调到 NVR 支持的最高水平。

**第二步：切换码流验证**。在预览页面点击 SD/HD 切换按钮，切到标清（SD）看是否能出画面。SD 能看到、HD 看不到说明高清码流带宽不够或编码参数有问题；两者都看不到则可能是设备编码故障或 P2P 云异常。

**第三步：局域网直连测试**。电脑连接到设备所在同网段，用 ONVIF Device Manager 或 VMS 软件搜索设备，确认能否直接拉流。如果 VMS 也拉不到画面，问题在设备侧；如果 VMS 能看到但 App 看不到，问题在 P2P 云通道或 App 端。

**第四步：版本与重启**。确认 App 版本为最新（Android 1.2.9 / iOS 2.4.3），版本过旧可能存在解码兼容性问题。最后尝试设备端和手机端都断电重启，等待 1~2 分钟后重连。
