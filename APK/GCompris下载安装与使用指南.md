## ✨ GCompris 是什么

GCompris 是一款面向 2~10 岁儿童的开源教育活动集合，涵盖电脑入门、阅读启蒙、数学闯关、科学人文四大板块，累计超过 100 个互动活动。它的核心特点是完全免费、跨平台、无广告、无内购，全家共用也不花一分钱。

这款软件最初由法国开发者在 2000 年发起，如今已发展成一个国际化项目，活动内容覆盖了图形识别、鼠标键盘操作、字母拼词、数学运算、时间认知、天文地理等多个领域。每个活动都有明确的设计目标——比如"补全缺失字母"不是随便让孩子填字母，而是通过"听到的词 + 看到的字形"两头夹出答案，帮孩子建立单词结构感。

> [!NOTE]
> 当前官方最新版本为 26.2，Windows、Android、Linux 平台均提供直接安装包。macOS 由于缺乏构建与测试基础设施，最新版暂缺，可用版本停在 4.3（Qt 技术构型的中代版本，活动数量少一些，但主干内容齐全）。

## 🔧 各平台安装步骤

GCompris 的安装在不同平台上略有差异，以下逐一说明。

### Windows

1. 从下载页获取 `.exe` 安装程序，双击运行。
2. 安装过程中可自定义路径，默认装在 `C:\Program Files\GCompris` 下。
3. 安装完成后桌面会生成快捷方式，双击即可启动。

> [!TIP]
> Windows 上首次启动可能被杀毒软件误报，属于正常现象——软件完全开源，可放心添加信任。

### Android

1. Google Play 商店搜索 GCompris 直接安装，或从下载页获取 `.apk` 手动安装。
2. 手动安装时需在系统设置中开启"未知来源"应用安装权限。
3. 首次启动会申请存储权限，允许后即可使用全部活动。

### Linux

Linux 平台提供两种安装方式：

| 方式 | 适用场景 | 命令 |
| --- | --- | --- |
| 独立脚本 | 不想用包管理器 | `chmod u+x gcompris-qt-26.2-Linux.sh && ./gcompris-qt-26.2-Linux.sh` |
| 系统包 | Debian/Ubuntu 系 | `sudo apt install gcompris` |

独立脚本方式会在当前目录下创建新文件夹存放软件，进入其 `bin` 目录运行 `gcompris-qt.sh` 即可启动。

### 树莓派

官方为树莓派提供了独立的 64 位安装包，适用于树莓派 3 及以上机型：

1. 下载 `gcompris-qt-26.2-Raspberry64.sh`。
2. 在下载目录打开终端，依次执行：
   ```bash
   chmod u+x gcompris-qt-26.2-Raspberry64.sh
   ./gcompris-qt-26.2-Raspberry64.sh
   ```
3. 按提示读完许可证（`q` 可跳过），输入"是"确认安装。
4. 进入新生成文件夹的 `bin` 目录，运行 `gcompris-qt.sh` 启动。

树莓派装上完整 Linux 版本后，搭配小屏和鼠标，就是一台现成的儿童学习机。

### macOS

macOS 当前可用的最后版本是 4.3，以 `.dmg` 镜像发布：

1. 下载 `.dmg` 文件并打开。
2. 将 GCompris 图标拖入"应用程序"文件夹完成安装。
3. 首次打开如遇到 Gatekeeper 拦截，右键应用选择"打开"即可。

> [!WARNING]
> macOS 4.3 版本活动数量比 26.2 少，电脑入门、阅读、基础数学的主干活动仍齐全，但部分进阶活动（如太阳系五星档、语法分类）不可用。如果家里有其他设备，可以交叉使用不同版本。

## 📖 核心活动玩法速览

GCompris 的活动设计遵循"由近及远、从易到难"的渐进路线，下面按板块展开。

### 阅读启蒙：从认字母到读句子

阅读板块设计了一条完整的进阶路径：认字母 → 字母接龙 → 补缺字母 → 三级台阶阅读 → 打字输出。

**补缺字母**是承上启下的关键环节。活动画面会显示一幅图（比如一只猫）和缺位写法（C _ T），从候选字母中选出正确的那个。语音会同时读出图和单词，孩子靠"听到的词 + 看到的字形"两头夹出答案。另一个"字母属于哪个单词"活动反着考：给一个字母和几幅图，判断它出现在哪个词里。两个活动互为镜像，一起玩对单词结构的理解更立体。

> [!NOTE]
> 陪玩时建议先让孩子点嘴唇图标听一遍词，再挑字母——听觉记忆比盯着看更快锁形。错了别直接报答案，换掉候选顺序让再选一次，通常第二次就能对。

三级台阶阅读是阅读板块的重头戏：

1. **横向阅读练习**：屏幕上出现几行短句，语音念其中一句，孩子选出对应的那行——模拟最正常的"从左到右读一句话"。
2. **纵向阅读练习**：同样的句子竖排展示，每个字母一行、一个词拆成竖列。为什么竖着？因为孩子会背句子的"形状"糊弄过去；竖排后形状记忆失效，只能老老实实逐字母认读。
3. **词汇课**：体量最大的活动，收录约一千张图片与语音素材（英文、西班牙语、法文、盖尔语等），玩法是听词选图、看图选词。中文家庭用它当"看图听音"的英语启蒙材料很合适。

走完这条阅读线，孩子就从"认识 A B C"走到了"能读能写"。

### 科学人文：由近及远的认知

科学板块的活动按"视角逐级拉远"的思路编排，恰好构成给孩子的第一堂宇宙观启蒙：

- **时序**：把历史场景按时间先后排序，从原始人到现代生活。画面是最直观的时间语言，四岁孩子也能按直觉排个八九不离十。
- **路易·布莱叶的历史**：以事件排序的方式讲盲文发明者的一生——排的是一段真实人生，作为盲文与摩斯电码启蒙的开场。
- **罗马数字**：在钟面上和数字对里认 I II III IV V，和时钟活动连玩最顺。
- **太阳系**：在太阳系图景里完成行星相关任务——认行星、排位置。对痴迷星空的孩子，这个活动能连玩一周。

| 活动 | 视角 | 难度 |
| --- | --- | --- |
| 时序 | 身边生活的变迁 | 一星 |
| 路易·布莱叶的故事 | 一个人的一生 | 四星 |
| 罗马数字 | 两千年前的记数法 | 四星 |
| 太阳系 | 亿万公里的空间 | 五星 |

玩后可以做延伸：时序排完，让孩子按同款玩法排"自己的一天"照片；太阳系玩完，晚上抬头找月亮和行星，空间认知落进夜空。

### 其他板块概览

- **电脑入门**：从第一个鼠标练习开始，逐步过渡到键盘操作、打字板输出自己认识的词。
- **数学闯关**：数字认知、加减法、时钟日历、基础几何，活动难度自动适配孩子水平。
- **音乐与艺术**：简单的节奏练习和绘图工具，虽然不是主打，但对小龄孩子的美育启蒙够用。
