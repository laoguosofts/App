## ✨ RoboMaster 机甲大师是什么

RoboMaster 机甲大师是大疆（DJI）为旗下 RoboMaster S1 和 EP 系列机甲战车开发的官方控制与编程应用。它把驾驶、对战、编程三大能力整合在一个界面里，既是遥控手柄也是图形化编程平台——连上机器人就能在手机或电脑上获得第一视角驾驶体验，最多支持六台机甲同时混战，还内置了 Scratch 和 Python 两套编程环境，让零基础的玩家也能通过拖积木的方式给机器人写自定义技能和自动化程序。

核心玩法一目了然：单机模式下可以练 FPV 驾驶、定点射击、移动射击和行人跟随能力；多人对战模式靠应用内置的裁判系统自动判定血量和得分，免去了手动计分的麻烦；编程实验室则从大师之路课程起步，逐步引导玩家从图形化积木过渡到 Python 代码控制。无论是想单纯体验开机甲的乐趣、和朋友组局对战，还是带孩子入门编程教育，RoboMaster 都能覆盖到。

## 🔧 安装与首次连接

### 平台支持

RoboMaster 应用覆盖主流平台，根据你的设备选择对应版本：

| 平台 | 安装方式 | 备注 |
| --- | --- | --- |
| iOS | App Store 搜索「RoboMaster」 | 需要 iOS 11.0 及以上 |
| Android | Google Play 或官网下载 APK | 需要 Android 7.0 及以上 |
| Windows | 官网下载 EXE 安装包 | 建议 Win10 及以上 |
| macOS | 官网下载 DMG | 支持 Intel 和 Apple Silicon |

### 安装注意点

> [!TIP] 核对版本号
> 安装完成后在「设置 → 关于」里核对应用版本，确保与机器人固件版本匹配。机器人固件可在应用内直接升级，也可通过 SD 卡手动刷入。

手机端安装时如果遇到「未知来源」提示，在系统设置里允许该来源的应用安装即可。PC 端安装过程中如果被杀毒软件拦截，添加信任或临时关闭防护后重试——官方安装包经过签名，无安全风险。

### 首次连接流程

1. **机器人开机**：按住电源键 3 秒，等待指示灯亮绿。
2. **打开应用**：进入主界面后点右上角齿轮进入设置。
3. **选择连接模式**：
   - **直连模式**（新手推荐）：APP 自动发现机器人的 Wi-Fi 热点，一键连接，适合单人使用，无需路由器。
   - **路由器模式**（多人对战必须）：机器人和手机都连同一个路由器，支持多台机甲同时在线对战。
4. **授予权限**：应用会请求位置权限、蓝牙和麦克风权限，全部允许以解锁完整功能。

> [!WARNING] 多人对战的网络要求
> 多机组网时，所有机器人和所有手机必须连**同一个路由器**，且路由器需满足：WPA/WPA2-PSK 加密、设备数未满、允许设备间互通、无二次认证。5GHz 频段优先，频段拥挤时可手动切换到干扰较小的信道。

## 📖 主界面与三大玩法入口

### 一屏看懂全部玩法

连接成功后，主界面中央是机器人的第一视角实时图传画面，底部一字排开三个入口按钮。这三个词就是这款应用的全部内容地图：

| 入口 | 中文含义 | 里面有什么 |
| --- | --- | --- |
| SOLO | 单机 | FPV 驾驶、定点射击挑战、移动射击挑战、行人跟随等单人内容 |
| BATTLE | 对战 | 竞速、乱斗、征服三种多人模式，靠裁判系统自动计分 |
| LAB | 实验室 | 大师之路课程、Scratch / Python 编程、视频课程与编程指南 |

主界面其他元素也各有用途：左上角是账号信息入口，登录状态影响对战匹配和程序分享功能；右上角显示机器人电量百分比和 Wi-Fi 信号强度，一眼就能判断连接质量；同样在右上角的设置齿轮里可以调整装甲灯颜色、射击类型、控制灵敏度、装甲编址和机器人校准等全部参数。

> [!NOTE] 离线也能浏览
> 主界面这三个入口在**没连接机器人时也能点进去看**，但 SOLO 和 BATTLE 的实际玩法必须在连接状态下才有意义；LAB 里的课程和编程指南可以离线浏览，写程序和运行程序则需要连着机器人。

### Scratch 图形化编程入门

编程实验室的 Scratch 模式采用三段式界面布局，左侧是积木分类、中间是编程区、右侧是实时画面与变量监控——编程**不需要配置任何环境**，打开就能拖积木，这点对教学场景是决定性的优势。

积木编程有三个核心心法：

1. **事件积木是入口**：所有程序从「当……时」类积木开始（程序启动、收到攻击、识别到视觉标签），没有事件头积木不会执行。
2. **循环积木是主力**：重复执行、当条件成立时循环——循线、呼吸灯这些经典效果全靠循环撑起来。
3. **变量先少用**：第一个月先把动作类积木玩熟，变量和判断逻辑等有进阶需求时再深入。

五分钟就能写出第一个程序：从「系统」分类拖出「开始」积木作为起点，接着拖「设置底盘速度为低速」接在下面，再拖「设置云台 LED 灯颜色为绿色」，然后是「前进」+「等待 0.5 秒」+「停止」的组合，点运行后机器人会亮绿灯、走半米、停下——跑通这个就已经掌握了「事件 → 动作 → 控制」的程序三要素。

### 对战准备清单

开打前 10 分钟按顺序过一遍检查单，每项一分钟，全部打勾再开局：

**供电与电池**：每台机器人电池满电（续航标称 35 分钟，六机混战实测更费电）；路由器供电稳定，户外场景建议用笔记本移动电源给路由器供电。

**网络组网**：全部机器人和全部手机接同一个路由器；路由器满足 WPA/WPA2-PSK、设备数未满、允许互通、无二次认证四个硬性条件；5GHz 频段优先，直连模式和路由器模式别混用。

**场地清障**：地面类型合适——木地板、地毯、瓷砖、混凝土都行，过滑的表面和沙地要避开；移走易倒物如水杯、花瓶、电线、宠物用品；水晶弹局划定场地边界，弹丸别飞出场外打到人。

**弹药与设置**：水晶弹提前泡发好、装填到位；全员射击类型设置一致（设置 → 控制）；全员装甲编址正确（EP 新机尤其注意）；灯色分队完成（设置 → 显示）。

**规则确认**：选定竞速、乱斗或征服模式与时长；自定义技能是否有使用限制赛前说好；各自试打一发确认血量判定正常——有人不掉血先排查再开局。

### 常见小问题快答

- **体感操控对手机有什么要求？** 只支持自带陀螺仪的移动设备，近十年的智能手机基本都有，个别平板没有。
- **两台机器人的零件通用吗？** 智能中控、云台、发射器、运动控制器不通用；麦克纳姆轮、装甲、水晶弹通用。
- **录像回放怎么不是 1080p？** 应用内回放统一显示 720p，1080p 原片在 SD 卡上，取卡导出即可。
- **能一直打空枪吗？** 不建议，无弹时切红外光束模式保护发射器齿轮。
- **云台上能挂东西吗？** 不能，挂载或长时间施力会引发电机过热触发保护。
- **不会编程能玩吗？** 完全能，驾驶和对战都不需要编程；要学的话应用内课程从零教起。
