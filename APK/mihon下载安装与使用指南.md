## ✨ Mihon 是什么

Mihon 是一款开源的 Android 漫画阅读器，2024 年 1 月开源社区项目 Tachiyomi 宣布停止核心开发后，原团队成员以社区形式接手组建了 Mihon 项目，继续维护和迭代。

Mihon 保持了 Tachiyomi 最核心的设计——**扩展驱动**的架构。它本身不托管任何漫画内容，而是通过社区开发的上百个扩展连接互联网上的各种漫画源。你选择装哪些扩展、看哪些源，完全由自己掌控。这种模式与传统漫画 App（如 MangaDex、Crunchyroll Manga 等自托管或签约内容的平台）形成鲜明对比。

| 特性 | Mihon | 传统漫画 App |
|------|-------|-------------|
| 内容托管 | 不托管任何内容 | 自托管或签约内容 |
| 漫画来源 | 通过扩展连接上百个源 | 仅限自家平台 |
| 费用 | 完全免费开源 | 订阅制或含广告 |
| 平台 | 仅 Android | 多平台 |

Mihon 使用 Kotlin 开发，最低支持 Android 8.0（API 26），UI 采用 Material 3 规范，Android 12+ 支持 Material You 动态主题。代码以 Apache License 2.0 开源，托管在 GitHub。

名字的由来也有讲究——Mihon（見本）在日语中意为「样本、典范」，项目定位是为后续的 Tachiyomi 分支（forks）提供一个干净的起点和参考实现。

> [!NOTE]
> Mihon 自身也有多个分支版本（如 TachiyomiSY、TachiyomiJ2K、Yōkai 等），各自增加不同的自定义功能。本文介绍的是官方主分支的稳定版。

版本形态主要有三种：Stable 稳定版面向普通用户，每 2-4 周发布一个新版本；Nightly / Preview 夜间预览版展示正在开发的新特性，但可能有 bug 和崩溃——使用预览版的用户**强烈建议开启自动备份**；此外还有各种 Fork 分支，满足不同用户的个性化需求。

## 🔧 怎么安装 Mihon

Mihon 仅支持 Android 平台，最低系统版本要求 Android 8.0（API 26）。安装方式与普通 Android App 相同，但因为不是从官方应用商店分发，需要先授予「未知来源应用安装」权限。

### 安装步骤

1. **下载安装包**：从上面的下载入口获取最新的 APK 文件。下载时建议核对文件大小和版本号，避免下载到损坏的旧版本。

2. **允许未知来源安装**：首次安装非应用商店的 APK 时，系统会拦截。需要进入手机「设置 → 安全」或「设置 → 隐私」找到「允许未知来源应用安装」开关，或者在弹窗里直接点「设置」跳转授权页面，对当前的文件管理器或浏览器放行。

> [!WARNING]
> 只对你信任的安装来源授予未知来源权限，不要长期保持全系统开启，安装完成后建议关闭。

3. **点击安装**：回到下载目录，点击下载好的 APK 文件，点「安装」等待几秒即可完成。

4. **首次启动初始设置**：打开 Mihon 后，按向导完成初始配置——选择存储位置、安装扩展、选择漫画源等。

### 版本核对建议

| 核对项 | 说明 |
|--------|------|
| 版本号 | 安装后可在「更多 → 设置 → 关于」里看到 |
| 存储位置 | 建议选外部存储的专属目录，方便日后迁移 |
| 扩展仓库 | 默认的 Keiyoushi 仓库在 Mihon 里直接能用，地址不变 |

Mihon 与 Tachiyomi 并行安装是完全允许的——如果之前用的是 Tachiyomi，两个 App 可以共存，迁移确认正确后再卸载 Tachiyomi 也不迟。

## 📖 Mihon 日常使用入门

Mihon 的核心使用逻辑是「先装扩展、再搜书看」——它只是一个阅读客户端，漫画内容由你选择的扩展来提供。本节从几个高频场景切入，帮你快速上手日常使用。

### 书架管理与多维筛选

书架漫画多了之后，找到想看的那本本身就是门技术活。Mihon 提供了强大的筛选器和搜索能力。

点书架顶部的三条横线图标可以打开筛选面板，分三个标签：**过滤（Filter）** 按条件排除或包含漫画，支持分类、追踪状态、未读章节、下载状态、章节状态、书签等多个维度；**显示（Display）** 控制封面徽章显示哪些信息，比如下载徽章、新章节徽章、追踪徽章、章节计数；**排序（Sort）** 则可以按手动、标题、添加时间、阅读时间、未读数、更新时间、追踪状态等方式排列。

> [!TIP]
> 过滤器可以叠加使用——比如「正在读分类 + 有新章节 + MangaDex 源」，一下子就能把需要追的漫画精准抓出来，追更效率翻倍。

### 全球搜索与搜索技巧

浏览标签下的搜索图标是**全球搜索**——它会同时在所有已安装扩展源里搜索你输入的关键词，比在每个源里单独搜高效得多。用法很简单：浏览 → 右上角搜索图标 → 输入漫画标题 → 点搜索，Mihon 会返回所有匹配结果，每条显示标题、源站和简介片段。

如果搜索不到结果，试试这些技巧：

| 技巧 | 说明 |
|------|------|
| 关键词搜索 | 只输部分标题，Mihon 支持模糊匹配 |
| 换语言 | 中文搜不到换英文、英文搜不到换日文原名 |
| mangaupdates id | 先在 MangaUpdates 网站找到对应 id，用「id:XXXX」格式搜索 |
| MAL id | 在 MyAnimeList 找 id，用「id:XXXX」格式搜索 |

进入漫画详情页后右上角也有搜索图标，但那是**当前源站内部搜索**，不是全球搜索，别搞混了。

### 自动备份：定时打包再也不怕数据丢

手动备份容易忘，Mihon 内置了自动备份功能，设好频率后它会在你使用 App 的过程中**后台静默**创建备份。

开启方式：**更多 → 数据与存储 → 自动备份**。可以设置备份频率（每天 / 每 2 天 / 每周）和保留数量（比如只保留最近 3 份，超过的自动删除）。自动备份文件固定存在存储位置的 `autobackup/` 文件夹下，文件名格式为 `app.mihon_YYYY-MM-DD_HH-MM.tachibk`。

| 设置项 | 推荐值 | 理由 |
|--------|--------|------|
| 备份频率 | 每天 | 足够频繁，又不会占用太多存储 |
| 保留数量 | 3-5 份 | 回溯有一定余地，又不会占太大空间 |

自动备份不是严格按时间点触发的——Mihon 会在你打开或使用 App 时检查是否到点，到了就后台创建。所以频率是「间隔时间」而非精确时间点。

> [!WARNING]
> 使用 Mihon Preview / Nightly 预览版的用户**强烈建议开启自动备份**——开发版不稳定，崩了有备份才能回滚。书架条目超过 100 本的用户也应该开，手动备份容易忘，丢了损失大。

手机本地的备份还不够安全，推荐配合云盘同步工具（如 FolderSync、Autosync for Google Drive）把 autobackup 文件夹自动同步到 Google Drive、OneDrive 或百度云，实现「定时自动生成 + 云端自动同步」的双保险。

### 从 Tachiyomi 迁移到 Mihon

如果你之前用的是 Tachiyomi，迁移过程非常顺畅。两者的备份格式完全兼容，迁移只需三步：

1. 在 Tachiyomi 里导出备份：**更多 → 设置 → 备份 → 创建备份**，选择备份所有数据，保存到容易找到的位置
2. 安装 Mihon，完成初始设置向导
3. 在 Mihon 里恢复备份：**更多 → 数据与存储 → 恢复备份**，浏览找到 Tachiyomi 导出的备份文件，点恢复

恢复完成后，书架条目、分类、阅读历史和进度、App 设置会全部回来。但有三样需要手动处理：

| 需手动处理项 | 原因 | 操作 |
|-------------|------|------|
| 追踪器重新登录 | 安全原因，token 不包含在备份里 | 更多 → 设置 → 追踪，逐个重登 |
| 扩展重新安装 | 扩展 APK 不在备份里 | 浏览 → 扩展，逐个重装 |
| 下载章节搬运 | 恢复后 Mihon 不知道旧文件归属 | 手动搬运 + 重新索引，或全部重新下载 |

所有 Tachiyomi 分支（TachiyomiSY、TachiyomiJ2K、Yōkai 等）都使用同一种备份格式，从任意分支导出的备份文件都可以在 Mihon 里恢复。但分支独有的设置项（比如 TachiyomiSY 的「保存搜索结果」）不会被 Mihon 识别，会丢失——共享设置项（书架、分类、历史、阅读器设置）正常恢复。

> [!NOTE]
> 两个 App 可以并行安装，迁移确认正确后再卸载 Tachiyomi。不要在迁移确认前就删旧 App——万一备份有问题就回不去了。
