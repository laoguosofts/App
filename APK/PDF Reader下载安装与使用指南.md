## ✨ PDF Reader 是什么：移动端 PDF 处理的全能选手

PDF Reader（也就是 KDAN PDF）是一款主打移动端的 PDF 全能工具。它不只是一个阅读器——批注、签名、表单填写、文件管理，这些日常办公场景里的 PDF 需求，基本都能在这一个 App 里搞定。

它的核心功能包括：

- **阅读体验**：支持垂直滚动和水平翻页两种模式，横版幻灯片、漫画分镜这类文件用水平滚动更接近纸面翻页的感觉；Text Reflow 重排功能可以把 PDF 里的文字重新排版成适合手机屏幕阅读的格式，放大时不会出现横向滚动条
- **批注工具**：高亮、下划线、删除线、便利贴、涂鸦、形状、图章，一套完整的标注工具箱，免费档就能全用
- **签名流程**：创建个人签名并保存到签名库，合同、采购单这类需要反复签字的文档，一键定位到签名栏就行；支持手写板手写、拍照实体签名板、导入图片三种创建方式
- **文件管理**：可以按文件夹组织 PDF，支持从本地存储、云盘导入，也能把签过名、加过批注的文件导出分享

适合谁用呢？如果你需要在手机或平板上处理 PDF 文档——不管是阅读、批注还是签字盖章——它都能覆盖。学生读论文、职场人处理合同文件、自由职业者签电子合同，这些场景下 PDF Reader 都是一个实用选择。它在免费档就提供了相当完整的功能，进阶的云同步和高级编辑功能则放在订阅服务里。

## 🔧 安装步骤与注意事项

PDF Reader 支持 iOS、Android、Windows、macOS 多平台，安装流程因平台而异。下面分别说明各平台的安装要点和注意事项。

### Android 安装

1. 从官方下载页获取 APK 安装包，或直接在 Google Play 搜索下载
2. 如果通过 APK 安装（绕过应用商店渠道），需要先在手机设置里开启「允许未知来源安装」：设置 → 安全 → 安装未知应用 → 选择下载 APK 的浏览器或文件管理器 → 允许
3. 打开 APK 文件，按提示完成安装

> [!WARNING]
> 安装 APK 时，请确认文件大小和版本号与下载页标注一致。如果两次下载的文件大小不同，说明传输过程中有损坏，务必重新下载，避免安装后出现闪退或功能异常。

### iOS 安装

1. 打开 App Store，搜索「PDF Reader」或「KDAN PDF」
2. 点击「获取」，完成 Face ID / Touch ID / 密码验证
3. 等待下载安装完成

### Windows / macOS 安装

1. 访问官网，进入下载页面，选择对应的系统版本（Windows 10+ / macOS 10.14+）
2. 下载安装程序后，双击运行（Windows 可能需要允许 SmartScreen 提示）
3. 按向导完成安装，建议选择自定义安装路径，避免装在系统盘根目录导致权限问题

> [!NOTE]
> 免费安装即可使用全部基础功能。如果需要云同步签名库、跨设备同步阅读进度等进阶功能，需要订阅 Document 365 服务——但免费档的签名创建、批注、阅读都完整可用，日常使用完全够用。

### 安装后核对

安装完成后，打开应用，进入「关于」或「设置」页面，确认版本号是否为最新。如果界面和使用说明对不上（比如某些按钮位置不同），先检查一下是不是版本过低——新版签名工具在 3.20.6 及之后版本引入，旧版工具条位置会有差异。

## 📖 使用入门：从基础到进阶

这一节围绕日常高频使用场景，介绍 PDF Reader 的核心操作技巧。内容覆盖阅读模式切换、批注与签名、跨设备同步几个主要方向。

### 选择合适的阅读方向

PDF Reader 提供两种阅读方向：**垂直滚动**和**水平滚动**。什么时候该切到水平？不是所有 PDF 都适合上下滚。横版幻灯片、画册排版、宽幅设计稿、漫画分镜，这些文件一屏一页左右翻，观感好得多。

| | 垂直滚动 | 水平滚动 |
| --- | --- | --- |
| 翻页方式 | 上下连续滚动 | 左右一屏一屏 |
| 适合场景 | 报告、长文、电子书 | 幻灯片、画册、漫画 |
| 导航 | 大纲 / 缩略图 | 缩略图更常用 |
| 免费档 | ✓ | ✓ |

切换方式很简单：阅读界面点方向切换按钮，或进菜单选「阅读方向」→「水平」，立刻变成一屏一页向右翻。免费档可用，不需要订阅。

> [!TIP]
> 水平翻页时，Text Reflow 重排、横版朗读方向也会随之调整。文件本身如果是竖版排版，硬切成水平滚动反而体验更差——不要为了翻页动画好看硬切，按文件形态选。

### 创建自己的签名库

合同、采购单、授权书这些场景的签名有一个共同需求：固定的签名样式、精确定位在签名栏、能缩放旋转调透明度、签名保存在应用里下次直接调用。PDF Reader 的签名工具就是为这个设计的。

创建步骤：

1. 打开任何 PDF，底部工具栏选「工具箱」
2. 选「签名」工具 → 「新建签名」
3. 三种创建方式任选其一：

| 方式 | 适合场景 |
| --- | --- |
| 在屏幕上手写 | 没有手写笔，手指直接画 |
| 拍照签名字板 | 有实体签名板，拍一张导入 |
| 导入图片 | 已有签名 PNG/JPG，直接上传 |

4. 创建好的签名会保存到应用内的签名库，可以创建多个签名（不同用途或不同风格）
5. 需要在 PDF 上签字时，从签名库选中一个，拖到签名栏位置，调整大小和透明度就行

> [!NOTE]
> 创建签名、保存签名库都在免费档可用。新版签名工具在 3.20.6 及之后版本引入，旧版工具条位置不同但功能类似。

### 跨设备同步签名和批注

免费档和订阅档在签名存储上有明显差异：

- **免费档**：创建的签名和批注**只保存在本设备**。卸载应用、换机、手机换了，本地签名库一起没。但有个关键点要记住——**签过名的 PDF 文件本身里包含签名**，把文件拷走，签名跟着走，不存在「签名没了」的情况
- **订阅档（Document 365）**：登录同一账号后，签名库和批注元数据同步到云端。换新设备登录账号，签名库自动下载回来，不用重新创建

关于批注跨设备可见性，这里也要理清楚：**标准 PDF 批注**（高亮、下划线、便利贴、签名、形状、图章）保存在 PDF 文件本身里——不管有没有云同步，只要把文件拷过去就跟着走。**应用状态**（阅读进度、最近访问列表）不保存在 PDF 文件里，这些只有云同步才能跨设备恢复，且需要订阅。

> [!WARNING]
> 不管买不买订阅，重要的 PDF 文件换机时**手动拷走**比云同步靠谱——拷完再确认文件没丢比等同步完成踏实。如果在云同步过程中网络中断或切换账号，签名库可能暂时丢失，但只要文件拷在，批注和签名就不会丢。

### PDF 打不开怎么办：五步排查

遇到 PDF 文件打不开的情况，不要慌，按以下顺序一条条排查，99% 的问题能定位：

**第一步：文件有没有传完整**——这是最常见的原因。重新下载或重新拷贝一次，对比文件大小。如果两次大小不一样，那就是下载/传输过程中损坏了。

**第二步：换个阅读器试**——用手机自带阅读器、浏览器或另一款 PDF App 打开同一个文件。别的阅读器也打不开 = 文件本身有问题，不是 PDF Reader 的事。

**第三步：文件是不是被加密了**——带打开密码的 PDF 会先弹密码框。如果弹窗没弹出来直接打不开，可能是加密方式比较特殊，需要用创建它的原软件先解密。

**第四步：格式对不对**——注意文件名后缀。`.docx`、`.xlsx`、`.pptx`、`.jpg`、`.png` 不是 PDF，PDF Reader 读不了。这些格式要用对应的软件打开，或先转成 PDF 再读。应用支持 TXT、ePub 和常见图片格式，但 .doc/.docx/.xlsx 这类 Office 格式不支持直接打开。

**第五步：文件权限**——Android 11+ 分区存储下，如果文件存在受限目录里（比如其他应用的私有目录），即使你能看到也读不了。移动到 PDF Reader 自己的应用目录或 Downloads 再试。

如果以上都试过了还打不开，大概率是 PDF 文件本身的问题（加密方式特殊、文件内部结构损坏），联系文件发送方让对方在原软件里重新导出一个干净版本。
