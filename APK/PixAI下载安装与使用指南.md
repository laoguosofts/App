## ✨ PixAI 是什么

PixAI 是一款专注于动漫与插画风格的 AI 图像生成平台，支持网页端、桌面客户端以及移动 App 三种使用方式。它的核心能力是通过自然语言描述或标签组合，快速生成高质量的二次元插画、角色设定图和场景作品。

与通用型 AI 绘图工具不同，PixAI 的模型家族从底层架构就针对动漫美学进行了优化——无论是人物面部的精致度、光影的表现力，还是多角色场景的自然度，都经过了专门的训练调校。平台目前提供 DiT、SDXL、编辑模型三条产品线共七个官方模型，既能满足新手用户"会说话就能出图"的简易操作，也能支撑进阶玩家玩转 LoRA 生态和参数调节。

除了基础的文生图能力，PixAI 还内置了丰富的工具箱，覆盖角色设定、双人互动、场景演绎、风格转换等数十种快捷生成器，能大幅提升量产效率。对于想要固定角色长相的创作者，平台同样支持 LoRA 训练与应用，让 OC（原创角色）的一致性不再是难题。

## 🔧 安装步骤

### Android 平台

从下载页获取 APK 安装包后，安装前需要注意以下几点：

1. **允许未知来源安装**：如果系统弹出"禁止安装未知来源应用"的提示，进入手机「设置 → 安全」找到未知来源开关并打开即可。不同品牌手机的路径可能略有差异，部分机型在首次安装时会直接弹窗询问授权选项。
2. **核对安装包信息**：建议下载完成后核对文件大小，避免下载到损坏的安装包。
3. **安装过程无特殊权限要求**：PixAI 仅需要存储和网络权限，一般系统会自动申请，手动授权即可。

### iOS 平台

iOS 用户的安装流程相对简单，直接在 App Store 搜索 PixAI，点击获取后等待下载安装完成即可。部分地区可能存在 App Store 上架限制，遇到此类情况可尝试切换账号或通过网页端使用完整功能。

### 网页端（全平台通用）

PixAI 提供网页版入口，电脑和手机浏览器均可直接访问。网页端功能与客户端基本一致，适合临时使用或不想安装 App 的用户。首次访问需要注册账号，支持邮箱注册或第三方登录。

> [!TIP]
> 建议先在网页端试用熟悉界面，确认功能满足需求后再下载移动端 App。客户端的优势在于可以保存本地草稿和离线浏览画廊，但生图本身仍然依赖网络。

## 📖 使用入门

### 五分钟跑通第一张图

第一次使用 PixAI 不要急着研究参数，目标是把「输入描述 → 出图 → 发布」这条最短路径完整走一遍。具体操作：

1. **进入生成页**：桌面端点左侧菜单的「生成」；手机端点底部的紫色加号按钮。页面布局分左中右三栏（桌面版）或上下结构（手机版），找到中间的提示词输入框就行。
2. **选一个模型**：直接选 Tsubaki.3——这是目前的旗舰模型，从写实到动漫的各种画风都能覆盖。桌面端在右侧 Model 分页用 Quick Select 一键切换，手机端在「模型」区块选择。
3. **写提示词并提交**：用一两句话描述想要的画面，比如"一个站在教室窗边的黑发少女"。不用追求术语，写清楚**谁、在做什么、在哪里**就够了。中文写不放心可以保持提示词助手开启，系统会自动把描述扩写成英文。写完点「送出」，稍等片刻图片就会出现在生成区下方。
4. **发布拿点数**：满意的结果点「发布」即可分享到社区画廊，每次发布能拿 1000 点奖励，每天最多十次——这是免费点数的重要来源。

### 模型怎么选：三条产品线对比

模型决定了画面的基本风格与品质上限，选错模型后面全白费。PixAI 目前有七个官方模型，分属三种架构：

| 我想要… | 推荐模型 | 架构 |
| --- | --- | --- |
| 最新旗舰、全画风、角色一致性、生成编辑一体 | Tsubaki.3 | DiT |
| 多角色场景、自然语言、35+ 预设风格 | Tsubaki.2 | DiT |
| DiT 入门、精细提示词遵循 | Tsubaki.1 | DiT |
| 经典动漫、手部眼睛更精致 | Haruka v2 | SDXL |
| 复古动漫美学、简单提示词出好图 | Hoshino v2 | SDXL |
| 自然成熟风、男性角色、画师标签 | Hoshino v1 | SDXL |
| 编辑现有图片、多图合成 | Reference Pro | DiT |

简单说，**会说话就选 DiT 架构**（直接写自然语言句子），**想精确控制每个标签、玩转社区 LoRA 就选 SDXL 架构**，**要改图就上 Reference Pro 编辑模型**。官方推荐新手优先掌握 Tsubaki.3、Tsubaki.2、Haruka v2 这三个，能覆盖绝大多数创作需求。

不同架构能调的参数也不一样——比如 SDXL 模型支持采样步数、CFG、VAE 等精细参数调节，而 DiT 架构的 Tsubaki 系列走的是更简化的操作面板。换模型前如果发现某些参数不见了，先确认一下是不是架构差异导致的。

### 景别与构图：让画面更专业

画面好不好看很大程度在"按快门"之前就决定了。构图思维的核心是景别——观众应该看到多少。六种常用景别及其适用场景：

| 景别 | 取景范围 | 适合 |
| --- | --- | --- |
| 不指定 | 模型自行判断 | 让模型发挥，常有意外的舒适取景 |
| 中景（Medium Shot） | 腰部以上 | 对话、互动、轻情绪，最日常稳定的叙事视角 |
| 牛仔镜头（Cowboy Shot） | 膝盖上下 | 展示角色状态加一点气场 |
| 宽景（Wide Shot） | 人物占比小 | 交代环境与场景感，重点在"人在哪里" |
| 近景（Close Up） | 弱化环境 | 强调表情、眼神与动作 |
| 特写（Choker） | 仅脸部甚至局部 | 放大情绪，冲击力强，多用会失去节奏 |

在提示词里直接写英文景别词（medium shot、wide shot、close up）即可生效。横竖版选择的口诀是：**主角是人选竖版，主角是场景选横版**。

一个实用的构图思考流程是：先定主题和环境元素（春天→花和草地），再从环境推导人物状态（草地上坐下比站立更符合氛围），然后加入变化因素（风让头发和花瓣动起来，甚至让角色抬手按住头发），最后决定景别收尾。顺序的本质是先有世界，再有人物，最后决定给观众看多少。

### 工具箱：批量创作的捷径

PixAI 工具箱的定位不是"做周边"，而是换一种方式塑造和演绎角色。它包含三批工具：

**角色与设定类**：角色设定图生成器可以一次性展现角色每个层次的细节，是人设交付的神器；双人互动生成器内置几十种互动模板，直接绕过手动生图中双人构图容易串特征的大坑，是 OC 互动图的量产方案；桌宠生成器能保留外观表情转成桌面桌宠风格；还有奇幻角色生成器、日式攻略书生成器、人物剪纸生成器等。

**场景演绎类**：Galgame 介面生成器让角色变成恋爱游戏主角，自带对话框与立绘元素；杂志封面生成器让角色一秒登上画报；拍立得生成器、巨型雕像生成器、腮红眼镜生成器等能让产出自带场景叙事感，适合做社媒内容与角色小剧场。

**效率向工具**：影像高画质一键提升分辨率，发图前最后一步的统一处理；即时生成功能则把生图变成"画涂鸦、出成图"的互动体验。

> [!NOTE]
> 工具箱是"短平快"路线，但上限更高的路径仍然是手动链路。比如三视图这种高一致性需求，用旗舰模型的参考图玩法控制力更强；表情包量产则可以走"工具箱出底 → 影像强化修细节 → 批量发布"的组合流程。工具会持续更新，以平台内实际清单为准。
