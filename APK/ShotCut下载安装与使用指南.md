## ✨ ShotCut 是什么

ShotCut 是一款免费、开源、跨平台的桌面视频剪辑器，由 Meltytech 团队开发，主导者是 MLT 多媒体框架的联合创始人 Dan Dennedy。它的名字来历有点曲折：2004 年曾有一个同名项目由 Charlie Yates 发起，2011 年前后 Dan Dennedy 基于自己维护的 MLT 框架完整重写了这款软件，沿用了旧名直到今天。

ShotCut 的技术底座决定了它的性格——底层用 MLT 框架，剪辑工程本质就是一个 MLT XML 文件，天然支持工程文件跨平台、可被脚本批量处理；解码编码全交给 FFmpeg，几百种音视频格式直接拖进时间线就能剪，不需要先导入转码；界面基于 Qt，Windows、macOS、Linux 三端同一套视觉和交互逻辑，还附带了矢量动画工具 Glaxnimate。

它适合什么样的人？不想付费、不想被水印和订阅绑架，又要正经多轨剪辑的人；电脑配置一般，但素材是 4K、高码率手机视频的人（它的代理剪辑与预览缩放是招牌能力）；需要录屏、摄像头采集、画外音、字幕、调色一条龙都在一个软件里完成的人；以及 Linux 用户——市面上好用的免费剪辑器不多，ShotCut 是少数认真维护 Linux 版的。面向进阶用户，它还留着专业接口：支持 Blackmagic Design 的 SDI/HDMI 采集卡做输入与外接监视，外接监视器方案连多屏布局都考虑到了，家庭用户用不上，但说明这套开源软件的底子是按准专业需求铺的。

它的位置刚好卡在中间：比 Windows 自带的剪辑工具功能全得多，比 DaVinci Resolve 这类专业软件轻得多；对纯新手来说上手门槛介于两者之间。官方下载页承诺安装包不含恶意软件、间谍软件与广告软件，也不捆绑浏览器工具栏之类的私货。

> 版本号长得像日期是 ShotCut 的特色——`26.9.27` 代表 2026 年 9 月 27 日发布的版本，从名字就能看出新旧。官方大约每两个月出一个正式版，每版都会带一批新功能和几十项修复。普通用户第一次安装直接装最新版就行；手头项目做到一半时不着急升级，升版前先备份工程文件以防万一。

## 📖 上手实操与高频问题

### 新建项目与界面导览

第一次启动 ShotCut 建议先把界面语言切换为中文，然后照着完整流程走一遍：新建项目 → 导入素材 → 拖入时间线 → 裁剪拼接 → 加滤镜 → 导出。ShotCut 的界面布局非常直观，左上是素材库、中间是预览窗口、下方是时间线、右侧是属性面板，跟主流剪辑软件的逻辑完全一致，有剪辑经验的人几分钟就能上手。

它的一大优势是 FFmpeg 底座——手机拍的 H.264/H.265、屏幕录制的 MP4/MKV、甚至一些不常见的编码格式，直接拖进时间线就能剪，不需要先做导入转码，这点跟很多开源剪辑器动辄要求预转码的体验形成了鲜明对比。

### 预览卡顿的排查顺序

「时间线上播放一顿一顿」是 ShotCut 被问得最多的问题，官方论坛里反复出现的答案可以归纳成一套排查顺序——先查便宜的，再动贵的：

1. **素材编码问题**：手机竖屏视频、屏幕录制类素材经常是可变帧率（VFR）或长 GOP 编码，天生难解。这是卡顿时最先要检查的一项
2. **代理剪辑开了没有**：高码率素材最有效的手段，打开代理后软件会自动生成低分辨率副本做预览，导出时用原始素材，效果丝滑
3. **预览缩放**：把预览窗口降到 360p 或 540p 来剪辑，导出时不受影响，预览变轻了卡顿自然缓解
4. **硬件解码开关**：ShotCut 26.1 起默认开启硬件解码，但个别机器上反而出问题——论坛里有用户主动关掉它才恢复流畅，值得一试
5. **视频模式是否虚高**：工程设成 4K、素材是 4K、但最终发布只用 1080p，等于全程白算一倍数据，把工程模式降到目标输出规格可以大幅减轻压力
6. **滤镜拖累**：降噪、稳定器类滤镜是逐帧重算的大户，预览时临时禁用它们，导出时再开

> [!NOTE]
> 预览缩放若不同时配合代理，可能出现「缩放了还是卡」——因为源素材仍按原分辨率解码再缩小，缩放本身就是计算量。低配机器的答案是**缩放与代理一起开**。CPU 核心数不够是硬伤，官方对 4K 素材建议八核起步。

### 版本更新与多版本共存

ShotCut 的更新节奏很稳定，大约每两个月一个正式版。每版都会带一批新功能，比如 26.9 版的自动闪避与片段调整、26.1 版引入的硬件解码等。旧版本不会消失，官方在 GitHub 发布页保留了历史版本，Windows 7/8 这类老系统用户还能找到对应的最终支持版。

多版本共存的官方做法朴素得可爱：Windows 把旧版文件夹改名加上版本号（比如 `Shotcut-26.6`），macOS 把 app 包改名带版本号，Linux 解压目录同理，新旧版装进不同位置互不干扰。想随时回退旧版的人，这一招比什么都靠谱。

### 专业能力一瞥

虽然 ShotCut 定位免费开源，但它在专业接口上的考虑并不含糊。面向进阶用户的场景，它支持 Blackmagic Design 的 SDI/HDMI 采集卡做输入采集与外接监视，外接监视器方案连多屏布局都考虑到了。对于有录屏、摄像头采集、画外音录制、字幕制作、调色这些一条龙需求的创作者来说，全部在一个软件里就能完成，不需要在多个工具之间来回切换。
