## ✨ MineChat 是什么

MineChat 是一款面向安卓平台的本地 AI 聊天前端，包体只有 2.78M——装完不占空间，但功能上一点不含糊。它本身不提供模型，而是通过接入外部服务商（OpenAI、Gemini、Claude、OpenRouter、Grok 等）来驱动对话，你只需要填好 API Key，就能用自己喜欢的模型和各种角色卡畅聊。

核心玩法围绕「角色卡」展开——MineChat 支持导入主流格式的角色卡文件，几步就能把设定好的人设搬进本地助手列表，随时随地开聊。v0.4 版本重点优化了角色卡导入流程，解析速度和兼容性都比之前好不少。

适合谁用？喜欢折腾 AI 对话的玩家、想把网页端角色搬到本地的用户、以及对隐私有要求不想把聊天记录留在云端的人。安卓 5.2 以上就能装，老机器也跑得动。

## 🔧 安卓安装全流程

### 安装前核对

在动手下载之前，先确认两件事：

> [!TIP] 安装前必查
> - **系统版本**：安卓 5.2 及以上，太旧的版本可能装不上
> - **包体大小**：约 2.78M，下载完成后可以在文件管理器里核对文件大小是否匹配——差太多就是下载不完整

### 五步装完

1. **获取安装包**：从下载页转存网盘分享链接，再下载到手机存储任意目录
2. **点开安装包**：在文件管理器或系统下载通知里找到 `MineChat_v0.4.apk`，点进去进入安装界面
3. **允许未知来源（如果需要）**：部分安卓系统默认禁止非应用商店来源的 APK，如果弹出「禁止安装未知来源应用」提示，点提示里的「前往设置」，给当前来源应用（网盘 App 或浏览器）打开「允许安装未知来源应用」开关
4. **回安装界面继续**：权限开好了，安装按钮从灰变亮，点一下就能继续
5. **等进度走完**：几秒到几十秒即可完成，桌面出现 MineChat 图标就是装好了

> [!NOTE] 不同品牌手机的未知来源权限入口
> | 品牌 | 设置入口路径 |
> |------|-------------|
> | 小米/红米 | 设置 → 更多设置 → 系统安全 → 安装未知应用 |
> | 华为/荣耀 | 设置 → 安全 → 更多安全设置 → 外部来源应用 |
> | OPPO/vivo | 设置 → 安全 → 未知来源安装 |
> | 三星 | 设置 → 生物识别和安全性 → 安装未知应用 |
> | 原生安卓 | 设置 → 安全 → 安装未知应用 |

> [!WARNING] 常见卡壳点
> - 安装按钮灰的 → 未知来源权限没给够，按上面的路径去开
> - 提示「解析包时出现错误」 → 系统版本低于 5.2 或 APK 下载不完整，重新下载一遍试试
> - 装好了打开闪退 → 先确认系统版本，再排查是否与其他 AI 类应用有冲突

## 📖 从打开 App 到发出第一条消息

装完 MineChat 不能直接聊天——它是个前端工具，自己不产模型，所有对话能力来自外部服务商。第一次打开 App 后，默认没有配置任何模型，直接发消息会失败。先花一分钟配好，之后就能尽情聊。

### 四步首次设置

**第一步：打开设置面板**
首页右上角有个头像图标，点进去就是设置面板。

**第二步：选择模型服务商**
在设置面板里找到「提供商」选项，从 OpenAI、Google Gemini、Claude、OpenRouter、Grok 里挑一家。各家的配置界面略有差异，但核心都是填 API Key + 选模型。

**第三步：填入 API Key 并保存**
选定服务商后，把你的 API Key 粘贴进去，再选具体想用的模型（比如 gpt-4o、gemini-pro、claude-3.5-sonnet 等）。配置完成点保存，连接信息当场生效。

**第四步：回首页开聊**
回到首页，左下角有个方块图标——这是当前模型的确认入口，点一下确认无误后就可以在底部输入框发出第一条消息了。日常想换模型，还是走这个方块。

### 导入角色卡开始聊天

MineChat 的真正乐趣在于角色卡。v0.4 版本对导入流程做了重点优化，支持主流格式，五步就能把一张角色卡变成本地助手：

1. 打开 MineChat，底部导航栏切到「助手」标签
2. 点「创建助手」按钮进入创建界面
3. 在创建界面里找到「导入角色卡」，从手机存储里选中角色卡文件——MineChat 会自动解析人设字段
4. 导入成功后，角色卡里的信息会自动填到表单里，你可以自由修改名字、调整性格描述、加开场白、设置立绘
5. 保存后助手出现在列表里，点一下就能和这个角色开聊

> [!TIP] 导入失败怎么办
> 常见原因是文件格式不兼容。MineChat 对角色卡格式支持有范围限制，如果遇到导入报错或字段缺失，检查一下文件是不是常见的 PNG/JSON 格式。格式没问题但还是失败的话，试着手动把角色卡里的关键信息（名字、描述、开场白）复制到创建表单里，效果是一样的。

### 设置面板还能做什么

除了模型服务商配置，设置面板里还有不少实用选项：

- **聊天外观**：调整气泡样式、字体大小、主题色
- **历史记录检索**：控制对话历史的保留范围和检索方式
- **角色偏好**：设置新助手的默认开场白风格、回复长度偏好

日常换模型、调外观、清理缓存，都走首页右上角那个头像入口就行。
