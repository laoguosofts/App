## ✨ OpenArt 是什么

OpenArt 是一款面向移动端的 AI 绘画应用，核心定位是让普通用户也能在手机上快速生成可商用的高质量图像。它内置了多款经过调教的主流模型，从角色生图、写实人像到插画风格都能覆盖，配合一套完整的编辑工具链——局部重绘、扩图、细节增强放大——构成了从生成到出成品的闭环工作流。

和同类应用相比，OpenArt 的优势在于**角色一致性**做得比较扎实：只要给一张参考定装照，就能在多轮编辑、换机位、换场景的情况下保持人物特征不漂移，这对需要批量产出角色物料的创作者来说是刚需。同时它的编辑流程设计得比较"省积分"——放大放最后、局部重绘修细节、比例在生成前就锁死，把重复生成的浪费降到最低。

适合的用户：想做角色设定集、短视频封面、社交平台图文、小说封面的独立创作者和小团队。不适合的场景：追求极致写实皮肤质感的商业人像摄影后期，这类任务更适合交给 Seedream 系列模型。

## 🔧 安装步骤

OpenArt 目前主要面向 Android 平台分发，安装流程和常规 APK 类似，但有几个注意点。

**Android 安装流程**：

1. 从下载入口获取最新版 APK 文件，文件大小通常在 150MB~300MB 之间，下载后核对文件大小是否正常，避免不完整的安装包
2. 如果是首次从外部渠道安装，系统会提示"允许安装未知来源应用"，在设置中给下载工具或文件管理器开启这个权限即可
3. 安装过程中如果杀毒软件报毒或拦截，多半是因为签名不被数据库收录，可以添加信任继续安装——这是第三方分发渠道的普遍现象
4. 安装完成后首次打开，应用会下载模型资源包，建议在 Wi-Fi 环境下进行，消耗约 1GB 流量

> [!WARNING]
> 安装时如果弹出"此应用无法安装"或"解析包时出现问题"，大概率是下载不完整或版本与系统架构不匹配。先核对系统版本要求（通常需要 Android 8.0 以上），再重新下载完整包。

**版本核对方法**：进入应用设置 → 关于页面，确认显示的版本号与下载页一致，再开始使用。

## 📖 使用入门

### 模型选择：从聚合模型里挑一款

OpenArt 内置了多款模型，新手最容易困惑的就是选哪款。简单记法：

- **Nano Banana 系列**：主打角色一致性，同一角色跨多张图、跨多轮编辑不走样。它最出彩的三个能力——多参考图输入、换机位不改人、连续迭代编辑——让它特别适合系列漫画分镜、IP 角色物料、绘本插画这类需要同一主角反复出现的项目。描述角色时固定一套角色描述词存成模板，每张图开头都放同一段，配合参考图双保险，一致性最稳。

- **Seedream 系列**：真人质感人像更强，皮肤纹理、光影过渡更自然，适合做写实风格的社媒头像、人像海报。

> [!TIP]
> 如果不确定选哪个模型，直接从 Nano Banana 开始——它的综合覆盖范围最广，出图稳定性也最好，绝大多数场景都能 hold 住。

### 画布比例：生成前就锁对

官方反复强调一个原则：**直接以发布比例生成，别事后裁剪**。事后裁剪毁构图——花十分钟调好的画面，一刀下去主体被切、留白全错。生成前把比例锁对，是整个流程里成本最低、收益最大的一步。

各平台对应比例速查：

| 发布场景 | 建议比例 |
| --- | --- |
| 短视频平台（竖版视频封面、竖版图文） | 9:16 竖版 |
| 图片社区与种草平台 | 1:1 方形 |
| 视频平台封面与横幅 | 16:9 宽屏 |
| 书籍封面与印刷品 | 常见开本比例 |
| 通用社交贴文 | 4:3 或 3:4 |

同一张图要发多个平台时，不要生成多份随机结果，而是先出一张满意的母版，再用扩图功能把母版延展成其他比例——扩图是在原构图基础上往外补画面，主体不变，各平台版本视觉上仍是"同一张"。

### 局部重绘：修那不对劲的一小块

几乎所有 AI 生图的最后一公里都是同一件事：整体不错，某个局部不行——手指多一根、表情僵了、物件形状怪。局部重绘专治这个：圈住问题区域，只重绘这一块，其余像素原样保留。

标准操作流程：

1. 进入编辑画布，选择局部重绘工具
2. 用笔刷圈出问题区域——**圈最小必要范围**，多圈一分风险多一分
3. 在重绘提示词里只写这块要变成什么
4. 生成后检查衔接处是否自然，不满意再微调圈选范围

重绘提示词的写法要点：只描述目标，不复述全图。比如手部不对，圈住手之后写"自然放松的右手，五指自然弯曲，握着杯沿"，写清物件加状态，别写"把手画好一点"这种没有信息量的描述。

> [!NOTE]
> 三个常见翻车原因：圈太大了（把脸连同头发一起圈，重绘后发型变了）；提示词与原区域冲突（圈住坐着的手却写奔跑姿势）；反复重绘同一处越改越糊。同一区域改两三轮还不好，回生成环节换张变体更划算。

局部重绘擅长"改物件、修细节"，不擅长"改结构"——透视、比例这些骨架级问题，重绘救不了，得回到生图环节调整提示词或换模型。

### 细节增强放大：放最后一步做

生成出的图默认是预览级分辨率，直接印会糊。放大功能用细节增强把图推到 2K 甚至 4K，但它是全流程里最不该早做的一步——**放大后再改任何地方，改完还得重新放大**，双倍积分。正确顺序：编辑全部做完，放大收尾。

档位选择参考：

| 用途 | 建议档位 |
| --- | --- |
| 社媒发图 | 原生分辨率即可，多数平台会压缩 |
| 手机壁纸、桌面壁纸 | 2K 档 |
| 印刷：书封、海报、周边 | 4K 或平台支持的最高档 |
| 按需印刷平台 | 按平台要求的最低像素数倒推档位 |

放大前后各做一次检查：放大前确认局部重绘都做完了，手、脸、文字这些细节区在放大后更显眼，先在小图上修干净；放大后抽查看三处——线条边缘有没有锯齿、纹理区有没有塑料感、文字区是否仍然清晰。

印刷质量的判断方法：把放大后的图除以目标印刷尺寸，每英寸像素数 300 左右是印刷级，低于 150 就会有明显颗粒感。拿不准就升一档再导出。

### 多参考图建角色的实战思路

如果你要做一个角色的系列物料——比如短视频的人物设定图、漫画分镜、封面插画——推荐的流程是：

1. 先准备一张角色定装照作为主参考图，同时可以加一张风格样张或场景参考
2. 固定一段角色描述词模板（发型、服装、体型、气质等），每次生图开头都放同一段
3. 用 Nano Banana 模型生图，生成多张后挑一张最满意的作为母版
4. 在母版上用局部重绘修细节，用扩图延展成不同比例，最后放大出成品

这套流程的关键是"固定描述词 + 多参考图 + 母版迭代"，三重保险让角色在整个项目里保持稳定。
