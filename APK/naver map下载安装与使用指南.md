## ✨ Naver Map 是什么

Naver Map 是韩国本土使用最广泛的地图导航应用，由 Naver 公司自研运营。它不是 Google Maps 的替代品那么简单——在韩国境内，Naver Map 的小巷识别、步行导航、3D 矢量渲染和本地生活服务覆盖度，都远超国际巨头。

核心能力可以归为四大块：**地图浏览**（矢量 3D 渲染、全方位旋转倾斜）、**路线导航**（驾车+步行+公交，步行导航专门优化过首尔老城区的小巷子）、**发现探索**（Discover 页的分类气泡一键筛选附近 POI）、**预订服务**（Booking 标签页集中餐厅订位、门票、高铁票等日常预订）。

适合两类用户：一是**去韩国旅游的游客**，从落地第一天到回国，导航、找吃的、订景点门票基本都能在这一个 App 里解决；二是**长期居住在韩国的外国人**，步行导航对陌生小巷的识别比 Google 靠谱得多，深夜不迷路。

## 🔧 安装步骤

Naver Map 原生支持 Android 和 iOS 双平台，安装流程分两种情况。

### Android 用户

1. **Google Play 安装**（推荐）：韩国区账号打开 Google Play，搜索 "Naver Map" 直接安装。这种方式后续能自动接收更新。
2. **APK 安装**：非韩国区 Play 商店找不到时，从下载页获取 APK 安装包，安装前需要在系统设置里打开「未知来源应用安装」权限（路径通常是设置 → 安全 → 允许安装未知应用）。

> [!WARNING]
> 安装包大小约 227MB，建议在 Wi-Fi 环境下下载，避免消耗大量移动流量。安装后首次打开会需要下载额外的地图数据，这一步也建议在 Wi-Fi 下完成。

### iOS 用户

在 App Store 搜索 "Naver Map" 直接安装。如果非韩国区账号搜不到，需要先切换 App Store 的地区到韩国（设置 → iTunes Store 与 App Store → Apple ID → 查看 Apple ID → 国家/地区）。

> [!TIP]
> 安装完成后打开 App，系统会请求定位权限、通知权限、蓝牙权限。**定位权限必须设为「始终允许」**——这是步行和驾车导航精确追踪位置的前提。通知权限建议开启，方便接收预订状态变更和导航提示。

### 安装后核对

首次启动后，在 Discover 页随意搜一个韩国地标（比如 "N Seoul Tower" 或 "景福宫"），如果地图能正常显示且搜索结果准确，说明安装和地图数据加载都没问题。

## 📖 使用入门

Naver Map 的功能密度很高，下面按日常使用频率从高到低拆解。

### 步行语音导航——韩国小巷的救星

这是 Naver Map 最值得单独拎出来的功能。首尔老城区（钟路、仁寺洞、弘大附近）有大量横街窄巷、楼梯、过街天桥，Google Maps 在这些区域的步行路线经常不准——要么把人引到死胡同，要么绕一大圈大路。Naver Map 的步行导航是专门为韩国小巷优化过的。

开启方式很简单：搜目的地 → 点路线 → 顶部选 Walking（步行）图标 → Start Navigation。语音会逐向报路，比如"前方 18 米右转""过人行横道后左转""前方有楼梯，下行后继续走 30 米"。中英文语音都有，切换 App 语言后导航语音自动变。

适合场景：从地铁站步行到酒店或景点（很多景点离地铁站步行 10-20 分钟）、深夜迷路时听语音不放手机、下雨天不想拿手机看屏幕。

> [!NOTE]
> 步行导航比驾车导航耗电少，但长时间使用还是建议带充电宝。出发前确保路线已加载好，防止中途断网。山地徒步路线不走这套——登山径请用专门的徒步 App。

### 3D 矢量地图——全方位旋转倾斜

Naver Map 默认就是矢量地图，用数学公式渲染而非位图，放大时始终锐利不模糊。在此基础上叠加了 3D 效果：双指旋转可以 360° 任意方向旋转地图，双指上下滑可以倾斜视角看到建筑的立体结构。景福宫、N 首尔塔等著名地标有精确的 3D 模型。

操作手势一张表搞定：

| 操作 | 手势 |
|------|------|
| 放大缩小 | 双指捏合 |
| 旋转地图 | 双指旋转 |
| 倾斜视角 | 双指上下滑 |
| 平移 | 单指拖动 |
| 回到正北朝上 | 点指南针图标 |

实用场景有三个：**看城市全貌**（倾斜后能看清汉江区、南山塔、景福宫的整体布局）、**看商场建筑结构**（搜 Lotte World 或 COEX Mall，倾斜就能看到几层裙楼）、**规划步行方向**（陌生区域倾斜+旋转比纯平面地图更不容易迷失）。

### Discover 页的分类气泡——一键筛选附近 POI

底部 Discover 标签页顶部，搜索框下面有一排彩色圆形气泡。每个气泡代表一种 POI 分类：Restaurant（橙）、Cafe（棕）、CVS（绿）、Pharmacy（绿+十字）、Gas Station（蓝）、Attraction（紫）、Subway 等。

点一下任意气泡，地图立刻高亮你附近该类型的所有 POI，其他类型会被淡化或隐藏，底部弹出筛选结果列表（默认按距离排序，可以切换成评分排序或营业中优先）。同一个气泡再点一下就恢复正常。

几个高频用法：深夜突然需要退烧药时点 Pharmacy 找还开着的药店；旅游逛累了点 Cafe 看附近评分高的店；租车自驾游油表快空时点 Gas Station 顺便比价格。气泡不能叠加筛选，需要多分类时用搜索框搜关键词更灵活。

### Booking 预订——地图里直接订餐厅门票

Booking 是底部五个主标签之一，把原本分散在各个 App 里的预订功能集中到了地图里。能订的东西很全：餐厅订位、美发预约、游乐园门票（Lotte World、Everland）、KTX 高铁票、泡菜课/韩服体验等一日课程、部分酒店和演出门票。

预订流程和一般 OTA 类似：找到商家或项目 → 查看详情（时间选项、价格、可订日期）→ 选时间 → 确认信息 → 填写姓名和手机号 → 支付。支持 Naver Pay、Visa/Mastercard/AMEX 信用卡、部分商家支持支付宝。外国游客用信用卡支付最方便。

预订成功后订单在 MY 标签页的 Bookings 里可查，支持修改时间（商家允许的前提下）和取消。每个商家的退订政策不同，订之前要看清——有的全退、有的部分退、有的不支持退。热门餐厅订位后最好提前半小时打个电话确认。
