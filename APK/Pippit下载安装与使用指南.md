## ✨ Pippit 是什么——一个面向电商卖家的 AI 内容工作台

Pippit 是 CapCut 团队推出的一款面向独立站卖家、TikTok Shop 运营和品牌营销人员的 AI 内容创作平台。它的核心定位很明确：**让不懂视频剪辑、不会设计的卖家，也能在几分钟内批量产出可直接发布的视频、图片和海报。**

平台的主打功能叫「万物成片」（Link to Video）——你给它一个产品链接、一张产品图或者一段产品描述，它就能自动生成一条完整的短视频：选数字人当主播、自动写口播文案、匹配画面素材、加上字幕和背景音乐，输出直接可以上传 TikTok 或 Instagram 的成片。除了视频，Pippit 还内置了 AI 图片智能体（批量生成商品图、多图融合、去背景、换背景）、AI 商品海报生成、视频翻译等工具，覆盖了从选品素材到跨平台发布的一整条内容生产线。

从功能划分上看，Pippit 更像是一个「一站式内容车间」——而不是某个单一能力的 AI 工具。它把视频生成、图片处理、定时发布、数据分析这几件事打通在同一个界面里，目标用户非常聚焦：每天要出好几条内容、但雇不起专职剪辑师和设计师的中小卖家和独立站主。

`> [!NOTE]
> Pippit 的底层账号体系与 CapCut 桌面版互通，已有 CapCut 账号的用户可以直接登录，无需重新注册。`

## 🔧 注册与上手——几分钟就能跑通第一条视频

Pippit 目前以 Web 端为主要入口，打开浏览器访问官方站点即可开始使用，**不需要下载安装任何桌面客户端**。注册流程非常轻量：

1. 选择登录方式：邮箱注册，或直接绑定 Google / Facebook / TikTok 等社交账号。已有 CapCut 账号的用户可以一键登录，数据互通。
2. **注册不需要绑定信用卡**——先用完免费额度，想升级再付费。这一点对新手特别友好，可以放心进去逛，不用担心忘记取消订阅被扣钱。
3. 进入工作台后，左侧导航栏能看到主要功能模块：**万物成片、图片智能体、商品海报、视频翻译、内容日历**，以及多平台发布和数据分析入口。

> [!TIP]
> 第一次上手建议先跑一遍「万物成片」的 Lite 模式——它消耗 Credits 少，生成速度快，能让你最快理解 Pippit 的基本工作流。等熟悉了再尝试 Agent 模式的深度定制。

上手最快的路径：点击「万物成片」→ 粘贴一条你在售产品的链接（或直接上传一张产品图）→ 选择一个 AI 数字人主播 → 点击生成。等 1-3 分钟，一条带口播、带画面、带字幕的短视频就出来了，可以直接下载或发布到社交平台。

## 📖 使用入门——从 Credits 到高级功能的完整指南

### Credits 体系：Pippit 的"能量值"

Pippit 的所有 AI 生成功能都消耗一种叫 **Credits** 的内部额度。理解 Credits 的消耗规则，是高效使用 Pippit 的前提。

| 操作 | Credits 消耗参考 |
|------|-----------------|
| 万物成片（Lite 模式） | 20-30 / 条 |
| 万物成片（Agent 模式） | 50-80 / 条 |
| AI 图片生成 | ~1 / 张 |
| 批量商品图（4 张一组） | 8-15 / 组 |
| 多图融合 | 5-10 / 次 |
| 批量编辑 | ~1 / 张 |
| 视频翻译 | 按视频长度 |
| 上传素材、编辑脚本、预览 | **不消耗** |

几个容易忽略的细节：**Lite 模式比 Agent 模式省 50-60% 的 Credits**，适合电商场景的批量基础产出；上传素材和调整参数这些准备工作不花钱，Credits 只在点击「生成」那一刻才扣。

### Free 版 vs Starter 版：怎么选

Pippit 提供两个订阅方案，核心差异集中在 Credits 额度、高级功能可用性和多平台管理能力上。

| 功能 | Free | Starter |
|------|------|---------|
| 每周 Credits | 150，每周清零 | 年度 21600，全年有效 |
| 万物成片 | ✅ Lite + Agent | ✅ 全部 |
| AI 图片智能体 | ✅ 基础款 | ✅ 完整功能 |
| 自定义数字人 | ❌ | ✅ |
| 批量商品图 / 多图融合 | ❌ | ✅ |
| AI 商品海报 | ❌ | ✅ |
| 视频翻译 | ❌ | ✅ |
| 定时发布 + 多平台管理 | ❌ | ✅ 3 个账号 |
| 数据分析面板 | ❌ | ✅ |
| 商用免版权素材库 | ❌ | ✅ |

一个实用的判断框架：

- **每周 5 条以内内容** → Free 版够用。150 Credits 大约能做 3 条 Agent 视频 + 25 张图片，小规模测试没问题。
- **每周 5-15 条，或需要定时发布** → Starter 几乎是必选。定时发布一个功能每周能省 2-3 小时手动上传，批量生成能省 5-10 小时。年付约 $29/月，假设你的时间价值 $50/小时，省 6 小时就能回本。
- **每周 15 条以上** → Starter + 额外充值 Credits。大促期间消耗会暴涨，提前多充一些。

`> [!WARNING]
> Free 版的 150 Credits **每周清零不结转**——周五不用完，周一就没了。建议把一周要做的内容集中在刷新后前 1-2 天完成，避免最后几天 Credits 耗尽但又有紧急内容要出。`

### Credits 不够用了怎么办

不管是 Free 版一周中后段就用完，还是 Starter 大促期间消耗暴涨，都有应对方案：

**临时救急**：
1. **Lite 模式替代 Agent**——效果略差但省一半 Credits，电商营销场景下够用
2. **手动输入替代自动抓取**——让 Pippit 跳过产品分析环节，直接进入生成
3. **拆长视频为短视频**——60 秒拆成两个 30 秒，Credits 消耗减半，还能多发一条
4. **降低画面数量**——画面越少，AI 消耗越少

**长期策略**：
- 升级 Starter 是最直接的解法——年付平均每周约 415 Credits，是 Free 版的 2.7 倍，还多出定时发布等全套功能
- 大促期间单独充值 Credits 包（有效期通常 1 年），单价略贵但灵活
- 用 Pippit 做核心内容（数字人口播视频），用免费的 CapCut 桌面版补图文轮播、产品图动画这类简单内容，Credits 用在刀刃上
- **内容复用**：一条视频跨平台发布（调整比例和文案）、一条长视频剪成多条短片段、一组产品图同时用来文生图和万物成片

### 批量商品图生成——一张图变出四种风格

这是图片智能体中最能帮电商卖家省时间的功能。典型场景：你拍了一张商品主图，想在上架时提供**多角度、多场景、多风格**的展示图，但又不想重新拍。

操作流程很简单：进入 Image Agent → 选择「Batch Generation」或「多图融合」→ 上传清晰的主图 → 告诉 Pippit 你想要的变体（比如「生成 4 张手袋的商品图」「展示这双鞋的不同角度和场景」）→ Pippit 生成一组变体供你挑选。

实际生成的变体可以做到：
- **背景变化**：同一只手袋，分别放在白色背景、大理石台面、木质桌面、金属架上
- **角度变化**：正面 3/4 俯视、侧面特写、内部结构、使用场景
- **光线变化**：自然光、工作室灯光、暖色调、冷色调
- **风格变化**：极简白底、杂志大片感、生活方式、电商促销

**多图融合**是另一个方向：给 Pippit 多张参考图，让它融合出独特的视觉风格——比如产品图 + 一张杂志参考图，就能生成杂志风格的产品图。这适合想建立品牌视觉语言的卖家。

还有一个容易被忽略的 **批量编辑** 功能：不是生成新图，而是对一批现有图做统一调整——裁剪缩放到统一尺寸、统一去背景、统一换背景、统一加滤镜。整理老商品图、跨平台适配图片尺寸时特别好用。

### 进阶玩法：配合 CapCut 做精细调整

Pippit 擅长快速批量生产，但如果需要复杂的叙事结构、精细的时间轴控制、专业级的调色和特效，可以配合 CapCut 桌面版使用：

- 用 Pippit 批量生成基础内容和数字人口播视频
- 把 Pippit 的导出文件导入 CapCut，做精细调整和复杂效果
- Pippit 省掉你从零搭建的时间，CapCut 补齐你对品质的要求

这种组合尤其适合重度用户和对视频质量有较高要求的运营团队——既保证了内容产能，又不会牺牲最终品质。
