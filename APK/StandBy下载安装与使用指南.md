## ✨ StandBy 是什么

StandBy 是一款把 iOS 17 独占的待机屏（StandBy）概念带到 Android 平台的应用——它让你的手机或平板在充电时自动进入一个精致的常亮界面，变身床头钟、书桌仪表盘或厨房信息板。支持 Android 7.0 及以上系统，覆盖三星、Pixel、摩托罗拉、一加、小米等主流品牌，旧平板也能通过它改造成专用智能屏，无需浏览器劫持或 Root。

应用内置上百款钟面（含免费的翻页钟 Retroflip、矩阵字符雨 Matrix、纯黑背景的 AMOLED 钟面家族），支持分屏模式（Duo 两格 / Quad 四格）、角标（Complications）迷你信息位、定时轮换的小组件轮播器等核心部件。天气、日历日程、通知等信息可以与时钟同屏排列，也能接入任意有桌面小组件的第三方应用（包括 KWGT 制作的自定义组件）。音乐控制件尤其实用——系统媒体会话里登记"正在播放"的播放器（Spotify、YouTube Music、Apple Music 等）都能直接在充电屏上暂停、切歌、拖动进度条，全程不用解锁手机。

## 🔧 安装步骤

StandBy 不要求 Root 或注册账号，装上就能用，但 Android 生态的安装路径比 iOS 稍复杂一些。

1. **下载安装包**：从官方下载页获取最新版 APK，核对文件大小和版本号是否与页面标注一致。

2. **允许未知来源**：如果是首次通过 APK 安装，系统会弹出安全提示。进入「设置 → 安全 → 允许安装未知来源应用」，给浏览器或下载器授权。安装完成后建议把这项权限收回，避免误装其他来源的应用。

   > [!WARNING]
   > 三方"破解版"安装包签名与正主不同，收不到更新、内容不可审查，而且正主已经免费，完全没必要走歪路。下载前校验文件哈希或签名能有效避坑。

3. **安装与首次启动**：点击 APK 确认安装，首次启动会弹出权限申请清单——通知访问、系统屏保接入、媒体会话读取等按需授权即可，没有过度索取。应用内有 Onboarding 引导流程，后续想重看可以在设置里找到入口。

4. **基本兼容性确认**：Android 7.0+ 都能跑完整功能，部分视觉效果（如翻页钟动画、AMOLED 纯黑）需要 Android 12+ 才能完全解锁。装上后把手机横放插电，应该能自动进入充电屏模式——这是最直观的"装对了"验证。

## 📖 使用入门

StandBy 的核心思路是"充电时亮屏，内容自由拼"——理解了组 / 变体、触发机制、分屏布局这三件事，就能把一台闲置设备变成顺手的信息终端。

### 触发机制：什么时候自动亮屏

应用最常用的触发条件是 **Quick Launch**：插上充电器、横放设备，屏幕会自动切换到充电屏。系统自带的 Daydream / Dream 屏保通道也能接入，作为不插电时的替代方案。如果整夜不灭屏，记得把屏幕睡眠定时关掉、同时打开高级防烧屏——默认情况下应用有棋盘图案每 60 秒翻转一次，配合熄屏定时能把烧屏风险压到很低。

### 内容组织：组、变体、轮播器

充电屏上的内容按 **组（Group）** 划分，左右滑动在不同组之间切换；同一组内部还有 **变体（Variant）**，上下滑动切换不同款式。比如一个组可以放"时钟 + 天气"，变体 A 是白底大字、变体 B 是暗色 AMOLED、变体 C 加个翻页钟效果。

**Widget Rotator（轮播器）** 是个特殊部件——它可以定时轮换同一个格子里的不同内容，比如半小时显示天气、半小时显示日历、半小时显示一个 KWGT 小组件，单屏的信息量一下就翻倍。

### 分屏与角标：把屏填满

**Duo** 模式把屏上半分成两格，**Quad** 模式分成四格（三格时居中排列）。每一格都可以独立放钟面、小组件或媒体控制。钟面两侧还有 **Complications（角标）**——十七种迷你信息位，常见的有电量、日期、步数、温度，像手表表盘上的小窗口一样灵活。

### 音乐控制：床头音响面板

媒体控制件把充电屏变成一张免解锁的音响面板。它读取的是系统媒体会话，所以 Spotify、YouTube Music、Deezer、Apple Music 以及大多数会在通知栏显示"正在播放"的播放器都能被控制——播放 / 暂停 / 上下首 / 收藏 / 随机循环 / 进度条拖动，抬手就按，做菜时手上湿也能点。依赖的权限是通知访问，控制失灵时先去设置里检查这项授权有没有开。

### 夜间调校：四个滑块调出舒服的暗

夜间模式不是"一档红色走天下"，官方把它拆成四个可调维度：

| 参数 | 管什么 | 调整建议 |
| --- | --- | --- |
| 色调颜色 | 暗色滤镜的色相，默认红 | 红色对暗适应最友好；书房夜用可试琥珀色 |
| 色调强度 | 滤镜压得多重 | 往大推会更深，但别盖过数字可读性 |
| 亮度 | 屏幕本身的光量，独立于滤镜 | 以"一米外看得清、不照亮房间"为标准 |
| 整体色彩 | 滤镜之上的输出微调 | 想保留一点钟面本色就用它微调 |

推荐配置顺序：先把亮度调到卧室里不刺眼的下限，再上色调强度看数字是否仍清晰，最后用整体色彩找平衡。亮度调到最低再叠最强滤镜是常见误区——滤镜是给内容调的，亮度是给环境调的，别用一个顶替另一个。

### 免费 vs 付费

免费层有 45 款钟面（含 Retroflip、Matrix、AMOLED 家族），Premium 层再解锁 51 款。免费层已经覆盖了翻页、矩阵、纯黑等主流风格，普通使用完全够用。付费的 Premium 主要是更多花样和定制自由度。
