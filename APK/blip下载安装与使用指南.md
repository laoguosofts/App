## ✨ blip 是什么

blip 是由韩国 Space Oddity 公司开发的一款 K-POP 粉丝向应用，核心定位是"粉丝的本命行程管家 + 专属记录体系"。它把三件事打通了——**艺人日程追踪**、**应援项目参与**、**个人追星日记（Fanlog）**——这三件事在其他追星 App 里通常是割裂的，blip 是少见的把它们串成完整闭环的产品。

截至当前版本，blip 内置包括中文（简体/繁体）在内的 11 种语言，全球用户看到的艺人列表、应援项目、日程表都是同一套数据，只有界面语言和通知语言可以按个人偏好切换。应用的主要用户群体是 K-POP 粉丝，尤其是那些同时追多团、希望把本命的所有行程和自己的追星回忆统一收纳的重度用户。

blip 的整体产品逻辑是：日程表告诉你今天本命有什么活动 → 提醒准时推送到你手机 → 你去参与或观看 → 回来后写 Fanlog 把这件事记进自己的追星历史。Gem 是应用内的虚拟货币体系，用于参与应援项目（比如地铁灯箱、生日咖啡厅、回归倒计时应援等），用户可以通过签到、写 Fanlog、社区互动等方式获取 Gem，也支持付费充值。

除了核心功能，blip 还内置了艺人照片集（按热门/全部分流、带话题标签归类）、社区讨论区（话题、帖子、投票）、应援项目广场等模块，形成了一个围绕 K-POP 粉丝需求的完整生态。

## 🔧 安装步骤

### Android 安装

1. 从官方下载页获取 APK 安装包，下载完成后在浏览器下载记录里点击文件触发安装
2. 如果系统弹出"未知来源"警告，进入手机设置 → 安全 → 允许安装未知来源应用，授权后重新点击安装
3. 安装过程保持默认即可，通常需要 50~80MB 的存储空间
4. 安装完成后在桌面找到 blip 图标，首次启动会自动检测手机系统语言——如果你的系统是中文，blip 会默认用中文界面

> [!TIP]
> 建议在安装前核对一下下载包的文件大小和版本号，与官方下载页标注的一致再安装，避免下载到非官方渠道的第三方修改包。

### iOS 安装

1. 打开 App Store，搜索「blip」，找到 Space Oddity 开发的官方应用
2. 点击"获取"，输入 Apple ID 密码或使用 Face ID 确认
3. 安装完成后首次打开，iOS 会请求通知权限（建议允许，否则日程提醒收不到）

> [!WARNING]
> 部分地区的 App Store 可能因为区域限制无法直接搜索到 blip。如果遇到这种情况，可以考虑用支持地区的 Apple ID 登录，或者关注官方下载页提供的替代安装方式。

### 安装后的第一次启动

首次启动时 blip 会引导你选择或登录账号。可选的登录方式包括 Google 账号和 Facebook 账号，产品方明确说明不会获取超出登录必需范围的权限（不会读取 Drive、照片、通讯录、位置等非登录数据）。登录完成后进入主界面，底部通常有"首页"、"日程"、"粉丝日志（Fanlog）"、"社区"、"我的"五个主要标签。

## 📖 使用入门

### 关注本命艺人

进入首页后可以从艺人推荐列表里选择你想追的团或 solo 艺人，点击"关注"后他们的日程、照片集、应援项目都会同步到你的个人首页。blip 的艺人库覆盖了主流 K-POP 团体和 solo 歌手，产品方和社区用户共同维护着艺人档案和行程数据。

关注完成后，打开日程标签就能看到本命近期的全部行程——包括回归、演唱会、签售会、直播、电视台音乐节目等等。每条日程会标注时间、地点、类型（Broadcast / Release / Event / Birthday 等），你可以给重要的日程单独开启推送提醒，到点时 blip 会直接把通知送到你手机上。

### 写 Fanlog：把追星回忆归档

Fanlog 是 blip 最独特的功能。它和普通日记 App 不同——**写的时候会自动带出当天你关注艺人的日程条目**，比如"今天 BLACKPINK 有 M Countdown 演出""TWICE 签售会在下午 3 点"，这些日程会作为自动插入的上下文，让你写日记时不用手动回忆那天本命做了什么。

写 Fanlog 的入口有两个：
- 从日程详情页点"写 Fanlog"，自动带出该日程的标题和时间
- 从粉丝日志标签进入，选择日期后点"+"新建

Fanlog 的格式完全自由——纯文字、图文并茂都可以。可以写某场直播本命说了什么、演唱会现场的感受、签售会拿到签名时的心情、生日咖啡厅的布置、应援项目推过 100% 那一刻的激动，或者日常的感慨。产品方不强制格式，写得随意也没问题。

> [!NOTE]
> Fanlog 里自动插入的日程条目只是参考文本，你可以删掉、改成自己的话、或者完全忽略不写。blip 不会强制你必须提当天的日程。

Fanlog 默认只有你自己能看到，也可以设置为好友可见。写完后按日期归档，月底打开日历视图翻一遍，就是整个月的追星轨迹。产品方还会评选每月 Fanlog 名人堂，写得用心的日记有机会被更多同好看到。

### 照片集浏览

每个关注的艺人都有独立的照片集。进入艺人页后切到"照片集"标签，就能看到该艺人的全部照片。照片来源包括产品方从官方渠道抓取的高清图、社区用户上传审核通过的图、应援项目落地照片、粉丝拍的现场照片等，整体质量较高。

照片集提供两种浏览模式：
- **热门**：按点赞数、浏览量排序，快速抓到本命近期最受关注的新物料
- **全部**：按时间倒序的完整照片流，想系统补旧图或翻某个活动的照片时用这个

每张照片都带话题标签（类似 #NewJeans、#2026回归、#生日咖啡厅），点进标签可以聚合所有带这个标签的照片。大图预览支持左右滑动翻同系列、双指缩放看细节，Android 版长按或在大图预览里找下载按钮可以直接保存到手机相册。

### 语言设置与隐私

blip 没有"地区"概念，所有用户看到的都是同一套全球艺人数据。语言可以在设置里随时切换（底部"我的"→ 设置 → 语言），切换后界面文案、日程分类标签、通知推送会全部变成新语言，但艺人名称、Fanlog 内容、Gem 数据、已关注列表都不会变。首次启动时如果系统是中文，blip 会默认用中文界面。

换设备时所有数据会自动同步——用同一个 Google 或 Facebook 账号登录新设备，已关注艺人、Fanlog、Gem 余额、设置偏好都会自动回来，不需要手动备份。如果不再使用 blip，可以在设置里退出登录回到游客模式，或通过设置里的注销入口（部分版本）/发送邮件到 help@blip.kr 申请完全删除账号。

### Gem 与应援

Gem 是 blip 内的虚拟货币，用于参与应援项目——比如为本命投生日应援、回归倒计时应援、地铁灯箱广告应援等。获取 Gem 的途径包括每日签到、写 Fanlog、社区发帖互动、观看广告（免费途径），以及付费充值。应援项目有明确的进度条和截止日期，推过 100% 后应援会落地执行，完成后你可以在项目详情页看到落地的照片和反馈。
