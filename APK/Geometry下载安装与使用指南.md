## ✨ Geometry 是什么

Geometry 是一款面向数学教学与学习的动态几何软件，它把纸面上静态的几何图形搬到了可交互的画布上——你画一个三角形，拖动顶点、边长、角度，所有关联的线段、角度、面积、代数表达式都会实时联动更新。这种"牵一发而动全身"的动态性，是它区别于传统绘图工具的核心价值。

软件内置了点、线、圆、多边形的全套绘制与构造工具，加上垂线、平行线、中点、角平分线等关系构造，以及测量长度、角度、面积、周长的验证功能，基本覆盖了从初中平面几何到高中解析几何的实验需求。代数区与画布同步呈现每个对象的坐标、方程、数值表达式，让几何关系与代数形式在同一界面里互相对应。

界面支持多语言切换，默认语言跟随系统，安装后可以在设置里改成中文。免费版对学习和教学场景开放全部核心功能，注册账号后额外获得云保存、在线资源同步等增值能力——不注册也能完整使用本地作图与保存。

## 🔧 安装步骤

Geometry 支持多平台安装，桌面端覆盖 Windows、macOS、Linux，移动端有 Android 和 iOS 版本。安装包体积不大，下载完成后按平台说明操作即可。

### 桌面端安装

1. 打开下载页，选择对应操作系统的安装包
2. Windows 用户运行 `.exe` 安装程序，按向导选择安装路径，建议保留默认位置，避免中文路径导致的兼容性问题
3. macOS 用户打开 `.dmg` 将应用拖入「应用程序」文件夹，首次启动如果提示安全限制，在「系统设置 → 隐私与安全性」里点「仍要打开」
4. 安装完成后首次启动会弹出语言选择界面，确认默认语言或切换为中文即可进入主界面

> [!TIP] 版本核对
> 打开应用后在「帮助 → 关于」菜单里查看版本号，与下载页标注的最新版本比对一致后再开始使用，避免使用过旧版本遇到功能缺失或已知 bug。

### 移动端安装

移动端直接从应用商店搜索软件名下载安装即可，不需要额外配置。首次启动同样会引导语言选择。

### 下载前的注意点

安装包大小因平台而异，桌面端约数百 MB。下载完成后建议核对文件大小与官网标注值是否一致，如果差距较大说明下载不完整，需要重新下载。不要从第三方镜像或网盘获取安装包，以防版本过时或被篡改。

## 📖 使用入门

### 画布上的三种点

点是几何构造的原子，描点工具在基础工具栏里排第二位。同一个按钮，点在不同位置会产生三种性质完全不同的点——这是新手最容易混淆也最值得搞清楚的第一个概念。

**自由点**：在画布空白处轻点，生成的点不受任何对象约束，可以被拖动工具拖到任何位置。坐标会实时显示在代数区，形如 `A = (x, y)`。自由点适合当作"已知条件"的起点，比如画三角形的三个顶点。

**对象上的点**：把点画在已有的线段、直线或圆周上，点会"吸附"在对象上。这种点只能在父对象上滑动——圆上的点绕圆周转，线段上的点只能在段内移动。做"动点沿边运动"类题目时全靠它。一个经典用法：画三角形 ABC，在边 BC 上描一个附着点 D，连接 AD 得到一条过 D 的线段，拖动 D 时线段 AD 扫过整个三角形，配合轨迹工具还能画出 D 的运动路径。

**交点**：点在两条线（或线与圆）的交叉处，生成的是交点。它由两条父对象共同决定，父对象动了它才动，自己不能被单独拖走。

三种点的判断方法很朴素：用拖动工具拖一下，能到处跑的是自由点，只能沿线跑的是附着点，纹丝不动的是交点。给关键点换醒目颜色、给辅助点调小号灰色，是保持画布清爽的好习惯。锁定功能可以把点固定在当前位置，防止课堂演示时手滑误拖。

### 测量与验证：勾股定理的动态实验

Geometry 的测量工具把"验证"变成了"看见"。以勾股定理为例，三步就能完成从特例到普适的演示：

**第一步：实测 3-4-5 三角形。** 画一个直角，在两条直角边上取 3 和 4 个单位（打开网格辅助对齐），量三边长度得到 a = 3、b = 4、c = 5，心算 9 + 16 = 25 成立。再从面积视角补证——三条边上各画一个正方形，测量面积分别是 9、16、25，两直角边上正方形面积之和恰好等于斜边上正方形面积。数字与面积两个视角都过了，定理才算真正"看见"。

**第二步：升级为任意直角三角形。** 拖动直角顶点让两直角边变成别的长度，再量新三边算 a² + b² 与 c²——依然相等。反过来把角拖离 90°，等式立刻瓦解。多拖几组：只要直角在，等式就在；一旦角变斜，定理就破。这个过程把"定理与直角的绑定关系"也顺带验证了。

**第三步：用滑动条参数化。** 滑动条是参数的图形化界面——建一个数值参数，拖动滑块改数值，绑定它的图形实时响应。勾股定理演示里两个滑动条分别控制直角边比例和图形大小，拖动时 3-4-5 变成 4-5-x 或别的组合，但三条边始终满足勾股关系。滑动条把一个固定图形变成了无穷多个图形，是 Geometry 区别于静态绘图软件的灵魂功能之一。

### 离线能力：断网还能用吗

教室里网络不稳、外出没有流量——断网场景下这款软件还能不能用？答案是：核心功能全部可用。

| 功能 | 断网能用吗 |
| --- | --- |
| 画布作图（点线圆多边形、构造、变换） | 能 |
| 测量与代数区 | 能 |
| 输入栏命令 | 能 |
| 本地保存（.ggb 文件） | 能 |
| 应用内资源搜索 | 不能 |
| 登录账号 | 不能 |
| 云端保存与分享链接 | 不能 |

核心价值——动态作图、拖动实验、测量验证——全部发生在本地引擎里，网络只是资源搜索与云同步的外延。三条实操建议：打算课上用应用内资源库的活动，提前联网打开一次并保存为本地文件，之后离线打开毫无障碍；离线期间只走本地 `.ggb` 文件保存，别在断网时纠结云同步，联网后一次性补传；网页版用户需要注意，以上边界只针对安装版，网页版本身依赖浏览器与网络，断网即不可用，考场、教室等需要离线可靠性的场景请使用安装版。

### 新手起步的几条建议

- **打开网格与坐标**：新手作图容易"画歪"，打开网格对齐后基本不会跑偏；代数区的实时坐标也能帮你理解每个点的精确位置
- **多用拖动实验**：画完图形不要停——拖一拖顶点、边长、角度，看什么变了什么没变，这是 Geometry 最大的学习价值
- **及时保存本地文件**：虽然可以注册云账号，但本地 `.ggb` 文件不依赖网络，是最稳妥的存档方式
- **截图记录实验过程**：动态验证的结论比静态截图更有说服力，实验结束后截一张带测量值和滑动条的图，方便复盘和分享
