## ✨ ChatPlusAI 是什么

ChatPlusAI 是一款面向跨境电商卖家的智能客服工作台，核心解决的是多平台、多店铺场景下客服接待效率低、跟单不及时、高价值会话容易被淹没的问题。它把 TikTok Shop、Shopee、Lazada 等平台的店铺消息统一收进一个收件箱，配合 AI 自动翻译、AI 智能跟单、自动回复、知识库快捷回复等能力，让一个客服能顶起多个店铺的接待量。

主要能力集中在几块：会话工作台（统一收件箱、重点追踪、搜索筛选）、AI 自动接待（精准回复买家问题、自动翻译到买家当地语言）、全链路跟单（催付、物流跟进、弃单召回、催好评）、店铺接入（支持多平台多店铺授权）、以及多端协同（Windows / macOS 桌面端、Android / iOS 手机端数据实时同步）。

适合谁用？做跨境电商的中小卖家、代运营团队、需要同时管多个平台店铺的客服主管。如果你只有一个店铺、每天咨询量不大，可能感受不到它的价值；但只要跨了平台或跨了店铺，会话量一上来，ChatPlusAI 的自动化能力就能显著减少人工重复劳动。

## 🔧 安装步骤

### iOS 端（iPhone / iPad）

iOS 端已在全球 App Store 上架，安装最省心：

1. 打开 App Store，搜索 **ChatPlusAI**
2. 核对图标和开发者名，确认是上海炯信信息科技有限公司发布的版本
3. 点"获取"，用 Face ID / Touch ID / Apple ID 密码验证
4. 安装完成后桌面出现图标，直接点开用账号密码登录

安装包体积约 47.5 MB（iPhone 版），iPad 版同样支持，会自动展开为左侧会话列表 + 右侧聊天窗口的双栏布局，比 iPhone 端多了不少操作空间。

### Android 端

Android 端可以通过应用商店搜索安装，也可以从下载页获取 APK 文件。如果是手动安装 APK：

1. 下载 APK 到本地，建议从官方下载页获取最新版本
2. 打开系统设置，允许"未知来源应用安装"（部分机型路径在安全设置里）
3. 点击 APK 文件，按提示完成安装

> [!WARNING]
> Android 系统在安装非商店渠道的 APK 时，可能会弹出"未知来源"警告——这是正常的安全提示，不是 APK 有问题。安装完成后建议把未知来源权限关掉。

### 桌面端（Windows / macOS）

桌面端安装包从下载页直接下载，安装过程都是标准的下一步流程：

1. 下载对应系统的安装包（Windows 为 .exe，macOS 为 .dmg）
2. 双击运行，选择安装路径（建议默认路径）
3. Windows 上如果遇到杀毒软件误报，添加信任即可——官方签名的安装包一般不会有问题
4. 安装完成后，首次启动需要登录账号

> [!TIP]
> **核对版本号**：安装完成后在客户端设置里查看当前版本，和下载页标注的最新版本对比一致即可。iOS 端可以在 App Store 里看版本历史，Android 和桌面端直接在客户端内看。

## 📖 使用入门

### 店铺接入——先把你的店铺连进来

安装好客户端后，第一件事是接入你的电商店铺。支持 TikTok Shop、Shopee、Lazada 等主流跨境平台，接入流程大同小异：

1. 进入管理中心 → 店铺管理 → 选择对应平台 → 添加店铺
2. 选择授权方式：自己直接授权，或把链接发给店铺管理员
3. 按引导完成平台侧的授权确认

以 TikTok Shop 为例，有几个容易踩的坑值得提前说：

- **必须用卖家主账号授权**——子账号没有 API 授权权限，用子账号操作会反复失败
- **多店铺授权要清理浏览器登录态**——前一次授权成功的账号在浏览器里还登录着，这次再授权新店铺，页面可能显示"授权成功"，但实际是假的，新店铺根本没连上。解决办法：每次授权新店铺都**退出浏览器里所有已登录账号**，或者直接用**无痕 / 隐私浏览窗口**打开授权链接
- 授权后会自动同步历史消息（约 30 天）和订单数据（约 90 天），耗时约 15 分钟，这段时间别关客户端

### 会话工作台——统一收件箱 + 重点追踪

店铺接入完成后，所有平台的消息会汇聚到统一的会话收件箱里。日常接待时，不是所有会话都同等重要：买家问了两次还没回复的、明确说要买但还没下单的、要投诉要升级售后的、VIP 老客户的——这些如果和"有没有货"的日常咨询混在一起，很容易被淹没。

ChatPlusAI 的做法是**右键会话 → 标记为重点**，标记后会话会带上明显的星标图标，出现在专门的"重点追踪"分类下。顶部筛选器可以一键筛选出所有已标记的会话，确保每次登录先处理这些高优先级的。

搜索功能也挺实用——顶部搜索框支持按买家昵称、会话关键词、快捷标签、会话状态、订单号等多个维度搜。找不到某条会话先搜一搜，搜不到说明数据没同步或者会话已经关闭了，不是真丢了。

关闭的会话不会消失，只是从活跃列表里移走了。以后买家再来消息，或者你主动重开，该会话会带着历史上下文重新出现在列表里。

### AI 智能跟单——自动化触发催付

跨境电商里有大量"下单了但没付款"的订单——买家可能在观望、可能忘了付、可能在比价。Shopee 等平台的付款窗口期一般是 24 小时，过了自动取消。

ChatPlusAI 的 AI 跟单模块能在**订单超时未付款时自动触发催付提醒**：

- 入口在管理中心 → 自动化 → AI 智能跟单 → 催付场景 → 开启
- 可以配置触发时机（建议订单创建后 4-8 小时，太早打扰、太晚来不及）、话术模板、最多催几次（建议 1-2 次）
- 模板会自动翻译成买家所在站点的本地语言

官方给出的数据是开启催付提醒后订单取消率下降约 40%，转化率提升约 100%——这个数字因品类和客单价差异很大，但催付本身是 ROI 很高的自动化动作，只花一次 AI 跟单额度就能挽回大量流失订单。

AI 跟单的所有场景（催付 + 物流跟进 + 弃单召回 + 催好评）**共享一个月度买家池**，不按场景单独计数。各套餐额度差异：

| 套餐 | 月度跟单买家数上限 |
| --- | --- |
| 个人版 | 20,000 |
| 初创版 | 30,000 |
| 基础版 | 50,000 |
| 进阶版 | 80,000 |
| 高阶版 | 100,000 |
| 专业版 | 150,000 |
| 企业版 | 不设上限 |

北京时间每月 1 号 0 点重置。额度用完后所有 AI 跟单场景暂停，下月重置或升级后恢复。

### 多端协同——办公桌 + 出门全覆盖

iOS / Android / Windows / macOS 四端登录同一个账号，数据实时同步。比较实用的搭配是：办公桌用 Windows 或 macOS 桌面端做批量操作（店铺接入、自动化场景配置、子账号管理这些复杂操作在桌面上完成），出门时用手机端及时响应新消息和 AI 跟单触发的通知。iPad 上自动展开的双栏大屏工作台，体验接近桌面端。

> [!NOTE]
> 手机端的管理中心操作不如桌面端方便，建议把店铺接入、自动化配置等设置类操作都在桌面端完成，手机端只专注于日常接待和快速回复。

消息推送方面，iOS 走 APNs 通道、Android 走系统推送，新会话通知、AI 跟单触发通知、会话转接通知都会推送到锁屏，可以在系统设置里为 ChatPlusAI 单独调整提醒模式和声音。
