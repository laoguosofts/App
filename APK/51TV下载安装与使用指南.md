## ✨ 51TV 是什么

51TV 是一款面向安卓电视盒子和智能电视的直播聚合 App，核心卖点是把主流卫视频道和中央台统一收口，配合 7 天回看和时移功能，解决了"想看的节目刚播完"的痛点。它本身不做内容生产，而是把公开可用的直播源整理到一个界面里，用户装完就能直接选频道开播。

当前覆盖的频道约 150 个，其中约 40 个主流频道支持回看——这 40 个是日常使用频率最高的那些，比如 CCTV 全系列、湖南卫视、浙江卫视、东方卫视等。回看窗口为 7 天，超出之后节目就自动从回看队列里移除，这不是 Bug，是版权限制。

适合的用户群很明确：家里有老人想看传统电视、又嫌有线电视年费贵的家庭；租房一族不想办宽带电视；想在电视上看体育直播但找不到合眼源的年轻人。如果你追求的是个性化推荐、专属片库，那 51TV 不是那类产品——它的定位就是"把电视直播这件事做简单"。

## 🔧 各平台安装步骤

51TV 只跑在安卓阵营的盒子和电视上，不同品牌的安装门槛差异不小。小米和 Redmi 盒子最省事，乐视盒子因为有 SLA 锁需要多花两步，天猫魔盒和其他安卓盒子的装法跟小米类似。

### 小米盒子（3 / 4 / 4S / Redmi 盒子）

第一步必须先打开"允许安装未知来源应用"——不开的话任何非小米应用商店的 App 都装不上：

1. 盒子首页按遥控器"菜单"键进入**设置**
2. 向下找到**账户安全**（或"安全"）
3. 打开**允许安装未知来源应用**开关，同时建议打开 **ADB 调试**

> [!NOTE]
> MIUI TV 和 PatchWall（小米电视新系统）的菜单位置不完全一样，但逻辑一致：设置 → 安全/账户安全 → 未知来源。找不到的话用搜索框搜"未知来源"。

未知来源开好之后有两种装法，推荐 U 盘法：

| 方法 | 步骤 | 优缺点 |
| --- | --- | --- |
| **U 盘法（推荐）** | APK 复制到 U 盘根目录 → 插盒子 USB → 文件浏览器找到 → 安装 | 最稳定，不受网络影响 |
| **投屏神器 App** | 手机装投屏神器 → 同 WiFi 配对 → 推送 APK | 不用 U 盘，但需要手机操作 |

> [!WARNING]
> 小米盒子没有自带文件浏览器。U 盘法前先确认盒子里有没有装过"文件管理"或"高清播放器"，没有的话得先通过投屏神器装一个——这是小米盒子最容易卡的地方。

### 乐视盒子（U4 / U4 Pro）和老款乐视超级电视

乐视的门槛比小米高一道 SLA（Secure Lock Access）锁，默认只允许装乐视商店里的 App。解除步骤：

1. **进开发者模式**：系统设置 → 关于本机 → 连续按遥控器**方向键上** 7 次，底部出现"已进入开发者模式"
2. **解 SLA 锁**：回到系统设置 → 新出现的**开发者选项** → SLA 锁选"允许" → 同时打开 **USB 调试**和 **USB 安装**

解完 SLA 之后装法跟其他盒子一样，U 盘或 ADB 都行。

> [!NOTE]
> 乐视盒子开机时"安全中心"可能会扫描并建议卸载"未知来源应用"。建议在设置 → 应用里找到"安全中心"直接停用，或者把 51TV 加入"可信应用"列表。

> [!WARNING]
> 不建议刷第三方固件（如当贝 OS）来绕锁。刷固件有变砖风险，保修也会作废，普通家庭用户得不偿失。

如果你的乐视超级电视是 **Y30 系列及以后**，系统已经换成 Android TV 原生系统，装法跟小米电视一致——设置里开未知来源 → U 盘安装即可。

### 下载与安装注意点

- APK 文件大小约 6MB，下载后核对一下文件大小是否匹配
- 安装到一半提示"解析包错误"通常是 APK 损坏或下载不完整，重新下载一份即可
- U 盘建议用 FAT32 格式，部分盒子不认 NTFS
- 装好后回到首页 → 我的应用 → 就能看到 51TV 图标

## 📖 使用入门

装完打开就是首页——频道列表直接铺在眼前，方向键左右切频道、上下换台，跟传统遥控器的直觉一致。真正值得深挖的功能集中在回看、时移和手机投屏三块。

### 回看搜索：7 天窗口内找节目

回看是 51TV 最核心的功能之一。两种路径看你更习惯哪种：

**按频道浏览 EPG**——适合"知道想看哪个台、但不确定具体节目"的场景：

1. 切到目标频道（比如 CCTV-1）
2. 按方向键上 → 弹出 EPG 节目单
3. 方向键右 → 切换到"昨天"或"前天"标签
4. 上下滚动找到节目 → OK 进入回看

**按关键词搜索**——适合"确切知道要找什么"的场景：

1. 回到首页顶栏搜索框
2. 输入节目名（如"狂飙""春晚""NBA 总决赛"）
3. 搜索结果里带"回看可看"标签的就是还在 7 天窗口内的
4. 选中直接进入

搜索结果页还能按时间范围筛选（今天 / 昨天 / 近 3 天 / 近 7 天），默认近 7 天全搜一遍。如果你记得节目大概的播出时间，缩小范围能让结果更精准。

搜不到的常见原因有四个：

1. **节目超出 7 天窗口**——51TV 只有 7 天回看，播完超过就没了，这是设计限制
2. **频道本身不支持回看**——150 个频道里只有约 40 个主流频道支持回看
3. **版权保护**——某些体育赛事、院线电影首播不授权回放
4. **节目名不是官方叫法**——比如"狂飙"有时被叫作"狂飙之扫黑风暴"，换关键词试试

### 时移播放：直播中途暂停/快退

时移和回看是两个功能：回看是回到已经播完的节目从头看，时移是直播中途你想倒回去补看刚错过的片段。进入直播画面后按方向键上弹出控制条，就能自由拖动时间线，快退补完之后再回到实时直播——适合突然来个电话错过精彩镜头的场景。

### 手机投屏：大屏继续看

51TV 手机版支持一键投屏到盒子/电视，适合"出门用手机看、回家推到大屏继续"的场景。投屏（Cast）和镜像（Mirror）不一样——投屏是把播放内容直接推到电视上，手机可以继续用别的 App；镜像是把整个手机屏幕实时投过去，手机做什么电视就显示什么。51TV 用的是 Miracast + DLNA 协议，不支持 AirPlay。

操作步骤：

1. 手机和电视连**同一个 WiFi 网络**（这是最常见的坑——手机连 5G、盒子连另一个 2.4G 路由器，设备互相看不见）
2. 打开 51TV 进入播放画面
3. 画面右上角点投屏图标（长方形 + 向下的箭头）
4. 选中盒子/电视 → 画面切换到电视继续播
5. 手机此时可以退出 51TV 用其他 App，电视上继续播

投屏的另一优势是**倍速播放**——手机端可以调最高 2.0 倍速，电视端同步变速，追连续剧跳片头片尾很好用。

投屏失败排查：

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 找不到设备 | 不在同一网络 | 统一连同一个 WiFi |
| 找不到设备 | 盒子没开投屏服务 | 盒子设置 → 显示 → 无线显示/Miracast → 打开 |
| 连上但没画面 | 盒子缓存问题 | 重启盒子 |
| 画面卡顿 | WiFi 信号差 | 手机靠近盒子，或换 5G WiFi |
| 自动断开 | 手机锁屏休眠 | 把 51TV 加到后台白名单 |

日常固定看电视还是直接在盒子上用 51TV 更顺手——少了投屏这一步。投屏适合的场景是：你先在手机上搜到了某个节目想转到电视上看，或者想把手机上搜到的任意视频投到大屏。
