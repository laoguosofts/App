## ✨ Gallery 是什么：一款轻量离线的安卓图库

Gallery 是一款面向安卓设备的轻量级图库应用，核心定位就是**替代系统相册**——启动快、滑动流畅、界面干净，没有开屏广告，也不逼你注册账号。对于嫌厂商预装相册臃肿、想换一个简单好用看图工具的用户来说，它的吸引力很直接：装上就能用，照片始终在本地，不要求云同步，也不收集任何需要联网才能拿到的数据。

从公开描述来看，Gallery 走的是 **"light and fast"** 路线——用现代化界面框架构建，冷启动进入可翻图状态的速度明显快于多数系统相册，日常浏览几千张照片量级下，缩略图滚动和大图缩放都应该无压力。它支持的安卓版本门槛也很低，据渠道记载安卓 7.0 即可安装，老设备的可用性正是这类轻应用的立身之本。

功能层面它覆盖了看图、设壁纸、筛选排序、多选批量处理等日常需求，**但视频动态壁纸、云端备份、跨设备同步这些能力不在它的范围里**——它就是一个专注本地存储的纯看图工具，不做减法也不做加法。照片数据的存储定位是完全本地：不提供云相册服务，没有上传环节，飞行模式下功能完整，应用卸载重装照片也不会丢。

## 🔧 安装步骤：安卓设备的标准流程

安装 Gallery 的门槛不高，但有几个注意点值得提前了解。

### 安装流程

1. **下载安装包**——从下载渠道获取 APK 文件，保存到手机本地；
2. **开启未知来源授权**——系统设置 → 安全 / 隐私 → 允许安装未知应用，对下载应用的那个渠道开启权限；
3. **点击安装包执行安装**——一路确认即可，不需要特殊权限申请；
4. **首次启动授予存储权限**——Gallery 需要读取照片和视频，这是唯一必须的运行时权限。

### 版本核对建议

> [!TIP]
> 安装完成后，可以打开应用的关于页面核对一下版本号是否与下载页标注的一致。有些应用市场上架的版本可能滞后一两个迭代，建议优先使用官方下载渠道获取最新版。

### 装完怎么确认是这一份

冷启动应用，从桌面点击图标后观察进入首页的速度——Gallery 的标志性体验就是**秒开无加载**，如果出现了开屏广告或长时间加载动画，大概率不是官方原版。

## 📖 使用入门：从看图到设壁纸的完整上手

Gallery 的日常使用路径并不复杂，但几个关键操作掌握之后，体验会好不少。下面从浏览、查找、管理三个维度，把它的核心玩法捋一遍。

### 浏览：两级定位比无尽时间线快得多

打开应用默认进入的是**相册总览页**——满屏的文件夹卡片代表手机上按目录分组的相册。点开任一相册，就进入**照片网格页**：方形缩略图按行排列，上下滑动即可浏览，加载流畅度是它比系统相册体验好的地方之一。

> [!NOTE]
> 网格页和总览页的区别：总览页管相册（文件夹卡片），网格页管照片（单张缩略图）。找不到某张图时，先想它在哪个文件夹，再进那个文件夹扫缩略图——两级定位比在一条无尽时间线里刷快得多。

网格页顶栏三个按钮是日常高频操作入口：放大镜用于本相册内按文件名过滤，筛选/排序按钮可以切换排序方式（按名称、按日期等），三点菜单则提供全选、批量处理等扩展功能。

缩略图密度可以在设置页调整——网格列数多的版本一屏能看三四十张，适合快速扫图找目标；列数少的每张大、看得清，适合慢慢欣赏。夜间翻图建议切深色模式，缩略图墙在暗色底上不刺眼。

### 查找：搜索、筛选与多选的配合

在海量照片里定位目标，Gallery 提供了几种实用手段：

- **文件名搜索**——网格页顶栏放大镜，输入关键词即可过滤；
- **长按多选**——长按任一缩略图进入多选模式，连续点选多张后可以批量移动、复制或删除；
- **合理利用文件夹结构**——Gallery 不强制重新组织照片，照片跟着文件夹走，所以手机上的文件夹命名和分类习惯直接影响找图效率。

### 设壁纸：长按几下让好图天天见

Gallery 内置了一键设壁纸的功能，官方专门列了一条 set any picture as wallpaper。操作路径很直接：打开目标照片进入单张查看器，点开三点菜单（或长按图片，入口随版本略有差异），选"设为壁纸"，系统弹出裁剪预览界面，拖动选框定好取景范围，确认后桌面立刻换装。

几个实用细节：

- **分辨率够不够**——壁纸取的是照片一块区域，原图分辨率越高裁出来越清晰；屏幕级壁纸一般两千像素宽起；
- **横图竖屏的取舍**——竖拍照片做手机壁纸最合适；横图做壁纸会裁掉两侧，主体居中的图效果最好；
- **深色壁纸更省眼**——如果同时使用深色模式界面，壁纸也选暗色调，夜间观感更统一。

设壁纸需要系统授予 SET_WALLPAPER 权限，这是安卓的标准应用权限，首次设置时系统会自动处理，无需手动开关。想要视频动态壁纸则不在 Gallery 的功能范围里，那需要专门的动态壁纸应用支持。

### 本地存储：照片跟着手机走，备份得自己扛

Gallery 是典型的**离线优先**应用：不注册、不登录，装上就能用，飞行模式下功能完整。这意味着好处和责任各一半：

**好处**：
- 没有云端泄露面，照片的隐私边界等于手机的物理边界；
- 应用卸载重装照片不受影响，它们本来就是独立文件；
- 没有跨设备同步的绑架，想换手机、想换看图工具，照片拷走就是了。

**责任**：
- 没有云端备份——手机丢了、进水、摔坏，照片跟着走；
- 没有跨设备同步——换新机照片不会自己飞过去；
- **备份习惯得自己重建**——用云相册的用户被平台备份惯坏了，换 Gallery 要补这一课。

备份方案的选择：

| 方案 | 做法 | 适合 |
|---|---|---|
| 网盘手动备份 | 定期把照片文件夹上传网盘 | 大众方案，简单可靠 |
| 电脑有线拷贝 | 数据线连电脑整目录复制 | 量大、坚持存原图的用户 |
| 局域网同步工具 | 手机电脑互传的同步应用 | 有电脑且愿意折腾自动化 |

备份的对象就是照片文件夹本身——文件思维的好处：文件夹在哪，照片就在哪，拷起来直截了当。

### 老手机卡顿优化

选轻量图库的用户多数是冲着"快"来的，但实际体验和设备配置、照片量有直接关系。Gallery 在低配置设备上的优化做了什么，卡了怎么办：

**它的优势场景**：
- 启动无广告无加载动画，冷启动速度明显快于系统相册；
- 几千张照片量级下滚动和缩放无压力；
- 安卓 7.0 即可安装，老设备友好。

**天然吃力场景**：
- 几万张照片的首次全库扫描和缩略图建立——任何图库都逃不掉；
- 单张几十 MB 的超大分辨率照片连翻；
- 低端机上密集网格的缩略图解码压力。

**卡了怎么办：五步优化**

1. **网格调疏一档**——解码量立减一半，低端机立竿见影；
2. **关闭视频自动播放**——视频解码是最重的负载，关掉能省不少资源；
3. **等首次扫描完成**——装完头几分钟卡是正常的，缩略图库建好后就顺了；
4. **清理超大文件夹**——单个文件夹上万张图，拆成子文件夹，扫描和加载都更轻；
5. **重启手机**——清理系统级的媒体扫描积压，老设备每周一重启是惯例。

用着一直好好的突然卡，多半不是 Gallery 本身的问题——后台在下载、手机发热降频、存储将满都会拖累全局。可以先确认一下照片扫描没在空转，再看看存储余量。
