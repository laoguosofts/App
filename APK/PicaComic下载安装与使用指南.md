## ✨ PicaComic 是什么

PicaComic 是一款开源、免费的多源漫画阅读器，主打聚合能力——一个应用里可以接入多个漫画源，支持在线浏览和离线下载。它的定位很明确：给喜欢看漫画的用户提供一个干净、无广告、功能完整的统一入口。

从功能上看，PicaComic 的核心优势在于跨源聚合和离线体验。支持的漫画源覆盖了从国内平台到海外站点的多种来源，用户可以在同一个书架里管理来自不同源的收藏和历史。阅读器本身也做了不少细节优化——保持屏幕常亮、独立亮度调节、横屏双页模式、长按放大等，都是为长时间阅读场景设计的。

版本更新频率不低，V3 到 V4 的迭代中修复了不少影响体验的硬伤：下载时文件扩展名检测错误、大文件写入不完整、下载目录变更不响应、删除后文件残留、Cloudflare 验证失败等等——这些都是用户高频反馈的问题，说明项目维护的节奏还是比较扎实的。

适合的人群很广：漫画重度读者（需要离线存一整部追更）、跨源用户（不想每个源装一个 APP）、喜欢折腾代理和自定义的技术向玩家。如果你只是偶尔翻翻、用的是单平台官方 APP，那 PicaComic 的价值可能没那么大。

## 🔧 安装步骤

### Android 端

安装 PicaComic 的 APK 流程和大多数第三方 Android 应用一样，关键点在于「允许未知来源」这一步：

1. 把 APK 文件传到手机上（USB 数据线、网盘下载、浏览器直下都可以）
2. 打开系统设置，找到安全相关选项，开启「允许安装未知来源应用」
3. 用文件管理器找到下载好的 APK，点击安装
4. 系统弹出权限申请时，按需授予即可

> [!WARNING] **签名不一致的坑**
> 如果之前装过来自不同签名源的版本（比如朋友转你的、应用商店下载的），直接覆盖安装会提示失败。这时候需要先卸载旧版，再装新的——别担心数据，卸载时系统会保留应用数据目录，重装后可以恢复。

首次启动时，应用会依次申请几项权限：

| 权限 | 是否必选 | 拒绝后的影响 |
| --- | --- | --- |
| 存储访问 | 必选 | 离线下载功能不可用，在线浏览不受影响 |
| 网络访问 | 必选 | 无法连接任何漫画源 |
| 通知权限 | 可选 | 没有下载完成提示和追更通知 |

> [!TIP] **存储空间预留**
> 应用本身体积不大，但离线下载漫画是实打实占空间的——一部漫画全下完几百 MB 很常见。建议至少预留 500MB 再开始批量下载，避免下到一半突然报空间不足。

### 桌面端（Windows）

桌面端的安装相对简单，下载安装包后双击运行，选择安装路径即可。3.1.4 版本之后，Windows 端的 WebView 已经支持在应用内单独设置代理——之前是只能跟系统代理走，对不想改全局代理的用户来说是个大改进。

安装时注意两点：一是路径尽量选非系统盘（比如 D 盘），方便后续清理；二是如果杀毒软件报了误报，添加信任即可——开源项目的代码是公开可审计的。

## 📖 使用入门

### 第一步：配置漫画源

装完打开应用，第一件事是配置你想看的漫画源。不同源的接入方式略有差异：有些源直接在应用内的「漫画源管理」里就能一键添加，有些海外源需要额外处理身份验证（比如 e-hentai 的 Cookie）。

添加完源之后，建议先在书架里每个源挑一部漫画试试能不能正常加载——能加载说明源已经通了，加载不了的话先别急着往下走，排查网络或代理问题。

### 在线浏览与收藏

在线浏览的体验和大多数阅读器类似：点开章节就能看，左右滑动翻页，长按画面可以放大看细节。读到想追的漫画，点收藏按钮加入书架，后续更新会自动推送通知（前提是授予了通知权限）。

### 离线下载

下载是 PicaComic 最常用的功能之一——毕竟谁也不想追更时每次都靠流量加载。下载前需要确认两件事：存储权限已授予、存储空间够。下载可以单章节下，也可以整部批量下，队列管理支持暂停、取消、重试。

下载过程中如果遇到个别章节一直失败，通常是源站的图片服务器临时不稳定——等几分钟再重试，或者切到同内容的其他源。

> [!NOTE] **下载目录变更**
> 如果你中途改了下载目录设置，3.1.4 之前的版本里正在进行的下载任务不会切换到新目录，需要先暂停所有下载、改完目录、再逐个重启任务。用 3.1.4+ 版本的话这个问题已经修掉了。

### 阅读器设置

阅读器里的几个设置建议一打开就调好，省得每次看漫画都要手动操作：

**保持屏幕常亮**——这是必开项。不开的话，阅读时如果手没碰到屏幕，设备会自动锁屏或降亮度，体验很差。注意这个常亮是临时的，退出阅读器后会自动恢复系统默认锁屏行为，不会一直亮着耗电。

> [!WARNING] **国产 ROM 的省电策略**
> 部分国产 Android ROM（小米、OPPO、vivo 等）的系统省电策略比较激进，即使应用申请了屏幕常亮，系统也可能强制忽略。如果发现开了常亮但还是锁屏，去系统设置里把 PicaComic 加到后台白名单和自启动权限里。

**屏幕方向**——手机用户大多用竖屏，适合条漫的从上至下模式和单手阅读。平板或大屏设备推荐横屏 + 双页模式，画面更大、信息量更足。

**夜间阅读**——夜间长时间看漫画对眼睛压力大，推荐一套组合：应用深色模式跟随系统或始终开启 → 打开「深色模式下降低图片亮度」→ 系统亮度调到最低但仍能看清 → 保持屏幕常亮开启。这套下来比默认设置舒服不少。

### 代理与网络问题

某些漫画源（特别是海外源如 e-hentai、nhentai）在国内网络下无法直接访问，需要走代理。Windows 端 3.1.4 之后支持在应用内单独设置 HTTP 代理或 SOCKS5 代理，不用改系统代理——这点对经常切换网络环境的用户很友好。代理白名单也可以配置，比如 PicACG 走直连、e-hentai 走代理。

Cloudflare 验证失败是海外源常见的问题。如果遇到验证过不了，按这个顺序排查：

1. **检查设备时间**——时间偏差会导致验证 Token 无效，把自动对时开上
2. **降低请求频率**——设置里的预加载张数调低一点，短时间频繁请求容易被临时封禁
3. **检查 Cookie 是否过期**——e-hentai 的 Cookie 里有身份验证字段（比如 igneous），3.1.3 版本之后支持单独更新这个字段，不用每次复制粘贴整个 Cookie
4. **切换网络环境**——Wi-Fi 和移动数据之间切一下，可能是当前出口 IP 被 Cloudflare 风控了
5. **升级到最新版本**——V4.0.1 专门修过 Cloudflare 验证的兼容性问题，旧版本可能已经不匹配新版防护规则了

### 常见下载问题

下载功能虽然方便，但也容易出状况。按现象分类：

**下载一直失败**——先查网络通畅性（浏览器访问源站试试）、查存储空间剩余、查存储权限。确认这三项没问题的话，可能是源站图片服务器在负载高峰不稳定，等几分钟再试，或者切换同内容的其他源。

**下载完成但打不开**——这个问题在旧版本里出现过几次：3.1.4 之前存在图片大文件写入不完整、文件扩展名检测错误（实际是 WebP 却保存成 JPG）的 bug。如果你遇到这种情况，删了已下载的漫画、重新下载一遍，确认用的是 3.1.4+ 版本就能解决。

**从下载列表删了但磁盘没释放**——同样是 3.1.4 之前的版本有这个 bug：删除下载项目时只清了列表记录、没删磁盘文件。V4.0.2 再次确认修复了这个问题。如果还在用旧版本，只能手动去下载目录清理残留文件。
