## ✨ LeviLauncher 是什么

LeviLauncher 是一款专门面向 Minecraft Bedrock Edition 的第三方启动器。它解决了官方启动器长期存在的几个痛点：版本管理混乱、数据全塞在 C 盘 AppData、资源包和 Mod 无法按版本隔离、缺少内容工具箱。如果你同时玩正式版和预览版、装了一堆资源包和行为包、或者想把游戏数据挪到非系统盘，LeviLauncher 基本就是为此量身定做的。

它的核心思路是「**隔离工作区**」——每个 Minecraft 版本（包括正式版、预览版、Beta）都有自己独立的资源包、行为包、世界存档和配置目录。版本之间完全隔离，互不污染。你可以在预览版里放心测试新 Mod，主存档不受任何影响。除了版本隔离，它还内置了内容工具箱（资源包导入、行为包管理、皮肤包、截图管理、服务器列表）、世界备份、一键打开真实文件目录等实用功能。

需要明确的前提是：LeviLauncher 不提供游戏本体，它只是 Windows Store 授权的 Bedrock 游戏的管理工具。你需要先拥有正版 Minecraft Bedrock Edition，才能用它来管理。

适合谁用？大致可以归为四类玩家：

- **测试党**：紧跟预览版更新，每个快照都想第一时间试玩，但不想把主存档搞坏
- **Mod 爱好者**：装了十多个行为包和资源包，换一个就可能冲突，需要逐个隔离测试
- **内容创作者**：经营生存档、创造档、红石测试档等多个世界，每个档想配不同的视觉风格
- **迁移党**：换电脑或换硬盘，不想重新折腾所有 Mod 和配置，隔离工作区直接复制即可

不满足以上场景、只玩正式版且不装任何 Mod 的玩家，官方启动器足够用了，没必要多装一个。

## 🔧 安装步骤

LeviLauncher 的安装流程比较简单，但有几个前置条件需要注意。

### 前置检查

1. **系统版本**：Windows 10 或 11（必须），7 和 8.1 不再支持
2. **Gaming Services**：Windows 应用商店的 Gaming Services 组件必须正常运行——打开 Microsoft Store 搜索就能安装或修复
3. **磁盘空间**：至少预留 10GB 给启动器本体和首个 Minecraft 版本，后续每个隔离版本会再占数 GB
4. **权限**：安装路径建议选非系统盘（D 盘或 E 盘），避免 C 盘空间被悄悄吃掉

### 安装过程

1. 从下载入口获取最新版本的安装包（通常是 `.exe` 格式）
2. 双击运行安装程序，选择安装路径
3. 安装完成后首次启动，启动器会引导你完成 Microsoft Store 授权验证——这一步必须做，否则启动器无法识别你已拥有的 Bedrock 正版授权
4. 授权通过后，启动器自动扫描本机已安装的 Minecraft 版本，识别成功即进入主界面

> [!WARNING]
> 如果安装时提示「找不到 Gaming Services」，不要跳过——打开 Microsoft Store 搜索「Gaming Services」手动安装，否则启动器启动时会白屏或闪退。

### 安装后核对

启动器首次运行成功的标志：

- 主界面能显示你已有的 Minecraft Bedrock 版本列表
- 左侧导航栏的「内容」「版本」「设置」等分区都能正常打开
- 版本详情页能看到当前版本的隔离工作区路径（默认在 C 盘，可以稍后在设置里改到其他盘）

## 📖 使用入门

### 版本管理与隔离

LeviLauncher 的第一核心功能就是版本隔离。进入「版本」页面，你会看到所有已安装的 Minecraft 版本，每个版本都有独立的隔离工作区。隔离的价值在于：

- **版本独立**：正式版和预览版各用各的资源包和行为包，互不干扰。预览版里装的测试 Mod 不会跑到正式版里
- **数据不串**：每个版本的世界存档、截图、服务器列表都存在自己的隔离目录里
- **可移植**：整个隔离工作区可以直接复制到另一台电脑，不需要重新配置

创建新版本隔离的操作也很简单：在版本详情页点「创建隔离」，选择存放路径即可。建议路径选在非系统盘，且给每个版本起个好认的名字，比如「1.21正式版主档」「1.22预览测试」。

### 资源包管理

资源包（Resource Pack）是改变游戏视觉风格的关键——方块贴图、物品图标、UI 界面、字体、音效都能改，但不影响游戏逻辑。LeviLauncher 对资源包的支持非常直观，这也是内容工具箱里使用率最高的功能之一。

导入方式有两种：

- **拖拽导入**：打开「内容 → 资源包」，把 `.zip` 或 `.mcpack` 格式的文件直接拖进窗口就行，启动器会自动识别格式和内部元数据
- **文件选择导入**：点页面上的「导入」按钮，手动选择本地文件

导入后的资源包默认是**未启用**状态，需要在列表里勾选复选框才会在下次进入游戏时生效。多个资源包同时启用时，排在上面的优先级更高——如果两个包都改了同一个方块的贴图，上面那个生效。拖动列表条目就能调整优先级顺序。

> [!TIP]
> 资源包都有版本兼容性标记。导入时启动器会提示完全兼容、部分兼容或不兼容。不兼容的包不会阻止你启用，但进游戏后可能出现黑色方块或贴图丢失，建议严格按提示选择。

资源包的常见来源包括 Bedrock 内置的 Marketplace、GitHub 搜索「minecraft bedrock resource pack」、以及 MCBEDROCK.net、CurseForge 等第三方资源站。

### 一键打开文件夹

Bedrock 的文件目录藏得非常深，默认隔离工作区可能在你自定义的任意路径，未隔离版本则在 `%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState`，而且 AppData 默认是隐藏文件夹。

LeviLauncher 几乎在所有内容管理页面都提供「打开文件夹」按钮：

- 世界页面选中世界 → 打开该世界的实际目录
- 资源包页面 → 打开当前版本隔离工作区的资源包目录
- 行为包、皮肤包、截图、服务器列表页面同理
- 设置 → 路径与存储 → 打开托管根目录和各版本隔离目录
- 版本详情页 → 打开版本隔离工作区根目录

打开文件管理器后你可以直接复制隔离工作区到另一块硬盘做备份、手动导入下载的资源包、或者清理启动器没删干净的残留文件。

> [!WARNING]
> 在打开的目录里操作时，不要删除游戏本体文件（那些由 Microsoft Store 管理），也不要随便改 `level.dat`——除非你非常确定自己在做什么。LeviLauncher 有专门的世界工具页面处理 level.dat 编辑。

### 隐私设置

进入「设置 → 隐私」分区，可以控制匿名使用数据收集（analytics）的开关。analytics 收集的是启动器功能使用频率、崩溃统计、操作系统和启动器版本等基本设备信息，**不收集** Microsoft 账号信息、游戏内行为、隔离工作区文件内容或个人身份信息。

如果你在意隐私可以直接关掉——关掉 analytics 不影响版本管理、内容工具箱等任何核心功能。但要注意，版本更新检查、Bedrock 版本下载、CurseForge 浏览、Microsoft Store 授权验证这些功能本身需要和外部服务通信，这和 analytics 是两回事，关掉 analytics 不影响它们正常工作。

LeviLauncher 的所有配置、隔离工作区、日志文件都保存在本地机器上，不会自动上传到云端。备份迁移时手动复制 `%APPDATA%\levilauncher.exe\` 和你的托管根目录即可。

### 典型使用场景

**测试党场景**：每次 Minecraft 发布预览版，在版本页面创建一个隔离工作区，把预览版单独放在里面。装新 Mod、测试新命令，玩完想删直接删除整个隔离目录，正式版主存档毫发无损。

**Mod 爱好者场景**：装了十多个行为包，用隔离版本逐个测试——每个候选组合建一个独立隔离，找到稳定的那套后把配置复制到主隔离，冲突再也不用逐个排查。

**迁移党场景**：换电脑或换硬盘，旧机器上 LeviLauncher 的托管根目录直接整块复制到新机器，安装启动器后指向这个目录，所有版本、资源包、世界存档原样可用，半小时搞定迁移。
