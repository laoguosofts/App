## ✨ Drawpile 是什么

Drawpile 是一款面向多人实时协作的自由绘画工具——简单说，就是一张"大家一起画的画布"。它的核心卖点不在单机创作功能有多强，而在**多用户同时连线、各自独立落笔、实时看到彼此笔触**这种共享画布体验。

软件本身是跨平台的（Windows、macOS、Linux 都有官方构建），底层用 C++ 编写、基于 Qt 框架，界面轻量、启动快，对硬件要求很低——哪怕是几年前的老笔记本也能流畅跑起来。画笔画刷引擎兼容 MyPaint 标准笔刷，意味着网上能找到的大量 MyPaint 笔刷资源可以直接导入使用。

Drawpile 的使用场景比较清晰：插画师之间的头脑风暴、朋友一起撸一张同人图、教学演示时边画边讲、甚至作为简单的逐帧动画工具。单机模式也能用，但价值主要在协作——单独画的话 Krita、Photoshop 这些专业工具功能更全。

除了基础绘画，2.3.x 版本引入了**时间轴与洋葱皮**功能，支持逐帧动画制作；图层面板支持多层级混合模式、权限锁定、固定图层等进阶特性；橡皮擦系统也比一般绘画软件更灵活。这些功能叠加起来，让 Drawpile 不只是一个"多人画板"，而是一个能支撑完整小型创作流水线的协作绘画平台。

## 🔧 Windows 安装方式全解

Drawpile 在 Windows 上提供**两种分发形式**，选哪种取决于你的使用场景：

### MSI 安装器 vs 便携版 ZIP

| 对比项 | MSI 安装器 | 便携版 ZIP |
|---|---|---|
| 安装方式 | 双击运行向导 | 解压到任意文件夹 |
| 写入注册表 | ✅ 是 | ❌ 否 |
| 默认路径 | C:\Program Files\Drawpile\ | 自选（建议 D:\Apps\Drawpile\） |
| 协议关联 | 自动注册 drawpile:// | 需手动或不关联 |
| 文件关联 | 自动关联 .dpcs/.dppr/.ora | 不关联 |
| 卸载方式 | 控制面板或开始菜单 | 直接删文件夹 |
| 适合人群 | 日常使用、想省心 | U 盘携带、无管理员权限、绿色软件爱好者 |

### MSI 安装器步骤

1. 双击 `.msi` 文件，Windows 可能弹出 SmartScreen 提示——点"更多信息" → "仍要运行"
2. 选择安装路径（默认即可），点下一步
3. 安装完成后，开始菜单和桌面会出现 Drawpile 快捷方式
4. 首次启动会弹出语言选择向导，选简体中文即可

### 便携版 ZIP 步骤

1. 把压缩包解压到目标目录（**不要放 U 盘根目录**，也不要放系统受保护目录如 C:\）
2. 双击 `drawpile.exe` 直接启动
3. 想升级新版本时，直接覆盖旧文件就行，配置不会丢

> [!WARNING] 运行报错 "VCRUNTIME140.dll not found"
>
> 这是系统缺少 Visual C++ Redistributable Runtime 导致的。去微软官网下载安装 VC 运行库（x64 电脑装 `vc_redist.x64.exe`），装完重启 Drawpile 即可。

### 版本兼容与多版本并存

Drawpile 官方支持 Windows 7 到 Windows 11 全系列。如果你想同时跑稳定版和测试版：

1. 先装好稳定版
2. 把测试版 ZIP 解压到另一个文件夹（比如 `D:\Apps\Drawpile-beta\`）
3. 从 beta 文件夹的 `drawpile.exe` 直接启动——两个版本互不干扰，甚至可以同时运行

下载页底部的 Extras 区还有 Windows on ARM 版本（适合 Surface 等 ARM 架构设备）、32 位版本（老电脑/虚拟机）、独立服务器程序和命令行工具，按需取用。

## 📖 核心功能与使用技巧

### 图层：协作的骨架

打开 View → Docks → Layers 就能看到图层面板。Drawpile 的图层和 Photoshop/Krita 类似，但有几个**协作场景特化的设计**值得注意：

多人会话中，每个图层旁边会显示**创建者用户名**——谁画的线稿、谁上的底色，一眼就能看清。图层名会被实时同步给所有人，所以建议起有意义的名字，比如"草稿""线稿""皮肤""头发"，而不是 Layer 8、Layer 9。

图层的基础操作也有协作特色：

- **锁定图层**（点图层名左边的小锁）——任何人（包括创建者自己）都不能修改内容，但可以调整位置和可见性。多人会话里用它保护关键图层，比如线稿层不被误改
- **权限锁定（ACL）**——房主专属权限，可以精确设置某个图层只允许哪些用户/权限组修改
- **合并向下**——选中后与下方图层合并，多人会话中合并操作会同步给所有人，**不可撤销**
- **复制图层**——Ctrl+Shift+D，复制出的图层自动带"副本"后缀，位置在原图层上方

2.3.x 还引入了 **Fixed Layer（固定图层）**——标记后在动画翻页预览和导出中自动跳过，平时正常显示。用来放标题、UI 元素、固定装饰这类不参与动画帧的内容特别方便。

图层的混合模式非常丰富：Normal、Multiply、Screen、Overlay、Difference、Add、Subtract、Divide、Lighten、Darken、Color、Hue、Saturation、Luminosity、Recolor、Erase、Behind——覆盖了从基础叠色到特殊效果的全部需求。Opacity 滑块支持 0% 到 100% 的精细调节，用来降低底色浓度或让叠层更柔和。

> [!TIP] 图层名里加颜色标记
>
> Drawpile 2.3.0 起支持在图层名里用 `#RRGGBB` 格式加颜色标记，比如 `#FFD1DC! 皮肤底色`，图层列表里会显示一个粉色小标记。多人协作时这个小功能能帮大家快速识别图层用途，省很多沟通成本。

### 橡皮擦：三种方式灵活切换

Drawpile 的橡皮擦不是一支单独的笔，而是**三种擦除机制**，从简单到进阶：

**方式一：Erase Mode 开关**——在 Brush Settings 里点 Erase Mode，当前使用的画笔立即变成橡皮擦。关掉开关就回到正常画笔。这是最方便的方式：先用压感笔、柔边笔涂上色，然后直接切到擦除模式擦淡局部，不用换笔。而且 Erase Mode 不改变笔触形状和引擎——所以你可以有"压力越大擦得越干净的柔边橡皮""方块形的像素橡皮"。

**方式二：专门的橡皮擦槽位**——Brush Slots 的最后一个槽位默认就是橡皮擦，按数字键直接切换。如果你喜欢把橡皮擦调成固定风格（比如边缘羽化、硬度 60 的柔边橡皮），就在这个槽位里调好，每次按快捷键切过去。

**方式三：Erase 混合模式**——在 Blend Mode 里选 Erase，效果和 Erase Mode 相同，但它是独立的混合模式，选中后一直生效直到你手动切回来。和 Erase Mode 开关的区别就在这里：开关关掉自动回到之前模式，混合模式不会。

#### 橡皮擦与 Alpha 锁定

擦除的本质是把像素 Alpha 值设为 0——让那部分变透明。但有一个关键前提：

**图层启用了 Alpha Lock 时，橡皮擦只会让不透明区域更透明，不会擦穿**。擦到底还是会被锁定区域挡住。这在插画中特别有用：给上色层开 Alpha Lock，然后在上面擦，只会擦淡、不会擦出"洞"来。反过来，没开 Alpha Lock 的话，橡皮擦会把像素直接擦没。

#### 实用技巧速查

- **柔边橡皮 + 低不透明度**做渐变过渡——阴影边缘想柔和一点，不用重新上色，调低 Opacity 慢慢擦淡就行
- **硬边橡皮 + Spacing 100% + Hardness 100%**——像素画修正边缘，擦完就是纯净透明像素
- **Erase 混合模式 + Alpha 保留**——擦除只作用于下笔位置，不影响画布已有其他颜色
- **多人会话擦错了**——房主可以用 Force Undo 把别人的擦除操作回滚，比让对方手动重画方便

### 洋葱皮与逐帧动画

2.3.x 版本加入的时间轴功能让 Drawpile 不只是绘画工具，还能做简单的逐帧动画。**洋葱皮（Onion Skin）**是逐帧绘制时最核心的辅助功能——灵感来自传统动画师把多张赛璐璐薄片叠在灯箱上的工作方式，在数字空间里把前几帧和后几帧半透明叠加在当前帧上，帮助把握动作连贯度。

#### 启用与参数

在时间轴 Dock 上找到洋葱皮图标（两层叠纸的样子），点击开关启用。展开设置面板可以调三个核心参数：

- **Previous Frames（前向帧数）**——在当前帧前方（已绘好的历史帧）叠加几帧，默认 3-5。数字越大历史轨迹越多，但画面越乱
- **Next Frames（后向帧数）**——在当前帧后方（尚未绘制的帧）叠加几帧，默认 1-2，用来"预演"即将要画的动作终点
- **Opacity（不透明度）**——洋葱皮图层的不透明度，默认 20-30%。前向可以稍高（参考价值大），后向可以稍低（只是预演）

#### 逐帧绘制典型流程

以画一个角色走路循环为例：

1. 先画好关键帧 1（左脚在前）、关键帧 5（右脚在前）、关键帧 9（左脚在前，循环点）
2. 开启洋葱皮：前向 4 帧、后向 4 帧、Opacity 25%
3. 在帧 2 落笔——洋葱皮同时显示帧 1 和帧 3（即将要画的终点），动作过渡自然
4. 在帧 3 落笔——洋葱皮显示帧 1、2、4，连贯推进
5. 全部中间帧画完后，关掉洋葱皮用 Flipbook（翻页预览）连续播放看实际效果

> [!NOTE] 多人协作中的洋葱皮
>
> Drawpile 里洋葱皮是**客户端本地功能**——你自己的设置只影响你的画面，不会同步给其他人。A 可能开前向 3 帧，B 可能开前向 5 帧，各自独立互不干扰。

#### 常见问题排查

- **洋葱皮不显示？** 检查三点：有没有切换到帧视图、轨道有没有被 Move Lock 锁住、前向/后向帧数是不是设了 0
- **画面太乱？** 降低前向/后向帧数到 2-3，或者降低 Opacity；也可以关掉后向帧（Next Frames 设 0）只看历史轨迹
