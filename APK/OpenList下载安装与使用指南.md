## ✨ OpenList 是什么

OpenList 是一个开源的文件聚合服务，把百度网盘、阿里云盘、OneDrive、Google Drive、Terabox 等十几家国内外网盘统一挂载到一个界面下管理。它最早由社区开发者从 AList fork 出来，在驱动数量、协议服务和安全加固上持续迭代，现在已经成为跨盘聚合领域生态最活跃的项目之一。

核心能力说三件事就够了：**统一入口**——所有存储在同一文件树里浏览、搜索、下载；**多协议输出**——内置 WebDAV、FTP、SFTP、HTTP 直链，播放器、笔记软件、挂载工具都能接；**轻量部署**——单二进制文件，不依赖数据库，128MB 内存就能跑起来。

适合谁用？家里有 NAS 或小服务器想把几块网盘合并成一个文件库的；想在电视上看网盘电影的；需要把海外盘和国内盘做跨地域互备的——这些场景 OpenList 都能覆盖，而且比每家网盘单独装客户端省内存、省维护。

## 🔧 安装与部署路线选择

OpenList 不止一种安装形态，选错了会绕弯路。先看一张对照表，再决定你走哪条路。

| 形态 | 运行平台 | 适合谁 | 上手难度 |
| --- | --- | --- | --- |
| 核心版（单二进制） | Windows / Linux / macOS / NAS / 路由器 | 追求最小资源占用、熟悉命令行 | 低到中 |
| 核心版（Docker） | 有 Docker 的服务器或 NAS | 好升级、好备份、和其他容器搭配 | 中 |
| 桌面版 | Windows 10+ / macOS 10.15+ / Linux | 只想在个人电脑上用图形界面操作 | 最低 |
| Workers 版 | Cloudflare Workers / EdgeOne / 阿里云 ESA | 不想维护服务器、要免运维边缘部署 | 中 |
| 移动版 | Android / iOS | 把手机当临时文件服务器分享给别人 | 低 |

> [!TIP] 选型速查
> 自己电脑上挂几个网盘用图形界面 → 桌面版；家里有 NAS 或常开的小服务器 → Docker 或一键脚本装核心版；没有服务器也不想买 → Workers 版；手机相册或下载目录临时分享 → 移动版；群晖 NAS 用户 → 社区 SynoCommunity 套件包，TrueNAS、1Panel 也有应用商店入口。

核心版单二进制安装最简洁——下载对应平台的可执行文件、解压、运行即可，默认监听端口 5244。Docker 部署稍复杂一点，但后续升级、备份、和其他容器（比如 MediaWiki、PhotoPrism）联动都更方便。Workers 版把程序丢到 Cloudflare 的边缘节点上跑，免费额度够轻度使用，但存储挂载能力受 Workers 运行时的限制。

> [!WARNING] 版本核对
> 下载后务必核对文件大小和 SHA256 校验值，避免中间人攻击或下载不完整。官方下载页会同时列出各平台的校验和。

## 📖 使用入门：从挂载第一块盘到对外服务

装完之后打开浏览器访问 `http://你的IP:5244`，默认管理员账号是 `admin` / `123456`，**登录后立刻改密码**。接下来按顺序走三个核心环节。

### 第一步：添加存储驱动

后台进「存储」页面，点「添加」。驱动列表里有几十种网盘和存储，选你手头有的。每种驱动的配置项不同，但大体可以分成两类：

**国内网盘**（百度、阿里、夸克、115 等）多数走 Cookie 或手机号登录，按驱动文档把浏览器登录态的 Cookie 复制过来，填进配置项就行。Cookie 会过期，OpenList 有自动刷新机制，只要别手动登出网盘账号通常能维持半年以上。

**海外网盘**（OneDrive、Google Drive）走 OAuth 授权，比 Cookie 稳定得多。OneDrive 要注意区域选择：全球版、世纪互联（CN）、德国、美国各有对应驱动，选错区域授权必然失败。从 AList 迁移过来的用户建议先去微软账号页解除旧应用授权再重新操作，避免令牌混乱。Google Drive 则需要在谷歌云控制台完成应用配置，团队共享盘还要单独设置根目录 ID。

> [!NOTE] 海外驱动的网络前提
> 搭建机的网络环境决定成败。OneDrive、Google Drive 的接口在国内网络下多数不可直连，部署在海外 VPS 上通常开箱即用；国内机器挂载前必须先解决代理中转，否则文件列表都会超时。反过来，Terabox 等部分海外盘限制海外 IP 之外的区域访问，方向别搞反。

驱动配置填完保存，OpenList 会自动尝试列出根目录文件——能看到文件列表就是挂载成功。

### 第二步：文件操作与跨盘复制

文件树里所有存储统一展示在一个目录下，搜索栏支持跨盘全文检索。下载、预览、在线播放是标配，视频文件支持 HLS 切片流式播放，不用等整个文件下载完。

跨盘复制是高频场景：比如把阿里云盘的备份同步到 OneDrive 做跨境互备。进文件列表选中源文件、点「复制」，切到目标存储的目录点「粘贴」，OpenList 在后端走 HTTP 流转发，**文件不经过你本地**，纯服务器到服务器直传。

### 第三步：对外服务——WebDAV 与安全加固

挂好存储、验证文件能正常访问之后，就可以给其他设备提供服务了。WebDAV 是最常用的协议，电视播放器、手机文件管理器、电脑挂载工具（比如 Rclone）都能连。

连接参数很简单：地址填你的 OpenList 域名加 `/dav` 路径，端口和网页端一致（默认 5244），用户名密码就是你登录 OpenList 的账号。但有个常见坑——WebDAV 权限是两级开关：

1. **WebDAV 读取**：只看、只播文件，播放器用户勾这一个就够
2. **WebDAV 管理**：写入操作（改名、删除、上传）需要它，**而且还要同时勾上对应的具体文件系统权限**——只勾 WebDAV 管理不勾具体权限位，写入照样失败

排查「WebDAV 能看不能写」时先回来看权限位，九成是这里漏勾。

管理员账号是整站的钥匙，强烈建议开启双因素验证（2FA）。手机装一个支持 TOTP 的验证器（Google Authenticator、Microsoft Authenticator 都行），登录后台进「个人资料」页点「启用 2FA」，扫二维码、填验证器当前显示的 6 位动态码就生效。开启后该账号每次登录都要附动态码，密码泄露也进不来。

万一管理员自己忘了 2FA 也有后门：在服务器上用命令行 `openlist cancel2fa` 清除验证器绑定，重启即生效。这也是为什么建议保留服务器 SSH 访问能力——2FA 锁死时它是唯一的恢复通道。
