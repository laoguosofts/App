## ✨ JHenTai 是什么

JHenTai 是一款开源的第三方 E-Hentai 客户端，专为安卓设备设计，用来在移动端浏览、搜索、下载和管理 E-Hentai 画廊内容。它提供了官方网页端不具备的离线阅读、批量下载、本地图库管理等实用功能，在 EH 用户圈子里积累了稳定的口碑。

核心能力包括：画廊浏览与搜索、多模式阅读、上传者关注与更新通知、标签投票与隐藏、下载分组管理、配置导出导入、本地图库离线管理等。

适合谁用：经常逛 E-Hentai 社区、希望在手机上获得比网页端更顺滑阅读体验的用户；有离线阅读需求、想把喜欢的画廊下载到本地长期保存的用户；对界面自由度、下载并发、代理配置等有个性化需求的高级用户。

## 🔧 安装步骤

### 安卓设备安装

1. 从下载页获取最新 APK 文件，保存到手机本地
2. 打开文件管理器，找到下载的 APK
3. 首次安装需在系统设置中开启「允许安装未知来源应用」或「允许此来源安装」权限
4. 点击「安装」→ 等待完成 → 打开应用

> [!WARNING]
> 安装过程中如遇杀毒软件误报拦截，通常属于 Android 第三方 APK 的常见现象，确认来源可信后可选择继续安装。不要随意从不知名渠道下载修改版 APK。

### 基础配置：登录与网络

安装完成后首次打开，建议先完成以下几项基础设置：

1. **登录 EH 账号**：支持密码登录、Cookie 登录、WebView 登录三种方式。登录后才能使用标签投票、上传者关注、收藏夹同步等社区功能。匿名访客也能浏览画廊，但功能受限。
2. **网络与代理**：根据自身网络环境配置代理参数，或开启 Domain Fronting 绕过部分地区的访问限制。设置 → 网络 中可调整超时时间与重试次数。
3. **EH 站点切换**：设置 → EH 中选择你常用的站点入口。

## 📖 功能与使用入门

### 画廊浏览与已关注更新

进入应用后，底部 Tab 栏包含画廊列表、搜索、已关注上传者、阅读历史、设置几个主要入口。

**已关注上传者（Watched）** 是追更新最方便的功能——在画廊详情页点击上传者昵称进入主页，点击「关注」按钮即可订阅。被关注的上传者发布新画廊时，已关注 Tab 会按发布时间倒序自动显示所有更新条目，不用每天手动刷各个上传者主页。关注状态与 EH 网页端同步。如果已关注 Tab 为空，要么你还没关注任何人，要么关注的上传者近期没有新作品发布。

**阅读历史（History）** 是 JHenTai 在本地自动维护的浏览记录——只要在应用内打开过某个画廊，不管有没有读完都会自动记录。它的价值在于：找回前几天偶然点开但忘了收藏的画廊、追踪自己的阅读趋势、清理重复阅读。历史记录保留时长可以在设置里调整（默认 30 天，最长不限），也可以配置进入阅读页是否自动清空历史以保护隐私。如果开启了应用加密与模糊切换，应用退到后台时历史记录不会被系统最近任务预览看到。

### 标签投票与隐藏管理

JHenTai 在画廊详情页的标签区域提供了 EH 社区的三项互动操作：**赞成（+1）**、**反对（-1）**、**隐藏（X）**。长按任意标签即可弹出操作菜单。

- **赞成** 表示标签描述准确，给它加一个赞成票
- **反对** 表示标签不准确或不应出现在这里，给它加一个反对票
- **隐藏** 表示你个人不想再看到这个标签——效果是全局性的，所有画廊详情页不再显示该标签、搜索时自动从结果中排除含有该标签的画廊、快速搜索建议里也不会出现

v8.0.14 版本新增了**投票撤销**功能：长按标签弹出的菜单底部会显示你当前的投票状态，点击「撤销投票」即可取消误投。所有投票与隐藏操作都需要登录 EH 账号，且实时同步到 EH 服务器。

社区层面，大量用户的投票数据会影响标签在画廊详情页的排序——高频赞成的标签排前面，高频反对的会被自动降权甚至移除，间接改善所有用户的浏览体验。

### 本地图库：离线阅读与管理

本地图库（Local Gallery）是一个独立的 Tab，专门展示设备本地存储的画廊内容。它和在线画廊的关键区别：

| 对比项 | 在线画廊 | 本地图库 |
| --- | --- | --- |
| 网络依赖 | 需要 | 不需要，纯离线可用 |
| 账号依赖 | 需要 Cookie | 不需要 Cookie |
| 社区元数据 | 有标签、评分、评论 | 无，只有文件名和图片 |
| 存储位置 | 服务器 | 设备本地 |

**导入方式**有三种：选择本地文件夹路径（目录里每个子文件夹被视为一本画廊，子文件夹名即画廊标题）、选择单个 ZIP/CBZ 压缩包、直接扫描下载目录自动导入。

**支持格式**方面，文件夹形式的图片目录直接识别；ZIP 和 CBZ 内置解压支持；RAR 和 CBR 需要系统预装 7z 或 unrar 才能解压。

每个本地画廊卡片支持的管理操作：长按卡片 → 打开阅读、移动到分组、重命名、导出到其他目录、删除（可选保留源文件）、重新扫描（画廊内容更新后用）。

本地图库还能按**下载分组**过滤，让下载、归档、阅读三个环节的路径保持一致。设置 → 下载 → 存储 中可以查看总空间占用、按分组查看空间分布、一键清理长期未阅读的画廊。

### 配置导出导入：换设备与备份

JHenTai 支持把几乎所有设置和数据导出成一个带时间戳的 JSON 文件，用于新设备迁移或版本更新前的防丢失备份。导出内容包括：账号信息（Cookie、登录方式）、收藏设置（隐藏标签、投票结果、收藏夹关联）、下载设置（分组列表、并发数、存储路径）、搜索历史、安全设置（加密开关、解锁方式）、阅读设置（默认模式、快捷键）、网络设置（代理、超时）、EH 站点切换配置。

**导出步骤**：设置 → 数据 → 导出配置 → 选择保存位置（建议选外部存储或网盘，不要放在 JHenTai 内部目录）→ 等待生成完成。

**导入步骤**：新设备（或重装后）安装 JHenTai → 设置 → 数据 → 导入配置 → 选择之前导出的 JSON → 确认导入范围（可全选或只选部分数据类型）→ 导入完成后重启应用。

> [!NOTE]
> 导入是「合并」操作，不会清除当前设备已有数据。但要注意：JSON 文件里的 Cookie 如果已过期，导入后需要重新登录；下载路径等在新设备上可能不存在，导入后要检查下载设置；某些设备特定的配置（如 Android 指纹解锁）在其他平台导入后会被自动跳过。

导出的 JSON 包含你的账号 Cookie——它能直接访问你的 EH 账号，**绝对不要分享给任何人**。

**建议的备份时机**：换设备迁移前、每月定期（文件存网盘）、版本大更新前（防止数据库 schema 变更导致数据丢失）、调试排障前（备份好再清理数据，方便恢复）。
