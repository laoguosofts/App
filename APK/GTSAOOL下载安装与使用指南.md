## ✨ GTSAOOL 是什么——安卓 GTA 玩家的 MOD 管家

GTSAOOL 是一款专为安卓平台 GTA 圣安地列斯玩家设计的整合管理工具。它把原本散落在各个论坛网盘上的 CLEO 脚本、车辆模型、人物皮肤、地图补丁，统一收进一个界面里，让用户可以直接浏览、下载、解压、启用，而不用自己去找文件、算 GPU 格式、折腾文件夹结构。

核心功能集中在五个功能页：圣安地列斯页负责整合包与脚本管理，圣安地列斯2页负责车辆与人物模型替换，罪恶都市页服务另一批玩家，联机功能页提供服务器联机入口，而最有用的大概是左上角那个三点菜单——闪退排查、一键关闭脚本、GPU 格式修正这些高阶操作，全藏在里面。

如果你是第一次接触 GTA MOD，GTSAOOL 能帮你绕过 80% 的入门坑；如果你已经装过不少脚本，它的闪退排除和格式检测功能会让你省下大把排查时间。

## 🔧 安装步骤——安卓端的标准流程

GTSAOOL 是安卓 APK 格式，安装过程和普通第三方应用一致，但因为涉及游戏文件的读写权限，有几个关键点不能跳过。

### 准备工作

1. 确保手机上已经安装了 GTA 圣安地列斯安卓版原版 APK——GTSAOOL 是 MOD 管理器，它本身不包含游戏本体
2. 在手机设置中开启「允许安装未知来源应用」，路径通常是：**设置 → 安全 → 安装未知应用 → 找到你的浏览器或文件管理器 → 允许**
3. 预留至少 2GB 存储空间——GTSAOOL 下载的 MOD 和整合包会占用不少空间

### 安装流程

1. 从下载页拿到 GTSAOOL 的 APK 文件，用文件管理器点击安装
2. 首次启动时，GTSAOOL 会请求存储权限和通知权限，**全部允许**——拒绝存储权限会导致无法解压任何 MOD
3. 应用启动后会自动扫描手机上已安装的 GTA 游戏版本，确认游戏路径正确即完成初始化

> [!WARNING]
> 如果手机弹出「此应用可能有害」之类的警告，通常是安卓系统对第三方 APK 的标准提示——只要来源可信就可以继续安装。如果安装后 GTSAOOL 打不开或闪退，先检查是不是下载了不兼容的版本。

### 安装后的核对

启动后看几个点：左上角三点菜单是否能点开、圣安地列斯页是否列出了整合包列表、设置里能否识别到游戏路径。这三项都正常就说明安装成功。

## 📖 使用入门——从整合包到联机的完整上手

GTSAOOL 的功能很多，但日常用到的核心操作其实可以归为三类：装整合包替换内容、排查闪退故障、进入联机服务器。下面按这个顺序展开。

### 整合包与脚本管理

整合包是 GTSAOOL 最常见的使用场景。进入圣安地列斯页，就能看到社区整理好的各类整合包——从画质增强到任务拓展、从车辆替换到天气系统，按需下载即可。

下载后 GTSAOOL 会自动弹出 GPU 格式选择。这一步很关键：选对格式 MOD 才能正常渲染（不会花屏、不会模型纯白），选错了轻则贴图错乱、重则进游戏直接崩。推荐按手机 GPU 厂商对号入座：

| GPU 厂商 | 推荐格式 | 常见手机品牌 |
| --- | --- | --- |
| 高通 Adreno | DXT / S3TC | 小米、OPPO、一加、部分 vivo |
| ARM Mali | ETC2 | 联发科、华为荣耀、部分 vivo |
| Imagination PowerVR | PVRTC | 魅族、部分联发科 |

如果不确定具体型号，就逐一尝试——解压完成后启动 GTA 测试，能正常显示就说明选对了。切换格式后**必须完全重启 GTA** 才能生效。

### 闪退排查——两阶段处理法

装了多个 MOD 之后闪退几乎是必然的。GTSAOOL 左上角三点菜单里专门藏了排查工具：

1. **一键关闭所有 CLEO**——先把所有 `.csa` 和 `.csi` 脚本全部禁用，启动 GTA 看还崩不崩
2. 如果不崩了，说明是脚本冲突，逐个启用、逐个测试就能定位到罪魁祸首
3. 如果还是崩，再点「闪退排除」，GTSAOOL 会扫描模组文件，排除最可疑的候选项

> [!TIP]
> GPU 格式选错的典型症状：花屏（彩色条纹、碎片）、模型纯白（能显示但没纹理）、贴图错乱（拼图错位）、颜色偏暗。按症状对照重新解压换格式即可。

如果两个排查工具都没找到问题，再检查存储空间是否充足（少于 500MB 可能影响运行）、最近安装的整合包是否损坏、以及是否同时启用了两个可能冲突的大型模组。

### 人物与车辆替换

圣安地列斯2页专门管理模型替换。人物模型可以替换的范围很广：主角 CJ、帮派成员、警察和军人、路人 NPC，每类都可以单独换。车辆模型则覆盖原版 GTA 里出现的所有载具——跑车、卡车、飞机、船只都有对应的替换条目。

替换步骤统一：找到目标模型 → 导入 `.dff` + `.txd` 文件（带专属动画的话还有 `.ifp`）→ 选 GPU 格式解压 → 重启游戏。GTSAOOL 在解压时会自动备份原版文件，想恢复原版时长按条目选「恢复原版」或「删除」，重启游戏即可。

替换 CJ 时需要注意：模型尺寸极端会导致动画错位（四肢飞出、头身分离），骨骼结构差异大也会让跑步、射击等动作异常，面部贴图分辨率太低进游戏后脸会糊。选模型时尽量找经过实测兼容原版骨骼的。

### 联机功能

联机功能页打破了 GTA 手游只能单机的局限。通过这个页面，GTASA 玩家可以连接到全球的联机服务器，和其他玩家一起在圣安地列斯世界里互动。

页面提供三个入口：公开服务器列表（显示服务器名称、在线人数、延迟）、自己创建房间（设置密码邀请朋友）、加入朋友的私人房间（输入房间码）。联机的技术基础是 SAMP 或 MTA 这类开源联机框架的手机适配版。

> [!NOTE]
> 联机前的准备：确保网络稳定（建议 Wi-Fi 或 5G）、检查游戏版本是否匹配服务器要求、关闭本地启用的 CLEO 脚本（服务器反作弊机制会检测）、部分服务器需要先注册账号。
