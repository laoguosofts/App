## ✨ KKTIX 是什么

KKTIX 是台湾地区最大的活动票务平台之一，覆盖演唱会、音乐节、展览、讲座、体育赛事等各类活动。它既是一个面向购票者的找活动、买票、管电子票的工具，也是一个给活动主办者提供完整售票、签到、数据统计能力的 SaaS 平台。

对于购票者来说，KKTIX 的核心价值在于聚合了台湾几乎所有主流活动的门票资源——从五月天、周杰伦的演唱会，到独立乐团的小型演出、艺术展览、专业讲座，基本都能在这里找到。平台支持多语言界面（繁体中文、简体中文、英文、日文），付款方式灵活，电子票入场流程便捷。

对于主办者来说，KKTIX 提供了一套完整的活动运营工具：活动创建与票务设置、邀请码定向发码、现场扫码签到（通过独立的 Manager App）、实时入场数据、报名者信息管理等，而且主办者端的所有功能都是免费的。

KKTIX 的核心市场在台湾，同时在香港、新加坡、马来西亚、日本等地区也有活动上线。平台起源于 2012 年，经过十余年发展，已成为华语地区活动票务领域的头部玩家。

## 🔧 安装步骤与注意事项

### Android 安装

1. 打开 Google Play，搜索「KKTIX」，找到官方发行的应用
2. 点击「安装」→ 等待下载完成 → 自动安装
3. 如果从第三方渠道下载 APK 文件，首次安装需要在系统设置中允许「未知来源」应用安装
4. 安装完成后在桌面找到 KKTIX 图标，点击打开

### iOS 安装

1. 打开 App Store，搜索「KKTIX」
2. 确认开发者为 KKTIX 官方 → 点击「获取」
3. 使用 Face ID / Touch ID 验证 → 自动下载安装
4. 安装完成后在桌面找到图标，点击打开

> [!NOTE]
> 务必确认下载来源为官方应用商店或官网分发渠道，避免安装到仿冒应用。可以通过开发者名称、应用图标细节、下载量等信息交叉验证。

### 版本核对

安装完成后，打开 App → 进入「我的」或「设置」页面 → 查看「关于」或「版本信息」，确认版本号为最新版。旧版本可能存在付款流程兼容性问题，建议保持自动更新开启。

## 📖 使用入门：从找活动到入场全流程

### 找活动与浏览

打开 KKTIX App 或网站后，首页会按地区和时间展示近期热门活动。你可以通过以下方式筛选：

- **地区筛选**：切换到你关注的城市（台北、高雄、香港等）
- **活动类型**：演唱会 / 展览 / 讲座 / 体育赛事 / 音乐季
- **时间排序**：按即将开演、按最新上架、按热门程度
- **关键词搜索**：直接搜艺人名字、活动名称、场馆名

### 注册与登录

首次使用需要注册账号。支持邮箱注册和手机号注册两种方式。注册完成后登录，个人信息中可以添加常用购票者姓名（用于实名制活动）、常用付款方式等。

### 购票流程

选定活动后点击「立即购票」，进入核心购票流程：

1. **选择票种**：活动可能设置多种票种——VIP 票、一般票、学生票、身障优惠票等，不同票种价格和权益不同
2. **选择座位 / 区域**：需要选座的活动会进入座位图界面，点击想选的座位确认；不需要选座的活动直接进入下一步
3. **填写购票者信息**：实名制活动需要填写身份证号并进行验证，非实名制活动只需填写姓名和邮箱
4. **选择付款方式**：进入付款环节，系统会自动列出当前地区可用的付款方式
5. **完成付款**：付款成功后，电子票自动出现在「我的票券」中

### 付款方式详解

KKTIX 支持的付款渠道覆盖全球主要支付网络，不同地区可用的方式有差异：

| 付款方式 | 适用地区 | 特点 |
| --- | --- | --- |
| 信用卡（VISA / Master / JCB） | 全球通用 | 即时付款，最常用 |
| PayPal | 全球通用 | 需要有 PayPal 账号 |
| Apple Pay / Google Pay | 持对应设备 | 一键付款，抢票时最快 |
| ATM 虚拟账号 | 仅限台湾银行 | 线下转账，有时间限制 |
| 全家 FamiPort | 仅限台湾 | 7-Eleven 机台付款取票 |

**信用卡付款**是最推荐的方式，流程最顺畅：输入卡号（16 位）、有效期、卡背面末 3 码（CVC）→ 银行发送 3D 验证短信 → 输入验证码 → 付款完成。KKTIX 不向购票者收取额外的信用卡手续费，但非台湾地区银行的信用卡可能会被发卡行收取约 1.5% 的海外刷卡手续费。

> [!TIP]
> 抢热门票时，提前在 Apple Pay / Google Pay 中绑定好信用卡，付款时一键确认，可以节省填卡号的宝贵时间。

**ATM 虚拟账号**是台湾地区特有的线下付款方式：系统生成专属虚拟账号后，需要在限定时间内（通常 30-60 分钟）到台湾银行 ATM 转账，超时虚拟账号作废。转账后系统需要几分钟到十几分钟确认，不是即时到账。

### 语言与地区设置

KKTIX 界面支持四种语言：繁体中文（默认，适合台湾用户）、简体中文（适合大陆用户阅读）、English（国际活动常用）、日本語（日系艺人活动常用）。App 内可在「设置」中切换，网站右上角有语言下拉菜单。

不同地区的功能和费用也有差异：

- **台湾地区**：核心市场，特有全家 FamiPort 购票取票、文化币 / 成年礼金支付、身心障碍认证购票等
- **香港地区**：每张门票收取固定 HK$12 平台服务费，实名制活动普遍
- **其他地区**：东南亚和日本也有活动上线，但数量相对较少

### 电子票入场

付款成功后，电子票自动存入「我的票券」。入场时的流程：

1. 活动当天打开 KKTIX App → 进入「我的票券」
2. 找到对应活动的电子票 → 点击展开 QR Code
3. 工作人员扫码 → 验证通过 → 入场

如果手机没电或网络不好，可以提前将电子票截图保存到相册——QR Code 本身是离线可扫的，但需要确认活动是否允许截图入场（部分实名制活动可能要求实时验证）。

### 主办者侧功能（KKTIX Manager）

如果你是活动主办者或工作人员，还需要了解 KKTIX Manager——这是一个独立的 App，专门用于活动当天的扫码签到和现场管理：

| | KKTIX App | KKTIX Manager |
| --- | --- | --- |
| 给谁用 | 购票者 | 主办者 / 活动工作人员 |
| 主要功能 | 找活动、买票、管电子票 | 扫码签到、实时入场数据、多入口管理 |
| 价格 | 免费 | 所有功能免费 |

Manager App 的核心能力包括：

- **扫码签到**：工作人员持手机对准购票者 QR Code，自动识别并标记「已入场」，实时同步到所有入口
- **多套签到簿（Attendance Books）**：一个活动可能有多个入口（A、B、C），每个入口的工作人员各负责一套，不同入口扫的票实时同步，不会重复入场
- **实时入场人数 Dashboard**：显示已入场总数、各入口已入场数、剩余人数，活动现场可以看到实时容量百分比
- **报名者信息查询**：扫码后显示购票者姓名、票种、购买时间、Tag 标签、实名制验证状态

登录 Manager App 需要主办者账号或被授权的组织成员账号，主办者可以在 App 内邀请临时签到员加入。

> [!NOTE]
> KKTIX Manager 所有功能完全免费——扫码签到、实时同步、多签到簿、邀请工作人员，都不另外收费。这相比其他售票平台（有些验票功能是付费增值服务）是明显优势。

### 邀请码：给特定人群的专属入口

主办者在运营活动时，经常需要给媒体、VIP、讲者等特定人群发专属购票通道——这就是 KKTIX 的邀请码功能。创建邀请码时可以设置：

| 功能 | 说明 |
| --- | --- |
| 专属票种 | 只有输入邀请码才能看到的票种（如 VIP 专属票、媒体免费票） |
| 限量 | 这个邀请码对应的票最多能被 N 个人买 |
| 有效期 | 邀请码的生效时间段 |
| 自动贴标签 | 用这个邀请码报名的人自动贴指定 Tag |
| 一次性 / 多次性 | 一个人用了一次就失效，还是可以多人用 |

典型用法包括：

- **媒体邀请**：创建「媒体专属」邀请码 → 关联免费媒体票种 → 限量 50 张 → 自动贴 `media` 标签 → 发给媒体通讯录
- **讲者 / 嘉宾免费票**：创建「讲者专属」邀请码 → 关联免费票种 → 限量按讲者人数设置
- **VIP 优先购票**：创建「VIP 优先」邀请码 → 关联提前 24 小时开放的 VIP 票种 → 发给赞助商，让他们在公开开票前优先买票

### 常见问题与注意事项

**付款失败**的常见原因及排查：

- 信用卡余额不足或额度超限 → 换一张卡试试
- 3D 验证短信发不出 → 等 5 分钟重试，或换 Apple Pay / Google Pay
- 付款超时 → 整个购票流程有总时限（从选位到付款完成），超时订单会被释放，需要重新走流程
- ATM 转账时虚拟账号已过期 → 回到活动页重新生成

**实名制活动**需要提前准备好身份证信息，部分活动还要求现场核验身份证件。购票后如果需要修改购票者信息，在「我的票券」中找到对应票券 → 点击「修改购票者」即可（部分活动可能不支持修改，以活动说明为准）。
