## ✨ Feem 是什么

Feem 是一款主打**本地局域网文件直传**的跨平台工具，核心技术是 Wi-Fi Direct —— 设备之间直接建立点对点连接，完全不依赖互联网路由器、不经过任何云服务器。它同时支持 Android、iOS、Windows、macOS、Linux 和 Web 浏览器，覆盖了日常能碰到的几乎所有终端。

和 AirDrop 只在苹果生态内可用、微信要走云中转、Snapdrop 必须联网走公网信令不同，Feem 的设计目标很纯粹：**只要两台设备之间能搜到彼此，不管有没有外网，就能传文件**。大到几 GB 的视频压缩包，小到一张照片，全双工多线程同时收发，默认 TLS 加密，断点续传稳得住。

Feem 的免费版带广告但相对克制，付费版解锁自定义设备昵称、WebShare 自定义密码等进阶功能。日常使用免费版已经完全够用。

## 🔧 Feem 安装实操指南

Feem 的安装在各平台都不复杂，但有几个注意事项提前留意，可以少踩坑。

### Android 安装

1. 从 Google Play 搜索 Feem 直接安装，这是最稳妥的方式。
2. 如果用 APK 安装包，需要先在系统设置里找到「安全」或「应用管理」，开启**允许未知来源应用安装**。安装完成后建议把这个开关关掉，避免其他来源的应用被误装。
3. 安装完成后首次打开 Feem，系统会请求**位置权限**和**附近设备权限**——这两个权限是 Feem 发现同局域网其他设备的必要条件，必须全部允许。

### iOS 安装

1. App Store 搜索 Feem 直接安装。
2. 首次打开后，iOS 14 及以上版本会弹出「本地网络权限」请求，必须点**允许**。如果当时忘了开，之后在「设置 → Feem → 本地网络」里手动打开即可，否则 Feem 完全搜不到同局域网的其他设备。

### Windows 安装

1. 下载 `.exe` 安装包，双击运行。安装路径默认在 `C:\Program Files\Feem`，一般不需要改。
2. 安装过程中如果 Windows Defender 防火墙弹出「是否允许 Feem 通过防火墙」的提示，**必须勾选专用网络和公用网络都允许**，否则 Feem 的 UDP 广播会被拦截，其他设备搜不到这台电脑。

> [!WARNING]
> 部分杀毒软件（尤其是国内厂商的安全卫士）可能把 Feem 的 Wi-Fi Direct 热点创建行为误判为恶意软件。如果安装或运行时被拦截，建议将 Feem 加入杀毒软件的信任名单，或者暂时关闭实时防护再安装。这是 Feem 在部分地区用户反馈最多的安装阻碍。

### 安装核对

安装完成后首次打开 Feem，界面上应该能看到 Feem 自动分配的一个**随机动物昵称**（比如 "Happy Turtle" "Grumpy Squirrel"），以及当前设备连接的 Wi-Fi 名称。如果界面空白且没有报错，说明安装没问题，只是暂时没有其他 Feem 设备在同局域网内。

## 📖 Feem 使用入门

### 设备发现：怎么让两台设备互相看见

Feem 的设备发现是**完全自动**的，不需要配对码、不需要扫码。它用局域网 UDP 广播机制——每台运行 Feem 的设备大约每秒向 45001 端口广播一次自己的存在，同局域网内其他 Feem 设备收到后就会把它加入设备列表。

但自动发现有几个**前置条件**必须同时满足，少一个都搜不到对方：

1. **两台 Feem 都在前台运行**——后台或锁屏时，系统省电策略可能暂停网络活动，广播就发不出去了。安卓用户尤其注意，很多厂商的系统对后台 App 限制很严。
2. **两台设备在同一个 Wi-Fi 网络**——Feem 界面顶部会显示当前连接的 Wi-Fi 名称，核对两台设备显示的名称是否完全一致。常见坑：手机弱信号时自动切到同名但不同路由器的 Wi-Fi，或者连了访客网络（访客网络通常和主网络隔离）。
3. **防火墙没有拦截 45001 端口**——Windows Defender、macOS 应用防火墙、Linux UFW 都有可能拦截，弹出提示时点允许就行。
4. **关掉所有 VPN**——VPN 会修改系统路由表，Feem 的广播包发不出去也收不到。
5. **iOS 的本地网络权限已开**——前面安装部分提过，再强调一遍：iOS 没开这个权限，Feem 连广播都发不了。

全部满足后，打开 Feem 等 5~10 秒，设备列表里就会出现对方的昵称，点进去就能选文件开始传了。

> [!TIP]
> 如果全部条件都满足还是搜不到，可以启用 Feem 的 Wi-Fi Direct 模式——让其中一台设备创建热点，另一台连这个热点，直接绕开路由器，在设备之间建立点对点连接。这是解决搜不到问题的终极方案。

### 开始传输：多线程全双工是核心优势

选中对方设备进入传输界面后，Feem 的体验和 Xender/ShareIt 之类的竞品有明显区别：

- **全双工同时收发**——Feem 是多线程架构，可以同时给多台设备发、同时从多台设备收。其他工具大多是半双工，同一时刻要么发要么收。在会议室、项目启动会这类多人协作场景下，Feem 的效率优势会被迅速放大。
- **无文件大小限制**——微信超过 200MB 就开始限速，超过 1GB 基本放弃。Feem 对文件大小没有硬限制，实测稳定传输几 GB 的视频文件没问题。
- **断点续传**——大文件传输中途如果 Wi-Fi 抖动或设备临时休眠，恢复后可以原地续传，不用从头再来。这一点在传 4GB 以上的 RAW 视频、工程文件夹时特别重要。
- **TLS 加密**——传输链路全程加密，文件在本地网络内不可窃听。这一点是 Feem 相比同阵营竞品的安全优势，尤其适合隐私敏感场景（客户合同、医疗影像、涉密图纸等）。

### WebShare：对方没装 Feem 也能收

这是 Feem 独有的补充功能——接收方不需要安装任何 App，用浏览器就能收文件。

开启后，发送方的 Feem 会在本地启动一个 HTTPS 加密的临时 Web 服务器，生成一个 4~6 位的 PIN 码和一个本地访问地址。接收方在浏览器里输入这个地址、确认自签名证书的安全提示、输入 PIN 码，就能看到文件列表并下载。整个过程数据只在本地网络传输，不经过 Feem 任何服务器，PIN 码用完即失效。

WebShare 是 App 直连的补充方案而非替代品。如果接收方愿意装 Feem，App 直连的体验明显更好——速度更快、支持断点续传、不会因为浏览器崩溃导致下载中断。

> [!NOTE]
> 不要在公共场合（展会、会议室）长时间开启 WebShare。虽然 PIN 码有一定保护，但如果有人路过看到屏幕上的 PIN 码和地址，他也能连上你的 WebShare 页面下载文件。用完就关。

### Feem 适合哪些场景

总结一下 Feem 最能发挥优势的使用场景：

| 场景 | 为什么选 Feem |
| --- | --- |
| 跨平台混传 | 苹果、安卓、Windows、Linux 之间体验一致，AirDrop 只在苹果生态内可用 |
| 无互联网环境 | 工地、地下室、野外、展会——没 Wi-Fi 路由器也能传，云中转方案全部失效 |
| 传大文件 | 几 GB 的视频压缩包稳得住，微信/QQ 限速到怀疑人生 |
| 隐私敏感文件 | 不经过任何服务器，TLS 加密，律师事务所/医疗团队的合规场景 |
| 多人同时互传 | 会议室里同时向 10 台设备发资料，自己同时也收别人的补充文档 |
| 对方不想装 App | 用 WebShare 浏览器接收，不给客户/朋友添负担 |

### Feem 的边界：哪些场景不适合它

Feem 不是万能的，以下情况还是得用其他方案：

- **远程跨地域传文件**——Feem 只在同一个局域网工作，北京传到上海还是得靠云盘或 P2P。
- **苹果全家桶深度用户**——AirDrop 体验已经非常顺滑，跨设备接力也方便，Feem 的优势不明显。
- **需要在线协作编辑**——Feem 只负责传文件，不做云同步、不做在线编辑，这方面还是 Google Drive 或飞书文档合适。
