## ✨ AppShare 是什么

AppShare 是一款面向 Android 用户的应用资源分享社区工具。它把散落在各家网盘上的 APK 安装包集中整理、统一收录，用户可以按分类浏览、按关键词搜索想要的软件，找到后直接下载到本地安装。整个社区由审核员和管理员运营维护，上传者需要先申请权限，审核通过后才能贡献自己整理的资源。

除了最核心的"找软件、下软件"，AppShare 还提供了几个实用的周边功能：已安装应用的更新检测、积分签到与任务系统、个性化的资料页自定义，以及活跃的社区权限群——上传规则变更、社区活动、审核结果同步都会在权限群里第一时间通知。

适合三类用户：第一类是需要随时搜罗小众或冷门 Android 应用的玩家；第二类是手头有好东西想分享给别人的上传者；第三类是想为社区做点事、申请审核或管理员岗位的活跃用户。对普通用户来说，不登录也能浏览和下载，只是少了积分、签到和更新记录这些个性化功能。

## 🔧 安装步骤

AppShare 是 Android 应用，安装流程和普通 APK 一样，但几个平台特性值得注意。

### 下载前的核对

下载时留意两点：

1. **文件大小**——不同版本体积可能差不少，拿到安装包先看一眼大小是否在合理范围，避免下载残缺文件。
2. **版本号**——如果下载页标注了版本，装完后在「我的」页面底部设置里对照一下版本信息，确保装的是自己想要的那一份。

> [!TIP]
> 安装包下载不完整会导致"解析包错误"——这是高频原因，不是手机坏了。回网盘重新下载一遍再试，反复出错就检查一下自己的安卓版本是否过旧。

### 未知来源授权

Android 系统默认不允许安装应用商店以外的 APK。安装 AppShare 时，如果系统弹了"禁止安装未知来源应用"，按以下路径放行：

1. 打开系统设置 → **安全** 或 **应用管理**
2. 找到 **未知来源** 或 **允许安装未知应用** 选项
3. 给你用来下载 APK 的那个文件管理器或浏览器勾上权限

> [!WARNING]
> 小米 / Redmi 手机还有一道额外门槛叫"纯净模式"，会额外拦截第三方 APK。路径是：**设置 → 安全 → 纯净模式 → 暂时关闭**，装完可以再打开，不影响 AppShare 正常使用。

### 装完之后的首次配置

第一次打开 AppShare，建议先做两件事：

- 允许 **查询所有已安装应用** 权限——不授权的话更新检测功能会失效，更新列表直接为空。Android 13 / 14 上这个权限默认是拒绝的，需要手动到系统设置里给 AppShare 打开。
- 如果想从蓝奏云之类的第三方网盘走 AppShare 内置下载，记得给 AppShare **剪贴板读取权限**——关闭直链解析时提取码会自动复制到剪贴板。

## 📖 日常使用指南

### 个人资料页自定义

登录后，AppShare 允许你把社区主页打扮成自己的风格。从「我的」页面点头像进入个人主页，点「编辑资料」就能调整：

| 字段 | 作用 |
|---|---|
| 用户名 | 社区里显示的名字 |
| 头像 | 点击编辑资料后更换 |
| 背景图 | 主页顶部的大背景图，从相册选 |
| 个人简介 | 简短的自我描述 |
| 兴趣标签 | 自定义标签，方便同好找到你 |

> [!NOTE]
> 积分和等级越高，你的资料页在社区广场里越靠前，曝光机会也越大。

### 每日签到与积分系统

登录 AppShare 后，「我的」页面顶部有个签到按钮，点开领当天的积分。规则很简单：

- 自然日重置，零点后可以签新的一天
- 连续签到会有额外奖励（具体以 AppShare 实际显示为准）
- 签到后积分实时到账

不签到不影响核心功能——分类浏览、搜索、下载、更新检测全都能用。积分只是换点小福利的额外渠道。重复下载同一条资源也不扣积分，AppShare 会自动记录下载历史避免重复扣费。

### 社区权限群与上传规则

上传者是 AppShare 社区的核心贡献者。想成为上传者，需要：

1. 登录后点头像 → **申请上传权限**
2. 审核通过后，系统会引导加入 **用户权限群**

权限群是社区的信息枢纽，主要用来同步：

- 上传规则变更
- 社区活动和积分奖励活动
- 你的上传审核结果（通过还是驳回）
- 审核员 / 管理员招募通知

AppShare 的审核和管理岗位全部来自活跃用户。入门路径是：先成为有稳定上传记录、审核通过率高的活跃上传者 → 加入权限群 → 等下次招募 → 通过审核规则和内容判断标准的考核。招募是周期性的，不是随时开放。

### 设置页与版本通道

在「我的」页面滚动到底部，能找到设置页入口。这里集中了几个重要选项：

| 项目 | 说明 |
|---|---|
| 版本信息 | 当前 AppShare 版本号，对照下载页确认 |
| 更新通道 | 正式版 / 快速更新通道切换——内测版走快速通道，每次更新都是强制的；不想被强制更就切回正式版 |
| 开发者信息 | 邢台市牧歌信息技术有限公司 |
| 联系渠道 | 用户权限群入口 |

### 常见问题快速定位

下载加载中卡住？去设置里关闭直链解析，或者换一条下载线路。蓝奏云提示非会员不能下载？这是蓝奏云侧的限制，可以用桌面端 UA 访问蓝奏云分享页，或者走 AppShare 内置下载。内测版强制更新不想更？设置里关闭快速更新通道切回正式版。

如果遇到的问题不在上面，AppShare 应用内「我的」页面有"帮助反馈"入口，可以查看更多问题解答或直接提交反馈。
