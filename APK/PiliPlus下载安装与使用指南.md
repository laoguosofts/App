## ✨ PiliPlus 是什么

PiliPlus 是一款面向 B 站用户的第三方 Android 客户端，在官方 App 的基础上做了大量细节增强和体验优化。它保留了 B 站的核心生态——视频浏览、番剧追更、专栏、直播、社区互动——同时在播放器、界面主题、收藏管理、账号工具等方面提供了比官方客户端更灵活的配置项和更顺手的操作体验。

它的受众很明确：常年泡 B 站、对界面观感和操作细节有要求的重度用户。官方客户端覆盖不到的那些边角需求——比如想把默认画质固定在高码率、想在视频详情页直接选收藏夹、想切换暗色模式跟随系统——PiliPlus 都给了入口。项目本身是开源社区维护的，不以盈利为目的。

PiliPlus 支持多账号登录，收藏、历史、订阅等数据走站内官方接口，客户端里的操作和网页端、官方 App 是互通的，不会出现"这边改了那边没同步"的尴尬。对于同时管理工作号和生活号的用户来说，多账号快速切换是刚需功能。

## 🔧 Android 安装步骤

PiliPlus 目前仅提供 Android 版本，安装过程和普通 APK 类似，但有几个注意点值得提前了解。

**准备工作**：安装前请确认设备允许安装未知来源应用。不同品牌手机的入口位置稍有差异——小米在设置→安全→安装未知应用里找到浏览器或文件管理器并授权，华为和 OPPO 也有类似的权限开关。如果不提前开这个权限，安装包点开后会直接被系统拦截。

**安装流程**：

1. 从下载入口获取最新版 APK 文件，保存到手机本地
2. 点开 APK，系统会弹出安装提示，确认权限申请后点击安装
3. 等待安装完成，首次打开时建议授予存储和网络权限
4. 登录 B 站账号即可开始使用

> [!WARNING]
> 安装包请务必从下载入口提供的渠道获取，不要来源不明的第三方网盘。安装前核对文件大小和版本号，避免装到旧版或被二次打包的非正规版本。

**杀毒软件误报**：部分手机管家可能会把第三方客户端的 APK 标记为"风险应用"，这是 Android 生态对非市场分发应用的通用策略，不是 PiliPlus 本身有安全问题。在确认来源正规的前提下，选择"仍要安装"即可。

**版本核对**：首次打开后可以在设置→关于里看到版本号和构建日期，和下载页的最新版本对照一下，确保装的是当前版本。旧版本可能存在已修复的兼容性问题。

## 📖 使用入门：从界面到播放器的实用细节

### 主题外观：三种模式随你切换

PiliPlus 的主题系统比官方客户端灵活得多。设置里提供三种主题模式：

- **亮色模式**：白底清爽，白天或强光环境下的可读性最好
- **暗色模式**：深色界面，夜间躺在床上刷视频不刺眼，OLED 屏幕还能顺带省电
- **跟随系统**：跟随手机系统的深浅色自动切换，日落换暗色、日出换亮色，最省心的选择

除了模式切换，应用还内置了多种配色方案，不同版本的配色数量有所增加，以你手上版本的设置列表为准。部分版本甚至支持动态取色——让应用的主题色跟随壁纸或系统配色，观感更统一。字体大小也可以在全局范围内调整，对视力不太好的用户特别友好。

| 场景 | 推荐组合 |
| --- | --- |
| 夜间床上刷 | 暗色模式 + 低亮度 |
| 白天通勤 | 跟随系统 |
| 平板长时间观影 | 暗色 + 关闭多余动效 |

交互震动反馈默认开启，觉得太吵可以在设置里关掉，手感偏好因人而异。

### 播放器：画质、音质、解码三件事各管一摊

视频播放时，画质、音质、解码格式是三个独立的维度，都可以临时切换，也可以预设成全局默认。

**画质档位**从 360P 到 1080P 高码率、4K、HDR 等，能开到哪一档完全取决于视频源本身。高清档位中需要大会员权限的内容，使用大会员账号登录后即可观看。项目本身不提供任何权限破解，官方仓库也明确声明不提供破解内容——高清能力完全依赖你自己的账号。网络不稳的时候降一档画质，比反复缓冲难受要好得多。

**音质档位**按视频源而定，部分音乐区视频提供高码率音频，听歌的时候值得留意。听不出差别的话保持默认即可，高音质档更吃带宽。

**解码与硬件加速**的组合对流畅度影响最大：

| 选项 | 说明 | 建议 |
| --- | --- | --- |
| 解码格式 | 常见如 AVC / HEVC，按视频源提供 | 兼容优先选 AVC；想省带宽选 HEVC |
| 硬件加速 | 交给芯片解码，降低 CPU 占用与发热 | 建议开启，视机型支持情况而定 |
| 超分辨率 | 算法提升低清视频观感 | 老番、低清源可开，性能弱的设备慎用 |

每次手动切画质太累，可以在设置里把默认画质、默认音质、默认解码预设好。针对不同网络环境还可以做组合——比如 Wi-Fi 下默认 1080P + 硬件加速，移动网络下降一档省流量。

### 收藏夹整理：比官方客户端更细的批量能力

收藏夹攒了几百个视频就乱了？PiliPlus 把收藏管理做得比官方细很多，批量整理是它的强项。

**收藏夹层面**，可以在媒体库的收藏区域新建收藏夹、改名、改简介、删除，还能调整收藏夹的展示顺序，常用的放前面。收藏夹的公开状态跟随站内设置，和官方端一致。

**收藏内容层面**，支持多选删除、跨收藏夹复制和移动——追番专属收藏和教程收藏可以分家管理。收藏夹内的内容也能按规则排序，方便按观看顺序刷。

几个顺手的小细节：在视频详情页点收藏时可以直接选择目标收藏夹（支持多选），不用事后再整理；长按首页卡片可以直接进"稍后再看"，把"以后整理"的压力分流出去；收藏夹内容也能像视频、番剧一样通过私信转发给别人。

> [!NOTE]
> 收藏数据是云端同步的，在 PiliPlus 里的整理动作会实时反映到 B 站网页端和官方 App。批量操作一旦确认就不可撤销，删除前想清楚。

### 账号资料：不用切回官方 App 就能改

账号面板里集成了完整的资料编辑功能，头像、昵称、签名、性别、生日都可以直接在这里修改，不需要专门打开官方 App。资料修改走的是站内官方接口，和官方端完全互通——这里改完，网页端和官方 App 同步生效。

改昵称有平台侧的频率限制，一段时间内可能只允许改一次，动手前想好再改。头像和签名内容请遵守 B 站社区规范，违规内容会被平台处理。

多账号用户切换身份前，记得先在账号面板确认当前登录的是哪个号，避免发错动态。公共设备上登录过的账号，用完务必退出。
