## ✨ Exping 是什么——一款地图标记与位置收藏工具

Exping 是由爱讯集团（iFREE Group）开发的地图标记与位置收藏应用，核心能力是在地图上创建个性化的地点地图、添加标记点、记录路线，并支持跨设备同步与多人协作。它曾经是地图创作和位置管理领域的一款轻量化工具，用户群体覆盖旅行爱好者、探店博主、实地调研人员等需要频繁记录地理位置的场景。

原版 Exping 的安卓包名为 `com.ifreegroup.exping`，开发者登记为前海爱讯科技（深圳）有限公司广州分公司，这两个硬特征是辨别原版与蹭词应用的关键依据。

## 🔧 怎么安装与验证

### 安装流程

1. **获取安装包**：从下载页拿取 APK 文件，确认版本号为 1.9.11（官方末版，停服公告当天发布的版本）
2. **开启未知来源授权**：Android 系统默认禁止安装非应用商店来源的应用，需进入系统设置 → 安全 → 允许未知来源应用安装
3. **安装 APK**：点击下载好的安装包，按提示完成安装，全程一路确认即可
4. **首次启动**：安装完成后打开应用，此时服务器已关闭，大概率停在登录界面

### 版本与完整性核对

> [!WARNING]
> 第三方软件站标注比 1.9.11 更高的「Exping 新版」安装包一律存疑——原版不可能再有更高版本，停服后不会出现任何新版本更新。建议在下载完成后核对文件 MD5 值，避免安装到被篡改的包。

### 装错了怎么办

如果不小心装了蹭关键词的同名应用也不用慌，这类应用与原版包名不同，不会占用原版的安装位置，卸载即可清理干净。想装回原版再按上述流程走一遍。

## 📖 主要功能与停服现状

### 停服事实与功能现状

2024 年 12 月 31 日，Exping 官方发布停服公告，服务器正式关闭。一切需要登录、联网、同步的功能全部失效，功能现状可按下表逐项对照：

| 功能 | 停服后的现状 |
| --- | --- |
| 安装 APK | 安装包本身仍可安装，但能否进入主界面取决于客户端对登录的依赖程度 |
| 注册 / 登录 | 服务端已关闭，新账号注册与老账号登录都无法完成 |
| 地图创作、云同步 | 无法使用，云端已无服务可同步 |
| 多人协作、实时位置共享 | 无法使用，邀请链接全部失效 |
| 社区（探索、精选地图、印记广场） | 无法使用，当年的公开地图内容也不可再访问 |
| 数据洞察（浏览趋势、访客分布） | 无法使用，统计随服务端一起消失 |
| 海报导出、图片生成 | 属客户端本地生成能力，能否离线使用以实际表现为准 |
| 当年的 Web 分享链接 | 已失效，原域名现在展示的是另一款产品 |
| 快捷指令、地点备注等本地编辑 | 依赖能否进入地图编辑界面，前提是过得了登录，实际多以失败告终 |

> [!NOTE]
> Exping 的产品设计把账号当成了入口：创作要登录、数据存云端、分享走服务器。这个架构在运营期带来了实时协作与跨设备同步，停服后则意味着几乎没有可离线运转的独立部分。官方停服前的应对也印证了这一点——最后的版本把力气花在「数据导出」上，让用户把数据带出去，而不是让应用脱网运行。

### 数据导出能力（停服前可用）

官方在停服公告中称「始终坚持数据自由的理念」，并把它落在末版 1.9.11 的导出功能上。停服前，单张地图与多张地图都支持导出，共五种格式：

| 格式 | 是什么 | 适合拿去做什么 |
| --- | --- | --- |
| GeoJSON | 标准地理数据格式，坐标与属性齐全 | 导入其他还在维护的地图工具，继续做图 |
| KML | Google 地图系通用格式 | 导入 Google 系工具，或长期归档 |
| Excel | 表格化的地点清单 | 做行程表、台账，人工整理 |
| HTML | 保留网页样式的静态页 | 双击就能在浏览器里回看，当纪念册 |
| Markdown | 纯文本笔记格式 | 转进 Notion、Obsidian 等笔记软件继续编辑 |

**导出文件里有什么、没什么**：地点坐标、路线几何、备注标签等属性会完整保留（Excel / GeoJSON 里是字段列）；但地图样式与贴纸（渲染层配置）、浏览数据、协作成员的实时位置等属于「带不走的东西」。

### 停服后的数据抢救

停服窗口已过，云端数据不可访问，但旧版本客户端的本地数据是最后的抢救对象。按以下顺序操作，尽量不要跳过任何一步：

**第零步：确认还有没有本钱**

先回答三个问题：手机里的 Exping 是停服前装的旧版本吗？停服后有没有卸载过、或在系统设置里清除过它的数据？手机换过吗？三个问题过完基本能判断有没有得救。

> [!TIP]
> 在此之前，**不要卸载、不要清数据**——这是全部流程的底线。任何一个清数据或卸载操作都会直接销毁仅存的本地状态。

**第一步：试登录态**

打开应用看当前状态：如果还能直接进入主界面（当年残留的会话缓存），这是最理想的情况，立刻找导出入口；如果停在登录页、任何操作都提示网络错误，登录态已失效，直接跳第三步。无论哪种结果，中途不要退出登录、不要点「清除数据」。

**第二步：找导出入口**

若界面还能进，入口通常在地图的菜单或设置里，支持单张与批量导出。导出为本地生成的能力，理论上在离线状态下也能走通。优先导出 GeoJSON（保坐标与属性）与 HTML（保纪念观感），Excel 补清单。

**第三步：翻本地缓存**

客户端在本地存储里可能留有数据副本。安卓上未 root 的常规手段有限，但可以尝试应用的数据目录（需文件管理器支持查看应用数据）、应用自带的离线收藏；有条件的技术用户可尝试读取应用的本地数据库文件。官方没有留下停服后本地数据的任何说明，这一步的成功率无法承诺，属于尽力而为。

**第四步：接受与止损**

如果以上全部落空，接受现实：云端那份已经没有了。剩下的止损动作包括把仅存的截图整理归档、对照当年的印象手工重建一份最重要的清单（从 Excel 起步），以及开始新的记录生涯时把「定期导出」变成习惯。

### 如何辨别同名/蹭词应用

在应用商店或软件站搜「exping」，结果列表里往往不止一款应用。原版停服下架后，名字带 exping 的新应用还在上架，蹭关键词的情况真实存在。两条不依赖「下载量」「评分」的辨别办法：

**办法一：核对包名与开发者**

原版 Exping 的两个硬特征：安卓包名 `com.ifreegroup.exping`——「ifreegroup」对应开发主体爱讯集团；开发者登记为前海爱讯科技（深圳）有限公司广州分公司。应用商店的「应用介绍」页底部或「信息」栏都会列出开发者与开发者其他应用，名字再像，包名和开发者主体对不上，就不是原版。

**办法二：用停服事实反推**

原版已于 2024 年 12 月 31 日停止服务，登录、社区、同步全部关闭。由此得到一个简易判据：**任何自称 exping、且现在还能正常注册登录并提供社区服务的应用，都不是原版。**

常见的混淆对象包括：iOS 商店上曾有一款以「exping」为名、开发者是个人的位置标记工具，与原爱讯系团队无关；原团队或社区相关的新地图应用有自己的名字，不会也不该自称 exping。
