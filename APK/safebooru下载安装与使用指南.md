## ✨ Safebooru 是什么：面向移动端的轻量 booru 图站客户端

Safebooru 是一款专为 booru 风格图站设计的轻量浏览客户端，目前以 Android 平台为主。它的定位很明确——给习惯了在 booru 站按标签搜图的用户，在手机上提供一个比浏览器更顺手的浏览体验。

booru 生态的图片站（比如 Danbooru、Gelbooru 等）有一套统一的标签系统和分级机制，Safebooru 把这套机制完整搬到了移动端。你可以用熟悉的 `rating:general`、`1girl blue_hair` 这类标签语法搜索，列表页以网格形式展示缩略图，点进详情页看高清原图、查看完整标签列表，一键下载到本地。

v1.0 版本走的是轻量路线，设置项不多，开箱即用——核心功能就是搜图、看图、下图，没有多余的社交或社区功能。对于每天固定要刷几张图、或者需要从 booru 站找参考素材的用户来说，它比反复在浏览器里切换页面省不少事。

## 🔧 安装步骤：Android 端部署全流程

### 安装前检查

Safebooru 目前只有 Android 安装包，安装前确认手机已开启「未知来源应用安装」权限——不同系统位置略有差异：

- **原生 Android**：设置 → 应用和通知 → 特殊应用访问 → 安装未知应用 → 选择你的文件管理器或浏览器 → 允许
- **MIUI / Redmi**：设置 → 隐私保护 → 特殊权限设置 → 安装未知应用 → 找到下载 APK 的应用 → 开启
- **EMUI / 鸿蒙**：设置 → 安全 → 更多安全设置 → 未知来源应用下载 → 允许

> [!WARNING]
> 部分国产系统（MIUI、ColorOS）会对未上架应用商店的 APK 弹出风险提示，这是正常机制——Safebooru 是开源轻量客户端，不会申请不必要的权限。

### 安装流程

1. 从下载入口获取最新版本 APK 文件
2. 用文件管理器找到 APK，点击安装
3. 系统可能弹出杀毒软件拦截或「风险警告」，选择「继续安装」或「安装 anyway」
4. 安装完成后首次打开 app

### 首次启动：权限授权

Safebooru v1.0 不会强制索要所有权限才能启动——你可以先逛，等到下载图片时才会触发存储权限请求。首次下载时系统弹窗要权限，点「允许」即可。

> [!TIP]
> 如果第一次下载没反应，大概率是存储权限没开。可以手动去系统设置 → 应用管理 → Safebooru → 权限，把「文件访问」或「存储」权限打开。

### 安装后核对

装好后可以通过两个方式确认是正确版本：

- 打开 app 进入设置页，查看版本号是否与下载页标明的一致
- 随便搜一个标签（比如 `hatsune_miku rating:general`），如果能看到网格缩略图，说明对接 booru 站成功

## 📖 使用入门：从搜图到下载的完整路径

### 搜索：booru 标签语法的移动端体验

Safebooru 对接的 booru 站沿用了整个生态统一的标签体系，搜索框支持 `标签名:值` 的元标签语法，核心用法和浏览器端完全一致。

### 分级过滤：用 rating 元标签精确筛选

booru 站给每张图都打上了四档分级，这是 Safebooru 最常用的筛选手段之一：

| 级别 | 元标签 | 含义 |
| --- | --- | --- |
| 通用 | `rating:general` | 普通内容，零敏感元素 |
| 敏感 | `rating:sensitive` | 轻微成人元素（泳衣、暗示等），仍在安全范围 |
| 争议 | `rating:questionable` | 有争议性的内容 |
| 明确 | `rating:explicit` | 明显成人内容 |

默认情况下，Safebooru 首页只展示 `general` 和 `sensitive` 两档，`questionable` 和 `explicit` 被自动过滤。

**搜索框里直接加 `rating:` 前缀来筛选**：

```
1girl rating:general
```

意思是搜少女图里分级为通用的内容。想搜蓝发 + 敏感分级：

```
blue_hair rating:sensitive
```

**多个分级用 `or` 连接**：

```
rating:general or rating:sensitive
```

这和默认行为一样。**排除某个分级用 `-` 号**：

```
1girl -rating:explicit
```

意思是搜少女图但排除明确分级的内容。

每张缩略图的右下角会显示一个小字母标识分级（G / S / Q / E），列表浏览时不用点进去就能判断。如果想永久屏蔽某些分级，可以在 Safebooru 设置里找「默认过滤级别」，或者把不想看的分级（比如 `rating:explicit`）加进黑名单——黑名单全局生效，效果和默认过滤一样。

### 列表空白排查：分两种表现对症处理

Safebooru 列表空白分两种完全不同的情况，搞清楚是哪种才能快速解决：

**表现一：整个列表纯白，连灰色占位都没有**

这是搜索请求返回了零结果——不是网络问题，而是你的标签条件没有命中任何图。试着缩小条件：把多个标签去掉几个，或者把 `rating:` 过滤放宽。比如搜 `hatsune_miku rating:general` 肯定有结果，用它来测试自己的标签语法是不是写错了。

**表现二：有灰色方块占位但图片永远加载不出来**

这说明搜索请求成功了（有图的 ID 和信息），只是图片的二进制文件拉不下来。最常见原因有三个：

1. **booru 站图片 CDN 被墙**：Safebooru 对接的 booru 站 CDN 在海外，国内直连经常超时或被阻断。连 VPN 或加速器就能验证
2. **移动网络限速**：某些运营商对海外 CDN 流量做了 QoS 降级，Wi-Fi 下试试对比
3. **图片被 booru 站删除**：booru 站定期清理违规图，列表里有占位但文件已删。换一张热门图（比如 `hatsune_miku rating:general` 第一张）试试，热门图也不行就不是个别图的问题

> [!NOTE]
> Safebooru 本身逻辑不复杂，大部分列表空白都是网络或标签问题，先排除这两者再怀疑 app bug。

### 画质设置：省流与高清的平衡

Safebooru 里有两种图片加载场景，画质策略应该分开考虑：

- **列表页缩略图**：网格里的小图，用来浏览筛选，加载快比画质高更重要
- **详情页预览图 / 原图**：大图页面，这个才需要高清

**推荐的省流设置**：

| 网络环境 | 缩略图模式 | 原图加载 |
| --- | --- | --- |
| Wi-Fi | 自动高清 | 自动加载原图 |
| 移动网络 | 低 / 中画质 | 不自动加载，想看再手动点 |

> [!TIP]
> 下载功能永远拉的是 booru 站原始文件，和画质设置无关——画质设置只管浏览时的缩略图和预览图，下载永远是最清晰的版本。

如果 Safebooru v1.0 没暴露太多画质选项（轻量客户端可能开箱即用没留太多开关），可以用变通方案：移动网络下少刷列表，Wi-Fi 时把想要的图先下好离线看。

### 下载失败排查：从权限到链接的五层诊断

详情页点下载没反应，按这个顺序排查最快：

**第一层：存储权限**（最常见原因）

Safebooru v1.0 不会强制索要存储权限才能用——你可能在没授权的情况下顺利搜了图、逛了详情页，直到点下载才发现存不了。检查：设置 → 应用管理 → Safebooru → 权限 → 把「存储」或「文件访问」打开。

**第二层：存储空间**

下载到一半就停？单张 booru 站图片通常 3~10MB，至少留出 100MB 可用空间。去系统设置 → 存储看一下剩余容量。

**第三层：网络中断**

下载过程中网络断了会静默失败。先确认 Wi-Fi 或移动数据正常，详情页里的预览图能不能加载出来。

**第四层：系统路径限制**

MIUI、EMUI、ColorOS 这类国产系统对 APK 和图片存储路径有额外限制。可以试试用文件管理器手动去 Pictures 目录找，下载完从文件管理器而不是系统相册查看，实在不行就手动把文件从应用目录移动到系统相册能识别的位置。

**第五层：原图链接失效**

booru 站偶尔换 CDN 或清理旧图，某些图片的原始文件链接可能 404 了。这种情况下可以试试下载预览图（不是原图），或者看详情页有没有多个下载入口（原图 / 缩略图 / 不同尺寸），换一个点。换一张热门图试试，如果热门图能下而某些特定图不能下，那就是那些图本身的问题。

> [!WARNING]
> 快速验证法：搜 `hatsune_miku rating:general`，点第一张热门图下载。热门图也下不了 → 大概率是权限或系统问题；热门图能下而少数图不能 → 是那些图的链接失效。
