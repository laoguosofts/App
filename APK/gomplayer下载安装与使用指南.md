## ✨ GOM Player 是什么

GOM Player 是韩国 GOM Lab 开发的一款免费 Windows 视频播放器，在东亚地区尤其是中文用户圈里口碑不错。它的核心优势在于**内置编解码器向导**——遇到无法播放的格式时能自动联网搜索并提示安装，省去了用户自己找 codec 包的麻烦。支持几乎所有常见视频格式（MKV、AVI、MP4、WMV、FLV 等），同时自带字幕下载、视频截图、A-B 段落重复、播放速度调节等实用功能。

界面是典型的韩系播放器风格：深色皮肤为主，控制面板可以停靠在主窗口右侧，也能拖成独立浮动窗口。免费版启动时会弹一个广告窗口，关掉就能正常用，不影响播放体验。对新手来说，安装完就能直接开视频；对进阶用户来说，控制面板里藏着不少可以折腾的东西。

适合谁用：想要一个开箱即用、不用折腾编解码器的 Windows 视频观众；喜欢调均衡器、调字幕、做截图的深度用户；需要 A-B 重复精听外语或练台词的学习者。

## 🔧 Windows 版安装全流程

### 系统要求先确认

| 项目 | 最低要求 |
| --- | --- |
| 操作系统 | Windows 10 64 位及以上 |
| 内存 | 2GB RAM 以上 |
| 硬盘空间 | 200MB 以上可用 |
| 额外依赖 | 部分视频可能需要 DirectX 或 Windows Media Player |

### 六步走完安装向导

1. **运行安装程序**：双击 `GOM_Player_Setup.exe`。Windows SmartScreen 可能弹出警告，点击"更多信息" → "仍要运行"即可继续。
2. **选择界面语言**：向导启动后第一屏让你选语言，简体中文在列表里，选中后 OK。
3. **同意许可协议**：勾选 "I accept the terms..." 然后 Next。
4. **选择安装类型**：Typical（典型安装）把全部组件装到 `C:\Program Files\GOM Player\`，推荐新手直接点；Custom（自定义安装）可以改路径、减组件。C 盘紧张的话选 Custom 把路径挪到其他盘。
5. **附加任务**：向导会问要不要创建桌面快捷方式、要不要在"打开方式"里注册 GOM Player。建议全勾，后续双击文件直接开。
6. **等待完成**：进度条走完，Finish 收尾。

> [!WARNING] 第三方下载站的捆绑软件
> 安装包建议从 GOM Lab 官方渠道或本站下载页获取。一些第三方下载站会在安装包里塞广告软件，安装向导中如果出现"推荐安装 XXX"之类的复选框，记得先取消勾选再点下一步。

### 初次启动会遇到什么

- 弹窗问要不要设为默认播放器，按个人偏好选。
- 免费版首次启动会展示一个广告窗口，关掉就行。
- 界面默认深色主题，想换浅色或其他皮肤可以在设置里调。

### 升级与卸载

升级时直接下载最新安装包覆盖安装，用户数据（字幕缓存、截图目录、均衡器预设）不会丢。卸载通过"应用和功能"或控制面板，卸载程序会问要不要保留用户数据，按需选择即可。

## 📖 使用入门：从打开视频到深度折腾

### 最基础的操作

双击视频文件用 GOM Player 打开后，底部就是播放控制条。空格键暂停 / 继续，左右方向键快退快进 5 秒，上下方向键调音量，**A** 键切换音轨——MKV 多音轨视频里这个特别好用。

### 控制面板：GOM Player 的瑞士军刀

按 **F7** 打开控制面板，它默认停靠在主窗口右侧，也能拖成独立浮动窗口。分四个标签页：

**Video（视频）标签**：亮度、对比度、饱和度三个滑块实时生效；Pan & Scan 循环切换放大级别；Screen Capture 一键截图，Advanced Screen Capture 可以自定义截图区域和格式；Color Setting 有 Normal / Cinema / Vivid 等色彩预设。

**Sound（音频）标签**：主音量 + 波形音量双层调节；勾选 Equalizer 启用均衡器；Normalizer 开关解决不同视频音量忽大忽小的问题。

**Subtitle（字幕）标签**：字号滑块调大小；"+" / "-" 按钮每次让字幕提前或延迟 0.5 秒，字幕快了慢了都能对齐；多语言字幕里切换也在这儿；字幕显示开关一键隐藏 / 显示。

**Play（播放）标签**：时间跳转滑块；Playback Speed 支持 0.25x 到 4x 全范围变速；A-B 段落重复用 Section Repeat Start / End 两个按钮标记起点和终点，播放时只会循环这一段，外语精听或练台词利器。

> [!TIP] 控制面板小技巧
> 双击标签页可以让控制面板从停靠状态变成独立浮动窗口，想放哪儿放哪儿。GOM Player 会记住控制面板上次的位置，下次打开自动归位。

### 均衡器：九个预设 + 自定义

按 **Shift + E** 也能打开均衡器面板。预设下拉框里有九种风格一键套用：

| 预设 | 效果 | 适用场景 |
| --- | --- | --- |
| Pop | 流行音乐增强 | 听歌、MV |
| Rock | 摇滚增强（低频 + 高频） | 摇滚、重金属 |
| Dance | 舞曲加强低音 | EDM、电子乐 |
| Vocal | 人声增强 | 电影台词听不清、外语精听 |
| Bass Boost | 低音炮加强 | 动作片、游戏 |
| Classical | 古典音乐（中音突出） | 古典乐、交响乐 |

勾选均衡器后也能切到 Custom 模式手动拉 10 个频带滑块（32Hz 到 16kHz），每个 ±12dB 范围。调好点 **SAVE** 输入名称保存，以后预设下拉框里直接能选，不满意点 **DEL** 删掉。

> [!NOTE] 均衡器设置是会话级的
> 关闭当前视频或切换文件时，均衡器会重置为 Normal。想让它对所有视频持续生效：设置（F5）→ 音频 → 勾选"开机时自动加载上次均衡器设置"。

### 有画面没声音？按顺序排查

这种情况十有八九不是播放器坏了，而是设置或系统层面的小问题。按以下顺序查，概率从高到低：

1. **GOM Player 自己静音了**：按 **M** 键看静音图标是不是亮着（一个带叉的喇叭），亮着的话按 M 解除。
2. **Windows 混音器把 GOM Player 静音了**：右键系统托盘喇叭 → 打开音量合成器 → 找到 GOM Player 那一栏，确认滑块不是最低、静音按钮没亮。
3. **音轨选错了**：MKV 文件可能有多条音轨，其中一条可能无声或音量极低。按 **A** 键逐条切换试试。
4. **音频输出设备不对**：插了蓝牙耳机或 HDMI 显示器后，Windows 可能把默认输出切过去了。设置（F5）→ 音频 → 输出设备选你实际在听的（扬声器 / 耳机 / 显示器），Windows 设置里也确认一下。
5. **硬件加速冲突**：某些显卡驱动或 Dolby Access、Nahimic 这类音效增强软件会干扰音频。设置（F5）→ 视频 → 关闭"硬件加速"重启播放器试试；音效增强软件临时关掉再试。

如果只有某一个视频没声音，其他都正常——说明问题出在那个文件上：跑一下编解码器向导，或者换个视频源。实在不行用 Windows 自带的"电影和电视"播放同一个视频验证，如果也没声音，就不是 GOM Player 的锅了。

### 字幕相关

GOM Player 最贴心的地方之一是字幕下载功能。播放视频时它会自动联网搜索匹配的字幕，弹出来问你要不要加载。如果找不到，也可以手动拖字幕文件（.srt / .ass / .ssa）到播放窗口里，直接生效。

字幕快了或慢了，除了控制面板里的 ±0.5 秒按钮，也可以右键 → 字幕 → 调整同步，支持更精细的微调。多语言字幕文件里想切换语言，在控制面板 Subtitle 标签里或按 **S** 键逐条切。
