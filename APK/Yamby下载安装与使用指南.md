## ✨ Yamby 是什么

Yamby 是一款面向 Emby 媒体服务器的 Android 客户端，主打 Material Design 3 的现代化设计和完整的手机端管理员能力。与 Emby 官方长期停留在旧版设计的客户端不同，Yamby 从一开始就跟进了 Google 的 Material You 设计规范，在圆角、动态取色、响应式布局等方面全面对齐 Android 12+ 的原生体验。

它的核心定位是「把 Emby 的管理员工作台搬到手机上」——除了常规的媒体浏览和播放，Yamby 还支持在手机端执行库扫描、元数据重新识别、影片刮削修复等高级操作，这是官方客户端和大多数第三方客户端都不具备的能力。如果你在家里搭了 Emby 服务器，想随时随地用手机管理媒体库，Yamby 是目前功能最完整的选择。

适用场景包括：自建 Emby 家庭影院的个人用户、需要多设备同屏播放的家庭用户、外出时想通过公网 IP 访问家里媒体库的用户，以及希望在手机上直接修复影片元数据的高级管理员。免费版支持保存最多 3 台服务器，足够大多数个人家庭使用；Pro 版解锁无限制服务器数量，适合管理多台 Emby 实例的重度用户。

## 🔧 安装步骤

Yamby 仅支持 Android 平台（iOS 用户需等待 Jellyfin 官方客户端或其他替代方案）。安装过程与普通 Android APK 一致，但有几个需要注意的点。

**1. 下载文件核对**

从下载页获取 APK 后，先核对文件大小和版本号是否与页面说明一致。不同渠道分发的 APK 版本可能略有差异，建议优先选择官方渠道发布的稳定版，避免使用第三方二次打包的版本。

> [!NOTE]
> Google Play 上架版和直接下载的 APK 版本功能基本一致，但 Play 版会在安装时自动处理签名验证，而侧载安装需要手动授权。

**2. 开启未知来源授权**

Android 8.0+ 对侧载安装做了更严格的权限控制，首次安装非应用商店来源的 APK 时需要：

1. 打开系统设置 → 安全（或应用）→ 「安装未知应用」
2. 找到你用来下载 APK 的浏览器或文件管理器
3. 勾选「允许从此来源安装应用」

授权完成后点击 APK 文件即可正常安装。部分定制 ROM（小米 MIUI、华为 EMUI）会在安装时弹出额外的安全确认，按提示操作即可。

**3. 安装后的首次启动**

首次打开 Yamby 需要授予以下权限：

- **存储权限**：用于缓存媒体缩略图和离线下载内容
- **网络权限**：连接 Emby 服务器必需
- **通知权限**：播放时显示通知栏控制

> [!WARNING]
> 画中画（PiP）权限是独立的系统级权限，不会在首次启动时动态请求。如果后续需要使用 PiP 功能，需要手动去 Android 设置 → 应用 → Yamby → 画中画 入口单独开启。很多用户因为漏掉这一步导致 PiP 按钮灰掉无法使用。

## 📖 使用入门

### 添加第一台 Emby 服务器

打开 Yamby 后，右下角会有一个醒目的 **+ 号按钮**，这是添加服务器的主入口。点击后依次填写四项关键信息：

**服务器地址**支持两种格式：局域网 IP（如 `192.168.1.100`）和公网域名。局域网内连接速度最快、最稳定，是首选；公网域名需要 Emby 服务器已配置好端口映射和 HTTPS 证书，适合外网访问场景。

**端口号** Emby 默认 HTTP 端口是 `8096`，HTTPS 端口是 `8920`。如果服务器改过端口，需要在 Emby Web 管理面板的网络设置里确认当前实际值。

**协议选择** 局域网内推荐 HTTP 速度最快，公网访问推荐 HTTPS 保障传输加密。自签名证书会弹出安全警告，需要手动确认信任。

**账号密码** 管理员账号可以解锁手机端管理员功能（库扫描、元数据编辑等），普通用户账号只能浏览和播放。添加完成后 Yamby 会自动测试连接，连接失败时按「网络 → IP → 端口 → 防火墙」的顺序逐项排查。

> [!TIP]
> 免费版最多保存 3 台服务器，Pro 版无数量限制。服务器切换在首页顶部下拉或侧边栏点击服务器名称即可，切换后当前播放进度会自动保存。

### 手机端管理员：识别电影与剧集元数据

这是 Yamby 区别于官方客户端的核心功能之一。Emby 服务器的自动刮削通常能正常工作，但以下场景会出现元数据错误：

- 影片文件名不规范（如 `[2024]新电影.1080p.mkv`）导致服务器无法匹配
- 刮削源有多个候选（重名影片）导致选错了
- 新资源还没被刮削源收录
- 想换刮削源（从 IMDb 换到豆瓣）

**操作流程**：进入媒体库 → 长按目标影片封面 → 弹出菜单 → 「识别」。Yamby 会调用 Emby 服务器的识别 API，服务器根据文件名和文件夹名生成搜索关键词，按配置的刮削源优先级依次搜索。如果有多个候选结果，会弹出候选列表，每个候选项显示标题、年份、评分、海报缩略图和来源刮削源，用户从中选择正确的那一个即可。

剧集的识别比电影复杂——整部剧集需要先识别父级，再匹配每季每集。如果整部剧集元数据错乱，建议对父级条目一次性重新识别，效率最高。

**强制重新识别**：默认识别只对没有元数据的条目生效。如果已有元数据但想强制换掉，长按封面进入高级识别选项，勾选「忽略已存在元数据」或选择「重置所有元数据后重新识别」。识别成功后海报墙自动刷新，新获取的标题、年份、评分、剧情简介、演员表、海报背景图立即生效。

### Material Design 3 带来的体验升级

Yamby 是 Emby 客户端中最早完整跟进 Material Design 3（MD3）的产品之一，所有组件都使用 MD3 规范的圆角和间距。顶部搜索栏采用胶囊形大圆角的 Search Bar 样式，底部导航栏选中项带有动态色块背景，图标库使用 Google 官方统一的 Material Symbols 图标集。

与 Emby 官方客户端长期停留在旧版 Material Design 2 的对比：

| 维度 | Emby 官方 | Yamby |
| --- | --- | --- |
| 设计版本 | MD2（过时） | MD3（最新） |
| 圆角 | 小（8px） | 大（12-24px） |
| 动态取色 | ❌ | ✅ Monet |
| 触摸目标 | 偏小 | 更大更舒适 |
| 折叠屏适配 | 基本没有 | 响应式布局 |

这些设计决策直接改善日常使用体验——大圆角让海报墙视觉分区更明了，大触摸目标减少单手操作时的误触，响应式布局在平板横屏时自动扩展为多列，动态取色让 Yamby 看起来像系统原生应用而非第三方皮肤。

### 画中画 PiP 模式

Yamby 同时支持 PiP 画中画和分屏两种多窗口模式。PiP 对系统版本和权限有硬性要求：Android 8.0+、系统级 PiP 权限已授予、设备硬件支持、Yamby 版本较新，缺任何一条都会导致 PiP 功能不可用。

常见问题排查：

- **PiP 按钮灰掉**：先确认 Android 版本够不够，再去系统设置 → 应用 → Yamby → 画中画 单独开启权限，最后完全关闭 Yamby 重新打开让新权限生效
- **按 Home 键不自动 PiP**：检查 Yamby 设置 → 播放器 → 画中画 → 自动 PiP 开关是否打开。Android 11 及以下不支持自动 PiP，只能手动点击 PiP 图标
- **某些小米/华为/OPPO 设备的定制 ROM 可能对 PiP 做了额外限制**，手动点击 PiP 图标也不行的话大概率是 ROM 层面屏蔽了

PiP 小窗无声时，检查系统媒体音量（不是铃声音量）和 Yamby 播放器内的音量滑块，某些设备在 PiP 模式下会临时降低音量，手动调高即可。

### 隐藏指定媒体库

连接服务器后如果不想在手机端看到某些库（比如测试库或内部内容库），可以在服务器设置里勾选「隐藏此库」。这个操作只影响 Yamby 客户端的显示，不会改动 Emby 服务器端的实际库配置，管理员可以放心使用。
