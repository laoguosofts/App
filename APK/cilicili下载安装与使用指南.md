## ✨ cilicili 是什么

cilicili 是一款面向 ACG 爱好者的移动端内容聚合应用，主打动漫番剧与漫画的一站式观看体验。它的核心吸引力在于：汇聚了大量番剧和漫画资源，支持在线播放与离线缓存，内置漫币经济体系让用户可以通过签到、阅读任务免费解锁付费章节，同时播放器提供自动续播、历史记录管理等实用功能。

这款应用适合两类用户：一类是追新番、补老番的重度动漫观众，另一类是喜欢在通勤、午休碎片化阅读漫画的用户。界面设计偏年轻化，番剧与漫画双板块并列，首页推荐 + 分类排行 + 关键词搜索三条发现路径覆盖了从漫无目的浏览到精确找片的各种场景。

## 🔧 安装与权限配置

cilicili 属于非商店分发的 APK 应用，安装过程的核心障碍在于 Android 系统默认拦截未知来源应用。以下按实际平台和品牌分述。

### Android 安装流程

1. **下载 APK 文件**：从下载入口获取最新版本的安装包，保存到手机本地存储。
2. **开启未知来源权限**：这是最关键的一步。Android 的「允许安装未知来源」不是一个全局开关，而是**针对具体应用授权**——你用哪个应用（文件管理器、浏览器）来点开 APK，就给那个应用授权。各品牌路径速查：

| 品牌 | 路径 |
| --- | --- |
| 华为 / 荣耀 | 设置 → 应用和服务 → 应用管理 → 选中文件管理器 → 外部来源应用下载 → 允许 |
| 小米 / Redmi | 设置 → 应用设置 → 应用管理 → 选中文件管理器 → 安装未知应用 → 允许 |
| OPPO / 一加 | 设置 → 应用管理 → 特殊应用权限 → 安装未知应用 → 选中应用 → 允许 |
| vivo / iQOO | 设置 → 应用与权限 → 权限管理 → 安装未知应用 → 选中应用 → 允许 |
| 三星 | 设置 → 应用 → 右上角三点 → 特殊访问权限 → 安装未知应用 → 允许 |
| 原生安卓 | 设置 → 应用和通知 → 特殊应用访问权限 → 安装未知应用 → 允许 |

> [!TIP] 最快的授权方法
> 直接在文件管理器里点 APK 文件，系统会弹出「禁止安装此来源的应用」提示，点提示里的「设置」按钮，手机会**自动跳到对应的权限页面**，不用自己一层层找路径。

3. **完成安装**：授权后回到文件管理器再次点击 APK，按屏幕提示完成安装。装完建议核对一下版本号是否与下载页面标注的一致。

### 常见问题

> 部分安全软件可能对非商店来源的 APK 发出风险提示，这是 Android 生态的常见现象。确认下载源可信即可放行。

## 📖 功能与使用技巧

安装完成后打开应用，首页会根据追番偏好推荐热门作品。以下围绕播放器、漫币体系和搜索三大核心板块，分享日常使用的实用技巧。

### 播放器核心功能

自动续播是 cilicili 最受欢迎的体验细节之一。播放过程中无论什么原因中断——切后台、来电、误触退出、网络断开——**下次打开同一集都会从上次停下的位置继续**。它的进度保存采用实时本地写入策略，每隔几秒就把当前位置存下来，不是等退出才保存，所以几乎不会丢。每部番的每一集独立记录进度，漫画阅读也有独立的进度系统，互不干扰。

关于跨设备同步：默认情况下进度只保存在本机，换手机会从零开始。部分版本在登录账号后支持云端同步观看历史和收藏列表，但同步的完整性因版本而异。如果需要借手机给别人用又不想暴露自己的观看记录，或者想重刷某部番，进入「我的 → 历史记录」可以单条删除或全部清空。

离线缓存方面需要注意：缓存是手动逐集触发的，不会像在线播放那样自动连播。看完一集后下一集需要手动点击，或者在播放器设置里开启自动连播（视版本而定）。

### 漫币经济与付费章节解锁

cilicili 的漫画板块采用「免费试读 + 漫币解锁」的模式。连载中的漫画前面十多话通常免费，最新章节需要漫币；已完结漫画可能整书免费，也可能后半部付费。热门作品的付费门槛更高，免费试读章节更少。

解锁流程分为三步：进入付费章节会弹出解锁提示，显示所需漫币数量（通常每话约 88 漫币）、当前余额和扣减后剩余；余额够的话点确认即可，不够会引导去充值或做任务；解锁成功后漫币自动扣除（优先扣有效期最短的券币），章节永久可读、随时回看。

> [!NOTE] 免费党漫币策略
> 完全不充值的用户可以这样规划：周一签到开始攒漫币，到周末通常能攒到约 134 漫币（签到 71 + 阅读任务 63），周末统一解锁想追的那一部漫画最新话。一周的漫币只够解锁一部，**集中资源追一部，别贪多同时追好几部**。

解锁失败的常见原因：一是余额不足，靠签到和阅读任务慢慢攒或充值解决；二是解锁时网络断开，漫币可能已扣但章节没解锁成功，这种情况去漫币流水里查记录，有消耗但没解锁的话联系客服可以补退；三是漫币过期——券币到期自动消失，虽然系统会优先消耗快过期的，但如果全部过期就只能等新签到了。漫币流水在「我的 → 漫币流水」里可以查看所有解锁历史。

### 搜索技巧

首页顶部有固定搜索框，点击后进入搜索页面，包含历史记录、热门词云和分类标签。基础搜索直接打片名就行——支持中文名、英文名、日文名罗马音，甚至缩写（比如「进巨」「龙傲天」）。搜索结果默认按相关度排序，也可以切换到追番量排序找热门版本。

搜不到的时候可以尝试：换语言（中文 → 英文 → 日文 → 缩写逐个试）、去掉版本限定词（比如去掉「TV 版」「剧场版」只搜基础名）、切换地区或类型标签、或者直接去首页推荐和分类排行榜找。如果担心搜索历史泄露隐私，可以在搜索页长按单条删除或一键清空，也可以在「我的 → 隐私设置」里关闭搜索历史保存。
