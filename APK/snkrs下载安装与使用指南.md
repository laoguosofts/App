## ✨ SNKRS 是什么

SNKRS 是 Nike 为限量鞋款推出的官方抢购平台，面向全球 Sneaker 爱好者。与常规电商不同，SNKRS 把热门联名款、经典重塑款的发售做成了"抽签 + 先到先得"双通道机制，让普通玩家也能公平参与限量鞋的购买，而不是被黄牛脚本垄断。

平台覆盖 iOS 和 Android 双端，核心功能包括 **Upcoming 新品日历**（预告所有即将发售的鞋款）、**Draw 抽签**（登记窗口内任意时刻提交中签概率平等）、**Lane Up 先到先得**（常规热销款即时抢购）、**SNKRS Pass 线下取货**（限定城市门店到店自取）、以及个性化推送通知。整体界面简洁，没有花哨营销，全部服务于"不遗漏、不错过"一个核心目标。

适合谁用？如果你经常关注 Nike 限量发售、想以原价拿到热门鞋款、不想在二级市场花溢价，SNKRS 是最直接的渠道。它不承诺必中，但至少给了每个会员平等的机会。

## 🔧 安装步骤

SNKRS 目前仅在移动端提供 App（iOS 与 Android），没有 PC 版。安装过程本身不复杂，但一些权限如果没在安装时开好，后续抽签、取货、收通知都会出问题——建议首次打开时就把所有请求的权限一次性允许。

### iOS 安装要点

1. 打开 App Store，搜索 **SNKRS**（注意是 Nike 官方开发者发布的）
2. 点击获取、完成 Face ID / 密码确认
3. 首次打开时依次允许：通知、位置、摄像头（后续 Pass 取货可能需要扫码）
4. 用 Nike 会员账号登录（没有账号的话可以在 App 内直接注册，或在 Nike 官网注册后登录）

### Android 安装要点

1. 打开 Google Play（部分地区可使用商店内搜索），搜索 **SNKRS**
2. 点击安装
3. 首次打开时依次允许：通知、位置（建议选"始终允许"）、摄像头
4. 登录 Nike 会员账号

### 安装后的必要预置

> [!WARNING] 别等中签了才想起开权限——第一次打开就全部开好。抽签关闭后的结果通知只有 10 分钟付款窗口，通知收不到等于自动放弃中签资格。

- **Nike 会员绑定**：确保账号已绑定手机号、保存了有效的支付方式（银联 / 信用卡皆可），抽签提交时会做预授权
- **推送通知**：通知权限分 App 内和系统层两层，下面"使用入门"里会详细讲怎么把系统层开关全部到位
- **位置权限**：Pass 线下取货依赖 GPS 定位，建议选"始终允许"并开启精确定位 / 高精度模式

## 📖 使用入门

装好并登录只是开始，SNKRS 的真正门槛在**机制理解**和**权限配置**两方面。下面按日常使用的几个核心场景，把从参考资料里提炼出的实操要点串起来。

### 新品日历：不遗漏每一次发售

打开 App 后默认进入 Upcoming 日历，这里列出了未来数天至数周所有即将发售的鞋款。每一款都标有 **发售日期、发售方式（Draw 抽签 / Lane Up 先到先得）、参与地区**。

看到感兴趣的鞋款，点进去详情页 → 点击 **「通知我」**。这样发售时间到点时 App 会推送通知直达你——但前提是系统层通知权限也开好了，后面会单独讲这个设置。

### Draw 抽签：限量鞋的公平机会

Draw 是 SNKRS 最值得用的功能，也是 Nike 对抗黄牛的核心机制。

#### Draw vs Lane Up 到底有什么不同

| | Draw 抽签 | Lane Up 先到先得 |
|---|---|---|
| 登记时间 | 固定窗口（30 分钟到数小时） | 发售时间点一触即发 |
| 中签概率 | 与提交时间完全无关，全部平等 | 完全取决于手速和网络 |
| 适合人群 | 普通玩家、想公平碰碰运气的人 | 有脚本、多设备、超快网络的专业买家 |
| 公平性 | Nike 承诺对所有人平等 | 对普通用户非常不利 |

#### Draw 的四步完整流程

**第一步：预售预告**

发售前数天至数周，Upcoming 日历会显示"即将发售"，点进去开"通知我"。

**第二步：登记开启**

到达登记时间后 SNKRS 推送通知。进入页面会看到 **倒计时时钟**（显示剩余登记时间），选好鞋码 → 点击「加入抽签」。

> [!TIP] 一旦提交就不能改鞋码也不能取消——提交前务必核对鞋码正确。

**第三步：随机抽选**

登记窗口关闭后，Nike 服务器会锁定所有有效提交、过滤掉多设备同账号的重复项和异常支付方式，剩余提交进入随机抽选池。抽选由算法完成，**与提交时间、会员等级、设备类型全部无关**——"早提交中签率高""苹果比安卓好"这些都是民间传说，没有官方依据。

**第四步：结果通知**

抽签关闭后 24 小时内一定会出结果：
- **中签者**：收到邮件 + App 推送，订单链接需在 **10 分钟内** 完成付款（预授权自动转正式扣款）
- **未中签者**：收到未中签通知，预授权自动解除，保持关注后续发售即可

> [!NOTE] 热门鞋款中签率通常只有 5%~15%，不中签才是常态。每次 Draw 是独立随机事件，保持心态、持续参与就好。

#### 提交成功怎么确认

打开 SNKRS → 个人资料 → 订单 / 活动记录，找到对应 Draw 条目。显示 "Entered / 已提交" = 成功；如果什么都没有，说明可能没提交上，下次注意。

### 推送通知：两层都要开，缺一不可

很多人收不到通知，问题几乎都出在只开了一层权限。SNKRS 的推送需要 **App 内 + 手机系统层** 同时开启，App 内"通知我"点亮了只是第一层，系统层没开等于白搭。

#### iOS 系统层设置

1. **通知总开关**：设置 → 通知 → 找 SNKRS → 开启"允许通知"
2. **通知风格全开**：横幅 ✅、声音 ✅、标记 ✅、锁屏通知 ✅、通知中心 ✅
3. **专注模式白名单**：如果你开了专注模式，设置 → 专注 → 选你常用的模式 → 添加 SNKRS → 允许通知，这样专注模式不会静音掉发售通知
4. **后台刷新**：设置 → 通用 → 后台 App 刷新 → 找 SNKRS → 开启，确保 App 在后台也能及时接收推送

#### Android 系统层设置

1. **通知开关**：设置 → 应用 → 找 SNKRS → 通知 → 打开"允许通知"
2. **通知优先级**：设为"高优先级"或"紧急"，这样通知会在屏幕顶部悬浮显示，不被其他通知遮挡
3. **电池优化**：这是 Android 最容易漏的一项——设置 → 电池 → 找 SNKRS → 设为"无限制"。国产手机（小米、华为、OPPO、vivo）都会强制限制后台 App 的网络连接，这一步必须关掉
4. **自启动**：国产 Android 额外要加——应用自启动管理 → 添加 SNKRS，确保 App 不会被系统杀掉

> [!WARNING] 设置完建议验证一次：从最近打开列表划掉 SNKRS，等 Nike 推送一条测试通知（可以临时找个即将发售的鞋开"通知我"），收到了说明设置正确，没收到就回到上面的步骤逐一排查。实在不行就卸载重装，首次打开时把所有权限请求都点允许。

### SNKRS Pass 线下取货：仅限参与门店城市

Pass 是 Draw 之外的另一种取货方式——中签后不是快递到你家，而是到指定 Nike 门店凭 Pass 码现场取鞋。好处是不用等快递、可以当场验货，但有两个硬前提：**GPS 定位在参与门店的地理范围内** + **门店有参与 Pass 发售**。

#### GPS 定位权限是硬性前提

Nike 为什么要加 GPS 限制？两个原因：一是防止异地代取（黄牛远程预约上海门店再代取），二是确保到店率（只给附近用户展示，中签后真到店的概率更高）。

- **iOS 设置**：设置 → 隐私与安全 → 定位服务 → SNKRS → 选"始终允许" → 开启"精确定位"
- **Android 设置**：设置 → 隐私 / 位置信息 → 定位服务 → SNKRS → 允许定位 → 开启高精度定位（Wi-Fi + GPS + 网络）

> [!WARNING] 不要用 VPN 或虚拟定位模拟自己在有门店的城市。Nike 明确禁止通过代理改变地理位置参与发售活动——这属于不公平购买行为，会触发处罚。

#### 如何判断自己在 Pass 范围内

打开 SNKRS → 确保位置权限已开 → 进入动态标签页（Stash / Discover）。如果附近有可用的 Pass 活动会直接显示；什么都没显示的话，可能是三种情况：你所在城市暂时没有参与门店、位置权限没正确开启、当前没有正在进行的 Pass 活动。

目前国内 Pass 参与门店主要集中在北上广深的核心商圈（上海南京东路、北京三里屯、深圳万象城等）以及成都、杭州、武汉、南京等省会城市，中小城市可能暂时还没有覆盖。

#### GPS 不工作时的排查清单

如果定位总出问题，按这个顺序逐项过：

1. 位置权限 App 内和系统层都开了吗
2. 手机 GPS / 定位开关开了吗
3. 在室内信号不好——走到窗边或室外试试
4. Android 定位模式是不是"高精度"
5. 关掉再重新开一次定位权限
6. 重启 SNKRS App
7. 极端情况重启手机

如果还是没门店显示，大概率是你所在城市暂时不在 Pass 覆盖范围——Nike 会逐步扩展，这期间你用 Draw 抽签不受任何影响。
