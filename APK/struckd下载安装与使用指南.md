## ✨ Struckd 是什么——零代码也能做游戏的创作工具

Struckd 是一款面向移动端和网页端的低代码游戏创作平台，核心理念是让没有编程基础的用户也能快速搭建出可玩的 3D 游戏。它提供了完整的创作工作台，从地形雕刻、角色摆放、行为逻辑设计到最终发布，全流程在可视化界面中完成，不需要写一行代码。

平台支持多种游戏类型的创作，从简单的跑酷、解谜到复杂的多人对战、RPG 冒险都能覆盖。内置的资产库提供了丰富的 3D 模型、纹理和音效素材，用户可以直接拖拽使用，也可以导入自己的资源。Muse Behavior 行为树系统让 NPC 的 AI 逻辑变得直观易懂，通过节点式的图形化编排就能实现站立巡逻、追击逃跑、对话触发等常见的 AI 行为。

Struckd 的创作端分为两个入口：Studio Web（浏览器端）和移动端 App。两者共享同一个云端草稿，在其中一端创建或修改的内容会实时同步到另一端，用户可以根据场景灵活选择创作设备——在 PC 上用鼠标精确雕刻地形，在手机上用触控快速调整角色参数。

> [!NOTE]
> 根据官方公告，Struckd 服务已于 2026 年 8 月 1 日终止，发布功能和在线游玩均不可用。本地已安装的创作工具仍可离线编辑草稿，但无法上传、发布或同步。

## 🔧 安装与初始化

移动端的安装相对简单，直接在应用商店搜索安装即可。这里重点说明 PC 端的使用方式和移动端安装后的注意事项。

### PC 端使用

PC 端不需要安装任何软件，直接通过浏览器访问 Studio Web 就能开始创作。推荐使用 Chrome 或 Edge 浏览器，Firefox 和 Safari 的兼容性可能存在细微差异。进入网站后，点击右上角登录按钮，使用邮箱注册或第三方账号登录即可进入创作工作台。

### 移动端安装

1. 打开 Google Play 或 App Store，搜索 "Struckd"
2. 找到官方发布的应用，点击安装
3. 安装完成后首次打开，授予必要的存储和网络权限
4. 使用与 PC 端相同的账号登录，草稿会自动同步

> [!WARNING]
> 服务终止后，移动端 App 可能会因为证书过期或服务器下线而无法正常启动。如果遇到启动即闪退或黑屏，可以尝试清除应用数据后重试，或确认当前设备的系统时间是否正确。

### 版本核对要点

安装完成后，建议检查以下几点来确认安装包的完整性：

- **版本号**：在设置页面确认版本是否为官方发布的最新稳定版
- **资产库加载**：打开创作界面，确认资产库中的模型和纹理能正常预览
- **云端同步**：尝试创建一个测试草稿，看是否能正常保存到云端（服务终止后此功能不可用）

## 📖 使用入门：从零到可玩的创作流程

Struckd 的创作体验遵循一个相对固定的工作流：先搭建场景地形，再摆放角色和物体，然后配置行为逻辑，最后测试和发布。下面结合几个核心模块来拆解具体操作。

### 地形雕刻：像画地图一样造场景

打开创建工作台后，左侧导航栏有一个山形图标，点击进入 Terrain 地形模式。进入后场景中会出现一个白色的"聚光灯"，这就是当前笔刷的作用范围。

笔刷的核心操作有四类：

1. **雕刻凸起**：按住鼠标或手指在空白区域拖动，地形会被堆起来形成山丘
2. **雕刻凹陷**：切换到凹陷模式，在已有地形上拖动可以挖出沟壑、洞穴
3. **绘制纹理**：在地形上绘制不同的地表纹理——草地、沙地、岩石、雪地
4. **调整笔刷大小和力度**：改变聚光灯范围控制笔刷宽度，调整强度控制每次雕刻的幅度

> [!TIP]
> 地形创建建议遵循"由粗到细"的顺序：先用大笔刷快速搭出山丘、平原、河谷的大轮廓，再用小笔刷雕琢悬崖、峭壁、小径等细节，最后根据高度和坡度绘制对应的纹理——山顶画岩石、山腰画草地、山谷画沙地。

Terrain 雕刻出的地形是"画布"，上面摆放的树木、花草、岩石等装饰物则来自资产库。两者互补——Terrain 负责地表形态，资产库负责地表上的具体物体。

### 可玩角色与 NPC 的区别

在 Struckd 中，每个角色资产头顶都会显示一个小图标来标记类型：绿色控制器图标代表可玩角色（Playable），白色控制器图标代表 NPC。这个标记只在创建界面可见，运行时不会显示。

选中任意角色资产，在参数面板里可以通过"Playable"开关随时切换角色类型。两种角色拥有不同的参数选项：

| 参数类别 | 可玩角色 | NPC |
|---------|---------|-----|
| 视角切换 | 支持鸟瞰、第一人称、第三人称 | 不支持 |
| 输入绑定 | 键盘/鼠标/触控自动映射 | 由行为逻辑控制 |
| 复活设置 | 可配置复活开关和延迟时间 | 无此选项 |
| 行为模式 | 无（由玩家操作） | 站立、跟随、防御、逃跑、漫游、攻击 |
| 对话系统 | 不触发 | 点击或靠近时可触发对话气泡 |
| 战利品掉落 | 无 | 被击杀时可配置掉落物品 |

一个游戏可以有多个可玩角色，也可以只有一个——取决于设计需求。多人模式下，每个玩家会控制一个独立的可玩角色，Struckd 自动分配角色并同步位置，NPC 则对所有玩家可见但由服务器统一控制行为。

### Muse Behavior 行为树：给 NPC 装上大脑

Muse Behavior 是 Struckd 的可视化 AI 行为设计系统，通过节点式的图形化编排来定义 NPC 的行为逻辑。每个节点代表一个动作或一个条件，行为树从上到下执行，遇到条件节点就判断真假，遇到动作节点就执行对应的操作。

常用的动作节点可以按功能分为几类：

**物理交互类**：Add Force 对物体施加力（要求物体开启物理且重量小于 10），Attach Object 把一个物体附加到另一个物体上（附加物的物理应关闭），Detach Object 取消附加关系。一个典型用法是让角色"携带"物品移动到指定位置。

**相机与视角类**：Camera Look At 让相机朝向指定对象，Change Camera 切换相机类型（第一人称/第三人称/鸟瞰）。常用组合是生成物品后立刻 Camera Look At，确保玩家不错过掉落物。

**伤害与生命类**：Attack 触发角色攻击（根据武器类型产生不同效果，但不会自动给角色装备武器），Hit 对目标造成伤害，Die 让目标立即死亡，Heal 回复生命值。

**生成与销毁类**：Spawn Object 在指定位置生成新对象，Destroy Object 销毁对象，Move To 让对象移动到指定位置。Spawn Object 特别适合做"敌人波次刷新"机制——当第一波敌人全被消灭后，在第二波位置生成新敌人。

**游戏流程控制类**：Trigger Win 和 Trigger Lose 可以立即触发胜负条件，配合 Condition 条件节点就能实现自定义的胜负逻辑。Pause Game 和 Resume Game 用于暂停和继续游戏。

**时间控制类**：Wait 节点暂停行为树执行指定秒数，是做"延时触发"的关键。比如玩家进入区域后，Wait 2 秒再 Spawn Object 生成敌人，就能制造出敌人突然出现的效果。

> [!NOTE]
> Attach Object 的坐标约定：X 轴指向目标物体左侧，Y 轴指向上方，Z 轴指向后方。这个约定在所有使用附加逻辑的场景中都一致。

### 发布你的游戏

在 Studio Web 或移动端 App 的创建界面，都可以找到发布入口——Studio Web 在右上角有一个上传箭头图标，移动端在底部有"Publish"按钮。

发布流程需要填写四项信息：

| 字段 | 说明 | 建议 |
|------|------|------|
| 游戏标题 | 社区列表中显示的名称 | 简洁、能体现玩法特色，可以加 emoji 增加辨识度 |
| 游戏描述 | 一句话介绍游戏类型和玩法 | 开头点明类型（FPS/跑酷/解谜），然后说亮点 |
| 封面图片 | 社区中展示的缩略图 | Studio Web 自动截取当前场景，也可手动上传 |
| 允许复制 | 是否允许其他用户把你的游戏当模板复制 | 新人建议开启，让更多人看到你的作品 |

填写完成后点击"Publish Game"，Struckd 会把草稿上传到云端服务器。上传时间取决于草稿大小和网络状况，可能需要几十秒到几分钟。发布是幂等的——上传中途断开可以重新点击 Publish，服务器会覆盖之前的版本，不会产生重复记录。

发布后游戏存在两个状态：草稿状态可以随意编辑，只有自己能看到；已发布状态对外可见，但仍然可以编辑草稿并重新发布——Struckd 会用最新草稿覆盖已发布版本，播放次数和点赞数据保留。
