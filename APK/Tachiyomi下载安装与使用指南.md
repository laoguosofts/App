## ✨ Tachiyomi 是什么——一个 App 读遍所有漫画

Tachiyomi 是一款开源的 Android 漫画阅读器，核心理念很简单：它自己不托管任何漫画内容，而是通过扩展系统让用户接入任意漫画网站。你安装 MangaDex 扩展就能浏览 MangaDex，装 Webtoon 扩展就能接入 Webtoon，一个 App 装多少扩展，就能读多少网站的漫画。

和市面上常见的漫画 App 相比，Tachiyomi 的差异非常鲜明：零广告、完全免费、数据本地可控、六种阅读模式深度定制、支持多平台追踪同步。它的设计哲学是把「阅读」这件事做到极致，而不是用广告和会员打断用户。

Tachiyomi 的典型使用者画像：同时追 MangaDex、Webtoon、韩漫站、国产条漫的多平台漫画爱好者；对翻页弹广告零容忍的老读者；已经在用 MyAnimeList 或 AniList 追踪动画、想把漫画也同步进去的追番追漫一族；以及喜欢折腾设置、追求个性化阅读体验的 Android 重度用户。

关于版本现状，原版 Tachiyomi 在 2024 年 1 月停止开发，但 Mihon（官方继任者）和 TachiyomiSY 等活跃分支一直在持续更新，生态完好。需要注意的是，Tachiyomi 从未有过 iOS 版，也不会有——iOS 的分发机制不允许这种扩展驱动的架构存在。

## 🔧 安装步骤

Tachiyomi 只在 Android 上运行，安装流程相对简单，但有几个注意点：

1. **允许未知来源安装**：进入 Android 系统设置 → 安全 → 安装未知应用 → 选择你的浏览器或文件管理器 → 开启「允许从此来源安装」。
2. **下载 APK 文件**：从上方下载入口获取最新版本的 APK，下载完成后点击文件即可触发安装。
3. **核对文件完整性**：安装前建议核对 APK 文件的体积和签名，避免下载到非官方的二次打包版本。可以在手机上用文件管理器查看 APK 详情，或在安装界面留意应用签名信息。

> [!WARNING]
> Google Play 上的部分克隆应用可能带有广告或恶意代码，建议优先从官方渠道获取安装包。

4. **完成安装**：安装完成后首次打开应用，会弹出权限请求（存储访问权限），按提示授权即可进入主界面。

> [!NOTE]
> 如果安装时提示「应用未安装」或解析包错误，通常是 Android 版本过低（Tachiyomi 需要 Android 7.0+），或下载的 APK 文件不完整，建议重新下载。

## 📖 使用入门

### 第一步：安装扩展

打开 Tachiyomi，底部导航栏切换到「扩展」标签。这里会列出社区开发的所有漫画源扩展——按语言分类，英语、日语、韩语、中文都有。找到你常用的漫画源，点右边的下载图标安装。安装完成后点启用，回到目录页就能看到对应来源的漫画列表了。

### 书架管理

书架是 Tachiyomi 的中枢。你可以创建自定义分类来组织漫画——比如「正在追」「完结待补」「国漫」「日漫」，支持多选批量操作、拖拽排序。长按书架空白处可以切换网格/列表视图，调整封面尺寸和排列密度。

更新检查会定时扫描书架里的每本漫画，发现新章节时在书角显示小圆点提示。可以设置自动下载新章节，也可以手动点进去看更新列表。

### 六种阅读模式

Tachiyomi 的阅读器提供六种模式，覆盖不同类型的漫画：

| 漫画类型 | 推荐模式 | 说明 |
|---|---|---|
| 日本漫画（大多数） | 从右往左翻页 | 默认模式，右滑=下一页，最贴近传统日漫书的阅读方式 |
| 欧美漫画 | 从左往右翻页 | 左滑=下一页，西方漫画的标准阅读顺序 |
| Webtoon / 韩漫 / 国产条漫 | 竖滑连续 | 上下连续滑动，无翻页感，像看长网页 |
| 长条漫画 | 长条无缝 | 类似竖滑连续但页与页之间无间距，视觉更紧凑 |
| 宽屏设备 + 日漫 | 双页横向 | 两页并排展示，平板和折叠屏的最佳选择 |
| 习惯上下翻书的用户 | 垂直翻页 | 上下滑动切换整页 |

切换阅读模式的方法：打开阅读器 → 屏幕中央点一下 → 底部弹出工具栏 → 点齿轮图标即可切换当前漫画的模式。也可以在全局设置里设默认模式（设置 → 阅读器 → 默认阅读模式），然后在单本漫画里单独覆盖。Tachiyomi 会记住每本漫画的阅读模式选择，下次打开自动用上次的模式。

### 离线下载

长按章节列表中的某一章 → 勾选想要的章节 → 点下载图标即可批量下载。下载队列在通知栏有进度条，也可以在应用内单独管理。可以在设置里配置并发下载数和「仅在 Wi-Fi 下下载」，节省移动流量。新章节自动下载也能开启——更新检查发现新章时会自动拉取到本地。

### 追踪同步

如果你在用 MyAnimeList、AniList、Kitsu、MangaUpdates、Shikimori 或 Bangumi 追踪动画，Tachiyomi 可以把漫画进度也同步进去。绑定方法：设置 → 追踪 → 选择服务 → 授权登录。绑定后读完一章，追踪平台的进度会自动推进，也可以手动调整状态（在读、已完成、搁置等）。

### 备份与还原

换机或换分支时，一键导出 `.proto.gz` 备份文件就能完整恢复书架、分类、阅读进度、追踪绑定和所有设置。导出路径：更多菜单 → 设置 → 备份 → 创建备份。新设备上点「还原备份」选择文件即可。建议定期做备份，防止意外丢数据。

### 历史记录与无痕模式

底部导航「历史」标签按时间倒序展示最近读过的所有章节，每条记录显示漫画封面、标题、具体章节和阅读时间。最实用的场景是继续追更——今天看到第 77 话，明天回来不用翻书架找，历史里点一下就回去了。

无痕模式是 Tachiyomi 比较独特的功能：开启后正常阅读，但**不记录历史、不更新追踪进度、不改变已读/未读状态**。适合试看一本漫画还没决定要不要追，或者想隐藏阅读痕迹的场景。开启方法：书架底部的「⋯」菜单 → 无痕模式开关。开启后状态栏会显示一个小幽灵图标提醒你。

> [!TIP]
> 无痕模式只影响阅读行为——搜索、加书架、下载这些操作还是会正常记录。如果需要更强的隐私保护，可以结合 Android 的「应用锁」功能，或选择带内置密码锁的 TachiyomiSY 分支。

### 主题与定制

Tachiyomi 提供浅色、深色、AMOLED 纯黑三种主题，部分分支还支持 Material You 动态取色。阅读器背景色可以设置为自动跟随页面主色调，看不同画风的漫画时界面颜色会自动适配，视觉上很舒适。
