## ✨ Sketchbook 是什么

Sketchbook 是一款面向全平台的位图绘画应用，从手机、平板到桌面都有对应版本。它的核心卖点很明确：**免费即可完整作画**，不设功能门槛；铅笔、马克笔、喷枪等常见笔刷的笔触反馈在移动端属于第一梯队，配合预测笔迹与稳态追踪，手指或压感笔都能画出干净的线条；扫描纸稿、延时录像、PSD 导入导出这些生产级功能也一并覆盖。

官方把它定位成「给所有爱画画的人」——这不是空话。随手涂鸦、手账记录、从纸上转数字的美术爱好者、乃至需要透视辅助与径向对称的概念美术从业者，都能在 Sketchbook 里找到自己的打开方式。界面走极简路线，打开就是一块白画布，三秒内可以开始画；工具栏在不使用时会自动收起，双指即可旋转缩放画布，地铁上用手指也能画出像样的草图。

当然，它也不是全能选手。逐帧动画的 FlipBook 时间轴只有桌面版 Pro 才有，移动端没有；图层调整只有模糊、锐化、亮度对比度等基础项，没有完整滤镜库；排版和矢量能力接近空白——这是位图绘画应用，不是设计软件。但在「免费、轻量、跨平台」这个定位上，Sketchbook 几乎没有竞品。

## 🔧 安装步骤

Sketchbook 覆盖 Android、iOS、Windows、macOS 四大平台，各平台安装路径大同小异，下面分平台说明关键注意点。

### Android 安装

1. 从上面的下载页拿到 APK 文件后，找到文件所在目录点击打开。
2. 系统可能弹出「未知来源安装」提示——这是因为 APK 不是从应用商店分发的。进入系统设置 → 安全 / 隐私，给当前文件管理器开启「允许安装未知应用」权限即可。
3. 安装完成后首次启动会请求存储、相机等权限——**相机权限必须开**，否则扫描纸稿功能无法使用；存储权限建议全开，Gallery 里的作品读写和导出都需要。

> [!WARNING]
> 如果安装时提示「解析包错误」或无法安装，大概率是下载的 APK 与设备 CPU 架构不匹配（比如 arm64 设备装了 x86 包）。回到下载页重新确认架构版本。

### iOS 安装

直接从 App Store 搜索下载即可，无需处理未知来源问题。首次启动同样需要授予存储与照片访问权限。

### Windows / macOS 安装

1. 从官网下载对应平台的安装包（`.exe` 或 `.dmg`）。
2. Windows 双击 `.exe` 运行安装向导，选择安装路径后等待完成；macOS 双击 `.dmg` 将 Sketchbook 图标拖入 Applications 文件夹。
3. 首次启动时如果系统弹出安全提示（Windows SmartScreen 或 macOS Gatekeeper），选择「仍要运行 / 打开」即可——这是未签名软件的常见提示，不影响使用。

> [!TIP]
> 桌面版安装完成后建议打开一次应用偏好设置，确认自动保存路径和备份位置。Sketchbook 的 Gallery 文件默认存储在用户目录下，重装前记得备份。

## 📖 使用入门

### 画布与工作区的基本操作

打开 Sketchbook 就是一块白画布。移动端双指捏合缩放、旋转，单指拖动平移；桌面版用鼠标滚轮缩放、中键拖动平移，快捷键 Ctrl + 0 快速回到 100% 视图。工具栏在画布边缘，不使用时自动收起，点一下笔刷图标或颜色圆盘即可调出。

### 调笔——画出顺手的线条

同一支笔，参数不同手感完全两样。Sketchbook 提供了三个调笔入口，按需选用：

- **双滑杆**：点一下当前笔刷图标，弹出两根滑杆，上滑杆调大小、下滑杆调不透明度。画图时最常用的就是这两项，改完收起继续画，不打断节奏。
- **圆盘（Puck）**：界面上的圆形小盘是 Sketchbook 的传统快速调节件，上半个盘拖调笔刷大小与不透明度，下半个盘调颜色饱和度与明度。优点是画到一半不用打开任何面板，拇指一划就改好了。
- **笔刷参数面板**：从笔刷图标进入参数编辑，可以调间距（Spacing）、硬度、流量与湿润度、压感响应等细项。间距调大变成虚线点点的效果；硬度决定边缘是否利落；压感响应适合有压感笔的用户，能让轻重手感和自己的力道匹配。

> [!TIP]
> 推荐的调笔顺序：先用滑杆把大小和不透明度调到顺手，手感不对再进参数面板动硬度和流量。调出一支满意的笔，**复制一支再改**，留一份原始参数当底，避免改坏了回不去。

### 扫描纸稿——从纸上转数字的捷径

这是移动端专属功能，桌面版没有。纸上画了一半想转数字继续？Sketchbook 内置的扫描草图功能可以直接完成透视校正和背景清理，扫完就进 Gallery 当新画布。

操作流程很简单：打开 Gallery → 点新建菜单选「添加扫描到 Gallery」→ 相机启动后对准纸稿，Sketchbook 自动检测画面并在找到纸稿时出现蓝色框，自动完成扫描。没有自动找到就手动按快门拍全画面，自动模式也可以关掉。调整确认后点「完成」即可。

扫完可以选三种处理方式：黑白（B&W）模式转黑白并去背景，适合线稿上色；彩色（Color）模式保留颜色、去掉背景，适合彩铅 / 水彩稿；原图（Original）模式颜色背景全保留。扫完的稿子打开是普通画布加图层结构，在线稿上方新建图层描线或直接上色就行。

扫描功能偶见的问题对照：设备不支持通常是没有相机；无法启动相机是系统没给权限；必须全屏扫描时退出分屏模式，Sketchbook 需要独占全屏。

### 延时录像——把画画过程录成视频

同样是移动端专属功能。画画的同时自动录屏，收尾导出一段快进视频，发社交平台或作品集效果很好。

录制三步：工具栏菜单里选 Time-lapse（手机在工具菜单里，平板直接有图标）→ 回到画布正常画，应用在后台按帧捕捉，放大做细节时录像也跟着放大 → 画完再点录像图标结束。结束窗口显示播放时长、已录帧数、本次会话时长三项信息，三个选择：保存到相册、继续、丢弃。

Sketchbook 每 16 帧合成 1 秒视频——这是它快进效果的来源。画得越久视频越长，但播放速度远快于实际速度；中途休息太久会稀释成片节奏，长作品可以分段录、后期剪辑拼接。安卓端存 MP4 格式，位置在 Pictures > Sketchbook Gallery，视频分辨率跟随设备屏幕尺寸。

两个实用提醒：别挂机录几小时，官方明确警告录制时间过长素材体积可能超出设备存储导致保存失败，长作品分段录最稳妥；锁屏或切出应用等于录制结束，会话会自动结束并保存已录部分，接着画就是新一段。

### 适合谁用，不该用来干嘛

Sketchbook 的四类典型用户各自的用法差别很大：

- 随手涂鸦、记录灵感的人：打开即画布，三秒内可以开始画，比找纸笔还快。
- 从纸上转数字的美术爱好者：铅笔、马克笔笔触反馈在移动端属于第一梯队，配合扫描纸稿功能过渡期很平滑。
- 画手账、写笔记、做卡片的人：文字工具支持导入自定义字体，加上图形和填色工具够用，但别指望复杂版式。
- 学生与概念美术从业者：一、二、三点透视导向、16 扇区径向对称、稳态与预测笔迹这些辅助工具是正经生产工具；PSD 导入导出让它能在平板起稿、回电脑的 Photoshop 精修，工作流接得上。

但如果你想画逐帧动画、有重度滤镜与调色需求、或者需要复杂排版 / 矢量设计，Sketchbook 就不是合适的选择了——找专门的动画软件、修图软件或设计软件更高效。数字绘画工具没有全能选手，但免费即可完整作画这一点让 Sketchbook 几乎没有试错成本。
