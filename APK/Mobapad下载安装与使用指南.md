## ✨ Mobapad 是什么

Mobapad（魔派）是一款面向 Switch、PC、安卓等多平台的第三方游戏手柄品牌，旗下产品线覆盖分体式（双子星系列）、全尺寸（虎贲系列）、轻量化（赤兔系列）等多种形态。相比官方 Pro 手柄，Mobapad 的核心竞争力在于**可自定义的按键映射、背键宏录制、全平台兼容**这三件事——对重度玩家来说，这三个特性直接决定了操作效率。

双子星 M12 / M6 是分体式 Joy-Con 替代方案，左右手柄各带一颗背键，可独立映射也可合体使用；虎贲 M9 / M9-HD / M9 2 是全尺寸主力手柄，背键支持自定义位置，部分型号带 OLED 显示屏；赤兔 Pro / 赤兔 2 / 赤兔 2 Lite 走轻量化路线，适合随身带出门。所有型号都通过 Mobapad App 统一管理配置、固件升级和宏录制。

如果你是射击游戏玩家想把 L3 下蹲放到背键上解放大拇指，或者是动作游戏爱好者想录一套连招一键触发，Mobapad 的生态能覆盖从入门到进阶的完整需求。

## 🔧 安装步骤

Mobapad 手柄的"安装"分两层：**手柄本身的配对连接**和**Mobapad App 的调试配置**。手柄插上就能玩，但想用到背键、宏、按键映射这些进阶功能，必须完成 App 侧的初始化。

### 前置条件检查

- **手机端（推荐先用安卓调试）**：Android 8.0 以上，蓝牙 5.0 为佳（蓝牙 4.2 可用但偶尔丢包）；iOS 受 MFi 认证限制，部分型号功能不全
- **手柄电量**：≥ 30%，电量太低时固件升级会失败
- **App 来源**：应用商店搜 "Mobapad" 或从官网下载最新 APK

### 手柄切到正确模式

大多数型号背后有模式开关——拨到 Android 档（虎贲系列标注为 Android，双子星标注为通用档）。Switch 和 PC 模式各有对应的档位，调试阶段统一先用 Android 档连 App。

### 蓝牙配对

1. 按住手柄 **Home 键 3 秒**开机，LOGO 灯开始闪烁
2. 手机设置里打开蓝牙，等待几秒出现 "Wireless Controller" 或 "Mobapad Controller"
3. 点击配对，配对码统一为 **0000**（部分型号不需要输入）
4. LOGO 灯从快速闪烁变为**常亮**——配对成功

> [!TIP]
> 配对了但 App 没识别？先关掉手机蓝牙再开一次，重新打开 App。或者把手柄关机重开，从 App 内部点「扫描设备」而非系统蓝牙列表配对。

### 首次打开 App

1. 安装并打开 Mobapad App，允许所有蓝牙权限请求
2. App 首页应自动弹出 "已连接：虎贲 HD" 之类的提示
3. 点击确认进入调试面板，顶部显示手柄型号、电量、固件版本
4. **优先检查固件版本**——如果不是最新的，先升级固件再调配置

### 固件升级

> [!WARNING]
> 固件升级过程中**不要断开手柄连接、不要关机**，全程保持通电（Type-C 插着充电），升级约 1-2 分钟。LOGO 灯颜色会在白、橙、绿之间交替切换——这是正常现象，不是故障。

1. App 首页顶部点击固件版本号或进入「关于」页
2. 如果有新版本，App 会自动检测到并提示下载
3. 下载完成后点「升级」，手柄进入升级模式
4. 等待 LOGO 灯恢复常亮即完成

## 📖 使用入门

成功配对并升级固件后，就可以开始真正使用 Mobapad 的核心功能了。这部分从四个高频场景展开：背键分配、宏录制、LOGO 灯状态解读、宏失效排查。

### 背键 M1 / M2——最常用的自定义键

出厂默认背键**什么都不做**，需要手动分配功能。背键的位置因型号而异：

| 系列 | M1 / M2 位置 |
| --- | --- |
| 赤兔 Pro / 赤兔 2 / 赤兔 2 Lite | 背面下部左右各一颗 |
| 虎贲 M9 / M9-HD / 虎贲 2 | 背面下部，可自定义位置 |
| 双子星 M12 / M6 | 左手柄 M1（左背）、右手柄 M2（右背） |

### 背键能分配什么

和正面按键映射一致，背键可以分配四类功能：

- **物理按键**（最常用）：L3、R3、ZL、ZR 等——射击游戏里把 L3 下蹲放到 M1 背键，左手指尖按背键就能下蹲，大拇指解放出来继续瞄准
- **连发（Turbo）**：5Hz / 8Hz / 12Hz 三档频率可选
- **宏**：一个键触发一串预设动作
- **禁用**：防止误触

> [!NOTE]
> 双子星分体式手柄的背键有物理限制——左侧 M1 只能映射左侧按键（左摇杆、L、ZL、L3、十字键等），右侧 M2 只能映射右侧按键（A/B/X/Y、R/ZR/R3 等），不能跨侧映射。

### 分配步骤

1. Mobapad App → **按键映射**页面
2. 左侧虚拟手柄图上找到 M1 / M2（有些型号需要切换「背面视图」）
3. 点击 M1 选中它
4. 右侧选择映射目标——L3、ZL、或你之前录好的宏
5. 保存

部分型号（M6 HD 等）支持**手柄本体直接录宏**：长按设置键 3 秒进入宏录制模式（LED2 常亮），按几下想录的按键，再按背键结束录制。这样录好的宏自动存到背键上，不需要打开 App。

### 宏——一键连招的核心

宏就是把一串按键动作录下来，绑在一个键上触发。比如格斗游戏里的升龙拳连招，可以录成宏分配给 M2 背键，按一下就自动跑完。

**录制步骤**（App 内录）：
1. App → **宏**页面 → 新建宏
2. 点「录制」，按顺序执行你想录的动作（比如 A→X→Y→B）
3. 点「停止录制」，时间轴上会显示每一步的按键和间隔
4. 可以拖动时间轴调整每个按键的触发时机
5. 保存后到按键映射页，把这个宏分配给 M1 或 M2

### LOGO 灯——手柄的状态解码器

Mobapad 的 LOGO 灯不是单纯的装饰，它在实时反馈手柄状态：

| 状态 | 灯光表现 | 含义 |
| --- | --- | --- |
| 未连接 | 慢速呼吸闪 | 待机中，等配对 |
| 配对中 | 快速闪（每秒 2 次） | 正在被发现 |
| 已连接 | 常亮 | 正常使用 |
| 电量低 | 每 5 秒闪 1 次红色 | 赶紧充电 |
| 充电中 | 常亮红色 | Type-C 插着在充 |
| 充满电 | 常亮绿色 30 秒后灭 | 充满了 |
| Turbo 连发 | 按连发键时按频率闪 | 5Hz=闪1次/秒，8Hz=闪2次/秒，12Hz=闪3次/秒 |
| 宏录制 | LED2 常亮 | 正在录宏 |
| 固件升级 | 快速连续闪 + 按一下亮一下 | **不要断开连接** |
| 升级失败 | 快闪后常亮红色 | 重开 App 重试 |

双子星系列分左右手柄，如果发现左右 LOGO 灯不同步——左边闪右边常亮——说明左右手柄固件版本不一致，需要分别升级。

### 宏失效排查：五种常见症状

宏是 Mobapad 最容易出问题的功能，但排查路径很清晰：

**症状一：按分配宏的按键，什么都没发生**
1. 打开 App → **按键测试**页，按那个按键——App 上对应的区域亮不亮
2. **不亮** → 按键映射被禁了，去映射页恢复
3. **亮了但宏没跑** → 检查宏旁边有没有开关按钮，关掉就是屏蔽了
4. 宏损坏 → 进宏编辑页点「单步执行」测试，单步也跑不了就删掉重录

**症状二：宏只跑了一半就停了**

| 可能原因 | 解决方式 |
| --- | --- |
| 宏太长（>20 步） | 拆成两个宏，或用循环 |
| 某个中间步骤长按松早了 | 重新录，长按录稳 |
| 目标游戏输入缓冲太严 | 每步间隔 +30ms，慢一点 |
| 固件 bug | 升级固件（2025 年之前的固件有宏中断问题） |

**症状三：宏慢半拍，按了等半秒才触发**
- 检查时间轴，把第一个按键块往前拉到 0ms 位置
- 升级固件
- 手机蓝牙延迟 → 换 USB 有线连接升级，或拉近手机和手柄的距离

**症状四：宏偶尔自己触发（误触发）**
- 背键同时映射了宏 + 开了连发 → 两个功能冲突，关掉一个
- 按键物理卡顿 → 清除宏后在测试页连续按 50 次看有没有卡住
- 左手柄宏误分到右手柄按键 → 硬件物理限制，确保每侧手柄只用同侧按键

**症状五：Switch 上能跑，PC 上不行**

这是游戏输入层差异——Switch 走系统 API，PC 上很多游戏自己解析手柄输入。同一个宏想跨平台用，建议 Switch 和 PC 各录一份，按键布局和间隔可能都需要微调。PC 端如果用 Steam 输入，还要检查 Steam 控制器设置里有没有屏蔽宏。
