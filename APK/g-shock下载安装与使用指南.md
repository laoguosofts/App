## ✨ G-SHOCK Connected 是什么

G-SHOCK Connected 是卡西欧为其蓝牙智能手表推出的官方连接应用，负责在手机和手表之间建立蓝牙通道，让用户在手机上完成时间同步、闹钟设置、世界时间调整、运动数据查看等操作。支持的手表型号涵盖 GG-B100、GBA-800、GBD-800 等带有蓝牙功能的 G-SHOCK 系列。

2024 年卡西欧宣布停止对 G-SHOCK Connected 的功能更新，但**没有强制关闭服务**——这一点和某些社交应用直接下线不同。截至 2026 年，应用安装后仍可正常使用，核心功能不受影响。G-SHOCK 手表本身的基础走时和按键操作从不依赖应用，应用只是让日常使用更便捷。

适合哪些用户？所有正在使用带蓝牙功能的 G-SHOCK 手表的用户都需要这款应用来完成首次配对和日常连接。如果你只是一块纯电子表型号，不需要这款应用。

> [!TIP] 为什么需要提前备一份安装包？
>
> 应用商店（Google Play / App Store）和官方支持页的下载入口正在逐步下架，重装时可能找不到。建议把安装包存到自己的网盘里以备不时之需。

## 🔧 安装前置条件与注意事项

### 手机系统版本

卡西欧官方标注的最低兼容性要求：

| 系统 | 最低版本 | 实际验证 |
| --- | --- | --- |
| Android | 8.0 或更高 | Android 12 / 13 / 14 运行正常 |
| iOS | 13.0 或更高 | 参考 iOS 13+ 即可 |

Android 7 或更低版本无法安装，CASIO WATCHES 同样要求 Android 8.0+。

### 硬件与功能要求

- **蓝牙必须可用**：飞行模式下无法连接，带物理方向键的安卓功能机没有完整蓝牙栈
- **位置权限**：Android 8 及以下需选择「高精度」模式才能扫描蓝牙设备
- **存储空间**：应用体积约 119~164MB，安装后还需预留运行空间

### 厂商系统的常见坑

官方兼容性页面特别注明：即使系统版本达标，不同手机厂商的系统更新也可能导致运行异常。实际使用中的典型问题：

| 厂商系统 | 常见问题 | 处理方式 |
| --- | --- | --- |
| 小米 / 红米 (MIUI) | 后台蓝牙活动限制较严 | 省电优化里手动放行 G-SHOCK Connected |
| OPPO / vivo (ColorOS / OriginOS) | 自启动和后台锁定被禁用 | 权限管理里补齐「自启动」「后台锁定」 |
| 华为 (HarmonyOS) | 纯净模式拦截未知来源安装 | 安装前暂时关闭纯净模式 |
| 三星 (One UI) | Android 9~12 熄屏后连接中断 | 手动触发前台连接，之后恢复正常 |

### 安装步骤

1. **确认手机系统版本达标**（设置 → 关于手机 / 系统信息 → Android 版本或 iOS 版本）
2. **从下载页获取安装包**（应用商店下架的情况下，使用备用下载页）
3. **Android 需开启未知来源安装权限**：设置 → 安全 → 安装未知应用 → 允许你的浏览器或文件管理器安装
4. **安装完成后首次启动**：应用会引导选择语言、同意服务条款、登记手表型号（按系列找到你的表，参考表盘示意图确认）

> [!WARNING] 安装包校验
>
> 下载完成后建议核对文件大小，正常范围约 119~164MB。如果远小于这个值，可能是下载不完整或拿到了错误的安装包，请重新下载。

## 📖 使用入门：配对、连接与日常操作

### 首次配对流程

手表侧和手机侧需要同时操作：

**手表侧**：长按连接键进入连接模式（不同型号连接键位置不同，以说明书为准）

**手机侧**按以下步骤操作：

1. **打开 G-SHOCK Connected 应用**——首次启动会引导选择语言、同意条款、登记手表型号
2. **添加 / 连接手表**——主画面点击「添加手表」或「连接手表」，应用开始扫描附近蓝牙设备
3. **在扫描列表里选你的表**——附近可能出现多个 G-SHOCK（比如身边有其他用户），找到自己的那块点击
4. **确认配对请求**——手机屏幕可能弹出系统级配对确认对话框（部分机型在顶部状态栏，下拉可见），点击「配对」或「确认」；部分型号手表会显示配对码，需与手机确认一致
5. **配对成功**——应用主画面显示手表已连接、当前电量（太阳能型号），时间校正、世界时间、闹钟等功能入口全部可用

### 配对后的日常使用

配对成功后，手机和手表两边都会记住这次配对（手表可存 10 台手机，手机可记多块表）。之后的日常连接不需要完整配对流程——打开应用把表带到手机旁边，多数情况下自动连上。

应用的核心功能入口：

| 功能 | 说明 |
| --- | --- |
| 自动时间校正 | 每天定时 4 次自动对时，也可手动触发 |
| 世界时间 | 支持 300+ 城市的时区切换 |
| 闹钟 / 定时器 / 提醒 | 在手机上批量设置，同步到手表 |
| 手机搜索 (Phone Finder) | 手表按键触发手机响铃，反向找手机 |
| 太阳能电量查看 | 太阳能型号可实时显示充电状态 |
| 指针位置补正 | 指针式手表的指针校准功能 |
| 运动数据 | GG-B100 支持任务日志回看；GBA-800 / GBD-800 支持计步和卡路里累计 |

> [!NOTE] Android 9~12 的已知连接坑
>
> 手机重启后、解除飞行模式后、蓝牙开关后，如果屏幕处于熄灭状态，部分手机会连不上表。这不是手表坏了，是系统后台调度导致的。处理办法：把应用切到前台打开，手动触发一次连接即可。

### 常见配对问题排查

配对过程中遇到以下情况时的处理方法：

| 现象 | 常见原因 | 解决方案 |
| --- | --- | --- |
| 应用扫不到任何表 | 手表未进入连接模式 / 手机权限未授予 | 先让手表长按连接键，再回到应用检查位置和蓝牙权限 |
| 扫到表但配对失败 | 手机配对请求弹窗被忽略 / 信号太弱 | 手表靠近手机 50cm 内，下拉状态栏找隐藏的配对确认弹窗 |
| 配对成功后立即断开 | 权限不全或省电优化拦截 | 逐项核对权限清单，确认后台自启动已放行 |
| 手表显示「ERR」退回计时模式 | 蓝牙信号不稳定 | 靠近手机重试，确认蓝牙开关处于开启状态 |

### 删配对重来的完整流程

如果常规排查都没解决问题，大概率是配对信息混乱（应用和手表各说各的：应用显示已连接、手表蓝牙图标却不亮），按以下步骤清理重来：

1. **应用侧删配对**——打开 G-SHOCK Connected，找到已配对手表，进入详情页点「删除配对」确认
2. **手表侧删配对**（型号支持才做）——长按特定按键或在应用里远程清除手表侧配对信息；找不到手表侧操作也没关系
3. **完整重置（终极方案）**：删手表侧配对 → 删应用侧配对 → 关闭蓝牙 → 卸载应用 → 手机重启（等 5~10 秒）→ 重新安装应用 → 重新配对

完整重置后还是不行的话，问题大概率不在应用层面：试试手机能不能连其他蓝牙设备（排查手机蓝牙硬件），或换一台手机试试能不能配对手表（排查手表蓝牙硬件）。如果两边硬件都正常但互相连不上，可能是蓝牙协议版本不兼容，只能换手机或考虑迁移到新应用。

### 关于停更后的未来

官方停更后，应用商店和支持页的下载入口正在逐步关闭，重装可能面临找不到安装包的困境。但值得放心的是：即使 G-SHOCK Connected 哪天彻底不能用了，你的 G-SHOCK 手表依然能正常走时——带 Multi Band 6 电波对时的型号可以接收无线电信号自动校正，所有型号都支持手动按键对时。应用是增值工具，不是必需品。

实际建议：现在一切正常就继续用，不用急着迁移；提前存一份安装包到自己的网盘；手机系统大版本升级前先查社区反馈确认兼容性；近期换手机则直接考虑 CASIO WATCHES，不再费力找旧版安装包。
