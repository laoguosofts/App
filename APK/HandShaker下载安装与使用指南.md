## ✨ HandShaker 是什么：电脑与 Android 手机之间的轻量文件管家

HandShaker 是 Smartisan（锤子）科技推出的跨平台桌面客户端，定位是电脑端管理 Android 手机文件的轻量工具。它在 Mac 和 Windows 上都能运行，通过 USB 或 Wi-Fi 与 Android 设备建立连接后，可以直接在电脑窗口里浏览手机的相册、文件、音乐、应用等资源，支持直接拖拽导入导出，不需要借助数据线插拔或手机上的文件管理 App 来回切换。

对普通 Android 用户来说，HandShaker 解决的是"手机和电脑之间传点东西总是不方便"这个高频痛点：拍的照片想挪到电脑存、电脑上的安装包想进手机、甚至只是想快速看看手机里有哪些大文件该清了——这些场景用 HandShaker 都能在同一个窗口里完成，不用频繁插拔数据线，也不用反复登录各种云盘。

对 Smartisan / 坚果品牌的手机用户来说，HandShaker 的价值更完整：它额外打通了欢喜云服务，能在电脑端直接管理闪念胶囊、查看完整设备状态，形成了手机端 Smartisan OS 和电脑端 HandShaker 之间的生态闭环。其他品牌的 Android 手机连接 HandShaker 后，基础的文件管理、相册浏览、文件预览等功能都可以正常使用，只是 Smartisan 生态相关的高级功能（闪念胶囊、剪贴板同步等）会不可用。

## 🔧 安装步骤

HandShaker 同时支持 Mac 和 Windows 两大桌面平台，两个平台的安装流程略有差异。

**Windows 安装：**

1. 下载 .exe 安装包后双击运行
2. 如果系统弹出"未知发布者"提示，选择"仍要运行"——HandShaker 是正规发布的软件，不会有问题
3. 选择安装路径（建议保持默认），等待安装进度完成
4. 安装结束后，桌面会生成 HandShaker 快捷方式，双击即可启动

**Mac 安装：**

1. 下载 .dmg 镜像，双击打开
2. 将 HandShaker 图标拖拽到"应用程序"文件夹
3. 首次启动时如果弹出"来自未知开发者"的拦截提示，进入"系统设置 → 隐私与安全性"，在页面底部找到拦截提示并点击"仍要打开"
4. 之后即可正常从 Launchpad 启动 HandShaker

> [!WARNING]
> 首次连接 Android 手机时，需要在手机上开启 USB 调试或同意 Wi-Fi 连接授权。如果连接失败，优先检查这两项是否正确设置，而不是反复重装 HandShaker 本身。

**安装后的核对：**

- Mac 用户：打开 HandShaker 后进入顶部菜单栏的"HandShaker → 关于 HandShaker"，可以看到版本号
- Windows 用户：在主界面右上角设置面板中可以查看版本信息
- 如果版本明显过旧（比如还停留在几年前的版本号），建议到官网下载最新安装包覆盖安装

## 📖 使用入门

### 连接设备：USB 还是 Wi-Fi？

HandShaker 支持两种连接方式。USB 连接稳定性好、传输速度快，适合批量导入导出大文件；Wi-Fi 连接更方便，不需要插线就能管理手机，适合日常轻量操作。两种方式的设置入口都在 HandShaker 主界面的"添加设备"按钮里。

> [!TIP]
> 如果你是 Smartisan / 坚果手机用户，Wi-Fi 连接时确认手机和电脑在同一个局域网下，连接速度和稳定性会明显好于跨网段的情况。

### 文件预览：不导出也能看

HandShaker 内置了轻量的文件预览面板，浏览手机文件时不用每次都导出到电脑再打开。在相册视图里点击任意照片，右侧会立即显示大图预览——支持滚轮或双指捏合缩放，也能左右切换上一张/下一张，预览面板下方还会显示文件大小、拍摄时间、分辨率等元信息。

视频文件双击后会调用系统默认播放器（Mac 上是 QuickTime），同时在 HandShaker 主窗口保留缩略图列表，方便你快速跳转到视频的某个时间点。音乐文件则直接在 HandShaker 底部激活播放控制条，支持播放/暂停、进度拖动、音量调节和顺序/随机/单曲循环三种播放模式。

对于 PDF、文本文件等文档，Mac 用户可以选中后按空格键用 Quick Look 快速预览，Windows 用户双击会调用系统默认程序打开。HandShaker 无法内置预览的格式（比如 PSD、RAW 格式图片、专业视频格式）会直接调用电脑上对应的程序，前提是电脑上事先安装了能处理该格式的应用。

### 设备信息面板：一眼看清手机状态

手机成功连接后，HandShaker 主界面侧边栏顶部会显示当前设备的关键信息，包括：手机型号和系统版本、当前电量百分比、内部存储的总容量和已用空间，有外置 SD 卡的话还会额外显示 SD 卡的容量和使用情况。

这个面板的实用价值在于：电量实时读取，Wi-Fi 连接时如果计划长时间管理文件，建议给手机接上电源；内部存储剩余空间少时，照片拍摄和应用安装都可能失败，这时可以直接从 HandShaker 把不需要的文件导出后删除来释放空间，SD 卡空间不足同样会影响应用数据写入。

如果你在 HandShaker 中连接过多台设备（换手机或多手机用户），侧边栏会显示所有历史设备，点击即可切换不同设备的内容。

### 相册自动同步：让手机照片自动备份到电脑

开启相册自动同步后，手机上拍的新照片会自动同步到电脑上指定的文件夹。这个同步文件夹会随着时间不断增长，合理的管理策略能避免电脑存储被占满、同时保证备份的有效性。

**清理旧照片的建议：**

1. 先确认备份——HandShaker 同步的文件就是备份，手机上也有一份
2. 不需要的旧照片：可以删除同步文件夹中的对应日期子目录（建议同时清理手机端）
3. 需要长期保留的：考虑迁移到外接硬盘或云盘

> [!WARNING]
> 不要在 HandShaker 运行中清理同步文件夹，可能导致同步逻辑出错。最稳妥的做法是先关闭自动同步 → 清理旧文件 → 重新开启，让它只同步手机上还有的照片。

**变更同步目标文件夹：** 如果想把同步目标改到另一个位置（比如外接硬盘），进入 HandShaker 设置 → 相册同步，修改目标文件夹路径后 HandShaker 会提示重新同步。注意原同步文件夹中的文件不会自动删除，需要手动处理。

**存储空间不足时：** 清理旧文件释放空间，或者把同步目标改到更大的磁盘分区 / 外接硬盘；如果都不方便，可以临时关闭自动同步，手动导出重要照片后再清理。

视频文件体积大、同步后占空间更多，建议定期迁移到专门的视频存储位置，或者在手机端用 HandShaker 手动导出后删除手机端原文件来释放手机存储。

### 欢喜云与闪念胶囊（Smartisan / 坚果用户专属）

闪念胶囊的电脑端管理完全通过欢喜云服务实现，不需要手机连接也能使用。首次使用需要在 HandShaker 中完成欢喜云账号登录：打开 HandShaker 设置面板 → 找到"欢喜云服务"选项 → 开启"闪念胶囊"开关 → 在主界面点击"闪念胶囊"标签进入登录流程 → 选择手机号或邮箱方式填写账号密码并完成验证码验证 → 登录成功后勾选"闪念胶囊（测试版）"并点击开启。

欢喜云是锤子科技推出的云服务，统一承载 Smartisan OS 的各种同步功能——闪念胶囊、云相册、便签、日历等都走这一套。对 Smartisan/坚果手机用户来说，HandShaker 相册同步到本地电脑硬盘、欢喜云相册同步到云端服务器，两者互补使用能形成更安全的双重备份。

如果登录时遇到问题：确认是否在 Smartisan/坚果手机上注册过欢喜云账号（没有的话需要先在手机端注册）、检查手机号是否被安全软件拦截短信验证码、留意锤子科技偶尔的服务器维护公告。
