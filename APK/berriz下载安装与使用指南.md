## ✨ Berriz 是什么

Berriz 是由 Kakao Entertainment 推出的一站式粉丝互动平台，把粉丝社区、艺人直播、周边电商和 AI 互动功能整合在同一个应用里。它的核心设计思路是让粉丝围绕自己喜欢的艺人形成独立社区——每个艺人都有专属的讨论空间、商品商店和收纳柜，用户可以在里面发帖、评论、看直播、买周边、收集道具。

平台覆盖了 Android 和 iOS 移动端，以及完整功能的桌面网页版。截至 2026 年 3 月一周年时，站内已经积累了大量艺人社区，AI 评论报告功能累计生成超过 5000 份，覆盖主要艺人社区的帖子评论分析。对于 K-pop 粉丝来说，Berriz 既是追艺人动态的社区，也是收集官方周边的正规渠道。

**核心功能一览：**

- **粉丝社区**：按艺人独立建圈，发帖、评论、点赞，活动奖励贴纸
- **艺人直播**：桌面和移动端均可观看，支持自动翻译艺人聊天内容
- **Berriz Shop**：IP 方自主配置的模块化商店，专辑、MD、限定 Event 商品
- **收纳柜**：每个艺人独立一格，存放 Shop 购入的摆件和社区活动获得的贴纸
- **AI 功能**：AI 评论报告自动总结粉丝反馈、AI Persona 角色模拟对话

## 🔧 安装步骤与环境要求

### 移动端安装（Android / iOS）

1. 打开手机应用商店（Google Play 或 App Store）
2. 搜索 **Berriz**，找到官方发布的应用
3. 点击安装，等待下载完成后自动安装

> [!TIP]
> **版本核对建议**：安装完成后进入应用设置，确认当前版本为最新版。旧版本可能存在直播播放器兼容性问题，特别是桌面网页版。

### 桌面网页版要求

桌面端不需要安装客户端，直接通过浏览器访问官方网站使用。但需要满足以下条件：

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10+ / macOS 10+ |
| 浏览器权限 | 受保护内容、JavaScript、Cookie 三项全部允许 |
| 网络 | 最低 20 Mbps（看直播需要） |

> [!WARNING]
> 桌面直播黑屏最常见的原因是浏览器权限未正确配置。遇到黑屏时优先检查「站点权限 → 受保护的内容」是否被拦截。

## 📖 功能拆解与使用技巧

### AI 评论报告：一眼看懂粉丝情绪

每当艺人在社区发帖并积累一定评论后，Berriz 的 AI 会自动触发评论分析，用户无需手动操作。报告会从四个维度总结社区反馈：

- **关键词分类**：把评论按「舞蹈」「造型」「回归期待」等话题分组
- **情感倾向**：正面 / 中性 / 负面的整体占比
- **亮点评论**：自动挑选最具代表性的评论
- **俏皮总结**：用生动的关键词形成一句话概括

这个功能解决了传统粉丝社区的一个痛点——艺人发帖后评论区消息量大，逐条翻看很难快速掌握整体氛围。AI 评论报告通常展示在艺人帖子下方或社区首页，方便快速浏览和对比不同帖子的社区关注重点变化。

### Artist Mall：按 IP 独立建店的电商架构

Berriz Shop 的设计理念是 IP 持有者可以自行配置商店，而不是平台统一铺货。这意味着：

- 每个艺人、厂牌、内容 IP 都能拥有独立商店
- 商店布局、商品分类、限时活动由 IP 方主导
- 支持限时 Event 页面（专辑回归、艺人 Birthday Event 等）
- 非娱乐 IP 也能开店，比如 Samsung Lions 棒球队

主流商店类型分为三种：**厂牌集合店**（如 SMTOWN &STORE 旗下全线艺人、CUBE、STARSHIP）、**艺人专属店**（如 ATEEZ 个人 MD 和 Birthday Event 周边、WayV 个人专辑）、以及**限时活动店**（活动结束后自动下架）。不同商店之间有快捷通道互相跳转，方便粉丝逛完一家继续看。

商品价格默认以美元显示，部分商品提供中国地区专属版本，带有 CHINA 标记，价格和运费可能有所不同。

### 直播观看：网络、权限与自动翻译

Berriz 直播的观看体验高度依赖网络环境，官方最低要求 20 Mbps 以上，低于此速度可能出现缓冲和画质下降。直播播放器对浏览器权限比较敏感，桌面端需要同时开启：

1. 受保护的内容 → 允许
2. JavaScript → 启用
3. Cookie → 第三方 Cookie 也建议允许

直播中有一个贴心功能：艺人本人发送的聊天短消息会自动翻译成用户设置的翻译语言。注意这是艺人在直播间发的消息，不是粉丝在弹幕或留言区的评论。

直播结束后，平台会自动生成 VOD 视频供回看，艺人在直播中的消息记录会保留在社区固定位置，直播数据也会计入艺人社区的互动统计。

> [!NOTE]
> **直播常见问题快速排查**：加载卡住优先检查网络带宽；桌面黑屏优先检查浏览器三项权限；画质低优先确认应用是否更新到最新版；翻译不出现则去设置中配置翻译语言。

### 收纳柜：独立管理每个艺人的收藏

收纳柜是 Berriz 中一个容易被忽视但很重要的模块。每个艺人有独立的收纳柜，购买的 Shop 摆件、社区活动获得的贴纸、宝丽来照片等道具都会存放在对应艺人的柜子里。

**收纳柜的删除规则需要特别注意：**

- **自动删除触发条件**：退出社区 + 取消 Shop 关注同时执行时，收纳柜会被自动删除
- **活动贴纸永久删除**：基于社区活动记录获得的贴纸，删除收纳柜后无法恢复
- **Shop 购买道具可恢复**：摆件、粉丝俱乐部卡、随机商品等基于订单数据，重新创建收纳柜后会自动重新发放
- **宝丽来视原图而定**：如果艺人原图被删除，即使重新保存也可能拿不到

> [!WARNING]
> **账户注销 ≠ 单个收纳柜删除**：注销账户会删除全部收纳柜数据且完全不可恢复，与删除单个收纳柜是不同级别的操作，执行前务必确认。
