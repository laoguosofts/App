## ✨ HP Smart 是什么

HP Smart 是惠普官方推出的跨平台打印管理应用，覆盖 Windows、macOS、iOS、Android 四大平台。它把打印机的配网、打印、扫描、传真、墨量监控、耗材订购等原本分散的功能集中到一个面板里，首次使用时的引导式向导让新设备入网不需要碰打印机面板上的小按钮，日常使用中手机相册里的照片、微信收到的文件也能直接发打印任务。

对家庭用户来说，HP Smart 解决的核心痛点是「设备入网一次性搞定，之后全家都能打」。不少人买回来打印机就一直插着 USB 线用，其实只要机型本身带无线模块，随时可以收线升级——让打印机加入家里的 Wi-Fi，之后手机、平板都能直接发任务，墨量不足时应用会自动推送低墨提醒。

对小型办公场景，HP Smart 同样有价值：Private Pickup（到场出纸）让敏感文件不会躺在出纸口等人翻；移动传真功能把手机当传真机用，不用再单独买一台传真设备；Instant Ink 订阅服务则把耗材成本按页分摊，适合打印量稳定的用户。

并非所有惠普打印机都支持 HP Smart——入门级基础款激光打印机可能只有最基础的驱动支持，没有完整的应用功能集。购机前在惠普官网的产品规格页确认「HP Smart 兼容」一项即可。

## 🔧 安装步骤

### 平台选择

HP Smart 在四个主流平台都有覆盖，安装方式因平台而异：

| 平台 | 安装方式 | 注意事项 |
| --- | --- | --- |
| Windows | Microsoft Store 搜索安装 / 官网下载 exe 安装包 | 旧版 Windows 7/8 不再受支持 |
| macOS | Mac App Store 搜索安装 / 官网下载 dmg | 需要 macOS 10.14 及以上 |
| iOS | App Store 搜索「HP Smart」 | iPhone/iPad 通用版本 |
| Android | Google Play 搜索「HP Smart」 | 需要 Android 8.0 及以上 |

### 安装前检查

1. **系统版本**：Windows 用户确认是 10 或 11；macOS 用户确认是 10.14 Mojave 及以上；旧系统装不上新版 HP Smart，此时用系统自带的打印驱动兜底
2. **设备存储空间**：应用本体不大（Windows 版约 300MB，移动端约 150MB），但首次运行会下载打印机驱动包，预留 1GB 以上空间稳妥
3. **网络环境**：安装过程需要联网下载驱动和完成账号登录，提前确认网络通畅
4. **权限放行**：Windows Defender 或第三方杀毒软件对未签名的 exe 可能误报，Microsoft Store 版走正规签名不会触发，优先选 Store 渠道

### 安装后验证

安装完成打开应用，首次进入会看到欢迎界面。按以下步骤确认安装成功：

1. 接受惠普的隐私条款
2. 应用自动扫描附近的惠普打印机——扫得到说明驱动和蓝牙/网络权限正常
3. 如果扫不到（新机器还没配网），点击「设置新打印机」继续下一节的配网流程

> [!TIP]
> 不要在第三方下载站下载 HP Smart 安装包——惠普只通过 Microsoft Store、Mac App Store、App Store、Google Play 和官网分发，其他渠道的文件可能被篡改或夹带广告。

## 📖 使用入门

### 新打印机连 Wi-Fi 四步走

新打印机第一次配网，全程由 HP Smart 的引导式设置带着走，不需要碰打印机面板上的物理按钮。向导界面会显示一条四步进度列表：

**第一步：发现打印机（Finding the printer）**
应用通过蓝牙和 Wi-Fi 搜索附近处于设置状态的打印机。这一步别切后台、别锁屏太久——搜索窗口通常在 2 到 3 分钟内完成，超时会报「未找到设备」。

**第二步：配置打印机（Configure the printer）**
应用把你家的 Wi-Fi 名称和密码发给打印机。密码错一个字，后面就会失败——输入时留意大小写，路由器开了隐藏 SSID 的话需要手动填完整网络名。

**第三步：加入网络（Join the network）**
打印机拿到凭据去连路由器，机身上的无线指示灯由闪烁转为常亮时表示入网成功。如果一直闪烁超过 1 分钟，检查路由器 2.4GHz 频段是否正常（部分打印机不支持 5GHz 频段）。

**第四步：完成连接（Finish connections）**
打印机回到你的网络里注册，HP Smart 绑定这台设备，首页出现对应的设备卡片，点开能看到实时状态与墨量。

> [!NOTE]
> 向导界面明确提示「每一步进行时请留在本页」，整个过程约 3 到 5 分钟，切走应用或锁屏可能导致中途失败，需要从头再来。

### 搜不到打印机？还原网络设置模式

新买回来的打印机不一定处于「待配网」状态——店里的演示网络、出厂测试、上一任主人的旧 Wi-Fi 都可能占着它的记忆。HP Smart 搜不到它时，正确做法不是反复刷新，而是让打印机**还原网络设置，重新进入配网模式**。

两种机型的还原方法：

**带触摸屏的机型**（如 OfficeJet、ENVY 高配系列）：
1. 在打印机控制面板打开「无线」或「设置」菜单
2. 进入「网络设置」，选择「还原网络设置」
3. 确认后打印机清掉旧网络记忆，无线灯开始闪烁

**没有触摸屏的机型**（大量基础款 LaserJet、DeskJet）：
- 找到机身上的无线按钮，按住不放几秒钟直到无线灯开始闪烁
- 部分机型需要「取消按钮 + 无线按钮」组合长按，以随机说明书为准

> [!WARNING]
> 还原后 **2 小时内** 必须完成重新设置——这是惠普官方标注的配网有效期，超时后打印机可能退出配网状态，需要按一次按钮重新触发。

还原前后各检查一遍：
- 还原前确认路由器 2.4GHz 能正常上网、手机能连上它、VPN 已断开
- 还原后如果还是搜不到，关掉 HP Smart 后台重开让它重新扫描，同时确认手机蓝牙已开启

还原操作只会重置网络相关设置（Wi-Fi 记忆、IP 配置等），打印首选项、墨水数据不受影响，不用重装墨盒。

### USB 转无线：收线升级的路径

不少家庭的打印机买来就一直插着 USB 线用，其实只要这台打印机本身带无线模块，随时可以转换——让打印机加入家里的 Wi-Fi，之后手机、平板都能直接发打印任务。

转换步骤需要在电脑端 HP Smart 里操作（Windows 版对这条路径支持最完整）：

1. 确认打印机当前以 USB 方式在线
2. 进入打印机设置，找到「更改连接类型」或连接方式选项
3. 选择从 USB 转为无线，应用会读取当前网络信息并下发给打印机
4. **让打印机确认入网后再拔掉 USB 线**——先拔线会让向导失去直连通道，转换流程直接中断
5. 手机端打开 HP Smart，用「添加已有打印机」把这台已加入网络的打印机认领进来

转无线之后的好处很直接：手机相册、微信里收到的文件直接打，不用先传电脑；应用里能实时看墨量、收低墨提醒；家里多个人共用一台打印机，谁都能用自己的设备发任务。

路径是可逆的——想回 USB 直连时重新插线，在同样的连接设置里改回 USB 即可。偶尔出差断网时，USB 也是最稳的兜底通道。

### Private Pickup：敏感文件到场才打印

远程打印最大的尴尬：文件到家了，人没到家。工资单、合同、身份材料就这么躺在出纸口，等家里任何人先「审阅」。Private Pickup（到场出纸）就是为这个场景设计的——**你在打印机旁边确认后，纸才出来**。

在哪开启：
打印预览的参数列表里，平板端和电脑端能看到 **Private Pickup** 一项，默认 Off（关闭）。打开后发送任务，文件先挂起；你走到打印机旁，在应用或设备上确认，出纸才开始。

使用体验上的取舍：
- **多一步确认**：普通打印发完就走，它必须人到——这是设计目标本身，不是故障
- **只对开启的任务生效**：不是全局限流开关，日常文件照常直打，敏感文件单独开
- **配合远程打印使用价值最大**：人在外发了任务，到家再让它出纸，文件全程不裸奔

还想更保险的三个补充：给打印机设密码挡住蹭打的人；不需要远程打印时关掉 Print Anywhere 权限；敏感文件打完立刻收走。

需要注意的是，这个功能需要登录惠普账号的云通道，纯局域网直打的任务没有挂起机制；很老的机型固件不支持该特性，参数列表里根本没有这一项，此时用「人到再发任务」的土办法替代。
