## ✨ Live2DViewerEX 是什么——让 2D 角色动起来的桌面伴侣

Live2DViewerEX 是一款跨平台的 2D 动态角色展示工具，支持在桌面、动态壁纸、VTuber 推流等多种场景下运行 Live2D 和 Spine 骨骼动画模型。它把静态的插画角色变成能眨眼、能转头、能做表情的动态伙伴，广泛用于桌面美化、直播间互动、虚拟形象展示等领域。

软件的核心能力包括：多模型槽同屏显示、面部捕捉驱动角色表情、创意工坊模型订阅下载、场景快照一键切换、WebSocket 开发者接口远程控制。Windows 和 macOS 版本功能最完整，Android 提供动态壁纸和悬浮窗两种形态，iOS 目前只有面部捕捉独立工具。

## 🔧 安装步骤——选对平台，注意版本差异

Windows 用户最主流的安装方式是通过 Steam。购买后 Steam 客户端会自动完成下载和安装，首次启动会在系统托盘区创建图标。macOS 同样走 Steam 渠道，也可以从官网直接下载 dmg 安装包。

### Steam 安装流程

1. 打开 Steam 客户端，搜索 Live2DViewerEX
2. 购买应用后点击「安装」，选择安装路径（建议预留 1GB 以上空间，创意工坊模型会占额外空间）
3. 安装完成后首次启动，Steam 会自动创建桌面快捷方式和托盘图标
4. 如果你计划购买 Spine Expansion DLC，同样在 Steam 商店页面的「可下载内容」区域找到并购买，安装后需要重启应用生效

> [!WARNING]
> Spine Expansion 是付费 DLC，单独购买。安装后建议在创意工坊里随便订阅一个 Spine 模型，某些用户反馈这是 DLC 功能完全激活的必要步骤。

### Android 安装

Android 有两个不同的 App：动态壁纸版（com.pavostudio.live2dviewerex）和悬浮窗版（com.pavostudio.live2dviewerex.floatingviewer）。前者设置为系统动态壁纸后常驻桌面背景，后者以悬浮窗口形式叠加在其他 App 之上。两个版本数据独立，互不互通。

安装后首次启动需要授予权限：存储访问（读取模型和背景文件）、摄像头（面部捕捉）、悬浮窗（悬浮窗版专属）。Android 11+ 的分区存储限制让手动复制模型文件有些麻烦，建议用第三方文件管理器操作。

### 版本核对建议

安装完成后，在控制面板的「设定」→「关于」里确认版本号。Live2DViewerEX 更新频率不低，新功能（比如 ExAPI 接口扩展、Spine 编辑器改进）只在较新版本中可用。如果遇到创意工坊模型不显示、面部捕捉失灵等问题，先检查版本是否落后。

## 📖 使用入门——从模型到场景，从日常到创作

### 模型生态：Live2D vs Spine

Live2DViewerEX 支持两种骨骼动画格式，各有侧重：

| 对比项 | Live2D Cubism | Spine |
|---|---|---|
| 技术原理 | 部件贴图 + 参数变形 | 骨骼结构 + 蒙皮贴图 |
| 动态能力 | 适合表情和头发等细节 | 适合复杂全身动作和打斗 |
| 适用场景 | 桌面宠物、VTuber 面部 | 游戏角色、复杂动画 |
| 文件格式 | `.model3.json` + 资源文件夹 | `.skel` + `.atlas` + `.jpg` |

简单说：Live2D 更擅长"脸动"，眨眼、张嘴、头发飘动这些细腻的表情和物理模拟效果出色；Spine 更擅长"全身动"，跑跳打斗等大幅度动作表现更好。Live2DViewerEX 可以在不同模型槽里同时显示两种格式的模型，互不干扰。

### 获取模型：创意工坊和本地导入

模型来源主要有两个渠道。Steam 创意工坊提供了社区用户制作的海量模型，订阅后 Steam 自动下载到本地，Live2DViewerEX 会自动识别并出现在模型列表里。另一个渠道是本地模型文件，支持 `.model3.json` 文件夹（Cubism 标准格式）、`.model.json` 文件夹（旧版 SDK 2 格式）、`.skel` + `.atlas` + `.jpg`（Spine 格式）三种可编辑格式。`.lpk` 和 `.wpk` 是创作者打包的成品包，可以直接导入但无法二次编辑。

### 自己做模型：两条路线

如果你想从零做自己的 Live2D 角色，有两条路线可选：

**完整建模**需要美术基础。流程是：用 Photoshop 或 Clip Studio Paint 画出分层的角色素材（头发、眼睛、身体等每个部件单独一层），导入 Live2D Cubism Editor 设置参数（Transform 参数控制位移旋转、Warp 参数控制网格变形、物理模拟让头发自然摆动、表情参数预设变形组合），配置面部参数控制器把摄像头追踪的数据映射到模型参数，最后导出 `.model3.json` 文件夹就能直接导入 Live2DViewerEX。

**EX 工作室编辑现成模型**不需要美术基础。Live2DViewerEX 在 Windows / Mac 上内置了 EX 工作室工具，可以对已有的 Json 模型做二次调整——修改参数数值范围、微调物理模拟、增删面部参数绑定、调整表情动作触发条件。但 EX 工作室不能创建新模型，也不能编辑 LPK / WPK 格式，功能比 Cubism Editor 简化很多。

> [!TIP]
> EX 工作室的可执行文件在 Live2DViewerEX 安装目录里，双击打开即可。操作界面和 Cubism Editor 类似但更精简，上手很快。

### 场景快照：调一次，永久切换

场景（Scene）是 Live2DViewerEX 的完整桌面状态快照，会记录所有模型槽的内容和位置、背景类型和图片/视频/网页、特效开关和参数（雨雪、可视化效果器、漂浮粒子）、滤镜状态和作用范围、小部件位置——类比游戏存档，存好之后随时读档。

典型工作流：花 30 分钟调好一个日常桌面场景（2 个模型 + 视频背景 + 雪花特效 + 冷色滤镜 + 数字时钟）保存为「日常默认」，再花 20 分钟调好一个推流专用场景（单个居中大模型 + 纯色背景 + 无特效 + 无滤镜）保存为「推流配置」，之后两个场景来回切换一键搞定。

**跨设备迁移**是场景系统的强项。控制面板 → 场景标签页 → 选中场景 → 导出，得到专用格式的场景文件。在另一台电脑上打开 Live2DViewerEX → 导入这个文件，就能恢复所有配置。需要注意：创意工坊模型只要 Steam 账号相同或模型已在新电脑下载就能跟着场景走；本地 LPK / WPK / Json 模型的文件需要手动复制到新电脑；背景图片和视频同样需要在新电脑上存在；面部捕捉配置的摄像头校准部分需要重新做。

Android 版有更直接的数据迁移方式：把旧手机 `/Android/data/com.pavostudio.live2dviewerex/files` 整个复制出来，新手机安装启动一次后覆盖同路径即可（悬浮窗 App 路径是 com.pavostudio.live2dviewerex.floatingviewer）。

> [!NOTE]
> 多显示器环境下，场景会记录每个显示器的背景和模型位置。从双屏电脑迁移到单屏时，超出屏幕边界的模型会被移动到可见区域，第二屏的背景可能丢失。建议在相同显示器配置的电脑间迁移。

### ExAPI：用代码远程控制 Live2DViewerEX

ExAPI 是 Live2DViewerEX 提供的 WebSocket API，让任何本机运行的软件（Python 脚本、Node.js 应用、浏览器扩展、移动端 App）都能远程控制它。默认监听 `ws://127.0.0.1`，不对外暴露（安全设计），需要在控制面板 → 设定 → 开发者相关里手动开启才会启动监听。

支持的操作覆盖全部核心模块：模型（载入、切换槽位、移除、调整位置）、背景（切换、编辑、替换）、特效和滤镜（开关、切换、配置参数）、场景（保存、载入、导出）、气泡（发送文本让角色"说话"）、小部件（开关、位置调整）、查询（获取当前状态）。

典型用例包括：语音助手触发气泡（早上闹钟响自动切换场景并发送"早上好"）、游戏联动（打开某款游戏自动加载同题材模型和背景）、多场景自动切换（Python 脚本根据时间在晨光/工作/夜景三个场景间轮转）、手机端遥控面板（本地网页通过 ExAPI 远程切换模型和背景）。

> [!WARNING]
> ExAPI 使用前注意两点：一是 VPN 如果接管了本地流量可能导致控制面板和渲染器之间的 WebSocket 通信失败；二是 iOS 没有 ExAPI，只有 Windows / macOS / Android 支持。
