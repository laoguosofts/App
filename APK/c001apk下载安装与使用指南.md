## ✨ c001apk 是什么

c001apk 是酷安社区的开源第三方客户端，由社区开发者基于酷安开放接口重新实现。它的核心定位很明确——给那些受不了官方版广告轰炸、觉得体积臃肿的用户一个轻量、干净的替代选择。

酷安作为国内最大的 Android 应用社区之一，聚合了海量用户分享的 APK、评测、动态和数码讨论。官方版在功能完备度上无可挑剔，但随之而来的是开屏广告、信息流推广位、应用详情页推荐等商业植入，加上百兆级的安装包体积和运行内存占用，对追求纯粹浏览体验的用户来说越来越重。c001apk 就是在这样的背景下诞生的——把酷安的社区内容原封不动地搬过来，去掉所有商业化元素，用最小的权限和最轻的体积提供核心浏览能力。

从技术栈来看，c001apk 的活跃分支采用 Flutter 构建，Android 端已经用 Jetpack Compose 重写，桌面端（Linux / Windows / macOS）也有实验性支持。它使用独立包名，与官方版完全隔离，可以同时安装、互不干扰。

适合谁用？如果你经常逛酷安找 APK 或看数码动态、对广告零容忍、在意手机上每 MB 的存储空间和每 MB 的运行内存，或者喜欢折腾开源软件，c001apk 是一个值得尝试的选择。

## 🔧 安装步骤

### Android 平台

c001apk 使用独立包名，与酷安官方版完全隔离，两者可以同时安装、互不干扰。安装前需要注意以下几点：

1. **允许未知来源安装**：如果你从酷安外部渠道下载 APK，需要在系统设置中开启「允许安装未知来源应用」。路径通常是：设置 → 安全 → 安装未知应用 → 选择使用的文件管理器 → 允许。
2. **核对版本号**：下载完成后建议在文件管理器中确认 APK 文件大小和版本标识，避免下载到损坏或过期的安装包。c001apk 的安装包体积通常在 5MB 左右，远小于官方版的 100MB+。
3. **点击安装**：找到下载好的 APK 文件，点击后系统会弹出安装确认窗口，一路确认即可。

> [!WARNING]
> 部分国产 ROM（小米、OPPO、vivo 等）可能会对未知来源应用弹出安全提示，这是系统的常规安全机制，不代表安装包有问题。如果手机装有杀毒软件，也可能误报，手动放行即可。

### 桌面端（Linux / Windows / macOS）

桌面端目前为实验性支持，需要从 GitHub Actions Artifacts 获取对应平台的构建产物，或自行编译。安装方式与普通桌面软件相同：解压后运行可执行文件（Linux 需要先赋予执行权限 `chmod +x`）。

## 📖 使用入门

### 首次启动三件事

打开 c001apk 后默认以游客身份运行，**不需要登录即可浏览全部内容、下载所有应用**。如果希望使用收藏、评论、发布动态、消息通知等功能，再点击右上角头像进入登录页，输入酷安账号密码即可（如已开启二步验证，需要先在官方 App 或网页端生成临时验证码）。

首次使用建议花两分钟完成三项基础配置：

**第一步：选择默认启动页**。进入「我的」标签页 → 设置图标 → 界面设置 → 默认启动页，可以在关注、应用、头条、热榜、话题、数码、酷图中任选其一。想专注刷社区动态选「关注」，主要目的是找 APK 选「应用」，想快速捕捉热门内容选「热榜」或「头条」。

**第二步：确认无广告模式已启用**。c001apk 默认已经去除所有广告，但还是可以进入设置 → 通用检查两项：广告过滤器开关（默认开启）、隐藏推广话题（建议开启，进一步屏蔽残留的推广类动态）。这两项保持默认状态即可，不需要额外调整。

**第三步：自定义主题配色**。Material Design 3 支持超过 50 种预设强调色，进入设置 → 个性化，挑选喜欢的颜色后开启「跟随系统深色模式」，让应用自动适配系统昼夜切换。夜间配合深色主题可以有效降低眼部疲劳。

另外还有一些实用小设置可以按需调整：字体大小（标准 / 大 / 特大三档，对老年用户很友好）、外部浏览器打开链接（默认关闭，点击外链时在应用内直接处理，想跳转系统浏览器可以手动开启）、清理缓存（一键清除图片缓存、搜索历史、浏览记录，建议定期执行释放存储空间）。

### 应用详情页与下载

从分类列表、排行榜、专题页或搜索结果点击某个应用卡片，就进入了应用详情页——这是找 APK 时最常用的页面。详情页集中展示了：应用图标 + 名称 + 开发者、当前版本号和更新日期、APK 文件体积、分类标签、酷安社区真实用户评分和评论数、开发者写的应用简介、官方或用户上传的截图、以及用户评论区。

下载按钮的交互设计得很贴心：WiFi 下直接点击立即开始下载，无弹窗；移动网络下会弹出「当前使用移动网络，继续下载？」的确认提示，避免浪费流量；下载中按钮变成进度条实时显示百分比；下载完成按钮自动变成「安装」，点击直接调用系统安装流程。游客身份也能正常下载所有应用，不需要登录。

> [!TIP]
> c001apk 内置应用更新提醒功能，会自动扫描手机已安装应用与酷安版本对比，发现新版本时在「应用」Tab 顶部显示红点提醒。如果你只关心应用商店正规渠道的更新，可以在设置中单独关闭「非官方渠道应用更新通知」开关。

评论区也是 c001apk 保留得很完整的功能——支持点赞、回复、查看对话线程，可以切换热度 / 时间排序，自己也能发表评论和评分。社区真实用户的使用心得、Bug 反馈、版本对比是判断一个 APK 靠不靠谱的重要参考。

### 与官方版的核心差异

如果你之前一直在用酷安官方版，切换到 c001apk 可能最直观的感受就是「清爽」——没有开屏广告、没有信息流推广位、没有应用详情页推荐位、没有搜索结果广告，推送通知也只包含用户主动开启的消息，不会有应用推广和专题推送。

体积上的差距也很明显：c001apk 安装包约 5MB，官方版约 110MB；启动速度快 50% 以上，运行内存低 60%。权限方面 c001apk 默认遵循最小权限原则——启动时不申请任何权限，仅在用户主动下载应用时申请存储权限，默认关闭位置、联系人、麦克风等非必要权限，不收集用户行为数据、不做个性化推送画像。

功能完整性上两者差距不大，首页多 Tab 浏览、应用下载、动态发布、评论点赞、搜索（动态 / 应用 / 数码 / 用户 / 话题）、消息通知、收藏管理、浏览历史、应用更新提醒这些核心功能 c001apk 都有。还有两个 c001apk 独有的功能：自定义机型参数和超过 50 种主题色可选，桌面端支持也是官方版没有的。

> 账号数据共用酷安平台接口，登录同一账号后可以访问相同的内容和社区，但本地缓存、收藏列表等不自动同步。许多用户选择两者并存——c001apk 日常浏览，官方版偶尔补充功能或作为备份。
