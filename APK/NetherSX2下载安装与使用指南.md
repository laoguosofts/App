## ✨ NetherSX2 是什么

NetherSX2 是一款针对 Android 设备优化的 PS2 模拟器，基于 PCSX2 开源项目的核心引擎，专门为手机和平板等移动平台做了深度调校。它能在骁龙 888 及以上的 Android 设备上流畅运行绝大多数 PS2 经典游戏，带来接近原生甚至超越原生的画质体验。

相比早期的 AetherSX2，NetherSX2 修复了大量兼容性问题，优化了 Vulkan 渲染路径的性能表现，并内置了 GameDB 数据库——自动识别游戏 ID 并应用对应的宽屏补丁、去隔行补丁、帧率提升补丁等，省去了用户手动配置的麻烦。

这款模拟器的核心竞争力在于「开箱即用」的体验：内置的速度黑客（Speed Hacks）预设值经过了社区实测调优，不需要用户从零开始摸索 VU Cycle Stealing、EE Cycle Rate 等参数；同时它支持加载外部高清纹理包，让二十年前的 PS2 游戏焕发新生。

适合的用户群体很明确：有 PS2 时代情怀、想在手机上重温经典作品（战神系列、GT 赛车、旺达与巨像、最终幻想等）、愿意花一点时间做基础配置的移动游戏玩家。

## 🔧 安装步骤

NetherSX2 目前仅支持 Android 平台，推荐 Android 10 及以上系统。安装过程与普通 APK 类似，但有几个关键注意点：

### 基础安装流程

1. **下载 APK**：从上方下载入口获取最新版本的安装包
2. **允许未知来源**：Android 10 及以上系统会在首次安装第三方 APK 时弹窗询问，允许浏览器或文件管理器安装应用即可
3. **授予存储权限**：首次启动时模拟器会请求文件访问权限，需要授予「所有文件访问」权限才能正常读取游戏镜像
4. **准备游戏镜像**：PS2 游戏需要从自己的实体光盘通过 ImgBurn 等工具导出 ISO 镜像文件，格式为 `.iso`、`.bin/cue` 或 `.chd`

> [!WARNING] 版本核对提醒
> 下载完成后务必核对文件大小和版本号。目前主流版本的安装包大小在 30–40MB 之间，如果下载到的文件明显偏小（比如只有几 MB），大概率是下载不完整或下载到了错误的文件。

### 设备性能基线

并非所有 Android 设备都能流畅运行 NetherSX2。以下是性能参考：

| 处理器 | 可玩程度 | 推荐内部分辨率 |
| --- | --- | --- |
| 骁龙 8 Gen2 / 8 Gen3 | ✅ 高帧率稳定 | 2x–3x Native |
| 骁龙 888 / 8 Gen1 | ✅ 大部分游戏流畅 | 2x Native |
| 骁龙 865 / 天玑 1200 | ⚠️ 部分游戏需要降配 | 1x–1.5x Native |
| 骁龙 845 / 天玑 1000 | ❌ 仅少数轻量游戏可玩 | 不推荐 |

## 📖 使用入门

成功安装并导入游戏后，下一步就是针对具体游戏调优参数。NetherSX2 的参数体系与 PCSX2 一脉相承，但做了移动设备的针对性简化。以下内容覆盖日常使用中最常遇到的调优场景。

### VU Cycle Stealing：手机上最关键的性能开关

VU Cycle Stealing（VU 偷帧深度）是 NetherSX2 中对 CPU 密集型游戏影响最大的速度黑客选项。PS2 的 VU1 单元负责处理角色骨骼动画、粒子效果等，VU Stealing 让模拟器可以从 EE 主 CPU 那里「借」一些执行周期给 VU1，从而提升整体帧率。但代价是 EE 主核的音频处理、游戏逻辑计算会被延迟，容易引发爆音或画面闪烁。

这个参数有四档（0–3），每升一档帧率大概能涨 5–10 FPS，但副作用也会同步加重。不同游戏对 VU Stealing 的敏感度差异很大——比如 GT 赛车 4 这种纯 CPU 密集型游戏，升到 2 档能带来显著的帧率提升，而旺达与巨像升到 3 档虽然帧率更高，但巨像的骨骼动画会明显不连贯，严重破坏游戏的沉浸感。

**通用调档策略**很简单：每升一档先跑 30 秒，确认帧率提升是否值得副作用。如果升到下一档后帧率只涨了 5 FPS 但爆音明显加重，就停在当前档。经验上大多数游戏用 2 档是性价比最高的选择——帧率收益大、副作用可接受。

### 爆音修复：音频延迟与偷帧的平衡

爆音是调 VU Stealing 时最常遇到的副作用——VU1 偷了太多周期给 EE 主核的音频处理留的时间不够，音频数据不能按时送出去，就会出现断断续续的爆音、音高抖动、背景音乐卡住等现象。

修复爆音的推荐顺序是：

1. **先增大音频延迟**——这是最直接且无性能损失的方法。进入全局设置 → 音频，找到「音频延迟」选项，默认值通常是 50–60ms，每次增加 20ms 直到爆音消失。上限不要超过 120ms，太高会让操作和声音脱节（比如开枪后半秒才听到枪声）。VU Stealing = 2 时推荐起步 80ms，VU Stealing = 3 时推荐 100–120ms。

2. **降低 VU Cycle Stealing 档位**——如果增大延迟后还是爆音，或者延迟已经太高影响体验，就从 3 降到 2、从 2 降到 1。这是最彻底的方法。

3. **切换音频同步模式**——Time Stretching 是默认推荐模式，它自动调整音频播放速度来匹配模拟器帧率。遇到极端爆音时可以试试 Async Mix（用单独线程处理音频），对帧率波动剧烈的游戏效果更好。

> [!TIP] 系统音频优化
> 某些手机系统会对模拟器强制应用杜比全景声、DTS、Hi-Res 解码等音频效果，反而导致额外的处理延迟。进入系统设置 → 声音 → 音频效果，找到「应用特定音频效果」或类似选项，关闭对 NetherSX2 的音频处理，音质和延迟都会更干净。

不同游戏的音频特性差异很大，比如 GT 赛车 4 的引擎音效动态变化复杂，需要 VU Stealing = 2 配合 80–100ms 延迟；GTA 圣安地列斯音频复杂度中等，用 0 或 1 档配合 60ms 延迟就够了；最终幻想系列管弦乐+语音的音频对延迟特别敏感，VU Stealing 建议用 0 或 1 档。

### 战神系列：兼容性标杆

战神 1 和战神 2 在 NetherSX2 上的兼容性表现堪称标杆。两款游戏的 GameDB 补丁都已经内置，宽屏支持和去隔行补丁自动启用，不需要用户手动调整任何兼容性设置。

战神 1 在骁龙 888 / 8 Gen1 上以 2x Native 分辨率运行时帧率稳定在 45–55 FPS，战神 2 因为画面复杂度更高（纹理量和光照计算都更大），帧率在 42–52 FPS。两者都有社区制作的高清纹理包（1K–4K），配合 2x Native 缩放效果提升非常明显。

推荐参数配置：

- 渲染器：Vulkan
- 内部分辨率：2x Native（骁龙 8 Gen2+ 可尝试 3x）
- MTU：开启
- VU Cycle Stealing：2 或 3
- EE Cycle Rate：100%
- 各向异性过滤：4x（战神 1）或 8x（战神 2）

已知的小问题包括：战神 1 潘多拉神殿关卡水面反射偶尔出现纹理闪烁（属于已知限制，后续 GameDB 更新可能修复）；战神 2 宙斯最终战可能短暂掉帧到 35 FPS 以下（属于正常负载极限）；VU Stealing 调到 3 档时武器挥砍音效偶尔丢失，降低到 2 档可以解决。

### 高清纹理包：让老游戏焕发新生

PS2 游戏的原始纹理分辨率通常只有 64×64 到 256×256 像素。高清纹理包是社区玩家用 AI 放大 + 人工修图的方式把游戏里每一张纹理重绘成 1K–4K 分辨率的版本——比如把战神 2 的角色皮肤纹理从 128×128 放大到 2048×2048，细节就从色块变成能看到毛孔和布料纤维的程度。

纹理包和内部分辨率缩放解决的是不同层面的画质问题：分辨率缩放是把模拟器内部渲染输出做像素插值放大，没有真实细节；纹理包则是直接替换游戏内置的低分辨率纹理，效果提升最显著但需要社区玩家对每款游戏逐张纹理重绘。**最佳实践是两者叠加**——先开分辨率缩放提升整体像素密度，再加载纹理包提供真实细节替换。

启用纹理包的步骤很简单：

1. 在全局设置 → 图形中打开「加载外部纹理」开关
2. 在游戏运行中暂停，查看纹理替换目录是否已存在
3. 把下载好的纹理包文件直接放进对应的纹理目录
4. 重启游戏，纹理自动加载

纹理包存放路径为 `/Android/data/xyz.nether.sx2/files/textures/<游戏代号>/`，游戏代号是 PS2 游戏的官方标识（比如战神 1 是 SCUS-97364，战神 2 是 SCUS-97365）。如果目录不存在，先在模拟器中运行一次该游戏，模拟器会自动创建。

> [!NOTE] 性能注意
> 4K 纹理包在骁龙 845/855 上可能直接导致 VRAM 不够用而崩溃，建议骁龙 888+ 才使用 4K 包。1K 纹理包在任何支持 Vulkan 的设备上都没有压力。加载纹理包后第一次进入游戏会加载较慢（纹理解压 + 上传 VRAM），之后就正常了。

纹理包的获取渠道主要有三个：Patreon 上的纹理包作者（最优质，通常按月费）、GitHub（搜索「游戏名 + AetherSX2 texture pack」）、Reddit 的模拟游戏社区（热门游戏的纹理包讨论和下载链接经常在这）。一个好消息是 AetherSX2、NetherSX2、PCSX2 的纹理包格式完全相同，可以互相通用。
