## ✨ Free Download Manager 是什么

Free Download Manager（简称 FDM）是一款老牌的跨平台下载管理工具，支持 HTTP、FTP、BitTorrent、磁力链接等多种下载协议。它的核心卖点是**分段加速下载**——把一个文件拆成多个片段同时拉取，速度可以比单线程浏览器下载快数倍甚至十倍以上。桌面端覆盖 Windows、macOS、Linux，移动端有 Android 版本，iOS 暂未支持。

FDM 的主要能力集中在三块：**下载引擎**（多线程分段、断点续传、镜像源自动切换）、**BT 客户端**（DHT、Tracker 管理、做种、文件优先级）、**远程控制**（手机遥控桌面端添加/管理下载任务）。界面是现代四区布局，支持主题切换、快捷键自定义、浏览器扩展集成。

适合谁用：经常下载大文件（安装包、视频、压缩包）需要速度的；经常用 BT / 磁力链接的；需要用手机遥控家里电脑下载的。如果你只用浏览器偶尔下小文件，FDM 可能显得有点重。

## 🔧 安装步骤

### Windows 安装

Windows 平台的安装相对直接。下载安装包后双击运行，会弹出安装向导。注意几点：

1. **安装路径**：默认装在系统盘的 Program Files 目录。如果系统盘空间紧张，建议改到非系统盘，比如 `D:\Program Files\FDM\`。FDM 本身不大，但下载的临时分段文件会写入你设置的下载目录。
2. **杀毒软件误报**：少数安全软件（360、火绒等）可能把 FDM 的安装包或主程序误报为可疑——原因是 FDM 需要建立大量网络连接（分段下载），行为特征和一些下载器类软件重叠。遇到这种情况，把 FDM 加入白名单即可。
3. **安装完成后勾选"立即启动"**：FDM 会自动弹出首次启动向导，下面单独讲。

### macOS 安装

macOS 用户下载 `.dmg` 文件，双击挂载后把 FDM 拖进 Applications 文件夹。首次打开如果系统提示「无法验证开发者」，右键 FDM → 打开 → 在弹窗里再点一次「打开」即可绕过 Gatekeeper。

### Linux 安装

Linux 发行版之间差异较大。官网提供了 Ubuntu/Debian 的 `.deb` 包和 Fedora 的 `.rpm` 包。也可以通过各自发行版的包管理器直接安装——比如 `sudo apt install freedownloadmanager`。安装包体积大概 50MB~60MB，Linux 版界面和 Windows/macOS 基本一致。

> [!WARNING]
> 装完后**一定要核对版本号**。FDM 有 5.x 和 6.x 两代并行，6.x 是当前主线（界面全新重构、支持远程控制），5.x 是旧版维护。建议用 6.x 版本——远程配对、快捷键自定义、新主题这些功能都只在 6.x 上有。

## 📖 使用入门

### 首次启动向导：五分钟走完初始配置

安装完第一次打开，FDM 会弹出一个一次性的引导向导，**跳过后再想改全部要进偏好设置手动调**，所以建议耐心走完每一步。

向导分五步：

1. **选语言**：FDM 支持 24 种语言，系统是中文的话会自动识别默认选中「简体中文」。翻译质量中等偏上，大部分功能准确，少数高级项可能保留英文。
2. **设默认下载目录**：**不要用系统默认的「下载」文件夹**——容易堆东西混乱，也可能有权限限制。推荐自定义一个专门目录，比如 `D:\Downloads\FDM\`。勾上「按文件类型自动分类」后，FDM 会在这个目录下自动创建 video/、archives/、programs/、music/ 等子目录，下载完成按扩展名归档。
3. **浏览器集成**：向导会列出检测到的浏览器（Chrome、Firefox、Edge 等），勾选后 FDM 帮你跳转对应的扩展商店安装官方扩展。注意扩展安装本身还是要在浏览器里手动点确认。Chromium 内核的其他浏览器（Brave、Opera、Vivaldi）需要手动在扩展商店搜 "Download with Free Download Manager"。
4. **剪贴板监控**：默认勾选，**强烈推荐保留**。这个功能让你复制任何 URL 时 FDM 自动弹出「添加下载任务」对话框——比切到 FDM 主界面手动粘贴 URL 方便得多。如果觉得太敏感，可以进偏好设置设置 URL 过滤规则，只对 `.zip` `.torrent` `.mp4` 这类结尾的 URL 响应。
5. **确认摘要**：最后一步显示所有选择的摘要，确认无误点「完成」。

向导里任何选项跳过了或改主意了，都可以按 **Ctrl+O**（Windows）或 **Cmd+,**（macOS）打开偏好设置面板手动调整。但高级网络、协议设置建议保持默认——改坏了可能导致下载失败。

### 主界面四区导航：快速定位高频功能

FDM 6.x 采用现代四区布局，类似 VS Code 或 Steam 的组织方式：

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部菜单栏 + 工具栏                                              │  ← 第一区
├──────────────┬───────────────────────────────────────────────┤
│              │                                               │
│ 左侧分类面板  │              中央下载队列                     │  ← 第二区 + 第三区
│              │                                               │
├──────────────┴───────────────────────────────────────────────┤
│ 底部状态栏（流量模式、网络状态）                                  │  ← 第四区
└──────────────────────────────────────────────────────────────┘
```

**第一区是顶部菜单栏和工具栏**。菜单栏的高频入口：工具 → 首选项（Ctrl+O）、工具 → 浏览器集成、工具 → 远程控制（Ctrl+Alt+R）。工具栏按功能分组——添加下载、控制任务状态、操作已下载文件、视图过滤。工具栏按钮可以自定义：右键工具栏 → 自定义 → 添加/移除按钮、拖动排序。

**第二区是左侧分类面板**，是所有任务的导航树。按下载状态分（活动中/已完成/已取消）、按文件类型分（视频/压缩包/安装包/音频/种子）、还有专项工具入口（站点浏览器、HTML 蜘蛛、BT 全局视图）。面板可以用 F9 快捷键折叠，也可以拖拽边缘调整宽度。

**第三区是中央下载队列**，主窗口核心。任务列表显示文件名、进度条、速度、剩余时间、状态等列——点击任意表头可以排序，右键表头可以选择显示/隐藏哪些列。选中一个任务后，中央区下方出现详情面板，有常规信息、分段进度、BT 文件列表、Tracker 状态、Peer 列表、下载日志等标签页。排查下载失败时，看日志标签页最直接。

**第四区是底部状态栏**，显示全局状态。从左到右：当前流量模式（极速/温和/浏览优先，点击可切换）、网络连接状态、BT DHT 状态、全局下载速度、所有任务总剩余时间、当前做种的 BT 种子数。

托盘图标也不能不提。Windows/macOS 上 FDM 默认在托盘区显示图标：左键最小化/还原主界面，右键菜单可以快速全部暂停或继续、切换流量模式、退出。下载完成时有弹窗通知。

### 远程控制：手机遥控桌面端下载

这是 FDM 6.x 独有的高级功能——**用 Android 手机遥控家里的 PC/Mac 上的 FDM**。两端都需要 6.x 版本，桌面端是 Windows/macOS/Linux，手机端是 Android（iOS 没有 FDM）。

配对后能做什么：手机粘贴 URL 电脑自动开下、手机查看电脑下载进度并暂停/继续/删除、手机添加 BT 种子到电脑、一个手机可以配对多台电脑。

**PC/Mac 端开启远程控制**：

1. 打开远程控制面板——Windows 走菜单栏「工具 → 远程控制」或按 Ctrl+Alt+R，macOS 走「Free Download Manager → 远程控制」或 Cmd+Alt+R
2. 默认关闭，点「启用远程控制」
3. FDM 自动生成一个 6 位数配对码——**只在当前会话有效**，关闭 FDM 再打开会重新生成（这是安全机制）。也可以在偏好设置里手动指定固定配对码方便记忆
4. **强烈推荐设置远程控制密码**——如果电脑有公网 IP 或通过内网穿透暴露，配对码加密码是最后一道防线
5. 保持 FDM 运行（包括托盘图标不能退出），否则远程通道断开

**Android 手机端配对**：

三种方式，推荐扫码配对：

| 方式 | 操作 | 适用场景 |
|---|---|---|
| 扫码配对 | PC 端远程面板有二维码，手机 FDM 点「扫描 QR 码」对准即可 | 最常用，不手动输入任何数字 |
| 手动配对码 | 输入 PC 端局域网 IP + 6 位配对码 + 密码 | 扫码失败时备选 |
| 自动发现 | 同一 Wi-Fi 下 Android FDM 可能自动扫到附近已开启远程的 FDM | 连配对码都不用输 |

手机在外用蜂窝数据、电脑在家的情况稍微复杂。推荐用 **Tailscale / Zerotier** 这类组网工具——两端都装、登录同一账号、自动分配虚拟内网 IP，手机配对时填这个虚拟 IP 就行，不需要公网 IP、不需要路由器端口映射。

> [!TIP]
> 配对失败先按这个顺序排查：① 两端网络互通了吗（同 Wi-Fi 或 Tailscale）；② 电脑防火墙/安全软件有没有拦截 FDM；③ 配对码是不是旧的（重启 FDM 会刷新配对码）；④ Android 厂商 ROM 有没有杀后台（小米 MIUI / 华为 EMUI 需要手动锁后台+电池不受限+自启+关闭后台限制）；⑤ 路由器有没有开启「AP 隔离」阻止设备互通。

### 快捷键：高频操作指尖搞定

FDM 几乎所有操作都有快捷键，而且**全部可以自定义**（偏好设置 → 常规 → 快捷键）。默认已经比较合理，除非你之前用惯了 IDM 想保持类似布局。

核心操作的默认快捷键：

| 功能 | Windows | macOS |
|---|---|---|
| 添加下载 | Ctrl + N | Cmd + N |
| 从剪贴板添加 | Ctrl + Shift + V | Cmd + Shift + V |
| 暂停所有 / 继续所有 | Ctrl + Shift + P / Ctrl + Shift + G | Cmd + Shift + P / Cmd + Shift + G |
| 暂停选中 / 继续选中 | Ctrl + P / Ctrl + G | Cmd + P / Cmd + G |
| 删除选中 | Delete | Delete |
| 搜索当前列表 | Ctrl + F | Cmd + F |
| 打开远程控制面板 | Ctrl + Alt + R | Cmd + Alt + R |
| 首选项 | Ctrl + O | Cmd + , |

三个流量模式（极速 / 温和 / 浏览优先）默认没有绑定快捷键，但非常推荐各绑一个——比如 Ctrl+Shift+1 极速、Ctrl+Shift+2 温和、Ctrl+Shift+3 浏览优先。开会前一键切保守、开完会一键切回极速，比点状态栏下拉菜单快得多。

其他可以考虑自定义的：校验选中（Ctrl+Shift+C）、转换格式（Ctrl+Shift+M）、打开所在文件夹（Ctrl+Enter）。五个键（添加、全暂停、切模式、校验、远程控制）覆盖日常 80% 的高频动作。

快捷键没反应时先排查三步：确认 FDM 主界面是当前焦点、检查偏好设置里的快捷键面板有没有和系统或其他应用冲突、切到英文输入法状态试试（某些中文输入法会"吃掉"特定组合键）。Windows 的 Win+D、Win+L 这类系统级快捷键不可被应用覆盖，FDM 也不能用。

### 界面个性化整理

装好、向导走完、快捷键调好之后，花五分钟把主界面整理到舒服的状态：

1. 工具栏只保留高频按钮——移除镜像源管理、批量添加等不常用的
2. 加一个「校验」按钮到工具栏，下载完成后一键校验完整性
3. 左侧分类面板宽度调到 200px 左右，刚好看全分类名又不占空间
4. 下载队列表头只保留 5 个列——文件名、进度、大小、速度、剩余时间，隐藏类型、开始时间等
5. 状态栏保留别折叠，流量模式和网络状态日常需要关注

这样整理完的界面比默认清爽不少。至此 FDM 的安装、初始配置、日常高频操作就全掌握了，剩下的就是根据自己的下载场景慢慢挖掘。
