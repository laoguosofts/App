## ✨ MobiMusic 是什么

MobiMusic（摩比音乐）是一款面向 Android 平台的聚合音乐播放器——它自己不存音乐，而是通过多线路聚合的方式，把各大音源的歌曲汇集到一个界面里搜索、试听和下载。你可以把它理解成一个"搜索引擎 + 本地播放器 + 下载工具"的合体。

核心能力可以用一句话概括：**搜得到、下得动、播得稳**。搜歌的时候走聚合线路，一条挂了自动换另一条；下载支持 MP3 和 FLAC 无损格式，部分线路最高能到 24bit 采样率；播放侧基于标准 Android Service 实现后台常驻，切 App、关屏幕都不会中断。

适合谁用？不想在多个音乐 App 之间来回切换、想要一个统一界面管理所有音源的用户；想要下载无损 FLAC 到本地离线听的发烧友；以及喜欢自建歌单精细管理收藏的人。

## 🔧 安装步骤

摩比音乐以 APK 形式分发，安装前需要给手机授权"允许安装未知来源应用"。以下是完整的安装流程：

1. **下载 APK 文件**：通过上方下载入口获取最新版本的安装包，建议优先选择官方下载源以避免第三方魔改版。

2. **允许未知来源安装**：
   - Android 8.0 及以上：首次点击安装包时系统会提示"该来源首次请求安装权限"，点设置 → 打开"允许安装未知应用"开关即可。
   - 旧版本：设置 → 安全 → 勾选"未知来源"。

3. **安装 APK**：点击下载好的文件，按提示完成安装。过程中如遇杀毒软件误报，可以先临时关闭扫描——官方原版 APK 不含任何恶意行为。

> [!TIP]
> 安装前务必核对包名。摩比音乐官方原版常见包名为 `com.mobimusic`、`com.gsdok.gsd_civil_pp.mobimusic` 或 `com.change.lly.mobi.music`，包名不一致的 APK 大概率是魔改版或二次打包的山寨版，安装前请谨慎甄别。

4. **首次启动权限授予**：打开 App 后会依次请求存储读取、网络访问等权限，全部允许即可。

5. **核对版本号**：进入"我的 → 关于"查看当前版本，与下载页标注的最新版对比。如果不是最新版，建议直接在 App 内检查更新。

## 📖 使用入门

### 搜歌与播放

打开 App 默认进入搜索页面，直接输入歌名、歌手或专辑名都能查到结果。搜索结果按线路分组展示——同一首歌可能有多条线路可用，选哪条取决于你在乎音质还是速度：

- **高音质线路**：适合 Wi-Fi 或流量充足时使用，加载稍慢但能试听 FLAC 格式。
- **稳定线路**：加载快、覆盖全，但音质一般为 320kbps MP3。

播放页面的交互比较直观：中间是封面，下方是进度条和播放控制，右下角可以切换音源线路。如果当前线路突然抽风，点"换源"按钮就能自动跳到下一条可用线路。

### 无损下载

摩比音乐支持两种下载格式：MP3 和 FLAC。想要无损下载的话，在播放页或搜索结果里点下载按钮，弹出的选项里选择 FLAC 格式。部分线路还支持 FLAC 24bit 采样率下载，文件体积会比普通 FLAC 大不少。

> [!WARNING]
> 批量下载大量 FLAC 文件前，务必确认好下载路径和存储空间。默认保存在手机内部存储，如果手机装了 SD 卡且写入速度够快，可以在"我的 → 设置 → 下载设置"里改路径。Android 11+ 分区存储下，想存到任意目录需要额外授予 MANAGE_EXTERNAL_STORAGE 权限。

下载完成后，在"本地"页面可以按全部歌曲、歌手、专辑或文件夹四种方式浏览已下载的文件。这些文件是标准音频格式，任何播放器都能识别，复制到电脑或其他设备上直接用就行。

### 自建歌单

收藏的歌多了之后，全部堆在"我的收藏"里很难管理。自建歌单就是给收藏分类的好办法——跑步一个、通勤一个、学习一个、睡前一个，想怎么分就怎么分。

**创建歌单**：打开"歌单"页 → 点"新建歌单" → 输入描述性名称（比如"跑步 140 BPM"比"歌单 1"好得多）。

**往歌单加歌**有好几种快捷方式：
- 播放页点更多菜单 → "添加到歌单"
- 搜索结果长按歌曲 → 弹出菜单选歌单
- 专辑页勾选想加的歌 → 批量添加

**歌单维护**的常见操作：

| 操作 | 入口 |
|---|---|
| 重命名歌单 | 歌单页长按歌单卡片 → "重命名" |
| 删除歌单 | 歌单页长按歌单卡片 → "删除"（有确认弹窗） |
| 调整歌曲顺序 | 打开歌单 → 拖动歌曲条目到新位置 |
| 合并歌单 | 歌单页菜单 → "合并歌单" → 选源歌单和目标歌单 |

v1.4.3 版本修复了跨歌单添加偶尔无效的问题，还新增了从歌单移除歌曲时的确认弹窗。建议保持版本更新，bug 修复基本都在新版本里。

### 后台播放

音乐 App 后台播放被中断通常有三个原因：Android 系统杀进程、国产手机系统的激进后台策略、以及电量优化白名单没加。摩比音乐的后台策略基于标准 Android 前台服务实现——播放时通知栏出现常驻通知（告诉系统"我在做前台任务"，进程优先级提升），播放逻辑运行在独立 Service 进程里，即使 App 界面被回收 Service 还活着，重启后还能自动回到上次播放的歌曲和位置。

但国产手机系统默认对第三方 App 很不友好，需要额外做一些设置才能保证后台稳定：

| 品牌 | 需要做的设置 |
|---|---|
| 小米 / Redmi | 后台弹出界面 + 自启动 + 无限制省电策略 |
| 华为 / 荣耀 | 电池 → 启动管理 → 允许自启动 + 手动管理允许后台活动 |
| OPPO / vivo | 应用冻结 → 不冻结 + 应用自启动管理 → 允许 |
| 三星 | 后台使用限制 → 将摩比音乐加入白名单 |
| 原生 Android | 应用 → 摩比音乐 → 电池 → 不受限制 |

车载场景对后台播放稳定性要求最高——手机通常接在车上、屏幕朝下放。除了加后台白名单和关闭自动清理后台，还要确保蓝牙自动连接，这样用车机的蓝牙或 AUX 输出时才能无缝衔接。

### 版本更新

摩比音乐的版本更新频率不算低，每个版本通常都包含 bug 修复（下载失败、播放卡顿、跨歌单添加无效）、线路兼容性优化（聚合播放器的生命线就是音源线路的稳定性，哪家版权策略变了、哪家服务器换了 IP，都需要跟进调整）、以及小幅功能增加（FLAC 24bit 下载、自动换源下载、WebDAV 云同步等）。不更新的话很可能某天你发现常用的那条线路突然用不了了。

更新方式有两种：
- **App 内更新**：设置 → 关于 → 检查更新，有新版提示直接下载安装。大版本更新文件可能几十到上百 MB，建议用 Wi-Fi。
- **手动下载**：应用市场没推送的话，可以去奇珀网、脚本之家、多特等渠道手动搜最新版 APK，覆盖安装即可，歌单和收藏数据会保留。

> [!NOTE]
> 跨大版本更新后，一些设置项可能有变动。更新完建议检查一下默认音源、音质选择等关键设置是否符合你的使用习惯。如果新版出了问题想降级，同样覆盖安装就行，数据不会丢。
