## ✨ Tripo AI 是什么

Tripo AI 是一款面向创作者和开发者的 AI 3D 内容生成平台。它的核心能力是把文本描述、单张图片、多张视图或草图输入，在几秒到几分钟内转化为可用的三维模型，覆盖从概念验证到生产管线的完整链路。

Tripo 提供两条产品线：Studio 网页端面向设计师、游戏开发者和 3D 打印玩家，打开浏览器就能用，集成了智能分割、部件补全、重拓扑、纹理编辑和 Uni-Rig 自动绑骨等全套工具链；API 开发者版面向企业和开发者，支持程序化批量生成，可嵌入自建管线或 ComfyUI 节点。两条线共享同一底层 3D 重建大模型，但积分独立计算、互不通用。

典型的使用场景包括：游戏道具快速原型、AR/VR 应用资产、3D 打印模型生成、电商产品 3D 展示，以及 ComfyUI 工作流中的批量模型生成环节。对于不想从零学习 3D 建模的新手来说，Tripo 的智能低多边形功能还能直接把高模简化成适合实时渲染的轻量资产，省去手动减面的繁琐步骤。

## 🔧 注册与快速上手

Tripo Studio 没有传统意义上的"安装"过程——它是一个浏览器工作台，核心流程是注册账号、领取免费积分、开始生成。下面是完整的初始化步骤。

### 1. 注册与登录

Studio 入口地址为 studio.tripo3d.com。打开后点击注册，支持手机号验证码一键登录，也支持邮箱注册。首次登录即可自动成为免费用户，每月发放约 200 积分（大约 8 次基础生成），足够用于概念验证和轻量使用。

### 2. 领取免费积分后的注意事项

> [!TIP]
> 网页端积分和 API 积分是两套完全独立的积分池。在 Studio 充的积分不能用来调 API，反之亦然。新手最容易在这里踩坑，如果同时需要 Studio 和 API 能力，务必分别关注各自的积分余额和有效期。

### 3. 基础环境准备

Tripo Studio 是纯浏览器应用，对本地环境要求极低：

- **浏览器**：推荐 Chrome、Edge 或 Safari 最新版，国内环境下优先使用 Chrome
- **网络**：生成任务需要上传输入素材并接收模型文件，建议稳定带宽，大模型下载时 50MB 以上文件可能需要等十几秒
- **存储空间**：模型文件体积从几 MB 到几十 MB 不等，本地准备好存放目录即可，Studio 云端也会自动保存最近的生成历史

### 4. 第一次生成

进入 Studio 工作台后，左侧工具栏选择生成模式（文本、图片、多视图、草图四种），输入素材后点击生成按钮。等待几秒到几分钟，模型自动出现在画布中。免费版基础生成速度较慢，付费版 HD 精度模式下耗时更长，这属于正常现象。

## 📖 核心功能与高级玩法

这部分覆盖 Studio 工作台中实用的进阶能力，包括智能低多边形、多动画导出到 Blender、Studio 与 API 的选择对比，以及订阅管理中容易忽略的细节。

### 生成模式选择

Tripo 提供四种生成入口，适用于不同场景：

- **文本生成**：输入自然语言描述（例如"一把木质椅子，北欧风格"），适合没有现成素材时的快速概念生成
- **图片生成**：单张图片即可生成 3D 模型，适合从产品照片、插画或截图出发
- **多视图生成**：输入同一物体的多个角度照片，模型精度更高，适合对还原度要求高的场景
- **草图生成**：手绘或线稿输入，适合设计师从草稿直接进入 3D 阶段

四种模式共享同一底层模型，但积分消耗和生成速度各有差异。图片和多视图模式的精度通常高于纯文本，HD 精度模式产出更细腻但耗时更长、积分消耗更多。

### 智能低多边形

高面数模型（高模）在游戏、AR/VR、Web 3D 等实时渲染场景中往往跑不动。Tripo 的智能低多边形功能可以在 Studio 里直接把高模简化成性能友好的轻量资产，不需要切到 Blender 或 Maya。

它的核心特点不是简单减面，而是**主动保留轮廓和关键视觉特征**：大的形状转折处保持面数以防轮廓垮掉，细节集中区域适度保留，平坦区域则大幅简化。这和 Blender 的 Decimate 修改器类似，但完全在 Studio 工作区内完成，且针对 AI 生成模型的三角面分布做了专门优化——AI 生成模型的面数分布通常不太均匀（局部极密或极疏），Tripo 会先清理再简化，效果比通用工具更干净。

典型应用场景：

| 场景 | 说明 |
| --- | --- |
| HD → 游戏 | 先用 HD 模式生成高模保证精度，再用智能低多边形减面，一条线完成从概念到可用资产 |
| 移动端 AR | 手机上能流畅运行的面数通常在 1–5 万，智能低多边形帮你把高模压到这个范围 |
| Web 3D | 网页加载时间有限，资产越小加载越快，用户体验越好 |
| 批量资产 | 一款游戏需要 50 个道具时，每个都用智能低多边形能保证面数和风格统一 |

在 Studio 中触发：进入编辑面板 → 重拓扑 → 智能低多边形。基础重拓扑消耗 5 积分，智能低多边形变体额外 +30 积分，总计 35 积分。

### 多动画导出到 Blender

传统做法中，每个动作需要单独导出一个文件——走路一个 FBX、跑步一个 FBX、挥手一个 FBX，然后在 Blender 里分别导入、逐个添加到同一个 Armature 上。这个过程繁琐且容易出错。

Tripo Studio 支持在绑骨完成后，依次从动作库选择多个动作应用到模型，每个动作可以单独命名，然后**导出一个包含所有动画轨道的单文件**。导入 Blender 后，每个动作自动成为独立的 Action（动作编辑器左上角下拉菜单可以切换）或 NLA 轨道，逻辑清晰、管理方便。

导出格式推荐 GLB：单文件内嵌模型、骨骼、贴图和所有动画，导入 Blender 零配置。FBX 作为备选，行业通用但纹理可能作为独立文件，偶尔出现骨骼比例问题。Unity 和 Unreal 同样适用——带多动画的 GLB/FBX 直接导入后，所有动画轨道作为独立条目在动画面板中显示。

> [!TIP]
> 导出前务必确认 Studio 导出面板里"包含动画"和"包含贴图"两个开关已勾选。GLB 默认内嵌贴图，FBX 可能需要单独打包纹理文件。

### Studio vs API：该选哪个

Tripo AI 有两条产品线，共享同一底层 3D 重建大模型，但面向完全不同的用户群体。

| 场景 | 选 Studio | 选 API |
| --- | --- | --- |
| 单次或少量生成 | ✅ 全流程可视化操作 | ❌ 需要编程环境，对简单场景过重 |
| 需要分割 / 绑骨 / 纹理编辑 | ✅ 完整内置 | ❌ 当前主要覆盖生成环节 |
| 批量或程序化生成 | ❌ 手动逐条提交 | ✅ 异步任务，支持队列管理 |
| ComfyUI / 自建管线 | ❌ 无集成 | ✅ 有官方节点和 SDK |
| 不想装软件 | ✅ 纯浏览器 | ❌ 需要编程环境和网络配置 |
| 免费试用额度 | ✅ 每月约 200 积分 | 以 API 控制台政策为准 |

如果你是设计师、3D 打印玩家或独立开发者，Studio 基本够用；如果需要把 3D 生成嵌入企业内部工具链或 ComfyUI 工作流，就需要对接 API。两条线的积分完全隔离，消费后互不通用。

### 订阅与积分管理

Tripo 国内版通过支付宝提供订阅服务，支持月付和年付两种方式。订阅权益包括更高的积分额度、HD 精度模式解锁、优先生成队列等。

关于取消自动续费，有一个容易忽略的细节：**取消不会立即停止当前权益**。比如你在 3 月 15 日订阅，4 月 10 日取消自动续费——你还能用到 4 月 15 日，4 月 16 日起降回免费版。取消操作不在 Studio 里，而是在支付宝 App 内完成：支付宝 → 我的 → 设置 → 支付设置 → 自动续费 → 找到带 Tripo logo 的服务 → 关闭服务。

> [!WARNING]
> Studio 当前没有直接提供取消自动续费的入口，因为支付链路由支付宝管理。所有支付宝自动续费服务都在支付宝 App 统一管理，这是支付宝的通用规则，不是 Tripo 特例。取消自动续费也不等于退款，已支付的周期费用不会退回。

| 常见问题 | 解答 |
| --- | --- |
| 找不到 Tripo 服务？ | 确认登录支付宝的账号和 Tripo 订阅用的是同一个手机号 |
| 取消后 Studio 还是显示付费版？ | 正常，权益持续到当前周期结束 |
| 想马上降回免费版？ | 目前不支持提前终止，只能等当前周期自然结束 |
| 月付和年付取消区别？ | 流程完全一样，年付取消后当前年度权益继续有效 |
