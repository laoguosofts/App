## ✨ UltData 手机数据恢复工具

UltData 是一款专注于 Android 设备的数据恢复工具，同时提供 App 端和桌面端两种形态。它的核心能力是从手机存储介质中找回被误删的文件——照片、视频、音频、短信、社交应用消息等，覆盖了日常使用中最常遇到的数据丢失场景。

这款工具适合什么样的人？任何一个曾经手滑删掉过东西的手机用户都可以用它。不管是清理相册时误删了重要照片、聊天记录不小心清空、还是系统升级后某些文件神秘消失，UltData 都能帮你试着找回来。它不要求 root 权限就能完成大部分恢复操作，对普通用户比较友好。

从功能定位上看，UltData 把恢复分成几个层级：最优先的是系统回收站里的残留（速度快、成功率高），其次是数据库层的系统数据（短信、聊天记录等），最底层才是存储介质的深度扫描（文件碎片级别的找回）。这种分层策略能帮用户在不同场景下选到最合适的恢复路径，而不是一上来就跑耗时很长的深度扫描。

## 🔧 安装步骤

UltData 有两个平台的产品，安装方式各有不同，分别说明。

### Android App 版安装

1. 打开应用商店搜索 UltData，或从下载页获取 APK 文件
2. 如果是 APK 安装包，需要在系统设置里开启"未知来源"权限（设置 → 安全 → 允许安装未知应用）
3. 安装过程中系统会请求存储读取权限，**必须全部授权**——没有存储权限就无法扫描和恢复
4. 首次打开 App 时还需要授予短信、通讯录等敏感数据的读取权限，按需开启

> [!WARNING]
> 权限没开的后果：UltData 能启动但扫描不到任何可恢复数据，或者只能扫描部分数据。安装完第一件事就是确认权限状态。

### Windows 桌面端安装

1. 从下载页获取安装程序
2. 运行安装向导，默认路径即可，不需要额外配置
3. 安装完成后首次连接手机时，需要在手机上开启 **USB 调试**（设置 → 关于手机 → 连续点击版本号激活开发者选项 → 返回开发者选项开启 USB 调试）
4. 手机连接电脑后，会弹出"允许 USB 调试"的授权弹窗，勾选"始终允许"后点确定

> [!TIP]
> USB 调试是桌面端恢复的前提条件，没有开启的话手机连接到电脑后 UltData 识别不到设备。如果识别失败，先检查数据线是否支持数据传输、换一个 USB 接口试试。

### 版本核对

安装完成后可以在应用内或"设置 → 关于"里看到当前版本号。建议保持最新版本，新版本通常会修复扫描算法、增加新机型支持。

## 📖 使用入门

UltData 的恢复操作有一定的学习曲线，但抓住几个核心原则就能快速上手。下面从实际使用流程出发，把关键技巧和常见场景串起来讲。

### 先扫回收站——最快最准

Android 11 及以上版本自带系统回收站，删除的照片和视频默认保留 30 天。UltData App 版首页有一个专门的回收站恢复入口，能自动检测系统回收站里还没被彻底清除的内容。

这是**最优先尝试的恢复路径**：扫描速度秒级完成（不像深度扫描要等几分钟甚至几十分钟）、成功率几乎 100%（数据还在系统里，只是被标记为待清理）、恢复出来是完整的原始画质。不同品牌手机的回收站入口位置不一样，但 UltData 不需要你手动找，打开 App 首页就能直接看到扫描结果。

如果回收站里能找到目标文件，直接勾选恢复即可。找不到再考虑深度扫描。

### 预览和选择性恢复

很多恢复新手容易犯一个错误：扫描完直接全选恢复。这其实是不对的——扫描结果里混着三种东西：本来就在系统里的正常文件（不是你要的）、已损坏的残缺文件（恢复了也没用）、以及完整可恢复的目标文件。

正确的做法是扫完先过滤、再预览、最后选择性恢复。UltData 提供了几个实用的筛选维度：

| 筛选维度 | 用途 |
|---|---|
| 文件夹分组 | 按来源目录分组，比如 WhatsApp、Instagram、相机 |
| 时间排序 | 快速定位某一天或某段时间删除的内容 |
| 是否已删除标记 | 过滤掉还在系统里的正常文件 |
| 格式筛选 | 只看 MP4 视频、只看 PDF 文档等 |

图片和视频的预览尤其重要：视频恢复前一定要先播放一遍，能流畅播放说明文件完整放心恢复；如果播到一半卡住或花屏，说明文件已损坏，恢复了也没用。社交应用消息恢复也类似——只有文本框里有内容的才是可恢复的，空白的说明已经被完全覆盖。

> [!TIP]
> 恢复操作会向存储介质写入新数据，恢复不需要的文件可能覆盖还没被覆盖的被删数据。所以宁可只勾几个确认过的文件，也别一股脑全选。

恢复到哪里也有讲究：SD 卡恢复时，恢复出来的数据绝对不能写回同一张 SD 卡——写入会覆盖还没恢复的残留。应该导出到电脑或其他存储位置。

### 短信恢复——仅限桌面端

短信恢复是桌面端独有的功能，App 版不支持。操作前需要手机解锁、USB 调试已开启，并在手机上授予短信读取权限。

桌面端连接手机后，进入 Android Data Recovery 模式，勾选 Messages（短信）数据类型开始扫描。短信数据库比照片小很多，扫描速度很快。扫描完成后，短信按会话线程分组展示，和系统短信 App 的组织方式一致。

每条被删除的短信会有"已删除"标记，恢复结果分三种情况：完整内容（系统缓存没被覆盖）、部分内容（被部分覆盖）、只有发送者号码内容空白（被完全覆盖）。这是因为系统删除短信时并不是真正删掉数据库里的行，而是标记为"已删除"等待新数据随机覆盖——覆盖越多，能恢复出来的内容越少。

恢复出的短信可以导出为 CSV 或 HTML 文件存档，也可以直接写回手机作为新短信写入数据库（注意接收者看到的是你自己的号码发出的）。桌面端还有内置搜索框，可以按内容、号码、时间过滤。

> [!NOTE]
> SIM 卡短信是系统短信之外的一条恢复路径。部分运营商会在 SIM 卡上备份短信，SIM 卡能存的条数有限（通常 100~500 条），但可能藏着你想要的旧短信。在手机短信 App 的设置里找"管理 SIM 卡信息"就能查看。

### 音频恢复——多种来源全覆盖

UltData 对音频文件的覆盖范围比较广，从普通的录音、音乐到社交应用语音消息都能处理。不同来源的支持情况如下：

| 来源 | 格式 | App 版 | 桌面端 |
|---|---|---|---|
| 手机录音 | AMR、WAV、MP3、M4A | ✅ | ✅ |
| 音乐文件 | MP3、FLAC、AAC、WAV | ✅ | ✅ |
| WhatsApp 语音 | OPUS 格式 | ✅ | ✅（更完整） |
| WeChat 语音 | AMR 格式 | ❌ | ✅（限小米/华为 + Android 12 以下） |
| 通知铃声 | MP3、OGG | ✅ | ✅ |

这里面有一个特殊情况：WhatsApp 和 WeChat 的语音消息不是普通的音频文件，它们存储在应用私有数据库里。UltData 需要用 WAL（Write-Ahead Logging）技术从数据库日志中提取。WhatsApp 的支持比较完善，App 版和桌面端都能提取；WeChat 语音目前只有桌面端支持，而且仅限小米和华为品牌、Android 12 及以下版本。

恢复出来的音频文件可能和原文件名不完全一致，建议先听一下确认内容再归档。系统自带的音乐 App 可能不会立刻刷新列表，但在文件管理器里能直接看到恢复出的文件。

### 使用流程总结

把上面的技巧串起来，日常恢复的完整流程大概是这样：

1. 安装 App 版，确认所有权限已开启
2. 打开 App 先扫回收站——有就直接恢复，到这里结束
3. 回收站找不到 → 根据丢失文件的类型选择对应的恢复入口（照片、视频、音频、社交应用消息）
4. 扫描完成后过滤掉还存在的文件、按时间或格式分组定位
5. 逐张预览确认完整性
6. 勾选目标文件 → 选择恢复位置（SD 卡恢复必须导出到别处）→ 恢复
7. 如果需要恢复短信或 WeChat 语音，切换到桌面端操作
