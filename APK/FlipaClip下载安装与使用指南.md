## ✨ FlipaClip 是什么

FlipaClip 是一款主打移动端的**逐帧动画创作工具**——你在一帧一帧之间手绘，它把这些帧连起来变成动画。不同于那种预设动作的动画 App，FlipaClip 给你的是一块空白画布和完整的时间线，每一帧都由你自己画。核心功能覆盖手绘笔刷、图层系统、时间线管理、音频配音、视频导入转描以及成片导出，完整跑通了从创意草图到成品动画的整个流程。

它的设计哲学很明确：**让逐帧动画回到"画"本身**。界面是手绘软件的思路——画笔、橡皮擦、填充、取色器放在左侧常驻，时间线在底部占一整条，画布区域尽量保留最大空间。对新手来说，没有复杂的参数面板和节点图，上手只需要选个画笔开始画；对有经验的动画师来说，图层不透明度、帧拉伸与分组、镜像辅助等功能又能支撑起进阶工作流。

适用场景相当广：想在短视频平台发自己画的小动画、做角色设计的动作测试、给教学视频画示意图、甚至作为专业动画师在移动设备上做快速分镜草稿，FlipaClip 都能胜任。它在 Google Play 上的定位是 "Animation Creator"，积累了数百万级的下载量，社区里能看到从个人创作者到小团队工作室的各种作品。

## 🔧 安装步骤

FlipaClip 支持 Android、iOS、Windows、macOS 四个平台，各平台安装流程略有差异，下面分别说明。

### Android 安装

1. **优先走 Google Play**：打开 Play Store 搜索 FlipaClip，点击安装即可自动完成，无需额外授权。
2. **APK 直装**：如果通过下载页获取 APK 文件，安装前需要在系统设置里开启"允许安装未知来源应用"（不同品牌 ROM 路径略有差异，一般在安全设置或应用管理里）。
3. **版本核对**：安装完成后在应用内「关于」页面核对版本号与下载页标注是否一致，避免装到旧版。

> [!WARNING]
> 部分国产手机 ROM 会默认拦截未知来源安装，开启权限后记得装完关掉，避免长期暴露风险。

### iOS 安装

1. 打开 App Store 搜索 FlipaClip，点击获取。
2. 首次打开时系统会询问通知、麦克风（配音用）、相册（导出保存）权限，按需允许即可。
3. iOS 端不支持 APK 或 IPA 侧装，全部走 App Store 分发。

### Windows / macOS 安装

1. 从下载页获取对应平台的安装包（Windows 为 `.exe`，macOS 为 `.dmg`）。
2. Windows 运行安装向导，选择安装路径后下一步即可；macOS 把应用拖入 Applications 文件夹。
3. Windows 安装时如遇杀毒软件误报，添加信任即可——官方签名可在安装包属性里查看。

> [!TIP]
> 多设备同步：FlipaClip 支持在登录账号后跨设备同步工程草稿，手机上画了一半，回电脑可以接着画，前提是在所有设备上登录同一个账号。

## 📖 使用入门

### 界面布局速览

打开一个新工程，你会看到三块核心区域：

- **左侧工具栏**：画笔、橡皮擦、填充、取色器、形状、文字、尺规、镜像，双击画笔图标可以展开二级菜单。
- **底部时间线**：横向排列的帧序列，点击某帧切换到该帧进行编辑；时间线右侧有播放控制和帧号显示。
- **中央画布**：主要作画区域，双指缩放、双指旋转可以调整视角，长按某帧可以拖拽排序。

### 画笔与镜像：对称作画加速器

FlipaClip 的画笔支持多种笔头样式，从铅笔到马克笔到喷枪都有。一个被低估的小工具是**镜像（Mirror）**——它和尺规同在一个二级菜单，双击画笔图标就能找到。

开启镜像后，你在画布一侧落笔，另一侧会自动出现对称笔迹。画正面角色的五官、对称图案、徽章花纹时特别省时间——画一次得一对。配合圆形尺规使用效果更佳：开圆形尺规画头部轮廓，同时开镜像保证左右对称。

> [!NOTE]
> 镜像只是作画辅助，不影响成片的摄影机轴和画面翻转。复杂动作里角色很少绝对对称，镜像画完的部分往往还要单独修饰——把它当起稿加速器，别当成最终答案。

### 帧与时间线：驻留与循环

逐帧动画最头疼的两件事：一张静态画面要停住三秒（比如片头文字），一段动作要循环好几次（比如角色挥手四轮）。旧做法是复制粘贴几十帧，工程里堆满重复帧，改起来麻烦。

FlipaClip 给了两个结构化方案：

**驻留单帧**：在时间线上抓住帧的右边缘横向拖拽，这一帧就被拉长到任意时长。视觉效果和复制粘贴一样，但工程里只有一份数据，文件更小，改时长只动一个方块。

**多帧循环**：一段动作要重复 N 次时，按住第一帧开始滑选，把这段动作的所有帧选中，执行打组（Group），多帧变成一个组方块。拉伸组的边缘，组内内容自动循环铺满你拉出的时长。想改循环次数？重新拉组边缘就行，不用动组内任何一帧。

| 需求 | 用哪个 |
| --- | --- |
| 单张静态画面停留 | 拉伸单帧 |
| 一段动作重复 N 次 | 打组后拉伸 |
| 停留后画面要修改 | 拉伸单帧（数据只有一份） |
| 复制之后要各自改不同细节 | 复制粘贴仍是正解 |

> [!TIP]
> 拉伸和分组只作用于画面帧，音频轨是独立的。驻留画面变长后记得回时间线检查音频落点是否还对齐，对不上就手动拖动音频块微调。

### 图层系统：显隐与不透明度

图层是 FlipaClip 进阶工作流的基础。默认新建工程只有一个图层，你可以叠加多个图层——比如底色层、线稿层、上色层、背景层。

**隐藏层**：点图层右侧显示"100%"的文字位置，该层立即隐藏；恢复时点被划掉的"眼睛"图标。典型用法：多帧核对角色动态时暂时藏起背景层，或者画上层内容时藏住干扰视线的下层细节。

**不透明度调节**：选中目标图层，点右侧百分比数字，**按住后上下滑动**就能调。这个功能在**转描工作流**里是核心参数——导入视频当参考底图后，把视频层不透明度调到 40%~60%，在半透明的视频上描摹轮廓，太高看不清自己的线稿与视频的边界，太低视频糊成一片描不准。

> [!WARNING]
> 图层不透明度影响整层所有帧。如果你只想让某一帧的某块颜色变淡，应该用画笔/油漆桶工具的颜色透明度，两者作用范围完全不同，别搞混。

### Time-lapse：把绘画过程录成成长视频

这是 FlipaClip 里社交属性最强的功能。Time-lapse（延时）自动把你在工程里的**绘画过程**录成视频——观众看到画一笔一帧浮现的全过程，这类"过程回放"在短视频平台的播放量通常比成片更高。

默认是关闭的，两种开法：

**按工程开**：在首页按住某个工程，点出现的计时器图标，三个选项——Share Time-Lapse（导出已录的过程视频）、Time-Lapse recording（开启录制）、Delete Time-Lapse Recording（删除已录内容）。

**全局默认开**：在应用设置的 Stage Options 里可以设为所有新工程默认录制，并指定录制帧率：12 / 20 / 24 / 30 FPS 四档。

录制的规则很智能：**只录操作，不录发呆**——画画、切工具、改帧才被记录，闲置时间自动跳过，成片紧凑。关了再开，之前的录制还在，不会互相覆盖。但存储代价要心里有数：录制在后台持续生成视频文件，工程越大、画得越久，过程视频越大。存储紧张时定期用 Share 导出后清理，或者只对重点工程开录制。

一个常用的内容创作组合拳：**延时视频（过程）+ 成片（结果）一起发**，过程视频展示功力，成片展示效果，两个配合发在社交平台上效果翻倍。

### 上手建议：从三分钟小动画开始

不要一开始就挑战长篇动画。拿一个简单的创意——比如一个小角色在屏幕上挥手——按以下节奏推进：

1. 新建工程，画第一帧（角色正面）；
2. 用镜像工具画对称部分（眼睛、嘴）；
3. 画中间帧和结束帧，用帧拉伸让静止部分驻留；
4. 加一段背景音乐，配音轨在时间线下方；
5. 打开 Time-lapse 录制，画完后导出过程视频；
6. 成片导出用"制作影片"流程，选分辨率和帧率，保存到相册或直接分享。

这个流程走完一遍，FlipaClip 的核心功能就基本摸透了。后续再尝试视频导入转描、多图层复杂场景、配音字幕等进阶玩法。
