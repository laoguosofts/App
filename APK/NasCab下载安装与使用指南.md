## ✨ NasCab 是什么

NasCab 是一款面向家庭用户的轻量级 NAS（网络附加存储）解决方案——把家里闲置的电脑或 Mac 变成一台私有云服务器，集中管理照片、影音、文件，同时通过专属域名实现外网访问，不需要公网 IP。

它的核心能力围绕家庭内容消费展开：照片库自动识别 EXIF 信息按时间地点归档，影音库支持刮削元数据生成海报墙，文件浏览器提供局域网共享和远程下载，还有多用户权限体系让家人各用各的互不干扰。

相比群晖、威联通等品牌 NAS 需要专门硬件和较高预算，NasCab 走的是「软件即服务」路线——你只需要一台常开的 Windows PC 或 Mac，装上它就能用，成本低、上手快。适合不想折腾硬件但又想把家庭数据握在自己手里的用户。

## 🔧 安装步骤

NasCab 的服务端支持 Windows、macOS、Linux 三大桌面平台，移动端提供 iOS 和 Android 客户端。安装前先确认自己的运行环境。

### Windows 平台

1. 从下载页获取最新版 `.exe` 安装包
2. 双击运行，按向导完成安装（建议安装在非系统盘，方便后续扩展存储）
3. 首次启动会在浏览器自动跳转至 `http://127.0.0.1` 进入初始化流程
4. 设置超级管理员账号（用户名 + 密码，记牢，后续权限管理全靠它）

> [!WARNING]
> Windows Defender 或其他杀毒软件可能对 NasCab 的本地服务进程误报，添加信任即可——软件本身不做任何加密或挖矿行为。

### macOS 平台（Intel / Apple 芯片）

NasCab 分别提供了 Intel（X64）和 Apple（arm64）两种芯片架构的安装包，下载前要先确认自己的 Mac 型号：

- **Intel 芯片**：关于本机 → 处理器 显示 Intel Core i5 / i7 / Xeon 等
- **Apple 芯片**（M1 / M2 / M3 / M4）：关于本机 → 芯片 显示 Apple M 系列

安装步骤：

1. 下载对应架构的 `.dmg` 文件
2. 双击 dmg，把 NasCab 图标拖到 Applications 文件夹
3. 首次启动遇到 Gatekeeper 警告时，右键点击 NasCab → 选「打开」→ 弹窗里点「打开」确认
4. 启动应用或浏览器访问 `http://127.0.0.1`，创建管理员账号

Mac 上的数据库缓存目录位于：`/Users/你的用户名/.local/share/nascab`

> [!NOTE]
> Mac 休眠后 NasCab 服务也会停止。如果需要 7×24 运行，在系统设置里关闭自动休眠，或者使用 `caffeinate` 命令阻止睡眠。

### 安装后核对

完成初始化后，在主界面检查：

- 版本号是否与下载页标注一致
- 服务状态显示「运行中」
- 局域网其他设备能否通过内网 IP 访问

## 📖 使用入门

### 内网穿透——外网访问不需要公网 IP

绝大多数家庭宽带背后是运营商的 CGNAT（运营商级网络地址转换），外网直接访问家里的设备会被拦掉。公网 IP 也越来越难申请：电信联通需要打客服碰运气，移动基本不给，就算有了还要手动配置路由器端口映射。

NasCab 的解决方案是**打洞 + 中继**组合，全程不需要你操心网络配置：

1. 家里的 NasCab 服务端主动连出去，建立一条到中继服务器的持久连接
2. 你在外面访问 `用户名.nas-cab.com`，请求先到中继服务器
3. 中继服务器通过那条持久连接把请求转发到你家里
4. 响应也走同一条路原路返回

**关键区别**：是家里的 NasCab **主动连出去**，而不是让外面被动连进来——运营商防火墙通常放行出方向连接，所以这套方案不会被拦。

中继服务器方案的速度瓶颈主要取决于两个因素：家里的**上传带宽**（最关键，千兆宽带上行一般只有 50-100Mbps），以及中继服务器的承载能力（所有用户共享）。对比自建 frp 穿透方案，NasCab 把云服务器中转、配置文件、运维维护全封装到了一键开通里，开箱即用。

### 多用户权限管理

NasCab 默认一个超级管理员账号（安装时创建），可以创建任意数量子账号，权限分两层控制：

**第一层：模块访问**——管理员给每个子账号选择能进哪些模块（照片 / 影音 / 音乐 / 文件 / 图书 / 磁盘共享）。

**第二层：路径级控制**——在文件浏览器和各模块的来源文件夹里，可以给每个子账号单独授权具体路径。比如管理员看全部磁盘，给老婆的子账号只授权照片和影音模块里的个人目录，给孩子的子账号关掉文件浏览器防止误删。

子账号之间数据完全隔离：看不到未授权的路径和模块，默认只能看和下载，删文件权限需要单独开。网页端和客户端都支持快速切换账号，不用退出重登录。

家庭共用的典型分配方案：

| 账号 | 权限 | 备注 |
|------|------|------|
| 管理员 | 全部 | 自己使用 |
| 配偶 | 照片 + 影音 + 文件 | 照片库授权个人照片目录 |
| 孩子 | 影音（仅卡通文件夹） | 文件浏览器权限关掉 |
| 访客 | 照片（只读） | 仅查看，不能上传和删除 |

### 媒体整理与图片压缩

3.6.0 版本新增的「媒体工具」模块提供了两个实用功能：

**图片压缩**：批量压缩本地照片文件体积，适合上传网盘或发社交平台。支持 JPEG / HEIC / PNG 等常见格式，可以设置压缩质量百分比和最大输出尺寸，输出到指定目录。

**媒体整理**：按规则自动整理照片文件夹结构，比如把散在不同目录的照片按「年/月」归档到同一个目录下。

> [!WARNING]
> 媒体整理**会移动原文件**——这和 NasCab 默认的「只读扫描」定位相反。使用前务必先备份重要目录，压缩前也建议先备份原图。

入口在照片管理 → 媒体工具（设置或顶栏里找）。这两个工具是「主动对原文件动手」的操作，使用前一定要谨慎。
