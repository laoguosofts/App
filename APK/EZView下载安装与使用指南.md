## ✨ EZView 是什么

EZView 是宇视（Uniview）推出的一款移动端视频监控管理应用，专门用于接入和操控宇视自家的监控硬件。它的核心能力很明确：远程查看 IPC 网络摄像机的实时画面、回放 NVR 存储的录像、控制 PTZ 云台转动、与现场进行双向对讲——一整套日常运维监控所需的操作都集中在这个 App 里完成。

EZView 不是万能通吃所有品牌的通用监控客户端，它只兼容宇视的产品线。目前支持的设备类型包括：**IPC 网络摄像机**（枪机、球机、PTZ、鱼眼、Wi-Fi 机型）、**NVR 网络录像机**、**人脸识别终端**以及宇视的视频管理平台 VMS。接入路径有两种——IPC 可以直接通过 P2P/DDNS/局域网方式连到 App，也可以先接入 NVR 再由 NVR 转发给 App，两条路径都支持双向对讲和 PTZ 控制。

适用场景方面，EZView 覆盖了从家庭小店铺到中小型企业的安防监控需求：装修师傅装了一台宇视 Wi-Fi IPC 在家门口，用 EZView 就能随时看门口情况；连锁门店的运维同事需要同时查看十几个门店的摄像头画面，EZView 多画面切换和回放功能够用；甚至在一些纯内网的合规项目里，设备不允许上外网，EZView 的本地直连模式也能跑通实况和 PTZ。

很多人第一次接触 EZView 时会发现，它内置了**演示设备**（Demo devices），直接在 App 里就能预览实况、回放、告警推送等全部功能——不用先买宇视硬件就能把整条流程跑通一遍。这对想先试用再决定是否采购的用户来说是个很贴心的设计。

## 🔧 安装步骤

安装过程本身并不复杂，但不同平台有几个需要注意的点。

**Android 平台**：
1. 从下载页拿到 APK 安装包后，在手机设置里找到「安全与隐私」或「应用安装权限」，开启对文件管理器或浏览器的「允许安装未知来源应用」授权
2. 用文件管理器找到下载好的 APK，点击安装——系统如果弹出安全提醒，确认继续即可
3. 安装完成后第一次打开 App，会请求摄像头、麦克风、存储权限，全部允许

> [!WARNING]
> Android 11 及以上版本的权限管控更严格。如果装完后双向对讲用不了，多半是麦克风权限没开，去系统设置里单独给 EZView 手动授权即可。

**iOS 平台**：
1. 直接在 App Store 搜索「EZView」点击获取
2. 系统会请求通知权限——建议开启，否则后续设备离线告警、异动推送都收不到
3. App Store 版本是经过苹果签名的，不存在未知来源问题，安装最省心

**PC 平台**：EZView 主要定位移动端，官方并未推出正式的 Windows/Mac 桌面版。需要在电脑端操作监控的用户，可以考虑宇视的 Web 客户端或者第三方宇视 SDK 集成方案。

> [!TIP]
> 安装完成后建议在 App 里确认一下版本号（「我的」→「关于 EZView」），对照官方最新发布版本看是否需要升级。老版本固件在某些新型号设备上可能会出现 PTZ 按钮不显示、对讲不可用等兼容性问题。

## 📖 使用入门

### 设备接入：先选模式

EZView 有两种完全不同的使用模式——**云绑定**和**本地直连**，核心区别在于是否依赖宇视的 EZCloud 云端服务。

| 对比项 | 本地直连 | 云绑定 |
| --- | --- | --- |
| 实况查看 | ✅ | ✅ |
| 录像回放 | ✅ | ✅ |
| PTZ 控制 | ✅ | ✅ |
| 双向对讲 | ✅ | ✅ |
| 远程配置 | ✅（部分） | ✅（完整） |
| 告警推送 | ❌ | ✅ |
| 设备分享 | ❌ | ✅ |
| 多手机同步 | ❌ | ✅ |
| 固件升级 | ❌ | ✅ |

简单来说，**核心的监控操作——看、放、转、说——两种模式都能用**。被裁剪掉的是那些依赖云端中转的功能：告警推送、设备分享、跨设备同步、固件远程升级。

选择本地直连的典型场景：项目完全在内网，设备不允许上外网（合规要求）；或者暂时不想注册云账号，先测通链路再说。进入本地直连很简单——打开 App，在登录页**什么都不输入**，直接点下方的「扫一扫」「IP 直连」或「局域网自动发现」任意一种方式添加设备即可。设备加完能正常开实况，就是本地直连模式了。

> [!NOTE]
> 本地直连的设备列表存在手机本地数据库里，不会同步到任何地方。换手机、重装 App、清除 App 数据，本地设备列表就没了。建议换手机前把每台设备的注册码/P2P 码手动记下来，或者之后注册云账号把本地设备同步上云。

实际项目中两种模式经常**混用**——外网能通的设备走云绑定享受完整功能，内网纯离线的设备走本地 IP 直连只求能看实况。App 里云绑定和本地直连的设备会同时出现在列表中，用小图标区分：云朵图标代表云绑定，无图标代表本地设备。

### PTZ 自动校准：云台方向不准怎么办

PTZ 球机安装好之后方向都是正的，但如果被外力碰过（大风、施工、人为推）、手动拧过云台，或者极少数情况云台电机失步，就会出现方向偏移——点左球机转向不是严格往左，或者调 PTZ 预设位时到达的位置不准。

EZView 内置了**自动校准功能**，路径是：PTZ 设备详情 → PTZ 设置 → 自动校准。整个校准过程 30–60 秒，球机会自己做几个「摇头晃脑」的动作：先转到最左最上方的物理零点记录坐标，再依次转到正前方、最右、最下、正上方等几个点，对比理论坐标和实际坐标算出偏差补偿值，后续所有 PTZ 操作都会应用这个补偿。

> [!WARNING]
> 校准过程中**不要碰球机、不要挡住它的转动范围**——中途干扰会导致校准失败，需要重来一次。

自动校准的一大好处是：校准后**所有已存的 PTZ 预设位坐标都会自动修正**，不需要一个个重新存取。

少数老型号 PTZ 不支持自动校准，会提供手动校准界面——在 PTZ 设置里选「手动校准」，用手势把球机慢慢转到你认为正确的正前方，点「设为零点」即可。

哪些设备支持自动校准？2018 年之后生产的宇视 PTZ 球机一般都支持；老型号半球、固定机（本身没有云台的）不需要也不支持校准。不支持的型号在 PTZ 设置页面里**找不到自动校准选项**。

### 设备离线排查：从上到下概率递减

使用 EZView 时最常见的问题就是设备显示离线——卡片变灰、点开提示「设备离线、无法连接」、实况窗口打不开。排查时按下面的顺序来，概率从高到低：

**第一步：电源和物理连接**（最常见）
- 看 IPC/NVR 指示灯亮不亮——完全不亮就是电源问题
- 网线有没有插紧？交换机或路由器端口指示灯闪不闪——不闪说明网线没通
- Wi-Fi 设备：在路由器后台看 Wi-Fi 列表里能不能搜到这台设备

**第二步：设备能不能拿到 IP**
- 用同一局域网的电脑 ping 一下设备 IP，能通但 EZView 还是离线，问题在 P2P 或云绑定；不能通说明设备根本没入网，先解决物理或路由器问题

**第三步：公网能否访问**（云绑定场景）
- 云绑定要求设备能访问公网，至少能连上 EZCloud。如果项目现场是纯内网、不能上外网，云绑定必然离线——要么改用本地直连，要么给设备开外网出口。另外检查 DNS 有没有配置，设备需要 DNS 才能解析 EZCloud 域名

**第四步：P2P 注册码**
- 设备有没有被重置过？重置后注册码会变，而 EZView 里存的还是旧注册码，对不上就会显示离线。注册码扫的时候也可能识别出错，极少数情况需要手动输入核对

**第五步：云账号绑定状态**
- 在设备详情里看「云绑定」状态，显示「已绑定到账号 X」说明绑定 OK，显示「绑定异常」就让设备重新联网或解除绑定后重新扫码

**极端情况：EZCloud 临时故障**
- 同一账号下其他设备如果也全部离线，大概率是 EZCloud 侧维护或故障了——等 5–10 分钟刷新，或看宇视官方公告

### 设备家族与接入架构

EZView 接入硬件有两种路径：

```
路径 A：IPC 直连
  EZView App ──► (P2P / DDNS / LAN) ──► IPC

路径 B：IPC 经 NVR 转发
  EZView App ──► NVR ──► 下挂的 IPC
```

两种路径都支持双向对讲和 PTZ 控制，实际能力取决于设备本身——老型号可能 PTZ 控制按钮不出现、鱼眼去畸变开关灰掉、对讲按钮点了提示功能不可用。这不是 App 的问题，是硬件固件版本或型号本身就不支持，对照设备的 quick start manual 查一下具体型号的能力清单最准确。

对于多画面同时查看的需求，EZView 支持 1 到 16 路画面切换（具体上限取决于设备型号和 App 版本），在实况页面点「多画面」按钮就能自由选择布局。回放时支持时间轴拖拽、快进快退、按事件搜索，四路同步回放也是近年来迭代中新增的实用功能。
