## ✨ ExtensoDesk 是什么

ExtensoDesk 是一款让安卓设备秒变电脑第二显示器的跨平台软件——在 Windows 电脑上安装服务端，安卓平板或手机上装客户端，通过 WiFi 或 USB 连接后，平板立刻变成一块独立的扩展屏幕，窗口可以自由拖拽过去，配合手写笔还能实现压感绘图。

这款软件的定位很清晰：它不是单纯的屏幕镜像工具，而是把平板真正当做第二块显示器来用。扩展屏模式下，Windows 会把平板识别为显示器 2，两块屏各自独立运行，主屏写代码、副屏查文档，主屏做设计、副屏放素材，是程序员、设计师、写作者提升效率的常用方案。

ExtensoDesk 还提供了几个实用的进阶能力：开机自启让电脑和平板两端都配置好之后可以实现拿起即用的零操作体验；手写笔测试工具可以快速定位压感问题到底出在笔、ExtensoDesk 还是创作软件；极限性能模式在游戏和绘图场景下能进一步降低延迟。

## 🔧 安装与基础配置

ExtensoDesk 的安装分两端：Windows 电脑装服务端，安卓设备装客户端。两端版本建议保持较新的状态——v1.2.0 之后开机自启不再弹窗，v1.3.4 修复了自启偶发失败，v1.3.5 进一步优化了自启逻辑；Android 端 v1.4.2 起可以直接在平板上修改服务端模式选项。

### Windows 服务端安装

1. 从下载页获取安装包，以管理员权限运行安装器
2. 按向导选择安装路径，默认路径即可
3. 安装完成后首次启动，建议立即在设置里打开「开机自动运行」开关
4. 检查开机自启是否生效的方法有两种：一是重启电脑后不手动启动 ExtensoDesk，直接在平板上扫，能扫到 = 自启成功；二是打开任务管理器 → 启动标签页，确认 ExtensoDesk 在列表中且状态为已启用

> [!WARNING] 安全软件拦截自启
> 360、火绒等安全软件可能弹出拦截提示，选择「允许」即可。如果自启注册失败，以管理员权限重新运行安装器覆盖安装一次，再回到设置里打开自启开关。

### Android 客户端安装

1. 应用商店搜索 ExtensoDesk 安装，或走官网下载 APK 手动安装
2. 首次打开时按提示授予必要权限（存储、网络等）
3. 如果希望平板端也开机自启，需要在平板系统设置里单独配置——不同平板的自启设置入口位置不同，安卓原生在设置 → 应用 → ExtensoDesk → 自动启动里开启

### 两端配对

两端都装好后确保在同一局域网（或用 USB 3.0 有线连接），平板端打开 ExtensoDesk 会自动扫描附近的 Windows 服务端，点击电脑名称即可建立连接。连接成功后平板默认进入扩展屏幕模式。

## 📖 核心功能与使用技巧

### 扩展屏模式：平板变独立显示器

扩展屏幕是 ExtensoDesk 的主打功能，和屏幕镜像的根本区别在于：扩展屏是**独立**的，Windows 会把它识别为显示器 2，拥有自己的位置和窗口管理。你可以在 Windows「设置 → 系统 → 显示」里像配置双显示器一样调整两块屏的相对位置（上下左右）、主屏副屏、分辨率和缩放比例。

窗口在两块屏之间来回移动有三种方式：

| 方式 | 操作 |
| --- | --- |
| 标题栏拖拽 | 鼠标按住窗口标题栏拖到平板区域释放 |
| 快捷键 | `Win + Shift + →` 移到右边，`Win + Shift + ←` 移到左边 |
| 平板触摸 | 直接在平板上触摸拖动窗口标题栏 |

v1.2.0 起服务端新增了几个实用设置项：**新窗口打开位置**可以选活动显示器、主屏或固定副屏；**副屏任务栏**开关让平板上也出现任务栏方便切换窗口；v1.2.7 新增的**锁定分辨率**可以固定你觉得体验最好的分辨率，不让系统自动调整。Android 端 v1.4.2 之后，这些模式选项可以直接在平板上改，不用回到电脑操作。

### 手写笔：压感测试与 Photoshop 配置

如果用手写笔在平板上绘图但觉得压感不对，ExtensoDesk v1.2.0 内置的**手写笔测试工具**可以帮你快速定位问题。打开方式：在 Windows 服务端主界面找到「手写笔测试工具」入口，点击后平板上会弹出一个独立的绘图测试窗口。

在测试区域画几笔，根据现象判断：

- **线条粗细随压力变化** → 压感正常，问题在你的创作软件（比如 Photoshop 画笔设置里没选钢笔压力）
- **线条一直一样粗** → 压感没传到 Windows，检查 ExtensoDesk 版本和笔的驱动
- **完全画不出线** → 笔只被识别为触摸，检查是否为支持压感的手写笔、是否正确配对

如果测试工具里压感正常但 Photoshop 里没反应，打开 Photoshop 画笔设置窗口，找到 Size Jitter / Opacity Jitter 等选项，把 Control 下拉框选为「钢笔压力」即可。v1.1.7 版本专门为部分 Photoshop 兼容性问题增加了一个修复选项。

### 极限性能模式：降低延迟的利器

ExtensoDesk 默认在画质和性能之间取平衡，但有些场景需要极致流畅——比如在平板上玩竞技类游戏、手写笔高速描绘、4K 高刷新率显示。v1.3.1 引入的**极限性能模式**开关就是为此设计的：开启后优先保证帧率和响应速度，画质可能略有降低但延迟和卡顿会显著减少。

适合开启的场景：游戏、实时触控绘图、WiFi 下卡顿明显；适合保持关闭的场景：日常办公、看视频、设计工作（颜色准确性优先）。对 GPU 有额外负载，显卡性能一般的电脑建议慎用。配合 USB 3.0 有线连接效果最好，WiFi 受网络本身延迟限制提升有限。

### 全自动体验：自启 + 自动重连

把两端的自启动都配置好之后，可以实现拿起平板直接用的零操作流程：电脑开机 → ExtensoDesk 自动后台运行（v1.2.0 起静默不弹窗），平板开机 → ExtensoDesk App 自动启动，两端自动扫描发现、自动连接。这是日常高频使用者最省心的配置方式。
