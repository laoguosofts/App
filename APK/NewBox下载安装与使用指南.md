## ✨ NewBox 是什么

NewBox 是一款开源的影视聚合播放器，最大特点是**不内置任何内容**——它把"看什么片"的选择权完全交给用户，通过订阅外部影视源来解锁分类浏览、搜索、缓存下载、追更提醒等一整套播放器能力。换句话说，NewBox 本身是个"空盒子"，你往里加什么源，它就能播什么。

这种设计在同类播放器里并不罕见，但 NewBox 做得比较极致：界面干净、源加载秒级完成、多线路自动切换、手机版和电视版双端适配、甚至还内置了投屏接收能力。社区里有人把它比作"影视界的 Kodi"——核心框架简洁，内容生态靠第三方贡献。

适合哪些人用？第一类是**懒得装一堆 App 的重度影视观众**——一个 NewBox 加几条源就能覆盖大部分观影需求；第二类是**喜欢折腾订阅源的技术向玩家**——自己维护源、调线路、搭配缓存路径，玩的就是这套；第三类是**家庭场景用户**——电视版直接大屏播放，手机投电视也能无缝衔接。

> [!TIP] NewBox 不生产内容
>
> NewBox 本身不提供任何影视资源，所有内容来自用户自行添加的订阅源。源的维护者是社区第三方，源的可用性和内容质量取决于维护者。

## 🔧 NewBox 安装指南

### Android 手机版安装

1. **下载安装包**：从下载页获取最新版本的 APK 文件，建议同时记录版本号用于后续核对
2. **允许未知来源**：Android 8.0 及以上系统会在安装弹窗里提示"未知来源安装"，勾选允许后继续；部分机型需要先进入系统设置 → 安全中心 → 允许未知来源应用
3. **安装**：点击安装包，等待系统完成安装，桌面出现 NewBox 图标即安装成功
4. **首次打开**：启动时会请求存储权限和网络权限，全部授予即可正常使用

> [!WARNING] 版本核对
>
> 安装完成后建议进入 NewBox 的"我的 → 关于"页面核对版本号与下载页一致，避免用到旧版或第三方修改包。

### TV 端安装

TV 版的安装路径根据你的电视品牌略有差异，但核心思路是把安装包文件传到电视上：

| 方法 | 适用场景 |
| --- | --- |
| U 盘侧载 | 最通用，把 APK 拷到 U 盘插电视 |
| 电视应用市场搜索 | 部分品牌应用市场有上架，直接搜索 NewBox |
| 通过电脑远程推送 | 同一局域网下用 adb 或文件管理器应用推送 |

### 存储路径规划

NewBox 默认把缓存文件放在内部存储。如果你的设备支持 SD 卡或外接 U 盘，强烈建议在设置里把缓存路径改到外部存储——一部 1080P 电影大约 1-3GB，4K 片源动辄 10GB 以上，外部存储更灵活也不挤占系统空间。设置缓存路径时注意：U 盘中途被拔掉或 SD 卡被卸载会导致缓存写入失败，需确保存储介质稳定。

## 📖 NewBox 功能与使用详解

### 添加订阅源：解锁全部能力的第一步

NewBox 支持两种订阅源格式——**影视源**（通常是 `.json` 后缀）和**直播源**（通常是 `.txt` 后缀）。影视源负责点播影视内容，直播源负责电视直播频道。多数用户会同时添加一条影视源和一条直播源，少数影视源的 JSON 里会附带直播频道数据，此时一条源就能通吃。

添加源的流程很简单：

1. 进入"我的"或"设置"页面，找到订阅源管理
2. 点击"添加订阅"，粘贴源地址
3. 等待几秒，NewBox 自动完成读取、解析和注入
4. 返回首页，你会看到分类导航条已经亮起来了

一个正常可用的影视源 JSON 文件包含几个关键字段：播放线路（视频点播接口地址）、解析脚本（处理特定格式的视频流）、分类规则（首页展示哪些标签页）、搜索接口、筛选接口。这些字段你不需要手动改——NewBox 在添加时自动识别并适配。订阅源的有效性取决于远程维护者，一条源可能今天能用明天就失效，但 NewBox 播放时会对每条线路做可用性检测，当前线路报错自动切到备用线路，这是它比同类播放器更省心的设计点。

> [!NOTE] 源的来源
>
> 订阅源通常由社区玩家公开分享，分发渠道包括影视论坛、社交群组、个人博客等。添加前可以先在浏览器里访问源地址，能直接返回 JSON 内容或文本列表说明源本身存活。

### 剧集追更：不推送但够用

NewBox 的追更功能不靠系统推送通知，而是在收藏页用"有新集"标记让你一眼看到。逻辑很朴素——打开 NewBox 时自动检查所有收藏剧的最新集数，对比你上次观看的进度，发现更新就打标。

收藏操作在影片详情页底部的心形图标，点一下加入收藏，再点取消。追更检查的触发时机有三个：打开应用时全量检查当前激活源的所有收藏；切换订阅源时检查新源的收藏；手动刷新收藏列表。

追更功能有几个局限需要了解：**不主动推送**（必须打开 NewBox 才触发）、**依赖源更新速度**（源里这部剧没同步最新集数就不会标记）、**新开播剧续播点缺失**（没建立过续播点之前即使更新了也不会标记）、**跨源续播点丢失**（不同源同一部剧的 ID 不同，续播点匹配不上）。实用小技巧：每天固定时间打开一次触发检查；追新剧第一集必须播放一下建立续播点；多源交叉追更作为补充。

### 缓存下载：离线观看的主力

NewBox 的缓存功能虽然稳定但也有常见坑。下载失败或点了下载没反应，大概率集中在四种情况：

| 错误提示 | 原因 | 解决 |
| --- | --- | --- |
| 存储空间不足 | 设备剩余空间不够 | 清理旧缓存、换更大缓存路径、降低清晰度 |
| 下载中断 | 网络波动 | 短期波动自动暂停等待，长期中断支持断点续传 |
| 无法下载此视频 | 源不支持断点续传 | 只能换源，没有修复方法 |
| 无法写入 | 缓存路径不可用 | U 盘重插、SD 卡重挂载、权限重新授权 |

这里有个硬伤要说明：NewBox 的缓存依赖 HTTP Range 请求——允许客户端从文件某个位置开始下载。少数订阅源的视频服务器不支持这个请求方式，**这种源的视频无法缓存，只能在线观看**。判断方法也简单：随便找一部电影点下载，10 秒后失败，切另一条源再试——另一条能下说明当前源不支持。

缓存文件本身是标准 MP4 格式，可以跨设备传输、用其他播放器打开，这一点比某些只能用自家播放器播放的缓存方案友好得多。建议至少保持缓存路径 2GB 以上可用空间，避免下载到一半被拒绝。

### 电视版投屏接收：大屏观看的另一条路

如果你的电视上也装了 NewBox 电视版，它内置了投屏接收服务——手机版可以把内容投射到大屏上播放。相比手机自带 Miracast 直接投屏，同内核协议的优势很明显：不需要额外转码、电视版可以后台挂着不影响使用、部分版本支持播放进度双向同步、投屏过程中电视遥控器也能控制播放。

接收端配置很简单：打开电视版 → 进入我的或设置页 → 找到投屏或多屏互动开关打开 → 电视版会广播服务名（如"客厅电视-NewBox"）→ 按遥控器返回退到桌面即可，接收服务后台运行。手机端在播放界面点投屏按钮，搜索列表里找到你的电视版，确认投屏。

投屏中断排查：画面卡顿延迟检查两端 Wi-Fi 信号强度（至少 3 格），路由器支持 5GHz 的话让两端都连 5GHz；投屏几秒后断开大概率是电视版被系统杀进程，在电视系统设置里把 NewBox 加入后台白名单；手机搜不到电视版确认两端同一 Wi-Fi、电视版开关已开、路由器没有开启 AP 隔离。

投屏和电视版直接播放的适用场景有别：手机上正在看的剧想搬到大屏继续用投屏更方便；想在电视上从头找片，电视版直接播放更自然；多人家庭一起看片还是电视版直接播放体验最好。
