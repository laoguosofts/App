## ✨ MultiTTS 是什么：让安卓全系统用上更好听的语音合成

MultiTTS 是一款针对 Android 系统的**第三方文本转语音引擎**。简单说就是：装上它以后，你手机里所有支持朗读功能的 APP——小说、浏览器、新闻、PDF 阅读器、乃至系统无障碍——都能调用 MultiTTS 的音色来"说话"，而不必被手机厂商自带的系统 TTS 引擎绑定。

它的核心设计点有两个。一是**内置多家大厂的语音引擎接口**——百度、搜狗、微软、讯飞、小米/小爱，不同引擎各有侧重：百度在中文普通话上稳定，搜狗方言多（粤语、四川话、东北话等），微软神经语音的自然度最高，讯飞擅长情感表达，小爱音源在移动端集成度好。二是**支持角色多声部朗读**——给小说里的男主、女主、旁白分配不同发音人，听书体验一下子就立体了。

对重度听书用户、外语学习者、或者觉得系统 TTS 声音太难听想换一换的人来说，MultiTTS 是那种"装一次、全系统受益"的工具。它不替代任何 APP，只是替换了 Android 系统底层的 TTS 引擎这一层。

## 🔧 安装步骤：第三方 TTS 引擎的标准安装流程

MultiTTS 的安装和普通 APP 有些不同——它不仅要装 APK，还要在系统设置里设为默认 TTS 引擎才能被其他 APP 调用。以下是完整流程：

**第一步：安装 APK**

1. 从下载页获取最新版本的 APK 文件
2. 如果是首次从非应用商店渠道安装，系统会提示"未知来源应用"——进入设置 → 安全 → 允许安装未知来源应用（不同 ROM 路径略有差异）
3. 安装完成后先不要打开 APP，继续第二步

> [!WARNING]
> 某些国产 ROM（MIUI、ColorOS、EMUI 等）对 TTS 类 APP 有额外限制。如果装完后在系统设置里找不到 MultiTTS 选项，试试给它关闭电池优化、锁定后台、并允许自启动。

**第二步：设为默认 TTS 引擎**

1. 打开系统设置 → 无障碍 / 辅助功能 → 文本转语音（不同手机路径可能是：语言和输入法 → 文字转语音输出）
2. 在"首选引擎"或"默认引擎"下拉菜单里，应该能看到 MultiTTS
3. 选中它，系统可能会弹出安全确认，点确定即可

**第三步：导入音源包（可选但推荐）**

安装 MultiTTS 本体后，所有引擎接口已经就绪（百度、搜狗、微软、讯飞、小米），但引擎需要音源数据才能发声。音源包是独立的 `.zip` 文件，里面是各引擎支持的发音人数据：

1. 在 MultiTTS APP 内找到"音源管理"或"导入音源包"入口
2. 从官方渠道获取音源包，在 APP 内导入
3. 可以一次导入多个音源包，它们可能来自不同引擎

> [!TIP]
> **引擎和音源包是两层概念**：引擎是软件内置的接口层，音源包是用户后导入的资源。不要把"引擎"当成"发音人"——同一个引擎可以有多个发音人（音源包导入的），切换引擎等于切换背后的厂商技术。

**第四步：快速验证**

装完设好以后，打开任意有朗读功能的 APP（比如番茄小说、微信读书），找一段文字点朗读——如果听到的是 MultiTTS 的音色，就说明安装成功。如果还是系统默认声，检查一下"首选引擎"有没有真的切过来，或者关掉 APP 重新打开。

## 📖 使用入门：引擎选择、角色分配与 APP 兼容性

### 引擎怎么选：场景化推荐

没有"哪家引擎最好"，只有"哪种场景用哪家更合适"。不同引擎的特性对比：

| 使用偏好 | 推荐引擎 | 典型音色特点 |
| --- | --- | --- |
| 普通话新闻 / 资讯朗读 | 百度 / 搜狗 | 发音标准清晰，中性客观 |
| 追求最自然的听感 | 微软神经语音 | 模拟人类语音节奏、停顿、情感，自然度最高 |
| 小说情感朗读 | 讯飞 | 情感表达和语调变化有特色，适合有情绪起伏的内容 |
| 粤语 / 方言爱好者 | 搜狗 | 粤语、四川话、东北话、上海话等多种方言音源 |
| 手机移动端轻量体验 | 小米 / 小爱 | 移动端集成度好，播放流畅 |
| 英语 / 外语朗读 | 微软 / 搜狗 | 微软神经语音的英语音源质量高 |

音源包更新比较灵活——大厂引擎接口本身很稳定，MultiTTS 的更新更多是音源包的更新和新引擎适配。你可以随时导入新的音源包来扩展发声能力，不必等软件大版本更新。

### 角色多声部朗读：给小说配不同声音

这是 MultiTTS 最有意思的功能——通过文本关键词识别角色并分配不同发音人，实现"男主磁性男声、女主温柔女声、旁白沉稳中性声"的多主播朗读效果。

**操作步骤**：

1. 打开 MultiTTS APP，找到"角色规则"或"文本角色分配"功能
2. 添加规则，每条规则需要填写：
   - **匹配模式**：文本（包含匹配）
   - **匹配条件**：角色名、对话标签、或自定义标记
   - **分配发音人**：从已导入的音源包里选一个
3. 建议同时设一个**兜底规则**——匹配条件设为空或通用标记，分配你最常用的旁白发音人

**匹配条件怎么写**：

- **角色名字**：最常见，比如小说里直接写了"张三说""李四道"，匹配条件就填"张三"或"李四"
- **对话标签**：有些阅读 APP 导出的文本用 `【男主】`、`<女主>`、`**旁白**` 这类格式，直接填标签片段即可
- **自定义标记**：如果你自己给文本加了标记（比如给男对白加 `[M]`、女对白加 `[F]`），也可以用

> [!NOTE]
> MultiTTS 的匹配是**简单的字符串包含检测**，不是语义理解。如果文本里"他是一位男主"这种非对话内容也会触发"男主"规则——规则写得越精确越好。另外中文小说里同一角色可能有多个称呼（"张三""三哥""张三少爷"），可以加多条规则覆盖。

**实战建议**：先从两个角色开始试——男主和女主各一条规则，旁白用默认发音人。跑通了再继续加配角。不要一口气建十几条规则，匹配优先级乱了反而效果不好。

### APP 兼容性：覆盖超过 90% 的日常应用

只要一个 APP **通过 Android 标准 TTS API（`TextToSpeech` 类）来发起朗读请求**，它就能调用 MultiTTS。这意味着绝大多数 APP 都支持——因为 TTS API 是安卓系统的标准组件。

**兼容性速查表**：

| APP 类别 | 代表应用 | MultiTTS 能否被调用 | 备注 |
| --- | --- | --- | --- |
| 小说 / 阅读类 | 番茄小说、微信读书、起点、七猫、晋江、掌阅、多看、藏书馆 | ✓ | 100% 支持；微信读书注意选"TTS朗读"而非"AI朗读" |
| 浏览器类 | Chrome、Edge、QQ 浏览器、UC、Firefox | ✓ | Chrome 需在设置里开启"大声朗读" |
| 新闻资讯类 | 腾讯新闻、网易新闻、今日头条、澎湃、36氪 | ✓ | 主流 APP 基本都有朗读入口 |
| PDF / 文档阅读器 | WPS Office、Adobe Acrobat、全文朗读类 APP | ✓ | WPS 有专门的"朗读"按钮 |
| 外语学习类 | 多邻国、每日英语听力、有道词典、欧路词典 | 大多支持 | 部分 APP 需在设置里开启自定义 TTS 引擎 |
| 系统无障碍 | TalkBack、选择朗读内容 | ✓ | 设为默认后整台手机的交互声音都用 MultiTTS |
| 有声书平台 | 喜马拉雅、懒人听书 | ✗ | 播放预录音频，不走 TTS API |
| 纯音频播放器 | 网易云音乐、QQ 音乐、小宇宙 | ✗ | 和 TTS 完全无关 |

### 第三方 APP 调不到声音？排查思路

设了 MultiTTS 为默认后，某些 APP 还是用旧的系统 TTS 或者没反应，通常有以下几种原因：

**APP 有自己的专属朗读引擎**——这是最常见的情况。比如微信读书有"AI 朗读"（云端）和"TTS 朗读"（系统）两种模式，喜马拉雅/懒人听书播放的是预录音频不是实时合成，某些企业定制 APP 集成了自己的百度/讯飞 SDK。解决办法：在 APP 自己的朗读设置里找 TTS 模式，强制用"系统 TTS"或"自定义 TTS 引擎"。

**APP 只在启动时读取一次 TTS 设置**——有些 APP 启动时存一次引擎就反复用，中途切换默认引擎不会跟着变。解决办法：关掉 APP（彻底杀后台进程），重新打开。

**APP 硬编码指定了某个引擎**——极少数 APP 在代码里写死了用 Google TTS 或其他引擎，不走系统默认。这种情况检查 APP 设置里有没有引擎选择项，没有的话这个 APP 就没法用 MultiTTS，只能换同类替代。

**定制 ROM 干扰**——部分国产 ROM 对 TTS 调用做二次拦截。可以在开发者选项里看有没有"TTS 调试"设置、给 MultiTTS 和目标 APP 都关闭电池优化，实在不行只能换干净一点的系统。

> [!TIP]
> 如果某个阅读 APP 就是不支持 MultiTTS，最实在的办法是**换一个支持系统 TTS API 的同类 APP**——阅读类 APP 市场上可选的太多了，番茄小说、微信读书、七猫、多看阅读、藏书馆对 MultiTTS 支持都很好。
