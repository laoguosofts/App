## ✨ DiskDigger 是什么

DiskDigger 是一款跨平台的数据恢复工具，核心能力是绕过操作系统文件系统直接读取磁盘的原始扇区——这意味着它能找回那些已经被删除、清空回收站、甚至格式化过的数据。从最早只能救 U 盘照片的小工具，到现在覆盖 Windows、Linux、Android 三大平台，支持恢复图片、视频、文档、音频、压缩包等近百种文件类型，DiskDigger 已经成长为数据恢复领域的老牌全能选手。

它的工作原理听起来简单：文件删除时，操作系统并没有真正擦掉磁盘上的实际数据，只是把文件系统索引里的记录删掉了。DiskDigger 直接扫描整个存储介质的扇区，从原始数据块里把还没被覆盖的文件"挖"出来。这个原理适用于几乎所有存储设备——硬盘、U 盘、SD 卡、MicroSD 卡，甚至光盘。

适合谁用？凡是遇到以下场景的用户都能从中受益：相机 SD 卡照片误删、手机 MicroSD 卡视频丢失、电脑硬盘文档清空回收站、光盘有划痕读不出、U 盘格式化后想救数据。免费版就能满足日常恢复需求，Pro 版解锁更多高级功能和文件类型。

## 🔧 安装步骤

DiskDigger 的安装非常轻量，不同平台略有差异。

### Windows 版

下载后是一个免安装的 exe 文件——解压即用，不需要传统的安装向导。建议解压到非系统盘目录（比如 `D:\Tools\DiskDigger\`），避免后续恢复系统盘文件时解压过程本身产生写入。

> [!WARNING]
> 如果你的目标是恢复系统盘（C 盘）上被删除的文件，**绝对不要把 DiskDigger 放在 C 盘上运行**。解压到 U 盘或外接硬盘，然后执行。

首次启动时建议**右键以管理员身份运行**——这样 DiskDigger 能访问到更多被系统锁定的文件区域，提高恢复成功率。Windows Defender 或其他杀毒软件可能会对扇区级扫描产生误报，添加信任即可，这是工具的正常行为。

### Android 版

从 Google Play 安装后即可使用，但要注意：Android 系统对内部存储有严格保护，USB 连电脑只能走 MTP 文件级访问，DiskDigger Android 版默认只能扫描设备的"共享存储"区域。如果需要完整扫描内部存储的原始扇区，需要 Root 权限。

### 版本核对

安装完成后打开软件，菜单栏 Help → About 可以看到版本号。恢复操作前建议确认是从官方渠道获取的最新版本，老版本可能存在兼容性问题。

## 📖 使用入门

DiskDigger 的核心使用流程可以概括为"选介质 → 选模式 → 选类型 → 扫描 → 预览 → 恢复"六步，下面结合常见场景展开。

### 两种扫描模式：Dig Deep 与 Dig Deeper

DiskDigger 提供两种扫描模式，理解它们的区别是高效使用的关键：

| 对比项 | Dig Deep | Dig Deeper |
|--------|----------|------------|
| 扫描对象 | 文件系统索引标记为"已删除"的文件 | 整个介质的原始扇区，按文件特征签名雕刻 |
| 文件名 | 保留原始文件名和目录结构 | 自动编号（如 image001.jpg），无目录 |
| 适用时机 | 文件刚删除不久、分区未格式化 | 删除已久、已格式化、Dig Deep 没找到任何东西 |
| 速度 | 快（几百 GB 盘 10-30 分钟） | 慢（硬盘可能 1-2 小时） |
| 恢复价值 | 文件块完整时 100% 可用 | 需逐个预览确认内容 |

实战经验是：**先 Dig Deep，不行再 Dig Deeper**。Dig Deep 扫完后列表里每个文件都有状态列——`recoverable` 表示文件块完整没被覆盖，恢复出来 100% 可用；`overwritten` 表示已被新数据覆盖，大概率打不开；`unknown` 无法确定，先恢复出来试试。

### 扫描结果的两种浏览视图

DiskDigger 扫描完成后可以用两种视图浏览结果，配合预览面板效率更高：

**列表视图**每文件一行，显示文件名、大小、日期、目录、可恢复状态等完整信息，适合已知文件名或目录的精确查找——比如找"2024年度报告.docx"，可以点击列头按名称或日期排序，状态列直接告诉你哪些文件值得优先恢复。

**缩略图视图**每文件一个方块，图片类文件直接显示缩略图预览，适合凭视觉找照片或视频——比如旅行照片按时间批量删掉了，拖鼠标滚轮快速扫缩略图，一眼就能认出目标文件。

> [!TIP]
> 最高效的配合方式：列表视图里快速选中疑似目标文件，**右边预览面板实时显示大图预览**（图片支持缩放和拖动、文档显示纯文本前几行、音频可以播放），确认后再决定是否恢复。

Dig Deeper 恢复的文件没有原始文件名，自动编号如 `image001.jpg`，这时缩略图视图加预览面板的组合尤为重要——你得凭内容逐个辨认哪些是你要的。

### 分场景实战

#### U 盘 / SD 卡照片恢复

这是 DiskDigger 最经典的使用场景。U 盘、SD 卡都是标准可移动存储介质，DiskDigger 可以直接扫原始扇区。步骤：启动 → 选中 U 盘/SD 卡盘符 → Dig Deeper（如果是刚删的也可以先 Dig Deep 试试）→ 只勾选图片和视频类型加速扫描 → 恢复到**电脑硬盘的另一个盘**。

> [!WARNING]
> **恢复出的文件绝对不能保存到正在扫描的介质上**。扫描 U 盘就保存到电脑硬盘，扫描 SD 卡就保存到 U 盘。保存到原地会直接覆盖还没被扫到的丢失数据，等于自杀。

#### Android 手机 MicroSD 卡恢复（无需 Root）

好消息是：**MicroSD 卡 ≠ 内部存储**。如果你的照片/视频是存在 MicroSD 卡上，不需要 Root——关机取卡，用读卡器连电脑，流程跟 SD 卡照片恢复完全一样。

| 对比项 | 取卡 + 桌面版 DiskDigger | Root + Android 版 DiskDigger |
|--------|--------------------------|-------------------------------|
| 操作难度 | 极低——拔卡插电脑就行 | 高——Root 本身就有学习成本 |
| 对手机风险 | 零 | Root 可能损坏系统、失效保修 |
| 恢复效果 | 完整分辨率照片 + 所有文件类型 | Root 后才能完整恢复 |
| 速度 | 快（电脑 CPU 和读卡器都比手机快） | 慢 |

但要注意一个陷阱：某些 Android 6.0+ 设备支持把 MicroSD 卡格式化为"内置存储"（Adopted Storage），这时卡会被全盘加密。取出来连电脑 Windows 会提示"需要格式化"——**绝对不要格式化**，放回原手机用 Android 版 Root 后扫描，因为只有那台手机知道解密密钥。

#### 电脑硬盘文档恢复

硬盘恢复比 U 盘/SD 卡更棘手，原因是硬盘上有持续的后台写入——虚拟内存、系统日志、浏览器缓存、杀毒软件扫描、自动更新都在不停写盘。**从发现文件丢了的那一刻起，丢失数据被覆盖的概率就在持续上升**。

紧急第一步：停掉不必要的写入。不要开浏览器，不要装软件，不要把 DiskDigger 解压到系统盘。更极端的情况——比如 C 盘丢了论文或项目代码——关机、拆硬盘、装到另一台电脑上作为从盘扫描，这是最彻底的隔离方式。

硬盘恢复的标准流程是先 Dig Deep 找近期删除的文件，扫不到立刻换 Dig Deeper 做全盘扇区雕刻。恢复出来的文件**必须保存到另一块独立的物理硬盘**，同一块盘的不同分区也不行。

#### 光盘 ISO 制作（隐藏功能）

很多人不知道 DiskDigger 还能用来制作光盘 ISO 映像——原理很巧妙：CD/DVD 每个扇区正好存储 2048 字节，DiskDigger 有原始扇区读取权限，把整张光盘的扇区按顺序读出来就是一个完整 ISO。

操作方法：光驱放入光盘 → DiskDigger 选中光驱 → Dig Deeper → 文件类型里勾选 "ISO" → 扫描 → 保存到硬盘。这个功能在划痕光盘恢复时特别有用——Windows 资源管理器复制遇到坏扇区可能直接中止，DiskDigger 会逐扇区读取，遇到坏扇区跳过并继续后面的，至少能保住大部分数据。

> [!NOTE]
> DiskDigger **不支持蓝光光盘**。蓝光扇区大小是 4096 字节，且有 AACS 加密层保护，目前无解决方案。
