## ✨ Seetong 是什么：面向小微场景的多平台监控客户端

Seetong 是天视通（Seetong）方案摄像机与配套录像机的官方客户端，覆盖 Android、iOS、Windows 等主流平台。它的定位很明确——让你在手机或电脑上随时查看家用、店铺、仓库里的监控画面，接收告警推送，回放录像，操作云台，一套 App 管齐。

市面上做监控客户端的品牌不少，但 Seetong 方案在中低端家用和小微商用场景的存在感特别强：机身上贴云 ID 的摄像机、几十台起卖的 NVR 录像机、安防配件店里随手能买到的套装，背后跑的很可能就是这套方案。客户端的功能跟着方案走——原生设备能用上云录像、人形侦测、区域入侵这些增值能力，第三方 ONVIF 设备则受限。

这套客户端适合谁？简单说：已经在用 Seetong 方案硬件的人；打算买一套性价比方案自己组网的人；手里有 ONVIF 设备想先凑合用起来的人。如果是企业级项目，那还是去找专业厂商的 VMS 客户端更合适。

Seetong 的核心能力可以归纳为几条：实时预览（支持多画面分割、轮巡）、录像回放（卡录像 + 云录像双通道）、云台控制（支持 PTZ 的设备）、人形侦测与告警推送、分享设备给协作者、隐私遮蔽。2025 年 5 月的 8.2.1.2 版本还新增了隐私遮蔽功能，在画面上框选敏感区域后，实时画面和录像里该区域都会被色块覆盖，兼顾安防与隐私。

## 🔧 安装步骤与注意事项

### Android 安装

1. 从应用商店搜索下载，或从下载页获取 APK 文件。
2. 非应用商店来源的 APK 需要在系统设置里允许「未知来源」安装：进入设置 → 安全，勾选允许安装未知来源应用。不同厂商系统路径略有差异，小米、华为、OPPO 等都有各自的命名。
3. 安装完成后首次打开，授予存储、位置、麦克风等必要权限——不给权限会导致录像保存、定位、对讲等功能不可用。

### Windows 安装

1. 从下载页下载电脑客户端安装包（.exe）。
2. 双击运行，选择安装路径（默认 C 盘 Program Files），建议保持默认或改到非系统盘避免权限问题。
3. 某些杀毒软件可能把安装包里的组件误报，属于常见现象，加信任即可。
4. 安装完成后，首次登录需要注册云账号或用已有账号扫码。

### 版本核对

> [!WARNING]
> 装完别急着加设备，先在「设置 → 关于」里核对版本号。老固件的设备（如 4.5.9.3 之前的版本）在通道分享、走廊模式回放等功能上会受限，必要时先升固件。

## 📖 使用入门：从添加设备到日常运维

### 添加设备的两条路径

Seetong 方案的设备用云 ID 添加是最顺畅的流程：拿到机身贴的云 ID，在客户端「添加设备」里输入，确认设备在线后即可完成。这个流程走的是私有协议，完整功能都能用——实时预览、回放、云存、人形侦测、对讲、分享，全套。

如果你手里是传统 ONVIF 协议的设备（其他品牌、老款网络摄像机），也能挂进来，但能力边界要先认清：**只能实时预览，不能回放录像**。这是协议层面的限制，ONVIF 覆盖取流、云台这些基础能力，但录像检索、私有码流这些 Seetong 私有协议里才有，客户端查不到录像索引，自然没有回放页面。对讲也不可用。

ONVIF 设备接入前需要在电脑端先做一轮配置：电脑装客户端，局域网内搜索或输入设备地址连上，进入远程配置 → 网络设置 → 以太网设置，**禁用全网通功能，开启 DHCP**，让设备自动获取 IP，保存后再到手机客户端按普通方式添加。

| 设备类型 | 添加方式 | 可用功能 |
| --- | --- | --- |
| Seetong 方案原生设备 | 云 ID 添加 | 实时预览、回放、云存、人形侦测、对讲、分享、隐私遮蔽 |
| 第三方 ONVIF 设备 | 局域网搜索 + 手动添加 | 仅实时预览 |

### 轮巡：让画面自动循环

轮巡（Wheel Patrol）解决的是「不想一直盯着屏幕」的场景——开启后客户端按顺序自动切换各路设备画面，循环往复。在预览界面找到 Cycle（轮巡/循环）按钮即可开启。配合多画面分割使用时，轮巡按整屏为单位切换，比如 4 分屏模式下一次轮巡 4 台设备，下一轮再换 4 台。

轮巡和告警推送是搭档，不是替代。开店场景的推荐组合是柜台上轮巡着画面，手机里开着人形侦测推送。夜里打烊后轮巡关掉，靠告警消息中心存档。

> [!NOTE]
> 轮巡持续拉多路实时画面，移动网络下费流量，建议 WiFi 环境再用。轮巡时也能随时点任意画面进单路全屏操作（对讲、抓拍都可用），退出后继续轮巡。

设备多到轮巡一圈时间太长的话，优先精简分组——把最重要的设备放进一个分组再轮巡。

### 隐私遮蔽：挡住敏感区域

监控装在自家院子、店铺，但镜头难免扫到邻居门窗、公共过道，甚至自家客厅——隐私遮蔽就是给画面打马赛克的官方方案。8.2.1.2 版本起支持这个功能，在设备设置里找到隐私遮蔽项，在画面上框选需要遮蔽的区域（可设多个色块），保存后该区域即时生效于实时画面与录像。

遮蔽区有两个关键属性：

- **遮蔽区域不参与侦测**——画了遮蔽的地方，人形侦测、区域入侵都不会在那里触发。配置顺序上建议先定遮蔽区，再画报警区域，避免侦测区落在遮蔽区里形同虚设。
- **遮蔽是写进设备的**——无论谁的手机看这台设备、通过分享还是主账号，看到的都是遮蔽后画面。

遮蔽解决「拍到不该拍的」，但解决不了「设备被入侵」。账号密码安全和分享码管理是隐私的另一半，别顾此失彼。

| 场景 | 遮蔽建议 |
| --- | --- |
| 镜头顺带拍到邻居院子/窗户 | 遮蔽邻居区域，避免邻里纠纷 |
| 店铺镜头扫到收银台密码输入区 | 遮蔽密码区 |
| 摄像头对着大门但包含公共楼道 | 遮蔽楼道段 |
| 院子镜头一角是浴室窗户 | 必须遮蔽 |

### 回放打不开的排查清单

「画面在，录像没了」是仅次于设备离线的第二大痛点。按这四层清单过一遍基本能定位：

**第一层：查错地方了（最常见）**

回放页分「云录像」「卡录像」两个页签，先确认：

- 设备装没装内存卡——没卡，卡录像页签自然是空的。
- 设备开没开云存——没开或已过期，云录像页签也是空的。
- 要找的时段在不在存储覆盖范围内：卡是循环覆盖的，太老的片段已被覆盖；云存只从开通时刻开始有；动态云存只有报警片段，没有报警的时段就是空白。

**第二层：设备状态问题**

- 设备离线中——手机端无法远程查看卡里的回放，需等设备上线。
- 云存链路正常但没新片段——报警没触发，检查侦测配置。

**第三层：录像机通道特有问题**

- 通道密码错误——改过摄像机密码后通道会异常，重新配对。
- 录像机硬盘故障——录像机本地界面查看硬盘状态，硬盘损坏需更换。
- 固件过旧——部分功能（如指定通道分享）要求固件 4.5.9.3+，走廊模式回放要求 4.5.7.8+。

**第四层：App 与版本**

应用商店评论区出现「有的录像还调不出来」「显示该软件停止运行」类反馈，大概率是版本 bug，先更新到最新版。更新后仍复现，用客户端内「我的——帮助中心」关键词查询，或带着设备型号、App 版本、问题时段找在线客服。

> [!WARNING]
> 被覆盖的卡录像、过期的云存片段，任何客户端操作都找不回来。重要录像的处理原则是「下载固化」——报警发生后第一时间把相关片段下载到手机，再走任何后续流程。
