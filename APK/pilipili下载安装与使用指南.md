## ✨ pilipili 是什么

pilipili 是一款面向移动端的 B 站轻量客户端，核心思路很明确——砍掉原版中所有非观影相关的模块，把资源集中在「看视频」这一件事上。安装包体积小，运行内存占用低，中低端安卓机也能流畅跑，甚至官方客户端明显卡顿的 1GB RAM 旧机上，pilipili 依然能正常播放、缓存、发弹幕。

保留下来的功能覆盖了 B 站观影链路的完整需求：番剧、影视、游戏、科普等全分区内容，实时弹幕互动，360P 到 4K 多档位画质切换，离线缓存，倍速 / 后台 / 画中画播放，B 站账号登录与多设备同步，追番更新提醒，手势快捷操作等。但直播打赏、商城购物、大会员专属画质、创作投稿、动态发布这些「逛」的功能基本都砍了——或者只保留了最基础的浏览入口。

简单来说，pilipili 适合那些「打开 B 站就是为了看番、看视频」的用户，尤其是手头设备配置不高、或者不喜欢原版越来越臃肿的人。如果你的使用习惯还包括逛动态、刷商城、看直播打赏，那原版客户端更合适，两个不冲突，pilipili 体积小，叠装也不占空间。

## 🔧 安装步骤

### 安装前准备

由于 pilipili 未在国内应用商店上架，安装包需要通过第三方渠道获取——下载页提供的版本是经过整理的当前最新稳定版，建议优先从那里获取，避免从陌生来源下载到被篡改的安装包。

安装前请确认两件事：一是设备允许安装未知来源应用；二是手机存储空间预留至少 500MB（应用本身不大，但离线缓存会占用空间）。

### 开启未知来源授权

安卓 8.0 及以上系统需要单独为下载来源授予权限：

1. 打开手机「设置」
2. 进入「安全」或「隐私」
3. 找到「安装未知应用」或「未知来源」
4. 选择你用来下载 APK 的应用（浏览器 / 文件管理器）
5. 打开「允许」开关

> [!WARNING]
> 未知来源权限授予后，注意仅在本次安装时开启，装完建议关闭，避免后续其他应用静默安装。

### 安装过程

1. 用文件管理器找到下载好的 APK 文件
2. 点击安装包，系统弹出「是否要安装此应用」确认框
3. 点击「安装」，等待几秒完成
4. 安装完成后点击「打开」或直接回桌面找图标

### 安装后核对

首次打开时可以快速核对几件事：

- 应用版本号是否与下载页标注的一致
- 能否正常进入首页并加载内容（网络正常的前提下）
- 播放任意一个视频，确认画面和声音正常
- 进入「设置 → 关于」，查看版本信息

## 📖 使用入门

### 三种登录方式对比

pilipili 不登录也能用——看视频、缓存、发弹幕（游客身份受限）都没问题。但登录 B 站账号能解锁弹幕发送、云端收藏 / 追番同步、跨设备观看历史续播、投币点赞等功能，大会员功能也有轻量支持。

pilipili 提供三种登录方式，按方便程度排序：

**方式一：扫码登录（最安全、推荐）**

在另一台已登录 B 站的设备上打开 B 站 App 或网页版，然后在 pilipili 登录页面选择「扫码登录」，用 pilipili 扫描那边的二维码，在另一台设备上点「确认登录」即可。密码全程不经过 pilipili，安全性最好。

**方式二：手机号 + 验证码**

适合只有手机这一台设备的场景。输入注册手机号 → 点「获取验证码」→ 手机收到短信 → 输入验证码登录。验证码 5 分钟内有效，过期需要重新获取，短时间内频繁获取可能触发风控。

**方式三：账号 + 密码**

最传统的方式，输入 B 站账号（邮箱或用户名）和密码，可能需要图形验证码。2023 年后 B 站对密码登录加强了风控，频繁失败会触发滑动验证，建议作为备选。

> [!TIP]
> 长时间不用建议在 pilipili「个人中心 → 设置 → 退出登录」主动登出，避免账号长期在线。登出后本地数据（缓存、收藏夹）不会丢，只是新产生的数据不再同步到云端。

### 番剧整季批量缓存

pilipili 的批量缓存功能对追番党特别实用——新番更新时一次性把整季都下好，离线慢慢看。操作路径：进入番剧详情页 → 点「选集」→ 在选集列表顶部点「批量缓存」→ 勾选想缓存的集数（可以点「全选」）→ 选默认清晰度 → 点「开始缓存」。

队列中的任务按顺序下载，完成一个自动开始下一个。中途可以随时暂停全部、恢复全部、单独取消某一集、或者清空全部。这些操作都在「离线缓存」列表的顶部管理栏完成。

> [!NOTE]
> pilipili 支持后台静默下载——开始批量缓存后可以退出应用、锁屏甚至切到其他 App，下载照常进行。不过部分国产 ROM（小米、华为等）会在锁屏后自动杀后台，如果发现锁屏后下载停了，需要把 pilipili 加入电池优化白名单。

队列的优先级规则：最新添加的任务排最前；手动置顶的任务（长按某集选「置顶」）优先下载；默认按添加顺序。如果某一集之前已经单独缓存过，批量缓存时会自动跳过，不会重复下载。

### 手势操作效率

横屏播放模式下，pilipili 内置 6 种手势，覆盖了日常 80% 的操作需求：

| 手势 | 位置 | 作用 |
| --- | --- | --- |
| 双击 | 屏幕任意位置 | 暂停 / 播放 |
| 左右滑动 | 屏幕中间 | 快进 / 快退 |
| 上下滑动 | 屏幕左侧 | 亮度调节 |
| 上下滑动 | 屏幕右侧 | 音量调节 |
| 捏合 | 视频画面 | 缩放（部分设备） |
| 长按 | 视频画面 | 1.5x 倍速预览 |

几个最实用的：双击暂停是使用频率最高的手势，暂停喝水、接电话都不需要找播放按钮；左右滑动调进度时，屏幕上会实时显示当前跳转的时间点（比如「跳到 12:34」），松手直接跳到那个位置，比点进度条更精准；长按视频画面会临时以 1.5x 速度播放，松手恢复原速，适合快速扫过 OP / ED 等不感兴趣的片段。

上下滑动分左右区域是 pilipili 的一个贴心设计——左半屏滑亮度、右半屏滑音量，互不干扰，调节时屏幕中央会显示当前值。如果觉得某个手势经常误触，可以在「设置 → 播放器 → 手势」里单独关掉。

### 轻量版 vs 原版怎么选

pilipili 和 B 站官方客户端的核心区别在于「砍了什么」。官方客户端不断叠加直播、商城、大会员、创作中心、短视频信息流、游戏中心、漫画频道等模块，安装包已经膨胀到上百兆，运行时内存占用水涨船高。pilipili 有意识地砍掉了所有非观影链路的模块，把资源省给真正用来「看视频」的部分。

砍掉的模块包括：开屏广告、信息流推广位、会员中心 / 会员购、创作中心 / 投稿、商城、漫画频道、游戏中心，动态发布只保留浏览不能发，表情弹幕不支持。直播功能也大幅简化，只保留观看入口。

保留的核心功能没有打折扣：全分区内容、实时弹幕（含开关 / 屏蔽 / 自定义样式）、360P 到 4K 多档位画质、离线缓存（单集 / 批量 / 清晰度选择）、倍速 / 后台 / 画中画、搜索 / 收藏 / 历史、账号登录 / 多设备同步、追番更新提醒、多语言字幕自动匹配、手势操作。

砍掉功能也有代价：原版大会员独享的 4K 高帧率、HDR 等画质档位在 pilipili 中不可用；直播不能发彩色弹幕、不能打赏、部分主播的互动玩法缺失；官方先上的新交互，轻量版可能要等一两个月甚至不会跟进；原版有主题色、动态卡片等大量自定义细节，pilipili 默认即最终。

一个简单的判断标准：你上 B 站主要是为了「看」还是「逛」？看番看视频选 pilipili 足够；逛动态、看直播打赏、刷商城大会员选原版；两者都要也不冲突，pilipili 体积很小，叠装无压力。
