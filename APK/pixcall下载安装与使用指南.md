## ✨ Pixcall 是什么——面向设计师与创作者的新一代素材管理器

Pixcall 是一款主打「数据所有权在用户手里」的本地素材管理工具，服务于设计师、前端开发者、产品经理以及需要长期积累视觉素材和技术资料的创作人群。不同于 Eagle、Lightroom 等传统软件要求将文件导入专有库的做法，Pixcall 的核心设计是让资源库文件夹与电脑文件夹一一对应——软件只在你指定的文件夹旁边放一个隐藏的 `.pixcall` 索引目录，原始文件本身不被修改、不被加密、不被重命名。

这种设计带来两个直观的好处：一是你随时可以用电脑资源管理器直接批量重命名、移动、删除文件，用 Everything 快速检索，甚至把整个资源库文件夹拷贝到 U 盘或网盘即可完成迁移；二是弃用时直接删掉 `.pixcall` 文件夹，原始文件干干净净留在原地，没有任何导入导出的来回折腾。

Pixcall 原生支持 PSD、JPG、PNG、WebP、GIF、HEIC、SVG 等常见图片格式的缩略图生成和详情预览，其中 PSD 预览是它相比同类工具的核心优势——哪怕电脑上没装 Photoshop，软件也能自己解析 PSD 格式来生成缩略图和全屏预览。此外通过插件生态，还能扩展出 PDF、DOCX、PPTX、EPUB、纯文本/代码语法高亮、MHTML 网页快照、视频逐帧、3D 模型等预览能力。

在资源收集方面，Pixcall 提供了客户端拖拽导入、浏览器扩展一键保存网页为 MHTML 快照、Eagle 库完整导入（保留标签、评分、来源网址）、以及最快速的资源管理器直接复制到资源库文件夹等多种方式，适应从零散添加到一次性导入几千个文件的不同场景。

## 🔧 安装步骤与注意事项

### Windows 平台安装

1. 从下载页获取最新版本的 `.exe` 安装包，建议同时核对文件大小和版本号，避免下载到旧版或损坏文件。

2. 双击运行安装包，若系统弹出 SmartScreen 警告提示「来自未知发布者」，这是因为软件签名未在本机缓存，属于正常现象——点击「更多信息 → 仍要运行」即可继续。

3. 选择安装路径时建议不要放在系统盘的 `Program Files` 目录，而是放到用户目录下（如 `D:\Apps\Pixcall`），这样后续以管理员权限运行不会遇到写入问题。

4. 安装完成后首次启动，软件会提示你创建或选择一个资源库文件夹——这个文件夹将成为你所有素材的存储位置，请慎重选择一个有足够磁盘空间的目录。

> [!WARNING]
> 资源库文件夹**不要**放在网盘同步目录（如 OneDrive、iCloud、Dropbox 的同步文件夹）中。这些同步工具在传输大量小文件时可能出现部分文件未同步完成就标记为已同步，导致 `.pixcall` 里的数据库文件不完整，引发软件异常。

### macOS 平台安装

1. 从官网下载 `.dmg` 镜像文件，打开后将 Pixcall 图标拖拽到 `Applications` 文件夹。

2. 首次启动时若系统提示「无法打开，因为来自身份不明的开发者」，请前往「系统设置 → 隐私与安全性」，在底部点击「仍要打开」即可。

3. 后续创建资源库文件夹的流程与 Windows 一致。

### 安装后的快速核对

安装完成并首次进入主界面后，建议做以下几项检查确认一切正常：

- 创建一个测试资源库文件夹，向其中拖入几张图片，确认缩略图能正常生成
- 打开「偏好设置 → 插件」，查看可用的预览插件列表
- 检查资源库文件夹根目录下是否存在隐藏的 `.pixcall` 文件夹

## 📖 使用入门——资源库体系、文件导入与预览能力

### 资源库文件夹的运作原理

Pixcall 的资源库文件夹就是一个普通的电脑文件夹，根目录下只有一个隐藏的 `.pixcall` 系统文件夹存放索引数据。两者之间是实时双向同步的关系：

- 在电脑资源管理器里向文件夹添加一个文件 → Pixcall 客户端自动出现这个文件
- 在 Pixcall 客户端里拖入一个文件 → 文件夹根目录自动出现这个文件
- 在资源管理器里重命名文件 → Pixcall 里文件名跟着变
- Pixcall 里重命名文件 → 资源管理器里文件名跟着变

> [!TIP]
> 要查看 `.pixcall` 文件夹，Windows 用户在资源管理器的「查看」选项卡勾选「隐藏的项目」，macOS 用户在 Finder 里按 `Command + Shift + 句号`。**绝对不要手动删除、移动或修改 `.pixcall` 里的任何文件**——绝大多数软件异常都源于这个索引文件夹损坏。

Pixcall 还提供了三个快捷入口帮你定位资源库文件夹：通过软件菜单「资源库 → 打开资源库文件夹」、在左侧文件夹树中右键选择「在资源管理器中打开」、或手动导航到根目录带有 `.pixcall` 隐藏文件夹的那个路径。

### 快速导入素材的四种方式

根据手头素材的规模和来源，选择不同的导入方式：

**方式一：资源管理器直接复制（大批量导入最快）**

当你有成百上千个文件要一次性放进 Pixcall 时，直接用资源管理器复制到资源库文件夹根目录是最高效的方式。Pixcall 通过操作系统 API 监控磁盘变化，在后台默默扫描新文件并生成缩略图和索引，整个过程中你可以继续在客户端里给已有文件打标签、搜索、整理，完全没有前台阻塞的等待。

| 方式 | 1000 个图片文件耗时 | 等待期间能做什么 |
| --- | --- | --- |
| Pixcall 客户端拖拽 | 3~10 分钟（前台阻塞） | 什么都做不了 |
| 资源管理器直接复制 | 1~3 分钟（后台处理） | 正常使用其他功能 |

复制完成后如果新文件迟迟不出现（超过几分钟），可以通过「资源库 → 立即同步」触发全面扫描。如果资源库放在 NAS 或移动硬盘上，Pixcall 无法实时监控这些设备的磁盘变化，需要退出软件再重新打开或手动重建索引。exFAT 格式的外置设备不推荐使用，重插拔后文件标识会改变。

**方式二：客户端拖拽（零散添加最直观）**

日常零散添加文件时，直接从资源管理器拖拽到 Pixcall 主界面或指定子文件夹即可。这种方式能精确定位导入位置，适合单个或少量文件的操作。

**方式三：Eagle 库完整导入**

如果手头素材已经在 Eagle 里，可以使用 Pixcall 的 Eagle 导入功能，完整保留 Eagle 中的标签、评分、描述、来源网址等元信息——比手动导出再复制更方便。

**方式四：浏览器扩展保存网页快照**

Pixcall 浏览器扩展可以把当前浏览的网页保存为 MHTML 格式快照。MHTML（MIME HTML）能把一个网页及其所有关联资源（图片、CSS、JS）打包成单个文件，离线访问时完全还原页面的文字、图片和布局，适合收藏设计参考页面、技术博客教程、产品 API 文档等场景。

### 图片与 PSD 原生预览

Pixcall 原生支持（无需额外插件）以下图片格式的预览和缩略图生成：

| 格式 | 预览能力 | 缩略图生成 |
| --- | --- | --- |
| PSD（Photoshop） | ✅ 原生 | ✅ 原生 |
| JPG / JPEG | ✅ 原生 | ✅ 原生 |
| PNG | ✅ 原生 | ✅ 原生 |
| WebP | ✅ 原生 | ✅ 原生 |
| GIF | ✅ 原生 | ✅ 原生 |
| HEIC / HEIF | ✅ 原生 | ✅ 原生 |
| SVG | ✅ 原生 | 视版本而定 |

其中 PSD 预览是 Pixcall 的标志性优势——软件自己解析 PSD 格式来生成缩略图和详情预览，不依赖系统接口、不要求电脑安装 Photoshop。所有 PSD 文件导入后几秒内自动生成缩略图，详情页可以查看完整分辨率的原始内容，设计师再也不用为了浏览素材来回启动 Photoshop。

图片详情页的操作方式：鼠标滚轮或键盘 `+` / `-` 放大缩小，按住鼠标拖拽在放大状态下平移查看，方向键 `←` / `→` 切换上/下一个文件，`Esc` 返回主界面。

对于 RAW、TIFF、AI、EPS 等非原生支持的格式，Pixcall 会尝试用操作系统的缩略图接口来显示——前提是电脑上安装了能处理这些格式的软件。如果操作系统也生成不了缩略图，就会显示通用文件图标。安装新软件后可以右键文件 →「缩略图 → 刷新缩略图」让 Pixcall 更新。

### 文本、代码与 MHTML 预览插件

安装文本编辑器插件后，Pixcall 可以对常见纯文本和代码格式做语法高亮预览：

- 纯文本类：TXT、Markdown
- 样式表：CSS、SCSS、LESS
- 脚本类：JS、TypeScript、PHP、Shell、Python、Java
- 标记类：HTML、XML、YAML、JSON
- 配置类：INI、ENV、Properties

插件提供语法高亮、行号显示、部分版本支持文件内搜索（`Ctrl + F`）等功能。这意味着你收藏的 CSS 渐变代码片段、Shell 脚本模板、项目 JSON 配置备份、Markdown 技术笔记等都可以和视觉素材放在同一个资源库里统一管理、打标签、分组。

保存的 MHTML 网页快照需要安装 MHTML 预览插件才能查看。安装后双击 MHTML 文件即可渲染出完整的网页快照效果，像在浏览器里看到的一样但完全离线，支持滚动浏览、复制文字、保存图片。

> [!NOTE]
> Pixcall 的预览能力采用插件化架构，核心客户端保持精简，用户按需安装。除了文本编辑器和 MHTML 插件外，还有 PDF、DOCX、PPTX、EPUB、视频播放器、GIF 播放器、音频播放器、3D 模型等预览插件，全部从「偏好设置 → 插件」入口安装。

### 实际工作流示例

**前端开发者的日常：** 收集 CSS 渐变代码片段 → 直接复制代码到资源库的「代码片段/CSS/」文件夹 → 打标签「渐变 + UI + 前端」→ 双击文件用文本编辑器插件做语法高亮预览 → 需要用时右键打开复制到项目里。

**技术写作者的资料积累：** 在技术博客上看到好文章 → 用 Pixcall 浏览器扩展保存为 MHTML → 文件进入「技术笔记/」文件夹 → 打标签「React + 性能优化 + 2026」→ 离线时双击查看完整内容。

**设计师的素材管理：** 大量 PSD 设计稿直接复制到资源库 → 后台自动生成缩略图 → 几秒后瀑布流里全部可见 → 按项目或功能创建子文件夹分组 → 为每个文件打标签便于后续搜索。
