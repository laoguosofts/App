## ✨ PrinterShare 是什么

PrinterShare（趣打印）是一款跨平台的移动打印解决方案，核心理念是让手机变身为打印遥控器——无论你手边的打印机是 USB 直连 PC、WiFi 联网，还是纯粹的老式打印机，只要有一台运行着趣打印接收端的电脑中转，Android 和 iOS 设备就能直接把文件送过去打印。

它的工作模式很简单：**发送端**（手机 App）负责选文件、选打印机、发起任务；**接收端**（Windows/Mac 桌面程序）常驻在有打印机的那台电脑上，负责接收任务、调度本地打印机。两端通过局域网或云服务通信，用户不需要折腾复杂的驱动配置。

趣打印覆盖的打印场景相当广泛：文档（PDF、Word、Excel、PPT）、图片（JPG、PNG、GIF）、网页直接打印、云盘文件分享打印，甚至支持通过热敏打印机打印 UPS 等物流标签。对于经常需要在移动中处理打印事务的上班族、自由职业者来说，趣打印解决的是一个真实存在的痛点——**不想每次打印都把文件导到电脑上再打开打印软件**。

收费方面，趣打印采用订阅制：基础版约 $19.99/月，包含每月 500 页额度；商业版 $79.99/月，解锁使用报告、多用户管理等团队功能。免费试用期 14 天，期间功能完整可用。

## 🔧 安装步骤

### Android 发送端安装

从 Google Play 搜索 PrinterShare 直接安装即可。需要注意的是，首次启动时趣打印会申请几项权限：

1. **存储访问**：读取你要打印的文件——必须允许，否则无法选择本地文档和图片
2. **位置权限**：用于扫描局域网内的打印机——同网段发现 PC 共享打印机时需要
3. **通知权限**：打印任务完成或失败时推送状态提醒

> [!NOTE]
> Android 11 及以上的分区存储机制下，趣打印读取 SD 卡文件时可能需要额外授权。如果选不到 SD 卡里的文件，到系统设置 → 应用 → PrinterShare → 权限里检查一下存储访问是否完整。

### iOS 发送端安装

从 App Store 安装，启动后授予「文件」访问权限即可。iOS 端的分享机制相对封闭，首次使用时需要在系统分享菜单里把 PrinterShare 启用——在任意 App 的分享面板上向左滑，点「更多」找到 PrinterShare 并开启开关。

### Windows 接收端安装

1. 从官网下载 Windows 版安装包（.exe）
2. 双击运行，安装路径默认 `C:\Program Files\PrinterShare`，一般不需要改
3. 安装过程中会弹出防火墙提示——**务必勾选允许专用网络**，否则手机端扫描不到这台 PC 共享的打印机
4. 安装完成后趣打印会自动启动，在系统托盘右下角可以看到它的图标

### macOS 接收端安装

1. 下载 .dmg 安装包，拖入「应用程序」文件夹
2. 首次打开时 macOS 可能提示安全限制，到「系统设置 → 隐私与安全性」里点「仍要打开」
3. 启动后系统会弹出防火墙权限请求，选「允许」

> [!WARNING]
> 杀毒软件误报是趣打印安装过程中最常见的问题。如果 Windows Defender 或第三方杀软弹窗拦截，将 PrinterShare 加入白名单/排除项即可——这类误报原因是趣打印需要常驻后台监听网络端口。

## 📖 使用入门

### 基本流程：手机把文件送到 PC 上的打印机

两端装好后，趣打印的典型使用路径是这样的：

1. **PC 接收端保持运行**——确保有打印机的那台电脑上趣打印开着，最好设置开机自启动（Windows：设置里勾选「随 Windows 启动」；macOS：系统设置 → 通用 → 登录项里添加 PrinterShare）
2. **手机和 PC 在同一局域网**——同一个 WiFi，IP 前三段一致
3. **手机端打开趣打印**，在「附近打印机」列表里应该能看到 PC 共享出来的打印机
4. **选文件 → 选打印机 → 点打印**，任务送到 PC，打印机开始工作

### 网页打印：两种方式任选

趣打印在网页打印这块提供了两条路径：

**内置浏览器方式**——主界面有「网页」入口，点击后在顶部 URL 栏输入网址，等页面加载完直接点「打印」。优点是全程在趣打印里完成，不用切 App。内置浏览器适合快速打印单个网页或固定网址的内容。

**系统分享方式**——在你平时用的浏览器（Chrome、Safari、Edge）里打开要打印的网页，点分享按钮，找到 PrinterShare，趣打印会拿到网页快照让你确认要不要保留样式。这种方式的好处是可以先在浏览器里用「阅读模式」处理掉广告和干扰元素，再分享过来打印，效果更干净。

> [!NOTE]
> 网页打印的局限：动态加载内容（滚动后才出现的部分）可能不完整，趣打印拿到的是静态快照。长网页打印时会自动分页，但分页位置不一定理想。如果是 UPS 等物流标签打印，趣打印对热敏打印机有专门的优化支持。

### 局域网发现不到打印机怎么办

手机打开趣打印后「附近打印机」列表是空的？按这个顺序排查：

**第一步：确认同网段**。路由器 DHCP 列表里看手机和 PC 的 IP 前三段是否完全一致。如果一个是 192.168.1.x、另一个是 192.168.0.x，说明不在同一个网段，趣打印扫描不到。

**第二步：PC 端是否真的在共享**。回到 PC 上的趣打印主界面，检查共享状态是否显示「已共享」。如果是「已停止」，点一下重新开始共享。

**第三步：防火墙放行**。Windows 上重点检查「控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙」，找到 PrinterShare 确保「专用网络」列勾选了。如果列表里找不到，点「更改设置 → 允许其他应用」手动添加 PrinterShare 可执行文件。macOS 首次启动弹出的权限请求选允许就行。

**第四步：重启清缓存**。手机上强制停止趣打印后重新打开，直接跳到打印机选择页点「附近打印机」扫描。趣打印内部的扫描缓存有时候会卡住，强制重启能清掉。

### 打印队列管理

PC 端趣打印主界面有个「打印队列」面板，是管理打印任务的核心位置。它会把任务分成四类：**入站任务**（待处理）、**正在打印**、**已完成**、**已取消/失败**。每条任务会显示来源账户、文件名、页数、大小和时间戳。

| 操作 | 方法 |
|------|------|
| 取消某条任务 | 右键该任务 → 取消 |
| 清空所有待处理 | 清空按钮 |
| 重试失败的任务 | 右键失败任务 → 重试 |
| 查看详情 | 双击任务行 |

远程打印时文件传输可能比较慢，队列里的「大小」字段可以帮你估算传输进度。如果是团队多人共享一台打印机，订阅商业版（$79.99/月）后还能解锁**使用报告**功能——按用户统计谁打了多少页、按时间段汇总打印量、打印活动时间线，适合办公室管理打印成本。基础版用户虽然没有详细报告，但账户页面能看到当月已用页数，方便控制额度。

### 云盘文件怎么送进打印机

趣打印本身不内置云盘客户端，它走的是 Android 和 iOS 的**系统级分享机制**——任何 App 只要支持系统分享，就能把文件送进趣打印。

**Android 端**（以 Google Drive 为例）：

1. Drive 里打开要打印的文件
2. 点文件旁边的菜单按钮 → 分享
3. 在系统分享面板里找到 PrinterShare
4. 趣打印加载文件 → 选打印机 → 打印

**iOS 端**（以 Files 为例）：

1. Files 里打开文件
2. 点分享按钮（向上箭头）
3. 左右滑动找到 PrinterShare（首次用可能需要在「更多」里启用）
4. 趣打印加载 → 选打印机 → 打印

趣打印注册了接受常见文档、图片格式的 Intent，所以主流云盘基本都能直接分享过来。百度云盘、阿里云盘这类国内云盘的限制稍微多一些，直连受限的情况下可以先把文件下载到本地存储，再从文件管理器里分享给趣打印。

> [!WARNING]
> 趣打印收到分享请求后，会先把云盘文件下载到手机本地缓存再处理打印。大文件（比如几十 MB 的 PDF）注意手机存储空间够不够，远程打印时大文件传输也会明显变慢。
