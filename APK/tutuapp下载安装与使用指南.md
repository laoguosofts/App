## ✨ tutuapp 是什么——兔兔助手的定位与核心功能

tutuapp，国内用户更习惯叫它「兔兔助手」，是一款跨平台的应用获取与管理工具。它的两端定位各有侧重：Android 端直接分发 APK 安装包，不走 Google Play；桌面端（Mac / Windows）则瞄准 iOS 生态，通过苹果开发者侧载通道把 Tweak 应用、MOD 游戏推送到 iPhone / iPad 上——这在官方 App Store 政策下是一条绕不开的灰色地带，但也是兔兔助手存在的核心价值。

目标用户基本是两类：一是想在 Android 上拿到特定版本或 Google Play 下架应用的老机用户，二是 iOS 越狱已经逐渐淡出后，仍然想体验 Tweak/MOD 生态的玩家。桌面版配合 Apple ID 签名的方案，让不用越狱就能装 Tweak 应用成为可能，代价是免费 Apple ID 的签名有效期只有 7 天，每过一周要重新签一次。

## 🔧 安装步骤——Android 端与桌面端分两条线

兔兔助手的安装按你的目标平台分两条路：Android 端下 APK 直接装，iOS 端必须走桌面版 USB 连接 Apple ID 签名。两条路线互不相干，各写一遍。

### Android 端：开未知来源 + 装 APK

Android 8+ 默认禁止从应用商店之外安装 APK，这是兔兔助手安装失败最常见的原因。第一步必须先给你的浏览器开「未知来源」权限。

**步骤一：开启未知来源权限**

通用原生 Android（Pixel / 摩托罗拉 / 一加）路径：**设置 → 安全 → 安装未知应用 → 选浏览器 → 允许从此源安装**。国内 ROM 叫法各异，整理如下：

| 品牌 | 路径 |
|------|------|
| 小米 MIUI / HyperOS | 设置 → 隐私保护 → 特殊权限设置 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| OPPO / vivo | 设置 → 安全 → 允许安装未知来源应用 或 应用管理 → 特殊访问权限 |
| 三星 One UI | 设置 → 生物识别和安全性 → 安装未知应用 |

> [!WARNING] 装完关掉！
> 未知来源开关一旦打开，所有通过该浏览器下载的 APK 都能被安装。推荐装完兔兔助手就回去关掉，后续应用内部自更新不需要再开这个权限。

**步骤二：下载 APK 并安装**

用刚开权限的浏览器打开兔兔助手官方下载页，点 Android 下载按钮。APK 体积通常十几到几十 MB，下载完成后从系统通知栏或「文件 → 下载」文件夹点开 `tutuapp.apk`。

安装界面会申请以下几类权限，全部点「允许」即可：

- 网络访问（下载和更新应用）
- 读写内部存储（缓存下载的 APK）
- 读取应用列表（扫描本机已装应用用于更新提示）
- 悬浮窗（安装进度浮窗）
- 后台启动（后台下载支持）

**常见安装问题排查：**

- **无法解析包 / 文件损坏** → 下载中断，回官方站重下，核对文件大小是否正常
- **安全中心阻断（小米 / 华为）** → 国内 ROM 对所有非商店来源都会高风险警告，忽略继续安装即可，或添加到安全中心白名单
- **老版本覆盖安装失败** → 不同版本签名可能变化，先卸载旧版再装新版（卸载前留意收藏列表等数据）

> [!TIP] 安卓模拟器也行
> 兔兔助手官方 FAQ 明确提到 Android 端可以在 BlueStacks、Nox 等模拟器里跑，步骤和真机一致。模拟器和真机隔离，想先试水的朋友可以走这条路。

### 桌面端（Mac / Windows）：USB 连接 + Apple ID 签名

桌面端是 iOS 侧载的唯一入口，核心流程是「USB 连接 → Apple ID 签名 → 推送安装」。前置条件有四个：Mac / Windows 电脑、能传数据的 USB 线（很多廉价线只有充电芯）、已解锁的 iPhone / iPad、Apple ID。

**步骤一：USB 物理连接**

1. USB 线一端插电脑，一端插 iPhone / iPad
2. iPhone 解锁后点「信任此电脑」并输入锁屏密码——不点桌面版识别不到
3. 电脑端等待识别：Mac 看 Finder 左侧栏是否出现设备，Windows 看 iTunes 右上角是否出现设备按钮

> [!NOTE] 线的问题最常见
> 电脑显示「正在充电」但 Finder / iTunes 里看不到设备 → 换一根靠谱的数据传输线，或插主机背面 USB 口（供电更稳）。扩展坞、集线器也可能出问题，直接插电脑自带 USB 口最稳。

**步骤二：打开桌面版，确认设备已连接**

兔兔助手桌面版启动后，顶部或侧边应该显示你的 iPhone 型号、iOS 版本、存储剩余。显示「未检测到设备」时按这个顺序排查：iPhone 是否保持解锁亮屏 → 「信任此电脑」点了没 → 系统是否已识别设备（Mac Finder / Windows iTunes 先确认这一步）→ USB 线是否插紧 → 防火墙 / 杀毒软件是否拦截了 iTunes 设备服务。

> [!TIP] Wi-Fi 同步可选
> USB 连接成功一次后，可以在 Finder / iTunes 里打开「通过 Wi-Fi 与此 iPhone 同步」。但首次绑定 Apple ID 和首次签名安装仍然必须 USB，Wi-Fi 只能用于后续管理。

## 📖 使用入门——桌面版浏览、签名、安装、更新

桌面版是兔兔助手功能最完整的形态，也是 iOS 用户真正用起来的核心。设备连好、Apple ID 绑定好之后，剩下的操作都在桌面版界面完成。

### 浏览应用库与查看详情

桌面版的应用库和官方站同步，左侧按分类组织：

- **Featured**：编辑精选，最新上架或下载量高的应用和 MOD
- **Top50**：下载量最高的 50 个应用
- **Games**：MOD 游戏分类
- **Apps**：Tweaked 应用
- **VIP**：部分只对 VIP 用户开放的应用和特殊 MOD

点击某个应用卡片，右侧展开详情面板：应用图标和名称、开发者（实际上是 MOD/Tweak 制作者）、简介和特色功能、文件大小、更新日期、当前版本号。每个应用都有独立的「安装」按钮和「收藏」按钮。

### 一键安装：签名 + 推送 + 设备端安装

点详情面板的「安装」按钮，桌面版依次执行四步：

1. **下载 IPA 包**——从兔兔助手官方 CDN 拉取，进度条实时显示
2. **Apple ID 签名**——把 IPA 里的签名替换成你的 Apple ID 开发者证书
3. **USB 推送**——签名后的文件通过 USB 传到 iPhone / iPad
4. **设备端后台安装**——iOS 自动完成安装，桌面版弹出成功提示

整个过程通常几十秒，取决于应用大小和 USB 传输速度。iOS 设备桌面上会直接出现新安装的应用图标。

### iOS 端信任开发者证书

首次打开通过桌面版装的应用，iOS 会提示「未受信任的企业级开发者」或「未受信任的开发者」——这里要信任的是**你自己的 Apple ID**，不是某个第三方企业证书。操作步骤：

1. iOS 设备上打开「设置 → 通用 → VPN 与设备管理」
2. 找到对应你的 Apple ID 名称的开发者条目（通常显示 "Apple Development: yourname@icloud.com"）
3. 点进去，点「信任」→ 二次确认「信任」
4. 回到桌面，再次打开应用

> [!WARNING] 7 天有效期
> 免费 Apple ID 的开发者证书有效期只有 7 天。每 7 天需要重新打开桌面版、插 USB、重新安装一次——覆盖安装不会丢失本地数据，相当于一次刷新证书。

### 批量安装、更新与卸载

桌面版支持一次装多个应用：在分类列表里勾选多个应用卡片 → 点底部「批量安装」→ 桌面版依次下载、签名、推送，全部完成后统一在 iOS 设备上批量安装。换手机或重装一批应用时效率比手机端一个个点高得多。

- **更新**：桌面版左侧「已安装应用」列表里，有更新的应用会显示红点。点「更新」自动下载新版本、重新签名、覆盖旧版本，本地数据不丢失。
- **卸载**：iOS 设备桌面长按应用图标 → 删除 App，桌面版也提供一键卸载已装应用的入口。

### 常见问题速查

| 场景 | 可能原因 | 解决方式 |
|------|----------|----------|
| 安装到一半失败 | USB 线不稳定 / 设备中途锁屏 | 换线、保持设备解锁亮屏 |
| 签名错误 | Apple ID 被风控 / 签名工具版本过低 | 重新绑定 Apple ID，升级桌面版 |
| 7 天后应用打不开 | 免费签名到期 | 插 USB 重新签名安装一次 |
