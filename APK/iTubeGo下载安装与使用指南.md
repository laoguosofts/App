## ✨ iTubeGo 是什么

iTubeGo 是一款主打全能型的音视频离线下载与处理工具，官方宣传支持 10000+ 网站的视频和音频抓取，内置格式转换、视频裁剪、DRM 音乐解密、直播录制等功能。和市面上只抓单一平台或只做格式转换的工具不同，它把"下载 + 转换 + 简单剪辑"整条链路放在了一个工作台里，口号是 *Magic One-Stop Video & Audio Converter*。

核心功能面板大致分为几块：下载 Tab（粘贴 URL 解析 + 批量任务队列）、Converter Tab（本地视频/音频格式转换）、内置浏览器（需要登录态的平台如 Facebook、OnlyFans 抓取）、以及一个轻量剪辑器。桌面端覆盖 Windows 和 macOS，移动端有 Android APK。

适合哪些人用？**重度归档者**收藏大量 YouTube 播放列表或 Twitch 直播回放，需要一次性拉回本地；**音乐离线派**订阅了 Amazon Music 或 Deezer，想把专辑转成通用格式带到车机或离线设备；**内容创作者**从多个参考源采集素材做剪辑；还有对 OnlyFans、Fansly 这类平台内容有离线保存需求的用户。移动端侧载 APK + WiFi 定时 + SD 卡自动存储的组合，对不想被应用商店审核限制的人也有吸引力。

不太适合的场景：只想偶尔下载单个 YouTube 视频、不需要转换或剪辑的人用在线工具更快；只需要格式转换不需要下载的话，HandBrake 之类的轻量工具足够；对隐私有极端要求的用户需要自行评估版权灰色地带的风险。

和几个主要竞品对比如下：

| 对比项 | iTubeGo | 4K Video Downloader | TubeMate |
| --- | --- | --- | --- |
| 支持网站数 | 10000+ | 约 30 | 约 50 |
| OnlyFans/Fansly | 专门适配 | 不支持 | 不支持 |
| DRM 音乐解密 | Amazon/Deezer/Apple | 不支持 | 不支持 |
| 直播录制 | 支持 | 有限支持 | 不支持 |
| 内置浏览器 | 有 | 无 | 无 |
| 内置剪辑 | 有 | 无 | 无 |
| 覆盖平台 | 桌面 + 移动 + 网页 | 仅桌面 | 仅移动 |

截至 7.0.0 版本，产品已进入成熟期，核心功能稳定。7.x 主要修复了 OnlyFans 无法下载的问题（Android 端同步修复），6.x 引入 Turbo 加速模式和批量并发上限 10。后续迭代以 bug 修复和新网站适配为主。

## 🔧 安装步骤

### Windows 端

1. 从下载页获取 `.exe` 安装包，双击运行
2. 安装向导默认路径是 `C:\Program Files\iTubeGo`，可以自定义
3. **注意杀毒误报**：Windows Defender 和部分第三方安全软件会把多线程下载器标记为 PUA（潜在不受欢迎应用）并静默拦截网络请求。如果安装后粘贴 URL 不解析，先检查防火墙 → 允许应用通过 Windows Defender 防火墙 → 勾选 iTubeGo
4. 装完启动，进入 Help → About 核对版本号是否与下载页标注的一致

### macOS 端

1. 下载 `.dmg` 文件，打开后将 iTubeGo 拖入 Applications 文件夹
2. 首次启动如果被 Gatekeeper 拦截，去系统设置 → 隐私与安全性，找到"iTubeGo 已被阻止"点"仍要打开"
3. Apple Silicon（M 系列芯片）用户：DRM 解密功能在 Apple Music 上偶尔失败，用 Rosetta 模式（右键 App → 显示简介 → 勾选"使用 Rosetta 打开"）可能解决

### Android 端

1. 侧载 APK 前先去系统设置 → 安全 → 允许未知来源安装
2. 安装完成后建议把默认存储路径设为 SD 卡，避免占用内部存储
3. WiFi 定时下载功能需要保持后台运行，别在系统里把 iTubeGo 的后台权限禁用了

> [!WARNING]
> 下载安装包时务必核对文件大小和版本号。同一大版本内的小版本更新通常直接覆盖安装即可，卸载重装会丢失下载历史和订阅列表。

## 📖 使用入门

### 基础下载流程

打开主界面，把目标视频或播放列表的 URL 粘贴到地址栏，iTubeGo 会自动解析并弹出格式选择面板。选好分辨率和格式后点下载，任务就进了队列。播放列表链接会自动展开成子任务，批量编号下载的逻辑在偏好设置里可以调。

Turbo 加速模式在偏好设置 → Downloader → 勾选"Enable Turbo Mode"，官方声称最高 10× 提速。但 Turbo 模式会被部分网站的反爬策略触发，如果发现下载到 90% 后反复重试，关掉 Turbo 重试通常能解决。

### 下载失败排查

下载失败不要直接重装，按四步排查下来 90% 的问题在前三步就能解决：

| 症状 | 可能原因 | 对应排查步骤 |
| --- | --- | --- |
| 粘贴 URL 后根本不解析 | URL 格式错、网络断了 | 检查网络 + 确认 URL |
| 解析成功但进度条不动 | 网站不支持、需要登录 | 用内置浏览器登录 |
| 90%+ 后反复重试 | Turbo 触发反爬、CDN 抖动 | 关掉 Turbo 重试 |
| 只有 Facebook/OnlyFans 失败 | 需要登录态 | 内置浏览器登录 |
| 程序直接崩溃 | 版本 bug、许可证失效 | 提交日志给官方 |

**第一步检查网络**：在浏览器里打开同一个 URL，确认视频能正常播放。浏览器也打不开就不是 iTubeGo 的问题，是网络或地区限制。同时确认 iTubeGo 没被防火墙拦截。

**第二步确认 URL**：iTubeGo 能解析的格式包括 YouTube 标准播放页（`watch?v=`）、播放列表（带 `list=` 参数）、Bilibili（`BV` 开头 ID）等。常见错误是复制了浏览器缩略后的短链接或带 `?pp` 后缀的地址，点进最终播放页再复制一次。

**第三步确认网站支持**：官方声称支持 10000+ 网站，但新网站适配有滞后。OnlyFans/Fansly 这类平台反爬策略随时变，地区锁视频、YouTube Premium 独家内容、Spotify 付费播放列表即使能抓到元数据也会报权限错误。

**第四步提交日志**：前三步没解决就打开 Help → Open Log Folder，把整个日志文件夹压缩成 zip，附上订单号、失败 URL、错误提示截图、版本号，发邮件到 `contact@itubego.com`。官方 support 通常 1–3 个工作日内回复，免费用户优先级低于付费用户。

### 内置浏览器捕获

Facebook 和 OnlyFans 的视频需要登录态才能下载，直接粘贴 URL 大概率失败。正确做法是：打开 iTubeGo 的内置浏览器（主界面顶部切换标签或菜单里找），在浏览器里登录你的账号，然后导航到目标视频页面。内置浏览器会自动捕获视频请求，在下方列表里显示可下载项，点下载即可。

### MP4 转 MP3 批量提取

iTubeGo 里"MP4 转 MP3"有两个完全不同的入口，别搞混：

**场景一：下载时直接选 MP3**——下载视频时格式下拉框直接选 MP3，iTubeGo 只抓音频轨输出纯音频文件，跳过视频画面下载。适合本来就只想拿音频的情况（YouTube 纯音乐、播客、课程音频）。

**场景二：本地视频批量转音频**——已下载好的 MP4 文件统一抽音轨，入口在 Converter Tab（和下载 Tab 并列）。适合先把视频全拉回来再统一抽音频归档的情况（比如批量归档演唱会录像后统一抽音轨做音频备份）。

批量转换操作：

1. 打开 Converter Tab → 把 MP4 文件或文件夹拖进列表（也可以点"添加文件/文件夹"按钮）
2. 右上面板选输出格式
3. 选输出路径
4. 点右下转换按钮开始

音频格式选择参考：

| 格式 | 音质 | 体积 | 适用场景 |
| --- | --- | --- | --- |
| MP3 320kbps | 有损最高 | 中 | 通用兼容性，多数播放器都支持 |
| WAV | 无损 | 大（约 10MB/分钟） | 专业剪辑、后期制作 |
| FLAC | 无损（约 WAV 60% 体积） | 小 | 归档首选，音质无损且体积控制较好 |
| AAC | 有损，同码率优于 MP3 | 小 | iOS/macOS 生态，iTunes 推荐格式 |
| OGG | 有损，开源格式 | 小 | 安卓、Linux、开源生态 |
| AIFF | 无损，iOS/macOS 原生 | 大 | 和 WAV 类似，Apple 生态有优势 |

> [!TIP]
> 文件已经是 FLAC/WAV 就没必要再转格式，直接用 Converter 面板里的"Copy"选项——不做重编码，直接拷贝文件到目标路径。

批量转换是多线程并行的，默认 2 并发，高配置机器可以在偏好设置里调到 4–6。FLAC/WAV 无损转换 CPU 占用较高，老机器建议限制并发数。1 小时视频转 MP3 大约 2–5 分钟。

### 视频片段裁剪

大多数下载器只有转码没有剪辑，想截取精华片段得先下载完再拖进别的软件。iTubeGo 内置了一个轻量剪辑器：

- 不用导出视频到另一个软件
- 界面只有时间轴 + 起止滑块，零学习成本
- 适合简单的"截一段精华 / 跳过广告 / 去掉开头结尾"场景

但它不是专业剪辑器——没有多轨、没有滤镜、没有转场、不能做精细帧级调整。专业剪辑还是得进 Premiere / Final Cut Pro / 剪映。

标准操作流程：

1. 在下载列表里右键某个视频 → 选 "Cut video"，或在 Converter Tab 添加视频后点剪辑按钮
2. 时间轴界面弹出：顶部是视频预览窗口，中间是时间轴 + 左右两个滑块（起点/终点），底部显示已选中片段的时长
3. 拖动滑块选好片段区间（精确到秒），或在底部直接输入起止时间（格式 `HH:MM:SS`，比如 01:23:45 到 01:45:00）
4. 选输出格式（和下载时的格式选项一致）
5. 点裁剪并下载/转换，输出就是选中的那段

三个实用小技巧：

**裁剪后直接转音频**——想从视频里截出音乐片段？格式下拉框选 MP3/FLAC/AAC，裁剪后输出就是音频片段，省了二次转换。

**批量裁剪多个片段**——iTubeGo 不支持一个视频剪出多个片段，但可以对同一个视频连续发起多个裁剪任务：一个视频要截 3 段，就添加 3 次、每次设不同起止点，一起进转换队列。

裁剪的已知限制：

| 限制 | 说明 |
| --- | --- |
| 无实时预览 | 拖滑块时预览画面不跳到对应帧，只有起止时间数字变化 |
| 最小裁剪单位 = 1 秒 | 不能做到帧级裁剪（专业剪辑器是 1/24 秒级） |
| 无转场/滤镜 | 纯剪切 + 可选格式转换 |
| 不支持多轨 | 一个输入视频只能剪一个输出 |
| 裁剪 = 重编码 | 和无损下载不同，裁剪一定走重编码流程 |

### 已知的平台级注意事项

- **Win7 用户**：无法通过应用内更新升级，每次手动去下载页下载最新版覆盖安装
- **Apple Silicon Mac**：DRM 解密在 Apple Music 上偶尔失败，用 Rosetta 模式可能解决
- **OnlyFans**：7.0.0 之前版本下载必挂，先升级到最新版；升级后仍失败 → 内置浏览器登录态过期，重新登录
- **地区锁视频、付费专区**：iTubeGo 不能绕过地理限制，Premium 独家内容能抓到元数据但下载会报权限错误
