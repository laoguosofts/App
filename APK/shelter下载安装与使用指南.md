## ✨ Shelter 是什么

Shelter 是一款专为 Android 设备打造的应用隔离工具，底层调用系统原生的「工作资料（Work Profile）」机制，在同一台手机上划分出两个完全独立的应用空间——主空间（MAIN）和隔离空间（SHELTER）。两个空间之间数据互不可见，应用进程、缓存、账号各自隔离，互不干扰。

它的核心价值在于解决了 Android 生态里三个常见痛点：**应用双开**（社交、游戏账号各登各的）、**冻结休眠**（不用的应用一键禁用、后台零活动）、**隐私隔离**（敏感应用放在隔离区，主空间看不到也碰不到）。整个项目开源，无广告、无跟踪、无付费墙，社区驱动维护。

Shelter 适合有以下需求的用户：一台手机管理多个社交/游戏账号、想彻底禁止某些应用后台偷跑、对隐私隔离有明确要求但不想刷第三方 ROM、希望用系统级方案替代平行空间等双开工具。

## 🔧 安装步骤与初始化

### 前置条件

Shelter 依赖 Android 的工作资料 API，**最低系统版本为 Android 5.0（Lollipop）**，但实际使用体验在 Android 8.0+ 上更好。安装前建议确认：

- 设备未开启「Samsung Secure Folder」等与工作资料冲突的功能（MIUI、OneUI 等定制系统部分机型有兼容性限制）
- 预留至少 1GB 存储空间（工作资料本身很轻，但隔离区安装的应用会占空间）
- 如果之前装过 Island 或 Insular（同类型工具），建议先清理干净再装

### 从 F-Droid 安装稳定版（推荐）

1. 如果手机还没装 F-Droid，先去 f-droid.org 下载 APK 并安装；
2. 打开 F-Droid，搜索 Shelter；
3. 找到 Shelter（作者 PeterCxy），点安装；
4. 安装完成后首次打开，进入设置向导。

> [!TIP]
> **关于渠道选择**：F-Droid 稳定版是签名最正统、更新节奏最稳的版本，日常用它就够了。作者还维护了一个自定义 F-Droid 仓库提供开发版，更新更频繁但签名不同，**两个渠道之间不能直接覆盖升级**——想换渠道必须先卸载再重装。

### 设置向导走完三页

首次打开 Shelter 会进入三页向导：

1. **欢迎页**：简要介绍工作资料机制，点下一步；
2. **权限说明页**：逐项解释需要哪些系统权限以及为什么需要，全部确认后下一步；
3. **兼容性提示页**：根据你的设备和系统版本给出针对性提示（比如 MIUI 用户会看到额外说明），确认后点下一步。

### 配置工作资料

向导最后一页点「下一步」后，系统会弹出**系统级**的工作资料创建确认界面（不是 Shelter 自己的界面）：

1. 确认系统弹窗，等待后台创建——通常只需几十秒；
2. 如果设备是 **Android 7 或更低**，注意**不要开勿扰模式**，因为需要点通知来完成后续配置；
3. 配置完成后自动回到 Shelter 主界面。

> [!NOTE]
> 配置卡住不动？先检查勿扰模式是否关闭；仍无反应可以重启 Shelter 重试；再不行就去系统设置里手动删除已创建但未完成的工作资料，然后重新打开 Shelter。

### 配置成功的三个标志

搞定了怎么判断？看这三点：

- 应用抽屉底部出现 **WORK** 标签页，图标是公文包；
- 「文件」「联系人」「时钟」等系统应用出现带公文包角标的第二份副本；
- Shelter 主界面清晰分成 **MAIN**（主空间）和 **SHELTER**（隔离空间）两个列表。

三个标志同时出现 = 配置完成，可以开始用了。

## 📖 使用入门

### 主界面速览：MAIN 与 SHELTER 双列表

Shelter 打开后的主界面就是两张列表：上方 MAIN 列出主空间所有应用，下方 SHELTER 列出隔离空间里的应用。每张列表里每个应用右侧都有一排操作按钮——克隆、冻结、启动、卸载等，按需点选。

主界面右上角三点菜单进入设置，自动冻结、文件穿梭等高级功能的开关都在那里。

### 克隆应用到隔离空间（双开的核心）

克隆是 Shelter 最常用的动作——把主空间里的应用在隔离空间里复制一份，两个实例各自运行、数据互不影响：

1. 在 MAIN 列表里找到目标应用；
2. 点右侧的「克隆」按钮（或长按应用图标选克隆）；
3. 系统弹出确认，等几秒完成；
4. 克隆完成后，SHELTER 列表里出现同名带公文包角标的应用，桌面 WORK 标签里也能找到。

克隆出来的应用第一次打开需要重新登录账号——这就是双开的实现原理。微信、QQ、 Telegram、游戏等都可以这样各登各的号。

> [!WARNING]
> **克隆 ≠ 安装**：克隆是把主空间已有的应用复制到隔离空间，签名、版本完全一致。如果想在隔离空间装一个主空间没有的应用，可以用「直接把 APK 安装进隔离空间」功能，从 Shelter 的 APK 安装入口走。

### 冻结与解冻：让应用彻底停下来

冻结 = 禁用。被冻结的应用进程被系统强制停止，后台不再运行、推送全部不可达、耗电为零。冻结有两种方式：

**手动冻结**：在 SHELTER 列表里点应用右侧的冻结按钮（雪花图标），应用图标变灰、从 WORK 标签页消失（或显示为禁用状态）。解冻同理，点一下恢复。

**自动冻结**：Shelter 提供可定制的自动冻结服务，**屏幕关闭时自动冻结隔离空间的应用，屏幕点亮后按需解冻**。适合夜里不想被打扰的场景：

1. 打开 Shelter → 右上角三点 → 设置；
2. 找到自动冻结开关并启用；
3. 按需定制细则（具体选项随版本变化，以实际界面为准）。

> [!WARNING]
> 自动冻结期间推送不可达——把需要整夜在线的通讯应用（微信、Telegram 等）排除在自动冻结范围之外，不然早上起来会发现错过一晚消息。

### 通知收不到的排查顺序

隔离空间的通知丢失大概率不是故障，是某个开关把它关了。按可能性从高到低排查：

| 序号 | 排查项 | 怎么查 |
| --- | --- | --- |
| 1 | 应用被冻结了？ | SHELTER 列表看状态，解冻即恢复 |
| 2 | 开了自动冻结？ | 锁屏后被自动冻结的应用夜里不推送，调整范围或关闭 |
| 3 | 整个隔离空间被暂停了？ | WORK 标签从桌面消失就是信号，恢复即可 |
| 4 | 系统勿扰模式？ | 勿扰压制的通知与 Shelter 无关，但最容易误判 |
| 5 | 电池/后台管控 | 部分厂商系统对资料内应用有限制，把目标应用加白名单 |
| 6 | 应用自身通知权限 | 进应用检查通知开关与分类设置 |

> [!TIP]
> 通讯类应用放进隔离空间前先想清楚：**冻结期间消息收不到是机制使然，不是故障**。要不要实时在线，决定它能不能被冻结、能不能开自动冻结。

### 文件穿梭：跨空间传文件

Shelter 支持「文件穿梭」功能——主空间和隔离空间之间互相传文件。启用后会出现一个穿梭工具，从任意一端选文件、传到另一端，对方空间里就能看到了。默认关闭，需要在设置里手动启用并授权。

### 一键暂停整个隔离空间

如果想暂时把隔离空间全部停掉（比如借给别人用、或者做系统维护），可以用「暂停整个隔离空间」功能。暂停后 WORK 标签消失，所有隔离应用进程终止、推送停发、耗电为零。恢复也很简单，进 Shelter 点一下取消暂停就行。
