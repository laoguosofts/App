## ✨ PipePipe 是什么：一款轻量无广告的 YouTube 客户端

PipePipe 是一个开源的 Android YouTube 客户端，它不需要登录账号就能直接浏览、搜索、下载视频。相比官方 YouTube 应用，它最大的卖点是**零广告**（跳过赞助片段和前置插播）、**支持下载本地观看**、以及灵活的**悬浮窗播放器**——边聊微信边刷视频这类场景对它来说是基本操作。

核心功能集中在几个方面：视频播放（主界面 / 悬浮窗 / 后台音频）、本地下载、内容过滤（屏蔽不想看的关键词和频道）、以及 SponsorBlock 自动跳过赞助片段。它不依赖 Google Play Services，在没有装任何 Google 套件的设备上也能正常跑。

适合谁用呢？如果你嫌官方 YouTube 广告太多、想把视频存进手机离线看、或者手头有一台没装 Google 框架的安卓盒子/平板，PipePipe 是一个值得试的选择。

## 🔧 安装步骤：侧载 APK 前要注意这几点

PipePipe 不在 Google Play 上分发，安装方式是侧载 APK。流程本身不复杂，但有几个细节值得留意。

### 第一步：开启未知来源安装

安卓系统默认禁止从浏览器直接装 APK。首次安装前，需要进入 **系统设置 → 安全 → 安装未知应用**，找到你用来下载的浏览器（Chrome / Edge 等），把权限打开。不同品牌手机的路径略有差异，但关键词就是「未知来源」或「安装未知应用」。

> [!WARNING]
> 如果你之前从没侧载过应用，建议养成一条习惯：**只从你信任的来源下载 APK**。本篇文末相关资源里整理了几个可靠的获取渠道。

### 第二步：核对版本和架构

下载页通常会提供多个 APK，主要区别在架构（arm64-v8a、armeabi-v7a、x86_64）和签名版本。大部分 2020 年后的手机都是 **arm64-v8a**，选这一份就对了。不确定自己设备架构的话，装一个 CPU-Z 之类的工具就能查到。

> [!TIP]
> 同一版本号下，还有稳定版和预发布版的区分。日常使用认准稳定版（Stable），预发布版是用来测试新功能的构建，可能存在已知问题。

### 第三步：安装与首次启动

APK 下载完成后，点文件管理器找到它、双击就能触发安装。首次启动时应用会申请若干权限——存储（用来放下载的视频）、悬浮窗权限（用来弹出小窗播放）。这些都是它正常工作必需的，全部允许即可。

## 📖 使用入门：从播放到下载的核心玩法

PipePipe 的界面设计比较克制，首页就是动态流和搜索栏，没有花哨的推荐位。但它的功能深度需要进 **Settings** 才能挖出来。下面结合几个高频场景展开。

### 悬浮窗播放器：一边聊天一边看

悬浮窗（Popup Player）是 PipePipe 最实用的功能之一。视频可以缩成一个浮在所有应用之上的小窗，位置随便拖、大小随手捏，回个微信消息、刷个微博都不用暂停视频。

打开方式有两种：在视频详情页点 **Popup** 按钮直接以悬浮窗开始播放；或者在 **Settings → Player** 里把 **Minimize on app switch** 设为 *Minimize to popup player*，这样主播放器切到别的应用时会自动缩成小窗。

有几个专属设置值得调整：**Default popup resolution** 单独控制悬浮窗的画质，默认 480p，小窗不需要高分辨率，省资源也省流量；**Remember popup properties** 默认开启，下次打开会保持你上次拖好的位置和大小。

> [!NOTE]
> 悬浮窗需要 `SYSTEM_ALERT_WINDOW` 权限，也就是常说的「显示在其他应用上层」。首次弹出时系统会让你授权，允许就好；如果之后发现悬浮窗放不出来，大概率是这个权限被系统回收了，去系统设置里手动打开。

### 高级格式：想看 2K/4K 需要开对开关

PipePipe 的 2K/4K 画质不是默认就能选的，需要先在 **Settings → Player → Enable advanced formats** 里开对解码格式。四个勾选项分别对应不同的视频编码：

| 格式 | 说明 | 默认状态 |
| --- | --- | --- |
| VP9 | 开放视频编码，安卓支持面广 | 开 |
| AV1 | 新一代高效编码，软解吃性能 | 关 |
| HEVC | 视频编码，安卓支持因机型而异 | 开 |
| EC-3 | 杜比数字 Plus 音频 | 关 |

两条关键规则：一是同一分辨率下，应用按 **AV1 → VP9 → HEVC → AVC** 的顺序挑格式，勾上 AV1 后它会优先使用；二是 **2K/4K 的门槛**是 VP9 或 AV1 至少开一个，只开 VP9 就够。

> [!TIP]
> 社区建议视频放得好好的就别全勾，默认（VP9 + HEVC 开）是最稳的组合。如果出现「画面卡住、声音正常」，按顺序回退：先关 AV1 降一档，还卡就关 VP9 和 HEVC 只留 AVC 试 720p。不同编码走安卓不同的解码器，换编码在一台设备上可能救场、在另一台上反而更糟，一格一格试。

### 内容过滤：把不想看的东西直接屏蔽

PipePipe 的内容过滤比 SponsorBlock 更「一刀切」——直接把匹配的内容从搜索结果和动态流里剔掉。两个维度可以独立配置：

- **按关键词过滤**（Filter by keywords）：填不想看到的关键词，逗号分隔，标题或信息命中就整条消失
- **按频道过滤**（Filter by channels）：填不想看到的频道名，同样逗号分隔
- **Apply Filter To**：决定过滤用在哪些表面——搜索结果、动态流、相关视频等

此外还有一个总开关 **Block YouTube Shorts and paid videos**，把短视频和付费条目从浏览面里直接滤掉。对用大屏追长内容、讨厌 Shorts 干扰的人，这一个开关就能让动态流清爽大半。

两个已知的坑要注意：**已加载的列表不会追溯**——过滤规则改动后，已经加载出来的列表不会重判，刷新或重开再看效果；**生效表面要说清**——反馈「过滤不生效」时要明确它出现在哪个表面（搜索？动态？播放列表？），同一规则在不同表面的求值路径不同。

### 追更新：四个渠道选一个就好

PipePipe 有四个更新渠道，加上应用内自带的更新检查，一共五种知道有新版的途径。但渠道之间**发布时间不同步**，选定一个就固定用它，别混着追。

| 渠道 | 节奏 | 适合谁 |
| --- | --- | --- |
| GitHub Releases | 最快，源头 | 想第一时间拿修复、愿意手动装的人 |
| Obtainium | 跟随 GitHub，自动提醒 | 装好就不想管的人 |
| F-Droid | 仓库同步，有延迟 | 习惯用 F-Droid 客户端的人 |
| IzzyOnDroid | 仓库同步，有延迟 | 已在用 IzzyOnDroid 生态的人 |

应用内也自带更新检查（**Settings → Updates**），但它只**通知**你新版本存在，不会替你下载安装。某个播放故障被报修复了、但你的仓库渠道还没同步时，先去 GitHub Releases 对照最新版本号，确认修复确实进了某个稳定版，再决定是等仓库还是手动从 GitHub 装。
