## ✨ StarNote 是什么

StarNote 是一款专注于手写笔记与 PDF 批注的工具类应用，核心竞争力在于「图层系统」这一独家设计——同一张纸上叠着多张透明薄膜，每层独立书写互不干扰，需要时可以隐藏、降低透明度或直接擦除。这个特性让刷题时遮住答案反复练习成为可能，特别适合备考、课堂自测等需要反复演练的学习场景。

除了图层系统，StarNote 在 PDF 批注方面也做了差异化：它不是传统 PDF 阅读器那种「先选文本再插注释框」的交互，而是直接用笔在页面上划、圈、写，手写优先的方式让批注速度远快于规整的矩形高亮。放大镜功能解决了密集公式、小字批注等局部精细书写问题，压感笔的自然粗细变化也让整体书写体验接近真实纸笔。

软件面向需要大量阅读和笔记整理的用户群体，学生党用它刷题做课堂笔记，职场人用它在 PDF 报告上手写批注，考研考公备考党用图层系统做二轮复习遮罩。不同场景下它的侧重点不同，但手写体验和图层组织能力始终是两条主线。

## 🔧 安装步骤

StarNote 目前主要面向移动平台开发，Android 和 iOS 设备均有对应版本。安装流程因平台不同略有差异。

**Android 安装要点：**

1. 从下载入口获取 APK 安装包，建议同时核对文件大小和版本号，避免下载到旧版或损坏的文件
2. 首次安装如果系统弹出「未知来源」警告，需要进入设置 → 安全 / 隐私 → 允许安装未知来源应用，或针对当前浏览器单独授权
3. 安装完成后首次打开，建议检查是否有存储权限请求，拒绝的话可能导致后续无法导入本地 PDF 文件

> [!WARNING]
> 部分手机厂商的安全中心会将第三方 APK 标记为风险，这是正常的安全策略提示。如果确定来源可信，可以选择「允许本次安装」继续。

**iOS 安装要点：**

1. 直接在 App Store 搜索 StarNote 下载安装即可，无需额外授权
2. 首次打开时系统会请求 iCloud 同步权限，根据个人需求选择是否开启

**装完核对：**

打开应用后新建一个空白笔记页面，用手写笔写几行字，再切换钢笔粗细和颜色，确认笔迹响应正常。如果设备支持压感，可以尝试用力和轻写两种方式，看笔迹粗细是否有自然变化——压感不生效的话检查一下「设置 → 手写笔设置」里的压感开关。

## 📖 手写笔刷、PDF 批注与图层刷题全解

StarNote 的核心使用场景可以归纳为三块：笔刷参数调节、PDF 直接批注、图层刷题玩法。三者组合起来覆盖了从课堂记录到备考复习的完整链路。

### 钢笔与荧光笔：日常书写和批注的主力

钢笔是使用频率最高的笔刷类型，适合日常记录、笔记正文、解题过程等场景。它的核心参数包括笔尖粗细（从超细到特粗）、压感响应（用力越大笔迹越粗）和笔触样式（部分版本支持实线 / 虚线 / 点线三种）。调节路径是底部工具栏点击钢笔图标旁边的小三角，在弹出的面板里拖动滑块调粗细、点颜色圆点切换颜色。

荧光笔在 PDF 批注和阅读笔记中用来标记重点，是半透明的，覆盖在 PDF 原文上既能看到高亮效果又不遮挡底层文字。它的独特设计支持水平 / 垂直绘制（适合高亮整段文字时保持整洁的直线条）和可调透明度，预设色除了经典黄色还有绿色、蓝色、粉色等，方便按主题做区分。

> [!TIP]
> 上课记录用中等粗细的深色钢笔快速低延迟书写；PDF 批注用细钢笔划线 + 荧光笔高亮关键句，颜色控制在两三种以内避免杂乱；解题过程用粗一些的钢笔、步骤之间留清晰留白。

### PDF 批注：手写优先而非文字注释框

在 StarNote 中导入的 PDF 作为底图存在，放在图层最底层不可直接编辑。所有手写笔迹、高亮、形状都是叠加在 PDF 上方的可编辑图层上。这个设计意味着原始 PDF 内容不会被破坏，批注可以随时擦除、修改、重写，导出 PDF 时还能选择「保留批注」或「清除批注」两种方式。

基本批注操作包括：用钢笔在重点句子下方划线、用荧光笔在段落上半透明涂抹、用矩形或圆形形状工具圈出关键词公式、用箭头连接相关段落、在 PDF 页边空白区域直接手写思考。如果 PDF 页边空白太窄，可以使用页面留白功能增加书写空间。

与传统 PDF 阅读器（如 Adobe Reader、WPS PDF）先选文本再插注释框的交互不同，StarNote 是手写优先的，直接用笔在页面上划圈写，这种方式的优势是批注速度快得多、笔迹形态更灵活、可以用荧光笔 + 钢笔 + 形状做组合标注。

### 放大镜：解决局部精细书写

放大镜功能在以下场景特别有用：密集公式推导（下标、上标、希腊字母需要写得很小很密）、小字批注（PDF 页面留白窄时在缝隙里插注释）、密集笔迹上的精确套索、小面积擦除（只想擦掉一个字但容易蹭到旁边）、表格单元格书写（单元格太小时正常书写容易出边框）。

开启方式有两种：工具栏放大镜图标或部分版本的双指长按手势。放大镜面板上可以调整放大倍数（2x~3x 比较合适，倍数太高笔尖定位变慢），移动放大镜位置通过手指或非书写笔点住边缘拖动，在放大镜里书写时光标实时显示精细内容。放大镜模式下压感笔的力度反馈依然正常，写出来的小字能保留自然的粗细变化，关闭后效果不变。

### 图层系统：刷题遮罩是核心玩法

图层是 StarNote 区别于其他手写笔记 App 的独家功能。简单说就是同一张纸上叠着多张透明薄膜，每张膜独立书写互不干扰，可以单独设置可见、不可见、透明度，擦除只影响当前选中的图层。默认每个页面有一个底图层（PDF 或图片）加一个书写层，你可以新建额外图层用来遮罩、批注、草稿。

> [!NOTE]
> 误删的图层可以通过恢复功能找回，版本 1.4.2 起支持。

刷题的典型流程是：先在底图 PDF 上的书写层写出自己的答案，然后新建一个「参考答案」图层写上正确答案和解题步骤，切换回书写层并隐藏参考答案层开始第二遍刷题，做完一题后逐题揭开核对，用不同颜色笔迹标记错题。

推荐的图层组织方案如下：

| 图层 | 用途 |
| --- | --- |
| 底图层 | 题目 PDF 原文（不可编辑） |
| 书写层 | 自己写的答案和草稿 |
| 遮罩层 | 遮住正确答案的半透明层 |
| 标错层 | 红色笔迹标记错题位置 |
| 解析层 | 老师讲的解析、二次理解笔记 |

这样组织的好处是每层有明确用途，复习时可以按层切换查看不会乱。图层面板在页面右上角或侧边栏，支持新建、选中、可见开关、透明度调整、擦除、恢复等全部操作。
