## ✨ QBot 是什么——QQ 浏览器里的 AI 助手

QBot 是 QQ 浏览器内置的 AI 功能集合，从单轮问答一路进化到能交付成品文件的 Agent 中心。它不是一个独立的 App，而是嵌入在 QQ 浏览器里的智能层——你装了 QQ 浏览器，就自动拥有 QBot。

QBot 的核心能力分两块：一块是普通的 AI 对话（提问、翻译、总结），另一块是更有特点的 Agent 中心。Agent 中心里的智能助手跟普通问答不一样——普通问答给你一段文字建议，Agent 中心给你一份可以直接打开的 PPT、Excel 表格或者文案稿。常见的 Agent 分类包括智能助理（下载助理、财经助理、高考通）、AI 高效办公（PPT 生成、Excel 分析）、写作与润色、图像音视频处理、文件格式转换等。

**卡片式交互**是 QBot Agent 中心的另一个降低门槛的设计。传统 AI 工具要求你一开始就把所有细节想清楚写成提示词，但多数人其实说不清楚自己到底要什么——只有看到结果才知道"不对，我想要另一种"。卡片式交互反过来：先给一个大致方向开工，执行中 Agent 在关键节点弹出决策卡片（比如"封面选商务风还是科技风""用这个图表还是换另一种"），你点选一步它走一步，最终输出自然就贴合预期了。

适合什么样的用户？如果你已经在用 QQ 浏览器，QBot 是零成本就能用的 AI 能力增量——不需要额外装任何东西，也不用维护单独的账号。日常查资料、整理文档、下载文件、做简单的数据分析，QBot 都能帮你省不少事。

## 🔧 安装步骤——装 QQ 浏览器就能用

QBot 没有独立的安装包，它是 QQ 浏览器的内置功能。"安装 QBot"本质上就是安装 QQ 浏览器，然后确认 QBot 功能已启用。

### 桌面端（Windows / macOS）

1. 从下载页拿到 QQ 浏览器安装包，双击运行
2. 安装过程中注意选择安装路径——默认装在系统盘，如果系统盘空间紧张可以改到其他盘
3. 首次启动后，在新标签页或侧边栏找 **Agent 中心** / **AI 对话** 入口，能打开就说明 QBot 功能正常

> [!WARNING]
> 如果安装完成后找不到 QBot 相关入口，可能是浏览器版本较旧——去设置里检查更新，升级到最新版即可。老版本 QQ 浏览器可能还没集成完整的 Agent 中心功能。

### 手机端（Android / iOS）

1. 在应用商店搜索"QQ 浏览器"下载安装
2. 打开后登录你的 QQ 账号（也可以游客使用，但登录后功能更完整）
3. 首页或底部工具栏找 AI 相关入口，点进去就能用对话和 Agent 中心

> [!NOTE]
> 手机端 Agent 中心的入口位置可能因版本不同略有差异，但功能本身是一致的。如果首页没看到，可以在侧边栏菜单里找找。

### 安装核对清单

- [ ] QQ 浏览器能正常启动并浏览网页
- [ ] 新标签页能看到 Agent 中心或 AI 对话入口
- [ ] 点进 Agent 中心能看到各类 Agent 分类目录
- [ ] 网络连接正常（QBot 的 AI 功能需要联网）

## 📖 使用入门——从对话到交付文件的跨越

### 日常对话：提问、翻译、总结

打开 QBot 对话页，直接输入你的问题就行。这块跟市面上其他 AI 对话工具的用法差不多，区别在于 QBot 能读取当前浏览器页面的上下文——比如你正在浏览一篇长文章，可以让它帮你总结重点；你看到一段外文，可以让它翻译。

### Agent 中心：让 AI 把活干完

Agent 中心是 QBot 最有特点的功能入口。它的使用流程可以概括为四步：

1. **浏览**：进入 Agent 中心，按分类找到你需要的 Agent。比如要做 PPT 就找"PPT 生成"，要下载文件就找"下载助理"
2. **开工**：输入需求描述，或者在支持的场景下上传文件
3. **决策**：Agent 执行过程中会弹出决策卡片让你选方向（比如"封面风格选商务风还是科技风""这个标题要不要改得更抓眼球"）。你点选即可，也可以选"换一个"让它重新生成
4. **收获**：结果以卡片形式出现在对话里，点开在工作区查看，支持下载和分享

### 给 Agent 下指令的小技巧

很多人用 AI 工具卡壳，不是工具不行，而是指令给得太模糊。以下四个原则能大幅减少 Agent 的追问和返工：

| 原则 | 反例（模糊） | 正例（具体） |
| --- | --- | --- |
| 给具体名称 | "帮我找个软件" | "帮我找 VLC 媒体播放器的 Windows 版安装包" |
| 给格式要求 | "帮我整理一下" | "帮我整理成 Excel，第一列是产品名，第二列是价格" |
| 给范围边界 | "帮我分析一下这个行业" | "帮我分析 AI 浏览器市场 2024-2026 年的主要玩家和市场份额" |
| 用结构化模板 | 自己一句话描述 | 用 AI 探索面板的角色-任务-要求三段式模板 |

> [!TIP]
> 复杂任务（PPT 生成、Excel 分析这类）可能需要几十秒到一两分钟，耐心等就好。如果超过 2 分钟还没动静，刷新页面或重启浏览器再试，顺便检查下网络连接。

### 关掉打扰：按需调整推荐和推送

如果觉得 AI 相关的推荐和推送太多，可以在设置里按需关闭：

- **手机端**：打开"我的" → 右上角"设置" → 找到"隐私和安全"相关项 → 关闭 AI 推荐和推送
- **桌面端**：右上角菜单 → 设置 → 找到"隐私和安全"或"通知"相关项 → 关闭不需要的推荐

浏览过程中右上角自动弹出的 AI 功能提示（翻译、总结等）也能在设置里关掉。关掉推荐和推送**不影响核心 AI 能力**——主动提问、Agent 中心运行、手动触发的 AI 浏览功能都照常工作，只是减少了被动打扰。

### 常见问题排查

**Agent 一直转圈圈不出结果**：先等 30-60 秒，复杂任务确实需要时间。超过 2 分钟没动静就刷新页面或重启浏览器，检查网络是否正常。

**Agent 反复追问同一个问题**：这通常说明你给的输入太模糊。对照上面四个原则，把需求描述得更具体、更有边界，追问就会少很多。

**Agent 执行到一半卡壳**：可以点"换一个方向"让它重新生成，或者换一个同类型的 Agent 试试（比如"AI 写作"和"爆款文案生成"都能写文案）。如果任务本身很大，拆成多次小指令执行比一次给全量要求更稳定。
